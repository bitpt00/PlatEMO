# Codex Execution Guide

Codex executes code and repository operations. GPT Pro reviews research direction.

## Rules

- Preserve the original `CMOEA-AOP` implementation as the baseline.
- Create variants in separate algorithm directories, for example `CMOEA-AOP-X1`.
- Record every research-facing change in an iteration note.
- Run a small smoke test before any long experiment.
- Do not commit heavy raw result files.
