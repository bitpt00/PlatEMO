# PlatEMO Research Workspace

This directory records experiment design, AI review notes, implementation logs, and result summaries.

## Layout

```text
research/
  experiments/   Experiment protocols, configs, scripts, summaries, and raw-result placeholders
  kb_links.md    Pointers to the external paper knowledge base
```

Keep algorithm source code under `PlatEMO/`. Keep heavy raw outputs under each experiment's `results/` directory; those files are ignored by git by default.
