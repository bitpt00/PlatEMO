# 特殊点引导的代理辅助复杂前沿搜索

## 核心内容

在昂贵多目标优化中，不把代理辅助搜索只看成“预测目标值并挑候选”，而是显式识别 Pareto 前沿上的特殊结构。用非支配等级加权的全局代理维持整体搜索，用膝点局部开发加速高价值区域收敛，用无样本参考向量定位潜在断裂区并通过区间代理探索，最后把少量真实评价样本回灌到档案和代理中。

```text
真实评价档案 DB
-> 参考向量分配 + 非支配等级划分
-> 分层基本代理 + 等级权重集成全局代理
-> 代理内循环产生普通非支配 infill
-> 识别边缘/凸膝点, 重构局部单目标问题
-> 置信区域局部代理搜索并真实评价改进膝点
-> 识别空置参考向量, 训练断裂区局部 Kriging
-> 区间适应度探索断裂附近候选并真实评价
-> 调整长期空置参考向量, 更新代理
```

## 建立理由

- 为什么值得独立维护：复杂 PF 的膝点和断裂区域往往正是普通代理最容易忽略或误导搜索的地方。该设计把 PF 拓扑特征转成可执行的 surrogate management 与 infill 调度流程。
- 已有跨论文支持，或单篇具体方法的直接复用价值：P2026-0013 在 DTLZ、WFG、IMOP 和两个真实工程问题上验证，且给出了参数、消融、参考向量调整和真实评价回灌接口。
- 与已有设计知识的区别：
  - 不同于“自适应代理内环加速器”：本知识不只控制代理内环是否继续，而是把膝点和断裂点作为独立 infill 来源。
  - 不同于“网格排序成对关系代理筛选”：本知识不学习候选间关系排序，重点是 PF 特殊拓扑结构驱动的代理训练与真实评价分配。
  - 不同于“约束违反状态驱动的代理搜索模式切换”：本知识面向无约束或弱约束 EMOP 的复杂前沿拓扑，不按可行性状态切换。
  - 不同于“收敛-边界两步代理采样更新”：本知识关注膝点和断裂 PF，而不是昂贵约束问题的可行边界采样。

## 解决的问题

- 适用场景：
  - 真实评价预算很少，但候选生成和代理查询相对便宜；
  - Pareto 前沿存在膝点、退化、强曲率、断裂或不规则覆盖；
  - 可维护真实评价档案、参考向量集合和代理模型；
  - 希望把 infill 预算分配给普通非支配候选、局部高价值区域和稀疏断裂区域。
- 现有方法为什么会失败或不足：
  - 只用非支配样本训练代理会忽略位置重要但当前目标值暂差的样本；
  - 使用所有样本训练单一代理会被大量低等级样本稀释关键区域精度；
  - 膝点开发如果没有局部搜索范围，会在昂贵评价下浪费真实评价；
  - 断裂 PF 附近样本稀缺，代理不确定性高，普通参考向量搜索容易反复尝试不可达空洞。
- 仍需解决的问题：
  - 早期样本不足时如何区分真实断裂区和暂未覆盖区域；
  - 特殊点模块之间的真实评价预算如何自适应分配；
  - 噪声评价、约束失败和混合变量下特殊点识别是否稳定。

## 为什么可能有效

```text
复杂 PF 的误差不是均匀分布
-> 膝点影响收敛和决策价值, 断裂区影响分布和参考向量浪费
-> 全局代理负责低成本铺开搜索
-> 膝点代理把局部拓扑转成小范围单目标优化
-> 断裂区代理把预测不确定性写入区间适应度
-> 真实评价只投给能改善关键区域或校正空洞判断的候选
```

核心假设是：当前非支配档案已经能给出足够可信的膝点和空置参考向量信号。如果这些信号主要来自早期采样不足、尺度归一化错误或代理偏差，特殊点模块会放大误判。

## 如何用于算法创新

### 局部创新

- 在任意参考向量 SAEA 中增加“膝点候选真实评价”分支，专门改善边缘点和凸膝点。
- 用非支配等级、拥挤度或贡献度给代理训练样本分层，而不是全样本训练一个模型。
- 把空置参考向量作为稀疏或断裂传感器，触发局部不确定性代理和区间排序。
- 将固定 `5D` 邻域样本、`T_Dmax` 和 `NumUp` 改为由代理误差、HV 改善或真实评价成功率控制。
- 用 EHVI、LCB/UCB 或 pairwise uncertainty 替换 Kriging 区间排序。

### 结构创新

- 构建通用 infill 调度器：普通代理候选、膝点候选、断裂区候选、约束边界候选都作为可竞争的真实评价请求。
- 将 PF 拓扑传感器独立成模块，输出 knee score、gap score、uncertainty score，再由不同 MOEA/BO 后端消费。
- 与约束状态切换结合，把“可行边界、膝点、断裂空洞”共同纳入昂贵约束 MOO 的代理搜索模式。
- 与决策空间变量分解结合，只在特殊点邻域训练低维局部代理，缓解大规模决策变量退化。

## 适用条件与风险

- 适用条件：
  - 评价代价显著高于代理训练和查询代价；
  - 目标空间可用参考向量、超平面或类似结构定位前沿区域；
  - 当前档案包含足够非支配样本以识别膝点或空置方向；
  - 算法能承受多个局部代理的维护成本。
- 不适用或可能失效的条件：
  - 评价便宜，频繁代理重建得不偿失；
  - PF 较简单连续，特殊点模块收益有限；
  - 目标数很高且参考向量极稀疏，膝点和空置向量信号不稳；
  - 决策空间极大且无降维，局部代理仍难以精确；
  - 约束或仿真失败导致空置方向不代表 PF 断裂。
- 计算与实现成本：
  - 需要维护全局代理、多个膝点局部代理、多个断裂区局部代理和参考向量调整；
  - 代理重建频繁，真实评价虽少但模型管理开销明显；
  - 实现复杂度高于单一代理预筛选方法。

## 待确认

- 空置参考向量信号如何与真实断裂、暂时未覆盖、目标归一化偏差区分；
- 高目标数下膝点识别和参考向量密度是否需要单独机制；
- 特殊点模块如何与约束处理、噪声评价和仿真失败兼容；
- 多个特殊点同时请求真实评价时，预算分配是否应基于历史贡献或信息增益；
- 是否能用增量代理、局部降维或共享核矩阵降低频繁重建开销。
