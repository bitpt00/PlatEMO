# 参考解引导的跨任务知识迁移

## 核心内容

从混合种群中选择具有全局价值的精英参考解，用参考方向引导不同任务或种群之间的信息迁移，避免完全随机的信息交换。

## 解决的问题

- 适用场景：多任务、多种群或多个搜索单元之间需要交换知识。
- 现有不足：随机配对与交叉可能传播无关或有害信息，造成负迁移。
- 仍需解决：缺少显式迁移收益评价和迁移强度反馈控制。

## 为什么可能有效

```text
无方向迁移容易产生信息错配
-> 使用全局精英参考解提供迁移方向
-> 提高迁移信息与优化目标的一致性
-> 降低无效迁移并改善收敛稳定性
```

## 如何用于算法创新

### 局部创新

将基础算法中的随机跨任务交叉、随机个体交换或无筛选迁移，替换为参考解引导的子代生成方法。

### 结构创新

增加独立迁移协调角色，使多个搜索单元产生的知识先经过全局参考或质量判断，再进入其他种群。

## 适用条件与风险

- 适用条件：不同搜索单元可以使用统一表示，且能够获得可靠参考解。
- 可能失效：参考解质量差、过于集中，或不同任务之间无法直接迁移。
- 风险：过度依赖精英方向可能削弱探索性。
