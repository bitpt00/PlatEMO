# Transformer 中段替代迭代的 MOEA 加速

## 核心内容

在昂贵多目标进化优化中，不让神经模型直接替代最终优化器，也不只把它当作普通 objective surrogate。先运行若干代真实 MOEA，收集当前问题和工况下的目标向量与决策变量轨迹；随后训练 Transformer 学习从 objective vector 到 decision vector 的映射，在中段用模型推理替代一段真实迭代；最后把预测解集作为后续种群初值，恢复 MOEA 的档案维护、选择、变异和约束修正。

P2026-0134 的 Transformer-MOHDMFOO 是该模式的实例：前 `t1` 代 MOHDMFOO 记录两个目标值（转子速度误差、无功功率误差）及 8 个 PI 参数；当 `t1 < t < t2` 时训练 Transformer 并预测新解集；预测结果作为 `t2+1` 代初始种群；后段继续使用 AGS 外部档案、RWS 全局最优选择和多分数阶自适应更新来精修。

```text
real MOEA warm-up
-> collect trajectory pairs (objective vector, decision vector)
-> train sequence model / Transformer
-> skip middle expensive iterations by inference
-> seed population at t2+1
-> resume MOEA refinement and archive maintenance
-> final nondominated solution set
```

## 建立理由

- 为什么值得独立维护：
  - 很多工程 MOEA 的真实仿真耗时远高于训练一个中小模型；
  - 普通 surrogate-assisted MOEA 往往预测目标值或做单点评价筛选，而本模式直接跳过一段进化轨迹；
  - 后段回到 MOEA，可保留非支配档案、多样性维护和约束修正，降低神经模型直接决策的风险；
  - 加速区间 `(t1,t2)` 和使用比例 `(t2-t1)/tmax` 是天然的预算控制接口。
- 单篇具体方法的直接复用价值：
  - P2026-0134 给出 objective-to-decision Transformer、在线历史轨迹训练、预测种群接入和后段精修伪代码；
  - 三个 DFIG-WTS 工况均显示相对无 Transformer 的 MOHDMFOO 至少约 75% 时间降低；
  - 与 TSEMO 的讨论说明该问题需要较宽 Pareto 解集时，串行 BO 虽能靠近真前沿但解数和分布宽度不足。
- 与已有设计知识的区别：
  - 不同于“自适应代理内环加速器”：该知识是在 MOEA 中用 surrogate 跑短期内循环并分配真实评价；本知识是用 Transformer 跳过一段迭代后再把种群交回原 MOEA。
  - 不同于“代理训练的注意力残差子代生成算子”：该知识生成 offspring 操作；本知识生成中段结束时的整代初始解集。
  - 不同于“预测代理驱动的实时多目标控制优化”：该知识关注实时控制决策和代理目标建模；本知识关注 MOEA 运行过程中的轨迹级加速。
  - 不同于“Transformer 概率预测 + Pareto 运维”的调度类知识：本知识中的 Transformer 预测决策变量种群，不是预测外部时间序列负荷或风险。

## 解决的问题

- 适用场景：
  - 每代需要大量仿真、控制模型或数字孪生评价；
  - 优化轨迹在同类问题/工况内具有可学习结构；
  - 仍需要较完整 Pareto 解集，而不是极少数串行 BO infill 点；
  - 前段真实迭代能提供足够在线数据；
  - 后段 MOEA 能处理预测误差、约束违反和多样性恢复。
- 现有方法为什么会失败或不足：
  - 纯 MOEA 真实迭代慢；
  - 直接神经预测最终解可能不可行、偏窄或不可解释；
  - 普通 objective surrogate 需要频繁代理评价和真假评价切换，不能直接减少一整段迭代；
  - 低预算串行 BO 可以快收敛到少数点，但在需要大量分布良好的 Pareto 解时不足；
  - 固定启发式加速区间可能不匹配不同复杂度问题。
- 仍需解决的问题：
  - objective-to-decision 映射可能一对多，Transformer 需要多样性或条件化机制；
  - 模型何时可信、何时进入/退出加速区间需要在线诊断；
  - 预测种群可能聚集，需要接入双空间多样性修复；
  - 跨工况、跨问题迁移时可能出现 out-of-distribution 预测；
  - 低复杂度问题中训练模型的成本和误差可能超过收益。

## 为什么可能有效

```text
expensive simulation dominates runtime
-> replacing N middle generations saves many evaluations

warm-up data is generated by the same optimizer and current scenario
-> Transformer sees local trajectory structure rather than unrelated offline data

prediction is not final decision
-> resumed MOEA can repair infeasibility and restore convergence/diversity

archive and diversity mechanisms remain active
-> final output is still a nondominated population, not one neural guess
```

核心假设是：前段真实迭代已经揭示了“目标区域与可行决策变量”之间的稳定映射，且中段搜索轨迹可以由模型近似。如果问题高度多峰、目标到决策变量强一对多、工况突然变化，或者前段样本太少，预测种群会偏窄或失真，必须依赖后段修复。

## 实现接口

- 输入：
  - 基础 MOEA 状态：种群、外部档案、约束处理器、评价预算；
  - 前 `t1` 代历史数据 `H={(f(x), x, optional metadata)}`；
  - 加速区间参数 `t1,t2,tmax`；
  - Transformer/sequence model、训练超参数和 early stopping 条件；
  - 预测解的 bounds/constraints 修复函数；
  - 后段 MOEA 的环境选择与多样性维护模块。
- 输出：
  - `t2+1` 代预测初始种群；
  - 训练误差、预测不确定性或可信度诊断；
  - 继续优化后的最终非支配档案。
- 插入位置：
  - 昂贵仿真 MOEA 的中段代际循环；
  - 控制器参数调优、能源调度、数字孪生校准、工程参数寻优；
  - 多任务/多工况优化中的 warm-start seeding 模块；
  - 与代理辅助评价、低保真仿真或 GPU 并行评价组合的预算调度层。
- 最小实现：

```text
initialize population P0 and archive A0

for t in 1..tmax:
    if t <= t1:
        evaluate real objectives
        update archive and population by base MOEA
        store (f(x), x) into H

    else if t1 < t < t2 and model_not_used:
        train Transformer on H: f(x) -> x
        P = predict_population_from_recent_objectives(H)
        P = repair_bounds_constraints_and_diversity(P)
        t = t2 + 1

    else:
        evaluate real objectives
        update archive and population by base MOEA

return nondominated archive A
```

## 如何用于算法创新

### 局部创新

- 用 HV plateau、档案新增率、训练误差和约束违反率共同触发 `t1,t2`。
- 用 ensemble Transformer 或 dropout uncertainty，对预测种群做风险排序。
- 预测多个候选子种群，再用决策空间距离、目标空间 reference vectors 或 crowding 做覆盖选择。
- 把输入从纯 objective vector 扩展为 objective、rank、crowding、constraint violation、generation index、scenario embedding。
- 在进入后段前加入 feasibility repair、local search 或 trust-region projection。

### 结构创新

- 通用三段式昂贵 MOEA 加速：

```text
MOEA evidence collection
-> neural trajectory compression
-> population seeding
-> MOEA verification/refinement
```

- 与多保真优化组合：中段 Transformer 先给低保真/代理种群，后段只对高潜力区域做高保真评价。
- 与多任务优化组合：源任务训练 trajectory prior，目标任务前 `t1` 代微调，再跳过中段。
- 与交互式 MOO 组合：用户指定偏好目标区域，Transformer 预测该区域候选解，MOEA 后段负责可行性和 Pareto 校正。
- 与并行岛模型组合：各岛学习本岛轨迹，driver 合并预测种群并用非支配排序迁移。

## 适用条件与风险

- 适用条件：
  - 真实评价或仿真调用是主要时间瓶颈；
  - 每次运行的前段轨迹足以训练模型；
  - 需要一个分布较宽的 Pareto 解集；
  - 基础 MOEA 有可靠的档案和多样性维护；
  - 允许中段预测后再花预算做后段校正。
- 不适用或可能失效的条件：
  - 评价便宜，模型训练与调参不划算；
  - 问题低复杂度，普通 MOEA 已足够快；
  - 同一 objective vector 对应多个相距很远的决策解，单一回归会平均化；
  - 强约束或离散变量使预测解大量不可行；
  - 工况变化导致前段轨迹不能代表后段。
- 计算与实现成本：
  - 需要额外的训练时间和超参数选择；
  - 需要存储并清洗历史轨迹；
  - 需要保证预测种群的 bounds、constraints 和多样性；
  - 若基础 MOEA 已有并行评价或强代理层，新增 Transformer 的边际收益需重新评估。

## 证据边界

- 当前只有单篇论文证据，且应用集中在 DFIG-WTS PI 参数调优。
- 三个 case 的对比基线中没有其他同类 neural iteration skipping 方法。
- Transformer 的结构细节、训练集规模和 `t1,t2` 选择原则描述不足，复现时需要补充。
- 结果表支持显著降时，但仍使用 50 个体、100 代的大规模评价；低预算昂贵优化未必适用。
- Table 8 在正文预算与表格抽取上存在 800/1000 次评估不一致，需要回看 PDF 原表或源数据。
- 缺少预测种群多样性、约束违反率和后段修复贡献的单独消融。

## 待确认

- objective-to-decision 预测是否需要多模态生成模型而不是点估计回归；
- 加速区间如何自动触发和提前终止；
- 预测种群进入后段前是否需要显式 decision-space diversity repair；
- 跨工况迁移时是否可复用旧运行的 Transformer 权重；
- 与 surrogate-assisted MOEA、parallel island MOEA、multi-fidelity MOEA 的组合收益是否可加。
