# 网格排序成对关系代理筛选

## 核心内容

在昂贵多目标优化中，不让代理模型直接预测多个目标值，而是学习两个解之间的相对优劣关系。先用网格环境选择筛出高质量子集，再只在该子集上构造成对训练样本，训练关系代理；之后把候选与多个参考点双向比较并累积分数，最后只真实评价少量高分且远离已评价样本的候选。

```text
真实评价档案
-> 网格排序选出高质量 Pbest
-> 构造 (x,y)/(y,x) 成对关系样本
-> 训练关系代理
-> 选择参考点 Pref
-> 候选与参考点双向比较并打分
-> 距离过滤和 Top candidates 真实评价
-> 更新档案与工作种群
```

## 建立理由

- 为什么值得独立维护：它把昂贵 MOO 的代理任务从“多目标值回归”改为“相对关系排序”，并给出可操作的训练样本裁剪和候选打分流程。
- 单篇具体方法的直接复用价值：P2026-0009 在 88 个 DTLZ/WFG 实例、CSI 真实问题、训练集规模、质量度量、参考点和代理模型消融上都给出证据。
- 与已有设计知识的区别：
  - 不同于“自适应代理内环加速器”：该知识关注代理内循环贡献和退出机制；本知识关注关系代理的训练样本构造与候选排序。
  - 不同于“预测代理驱动的实时多目标控制优化”：该知识用于实时工程控制和 Bayesian MOO；本知识用于 EMOP 的进化候选预筛选。
  - 不同于“约束违反状态驱动的代理搜索模式切换”：本知识不处理约束模式调度，而是处理无约束或弱约束场景中的 pairwise surrogate ranking。
  - 不同于“目标条件化生成式设计采样”：本知识不生成目标条件化样本，而是给已有候选排序并分配真实评价预算。

## 解决的问题

- 适用场景：
  - 真实评价昂贵，无法大量评估候选；
  - 多目标值回归代理不稳定或训练成本高；
  - 分类代理存在好/坏样本不平衡；
  - 算法能维护真实评价档案，并能在每轮生成大量候选供代理筛选；
  - 需要在收敛和分布之间用参考点或网格信息保持平衡。
- 现有方法为什么会失败或不足：
  - 回归代理必须预测所有目标值，有限样本下误差会直接传递到选择；
  - 简单二分类代理会受类别不平衡和阈值选择影响；
  - 全部样本两两配对会产生大量冗余关系，训练时间上升；
  - 只按单个精英或单一指标评分候选，会导致目标空间覆盖不足。
- 仍需解决的问题：
  - 关系标签如何处理互不支配、近似相等和噪声评价；
  - 高目标数下网格排序和参考点选择是否仍足够稳定；
  - 训练对数量、代理复杂度和真实评价收益之间如何自适应平衡；
  - 离散、混合变量和带约束问题中距离过滤如何定义。

## 为什么可能有效

```text
多目标绝对值难预测
-> 两个解的相对优劣可能更容易学习
-> (x,y)/(y,x) 天然产生方向相反样本, 缓解类别不平衡
-> 网格排序先去掉低价值样本, 减少训练对和噪声关系
-> 候选对多个参考点比较, 避免只围绕单个当前最优解搜索
-> 真实评价闭环修正代理偏差
```

核心假设是：目标空间中的网格质量排序能选出对学习相对优劣最有价值的样本；如果网格排序本身被退化 PF、断裂 PF 或 many-objective 稀疏性误导，关系代理会继承这种偏差。

## 实现接口

- 输入：
  - 当前真实评价档案 `Arc`；
  - 当前工作种群及其目标值；
  - 网格划分参数 `div`；
  - 参考向量集合和参考点数量 `k`；
  - 代理训练器，可为 PNN、DT、RF、SVM 或其他 pairwise ranking model；
  - 候选生成器和真实评价预算。
- 输出：
  - 关系代理模型；
  - 候选关系分数；
  - 供真实评价的少量 promising candidates；
  - 更新后的档案和工作种群。
- 插入位置：
  - expensive MOEA 的 surrogate management 层；
  - offspring generation 后、true evaluation 前的候选预筛选；
  - reference-vector 或 grid-based MOEA 的候选排序模块。
- 最小实现：

```text
Pbest <- grid_environmental_selection(P, N/2, div)
Dtrain <- []
for each ordered pair (xi, xj) in Pbest:
    Dtrain.add(concat(xi, xj), relation_label(xi, xj))
model <- train_pairwise_surrogate(Dtrain)

Pref <- select_reference_points(P, reference_vectors, k, progress)
candidates <- generate_many_candidates(P)
for x in candidates:
    score[x] <- 0
    for y in Pref:
        score[x] += predict(model, concat(x, y))
        score[x] -= predict(model, concat(y, x))

Q <- distance_filter(candidates, Arc)
evaluate top scored Q by true functions
update Arc and P
```

- P2026-0009 的具体实例：
  - 用 GrEA 风格网格选择和 `GR` 估计收敛质量；
  - 从前 `N/2` 个个体构造 `(N/2)(N/2-1)` 个有序训练对；
  - 关系代理采用 PNN，带宽参数 `sigma=0.2`；
  - `k=6` 个参考点由参考向量激活、k-means 聚类和 APD 选择得到；
  - 候选需满足与历史真实评价点的距离大于 `gamma*Delta_g`；
  - 每轮最多真实评价 6 个候选。

## 如何用于算法创新

### 局部创新

- 用 pairwise ranking surrogate 替代某个 SAEA 中的目标值回归代理。
- 把固定 `N/2` 训练样本改为按网格拥挤度、预测不确定性或历史贡献自适应选样。
- 对关系预测加入置信度门控，只真实评价高分且高置信或高信息增益候选。
- 将二值关系标签扩展为三值或软标签，降低互不支配和近似相等样本带来的噪声。
- 将候选与参考点的分数改为多任务打分：收敛关系、分布关系、可行性关系分别建模。

### 结构创新

- 构建通用昂贵 MOO 代理层：质量筛选器、关系训练器、参考任务集、候选打分器和真实评价门控相互独立。
- 与代理贡献退出机制结合：若关系代理推荐候选的真实贡献下降，则减少内循环代数或切换到其他代理。
- 与约束状态切换结合：全可行阶段学习目标关系，全不可行阶段学习 CV 改善关系，部分可行阶段混合两类关系。
- 与生成模型结合：生成模型负责提出候选，关系代理负责排序和去重，真实评价负责闭环校正。

## 适用条件与风险

- 适用条件：
  - 真实评价预算明显小于候选生成预算；
  - 可获得历史真实评价样本及其目标值；
  - 相对优劣关系比精确目标值更容易学习；
  - 目标空间质量度量能够提供较可靠的训练样本筛选；
  - 候选生成器能产生足够多的备选个体供代理排序。
- 不适用或可能失效的条件：
  - 评价便宜，代理训练和候选筛选开销不划算；
  - 目标空间严重退化或断裂，网格排序无法代表真实搜索价值；
  - 互不支配关系过多且标签定义粗糙，导致关系学习噪声大；
  - 决策空间距离与目标变化弱相关，距离过滤可能错误排除有效候选；
  - 高目标数下参考点激活稀疏，候选分数可能不稳定。
- 计算与实现成本：
  - 训练对数量随入选样本二次增长；
  - 需要维护网格、参考点、代理模型和真实评价档案；
  - 相比简单分类代理更复杂，但可避免多目标回归代理的目标值预测开销。
- 解释风险：
  - 关系代理输出不是 Pareto dominance 的严格证明，只是基于训练数据的预测评分；
  - 网格排序选出的高质量子集可能减少噪声，也可能丢掉边缘稀有区域；
  - CSI 结果支持工程可用性，但论文并未直接解决显式约束处理。

## 证据边界

- 当前只有单篇论文证据。
- 主要 benchmark 是无约束 DTLZ/WFG；CSI 只说明工程问题可用性，不代表通用约束处理。
- DTLZ7 和 WFG4 上 K-RVEA 更强，说明断裂 PF 或特定复杂 PF 下该方法不是稳胜。
- `N/2` 训练样本策略主要由时间效率支持，性能优势不是绝对。
- 关系代理的标签定义、近似相等样本和噪声样本处理仍需进一步验证。

- 如何扩展到显式约束、离散/混合变量和噪声评价；
