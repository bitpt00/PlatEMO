# 目标解耦双 Critic 的多目标连续控制

## 核心内容

在连续动作多目标控制中，不把多个目标先压成一个 reward 再训练单个 critic，而是为每个关键目标维护独立 critic。Actor 更新时按偏好权重组合多个 Q 值或 Q 梯度，从而生成不同偏好的连续动作策略。训练后通过扫描或采样偏好权重，得到一组可行策略和近似 Pareto 前沿。

```text
定义连续状态和连续动作
-> 为每个目标设计 reward
-> 每个目标训练一个 critic
-> actor 用加权 Q 值/梯度更新
-> 对动作做约束投影或安全修正
-> 采样不同偏好权重生成策略集合
-> 形成 Pareto 决策面供选择
```

P2026-0063 的实例为 rail welded joint grinding：Critic-1 评估磨削量，Critic-2 评估打磨次数；actor 输出连续打磨深度和位置；动作被投影到最大允许磨削深度内，并用直顺度罚项保证几何质量。

## 建立理由

- 为什么值得独立维护：
  - 连续动作工程控制中，多目标常常既冲突又不能简单离散化。
  - 独立 critic 能保留每个目标的价值结构，避免单 reward 过早把 trade-off 混在一起。
  - 偏好权重位于 actor 更新层，天然支持面向不同用户、场景或资源约束生成多种策略。
- 单篇具体方法的直接复用价值：
  - P2026-0063 明确给出 `Q1/Q2`、加权 actor loss、投影约束、拉格朗日罚项和 target network 更新。
  - 实验显示两个 critic 在 6000 steps 内稳定，且 300 组偏好权重能为单个 case 生成 220 个以上可行策略。
  - 现场验证显示模型输出可转化为实际工程作业序列。
- 与已有设计知识的区别：
  - 不同于“状态驱动的 DRL 演化算子选择”：这里 RL 直接输出连续控制动作，不是选择进化算子。
  - 不同于“POMIS 约束的元获取策略学习”：这里不是选择 BO 的下一次干预，而是训练连续控制策略。
  - 不同于“预测代理驱动的实时多目标控制优化”：这里不先训练静态代理再做 BO，而是通过 actor-critic 学习闭环策略。

## 解决的问题

- 适用场景：
  - 决策变量是连续动作，如控制量、位置、深度、速度、流量或功率；
  - 多个目标长期回报不同，且偏好会随场景变化；
  - 离散化会明显损失控制精度；
  - 可以定义模拟环境、数字孪生或可重复的离线训练环境。
- 现有方法为什么会失败或不足：
  - 单 reward 标量化让目标尺度、权重和约束惩罚纠缠，难以解释每个目标贡献。
  - 离散动作 RL 会牺牲连续控制精度或造成动作空间爆炸。
  - 后验 Pareto 筛选若只基于单策略输出，无法覆盖不同偏好下的动作模式。
  - 传统启发式规则难以根据当前状态生成精细连续动作。
- 仍需解决的问题：
  - 多 critic 的 reward 尺度需要归一化，否则 actor 更新会被某个 critic 主导。
  - 权重采样只能近似 Pareto 面，可能漏掉非凸或不连续区域。
  - critic 之间可能对同一动作给出冲突梯度，导致训练震荡。

## 为什么可能有效

```text
每个目标有不同长期回报结构
-> 独立 critic 分别学习这些结构
-> actor 更新时保留可调偏好权重
-> 同一个状态下可生成不同偏好的连续动作
-> 约束投影和罚项减少不可执行策略
-> 多权重扫描形成决策支持用 Pareto 集
```

关键假设是：各目标的回报可以被相对独立地估计，并且加权 Q 梯度足以引导 actor 在偏好变化时移动到不同有效策略。

## 实现接口

- 输入：
  - 状态表示，如传感器序列、系统状态、残余误差、时间/阶段和操作上下文；
  - 连续动作定义及上下界；
  - 每个目标的 reward 函数；
  - 偏好权重集合或在线偏好输入；
  - 可行性约束、动作投影或安全过滤器。
- 输出：
  - 连续控制动作；
  - 每个 critic 的 Q 值或目标贡献；
  - 不同偏好权重下的策略集合与 Pareto front。
- 插入位置：
  - 连续动作工程控制器；
  - 数字孪生或模拟环境驱动的离线策略学习；
  - 多目标决策支持系统的候选策略生成模块。
- P2026-0063 的默认实例：
  - 状态为 5 m 焊缝纵向轮廓 `Y(t)`、残余弦幅和迭代上下文；
  - 动作为各位置打磨深度 `G_t`；
  - 目标为最小化总磨削量 `V` 和打磨次数 `J`；
  - 两个 reward 都包含直顺度阈值违反惩罚；
  - actor loss 为 `-E[omega_1 Q_1(s,mu(s)) + omega_2 Q_2(s,mu(s))]`；
  - 深度通过 `g_i,t <- min(g_i,t,T_i,t)` 投影；
  - target network soft update 使用 `tau=0.005`；
  - 训练中加入 Gaussian action noise。

## 如何用于算法创新

### 局部创新

- 从双 critic 扩展为 critic bank，每个目标或约束风险一个 critic。
- 用动态偏好权重替代固定权重，让调度系统、用户偏好或安全风险实时改变 actor 更新方向。
- 对冲突 critic 梯度使用 PCGrad、normalized gradient 或 Pareto stationarity 方法减少梯度冲突。
- 在 actor 输出后加入设备量化、可执行动作压缩或安全控制 barrier。
- 用不确定性 critic 判断哪些策略需要真实环境复核。

### 结构创新

- 构建连续控制决策支持框架：

```text
状态感知
-> 多目标 critic bank
-> 偏好条件 actor 或权重扫描
-> 安全投影/约束修正
-> Pareto 策略集
-> 人机协同选择
```

- 与代理 MOO 结合：critic 学习长期控制价值，代理模型预测即时目标和约束，二者共同筛选动作。
- 与离线 RL 结合：先在历史/模拟数据中训练安全策略，再用少量现场反馈做保守更新。
- 与分层控制结合：上层选择目标权重或工作模式，下层 dual-critic actor 输出连续动作。

## 适用条件与风险

- 适用条件：
  - 存在可训练的模拟环境、数字孪生或足够离线交互数据；
  - 动作连续且离散化代价高；
  - 多个目标都能定义 reward，并可在训练中观察；
  - 有可实现的动作边界和安全约束。
- 不适用或可能失效的条件：
  - 环境模型与真实系统偏差大，现场执行风险高；
  - reward 尺度相差过大，权重无法稳定表达偏好；
  - 目标数过多导致 critic bank 和权重扫描成本过高；
  - 约束是硬安全约束，仅靠罚项不够可靠。
- 计算与实现成本：
  - 训练成本高于单 critic DDPG；
  - 每个目标需要单独 reward、critic 和监控指标；
  - 多权重生成策略集会增加推理或后处理成本，但可离线完成。

## 证据边界

- 当前只有单篇论文证据。
- 缺少与单 critic DDPG、传统 MOEA、Pareto Q-learning 或启发式规则的系统消融对比。
- 现场验证只有两个 case，主要支持 feasibility，不足以证明普遍最优。
- 目标只覆盖磨削量和次数，尚未证明加入更多目标时训练仍稳定。
- 设备分辨率、操作误差和现场安全约束仍需额外处理，不能只依赖连续 actor 输出。
