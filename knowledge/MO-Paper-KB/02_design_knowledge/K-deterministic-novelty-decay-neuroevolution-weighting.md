# 确定性新颖性衰减的神经进化权重调度

## 核心内容

在结构进化或神经架构搜索中，把候选解的行为新颖性作为早期探索压力，并让新颖性权重随代数确定性下降；与此同时，性能、泛化或任务目标的权重逐渐上升。这样算法不需要额外反馈控制器，也能从“多看不同结构”平滑过渡到“集中优化有效结构”。

```text
定义行为描述符
-> 计算候选与历史/种群的行为新颖性
-> 早期给新颖性较高权重
-> 按代数线性或其他确定性曲线衰减新颖性权重
-> 同步提高性能目标权重
-> 后期由准确率、泛化、成本等任务目标主导搜索
```

P2026-0040 的实例为 NEAT-dyMO：行为描述符包含网络拓扑、训练超参数和采样特征掩码；新颖性距离使用 Gower distance；新颖性权重从初值线性衰减到下限，性能权重为 `1-w_N(t)`。

## 建立理由

- 为什么值得独立维护：
  - 结构搜索、NAS、GP 和多算子进化都需要在探索新结构与优化已有结构之间切换。
  - 该方法提供低成本控制接口：行为描述符、新颖性分数、代数 schedule 和标量 fitness 组合。
  - 它不依赖特定垃圾检测数据集，也不依赖 NEAT 的全部实现，可迁移到其他结构候选生成框架。
- 单篇具体方法的直接复用价值：
  - P2026-0040 明确给出三目标信号、行为描述符、Gower novelty 和动态权重公式；
  - 实验覆盖图像、语音和文本三种模态，NEAT-dyMO 相对静态权重和多个基线有稳定优势；
  - SHAP 分析提供机制证据：早期探索更偏大结构和 dropout，后期准确率更受较小学习率和中等 batch size 影响。
- 与已有设计知识的区别：
  - 不同于“成功率反馈的算子与参数自适应选择”：这里不根据近期成功率更新概率，而是用预设时间 schedule 控制探索压力。
  - 不同于“状态驱动的 DRL 演化算子选择”：这里没有状态编码、reward、replay buffer 或策略网络。
  - 不同于一般 novelty search：新颖性不是永久主导目标，而是早期引导项，后期被任务目标接管。

## 解决的问题

- 适用场景：
  - 搜索对象是结构、程序、网络拓扑、组合方案或混合超参数；
  - 早期容易陷入少数高适应度但结构单一的区域；
  - 可以为候选解定义行为描述符，并计算与种群或档案的差异；
  - 反馈控制器或 RL 调度太重，或者可用预算不足以稳定训练策略。
- 现有方法为什么会失败或不足：
  - 固定高新颖性权重可能后期仍奖励无效差异，拖慢收敛。
  - 固定低新颖性权重又可能早期不够探索，错过潜在结构。
  - 静态标量权重难以同时满足不同搜索阶段的需求。
  - 反馈式控制虽然灵活，但需要额外状态、奖励和稳定性设计。
- 仍需解决的问题：
  - schedule 参数若设置不当，可能过早收敛或过久探索。
  - 行为描述符不充分时，新颖性会奖励表面差异。
  - 动态标量化可能掩盖真实 Pareto trade-off。

## 为什么可能有效

```text
早期结构空间不确定性高
-> 新颖性奖励扩大拓扑和超参数覆盖
-> 随代数推进，已有多样结构可供选择
-> 降低新颖性权重，减少无效差异奖励
-> 性能和泛化目标接管搜索
-> 后期集中改进可用结构
```

关键假设是：早期行为多样性能够提高发现高潜力结构的概率，而搜索后期更需要把评价预算用于性能、泛化或成本改进。

## 实现接口

- 输入：
  - 行为描述符，如结构规模、连接模式、算子使用轨迹、超参数、输出响应、特征掩码或约束违反模式；
  - 新颖性距离函数，如 Gower distance、Hamming distance、graph edit distance、embedding distance 或行为输出距离；
  - 任务目标，如准确率、损失、泛化间隙、HV/IGD 贡献、推理成本或可行性；
  - schedule 参数，如初始新颖性权重、最低新颖性权重、最大代数和曲线形状。
- 输出：
  - 当前代新颖性权重和任务目标权重；
  - 用于选择或排序候选解的动态标量 fitness；
  - 可选的新颖性档案与行为描述符日志。
- 插入位置：
  - 候选解评价之后、选择之前；
  - 或作为多算子/结构候选生成模块的额外排序压力。
- P2026-0040 的默认实例：
  - 行为描述符 `b(g)=[L, n, activation, dropout, learning rate, batch size, sampled feature mask]`；
  - 新颖性使用混合变量 Gower distance；
  - 泛化间隙为 `G(h)=max(0,A_train(h)-A_val(h))`；
  - 新颖性权重 `w_N(t)` 从初值线性衰减到 `w_min`；
  - 任务权重 `w_F(t)=1-w_N(t)`；
  - 动态 fitness 近似为 `w_F(t)*F_initial(h)+w_N(t)*N(g)`。

## 如何用于算法创新

### 局部创新

- 将行为描述符从手工超参数扩展为输出行为、局部搜索轨迹、参考向量覆盖、约束违反模式或可行性恢复路径。
- 把线性衰减换成 sigmoid、分段、余弦、预算感知或停滞触发 schedule。
- 将任务目标从准确率替换为多目标档案贡献、HV 增量、IGD 改善、推理成本或鲁棒性。
- 在不同物种、子种群、参考向量或问题区域使用不同的新颖性衰减速度。
- 给新颖性设置最低保留权重，避免后期完全丢失多样性。

### 结构创新

- 构建轻量策略层：

```text
行为档案/描述符
-> 新颖性评分
-> 确定性权重调度
-> 候选结构选择
-> 演化历史诊断
```

- 与多种群框架结合：探索型子种群保持较慢衰减，开发型子种群快速降低新颖性权重。
- 与代理模型结合：早期用新颖性扩展训练集覆盖，后期用代理不确定性和性能贡献共同筛选真实评价样本。
- 与演化历史 XAI 结合：用 SHAP 或敏感性分析复盘 schedule 是否过快或过慢，再调整下一轮搜索。

## 适用条件与风险

- 适用条件：
  - 候选结构或策略之间存在可描述的行为差异；
  - 新颖性计算成本低于或远低于真实评价成本；
  - 搜索预算足够经历探索和开发两个阶段；
  - 任务目标经过归一化，能与新颖性分数稳定组合。
- 不适用或可能失效的条件：
  - 行为描述符与最终性能几乎无关，只捕捉无意义差异；
  - 评价预算太短，schedule 尚未完成有效切换；
  - 问题需要持续探索，过早降低新颖性会丢失后期新模式；
  - 目标间冲突强，动态标量 fitness 丢掉了应保留的 Pareto 结构。
- 计算与实现成本：
  - 需要维护行为描述符和可能的新颖性档案；
  - Gower 或其他距离计算会随档案大小增长，可用近邻采样或滑动档案控制成本；
  - 总体低于训练 RL 控制器或复杂反馈调度器。

## 证据边界

- 当前只有单篇论文证据。
- 证据来自多模态垃圾检测分类，不代表所有 NAS、GP 或通用多目标优化问题。
- 图像任务接近性能天花板，部分全局显著性检验不强。
- 动态标量化与真正 Pareto 保留策略的长期权衡仍需更多消融。
- schedule 参数、描述符权重和新颖性档案大小对性能的敏感性还不充分。

## 待确认

- 新颖性衰减速度是否应随种群多样性、停滞程度或评价预算自适应；
- 行为描述符应如何自动学习，而不是手工定义；
- 在强约束、多峰、动态或昂贵优化中，最低新颖性权重应如何设置；
- 多目标场景下是否应保留动态权重之外的 Pareto archive；
- 与 bandit、成功率反馈和 DRL 调度相比，何时确定性 schedule 更划算。
