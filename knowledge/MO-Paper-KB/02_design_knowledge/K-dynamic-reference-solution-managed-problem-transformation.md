# 动态参考解管理的问题变换

## 核心内容

在大规模多目标 problem transformation 中，不把参考解视为固定映射锚点，而是维护一个随搜索过程更新的参考解集合：原始高维空间优化器持续发现高质量候选，周期性替换 PT 中不再贡献的参考解；低维权重空间通过当前参考解映射回高维候选，并与原始空间候选共同参加环境选择。

```text
原始空间优化器产生候选 P
-> PT 用参考解 T 将低维权重 W 映射为高维候选 Pw
-> P 与 Pw 共同环境选择
-> 识别 T 中过时或无贡献参考解
-> 用 P 中高质量解或其探索变体刷新 T
-> 更新后的 T 继续指导下一轮 PT
```

P2026-0007 的实例中，原始空间优化器是 EIEA，低维权重空间优化器是 RVEA，环境选择采用参考向量和 PBI。

## 建立理由

- 为什么值得独立维护：
  - 它抓住 PT 方法的关键失效点：参考解一旦过时，低维权重再优化也可能被错误锚点限制。
  - 它给出了可迁移的“参考解贡献评价 -> 替换 -> 重新生成权重 -> 与主种群共同选择”接口。
- 单篇具体方法的直接复用价值：
  - P2026-0007 给出 Algorithm 1/3/4 和 toy example，说明 EIEA 与 PT 如何双向交换；
  - 消融中去掉人口交换/参考解更新后性能显著下降；
  - 5000 维 LSMOP/DTLZ 实验证明该机制可用于超高维连续问题。
- 与已有设计知识的区别：
  - 不同于参考解引导的跨任务知识迁移：本知识中的参考解是 PT 的映射锚点，不是在多任务间迁移信息。
  - 不同于依赖结构指导变异：它不直接学习变量依赖，而是通过参考锚点和低维权重搜索改造候选生成。
  - 不同于资源分配：它调度的是参考解生命周期，不是函数评价预算。

## 解决的问题

- 适用场景：
  - 决策变量维度很高，直接生成高维候选效率低；
  - 已有 PT 框架依赖参考解将低维权重映射回原始空间；
  - 参考解质量会随搜索阶段变化；
  - 主优化器能在原始空间发现可作为新锚点的候选解。
- 现有方法为什么会失败或不足：
  - 固定参考解会把映射候选限制在早期局部区域；
  - 简单选择参考解不能反映当前搜索状态；
  - PT 只优化权重而不刷新锚点时，会丢失高维空间新发现的信息；
  - 主优化器和 PT 分开运行时，双方不能共享各自优势。
- 仍需解决的问题：
  - 如何严格定义“参考解不再贡献”；
  - 如何在参考解更新中平衡收敛锚点和探索锚点；
  - 如何处理变量分组错误和强交互变量。

## 为什么可能有效

```text
PT 降维依赖参考解映射
-> 参考解过时会导致映射候选质量下降
-> 原始空间优化器持续提供当前有效候选
-> 用新候选替换过时参考解
-> 低维权重搜索围绕新锚点生成更多候选
-> 共同环境选择把有价值的变换解反馈给主搜索
```

关键假设是：原始空间优化器能比固定 PT 更早发现新的有用区域，而低维权重搜索能围绕这些区域高效产生变体。

## 实现接口

- 输入：
  - 原始空间主种群和目标值；
  - 参考解集合 `T`；
  - 低维权重种群 `W`；
  - 变量分组和变换函数；
  - 参考解贡献或过时判据；
  - 环境选择器。
- 输出：
  - 更新后的参考解集合 `T`；
  - 更新后的权重种群 `W`；
  - 融合原始解和变换解后的下一代主种群。
- 插入位置：
  - PT 映射前后维护参考解；
  - 主优化器环境选择前合并变换解。
- P2026-0007 的默认实例：
  - 初始 `T=P`；
  - `D` 个变量线性分为 `S` 组；
  - 变换函数按组用权重缩放参考解；
  - 过时参考解中一半由 `P` 中随机个体替换，另一半由该随机个体的 OBL 对立解替换；
  - 更新后重新生成对应权重；
  - `P` 和 `Pw` 用 PBI 环境选择共同筛选。

## 如何用于算法创新

### 局部创新

- 用贡献次数、最近存活率、HV 增益、参考向量覆盖缺口或年龄替代模糊的“no longer contributes”判据。
- 将替换来源从随机主种群个体改为分区精英、低拥挤度个体、可行边界个体或高不确定性个体。
- 将 OBL 替换为扰动、局部搜索、代理预测或跨区域重组，生成探索型参考解。
- 对参考解设置最小年龄和最大年龄，避免频繁震荡或长期僵化。

### 结构创新

- 设计参考解生命周期管理器：

```text
生成参考解
-> 记录被 PT 使用次数和产出候选贡献
-> 判断过时或过度集中
-> 选择替换来源和探索变体
-> 更新相关权重和映射状态
```

- 让多个原始空间优化器共同维护共享参考解池，PT 从不同算法的高价值锚点中生成候选。
- 为不同目标空间区域维护局部参考解集合，使 PT 映射具备区域适应性。
- 把参考解更新与变量分组同时学习，减少错误分组对 PT 的限制。

## 适用条件与风险

- 适用条件：
  - 决策变量连续或可按组缩放；
  - PT 候选生成依赖显式参考解；
  - 主优化器能提供质量尚可且分布较广的候选；
  - 能追踪参考解产生的映射候选是否被选择。
- 不适用或可能失效的条件：
  - 变量不能线性缩放或分组映射；
  - 参考解贡献很难归因，导致误删有潜力但暂时低贡献的锚点；
  - 频繁替换使 PT 权重搜索无法积累；
  - 主优化器早熟时会把 PT 也锚定到同一局部区域；
  - OBL 对立解在强约束或不规则边界中不可行。
- 计算与实现成本：
  - 需要维护参考解、权重、映射候选和贡献记录；
  - 每轮信息交换要重新生成部分权重并评价映射候选；
  - 共同环境选择可能增加候选集规模。

## 待确认

- 参考解贡献应按映射候选存活率、目标改进、区域覆盖还是长期档案贡献来定义；
- 替换频率如何自适应；
- 如何避免主优化器早熟后污染参考解池；
- 如何扩展到约束、离散、混合变量和非线性变量分组；
- 能否将参考解管理与代理模型或变量依赖学习结合。
