# 双射区间分式目标确定性化变换

## 核心内容

对带区间分子、区间分母和区间约束的分式多目标问题，先用双射 `psi: Omega -> R^2` 定义区间序关系，再为每个分母上下界引入倒数辅助变量，把每个区间分式目标变成两个实值目标。这样原始 IFOP/MIFOP 可转化为普通 bi-objective 或 `2n` 目标实值规划问题，并由常规数学规划软件或多目标进化算法求解。

一种最小接口是：

```text
区间目标 [f1(x), f2(x)] / [g1(x), g2(x)], 0 < g1 <= g2
-> 写成 [f1(x)/g2(x), f2(x)/g1(x)]
-> 引入 v1=1/g1(x), v2=1/g2(x)
-> 得到区间目标 [f1(x)v2, f2(x)v1]
-> 用 psi([a,b])=(lambda a+(1-lambda)b, mu a+(1-mu)b)
-> 输出两个实值目标及倒数等式约束
```

## 建立理由

- 为什么值得独立维护：它提供了明确的“区间分式建模层 -> 实值多目标求解层”接口，可让 NSGA-II、MOEA/D、RVEA、constrained MOEA 或数学规划软件处理原本不易比较的区间分式目标。
- 单篇具体方法的直接复用价值：P2026-0104 给出 `psi` 映射、区间序关系、IFOP/MIFOP 变换公式、有效解等价定理和库存模型验证；实现时不需要重新推导区间比较规则。
- 与已有设计知识的区别：
  - 不构造辅助任务或跨任务迁移；
  - 不是目标空间多样性选择或 benchmark/indicator；
  - 它修改的是问题表示与目标评价接口，位于优化算法之前，也可嵌入环境选择中的 interval dominance 计算。

## 解决的问题

- 适用场景：
  - 目标或约束参数只能以闭区间表示；
  - 目标是比率型指标，如利润/成本、收益/风险、运输/损耗、资源效率；
  - 需要把 interval fractional MOP 交给常规实值多目标优化器求解；
  - 决策者愿意显式选择区间排序偏好。
- 现有方法为什么会失败或不足：
  - 直接比较区间目标没有唯一自然序关系；
  - 先把区间压缩为期望或中点会丢失 optimistic/pessimistic 边界；
  - 参数积分式 interval fractional 方法可能复杂耗时；
  - 不保持区间序关系时可能得到不可行解或 improper interval。
- 仍需解决的问题：
  - 如何为具体应用选择 `lambda, mu`；
  - 如何处理分母跨 0 或接近 0；
  - 如何在目标数翻倍和新增等式约束后保持 MOEA 的可行性和搜索效率。

## 为什么可能有效

```text
区间目标难以直接排序
-> 用 psi 把区间映射到 R^2，并用实空间偏序诱导区间序
-> 区间上下界信息被保留为两个实值分量
-> 分式目标通过倒数辅助变量消去分母
-> 原问题变成常规多目标约束优化问题
-> 常规 MOEA/数学规划工具可以搜索有效解
-> 回译到区间目标后仍能报告上下界和偏好来源
```

关键点是：`psi` 不是中性的编码，而是显式偏好映射。不同 `lambda, mu` 可产生不同有效解，因此应作为决策偏好或风险态度公开报告。

## 实现接口

- 输入：
  - 每个目标的区间分子 `[f_i1(x), f_i2(x)]`；
  - 每个目标的区间分母 `[g_i1(x), g_i2(x)]`，且 `0<g_i1(x)<=g_i2(x)`；
  - 区间约束 `[h_j1(x), h_j2(x)]`；
  - 每个目标或约束的 `psi_i` 参数 `lambda_i, mu_i`，满足 `lambda_i != mu_i`。
- 输出：
  - `2n` 个实值目标；
  - 每个分母上下界对应的倒数辅助变量和等式约束；
  - 按 `psi` 展开的实值不等式约束；
  - 可回译的区间目标上下界。
- 插入位置：
  - 原问题建模之后、优化器评价函数之前；
  - 或在 MOEA 的 dominance/environmental selection 中，用 `psi` 空间替代直接区间比较。
- 最小复用步骤：
  1. 检查所有分母区间严格为正；
  2. 为每个分母上下界添加倒数变量；
  3. 将每个区间比值转成 `[f_i1 v_i2, f_i2 v_i1]`；
  4. 用 `psi_i` 生成两个实值目标；
  5. 选择 constrained MOEA 或 penalty/repair 机制处理倒数等式；
  6. 输出解时同时报告原始区间目标和 `psi` 参数。

## 如何用于算法创新

### 局部创新

- 给任意实值 MOEA 增加 interval-fractional objective wrapper，使其能处理区间分式目标。
- 将基础算法中的 interval dominance、robust objective aggregation 或中点评价替换为 `psi` 空间评价。
- 为倒数等式约束设计 repair operator，使变异/交叉后的个体自动满足 `v*g(x)=1`。
- 在 MOEA/D 中把 `psi` 产生的 `2n` 目标与参考向量一起设计，形成偏好可解释的分解权重。

### 结构创新

- 构建四层求解框架：

```text
区间建模层
-> psi 偏好映射层
-> 常规多目标/约束求解层
-> 区间解回译与偏好解释层
```

- 维护多个使用不同 `psi` 的子种群，形成风险偏好扫描，而不是只给出一个固定区间序下的 Pareto 解。
- 把 interval surrogate 与该变换结合：代理模型预测目标上下界，`psi` 空间负责选择和约束处理。
- 将用户交互偏好反馈到 `lambda, mu`，动态调整 optimistic/pessimistic 侧重点。

## 适用条件与风险

- 适用条件：
  - 区间上下界可计算或可由模型/代理给出；
  - 分母区间严格正且不跨 0；
  - 决策者能接受 `psi` 代表区间排序偏好；
  - 优化器能处理目标数增加和新增等式约束。
- 不适用或可能失效的条件：
  - 分母可能为 0、跨 0 或符号不确定；
  - 区间上下界本身不可靠，或上下界相关性被简单区间算术过度放大；
  - 希望得到与偏好无关的唯一 interval Pareto 概念；
  - 高目标数问题中目标翻倍导致选择压力失效。
- 计算与实现成本：
  - n 个区间分式目标会扩展为 `2n` 个实值目标；
  - 每个目标至少增加两个辅助变量和两个倒数等式；
  - 约束处理、变量边界、数值稳定性和回译报告都需要专门实现。
- 解释风险：
  - 不同 `psi` 可能改变可行域几何和有效解，不能混作同一问题的无偏结果；
  - 单独报告某个 `psi` 的解可能掩盖风险偏好的敏感性；
  - 若只看 `psi` 空间实值目标，容易丢失原始区间上下界的决策含义。

## 证据边界

- 当前只有单篇论文证据，且没有官方实现或跨问题系统 benchmark。
- 应用验证主要是两产品库存模型；摘要和结论提到高维 scalability，但正文中缺少可核验的详细数据。
- Friedman test 未达到统计显著性，不能证明某个求解器稳定优于其他求解器。
- 实验表中存在少量数值排版不一致，复现时应以 Table 4/5 和原模型公式重新校验。
- `psi` 的偏好含义需要应用侧解释；论文没有给出通用参数选择准则。
