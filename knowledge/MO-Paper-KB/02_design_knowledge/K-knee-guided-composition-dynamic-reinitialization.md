# 膝点引导的组成结构动态重初始化

## 核心内容

动态多目标优化检测到环境变化后，不把整个新种群交给单一预测、记忆或随机移民策略，而是按功能拆成三类：膝点个体负责快速贴近高边际效用区域，非支配迁移个体负责复用上一环境高质量历史信息，多样性个体负责填充预测膝点之间的前沿空隙。三类个体都由膝点运动趋势提供结构锚点，合并后作为新环境初始种群。

P2026-0267 补充了一个在线分流版本：先估计环境变化强度。轻微变化时，用 KGNS 在旧膝点邻域采样并按两个最近膝点的移动趋势平移非支配解；剧烈变化时，用 KGIT 将膝点和邻近非支配解组成正样本，通过 GFK、CORAL 和 KNN 从目标域未标注候选中筛选新初始种群。

```text
环境变化检测
-> 历史膝点集和非支配档案
-> HNSSE: 邻域搜索 + 步长探索预测新膝点
-> KBTR: 两近邻膝点分类生成迁移目标域 + GFK 迁移非支配解
-> UniInter: 在预测膝点之间均匀插值生成多样性个体
-> 合并为 POPinit
-> 静态 MOEA 在新环境继续优化

在线分流变体:
环境变化检测 -> 计算变化强度
-> 轻微变化: KGNS 局部邻域采样 + 非支配解趋势移动
-> 剧烈变化: KGIT 人工膝点平衡 + GFK/CORAL/KNN 迁移筛选
-> 宿主 MOEA/D 精修
```

## 建立理由

- 为什么值得独立维护：它把动态响应从“选择一个预测策略”改成“设计新环境初始种群的组成结构”，接口清楚，能插入多种 DMOEA 宿主。
- 已有跨论文支持，或单篇具体方法的直接复用价值：P2026-0147 在 DF1-DF14 的 42 个动态场景和四目标动态 UAV 路径规划中验证三组成重初始化；P2026-0267 在动态双 UAV 在线路径规划中验证变化强度分流、KGNS/KGIT 和实时响应。
- 与已有设计知识的区别：
  - 不同于“环境变化严重度驱动的多策略预测响应”：该知识按变化强度选择或组合响应策略；本知识固定围绕新种群组成角色来组织生成器。
  - 不同于“带电引导种群的动态预测响应”：该知识用带电排斥改善预测后分布；本知识先构造膝点、迁移解和插值解三类个体。
  - 不同于“双空间子种群的动态预测响应”：该知识按目标/决策空间划分子群并做中心预测；本知识用膝点作为区域趋势锚点，并优化迁移学习目标域。
  - 不同于“特殊点引导的代理辅助复杂前沿搜索”：该知识面向昂贵静态 EMOP 的代理 infill；本知识面向动态 MOO 的环境变化重初始化。

## 解决的问题

- 适用场景：
  - 环境变化后需要快速生成高质量初始种群；
  - 相邻环境间存在一定连续性，膝点或区域代表点能反映局部运动趋势；
  - 可维护上一环境非支配档案，并能检测环境变化；
  - 需要同时控制收敛、历史迁移和多样性。
- 现有方法为什么会失败或不足：
  - 全局中心预测无法描述不同 PF/POS 区域的不同运动；
  - 随机移民提升多样性但会引入大量低质量个体；
  - 只迁移膝点会浪费其他非支配精英信息；
  - 迁移学习若目标域随机生成，会因目标域质量差而产生负迁移。
- 仍需解决的问题：
  - 膝点数量和子空间数如何随问题复杂度自适应；
  - 当膝点识别失败时是否需要退化到中心预测、随机移民或多策略响应；
  - 目标空间插值点到决策空间的反求在离散和高维问题中如何实现。

## 为什么可能有效

```text
动态变化后旧种群失配
-> 膝点提供局部结构趋势和高价值锚点
-> 非支配档案提供可迁移历史精英
-> 膝点分类提高 GFK 目标域质量, 减少随机目标域噪声
-> 膝点间插值补齐前沿分布, 少用盲目随机
-> 初始种群更接近新 POF, 静态优化器调整负担更小
```

关键假设是相邻环境之间仍有可学习的局部运动相关性。如果环境突变完全随机，或膝点数量不足以表示 POF 结构，三类生成器会继承同一个错误锚点。

## 如何用于算法创新

### 局部创新

- 用 HNSSE 替换 DMOEA 中的 AR 膝点预测或固定步长特殊点预测。
- 在任何迁移学习 DMOEA 中，用膝点分类目标域替换随机目标域。
- 将随机移民比例的一部分替换为膝点间均匀插值个体。
- 根据变化严重度动态调整膝点、迁移解、多样性解的比例。
- 对轻微变化只做膝点邻域采样和非支配解趋势平移，对剧烈变化再启用 GFK/CORAL/KNN 迁移筛选。
- 用人工膝点扩充膝点邻近高质量样本，缓解膝点数量少导致的迁移学习正样本不平衡。
- 用预测误差反馈调节膝点邻域搜索半径和步长探索样本数。

### 结构创新

- 构建动态 MOO 响应层：变化检测器、膝点趋势估计器、迁移目标域生成器、多样性插值器、组成比例调度器分离。
- 与双空间子群预测结合：先按目标/决策空间划分子群，再在每个子群内部执行膝点组成结构重初始化。
- 与带电排斥预测结合：三类个体合并后使用排斥场纠正过密区域。
- 与主辅问题动态重调度结合：受扰动子问题内部使用膝点组成结构生成快速修复种群。

## 适用条件与风险

- 适用条件：
  - DMOP 的 POF/POS 在相邻环境间有一定连续性；
  - 历史非支配解质量较高，外部档案没有严重过期；
  - 膝点或区域代表点可被较稳定识别；
  - 静态宿主算法能从较好的初始种群继续优化。
- 不适用或可能失效的条件：
  - 环境变化随机且无可预测趋势；
  - POF 有多个复杂凸凹段但膝点识别数量固定；
  - 决策空间为高维、离散或强多峰，内点法反求插值点不可靠；
  - 真实响应时间极短，GFK 和内点法成本不可接受。
- 计算与实现成本：
  - HNSSE 需要额外邻域评价和步长探索；
  - KBTR 需要外部档案评价、LPCA/PCA、GFK 和单目标反求；
  - UniInter 也需要目标点到决策点的反求；
  - 总体复杂度高于简单中心预测或随机移民，但可减少后续静态优化调整成本。

## 待确认

- 如何自适应估计膝点数量和子空间数；
- 如何检测膝点趋势预测失败并切换响应策略；
- 如何把变化强度阈值、响应间隔和 KGNS/KGIT 使用比例做成在线自适应；
- 人工膝点数量、KNN 邻居数和 CORAL/GFK 组合对正样本质量与实时性的影响；
- 插值目标点到决策空间的反求是否适合高维、离散和混合变量；
- GFK、LPCA 和内点法在实时场景中的成本是否可控；
- 是否能把组成比例与环境变化严重度、预测误差或历史贡献闭环联动。
