# 环境变化严重度驱动的多策略预测响应

## 核心内容

在动态多目标优化中，检测到环境变化后，不使用单一响应策略，而是根据相邻环境种群的变化严重度，在多个预测/响应策略之间自适应分配生成新种群的比例。变化越严重或越随机时，提高探索型预测比例；变化较轻或更可预测时，提高收敛型或趋势校正预测比例。

P2026-0103 的具体实现是 ASS：

```text
检测到环境变化
-> 计算当前种群到上一环境种群的平均最近距离 alpha
-> 用 p=1/(1+exp(alpha)) 得到调度概率
-> p 较小时提高 DDP 使用比例，生成多方向探索解
-> p 较大时提高 CSP 使用比例，按校正中心平移个体
-> 用混合预测种群初始化新环境搜索
-> 环境稳定时继续由 MOEA/D-DE 优化
```

## 建立理由

- 为什么值得独立维护：它提供了清楚的“变化检测 -> 变化严重度估计 -> 策略池概率调度 -> 新环境种群生成”接口，可嵌入 MOEA/D、NSGA-II、RVEA、动态 PSO 或其他 DMOEA。
- 单篇具体方法的直接复用价值：P2026-0103 给出 Algorithm 1-3、变化严重度公式、DDP/CSP 生成公式和消融实验。
- 与已有设计知识的区别：
  - 不构造辅助任务；
  - 不做算法选择或推荐；
  - 不是代理内环加速；
  - 不修改目标空间环境选择；
  - 作用位置是 DMOP 环境变化后的响应与再初始化模块。

## 解决的问题

- 适用场景：
  - 动态多目标问题中 PS/PF 随时间变化；
  - 环境变化既可能随机剧烈，也可能快速但具有短期趋势；
  - 单一预测模型或单一随机引入策略难以同时兼顾多样性和收敛；
  - 可获得相邻环境中的种群历史信息。
- 现有方法为什么会失败或不足：
  - 随机引入/变异能增加多样性，但可能损失收敛；
  - 单一预测模型可能在复杂变化下给出错误方向；
  - 只按固定比例混合策略不能适应不同变化幅度；
  - 只利用中心移动可能在中心不变、形状变化或多峰 PS 中失效。
- 仍需解决的问题：
  - 如何更准确地区分随机变化、平移变化、形状变化和长时序变化；
  - 如何根据历史贡献而不仅是距离严重度调整策略比例；
  - 如何在变化频繁和高维问题中控制预测模型训练成本。

## 为什么可能有效

```text
动态环境变化类型不固定
-> 随机/严重变化更需要探索新区域和保持多样性
-> 轻微/趋势性变化更需要快速收敛到新 PS
-> 用相邻环境种群距离估计变化严重度
-> 严重变化时增加 DDP 多方向预测
-> 较平稳变化时增加 CSP 中心校正预测
-> 混合响应比固定单一策略更能覆盖不同变化情形
```

## 实现接口

- 输入：
  - 当前环境种群 `P_t`；
  - 上一环境种群 `P_{t-1}`；
  - 可选的更早历史种群 `P_{t-2}`；
  - 动态目标函数或变化检测器；
  - 一组响应策略。
- 输出：
  - 新环境初始化种群或候选种群；
  - 每个响应策略的使用比例；
  - 可选的变化严重度和策略贡献记录。
- P2026-0103 的最小实现：

```text
alpha <- mean_{x in P_t} min_{z in P_{t-1}} distance(x,z)
p <- 1 / (1 + exp(alpha))
train ANN from paired MOEA/D subproblem solutions
center <- select perturbed center by nondominated sorting
for each individual:
    r <- uniform(0,1)
    if p < r:
        child <- DDP(x)
    else:
        child <- CSP(x)
```

- 可替换组件：
  - 变化严重度：决策空间距离、目标空间距离、PF 指标差、可行率变化、中心/协方差变化；
  - 策略池：随机重启、预测平移、中心平移、知识迁移、局部修复、代理预测、多方向历史外推；
  - 调度器：sigmoid、softmax、bandit、reinforcement learning、基于贡献的自适应概率；
  - 静态优化器：MOEA/D-DE、NSGA-II、RVEA、SPEA2、动态 PSO 等。

## 如何用于算法创新

### 局部创新

- 替换固定比例的变化响应机制，让响应比例随变化严重度调整。
- 给已有预测型 DMOEA 加入第二种互补策略，例如探索型 DDP 或收敛型 CSP。
- 把 `alpha` 换成更可靠的变化类型识别器，并保留 ASS 的策略调度接口。
- 把 DDP 的 ANN 换成更轻量或更强的时序模型。
- 把 CSP 的中心筛选换成 HV 贡献、拥挤度、参考向量覆盖或可行性优先准则。

### 结构创新

- 构建动态响应策略池：每种策略负责一种变化类型，调度器根据变化严重度和历史收益分配响应预算。
- 将变化检测、变化分类、策略调度、静态优化器解耦，使动态算法能逐步替换其中任一模块。
- 为真实工业动态优化构建“数据 surrogate + 动态响应策略池 + 控制候选筛选”的闭环结构。

## 适用条件与风险

- 适用条件：
  - 环境变化可被检测；
  - 相邻环境存在可复用历史种群；
  - 变化后的优良解与历史种群存在一定相关性；
  - 静态优化器能从预测种群继续搜索；
  - 评价预算较紧，需要在变化后快速恢复。
- 不适用或可能失效的条件：
  - 环境变化完全无规律，历史解无参考价值；
  - 决策空间存在多个等价 PS 区域，中心距离无法代表有效变化；
  - 变量尺度差异大而严重度未归一化；
  - 高维或高频变化导致预测器训练成本过高；
  - 固定 sigmoid 调度在某些尺度下过早饱和。
- 计算与实现成本：
  - 需要存储至少 2-3 个历史环境的种群；
  - 若使用 DDP，需要在每次变化后训练预测模型；
  - 需要维护策略选择、边界修复和预测解评价。
- 解释风险：
  - 变化严重度大不一定等于随机变化，也可能是规律性大幅平移；
  - 中心移动小不代表 PS/PF 没有发生形状变化；
  - 策略比例的提升不等于该策略一定贡献更大，仍应做历史贡献反馈。

## 证据边界

- 当前只有单篇论文证据。
- ASS 在 CEC2018 上并非全面优于对比算法，只在 7/14 个问题上最佳。
- 消融只覆盖 4 个测试实例，且没有详细统计显著性。
- WFGD 数据保密，真实 PF 不可得，应用证据主要依赖 MHV 和分布图。
- `alpha` 与 sigmoid 调度缺少参数敏感性和尺度归一化分析。
- 论文没有报告运行时间和 ANN 训练开销。
