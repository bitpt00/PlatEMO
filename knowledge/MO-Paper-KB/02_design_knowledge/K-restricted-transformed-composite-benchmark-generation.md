# 受限子问题变换组合的基准生成

## 核心内容

从一个已知 PS/PF 的标准多目标问题出发，构造多个只保留局部 PS/PF 的受限子问题；对这些子问题进行平移、旋转和缩放，并将其非重叠放置到决策空间中；最终用最近组件硬归属组合目标函数，得到具有多个可调 Pareto set 区域的 MMOP benchmark。

```text
已知 PS/PF 的标准 MOP
-> 定义若干受限盒并裁剪盒外点
-> 每个受限问题只保留标准 PS 的一个片段
-> 对受限问题做平移/旋转/缩放
-> 用非重叠 MEB 放置多个组件
-> 候选解按最近组件归属并调用对应受限目标
-> 得到可知 PS/PF 且具有多个 PS 区域的 MMOP
```

## 建立理由

- 为什么值得独立维护：它不是单个测试函数，而是一个 benchmark 生成接口，可系统调节 PS 区域数量、尺度差异、方向、变量依赖和 PF 局部覆盖。
- 单篇具体方法的直接复用价值：P2026-0144 给出受限目标、组合目标、非重叠放置算法、样例 CMMOP 套件和理论 PS/PF 性质。
- 与已有设计知识的区别：
  - 不修改优化器的后代生成；
  - 不构造辅助任务或迁移知识；
  - 不属于目标空间选择策略；
  - 直接用于构造评价环境和压力测试问题。

## 解决的问题

- 适用场景：
  - 需要多 PS 区域、可知 PF 和可调难度的 MMOP benchmark；
  - 需要测试算法是否能同时发现多个等价 Pareto 最优区域；
  - 需要在同一基础 PF 难度上改变决策空间结构。
- 现有方法为什么会失败或不足：
  - 固定 benchmark 难以覆盖足够多的 PS 区域形态和尺度差异；
  - 部分 scalable MMOP 的 PS 区域过于规则或变量结构过于可预测；
  - 目标数、维数、PS 区域数量和局部 PF 覆盖难以独立调节。
- 仍需解决的问题：
  - 如何在保证 PF 可解析的同时避免硬组件边界带来的不连续；
  - 如何将框架扩展到约束、多局部 PF 或真实工程可行域；
  - 如何定义生成实例的难度标尺，而不只依赖随机参数。

## 为什么可能有效

```text
标准 MOP 已有明确 PF 和收敛难点
-> 受限盒截取标准 PS 的局部片段
-> 多个片段经几何变换后形成多个不同 PS 区域
-> 非重叠放置避免组件间互相改变全局 PS/PF 证明
-> 最近组件硬归属保持组合问题的 PF 可追踪
-> 参数控制区域数量、尺度、旋转和 PF 覆盖缺口
-> benchmark 同时具备可解析性、可扩展性和可调复杂度
```

## 实现接口

- 输入：
  - 一个已知 PS/PF 的 box-constrained 标准 MOP；
  - PS 上下界、ideal/nadir 和包含 PS 的 MEB；
  - 组件数量 `N`；
  - 尺度差异 `lambda_max2min`；
  - 目标 PF 覆盖缺口 `Delta_R^target`；
  - 旋转概率或依赖强度 `p_rot`。
- 核心步骤：
  - 对每个受限问题选择受限维度和受限盒；
  - 用裁剪点 `x_near` 和距离惩罚定义盒外目标；
  - 为每个组件采样缩放、旋转和平移；
  - 将各组件 MEB 非重叠放入统一决策域；
  - 评价时选择归一化距离最近的组件。
- 输出：
  - 组合目标函数；
  - 可追踪的组合 PS；
  - 继承或可推导的组合 PF；
  - 每个 PF 参考点对应的多个决策空间参考解。

## 如何用于算法创新

### 局部创新

- 在现有 MMOP benchmark 之外增加一个可调外层生成器，用于测试算法对 PS 区域数量、尺度差异和变量旋转的敏感性。
- 将单个标准 MOP 的 PF 难度与多 PS 区域结构解耦，构造更精确的对照实验。
- 设计针对某个算法弱点的实例，例如小 PS 区域、强旋转、局部 PF 覆盖缺口或非均衡吸引域。
- 将生成实例用于算法训练、调参或鲁棒性筛选。

### 结构创新

- 构建 benchmark factory：生成器负责采样实例，难度评估器根据多算法表现标注实例，筛选器形成分层测试套件。
- 将“PS 区域生成”和“PF 难度继承”作为两个独立模块，分别调控决策空间多模态性和目标空间收敛困难。
- 为多模态多目标算法设计 curriculum：从少量大区域、弱旋转实例逐步过渡到多小区域、强依赖和局部 PF 覆盖实例。

## 适用条件与风险

- 适用条件：
  - 基础问题的 PS/PF 和关键边界信息可知；
  - PS 可被受限盒有效截取；
  - 组件 MEB 能在目标决策域内非重叠放置；
  - 研究目标是 benchmark 构造或压力测试，而非直接求解真实未知 PS 问题。
- 不适用或可能失效的条件：
  - 基础问题 PS 退化、离散、极不规则或不满足 `(M-1)` 维流形假设；
  - 需要真实连续 landscape 而不能接受组件边界不连续；
  - 约束、局部 PF 或真实可行域是主要难点，但生成器未显式建模；
  - 所需 PS/PF 信息不可获得。
- 计算与实现成本：
  - 需要计算或近似 PS 的 MEB、受限 PF 覆盖比例和多组件非重叠放置；
  - 随机生成过程需要保存种子和完整参数，才能复现实例；
  - 需要额外生成 IGED 类指标所需的 PF/PS 参考集。
- 解释风险：
  - “基于任意标准 MOP”应理解为“基于满足可知 PS/PF 等前提的标准 MOP”；
  - 硬最近组件边界可能成为 benchmark 的主要人工难点；
  - 随机实例间难度差异大时，单个实例不能代表整类问题。

## 证据边界

- 当前只有单篇论文证据；虽然生成器实现明确，但尚缺其他论文独立采用或复核。
- Theorem 2 证明中存在 `T` 与 `T^{-1}` 记号混用，复用时应重新核对变换方向。
- 惩罚系数 `phi_0` 的默认设置不够清楚。
- 论文没有直接比较该生成器与已有 benchmark generator 在覆盖性、难度可控性和 landscape 质量上的量化差异。
- 摘要写“五个 composite problems”，正文和 Table 1 给出八类 CMMOP，应以正文为准。
