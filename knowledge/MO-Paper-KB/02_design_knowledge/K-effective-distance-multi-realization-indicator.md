# 多实现有效距离综合指标

## 核心内容

对每个目标空间参考点，同时考虑它对应的多个等价 Pareto 最优决策解。先分别计算种群对每个等价决策解的目标空间最近距离，再用反距离幂和合成为一个有效距离，使指标既奖励目标空间接近 PF，也奖励发现更多不同决策空间 realizations。

```text
PF 参考点 f_q*
-> 找到映射到 f_q* 的多个等价 PS 参考解 x_qp*
-> 种群解按决策距离分配给最近 x_qp*
-> 每个 realization 计算目标空间最小距离 d_qp
-> 用 inverse-power sum 得到有效距离 d_q^eff
-> 对所有 PF 参考点平均，得到综合指标
```

## 建立理由

- 为什么值得独立维护：它提供一个明确接口，把“目标空间接近”和“决策空间多等价解覆盖”合并到同一个距离指标中，可用于 MMOP 评价和搜索反馈。
- 单篇具体方法的直接复用价值：P2026-0144 给出 IGED、IGED+_alpha 的公式、偏好参数解释、控制示例和大规模算法比较。
- 与已有设计知识的区别：
  - 不改变 benchmark 生成；
  - 不属于变量结构变异；
  - 不是单纯目标空间 diversity selection；
  - 直接修改性能评价、档案维护或环境选择的度量方式。

## 解决的问题

- 适用场景：
  - MMOP 中多个决策空间 Pareto 解映射到相同或相近目标点；
  - 需要区分“只找到一个 PS 区域但 PF 分布好”和“找到多个 PS 区域但目标空间略差”的解集；
  - 需要用一个偏好参数表达收敛与等价解覆盖的权衡。
- 现有方法为什么会失败或不足：
  - IGD/HV 只看目标空间，可能忽略只覆盖单一 PS 区域的问题；
  - IGDX/PSP 单独看决策空间时，可能与目标空间指标结论冲突；
  - IGDM 需要 `d_max`，空簇惩罚和点式 clustering 容易影响结果；
  - APHVs 需要预先划分 PS 区域。
- 仍需解决的问题：
  - 如何在 PS 未知或等价解不完整时构建参考集；
  - 如何选择、报告和解释 `alpha`；
  - 如何降低大参考集上的计算成本。

## 为什么可能有效

```text
MMOP 的理想解集应同时接近 PF 并覆盖多个等价 PS 解
-> 单个 PF 参考点可能有多个决策空间 realizations
-> 对每个 realization 分别求最近目标距离
-> 反距离相加让多个有效 realizations 共同降低有效距离
-> alpha 控制“最佳近似”与“多 realization 覆盖”的权重
-> 平均所有 PF 参考点后得到综合 MMO 质量
```

## 实现接口

- 输入：
  - 待评价种群或档案 `X`；
  - PF 参考点集合 `{f_q*}`；
  - 每个 `f_q*` 对应的等价 PS 参考解集合 `{x_qp*}`；
  - 目标函数值 `F(x)`；
  - 偏好参数 `alpha>0`。
- 核心计算：
  - 对每个 `q`，将种群解分配给最近 `x_qp*`；
  - 计算每个 realization 的目标空间最近距离 `d_qp`；
  - 使用 `(1/d_q^eff)^alpha = sum_p (1/d_qp)^alpha` 聚合；
  - 对全部 `q` 平均得到 IGED；
  - 若把目标距离替换为 IGD+ 距离，则得到 IGED+。
- 输出：
  - 单值 IGED 或 IGED+_alpha；
  - 可选地输出各 `q,p` 的覆盖图谱，用于诊断哪些 PF 位置缺少等价解。

## 如何用于算法创新

### 局部创新

- 将 IGED+_alpha 作为 MMOP 算法的离线评价指标，替代单独报告 IGD/HV 与 IGDX/PSP。
- 将有效距离用作外部档案更新准则，保留对新决策 realization 有贡献的解。
- 在环境选择中加入“目标参考点 - 决策 realization”覆盖贡献，使算法避免只围绕单一 PS 区域收敛。
- 对同一算法报告多 `alpha` 曲线，显示其偏好收敛还是偏好发现等价解。

### 结构创新

- 构建双层记忆：外层维护 PF 参考点，内层维护每个参考点的多个决策 realization，选择时按有效距离分配搜索压力。
- 将 `alpha` 作为用户偏好或阶段参数：早期小 `alpha` 强调发现更多 PS 区域，后期大 `alpha` 强化收敛。
- 把 realization 覆盖缺口反馈给变异/重启模块，专门搜索已知 PF 位置下缺失的决策空间区域。

## 适用条件与风险

- 适用条件：
  - 目标是评价或引导 MMOP，而不是普通单 PS 多目标问题；
  - 可获得足够可靠的 PF 参考点和等价 PS 参考解；
  - 研究者愿意显式报告收敛与多解覆盖的偏好参数。
- 不适用或可能失效的条件：
  - 真实 PS/PF 未知，参考集由算法结果并集近似且可能遗漏困难区域；
  - 等价 PS 区域连续且很大，离散参考解密度强烈影响分数；
  - 算法产生被支配但覆盖新 realization 的解，指标解释会不同于传统 Pareto 收敛指标；
  - 单个 `alpha` 被用于宣称绝对排名，而不说明偏好。
- 计算与实现成本：
  - 需要维护每个 PF 参考点对应的多个 PS 参考解；
  - 计算量随种群大小、PF 参考点数和 realization 数增长；
  - 大规模问题可能需要近似最近邻、分层采样或缓存。
- 解释风险：
  - `alpha` 不是应被隐藏的无关参数，而是会改变排名的偏好参数；
  - 指标值提升可能来自发现更多较差的等价解，而不一定来自更好的目标空间收敛；
  - 点式 clustering 仍可能发生区域误归属。

## 证据边界

- 当前只有单篇论文证据，尚缺其他研究独立验证。
- 论文没有系统比较 IGED+ 与 IGDM、APHVs、I_EDR 在已知失败案例上的判断差异。
- 排名随 `alpha` 改变是指标的设计特性，但也意味着单个数值不能代表唯一客观优劣。
- 若参考 PS 解不完整，指标会系统性低估未被参考集覆盖的难找区域。
- 论文没有给出复杂度分析和大规模近似计算策略。
