# 自适应子区多方向竞争更新

## 核心内容

在竞争式群体算法中，不再只让 losers 向 winners 学习。先根据当前种群目标分布自适应生成参考向量并划分子区，为每个子区维护一个代表性最优解；再围绕子区最优解做多方向探索；随后让 winners 优先向稀疏子区代表学习，最后 losers 向 winners 学习。该结构同时缓解固定参考向量不适配、winner 聚集和 loser-only 更新导致的早熟。

最小接口：

```text
当前种群 Pop
-> 根据目标分布动态确定参考向量数量 K
-> 用参考向量划分目标空间并选每个子区代表 S
-> 对 S 做多方向探索，生成 S'
-> 用 SDE/适应度随机配对 winners 与 losers
-> winners 按密度偏向稀疏子区代表更新
-> losers 向 winners 更新
-> 环境选择得到下一代
```

## 建立理由

- 为什么值得独立维护：它提供了一个完整的“子区代表 -> 多方向探索 -> 胜败双侧更新”接口，可替换 CSO/PSO 类算法中固定参考向量、只更新 losers 或单/双方向搜索的模块。
- 单篇具体方法的直接复用价值：P2026-0037 的 Algorithms 2-4、Eq. (7)-(19) 给出参考向量数量、APD 子区代表、多方向候选、winner/loser 更新和边界处理；消融分别验证了自适应子区和多方向探索。
- 与已有设计知识的区别：
  - 不属于目标空间流形嵌入选择；
  - 不构造辅助任务或跨任务迁移；
  - 不使用代理模型；
  - 直接改造竞争式 swarm 的搜索角色和信息流。

## 解决的问题

- 适用场景：
  - 大规模连续多目标优化；
  - CSO/PSO/MOEA 中 winners 或 elites 容易聚集；
  - 固定参考向量无法适应当前 PF/种群分布；
  - 双向或单方向搜索容易错过 PS 交点。
- 现有方法为什么会失败或不足：
  - 只更新 losers 会使 winners 逐渐成为静态聚集中心；
  - 固定子区过多会削弱 winners 差异，过少会丢失区域信息；
  - 单向/双向搜索在复杂 PS 结构上交点概率有限；
  - 无区域密度反馈时，稀疏区域缺少搜索预算。
- 仍需解决的问题：
  - 如何比目标标准差更准确地估计参考向量数量；
  - 如何为非盒约束、离散变量和混合变量设计多方向探索；
  - 如何在线控制 winner 更新概率、方向数和环境选择压力。

## 为什么可能有效

```text
固定参考向量和静态 winners 容易造成局部聚集
-> 用当前目标分布动态调整子区数量
-> 每个子区保留代表解，避免区域失活
-> 子区代表在多个决策方向上探索，增加与 PS 相交概率
-> winners 向稀疏子区代表学习，削弱拥挤区域吸引
-> losers 继续向 winners 学习，保留 CSO 快速收敛
-> 环境选择整合父代、子代和方向探索解
```

## 实现接口

- 输入：当前种群 `Pop` 及目标值、决策变量上下界 `L,U`、种群规模 `N`、目标数 `M`、子区更新周期 `cy`、winner 稀疏区学习概率阈值 `tr`。
- 输出：下一代种群、每个子区代表解集合 `S`、可选方向探索解集合 `S'`。
- 插入位置：适合替换 CSO/PSO 的竞争更新模块，也可作为 MOEA 的 offspring generation 或 elite exploration 模块。
- 可独立替换的子模块：参考向量数量估计、子区代表解选择、多方向生成、winners 向稀疏区学习的概率规则、loser 更新、边界修复和环境选择。

## 如何用于算法创新

### 局部创新

- 将固定参考向量的环境选择改为基于当前目标分布动态确定 `K`。
- 在 CSO/PSO 中增加 winner-side update，避免 winners 每代直接继承。
- 把单向或双向 offspring generation 替换为多方向候选生成。
- 将稀疏子区代表作为 winner 引导源，替代随机 elite 或全局 best。
- 使用空子区比例触发重启、扰动或边界修复策略。

### 结构创新

- 构建区域-个体双层协同搜索：

```text
区域层：参考向量、子区代表、空区状态、密度
个体层：winner/loser 配对、winner 跨区学习、loser 追随 winner
```

- 维护多方向历史记忆，为每个子区统计方向成功率，并据此自适应分配方向探索预算。
- 把参考向量数量、方向数量和 winner 学习概率作为同一搜索状态控制问题，由强化学习或 bandit 策略动态调节。

## 适用条件与风险

- 适用条件：
  - 连续 box-constrained 决策变量；
  - 目标值可用于参考向量关联和 APD/SDE 计算；
  - 需要在大规模决策空间中保留较轻量的 swarm 搜索；
  - 局部最优和 winner 聚集是主要问题。
- 不适用或可能失效的条件：
  - 强约束、离散或混合变量问题没有合适的方向修复；
  - PF 退化、断裂或高目标数导致目标标准差不能稳定表示分布；
  - 子区数量频繁变化造成代表解继承不稳定；
  - 多方向探索成本超过函数评价预算。
- 计算与实现成本：
  - 每轮多方向探索产生约 `4K` 个额外候选；
  - 需要 APD、SDE、参考向量关联和 T-ENS/环境选择；
  - 参数 `tr`、`cy` 与边界处理策略需要调试。
- 复现风险：
  - P2026-0037 中 uniform initialization 公式疑似缺少下界平移；
  - Algorithm 4 的边界处理 if/else 与正文解释疑似相反；
  - 论文没有单独隔离 density-aware winner update 的贡献。

## 证据边界

- 当前只有单篇论文证据，尚缺独立复现和官方代码核验。
- 综合实验使用 LSMOP1-LSMOP9，仍属于 benchmark 证据；真实应用仅 WSN 简化模型。
- AMRCSO 在部分实例仍有局部收敛问题；并非所有问题均优于 ALMOEA/DGEA。
- HV 在部分多模态实例上因参考点设置变成 0，区分力有限。
- Density-aware winner updating 没有被单独移除做消融，因此 tri-stage 内部贡献还不完全清楚。
