# 数据流动态优化的代理超参数迁移

## 核心内容

当优化器不能主动调用真实目标函数、只能从当前时间步的数据流中获得带目标值样本时，用代理模型替代目标函数；相邻时间步之间不直接迁移历史最优解，而是迁移代理模型的超参数，让当前代理训练从更合理的初始状态开始。多个代理可以并行驱动搜索，再用不确定性区间筛出更可靠的候选解。

```text
当前数据流 + 上一时间步代理超参数
-> 训练当前 Kriging/RBFN 代理
-> 双代理并行驱动 MOEA 搜索
-> 用 Kriging 预测值和 RMSE 构造 UCB/LCB
-> 互相淘汰不可靠候选
-> 输出当前时间步 Pareto 解集
```

## 建立理由

- 为什么值得独立维护：
  - DDMOP 中算法不能主动评价候选解，历史种群或预测种群的真实优劣难以确认。
  - 直接迁移历史解可能把错误候选带入新环境；迁移代理超参数的风险更低，且能提升当前代理质量。
  - 超参数迁移是一个明确接口，可替换代理模型、基础 MOEA 和不确定性筛选规则。
- 与已有设计知识的区别：
  - 不同于动态预测响应类卡片，它不预测新环境种群，而是改善当前时间步的 surrogate training。
  - 不同于普通 surrogate-assisted sampling，它面对的是“不能主动获取真实评价”的数据流限制。
  - 不同于模型选择，它不只在 Kriging/RBFN 间二选一，而是让两个代理并行搜索并互相监督筛选。

## 解决的问题

- 适用场景：
  - 真实目标函数不可主动调用，只能使用观测数据流；
  - 目标函数随时间平滑漂移；
  - 当前时间步数据量有限，单独训练代理不稳定；
  - 历史模型与当前模型有相关性，但直接复用历史预测值风险较高。
- 现有方法为什么会失败或不足：
  - 动态 MOEA 依赖大量实时函数评价；
  - offline data-driven MOEA 通常忽略相邻时间步之间的代理训练信息；
  - 历史解继承需要准确判断历史解质量，但在无主动评价场景中难以做到；
  - 固定代理超参数在高维或分布变化场景下容易引发严重预测误差。

## 为什么可能有效

```text
相邻时间步目标函数平滑变化
-> 代理模型的合适超参数也不会剧烈变化
-> 上一时间步超参数可作为当前训练的 warm start 或分布先验
-> 当前代理预测更稳定
-> 双代理并行搜索降低单代理偏差
-> 不确定性筛选减少错误候选进入最终解集
```

关键假设是：动态变化虽存在，但相邻时间步之间的目标函数形状、数据分布或代理超参数仍有连续性。

## 实现接口

- 输入：
  - 当前时间步数据流；
  - 上一时间步代理模型或其超参数；
  - 基础 MOEA；
  - 最终解集容量；
  - 可选的代理不确定性估计。
- 代理迁移：
  - Kriging：把上一时间步优化得到的 `Theta` 作为当前超参数优化初始点；
  - RBFN：根据当前目标值分布均匀性和上一时间步 `alpha` 选择新的 `alpha`；
  - 若历史超参数长期不变，可 reset 初始点以避免局部锁死。
- 双代理搜索：
  - 用 Kriging 驱动一次 MOEA 搜索，得到 `Pk`；
  - 用 RBFN 驱动一次 MOEA 搜索，得到 `Pr`；
  - 两个搜索过程互不依赖，可并行执行。
- 可靠解筛选：
  - 用带不确定性的代理重新评价两个候选种群；
  - 构造 UCB/LCB；
  - 用一个种群的乐观/保守区间淘汰另一个种群中明显不可靠的解；
  - 若可靠解不足，再用另一个代理评价剩余候选并补足。

## 如何用于算法创新

### 局部创新

- 将上一时间步超参数扩展为多时间步加权历史，以应对随机波动或周期变化。
- 用在线贝叶斯更新替代简单 warm start，维护超参数分布而非单点。
- 将固定 `3 * RMSE` 区间替换为风险偏好、自适应置信水平或 conformal prediction 区间。
- 用数据流漂移检测决定何时迁移、何时 reset、何时丢弃历史。

### 结构创新

- 构建通用数据流 MOO 代理层：

```text
观测层：接收当前时间步数据流
记忆层：保存历史代理超参数与分布统计
代理层：训练多个互补 surrogate
搜索层：多代理并行驱动 MOEA
筛选层：基于不确定性的可靠解融合
```

- 将该机制接入昂贵动态优化、实时推荐、工业过程控制或在线仿真校准。
- 让基础 MOEA 与代理模型自动匹配，例如在高维时选择更稳健代理，在低维时选择更精细代理。

## 适用条件与风险

- 适用条件：
  - 当前数据流包含决策向量和目标值；
  - 相邻时间步之间存在平滑性或可迁移结构；
  - 代理超参数对预测质量有显著影响；
  - 代理能给出不确定性或至少可构造可靠性指标。
- 不适用或可能失效的条件：
  - 目标函数随机剧烈变化，相邻时间步无可迁移关系；
  - 当前数据流过少或严重偏置，RBFN 分布判断容易误判；
  - 真实任务中的误差主要来自约束、噪声或采样偏差，而非代理超参数；
  - 双代理搜索成本超过时间步允许预算。
- 计算与实现成本：
  - 需要维护历史代理状态；
  - Kriging 超参数优化和不确定性估计可能较重；
  - 两个代理各自驱动搜索，计算量约为单代理搜索的两倍。

## 证据边界

- 当前只有单篇论文证据。
- 实验主要是合成 benchmark，真实数据流优化验证不足。
- 正文承认没有专门 DDMOP 对比算法，因此比较对象是逐时间步离线数据驱动 MOEA。
- 方法依赖相邻时间步平滑变化；随机变化时需要多历史步或更强漂移检测。
- RBFN `alpha` 的均匀性判断较启发式，在少样本或多峰分布下可能不稳。

## 待确认

- 多时间步超参数迁移是否比只迁移上一时间步更稳定；
- Kriging/RBFN 之外的代理是否也能通过类似超参数迁移获益；
- UCB/LCB 的置信水平是否应由问题风险或样本量自适应；
- 对 noisy objective、约束数据流和不完整目标值数据是否仍有效；
- 真实工业数据流中时间预算能否容纳双代理搜索。
