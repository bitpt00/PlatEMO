# IUD-ERT-RLS 批调度启发式解码

## 核心内容

将进化算法给出的“工件顺序 + 机器分配”候选解解码为可行批处理排程：先按机器分组，把每个工件视为单工件批；再用改进 updated distance 合并相近且容量可行的批；随后按最早 ready time 排序批；最后用右移和左移调整批起始时间，在提前/延误与最大完工时间之间折中。

```text
候选解的工件顺序和机器分配
-> 每台机器上初始化单工件批
-> 用 IUD 距离反复合并可行且相近的批
-> 按 ERT 规则排列批
-> 对批内工件按交期排序并估计批代表交期
-> RLS 调整起止时间
-> 计算 Cmax、TEC、ET
```

## 建立理由

- 为什么值得独立维护：
  - 它把“连续/整数编码个体”稳定映射为可行调度，是调度型 MOEA 的关键接口。
  - 合批、排序和起始时间调整分别对应容量、到达时间、交期和能耗目标，模块边界清楚。
- 单篇具体方法的直接复用价值：
  - P2026-0026 给出 Eq. (22) 和 Algorithm 2，说明距离矩阵、合批、ERT 和 RLS 的完整流程；
  - 真实 burn-in 案例中作者将能耗优势归因于紧凑合批和低能耗机器分配。
- 与已有设计知识的区别：
  - 不同于通用算子自适应：该知识位于调度解码层，输出可行排程。
  - 不同于资源分配或代理加速：它不调度函数评价预算，也不替代真实评价。
  - 不同于有序分割 DP：它是启发式解码，不枚举完整 Pareto 前缀。

## 解决的问题

- 适用场景：
  - 并行批处理机器、炉批、染整、半导体 burn-in 等批量加工场景；
  - 工件有尺寸、到达时间、交期和加工时间；
  - 机器存在容量和单位时间能耗差异；
  - 优化器编码不直接保证批容量和批起始时间可行。
- 现有方法为什么会失败或不足：
  - 只优化工件顺序无法决定合批；
  - 简单 first-fit 合批可能忽略加工时间、到达时间和交期相似性；
  - 只按 ready time 排序可能造成大量提前/延误；
  - 只追求交期右移会增加最大完工时间。
- 仍需解决的问题：
  - 如何自适应 IUD 距离中的加工时间、到达时间、交期权重；
  - 如何处理不兼容工件族、设置时间、退化效应和随机到达；
  - 如何证明 RLS 的触发概率对不同 Pareto 权重合理。

## 为什么可能有效

```text
批处理机器的能耗和 makespan 受批数量、批紧凑度和空闲时间影响
-> IUD 将加工时间/到达/交期相近且容量可行的工件合批
-> ERT 减少等待到达造成的空闲
-> RLS 把批尽量移动到更接近代表交期的位置
-> 紧凑批和低空闲时间降低 TEC，同时改善 ET
```

关键假设是：加工时间、到达时间和交期相近的工件更适合同批处理；按 ready time 排列批可以减少机器等待；起始时间微调能在不严重牺牲 `Cmax` 的情况下改善 `ET`。

## 实现接口

- 输入：
  - 每个工件的机器分配和序列优先级；
  - 工件加工时间、到达时间、交期、尺寸；
  - 每台机器容量和单位时间能耗；
  - IUD 权重 `alpha/beta/gamma` 和 RLS 折中规则。
- 输出：
  - 每台机器的批集合、批顺序和批起止时间；
  - `Cmax`、`TEC`、`ET`。
- 插入位置：进化算法的解码和目标评价阶段。
- P2026-0026 的默认实例：
  - IUD 距离同时考虑加工时间差、到达时间差和交期差；若合并后尺寸超过机器容量，则距离为无穷；
  - 合并后批加工时间取批内最大加工时间，到达时间取批内最大到达时间，代表交期取批内交期均值；
  - ERT 按批到达时间排序；
  - RLS 中若批完成时间早于代表交期，则右移到代表交期附近；否则在不违反到达时间和前序批约束下逐步左移；
  - IUD 系数经 Taguchi 调参，最优 `alpha=0.6, beta=0.2, gamma=0.6`。

## 如何用于算法创新

### 局部创新

- 将固定 IUD 权重改为随当前子问题权重、交期紧张度或机器负载自适应。
- 用能耗系数、机器速度或设置时间扩展 IUD 距离。
- 将 RLS 的右移/左移选择由随机数改为 Pareto 权重或局部边际收益判断。
- 在合批后加入小规模局部搜索，如批内交换、跨批搬移、跨机器重分配。

### 结构创新

- 设计可插拔调度解码器：优化器只负责生成顺序和分配，解码器负责可行性、合批和时间安排。
- 将多个合批启发式视为候选解码器，用在线成功率选择不同解码路径。
- 构建双层优化：外层演化机器分配和工件优先级，内层解码器根据目标权重生成不同时间表。

## 适用条件与风险

- 适用条件：
  - 批内加工时间由最长工件决定；
  - 容量约束是合批主要硬约束；
  - 工件到达时间和交期对批选择有明显影响；
  - 候选解能提供机器归属和工件优先级。
- 不适用或可能失效的条件：
  - 批内工件存在族不兼容、温度曲线或配方约束；
  - 设置时间强依赖批序列；
  - 能耗由启停、待机、TOU 电价或速度档位复杂决定；
  - 紧交期场景中右移可能明显增加迟交；
  - 代表交期用均值/中位数可能掩盖极端紧急工件。
- 计算与实现成本：
  - 每台机器需要维护距离矩阵并反复合批；
  - RLS 逐单位左移在大时间尺度下可能较慢，可用边界跳转优化；
  - 与主优化器目标评价紧耦合，必须保证解码确定性和可复现。

## 证据边界

- 当前只有单篇论文证据。
- 所有对比算法也使用相同混合启发式，因此实验不能单独证明 IUD-ERT-RLS 优于其他解码器。
- RLS 在降低 `ET` 时可能增加 `Cmax`，论文用随机数平衡，但未给出充分敏感性分析。
- 目前证据主要是 PBPMSP 和一个半导体 burn-in 场景。
