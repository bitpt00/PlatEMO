# 双空间子种群的动态预测响应

## 核心内容

在动态多目标优化中，检测到环境变化后，不直接用全局中心预测整个种群，而是从目标空间和决策空间两个视角分别划分子种群。每个子群用最近两个环境中非支配代表的中心点移动方向生成预测个体，同时根据该子群上下边界的历史移动趋势，在预测边界内随机生成多样性个体。最后把目标空间响应种群、决策空间响应种群和原种群合并，通过非支配排序选出新环境初始种群。

```text
环境变化
-> 目标空间按权重向量分区
-> 决策空间按代表中心聚类
-> 每个子群计算非支配/最高 rank 代表中心
-> 中心趋势预测个体 MPPS
-> 子群边界预测 + 区域随机补充 MPDM
-> 合并双空间候选并选择新种群
```

## 建立理由

- 为什么值得独立维护：它提供了一个可直接插入 DMOEA 的变化响应层，明确规定如何在环境变化瞬间用双空间子群生成新种群。
- 单篇具体方法的直接复用价值：P2026-0079 给出 MPDS、SDOS、SDDS、MPPS、MPDM 的伪代码、复杂度、参数分析和组件消融。
- 与已有设计知识的区别：
  - 不同于“环境变化严重度驱动的多策略预测响应”：该知识根据变化严重度调度多个响应策略；本知识关注同一次响应中如何同时利用目标空间和决策空间子群结构。
  - 不同于“带电引导种群的动态预测响应”：该知识按分布质量划分 guiding/tracking population 并用排斥力维持分布；本知识按空间结构划分子群，并用中心趋势和边界随机补充生成新个体。
  - 不同于“双空间分层自适应资源分配”：该知识是大规模静态 MOO 中的评价预算调度；本知识是 DMOP 环境变化后的种群重构机制。

## 解决的问题

- 适用场景：
  - DMOP 中 POF/POS 随时间移动，且相邻环境有一定历史相关性；
  - 单一中心预测忽略局部区域移动方向；
  - 只看目标空间会丢失决策结构，只看决策空间会丢失目标折中区域；
  - 需要在变化后快速恢复收敛，同时保留新环境探索能力。
- 现有方法为什么会失败或不足：
  - 全局中心平移会把所有个体推向同一方向，难以处理局部区域不同步移动。
  - 目标空间分区能维护 POF 覆盖，但未必保留决策空间可行结构。
  - 决策空间聚类能保留结构相似性，但不保证目标空间覆盖均匀。
  - 只生成预测个体容易陷入局部，只随机注入又会牺牲收敛速度。
- 仍需解决的问题：
  - 双空间候选的比例如何自适应分配；
  - 子群数量如何随目标数、维度和变化类型自动调整；
  - 线性中心预测如何扩展到旋转、非周期、拓扑断裂或剧烈形状变化；
  - 高维决策空间中聚类和边界预测成本如何控制。

## 为什么可能有效

```text
动态变化后需要快速重新定位
-> 历史中心点移动提供短期趋势
-> 子群中心比全局中心更能捕捉局部变化
-> 目标空间子群保证 POF 区域覆盖
-> 决策空间子群保留结构和可行性线索
-> 边界区域随机补充缓解预测偏差和局部收敛
```

关键假设是：相邻环境之间存在可利用的短期连续性，子群中心和边界的移动方向能近似新环境的有效区域。若环境变化完全随机、PF/POS 拓扑断裂，或历史子群代表质量很低，中心趋势预测可能产生偏差。

## 实现接口

- 输入：
  - 当前种群和上一环境种群；
  - 目标值、决策变量、非支配 rank；
  - 目标空间权重向量数 `K1`；
  - 决策空间聚类中心数 `K2`；
  - 预测比例 `r1` 和多样性比例 `r2`；
  - 边界检查和环境选择器。
- 输出：
  - 目标空间响应候选 `P_mcos`；
  - 决策空间响应候选 `P_mcds`;
  - 合并选择后的新环境初始种群。
- 插入位置：
  - DMOEA 的 change response / reinitialization module；
  - NSGA-II、MOEA/D、RVEA、RM-MEDA 或 PSO 类动态算法的环境变化后种群生成；
  - 多区域预测、记忆复用或随机移民策略的替换/补充模块。
- 最小实现：

```text
if change_detected:
    P_obj <- dual_space_response(P, "objective")
    P_dec <- dual_space_response(P, "decision")
    P <- environmental_selection(P union P_obj union P_dec, N)

function dual_space_response(P, division_type):
    subpops <- divide(P, division_type)
    pred <- []
    divs <- []

    for each subpop in subpops:
        reps <- nondominated_or_best_rank(subpop)
        center_t <- mean(reps at time t)
        center_tm1 <- mean(reps at time t-1)
        direction <- center_t - center_tm1
        pred.add(generate_around_individuals(subpop, direction, r1))

        lower_t, upper_t <- bounds(subpop at time t)
        lower_tm1, upper_tm1 <- bounds(subpop at time t-1)
        lower_next <- lower_t + (lower_t - lower_tm1)
        upper_next <- upper_t + (upper_t - upper_tm1)
        divs.add(random_uniform(lower_next, upper_next, r2))

    return boundary_repair(pred union divs)
```

- P2026-0079 的具体设置：
  - 种群规模 `N=100`；
  - 决策变量数 `D=10`；
  - detector size 为种群 10%；
  - `r1=0.6`，`r2=0.4`；
  - 算法定义中 `K1=4` 为目标空间子群数，`K2=2` 为决策空间子群数；
  - 静态优化器为 RM-MEDA。

## 如何用于算法创新

### 局部创新

- 用双空间子群预测替换 DMOEA 中的全局中心平移预测。
- 对不同子群设置不同 `r1/r2`：稳定子群增加预测个体，不确定子群增加随机补充。
- 用变化严重度或历史预测误差调节 `K1/K2`，变化剧烈时增加子群或随机补充比例。
- 将边界随机生成改成低差异采样、拉丁超立方采样或可行性过滤采样。
- 对子群中心移动使用二阶趋势、Kalman filter、LSTM 或局部 surrogate，而不是两点线性差分。

### 结构创新

- 构建“变化检测 -> 双空间分区 -> 子群趋势预测 -> 子群边界探索 -> 合并选择”的通用 DMOEA 响应层。
- 将该机制和带电排斥预测结合：子群内部预测时引入个体间排斥，防止预测个体过密。
- 将双空间子群和多任务/多智能体框架结合，让不同节点负责不同空间区域并交换中心与边界摘要。
- 与自适应策略池结合：当双空间预测失败时自动切换到随机移民、记忆召回或严重度驱动多方向预测。

## 适用条件与风险

- 适用条件：
  - 相邻环境具有短期连续性；
  - 可保存至少两个历史时间步的子群中心和边界；
  - 目标空间和决策空间都能提供有意义的区域结构；
  - 变化后允许先生成额外候选再做环境选择。
- 不适用或可能失效的条件：
  - 环境变化完全随机，历史趋势无预测价值；
  - POF/POS 突然断裂或旋转，线性中心预测偏差大；
  - 决策空间维度很高，聚类中心和边界预测不稳定；
  - 简单规则前沿中机制过重，动态响应可能引入多余扰动。
- 计算与实现成本：
  - 目标空间划分约 `O(N*K1*M)`；
  - 决策空间划分约 `O(N*K2*D)`；
  - 方向更新和后代生成约 `O(ND)`；
  - 子群过多会增加碎片化和冗余搜索。
- 解释风险：
  - 不能把 MPDS 的收益全部归因于双空间信息，预测比例、随机补充和 RM-MEDA 宿主也共同影响结果。
  - 只在 10 维决策变量上验证，不能直接外推到高维 DMOP。
  - 组件消融显示 MPDS 优于 MCOS/MCDS，但未证明所有问题上双空间组合都优于更强自适应单空间策略。

## 证据边界

- 当前只有单篇论文证据。
- 决策变量数固定为 10，对高维动态问题没有直接证据。
- 对照算法为 IEC、MRCDMO、PBDMO、KF、NHSS，未覆盖所有近期深度预测或代理辅助 DMOEA。
- 静态优化器固定为 RM-MEDA，移植到其他 MOEA 后的收益需要验证。
- 对简单规则 POF、强不连续、强多峰欺骗和极端动态变化的表现不稳定。
