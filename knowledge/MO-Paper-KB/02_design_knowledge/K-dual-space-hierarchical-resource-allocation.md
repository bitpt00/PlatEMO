# 双空间分层自适应资源分配

## 核心内容

将有限函数评价预算按三个尺度分配：先评价目标空间中不同个体区域或子种群的搜索价值，再评价决策空间中不同变量组的重要性，最后根据当前搜索状态决定本阶段总预算；三者合成每个“区域-变量组”搜索单元的实际评价次数，并保留最小探索资源。

```text
当前种群
-> 目标空间分区并估计区域价值 GP_i
-> 每个区域内划分变量组并估计组价值 Gg_ij
-> 根据搜索状态决定阶段总预算 FE_t
-> 合成并取整每个区域-变量组预算 FEg_ij
-> 宿主优化器按预算更新各搜索单元
-> 周期性重新估计价值和预算
```

P2026-0112 的具体实例使用：

- SDE 适应度和分组贡献估计目标空间子种群价值；
- Pearson 相关加 k-means 构造变量组；
- 在子种群平均位置扰动变量组，用目标变化估计组重要性；
- 用子种群最大目标离散度控制下一阶段总预算；
- 用保底项 `T` 防止变量组完全失去搜索机会。

## 建立理由

- 为什么值得独立维护：
  - 它提供了明确的“搜索单元估值 -> 预算合成 -> 宿主执行 -> 周期重估”接口，可用于分组协同进化、分区 MOEA、群智能、局部搜索组合或算法 portfolio。
  - 它直接改变函数评价预算的流向，与只改变选择概率、变异范围或搜索方向的方法不同。
- 单篇具体方法的直接复用价值：
  - P2026-0112 的 Algorithm 2-6 和 Eq. (10)-(22) 给出目标空间价值、变量组价值、联合预算和阶段预算；
  - 完整 DSDRA 分别接入 GDE3、MMOPSO 和 MOCPSO，提供跨宿主移植证据；
  - 与三种资源分配策略有统一宿主比较。
- 与已有设计知识的区别：
  - 不等同于依赖结构指导的变异；变量组只是被调度的搜索单元，核心输出是预算。
  - 不等同于自适应子区多方向更新；不要求特定 winner/loser 信息流或多方向候选生成。
  - 不等同于自适应代理内环；不通过代理替代真实评价，而是分配宿主搜索中的评价次数。
  - 不等同于目标空间多样性选择；目标空间信息用于估值和调度，不只用于环境选择。

## 解决的问题

- 适用场景：
  - 函数评价预算有限，且不同区域、变量组或搜索模块的边际收益差异明显；
  - 大规模决策变量可被划分为若干可局部更新的组；
  - 宿主算法允许按组、区域或模块控制更新次数；
  - 单一空间信号不足以判断资源价值。
- 现有方法为什么会失败或不足：
  - 均匀预算会让低收益单元占用过多评价，同时使高价值单元演化不足；
  - 只按目标空间质量分配资源会忽略哪些变量真正影响目标；
  - 只按变量重要性分配资源会忽略不同解区域的搜索潜力；
  - 固定阶段长度无法适应停滞、集中或分布良好的不同搜索状态；
  - 完全取消低分单元预算会造成不可逆早熟。
- 仍需解决的问题：
  - 如何估计“单位评价的预期收益”，而不是只用当前绝对质量或静态敏感度；
  - 如何在预算取整后保证总预算守恒；
  - 如何在开发高价值单元和探索低置信单元之间保持可控平衡；
  - 如何处理搜索单元价值随阶段快速变化或估计噪声较大的情况。

## 为什么可能有效

```text
不同搜索区域和变量组的边际收益不相同
-> 均匀或单侧资源分配产生浪费与偏置
-> 分别用目标空间和决策空间信号估计价值
-> 联合价值将预算集中到当前更有希望的区域-变量组
-> 保底资源维持低分单元的探索机会
-> 阶段控制器根据搜索状态调整重估频率和开发时长
-> 周期重估使资源流向随搜索过程改变
```

该机制的关键假设是：当前目标空间状态和变量组扰动/历史表现，能够对接下来一段搜索中的相对收益提供足够有用的排序信号。

## 实现接口

- 输入：
  - 当前种群、目标值和函数评价预算；
  - 目标空间搜索单元划分；
  - 决策变量组或其他可调度模块；
  - 区域价值、变量组价值和阶段状态估计器；
  - 可按单元执行有限次数更新的宿主优化器。
- 输出：
  - 每个搜索单元的整数评价预算；
  - 下一阶段总预算或重估时机；
  - 更新后的种群和资源价值状态。
- 插入位置：
  - 外层位于宿主优化器的阶段/周期控制器；
  - 内层位于分组更新、子种群更新或模块调用之前。
- 最小实现：

```text
regions <- partition_population(population)
region_value <- estimate_region_value(regions)

for each region i:
    groups_i <- partition_variables(region_i)
    group_value_i <- estimate_group_value(region_i, groups_i)

stage_budget <- estimate_stage_budget(search_state)
budget_ij <- integer_allocate(
    floor_budget + stage_budget * region_value_i * group_value_ij
)

for each region-group unit (i,j):
    host_optimizer.update(unit=(i,j), evaluations=budget_ij)
```

- P2026-0112 的预算实例：
  - `FEg_ij = (T + FE_t × GP_i × Gg_ij) / N_i`；
  - Algorithm 5 通过变量组在阶段内参与更新的持续时间实现不同预算；
  - 前 90% 总预算执行分层分组搜索，最后 10% 回到全空间精修。

## 如何用于算法创新

### 局部创新

- 将目标空间价值从绝对适应度改为近期进展率、HV 增益、可行率、覆盖缺口或预测不确定性。
- 将变量组价值从单点扰动敏感度改为历史成功后代率、多尺度扰动、代理梯度或组贡献。
- 给预算分配加入熵约束、温度参数或 UCB 探索项，防止强者恒强。
- 让保底预算随组大小、价值置信度、停滞时长和跨组依赖变化。
- 用最大余数法、受约束整数分配或 knapsack 保证离散预算严格守恒。
- 将固定全空间精修比例改为跨组协同不足或分组收益下降时触发。

### 结构创新

- 构建四层资源调度架构：

```text
区域层：哪些解区域值得搜索
变量层：哪些决策模块值得修改
阶段层：当前结构应搜索多久、何时重估
执行层：宿主优化器如何消费预算
```

- 维护多个竞争变量分组或区域划分假设，让它们共享总预算，并按真实后代贡献在线淘汰或增权。
- 把局部搜索、代理搜索、知识迁移、可行性修复和全空间搜索都视为资源消费者，由统一调度器分配预算。
- 用 contextual bandit 或强化学习学习“搜索状态 -> 资源组合”，同时保留显式最小探索约束。
- 采用多时间尺度控制：高频调整变量组预算，中频调整区域预算，低频调整总阶段预算和宿主策略。

## 适用条件与风险

- 适用条件：
  - 可以定义可重复调用的搜索单元；
  - 各单元的搜索收益具有一定持续性，当前估值能预测短期未来；
  - 宿主算法允许非均匀更新次数；
  - 额外估值成本低于错误均匀分配造成的浪费。
- 不适用或可能失效的条件：
  - 搜索单元之间强耦合，单独增加某组预算无法产生有效完整解；
  - 当前质量高的区域已接近停滞，而困难区域需要长期投入后才有回报；
  - 单点扰动或短期贡献无法代表非线性、延迟或协同收益；
  - 价值估计噪声大且阶段过短，导致预算频繁震荡；
  - many-objective 或复杂约束下，目标空间质量信号退化。
- 计算与实现成本：
  - 需要周期性分区、变量分组、价值估计和预算取整；
  - P2026-0112 的 Pearson 分组为 `O(iter × D^2)`，SDE/环境选择含 `O(N^2)` 项；
  - 变量组扰动本身需要额外目标评价，昂贵问题中必须计入总预算。
- 数值和复现风险：
  - P2026-0112 用 `e^(log(Fg_ij)/10)` 压缩变量组敏感度；零敏感度、未说明的对数底数、零目标范围和零归一化分母需要回退规则；
  - 连续预算必须明确取整、余数和总预算守恒；
  - 扰动幅度和越界修复会显著影响变量组价值；
  - P2026-0112 的多处公式/伪代码引用存在歧义，不能直接逐行照搬。

## 证据边界

- 当前只有单篇论文证据，尚无独立复现或官方代码核验。
- 跨宿主实验支持完整 DSDRA 框架，但没有严格隔离目标空间分配、决策空间分配、阶段预算、混合环境选择和末段精修的独立贡献。
- 与 ARA-MMOPSO 的比较同时改变随机分组和固定阶段预算，不能单独证明某一个组件。
- 实验主要是连续、2-3 目标、无约束 benchmark；实际证据只有 TREE 一个问题族。
- P2026-0112 的目标空间分配偏向当前优秀子种群，可能牺牲困难区域覆盖。
- 论文称额外成本不显著，但理论复杂度包含 `D^2` 分组和 `N^2` 选择项，且变量组重要性估计需要额外函数评价。
- 论文中的预算取整、零值处理、越界修复和若干伪代码引用未说明清楚。
