# 目标条件化生成式设计采样

## 核心内容

先用昂贵评价得到一批覆盖不同目标/约束需求的设计数据，再将目标性能、参考方向或偏好编码为条件输入，训练条件生成模型学习“需求条件 -> 高质量设计分布”。该知识既可用于离线训练、在线按需生成，也可嵌入主动学习闭环：用当前非支配档案增量更新生成器，按前沿缺口或偏好区域生成候选，再通过代理引导、批采集和少量真实评价持续改进档案。

```text
离线采样/生成设计
-> 昂贵仿真或真实评价得到多目标性能
-> 将性能、偏好或约束离散/连续编码为条件
-> 训练条件生成模型 p(design | target condition)
-> 在线输入目标条件
-> 快速采样候选设计
-> 验证、筛选、修复或送入 MOEA 继续优化

主动学习变体:
当前非支配档案 -> 增量训练条件生成器
-> 按参考方向/档案缺口生成候选
-> 代理引导与批采集
-> 少量真实评价
-> 更新档案和生成器
```

## 建立理由

- 为什么值得独立维护：它把“每个目标需求重新优化”或“在高维空间盲目变异”的流程改为“学习目标条件化设计分布，再按需求或档案缺口采样”，适合昂贵仿真、多目标、多需求变化和高维候选生成。
- 跨论文支持：
  - P2026-0068 给出离线工程实现，包括随机合法设计生成、FEA 标注、40 档目标条件、条件扩散训练和在线反向扩散生成；
  - P2026-0138 给出主动学习实现，包括连续偏好方向、Transformer 条件扩散、代理梯度引导、批采集、真实评价反馈和增量更新。
- 与已有设计知识的区别：
  - 不做跨任务知识迁移；
  - 不修改传统 MOEA 的环境选择；
  - 不是 benchmark 或性能指标；
  - 直接改变昂贵多目标设计的求解架构，也可作为 MOEA 的候选提议模块。

## 解决的问题

- 适用场景：
  - 每次评价昂贵，例如 FEA、CFD、多物理场仿真或实验；
  - 目标、约束或偏好会频繁变化；
  - 需要快速给出多个满足不同 tradeoff 的候选设计；
  - 高维决策空间中的普通变异难以有效到达当前 Pareto 区域；
  - 设计表示可被生成模型处理，例如 voxel、image、mesh、graph、sequence 或参数向量。
- 现有方法为什么会失败或不足：
  - GA/NSGA-II 等每次目标变化都要重新评价大量个体；
  - DRL 或策略学习方法可能需要为不同奖励重新训练；
  - 参数优化依赖人工参数化设计，探索范围窄；
  - 纯 surrogate optimization 仍需要迭代搜索才能为每个新需求找解；
  - 无条件生成或各向同性变异容易集中在少数 trade-off 区域，浪费有限真实评价预算。
- 仍需解决的问题：
  - 如何保证生成结果可行并满足目标条件；
  - 如何覆盖稀有、高性能或强约束区域；
  - 如何把生成模型的不确定性和失败率反馈给优化器；
  - 如何在代理引导错误、Pareto set 高度碎片化或变量离散时保持稳定。

## 为什么可能有效

```text
昂贵设计问题常需要为很多需求点重复求解
-> 离线用仿真数据学习设计拓扑与目标性能之间的整体映射
-> 条件输入把目标需求变成生成模型的控制信号
-> 在线采样用一次前向/反向生成替代长时间迭代优化
-> 随机生成保留同一需求下的多个候选形态
-> 后续验证筛选保证工程可信度

或:
昂贵优化只允许少量真实评价
-> 当前档案近似高质量设计分布
-> 偏好条件把生成预算分配到不同前沿区域
-> 生成器提出靠近当前 Pareto 流形的候选
-> 代理引导与采集提高真实评价命中率
-> 新评价结果继续修正生成分布
```

## 实现接口

- 输入：
  - 设计表示；
  - 可评价设计性能的仿真、实验或代理模型；
  - 目标条件编码方式，可以是离散 bin、连续目标向量、参考方向、偏好权重或约束向量；
  - 条件生成模型；
  - 主动学习变体还需要当前非支配档案、代理/筛选器和真实评价预算。
- 输出：
  - 对应目标条件的一批候选设计；
  - 可选的条件命中概率、可行性评分或不确定性估计；
  - 主动学习变体输出待真实评价的批候选和更新后的档案。
- 最小流程：

```text
data = []
for design in offline_design_pool:
    y = expensive_evaluate(design)
    c = encode_condition(y)
    data.append((design, c))

model = train_conditional_generator(data)

for target_condition in requested_conditions:
    candidates = sample(model, target_condition, n)
    candidates = repair_or_filter(candidates)
    verified = evaluate_or_surrogate_screen(candidates)
```

- 主动学习最小流程：

```text
archive = evaluate(initial_designs)
while budget_remains:
    model = warm_start_train(generator, nondominated(archive))
    candidates = sample_by_preferences_or_archive_gaps(model)
    candidates = surrogate_guide_or_screen(candidates)
    batch = acquisition_select(candidates)
    archive += expensive_evaluate(batch)
```

- 可插入位置：
  - 作为昂贵 MOO 的初始种群生成器；
  - 作为停滞后的重启/补点模块；
  - 作为 reference direction 或偏好点驱动的候选提议器；
  - 作为交互式设计工具，在用户改变需求后快速给出候选；
  - 作为昂贵优化主动学习循环中的主候选生成器。

## 如何用于算法创新

### 局部创新

- 用条件生成器替换随机初始化，使初始种群更接近指定目标区域。
- 在 MOEA 中按当前档案缺口、reference direction 或偏好权重生成候选。
- 用条件生成器产生多个候选，再通过真实评价只保留少量高置信设计。
- 将失败样本重新加入训练集，形成主动学习式数据增广。
- 在生成轨迹中加入代理多目标下降、可行性或领域规则引导，提高候选命中率。
- 用偏好向量负责全局 trade-off 覆盖，再用目标空间排斥或档案缺口控制局部多样性。

### 结构创新

- 构建“离线数据池 + 条件生成器 + 在线验证器 + 多目标档案”的混合优化框架。
- 让生成器学习整个目标条件空间，MOEA 只负责局部精修和验证边界区域。
- 将制造约束、可行性、用户偏好和物理场指标统一作为 conditioning channel，减少每次重写目标函数的成本。
- 形成闭环：档案发现哪些条件区域缺失，生成器针对缺口采样，昂贵评价再更新生成器。
- 将生成器作为可受多个控制信号干预的搜索轨迹，分别在不同生成阶段加入偏好、收敛、多样性和可行性控制。

## 适用条件与风险

- 适用条件：
  - 已有或可生成覆盖足够广的训练设计；
  - 或者主动学习档案能逐步提供足够多的高质量训练样本；
  - 性能标签可信，且目标条件与设计结构存在可学习关系；
  - 在线生成后的候选可以被快速筛选或最终验证；
  - 允许生成器先给候选而不是一次保证最优。
- 不适用或可能失效的条件：
  - 高性能区域极小且离线数据几乎没有覆盖；
  - 目标条件过细或连续高维，但训练数据不足；
  - Pareto set 高度碎片化，单一生成分布难以覆盖所有区域；
  - 代理梯度或筛选器误差过大，主动闭环会放大错误；
  - 离散/混合变量缺少合适的生成表示、修复或引导机制；
  - 生成后可行性检查非常昂贵且失败率高；
  - 问题需要严格证明最优性，而不是快速候选设计。
- 计算与实现成本：
  - 离线需要大量仿真或历史数据；
  - 需要训练和调参生成模型；
  - 主动学习版本还需反复更新生成器、代理和采集模块；
  - 需要约束检查、后处理和验证机制；
  - 训练数据分布不均衡时可能需要重采样、加权或主动学习。
- 解释风险：
  - 生成的 candidate front 不自动等于 Pareto-optimal front；
  - 条件命中率小于 100% 时，不能省略最终评价；
  - 离散条件 bin 会牺牲精确目标控制；
  - 生成“新设计”不等于拓扑机制真正多样或可制造；
  - 目标空间覆盖不等于决策空间中等价解或多模态 Pareto set 覆盖。

## 证据边界

- 当前已有两篇论文证据，分别覆盖离线 ILM 工程设计生成和在线高维昂贵优化主动学习，但尚缺独立复现。
- 生成器三条件命中率约 72%，说明它是候选提议器，不是无验证的最终求解器。
- 与 GA/DRL 的比较不是完全相同设计域、材料和目标设置下的公平绝对性能比较。
- 论文中的 quasi-Pareto front 未用 HV、IGD 或 dominance 检验其真实 Pareto 最优性。
- 当前条件是 40 个离散 bin，尚未证明连续目标条件下同样有效。
- 工程模型简化较多，包括 2D 单元、水平滑动、无制造约束和未完整网格收敛。
- P2026-0138 的高维优势主要来自合成 benchmark；真实 RE 问题只有低维，且混合整数只通过舍入处理。
- P2026-0138 的 RBF 不确定性、可行性分类器共享结构和部分执行顺序描述不清，复现前需要代码核验。
- 生成器学习当前档案可能形成自强化偏差，必须保留真实评价、探索和错误监控。
