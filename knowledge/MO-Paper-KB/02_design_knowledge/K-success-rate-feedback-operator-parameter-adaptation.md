# 成功率反馈的算子与参数自适应选择

## 核心内容

在进化算法中维护一组候选搜索算子和控制参数区间；学习期内均匀随机尝试，学习期后根据最近窗口内“由该算子或参数区间产生、并成功进入下一代的试验个体比例”更新选择概率。成功率越高的算子或区间，在后续代中被选择的概率越大。

```text
候选算子/参数区间初始化为均匀概率
-> 学习期随机探索
-> 记录每个算子和参数区间生成的试验个体数
-> 记录其中成功进入下一代的个体数
-> 用滑动窗口成功率更新选择概率
-> 按更新概率生成下一批试验个体
```

P2026-0026 的 SLBS 实例同时控制四个 DE 变异算子和 `F/CR` 候选区间，并嵌入 SMODE/D 的子代生成步骤。

P2026-0239 提供了一个参数层面的轻量变体：不在多个算子间重分配概率，而是在离散 DE 中用历史成功信息更新 `MU/CR` 的标准值，再分别通过 Cauchy/Normal 扰动生成当代 mutation/crossover probability。

P2026-0163 提供了一个双算子比例层面的变体：在 FDSEA 的决策域子种群中，用 `gamma` 控制 GA/DE offspring 比例，并结合绝对存活效率与相对存活效率的双激活函数更新 `gamma`，避免某一算子因短期调用次数过低而被完全淘汰。

P2026-0145 提供了一个局部搜索邻域层面的轻量变体：LNSS 不显式定义搜索状态，只维护候选邻域的 reward value 和调用次数，用 `epsilon`-greedy 在历史改进表现较好的邻域和随机探索之间切换。

## 建立理由

- 为什么值得独立维护：
  - 它提供了清楚的“多算子/多参数区间 -> 成功率统计 -> 概率更新 -> 下一代选择”的通用接口。
  - 它不依赖 PBPMSP 本身，也不依赖特定解码器；只要算法能定义成功进入下一代，即可移植。
- 单篇具体方法的直接复用价值：
  - P2026-0026 给出 Algorithm 3、学习期、候选算子、`F/CR` 区间和概率公式；
  - 对比 MODE/D 时主要差异是 SLBS，实验显示 SMODE/D 在 C-Matrix、NR、IGD 和鲁棒性上均优于 MODE/D。
- 与已有设计知识的区别：
  - 不同于代理加速：不训练预测模型，只用真实搜索反馈调整策略。
  - 不同于资源分配：调度的是算子和参数区间，不直接分配函数评价预算。
  - 不同于邻域动量：不构造额外候选方向，而是选择已有生成策略。

## 解决的问题

- 适用场景：
  - 一个算法有多个变异、交叉、局部搜索或修复算子；
  - 控制参数存在多个合理区间，且不同阶段最佳区间会变化；
  - 可以追踪候选个体来源，并判断其是否进入下一代、档案或精英集合；
  - 固定参数或随机算子选择导致探索/开发失衡。
- 现有方法为什么会失败或不足：
  - 固定 `F/CR` 或固定算子难以同时适应早期探索和后期开发；
  - 随机选择算子没有利用历史表现；
  - 顺序应用所有算子可能浪费计算；
  - 单一最佳算子可能只在局部阶段有效。
- 仍需解决的问题：
  - 成功率高不一定代表长期贡献高；
  - 低频但关键的探索算子可能被过早降权；
  - 需要处理成功率统计窗口、平滑项和选择温度。

## 为什么可能有效

```text
不同搜索阶段需要不同算子和参数
-> 历史成功个体提供短期有效性信号
-> 近期成功率提高有效配置的调用概率
-> 保留非零平滑项避免概率归零
-> 算法随搜索状态在探索与开发间移动
```

关键假设是：近期能产生有效后代的算子和参数区间，在接下来一小段搜索中仍具有较高收益。

## 实现接口

- 输入：
  - 候选算子集合；
  - 候选参数区间集合；
  - 学习期长度或滑动窗口长度；
  - 每个试验个体的算子/参数来源；
  - 成功判据，如进入下一代、替换父代、进入外部档案或产生 HV 增益。
- 输出：
  - 下一代每个算子和参数区间的选择概率；
  - 用选中算子和参数生成的试验个体。
- 插入位置：子代生成前，用于选择搜索算子和控制参数。
- P2026-0026 的默认实例：
  - 候选算子为 `DE/rand/1`、`DE/rand/2`、`DE/best/1`、`DE/current-to-rand/1`；
  - `F` 与 `CR` 共用四个区间 `[0,0.25]`、`[0.25,0.5]`、`[0.5,0.75]`、`[0.75,1]`；
  - 学习期 `lp=0.3G`；
  - 成功率加平滑项 `0.01`，避免概率为零；
  - 对多目标 `DE/best/1`，从外部档案中选择 HV 贡献最大的非支配解作为 `best`。
- P2026-0163 的默认实例：
  - 候选算子为 GA 与 DE；
  - `gamma` 表示 GA 后代比例，DE 后代比例为 `1-gamma`；
  - 用当代 GA/DE 后代进入环境选择后的存活数计算绝对效率与相对效率；
  - 当 `gamma` 接近 `0.5` 时更重视绝对存活差异，当 `gamma` 靠近 `0` 或 `1` 时更重视相对存活差异；
  - 将 `gamma` 限制在 `[0.1,0.9]`，保留两个算子的最小调用比例。
- P2026-0145 的默认实例：
  - 候选 action 为 6 个 DHPFSP-FMS 邻域，分别作用于 job sequence、factory assignment 和 machine speed setting；
  - Q-table 规模为 `m x 2`，第一列记录 action reward value，第二列记录 action 被选择次数；
  - 对当前非支配个体，用 `epsilon`-greedy 选择邻域并生成新解；
  - 若新解支配旧解，reward 为 `1`；若旧解支配新解，reward 为 `0`；若互不支配，reward 为 `0.5`；
  - 默认参数实验显示 `epsilon=0.3` 在探索和开发之间较优；
  - 不需要 state definition，可替代 Q-learning/DQN 式邻域选择。

## 如何用于算法创新

### 局部创新

- 将成功判据从“进入下一代”替换为 HV 增益、IGD 贡献、可行性改善、拥挤区补洞或参考向量子问题改进。
- 给低概率算子增加最小探索概率，避免关键探索算子消失。
- 将固定学习期改为停滞触发或不确定性触发。
- 用温度化 softmax、UCB 或 Thompson sampling 替代简单比例成功率。
- 将参数区间从固定四段改为自适应分裂和合并。

### 结构创新

- 建立统一策略控制器，同时选择变异算子、交叉算子、修复算子、局部搜索、代理模块和解码启发式。
- 按目标空间区域或参考向量维护不同的成功率表，使不同 Pareto 区域使用不同搜索策略。
- 将短期成功率与长期档案贡献分开统计，形成双时间尺度策略选择。

## 适用条件与风险

- 适用条件：
  - 算法能记录候选来源；
  - 每个候选策略都有足够调用次数；
  - 成功判据与最终优化目标正相关；
  - 策略切换成本较低。
- 不适用或可能失效的条件：
  - 成功事件稀少，统计噪声太大；
  - 后代短期可替换但长期损害多样性；
  - 策略之间强依赖，单独记账会误判贡献；
  - 早期简单问题区域让开发型算子胜出，导致全局探索不足。
- 计算与实现成本：
  - 需要为每个后代保存算子和参数来源；
  - 每代更新计数和概率，成本很低；
  - 若按区域维护多张表，需要更多样本和内存。

## 证据边界

- 当前有三篇论文证据，但 P2026-0239 主要支持参数成功历史更新，不单独隔离算子选择与参数选择贡献。
- P2026-0163 的 dual-activation 证据只覆盖 GA/DE 两个算子的比例调节，尚未证明可直接扩展到多算子池。
- P2026-0163 的收益来自 FDSEA 频域搜索、双种群协同和算子 selector 的组合；Table 3 只隔离决策域 selector 的贡献，不代表完整 FDSEA 的全部优势来自 selector。
- P2026-0145 的 LNSS 证据来自调度局部搜索邻域，尚未证明可直接替代所有进化算子选择器。
- P2026-0145 中 LNSS 的 reward 是基于单步支配关系的短期反馈，可能低估长期多样性贡献或稀有探索邻域。
- 实验没有完全隔离算子选择与参数区间选择的单独贡献。
- 对比算法也集成了本文混合解码启发式，因此证据主要支持 SLBS 对 MODE/D 的增益，不证明其在所有宿主算法上有效。
- `lp=0.3G` 来自预实验，跨问题泛化需要重新验证。

## 待确认

- 哪种成功判据最能预测长期 Pareto 前沿质量；
- 如何在探索算子低短期收益但高长期价值时避免过早降权；
- 如何处理算子之间的组合贡献；
- 双激活 absolute/relative survival 机制如何推广到多算子连续比例向量；
- 是否应按目标区域、约束状态或搜索阶段维护不同概率表；
- 在离散、混合变量、强约束和动态问题上的稳定性。
- LNSS 这种无状态 RAR 更新与显式状态 RL 在动态/强约束问题上的边界条件。
