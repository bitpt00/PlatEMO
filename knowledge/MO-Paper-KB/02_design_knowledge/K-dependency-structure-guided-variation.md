# 依赖结构指导的变异算子

## 核心内容

先从数据、领域知识或问题结构中获得一组相互关联的决策变量模板；产生每个后代时，选择一个或少数模板，只在模板覆盖的维度内执行变异或交叉，其余维度保持不变。

```text
发现或给定变量依赖结构
-> 构造多个局部变量组/模板
-> 为每个父代选择一个模板
-> 仅在模板维度中执行类型匹配的变异
-> 用完整目标评价后代并选择
```

## 建立理由

- 为什么值得独立维护：它提供明确的“变量结构 -> 后代模板 -> 组内变异”接口，可替换任意进化算法中的逐维独立变异或无结构交叉。
- 单篇具体方法的直接复用价值：P2026-0076 使用 Markov Blanket 产生特征组，并在组内执行自适应 Cauchy 变异；综合实验和消融均直接比较了结构化与无结构后代生成。
- 与已有设计知识的区别：
  - 不构造辅助任务；
  - 不进行跨任务知识迁移；
  - 不修改目标空间环境选择；
  - 直接修改决策空间中的后代生成算子。

## 解决的问题

- 适用场景：
  - 决策变量具有耦合、模块、因果、功能或交互关系；
  - 任意逐维扰动容易产生不可行、无意义或低质量组合；
  - 问题维数较高，但单次有效改变只涉及局部变量组。
- 现有方法为什么会失败或不足：
  - 独立变异会破坏变量间必须共同变化的关系；
  - 全维变异会扩大搜索空间，并产生大量不相关改变；
  - 把复杂结构全部写成目标或惩罚项会增加目标冗余和评价难度。
- 仍需解决的问题：
  - 结构错误、遗漏或随搜索变化时如何保持探索能力；
  - 如何为不同变量类型和不同模板配置合适算子；
  - 如何评估每个结构模板的真实搜索贡献。

## 为什么可能有效

```text
问题中的有效修改通常集中在相互关联的变量组
-> 无结构扰动大量产生破坏关系或无关的后代
-> 用依赖模板限制一次变异的作用范围
-> 提高后代保持局部一致性和可行性的概率
-> 缩小单次搜索子空间，并自然产生稀疏修改
-> 多个模板随机或自适应切换，保留解集多样性
```

## 实现接口

- 输入：
  - 当前父代种群；
  - 变量组集合或映射字典；
  - 每类变量可用的变异算子。
- 输出：只在选定变量组中发生变化的后代种群。
- 插入位置：父代选择之后、后代评价之前。
- 最小实现：

```text
for each parent:
    group <- sample(variable_groups)
    child <- parent
    child[group] <- mutate(parent[group])
    repair(child)
```

- 结构来源可以是：
  - Markov Blanket、条件依赖图或因果图；
  - 变量交互检测；
  - 工程模块、约束耦合和领域规则；
  - 历史成功变异统计；
  - 动态学习的图或变量聚类。

## 如何用于算法创新

### 局部创新

- 将逐维独立变异替换为依赖组内变异。
- 保留基础算法的环境选择，只改变后代生成接口。
- 为连续、整数、类别和排列变量配置组内类型安全算子。
- 使用软限制：大多数后代遵循结构组，少数后代允许跨组探索。

### 结构创新

- 建立结构发现器与算子调度器：前者生成候选变量组，后者根据各组产生后代的历史贡献分配搜索预算。
- 维护多个竞争结构假设，让不同子种群按照不同结构模型搜索，再由统一环境选择保留有效模式。
- 将结构置信度反馈到组大小、变异强度和跨组探索概率，使算子随证据动态调整。

## 适用条件与风险

- 适用条件：
  - 能获得比随机分组更有意义的变量关系；
  - 完整解仍可被目标函数或约束评价；
  - 局部结构在一定时间内稳定，或可被动态更新。
- 不适用或可能失效的条件：
  - 最优改变需要跨越多个未连接变量组；
  - 学得结构错误或遗漏关键变量；
  - 变量关系随搜索阶段快速变化而模板固定；
  - 模板过大时退化为全维变异，过小时无法保留协同关系。
- 计算与实现成本：
  - 结构发现可能需要条件独立检验、交互分析或图学习；
  - 需要处理模板重叠、组选择、变量类型、边界和约束修复。
- 解释风险：
  - 数据依赖或 Markov Blanket 不自动等于可干预因果关系；
  - “结构一致的后代”不自动等于现实可执行或可行解。

## 证据边界

- 当前只有单篇论文证据，尚无将该算子移植到多个基础 MOEA 的直接实验。
- P2026-0076 的 Algorithms 2-3 存在独立性判断和映射接口歧义，复用时应以抽象接口重新实现并单元测试。
- 结构化变异并非总是改善：原始或其他变体仍在部分问题上显著更优。
- 论文用 Markov Blanket 结构作强因果解释，但其实验没有验证真实因果方向。
