# 有序分割的精确 Pareto 前缀动态规划

## 核心内容

对解天然由有序连续片段组成的问题，把完整解拆成“前缀子问题的 Pareto 解 + 最后一个片段”。每个前缀状态保存完整非支配集合，追加新片段后用目标增量计算候选值，再通过支配剪枝保留该前缀的 EPF。

如果某个目标被改成硬约束，例如要求恰好 `b` 个片段，则把该资源量加入 DP 状态，维护 `Pareto[k,q]`，避免候选在未达到目标资源水平前被其他资源水平的解提前支配删除。

## 解决的问题

- 适用场景：多目标有序分割、序列切割、特征分箱、分段建模等问题；解由连续片段组成，且追加最后一段时能增量更新目标值。
- 现有不足：MOEA/启发式方法只能给近似 Pareto front，可能漏掉真实 EPF 解，也可能保留非真实前沿解；如果业务要求固定资源水平，普通 Pareto 支配会偏向少资源解。
- 仍需解决：完整 EPF 的输出规模可能指数大；状态前沿集合过大时，精确算法会受内存和时间限制。

## 为什么可能有效

```text
有序连续分割解
-> 任一完整解可写成某个前缀解 + 最后一段
-> 每个前缀只保留当前子问题的非支配集合
-> 转移时追加片段并增量计算目标
-> 得到完整 EPF，而不是采样式近似前沿
```

资源约束版本的关键逻辑是：

```text
资源量若只作为目标参与支配
-> 高资源中间解可能被低资源解提前删除
-> 后续无法构造满足精确资源要求的完整解
-> 将资源量加入状态维度
-> 在同一资源水平内做支配剪枝
```

## 如何用于算法创新

### 局部创新

- 将多目标分箱、路径分段、时间序列切割、阈值选择等问题中的“候选切点枚举”替换为前缀 Pareto DP。
- 把原算法中的固定复杂度惩罚目标改成资源约束状态，例如精确片段数、精确预算层、最大变化次数等。
- 用 exact DP 在小中规模实例上产生真实 EPF，作为启发式多目标算法的评价 oracle。

### 结构创新

设计 exact-and-heuristic 混合框架：小规模或压缩后的实例用前缀 Pareto DP 求真前沿，大规模实例用其前沿分布、支配剪枝经验或资源层结构训练/指导启发式搜索。

## 适用条件与风险

- 适用条件：元素有固定顺序；可行片段必须是连续区间；完整解可由前缀解追加最后一段构造；目标能被片段追加增量计算，或至少能在可接受成本内重算。
- 可能失效：问题包含任意重排、非连续组合、跨片段强耦合约束，导致“前缀 + 最后一段”不再覆盖所有可行解。
- 成本：子问题数量通常为 `n` 或 `nb`，但每个状态保存的 EPF 可能指数大；完整 EPF 本身也可能指数大，精确算法无法绕过输出规模下界。
- 使用风险：如果先用预分箱、采样或候选切点筛选压缩输入，DP 只对压缩后的问题保持精确，对原问题只能视为近似。

## 待确认

- 在一般多目标分段问题中，哪些目标可以被安全地增量更新，哪些需要维护额外充分统计量；
- 当子问题 EPF 过大时，怎样做近似剪枝仍能保留可解释的误差界；
- 资源维度较多时，`Pareto[k,q]` 会扩展为高维状态，需要研究状态稀疏化或分层调用策略。
