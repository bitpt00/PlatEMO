# 双种群共识的变量类型挖掘

## 核心内容

在稀疏大规模多目标优化中，用两个具有不同搜索压力的种群同时演化：一个偏收敛，一个偏稀疏探索。算法持续观察两个种群非支配精英中每个变量的激活概率，并与静态变量重要性评分结合。只有在两个信息源中都呈现一致活跃或一致关闭的变量，才强烈更新其变量类型得分。最终将变量分为 essential、redundant 和 dynamic 三类，并在后续繁殖中分别执行强化注入、剪枝关闭和分组探索。

```text
静态变量评分
-> 收敛种群 P1 + 探索种群 P2
-> 两个精英档案 A1/A2 记录非支配解
-> 统计每个变量在 A1/A2 中的激活概率
-> 与静态 score 融合后分别聚类
-> 取两个聚类结果的共识活跃/共识关闭变量
-> 更新历史 type score
-> 划分 Te / Tr / Td
-> 类型感知 offspring generation
```

P2026-0152 将该机制用于 TS-VTMEA：探索阶段积累变量类型知识，优化阶段用 `OperatorO` 强化 `Te`、削减 `Tr`、对 `Td` 分组局部搜索。

## 建立理由

- 为什么值得独立维护：
  - 稀疏高维 MOO 的关键问题不是普通搜索方向，而是“哪些变量应该保持激活”。
  - 单一变量重要性评分容易受初始随机性、种群状态或目标耦合误导。
  - 双种群共识提供了一种低成本交叉验证：只有在不同稀疏压力下都稳定出现的激活/关闭模式才被强化。
  - 三类变量比二分变量筛选更可操作，`Td` 保留了尚不确定和上下文依赖变量的继续探索通道。
- 单篇具体方法的直接复用价值：
  - P2026-0152 给出 StaticVariScore、VariType、ChosenGroups、OperatorE、SparsityControl 和 OperatorO 的完整伪代码。
  - 在 32 个 SMOP benchmark 中取得 20 个最佳 IGD，并在 NN/PO 多个真实问题上取得最好 HV。
  - 消融显示去掉变量类型挖掘后性能在 7/8 个 2000 维 SMOP 上退化。
- 与已有设计知识的区别：
  - 不同于“动态辅助任务构造”：该知识用变量重要性构造低维辅助任务；本知识不构造任务，而是把变量类型直接嵌入稀疏繁殖算子。
  - 不同于“依赖结构指导的变异算子”：该知识利用变量依赖关系设计变异；本知识先按激活贡献把变量分成 `Te/Tr/Td`，再决定注入、剪枝或分组探索。
  - 不同于“非支配掩码相似性引导的稀疏模式继承”：该知识通过非支配掩码相似性继承完整稀疏模式；本知识通过双档案共识获得变量级类型并驱动后续算子。
  - 不同于“双空间分层自适应资源分配”：该知识按目标空间单元和决策变量组分配预算；本知识聚焦稀疏变量类型识别与 mask-level reproduction。

## 解决的问题

- 适用场景：
  - 决策维度很高，Pareto 最优解只激活少量变量；
  - 解表示包含 binary mask、稀疏选择向量或可被强制置零的连续变量；
  - 可从非支配解中统计变量激活频率；
  - 冗余变量误激活会明显浪费搜索预算或恶化目标；
  - 需要在探索关键变量和保持稀疏之间动态平衡。
- 现有方法为什么会失败或不足：
  - 只按静态变量评分会误判上下文依赖变量。
  - 直接降维会把误判变量永久删除，导致早熟。
  - 分组方法把变量放入固定组，可能破坏变量交互或浪费预算。
  - 普通稀疏变异只控制激活率，不知道哪些变量应被保护、关闭或继续探索。
- 仍需解决的问题：
  - 如何识别高阶变量依赖，而不只看单变量激活频率；
  - 如何处理目标特异变量和约束敏感变量；
  - 如何在变量类型变化较快的动态问题中避免历史得分滞后；
  - 如何在强离散组合结构下定义合理的变量激活概率。

## 为什么可能有效

```text
稀疏 PF -> 只有少量变量持续有贡献
-> 不同搜索压力下仍活跃的变量更可能是 essential
-> 不同搜索压力下都关闭的变量更可能是 redundant
-> 不确定变量保留为 dynamic 继续分组探索
-> 后代生成时强化 essential、剪掉 redundant、局部搜索 dynamic
-> 有效维度下降，搜索更集中，稀疏解质量提高
```

关键假设是：非支配精英的激活模式包含足够可靠的变量贡献信息，并且两个种群的不同稀疏压力能暴露变量是否真正重要。若变量价值高度依赖组合、目标区域或具体取值，单变量激活统计可能不足。

## 实现接口

- 输入：
  - 稀疏编码种群，包括 `mask` 和可选 `dec`；
  - 静态变量重要性评分；
  - 两个具有不同稀疏压力或搜索偏好的种群/档案；
  - 每个变量的历史 type score；
  - 聚类数、遗忘因子、动态变量组数；
  - 类型感知繁殖算子。
- 输出：
  - `Te`：essential variables；
  - `Tr`：redundant variables；
  - `Td`：dynamic variables；
  - 更新后的 type score；
  - 类型感知生成的 offspring。
- 插入位置：
  - SparseEA 类 decoupled encoding 的 mask update；
  - 特征选择或投资组合优化的变量筛选模块；
  - 大规模 MOEA 的变量分析与候选生成之间；
  - 代理辅助高维优化的输入变量压缩层。
- P2026-0152 的默认实例：
  - `StaticVariScore` 用 identity、lower-triangular、anti-diagonal 和 score-sorted mask 生成静态 score。
  - `P1` 为 convergence-oriented population，`tau1=0`；`P2` 为 exploration-oriented population，带目标激活率 `tau2`。
  - `SparsityControl` 每 5 代按 `P1/P2` 在第一非支配层中的占比和中位激活率差异调整 `tau2`。
  - `VariType`：
    - 计算 `A1/A2` 的中位激活率和每变量激活概率；
    - 将静态 score 与激活概率等权融合；
    - 对两个融合向量分别 K-means，`kc=3`；
    - 取两个聚类结果中的共识活跃集合和共识关闭集合；
    - 用遗忘因子 `gamma=0.9` 更新历史 `tscore`；
    - 按更新后 `tscore` 排名取 `Te`，负分变量为 `Tr`，其余为 `Td`。
  - `OperatorO`：
    - 对 `Td` 分组并选择高潜力组；
    - mutation 限制在选中动态变量组内；
    - 按父代中 `Te/Tr` 的中位计数调整 offspring 的激活/关闭。

## 如何用于算法创新

### 局部创新

- 将变量类型得分从单一激活频率扩展为激活频率、HV contribution、约束违反贡献和目标局部贡献的混合分数。
- 对不同 Pareto 区域分别维护 `Te/Tr/Td`，避免全局类型掩盖偏好区域差异。
- 用变量类型不确定性控制操作强度：高置信 `Te/Tr` 强制保护或关闭，低置信变量保留随机探索。
- 将 `Td` 分组从按 score 排序替换为基于互信息、相关性、图结构或代理梯度的交互分组。
- 在 `SparsityControl` 中加入真实评价预算、可行率或 archive 增长率，而不只看非支配层占比。

### 结构创新

- 构建稀疏高维 MOEA 的变量记忆层：

```text
静态变量探测
-> 双种群激活统计
-> 变量类型记忆
-> 类型感知繁殖
-> 类型贡献反馈
```

- 与代理辅助优化结合：只在 `Te` 和高潜力 `Td` 上训练局部 surrogate，低频抽查 `Tr`。
- 与多任务优化结合：不同任务共享高置信 `Te`，任务特异的 `Td` 保留独立探索。
- 与动态优化结合：环境变化后衰减旧 `tscore`，提高 `Td` 比例，避免过度继承旧变量类型。
- 与解释型特征选择结合：输出变量类型稳定性，作为特征选择可信度报告。

## 适用条件与风险

- 适用条件：
  - 问题存在稀疏 Pareto 最优解；
  - 变量是否激活可以被明确表示或统计；
  - 非支配精英能逐渐反映变量贡献；
  - 两个种群能形成有意义的搜索压力差异；
  - 冗余变量关闭不会破坏基本可行性。
- 不适用或可能失效的条件：
  - 变量值和变量激活强耦合，单独优化 mask 会误导搜索；
  - 变量贡献完全依赖高阶组合，单变量激活频率不可靠；
  - 最优解不是稀疏的，强制稀疏会损失性能；
  - 离散组合结构存在复杂可行性约束，关闭变量可能产生不可修复解；
  - 早期非支配精英质量低，历史 type score 被噪声污染。
- 计算与实现成本：
  - 需要维护两个种群、两个档案和历史 type score；
  - 初始化静态评分在论文中有 `O(MD^2)` 成本；
  - 每代变量类型挖掘、分组和 offspring generation 额外约 `O(D log D + ND)`；
  - K-means 和档案统计对超高维问题需要向量化或稀疏实现。

## 证据边界

- 当前只有单篇论文证据。
- 主要 benchmark 是双目标 SMOP，many-objective 稀疏问题尚未验证。
- 在 SMOP4-6 等 mask/value 强耦合问题上不稳定，集成式方法 MSKEA/S-ECSO 更有优势。
- CN 组合网络问题上并非总体最优，说明该机制更适合连续或弱组合约束的稀疏高维问题。
- 静态 score 的排序方向和符号在伪代码与文字描述中需要复现时谨慎核对。
- 数据声明为 confidential，完整复现实验存在外部数据可用性风险。
