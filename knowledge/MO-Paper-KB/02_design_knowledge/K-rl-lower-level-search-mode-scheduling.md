# 强化学习调度的下层搜索模式

## 核心内容

在双层或层级优化中，把昂贵的下层搜索/约束修复拆成多个强度不同的模式：全量修复、只修 promising 候选、暂时不修复而推进上层探索。再把模式选择视为强化学习动作，用昂贵搜索是否真正产生有效双层可行解作为反馈，让算法动态调整“下层约束满足”和“上层目标推进”的优先级。

```text
当前双层种群
-> 计算有效 LLS 率与双层可行非支配比例
-> Q-learning 选择 LLS 模式
-> 全量修复 / promising 修复 / 暂不修复
-> 更新上层种群和历史下层数据库
-> 依据指标变好或变差给奖励
-> 下一代更新模式选择
```

## 建立理由

- 为什么值得独立维护：
  - 双层优化中的下层最优性验证非常昂贵，不能默认每个候选都严格求下层。
  - 完全忽略下层约束又会被表观上层好解误导。
  - 三档 LLS 模式提供了清晰的可控开关，Q-learning 提供了在线自适应选择机制。
- 与已有设计知识的区别：
  - 不同于“状态驱动的 DRL 演化算子选择”，这里调度的是下层搜索强度和约束满足优先级，不是普通子代生成算子。
  - 不同于“约束违反状态驱动的代理搜索模式切换”，这里的约束是 bilevel follower optimality，不是普通昂贵约束代理。
  - 不同于层级策略评估，它不是固定 follower 评估层，而是按搜索反馈决定是否、对谁、以多大强度执行下层搜索。

## 解决的问题

- 适用场景：
  - 下层优化或约束修复代价远高于上层搜索；
  - 下层约束违反会误导上层目标比较；
  - 不同阶段对上层探索和下层修复的需求不同；
  - 能定义“修复/下层搜索是否有效”的反馈指标。
- 现有方法为什么会失败或不足：
  - 嵌套式全量 LLS FE 成本过高；
  - 固定只修 promising 或周期性修复缺少状态适应性；
  - 只看上层目标会保留 lower-level infeasible 的伪优解；
  - 只看下层可行性会牺牲上层 Pareto 进展。

## 为什么可能有效

```text
不同 BLMOP 类型和不同阶段需要不同优先级
-> 全量 LLS、promising LLS、无 LLS 各有优势
-> R_ELS 衡量下层搜索是否真正有用
-> R_NBF 衡量种群是否维持双层可行非支配方向
-> Q-learning 累积状态-动作收益
-> 算法按反馈选择更合适的 LLS 强度
```

关键假设是：`R_ELS` 与 `R_NBF` 的变化能反映当前 LLS 模式对后续双层 Pareto 搜索的真实贡献。

## 实现接口

- 输入：
  - 当前种群；
  - 已确认或近似的双层可行解数据库；
  - lower-level search/repair 算子；
  - 有效搜索判定；
  - 上层环境选择器。
- 模式集合：
  - `a1`：全量下层搜索；
  - `a2`：只对 promising 候选执行下层搜索；
  - `a3`：暂不执行下层搜索。
- 状态反馈：
  - `R_ELS`：下层搜索后有效解占比；
  - `R_NBF`：当前种群非支配双层可行解比例；
  - 指标变好给正奖励，变差给负奖励。
- 历史记忆：
  - 保存已执行下层搜索的上层决策及其下层候选；
  - 遇到相近或相同上层决策时从历史继续局部探索；
  - elite population 从历史双层可行记录中维护。

## 如何用于算法创新

### 局部创新

- 把 `R_ELS/R_NBF` 扩展为多维状态，加入上层 HV/IGD 改善、下层约束误差、promising 集合大小和 FE 消耗。
- 用 contextual bandit、Thompson sampling 或 UCB 替代 Q-table，降低学习成本。
- 对 `a2` 设计更细粒度的候选选择，例如膝点、参考向量稀疏区、下层不确定性或约束风险。
- 将 hybrid LLS 替换为代理辅助、多保真、warm-start 或可微下层求解器。

### 结构创新

- 构建双层优化控制器：

```text
上层搜索器
-> 下层搜索强度调度器
-> 历史下层数据库
-> 有效修复/搜索反馈
-> 策略更新
```

- 将该调度器用于昂贵约束修复、仿真校准、follower 策略评估或多阶段工程优化。
- 把历史下层数据库做成可查询记忆层，支持相近上层决策的 lower-level warm start。

## 适用条件与风险

- 适用条件：
  - 下层搜索结果可近似判定为有效或无效；
  - 有足够代数让策略从模式反馈中学习；
  - 下层搜索可被拆分为不同强度；
  - 历史下层优化记录可复用。
- 不适用或可能失效的条件：
  - 下层最优性必须严格保证，不能容忍临时忽略；
  - 下层搜索结果噪声过大，`R_ELS` 难以稳定衡量；
  - 问题太小或预算太低，Q-learning 尚未形成有效偏好；
  - `a3` 频繁执行会把种群推向大量伪优不可行解。
- 计算与实现成本：
  - 需要维护 Q-table、历史下层数据库和有效性统计；
  - promising 判定依赖当前双层可行解集；
  - hybrid LLS 仍可能是主要成本，只是被更谨慎地调用。

## 证据边界

- 当前只有单篇论文证据。
- 测试问题主要为一个 follower 且上下层各两个目标。
- 真实应用只验证一个 WP-CoMEC 定价模型。
- 类型检测和奖励指标都有经验阈值或简化状态，跨问题稳定性仍需更多验证。
- exact FE 难以闭式计算，论文主要给 worst-case 估计和实验统计。

## 待确认

- 多 follower、多目标、多约束或混合变量 BLMOP 中是否仍稳定；
- `R_ELS/R_NBF` 是否足以表达复杂下层约束违反状态；
- Q-learning 与 bandit/规则调度相比在低预算下是否值得；
- promising 候选判定如何处理噪声、代理误差或不可精确判断的下层可行性；
- 历史下层数据库在高维上层空间中如何避免膨胀和误复用。
