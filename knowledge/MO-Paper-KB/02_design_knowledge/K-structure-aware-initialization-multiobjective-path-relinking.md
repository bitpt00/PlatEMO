# 结构启发初始化与多目标路径重联

## 核心内容

在排列、路径、布局或调度这类离散多目标问题中，不让初始种群和局部搜索完全依赖随机扰动，而是先用问题结构生成高质量且可行的初始解，再在目标冲突明显的精英解之间执行 path-relinking。路径重联从一个精英解逐步变换到另一个精英解，每一步都生成可评价的中间解；这些中间解经过非支配和冗余过滤后回收到精英集，用来扩展 Pareto 前沿并增强局部开发。

```text
领域结构/约束/邻接收益
-> 结构启发式生成初始种群
-> 常规 MOEA 全局演化
-> 选择目标冲突明显的精英解对
-> 沿编码空间逐步 path-relinking
-> 评价中间解并过滤支配/冗余
-> 中间精英回流种群或 elite set
```

P2026-0098 将该机制用于多周期动态走廊布局问题：初始化利用物料流邻接优先、行长平衡和设施约束；PR 则先调整上下行断点，再通过交换逐步对齐 guide solution。

## 建立理由

- 为什么值得独立维护：
  - 离散 MOO 的随机初始化常产生低质量或不可行起点，导致早期预算浪费。
  - 普通交叉/变异难以系统性探索两个高质量解之间的结构过渡区域。
  - Path-relinking 能把“精英解差异”变成一条可搜索路径，适合排列、路由、布局、调度等有明确编辑操作的问题。
  - 结构初始化和 PR 可以形成协同：更好的起点让精英路径更有质量，PR 又把局部中间解反馈给 Pareto 集。
- 单篇具体方法的直接复用价值：
  - P2026-0098 给出面向 `(pi[t], y[t])` 编码的初始化、断点调整、序列交换、精英回收和种群处理流程。
  - 消融区分了仅初始化、仅 PR 和完整组合，显示完整 INSGA-II 在较大实例上取得更好 HV 或目标极值。
  - Fig. 14-15 直接分析初始化对 PR 改进幅度、可行中间解数量和精英接受率的影响。
- 与已有设计知识的区别：
  - 不同于“成功率反馈的算子与参数自适应选择”：该知识在线选择算子/参数；本知识设计的是结构化初始化和精英路径局部搜索。
  - 不同于“连续偏好编码的学习引导离散 MOO”：该知识用机器学习从连续偏好分数生成离散候选；本知识沿两个离散精英解之间的编辑路径生成候选。
  - 不同于“因果领域引导的离散反事实搜索”：该知识面向反事实推荐并使用因果领域变异；本知识面向通用排列/路径/布局型 MOO 的初始化与 PR。
  - 不同于“IUD-ERT-RLS 批调度启发式解码”：该知识是调度解码器；本知识是可插入 MOEA 的初始种群和精英局部搜索层。

## 解决的问题

- 适用场景：
  - 解是排列、路径、序列、断点、机器排序、设施布局或任务顺序；
  - 目标之间存在冲突，精英解之间的结构差异可能蕴含有价值折中；
  - 可定义从一个解逐步变换到另一个解的合法编辑操作；
  - 存在领域结构可用于初始化，如邻接收益、工艺先后、距离、负载、行长或资源平衡；
  - 常规 MOEA 的初始质量、局部开发或 PF 多样性不足。
- 现有方法为什么会失败或不足：
  - 随机初始化忽略领域结构，可能使初始种群远离高质量可行区域。
  - 只用交叉/变异可能重复破坏已有优质结构，缺少沿精英差异的系统性搜索。
  - 单纯局部搜索容易围绕单个解微调，覆盖不到两个冲突精英之间的折中区域。
  - 传统 PR 多用于单目标或双目标，若不做多目标筛选，中间解可能被单一目标牵引。
- 仍需解决的问题：
  - 如何选择最有价值的精英端点对；
  - 如何控制 PR 频率、路径长度和计算开销；
  - 如何避免中间解过多导致精英集膨胀；
  - 如何在强约束下保证路径中间解可行或可修复。

## 为什么可能有效

```text
领域结构 -> 更高质量初始种群
-> MOEA 更早形成有意义精英
-> 选择目标冲突精英作为路径端点
-> 中间路径覆盖潜在折中区域
-> 非支配过滤保留有贡献中间解
-> 收敛、多样性和局部开发同步增强
```

关键假设是：精英解之间的编码差异可以通过局部编辑平滑过渡，并且路径中间解对应目标空间中的有用折中。如果编码空间中的小编辑会导致目标值剧烈跳变，或中间解大量不可行，PR 收益会下降。

## 实现接口

- 输入：
  - 离散编码及解码器；
  - 领域启发式初始化规则；
  - 精英集或外部非支配档案；
  - 精英端点选择规则；
  - 从初始解到引导解的编辑算子；
  - 中间解过滤和精英集更新规则。
- 输出：
  - 结构化初始种群；
  - PR 生成的中间候选；
  - 更新后的精英集和种群；
  - PR 接受率、可行率、贡献率和耗时统计。
- 插入位置：
  - MOEA 初始化阶段；
  - 每若干代后的 elite local search；
  - 外部档案更新后；
  - 离散候选生成或重启模块。
- P2026-0098 的默认实例：
  - 编码为多周期 `(pi[t], y[t])`：`pi[t]` 是设施排列，`y[t]` 是下行设施数断点。
  - 初始化：
    - 随机选上下行起点保持多样性；
    - 按物料搬运频率计算邻接优先；
    - 分配时保持两行长度平衡；
    - 移除并重插受位置/关系约束的设施；
    - 输出结构化排列。
  - PR：
    - 从 elite set 选择两个目标冲突明显的极端个体；
    - Phase I 用插入操作调整每期上下行设施数量，使断点匹配 guide solution；
    - Phase II 用交换操作逐步修正序列位置；
    - 对 `F1`、`F2`、`F3` 分别考虑最佳中间路径；
    - 每次只变换单周期并与其他周期当前解组合，减少随机性和特征丢失；
    - 中间解加入 elite set 后做支配和冗余过滤。

## 如何用于算法创新

### 局部创新

- 将随机初始化替换为“结构得分 + 平衡约束 + 可行修复”的混合初始化。
- 端点选择不只选极端解，也可选参考方向空缺、拥挤距离大、HV contribution 高或决策空间差异大的精英对。
- 对 PR 中间解使用代理模型预筛，降低昂贵评价问题中的真实评价成本。
- 根据 PR 新解接受率自适应调整 PR 触发频率。
- 为不同目标或约束类型维护不同编辑算子，例如目标 A 优先 swap，目标 B 优先 insert。

### 结构创新

- 构建离散 MOO 的三层候选生成器：

```text
结构初始化
-> 全局演化交叉/变异
-> 精英路径重联局部增强
```

- 将 PR 作为 archive densification 层：当某个参考方向缺解时，选择相邻方向精英做路径重联。
- 与多岛模型结合：岛内演化，岛间用两个岛的代表精英执行跨岛 PR。
- 与动态优化结合：环境变化后，用旧环境精英和新环境初始精英做 PR，生成平滑过渡候选。
- 与人类偏好结合：让用户选择两个偏好解，PR 自动生成二者之间的 Pareto 折中方案。

## 适用条件与风险

- 适用条件：
  - 解空间具有可解释的编辑路径；
  - 中间解容易解码、评价或修复；
  - 领域结构能提供较可靠的初始构造规则；
  - 精英解之间存在有意义的结构差异；
  - 局部增强开销相对评价预算可接受。
- 不适用或可能失效的条件：
  - 编码高度非局部，单次编辑会导致大幅不可控变化；
  - 约束极硬，中间路径几乎全不可行；
  - 初始启发式过强导致种群多样性过低；
  - 端点精英过近，PR 只产生重复解；
  - 端点精英过远，路径过长且中间解质量差。
- 计算与实现成本：
  - 需要额外维护 elite set 和去重机制；
  - PR 会增加候选评价和局部搜索时间；
  - 对多周期或大规模排列，路径长度和中间解数需要截断；
  - 可行性修复若复杂，PR 可能成为主要耗时。

## 证据边界

- 当前只有单篇论文证据。
- 主要验证对象是 corridor allocation / dynamic layout，尚无其他排列型 MOO 复现实验。
- 完整 INSGA-II 同时包含初始化、PR 和自适应变异，不能把所有收益都归因于 PR。
- 算法比较未覆盖 MOEA/D、SPEA2、RVEA 等更多 MOEA。
- PR 增加运行时间，在评价昂贵或实时场景中需要预算控制。
- 强约束路径中间解的可行率依赖本文特定修复和编码方式。
