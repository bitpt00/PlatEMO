# 级联聚类驱动的多模态子种群阶段管理

## 核心内容

周期性把多个子种群合并视为一个待重划分集合，先用级联聚类在决策空间中分离潜在等价 Pareto 解集，再用子种群相似性合并重复方向；随后用聚类前后子种群划分的一致性指标判断模态检测是否稳定，稳定后从“发现多个 PS”的阶段切换到“合并重复方向并精细收敛”的阶段。

```text
当前多个子种群
-> 选择非支配解中的聚类中心
-> 按决策空间掩码距离分配剩余个体
-> 按多对非支配解相似性合并重复子种群
-> 计算聚类前后子种群标签 NMI
-> NMI 足够高则切换到第二阶段
-> 第二阶段继续合并相似方向并独立收敛
```

P2026-0011 的 CCTS-MMEA 在大规模稀疏 MMOP 中使用该机制，同时处理未知 PS 数量、重复子种群和阶段切换。

## 建立理由

- 为什么值得独立维护：
  - MMOP 中多子种群应尽量对应不同等价 PS，而不是盲目维持固定数量。
  - 该方法提供“拆分潜在 PS -> 合并重复 PS -> 判断阶段稳定”的完整管理接口。
  - 它避免每次只增加或减少一个子种群的低效，也避免固定周期反复分裂/合并造成的不稳定。
- 单篇具体方法的直接复用价值：
  - P2026-0011 给出 Algorithm 1、3、4 和 NMI 阶段检测流程；
  - 消融显示去掉 cascade clustering 后算法只能识别单个等价 PS；
  - Friedman 检验中 CCTS-MMEA 在 IGDX 上综合平均秩为 1.00。
- 与已有设计知识的区别：
  - 不同于多实现有效距离综合指标：该方法用于搜索过程中的子种群管理，不只是评价解集。
  - 不同于状态驱动 DRL 算子选择：这里调度的是子种群划分和阶段，不直接选择演化算子。
  - 不同于稀疏掩码模式继承：这里用掩码距离识别 PS 区域，不直接保存和复制完整稀疏模式。

## 解决的问题

- 适用场景：
  - 目标问题可能有多个等价 PS，且 PS 数量未知；
  - 算法使用多个子种群或档案探索不同决策空间区域；
  - 需要区分“还在发现模态”和“已经进入精细收敛”两个阶段；
  - 子种群可能重复探索同一 PS，也可能一个子种群混有多个 PS。
- 现有方法为什么会失败或不足：
  - 固定子种群数量可能小于或大于真实 PS 数；
  - 每轮只分裂或合并一个子种群，在 PS 多时效率低；
  - 用单个代表解衡量子种群相似性容易误判；
  - 固定周期阶段切换不能判断模态检测是否稳定。
- 仍需解决的问题：
  - 聚类中心质量依赖当前非支配解；
  - 相似性阈值和 NMI 阈值需要跨问题自适应；
  - 稀疏掩码距离不一定适合非稀疏或混合变量 MMOP。

## 为什么可能有效

```text
不同等价 PS 在决策空间形成不同区域
-> 子种群标签应随聚类逐渐稳定
-> 稳定前优先拆分和发现 PS
-> 稳定后合并重复方向并加强收敛
-> 每个子种群对应一个更清晰的搜索方向
```

关键假设是：当前优质解在决策空间中的距离或相似性能反映其所属等价 PS，并且聚类前后标签一致性可以作为模态检测是否完成的代理信号。

## 实现接口

- 输入：
  - 当前子种群集合；
  - 每个解的决策空间表示，P2026-0011 中为二进制稀疏掩码；
  - 非支配排序结果；
  - 子种群相似性度量；
  - 阶段稳定性指标，如 NMI。
- 输出：
  - 重划分后的子种群集合；
  - 是否从模态检测阶段切换到准确进化阶段；
  - 合并后的子种群数量。
- 插入位置：多子种群算法的周期性结构管理阶段，通常在若干代常规进化之后。
- P2026-0011 的默认实例：
  - cascade clustering 每 `T=10` 代执行一次；
  - 第一层从每个子种群非支配解中根据平均距离选择聚类中心；
  - 其余个体按二进制掩码 Hamming 距离分配给最近中心；
  - 第二层根据多对非支配解的平均相似性合并子种群；
  - `sim > 0.5` 时合并；
  - 聚类前后 NMI 大于 0.5 时切换到第二阶段。

## 如何用于算法创新

### 局部创新

- 用 Jaccard、加权 Hamming、Mahalanobis 或学习距离替换普通 Hamming 距离。
- 把固定 `sim > 0.5` 和 `NMI > 0.5` 替换为基于历史稳定性、置信区间或目标空间退化的自适应阈值。
- 让聚类中心选择考虑 HV 贡献、档案新颖性或 PS 覆盖缺口，而不只看平均距离。
- 合并时使用多代表解、簇边界解或核密度估计，降低单一代表误判。
- 当 NMI 长期不稳定时触发重启或增加探索子种群。

### 结构创新

- 构建多层 MMOP 控制器：

```text
模态发现层：级联聚类重划分 PS 区域
阶段判断层：用标签稳定性判断是否切换阶段
收敛管理层：合并重复方向并分配每个 PS 的搜索资源
```

- 将该机制与算子选择控制器结合：不同 PS 子种群使用不同算子、参数或局部搜索。
- 将聚类结果作为档案索引，使每个等价 PS 维护独立精英档案和覆盖指标。
- 在动态 MMOP 中用 NMI 下降作为环境变化或 PS 结构变化的检测信号。

## 适用条件与风险

- 适用条件：
  - 等价 PS 在决策空间中有可区分的区域结构；
  - 当前种群中已有足够优质解支持聚类；
  - 子种群可以被拆分、合并并继续独立进化；
  - 聚类和相似性计算成本相对评价预算可接受。
- 不适用或可能失效的条件：
  - 不同 PS 在决策空间高度交错或距离度量不可靠；
  - 早期非支配解质量太差，聚类中心偏离真实 PS；
  - 真实 PS 数持续变化或阶段边界不清晰；
  - 子种群合并后难以恢复被误合并的稀有 PS。
- 计算与实现成本：
  - 需要周期性非支配排序、距离计算、相似性矩阵和 NMI；
  - P2026-0011 给出的 cascade clustering 复杂度包含 `O(MN^2 + N^2D)`；
  - 高维和大种群下需要稀疏表示、近似距离或并行计算。

## 证据边界

- 当前只有单篇论文证据。
- 证据主要来自 SMMOP 稀疏大规模 benchmark，非稀疏 MMOP 和混合变量场景尚未验证。
- 消融同时移除了 cascade clustering 对阶段切换和子种群重划分的作用，不能完全分离每个子组件贡献。
- 阈值 `0.5` 和周期 `T=10` 由实验选择，自动化泛化仍需研究。
- 最高 benchmark 维度为 500，作者承认超大规模可扩展性有限。
