# 收敛-边界两步代理采样更新

## 核心内容

在昂贵约束多目标优化中，每轮代理搜索后分两步选择新的真实评价样本：先从当前优化器输出的有约束候选中选择目标空间表现好且分布较广的收敛样本；再从代理搜索全过程访问过的候选中选择靠近约束边界的样本。前者强化 Pareto 前沿收敛和分布，后者提升代理模型对可行/不可行边界的预测精度。

```text
代理辅助优化器产生最终种群 P1 和访问日志 O
-> 从 P1 去除已评价样本
-> 按目标空间表现和多样性选 K1 个收敛样本 C
-> 从 O 中筛选约束边界附近样本
-> 去除已评价和已选样本
-> 按表现和聚类选 K2 个边界样本 F
-> 真实评价 C union F
-> 更新训练集和代理模型
```

P2026-0023 的 SSCF 用该策略更新 Kriging 训练集，并与 FuzzyCM-Kriging 和 CCMO optimizer 组合。

## 建立理由

- 为什么值得独立维护：
  - 昂贵 CMOP 的真实评价点非常少，采样策略直接决定代理模型在哪里准确。
  - 只采最终优质解会忽略约束边界；只采边界又可能牺牲目标收敛。
  - 该方法给出清楚的“双需求、双来源、少量真实评价”接口，可替换或补充常见 infill 准则。
- 单篇具体方法的直接复用价值：
  - P2026-0023 给出 Algorithm 2、边界距离公式、`K1/K2/epsilon` 参数分析和 31 个 benchmark 证据；
  - LIR-CMOP 分析说明约束边界建模对小可行域或阻隔型不可行区域特别重要；
  - 弹簧设计验证了近边界采样在工程约束问题上的作用。
- 与已有设计知识的区别：
  - 不同于约束边界远距不可行辅助引导：该知识用于代理训练集更新和真实评价选择，不是普通 CMOEA 的辅助种群环境选择；且 P2026-0023 最佳设置偏向可行侧近边界样本。
  - 不同于约束违反状态驱动的代理搜索模式切换：这里不切换搜索模式，而是在每轮代理搜索后选择哪些点做真实评价。
  - 不同于自适应代理内环加速器：这里面向约束昂贵 MOO，重点是训练集采样需求分解，而不是无约束代理内循环何时退出。

## 解决的问题

- 适用场景：
  - 目标和约束真实评价都昂贵；
  - 代理模型需要同时预测目标值和可行性；
  - CPF 位于或接近约束边界；
  - 搜索过程中能记录大量未真实评价的访问候选；
  - 每轮真实评价预算可拆成少量收敛样本和边界样本。
- 现有方法为什么会失败或不足：
  - 只从最终输出种群采样会偏向目标空间好看的候选，忽略边界预测误差；
  - 只按 EI/CEI 等单一准则采样，可能难以显式保证边界样本覆盖；
  - 训练集中过少的近边界样本会让约束代理误判可行性；
  - 随机边界采样可能浪费在目标质量差或重复区域。
- 仍需解决的问题：
  - 如何在可行样本很少时选择边界侧；
  - 多约束尺度和方向不同，单个 `max g_j` 可能不足；
  - 收敛样本和边界样本的预算比例需要自适应。

## 为什么可能有效

```text
昂贵 CMOP 的高质量解常靠近约束边界
-> 代理若边界不准会误判可行性并污染最终解
-> 从 P1 采样优质分布解保证目标收敛
-> 从 O 采样近边界解补足可行性信息
-> 真实评价后训练集同时覆盖 CPF 附近和边界附近
-> 后续代理搜索更少产生误导性不可行或远离 PF 的候选
```

关键假设是：访问日志 `O` 包含足够多接近约束边界的候选，并且这些候选真实评价后能显著改善约束代理在 CPF 附近的判别能力。

## 实现接口

- 输入：
  - 当前训练集 `A`；
  - 代理优化器输出的有约束种群 `P1`；
  - 代理搜索期间访问过的候选集合 `O`；
  - 约束函数预测值或真实值估计；
  - 每轮收敛样本数 `K1`、边界样本数 `K2`；
  - 边界阈值 `epsilon`。
- 输出：
  - 需要真实评价的新增样本 `C ∪ F`；
  - 更新后的训练集 `A`。
- 插入位置：每轮代理搜索结束后、下一轮代理建模之前。
- P2026-0023 的默认实例：
  - `K1=10`，`K2=5`；
  - 收敛采样从 `P1` 去掉已在 `A` 中的样本，在目标空间 K-means 成 `K1` 类，每类选 fitness 最小样本；
  - 边界距离 `dist(x)=max_j g_j(x)`；
  - 若 `epsilon < 0`，选 `epsilon <= dist(x) <= 0` 的可行侧近边界样本；
  - 若 `epsilon > 0`，选 `0 <= dist(x) <= epsilon` 的不可行侧近边界样本；
  - 去除 `A` 和 `C` 中已有样本后，若候选少于 `K2` 则全选，否则 K-means 成 `K2` 类并每类选 fitness 最小样本；
  - 实验推荐 `epsilon=-0.1`。

## 如何用于算法创新

### 局部创新

- 将固定 `K1/K2` 改为根据可行率、约束代理误差或边界不确定性动态分配。
- 对边界样本加入代理预测方差、CV 不确定性或约束分类置信度。
- 按每个约束分别维护边界候选池，避免 `max_j g_j` 掩盖关键约束。
- 将边界侧从固定可行侧改为随阶段切换：早期可选不可行侧探索，后期选可行侧精修。
- 对收敛样本使用参考向量、HV 贡献或 archive gap，而不是 K-means 聚类。

### 结构创新

- 构建昂贵 CMOP 采样控制器：

```text
候选访问日志
-> 收敛需求池
-> 可行性边界需求池
-> 多样性/不确定性去冗余
-> 少量真实评价
-> 代理模型更新
```

- 与约束状态驱动代理模式切换结合：全不可行、部分可行和全可行状态使用不同边界侧与 `K1/K2`。
- 与多保真仿真结合：边界候选先用低保真校验，再选择少数高保真真实评价。
- 将访问日志变成可查询记忆库，用主动学习策略在历史候选中选择最能降低边界不确定性的点。

## 适用条件与风险

- 适用条件：
  - 真实评价成本高，代理搜索可以廉价产生较多候选；
  - 可获得每个候选的约束预测值，用于估计边界距离；
  - CPF 或可行优质解与约束边界关系密切；
  - 候选空间可聚类或有其他去冗余机制。
- 不适用或可能失效的条件：
  - 约束边界与优质 CPF 距离很远，近边界采样收益小；
  - 代理约束预测早期极差，边界候选筛选本身不可靠；
  - 多约束尺度未归一化，`max_j g_j` 被某个约束主导；
  - 评价预算极少，分出 `K2` 会明显削弱收敛采样；
  - 可行域极小且初期没有可行侧近边界候选。
- 计算与实现成本：
  - 需要记录代理优化器访问过的候选；
  - 每轮需执行去重、fitness 计算和 K-means；
  - 真实评价次数为 `K1+K2`，需纳入总训练样本预算。

## 证据边界

- 当前只有单篇论文证据。
- 缺少把 FuzzyCM、CCMO optimizer、convergence sampling、boundary sampling 分别拆开的完整消融。
- 设计变量维度整体不高，除 CTP 外多数 benchmark 设置为 10 维。
- `epsilon=-0.1` 与约束函数尺度相关，跨问题直接复用有风险。
- 真实工程应用只有弹簧设计一个案例。

- 如何动态调节 `K1/K2`；
- 是否应加入代理不确定性以避免只采模型自信但错误的边界点；
- 与其他 optimizer 和非 Kriging 代理组合时是否仍稳定。
