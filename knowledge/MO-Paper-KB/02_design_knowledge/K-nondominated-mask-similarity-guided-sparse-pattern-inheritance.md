# 非支配掩码相似性引导的稀疏模式继承

## 核心内容

把每个解的激活变量集合表示为二进制掩码，以当前非支配解为引导集；候选掩码与全部引导掩码分别计算集合相似度并聚合，选择高相似候选进入档案，再将档案中的完整掩码继承给部分种群成员。

```text
显式表示每个解的激活掩码
-> 从当前优质解中构造引导掩码集合
-> 评价候选掩码与多个引导掩码的整体相似度
-> 保存高分完整掩码到受控档案
-> 将档案掩码继承给部分个体
-> 继续优化掩码对应的数值并统一选择
```

## 建立理由

- 为什么值得独立维护：它给出了“优质解集合 -> 完整结构相似度 -> 模式档案 -> 后代结构继承”的清晰接口，可替换逐变量重要性估计、固定稀疏率采样或局部频繁项挖掘。
- 单篇具体方法的直接复用价值：P2026-0111 使用二进制 `Mask`、累计 Jaccard 评分、渐增档案和随机整掩码复制形成完整算法模块，并在最高 10000 维的基准和真实问题中验证。
- 与“依赖结构指导的变异算子”的区别：
  - 依赖结构指导的变异先获得局部变量组，并限制一次变异的作用范围；
  - 本知识从演化中的优质解学习完整激活模式，并直接替换个体的整体掩码；
  - 前者修改局部扰动模板，后者修改稀疏结构学习、档案更新和后代结构生成。

## 解决的问题

- 适用场景：
  - Pareto 最优解预计具有强稀疏性；
  - 解可以分成“是否激活”的结构层与激活后的数值层；
  - 单个变量独立评分不足以描述变量间协同激活关系；
  - 函数评价预算有限，需要尽快传播与目标质量相关的稀疏结构。
- 现有方法为什么会失败或不足：
  - 只逼近目标稀疏率或非零数量，不保证所选组合能快速改善目标值；
  - 从极少数精英挖掘频繁项，容易得到局部、有偏或不可靠的模式；
  - 独立改变变量激活概率会破坏完整变量组合；
  - 直接反复复制单一精英会快速丧失多样性。
- 仍需解决的问题：
  - 如何保护只服务于部分 PF 区域的稀有优质模式；
  - 如何同时适配新掩码和对应数值；
  - 如何在弱稀疏、many-objective 和百万变量场景中控制开销与误导。

## 为什么可能有效

```text
优质解的激活结构包含与目标表现相关的信息
-> 单个优质解可能偶然或有偏
-> 同时参考多个优质解，寻找与其共享整体结构的候选
-> 过滤掉与优质结构关系较弱的掩码
-> 将高分完整结构受控地传播给后代
-> 减少形成有效稀疏组合所需的随机试探
```

它与直接复制精英不同：被保存的候选可以不是引导解本身，而是与多个引导解具有较高整体相似度的中间结构。档案容量和继承比例用于控制知识传播强度。

## 实现接口

- 输入：
  - 具有显式二进制激活掩码的当前种群；
  - 优质解或非支配解构成的引导集；
  - 上一代模式档案；
  - 档案容量或传播强度调度规则。
- 输出：
  - 更新后的完整掩码档案；
  - 部分继承档案掩码、等待数值优化与评价的种群。
- 插入位置：
  - 环境选择后或生成后代前的掩码学习阶段；
  - 也可作为重启、初始化或稀疏结构修复模块。
- 最小实现：

```text
guides <- nondominated(population)
candidates <- population union archive

for each candidate:
    score(candidate) <- sum(
        jaccard(candidate.mask, guide.mask)
        for guide in guides
    )

archive <- top_k(candidates, score)

for each selected archive mask:
    target <- sample(population)
    target.mask <- archive_mask

optimize_values_and_select(population)
```

- P2026-0111 的具体实现：
  - `J(A,B)=|A∩B|/|A∪B|`，对全部当前非支配引导解求和；
  - 按 `k = c + N*i/i_max` 线性增加档案容量；
  - 每个档案掩码至多指导一个种群成员；
  - 整掩码复制后使用 SPEA2 交叉、变异和环境选择。

## 如何用于算法创新

### 局部创新

- 在采用 `Mask + Dec` 编码的 SparseEA 类算法中，替换原有掩码评分或稀疏遗传算子。
- 用参考向量、聚类或 PF 区域构造多个局部引导集，分别学习区域特有掩码。
- 用 HV 贡献、目标改善量或成功后代比例对引导解加权，降低简单多数模式偏置。
- 用加权 Jaccard 或 Tversky 相似度区分漏激活与误激活的不同代价。
- 复制掩码时同步迁移相关数值、重初始化新激活位或调用修复器。
- 使用位集、稀疏索引或 MinHash 近似加速超高维相似度计算。

### 结构创新

- 维护多个竞争档案：全局共有模式、PF 区域特有模式、探索性稠密模式；按在线收益分配传播预算。
- 建立闭环传播控制器，根据继承后代的存活率、HV 增量或多样性损失，自适应调节档案容量、继承次数和相似度选择压力。
- 构造稀疏/稠密双分支种群，由统一环境选择判断问题当前阶段更需要模式继承还是自由变量探索。
- 将完整掩码视为可迁移知识，在相关任务或动态环境之间进行结构级迁移，并用目标改进验证迁移是否有益。

## 适用条件与风险

- 适用条件：
  - 问题确有较强稀疏性，且“激活集合”具有稳定语义；
  - 优质解的结构相似性与后续目标改善存在可利用关系；
  - 算法能在更换掩码后继续优化或修复对应数值；
  - 保留少量无引导探索，避免所有个体被档案模式覆盖。
- 不适用或可能失效的条件：
  - 最优解较稠密，或不同 PF 区域需要几乎互斥的掩码；
  - 早期非支配解质量差，累计相似度会放大错误共性；
  - Jaccard 对掩码大小差异敏感，且所有引导解简单求和会偏向多数/中心模式；
  - many-objective 问题中多数个体都非支配，引导集失去筛选力；
  - 整体复制掩码会抹除稀有结构，或使原有数值与新结构失配。
- 计算与实现成本：
  - 精确评分成本为 `O(N|F|D)`；仅在非支配集远小于种群时可近似看作线性于 `ND`。
  - 超高维掩码需要稀疏集合、位运算、近似相似度或并行计算。
  - 必须定义空掩码之间 Jaccard 分母为零时的行为。
- 解释风险：
  - 与全部当前非支配解相似不等于接近真实 Pareto 最优结构；
  - 共享激活变量不自动意味着变量之间存在因果或功能依赖；
  - 更清晰的稀疏结构不自动意味着更好的目标空间覆盖。

## 证据边界

- 当前只有单篇论文证据，尚无将该模块移植到不同基础 MOEA 的直接实验。
- 论文没有组件消融和参数敏感性实验，无法分离累计 Jaccard、渐增档案、整掩码继承和 SPEA2 框架的贡献。
- SMOP 实验仅覆盖两目标、强稀疏设置 `θ=0.1` 和最高 10000 维。
- 论文没有理论收敛保证。
- 控制参数在公式中记为 `c`，实验中写为 `m=10`；档案容量取整、上限和末期可能超过 `N` 的行为需要代码核验。
