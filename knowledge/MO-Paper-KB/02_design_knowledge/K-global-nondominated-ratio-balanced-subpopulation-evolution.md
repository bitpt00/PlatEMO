# 全局非支配占比驱动的子种群均衡进化

## 核心内容

在多子种群算法中，先把所有子种群合并成临时档案并进行非支配排序；对每个子种群，计算其成员进入全局第一非支配层的比例。如果某个子种群的比例低于设定阈值，就让该子种群继续独立进化并重新评估，直到达到指定比例。这样可以补齐进化较慢的模态或区域，避免只有部分快子种群收敛。

```text
合并所有子种群为 archive
-> 对 archive 做非支配排序得到全局 F1
-> 对每个子种群计算 F1 成员比例
-> 比例低于阈值的子种群继续独立进化
-> 更新该子种群与全局 F1
-> 所有子种群达到阈值后退出
```

P2026-0011 将阈值设为 0.5，用该机制保证每个已识别等价 PS 都达到基本收敛水平。

## 建立理由

- 为什么值得独立维护：
  - 多子种群算法容易出现进化进度不均衡：某些区域已接近收敛，另一些区域仍停留在早期。
  - 该方法给出一个简单、可移植的进度判据：子种群在全局非支配层中的占比。
  - 它不要求预先知道真实 PS 质量，只依赖当前所有子种群的相对竞争关系。
- 单篇具体方法的直接复用价值：
  - P2026-0011 给出 Algorithm 5 的完整循环；
  - 消融显示去掉 balanced evolution 后多数问题退化，且高维场景影响更明显；
  - 参数分析显示均衡比例 `beta=0.5` 在该实验中综合最好。
- 与已有设计知识的区别：
  - 不同于双空间分层自适应资源分配：这里不显式分配函数评价预算给变量组，而是让落后的子种群继续进化直到达到质量阈值。
  - 不同于不可行解辅助种群管理：这里平衡的是不同模态或子种群的收敛进度，不是可行/不可行组成。
  - 不同于目标空间多样性选择：这里的非支配层占比用于决定是否继续进化某个子种群，而不是一次性环境选择。

## 解决的问题

- 适用场景：
  - 多个子种群分别负责不同 PS、区域、任务或参考向量；
  - 不同子种群收敛速度差异明显；
  - 希望每个子种群至少达到基本竞争力，而不是让少数强子种群主导全局选择；
  - 可以对单个子种群额外执行若干代演化。
- 现有方法为什么会失败或不足：
  - 同步每个子种群进化相同代数，不能补偿难度不同的区域；
  - 全局环境选择可能淘汰慢子种群，使对应 PS 丢失；
  - 只看子种群内部非支配率可能无法反映其相对全局质量；
  - 固定资源分配不考虑子种群当前进化程度。
- 仍需解决的问题：
  - 阈值过高会造成额外计算开销；
  - 全局 F1 可能偏向某些目标区域或短期质量；
  - 落后子种群如果方向错误，继续进化可能浪费预算。

## 为什么可能有效

```text
每个子种群代表一个潜在模态或区域
-> 只同步进化会导致进度差异累积
-> 全局 F1 占比反映该子种群的当前竞争力
-> 对低占比子种群追加独立进化
-> 各模态都达到基本收敛水平后再继续主流程
```

关键假设是：子种群进入全局第一非支配层的比例能近似反映该子种群对应模态是否已充分进化。

## 实现接口

- 输入：
  - 子种群集合；
  - 每个子种群的局部更新算子；
  - 全局非支配排序方法；
  - 均衡阈值 `beta`；
  - 可选的最大额外代数或预算上限。
- 输出：
  - 进化程度更均衡的子种群集合；
  - 每个子种群的额外进化次数或预算消耗。
- 插入位置：多子种群算法的周期性管理阶段、阶段切换后、合并/划分后或全局选择前。
- P2026-0011 的默认实例：
  - `archive` 为所有子种群合并；
  - `F1` 为 `archive` 的第一非支配层；
  - 若 `globalNum / |subP_i| < 0.5`，则更新该子种群局部指导向量，选择父代，执行 score-guided variation 和环境选择；
  - 用其他子种群加当前子种群重新排序，直到该比例达到 0.5。

## 如何用于算法创新

### 局部创新

- 将阈值从固定 0.5 改为根据子种群数量、目标数、阶段或进展率自适应。
- 把全局 F1 占比替换或扩展为 HV 贡献、IGD 改善、可行率、区域覆盖缺口或档案新增率。
- 给额外进化设置预算上限，避免错误方向子种群长期占用资源。
- 对低占比子种群切换更强探索算子、局部搜索或重启，而不是简单继续原流程。
- 将“低占比”作为状态信号交给 DRL 或 bandit 控制器决定补偿策略。

### 结构创新

- 构建子种群进度调度器：

```text
区域/模态识别
-> 估计每个子种群的全局竞争力
-> 对落后子种群追加搜索或更换策略
-> 达标后再执行合并、迁移或全局选择
```

- 将该机制用于多任务优化，确保每个任务或辅助任务都有足够非支配代表后再发生知识迁移。
- 与预算分配方法结合：先用非支配占比发现落后区域，再按收益估计分配额外评价预算。

## 适用条件与风险

- 适用条件：
  - 子种群之间代表的区域或模态相对清晰；
  - 全局非支配排序能较好反映整体竞争力；
  - 额外进化不会破坏全局评价预算或有明确预算上限；
  - 每个子种群都有可独立执行的更新流程。
- 不适用或可能失效的条件：
  - many-objective 问题中大量个体都属于 F1，比例失去区分度；
  - 强约束问题中非支配层忽略可行性风险；
  - 子种群方向错误或对应区域本来不可达，追加进化只会浪费；
  - 全局 F1 偏向某些目标空间区域，低估其他有价值模态。
- 计算与实现成本：
  - 需要反复合并排序并对子种群追加演化；
  - P2026-0011 给出 balanced evolution 复杂度为 `O(MN^2)`；
  - 实际函数评价消耗应显式计入总预算，尤其在昂贵问题中。

## 证据边界

- 当前只有单篇论文证据。
- 消融位于 CCTS-MMEA 框架内部，尚未证明该均衡机制移植到其他多子种群算法后仍有效。
- 全局非支配占比在 many-objective、强约束或目标空间退化场景中可能失去选择力。
- 额外进化的函数评价预算和主循环预算关系需要实现时明确。
- 阈值 0.5 来自该论文实验，不应直接视为通用最优。

## 待确认

- 如何定义兼顾目标空间、决策空间和可行性的子种群进度指标；
- 如何为低进度子种群设置追加预算上限；
- 如何判断低进度是因为问题更难，还是因为子种群方向错误；
- 是否应该按模态稀缺性或用户偏好给不同子种群设置不同阈值；
- 在多任务、动态和昂贵优化中该机制是否仍划算。
