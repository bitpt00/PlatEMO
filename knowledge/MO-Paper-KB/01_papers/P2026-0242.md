# Component-Sharing Preference in Expensive Multiobjective Optimization

## 一句话理解

这篇论文把“最终多解必须共享指定组件”的昂贵多目标优化偏好建模为特殊双层 MOP：上层搜索共享变量，使对应 lower-level regular front 的 HV 最大；下层在固定共享变量下搜索非共享变量，并用 Bayesian bi-level search (BBS) 与 component-sharing LCB (CSLCB) 在有限真实评价预算内主动分配采样。

## 问题与动机

- 研究问题和场景：论文研究 expensive component-sharing MOO。决策变量被分为共享变量 `s` 和非共享变量 `x`；最终输出不是任意 Pareto 解集，而是一组在 `s` 上取相同值、但在 `x` 上形成多目标 tradeoff 的设计。典型场景是模块化设计和产品族设计，例如多种水下滑翔机平面形状共享同一 fuselage / pressure cabin，以降低后续制造和开发成本。
- 现有算法为什么不足：作者观点是，大多数昂贵 MOO 算法以 Pareto optimality 为核心，目标是逼近 PF 或 PF 上特定区域；但 component-sharing preference 是作用于整个最终解集的跨解约束，可能与 Pareto optimality 冲突。先做普通 MOO 再从 PF 中找共享变量的 post-optimization 方法，在 optimal RF 与 PF 不重合时会失败；EPSL 等学习方法能生成共享解，但没有明确定义“共享性能与整体性能之间的最优折中”，且通常需要上千次评价。
- 本文希望解决什么：给出 component-sharing MOO 的显式 optimality 定义，并在 lower-level objective expensive-to-evaluate 时，用同一个全局评价档案训练 GP，避免对每个共享变量都独立运行一次昂贵 MOBO。

## 核心理念与算法流程

- 核心理念：固定一个共享变量 `s` 后，下层 `min_x F(x,s)` 的最优解集称为 regular set (RS)，其目标空间图像称为 regular front (RF)。component-sharing MOO 的任务是找到 HV 最大的 RF，而不是找到原始 `min_{x,s} F(x,s)` 的 PF。
- 主要流程：
  1. 建模：将问题写成上层 `max_s h(s)=HV(F_s(s),r)`，下层 `F_s(s)=min_x F(x,s)`。
  2. NestedEBS：若下层目标便宜，上层用 EGO 搜索 `h(s)`，每个候选 `s` 触发一次 lower-level MOP 求解；下层用 MOEA/D 权重分解近似 RF。
  3. BBS：若 `F(x,s)` 昂贵，维护统一评价档案 `D={((x_i,s_i),F(x_i,s_i))}`，每轮用全部数据为每个目标训练一个 GP。
  4. CSLCB：用 `fhat_i(x,s)=mu_i(x,s)-beta*sigma_i(x,s)` 构造 optimistic lower-level RF，定义 `alpha_CSLCB(s)=HV(Fhat(X*,s),r)`，其中 `X*` 由 MOEA/D-DE 求解多个 scalarized lower-level subproblems。
  5. Acquisition optimization：用扩展 NestedEBS 优化 `alpha_CSLCB(s)`；先评估当前最优 `s*` 和 `5ds-1` 个 LHS 初始共享变量，再用 GP+EI 搜索更优 `s`；若相对当前 `s*` 的 CSLCB 改善低于阈值 `gamma`，保守地继续用 `s*`。
  6. 真实评价：从候选 lower-level solution set 中按 HV-based batch selection 选择 `q` 个 `(x,s)` 做真实评价，更新档案和当前最优共享变量，直到 FE 预算耗尽。
- 关键组成部分：
  - RS/RF 定义：允许最终共享解集被普通 PF 支配，只要求在固定共享变量下 Pareto 最优。
  - Component-sharing HV / HV difference / accuracy：专门评价“是否找到了好的共享变量及其 RF”，避免普通 HV 混合不同 RF 时误判。
  - BBS 全局档案：不同共享变量下的评价数据共同训练 GP，解决 nested MOBO 重复浪费样本的问题。
  - CSLCB：把 BO 的 optimism 从单点扩展到“固定共享变量下整条 RF 的 optimistic HV”。
- 可能被修改的位置：可替换上层指标 HV 为 R2；替换 GP 为 ensemble/local/sparse surrogate；替换 NestedEBS 为 multitask lower-level solver；替换 batch selection 为 qEHVI/uncertainty/diversity 组合。
- 必须保留的核心：需要明确哪些变量必须共享，并且最终输出必须由同一个共享变量值对应的一组 lower-level tradeoff 解组成；若没有跨解共享变量偏好，该框架就退化为普通 expensive MOO。

## 实验证据

- 测试问题和对比算法：提出 6 个 component-sharing benchmark，包含 Type I、II、III：optimal RF 分别为 PF 子集、与 PF 部分重合、与 PF 仅一点相交；共享变量数 `ds={1,3,5}`，非共享变量数固定 `dx=6`。真实应用为 Blended-Wing-Body underwater glider (BWBUG) 平面形状设计，3 个共享 fuselage 变量、7 个非共享变量，CFD 单次约 30 分钟。
- 评价指标：合成问题用 component-sharing HV difference 和 component-sharing accuracy；真实问题因 true RF 未知，用 component-sharing HV。
- NestedEBS 证据：在下层目标便宜的实验中，NestedEBS 相比 mRegEMO、EPSL、RRA 在 component-sharing accuracy 和 HV difference 上整体更优；mRegEMO 在 Type III 问题上明显退化，说明先找 PF 再找共享变量并不稳定。
- BBS benchmark 证据：在昂贵设置中，BBS 与 RegMOBO、RegSAEA、BPSL、BBS-RRA 比较。作者报告 BBS 在 component-sharing accuracy 的 median 上对所有测试实例识别共享变量表现最好；在 HV difference 上显著优于 RegMOBO/RegSAEA 多数实例，对 BPSL 和 BBS-RRA 也达到显著改进或相当。
- BWBUG 证据：在 300 次 CFD 评价预算下，BBS 的 component-sharing HV 为 `212.6033`，高于 RegMOBO 的 `168.8330`；RegMOBO 只找到 7 个 optimal designs 且最大 lift 不超过 135 N，BBS 找到 39 个满足共享偏好的 designs，最大 lift 超过 150 N，目标空间覆盖更宽。
- 参数实验：`beta=1` 更有利于准确定位 optimal shared variables，但 `beta=0.5` 在 HV difference 上常与 `beta=1` 相当或更好，因此作者推荐 `beta=0.5`；`gamma<=1e-3` 能找到 optimal shared variables，`gamma=1e-2` 在 CSMOP3/4 上失败，作者推荐 `gamma=1e-3`。
- 证据边界：
  - 大量表格数字在 Markdown 中是图片，关键结论已通过 PDF 第 11、13 页文字核验。
  - 新 benchmark 是作者构造的，真实应用只有 BWBUG 一个案例。
  - BBS 仍依赖 GP 和嵌套 acquisition 优化，高维和复杂局部多峰目标上存在明确风险。

## 局限与未来工作

- 作者明确说明的局限：
  - BBS 受双层结构和 GP 模型的 curse of dimensionality 影响，高维问题表现困难。
  - 若 GP 难以可靠近似复杂目标，例如有许多局部最优的目标，BBS 可能失败。
  - BBS 用 NestedEBS 优化 bi-level acquisition，简单有效但搜索效率低。
- 作者未来工作：
  - 将 BBS 与 relation model、classification model 等 advanced surrogate 结合，提高高维场景可扩展性。
  - 使用 ensemble strategies，例如 global model + multiple local models，或组合多个 acquisition functions，处理复杂和多模态优化问题。
  - 用 multitask MOO 改进 NestedEBS，同时求解多个 lower-level MOP，提高计算效率。
- 我们认为仍需确认的问题：
  - 当共享变量是离散、混合变量或结构变量时，CSLCB 与 NestedEBS 如何改造。
  - component-sharing HV 只取相同 `s` 子集中的最大 HV，噪声和数值精度会影响“相同共享变量”的分组。
  - 若 DM 允许近似共享而非完全共享，需引入容差或制造成本模型。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“共享变量上层搜索的贝叶斯双层采样”：该方法具有明确插入位置、建模对象、acquisition 与实验验证，适合昂贵模块化设计和产品族 MOO 复用。
- 暂留在论文卡中的方法、原理或架构启发：
  - Type I/II/III component-sharing benchmark 构造法可用于测试偏好 MOO，但主要是评价基准，暂不单独建卡。
  - Component-sharing HV/accuracy 是评价指标，也可未来并入指标类知识。
- 局部创新线索：
  - 将 CSLCB 中的 LCB 换成 qEHVI、Thompson sampling 或 entropy search，比较 RF-level acquisition。
  - 用 trust-region 或 local GP 代替全局 GP，处理高维共享变量。
  - 在 `gamma` 阈值中加入预算状态：早期更鼓励探索新 `s`，后期更集中逼近当前 optimal RF。
- 结构创新线索：
  - 构建“共享变量 portfolio + 多任务 lower-level MOBO”的架构，同时维护多个候选 `s` 的 RF 质量和不确定性。
  - 与 manufacturing cost model 联合：上层目标不是只最大化 RF HV，而是 RF quality 与共享组件成本节省的双目标或约束式权衡。
