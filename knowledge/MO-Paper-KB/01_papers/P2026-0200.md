# A Two-Stage Learning Guided Multi-Objective Evolutionary Algorithm for Task Offloading in Edge Computing

## 一句话理解

本文把边缘计算中大量任务的卸载决策建成一个离散大规模三目标优化问题：同时最小化任务时延、经济成本和负载不均衡。为避免普通 LSMOEA 连续化处理离散变量或丢失高维搜索信息，作者提出 TSLEA：先用 adaptive incremental histogram learning model 从历史概率和当前种群 Pareto rank 中学习每个任务分配到各服务器的概率分布，再用 decision space division 把种群聚类成多个子区域，在每个局部子区域中继续用直方图模型采样细化。

## 问题与动机

- 应用问题：
  - edge computing task offloading；
  - SDN 统一接收大量终端设备任务；
  - 每个任务需要分配到覆盖范围内某个异构 edge server；
  - edge servers 具有不同计算能力、通信范围和服务价格。
- 优化目标：
  - task time delay：包含任务执行 delay 和 uplink transmission delay，下行传输延迟被忽略；
  - economic cost：按 edge server 计算资源价格计费；
  - load balancing：用服务器 workload 的标准差衡量负载不均衡。
- 难点：
  - 任务数快速增长时，决策维度达到数百到数千；
  - 每个变量是可选 edge server 的离散编号；
  - 三个目标冲突，低时延通常会提高成本并造成负载集中；
  - 机器学习式 offloading 依赖高质量训练集，且常把多目标压成单 reward；
  - 传统 EA 对大规模离散任务卸载容易收敛慢或质量不稳；
  - 许多 LSMOEA 为连续变量设计，对离散变量需 relaxation，可能引入波动或信息损失。

## 方法核心

- 个体编码：
  - 一个 offloading scheme 是 `D` 维向量；
  - 变量 `x(i)` 表示任务 `T_i` 分配到哪个 edge server；
  - 每个变量的可行域为 `pi_i`，即可覆盖并处理该任务的服务器集合；
  - 用 Algorithm 1 计算三目标 fitness。
- TSLEA 总体流程：
  - 初始化 population 和每个变量的 histogram learning model `PRO_i`；
  - 第一阶段执行 AIHLM global search；
  - 第二阶段执行 DSD local search；
  - 通过已有 MOEA 环境选择保留下一代。
- AIHLM global search：
  - 对每个决策变量维护一个离散直方图；
  - 每个 bin 表示该任务选择某个服务器的概率；
  - 初始时各 bin 概率均匀；
  - 第 `g` 代模型由历史概率 `PRO(g-1)` 和当前种群概率分布 `PD(g)` 加权更新；
  - learning rate 设置为 `lr = g/Gmax`，后期更依赖当前 population；
  - `PD(g)` 由 adaptive incremental bin height 计算；
  - bin height 根据不同 Pareto rank 的个体优越性加权，rank 更好的个体对对应服务器选择概率贡献更高；
  - offspring 直接从各变量的 histogram 中采样生成，不需要把离散变量连续化。
- DSD local search：
  - 用 k-means 思路将 population 聚成 `alpha` 个 clusters；
  - 每个 cluster 由 centroid 和 radius 定义一个 decision-space subregion；
  - radius 由 cluster centroid 之间距离计算，避免子区域过小或过大；
  - 每个 subregion 内维护并更新局部 histogram model；
  - 在各 subregion 内执行局部采样搜索 `theta Gmax` 次，以增强局部 exploitation。
- 复杂度：
  - global search 复杂度约为 `O(DSK)`；
  - local search 复杂度约为 `O(alpha DSK)`；
  - 环境选择基于非支配排序，复杂度约为 `O(N^3)`；
  - 总体复杂度记录为 `O(N^3 + alpha DSK)`。

## 实验设置与结果

- 数据集：
  - Google cluster dataset；
  - Alibaba cluster dataset；
  - EUA dataset，包含 Melbourne CBD 周边 125 个 edge servers 和 816 个 end users，任务请求数据由真实坐标和模拟服务请求组合构造。
- 问题规模：
  - 构造 60 个测试实例；
  - 由 5 个服务器规模和 4 个任务规模组合得到 20 个配置；
  - `K ∈ {25, 50, 75, 100, 125}`；
  - 任务数为 `{100, 500, 1000, 3000}`；
  - 每个配置在三个数据集上测试。
- 对比算法：
  - EA/LSMOEA：NSGAIIENS、LMOCSO、NNCSO、ALMOEA、HDDEA、GMDEC；
  - ML-based task offloading：OnDisc、RLPNet；
  - TSLEA 参数：local search ratio `theta=0.3`，subregions `alpha=5`；
  - 所有 evolutionary algorithms 的最大 function evaluations 为 `1.0e5`，population size 为 100，独立运行 20 次。
- 指标：
  - 使用 HV；
  - 因真实 Pareto front 不可得，未用 IGD；
  - reference point 由所有算法 20 次运行得到的 non-dominated solutions 的 nadir point 乘以 1.1 设置；
  - Wilcoxon rank-sum test 显著性水平为 `0.05`。
- 与 EA-based 算法对比：
  - 在 60 个测试问题上，TSLEA 相对 GMDEC、HDDEA、NNCSO、ALMOEA、LMOCSO、NSGAIIENS 分别在 38、31、40、37、47、45 个问题上取得更好 HV；
  - 作者认为 LMOCSO 只让 loser 向 winner 学习，忽略整个种群在离散决策空间中的分布特征；
  - ALMOEA/NNCSO 依赖浅层 neural model 且只用当前代训练样本，历史经验不足；
  - GMDEC/HDDEA 部分实例优于 TSLEA，但可能因变量相关分析或环境选择消耗评价预算、子代生成缺少自适应学习；
  - NSGAIIENS 使用常规 SBX 在高维离散空间探索效率不足。
- 收敛曲线：
  - 在 EUA 数据集的多数问题上，TSLEA 早期收敛更快；
  - 对 `D=100,500,3000` 的任务规模尤其明显；
  - 需要 relaxation 的算法在离散变量映射时出现一定波动。
- 与 ML-based 算法对比：
  - 在 500 tasks、100 servers 设置下，TSLEA 在三个数据集的平均 delay、cost 和 load 指标上整体优于 OnDisc 和 RLPNet；
  - TSLEA 标准差较高，说明性能更不稳定；
  - OnDisc 更稳定但平均效果较差；
  - RLPNet 在 load 上相对 OnDisc 有优势；
  - 作者认为 TSLEA 更适合追求更优解的场景，ML 方法更适合要求稳定快速反馈的场景。
- 消融：
  - 用 GMM 替换 AIHLM 的 TSLEA-AIHLM 在 14 个 EUA test problems 上低于原 TSLEA；
  - 去掉 local search 的 TSLEA-LS 在 13 个问题上低于原 TSLEA；
  - 同时去掉 AIHLM 和 local search、改为随机采样的 TSLEA-ALL 整体最差；
  - 结果支持 AIHLM 与 DSD local search 均有贡献。
- 参数敏感性：
  - 比较 `theta ∈ {0.1,0.2,0.3,0.4}` 和 `alpha ∈ {1,3,5,10}`；
  - `theta=0.4, alpha=10` 排名最好；
  - 由于更大的 `alpha` 增加 subgroup 数和计算开销，最终采用 `theta=0.3, alpha=5`。

## 局限与未来工作

- 作者明确指出：
  - 当前是静态 MOEA，没有考虑 edge computing 动态变化，例如 TD 与 edge server 距离变化；
  - 未来将研究 dynamic task offloading 和 cloud-edge-end collaborative computing；
  - 真实 task offloading 数据可能不完整或有噪声；
  - 未来考虑引入 latent factor analysis 提升鲁棒性。
- 证据边界：
  - Tables III-VII 为图片占位，精确数值需回 PDF；
  - TSLEA 与 ML 方法比较时，用 TSLEA 多个非支配解的平均目标值对比 ML 单解，评价口径仍需谨慎；
  - 任务卸载模型为静态批量问题，未覆盖实时到达、迁移成本、队列动态和服务器故障；
  - 只使用 HV，缺少运行时间、稳定性和真实服务 QoS 的系统对比。
