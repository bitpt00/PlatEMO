# Joint Optimization of Vehicle and Pedestrian Traffic Signals Using Multi-Objective Deep Reinforcement Learning

## 一句话理解

本文面向城市交叉口车流效率与行人通行安全的联合交通信号控制，提出 Dueling DQN 框架下的 DFASD 可行动作集过滤和 ACSCS 行人过街状态增强，用硬动作约束或软状态提示保证/减少 crosswalk 最大等待间隔违规，同时优化车辆等待、排队、公平性和应急车辆优先。

## 问题与动机

- 研究问题和场景：城市交叉口 TSC 需要同时优化车辆通行效率和行人过街安全便利；IoT、IoV、V2X 可提供车辆位置、速度、等待时间、车辆类型和行人过街相关状态。
- 现有算法为什么不足：cycle-based 方法信号顺序可预测、行人相对容易获得周期性绿灯，但缺少对实时交通波动的灵活响应；non-cycle DRL 能按实时车流选择相位，但常主要优化平均等待时间或队列长度，可能长期忽视低流量车道、应急车辆和行人过街权利。已有 pedestrian-aware DRL 常依赖细粒度行人位置/等待时间，或用简单加权和奖励导致低流量行人仍可能等待过久。
- 本文希望解决什么：在不依赖复杂个体行人跟踪的情况下，为每个 crosswalk 设置最大允许信号间隔 `maxCWSI`，并在 Dueling DQN 中同时考虑车辆效率、车道公平、应急车辆优先、车辆最大等待违规和行人过街间隔违规。

## 核心理念与算法流程

- 核心理念：对必须严格满足的行人等待上界，用 action-space filtering 在每次决策时动态构造可行动作集，保证下一步选择不会让任一 crosswalk 超过 `maxCWSI`；对可通过学习平衡的行人需求，把未来 `maxCWSI` 触发信息作为 crosswalk sub-state 输入，使 Dueling DQN 提前选择更合理的相位。二者可单独使用，也可作为硬约束与软提示结合。
- 主要流程：
  1. 建立 J-way intersection 的车辆监测区，把每条入口车道离散成 cells，记录车辆存在、类型、速度、等待时间；
  2. 定义每个 vehicle signal phase 对应可同时放行的 crosswalk 集合 `CWS_a`，以及每个 crosswalk 可由哪些 vehicle phases 放行的集合 `ACW_j`；
  3. 维护每个 crosswalk 自上次绿灯以来的 elapsed time `ETCW_j` 与最大允许间隔 `maxCWSI_j`；
  4. Dueling DQN 输入包括 `(N+1)` 步车辆流状态、历史 action sequence，ACSCS 额外输入 crosswalk sub-state；
  5. DFASD 在每个决策时从当前和未来 `t, t+T, ..., t+(J-2)T` 检查哪些 crosswalk 即将达到 `maxCWSI`，构造 `SFA(t)=union ACW_j`；
  6. DFASD action selection 和 target Q max 都只在 `SFA(t)` 中进行，保证行人要求；
  7. ACSCS 不改变 action space，而是把 crosswalk exceedance timing 矩阵输入 MLP，让网络学习车辆/行人折中；
  8. reward 分为 vehicle group 和 pedestrian group，包括等待、队列、公平性、应急车辆、车辆最大等待违规、maxCWSI 违规和连续违规；
  9. 用 SUMO + Unity 仿真训练和比较 DFASD、ACSCS、DFASD+ACSCS 与多个基线。
- 关键组成部分：Dueling DQN、vehicle traffic flow sub-state、previous action sequence sub-state、crosswalk sub-state、DFASD dynamic feasible action set、ACSCS state augmentation、multi-objective reward group、first pedestrian detection extension。
- 可能被修改的位置：安全/服务约束 RL 的 action masking、交通信号控制 DRL、离散动作多目标控制、等待上界和服务水平约束建模。
- 必须保留的核心：若要保证约束，action selection 和 next-state target max 都必须使用 feasible action set；若只加入 reward penalty 或 state augmentation，则只能降低违规概率而不能保证零违规。

## 实验证据

- 测试问题和对比算法：SUMO + Unity 四向交叉口，6 相位信号，单步 `T=15s`，每 episode 240 步；车流由方向相关 log-normal/Poisson 和 uniform 混合到达，应急车 uniform 到达；行人按 log-normal 到达。比较 Dueling DQN、DFASD、ACSCS、DFASD+ACSCS、PV-TSC、CAMABRL、3DQN Cycle 和 Cycle Webster；还测试真实道路 arrival data、on/off-peak、T-shaped intersection、不同 pedestrian arrival models 和 FPD。
- 主要实验结论：DFASD、ACSCS、DFASD+ACSCS 的 reward 收敛均优于 Dueling DQN；DFASD+ACSCS 综合 reward 略优于单模块。与现有 DRL 和 Webster 比较时，提出方法在车辆和行人指标上整体相当或更优，lane fairness 相对 DRL 基线提升约 50%-85%，emergency vehicle waiting time 约低 20%-30%，pedestrian waiting time 降低约 20%-55%。
- 消融或机制证据：DFASD 和 DFASD+ACSCS 在 maxCWSI 违规和连续违规上为零；ACSCS 随学习能稳定降低违规，相比 Dueling DQN 约减少超过 60%。DFASD 因 action space 受限早期车辆指标较弱，但收敛后改善；ACSCS 对公平性随训练改善明显；组合方案把 ACSCS 的 soft-constraint signal 与 DFASD 的 hard compliance 结合，提升有限但稳定。
- 场景泛化证据：on-peak 下 DFASD/组合因更强行人约束会有一定车辆延迟代价，但行人等待和违规明显更好；off-peak 和 T-shaped intersection 下提出方法保持稳定；FPD 在低行人密度 PAM2/PAM3 下显著改善车辆流，同时保持行人服务保证。
- 证据边界：仿真为单交叉口或 T-shaped 单点场景，尚未多交叉口协调；实验权重和 `maxCWSI` 需按政策设置；表格数值多为图片占位，PDF 已定点核验。

## 局限与未来工作

- 作者明确说明的局限：当前框架未加入 emergency vehicle 专用路径规划或信号抢占机制；尚未扩展到 multi-intersection 协调控制。
- 作者未来工作：扩展到多交叉口环境，优化互联交叉口的 coordinated TSC；集成 real-time emergency vehicle detection、priority path planning 和 signal preemption。
- 我们认为仍需确认的问题：DFASD 在复杂多相位、行人/车辆冲突矩阵更复杂时可行动作集是否可能过小或频繁退化；`maxCWSI` 与车辆拥堵之间的权重/阈值如何政策化设定；行人检测误报/漏报对 FPD 的影响；多交叉口中局部 maxCWSI 保证是否会破坏网络级协调。
