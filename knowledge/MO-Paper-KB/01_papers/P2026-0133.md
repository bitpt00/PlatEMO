# An adaptive auxiliary problem-based evolutionary algorithm for multi-objective optimization problems with complex constraints

## 一句话理解

论文提出 AA-CMOEA：不再把辅助问题固定为“无约束 MOP”“松弛约束 MOP”或“CV 额外目标 MOP”，而是让辅助问题随搜索进程逐步加入合适的约束子集。约束加入顺序由两类相关性决定：先看每个约束的违反序列与目标值变化是否显著相关；若没有显著约束，则用 APC 对未处理约束按 infeasible ratio 和平均 violation 分组，并按 expected constraint violation 选择下一组。主/辅种群之间的协作强度由 JSD 相似度控制，必要时还用动态参考点在 APF 和 CPF 之间采样新个体。

## 问题与动机

- 研究问题：
  - CMOP 的核心难点是平衡目标优化和约束满足；
  - AOF 类 CMOEA 常构造一个或多个辅助问题来帮助主问题，但辅助问题通常固定；
  - 单一辅助问题只适合特定 CMOP，例如无约束辅助在 UPF 与 CPF 重合或包含时有效，但 UPF 与 CPF 距离大时可能误导搜索；
  - 多阶段 CMOEA 能逐步加入约束，但约束处理顺序会明显影响结果；
  - 现有方法缺少有效的 constraint-handling sequence determination mechanism。
- 现有方法为什么不足：
  - 固定辅助问题不能随主种群需求变化；
  - 两阶段或三阶段辅助种群只是粗粒度切换，无法及时响应主种群需要；
  - 按 infeasible rate 或原始约束顺序逐个处理，忽略约束-目标关系和约束间耦合；
  - 弱合作在 UPF/CPF 差距大时可能造成负迁移，强合作又可能在相似度高时浪费计算；
  - 只靠 DE 生成后代，可能难以探索主/辅种群之间未开发区域。
- 本文希望解决什么：
  - 基于进化数据自动确定约束处理顺序；
  - 动态更新辅助问题包含的约束子集；
  - 按主/辅种群相似度调节协作强度，降低 negative transfer；
  - 当辅助后代在主种群中 survival ratio 低时，用动态参考点生成额外个体探索 APF-CPF 间区域；
  - 在 benchmark 和煤矿综合能源系统日内调度问题上验证泛化能力。

## 核心模型与算法流程

- AA-CMOEA 总体框架：
  - 维护主种群 `P1` 和辅助种群 `P2`；
  - `P1` 求解原始 CMOP，其前沿为 CPF；
  - `P2` 求解包含可变约束子集的辅助 MOP，其前沿为 APF；
  - 初始辅助问题为 unconstrained MOP，用于提升收敛并收集后续相关性分析数据；
  - 最终辅助问题会转为把 overall constraint violation 当作额外目标的 MOP，以增加多样性；
  - 主种群用 epsilon-constraint handling + crowding distance 更新；
  - 辅助种群因约束较少，用 constrained dominance principle + crowding distance 更新。
- AUS-AP 自适应辅助问题更新：
  - 维护约束矩阵 `CM` 和目标矩阵 `OM`；
  - `CM` 的列记录各约束在当前辅助问题阶段每代的平均违反度；
  - `OM` 的列记录各目标在当前辅助问题阶段每代的平均目标值；
  - 若当前辅助种群已靠近 APF，或连续 `G` 代辅助 offspring 在主种群中的平均 survival ratio 低于阈值 `sigma`，则更新辅助问题；
  - 若当前辅助种群 feasible ratio `fr=1`，直接把所有约束加入辅助问题；
  - 否则先做 constraint-objective correlation analysis；
  - 若没有找到显著相关约束，再做 constraint-constraint correlation analysis。
- CHSDM-CA 约束序列确定：
  - 对每个约束序列 `CM_i` 和每个目标序列 `OM_j` 计算 Pearson correlation；
  - 若假设检验值低于 0.05，认为该约束与目标显著相关；
  - 只要某约束与任一目标相关，就加入待处理约束子集 `Cs`；
  - 若 `Cs` 为空，对未处理约束计算 infeasible solutions ratio `ifr(i)` 和 normalized average constraint violation `acv(i)`；
  - 用 Affinity Propagation Clustering 将未处理约束分为 `K` 组；
  - 对每组计算 `EC(k)=aifr(k)*a2cv(k)`，选择 `EC` 最大的约束组作为下一批 `Cs`；
  - 这种分组的目的不是同时处理所有约束，而是减少辅助问题更新频率并利用相似约束耦合。
- ACM-S 相似度引导协作：
  - 用 Jensen-Shannon divergence 估计主/辅种群分布差异；
  - `JSD` 越小，说明两种群越相似，协作强度越弱；
  - 协作生成的 offspring 数量为 `Ns=floor(N*JSD)`；
  - 从 `P1` 和 `P2` 各随机选 `Ns` 个体组成临时集合 `TS`，用 `DE/current-to-rand/1` 生成协作 offspring `O`；
  - 剩余 `N-Ns` 个体分别在 `P1` 和 `P2` 内部独立生成 `O1` 和 `O2`。
- IGM-DR 动态参考点个体生成：
  - 辅助种群通常收敛性更强，主种群通常可行性更强；
  - 当辅助 offspring survival ratio `sr < sigma` 时，说明 APF 与 CPF 可能相距较远，触发 IGM-DR；
  - 在主种群中确定上边界点 `Zmax^M`，在辅助种群中确定下边界点 `Zmin^H`；
  - 从主种群随机取 `eta` 个体，构造指向 `Zmin^H` 的 convergence directions；
  - 从辅助种群随机取 `eta` 个体，构造指向 `Zmax^M` 的 feasibility directions；
  - 沿两类方向各生成 `N/2` 个体，形成 `O3`；
  - 该模块只在需要时触发，因为它会额外消耗计算资源。
- 复杂度：
  - DE 子代生成和种群相似度计算为 `O(N*d)`；
  - IGM-DR 生成个体为 `O(N)`；
  - 约束-目标相关分析为 `O(Th*q*M)`；
  - 约束间分析/APC 为 `O(N^2*q + N^2*T1)`；
  - 环境选择为 `O(M*N^2)`；
  - 作者给出每代总复杂度主项为 `O(N^2*q + N^2*T1)`。

## 实验证据

- 实验设置：
  - benchmark：DOC 和 LIRCMOP 共 23 个测试函数；
  - 真实案例：coal mine integrated energy system day-ahead scheduling problem；
  - scalable constrained MaOP：CDTLZ 10 个问题，目标数为 3 和 5；
  - 对比算法 11 个：ToP、EMCMO、MTCMO、CMEGL、CTAEA、CMOEAD、CMOEA_MS、Bico、MSCEA、CSEMT、TPEA；
  - 指标：IGD、IGD+、HV、Runtime；真实 CMIES 还用 NR；
  - population size `N=100`，`MaxGen=200000`；CMIES `MaxGen=300000`；
  - DE 参数 `CR=1`、`F=0.5`，polynomial mutation probability `1/d`，distribution index 20；
  - 所有算法独立运行 30 次，Wilcoxon rank-sum test 显著性水平 0.05，PlatEMO 实现。
- 消融 1：AUS-AP vs 固定辅助问题：
  - AA-CMOEA1 使用 unconstrained MOP；
  - AA-CMOEA2 使用 relaxed constraint boundary CMOP；
  - AA-CMOEA3 使用 CV 作为额外目标的 MOP；
  - Table 3 中，AA-CMOEA 相对三个变体在 IGD 上分别为 `5/12/6`、`6/10/7`、`4/16/3`，在 HV 上分别为 `5/11/6`、`6/12/4`、`5/13/4`；
  - 作者说明固定辅助问题只在特定结构如 LIRCMOP5/9 上有效。
- 消融 2：CHSDM-CA vs 约束序列方法：
  - 对比随机序列、原始顺序、先简单约束、先复杂约束、distance correlation；
  - Table 4 中，AA-CMOEA 相对 FRM1/FRM2 在 IGD 上均为 `2/17/4`，HV 上为 `3/17/2` 和 `4/16/2`；
  - 与 distance correlation 结果相近但运行时间更优，作者认为 Pearson 足以捕捉趋势相似，复杂非线性相关未带来明显收益。
- 消融 3：IGM-DR：
  - AA-CMOEA4 去掉 IGM-DR，只用 DE；
  - AA-CMOEA5 每代都使用 IGM-DR；
  - 完整算法相对 AA-CMOEA4 在 IGD/HV 上为 `1/8/14` 和 `2/7/13`；
  - 相对 AA-CMOEA5 为 `2/12/9` 和 `1/12/9`，说明按 `sr<sigma` 触发比每代使用更稳。
- 消融 4：ACM-S：
  - AA-CMOEA6 使用 weak cooperation；
  - AA-CMOEA7 使用 strong cooperation；
  - 完整 AA-CMOEA 相对二者在 IGD 上为 `0/13/10`、`2/15/5`，在 HV 上为 `2/13/7`、`1/13/7`；
  - 弱合作在 LIRCMOP1-4 等 UPF/CPF 距离大问题上较差。
- 参数分析：
  - `sigma` 同时控制 IGM-DR 触发和辅助问题是否仍有益；
  - `sigma=0.01` 在多数 test cases 上最好；
  - `sigma=0` 时退化为无 IGM-DR 的 AA-CMOEA4；
  - `G` 控制辅助问题更新频率，`G=100` 在多数 case 上最佳。
- 23 个 benchmark 结果：
  - IGD 上，相比 11 个对比算法，AA-CMOEA 显著更优数量为 21、21、18、19、19、18、20、20、18、18、16；
  - IGD+ 上显著更优数量为 21、21、17、19、19、18、20、20、18、18、17；
  - HV 上显著更优数量为 19、20、16、18、19、17、19、19、17、17、17；
  - runtime 不如 ToP、Bico、CMOEA_MS、MTCMO、TPEA，但优于另外 6 个算法；
  - Friedman ranking：AA-CMOEA 的 IGD/IGD+/HV 排名分别为 `1.65217`、`1.69565`、`2.00000`，均最佳；runtime 排名为 `7.17391`。
- CDTLZ scalable constrained MaOP：
  - 在 3 目标和 5 目标 CDTLZ 上，AA-CMOEA 在 IGD、IGD+、HV 指标整体仍优于 11 个对比算法；
  - runtime 仍慢于 ToP、Bico、CMOEA_MS、MTCMO、TPEA，但快于另外 6 个。
- CMIES 真实案例：
  - 问题为煤矿综合能源系统日前调度，调度周期 24 h，时间间隔 1 h；
  - 决策变量 `20*24=480`，约束 `22*24=528`；
  - 两个目标：economic cost 和 carbon trading cost；
  - AA-CMOEA 获得最高 NR `1.0000e+0` 和最高 HV `7.2982e-1 (1.39e-2)`；
  - runtime `5.4904e+1 s`，仅慢于 Bico 的 `4.3238e+1 s`；
  - ToP 和 CTAEA 未能获得可行解，HV 为 NaN；
  - 选取的调度方案满足电、热、冷负荷平衡，并利用风光和矿井衍生能源减少排放。

## 局限与未来工作

- 作者明确局限/未来方向：
  - 需要探索融合问题特征和进化知识的新约束分组方法，以提高分组准确性；
  - 约束-目标相关分析可使用更鲁棒的方法；
  - 当前只处理传统约束，多序列约束问题仍需深入研究；
  - 动态约束多目标优化也值得研究；
  - 需要扩展到 constrained large-scale multi-objective optimization。
- 我们认为仍需谨慎的问题：
  - Pearson correlation 简单高效，但只能捕捉趋势相关，非单调或滞后关系可能被忽略；
  - APC 聚类和 `EC=aifr*a2cv` 依赖当前辅助种群分布，早期或误导性 APF 附近可能给出错误分组；
  - AUS-AP、ACM-S、IGM-DR 同时作用，真实收益难完全归因到单个模块；
  - runtime 不是最优，APC、JSD 和 IGM-DR 会增加额外计算；
  - CMIES 真实案例的模型参数来自已有文献，且真实 PF 未知，NR/HV 只基于算法联合解集评估。

## 可迁移设计要点

- 动态辅助问题可以把“约束子集”作为可更新结构，而非只在若干固定辅助公式之间切换；
- 约束处理顺序不应只按可行率或困难度，还应看约束违反与目标改善之间的动态关系；
- 相似约束可成组加入，减少阶段切换频率并利用耦合；
- 主/辅种群协作强度可由分布差异控制，避免固定弱/强合作；
- 当辅助种群后代无法在主种群存活时，应主动探索 APF-CPF 之间的未开发区域，而不是继续沿原辅助问题浪费预算。
