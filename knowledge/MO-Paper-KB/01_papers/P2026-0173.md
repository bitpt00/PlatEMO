# A Constrained Learning-Based Competitive Swarm Optimizer for Large-Scale Multiobjective Optimization

## 一句话理解

本文针对大规模多目标 CSO 中随机两两竞争导致 loser 学习对象质量不稳、方向剧烈抖动的问题，用参考向量子区约束 loser 只向同子区或邻子区 winners 学习，并用 winners 拟合高斯模型继续演化 winners，从而同时加速收敛和维持多样性。

## 问题与动机

- 研究问题和场景：500-5000 维、2-3 目标的 large-scale MOP，以及实例选择等真实大规模二目标问题。
- 现有算法为什么不足：DVA/grouping 方法消耗额外评价或误分变量，problem transformation 可能丢失有用搜索空间；CSO 虽适合高维直接搜索，但 pairwise random competition 可能选出质量不够的 winner，且 loser 每代学习方向随机变化，收敛速度受限。多数 CSO 还直接保留或简单变异 winners，未充分提升 winner 质量。
- 本文希望解决什么：在不做昂贵变量分析或复杂神经模型训练的前提下，约束 loser 的学习方向并增强 winner 演化，让 CSO 在大规模原始决策空间中更稳定搜索。

## 核心理念与算法流程

- 核心理念：参考向量子区可把目标空间相近的粒子组织成局部竞争单元；loser 应优先学习同一子区的高质量 winner，少量通过邻子区 winner 平均信息补充开发；winner 本身也要通过轻量分布模型继续演化，不能静态继承。
- 主要流程：
  1. 初始化 swarm `P`，生成 `N/2` 个均匀参考向量；
  2. Spatial Partition：按与参考向量的角度把两个最近粒子分到每个子区，用 Tchebycheff 值区分 winner 和 loser；
  3. Constrained Learning：每个 loser 以概率 `p=0.9` 执行 intra-subregion learning，向同子区 winner 更新；否则执行 cross-subregion learning，利用 `T=10` 个邻近 winner 的平均位置更新；
  4. GM-Assisted Evolution：用所有 winner 的决策向量均值和协方差构造多元高斯，采样 `N/2` 个粒子辅助更新 winners；
  5. Environmental Selection：合并父代、更新后的 losers 和 winners，用参考向量关联和 APD 选择下一代。
- 关键组成部分：reference-vector spatial partition、Tchebycheff winner/loser 判定、ISL、CSL、Gaussian model-assisted winner evolution、APD environmental selection。
- 可能被修改的位置：CSO/PSO 的竞争配对和 loser update、winner update、参考向量环境选择、LMOEA 的高维直接搜索算子。
- 必须保留的核心：loser 学习对象必须由目标子区或邻子区约束；winner 不只是保留或普通变异，而要从 winner 分布中采样产生的候选辅助演化。

## 实验证据

- 测试问题和对比算法：LSMOP1-9、IMF1-9，维度 `D={500,1000,2000,5000}`；对比 FDV、LMEA、LMOCSO、S-ECSO、LSMOEA/D、CCSO、NN-CSO，并额外对比 MPSOEBCD、LERD、LSTPA、APTEA/R 等 SOTA LSMOEAs；真实应用为 Fourclass、Abalone、Phishing instance selection。
- 主要实验结论：LSMOP 二目标 36 个设置中 CL-CSO 取得 26 个最佳 IGD，三目标 LSMOP 中也整体领先；IMF 36 个设置中 CL-CSO 取得 27 个最佳 IGD。Friedman rank 在四个维度上均为 1.5，总平均 1.5，优于七个 baseline。
- 消融或机制证据：CL-CSO-I 用 PRC 替换 CL 后弱于完整方法；LMOCSO 加入 CL 后优于原 LMOCSO；CSL 组件消融显示完整 CSL 在 IMF 上整体更好；用 PM 或直接保留替代 GM-assisted winner evolution 后 IGD 变差。
- 证据边界：主文大量精确 IGD/HV 和消融结果位于 supplementary，Markdown 中为文字摘要和图片占位；参数 `p=0.9`、`T=10` 基于 IMF `D=500` 的敏感性分析，跨问题自动化仍需确认。

## 局限与未来工作

- 作者明确说明的局限：未来仍需进一步研究 machine learning 提取有效搜索特征、multitasking 方法处理 LMOP，以及 CSO 在真实调度优化问题中的能力。
- 作者未来工作：用 machine learning 改善 CSO 搜索路径，构建处理 LMOP 的 multitasking 方法，并扩展到真实调度优化。
- 我们认为仍需确认的问题：高斯模型在高维协方差估计上的稳定性；参考向量子区在 many-objective、退化 PF 或强不连续 PF 中是否仍可靠；强约束、离散或混合变量下 ISL/CSL 的位置更新如何修复。
