# Generating continuous multi-objective benchmark problems by the object-oriented method

## 一句话理解

论文提出 OOMOP / object-oriented construction (OOC) 方法：把连续 MOP 的景观拆成 MOP、Objective、Private landscape、Public landscape、Public Pareto region、Peak、Shape 等对象，通过控制私有/公有变量、峰、Public Pareto region 的数量/形状/位置/大小和 PF 形状函数，生成具有已知 PS/PF、异构目标结构、复杂 PS/PF 映射和可调难度的多目标 benchmark。

## 问题与动机

- 研究问题和场景：
  - 人工 MOP benchmark 需要用于评估 MOEA 在不同问题特征上的能力。
  - 好的 benchmark 应具备可扩展目标/变量数、已知 PS/PF、多模态 PS、复杂 PS/PF 形状和可控 separability。
- 现有构造方法为什么不足：
  - SOP combination 方法能产生异构目标结构，但高维/多目标下真实 PS/PF 难获得。
  - Bottom-up 方法可扩展且 PS/PF 可知，但各目标结构同质，并且 position-related variables 上初始解可能已经高概率落在 PF 附近，削弱真实收敛压力。
  - Polygon 方法便于可视化和多目标扩展，但难精确控制非线性 PS/PF 形状。
  - 现有人工测试套件与真实 MOP 仍有差距，尤其在多模态、稀疏变量交互和复杂局部结构方面。
- 本文希望解决什么：
  - 用对象化方式组合局部景观特征，既保留异构目标结构，又保留已知 PS/PF。
  - 可分别控制 private space 和 public conflict space 的维数与难度。
  - 可生成 steep / flat / narrow Public Pareto region、many-to-many PS-PF 映射和不规则 PF。

## 核心构造框架

- 变量分组：
  - Private variables：只关联某一个目标，可为 0 个。
  - Public variables：同时影响多个目标，用于表达目标冲突，至少 1 个。
  - 总变量数为 public variables 加各目标 private variables。
- 对象层次：
  - `MOP` object：包含多个 objective objects。
  - `Objective` object：由 private landscape 和 public landscape 组成。
  - `Private landscape`：由多个 peak objects 构成。
  - `Public landscape`：由多个 Public Pareto region objects 构成。
  - `Public Pareto region`：由 shape function、radiation decay rate 和 quality decay rate 定义。
  - `Shape` object：定义 Public Pareto region 的端点、函数类型和 offset。
- 目标函数：
  - 每个目标值由 private space 与 public space 两部分相加构成。
  - Private space 使用 moving peak / general peak function，也可替换为经典全局或多峰优化函数。
  - Public space 中，Public Pareto region 被视为“辐射源”：region 内点互不支配，离 region 越远目标值按距离衰减，从而保证 region 外点被设计的 Pareto regions 支配。
- Global / local Public Pareto region：
  - Global Public Pareto region 构成 global PS 的 public-space 部分。
  - Local Public Pareto region 被 global region 支配，可用于构造 local PS 和多模态干扰。
  - Local region 的目标值由 global region 对应点衰减得到，衰减率 `r` 控制局部 PS 优劣层级。
- PF 设计：
  - 用单调递减函数 `psi` 规定 global Public Pareto region 上目标间关系。
  - 论文给出 linear、convex/concave、periodic 等 `psi` 类型。
  - 通过调整 peak positions 和 objective degradation patterns 可构造退化或局部退化 PF。
- 构造函数：
  - `OOMOP(obj_num, pri_var, pub_var, pri_peak_num, ps_num, global_ps_num, ps_type, ps_span, ps_decay_rate, ps_slope, pf_type, ymax)`
  - 主要参数控制目标数、私有变量数、公有变量数、私有峰数量、Public Pareto region 数量、global region 数量、region 形状/跨度/衰减/斜率和 PF 类型。

## 可构造的问题特征

- Flexible variable grouping：
  - 可独立设置每个目标的 private variables 和所有目标共享的 public variables。
  - 可区分算法困难来自 private space 收敛，还是 public conflict space 中的 PS/PF 搜索。
- Public Pareto region 的形状、大小、数量：
  - 可生成线段、幂函数曲线、周期正弦曲线等 region。
  - 可同时指定 global 和 local Public Pareto regions。
- Steep Public Pareto region：
  - global region 附近目标值衰减很快，导致大部分被其支配的区域反而劣于 local region，算法容易被 local PS 吸引。
- Flat Public Pareto region：
  - 大面积区域具有相同或近似相同 rank，缺少朝更优区域演化的梯度/排序信息。
- Narrow Public Pareto region：
  - global PS 只控制极窄邻域，算法只有落入其吸引域并产生好 offspring 才能继续靠近，否则会收敛到吸引域更大的 local PS。
- PS-PF mapping：
  - 可构造 one-to-one、one-to-many、many-to-one、many-to-many。
  - many-to-many 时，任何 PS segment 丢失都会导致对应 PF segment 缺失。
- Customized PF：
  - 通过 `psi` 函数生成线性、凸、凹、周期或不规则 PF。

## 实验证据

- 构造能力对比：
  - Table 5 对比 SOP、bottom-up、polygon 和 OOC。
  - OOC 支持 scalable objectives、user-defined variable assignment、controllable PS position/quantity/shape/size、controllable mapping relationship、controllable attraction basin、known PS 和 user-defined PF。
  - 作者强调其能构造 steep、flat、narrow Public Pareto region 等复杂特征，而其他方法实现困难。
- 测试算法：
  - 使用 NSGA-II、MOEA/D、IBEA、MO-CMA、RM-MEDA 五类经典 MOEAs。
  - 实现来自 PlatEMO；bi-objective 初始化 100 个体，tri-objective 初始化 300 个体；每个 OOMOP 随机生成新实例，30 次独立运行，终止为 50,000 evaluations。
- OOMOP1 vs ZDT1：
  - 在 10D 中，ZDT1 多数算法 IGD+ 在约 100 generations 前收敛，而 OOMOP1 约 300 generations 才趋稳。
  - 作者归因于 OOMOP1 的 public conflict space 有 6 维，说明冲突空间维数比独立空间维数更影响收敛速度。
- Local PS 数量：
  - OOMOP2 中随机 5 个 Public Pareto regions，仅 1 个 global PS。
  - RM-MEDA 的 IGD+ 最好，原因是 OCR 后期更高，能更大概率进入 global PS 控制区域。
  - 但所有算法 OCR 始终小于 1，约只有 60% 概率收敛到 global PS。
  - 当 local PS 增到 9 个、global PS 1 个时，所有 MOEAs 找到 global PS 的概率低于 60%。
- Many-to-many mapping：
  - OOMOP3 初始化 4 个 PS segments 对应 4 个 PF segments。
  - OCR 和 IGDX 显示，算法常从覆盖全部 global regions 退化为只覆盖部分 regions，丢失的 PS segment 会直接导致 PF segment 缺失。
- Narrow Public Pareto region：
  - OOMOP4 中 global PS 的 dominance scope 只有 0.05。
  - 所有 tested MOEAs 的 OCR 快速接近 0，种群收敛到 local Pareto region，global PS 完全丢失。
- Tri-objective periodic PF：
  - OOMOP5 使用 3 目标，public space 为 plane-shaped Public Pareto region，PF 由 periodic `psi` 生成。
  - IBEA 在 IGD+ 上最好；NSGA-II 覆盖 PF 更完整，而 MOEA/D 虽 public/private 收敛更好，却丢失部分 PF 区域。
  - 作者指出五个算法没有一个能完美解决该 tri-objective case。

## 局限与未来工作

- 作者明确说明的局限和未来方向：
  - 当前测试只覆盖 bi-objective 和 tri-objective cases。
  - 未来需要考虑 many-objective，尤其是 complicated PS/PF shapes。
  - 可将 decision-space constraints 引入 OOMOP，以构造 constrained MOP 中位于可行边界的 PS。
  - 可为 landscape components 添加 dynamic attributes，构造 dynamic MOPs。
- 我们认为仍需确认的问题：
  - 高目标数下 `psi` 诱导 PF 形状会扭曲，论文也指出高维目标空间中 PF 精确控制是未来重点。
  - 构造器参数较多，需要建立难度标尺和默认实例集，否则随机实例之间可比性不足。
  - Public Pareto region 最近点/对应点计算在高维复杂曲面上可能成为实现瓶颈。
  - 当前实验主要证明“能暴露算法差异”，还缺少与真实 MOP landscape 的系统统计对齐。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：对象化公私空间的 MOP 基准生成。它可作为 benchmark factory：用 private space 施加目标独有收敛难度，用 public Pareto regions 控制冲突空间 PS/PF 结构，用 `psi` 控制 PF 形状，并输出 PriCQ/PubCQ/OCR 诊断。
- 暂留在论文卡中的方法、原理或架构启发：
  - 不只报告最终 IGD/HV，还应同时监测 private/public space 收敛与 global PS basin 覆盖。
  - Many-to-many PS-PF 映射能直接暴露算法是否只找到了部分等价或局部 PS。
  - Narrow global PS 是一种强压力测试，可检验算法能否保留小吸引域的全局区域。
- 局部创新线索：
  - 用 OOMOP 自动生成算法训练 curriculum，从单 global region 到多 local regions、many-to-many、narrow basin 和 periodic PF。
  - 为每个生成实例计算 landscape features，例如 local/global basin ratio、public-space dimension、region curvature 和 PF segment count。
  - 将 constraints/dynamics 作为 Public Pareto region 的可插拔属性，形成 constrained/dynamic OOMOP。
