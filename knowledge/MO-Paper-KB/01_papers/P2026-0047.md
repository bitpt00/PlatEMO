# An adaptive high-order knowledge guided multi-objective evolutionary algorithm for dynamic community detection

## 一句话理解

论文提出 AHKG-MOEA，用于动态社区检测：它不固定使用最近几个历史快照，而是按当前快照与历史快照的拓扑相似度自适应分配高阶历史知识权重，将该权重写入 Adp-HoNMI 目标函数，并把最相似历史快照的优质社区结构注入 locus 编码初始化、偏置变异和双扰动模拟退火。

## 问题与动机

- 研究问题和场景：
  - 动态社区检测需要在每个时间快照中识别社区，同时保持跨时间的结构连续性。
  - 社区检测天然有多目标冲突：当前快照的 modularity 要高，社区结构又不能与历史结构无关。
  - 历史快照对当前快照的影响并不相同，尤其网络发生较大结构变化时，旧快照可能带来负迁移。
- 现有方法为什么不足：
  - DYNMOGA、DMultiMOGA 等方法通常使用固定前一快照或固定数量连续快照。
  - HoKT 引入高阶知识，但历史权重需要人工设置，不能随当前结构变化自适应。
  - 连续 DMOP 中的 TCA/SVM/prediction transfer 等方法依赖连续决策空间，难直接映射到离散社区划分空间。
  - 普通 locus-based 编码和 neighbor mutation 没有充分利用历史结构片段。
- 本文希望解决什么：
  - 让历史快照是否参与、参与多少，由当前和历史拓扑相似性决定。
  - 将高阶知识同时用于目标函数、初始化、变异和局部搜索。
  - 在不预设社区数量的情况下获得动态网络社区划分。

## 核心理念与算法流程

- 两个优化目标：
  - `Q`：modularity，衡量当前快照社区内部连边密度与外部连边稀疏程度。
  - `Adp-HoNMI`：带自适应权重的高阶 NMI，用于衡量当前社区划分与历史社区结构之间的加权相似性。
- 自适应高阶知识：
  - 对当前快照 `G_t` 和每个历史快照 `G_i` 计算拓扑相似性 `s_i = Psi(G_t, G_i)`。
  - `Psi` 使用 adjacency matrices 的 overlap ratio。
  - 通过 softmax 把相似性归一化为历史权重 `w_i`。
  - 权重越大，表示对应历史快照携带更强、更稳定、与当前更相关的结构模式。
  - 若当前快照与前一快照相似度 `r > sigma`，则认为 first-order knowledge 已足够，直接使用相邻快照 NMI；否则使用所有历史快照加权的高阶知识。
- 高阶知识编码与初始化：
  - 采用 locus-based adjacency representation，每个基因表示节点连接到的邻居节点。
  - `t=1` 时没有历史知识，使用常规 locus-based 初始化并优化社区结构。
  - `t>=2` 时，选择与当前最相似的历史快照及其最优个体。
  - 若节点在历史最优个体中存在且连接仍有效，则以一定概率保留历史基因；否则随机选择邻居节点。
- 高阶知识偏置变异：
  - 变异时同样寻找最相似历史快照的 best-adapted individual。
  - 若被变异节点在历史个体中存在且历史连接可行，则有概率变异为历史个体中的对应 gene。
  - 若节点不存在或连接无效，则退回到邻居随机变异。
- 双扰动模拟退火：
  - 每次扰动生成两个候选解：随机扰动解和历史引导扰动解。
  - 历史引导扰动把部分当前基因替换为相似历史快照最优个体的对应基因。
  - 用 Metropolis criterion 接受候选解，冷却后结束，用于增强跳出局部最优的能力。
- 总体框架：
  - 基于 NSGA-II 做非支配排序和环境选择。
  - 每个时间步输出一组 Pareto 解。
  - 为得到单个社区划分，作者从结果中选择 modularity 较高的解作为当前时间步最优社区结构。

## 实验证据

- 论文实验直接支持：
  - Adp-HoNMI、high-order encoding、biased mutation 和 simulated annealing 的消融结果均显示去除后指标下降，支持“自适应高阶历史知识贯穿目标、初始化、变异和局部搜索”的机制价值；
  - Friedman/Nemenyi 检验支持 AHKG-MOEA 相对多数对比方法的整体排名优势，但相对 HoKT 的差异未达到 Nemenyi 显著优势。
- 基本设置：
  - 实现为 Matlab。
  - 每个方法在每个数据集上独立运行 30 次，记录平均结果。
  - 主要评价指标为 NMI、F1-score 和 Error。
  - Population size 200，generations 100，crossover rate 0.7，mutation rate 0.3。
  - 高阶编码概率和偏置变异概率在 Cell 数据集上调参，最终分别取 0.2 和 0.3。
- 对比算法：
  - 包括 HoKT、DYNMOGA、KT-MOEA/D、MODPSO、Infomap、CIDLPA 等动态社区检测或图聚类方法。
  - 共同参数尽量设为相同，算法特定参数沿用原论文设置。
- 真实网络：
  - Cell Phone Call：400 个节点，10 天通话记录构成动态网络。
  - Enron：151 个用户、约 50,000 封邮件，按时间形成动态网络。
  - 论文报告 Cell 上 AHKG-MOEA 在 NMI、F1-score 和 Error 上整体领先；早期 1-3 个时间步高阶知识积累不足，优势较弱。
  - Enron 上 AHKG-MOEA 在 12 个时间点中 NMI 最优 8 个、F1-score 最优 10 个、Error 最优 8 个。
- 合成网络：
  - SYNFIX：128 个节点、4 个社区，每步随机移动节点。
  - SYNVAR：256 个节点、4 个社区，每步删除和新增节点。
  - Four Events：Birth/Death、Expansion/Contraction、Intermittent Communities、Merge/Split 四类事件，每类 5 个时间步、1000 节点、平均度 15。
  - SYNFIX 上 AHKG-MOEA 在 NMI 和 F1-score 6 个时间步领先，在 Error 8 个时间步领先。
  - SYNVAR 上 AHKG-MOEA 在 NMI、F1-score 和 Error 均有 8 个时间步领先。
  - Four Events 上除第一个时间步外，AHKG-MOEA 在三项指标上显示较强优势。
- 消融实验：
  - 用 HoKT 的人工权重替代 adaptive weight 后，Cell 和 Enron 上指标下降，支持 Adp-HoNMI。
  - 去掉 high-order encoding strategy 后，SYNFIX 和 SYNVAR 上指标下降。
  - 去掉 biased mutation operator 后，Four Events 四类数据上完整方法更好。
  - 去掉 simulated annealing 或替换为 hill climbing 后，完整 AHKG-MOEA 在 Cell/Enron 上仍更优，尤其 Enron 结构快速变化时差距更明显。
- 统计检验：
  - Friedman test 显示七个算法在三项指标上的差异显著，p-value 远小于 0.05。
  - AHKG-MOEA 在 NMI、F1-score 和 Error 上平均排名分别为 1.7258、1.7016、1.6935，均为第一。
  - Nemenyi post-hoc test 中 AHKG-MOEA 显著优于 Infomap、MODPSO、DYNMOGA、KT-MOEA/D 和 CIDLPA。
  - 相对第二名 HOKT 的排名差未超过 critical difference，因此不能说相对 HOKT 达到 Nemenyi 显著优势。

## 复杂度与实现成本

- 设迭代数为 `g`，population size 为 `p`，边数为 `m`，节点数为 `n`，时间步数为 `T`，模拟退火迭代数为 `I`。
- 单个个体主要成本：
  - 解码 `O(n log n)`；
  - crossover `O(n)`；
  - mutation `O(1)`；
  - modularity `Q` 计算 `O(m)`；
  - Adp-HoNMI 计算 `O(Tn)`。
- 模拟退火模块复杂度为 `O(I(n log n + m))`。
- 作者给出总体复杂度近似为 `O(gp(n log n + m + Tn))`。
- 主要瓶颈来自历史快照关系评估和 Adp-HoNMI，时间步或网络规模增大时成本会明显上升。

## 局限与未来工作

- 作者明确说明的局限：
  - 需要评估多个高阶历史关系并动态调整权重，时间复杂度较高。
  - 当网络规模大或历史快照数量多时，可扩展性不足。
  - 未来需要 surrogate models 或 parallel computation 来加速高阶关系评估。
- 我们的判断/仍需确认的问题：
  - 真实网络缺少 ground truth 时，论文用 Louvain 结果作为 benchmark，这更像近似参考而非真实标签。
  - Cell 数据集和正文中时间点表述存在轻微不一致，复现时应核对原始划分。
  - Adjacency overlap ratio 只能表达边重叠，对节点语义、社群拆并和长期结构相似性的刻画较粗。
  - 最终从 Pareto set 中选择 high modularity 解，会弱化多目标折中给决策者的完整信息。
  - 需要更多大规模、强节点 churn 和无稳定历史模式的数据验证高阶知识是否会产生负迁移。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：自适应高阶快照知识迁移的动态社区 MOEA。它把历史快照相似性变成权重分布，并贯穿 objective、initialization、mutation 和 local search。
- 暂留在论文卡中的方法、原理或架构启发：
  - 动态离散 MOO 中，历史解不一定直接迁移整个 chromosome；可迁移的是仍然有效的局部结构 gene。
  - 当连续 DMOP 迁移模型不适用时，可把历史知识转成结构相似性、局部邻接模式或标签关联。
  - 早期快照知识不足时，应允许算法退回当前结构优化，而不是强行使用高阶知识。
- 局部创新线索：
  - 用 graph embedding、motif overlap 或 community transition matrix 替代 adjacency overlap ratio。
  - 将 `sigma`、编码概率和历史引导扰动概率改成随结构变化强度自适应。
  - 保留 Pareto set 并用 knee point、Nash bargaining 或时间稳定偏好做选解，而不是只选高 modularity。
  - 用增量更新或候选历史快照筛选降低 `O(Tn)` 历史关系成本。
