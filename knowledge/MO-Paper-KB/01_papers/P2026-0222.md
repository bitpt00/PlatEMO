# Performance Assessment of Population-Based Multiobjective Optimization Algorithms Using Composite Indicators

## 一句话理解

本文提出基于 double reference point (DRP) 的复合质量指标，把多个已有 QI 按 aspiration/reservation levels 归一化后聚合成弱、强、混合三种 CQI，从总体表现、最弱短板和综合排名三个角度评价多目标算法。

## 问题与动机

- 研究问题和场景：population-based multiobjective optimization algorithms 通常输出 nondominated approximation set，需要用 unary quality indicators (QIs) 衡量其质量。
- 现有算法为什么不足：
  - 单一 QI 很难同时刻画 convergence、cardinality、spread、uniformity/diversity；
  - 不同 QI 对同一算法可能给出不同排名，导致性能结论依赖指标选择；
  - HV 虽然是综合且 Pareto-compliant 的代表指标，但高维目标时计算成本高；
  - 常规归一化/加权聚合缺少对“可接受下限”和“理想目标”的显式表达。
- 本文希望解决什么：提供一个可调的 composite QI 框架，让分析者按需要选择要聚合的单指标，并用 reservation/aspiration levels 解释算法在每个指标上是差于、处于还是优于期望区间。

## 核心理念与算法流程

- 核心理念：先把各单 QI 的原始值映射到同一条 0-3 的 achievement scale，再用不同 compensation schemes 聚合。W-CQI 允许好指标补偿坏指标，给总体表现；S-CQI 不允许补偿，暴露最弱指标；M-CQI 线性综合二者，用于整体排名。
- 主要流程：
  1. 选择要聚合的单一 QI，可覆盖 convergence、spread、uniformity、cardinality 中一个或多个标准。
  2. 将所有 QI 转成 maximization form；若原指标是越小越好，则取相反数。
  3. 对每个 QI 设定 minimum、maximum、reservation level 和 aspiration level。可由专家绝对给定，也可由实验数据相对设定。
  4. 用 piece-wise linearization 将每个 QI 值归一化到 0-3：`0-1` 表示差于 reservation，`1-2` 表示介于 reservation 和 aspiration，`2-3` 表示优于 aspiration。
  5. 设定各 QI 权重，计算 W-CQI、S-CQI 和 M-CQI。
  6. 联合查看 W-CQI 与 S-CQI 散点，识别总体强但存在短板的算法；用 M-CQI 形成全局排序。
- 关键组成部分：
  - DRP preference scheme：每个 QI 有 reservation 和 aspiration 两个偏好阈值。
  - W-CQI：fully compensatory，衡量算法相对于全局 reservation/aspiration 的整体位置。
  - S-CQI：noncompensatory，等价于关注最差 normalized QI，适合发现短板。
  - M-CQI：weak/strong 的线性组合，参数控制补偿程度，本文实验使用 `lambda=0.5`。
  - Pareto compliance 结果：若聚合的 QI 都 weakly Pareto-compliant 且至少一个 Pareto-compliant，则 W-CQI 和 M-CQI Pareto-compliant，S-CQI weakly Pareto-compliant。
- 可能被修改的位置：
  - 可选择不同 QI 组合，做全局综合评价，也可以只聚合多个 convergence 或 diversity 指标；
  - aspiration/reservation levels 可由百分位数、历史基准、专家期望或任务阈值设定；
  - 权重可由 AHP、MACBETH、PCA、factor analysis、DEA 或专家输入决定；
  - 可将 S-CQI 加 augmented term，使其也满足 Pareto-compliance。
- 必须保留的核心：归一化必须围绕 reservation/aspiration 两个偏好水平展开，并同时报告至少 W-CQI 与 S-CQI；只给一个完全补偿分数会掩盖单项 QI 短板。

## 实验证据

- 测试问题和对比算法：
  - 对比 18 个 PlatEMO 算法：AGEMOEAII、CLIA、DGEA、EFRRR、EMyOC、GrEA、GWASFGA、HEA、LERD、LMEA、LMOCSO、MaOEADDFC、MOEADDE、NSGA-III、PPS、RVEA、SSCEA、VaEA。
  - 测试 DTLZ1、IDTLZ2、WFG1，目标数为 3、5、8；每个算法每个问题 20 次独立运行。
  - 种群规模分别为 300、400、500；函数评价数分别为 150000、200000、250000。
  - 聚合四个单 QI，每个 QI 对应一个性能标准；具体表格在 PDF/补充材料中，Markdown 中为图片占位。
  - 实验中 reservation/aspiration levels 分别用所有算法所有运行 QI 值的 25/75 百分位设置。
- 主要实验结论：
  - 三目标 DTLZ1 上，LMEA 有最高 W-CQI 且超过全局 aspiration level，但 S-CQI 低于 1.5、接近 reservation，说明总体强但存在单项短板。
  - 同一问题上，EMyOC 的 W-CQI 不算最高，但 S-CQI 最高且处于 reservation/aspiration 区间，说明其最差单项 QI 仍在期望范围内。
  - EFRRR 在三目标 DTLZ1 上 W-CQI 第三，但 S-CQI 低于 1，说明某个单 QI 差于 reservation level；这类信息会被 W-CQI 隐藏。
  - 三目标 IDTLZ2 和 WFG1 上，AGEMOEAII 的 W-CQI 最好，S-CQI 分别最好/第二好；W-CQI 超过 aspiration level，S-CQI 位于 reservation/aspiration 区间。
  - 用 `lambda=0.5` 的 M-CQI 与 HV 排名比较：AGEMOEAII 在 M-CQI 和 HV 下都排名第一，在 9 个问题中 4 个排名第一，其余均在前 6；DGEA 在两个指标下 6/9 个问题最差、2/9 个问题倒数第二。
- 消融或机制证据：
  - W-CQI vs S-CQI 图能区分“总体高但有短板”“总体一般但无明显短板”等不同性能形态。
  - M-CQI 排名用 Wilcoxon rank-sum test 检验；补充材料 Tables A.31-A.33 显示 pairwise 显著性支持 Table II 的排名鲁棒性。
- 证据边界：
  - 实验是 proof of concept，本文没有把 CQI 直接嵌入 indicator-based MOEA 作为搜索指标；
  - 结果依赖所选单 QI、权重以及 reservation/aspiration levels；
  - 如果聚合的单 QI 本身耗时，CQI 也会耗时。

## 局限与未来工作

- 作者明确说明的局限：
  - CQI 计算成本取决于所聚合 QI 的计算成本；
  - 权重、QIs 选择和参考水平会影响最终解释；
  - 当前实验主要验证评价用途，还未系统用于 indicator-based optimization algorithms。
- 作者未来工作：
  - 更详细分析每个单 QI 的排序如何相对 CQI 排名改变；
  - 扩展到超过两个 desirable reference levels，例如应用 MRP-WSI；
  - 分析 CQIs 在 indicator-based multiobjective optimization algorithms 中的表现。
- 我们认为仍需确认的问题：
  - 当各 QI 强相关时，是否会重复计权某一性能标准；
  - 25/75 百分位是否适合不同 benchmark 或真实工程场景；
  - 若没有 HV 参与，W/M-CQI 是否仍能保持 Pareto-compliance；
  - 在 noisy 或 stochastic algorithms 下，reference levels 是否应随置信区间调整。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“愿望-保留水平驱动的复合质量指标”，因为它提供通用评价接口，可以聚合多个 QI、显式注入偏好阈值，并同时报告总体表现与最弱性能。
- 暂留在论文卡中的方法、原理或架构启发：
  - S-CQI 不是为了单独排名，而是配合 W-CQI 做诊断；
  - M-CQI 可作为最终排名，但应回看 W/S 差距解释原因；
  - 0-3 归一化区间让指标值具有可读含义：差于期望、达标、优于期望。
- 局部创新线索：
  - 在算法对比报告中，用 CQI 替代“多张指标表 + 主观总结”；
  - 给每类 benchmark 设置不同 aspiration/reservation levels，形成领域化评价；
  - 在在线进化中用 S-CQI 发现最弱标准，并触发针对性算子或参数调整。
- 结构创新线索：
  - 构建“单 QI 计算层 -> DRP 归一化层 -> W/S/M 诊断层 -> 算法选择/调参层”的评价框架；
  - 将 CQI 作为 indicator-based MOEA 的选择压力，让算法同时优化多个评价标准且避免单项短板。
