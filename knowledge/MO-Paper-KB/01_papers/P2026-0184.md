# A Knowledge-Enhanced Evolutionary Multitasking Memetic Algorithm for Multimodal Multiobjective Flexible Job Shop Scheduling Considering Speed

## 一句话理解

本文提出 KEMMA：把可变速度柔性作业车间调度建模为多模态多目标问题，在主任务 FJSP-S 旁构造去掉速度选择的简化辅助任务，通过 evolutionary multitasking、任务特化知识增强、非支配增强精英显式迁移，以及按机器顺序映射后的决策空间去冗余，同时改善 makespan/total energy consumption 的 Pareto 收敛和多个等价调度方案的保留。

## 问题与动机

- 研究问题和场景：
  - Flexible job shop scheduling considering speed，简称 FJSP-S；
  - 决策包含 machine assignment、operation sequencing 和 speed selection；
  - 目标为最小化 makespan `Cmax` 与 total energy consumption `TEC`；
  - `TEC` 同时考虑加工能耗和空闲能耗，机器速度越高加工时间越短，但功率/能耗随速度非线性增加。
- 为什么是 multimodal multiobjective：
  - 不同机器分配、工序顺序和速度组合可能得到相同的 `Cmax` 和 `TEC`；
  - 目标空间相同的解在决策空间可对应不同排程，例如负载更均衡或换型/转移更少；
  - 只保留目标空间少量代表会丢失可供决策者选择的等价调度方案。
- 现有方法为什么不足：
  - 传统 FJSP/FJSP-S 多默认常速或只关注目标空间 Pareto front；
  - MMOP 研究主要集中在连续问题，组合调度中的多模态属性研究较少；
  - 直接套用 NSGA-II、MOEA/D 或 EMT 算法容易丢失 decision-space 多样性；
  - 编码层面的距离不能可靠表示解码后 Gantt chart 的真实相似性。
- 本文希望解决什么：
  - 在可变速度调度中同时获得收敛的 Pareto front 和多个 Pareto set；
  - 利用简化辅助任务提升主任务搜索效率，并控制跨任务负迁移；
  - 在环境选择中按真实排程结构去掉冗余，而不是只按原始编码距离删点。

## 核心理念与算法流程

- Main task and auxiliary task：
  - `T1` 为 FJSP-S 主任务，包含速度选择；
  - `T2` 为简化 FJSP 辅助任务，不含速度选择，搜索空间更小；
  - `T2` 与 `T1` 存在结构交集，可为主任务提供边界或粗粒度调度知识；
  - 任务分配比例 `alpha` 控制两个任务的种群规模，作者参数实验中推荐 `alpha=0.9`。
- Overall KEMMA loop：
  - 初始化带 skill factor 的 population `P` 和 archive `Omega`；
  - 通过 tournament selection 得到 mating pool；
  - 执行 genetic implicit transfer，根据 skill factor 和 random mating probability `RMP` 决定同任务或跨任务交叉变异；
  - 执行 knowledge enhancement and explicit transfer，对两个任务分别做局部知识增强，并把增强后的非支配解显式转移到另一任务；
  - 执行 mapping transformation-based environmental selection，在目标空间和映射后的决策空间共同去冗余；
  - 更新 archive，最终从 archive 中输出 Pareto sets 和 Pareto front。
- Genetic implicit transfer：
  - 同 skill factor 父代执行任务内交叉变异；
  - 不同 skill factor 父代以概率 `RMP` 做跨任务交叉，否则各自寻找同任务伴侣；
  - offspring 只在继承的 skill factor 对应任务上评价；
  - OS 使用 improved precedence operation crossover 与 inversion mutation；
  - MS/SS 使用 multipoint crossover 与 multipoint mutation；
  - 辅助任务个体转向主任务时需要补速度序列，主任务转向辅助任务时忽略速度序列。
- Knowledge enhancement and explicit transfer：
  - 从每个任务内选取部分 elite 进行任务特化局部搜索；
  - `KES-1`：主任务上使用 N8 邻域，从关键路径块移动操作，做大步搜索；
  - `KES-2`：主任务上随机选择非关键路径操作并降低机器速度，尝试减少能耗；
  - `KES-3`：辅助任务上使用 N6 邻域，调整关键路径块内操作，做小步搜索；
  - `KES-4`：辅助任务上选择关键路径最后完成操作并分配给加工时间最短机器，尝试减少 makespan；
  - 增强种群中的非支配解被显式转移到另一任务；`T2 -> T1` 时速度序列初始化为最低速度，`T1 -> T2` 时丢弃速度序列。
- Mapping transformation-based environmental selection：
  - 先按 scalar fitness `phi` 在各任务内选 elite；
  - 再基于 objective values 做聚类，识别目标空间中容易冗余的候选；
  - 将原始编码映射为按机器顺序排列的 `[job, operation, speed]` 结构，辅助任务忽略 speed；
  - 在映射后的决策空间中计算拥挤距离并删除最拥挤个体；
  - 这样可以缓解“编码差异大但解码排程相似”或“目标相同但等价方案被误删”的问题。
- 必须保留的核心：
  - “简化辅助任务 + skill-factor 隐式迁移 + 任务特化 KES 显式迁移 + 排程映射变换环境选择”是 KEMMA 的完整可复用结构。

## 实验证据

- 实验设置：
  - 平台为 MATLAB；
  - 基准来自 classic MK 和 DP instances；
  - 速度等级为五档；
  - base processing power 为 10，base idle power 为 3；
  - 指标为 HV、IGD 和 IGDX；
  - 每个实验通常独立运行 20 次，MaxFEs 为 `1.00E+05`。
- 参数敏感性：
  - Taguchi `L25(5^3)` 同时测试 `N`、`alpha` 和 `RMP`；
  - `N={100,125,150,175,200}`；
  - `alpha={0.5,0.6,0.7,0.8,0.9}`；
  - `RMP={0.3,0.4,0.5,0.6,0.7}`；
  - 推荐参数为 `N=100`、`alpha=0.9`、`RMP=0.7`。
- 消融实验：
  - `KEMMA-AT` 移除辅助任务；
  - `KEMMA-T` 移除知识迁移；
  - `KEMMA-GIT` 移除 genetic implicit transfer；
  - `KEMMA-KET` 移除 knowledge explicit transfer；
  - `KEMMA-KE` 移除 knowledge enhancement；
  - `KEMMA-MTES` 移除 mapping transformation environmental selection；
  - KEMMA-AT 和 KEMMA-T 明显更差，说明 EMT 框架和迁移机制对收敛有价值；
  - KEMMA 显著优于 KEMMA-KET，说明显式迁移有效；
  - KEMMA-MTES 排名最差且显著差于完整 KEMMA，说明映射变换选择对多模态调度很关键。
- 对比算法：
  - 多目标算法：MOEA/D、NSGA-II、DSSEA；
  - 多模态多目标算法：HREA、BOEA；
  - EMT 算法：MO-MFEA、EMTMA、BLKT-DE；
  - MMFJSP 相关算法：NSGA-MSPM、APHMA；
  - KEMMA 通常显著优于大多数对比算法，KEMMA、APHMA、NSGA-MSPM 是整体最强三类；
  - 作者指出多模态感知算法通常优于普通多目标算法。
- 现象分析：
  - 在 MK01、MK05、DP08 的可视化中，KEMMA 的 PF 点数更多且接近支配其他算法；
  - 运行时间上，MOEA/D 和 NSGA-II 虽快但效果较弱；KEMMA 时间可接受；APHMA 未能在给定时间内完成部分结果；
  - MK02 上的 multimodal solution ratio 显示，KEMMA 能维持合理比例，NSGA-II/MO-MFEA 早期停滞，MOEA/D/HREA 因重复和多样性损失接近 0；
  - supplementary 中展示了多个目标值相同但决策空间不同的调度方案。
- 证据边界：
  - 许多详细数值在图片表格或 supplementary 中，Markdown 无法完整抽取；
  - 能耗模型、速度等级和 benchmark 仍是合成调度设置；
  - energy-saving strategy 不是本文主创新，需结合前作理解。

## 局限与未来工作

- 作者明确未来方向：
  - 研究真实调度问题中的多模态属性；
  - 根据任务特征进一步探索知识转移方向和转移数量；
  - 优化调度问题的决策空间表示。
- 我们认为仍需确认的问题：
  - 简化辅助任务与主任务的相关性在不同机器/作业规模下可能变化；
  - `T2 -> T1` 使用最低速度初始化可能偏向低能耗、慢加工区域；
  - 映射后的 `[job,operation,speed]` 距离是否适合更复杂约束，如换模、运输、批处理或工人约束；
  - objective clustering 与 decision-space crowding 的截断参数会影响等价解保留数量；
  - 在三目标调度、动态故障重调度或真实工厂数据中仍需验证。
