# Balancing different objectives in multi-objective optimization consensus for social network large-scale group decision-making with unmanned aerial vehicle review filtering

## 一句话理解

本文面向社交网络大规模群决策中的 UAV 购买问题，先用高质量评论筛选、情感分析、信任传播和分群构造可靠的概率语言评价系统，再用 DeGroot-HK 组内意见演化和 NSGA-II 求解的满意度-成本-共识三目标模型实现跨群体共识。

## 问题与动机

- 研究问题和场景：social network large-scale group decision-making (SN-LSGDM)，案例为从电商平台 UAV 在线评论中选择 UAV 产品；20 个热门店铺作为 DMs，5 个 UAV 模型作为 alternatives，属性为 price、performance、appearance、battery life、quality。来源：Sec. 8.1，PDF 23-24。
- 现有算法为什么不足：
  - 在线评论质量不一，低质量、无关或噪声评论会削弱 sentiment analysis 对偏好矩阵的可信度。来源：Sec. 1、Sec. 4。
  - 传统信任传播常忽略多路径、路径长度、传播效率和全局核心节点影响，只用局部路径会低估复杂社交网络中的间接信任。来源：Sec. 1、Sec. 5。
  - 缺失信息填补若只看单一相似性或静态邻居，难同时反映偏好相似、社会信任和网络结构一致性。来源：Sec. 5.2。
  - 既有 LSGDM 分群多依赖单一 opinion similarity、固定阈值或静态聚类，难刻画 cardinal/ordinal preference 与 trust network 的共同作用。来源：Sec. 6、Sec. 9.2。
  - 既有 CRP 常把共识简化为单目标 minimum-cost adjustment 或线性反馈，忽略个体满意度、调节成本、共识程度和心理调节意愿之间的冲突。来源：Sec. 1、Sec. 7。
- 本文希望解决什么：从评论数据源、信任网络、缺失值、分群和共识调节五个层面提高 SN-LSGDM 的信息可靠性和共识质量，并在最终反馈阶段显式给出 satisfaction、cost、consensus degree 的 Pareto 折中。

## 核心理念与算法流程

- 核心理念：群体共识不应只追求“最低调整成本”或“最快意见收敛”。先用评论质量和社交信任构造更可靠的初始评价，再把共识过程拆为组内意见演化和组间多目标协调两条路径，让 DMs 在 Pareto 解集中选择满意度、成本和共识之间的折中方案。
- 主要流程：
  1. 对原始 UAV 评论做清洗，用 CQI-DRI 从 spelling quality、attribute coverage、technical terminology density、functional relevance、temporal validity 等维度筛选高质量评论。来源：Sec. 4.4、Algorithm 1，PDF 10-11。
  2. 用 MiniLM 生成句向量并匹配属性相关文本，用 RoBERTa 做 sentiment classification，将情感输出转换为 PLTS，并形成 PL-IIS。来源：Sec. 4.5-4.6。
  3. 从显式 trust matrix 出发，融合 latent trust；在间接路径上按 trust strength 和 path length 计算 propagation efficiency，并用 PageRank 给多路径分配权重，得到完整 trust matrix。来源：Sec. 5.1、Algorithm 2，PDF 12-13。
  4. 用 trust-enhanced KNN 填补 PL-IIS：邻居可靠度由 preference similarity、trust degree 和 structural consistency 乘积决定，低任一维都会降低填补权重。来源：Sec. 5.2、Algorithm 3，PDF 14-15。
  5. 计算评价值相似度和 Kendall ranking similarity，融合 trust matrix 得到 interdependency matrix，再用 Infomap 自动检测 subgroup。来源：Sec. 6.1、Algorithm 4，PDF 15-17。
  6. 计算 DM confidence、degree centrality、DM weights 和 subgroup weights，为共识测度和意见演化提供权重。来源：Sec. 6.2，PDF 17-18。
  7. 第一路径：在组内计算三层 consensus level，识别未达标 subgroup/DM，选择 subgroup leader，用 DeGroot 机制稳定 leader 聚合，用 HK bounded-confidence 机制描述成员局部交互，并随意见调整更新 trust matrix。来源：Sec. 7.1，PDF 18-20。
  8. 第二路径：若全局共识不足，基于 agreeableness/personality traits 建立 MSCC 多目标模型，同时最小化 adjustment cost、最大化 satisfaction、最大化 GEG consensus degree，并用 NSGA-II 求 Pareto set。来源：Sec. 7.2、Algorithm 5，PDF 20-22。
  9. 共识后用 PLTS score function 得到最终 alternative ranking。来源：Sec. 7.3、Sec. 8.3。
- 关键组成部分：
  - CQI-DRI review filtering：提升文本偏好输入质量；
  - MiniLM+RoBERTa SA：把评论转为概率语言评价；
  - trust decay + PageRank propagation：用路径效率和节点全局影响补全信任；
  - trust/similarity/structure multiplicative KNN：填补缺失 PL-IIS；
  - cardinal-ordinal-trust Infomap clustering：从偏好数值、排序结构和社交依赖共同分群；
  - DeGroot-HK opinion evolution：组内兼顾 leader-driven convergence 与 bounded local diversity；
  - MSCC tri-objective consensus optimization：组间在 satisfaction、cost、GEG 上求 Pareto 折中。
- 可能被修改的位置：
  - 评论过滤可替换为 LLM relevance scoring、domain lexicon quality control 或 multimodal evidence filtering；
  - trust propagation 可加入 negative trust、temporal decay、adversarial robustness 或 dynamic graph update；
  - KNN 填补的乘积权重可替换为可学习 reliability model；
  - Infomap 可替换为动态社区检测、多层图聚类或 overlapping communities；
  - MSCC 求解器可替换为 MOEA/D、RVEA、indicator-based EMO 或带偏好的 interactive EMO。
- 必须保留的核心：数据可靠性建模、社交信任结构、组内意见演化、组间三目标共识优化四层接口。若只保留 NSGA-II 三目标模型而不处理信任/分群，方法会退化为普通 group consensus optimization；若只做 DeGroot/HK 演化而没有 Pareto 共识优化，就无法显式平衡成本、满意度和共识。

## 实验证据

- 测试问题和对比算法：
  - UAV 案例：20 个 JD.com、Taobao、Tmall 等平台热门 UAV-selling stores，5 个 UAV alternatives，5 个评价属性；采集 review text、rating information 和 timestamps。来源：Sec. 8.1，PDF 23-24。
  - Generalization experiment：Kaggle Disneyland Reviews，约 42,000 reviews，3 个 Disney parks、20 个 visitor-country DMs、5 个属性。来源：Sec. 8.4，PDF 28-29。
  - Trust propagation 对比：our method、uniform weighting、degree centrality weighting；trust decay 对比 inverse、linear、exponential 等。来源：Sec. 9.1。
  - Clustering 对比：Shen et al.、Guo et al.、Wang et al.、Meng et al. 等。来源：Sec. 9.2。
  - CRP 对比：Guo et al.、Rodriguez et al.、Shen et al.、Liu et al. 等；指标包括 ADT、GEG、AC、AE、Time。来源：Sec. 9.3、Table 13。
  - Simulation：DM 数 `q={30,40,50,60,80,100,200,300,400,500}`，alternatives 数 `m={4,6,8}`。来源：Sec. 9.3.3。
- 主要实验结论：
  - UAV 案例中，CQI-DRI 从每个 DM 的各 alternative 评论中筛出高质量评论，随后形成四个 subgroups；组内 consensus level 从 `0.542/0.497/0.639/0.673` 提升到 `0.894/0.862/0.856/0.851`。来源：Sec. 8.3、Table 6-8，PDF 24-28。
  - 第二路径初始全局 consensus `GEG=0.618` 未达阈值，MSCC 给出 Pareto optimal solution set 供 DMs 按需求选择。来源：Sec. 8.3、Fig. 11。
  - Disneyland 泛化实验中，不改模型核心结构和参数，Infomap 仍得到结构清晰的 subgroups，dual-path consensus 可引导异质群体快速收敛，MSCC Pareto set 在 satisfaction、cost、consensus level 之间保持平衡。来源：Sec. 8.4。
  - 单位调整成本参数 `M` 越大，cost 单调上升，高 consensus 区域出现边际收益递减；consensus threshold 从 0.85 到 0.95 时第一路径迭代次数为 `2,2,2,3,3,5,7`，共识可在有限迭代内达到。来源：Sec. 8.5、Fig. 15-16、Table 9。
  - Trust propagation 中 PageRank 路径权重随 DM 规模增加误差增长更慢；在 20-200 DMs 下，MAE 波动小于 0.11，最大规模 MSE 仍比 UW 约低 4.6%。来源：Sec. 9.1.1、Fig. 17。
  - Trust decay 对比中，本文方法在各规模下 MAE/MSE 最低；20 DMs 时相对 Linear 的 MAE/MSE 分别降低 41% 和 37%。来源：Sec. 9.1.2、Fig. 18。
  - CRP 对比中，本文 `GEG=0.877`、`AC=0.0075`、`AE=0.2535` 均最好，运行时间 `23.47` 不最短但可接受。来源：Sec. 9.3.1、Table 13。
  - Simulation 中所有规模下 final GCL 明显高于 initial GCL，时间随 DMs 增加但保持可接受，说明可扩展到更大群体。来源：Sec. 9.3.3、Fig. 19。
- 消融或机制证据：
  - SA 消融：引入 CQI-DRI 后，SA 与 human annotations 的一致性提高，MAE/MSE 降低。来源：Sec. 9.4.1、Fig. 20。
  - Trust 消融：B1 完整方法在 coverage 都为 1.0000 的情况下，trust entropy 和 modularity 最好，证明 latent trust fusion、propagation efficiency 和 PageRank path weighting 都有贡献。来源：Sec. 9.4.2、Fig. 21。
  - Imputation 消融：C1 完整 KNN 在不同 missing ratios 下 MSE/MAE 均低于去掉 trust、去掉 rating similarity 或随机填补顺序的变体，缺失比例越高优势越明显。来源：Sec. 9.4.3、Fig. 22。
  - Clustering 消融：A1 完整方法在 modularity、conductance、silhouette 上整体最好且波动较小，支持 similarity fusion + trust propagation 的必要性。来源：Sec. 9.4.4、Fig. 23。
  - CRP 消融：hybrid DeGroot-HK 相比单一 DeGroot/HK 更好平衡收敛效率、结构层次和意见多样性；三目标 MSCC 相比去掉任一目标的 bi-objective 模型 Pareto front 更丰富，cost/satisfaction/GEG 平衡更好。来源：Sec. 9.4.5、Fig. 24-25。
  - Hypothesis testing：trust propagation、clustering、CRP 的 paired T-test 均给出 `p<0.05` 的显著差异。来源：Sec. 9.5、Tables 15-17，PDF 40-42。
- 证据边界：
  - UAV 案例和 Disneyland 泛化仍属于评论驱动的消费评价场景，尚未覆盖公共采购、能源基础设施等作者声称的更广泛场景。
  - NSGA-II 只是 MSCC 求解器，没有与其他 MOEA 在共识 Pareto set 质量上做系统比较。

  - 统计测试只证明本文设置下性能差异显著，不说明参数迁移到全新领域时仍保持最优。

## 局限与未来工作

- 作者明确说明的局限：
  - SA 模块高度依赖 online review 数据质量；在评论稀疏或语言噪声很强时 CQI-DRI 性能可能下降。
  - 当前模型主要处理文本评论，缺少从 multimodal information 中抽取和融合决策偏好的机制。
  - 多个关键参数虽经敏感性分析显示在合理范围内鲁棒，但最终阈值仍依赖领域知识或经验调参，新场景 plug-and-play 有挑战。
  - Trust propagation 假设信任会沿网络路径衰减传递，不能充分描述 sudden trust breakdown、negative trust 或 adversarial groups 中的动态演化。来源：Sec. 10，PDF 42。
- 作者未来工作：
  - 提升 large-scale scenarios 下的 framework scalability；
  - 扩展到多领域文本和 heterogeneous data；
  - 引入 symbolic learning 与 neural networks 的 hybrid architecture，以刻画 negative trust 等复杂社会关系；
  - 发展更智能的 deep learning data-driven GDM 模型；
  - 将 SA 与 LLM 结合，用 LLM 做 semantic knowledge expansion 和 attribute association mining，用 CQI-DRI 做质量过滤和概率语言量化。来源：Sec. 11，PDF 42-43。
- 我们认为仍需确认的问题：
  - CQI-DRI 阈值 `0.35/0.35` 在非 UAV 领域是否仍有效；
  - PageRank path weighting 对稀疏、极端同质或存在恶意节点的 trust network 是否稳健；
  - agreeableness 从评价熵和 tendency 推断是否足以代表真实调节意愿；
  - MSCC Pareto set 中最终方案如何由 DMs 选择，是否需要交互式偏好引导；
  - 评论来源、社交关系问卷和 DMs 身份之间的建模假设是否适合更正式的组织决策。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“双路径意见演化-多目标共识优化”：抽象为 trust-aware subgrouping、组内 DeGroot-HK opinion evolution、组间 satisfaction-cost-consensus Pareto adjustment 的 SN-LSGDM 共识架构。
- 暂留在论文卡中的方法、原理或架构启发：
  - CQI-DRI 可作为评论驱动 MCDM 的数据质量前置层；
  - trust degree、preference similarity、structural consistency 的乘积可靠度可迁移到推荐、协作过滤或群体偏好补全；
  - cardinal similarity + ranking similarity 的双维偏好图可用于偏好聚类；
  - DeGroot-HK hybrid 可看成“快速 leader 聚合 + bounded local diversity preservation”的意见动力学模板。
- 局部创新线索：
  - 用 LLM 或 domain ontology 自动构建 CQI-DRI 的 attribute coverage 和 technical term metrics；
  - 用 dynamic graph neural network 学习 trust propagation，并显式处理 negative trust；
  - 在 MSCC 中加入 fairness、minority protection、regret 或 robustness 作为第四目标；
  - 用 interactive EMO 在 Pareto consensus set 上逐步获取 DMs 对 satisfaction/cost/consensus 的偏好。
- 结构创新线索：
  - “文本偏好抽取 -> trust-aware imputation -> community detection -> opinion dynamics -> multi-objective consensus”可作为社交评论驱动决策系统的端到端框架；
  - 在多智能体协商、公共资源配置、企业投标评价中，把每个 subgroup 视为一类 actor，并用三目标共识模型替代单一权重投票或单目标成本最小化。
