# Adaptive Convergence Indicator and Neighborhood Fuzzy Crowding Distance for Multimodal Multi-Objective Optimization

## 一句话理解

论文提出 ACEA-NFCD：在 MMOP 中用邻域密度判断一个解该按 local convergence 还是 global convergence 评价，从而保留 global/local PSs 又剔除无价值 isolated solutions；同时用 fuzzy set theory 融合决策空间和目标空间的邻域拥挤距离，更新双档案并平衡每个 PF 上的解数。

## 问题与动机

- 研究对象：multimodal multi-objective optimization problems (MMOPs)。
- MMOP 特征：
  - 多个决策空间中的 PSs 可映射到同一个 PF；
  - 可能存在 local PSs；
  - Type I：多个 equivalent global PSs；
  - Type II：一个 global PS 和一个 local PS；
  - Type III：多个 equivalent global PSs 和 local PS 同时存在。
- 核心难点：
  - convergence-first selection 会把 local PSs 当作低效解删除；
  - 只用 local convergence indicator 可以保留 local/global PSs，但孤立解因为邻域为空或邻居很少，会被误判为局部收敛很好；
  - MMOP 的不同 PSs 在决策空间分散，计算全局 crowding distance 很难区分真实局部拥挤；
  - 静态阈值和单空间距离难以适应不均衡、形状不规则的 PS 分布。
- 作者希望：
  - 在找到 global PSs 和 local PSs 的同时，减少 isolated solutions 对 population 资源和搜索方向的干扰；
  - 在 selection/truncation 中同时考虑 objective-space convergence 和 decision-space PS coverage。

## 核心方法：ACEA-NFCD

- 双档案框架：
  - `CArc` convergence archive 偏向 objective dominance，用于加速向 PF 收敛并为 diversity archive 提供指导；
  - `DArc` diversity archive 平衡 convergence 与 spatial distribution，用于探索和维护多个 global/local PSs；
  - 每代从 `CArc` 和 `DArc` 各产生 `N/2` offspring，两个 offspring 集合共享到两个 archive 的更新中。
- Neighborhood fuzzy crowding distance (NFCD)：
  - 对 archive 个体做 nondominated sorting，得到 `FrontNo`；
  - 设 `K = ceil(eta * length(Decs))`；
  - 在决策空间和目标空间分别归一化后，计算每个个体到最近 `K` 个邻居的 Euclidean distance 之和；
  - 目标空间 crowding distance 进一步除以 `FrontNo`，把 Pareto rank 信息嵌入目标空间拥挤度；
  - 用改进 logistic membership function 把 `DecCD` 与 `ObjCD` 映射为 fuzzy membership，并组合得到 `NFCD`；
  - 只看邻域而非全体个体，避免不同 PS 间距离过大导致拥挤距离失真。
- Adaptive convergence indicator：
  - 用阈值 `V` 计算每个个体邻居数 `N_i`；
  - 若 `N_i < xi * length(Arc)`，说明该个体邻域支撑不足，计算 global convergence indicator；
  - 否则计算 local convergence indicator；
  - 该切换使 isolated solutions 不能因为没有邻居而自动获得最好 local convergence。
- Convergence archive update：
  - 先用 adaptive convergence indicator 计算 `Con`；
  - 候选优先取 `Con == 0` 个体；
  - 候选不足 `N` 时，按 `Con` 和 `NFCD` 排序补齐；
  - 候选超过 `N` 时，用决策空间 neighborhood crowding distance 删除极度拥挤个体；
  - fitness 根据 archive 是否满员，在 `Con + normalized NFCD` 或 `NFCD` 间切换。
- Diversity archive update：
  - 先取 adaptive convergence indicator 为 0 的个体；
  - 再用 nondominated sorting 选第一层个体作为 `SelArc`，其余为 `RemainArc`；
  - 删除 `RemainArc` 中相对 `SelArc` 极度拥挤的个体；
  - 若 `SelArc` 超过 `N`，用 balance strategy 平衡每个 PF/rank 的解数；
  - 个体数偏少的 PF/rank 获得 reward index，使其后续 tournament selection 更容易被选为父代。
- 复杂度：
  - adaptive convergence indicator 和 archive update 主要为 `O(N^2)`；
  - 作者认为总体复杂度为 `O(N^2)`，与主流 MMOEAs 计算速度没有过大差异。

## 实验证据

- 实验设置：
  - 对比算法：DNNSGA-II、MO_Ring_PSO_SCD、MOEA/D-SS、MMODE_CSCD、HREA、CMMO、CoMMEA、FPITSEA、CDP-BCD；
  - 测试集：CEC 2019、IDMP、IDMP_e、MMMOP，共 62 个 benchmark problems；
  - 每个算法 24 independent runs；
  - 指标：rPSP、IGDX 衡量决策空间性能，IGDF 衡量目标空间性能；
  - Wilcoxon rank-sum test，`p < 0.05`；并报告 Friedman ranks。
- 综合性能：
  - CEC 2019：ACEA-NFCD 在 rPSP 上 22 个问题中 9 个最佳，在 IGDX 上 8 个最佳，Friedman rank 最低为 2.23；在 MMF10、MMF11、MMF12 等 local PS 问题上优于 MO_Ring_PSO_SCD 和 DN-NSGA-II；
  - IDMP：ACEA-NFCD 在 12 个问题中 11 个 rPSP/IGDX 最佳，Friedman rank 为 1.08；
  - IDMP_e：ACEA-NFCD Friedman rank 第一，为 1.62，并在 8 个问题中 5 个 rPSP 最佳；
  - MMMOP：ACEA-NFCD 在 20 个问题中 9 个 rPSP 最佳，并在复杂高维实例上优于更偏 convergence-first 的 CMMO；
  - Overall：作者总结 ACEA-NFCD 在三个指标上平均 Friedman ranks 均为第一，decision-space coverage 是主要优势。
- NFCD 消融：
  - ACEA-ED 用 improved Euclidean distance 替代 NFCD；
  - ACEA-CSCD 用 CSCD 替代 NFCD；
  - ACEA-FCD 去掉 neighborhood feature，在全体个体上计算 fuzzy crowding；
  - 在 62 个 benchmark problems 上，ACEA-NFCD 的 rPSP 和 IGDX 最优，其他变体明显更差；
  - IGDF 上 ACEA-CSCD 某些问题接近或较好，但综合性能仍弱于 ACEA-NFCD。
- 参数分析：
  - `eta_v` 控制 neighborhood threshold，过小会限制 local search，过大降低收敛并破坏多样性；推荐 `eta_v=0.2`；
  - `xi` 控制 adaptive convergence indicator 的判别阈值；`xi=0` 退化为传统 local convergence indicator，会保留大量 isolated solutions；过大则过多使用 global convergence indicator，可能删除真实 PS 个体；推荐 `xi=0.02`；
  - `eta` 控制 NFCD 选取邻居比例；推荐 `eta=0.1`，当 `eta >= 0.2` 时性能下降趋势明显。
- 实际应用：
  - 摘要和结论称在 map-based distance minimization practical application 上验证了 ACEA-NFCD 的优越性；
  - 主文说明应用分析在 supplementary material 中，当前卡片未展开其具体建模和数值结果。

## 局限与未来工作

- 作者未来工作：
  - 设计更合理的 convergence indicators，以更好发现所有 global PSs 和 local PSs；
  - 设计更贴近实际情形的 MMOP testing problems。
- 我们认为仍需确认的问题：
  - `eta_v/xi/eta` 三个关键参数仍需人工设置，尽管有推荐值；
  - isolated solution 的判别只基于邻居数，未显式区分稀有但真实的细小 PS 与无价值孤立点；
  - NFCD 的距离仍为归一化欧氏距离，高维或混合变量 MMOP 中可能出现距离集中或语义不匹配；
  - map-based application 的主文细节不足，需要补充材料复核可复现性；
  - 消融主要验证 NFCD，adaptive convergence indicator 的直接变体对比更多体现在参数分析而非完整算法拆解。
