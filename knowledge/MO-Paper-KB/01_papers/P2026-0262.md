# Top-K-Aware Set Optimization for Component-Sharing Multiobjective Optimization

## 一句话理解

论文把 component-sharing MOO 中“最终只要少量 top-K 共享组件方案”的需求前置到建模和搜索过程：用一个拼接向量编码 K 个非共享解，在共享变量空间上做双层搜索，并用 top-K-aware 并行下层任务协作与 HV-guided 环境选择减少下层评价浪费。

## 问题与动机

- 研究问题和场景：component-sharing multiobjective optimization (CSMOO)。决策者希望最终输出多种高质量设计，但这些设计共享某些组件或变量，例如水下滑翔机多个方案共享复杂 fuselage。
- 现有 CSMOO 为什么不足：
  - RegEMO、EPSL、NestedEBS 等方法通常为每个共享变量或全局问题生成大量候选解，再由决策者或后处理挑选，容易信息过载。
  - 当最终只需要少量 `K` 个方案时，先求大规模 lower-level Pareto/RF 再做 subset selection 会浪费大量下层函数评价。
  - 直接把 K 个解拼成一个大向量后用 DE 或普通 single-objective bi-level optimizer 搜索，会忽略 K 个解之间的非支配、多样性和 HV 关系，搜索效率差。
  - NestedEBS 逐个独立求解下层 MOP，忽略相邻共享变量诱导的下层任务相似性。
- 本文希望解决什么：
  - 直接定义 top-K-aware CSMOO，而不是“求大集合后选 K 个”；
  - 设计能利用 K 个解内部关系的环境选择；
  - 同时求解一批相近共享变量对应的 lower-level top-K MOP，减少重复下层搜索。

## 核心理念与算法流程

- 核心理念：固定共享变量 `s` 后，不再近似整条 lower-level regular front，而是直接优化一个 size-K solution set。把 K 个非共享向量 `x^(1),...,x^(K)` 拼成 `p=(x^(1),...,x^(K))`，以下层 top-K set 的 HV 作为质量；上层搜索共享变量 `s`，下层搜索对应的拼接向量 `p`。相近的 `s` 往往诱导相似的 top-K set，因此多个下层任务可以像 MOEA/D 邻域一样协作。
- 问题建模：
  1. 原 CSMOO：上层找共享变量 `s`，最大化固定 `s` 后 lower-level MOP 的 RF-HV。
  2. Top-K-aware CSMOO：对每个 `s`，只找由 `p` 编码的 K 个 non-shared solutions，并最大化这 K 个点的 set utility。
  3. 本文默认 set utility 为 HV，因此整体可看作在 `Omega_p x Omega_s` 上最大化 `HV(F(p,s), r)` 的 top-K set optimization。
- TopK-BLS 总体流程：
  1. 初始化 `n` 个 upper-level shared variables `S={s^1,...,s^n}` 和对应 lower-level concatenated vectors `P={p^1,...,p^n}`。
  2. 调用 Top-K-aware parallel lower-level search，同时优化这批 `s` 诱导的 lower-level top-K MOPs。
  3. 用得到的 `p_i*` 计算每个 `s_i` 的 upper-level fitness。
  4. 通过 DE 生成 upper-level offspring `S_hat`。
  5. 根据 offspring 与已有共享变量的邻近关系，从邻近 `P*` 初始化 lower-level offspring。
  6. 对 `S_hat` 再做 parallel lower-level search。
  7. 若 offspring 共享变量对应 top-K set 的 HV 更好，则替换 parent。
  8. 返回最佳 `(s*, p*(s*))`。
- Top-K-aware parallel lower-level search：
  1. 按 shared variable 欧氏距离构造 neighborhood `B(i)`。
  2. 对第 `i` 个 lower-level task，从邻域随机选两个任务，使用 DE 和 polynomial mutation 生成候选拼接向量 `p_hat`。
  3. 若当前 `F(p_i,s_i)` 不严格支配候选 `F(p_hat,s_i)`，调用 HV-guided environment selection 更新 `p_i`。
  4. 用更新后的 `p_i` 尝试更新邻域任务 `p_j`，实现下层任务协作。
- HV-guided environment selection：
  1. 合并当前 K 个解和候选 K 个解，形成 `2K` 个共享同一 `s` 的解。
  2. 对这 `2K` 个解做 non-dominated sorting。
  3. 逐层填充到 K 个；若最后一层超出容量，解 HVSS 选出最能提升 HV 的剩余解。
  4. 将选出的 K 个解重新拼接为 `p†`；若 `HV(p†,s_i)` 优于旧 `p_i`，则替换。

## 实验证据

- Test problems：
  - CSMOP1-CSMOP6，包含 `m=2` 和 `m=3`，RF 类型覆盖 convex、concave、disconnected、linear with nonlinear RS。
  - `m=2` 时 `K=5`，`m=3` 时 `K=10`。
  - 三种维度设置：`(ds+dx)=(5+6),(10+10),(20+20)`。
  - 真实问题：Blended-Wing-Body underwater glider shape optimization，3 个 shared variables 控制 fuselage planform，7 个 non-shared variables 控制 transition sections 和 wings；目标为 negative lift 与 drag。
- Compared algorithms：
  - DE：把 top-K CSMOO 视为 classic single-objective optimization。
  - BOC：把 formulation 视作 single-objective bilevel optimization。
  - RegEMO-SS：RegEMO 先生成大共享解集，再 HVSS 选 K 个。
  - NestedEBS-SS：NestedEBS 生成大 RF，再 HVSS 选 K 个。
  - BLS-SMS：把 TopK-BLS 的协作下层搜索替换为多个独立 SMS-EMOA runs。
- 参数设置：
  - TopK-BLS lower-level population `N=200` for `m=2`，`N=300` for `m=3`。
  - Upper-level population `n=floor(N/K)`。
  - Shared-variable DE：`CR=0.8`，`F=0.8`。
  - Concatenated-vector DE：`CR=1`，`F=0.5`，polynomial mutation probability `1/(K dx)`，mutation index `20`。
  - Neighborhood size `T=0.3n`。
  - Lower-level search 最多 200 generations；若连续 10 代 objective vectors 平均最小距离低于 `1E-4` 则早停。
  - Upper-level 终止：upper-level evaluations 超过 `1000 ds`，或 accuracy 低于 `1E-6`，或 lower-level FEs 超过 `200N*30ds`。
  - 所有算法每个问题 19 independent runs；Wilcoxon rank-sum test `0.05`，Holm-Bonferroni correction。
- Benchmark 结果：
  - TopK-BLS 在所有 benchmark instances 上 component-sharing accuracy 的 median 均为 `0`。
  - TopK-BLS 在所有 test instances 上 `Delta HV_S` 的 median 最好，并显著优于所有比较方法。
  - TopK-BLS 所需 lower-level FEs 显著少于其他算法。
  - 相比 DE：DE 耗尽全部 FE 预算，TopK-BLS 平均使用不到 14% 预算；DE 只在 3/18 个实例上达到 median accuracy 0，`Delta HV_S` 在 18/18 上都差于 TopK-BLS。
  - 相比 BOC：BOC 耗尽预算且几乎所有实例在 accuracy 和 HV difference 上差于 TopK-BLS，主要因为拼接向量维度 `K dx` 随 K 和维度膨胀。
  - 相比 RegEMO-SS：RegEMO-SS 在 CSMOP1-2 和 CSMOP6 等 optimal RF 与 PF 重合/相交的问题上较好，但整体不稳定。
  - 相比 NestedEBS-SS：NestedEBS-SS 在 17/18 个实例上能定位共享变量，但 `Delta HV_S` 在 18/18 上显著差于 TopK-BLS；TopK-BLS 通常使用低于 14% 的预算，而 NestedEBS-SS 平均常在 13%-37%。
  - 相比 BLS-SMS：低维时可行，但维度增大后 performance deteriorates，说明 `K` 大小的独立 indicator-based population 难保持搜索多样性。
- 进一步分析：
  - `T=0.3n` 在 neighborhood size sensitivity 中综合表现最好。
  - exact HV-guided environment selection 优于 SimpleEnvSel 和 GreedyEnvSel variants。
  - 去掉协作更新的 NoCollab 在 `Delta HV_S` 上被 TopK-BLS 稳定超过，说明 lower-level task sharing 是关键。
- 真实水下滑翔机结果：
  - CFD 评价昂贵，论文用 Latin hypercube samples 建立两个 quadratic regression surrogate，两个目标模型 `R^2=0.999`。
  - 因真实 optimal shared variable 未知，nested algorithms 不使用 accuracy termination，统一跑满 lower-level FE budget。
  - TopK-BLS median component-sharing HV difference 为 `1.0371E-4`，显著优于所有比较方法。
- 证据边界：
  - Table V-VIII 宽表抽取噪声较大，精确数值需回 PDF。
  - 真实问题用 quadratic surrogate 替代 CFD，不是直接在线 CFD 优化。
  - exact HVSS 在 `m>=3` 存在复杂度瓶颈，many-objective 场景未充分解决。

## 局限与未来工作

- 作者明确局限：
  - 当前 CSMOO benchmark suites 仍有限。
  - TopK-BLS 多次求解 HVSS；exact HVSS 在 `m>=3` 为 NP-hard，限制 many-objective scalability。
  - 仍依赖 nested bilevel framework，每个 lower-level problem 需要较充分求解，即使用并行协作仍消耗较多 lower-level FEs。
- 作者未来工作：
  - 开发新的 CSMOO synthetic test problems，并探索更广泛真实应用。
  - 集成更高效准确的 many-objective HVSS approximation，或探索更易计算的 alternative top-K definitions。
  - 研究超越 nested framework 的替代方法，把预算选择性分配给最有希望的 lower-level MOPs。
  - 将 top-K-aware parallel lower-level search 扩展到 parametric MOO。
- 我们认为仍需确认的问题：
  - 在 `K` 更小、目标更多、RF 高度断裂或约束强时，HV-guided selection 是否仍稳定。
  - 共享变量距离是否总能代表 lower-level top-K set 相似性；可能需要 task embedding 或性能相似度。
  - 是否可以用 surrogate/learning 预测哪些 upper-level candidates 值得充分下层优化。
  - 对实际产品族设计，top-K 定义是否应加入制造成本、近似共享容差和鲁棒性，而不只是 HV。

  - 将 top-K 的 utility 从 HV 换成 preference-weighted HV、coverage、manufacturing cost-aware utility 或 robust HV。
  - 在 upper-level 上加入 bandit/resource allocation，只充分求解最有希望的 `s`。

  - 构建“共享组件 top-K 产品族设计器”：

```text
DM specifies shared components and K
-> encode K variants as concatenated vector
-> upper shared-variable search
-> cooperative lower-level top-K set search
-> HV/preference/cost utility selection
-> final manufacturable design family
```

  - 与 surrogate-assisted expensive optimization 结合：下层协作搜索在 surrogate 上运行，少量 top-K representative variants 做高保真验证。
