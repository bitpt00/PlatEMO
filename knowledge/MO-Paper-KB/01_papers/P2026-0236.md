# Comprehensive-Forecast Multiobjective Genetic Programming for Neural Architecture Search

## 一句话理解

本文提出 CFMOGP-NAS，用多目标 GP 搜索 CNN cell，在评价层混合 partial/full training、用不确定性加权的多回归模型预测架构性能，并用随机正则化锦标赛维持结构多样性，从而以较低 GPU 成本得到精度-参数-FLOPs 折中架构。

## 问题与动机

- 研究问题和场景：面向图像分类的 Neural Architecture Search (NAS)，同时考虑 accuracy、Params 和 FLOPs 等多个目标。
- 现有算法为什么不足：
  - NAS 需要全局拓扑探索，训练每个候选架构非常耗时；
  - EA/GP-based NAS 能探索多样结构，但多个候选完整训练会造成大量 GPU day 开销；
  - 只用 partial training 虽能省时，却可能因为早期评价不准而淘汰潜在优质架构；
  - 单一 performance predictor 容易受样本少、噪声训练和模型偏差影响；
  - 普通 tournament selection 容易过分关注当前高精度个体，导致结构多样性不足和局部收敛。
- 本文希望解决什么：在不明显牺牲架构精度的前提下，降低 NAS 搜索时间，并提升 GP 搜索过程中的候选多样性和预测鲁棒性。

## 核心理念与算法流程

- 核心理念：NAS 的真实训练评价可以分层处理：多数候选用低成本 partial/渐进训练筛选，潜在好但被早期淘汰的候选进入 archive 后继续用更多 epochs 重评；同时用多回归模型的综合预测减少低性能架构的完整训练，并用 aging/tournament 混合选择避免种群只围绕短期高精度结构收敛。
- 主要流程：
  1. 用 Normal Cell 和 Reduction Cell 的基因串编码 CNN 架构，每个 gene 包含 operation 和连接 index。
  2. 多目标 GP 生成和更新种群，评价 objectives 为 accuracy、Params、FLOPs。
  3. 通过 intercell/intracell crossover 和 mutation 产生 offspring。
  4. RSRTA 在普通 tournament selection 与 aging-based tournament 之间随机切换，阈值 `delta` 自适应调整。
  5. 用 CPTES 加速训练评价：NSGA-II 先筛选 parent+offspring，再把部分被淘汰但潜力较高的个体放入 archive，并随着训练 epochs 更新进行重评。
  6. 用 RF、KNN、LR、SVM 等 regression models 做 stacked generalization；按置信区间估计不确定性，对高不确定预测降权、低不确定预测增权。
  7. 重复进化直到生成 Pareto parent population，并对最优架构进行 retraining 和数据集验证。
- 关键组成部分：
  - CPTES：Combined Partial and Total Evaluation Strategy，兼顾低成本 early evaluation 和 full/longer epoch 评价的准确性。
  - Uncertainty-aware regression agent：多模型综合预测，使用 confidence interval/standard error 调整权重。
  - RSRTA：Randomly Selected Regularized Tournament Algorithm，用 aging counter 和 alternative set 增加结构多样性。
  - Cell gene encoding：用 operation alphabet 和连接 index 表达 Normal/Reduction cell。
- 可能被修改的位置：
  - regression ensemble 可替换为 GNN predictor、pairwise rank predictor、Bayesian ensemble 或 conformal predictor；
  - CPTES 的 archive 进入规则可由 NSGA-II 淘汰集改为不确定性、高 diversity 或 learning-curve 外推；
  - RSRTA 的 `delta` 可由 diversity、HV 进展或预测误差反馈自适应；
  - 目标可扩展为真实 latency、energy、memory peak 或硬件约束。
- 必须保留的核心：不能把 NAS 评价简化为“全部短训”或“全部预测”；需要让部分候选在低成本评价后仍有被重新训练/纠偏的机会，同时用预测不确定性约束 surrogate 的影响。

## 实验证据

- 测试问题和对比算法：
  - 数据集：CIFAR-10、CIFAR-100、STL-10、Oxford 102 Flowers。
  - 环境：Python + PyTorch，NVIDIA GeForce RTX 3090 Ti 云服务器。
  - 指标：Accuracy、Params、FLOPs、search time；另对 predictor 使用 MSE/MAE、Accuracy、Precision、Recall、F1-score 与 95% confidence interval。
  - 对比对象覆盖 RL、SMBO、gradient、evolution 等 NAS 方法，以及 SVM、RF、KNN、LR 等 predictor/agent 变体。
- 主要实验结论：
  - 摘要声称 CFMOGP-NAS 在不牺牲 accuracy 的情况下减少约 50% search time。
  - CIFAR-10 和 CIFAR-100 case study 中分别达到 97.55% 和 79.62% accuracy；平均 search time 为 0.43 GPU days，参数量约 2.2M。
  - CIFAR-100 上 0.43 GPU days 得到 79.62% accuracy；作者对比称 AmoebaNet 用 3150 GPU days 得到 81.07%，LargeEvo 用 2750 GPU days 得到 77.00%。
  - 与 SVM/RF/KNN agent methods 比较，CFMOGP-NAS 在参数量、accuracy、precision、recall、F1-score 等方面总体更优；95% confidence interval 完全高于现有方法区间。
- 消融或机制证据：
  - Agent model：将 CFMOGP-NAS 替换为传统 regression 后，最终 retraining accuracy 为 CIFAR-10 90.96%、CIFAR-100 74.55%，低于完整方法。
  - Predictor comparison：后期 KNN/RF/LR/SVM 等 regression models 更难继续找到改进网络，完整 agent model 更稳定。
  - RSRTA：相对只用 tournament selection 或 aging evolution，RSRTA 在 Fig. 16 中表现更好；`delta=0.3` 时平均 accuracy 最优。
  - NRSRTA 消融：CFMOGP-NAS 在 CIFAR-10、CIFAR-100、STL-10 上整体在 accuracy、recall、F1-score 等指标更有竞争力，尽管 CIFAR-100 accuracy 略低于无 RSRTA 版本。
  - CPTES：相对纯完整/纯部分训练方案，CPTES 在时间和 accuracy 之间达到较优平均表现。
- 证据边界：
  - 多张结果表在当前 Markdown 中为图片占位，无法逐项核对数值；
  - 评价策略部分对 CES/PES 的文字描述存在命名和“快/准”关系不够清晰的地方，后续如需复现应回看 PDF 图表和代码；
  - 主要是图像分类 CNN cell NAS，跨 Transformer、检测/分割、硬件实测 latency 还需要验证。

## 局限与未来工作

- 作者明确说明的局限：
  - 真实环境中数据量与分布会变化，需要及时调整 evolutionary updates 和模型维护；
  - complex skip connections 的有效管理仍值得研究。
- 作者未来工作：
  - 将 MOGP-based NAS 用于 sense-compute integrated neural architecture chip design；
  - 进一步理解和改进 genetic operations 对网络架构演化的影响。
- 我们认为仍需确认的问题：
  - CPTES 的 archive 重评规则是否可稳定识别“短训不佳但长训优”的架构；
  - regression ensemble 的 uncertainty 是否校准，置信区间是否能真实反映 NAS 训练噪声；
  - 0.43 GPU days 的搜索成本与对比方法是否在同一训练 schedule、数据增强和硬件条件下公平；
  - RSRTA 的多样性增益是否来自 aging 机制本身，还是与编码/search space 共同作用。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“多保真不确定集成的 NAS 评价加速”，因为 CPTES、uncertainty-aware regression ensemble 和 RSRTA 形成了可迁移到昂贵结构搜索的候选评价与选择控制接口。
- 暂留在论文卡中的方法、原理或架构启发：
  - 短训评价可用于排序而非最终淘汰，关键是给潜在好个体保留延迟重评通道；
  - NAS predictor 不一定追求绝对精确拟合，较粗粒度的性能比较可能更抗噪；
  - aging/regularized selection 可以作为“高精度偏置”的制动器，防止搜索过早集中在同质结构。
- 局部创新线索：
  - 在现有 ENAS/MOEA-NAS 中加入 CPTES archive，对被淘汰但高不确定或高多样性的个体继续追加 epochs；
  - 用不确定性加权 ensemble 取代单一回归性能预测器；
  - 在 regularized evolution 或 NSGA-Net 中加入 RSRTA 式 aging/tournament 混合选择。
- 结构创新线索：
  - 构建“低成本初评 -> 潜力档案 -> 追加训练重评 -> 不确定性 predictor -> 多目标选择”的 NAS 评价闭环；
  - 将该框架推广到程序搜索、调度规则 GP、自动算法设计和硬件结构搜索等昂贵结构候选优化。
