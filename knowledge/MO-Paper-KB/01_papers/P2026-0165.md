# Fairness-constrained influence maximisation via multi-objective optimisation

## 一句话理解

本文把 fair influence maximisation 建成双目标问题：同时最大化总体扩散范围和社区级 equity fairness。公平目标不只用一个比例指标，而是把 realised activation share `P` 与 community-size reference `Q` 的 Jensen-Shannon similarity，以及 `P_j/Q_j` 比例是否均衡的 Jain fairness index 合成一个可解释目标；搜索层提出 FairWolf，把 Grey Wolf Optimiser 改造成固定预算种子集上的离散多目标搜索，并用稀疏区域 explorer leaders 和 HV 停滞扰动维持 Pareto front 覆盖。

## 问题与动机

- 研究问题和场景：
  - 面向社交网络 influence maximisation (IM)；
  - 每个解是预算为 `k` 的 seed node set；
  - 输出是 spread-fairness trade-off 的 Pareto seed sets；
  - 目标应用包括 viral marketing、public health messaging、political communication、social recommendation 和 resource allocation。
- 现有方法为什么不足：
  - 传统 IM 主要最大化总触达，容易让结构上更中心的社区获得更多传播收益；
  - early-adopter、time-critical、maximin、welfare、equity 等公平概念各有侧重，单一公平指标的可解释性不足；
  - 只要求每个社区期望影响与人口比例成正比，仍可能掩盖整体分布错配或局部社区过/欠分配；
  - 固定预算种子集是离散组合空间，标准连续 GWO 更新不能自然保持 cardinality constraint；
  - 现有多目标 fair IM 方法容易 leader crowding 或 archive stagnation。
- 本文希望解决什么：
  - 让 diffusion benefit 的社区分配公平可解释、可诊断；
  - 形成明确的 spread-equity 双目标 Pareto 问题；
  - 在离散 seed-set 空间中保持固定预算可行性；
  - 改善 archive 覆盖、减轻局部停滞；
  - 给决策者一组可选的传播效率-公平折中方案。

## 核心理念与算法流程

- FMOIM 问题建模：
  - 图 `G=(V,E)` 为无向社交网络；
  - 节点按社区集合 `{C_j}` 分组，本文实验用 Leiden algorithm 识别社区；
  - 每个候选解 `S(i)` 是大小为 `k` 的 seed set；
  - 扩散模型采用 Independent Cascade (IC)，主实验中最大扩散步数固定为 2；
  - 第一目标 `f1` 是 Monte Carlo 扩散后的平均激活节点比例；
  - 第二目标 `f2` 是社区级 equity fairness。
- 公平目标：
  - `P={P_j}` 表示各社区 observed activation proportions；
  - `Q={Q_j}` 表示各社区 population-size proportions；
  - `JSsim(P,Q)` 衡量激活分布与人口参考分布的整体对齐；
  - `Jain(P/Q)` 衡量各社区 activation share 与 population share 的比值是否均衡；
  - `f2` 用权重 `lambda` 合成两项，默认 `lambda=0.5`；
  - 两项互补：JSD 抓整体分布偏移，Jain 抓社区级比例失衡。
- FairWolf 搜索框架：
  - 每只 wolf 直接编码为一个固定大小 seed set；
  - archive 保存 non-dominated seed sets；
  - discrete position update 用 set-swap 操作替代连续位置更新；
  - 当 `|A| < 1` 时，解向 leader 的 seed set 靠拢，做 exploitation；
  - 当 `|A| >= 1` 时，解远离 leader 的重合节点并采样新节点，做 exploration；
  - 若更新后解不变，则随机重采样以维持多样性。
- Explorer-Augmented Leader Selection：
  - leader pool 同时包含 core leaders 和 explorer leaders；
  - core leaders 来自当前 non-dominated archive，提供收敛压力；
  - explorer leaders 偏向 objective-space sparse grid cells；
  - persistent grid 只在新解越界时扩张，减少频繁重划分；
  - archive 超容量时按 grid density 和 crowding distance 删除拥挤区域解。
- HV-triggered perturbation：
  - 维护长度为 `tau` 的 HV 滑动窗口；
  - 如果窗口内 `Delta HV` 小于阈值 `epsilon_HV`，说明 archive 进展停滞；
  - 对比例为 `perturb` 的随机个体做一次 seed swap；
  - 扰动只在停滞时触发，避免无谓破坏正在改善的搜索。
- 必须保留的核心：
  - 公平目标同时包含 distribution alignment 和 proportional balance；
  - 搜索变量始终是 fixed-budget seed set；
  - set-based update 需要保持预算约束；
  - sparse-region explorer leader 和 HV stagnation trigger 分别处理覆盖不足与停滞。

## 实验证据

- 实验设置：
  - 8 个真实网络：Dolphin、Food、Email、Ham、Facebook、Rice、Wiki、LastFM；
  - 社区由 Leiden algorithm 识别；
  - 对比算法包括 GFMOGWO、MODBA、MODPSO、SetMOGWO、MOEA/D、SPEA2；
  - `MaxIt=100`，独立运行 10 次；
  - seed budget `k=30`；
  - propagation probability 为 `p=0.01, 0.05, 0.1`；
  - 每次评价 Monte Carlo simulations `N=10`；
  - archive size 和 population size 均为 100；
  - FairWolf 默认 `n_explorers=2`、`tau=5`、`perturb=0.15`、`lambda=0.5`；
  - 指标包括 HV、IGD、Spacing、Spread、Time、POF、POI。
- 消融实验：
  - 在 Food 网络、`p=0.1`、`pop=100`、`T=100` 下进行；
  - 比较 FMODGWO、只加 HV perturbation 的 H-FMODGWO、完整 FairWolf；
  - 完整 FairWolf 取得最高 HV `0.3398 ± 0.0126`、最低 IGD `0.0111 ± 0.0052`、最低 Spacing `0.0018`、最低 Spread `0.0050`，且 runtime 最低 `0.2238 ± 0.0679`；
  - 作者解释 HV perturbation 主要加速早期进展，explorer leaders 进一步改善覆盖并稳定收敛。
- 参数敏感性：
  - 搜索参数测试 `n_explorers in {0,1,2}` 与 `perturb in {0.05,0.10,0.15}`；
  - `S9` 即 `n_explorers=2`、`perturb=0.15` 取得最佳 IGD `0.0085 ± 0.0036` 和最佳 HV `0.3447 ± 0.0078`；
  - 公平权重测试 `lambda=0.3,0.5,0.7`；
  - `lambda=0.5` 的 Fair2 取得最高 HV `0.3422 ± 0.0054` 和最低 Spacing `0.001194245`，作为默认设置。
- 主对比实验：
  - `p=0.01` 时，FairWolf 在 5 个数据集上取得最佳 HV，并在 Wiki、LastFM、Facebook 上取得最佳 IGD；
  - `p=0.05` 时，FairWolf 在 4 个数据集上取得最佳 HV，整体仍处于 top group；
  - `p=0.1` 时，FairWolf 在 4 个数据集上取得最佳 HV，MOEA/D 成为更强竞争者；
  - 平均排名表中 FairWolf 在 `p=0.01` 和 `p=0.05` 排名第一，在 `p=0.1` 排名 3.63，综合排名 3.24，为所有算法最好；
  - FairWolf Pareto fronts 通常覆盖更广且更均匀。
- 社区公平解释：
  - Ham 网络 `p=0.1` 上分析 signed allocation bias `delta_j=P_j-Q_j`；
  - Worst-case Allocation Deviation 中 MOEA/D 中位数最低，FairWolf 接近第二且 IQR 更紧；
  - FairWolf 的社区偏差图更均衡，没有明显集中在少数社区的过/欠分配带。
- 2-hop 与 full IC 对照：
  - 主实验使用 2-hop 扩散近似；
  - 在 Ham 网络上补充 full IC，对 `p=0.01,0.05,0.1` 做对照；
  - full IC 下 FairWolf 在三个概率设置中均取得最佳 HV；
  - 在 `p=0.1` 下 FairWolf 也取得最佳 IGD；
  - 作者认为 2-hop 近似不改变主要比较结论。
- Fairness-influence trade-off：
  - 在 `p=0.01` 下，FairWolf 在多数数据集上取得最低 POF 和 POI；
  - Facebook 和 Wikipedia 上 GFMOGWO 在 POF/POI 上最好，但 FairWolf 的 Spacing 和 Spread 更好，说明其 Pareto 解集更均衡。

## 局限与未来工作

- 作者明确说明的未来工作：
  - 将 FairWolf 扩展到 diffusion patterns 随时间变化的 dynamic networks；
  - 将相关机制应用到 influence maximisation 之外的 resource allocation、recommendation 等公平-效率折中问题。
- 作者或实验设置暴露的边界：
  - 主实验用 2-hop IC 近似，full IC 只在 Ham 网络做一致性检查；
  - Monte Carlo simulations 每次评价只有 `N=10`，随机扩散噪声可能影响细粒度公平诊断；
  - 社区是结构分组，不等同于不可变的真实人口统计群体；
  - proportional allocation 默认按社区规模作为 reference，未纳入脆弱性、风险等级或政策优先级；
  - `lambda=0.5` 是经验默认，实际部署需由场景偏好校准；
  - diffusion simulation 仍是主要成本，大型动态图或百万节点图需并行、代理或多保真评价。
- 我们认为仍需确认的问题：
  - JSD 与 Jain 两项是否会在高度不均衡社区数量下产生偏置；
  - Leiden 社区划分变化会如何影响 Pareto front 和公平结论；
  - FairWolf 的改进来自公平目标、discrete update、explorer leader 还是 HV perturbation 的相对贡献；
  - POF/POI 的解释是否能被业务方直接采用；
  - 公式多处图片省略，复现前需从 PDF 或代码核对 `f2` 归一化和 set update 细节。

  - Worst-case Allocation Deviation 是结果解释指标，可并入公平 dashboard，但本文不是主要优化目标；
  - 2-hop diffusion 是计算近似，不单独建卡；
  - persistent grid archive 可作为实现细节复用，但与 explorer leader 绑定更紧密。
- 局部创新线索：
  - 将 `Q` 从 community-size reference 改为 vulnerability-weighted 或 policy-priority reference；
  - 将 `lambda` 由固定值改成 preference vector、HV contribution、POF/POI 或 fairness violation 驱动的动态权重；
  - 将 WAD 直接作为第三目标或 epsilon constraint，避免个别社区严重 under-service；
  - 让 explorer leaders 按 fairness-deficient communities 采样，而不只按 objective-space sparse grid 采样；
  - 用 multi-fidelity diffusion：普通个体 2-hop，archive/explorer leaders full IC 或更多 Monte Carlo 复评。
- 结构创新线索：
  - 构建“公平诊断-搜索反馈”架构：每轮识别 under-served communities，再引导 seed replacement 优先覆盖这些社区；
  - 将 JSD/Jain 终态公平与 step-wise entropy 过程公平合成三目标或层级目标；
  - 在动态图扩散中维护滚动 `P,Q`，用 FairWolf-style set-swap 对新时段 seed set 做局部修补。
