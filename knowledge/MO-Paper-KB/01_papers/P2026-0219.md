# Data-Driven Evolutionary Algorithm Based on Inductive Graph Neural Networks for Multimodal Multiobjective Optimization

## 一句话理解

本文提出 DEA-IGNN，将 MMOP 中多代种群按决策空间邻域构造成图序列，用 GraphSAGE 和 temporal convolution 学习 Pareto set 拓扑变化，并与传统变异混合生成兼具决策空间多样性和目标空间收敛性的子代。

## 问题与动机

- 研究问题和场景：multimodal multiobjective optimization problems (MMOPs) 中，不同 Pareto optimal solution sets (PSs) 的多个解会映射到同一个 PF 点；找到多个等价 PS 能给决策者提供更丰富的方案。
- 现有算法为什么不足：
  - 传统 MMOEA 多通过复杂 mating selection 维护决策空间多样性，但没有显式学习 PSs topology，适应不同 MMOP 类型时偏好固定；
  - 近似函数模型难拟合形状复杂、非函数型、持续变化的 PSs；
  - GAN、autoencoder、growing neural gas 等机器学习辅助方法通常只看当前种群或忽略 population data 的 non-Euclidean structure；
  - 高维决策空间中，直接估计 diversity 会变得复杂且不准确。
- 本文希望解决什么：把多代种群分布转成图数据并学习其时空变化，用可归纳的图神经网络预测下一代高质量子代，减少对手工 mating selection 的依赖。

## 核心理念与算法流程

- 核心理念：MMOP 的 PS 分布不是一组孤立点，而是决策空间中的拓扑结构和随代变化的轨迹。把每代种群构造成邻接图，再用时序卷积捕捉多代变化、GraphSAGE 聚合邻域结构，可以让模型直接预测更贴近 PSs 的子代。
- 主要流程：
  1. 初始化主种群 `Pop`、模型 `Net`、收敛档案 `CArc` 和图档案 `Graph`。
  2. 每代从 `CArc` 通过 crowding distance 和 tournament selection 生成传统变异子代 `O1`。
  3. 将当前 `Pop` 转成决策空间邻接图并加入 `Graph`；当达到训练频率 `lambda` 时，用图档案训练模型并预测模型子代 `O2`，否则用传统变异生成 `O2`。
  4. 合并 `O1` 与 `O2`，用 local convergence quality 和 decision-space crowding distance 更新主种群。
  5. 用 hierarchy ranking method 更新 `CArc`，再将更新后的 `Pop` 构图加入 `Graph`，持续刷新模型可学习的 PSs。
- 关键组成部分：
  - 决策空间图构造：每个个体是图节点，节点特征为 decision vector；对每个个体选最近的 `NSize=0.05*N` 个邻居建边，形成有向图。
  - 图档案：保存连续多代 population graphs，作为模型训练数据；每次模型训练后清空并重新累积。
  - GraphSAGE 空间卷积：通过邻域采样和特征聚合学习未知节点表示，适合启发式搜索中新个体不断出现的 inductive 场景。
  - Temporal convolution：用两个 1-D temporal convolution blocks 捕捉相邻代 PSs 的变化依赖；固定结构下 `WinSize=5`。
  - 混合 reproduction：传统变异持续探索未知 PS 区域并产生训练数据，模型子代用于利用已学到的 PSs topology 和变化模式。
- 可能被修改的位置：
  - 可替换图构造距离，如 Mahalanobis、manifold distance、稀疏 mask distance 或任务相关距离；
  - 可替换 GraphSAGE 为 GAT、Graph Transformer、dynamic GNN 或 message passing with edge features；
  - 可把 `lambda` 训练频率改成性能触发、图分布漂移触发或不确定性触发；
  - 可将模型预测子代作为候选池，再用真实评价预算或局部搜索筛选，而不是直接合并。
- 必须保留的核心：模型不能完全替代传统变异。DEA-IGNN 的证据显示纯模型 `IGNN*` 平均排名最差，传统变异用于探索未知 PS 和刷新训练数据是结构必要条件。

## 实验证据

- 测试问题和对比算法：
  - 对比 11 个 MMOEA：MO_Ring_PSO_SCD、SS-MOPSO、MMODE_CSCD、MOEA/D-SS、TriMOEA-TA&R、MMEAWI、HREA、MMEASND、CDP-BCD、SVMEA、MMEAPSL。
  - 三个主测试套件：CEC2020、IDMP、MMMOP；另有 100 维 SMMOP 大规模测试和 map-based practical problem。
  - 指标：PSP 越大越好，IGDX 和 IGDF 越小越好；主对比 20 次独立运行。
  - 参数：`lambda=7`、learning rate `0.01`、training epochs `300`；主对比 population size `200*n_var`，maximum evaluations `10000*n_var`。
- 主要实验结论：
  - CEC2020：DEA-IGNN 在 PSP 和 IGDX 上分别获得 12 和 10 个 best values，IGDF 在 7 个 MMOP 上最好。
  - IDMP：DEA-IGNN 在 PSP 和 IGDX 上分别获得 4 个 best values；IGDF 上 DEA-IGNN、MMEAPSL、MMODE_CSCD、MMEA-SND、SVMEA 分别在 7、2、1、1、1 个 MMOP 上最好。
  - MMMOP：DEA-IGNN 在 PSP 和 IGDX 上分别在 3 个 MMOP 上优于其他算法，IGDF 在 7 个 MMOP 上最好；作者指出其在高维决策向量上可避免复杂且不准确的 diversity estimation。
  - SMMOP 大规模测试：8 个 100 维 MMOP，DEA-IGNN 在 IGDX 和 IGDF 上分别取得 3 和 5 个 best values；IGDF 综合最好。
  - Map-based problem：作者称 DEA-IGNN 能有效维持 diversity 和 convergence，其他多种算法在最大 Pareto region 有 gaps 或分布不均。
- 消融或机制证据：
  - 将 DEA-IGNN 的 data-driven reproduction 分别替换为 PSO、DE、GA 得到 Variant-PSO、Variant-DE、Variant-GA；补充材料 Tables S-X-S-XII 给出 56 个 MMOP 上均值、标准差和 Wilcoxon rank-sum `p<0.05`，正文总结 DEA-IGNN 在三个指标上显著优于三种变体。
  - Fig. 5 显示 MMMOP6B 上模型学习到的 PSs 随代数逐步接近 true PSs。
  - Fig. 6 显示相同父代下，模型生成子代比 PSO/DE/GA 变体更能形成 well-distributed offspring。
  - 参数分析显示 `NSize` 不宜过大：IGDX 在邻域比例大于 `0.3` 后变差，IGDF 在大于 `0.2` 后受影响；作者最终采用 `0.05*N`。
  - 纯模型生成 `IGNN*` 在三类测试套件平均排名最差，说明只用模型会削弱探索，混合传统变异是必要机制。
- 证据边界：
  - 许多详细统计表在 supplementary material，当前 Markdown 只有正文摘要和解释；
  - Runtime 明显偏高，DEA-IGNN 约为最短 runtime 的 5-6 倍；同 runtime 终止条件下没有总体优势，但仍在 MMF13 和 IDMPM4T3 上分别赢过 10 和 4 个算法；
  - 模型训练成本可能需要 GPU 或更高效的动态图学习实现来缓解。

## 局限与未来工作

- 作者明确说明的局限：
  - GraphSAGE 模型训练增加 runtime，DEA-IGNN 时间性能弱于若干传统算法；
  - 模型只能学习已有训练数据中的 PSs 和变化模式，未知区域仍依赖传统变异探索；
  - 纯模型子代生成会导致探索能力明显下降。
- 作者未来工作：
  - 开发更智能的模型辅助进化算法求解 MMOP；
  - 将这类算法扩展到 dynamic MOP。
- 我们认为仍需确认的问题：
  - 决策空间欧氏邻域在混合变量、离散变量或强尺度不均问题中是否仍合适；
  - 图节点数量随种群规模增大时，GraphSAGE 训练和推理成本如何控制；
  - 模型预测的子代是否需要显式可行性修复或边界投影；
  - map-based practical problem 的定量指标在补充材料中，需要后续补读。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“时空图学习的多模态 PS 子代生成”，因为它给出可迁移的结构：种群转图、历史图序列学习、模型子代与传统变异混合，可用于 MMOP、动态 MOP 和其他多等价结构搜索。
- 暂留在论文卡中的方法、原理或架构启发：
  - 对多模态问题，学习 PS 拓扑比只维护当前个体距离更主动；
  - 图档案应随种群更新，避免模型学习过时 PS；
  - 训练频率同时控制数据量和模型使用频率，过小/过大都会限制收益。
- 局部创新线索：
  - 用图分布漂移检测替代固定 `lambda`，当 PSs 变化显著时再训练；
  - 在模型子代上增加局部修复、可行性过滤或不确定性筛选；
  - 将 `NSize` 自适应为局部密度、模态数量或图连通度函数。
- 结构创新线索：
  - 构建“传统探索产生数据 -> 时空图模型学习 PS 变化 -> 模型生成 exploitation 子代 -> 环境选择刷新图”的闭环；
  - 将 PS 图学习扩展到动态环境响应，把历史环境图序列用于预测新环境初始种群。
