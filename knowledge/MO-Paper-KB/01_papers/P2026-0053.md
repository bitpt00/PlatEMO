# A constrained multi-objective co-evolutionary algorithm with dynamic game

## 一句话理解

论文提出 DGCMOEA：一个双种群约束多目标进化算法。主种群用 CDP 专注 CPF 附近的可行收敛，辅助种群用 relaxed constraints、rank-based adversarial win-rate 和空间扰动敏感性保留有价值不可行解；两种群之间再用 Cournot-inspired competitiveness 动态分配 offspring 数，避免固定资源配额导致主/辅种群失衡。

## 问题与动机

- 研究问题：
  - CMOP 同时要处理目标冲突、复杂约束、可行域碎片化和 UPF/CPF 分离；
  - 单一 CHT 或固定两阶段策略难以同时兼顾 feasibility、convergence 和 diversity；
  - 双种群/多种群方法能让主群开发 CPF、辅群探索 infeasible regions，但资源分配常是固定的；
  - 辅助群若长期占用过多资源探索 UPF 或不可行多样性，会削弱主群对 CPF 的深度开发。
- 现有工作为什么不足：
  - epsilon、push-pull 和两阶段方法依赖切换条件或参数，难适应不同约束景观；
  - 多种群框架能并行探索，但可能产生资源竞争、冗余和互相干扰；
  - 传统辅助选择常依赖绝对 fitness 或总 CV，容易受极端不可行值和尺度影响；
  - 固定主/辅 offspring 配额不能响应搜索阶段变化。
- 本文希望解决什么：
  - 为辅助种群设计更稳健的环境选择，既保留 promising infeasible solutions，又维护结构多样性；
  - 为主/辅种群设计动态、参数少的 offspring allocation；
  - 通过跨种群 DE 交互让辅助群的多样性材料能被主群利用；
  - 在标准 CMOP、可扩展高维测试和工程问题上验证整体性能与失败边界。

## 核心模型与算法流程

- 双种群框架：
  - `P1`：primary population，最终输出来源，使用 CDP 进行环境选择；
  - `P2`：auxiliary population，探索 relaxed infeasible regions，使用 Algorithm 2 的辅助环境选择；
  - 初始时 `P2` 是 `P1` 的复制，`N1=N2=NP`；
  - 每轮生成 `O1`、`O2` 后合并为 `O`，主/辅环境选择共享 offspring 信息。
- 主种群 offspring：
  - 使用 `DE/current/best/1` 强化收敛；
  - `Pbest` 从 `P1` 中按 CDP 选 top 10% elite 后复制到 `N1`；
  - 操作形式使用来自 `P2` 和 `P1` 的交叉信息：`P2(r1)`、`Pbest`、`P1(r2)`、`P2(r3)`。
- 辅助种群 offspring：
  - 使用 `DE/rand/1` 强化探索和多样性；
  - `Pr1` 来自 `P1`，`Pr2`、`Pr3` 来自 `P2`；
  - DE 参数 `F` 从 `{0.6,0.8,1.0}` 随机选，`CR` 从 `{0.1,0.2,1.0}` 随机选，随后执行 polynomial mutation。
- 辅助环境选择：
  - 对目标和约束违反做 min-max normalization；
  - 约束通过 epsilon relaxation，`epsilon_0` 为初始主/辅群最大 CV，衰减参数 `pp=0.5`；
  - baseline fitness `v_i` 用指数化目标项和对数 relaxed constraint penalty 组合；
  - pairwise win probability 为 `P(i ≻ j)=1/(1+exp(sgn(v_i-v_j)))`，将绝对差值压成三值比较，降低极端 outlier 影响；
  - `w_i` 是个体 `i` 对其它个体的平均 win-rate；
  - `rho_i = || sum_{j!=i} (x_i-x_j)/(||x_i-x_j||+delta) ||`，表示决策空间局部扰动敏感性或结构影响；
  - final score `S_i = exp(w_i) * ln(1 + rho_i)`，选 `S_i` 最大的 `NP` 个体进入 `P2`。
- Cournot-inspired 动态资源分配：
  - 对每个种群，计算 adaptive penalty `lambda = sigma(F_tilde)/(sigma(C_tilde)+delta)`；
  - 质量成本 `Q = mean(sum F_tilde + lambda * sum C_tilde)`，越小表示 convergence/feasibility 越好；
  - 多样性 `D` 为平均 pairwise Euclidean distance；
  - 竞争度 `eta = D/(Q+delta)`，偏好“高多样性、低质量成本”的种群；
  - `alpha1=max(2*eta1-eta2,0)`，`alpha2=max(2*eta2-eta1,0)`；
  - 将总 offspring 数 `2NP` 按 `alpha` 比例分给 `N1` 和 `N2`，并用 `max(...,1)` 防止某个种群完全断粮。
- 复杂度：
  - 每代主要成本在 pairwise density / distance 和环境选择；
  - 总复杂度约为 `O(N^2(M+D))`，与常见 CMOEA 同阶。

## 实验证据

- 实验设置：
  - 对比算法 7 个：`theta-DEACPBI`、BiCo、C3M、CMOEA-MS、DSPCMDE、LCMEA、APSEA；
  - 42 个 benchmark functions：CF、DAS-CMOP、DOC、LIR-CMOP；
  - 30 次独立运行，`MaxFES=100000`，population size `100`；
  - 平台为 PlatEMO；
  - 评价指标包括 IGD、HV 和 feasible solution ratio，统计用 Wilcoxon rank-sum / signed-rank test。
- D=30 综合结果：
  - CF 上 DGCMOEA 在多数对比中赢多输少，CF2/CF3/CF4/CF6/CF9 取得最优 IGD/HV；
  - DAS-CMOP 上 DGCMOEA 对多个算法达到 `8-9` 个 win，且保持 `100%` feasible solution ratio；
  - DOC 上 DGCMOEA 在 9 个函数全部取得 best IGD，对 HV 也保持领先或竞争；
  - LIR-CMOP 上 DGCMOEA 在多数函数获得 best 或领先统计结果，例如对 `theta-DEACPBI` 的 IGD/HV 均为 `14/0/0`。
- 高维扩展：
  - 作者把维度扩展到 `D=50,100,200`；
  - 在 `D=200` 时，DGCMOEA 对 `theta-DEACPBI` 的 IGD/HV 为 `30/7/5`、`29/8/5`，对 C3M 为 `26/9/7`、`25/9/8`，对 DSPCMDE 为 `25/10/7`、`24/10/8`；
  - 作者认为空间扰动敏感性和动态资源分配使算法在高维下仍能维持多数胜场。
- 运行时间：
  - Table 4 显示 DGCMOEA 在各测试集和维度上平均运行时间均为最小；
  - 例如 `D=30` 时 CF/DASCMOP/DOC/LIRCMOP 分别约 `4.916 s`、`32.324 s`、`6.149 s`、`20.324 s`；
  - `D=200` 时分别约 `5.732 s`、`37.325 s`、`8.294 s`、`26.839 s`；
  - 作者解释为动态资源分配能减少无效探索，且核心评价是轻量矩阵和欧氏距离计算。
- 工程问题：
  - 三个真实/经典工程问题：Welded Beam Design、Speed Reducer Design、Spring Design；
  - Spring Design 上 DGCMOEA 的 IGD 为 `2.55e+01`，显著优于全部 7 个对比算法，HV 也达到 best 或并列 best；
  - Welded Beam 上 HV 为 `8.60e-01`，优于对比算法；
  - Speed Reducer 上 BiCo/CMOEA-MS 在部分指标上略优，说明 DGCMOEA 并非所有工程问题绝对领先；
  - DGCMOEA 在三类工程问题中保持 `100%` feasible solution rate。
- 全局统计：
  - Signed-rank test 中 DGCMOEA 对 7 个 baseline 的 IGD 和 HV 差异均为 `p<0.05`；
  - 例如 IGD 对 `theta-DEACPBI` 的 `p=2.31015E-09`，HV 对 APSEA 的 `p=8.45279E-07`。
- 消融实验：
  - DGCMOEA-A：辅助环境选择改为 epsilon model；
  - DGCMOEA-B：辅助环境选择改为 CDP；
  - DGCMOEA-C：固定 population size / 固定资源；
  - DGCMOEA-D：移除跨种群交互，只在 `P1` 用 `DE/current/best/1`、在 `P2` 用 `DE/rand/1`；
  - 完整 DGCMOEA 对四个 ablation variants 均显著更优，IGD 胜平负分别为 `37/2/2`、`40/0/1`、`36/4/1`、`38/3/0`；
  - HV 胜平负分别为 `38/1/2`、`39/0/2`、`37/3/1`、`36/4/1`；
  - Figure 6 显示完整算法早期偏向辅助群探索，后期把资源转回主群开发。

## 局限与未来工作

- 作者明确指出的失败：
  - 在 CF8 和 CF10 上，DGCMOEA 所有独立运行都无法找到 feasible solutions；
  - FSR 为 `0.00%`，IGD/HV 为 NaN；
  - C3M、`theta-DEACPBI` 等部分 baseline 能在这些实例上找到可行解。
- 失败原因解释：
  - CF8/CF10 的 feasible regions 极窄、孤立且带欺骗性，周围有大量 infeasible areas；
  - 辅助群的空间扰动敏感性可能过度奖励 infeasible diversity；
  - 动态资源分配若把高 diversity 误判为高 competitiveness，会持续把 offspring 给辅助群；
  - 主群因此缺少穿透极窄可行边界的资源，出现 evolutionary stagnation。
- 作者未来方向：
  - 加入 adaptive stagnation-detection；
  - 当主群长期找不到 feasible solutions 时，临时 override 动态资源分配，把资源强制转回 strict constraint satisfaction；
  - 增强对 uncertainty 和 dynamic noise 的鲁棒性。
- 我们认为仍需确认的问题：
  - `rho_i` 的方向向量和在高维稀疏空间中的密度意义需要进一步分析；
  - `eta=D/Q` 把 diversity 直接作为资源优势，极窄可行域下容易过度鼓励不可行游走；
  - `S_i` 的目标项、约束项、win-rate 和 spatial sensitivity 的尺度互动较复杂，需要更细参数/归一化敏感性；
  - 工程问题数量仍少，且 Speed Reducer 上非全面领先；
  - “dynamic game / Cournot”更像启发式资源分配公式，而不是严格博弈均衡推导。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：[博弈竞争驱动的双种群资源分配与辅助选择](../02_design_knowledge/K-game-competitive-dual-population-resource-allocation.md)。它适合迁移到双种群 CMOEA、不可行辅助搜索、主/辅资源分配和跨种群差分进化框架。
- 与已有设计知识的边界：
  - 不同于 [约束难度加权的多辅助种群资源分配与合并](../02_design_knowledge/K-constraint-difficulty-weighted-auxiliary-resource-merging.md)，本文不是为多个 constraint-specific populations 分配资源，而是在主/辅两个功能种群之间按竞争度动态分配 offspring；
  - 不同于 [双边界不可行辅助指标与分组 DE](../02_design_knowledge/K-dual-boundary-infeasible-indicator-vgde.md)，本文不使用 alpha/beta 双松弛边界和变量分组，而是用 win-rate、spatial sensitivity 和 Cournot allocation；
  - 不同于 [双空间分层自适应资源分配](../02_design_knowledge/K-dual-space-hierarchical-resource-allocation.md)，本文分配的是双种群 offspring 数，不是目标区域-变量组函数评价预算；
  - 不同于 [状态驱动的 DRL 演化算子选择](../02_design_knowledge/K-drl-state-driven-evolutionary-operator-selection.md)，本文没有训练 RL policy，而是使用显式质量/多样性竞争公式。
- 暂留在论文卡中的方法、原理或架构启发：
  - 论文中提到 information entropy 和 causal reasoning，但核心实现证据主要是 win-rate、spatial sensitivity 和 Cournot allocation，暂不单独成卡；
  - `pp=0.5` 来自既有 epsilon-constraint 设置，暂不作为新知识；
  - 具体 baseline 排名不直接推广为通用算法优先级。
- 局部创新线索：
  - 给 `eta=D/Q` 加 feasible-ratio 或 main-stagnation correction，防止不可行多样性虚高；
  - 将 `rho_i` 从决策空间方向和改为 reference-vector niche impact 或 objective-space sparse contribution；
  - 对 `S_i` 加 temperature，使 win-rate 与 diversity 的相对权重可随阶段变化；
  - 为 `N1,N2` 设置更高的动态下限，例如主群在无可行解时保底 `0.8NP`。
- 结构创新线索：
  - 构建带 watchdog 的双种群 CMOEA：正常时按 game competitiveness 分配资源，主群停滞时触发 feasibility override；
  - 将辅助群拆成“边界探索”和“全局不可行探索”两类，再用 game allocation 分三方资源；
  - 把 resource allocation、operator choice 和 constraint relaxation 合成一个可解释控制器；
  - 在昂贵 CMOP 中，用低成本 surrogate 预估 `Q/D/eta`，只对高优先级 offspring 做真实评价。
