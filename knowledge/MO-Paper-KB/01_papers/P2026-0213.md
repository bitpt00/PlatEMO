# MOEA/DCH：层级估计与聚类分解的模糊柔性作业车间调度

## 一句话理解

论文面向 type-2 fuzzy processing time 下的多目标柔性作业车间调度，提出 MOEA/DCH：用 dominance 信息和 PBI 标量化信息把父代+子代分成 5 个层级，再在关键层中以非支配解作为聚类中心筛出有效参考向量并轮流补齐精英集，从而在不确定离散调度问题的非规则/断裂 PF 上兼顾收敛与分布。

## 问题与动机

- 研究问题和场景：
  - Multiobjective fuzzy flexible jobshop scheduling problem (MFFJSP)。
  - 加工时间用 nonsymmetrical triangular interval type-2 fuzzy numbers (T2FNs) 描述，以反映制造系统中的加工时间不确定性。
  - 三个目标为最小化 makespan、total energy consumption (TEC) 和 total flow time (TFT)。
- 现有算法为什么不足：
  - dominance-based MOEA 可按支配关系保留精英，但在 fuzzy objective values 下做多样性评价更困难。
  - decomposition-based MOEA 通过参考向量维护多样性，但对均匀连续 PF 更友好；MFFJSP 离散决策/目标空间容易产生非规则、断裂 PF。
  - 断裂 PF 下部分参考向量不与真实 PF 相交，沿这些无效向量搜索会浪费有限计算资源。
  - 直接删除疑似无效参考向量也有风险：误删有效向量会损害收敛和覆盖。
- 本文希望解决什么：
  - 在未知真实 PF 时识别并弱化无效参考向量的影响。
  - 环境选择中同时利用非支配层级、参考向量关联和 PBI 标量化值。
  - 在关键层个体过多时，用非支配解引导的聚类选择保持有效分布。

## 模型与编码

- 模糊调度模型：
  - 每个作业包含多个有先后约束的工序，每个工序可在多个机器上加工。
  - 工序加工时间为 T2FN `p_i,j,k=(p1,p2,p3,p4,p5)`。
  - 约束包括：每道工序一次只能在一台机器上加工；每台机器同一时刻最多处理一道工序；工序不可中断；同一作业内部先后顺序必须满足。
  - 不考虑机器故障、运输时间、运输能耗和机器切换能耗。
- 目标：
  - **Makespan**：最后完工工序的完成时间。
  - **TEC**：机器加工能耗和空闲能耗之和。
  - **TFT**：所有作业完成时间之和。
- 编码与解码：
  - 使用两层编码：operation code 表示工序处理顺序，machine code 表示每个工序选择的机器。
  - operation code 中整数 `i` 表示作业 `J_i`，出现次数对应该作业工序数。

## 核心理念与算法流程

- 核心理念：
  - 支配关系主要保护收敛，标量化/PBI 主要提供参考向量方向上的多样性，两者需要组合而不是二选一。
  - 对断裂 PF，不能只按固定参考向量硬选解；应观察非支配解实际落在哪些区域，再决定哪些参考向量有效。
  - 当高层级解不足以填满精英集时，关键层选择必须按非支配解周围的有效聚类轮流补齐，避免集中到某一断裂区域。
- MOEA/DCH 流程：
  1. 用三条调度启发式初始化种群 `pop`，并作为 elite set `Et`。
  2. 每代用交叉和变异生成 offspring `Qt`。
  3. 合并 `Pt = Qt ∪ Et`，提取非支配解 `Np`。
  4. 对 `Pt` 执行 hierarchical estimation，得到 `L1..L5`。
  5. 从低层级开始删除，直到剩余精英集不足以填满 `N`，此时当前层为 critical level。
  6. 对 critical level 执行 clustering-based adaptive decomposition，以非支配解为潜在聚类中心，确定有效聚类中心和有效参考向量。
  7. 在有效聚类中按 PBI 值排序，并轮流选取个体补齐 elite set。
  8. 重复直到达到最大评价次数。
- 初始化：
  - Rule 1：随机 operation code；每个工序分配给加工时间最短机器。
  - Rule 2：随机 operation code；每个工序分配给完成时间最短机器。
  - Rule 3：随机生成工序序列和机器分配。
  - 三类规则各占约 1/3 种群。
- 子代生成：
  - 父代通过二元锦标赛选择。
  - operation code 使用 POX 或 GPX；machine code 使用 UX。
  - operation code 随机执行 insert、swap、inverse。
  - machine code 有三类问题启发式变异：把最终完成工序分给最短加工时间机器；将最高负载机器上的工序移到其他机器；随机工序分配给最短加工时间机器。

## 层级估计与聚类分解

- Hierarchical estimation：
  - 先用 ideal/nadir 归一化目标值，使参考向量从 ideal point 出发。
  - 每个解关联到夹角最小的参考向量。
  - 参考向量分成三类：
    - `omega_o`：没有关联解的参考向量；
    - `omega_n`：关联了非支配解的参考向量；
    - `omega_d`：只关联 dominated solution 的参考向量。
  - 按 dominance 和 PBI 将解分到五级：
    - `L1`：所有非支配解；
    - `L2`：在 `omega_d` 各向量中 PBI 最小的解，用于补充没有非支配解覆盖的方向；
    - `L3`：与 `omega_n` 同向量关联、但非 `L1` 的 PBI 最小 dominated 解，用于补充收敛；
    - `L4`：`omega_d` 中 PBI 次优解，用于进一步平衡多样性和收敛；
    - `L5`：剩余解。
- Clustering-based adaptive decomposition：
  - 当删除低层后需要从 critical level 中补齐 elite set 时启动。
  - 以非支配解 `Np` 作为 potential clustering centers。
  - critical level 中的解按到非支配解的欧氏距离归入最近 cluster。
  - 非空 cluster 的中心被定义为 effective clustering center；与其关联的参考向量被视作 effective reference vector。
  - 每个有效 cluster 内按 PBI 值排序，然后各 cluster 轮流选第一个、第二个……直到填满精英集。

## 实验证据

- 实验设置：
  - 数据：30 个 MFFJSP benchmark cases，格式如 `JnMm` 表示 `n` 个作业、`m` 台机器。
  - 对比算法：MOEA/D、NSGA-II、IAIS、FBEA、LRVMA、MOEA/D_2N。
  - 种群规模 100，最大 fitness evaluations 10000，每个算法独立运行 20 次。
  - 指标：HV、GD、Spread；Wilcoxon signed-rank test，显著性 0.05；Friedman test 汇总排名。
- HV：
  - **论文实验直接支持**：MOEA/DCH 在 30 个案例中 20 个获得最优 HV。
  - **论文实验直接支持**：MOEA/DCH 的 HV 优于 NSGA-II 29/30、IAIS 24/30、MOEA/D_2N 23/30、MOEA/D 25/30、FBEA 28/30、LRVMA 30/30。
  - **论文实验直接支持**：相对 NSGA-II、LRVMA、MOEA/D、MOEA/D_2N 等多数比较具有统计显著优势；但在 J100M8、J100M9、J80M8、J80M6 等大案例上相对 IAIS 不占优且无显著差异。
  - 作者指出随 case size 增大，MOEA/DCH 的 HV 表现下降，可能因为依赖非支配解指导演化影响决策空间探索。
- GD：
  - **论文实验直接支持**：MOEA/DCH 在 30 个案例中 24 个获得最优 GD。
  - **论文实验直接支持**：GD 上优于 NSGA-II 30/30、IAIS 26/30、MOEA/D 28/30、FBEA 30/30、LRVMA 28/30、MOEA/D_2N 30/30。
  - 作者解释：非支配解引导的种群演化更有利于收敛，因此 GD 优势比 HV 更强，但多样性可能相对更难保持。
- Spread：
  - **论文实验直接支持**：MOEA/DCH 在 30 个案例中 16 个获得最优 Spread。
  - **论文实验直接支持**：Spread 上优于 NSGA-II 23/30、IAIS 30/30、MOEA/D 20/30、FBEA 30/30、LRVMA 27/30、MOEA/D_2N 30/30。
  - Spread 有时超过 1，作者归因于非支配解数量少且分布差异大。
- 综合排名与可视化：
  - **论文实验直接支持**：Friedman test 中，MOEA/DCH 在 HV、GD、Spread 三个指标上均排名第一。
  - **论文实验直接支持**：Fig. 5 中 MOEA/DCH 获得的非支配解质量较高且数量较多，支持其能平衡收敛和多样性。
- 层级估计分析：
  - **论文实验直接支持**：Table VI 显示 critical level 主要是 `L5`，`L4` 很少成为 critical level，且随着案例规模增大逐渐降为 0。
  - 作者解释：大规模案例中非支配解更少、许多参考向量没有关联解，说明解更集中，离散 MFFJSP 的不可行区域和断裂 PF 加剧了搜索困难。

## 局限与未来工作

- 作者明确说明的局限：
  - MOEA/DCH 在大规模案例上无法取得显著优势。
  - 一个可能原因是算法删除部分无效参考向量后，会削弱近似 PF 的能力。
- 作者未来工作：
  - 引入数据驱动和自适应机制克服大规模案例上的不足。
  - 扩展 MOEA/DCH 到其他复杂调度问题。
- 我们认为仍需确认的问题：
  - clustering-based adaptive decomposition 依赖当前非支配解作为中心；若早期非支配解少且偏置，可能把有效参考向量误判为无效。
  - 关键层选择规则更偏向已有非支配区域，可能在断裂 PF 的空白区域探索不足。
  - 论文对初始化、交叉变异和层级/聚类三类组件的独立消融主要放在补充材料，主文无法完全分离每个贡献。
  - 只在 MFFJSP 上验证；是否可迁移到连续不规则 PF 或其他离散 MOO 需要测试。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“层级估计与聚类筛选的有效参考向量”：它把支配层级、参考向量关联、PBI 排序、critical-level 选择和非支配聚类中心组合成可移植的分解式环境选择模块。
- 暂留在论文卡中的方法、原理或架构启发：
  - T2FN 具体调度建模、能耗公式和调度专用变异算子保留在论文卡。
  - 启发式初始化可作为调度问题特定经验，暂不单独建卡。
- 局部创新线索：
  - 用非支配解历史稳定性判断聚类中心是否可靠，避免早期偏置中心主导参考向量筛选。
  - 对被判无效的参考向量不直接删除，而是保留少量探索预算或周期性复活。
  - 将 critical-level 轮流选择改为按 cluster 贡献、拥挤度或预测空洞自适应分配名额。
  - 在 fuzzy objective 中将 T2FN 不确定性宽度纳入层级评分，保护鲁棒性高的解。
- 结构创新线索：
  - 构建“支配保护收敛 + 分解保护分布 + 聚类识别有效方向 + 弱保留无效方向探索”的离散不规则 PF 环境选择框架。
  - 与代理或数据驱动机制结合：预测哪些参考向量可能在后期变有效，避免永久误删。
  - 将该层级估计模块接入 NSGA-II、RVEA 或 MOEA/D-DRA，测试其作为通用环境选择插件的能力。
