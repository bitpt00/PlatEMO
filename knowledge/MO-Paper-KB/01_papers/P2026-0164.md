# A constrained multi-objective co-evolutionary algorithm with a dynamic diversity-enhanced auxiliary population

## 一句话理解

本文提出 CMOCEA-DDAP：在约束多目标优化中维护一个同时考虑目标和约束的主种群，以及一个忽略约束、规模动态缩减的辅助种群；辅助种群和多样性档案早期广泛探索无约束/不可行区域，主种群用双策略 CHT 与自适应 DE 算子把这些多样性信息拉回到可行 Pareto 前沿。

## 问题与动机

- 研究问题和场景：
  - constrained multi-objective optimization problems (CMOPs)，尤其是可行域狭窄、断裂，或被 infeasible regions 分割的连续约束优化问题；
  - 目标是同时获得收敛、可行和分布均匀的 Pareto optimal solutions；
  - 论文还强调 mechanical design problems 中常见多个目标和多个工程约束。
- 现有算法为什么不足：
  - 作者认为多种群 CMOEA 常把辅助种群固定为某种角色，或不能充分利用历史搜索信息来动态平衡 convergence 与 diversity；
  - 只强调 constraints 可能使搜索困在局部可行区，难跨越大面积不可行区；
  - 只忽略 constraints 追求 UPF/目标空间多样性又可能在 UPF 与 CPF 距离较远时浪费预算；
  - ranking-based CHT 在 Pareto front 上解很密集时，作者观察到难以产生均匀分布；
  - 单一 mutation operator 难同时提供 exploration 和 exploitation。
- 本文希望解决什么：
  - 让辅助种群早期保留更多 diversity，后期逐渐减少规模和随机保留比例，从探索转向收敛；
  - 通过 diversity archive 从 MainPop/AuPop/历史 DA 中抽取方向均匀的非支配候选，持续给辅助种群供给多样性；
  - 给 MainPop 和 AuPop 配置不同 CHT、不同搜索算子和不同环境选择；
  - 用历史成功率在两类 DE 搜索操作之间自适应选择，使 MainPop 能随阶段调整开发/探索。

## 核心理念与算法流程

- 核心理念：
  - `MainPop` 是最终输出来源，负责 constraint-aware convergence 和 CPF exploitation；
  - `AuPop` 只按目标函数排序和拥挤距离选择，负责提供 objective-space diversity 与跨不可行区探索信息；
  - `DA` 是多样性档案，不直接让 MainPop 参与 AuPop 演化，而是先从 `DA + MainPop + AuPop` 中采样均匀解，再用 `DA` 引导 AuPop；
  - `AuPop` 与 `DA` 的规模线性递减，早期扩大探索，后期降低成本和不可行空转。
- 主要流程：
  - 初始化 `MainPop`、`AuPop` 和空的 diversity archive；
  - 每代先用 Algorithm 6 更新 `DA`；
  - 用 Algorithm 5 从 `AuPop + DA` 选择父代，生成半个辅助种群规模的 GA offspring；
  - 合并 `AuPop`、辅助 offspring 和 `DA`，用 Algorithm 3 更新 `AuPop`；
  - 用 Algorithm 4 基于 `MainPop` 与 `AuPop` 的 rank-1 候选生成 MainPop offspring；
  - 合并 `MainPop`、`AuPop` 和 MainPop offspring，用 Algorithm 2 更新 `MainPop`；
  - 输出 `MainPop` 的非支配解。
- 关键组成部分：
  - dynamic diversity-enhanced auxiliary population；
  - multi-strategy cooperative CHT；
  - MainPop adaptive multi-mutation DE search；
  - AuPop GA search with dynamic size；
  - diversity archive and angular sampling。
- 可能被修改的位置：
  - `AuPop/DA` 的规模调度可由线性递减改成可行率、UPF-CPF 距离或 archive contribution 反馈；
  - MainPop 的双策略 CHT 可替换为更强的 adaptive CHT；
  - Algorithm 4 的两类 operator group 可替换为更多算子池、RL 控制或 survival-rate credit；
  - Algorithm 6 的参考向量角度采样可换成 region vacancy、clustering 或 decision-objective 双空间采样。
- 必须保留的核心：
  - 主群和辅群的角色必须不同：主群同时考虑目标/约束，辅群承担较少约束压力的 diversity source；
  - 辅助信息应通过选择/档案/合并机制回流主群，而不是让辅群长期无约束空转；
  - 辅助规模或资源必须随阶段降低，否则在 UPF 与 CPF 远离时容易消耗后期精修预算。

## 实验证据

- 测试问题和对比算法：
  - 对比 14 个 state-of-the-art CMOEAs：APSEA、CMME、CMOCSO、CMODE-FTR、CMOEMT、CMOES、CSEMT、DPCPRA、MCCMO、PPS、TPCMaO、URCMO、DRLOS-EMCMO、CMODRL；
  - benchmark 包含 NCTP、LIR-CMOP、MW、CF，共 56 个测试问题；
  - 真实问题为 21 个 mechanical design problems，目标数 2 或 3，变量数 2 到 10，约束数 1 到 11；
  - population size `N=100`，最大评价次数 60000，每个算法每题 30 次独立运行；
  - 指标为 IGD、HV 和 Wilcoxon rank-sum test，机械设计因 true PF 不可得只报告 HV。
- 主要实验结论：
  - IGD 总计中 CMOCEA-DDAP 相比 14 个对比算法为 `58/653/73`（差/优/等），平均在 83.29% 的实例上显著优于对比算法；
  - HV 总计为 `69/589/126`，平均在 75.13% 的实例上显著优于对比算法；
  - NCTP 上 IGD 最强，LIR-CMOP 上 HV 最强且表现最稳定；
  - CMOCEA-DDAP 对 LIR-CMOP6、LIR-CMOP10、LIR-CMOP12 等断裂可行域问题能找到接近 true PF 的解；
  - average feasibility rate 在四个 benchmark test suites 上均达到 100%；
  - LIR-CMOP 平均运行时间在 15 个算法中排第 4，作者认为 MainPop update 是主要耗时部分；
  - 收敛曲线显示早期不一定最快，但后期可达到更好值，作者归因于早期充分探索 infeasible regions。
- 消融或机制证据：
  - 七个变体分别去除 diversity enhancement、AuPop、自适应选择、扰动、MainPop Strategy I、AuPop 随机选择、动态 AuxPop size；
  - 去除任一模块都会削弱性能，其中去除 diversity enhancement 的 CMOCEA-DDAP-I 差异最大；
  - 完整 CMOCEA-DDAP 在 Friedman/Scheffe 检验中排名高于七个变体，且与每个变体差异显著；
  - 无扰动变体在 MW2 和 MW6 上停滞，可视化支持 perturbation 对逃逸 stagnation 有用；
  - 只用 MainPop Strategy II 的变体在 MW4 和 MW8 上分布均匀性差于完整算法，支持 Strategy I 的 uniformity 作用；
  - 参数分析显示 `CR=0.05` 最优但与 0/0.1 差异不显著，`alpha=0.01` 最优且过大/为 0 都会恶化，`beta=0.8` 与 1.0 差异不明显。
- 证据边界：
  - CF8-CF10 上 TPCMaO 的 HV 优于 CMOCEA-DDAP，作者解释为这些问题的 PF 是大目标空间中多个断裂 nonlinear 2D surfaces，而 TPCMaO 三种群分别朝不同区域演化更合适；
  - MW5、MW11、MW12、LIR-CMOP13、CF3 是 CMOCEA-DDAP 在 IGD/HV 上相对弱的主要问题；
  - 作者明确指出，当 UPF 远离 CPF 且 CPF irregular/densely distributed 时，CMOCEA-DDAP 可能把预算花在无约束 PF 探索，后期没有足够资源执行 Strategy I 形成均匀 CPF；
  - 实验主要是 2-3 目标连续 CMOP 和 mechanical design，many-objective、离散/混合变量、昂贵评价和动态约束场景仍需额外验证。

## 局限与未来工作

- 作者明确说明的局限：
  - 在 unconstrained PF 远离 constrained PF，且 constrained PF 不规则、稠密分布的问题上表现较差；
  - 根本原因是 objective functions 与 constraints 的平衡仍不充分；
  - 早期无约束探索会消耗计算资源，若后期才收敛到 CPF，可能来不及获得均匀解集。
- 作者未来工作：
  - 进一步改进 MainPop 与 AuPop 之间的 collaborative constraint-handling strategy；
  - 根据具体问题特征自适应协调 constraint handling。
- 我们认为仍需确认的问题：
  - `NR >= beta*N` 触发 Strategy I 的密集判据是否足以表示“需要均匀性修复”；
  - 线性缩减 AuPop/DA 对所有 UPF-CPF 关系是否合适，是否应由 feasibility progress 或 archive contribution 控制；
  - AuPop 忽略 constraints 的信息何时从“有用跨越”变成“误导或预算浪费”，当前算法缺少显式检测；
  - Algorithm 4 用两组 operator 的短期 success rate 作为选择概率，是否会在难题上被噪声或暂时停滞误导；
  - `O(m(2N+Na)^2)` 级更新成本在更大种群或 many-objective 下是否可接受。

- 值得建立或补充的设计知识：
  - 新建 [动态辅助种群多样性增强的约束协同进化](../02_design_knowledge/K-dynamic-auxiliary-population-diversity-constraint-coevolution.md)。
- 暂留在论文卡中的方法、原理或架构启发：
  - MainPop CHT 的 Strategy I/II 可以单独作为“密集非支配态切换选择器”移植，但目前证据来自本算法组合，暂不单独建卡；
  - Algorithm 4 的“按是否 crossover 分组，再用 success rate 选择组内随机算子”可用于 DE operator portfolio，但属于常见自适应算子选择变体；
  - Algorithm 6 的方向均匀 `DA` 可作为 archive truncation 或 auxiliary seeding 方法，但本轮先并入动态辅助种群知识。
- 局部创新线索：
  - 用 UPF-CPF 距离估计、可行率变化或 `DA` 贡献率替代线性 AuPop/DA shrink；
  - 给 AuPop 加 boundary-infeasible filter，避免远离 CPF 的无约束前沿长期占资源；
  - 将 MainPop Strategy I 的触发从 `rank-1 count` 改为 reference-vector vacancy、spacing entropy 或 crowding variance；
  - 用 delayed survival credit 修正 Algorithm 4 的 operator selection，避免短期 fitness 改善误导。
- 结构创新线索：
  - 三角色扩展：MainPop 负责 CPF，AuxPop 负责 UPF，BoundaryPop 负责 low-CV/near-boundary infeasible solutions；
  - 将 CMOCEA-DDAP 与资源分配卡结合：动态决定 AuPop offspring 数、MainPop offspring 数和 `DA` 容量；
  - 在 many-objective CMOP 中把 `DA` 的参考向量角度采样与曲率投影/角度选择结合；
  - 建立 UPF-CPF relatedness detector，若检测到远离或负迁移，则提前降低 AuPop 权重并增强 MainPop uniformity repair。
