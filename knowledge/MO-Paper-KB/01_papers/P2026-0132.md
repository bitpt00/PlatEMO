# A data-driven multi-objective differential evolution framework for charging-thermal coupled parameter optimization in rotary hearth furnace operations

## 一句话理解

论文面向 rotary hearth furnace (RHF) 固废回收过程的工艺设定优化，先用历史生产数据训练 XGBoost 代理来预测污染物排放和金属产量，再在代理上运行带 S-metric selection 和自适应 Gaussian local search 的 SaMODE，得到污染排放最小与金属产量最大之间的 Pareto set，最后用熵权法从每组 Pareto set 选择可执行工艺参数。

## 问题与动机

- 研究场景：RHF 是钢铁冶金固废资源化处理的高温反应器，用于处理含铁、锌的粉尘和污泥，同时回收金属产物。
- RHF 优化困难：
  - 过程包含传热、气体扩散、化学反应、多相多物理场耦合，机理模型难以准确且泛化；
  - 高温还原促进金属回收，但也会增加 CO/CO2、颗粒物、SO2、NOx 等排放风险；
  - 生产设定需要满足实际安全上下界，不能由随机优化器任意外推；
  - 传统经验设定对工况变化适应性差，物理实验和 CFD/机理仿真成本高。
- 本文希望解决什么：
  - 用工业历史数据替代难构造的一阶原理模型；
  - 建立 charging-thermal coupled parameters 到污染物排放和金属产量的代理映射；
  - 在代理上高效搜索安全范围内的 Pareto 工艺设定；
  - 从 Pareto 解集中选出实际生产可用的折中方案。

## 核心理念与算法流程

- 核心理念：把复杂 RHF 看作带时滞的黑箱过程。先通过 time-lag alignment 将 `lambda(t - tau)` 的工艺设定与 `z(t)` 的产品/排放结果对齐，再训练 XGBoost 预测六个输出指标；随后把三个污染指标和三个产量指标分别聚合成 `f1` 与 `f2`，用多目标 DE 在代理上搜索。
- 数据与变量：
  - 数据来自上海某钢厂 RHF 生产过程，覆盖 31 天，10 min 采样间隔。
  - 原始数据经过 time-lag alignment、constraint-based filtering 和 outlier removal。
  - 18 个决策变量 `lambda = {x_u, y_v, T_w}`：
    - 6 个 material parameters：carbon-oxygen ratio、chlorine-zinc ratio、carbon content、zinc content、sulfur content、ferrum content；
    - 7 个 energy parameters：air-fuel ratio、furnace pressure A/B、mixed gas pressure、compressed air pressure、mixed gas temperature、compressed air temperature；
    - 5 个 temperature parameters：Reduction Zone 1-4 temperature、Heating Zone temperature。
  - 6 个代理预测输出：
    - 污染：particulate、sulfur dioxide、nitrogen oxides；
    - 产量：DRI pellets、DRI powder、zinc powder。
- 目标模型：
  - XGBoost 预测每个输出子指标 `hat z_i(lambda)`；
  - 污染排放目标 `f1` 是 particulate、SO2、NOx 的加权和，权重来自税率或惩罚严重度；
  - 金属产量目标 `f2` 是 DRI pellets、DRI powder、zinc powder 的加权和，权重来自产品经济价值或优先级；
  - 优化方向写作 `min F(lambda) = [f1(lambda), -f2(lambda)]`；
  - 约束是每类决策变量的安全上下界 `L <= lambda <= U`，来自实际生产安全要求。
- SaMODE 主流程：
  1. 初始化父代种群 `P`，用训练好的 XGBoost 代理评价。
  2. 从初始 `P` 中识别 non-dominated `POS`。
  3. 每代根据 self-adaptive triggering 判断是否执行 GLS；触发规则基于 power-law stage schedule，参数 `p=0.5`。
  4. 未触发时执行 DE：`mu = lambda + Fs * (lambda1 - lambda2)`，再按 `CR` 做交叉。
  5. 触发时执行 GLS：从 `POS` 随机选个体，随机选择 `l_size` 个维度，按该维标准差附近扰动。
  6. 越界变量用随机重初始化回 `[L,U]` 内，确保代理输入物理可行。
  7. 合并父代和子代，使用 fast non-dominated sorting 和 SMS-based selection；在最后一层按 HV contribution 删除贡献最小个体。
  8. 达到最大迭代后输出 best POS。
  9. 对每个 POS 用 entropy weighting + fuzzy set evaluation 选择 `EV` 最低的可执行方案。
- 关键组成部分：
  - time-lagged industrial data surrogate；
  - XGBoost 多输出子指标代理；
  - 污染/产量子指标聚合为双目标；
  - bounds-based safety constraints；
  - DE + SMS-based HV contribution survival；
  - power-law triggered Gaussian local search；
  - entropy-weighted Pareto post-selection。
- 可能被修改的位置：
  - 用 uncertainty-aware XGBoost ensemble、GP、NGBoost 或 conformal predictor 替代单点代理；
  - 将 `f1/f2` 的固定权重改成多目标的六指标直接优化或偏好可调聚合；
  - 用 MPC/在线控制层接收 Pareto setpoints；
  - 对越界变量使用投影或 repair，而不是随机重初始化；
  - 用真实生产反馈或小批次试验验证代理前沿，并回灌更新模型。

## 实验证据

- 数据与代理模型：
  - 31 天、10 min 采样间隔的上海钢厂 RHF 生产数据；
  - 按 6:2:2 划分 train/validation/test，随机种子 42；
  - XGBoost 超参数由 grid search 确定；六个输出使用不同 `n_estimators/learning_rate/gamma/max_depth`。
  - 与 RF、GBDT、MLP、SVR 比较，Fig. 7 显示 XGBoost 在 MAPE、MAE、RMSE 和 runtime 上整体最优；图中数值未在 Markdown/PDF 文本中抽取。
- XGBoost 预测精度：
  - 除 particulate 和 SO2 外，其他四个输出在 `±1.00 std` 内命中率超过 90%。
  - Table 5 命中率：
    - particulate：`83.97% / 91.10% / 96.36%` for `±1.00 / ±1.25 / ±1.50 std`；
    - SO2：`70.12% / 80.32% / 88.05%`；
    - NOx：`92.57% / 96.79% / 98.25%`；
    - DRI pellets：`93.73% / 96.21% / 97.08%`；
    - DRI powder：`96.79% / 97.81% / 98.69%`；
    - zinc powder：`98.25% / 98.83% / 99.56%`。
  - 误差尺度示例：particulate 多在 `±0.22 mg/m3`，SO2 多在 `±5.24 mg/m3`，NOx 多在 `±23.1 mg/m3`，DRI pellets 多在 `±852 kg`，DRI powder 多在 `±266 kg`，zinc powder 多在 `±17.4 kg`。
- SaMODE 参数校准：
  - Python 3.13，12th Gen Intel Core i5 3.70 GHz，32 GB RAM；
  - `MaxFEs=100000 = pop_size 50 x n_gen 2000`；
  - 正交实验比较 `CR`、`Fs` 和 mutation type，HV 为响应值；
  - `Fs` 对 HV 影响最大，mean response delta 为 `0.0416`，mutation type 为 `0.0288`，`CR` 为 `0.0247`；
  - 最终参数：`CR=0.7`，`Fs=0.8`，Polynomial mutation。
- 与其他 MOEA 比较：
  - Baselines：NSGA-II、NSGA-III、UNSGA-III、MOEA/D、K-RVEA、Age-MOEA-II。
  - 每个算法在 20 个 surrogate-derived test instances 上独立运行 5 次，统一 `MaxFEs=100000`、`CR=0.7`、`Fs=0.8`、seed 42、polynomial mutation。
  - 指标：HV、Spacing (SP)、Success Rate (SR)。
  - ANOVA 显示 algorithm type 对 HV、SP、SR 影响显著，p-values 分别为 `9.8813e-60`、`3.6984e-05`、`7.6737e-34`。
  - Rank-sum average ranks：SaMODE 在 HV 为 `1.25`、SR 为 `1.08`，均最佳；SP 为 `4.65`，不如 MOEA/D、UNSGA-III、NSGA-III，说明分布间距不是绝对优势。
  - HV 收敛表：SaMODE 从 iteration 1 的 `0.406` 到 500 的 `0.793`，1500 的 `0.862`，4000 的 `0.899`；作者认为约 1500 iterations 稳定。
- 消融实验：
  - 三个变体：SMS-Base、SMS-Periodic、完整 SaMODE。
  - ANOVA p-values：HV `4.8656e-04`，SP `5.0941e-05`，SR `3.3196e-10`。
  - Average ranks：SaMODE 在 HV 和 SR 上均为 `1.15` 最佳；SP 为 `3.0`，低于 SMS-Base 和 SMS-Periodic。
  - 作者结论：固定频率 local search 提升多样性，自适应 local search 进一步提升收敛和鲁棒性。
- 工业案例选解：
  - 对 20 组案例记录 POS，用 entropy weighting + fuzzy set evaluation 选择最低 `EV` 的方案。
  - 与原始数据抽取的 20 组生产数据比较，选中方案使污染排放目标 `f1` 平均降低 `26.89%`，金属产量目标 `f2` 平均提高 `34.66%`。
- 证据边界：
  - 优化效果主要在 XGBoost 代理上计算，缺少在线生产闭环或新工况真实验证。
  - Fig. 7 的模型比较缺少可抽取数值，除 XGBoost 外的模型误差只能定性记录。
  - 目标聚合权重依赖环境税率、惩罚和产品价值，迁移到其他地区/工厂需要重算。
  - `SO2` 预测误差相对大，`±1.50 std` 内命中率仍只有 `88.05%`。
  - GLS 伪代码写 `Random(-sigma_j, sigma_j)`，但正文称 Gaussian perturbation，复现时需明确扰动分布。

## 局限与未来工作

- 作者未来工作：
  - 纳入 model uncertainty，量化 feed composition、sensor noise 和 surrogate intrinsic inaccuracies 等动态不确定性，提高鲁棒性；
  - 与 process control systems 集成，建立高层优化目标到低层控制指令的映射，用实时数据实现自适应闭环控制。
- 我们认为仍需确认的问题：
  - 代理优化的 Pareto set 是否在真实生产新样本上仍有效，尤其是被优化器推向历史数据稀疏区域时。
  - 污染和产量的加权聚合会隐藏单个污染物超标风险，实际部署可能需要将 SO2、NOx、particulate 作为约束或单独目标。
  - 越界随机重初始化虽保证 bounds，但可能破坏局部搜索结构；工业控制更常见的是投影、饱和或安全控制屏蔽。
  - 熵权法只依据 POS 的数据分布客观赋权，不等同于管理层或环保监管偏好。
  - 当前数据来自一个钢厂和 31 天窗口，季节、原料变化、设备老化和跨厂迁移仍未验证。

  - 对每个污染物建立 chance constraint 或 worst-case penalty，避免加权污染目标掩盖局部超标。

  - 将 GLS trigger 从固定 power-law schedule 改为基于 HV 停滞、代理不确定性和 constraint-boundary density 的联合触发。
  - 对越界修复使用 process-safe projection，保留变量间工艺关系。
- 结构创新线索：
  - 构建工业过程数字孪生优化层：historical data alignment、surrogate objective model、safe setpoint optimizer、MCDM selector、control-system adapter、online feedback updater。
  - 将该框架扩展到 blast furnace、electric arc furnace、chemical reactor、wastewater treatment、semiconductor epitaxy 等黑箱工艺参数优化。
  - 与已有 GP uncertainty + RL digital twin 结合：离线 SaMODE 生成 Pareto setpoints，在线 RL 在安全邻域内做微调。
