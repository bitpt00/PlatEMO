# A large-scale multi-objective evolutionary neural network model considering robustness for short-term wind power prediction

## 一句话理解

本文把短期风电预测模型训练改造成大规模多目标神经演化问题：先用 DTNN 将时序切成多个 temporal micro-batches，并用共享权重的时间注意力筛掉非关键时间步；再用 EAET、EVET、EAT 三个目标同时约束跨时间步平均误差、误差方差和全序列误差；最后用 LMMSCSO 在数百到上千维神经网络权重空间中按进化状态切换竞争学习策略，得到兼顾精度和鲁棒性的风电预测模型。

## 问题与动机

- 研究问题：short-term wind power forecasting。风电受复杂环境影响，间歇性和随机性会冲击电网计划、市场竞价和调度，极端条件下问题更严重。来源：Sec. I。
- 现有深度预测模型不足：
  - GRU/LSTM 等顺序处理模型强调历史信息对当前状态的影响，但并非所有历史时间步都有相关性，冗余时间信息会增加计算并降低可靠性。来源：Sec. I。
  - 标准 self-attention 能捕获时间关系，但 `T x T` 对齐矩阵带来高内存和高时间复杂度，不适合 MOEA 需要反复评价网络权重的场景。来源：Sec. II、IV-B。
  - 在线学习通过 concept drift detection 和被动调参增强鲁棒性，但对非高斯风电数据和剧烈波动，调整学习率等外部超参数难以真正改变模型内部预测能力。来源：Sec. I、II。
  - 只用单一全局误差 loss 会让平稳时段的好表现补偿风电 ramp 时段的灾难误差，不能显式惩罚误差集群。来源：Sec. IV-C。
- 大规模优化动机：
  - 神经网络权重高度耦合，decision variable analysis 类方法若只优化部分权重会导致预测失败；
  - problem transformation 类降维难适配高度非线性 NN loss；
  - 需要一种能同时优化全部权重、并在 convergence/diversity 间自适应切换的大规模 MOEA。来源：Sec. II、IV-D。

## 核心理念与算法流程

- 整体架构：
  1. 用 sliding window 将历史风电序列构造成 `T` 个 time-step micro-batches。
  2. DTNN 对每个 time step 输出子序列预测，再拼接为最终预测序列。
  3. 基于各 time step 的预测误差构造三目标大规模 MOO。
  4. 用 LMMSCSO 优化 DTNN 的所有连接层 weights and biases。来源：Sec. IV-A、Fig. 1。
- DTNN temporal micro-batching：
  1. 将序列拆成 `{x_t, y_t}_{t=1}^T`，其中 `x_t` 是第 `t` 个时间步的输入 micro-batch。
  2. temporal attention layer 用共享权重和 element-wise product 计算各时间步的 temporal feature / attention，避免标准 self-attention 的二次复杂度。
  3. 对 `TA_t` 排序，选 top 1/2 作为 key time steps；non-key time steps 不只是降权，而是阻断或重置其 hidden-state 信息传递，以避免冗余或漂移信息累积。
  4. 该 hard-thresholding 不可微，但与不依赖梯度的 MOEA 训练兼容。来源：Sec. IV-B。
- 鲁棒三目标训练：
  1. `EAET`：各时间步误差均值，约束局部 micro-batch 平均精度。
  2. `EVET`：各时间步误差的标准差/方差，惩罚误差在特定波动时段聚集，提升鲁棒性。
  3. `EAT`：拼接后完整序列的全局误差，防止局部均值好但全局序列出现极端偏差。
  4. 单步误差用 MAPE 形式，但分母使用 installed capacity `pc`，避免风电输出趋近 0 时 MAPE 发散。来源：Sec. IV-C。
- LMMSCSO 训练流程：
  1. 初始化 `N` 个权重粒子及速度。
  2. 用 DTNN 评价每个粒子的三目标值。
  3. 计算 composite fitness，由 average ranking (AR)、global damage (GD) 和 crowding distance (CD) 综合 convergence 与 diversity，fitness 越小越好。
  4. 随机成对竞争，按 evolutionary state 决定 winner/loser 判定策略。
  5. loser 从对应 winner 学习；winner 也向全局 leader 演化，以利用当前种群全局信息。
  6. 用 fast non-dominated sorting 和 fitness-based retention 做 elite selection。来源：Sec. IV-D、Algorithms 1-2。
- evolutionary state：
  - 根据 paired particles 的差异和 population average difference 更新 `ES(g)`。
  - `ES=1` 表示种群差异显著、算法偏向 convergence，此时优先用 dominance relationship 判定 winner，无支配关系时再用 fitness。
  - `ES=2` 表示需要增加 diversity，此时使用 fitness 作为配对竞争标准，并通过 winner/leader 更新扩大搜索空间。
  - 该状态调节在不改变 `O(ND)` 复杂度阶的前提下，为高维权重搜索增加 convergence/diversity 平衡。来源：Sec. IV-D。

## 实验证据

- 数据与设置：
  - Case 1：Ontario, Canada, IESO 公共数据，1 小时分辨率；Dataset 1 为 2020-01-01 至 2020-03-31，Dataset 2 为 2020-07-01 至 2020-09-30。
  - Case 2：Spain, ENTSO-E 公共数据，15 分钟分辨率；Dataset 1 为 2023-05-01 至 2023-07-31，Dataset 2 为 2023-10-01 至 2023-12-31。
  - 训练/验证/测试划分为 70%/15%/15%。来源：Sec. V-A。
  - DTNN 参数：batch size `B=30`，sliding steps `10`，输入节点 `L` 分别为 `14/9/8/6`，hidden nodes 为 `10/12/10/10`。LMMSCSO：population `N=100`，iterations `G=300`。来源：Table 3。
  - MOEA 对比：NSGA-III、SPEA2、LMEA、WOF、LMOCSO；population 100，termination 30000 evaluations，每个数据集 30 次独立运行，Wilcoxon rank-sum test 显著性 0.05。来源：Sec. V-B。
  - 预测模型对比：ELM、GRU、LSTM、CNN、TCN、Informer、O-LSTM；消融模型包括去 temporal attention 的 STNN 和单 Huber loss 的 SODTNN。来源：Sec. V-B。
- LMMSCSO 优化效果：
  - 决策变量维数分别为 `1101/817/681/541`。来源：Table 4。
  - HV 上 LMMSCSO 在四个数据集均为最高：`0.9211/0.9522/0.9855/0.9892`；相对 NSGA-III、SPEA2、LMEA、WOF 在 4/4 数据集显著更好，相对 LMOCSO 在 3/4 显著更好、1/4 相近。来源：Table 4。
  - Spacing 上 LMMSCSO 在四个数据集均最低：`1.47e-4/1.29e-4/1.71e-4/1.48e-4`，说明 Pareto 解更均匀。来源：Table 5。
  - 运行时间上 LMOCSO 最快，LMMSCSO 稍慢但仍远低于 NSGA-III/SPEA2/WOF，且远低于 LMEA；例如 Case 1 Dataset 1 为 LMOCSO `127.47s`、LMMSCSO `163.16s`、LMEA `16547.91s`。来源：Table 6。
  - 作者认为 LMEA/WOF 在 NN 权重优化上失败，原因分别是变量聚类/部分优化导致预测失败，以及 transformation 难处理高度非线性 loss。来源：Sec. V-D。
- 预测效果：
  - Table 7 中 DTNN 在多数主要误差指标上取得最佳或接近最佳结果；例如 Case 1 Dataset 1 的 `MAPE/RMSE/MAE/R2/CORR` 为 `3.41% / 208.42MW / 156.83MW / 95.66% / 97.83%`，Case 2 Dataset 2 为 `0.63% / 194.82MW / 131.82MW / 99.63% / 99.82%`。来源：Table 7。
  - Case 1 Dataset 1 上，去掉 temporal attention 的 STNN 相比 DTNN，MAPE/RMSE/MAE 分别增加 `19.65% / 15.01% / 19.58%`。来源：Sec. V-D。
  - 去掉 MOO 框架、改用单 Huber loss 的 SODTNN 在所有数据集上预测精度下降，说明三目标 loss 有贡献。来源：Sec. V-D。
  - 相对 ELM、GRU、LSTM、CNN、O-LSTM、TCN、Informer，DTNN 在 RMSE 指标上的平均改进分别为 `26.41% / 30.06% / 24.46% / 30.22% / 15.85% / 21.28% / 8.01%`。来源：Sec. V-D。
- 鲁棒性：
  - 在归一化数据上加入 5%、10%、15%、20% uniform stochastic disturbances，DTNN 在多数 MAPE/RMSE/R2 指标上保持最优或近最优。来源：Sec. V-D、Table 8。
  - 作者总结随机扰动从 5% 到 20% 时，预测精度改善幅度从 `10.2%` 提升到 `15.6%`，说明扰动越强，鲁棒设计优势越明显。来源：Conclusion。
  - 用 Page-Hinkley test 在 Case 1 Dataset 1 的测试集检测到 16 个 concept drift points；前 10 个 drift points 上，DTNN 几乎全部取得最低 absolute error，支持其面对高波动时更稳。来源：Sec. V-D、Figs. 6-7。
  - 作者结论称整体 RMSE forecasting error 平均降低 `12.5%`。来源：Abstract、Conclusion。

## 局限与未来工作

- 初始训练阶段需要大量 MOEA 迭代，在低功耗 edge devices 上实时重训练可能困难。来源：Conclusion。
- 当前 temporal attention 采用固定排序和 top 1/2 pruning ratio，可能不适合所有非平稳程度不同的 wind regimes。来源：Conclusion。
- 作者未来计划引入 surrogate models 加速优化，并基于 real-time data drift detection 设计自适应过滤阈值。来源：Conclusion。
- 本文主要是离线训练与扰动/漂移测试，没有给出在线滚动部署、低延迟重训或电网调度闭环验证。
- 使用 MOEA 直接优化 NN 权重适合中小型 DTNN；若扩展到深层 Transformer 或大模型，权重维度和评价成本会迅速上升。
- Top-half hard filtering 是不可微的，虽适合 MOEA，但最终阈值选择对不同数据集和风况的敏感性仍需进一步验证。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“时间微批鲁棒多目标神经演化预测”：抽象为 temporal micro-batch filtering、EAET/EVET/EAT 鲁棒三目标训练和 evolutionary-state competitive weight optimization 的预测架构。
- 暂留在论文卡中的方法、原理或架构启发：
  - 在预测鲁棒性中，误差方差目标比简单 Huber outlier penalty 更适合处理“某些时间段连续犯错”的问题；
  - 不可微的 hard temporal filtering 可以通过 MOEA 而非梯度下降训练，为模型结构加入更强规则；
  - NN 权重高度耦合时，变量分组/降维型 LSMOEA 可能比经典 MOEA 更差，不能默认“专门大规模算法”一定适合神经训练。
- 局部创新线索：
  - 将固定 top 1/2 时间步过滤改为 drift severity、attention entropy 或 validation robustness 自适应阈值；
  - 用 CVaR、ramp-period error、extreme-event recall 或 reserve-cost-aware loss 替换/补充 EVET；
  - 对 LMMSCSO 的 evolutionary state 加入 objective-space stagnation、spacing 变化或 validation error signal；
  - 用 surrogate-assisted MOEA 或权重低秩表示降低 DTNN 权重演化成本。
- 结构创新线索：
  - “temporal filter -> robust multiobjective loss -> large-scale neuroevolution -> drift/noise audit”可迁移到光伏、负荷、交通流、工业过程和金融风险预测；
  - 与概率预测结合时，可把 EAET/EVET/EAT 扩展为 pinball error mean、interval-width stability 和 global calibration loss。
