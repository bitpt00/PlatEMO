# An Indicator-Based Evolutionary Algorithm for Large-Scale Constrained Multiobjective Optimization

## 一句话理解

本文提出 ILCMO，用可行性导向指标保存优质可行解，用含两个动态松弛约束边界的不可行辅助指标在可行解周围均匀探索，再配合变量分组 DE 加速高维搜索，从而求解大规模约束多目标问题。

## 问题与动机

- 研究问题和场景：large-scale constrained multiobjective optimization problems (LSCMOPs)，即决策变量维度通常 `D >= 100`，同时存在复杂约束和多目标冲突。
- 现有算法为什么不足：
  - 多数 CMOEA 主要面向小规模变量，直接扩展到高维时会因维数灾难、可行域难找和多样性丢失而退化；
  - 传统 SBX/PM/DE/PSO 往往在完整变量空间中搜索，难以高效生成高质量可行解；
  - 大规模变量会让小而离散的可行域更难定位，算法需要利用 promising infeasible solutions 从不同方向靠近多个可行区域；
  - 一些 LSCMOP 的目标与约束关系复杂，目标空间充满 local infeasible regions，种群容易聚集在局部区域。
- 本文希望解决什么：同时解决复杂约束处理和大规模变量搜索效率，在可行性、收敛性和多样性之间建立可解释的质量评价与 reproduction 机制。

## 核心理念与算法流程

- 核心理念：用两个种群承担互补任务。`P1` 通过 feasibility-oriented indicator `I_s` 把搜索稳稳推向可行非支配区域；`P2` 通过 infeasibility-assisted dynamic indicator `I_d` 在可行解周围的松弛约束边界内保持均匀搜索，持续提供可帮助跳出局部可行域的不可行信息。高维搜索则由变量分组 DE 降低子代生成维度并逐步回到完整空间精修。
- 主要流程：
  1. 初始化两个规模为 `N` 的种群 `P1`、`P2`，并生成均匀 weight vectors。
  2. 每代分别对 `P1` 和 `P2` 执行 VGDE reproduction，得到 `Off1` 和 `Off2`。
  3. `P1` 用 `P1 ∪ Off1 ∪ Off2` 更新，主要依赖 `I_s` 保留 feasible nondominated solutions。
  4. `P2` 用 `P1 ∪ P2 ∪ Off1 ∪ Off2` 更新，显式引入 `P1` 的可行信息来构造探索/开发区域。
  5. `P2` 先用 `I_d` 筛出 exploitation regions 内的个体；若超过规模 `N`，按 weight-vector subregions 删除最拥挤子区中 fitness 最差个体。
  6. 终止时输出 `P1`。
- 关键组成部分：
  - `I_s` feasibility-oriented static indicator：`I_s(x|P) >= 0` 当且仅当 `x` 是 feasible nondominated solution；可行解优先于不可行解，不可行解中低 CV 优先。
  - `I_d` infeasibility-assisted dynamic indicator：用 `alpha_t` 定义局部搜索边界，用 `beta_t` 将局部区域分成 exploration/exploitation regions；`alpha_t` 从初始最大 CV 逐步降到 0，`beta_t` 随可行比例调整且 `beta_t <= alpha_t`。
  - VGDE：先按 indicator fitness 将种群分成较优子集 `Se` 和较差子集 `Sp`；对 `Se` 用 group-based intralearning DE 增强多样性，对 `Sp` 用 group-based interlearning DE 向 `Se` 精英学习以加速收敛。
  - 动态搜索空间：初期以较大概率只在变量组子空间中生成 offspring，后期逐步转向完整变量空间以微调所有变量。
- 可能被修改的位置：
  - `alpha_0` 可不只取初始最大 CV，可由分位数、历史 CV、可行率或 problem-type recognition 自适应决定；
  - `beta_t` 可结合 crowding、subregion occupancy、CV 分布或可行域发现速度调整；
  - ordered grouping 可替换为变量重要性、约束敏感性、稀疏性或依赖结构分组；
  - `I_d` 的 subregion truncation 可替换为 reference-vector、angle、SDE 或 decision diversity truncation。
- 必须保留的核心：`I_s` 和 `I_d` 分工必须清晰，一个负责可行优质解的稳定保留，一个负责可行解周围不可行/半可行区域的均匀探索；VGDE 需要动态平衡低维子空间搜索和完整空间微调。

## 实验证据

- 测试问题和对比算法：
  - Benchmark 维度从 `D=50` 到 `D=1000`，包括 DASCMOP、LIRCMOP、SDC、LSCM 四套，其中 DASCMOP/LIRCMOP 为 objective-space constraints，SDC/LSCM 为 decision-space constraints。
  - 对比 7 个算法：ICMA、EMCMO、IMTCMO、DGEA、POCEA、CMOCSO、LCMOEA。
  - 指标：IGD、IGD+、HV；每个问题 30 次独立运行，Wilcoxon rank-sum test at 0.05。
  - 参数：VGDE 使用 ordered grouping，`K=4`；`pm=1/D`，`eta_m=20`；2/3 目标问题种群规模为 100/120；最大函数评价为 `2000*D`。
- 主要实验结论：
  - Search behavior：LIRCMOP4, `D=500` 上，`P2` 后期覆盖 CPF 周围不可行区域，帮助 `P1` 从局部 CPF 改善到更完整 CPF。
  - Generalization：SDC2、SDC3、DASCMOP3 变体上，ILCMO 在所有 variant functions 上优于或不劣于竞争算法；DASCMOP3-1 到 3-5 中 ILCMO 输出种群可行比例保持 `100%`，DGEA 从 `31.4%` 降到 `9.5%`。
  - DASCMOP：ICMA、EMCMO、IMTCMO、DGEA、POCEA、CMOCSO 在所有 test instances 上差于 ILCMO，且都出现无法找到可行解的情况；LCMOEA 在 IGD/IGD+/HV 上分别只有 3/2/1 个函数优于 ILCMO，21/23/23 个函数差于 ILCMO。
  - SDC：ILCMO 在 45 个函数中 IGD、IGD+、HV 分别有 32、33、31 个 best results。
  - LSCM：ILCMO 在 36 个函数中 IGD、IGD+、HV 分别有 21、21、16 个 best results；ECDF 曲线初期最陡且始终位于顶部。
  - Small-scale CMOP：`D=50` 的 LIRCMOP/DASCMOP/SDC 上，ILCMO 总体在 IGD、IGD+、HV 上排名靠前；虽然 LIRCMOP 不完全理想，但作者认为仍可接受。
  - Real-world application：grid-connected microgrid dispatch，`D=144`，population size 100，function evaluations `10^6`；ILCMO 在 IGD、IGD+、HV 上显著优于所有 7 个 peer algorithms，DGEA 30 次运行均未找到可行解。
- 消融或机制证据：
  - `I_d` 双边界消融：`ILCMO_0_0` 最差，说明只优化约束会陷入局部；`ILCMO_A_A` 类似传统 epsilon 方法，缺少 exploitation 会丢失 CPF fragments；完整 ILCMO 显著优于六种边界设置变体。
  - VGDE 搜索空间消融：完整 ILCMO 相比始终完整空间的 `ILCMO_VGDE0`，在 50 个函数上 IGD/IGD+/HV 分别有 35/37/36 个更优；始终低维子空间的 `ILCMO_VGDE1` 最差且部分问题找不到可行解。
  - 分组机制消融：ordered grouping 通常表现最佳；linear grouping 只在 LSCM 这类变量天然有序的问题上表现较好。
- 证据边界：
  - 许多表格和参数敏感性结果在 supplementary material，当前 Markdown 只有正文摘要和解释；
  - ILCMO 在 LIRCMOP5-8 随维度增加可能弱于 CMOCSO/EMCMO，原因是初始最大 CV 很小或为 0，导致 `alpha_t` 定义的 local search regions 无法增强局部多样性；
  - 在 SDC4/6/13 中，当可行解很少时，`P2` 可能过度关注目标并陷入无助于找到 CPF 的不可行区域。

## 局限与未来工作

- 作者明确说明的局限：
  - `I_d` 的有效性高度依赖 initial solutions 的 maximum constraint violation，即初始 `alpha` 设置；
  - 某些复杂 LSCMOP 上仍会得到较差指标值；
  - 当前未处理 expensive、multimodal、dynamic 等更复杂属性。
- 作者未来工作：
  - 研究更合适的 initial `alpha` 设置；
  - 进一步分析 LSCMOP 的挑战并设计更有效机制；
  - 扩展到 expensive、multimodal、dynamic constrained MOP。
- 我们认为仍需确认的问题：
  - 如果初始种群 CV 范围极小，是否需要用外部采样或约束放大机制设置 `alpha_0`；
  - `beta_t` 只由 feasible ratio 控制，是否足以反映局部可行域数量、大小和分布；
  - ordered grouping 对变量乱序、强变量依赖或黑箱变量含义未知问题是否稳定；
  - `P2` 计算 budget 是否可以随 `P1` 可行域发现状态自适应调整。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“双边界不可行辅助指标与分组 DE”，因为它把约束处理和高维搜索耦合成可直接迁移的结构：可行主种群保真、不可行辅助种群局部均匀搜索、动态变量组子空间 reproduction。
- 暂留在论文卡中的方法、原理或架构启发：
  - `I_s >= 0` 作为 feasible nondominated detector 可用于其他环境选择器；
  - `alpha_t` 和 `beta_t` 可看成两个动态半径，一个圈定 local search regions，一个调节 exploration/exploitation；
  - 高维约束问题的 reproduction 不宜一直低维，也不宜一直全维，动态过渡是关键。
- 局部创新线索：
  - 用 CV 分位数或可行域发现事件更新 `alpha_t`，缓解初始最大 CV 过小；
  - 将 `beta_t` 与 subregion density 或 infeasible archive contribution 绑定；
  - 用变量约束敏感性分组替代 ordered grouping。
- 结构创新线索：
  - 构建“feasible elite population + infeasible local-search population + dynamic grouped variation”的通用 LSCMOP 框架；
  - 将 `I_d` 的 exploitation/exploration region 概念移植到代理辅助、动态约束或多模态约束优化。
