# A multi-stage evolutionary algorithm based on finite state machine theory for constrained multi-objective optimization problem

## 一句话理解

论文提出 FSM-CMO：把约束多目标进化搜索拆成四个状态，并用有限状态机根据种群非支配比例、HPop 可行非支配解、状态往返计数和评价进度触发切换。MPop 作为最终输出种群始终接受可行性/收敛/分布选择，HPop 在不同状态下分别承担多样性探索、无约束 UPF 推进、狭窄可行边界稀疏探索和最终分布修正。

## 问题与动机

- 研究问题：
  - CMOP 需要同时平衡 feasibility、convergence 和 diversity；
  - 多阶段 CMOEA 能把搜索任务拆开，但“什么时候切换阶段”与阶段内部策略同样关键；
  - 现有 PPS、ToP、CMOEA-MS 等多阶段方法多依赖固定阈值、固定阶段或少数触发规则；
  - 复杂可行域、离散可行域、大不可行屏障和狭窄可行域中，错误阶段策略会浪费评价预算并降低最终分布。
- 本文希望解决什么：
  - 用 FSM 把多阶段搜索表述成有限状态和可解释事件；
  - 让 stage switching 从“固定阶段”变为“事件响应”；
  - 在 MPop/HPop 双种群框架中按当前状态启用不同 HPop 策略；
  - 给不同约束景观匹配不同状态：早期探索、跨越不可行区、细搜边界、最终均匀化。

## 核心模型与算法流程

- 总体框架：
  - 初始化 `MPop` 和 `HPop`，`state=1`，`a=0`，`count=0`；
  - 每轮根据当前 state 执行对应策略；
  - 每隔固定检查间隔执行 Algorithm 4，更新 `rho_M0/rho_H0`、`a`、`count` 和 state；
  - 最终输出 `MPop`。
- MPop 更新：
  - 先合并 `H=MPop ∪ Q`，提取可行解集合 `Sc`；
  - 若 `|Sc|=N`，直接作为 `MPop`；
  - 若 `|Sc|>N`，对可行解做基于原始 MOP 的非支配排序，再用权重向量关联、最拥挤子区和 Tchebycheff 值删除冗余解；
  - 若 `|Sc|<N`，用 C-TAEA 定义的 MOP 对不可行解排序补齐，再删除高 CV 解；
  - 因此 `MPop` 始终承担最终可行性、收敛和分布质量。
- HPop 更新：
  - State I：按权重向量子区从 `HPop ∪ Q` 中补充 MPop 稀疏子区，强调多样性支援；
  - State II：从 `Q` 中按 SPEA2 选择 `N` 个解，不考虑约束，推动 HPop 接近 UPF；
  - State III：从 `Q` 中按稀疏评价 `F` 选择 `N` 个解，支援狭窄可行边界覆盖；
  - State IV：把 HPop 分成两半，`P1` 用 `SPEA2+CDP`，`P2` 用 SPEA2，再合并为新 HPop。
- FSM 状态与事件：
  - 输入状态量包括 `rho_M0/rho_M`、`rho_H0/rho_H`、`HPop_nd`、`a`、`count`、NFE；
  - `rho_M` 和 `rho_H` 是 MPop/HPop 中非支配解比例；
  - `alpha=0.05` 判断比例变化是否显著；
  - event1：`|rho_M-rho_M0|>alpha`，State I 仍有明显变化，保持/回到 State I；
  - event3：`|rho_M-rho_M0|<=alpha`，State I 停滞，转向 State II；
  - event4：State II 中 MPop 停滞且 HPop 已找到可行非支配解或 HPop 也停滞，回到 State I；
  - event5：`count>=2`，State I/II 往返后仍未有效改善，进入 State III；
  - event6：`NFE>=0.8*maxNFE`，进入 State IV 做最终分布调整。
- 四个状态：
  - State I：初始探索。按 `rho_m/rho_h` 决定第一个 parent 来自 MPop 还是 HPop；第二个 parent 早期更可能来自 MPop，概率为 `exp(-NFE/maxNFE)`，后期更可能来自 HPop；用 GA 生成 offspring。
  - State II：大不可行区穿越。两个 parent 都从 HPop 选，HPop 忽略约束朝 UPF 推进，MPop 通过 `UpdateMPop` 接收可用信息。
  - State III：当前可行边界细搜。首次进入时 `HPop <- MPop`；用 DE 生成 offspring；用 binary tournament 和稀疏评价 `SE` 选择；`a mod 2` 控制 `F` 在 `SE` 和原始目标之间切换。
  - State IV：最终均匀化。HPop 分两半分别做 constrained/unconstrained 评价，再用 SPEA2 truncation 调整距离分布，提升 CPF 覆盖均匀性。
- State III 的 SE 指标：
  - 每个目标先做 min-max normalization；
  - 邻居数 `k=floor(sqrt(N)+1)`；
  - 距离使用 `sqrt(sum_i max(0, f_i(y)-f_i(x))^2)`，只统计邻居在归一化目标上差于或远离当前解的正向差；
  - 邻域 `N(x)` 由距离 rank 前 `k` 个解构成；
  - `SE(x)=1/(dist(x,x')+2)`，距离越大 `SE` 越小，表示解处于更稀疏区域；最小化 `SE` 可偏向稀疏区域。
- 复杂度：
  - State I 近似 `O(mN^2)`；
  - SPEA2 truncation 和部分环境选择可达 `O(N^3)`；
  - 作者将总体复杂度归为 `O(N^3)`，并指出高维问题可能出现截断策略瓶颈。

## 实验证据

- 实验设置：
  - 平台为 PlatEMO；
  - benchmark 包括 C-DTLZ/DC-DTLZ、MW、LIR-CMOP、DAS-CMOP，共 47 个问题；
  - 真实问题包括 14 个 RWCMOP，如 Vibrating Platform、Welded Beam、Speed Reducer、Water Resources、Two Reactor 等；
  - baseline 7 个：C-TAEA、CMOEA_MS、CMOEMT、CMOES、DCNSGAIII、NSBiDiCo、tDEACPBI；
  - 每个实例独立运行 30 次；DTLZ/MW 最大评价 100000，DAS-CMOP 最大评价 200000；
  - 指标为 IGD 和 HV，统计用 Wilcoxon rank-sum test，显著性水平 0.05。
- 参数敏感性：
  - 采用 Taguchi `L25(5^4)` 设计分析四个控制因子；
  - 最优设置为 `alpha=0.05`、State IV 触发比例 `0.8`、`count=2`、检查间隔 `50`；
  - Range analysis 显示重要性顺序为 `D-C-A-B`；
  - ANOVA 中检查间隔 D 贡献率 `42.98%`，count 阈值 C 贡献率 `21.32%`，A/B 约 `16%-17%`，所有因素 `p<0.001`。
- SE vs crowding distance：
  - 只把 State III 的 SE 换成 crowding distance 得到 `FSM-CMO_cd`；
  - 在 21 个窄/断裂/复杂约束问题上，FSM-CMO 在 IGD 和 HV 均取得 `0/18/3` 的显著比较结果，即 18 个显著优于变体、3 个相当；
  - 优势主要出现在 LIR-CMOP 和 DAS-CMOP。
- HPop 贡献分析：
  - MW11 中 State IV 贡献率达到 100% 并显著改善 IGD/HV，说明最终分布修正有价值；
  - LIRCMOP6 中 State II 的 HPop 贡献率上升伴随 IGD/HV 改善，State III 后又出现性能跳跃，说明大不可行区穿越和窄可行边界覆盖都起作用。
- Benchmark 结果：
  - DTLZ 上 FSM-CMO 对多数 baseline 在 IGD/HV 上赢多输少，例如 IGD 对 C-TAEA、CMOEMT、NSBiDiCo 的 `+/-/=` 为 `0/10/0`，对 DCNSGAIII 为 `1/8/1`；
  - MW 上 FSM-CMO 获得 10 个 IGD best 和 8 个 HV best；在 MW9 等窄且分离的可行区上覆盖更完整；
  - LIR-CMOP 上 FSM-CMO 对 C-TAEA、DCNSGAIII、tDEACPBI 等在 IGD/HV 上几乎全胜，对多任务或均匀搜索类方法也整体占优；
  - DAS-CMOP 上 FSM-CMO 的 IGD 优势明显，HV 也保持强竞争；DAS-CMOP5/7/8 上其它算法在局部分布或 decomposition penalty 上有局部优势。
- 真实工程问题：
  - 14 个 RWCMOP 只报告 HV；
  - FSM-CMO 在 8 个问题上达到最高 HV，包括 Vibrating Platform 和 Welded Beam；
  - Two Reactor Problem 中 C-TAEA 和 CMOES 返回 NaN，而 FSM-CMO 取得 `3.0444e-2` HV；
  - win/tie/loss 汇总显示 FSM-CMO 相对 tDEACPBI 为 `0/9/6`，相对 CMOEA_MS 为 `1/14/0`，相对 C-TAEA 为 `0/12/1`。
- 消融实验：
  - 移除四个 state 分别得到 FSM-CMO_I/II/III/IV；
  - 完整 FSM-CMO 在四个测试套件平均 Friedman rank 均最好：DTLZ `1.01`、MW `1.49`、LIR-CMOP `2.49`、DAS-CMOP `1.41`；
  - 移除 State II 在 DTLZ/MW 上退化最大，说明其处理大不可行区重要；
  - 移除 State III 在 LIR-CMOP 上平均 rank 从 `2.49` 降到 `4.58`，说明窄可行域细搜重要；
  - 移除 State IV 后各套件均明显退化，作者强调最终均匀覆盖是关键。

## 局限与未来工作

- 作者明确局限：
  - state switching factors 依赖经验设定，可能限制适应性；
  - FSM-CMO 只能在当前 state 更新完成后才判断是否切换，若某个 state 对当前问题无用，会引入额外开销；
  - 高维场景中 SPEA2 truncation 和 `O(N^3)` 环境选择可能成为瓶颈；
  - 使用近似 truncation 可减轻成本，但会损伤分布质量。
- 作者未来方向：
  - 优化 state switching factors；
  - 设计更全面、可定制的 stage strategies；
  - 在动态约束优化中把环境变化建模为触发事件；
  - 加入 re-exploration state，用于环境变化后快速重新定位可行域和 PF。
- 我们认为仍需确认的问题：
  - `rho_M/rho_H` 只看非支配比例，不能直接区分可行性改善、目标收敛或分布补全；
  - `count>=2` 和固定 50 轮检查较粗，可能导致无用往返；
  - State III 的 `SE=1/(dist+2)` 文本说“sum of distances”，公式却只呈现一个邻居距离，复现时需核对代码；
  - State IV 固定在 `0.8*maxNFE` 触发，若前期搜索失败，后期均匀化可能过早；
  - 真实问题只用 HV，无法单独判断可行性发现、收敛和均匀性贡献。

  - 用 state survival rate 反向调整 event threshold；
  - 将 State IV 的固定 80% 触发改为“CPF 覆盖不足但收敛稳定”触发。
- 结构创新线索：
  - 建立可插拔 FSM-CMO 控制器：
    `state definitions + event detector + state-specific mating/selection/operator + transition log`；
  - 在 dynamic CMOP 中增加 `environment-change -> re-exploration state`；
  - 在昂贵 CMOP 中把 State II/III 改成 surrogate-assisted 低成本候选生成；
  - 在多目标调度中把 “repair / infeasible crossing / neighborhood polishing / distribution balancing” 映射成 FSM states。
