# A novel large-scale multi-objective particle swarm optimization based on distribution direction of pareto set

## 一句话理解

本文提出 DEMOPSO：每代先用参考向量选目标空间分布均匀的代表解，再在高维决策空间为每个代表解构造并筛选可能指向 Pareto set 的方向，沿保留方向采样形成引导 archive，让 PSO 粒子从这些“PS 分布方向”而不是只从历史最优位置学习。

## 问题与动机

- 研究问题和场景：large-scale multi-objective optimization problems (LSMOPs)，特别是 1000-5000 决策变量的两/三目标连续问题，以及 transformer ratio error estimation (TREE) 真实大规模问题。来源：Abstract、Sec. 4。
- 现有算法为什么不足：
  - 传统 MOEA 多关注目标数扩展，对决策变量维度扩展关注不足；高维决策空间会导致早熟和局部最优。来源：Sec. 1。
  - CC、DVA、problem transformation 和 learning-based meta-search 各有优势，但变量分组/降维/学习方向可能仍难捕捉非线性 Pareto set 结构。来源：Sec. 1。
  - PSO 用于 LSMOP 时，速度更新在高维空间中容易失去优化动量，global best 引导效率下降；过度依赖历史 best 还会削弱决策空间探索，造成多样性不足。来源：Sec. 1。
  - 既有 intra-decision vector sampling 可能沿无效方向采样，浪费评价；单个代表解的双向向量也只可能接近 PS 的少数交点。来源：Sec. 2.2-2.3。
- 本文希望解决什么：低成本估计当前 Pareto set 在决策空间中的分布方向，把高维 PSO 的盲目历史最优学习改为方向筛选、方向采样和 archive 引导学习，从而同时提高收敛与多样性。

## 核心理念与算法流程

- 核心理念：在高维决策空间中，直接问“哪个粒子的历史最优最好”不够；更有效的是先从当前种群抽取覆盖不同目标区域的代表解，再围绕这些代表解探测哪些决策空间方向能产生支配或非劣的新样本，这些方向近似描述了 Pareto set 的局部分布，可作为 PSO 的外部引导。
- 主要流程：
  1. 初始化种群 `P` 和均匀参考向量 `V`。来源：Algorithm 1。
  2. 每代用 K-means 将参考向量分为 `Nc` 个 cluster centers；归一化目标值，按最小角度把种群分配到 cluster；每个非空 cluster 选投影距离最小个体为代表解，空 cluster 用未选个体中角度最小者补齐。来源：Sec. 3.1、Algorithm 2。
  3. 对每个代表解在决策空间构造六个候选方向：向 lower bound 的 `DL`、向 upper bound 的 `DU`、二者反向 `rDL/rDU`，以及 Hadamard product 方向 `HL/HU`。来源：Sec. 3.2、Algorithm 3。
  4. 每个候选方向采一个 trial solution，与原代表解一起做 non-dominated sorting；若 trial 解支配或与代表解互不支配，则保留该方向为 promising direction `Pd`。来源：Sec. 3.2。
  5. 沿保留方向均匀采样 `Ns` 个样本，若样本数超过种群规模则用 NSGA-II 筛成 archive；否则直接使用样本集。来源：Algorithm 1、Sec. 3.3。
  6. 将 archive 与当前种群合并，用 SDE 计算综合 fitness；前半高 fitness 个体作为 guiding particles `Apop`，后半作为 exploration particles `Epop`。来源：Algorithm 4、Sec. 3.3。
  7. `Apop` 中 fitness 最优者为 `gbest`；对每个 `Epop` 粒子，在 `Apop` 中按最小角度选择 `pbest`，再用 PSO 速度/位置公式生成 offspring。来源：Algorithm 4。
  8. 用 RVEA-inspired environmental selection 在 archive、原种群和 offspring 中生成下一代。来源：Algorithm 1、Sec. 3。
- 关键组成部分：
  - 目标空间代表解选择：保证每代 PS 方向探测覆盖不同 PF 区域；
  - 六方向构造：边界方向、反方向和 Hadamard 组合方向共同捕捉 PS 局部几何；
  - dominance-based direction screening：只保留能让样本支配或不劣于代表解的方向，降低盲采样；
  - uniform directional sampling：从 promising directions 产生 archive，引导后续粒子；
  - SDE fitness 分层：同时考虑 convergence 和 diversity，把合并种群分为 guide/explorer；
  - angle-based pbest pairing：每个 explorer 跟随目标/方向上最近的 guide，避免所有粒子只追单一 global best。
- 可能被修改的位置：
  - 代表解选择可替换为参考向量、HV contribution、knee-aware 或 decision-space niche；
  - 候选方向可加入 PCA/LPCA、变量重要性、历史成功方向、梯度/代理方向或随机正交方向；
  - direction screening 可改为 epsilon dominance、R2 contribution、可行性改善或 surrogate 预测；
  - archive 筛选可由 NSGA-II 换成 RVEA、SPEA2、reference-vector selection 或 dual-space selection；
  - PSO pairing 可按目标角度、决策距离、方向相似度或子区域贡献选择 `pbest`。
- 必须保留的核心：代表解覆盖、决策空间方向构造、方向样本筛选、方向采样 archive、archive-guided PSO 学习。若只保留普通 PSO 或只做随机方向采样，就失去“用 PS 分布方向补偿高维 PSO 盲目性”的设计。

## 实验证据

- 测试问题和对比算法：
  - LSMOP1-9：两/三目标，决策变量 1000、3000、5000；用 IGD 评价。来源：Sec. 4.4。
  - WFG1-9：两/三目标，1000D、3000D、5000D；用 IGD 评价。来源：Sec. 4.7。
  - TREE1-5：transformer ratio error estimation，二目标，`D=3000`；用 HV 评价。来源：Sec. 4.6、Table 6。
  - 对比算法：DGEA、FDV、LMOCSO、LMOEA_DS、LSMOF、WOF；TREE 上另与 CMOCSO、LERD、LMOCSO、PCPSO 比较。来源：Sec. 4。
  - 设置：LSMOP/WFG 初始种群两目标 `N=196`、三目标 `N=496`，`maxFE=150000`，20 runs；DEMOPSO `Nc=10`、`Ns=10`、`omega in [1,1.5]`、`c1,c2 in [1.5,2.5]`。来源：Table 1。
  - 平台：Intel i9-13900HX、16 GB RAM、Windows、MATLAB R2023a、PlatEMO 4.5。来源：Sec. 4.2。
- 主要实验结论：
  - 方向数敏感性：DEMOPSO_D4 只用四个边界/反向方向，DEMOPSO 加入 Hadamard 的 `HL/HU`；在 27 个 LSMOP two-objective 实例中，除 LSMOP5/8 等困难问题外，六方向策略显著优于四方向，2000D 时优势更明显。来源：Sec. 4.3、Table 3。
  - 采样数敏感性：`Ns=10` 的 DEMOPSO 与 `Ns=20/30` 变体比较，27 个实例中 16 个取得更优 IGD，说明少量定向采样足够且能降低计算开销。来源：Sec. 4.3、Table 4。
  - LSMOP 综合：在 54 个 LSMOP test instances 中，DEMOPSO 获得 36 个最佳 IGD；LMOEA_DS 12 个、LSMOF 3 个、WOF 2 个、DGEA 1 个。Wilcoxon 统计显示 DEMOPSO 相对 DGEA/FDV/LMOCSO/LMOEA_DS/LSMOF/WOF 的 `+/−/=` 分别为 `1/49/4`、`0/54/0`、`0/53/1`、`18/34/2`、`9/40/5`、`4/45/5`，其中符号口径是比较算法相对 DEMOPSO。来源：Sec. 4.4、Table 5。
  - LSMOP 可视化：两目标 LSMOP1/4/9 3000D 和三目标 LSMOP4/8/9 1000D 的图示显示 DEMOPSO 在 convergence 和 diversity 上整体更好；LSMOP9 discontinuous problem 中能找到几乎所有 PS 区域。来源：Figs. 4-5。
  - 收敛曲线：三目标 LSMOP5 1000D 和两目标 LSMOP9 3000D 上，DEMOPSO 的 IGD 收敛趋势优于六个对比算法。来源：Fig. 6。
  - 复杂度与时间：单代 worst-case complexity 为 `O(N*(logN+Nc)+M*N^2)`；作者承认 DEMOPSO 在时间复杂度上不占优，但运行时间在同目标数/维度下较稳定，优化质量可弥补部分缺点。来源：Sec. 4.5、Fig. 7。
  - TREE 应用：TREE1-5 均为二目标 3000D；DEMOPSO 在 HV 上优于 CMOCSO、LERD、LMOCSO、PCPSO 等，TREE2-5 的 final population 支配其他算法，TREE1 中 LMOCSO 收敛接近但多样性较差。来源：Sec. 4.6、Table 7、Fig. 8。
  - WFG 综合：54 个 WFG instances 中 DEMOPSO 获得 40 个最佳 IGD；相对 DGEA/FDV/LMOCSO/LMOEA_DS/LSMOF/WOF 的 `+/−/=` 为 `1/52/1`、`5/48/1`、`0/52/2`、`4/39/11`、`3/47/4`、`1/49/4`。来源：Sec. 4.7、Table 8。
- 消融或机制证据：
  - 六方向 vs 四方向验证 Hadamard 方向能提供更丰富 PS distribution information；
  - `Ns=10/20/30` 验证更多方向采样不一定更好，低成本筛选足够；
  - 可视化和收敛曲线共同支持 direction screening + archive-guided PSO 的收敛/多样性作用。
- 证据边界：
  - 多张关键表为图片占位，逐实例 IGD/HV 数值需要回查 PDF 表格或原始数据；
  - DEMOPSO 没有与去掉 archive-guided PSO、去掉 direction screening、改用随机方向等完整消融逐项隔离；
  - 复杂度不低，作者明确未来要优化 computational time；
  - LSMOP/WFG 是标准 benchmark，TREE 虽有真实背景但仍是 benchmark 式问题，未证明在线工业部署；
  - 代表解与方向筛选默认连续有界变量，离散/强约束/变量顺序无意义场景需要重构。

## 局限与未来工作

- 作者明确说明的局限：
  - DEMOPSO 时间复杂度并不占优，优化质量部分补偿了这一不足。来源：Sec. 4.5。
  - 在部分问题上仍不总是最好，例如 LMOEA_DS 在 WFG1 更优，WFG3 上 LSMOF/DEMOPSO 分别在不同设置下较强，WFG5 部分维度与 LMOEA_DS/FDV 接近。来源：Sec. 4.7。
- 作者未来工作：
  - 优化算法 computational time；
  - 应用于更多 real-world applications。来源：Sec. 5。
- 我们认为仍需确认的问题：
  - direction screening 只用单个 trial sample 判断方向，是否容易受噪声或偶然样本误导；
  - 六个方向是否足以覆盖非轴向、弯曲或多模态 PS；
  - `Nc=10`、`Ns=10` 是否适用于更多目标数或更复杂 PF；
  - archive-guided PSO 与 direction sampling 各自贡献缺少独立消融；
  - 高维变量相关性极强或约束可行域稀疏时，沿方向均匀采样可能产生大量不可行或低质候选。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“Pareto set 方向筛选引导的粒子生成”：抽象为代表解覆盖、决策空间多方向候选、dominance 筛方向、方向采样 archive 和 guide/explorer PSO 学习。
- 暂留在论文卡中的方法、原理或架构启发：
  - direction screening 可作为任何大规模 MOEA 的低成本候选方向过滤器；
  - angle-based pbest pairing 能避免全体粒子追同一 leader；
  - SDE fitness 的 guide/explorer split 可迁移到其他 swarm 或 DE/GA 算子中。
- 局部创新线索：
  - 用多个 trial points 或 surrogate uncertainty 给方向打置信分，而不是一采样一判定；
  - 对弯曲 PS 维护方向历史，形成局部折线/流形方向；
  - 方向池可引入 PCA、随机投影、变量重要性或历史成功移动；
  - `Ns` 可按 direction confidence、cluster 稀疏度或 HV 改善率自适应分配。
- 结构创新线索：
  - “目标空间代表解 -> 决策空间方向探测 -> 方向 archive -> swarm 学习”的结构可迁移到 DE、CSO、GA、EDA 和代理辅助 LSMOP；
  - 与低频频域/变量重要性/双空间双种群搜索结合：方向探测只在低维或重要变量子集执行，降低 `M*N^2` 和采样成本。
