# A Time-Division-Based Constrained Multiobjective Optimization Method for Coal Mine Integrated Energy System Dispatch Problem

## 一句话理解

本文把煤矿综合能源系统日调度看成 432 维、多约束、强耦合 CMOP，先按时间段拆成低维子问题并独立优化，再用随机拼接把各子问题的变量片段合成完整调度解，最后用主种群、动态辅助种群和单目标辅助种群在原问题上修复跨时段约束并逼近 CPF。

## 问题与动机

- 应用场景：coal mine integrated energy system dispatch problem (CMIES-DP)，系统包含 PV、WT、PG、GT、VOHP、WSHP、GSHP、ASHP、AC、EC、ES、TS 等 12 类设备。
- 优化目标：
  - `f1`：最小化运营成本，包括购能成本和设备运维成本；
  - `f2`：最小化弃能成本，包括弃可再生能源和弃关联能源成本。
- 约束：电/热/冷供需平衡、设备输出与能量转换、GT ramp rate、热储能和电储能约束。
- 难点：
  - 日调度以 1 h 为间隔，每台设备 24 维；考虑储能设备 0/1 指示变量和输入/输出变量，总维度为 `24 * (10 + 2*4)=432`；
  - 除 GT ramp rate 只跨相邻时段外，多数约束按时段成立，整体约束数量大；
  - 0/1 指示变量和功率变量乘积带来非线性；
  - 多能源设备在多个等式约束中重复出现，导致变量、目标和约束强耦合；
  - 既有 CMOEA 多面向低维 CMOP，CMIES-DP 专用方法也较少显式分析问题结构。

## 核心理念与算法流程

- 核心理念：利用调度问题的时间可加性做降维。目标函数是各时段求和，除 GT ramp rate 外主要约束也按时段局部成立；因此可以暂时放弃子问题之间的 GT ramp rate，把整日调度拆成若干相邻时间块子问题，先获得较好的局部变量片段，再拼回完整日调度并在原问题上修复所有约束。
- 问题特征分析：
  - Temporal characteristic：当忽略子问题之间的 GT ramp rate 时，`T` 个时段可被划分为 `k` 个子问题，每个子问题包含 `u=T/k` 个相邻时段；
  - Optimization characteristic：用 IMTCMO 生成搜索轨迹并绘制约束 landscape。作者观察到靠近原点 CV 更大，中部存在低 CV 区域容易诱导局部停滞；同时 `f1` 下降时 frontier solutions 的 CV 增大，而 `f2` 与 CV 无明显单调关系。
- 第一阶段：
  - 对每个时间块子问题独立优化；
  - 每个子问题使用两个辅助种群：dynamic auxiliary population `SDAP_i` 和 single-objective auxiliary population `SSAP_i`；
  - `SDAP_i` 用 epsilon technique 处理复杂约束并扩大搜索范围；
  - `SSAP_i` 将输入解的 `f2` 设为 0，相当于单目标优化 `f1` 与约束，用于寻找 `f1` 方向的可行优质片段；
  - 每个子问题分配 `(ra * MaxFES)/k` 评价资源。
- 第二阶段：
  - Random concatenation：对每个新个体，分别从各子问题输出种群中随机选择一个片段，把 `k` 个变量片段拼成完整 24 h 调度解；
  - 由第一阶段 `SDAP` 和 `SSAP` 分别拼接初始化第二阶段的 `DAP` 和 `SAP`；
  - 在原始 CMIES-DP 上同时维护三类种群：
    - `MP`：主种群，用 feasibility priority / CDP 保存可行 Pareto optimal solutions；
    - `DAP`：动态辅助种群，用 epsilon method 利用多样 infeasible solutions，避免陷入局部可行区域；
    - `SAP`：单目标辅助种群，只优化 `f1` 与约束，补充 `f1` 方向的可行解和前沿端点；
  - 三个种群分别生成 offspring，并在环境选择阶段共享 offspring 信息；最终输出 `MP`。
- 后验决策：若决策者无明确偏好，作者示例采用 knee-point 选择：用 PF 两个端点定义极端线，选择到该线距离最大的解作为折中方案。

## 实验证据

- 实验设置：
  - 案例：山西某煤矿 2020 年某冬日的真实 CMIES 日调度数据；冬季热负荷显著高于电/冷负荷，更符合煤矿关联能源供热特征；
  - 对比算法：CCMO、TriP、DGMA、URCMO、CV-TCMOEA、IMTCMO、MMDE EKT ANM；
  - 每个算法 30 次运行，`MaxFES=1,000,000`，population size 100；
  - 平台：PlatEMO / MATLAB，Intel Core i7 CPU，32 GB RAM；
  - 指标：FSR、NSR、IGD、HV；IGD 的参考集为所有算法解集并集中的最优解。
- 机制分析：
  - 第二阶段初始分布中，时间分块初始化得到的 `DAP` 和 `SAP` 比 random initialization 收敛更好；
  - 与不做时间分块、第一阶段直接优化原问题的 `DAP k=1` / `SAP k=1` 相比，时间分块版本位于更好区域；
  - 第二阶段初始 population 的平均 CV 为 2018.63，random initial population 为 21383.59；
  - 第二阶段 `MP` 的平均 CV 最终降为 0，说明原问题阶段可修复第一阶段忽略的跨子问题 GT ramp rate 风险。
- 综合对比：
  - TDCEA 在 IGD 的 mean、standard deviation、max、min 上均最好，Wilcoxon test 显示七个对比算法均显著差于 TDCEA；
  - HV 同样四项统计最好，并显著优于所有对比算法；
  - FSR 上 TDCEA 排名第一，NSR 排名第三，说明可行性和非支配可行解比例也较稳；
  - 分布图中 TDCEA 相比多个对比算法获得更好的收敛/多样性折中，尤其保存更多 `f1` 方向优质解。
- 消融实验：
  - `TDCEA Stage2` 移除第一阶段后收敛差，支持 time-division optimization；
  - `TDCEA no SAP` 收敛接近完整 TDCEA，但丢失更好 `f1` 端点解；
  - `TDCEA no DAP` 和 `TDCEA only MP` 的收敛和多样性都较差，说明 DAP 对复杂约束处理关键；
  - `TDCEA add f2` 虽找到更好 `f2` 解，但整体收敛显著弱于 TDCEA，支持只为 `f1` 设置 SAP 的设计。
- 调度可行性与 CPLEX：
  - 左端点方案优先低成本能源，夜间用低价电补冷，优先利用 VOHP 降低污染罚项；
  - 右端点方案最小化弃能，AC 利用热能供冷，关联能源和可再生能源满发以减少弃能；
  - 与 CPLEX 加权求解 200 个单目标问题相比，TDCEA 在部分区域找到支配 CPLEX 解，其余区域收敛接近；
  - 运行时间：CPLEX 86 s，TDCEA 1322 s；CPLEX 更快，但增加权重时可行解数量不明显增加且时间非线性增长。

## 局限与未来工作

- 作者明确说明的局限：
  - random concatenation 不考虑子问题之间的关系，导致第二阶段需要更多资源修复跨子问题约束；
  - TDCEA 维护三种群，运行时间较长；更长调度周期或更短时间间隔会进一步扩大维度；
  - 实验只使用冬季单日数据，季节和更长周期泛化仍不足。
- 作者未来工作：
  - 研究利用问题特征的更有效拼接方法；
  - 通过调整子问题数量 `k`、机器学习方向学习、硬件加速或数学规划辅助提高效率；
  - 收集其他季节或更长调度周期数据做更细实验。
- 我们认为仍需确认的问题：
  - 第一阶段忽略跨块 GT ramp rate 是否在更激烈负荷变化下会导致难以修复的片段组合；
  - `k` 和 `u` 应如何随调度周期、负荷波动、ramp rate 严格程度自适应；
  - random concatenation 是否可被基于跨块边界状态匹配的拼接替代；
  - `SAP` 只优化 `f1` 的合理性依赖 `f1-CV` 关系，在其他能源系统中需重新分析 landscape。

## 可复用知识与创新线索

- 已建立设计知识：[时段分解随机拼接的约束调度搜索](../02_design_knowledge/K-temporal-block-decomposition-random-concatenation-cmoea.md)。
- 局部创新线索：
  - 将 random concatenation 改为 boundary-aware concatenation：按 GT 出力末端、储能 SOC、冷热负荷余量等跨块边界状态匹配片段；
  - 用可行性预测或快速线性规划修复拼接后的跨块 ramp/storage 约束；
  - 用 landscape 分析自动决定是否为 `f1`、`f2` 或某个约束建立单目标辅助种群；
  - 对 `k` 做动态调度：早期小块快速降维，后期合并相邻时间块做跨块精修。
- 结构创新线索：
  - 把长时域能源/生产/交通调度抽象成“时间块预优化 -> 片段组合 -> 原问题全约束修复”的两阶段 CMOEA；
  - 与商业求解器结合：第一阶段子问题用 MILP/LP 快速求局部候选，第二阶段 EA 拼接并搜索非凸/多目标前沿；
  - 与动态重调度结合：滚动窗口中只重新优化受扰时间块，再和历史块边界匹配拼接。
