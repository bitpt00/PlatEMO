# Multi-objective evolutionary algorithms for solving a green multi-item fixed-charge 5D transportation problem under intuitionistic fuzzy uncertainty

## 一句话理解

论文提出一个三阶段绿色多目标多物品固定费用五维运输问题 GMMFC-5DTP：把司机作为运输决策维度之一，并把司机、车辆、路线共同嵌入碳排目标和碳排约束；再用可行初始化、算术交叉和可行性保持变异支撑改造 NSGA-II/NSGA-III，在印度农产品运输案例中给出成本、碳排、风险、满意度和时间的 Pareto 折中。

## 问题与动机

- 研究问题和场景：
  - 多阶段供应链运输：origin -> distribution center -> warehouse -> destination；
  - 多物品、固定费用、容量约束、路线/交通方式/司机选择同时存在；
  - 参数包括成本、风险、时间、供需和容量等，处于 trapezoidal intuitionistic fuzzy (TrIF) uncertainty；
  - 决策者需要同时考虑 TTC、TCE、TR、TDT 最小化和 TRS 最大化。
- 现有工作为什么不足：
  - 传统 2D/3D TP 或 deterministic TP 多只优化成本，难覆盖多阶段、多物品和固定费用；
  - 绿色运输模型常把碳排视为车辆/距离/路线函数，缺少 driver behavior 对排放的显式建模；
  - classical 或单目标方法通常输出一个 compromise solution，无法给出多目标折中集；
  - 高维运输流量直接随机编码容易产生违反供需、DC/warehouse 容量、conveyance capacity 和阶段流量守恒的候选。
- 本文希望解决什么：
  - 建立 TrIF 环境下的三阶段 GMMFC-5DTP；
  - 让碳排既作为 objective，又作为 `CE <= CEmax` 的硬约束；
  - 设计能在强约束多维流量空间中保持可行性的 MOEA 初始化和变异；
  - 比较 NSGA-II 与更适合多目标/多目标数场景的 NSGA-III。

## 核心模型与算法流程

- 运输网络和决策变量：
  - stage 1: `x_pqetui` 表示 item `i` 从 origin `p` 到 DC `q`，使用 conveyance `e`、route `t`、driver `u` 的数量；
  - stage 2: `y_qretui` 表示 DC `q` 到 warehouse `r` 的对应数量；
  - stage 3: `z_rsetui` 表示 warehouse `r` 到 destination `s` 的对应数量；
  - 约束覆盖 origin supply、DC/warehouse storage capacity、destination demand、各阶段 conveyance capacity 和跨阶段流量平衡。
- 司机感知的碳排建模：
  - 以前车辆-路线排放常用 `3 - (v_e + r_t)` 类效率因子；
  - 本文加入 driver efficiency `d_u`，形成 `4 - (v_e + r_t + d_u)`；
  - 每条 stage arc 的排放近似为 `E_e_CO2 * (4 - (v + r + d)) * distance * shipped_quantity`；
  - 该项同时进入 TCE 目标和 `CEmax` 约束。
- 不确定性处理：
  - 运输成本、风险、时间、供需和容量等参数用 TrIF 数表示；
  - 通过 expected value criterion 将 TrIF 模型转化为 crisp MOTP；
  - 之后在 crisp feasible region 上执行 MOEA。
- 改造 NSGA-II/NSGA-III：
  - Algorithm 1 生成 feasible initial population：按阶段和物品随机选择 origin/DC/warehouse/destination、conveyance、route、driver，并分配 `min(remaining supply, remaining demand/capacity, remaining conveyance capacity)`，逐步扣减库存和容量；
  - arithmetic crossover 使用凸组合，作者认为在 convex feasible region 与可行父代前提下能保持可行；
  - Algorithm 2 mutation 在每个 stage 内选一个 item，抽取两个正流量位置，令 `q2 <= min(q1)`，通过交换/重分配 conveyance、route、driver 对应列，把流量从原位置移到新位置，保持总量和容量结构；
  - NSGA-II 用 crowding distance，NSGA-III 用 reference-point/reference-vector 机制，更适合本文五目标运输场景的分布维护。
- 可能被修改的位置：
  - driver/route/vehicle efficiency 函数的具体形式；
  - TrIF expected value criterion 与风险态度参数；
  - 初始化中的随机分配顺序、容量扣减策略和 stage 顺序；
  - mutation 中新 route/driver/conveyance 的选择分布；
  - NSGA-III reference point 数量、population/generation 和约束处理方式。
- 必须保留的核心：
  - 司机行为必须进入碳排因子，而不是只做后验解释；
  - 碳排要同时作为目标和约束，才能表达政策/监管边界；
  - 多阶段运输解用 stage-wise allocation matrices 表示，且初始化和变异都围绕供需/容量守恒设计；
  - 结果解释要同时看 cost-emission-risk-service-time 的折中，而不是单看成本。

## 实验证据

- 实验设置：
  - 真实案例为印度农产品运输，物品包括 wheat 与 rice；
  - origins: Amritsar、Rohtak、Bhopal；
  - DCs: Chandigarh、Delhi、Nagpur；
  - warehouses: Varanasi、Patna、Ranchi；
  - destinations: Gaya、Kolkata、Guwahati；
  - conveyances 包括 trucks 和 trains，routes 两类，drivers 两类；
  - 距离来自 Mappls/Indian Railways 等来源，碳排和供需/容量等参数由表格给出并转为 crisp 值。
- 单目标参考与参数：
  - Table 19 给出目标单独优化参考：TTC `323965.9`，TCE `6569.71`，TR `57.14583`，TRS `1800`；
  - `CEmax` 取 `7725`，作为多目标优化中的总碳排上限；
  - TOA 参数表给出 population、iteration、crossover/mutation 参数候选，正文后续用相同设置比较 NSGA-II/NSGA-III。
- NSGA-II 与 NSGA-III：
  - modified NSGA-II 产生 4 个 Pareto solutions，其中只有 2 个满足 CE constraint；
  - modified NSGA-III 在 population size 100 下识别 98 个 high-performance trade-off solutions；
  - Table 22 中 NSGA-III 代表解包括：
    - 较低成本：`(331564.2819, 7686.023, 130.995, 1339.806, 618.79)`；
    - 较低碳排：`(358357.7884, 6600.529, 128.666, 1365.964, 830.83)`；
    - 较低风险：`(393075.5765, 7669.492, 62.741, 1323.617, 797.019)`；
    - 高满意度：`(401509.6588, 7674.330, 120.136, 1769.259, 926.82)`；
    - 折中解：`(367045.1726, 6886.265, 88.89, 1579.364, 1005.3937)`。
- 与其它算法/方法比较：
  - Table 23 中 GP 和 FPT 为单解方法，HGA、NSDE-R、AL-NSGA-III、MOEA/D、SPEA2 等给出不同数量解；
  - 本文 NSGA-III 报告 98 个解、约 8 s，NSGA-II 2 个 CE-feasible 解、约 3.836 s；
  - 作者指出多项 NSGA-III 解支配 NSGA-II、NSDE-R 或 SPEA2 示例解。
- 碳排约束的作用：
  - 去掉 CE constraint 后可得到更低成本但更高排放的解；
  - 例：受约束解 `(358357.7884, 6600.529, 128.666, 1365.964, 830.83)` 与无约束解 `(349357.27, 8070.98, 90.266, 1630.36, 957.7837)` 对比，成本下降不大但排放显著上升；
  - 说明 `CEmax` 不是装饰性约束，会改变可行前沿结构。
- 司机/车辆/路线影响：
  - Case 1 新车辆、平滑路线、经验司机时，TCE 区间约 `4476-5155`；
  - 单个因素退化的 Cases 2-4 通常把 TCE 推高到约 `5800-6700`；
  - Case 5 旧车辆、粗糙路线、低经验司机时，TCE 达到约 `8700-10100`；
  - 作者据此强调司机行为可以成为绿色运输决策变量，而不是仅作为管理解释变量。
- 敏感性分析：
  - 限制 cost 使 TTC 接近 `330000`，但 TCE/TR 上升、TRS 下降；
  - 限制 CE 使 TCE 接近 `6580`，成本约 `360000`，TR 和 TRS 变差；
  - 限制 risk 使 TR 接近 `60`，但 TTC/TCE 上升；
  - 限制 retailer satisfaction 使 TRS 接近 `1800`，但成本、排放和风险提高；
  - 供需、DC/warehouse、conveyance 容量加倍后，TTC、TCE、TR、TRS 基本近似线性放大。
- 性能指标：
  - `HV(NSGA-III)=0.5`，`HV(NSGA-II)=0.338`；
  - `Cov(NSGA-III, NSGA-II)=0.5`，`Cov(NSGA-II, NSGA-III)=0`；
  - `GD(NSGA-III)=0.46388`，`GD(NSGA-II)=6.5577`；
  - 作者据此认为 NSGA-III 在收敛、覆盖和多样性上都更优。

## 局限与未来工作

- 作者明确说明的挑战：
  - 实际数据的 availability 与 accuracy 会影响模型可靠性；
  - feasible initialization 面向本文结构定制，推广到其它运输结构不一定直接可用；
  - EA 参数调节仍重要，population/generation 变化会影响结果；
  - 当前模型多为静态供需和静态运输条件；
  - retailer satisfaction 与 driver performance 存在 subjective estimation；
  - 大规模实例存在计算复杂度压力；
  - 尚未支持 real-time/dynamic decision-making。
- 作者未来方向：
  - 使用 Type-2 fuzzy 或 neutrosophic environment 表示更复杂不确定性；
  - 引入 real-time data、dynamic transportation planning；
  - 发展 ML-assisted 或 parallel optimization，提高大规模场景效率。
- 我们认为仍需确认的问题：
  - driver efficiency `d_u` 的实测来源、校准方法和跨路线泛化能力；
  - `4 - (v + r + d)` 是否足以表示驾驶行为、拥堵、载重和速度的非线性排放；
  - 算术交叉在所有 crispified 约束下保持可行的条件是否严格成立；
  - NSGA-III 优势是否来自 reference point，还是来自可行初始化/变异与参数设置组合；
  - Table 19/性能指标部分主要使用 TTC/TCE/TR/TRS，TDT 在部分指标说明中弱化，需要后续复核完整五目标评价口径。

- 与已有设计知识的边界：
  - 不同于 [风险态度模糊机会约束确定化](../02_design_knowledge/K-risk-attitude-fuzzy-chance-constraint-determinization.md)，本文的重点不是 chance constraint/risk attitude，而是 TrIF expected value、司机-路线-车辆碳排和多阶段流量可行进化；

- 暂留在论文卡中的方法、原理或架构启发：
  - TrIF expected value 细节和具体公式较依赖该类运输模型，暂不单独成卡；
  - modified NSGA-II/NSGA-III 本身改动有限，核心贡献在编码、初始化、变异和模型；
  - TOA 参数选择可以后续与其它算法参数自适应论文合并整理。
- 局部创新线索：
  - 把 `d_u` 替换为驾驶风格画像，例如急加速频率、超速概率、eco-driving score；
  - 在 mutation 中按 emission/risk sensitivity 选择 route-driver 替换，而不是均匀随机；
  - 对 CE constraint 使用 adaptive epsilon，使早期探索高排放低成本区域、后期收紧到绿色可行域；
  - 用 repair 或 min-cost flow 局部优化替换随机容量扣减，提高初始化质量。
- 结构创新线索：
  - 构建“人因-设备-路线”三因子绿色运输 MOEA，将碳排、风险和服务质量统一绑定到 arc choice；
  - 将 stage-wise allocation matrix 与 reference-vector selection 结合，按目标空间 niche 维护不同运输结构；
  - 引入在线数据后，把司机状态、道路拥堵和碳排因子作为动态参数，形成 dynamic green transportation MOEA；
  - 与多任务/迁移优化结合，让不同地区或品类共享 driver-route-vehicle emission response。
