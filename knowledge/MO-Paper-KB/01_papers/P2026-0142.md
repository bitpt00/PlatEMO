# Enhancing Pareto Set Learning with evolutionary multi-objective optimization

## 一句话理解

论文提出 Enhanced Pareto Set Learning：先用 EMOA 全局搜索生成非支配档案，再用 Tchebycheff 最优性关系把非支配解反推为 preference-solution pairs 预训练 Pareto set model，最后用 PSL 细调，从而把 EMOA 的全局探索能力和 PSL 的连续偏好到解映射结合起来。

## 问题与动机

- 研究问题和场景：
  - 面向黑箱多目标优化，目标是学习一个 Pareto set model `h_theta(lambda)`，使决策者给定任意 preference vector 后，都能生成相应 Pareto-optimal solution。
  - EMOA 能在复杂景观中全局搜索并维护非支配解多样性，但输出是有限解集，难以连续覆盖 PF。
  - PSL 能用一个模型表示连续 Pareto set，但依赖 gradient-based 或 zeroth-order gradient 训练，复杂多峰景观中容易陷入局部区域。
- 现有算法为什么不足：
  - 传统 EMOA 的有限 population 可能使决策者错过偏好区域，尤其在连续 PF 上覆盖稀疏。
  - 传统 PSL 从随机或弱初始化开始训练，在局部最优多、目标景观复杂时难以找到全局优质 Pareto set。
  - 普通 hybrid warm-start 只是提供初始解或模型参数，不能直接告诉 PSL “哪个 preference 对应哪个 solution”。
- 本文希望解决什么：
  - 把 EMOA 的非支配档案转化为 PSL 可直接监督学习的数据；
  - 让 EMOA 不只是初始化器，而是 Pareto set inverse mapping 的功能性估计器；
  - 在固定 FE budget 下自适应决定 EMOA search 与 PSL fine-tuning 的资源分配。

## 核心理念与算法流程

- 核心理念：
  - PSL 要学的是从 preference vector 到 Pareto solution 的逆标量化映射。EMOA 搜到的非支配解虽然没有显式 preference 标签，但可通过 Tchebycheff optimality conditions 近似反推其局部 preference，从而构造监督训练集。
- 整体流程：
  1. 用 EMOA，例如 NSGA-II，在固定预算的一部分上搜索 MOP。
  2. 用 unbounded external archive `S` 保存 EMOA 运行过程中的所有生成解。
  3. 运行结束后删除 dominated solutions，得到 `S_ND`。
  4. 对每个 `x_hat in S_ND`，根据 ideal point `z*` 和 Tchebycheff 条件推断 preference vector `lambda(x_hat)`。
  5. 用数据集 `D={(lambda(x_hat), x_hat) | x_hat in S_ND}` 监督预训练 Pareto set model `h_theta(lambda)`。
  6. 用 PSL 的 Smooth Tchebycheff loss 和 ES gradient approximation 继续 fine-tune。
- 偏好标签构造：
  - Tchebycheff 最优解满足类似 `lambda_i(f_i(x)-z_i*) = lambda_j(f_j(x)-z_j*)` 的关系。
  - 因此论文用
    `lambda(x_hat) = [1 / (f(x_hat)-z*+epsilon)] / ||1 / (f(x_hat)-z*+epsilon)||_1`
    反推出 preference。
  - 作者明确说明：preference-to-solution mapping 在 disconnected 或 non-smooth Pareto sets 上通常 non-injective，所以该反推 preference 是 local / representative label，不是唯一真值；有限精度 EMOA 解上的推导是 heuristic。
- 预训练：
  - `h_theta(lambda)` 以 preference vector 为输入、decision vector 为输出。
  - 预训练使用 EMOA 已评价过的 archive 解，因此不额外消耗 function evaluations。
  - 预训练的意义是让模型从 EMOA 发现的 Pareto set geometry 出发，而不是随机初始化。
- fine-tuning：
  - 使用 PSL 的 Smooth Tchebycheff scalarization，针对采样偏好优化生成解。
  - 黑箱场景下没有 `gradient_x g_STCH`，使用 evolution-strategy gradient approximation。
- 自适应 function-evaluation allocation：
  - 总预算 `T` 被拆为 `T_EMOA + T_PSL`，但不是人工固定比例。
  - 作者把 EMOA convergence detection 改造成预算分配控制器，而不是整体终止准则。
  - 用 external archive ideal point 的相邻代变化 `Delta_t = ||z_t* - z_{t-1}*||_inf` 作为收敛指示；当 `Delta_t < epsilon` 连续 `g` 代时，停止 EMOA stage，把剩余预算给 PSL fine-tuning。
  - 难问题 EMOA 收敛慢，会获得更多探索预算；简单问题 EMOA 早停，给 PSL 留更多细调预算。
- 可能被修改的位置：
  - EMOA 可替换为 NSGA-II、NSGA-III、MOEA/D 或其他 archive-rich optimizer；
  - 反推 preference 可替换为 PBI、ASF、R2 utility、local KKT surrogate 或多标签 preference；
  - 收敛检测可从 ideal point change 换为 HV stagnation、archive coverage、preference-label entropy 或 model validation loss；
  - 预训练模型可换成 conditional diffusion、normalizing flow、Set Transformer 或 latent Pareto model。
- 必须保留的核心：
  - EMOA archive 产生覆盖较广的非支配解；
  - 非支配解被转化为 preference-solution pairs，而不是仅当作初始 population；
  - 预训练后仍由 PSL fine-tuning 修正模型，而不是只依赖监督拟合。

## 实验证据

- 测试问题和对比算法：
  - Synthetic 16 个：DTLZ2、DTLZ4-6、WFG1-4、F1-F6、VLMOP1-2。
  - Engineering design 16 个：RE21、RE22、RE23、RE24、RE25、RE31、RE32、RE33、RE34、RE35、RE36、RE37、RE41、RE42、RE61、RE91。
  - 对比原始 PSL，以及 NSGA-II、NSGA-III、MOEA/D-TCH、MOEA/D-PBI。
  - 全部方法使用相同总 FE：2 目标 `T=26000`，3 目标及以上 `T=41000`。PSL/Enhanced PSL 中最多 1000 FE 用于 performance evaluation，其余优化预算满足 `T-1000 = T_EMOA + T_PSL`。
  - Pareto set model 为 2 hidden layers、每层 1024 nodes、ReLU；pre-training 30 epochs、batch size 64、Adam lr 0.0025；fine-tuning 用 STCH `mu=0.1`、ES gradient `K=5`、`sigma=0.01`。
  - EMOA convergence allocation 参数为 `epsilon=0.0001`、`g=20`。
  - 指标为 hypervolume difference `Delta HV`，越小越好；31 次独立运行，Wilcoxon rank-sum test，显著性 0.05。
- 主要实验结论：
  - 与 PSL 的相同解数比较：Table 3 中 Enhanced PSL 在 32 个问题上 `+/=/− = 17/9/6`，即显著优于 PSL 17 个、相当 9 个、显著差 6 个。
  - 与 PSL 的 dense output 比较：Table 4 中 Enhanced PSL 为 `20/6/6`，显示预训练模型在密集采样时更常提供更好 PF 表示。
  - 作者强调 large solution sets 的 HV 改善是 learned Pareto set model 可密集采样的表示优势，不应解释为使用更多计算资源带来的优化优势。
  - 与 standalone EMOA 比较：Table 5 显示，在相同 FE 和相同 solution count 的 small 设置下，Enhanced PSL 通常相当或优于对应 EMOA；large 设置进一步体现 PSL 可生成密集前沿的优势。
  - 自适应 FE 分配：Fig. 4 显示 adaptive allocation 平均表现最好，极端 0% 和 100% allocation 更差；即使和最优固定比例 small 40%、large 30% 相比，自适应方法仍更好。
  - EMOA 选择：Fig. 5/6 显示集成 NSGA-II 通常排名最好，作者解释为 NSGA-II 能产生更 diverse 的非支配档案。
  - 可视化：RE33、RE34、RE35、RE37 等工程问题中 Enhanced PSL 覆盖和多样性明显优于 PSL。
- 消融或机制证据：
  - 0% EMOA 等价 pure PSL，100% EMOA 等价 pure EMOA with pretraining only；二者都不如自动平衡的方案，支持“全局探索 + 模型细调”两者都必要。
  - 比较不同 EMOA 表明 archive 的多样性会影响预训练质量，NSGA-II 的 diverse archive 更适合作为标签来源。
- 证据边界：
  - Enhanced PSL 在 WFG3、WFG4、VLMOP1/2、RE36 等问题上略差于 PSL。作者解释：WFG3/WFG4 的 PF highly nonsmooth/deceptive，EMOA archive 不均匀会偏置预训练；VLMOP1/2 简单低维，PSL 已能可靠收敛；RE36 可行域 constrained and irregular，EMOA 解多样性受限。
  - Table 5 的 small 设置并非所有 EMOA 都被明显超越，例如 NSGA-II small 在 synthetic problems 中 standalone 与 Enhanced 各胜 8 个。
  - 论文主要是连续无约束或工程黑箱 benchmark；尚未验证 large-scale、constrained、NAS、RL 等作者未来方向。

## 局限与未来工作

- 作者明确说明的局限：
  - 没有 formal convergence guarantees，也没有 learned Pareto set approximation error 的 theoretical bounds。
  - 黑箱 MOO 中缺少梯度信息和解析结构，这使理论保证困难。
  - EMOA-based pre-training 是经验性地改善 PSL 初始化、收敛速度和鲁棒性。
- 作者未来工作：
  - 建立 dense EMOA sampling consistency 或 neural Pareto set approximation bounds。
  - 引入 fuzzy logic-based controller，使 adaptive strategy 对不同 problem landscapes 更鲁棒。
  - 扩展到 large-scale and constrained MOO、NAS、reinforcement learning。
  - 研究其他 nature-inspired optimization algorithms 与框架结合。
- 我们认为仍需确认的问题：
  - 反推 preference 标签在 disconnected/non-smooth PF 上非唯一，单标签监督可能错误压缩多解区域。
  - EMOA archive 若偏置，会把偏置直接注入 Pareto set model；需要 label confidence 或 archive reweighting。
  - 预训练损失与最终 HV/Delta HV 之间缺少显式对齐，可能需要区域加权或偏好覆盖正则。
  - FE allocation 只看 ideal point change，可能忽略 PF 覆盖已经不足但 ideal point 停滞的情况。
  - 目前 `z*` 和参考前沿/归一化依赖 benchmark 信息，真实问题中 ideal/nadir 和 reference PF 估计会影响标签和评价。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：EMOA 档案预训练的 Pareto 集学习。它可用于任何 preference-conditioned Pareto generator：先用 MOEA/局部搜索/精确启发式获得 archive，再把解反推为偏好标签，预训练 `preference -> solution` 模型，最后用可微或黑箱 fine-tuning 精修。
- 暂留在论文卡中的方法、原理或架构启发：
  - EMOA convergence detector 可被重用为跨模块预算分配器，而不是只做终止判断。
  - Dense sampling 的评价需要和相同解数公平评价分开报告，否则容易把表示密度误当作优化质量。
  - Preference labels 应记录置信度，尤其在多解同偏好、PF 断裂或 EMOA 解远离真 PF 时。
- 局部创新线索：
  - 用 archive density 或 crowding distance 重新加权 pretraining loss，避免非均匀 EMOA archive 偏置模型。
  - 用多个 scalarization 反推多个 candidate preferences，做多标签或软标签训练。
  - 用 validation preferences 的 STCH 改善率来触发 EMOA/PSL 切换，而不是只看 ideal point。
  - 用 active learning 让 PSL 模型发现偏好空间中误差高的区域，再请求 EMOA 局部补 archive。
- 结构创新线索：
  - 构建双向闭环：

```text
EMOA archive -> preference labels -> Pareto set model
Pareto set model uncertainty -> select preference gaps
targeted EMOA / local search -> refill archive
```
