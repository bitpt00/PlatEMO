# Dynamic Multivariation Multifactorial Evolutionary Algorithm for Large-Scale Multiobjective Optimization

## 一句话理解

这篇论文把 LSMOP 的原始高维搜索和多个低维问题变体放进 multifactorial evolutionary framework，通过候选辅助任务池和累计贡献率动态选择当前最有用的低维维度，并用跨维知识迁移在不同低维/高维表示之间生成后代。

## 问题与动机

- 研究问题和场景：large-scale multiobjective optimization problems (LSMOPs)，决策变量可达 500 到 8000 维，直接搜索困难。
- 现有算法为什么不足：problem transformation-based MOEAs 能降低维度，但变换后可能丢失原问题的全局/近全局最优解；MOEMT 用原始任务加低维辅助任务缓解该风险，但辅助任务维度固定，不能适应早期粗粒度搜索和后期精细搜索的不同需求。
- 本文希望解决什么：在演化过程中动态选择合适维度的问题变体作为辅助任务，并设计跨任务、跨维度的知识迁移机制，减少负迁移和低维/高维表示不兼容。

## 核心理念与算法流程

- 核心理念：同一个 LSMOP 被表示为一个原始高维主任务和多个不同维度的低维辅助变体。哪些辅助维度有用不是预先固定，而是由这些变体通过 cross-task transfer 产生的 offspring 在环境选择中存活的贡献率决定。
- 主要流程：
  1. 初始化主任务 `Task1`，以及候选问题变体池 `pool`，每个变体对应一个低维 transformed space。
  2. 初始随机从 `pool` 中选 `K-1` 个变体作为辅助任务；`CR` 累积贡献率初始化为 1。
  3. 每代先在原始高维空间优化主任务，再从主任务中选 reference solutions `Prime`。
  4. 对每个辅助任务，用 weight optimization / inverse transformation 在低维空间生成辅助种群并优化。
  5. 如果父代 skill factor 相同，则在对应任务空间内用 SBX/PM；如果 skill factor 不同，则触发 cross-task knowledge transfer (CKT)，并记录转移 offspring 集 `Q`。
  6. 用环境选择从 `P ∪ O` 中筛选下一代，并根据 `P ∩ Q` 中各辅助变体贡献的存活 offspring 数计算 improvement rate `IR`。
  7. 更新每个候选变体的 cumulative contribution rate `CR`，再通过 roulette wheel selection 选择下一代辅助任务维度。
- 关键组成部分：
  - Problem variant pool：候选低维维度覆盖不同搜索粒度。
  - Efficacy Quantification of Variants (EQV)：用跨任务转移后代的存活贡献更新候选变体 `CR`。
  - Cross-Task Knowledge Transfer (CKT)：不同维度低维表示之间不直接硬拼接，而是用一方低维向量作为权重调制另一方高维变量组，并用 least-squares mapping matrix 校准高维信息。
  - Original task + auxiliary tasks：主任务保留全局正确性，辅助任务利用低维快速探索。
- 可能被修改的位置：LSMOP 的 problem transformation 模块、EMTO/MFEA 的辅助任务选择器、跨任务交叉/迁移算子、低维变体维度调度。
- 必须保留的核心：动态任务选择的贡献信号应来自“辅助变体通过迁移产生的后代是否被环境选择保留”，否则会退回普通固定维度或全局指标驱动的任务选择。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：LSMOP1-LSMOP9，目标数 2 和 3，决策维度 500、1000、2000、5000、8000。
  - 对比 MOEMT、WOF、ALMOEA、LSMOEA/PT、LERD；PlatEMO v4.6，MATLAB 2023a。
  - 参数：population size 100，`maxFEs=100000`；WOF/MOEMT/MOEMT/D 变量组数 4，内部优化器 NSGA-II；MOEMT/D 候选池维度为 1、5、10、15、20、25、50，辅助任务数 4。
  - 真实问题：neural network training (NN) 与 portfolio optimization (PO)，决策维度约 100-5000，指标 HV。
- 主要实验结论：
  - 消融中 MOEMT_EQV 相对 MOEMT 在 72 个 case 中 30 个显著更好，支持动态辅助任务选择。
  - MOEMT_CKT 相对 MOEMT 在 72 个 case 中 29 个显著更好，支持跨维知识迁移。
  - 完整 MOEMT/D 相对 MOEMT 在 72 个 case 中 47 个显著更好，说明 EQV 与 CKT 有协同。
  - 二目标 LSMOP 上，MOEMT/D 相对 WOF、LSMOEA/PT、ALMOEA、LERD 在 45 个测试场景中全部更好。
  - 三目标 LSMOP 上，MOEMT/D 相对 WOF、LSMOEA/PT、LERD 分别在 42、43、37 个场景更好；对 ALMOEA 在 LSMOP2 等简单可分场景略弱。
  - 真实 NN/PO 上，MOEMT/D 获得最优综合 HV，解集在收敛和分布上优于多个对比算法。
- 消融或机制证据：
  - Fig. 3 雷达图显示动态选择辅助任务和 CKT 变体多数维度下均缩小 IGD 多边形面积。
  - Fig. 4 显示 MOEMT/D 在 bi-objective LSMOP1 的 500-5000 维上比 MOEMT 收敛更快且置信区间更窄。
  - Fig. 5 说明 8000 维二目标 LSMOP 中，MOEMT/D 在复杂 landscape 上保持较好目标空间分布。
- 证据边界：
  - 主文表格大多为图片占位，精确均值和方差需回 PDF 或 supplementary。
  - 候选池维度和辅助任务数量仍手工设定。
  - 对 ALMOEA 在简单 mixed-modality separable LSMOP2 上并非总是更优，说明复杂框架对简单结构问题未必划算。

## 局限与未来工作

- 作者明确说明的局限：MOEMT/D 仍有改进空间，尤其是贡献度量、降维/变换方法和 EMTO 框架选择。
- 作者未来工作：
  - 研究更细粒度的指标来量化不同降维策略对演化过程的贡献。
  - 设计更自适应的 dimensionality reduction 和 transformation 方法，扩大适用范围。
  - 将本文理论概念嵌入其他 EMTO 框架，并寻找更合适的 advanced framework。
- 我们认为仍需确认的问题：
  - `CR` 只看转移 offspring 是否存活，是否会偏向短期 exploitation 而忽略长期潜力维度。
  - 候选维度池是否需要根据 `D`、变量交互和搜索阶段自动生成。
  - CKT 的 linear mapping matrix 在强非线性变量交互下是否仍可靠。
  - 在 expensive LSMOP 中，多辅助任务和 CKT 额外评价/计算成本是否可接受。

- 值得建立或补充的设计知识：
  - 补充“动态辅助任务构造”：本文提供候选低维变体池、贡献率驱动任务选择和跨维知识迁移的第二篇强证据。
- 暂留在论文卡中的方法、原理或架构启发：
  - CKT 可作为独立跨维迁移算子继续观察，但目前与 MOEMT/D 的动态任务池紧密耦合，先不单独建卡。
  - Least-squares mapping matrix 可扩展到 domain adaptation，但本文只给线性闭式映射。
- 局部创新线索：
  - 用 HV contribution、IGD improvement、archive survival duration 或 uncertainty-aware credit 替代 `assist_count`。
  - 对不同阶段自适应扩展/收缩候选维度池，而非固定 1、5、10、15、20、25、50。
  - 将 CKT 的线性映射替换为低秩、稀疏、kernel 或 autoencoder mapping。
  - 为每个辅助维度设置评价预算，而不只是任务选择概率。
- 结构创新线索：
  - 构建 LSMOP 动态变体池：原始任务保证全局锚定，多个低维变体提供不同搜索粒度，贡献反馈决定任务驻留时间和迁移强度。
  - 与动态参考解管理的问题变换结合：参考解池和辅助维度池同时动态更新。
