# Evolving Multimodal Models for Physical Dynamics: A Multi-objective Neuroevolution Approach

## 一句话理解

论文把物理动力学模型设计从手工调架构改成多目标神经演化：每个候选模型同时编码流形维度、FNO 层数/频率模态、卷积通道、学习率和 LLM 物理语义注入强度，在 RMSE 与 FLOPs 两个目标上搜索 Pareto 前沿；代表模型 Evo-ManiEarth 将文本化方程/边界条件、流形降维和 FNO 时空演化合在一个可进化搜索空间中，在多类 PDE 与极端天气数据上获得更好的精度、物理一致性和效率折中。

## 问题与动机

- 研究问题和场景：
  - spatiotemporal physical dynamics forecasting；
  - 包括已知物理方程数据：Navier-Stokes、Shallow Water、Rayleigh-Benard Convection、Diffusion-Reaction；
  - 包括未知方程/真实场景：SEVIR、Kuroshio、Typhoon；
  - 目标不是只找到一个最优模型，而是找到 accuracy-efficiency Pareto 模型族。
- 现有方法为什么不足：
  - CNN/RNN/Transformer 等视觉骨干可建模时空数据，但计算成本高，且可能过平滑或物理不一致；
  - operator learning/FNO 能学习函数空间映射，但高维 latent representation 的维度选择和计算成本仍困难；
  - PINN/Evo-PINN/Physics-informed NAS 多数把物理知识作为 soft loss、残差约束或单模态结构搜索，较少把文本化方程、边界条件和外力作为可调语义分支；
  - 手工决定 FNO 层数、流形维度、通道数、学习率和物理语义融合强度，难以系统探索精度和成本折中。
- 本文希望解决什么：
  - 自动搜索多模态 physics-informed model 的架构与超参数；
  - 将 LLM-derived symbolic physics、manifold learning 和 FNO backbone 作为一个联合搜索空间；
  - 输出一组可按计算预算选择的 Pareto-optimal models；
  - 验证 LLM 语义分支不是噪声注入，而是能改善物理一致性。

## 核心理念与算法流程

- Genome encoding：
  - 每个个体为 6 维 genome `g=(d', L_FNO, C_enc, k_max, alpha_lr, gamma_LLM)`；
  - `d' in {8,16,32,64,128,256}` 表示 manifold dimension；
  - `L_FNO in {2,3,4,5,6,8}` 表示 FNO spectral layers；
  - `C_enc in {16,32,64,128}` 表示 encoder channel width；
  - `k_max in {8,12,16,20,24}` 表示 truncated Fourier modes；
  - `alpha_lr in [1e-4,1e-2]` 为 log-sampled learning rate；
  - `gamma_LLM in [0,1]` 为 LLM 分支融合强度门控。
- Fitness objectives：
  - `f1=RMSE`，在 held-out validation split 上最小化预测误差；
  - `f2=FLOPs (M)`，通过实例化架构的解析计算得到；
  - 每个候选短训 30 epochs，最终 Pareto 前沿 top-5 个体再 full convergence retraining。
- Evolutionary process：
  - 使用 NSGA-II 风格的多目标演化；
  - population size `40`，generations `50`，总计 `2000` 次短周期评价；
  - 连续基因用 SBX crossover 和 polynomial mutation；
  - 离散基因用 single-point crossover 和 uniform resampling；
  - selection 使用 non-dominated rank + crowding distance；
  - 训练早期发散的候选赋为 `(+inf,+inf)` 排除。
- 候选模型 forward path：
  - video frames 经 Conv2d encoder 得到高维空间特征；
  - manifold mapping `phi` 将特征投影到低维 `Y_d'`；
  - prompt 经 LLM 处理方程、边界条件、外力和物理参数，得到文本物理特征；
  - LLM 特征再经 depth-wise Conv2d adapter，对齐到空间特征分辨率；
  - `Y_d'` 与 `gamma_LLM * F_LLM` 拼接后进入 FNO blocks 做 latent evolution；
  - decoder 重构未来时空序列。
- 设计直觉：
  - LLM 分支提供高层物理语义先验，尤其约束 incompressibility、boundary conditions 和 conservation；
  - manifold bottleneck 过滤冗余空间噪声，并让 FNO 在更少 intrinsic coordinates 上演化；
  - FNO 负责频域中捕捉动态演化；
  - neuroevolution 自动调节三者配比，避免手工固定物理语义强度或流形维度。
- 可修改接口：
  - 搜索算法：NSGA-II 可替换为 MO-TPE、qEHVI、SA-MOEA、regularized evolution 或 surrogate-assisted MOEA；
  - genome 基因：可加入 latency、memory、energy、prompt type、adapter depth、operator block type；
  - 评价预算：短训 epoch、full retraining 数量、early termination 阈值；
  - LLM 分支：模型、temperature、缓存策略、prompt 模板、embedding adapter；
  - 物理度量：可把 divergence、mass error、energy spectrum error 直接纳入多目标或约束。
- 必须保留的核心：
  - 将领域物理文本语义、连续/离散架构结构和计算成本放入同一个可演化编码；
  - 用 Pareto search 而不是单一手工模型选择；
  - 对 LLM 物理分支设置可搜索的融合强度，防止固定注入过强或过弱；
  - 用物理一致性指标和 prompt 鲁棒性测试确认语义分支确实传递物理内容。

## 实验证据

- 搜索设置：
  - NSGA-II，`N_pop=40`，`G=50`；
  - 总计 `2000` 个 short-cycle training runs；
  - 每个短训候选 30 epochs；
  - top-5 Pareto-front individuals 做 full convergence retraining；
  - 论文报告单个 short-cycle evaluation 在 A100 上约 6-11 分钟，完整搜索约 280 A100-hours per benchmark。
- Navier-Stokes Pareto 代表模型：
  - High-Accuracy Model：RMSE `0.2315`，FLOPs `751.2M`，`d'=128`、FNO layers `6`、channels `64`；
  - Balanced Model / Evo-ManiEarth：RMSE `0.2465`，FLOPs `571.4M`，`d'=64`、FNO layers `4`、channels `32`；
  - High-Efficiency Model：RMSE `0.2890`，FLOPs `310.5M`，`d'=32`、FNO layers `2`、channels `32`；
  - 这说明搜索得到的不是单点，而是可按预算选的模型族。
- 综合精度结果：
  - Unknown equations：SEVIR `0.1608`、Kuroshio `0.0399`、Typhoon `0.0152`；
  - Known equations：Navier-Stokes `0.2465`、Shallow Water `0.0025`、Rayleigh-Benard `0.1392`、Diffusion-Reaction `0.0007`；
  - 表格显示 Evo-ManiEarth 在这些场景中均优于 U-Net、ResNet、Swin-Transformer、FNO、F-FNO、LSM。
- 效率结果：
  - Navier-Stokes 代表场景：Evo-ManiEarth FLOPs `571.42M`、参数 `0.84M`、inference `0.64s`，低于 FNO 的 `743.15M` FLOPs 和 `38.71M` 参数；
  - SEVIR 代表场景：Evo-ManiEarth FLOPs `288.79M`、参数 `18.24M`、inference `0.71s`，低于 ResNet/FNO；
  - 作者总结相对 FNO 可减少约 23%-61% FLOPs。
- 物理一致性：
  - Navier-Stokes：RMSE `0.2465`、divergence `4.51e-4`、energy spectrum error `0.0314`；
  - Shallow Water：RMSE `0.0025`、mass error `1.23e-4`、energy spectrum error `0.0098`；
  - Rayleigh-Benard：RMSE `0.1392`、energy spectrum error `0.0425`、enstrophy error `0.0287`；
  - Diffusion-Reaction：RMSE `0.0007`、mass error `3.18e-5`；
  - 论文报告这些物理指标均优于对照模型。
- LLM 分支消融：
  - 无物理特征：RMSE `0.2814`、divergence `1.42e-3`、energy spectrum error `0.0852`；
  - one-hot + MLP：RMSE `0.2652`、divergence `1.10e-3`；
  - manual structured params：RMSE `0.2605`、divergence `9.85e-4`；
  - LLM equations only：RMSE `0.2541`、energy spectrum error `0.0385`；
  - LLM boundary only：RMSE `0.2588`、divergence `5.12e-4`；
  - full prompt：RMSE `0.2465`、divergence `4.51e-4`、energy spectrum error `0.0314`。
- 长期 rollout：
  - Navier-Stokes autoregressive horizon 从训练 `T=10` 扩展到 inference `T=50`；
  - ResNet step 50 为 `2.5810 (Unstable)`；
  - FNO step 50 为 `1.3421`；
  - Evo-ManiEarth step 50 为 `0.6845`。
- Search budget fair comparison：
  - 同一 search space、同样 `2000` evaluations 下，Random Search HV `0.412`，MO-TPE `0.487`，qEHVI `0.531`，SA-MOEA `0.544`，NSGA-II/Ours `0.572`；
  - Optimized FNO 经 500 trials random search 后 RMSE `0.2852`、FLOPs `820.5M`，仍弱于 Evo-ManiEarth 的 `0.2465`、`571.4M`。
- Prompt robustness：
  - semantic-preserving rewrite：RMSE `0.2482`，cos-sim `0.983`，变化小于 1%；
  - variable renaming：RMSE `0.2478`，cos-sim `0.987`；
  - random word scrambling：RMSE `0.2812`，cos-sim `0.412`；
  - adversarial wrong-equation prompt：RMSE `0.3224`，cos-sim `0.298`；
  - 作者据此认为 LLM 分支利用组合语义和真实物理内容，不是关键词匹配或噪声注入。
- 证据边界：
  - 论文实验很强依赖大规模短训评价，完整搜索成本高；
  - 代表模型和搜索空间同时贡献性能，不能把增益单独归因于 NSGA-II；
  - 表格中部分数值 OCR 混排，精确复核应回看 PDF；
  - LLM 使用 GPT-4o-mini 固定版本、temperature 0、embedding 缓存，实际可复现性依赖模型版本和 prompt 实现；
  - 论文主要展示物理预测模型设计，未验证一般图像 NAS、非物理时空预测或严格实时部署。

## 局限与未来工作

- 作者明确或隐含的局限：
  - 搜索成本约 280 A100-hours per benchmark，对普通实验室较重；
  - LLM 物理描述需静态缓存，动态变化方程或在线物理条件需要重新设计缓存和调用策略；
  - 物理 prompt 错误会显著损害模型，必须有方程/边界条件校验；
  - 图片和表格显示代表模型较强，但跨更复杂真实系统、噪声条件和多分辨率数据仍需验证。
- 我们认为仍需确认的问题：
  - `gamma_LLM` 与 `d'` 是否在不同 PDE family 上形成稳定规律；
  - 是否应把物理指标直接作为多目标，而不只用 RMSE/FLOPs 搜索后再报告；
  - LLM embedding 和 depth-wise Conv2d adapter 的空间化方式是否可替换为 cross-attention、FiLM 或 physics token conditioning；
  - 同一搜索空间下 NSGA-II 优于 MO-TPE/qEHVI/SA-MOEA 的原因是否来自离散-连续混合基因、评价噪声或选择压力；
  - 错误方程 prompt 的退化说明语义分支有效，也说明部署时需要 prompt provenance 和安全校验。
