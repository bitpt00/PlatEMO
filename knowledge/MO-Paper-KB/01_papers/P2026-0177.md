# Multiobjective Task Allocation for Electric Harvesting Robots: A Hierarchical Route Reconstruction Approach

## 一句话理解

论文定义了面向果园多电动采摘机器人的 AMERTA 问题，同时最小化 makespan 和总能耗，并显式考虑负载影响速度/能耗、容量、多次返仓和电池更换约束；提出 HRRA，用“微观路线层 + 宏观机器人调度层”的分层编码，把普通全局任务序列搜索改造成可独立优化单条路线、机器人任务序列、充电后尾段任务和最长路线的层级重构框架。

## 问题与动机

- 研究场景：果园中有多个成熟果树任务节点，多个同质电动采摘机器人从 depot 出发，所有任务节点必须被采摘，每个节点只能由一个机器人一次完成。
- 两个优化目标：
  - 最小化最大完成时间 `T_max`；
  - 最小化总能耗 `E_total`。
- 真实约束：
  - 机器人容量有限，需要多次 trip；
  - 机器人携带水果负载会影响速度和能耗；
  - 电池容量有限，只有电量低于阈值时允许在 depot 更换电池；
  - 机器人始终空载离开 depot。
- 为什么现有方法不足：
  - EVRP 常假设常数能耗或充电站/单次配送，不适合果园采摘中负载实时变化、多次返仓和 depot 换电；
  - 现有 agricultural MRTA 多用固定维度全局序列编码，难以单独优化每条 trip；
  - 普通 NSGA-II/蜂群/ACO 等全局算子容易忽略 battery replacement 对后续任务结构的扰动；
  - 加权单目标 EVRP 方法不能输出 makespan-energy trade-off 方案集。
- 本文希望解决什么：
  - 建立 AMERTA 数学模型；
  - 构造同时适配 route construction 和 route-robot assignment 的表示；
  - 用路线内、路线间、充电后尾段和最长路线分割四类重构机制，提升多目标任务分配质量；
  - 构建 45 个实例并验证 HRRA 相比七类算法的优势。

## 核心理念与算法流程

- 核心理念：农业 MRTA 中的决策不是单一全局任务序列，而是“任务组成的 trip、trip 分配给机器人、机器人执行过程中的充电/换电位置”共同决定目标值。因此应把编码和搜索拆成可局部更新的层级结构，再针对主要约束瓶颈做局部抽取和重构。
- AMERTA 模型：
  - `N` 为 depot 和任务节点，`R` 为机器人集合，`S` 为可能路线；
  - 每个任务有产量 `q_i`，机器人容量 `Q=300`，电池容量 `B=432`，换电阈值 `B_th=0.2B`；
  - travel energy 随距离和当前负载变化，travel time 由能耗和最大功率推导；
  - picking energy/time 与产量成比例，换电有时间惩罚 `t_swap=150`；
  - 约束包括路线守恒、节点访问、载重更新、容量、电池可行性、换电状态和路线-机器人分配。
- HRRA 的分层表示：
  - Layer1 microroute：每条 trip 表示为 `{S_i, T_route_i, E_route_i}`，包含 depot 节点、该路线执行时间和能耗；
  - Layer2 macroscheduling：包含 global task sequence、robot-task mapping sequence、每个机器人的能耗/完成时间、charging position record；
  - 这种结构允许只重算被修改 route 的指标，而不必每次重算整个个体。
- VLDIM 初始化：
  1. Route construction：从 depot 附近任务开始，按距离贪心扩展路线；
  2. 用线性递减 load limit `Q_p` 控制每个初始个体的路线长度和载重，兼顾可行性与多样性；
  3. Route-robot assignment：当路线数不少于机器人数量时，用 MILP1 最小化最大完成时间；路线数不足时迭代分割最长路线，直到可分配给机器人。
- Task sequence optimization：
  - DRRM：先按任务到 depot 的距离降序重排，让远距离/高能耗任务在电量较充足时执行，再用 2-opt 做路线内局部搜索；
  - TRRM：对非支配解执行 task exchange 和 task reallocation，把长完成时间机器人的任务向短完成时间机器人迁移，改善负载均衡和电池利用。
- Charging-based route reconstruction, CRRM：
  - 针对每个非支配解，抽取每个机器人最后一次充电后的任务序列 TLC；
  - 保留充电前任务结构，只重排和优化充电后受扰动的任务；
  - 用 MILP2 将优化后的 TLC 重新分配给机器人，并允许部分机器人不接收新路线，以避免额外充电。
- Split-based route reconstruction, SRRM：
  - 在剩余时间不足以完整迭代时作为最终精修；
  - 从 Layer2 还原 Layer1 路线，识别执行时间最长的 route；
  - 从头或尾开始贪心切分，使两个子路线执行时间尽量平衡；
  - 用 MILP1 重新分配所有 routes，从而改善 makespan。
- 完整流程：
  1. VLDIM 生成初始 population；
  2. 对 Layer1 路线执行 DRRM；
  3. 每轮迭代中先优化 Layer2 的机器人任务序列，再用 TRRM 调整全局任务序列；
  4. 对非支配解执行 CRRM + DRRM + MILP2 重分配；
  5. 用 NSGA-II 式环境选择保留高质量 population；
  6. 根据平均迭代时间判断剩余预算，最后执行 SRRM；
  7. 输出 makespan-energy 折中解集。

## 实验证据

- 实验设置：
  - 构建 15 个 benchmark problems，覆盖不同场景尺寸、任务数、总产量和最大任务-depot 距离；
  - 每个任务产量从 `[40,70]` 随机生成；
  - 机器人数量为 `{4,5,6}`，共 45 个 test instances；
  - 种群规模 30，停止条件为 CPU 时间 `0.5 x n` 秒；
  - MATLAB 2021a，Intel Core i7-12700 CPU，32 GB RAM；
  - 指标：IGD+ 越小越好，HV 越大越好，HV reference point 为 `(1,1)`。
- 对比算法：
  - 农业 MRTA：AMOEA、CDABC、MODABC；
  - 一般 MRTA：RNSGA；
  - EVRP 加强为多目标版本：IALNS、HACO；
  - 经典基线：改进版 NSGA-II。
- 综合结果：
  - HRRA 在 71.1% 的 test instances 上取得更低平均 IGD+；
  - HRRA 在 93.3% 的 cases 上取得更高平均 HV；
  - PF 可视化显示 HRRA 的解集位于更靠前的目标区域；
  - Boxplot 说明 HRRA 不仅均值更好，四分位距也更小，稳定性更强。
- 统计检验：
  - Wilcoxon signed-rank test 中 HRRA 相对每个竞争算法在 IGD+ 和 HV 上的 `R+` 均明显大于 `R-`；
  - 所有关联 `P` values 均小于 0.05；
  - Friedman test 中 HRRA 排名第一。
- 机制解释：
  - 小规模且机器人冗余时，CRRM 贡献有限，甚至可能引入额外计算开销；
  - 机器人利用率高时，SRRM 能通过路径分割和任务重分配优化 makespan；
  - 复杂度增加时，HRRA 的组合优势更明显；
  - 消融结果位于补充材料，正文总结 CRRM 缺失会降低能量管理效率，SRRM 缺失会削弱细粒度路径优化能力。
- 证据边界：
  - 详细数值表格多为图片占位；
  - 参数 `theta=0.8736`、组件消融、置信区间和默认输出比较主要在补充材料；
  - benchmarks 为新构造实例，真实果园部署或在线动态场景尚未验证。

## 局限与未来工作

- 作者未来工作：
  - 动态场景适应：实时任务到达、机器人故障、任务能耗实时监测，发展在线优化和快速响应策略；
  - 异构机器人团队：考虑不同载重、速度、能耗模型和作业能力；
  - 跨场景应用：扩展到仓储物流、城市配送等类似领域，验证模型和算法迁移能力。
- 我们认为仍需确认的问题：
  - CRRM 只抽取最后一次充电后的任务，若多次充电或早期充电决策已经错误，能否充分修复；
  - SRRM 作为尾部精修依赖剩余时间判断，触发时机是否可自适应；
  - MILP1/MILP2 在更大任务规模或异构机器人下是否成为瓶颈；
  - 线性 load limit 是否能适应不同产量分布和路网结构；
  - 当前算法是离线确定性优化，对动态果园任务和实际导航不确定性仍需扩展。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：层级路径重构的约束感知 MRTA。它不同于“结构启发初始化与多目标路径重联”或“非支配排名驱动的辅助速度决策修正”，核心不是沿精英路径生成中间解，也不是修正速度档位，而是用分层 route/robot encoding 和 constraint-triggered reconstruction 局部重构受电池、负载和 makespan 瓶颈影响的任务子结构。
- 暂留在论文卡中的方法、原理或架构启发：
  - AMERTA 的具体果园参数、能耗公式和换电阈值暂留本文卡；
  - `theta=0.8736` 属于本文实例参数，暂不建卡；
  - 45 实例 benchmark 构造方法暂不单独建基准卡。
- 局部创新线索：
  - 把 CRRM 的 TLC 抽取改成多段充电片段检测，针对所有充电瓶颈做局部重构；
  - 用 learned route criticality 或 HV contribution 选择需要重构的机器人/路线，而不是只看非支配解；
  - 将 MILP1/MILP2 替换为快速 min-cost flow、assignment heuristic 或 surrogate-assisted allocation；
  - 让 SRRM 的路线分割点同时考虑能耗、产量、拥堵和充电概率，而不只平衡执行时间。
- 结构创新线索：
  - 构建“层级编码 + 局部可重算 route metrics + 约束瓶颈抽取 + 小 MILP 重分配”的多目标组合优化框架；
  - 迁移到仓储 AMR 订单拣选、电动车配送、无人机巡检、多机器人清扫、农业喷洒等带电量/容量/多 trip 的任务分配；
  - 与动态优化结合：环境变化后只抽取受影响路线片段重构，而不是重启全局种群。
