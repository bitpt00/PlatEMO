# A multi-objective ensemble learning model with re-decomposition and residual learning for grain futures price prediction

## 一句话理解

本文提出 RL-CEEMD-MOLA：先用 CEEMD 和样本熵对粮食期货价格去噪，再从 ARIMA、BiLSTM、BPNN、ELM、VAF 中选择主预测模型；随后对主模型残差再次分解去噪，用剩余异构模型预测残差，并由多目标 Lichtenberg algorithm 同时优化残差集成权重和区间调节系数，从而同时改善点预测精度、方向一致性和预测区间宽度。

## 问题与动机

- 研究问题和场景：
  - 面向粮食期货价格预测，数据包括大连玉米期货、伦敦小麦期货和美国小麦期货；
  - 粮食价格受供需、天气、政策、金融投机和地缘事件影响，呈现非线性、随机性、混沌和波动聚集；
  - 预测结果用于粮食安全、政策制定、企业采购与投资风险管理，既需要点预测，也需要置信区间。
- 现有方法为什么不足：
  - 单一统计模型难处理非线性和混沌结构，单一深度模型又可能过拟合或解释弱；
  - 分解-集成模型通常只对原序列分解，主预测后的残差仍可能保留可学习信息；
  - 固定加权或单目标集成难同时兼顾误差、稳定性和方向准确性；
  - 传统正态假设区间为保证覆盖率往往过宽，区间锐度不足；
  - 粮食期货受到突发不确定性冲击时，单靠历史价格序列难以完全解释异常点。
- 本文希望解决什么：
  - 把序列去噪、主预测、残差再学习和区间预测组合成一个两阶段框架；
  - 用多目标优化自适应确定残差集成权重；
  - 用多目标优化调整上下界系数，在覆盖率和区间宽度之间取得折中；
  - 验证框架在真实数据、Bootstrap 数据、消融和重复实验中的稳定性。

## 核心理念与算法流程

- 核心理念：
  - 价格原序列和主模型残差都可能混有噪声与可预测结构，应分别分解和筛选；
  - 主预测模型负责提取主趋势，残差学习模块负责捕获主模型遗漏的非线性局部信息；
  - 异构模型池比单类集成更容易覆盖统计、神经网络、快速学习器和混沌重构模型的互补优势；
  - 区间预测不应只套用固定分布假设，而应通过可调系数响应市场波动。
- 数据处理模块：
  - 对原始价格序列进行 CEEMD 分解，得到多个 IMF；
  - 用样本熵衡量 IMF 复杂度；
  - 以 `mean + std` 为阈值剔除高复杂度 IMF；
  - 将保留 IMF 重构为 denoised data。
- 主预测模块：
  - 模型池包括 ARIMA、BiLSTM、BPNN、ELM 和 VAF；
  - 所有模型在 denoised data 上训练和预测；
  - 以预测精度选择 best model 作为主预测器；
  - VAF 分支通过最大 Lyapunov 指数、互信息、false nearest neighbors 和相空间重构处理混沌序列。
- 残差学习模块：
  - 计算主预测残差；
  - 对残差再次使用 CEEMD 和样本熵过滤高频噪声；
  - 从模型池中排除主预测模型，剩余模型预测过滤后的残差；
  - MOLA 在残差预测上优化集成权重；
  - 最终点预测为主预测值加权重残差预测值。
- 区间预测模块：
  - 在最终点预测周围引入上下界 intelligent interval adjustment coefficients；
  - MOLA 同时优化覆盖准确性和区间长度相关目标；
  - 高波动时允许区间扩大，稳定期收窄区间。
- 可能被修改的位置：
  - CEEMD 可替换为 VMD、EEMD、wavelet 或 learnable decomposition；
  - 样本熵阈值可替换为能量占比、频谱特征、互信息或验证集误差贡献；
  - MOLA 可替换为 NSGA-II、MOEA/D、CMA-ES 多目标版本或 Bayesian MOO；
  - 残差集成权重可从静态权重改为状态条件化权重；
  - 区间系数可由市场波动特征、外生事件或 conformal calibration 共同调节。
- 必须保留的核心：
  - 主预测和残差学习是两阶段结构；
  - 残差必须被重新分解和去噪，而不是直接平均；
  - 集成权重和区间系数都由多目标折中驱动；
  - 点预测与区间预测共享同一最终预测骨架。

## 实验证据

- 测试数据和设置：
  - 三个真实粮食期货价格序列：DCFP、LWFP、UWFP；
  - DCFP 样本数 2835，最大值 2954，最小值 1436，均值 2168.118，Lyapunov 指数 0.090；
  - LWFP 样本数 3024，最大值 235.1，最小值 92.25，均值 155.587，Lyapunov 指数 0.106；
  - UWFP 样本数 3081，最大值 943.3，最小值 361，均值 577.810，Lyapunov 指数 0.095；
  - 三个序列 Lyapunov 指数均为正，作者据此认为存在混沌特征；
  - 点预测指标包括 MAPE、DA、RMSE、MAE；区间指标包括 FICP、AIS、FINAW。
- 总体结果：
  - 三个真实数据集和 60 个 Bootstrap 数据集上，MAPE 为 0.392%-0.980%；
  - DA 为 59.290%-87.226%；
  - 与传统区间方法在相同置信要求下相比，FINAW 收窄 58.242%-85.714%；
  - 三步预测中，DCFP 的 MAPE 为 0.392、0.368、0.440，DA 为 60.656、65.318、66.087；
  - LWFP 的 MAPE 为 0.495、0.612、0.697，DA 为 86.706、67.575、65.574；
  - UWFP 的 MAPE 为 0.815、0.995、0.980，DA 为 87.226、59.290、68.033。
- 比较实验 I：
  - 与 ARIMA、BiLSTM、BPNN、ELM、VAF、CNN-LSTM、CNN-LSTM-HW、PatchTST 对比；
  - RL-CEEMD-MOLA 取得最低预测误差和最高方向一致性；
  - 最低 MAPE 相对改进至少 21.92%，DA 改进范围为 0.58%-37%。
- 比较实验 II：
  - CEEMD 与 VMD 对比，CEEMD 在预测误差和 DA 上整体更好；
  - 作者认为 CEEMD 参数调节成本更低，鲁棒性更强。
- 比较实验 III：
  - MOLA 与 MOSMA、MOALO、NSWOA 对比；
  - MOLA 在三步预测的误差和方向准确性上整体最佳。
- 比较实验 IV：
  - 与传统集成、等权、AdaBoost、RF、XGBoost、CatBoost 等方案对比；
  - 异构多类型子模型集成优于单类型集成；
  - 残差学习架构优于传统直接集成架构；
  - 等权策略适应性较差。
- 比较实验 V：
  - IIAC 区间与正态分布置信区间对比；
  - 除 UWFP 上 RL-CEEMD-MOLA 的 FICP 为 0.96 外，其余 FICP 均达到 1，并满足 95% 置信要求；
  - RL-CEEMD-MOLA 区间显著更窄，FINAW 在 DCFP、LWFP、UWFP 上分别降低 58.242%、85.714%、80.220%。
- 统计、消融和稳定性证据：
  - DM tests 显示主要对比改进具有统计显著性；
  - 消融显示数据处理模块、残差学习模块、残差再分解去噪都对性能有贡献；
  - MOLA 人口规模和迭代次数敏感性较小；
  - 10 次重复实验波动较小，60 个动态 block bootstrap 数据集上性能稳定；
  - QQ 图显示最终残差比初始残差更接近正态，说明残差模块提取了剩余信息。
- 复杂度和部署证据：
  - 可训练参数为 84551，略高于 CNN-LSTM 和 CNN-LSTM-HW；
  - GPU 训练约 282-297 秒，推理约 0.05-0.07 秒；
  - CPU 推理比 PatchTST 快 6.1-30 倍；
  - 作者认为适合实时、中频、小时级或离线批量预测。

## 局限与未来工作

- 作者明确说明的局限：
  - 模型仅使用历史价格序列，没有纳入汇率、利率、极端天气、地缘事件和政策变化等外生因素；
  - 在突发不确定性冲击下，预测精度会下降；
  - 异常点与融资收储、供应忧虑、干旱和地缘事件有关，历史价格单变量难以解释。
- 作者未来工作：
  - 融合汇率、利率、极端天气、地缘政治和政策变化等多源数据；
  - 建立动态调整机制，以更好应对不确定性冲击；
  - 扩展到更多粮食品种和金融市场场景。
- 我们认为仍需确认的问题：
  - MOLA 的目标函数细节在 Markdown 中部分由图片承载，需在可解析 PDF 或源码中进一步核对；
  - 残差再分解是否会在极短序列或高噪声序列中放大伪模式；
  - 模型池排除主模型后是否总能保留互补性；
  - IIAC 的覆盖优势是否需要 conformal calibration 提供更严格保证；
  - 外生冲击场景下，静态训练得到的权重和区间系数可能失效。

- 值得建立或补充的设计知识：
  - 新建 [残差再分解的多目标集成与区间调节预测](../02_design_knowledge/K-residual-redecomposition-multiobjective-ensemble-interval-forecast.md)。
- 暂留在论文卡中的方法、原理或架构启发：
  - VAF 的混沌检测和相空间重构可作为金融/能源时序的模型池成员；
  - 样本熵阈值 `mean + std` 是轻量 IMF 过滤规则，但还不够通用，不单独建卡；
  - Bootstrap 生成多数据集评估预测框架稳定性，可复用于小样本时序算法验证。
- 局部创新线索：
  - 把残差权重从全局常数改为随波动状态或 regime 变化的条件权重；
  - 用 conformal score 校准 IIAC，保留多目标宽度优化同时获得分布无关覆盖保证；
  - 用事件特征门控残差模型，在极端天气、政策或战争新闻窗口提升区间上界；
  - 将残差再分解模块与在线漂移检测结合，只在残差复杂度升高时触发。
- 结构创新线索：
  - 建立通用 two-stage forecast correction layer：任意主模型输出残差后，都可接入分解、去噪、异构残差专家和多目标权重优化；
  - 把 interval coefficients 作为可进化控制量，与 point forecast ensemble weights 一起进入 Pareto selection；
  - 在能源负荷、库存、交通流和材料性能预测中复用“主趋势-残差结构-区间调节”的三层预测骨架。
