# Turning Sparse Large-Scale Multiobjective Optimization Into Evolutionary Multitasking

## 一句话理解

论文提出 SparseEMT，把一个 sparse large-scale MOP 拆成三个协同任务：主任务在原始高维空间保持全局搜索，辅助任务 2 在由潜在非零变量 union 构成的低维空间同时探索零/非零变量，辅助任务 3 在更小的 intersection 变量空间精修最可能非零变量；三类任务通过保留原空间信息的 sparsity knowledge transfer 交换知识，避免传统低维到高维 zero-padding 带来的负迁移。

## 问题与动机

- 研究问题和场景：Sparse large-scale multiobjective optimization problems (SLSMOPs) 的决策变量维数很高，但 Pareto optimal solutions 中只有小部分变量非零。典型应用包括 feature selection、adversarial ML、neural network training、sparse signal reconstruction、portfolio optimization 等。
- 现有方法为什么不足：
  - 新变异算子类 sparse MOEA 仍主要在原始高维空间搜索，难以充分缓解维度灾难。
  - 降维类算法在低维空间搜索更快，但不能保证原空间全局最优被保留。
  - two-layer encoding 类方法常强调 zero/nonzero mask 识别，却对 nonzero variables 的连续取值精修不足。
  - 现有 EMT 可以把低维任务和原任务协同优化，但通用高低维对齐常用 dimension selection + zero-padding；低维解映射回高维时人为填 0 会破坏稀疏结构、变量相关性和 fitness landscape，引发 negative transfer。
- 本文希望解决什么：
  - 把 SLSMOP 内部的“识别零变量”和“精修非零变量”显式拆成辅助任务；
  - 保留原始高维主任务，降低降维丢失全局最优的风险；
  - 设计适合 sparse encoding 的跨任务空间对齐与知识迁移；
  - 作为通用 wrapper 嵌入已有 sparse MOEAs，提高不同编码和 solver 上的表现。

## 核心理念与算法流程

- 核心理念：一个 SLSMOP 本身包含多个相互关联的子问题：哪些变量应保持 0、哪些变量可能非零、这些非零变量取什么值。把这些子问题转成 evolutionary multitasking，让辅助低维任务负责快速识别和精修稀疏结构，主任务负责保留原空间全局可达性。
- SparseEMT 总流程：
  1. 初始化原始维度 `D` 的 population。
  2. 通过 `Multitask_Construct(D)` 构造三类任务。
  3. 每代先用 `Multitask_Update` 更新主任务和两个辅助任务的 task populations。
  4. 用 embedded optimizer 的 selection 规则选出 `N` 个 parents。
  5. 用 `Sparse_KT` 按 parents 的 skill factors 执行任务内 reproduction 或跨任务 knowledge transfer。
  6. 用 embedded optimizer 的 environmental selection 从父代和子代中选出下一代。
- Multitask construction：
  - 构造 zero vector `Base` 和 identity matrix `Mask`。
  - 进行 `NoSample` 次采样：每次生成 `D x D` random matrix，与 `Mask` 组合成只激活单变量的 population `Q`。
  - 对 `Base ∪ Q` 做 nondominated sorting；若某个单变量激活解的 front number 优于 `Base`，则认为该变量较可能为 nonzero，并存入集合 `d_i`。
  - `Task1.Dim={1,...,D}`：原始高维主任务。
  - `Task2.Dim=d_1 ∪ ... ∪ d_NoSample`：较宽的低维辅助任务，覆盖所有可能非零变量，兼顾 zero/nonzero 识别。
  - `Task3.Dim=d_1 ∩ ... ∩ d_NoSample`：更窄的低维辅助任务，聚焦最稳定的非零变量，做细粒度精修。
  - 三类任务的变量上下界由所选维度继承，保持低维与高维表示可逆映射。
- Sparsity knowledge transfer：
  - 高维到低维：只保留目标任务对应维度。
  - 低维到高维：不简单 zero-padding，而是利用 parent 保留的原空间信息重建缺失维度，避免注入无关 0 值。
  - 父代 skill factor 相同：同任务内 reproduction；主任务用 embedded solver operator，辅助任务用 SparseEMT operator。
  - 父代 skill factor 不同：根据主/辅任务组合选择在原空间、Task2 或 Task3 空间生成 offspring，并让 offspring 继承相应 skill factor。
  - 主任务可把全局优化经验传给辅助任务，辅助任务可把稀疏结构和非零变量信息传回主任务。
- 进一步策略：
  - `Multitask_Update`：主任务 population 保持 `N`，两个辅助任务各用 top `floor(N/4)` individuals 补充并重新评价，避免辅助任务进展慢导致陷入局部最优。
  - `SparseEMT_Operator`：若 embedded optimizer 用 two-layer encoding，对 real layer 做 SBX/PM，对 binary mask 做 uniform crossover/bit-flip mutation，并强制继承双亲共同非零位置和共同零位置；若为普通 genetic encoding，则直接 SBX/PM。
- 可能被修改的位置：
  - 变量重要性检测可替换为 archive activation frequency、双种群共识、Jaccard mask similarity、surrogate attribution 或 SHAP/MI；
  - Task2/Task3 可从 union/intersection 改为置信度分层、top-k、probabilistic masks 或动态维度；
  - Sparse_KT 可加入迁移收益反馈、uncertainty-aware transfer 或负迁移检测；
  - Embedded solver 可换成 SparseEA、MGCEA、S-NSGA-II、PSO/DE sparse solver 或 problem-specific repair。
- 必须保留的核心：
  - 原始高维主任务必须保留，作为全局最优可达性的锚点；
  - 至少两个辅助任务要区分“广覆盖潜在非零变量”和“窄范围非零变量精修”；
  - 跨维度迁移不能简单 zero-padding，必须保留/重建缺失维度的原空间信息；
  - 子代生成和 skill factor 需要识别任务来源，避免无条件混合造成负迁移。

## 实验证据

- 实验设置：
  - Benchmark：SMOP1-SMOP8，决策变量数 500、1000、2000、5000。
  - Real-world applications：Sparse_PO、Sparse_SR、Sparse_CD、Sparse_CN；其中 Sparse_PO 为 portfolio optimization，Sparse_SR 为 sparse signal reconstruction，Sparse_CD/CN 为 sparse function decomposition。
  - SparseEMT 被嵌入三个强 sparse optimizers：MSKEA、MGCEA、S-NSGA-II，用于与原算法成对比较。
  - 还与 MOEA/PSL、TS-SparseEA、DKCA、SCEA 四个代表性算法比较；benchmark 使用 IGD，real-world 使用 HV；Wilcoxon rank-sum test 显著性水平 0.05；每组 30 次独立运行。
  - SMOP1-8：population size 100，objectives 2，maximum evaluations `100*D`。Real-world：population size 50，maximum evaluations 100000。
- Benchmark pairwise 结果：
  - SparseEMT_MSKEA 相比 MSKEA 在 SMOP1-SMOP8、500-5000 维上表现出压倒性优势；作者认为辅助任务能累积和增强 embedded optimizer 各阶段知识。
  - SparseEMT_MGCEA 在 32 个测试问题中 20 个优于 MGCEA，SMOP8 上有轻微退化，作者认为 SparseEMT 额外评价与 MGCEA 的层级演化阶段可能存在不匹配。
  - SparseEMT_S-NSGA-II 在 SMOP1-SMOP8 的 36 个实例中 28 个统计表现最佳，说明框架也能支持非 two-layer encoding 的 sparse solver。
- Benchmark 与其他算法比较：
  - 采用 MSKEA 作为 embedded optimizer 时，SparseEMT 在 32 个 SMOP test problems 上优于 MOEA/PSL、TS-SparseEA、DKCA、SCEA。
  - Friedman test 中 SparseEMT_MSKEA 平均排名 1.00，作者认为显著优于四个对比算法。
  - 随决策变量数增加，SparseEMT 的 IGD mean 变化比其他算法更小，显示高维扩展稳定性。
- Real-world 结果：
  - 与三个 embedded optimizers 成对比较时，SparseEMT 在 14 个 real-world problem settings 上整体优于原 optimizer，且对 continuous 和 discrete SLSMOPs 都有竞争力。
  - S-NSGA-II 不支持 binary SLSMOPs，因此与 SparseEMT_S-NSGA-II 比较仅覆盖 Sparse_PO 和 Sparse_SR。
  - 与 MOEA/PSL、TS-SparseEA、DKCA、SCEA 比较时，正文称 SparseEMT 在 14 个问题中 6 个取得最好 HV；Table V 图像占位，精确数值需回查 PDF/补充材料。
- 证据边界：
  - 主文 Table II-V 多为图片占位，Markdown 无法保留全部数值。
  - Real-world HV 段落中“SparseEMT achieves a Friedman ranking of 4.07, significantly higher than MOEA/PSL (2.00), TS-SparseEA (1.86) ...”与常规“lower rank better”的 Friedman 解释存在疑似方向或表述不一致；该部分应谨慎引用。
  - 对 MGCEA 的 SMOP8 轻微退化说明 SparseEMT wrapper 与 embedded solver 的阶段机制可能产生不匹配。

## 局限与未来工作

- 作者明确说明的局限：
  - 两个辅助任务的维度在整个演化过程中保持静态，没有根据 population 变化动态调整。
  - SparseEMT 相比部分 SOTA 算法存在计算效率限制。
  - 如何设计 universal indicator 来检测是否发生 negative transfer 仍是开放问题。
- 作者未来工作：
  - 根据上一代或历史 population 信息确定下一代辅助任务维度。
  - 提高 computational efficiency，降低 time complexity。
  - 设计负迁移检测指标。
- 我们认为仍需确认的问题：
  - 单变量激活测试是否能捕捉强交互型非零变量组合。
  - Union/intersection 任务在弱稀疏、目标区域差异大或 noisy objectives 中是否稳健。
  - Task2/Task3 population size `floor(N/4)` 如何自适应。
  - 低高维重建策略在离散、混合变量和强约束 sparse problems 中如何修复可行性。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：稀疏三任务 EMT 与保结构迁移。它不同于普通动态辅助任务构造、变量类型挖掘或掩码相似性继承；重点是把一个 SLSMOP 的稀疏识别和非零精修拆成三类可迁移任务，并处理跨维度空间对齐。
- 暂留在论文卡中的方法、原理或架构启发：
  - SparseEMT 可嵌入 MSKEA/MGCEA/S-NSGA-II 的 wrapper 思路保留在本文卡中，不单独建 solver 卡。
  - Sparse_PO/SR/CD/CN 是应用和测试问题，不单独建应用卡。
- 局部创新线索：
  - 将 `Task2=union`、`Task3=intersection` 改为概率阈值任务，例如 high-confidence / medium-confidence variable groups。
  - 用双种群变量类型共识替代单变量 sampling，减少交互变量漏检。
  - 给 Sparse_KT 加迁移收益记录，按任务对自适应控制迁移概率。
  - 对 low-to-high reconstruction 加 uncertainty mask，只对高置信缺失维度继承原空间值。
- 结构创新线索：
  - 构建“原空间主任务 + 宽低维稀疏识别任务 + 窄低维非零精修任务 + 保结构迁移”的 SLSMOP 通用框架。
  - 把 SparseEMT 与 dynamic task construction 结合，让 Task2/Task3 的维度随代数、稀疏率和转移收益更新。
