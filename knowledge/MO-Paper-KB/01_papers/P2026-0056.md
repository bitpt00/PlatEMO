# Mutual risk prompt learning with multi-objective optimization for collaborative tumor and peritumor segmentation

## 一句话理解

本文把肿瘤与周围 organs-at-risk (OARs) 的联合 3D CT 分割建成带临床风险取舍的多目标多任务优化：ROJS-Net 用共享编码器和互风险 prompt 提取肿瘤/OAR 任务特定提示，再用 top-K 稀疏多门控专家解码器为不同任务动态分配专家路径，以缓解“完整肿瘤切除”和“OAR 保护”之间的优化冲突。

## 问题与动机

- 研究问题和场景：面向术前或放疗规划中的肿瘤及邻近 OAR 联合分割。恶性鼻咽癌中肿瘤侵袭性强、边界不清且靠近关键器官，临床上更强调 OAR 功能保护；良性前列腺肿瘤通常边界更清楚，完整切除肿瘤优先级更高。作者将这种随疾病场景变化的治疗优先级称为 joint segmentation 中的风险优化需求。
- 现有算法为什么不足：作者认为单独训练肿瘤/OAR 分割网络会阻断两类高度相关结构的信息共享；单一共享 encoder-decoder 的多任务网络容易引入任务干扰；共享 encoder 加任务专属 decoder 虽能减轻干扰，但仍难显式建模肿瘤与 OAR 的重叠、邻近和潜在冲突，可能导致肿瘤欠分割或 OAR 假阳性。CNN、attention、Transformer 等通用分割网络也没有显式处理任务间优化冲突。
- 本文希望解决什么：在一个统一网络中同时利用肿瘤和 OAR 的互补解剖信息，并能根据输入图像和临床场景隐式调整肿瘤/OAR 分割的优先级，从而得到更适合风险可控治疗规划的联合分割结果。

## 核心理念与算法流程

- 核心理念：用“共享特征 + 可学习通用 prompt”生成肿瘤/OAR 的任务特异风险提示，再让提示特征驱动稀疏 MoE decoder 路由。prompt 负责表达任务相关解剖风险和互补信息，MoE 路由负责在共享与专属参数之间动态折中。
- 主要流程：
  1. 输入 3D CT 图像，经共享编码器 `E(.)` 得到多尺度共享特征 `F_shared`。共享编码器由一个 Conv block 和四个带 SE/residual 的 Base block 组成，decoder 阶段设置四个结构对称的专家解码器。
  2. 互风险 prompt 模块定义可学习通用 prompt `P_universal`，将其与 `F_shared` 拼接，经 3D 卷积融合后按通道拆分为 `P_oars` 和 `P_tumor`。PDF 第 3-4 页核验公式(1)：`{P_oars, P_tumor}=Split(f(concat(P_universal,F_shared)))`。
  3. `F_shared` 分别与 `P_oars/P_tumor` 拼接，输入 OAR 和 tumor 的任务专属 gating network。
  4. 每个 gate 对四个专家解码器产生稀疏权重，只保留 top-K 专家。PDF 第 5 页核验公式(2)-(6)：`G_tumor(F)=Softmax(TopK(I(F),K))`，`I(F)` 由线性 gate 权重、噪声控制权重和 Softplus 平滑项构成，输出为 `sum_i G_i(F) ED_i(F)`；OAR 任务同理。
  5. 作者实现中 `K=2`，理由是在专家多样性、计算开销和过拟合之间折中。共享 encoder 与 prompt 模块先在大规模多器官 CT 数据上用双任务 decoder 预训练，再迁移到 ROJS-Net 微调。
- 关键组成部分：共享编码器；可学习 universal prompt；通道拆分的任务特异 prompt；四个 expert decoders；两个任务专属 sparse top-K gating networks；预训练的 prompt/encoder；Dice+CE 监督损失；dropout、weight decay、early stopping 等正则化。
- 可能被修改的位置：若把该思路迁移到其他多目标神经优化或多任务 surrogate，可替换固定加权 loss、固定多头 decoder 或静态专家选择；也可把 prompt 输入从影像特征扩展为显式风险/偏好/场景变量。
- 必须保留的核心：任务冲突不是只靠 loss 权重处理，而是通过“任务风险提示 -> 稀疏专家路由 -> 专家组合输出”形成条件化参数分配。

## 实验证据

- 测试问题和对比算法：三个 3D CT 数据集。Malignant Nasopharyngeal Carcinoma Dataset 含 739 名患者、1394 张 H&N CT，标注喉、下颌、左右颞叶、左右腮腺、口腔和原发肿瘤；Benign Prostate Tumor Dataset 含 90 例前列腺癌放疗 CT，标注 GTV、前列腺、膀胱、直肠；Public SegRap 含 120 例 NPC CT。指标为 DSC、HD95、ASD，并用 paired t-test 检验。对比 3D UNet、VNet、Attention UNet、TransUNet、SwinUNETR、UNETR++。
- 主要实验结论：
  - NPC 数据集：ROJS-Net 在肿瘤 DSC/HD95/ASD 上为 61.17%/5.20mm/4.20mm，在 OAR 上为 80.82%/5.01mm/2.96mm，整体优于对比方法；作者将其归因于复杂解剖关系建模和任务冲突缓解。Tables 1，PDF 7。
  - Benign prostate 数据集：ROJS-Net 肿瘤指标为 66.14%/5.79mm/4.24mm，OAR 为 85.06%/4.47mm/3.54mm。作者强调良性场景中完整肿瘤切除优先，互风险 prompt 能引导 MMOE 偏向肿瘤边界完整性。Table 2，PDF 8。
  - SegRap 数据集：ROJS-Net 肿瘤指标为 76.14%/7.82mm/5.26mm，OAR 为 92.42%/5.65mm/2.78mm；作者报告相对对比方法平均提升肿瘤 3.47%/3.75mm/1.30mm、OAR 1.84%/0.82mm/0.31mm。Table 3，PDF 9-10。
  - 定性图 7-9 显示作者认为 ROJS-Net 在肿瘤-OAR 边界、OAR 假阳性控制、肿瘤欠分割缓解方面更接近 ground truth；这些是作者对图像结果的解释，不应直接扩大为所有医学分割场景的事实。
- 消融或机制证据：
  - 不同 backbone 消融：在 UNet、TransUNet 和本文 backbone 上分别加入 MMOE 或 MRPL，三数据集均有不同程度提升；作者报告 MMOE 对肿瘤平均提升 2.19%/0.39%/1.09%，对 OAR 提升 1.68%/0.48%/0.81%；MRPL 对肿瘤提升 2.43%/1.40%/1.63%，对 OAR 提升 1.60%/0.49%/0.98%。Tables 4-6，PDF 11-12。
  - 多目标协同结构消融：Shared Network 最差，Multi-task Network 有改善但仍存在优化方向不一致；Independent Networks 对 OAR 有利但缺少 OAR 上下文辅助肿瘤分割；Multi-task+MMOE 优于普通多任务；ROJS-Net 最优。Tables 7-9，PDF 12-13。
  - MRPL 可视化消融：Fig. 11 展示有/无互风险 prompt 在恶性鼻咽癌和良性前列腺肿瘤中的差异，作者认为该模块能按风险水平为肿瘤/OAR 分配不同优先级。Sec. 3.10、PDF 12-15。
  - 计算效率：ROJS-Net 为 39.41M 参数、209.33G FLOPs、6.68 FPS。作者认为 FLOPs 偏高来自多专家 decoder 和 prompt 融合，但 top-K 稀疏门控限制每次激活专家数，使其适合离线治疗规划或手术辅助等非实时场景。Table 10、PDF 13-15。
  - 临床可接受性：三名临床专家用 1-5 Likert 对三数据集输出评分，平均 4.58±0.63，无病例低于 3。作者用它支持输出具有临床可信度，但该评价仍是定性补充。Discussion，PDF 14。
- 证据边界：
  - “risk” 当前为隐式解剖/语义依赖，不是显式临床风险评分；不能证明模型真正学习了复发率、剂量约束或手术安全边界。
  - 实验是医学影像分割任务，不能直接外推到传统 Pareto-front MOEA 的搜索性能；对多目标优化知识库的价值主要在“多目标/多任务冲突的神经结构调度”。
  - 两个私有数据集不可公开复核；SegRap 是公共数据集但仍限于 NPC/头颈场景。

## 局限与未来工作

- 作者明确说明的局限：受计算资源限制，专家 decoder 数量和每任务选择的专家数受约束；prompt 只在特征编码层部分缓解任务冲突；当前风险信息主要由互风险 prompt 隐式表示，在多样临床应用中有限；当前模型只考虑肿瘤与 OAR 的关系，真实临床还涉及血管、神经、剂量、副作用、手术机器人运动范围等更多风险因素。
- 作者未来工作：加入更显式的临床风险指标，如肿瘤分级、放疗剂量约束、手术安全切缘、肿瘤位置、与 OAR 距离、术后损伤严重度、复发和转移信息；进行结构化 reader studies；引入 attribution 分析和专家专属 feature visualization 来解释 gating/decoder 决策路径。
- 我们认为仍需确认的问题：top-K gate 学到的专家分工是否稳定跨数据集、扫描协议和目标器官；K=2 和四专家是否在更复杂任务中仍合适；prompt 预训练数据规模、器官覆盖和 domain shift 对性能影响多大；是否可把显式临床变量作为 prompt 输入并做可控偏好调节；是否能迁移到非影像的多目标深度模型或 MOEA 内部 learned module。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：已新建 [风险提示驱动的稀疏专家路由](../02_design_knowledge/K-risk-prompt-sparse-expert-routing.md)，因为该机制具有明确插入位置、可实现流程和消融证据，可迁移到多任务/多目标神经模型中的冲突缓解层。
- 暂留在论文卡中的方法、原理或架构启发：
  - “风险”先用隐式解剖关系建模，再逐步加入显式临床变量，可作为 risk-aware MOO 的渐进式建模策略。
  - 不同临床场景可以改变目标优先级：恶性肿瘤偏 OAR 保护，良性肿瘤偏完整切除；这可启发 preference-conditioned 或 scenario-conditioned 多目标模型。
  - 临床专家 Likert 评价可以补充传统 DSC/HD95/ASD，但仍需结构化读片研究和 inter-rater analysis。
- 局部创新线索：
  - 在多目标 surrogate 或 neural acquisition 中加入 prompt-guided sparse expert routing，让不同目标/约束/偏好区域调用不同专家。
  - 将 `P_universal` 替换为显式风险 prompt：剂量阈值、距离图、器官重要性、用户偏好权重或约束 slack。
  - 对 top-K gate 加入负载均衡、专家熵、任务公平性或可解释正则，避免少数专家长期主导。
- 结构创新线索：
  - 构建“共享表征层 + 风险/偏好 prompt 层 + 稀疏专家优化层 + 多目标输出层”的通用多目标深度优化框架。
  - 在 MOEA 中把专家 decoder 改成多个 operator/surrogate/local-search experts，用问题状态和偏好 prompt 进行稀疏路由。
