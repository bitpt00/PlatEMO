# Multi-objective walking sheep identification method through the back appearance and diversion channel

## 一句话理解

本文的 “multi-objective” 更接近多目标/多对象行走羊个体识别，而不是严格的多目标优化：作者用分流通道把羊群整理成多个单列通过流，再用顶视背部外观、轻量检测跟踪、检测框重匹配裁剪、清晰度过滤和序列投票，把自由行走场景下的羊只身份识别准确率提升到 `99.05%`。

## 问题与动机

- 应用问题：放牧和圈舍管理中，羊只每天进出栏，需要确认数量和个体身份；破损围栏或混群会造成个体丢失和归属不清。
- 接触式识别如耳缺、烙印、耳标、RFID 会增加动物应激、损伤或维护成本，也可能受脱落、污损和读取距离影响。
- face、nose print、iris、retina 等生物特征往往要求动物配合；行走状态下头部姿态变化大，脸部容易被遮挡。
- 前期研究显示背部和侧面外观比脸部更适合行走羊识别；本文进一步把羊群通过 diversion channel 整形成有序单列流，降低遮挡和速度波动。

## 核心流程

- Walking sheep detection and tracking：
  - 用 MEB-YOLOv8n 检测行走羊背部目标；
  - 用 ByteTrack 关联检测框并赋予随机 track ID；
  - ByteTrack 同时利用高、低置信度检测框，减少漏检导致的轨迹中断。
- Back image sequence extraction and filtering：
  - 对每个 track ID，在设定通道范围内提取背部图像序列；
  - 用 MIoU 在 tracking box 和全部检测框之间找最大 IoU 的检测框；
  - 以检测框而非 tracking box 裁剪背部图像，减少背景和邻近羊只干扰；
  - 对 `224 x 224` crop 计算 Laplacian variance，过滤低清晰度图像。
- Identity recognition：
  - 用 CM-MViT 对每张背部图像预测羊只身份；
  - 对同一 track ID 的图像序列投票；
  - 若投票并列，则累加类别置信度并取最大者作为最终身份。

```text
diversion channel + top-view camera
-> MEB-YOLOv8n detection
-> ByteTrack track ID
-> MIoU matched detection-box crop
-> Laplacian variance quality filtering
-> CM-MViT per-frame identity classification
-> sequence voting / confidence tie-break
```

## 模型与关键机制

- MEB-YOLOv8n：
  - 以 YOLOv8n 为轻量部署基础；
  - 用 MobileViT 替换 backbone，以更少参数保留局部卷积和全局特征；
  - 在 neck 的 C2f 中加入 ECA，形成 C2f-ECA；
  - 在 C2f-ECA 与小目标检测头之间插入 BiFormer，增强遮挡和小目标背部特征。
- MIoU 裁剪：
  - tracking box 由历史轨迹预测和关联产生，定位可能偏移；
  - detection box 由检测模型逐帧定位，通常更贴近人工标注的背部区域；
  - 因此 tracking box 负责保持目标身份链路，最大 IoU detection box 负责实际裁剪。
- 清晰度过滤：
  - 灰度化和 Gaussian filtering 后计算 Laplacian variance；
  - 作者通过不同模糊等级下的识别准确率趋势选择阈值；
  - 最终过滤 `Laplacian variance < 35` 的图像。
- 区域提取窗口：
  - 比较 `0-1`、`1/6-5/6`、`1/4-3/4`、`Mid-1/2` 和 `All-Screen`；
  - `1/6-5/6` 在保证图像数量的同时避开入口/出口不稳定区域，取得最高平均识别准确率。
- CM-MViT：
  - 以 MobileViT 为基础；
  - 在每个 MobileViT block 的 Convolutional Projection 和 Convolutional Fusion 之间加入 ECA；
  - 在 Convolutional Fusion 后加入 EMA，强化通道、空间和多尺度背部纹理特征。

## 数据与实验设置

- 实验 1：检测模型数据。
  - 时间为 2023 年 7 月和 2024 年 6 月；
  - 三个羊群：75 只 juvenile goats、80 只 adult goats、61 只 adult sheep；
  - 设计 16 个正交试验组合，其中 2 个因天气和羊群移动未实施；
  - 因素包括 flock type、是否分流、光照、相机高度和通道背景色；
  - 每群 20 次通过，视频为 `15 FPS`、`1280 x 720`。
- 实验 2：个体身份识别数据。
  - 74 只 adult sheep；
  - 采用 diversion channel、black background、overcast、camera height `385 cm`；
  - 采集 39 段 `15 FPS`、`1920 x 1080` 视频。
- 检测数据集：
  - 90 段视频抽帧，去除无羊、模糊和高相似图像；
  - 原始图像共 4490 张，按 `8:1:1` 划分为 train/val/test；
  - 训练集经随机裁剪、镜像、旋转、噪声、颜色变换和 SRGAN 扩增到 19,531 张。
- 身份识别数据集：
  - 10 段实验 2 视频用于 ByteTrack 调参和 CM-MViT 训练；
  - 74 只羊编号为 `001-074`；
  - 去除模糊、不完整和过高相似图像后得到 6230 张；
  - 按 `7:1:2` 划分，并把每只羊的训练图像扩增到 200 张，总训练集为 14,800 张。
- 整体视频识别评估使用实验 2 中剩余 19 段视频。

## 训练与指标

- 硬件与软件：Windows 11，Intel i9-13900K，64 GB RAM，NVIDIA RTX 3090 24 GB，CUDA 11.8，PyTorch 2.0.1，Python 3.11。
- MEB-YOLOv8n：
  - input size `640 x 640`；
  - SGD，initial learning rate `0.001`，momentum `0.937`，weight decay `0.0005`；
  - batch size `16`，300 epochs。
- ByteTrack：
  - `Track_high_thresh=0.5`；
  - `Track_low_thresh=0.1`；
  - `Match_thresh=0.91`。
- CM-MViT：
  - ImageNet pretrain；
  - input size `224 x 224`；
  - SGD，initial learning rate `0.0125`，step decay every 2 epochs，decay `0.973`；
  - momentum `0.9`，weight decay `0.0001`；
  - batch size `32`，500 epochs。
- 指标：
  - 检测：Precision、Recall、AP、mAP@0.5、mAP@0.5:0.95；
  - 分类：Top-1、Top-5、Mean Precision、Mean Recall、Mean F1；
  - 视频身份识别：accurate identification number、accuracy rate、average accuracy rate。

## 主要结果

- 检测模型：
  - MEB-YOLOv8n 的 Precision 为 `97.43%`，Recall 为 `96.12%`；
  - mAP@0.5 为 `98.69%`，mAP@0.5:0.95 为 `82.85%`；
  - 参数量 `1.19M`，FLOPs `5.5G`；
  - 相比原始 YOLOv8n，mAP@0.5 提升 `0.48%`，参数量降到约 `0.4x`。
- 身份识别模型：
  - CM-MViT 的 Top-1 为 `96.44%`，Top-5 为 `99.34%`；
  - Mean Precision/Recall/F1 分别约为 `96.42%`、`96.46%`、`96.33%`；
  - 相比 MobileViT，Top-1 提升 `1.31%`，Mean F1 提升 `1.29%`，参数和 FLOPs 增幅很小。
- 清晰度过滤：
  - 当 Laplacian variance 阈值提高到 35 后，低质图像导致的错误明显减少；
  - 在 All-Screen 设置下，阈值 35 使整体平均识别准确率提升约 `1.32%`，FPS 也提升约 `1.42%`。
- 提取区域：
  - `1/6-5/6` 提取窗口达到最高平均识别准确率 `99.05%`；
  - `Mid-1/2` FPS 最高，但图像数量较少，准确率低于 `1/6-5/6`；
  - 方差分析显示 extraction method 对识别结果显著，experimental group 及交互项不显著，说明方法排序较稳定。
- 机制观察：
  - Grad-CAM++ 显示 MEB-YOLOv8n 更集中关注羊背区域，背景噪声更少；
  - CM-MViT 更聚焦毛发纹理和外部纹理；
  - 即使 ByteTrack 把同一只羊切成多个 track ID，若每段序列识别正确，最终身份仍可由投票保持一致。

## 与知识库相关的设计知识

- 新增/关联设计知识：
  - `K-controlled-channel-sequence-vision-identification`：受控通道序列视觉个体识别。
- 与已有设计知识的区别：
  - 不同于 `K-pareto-data-association-online-tracking-selection`：该知识把在线跟踪的数据关联本身建模为多目标组合优化；本文没有 Pareto 搜索，而是用 ByteTrack 保持轨迹、MIoU 选择检测框裁剪，再由序列投票完成身份识别。
  - 不同于一般轻量检测网络结构知识：本文的可复用价值不只是 MobileViT/ECA/BiFormer/EMA 模块组合，而是“物理分流 + 顶视背部外观 + 轨迹级序列证据”的系统架构。
  - 不同于单帧动物脸/鼻纹识别：本文主动避开需要配合的正面特征，利用更稳定的背部纹理和通道内连续多帧证据。

## 局限与未来工作

- 本文不是严格的多目标优化论文，缺少目标冲突建模、Pareto 搜索和多目标指标；其价值主要在工程识别系统架构。
- 系统仍依赖较强计算资源，作者指出终端低功耗部署存在困难，未来需要 pruning、distillation 和 deployment optimization。
- 方法依赖相对稳定的背部外观；剪毛、毛发生长、污染或季节变化会降低识别可靠性。
- 作者建议在背部外观稳定周期内运行系统；外观变化较大时，可重新采集背部图像并只更新 CM-MViT，检测、跟踪和提取模块可以保持不变。
- 对渐变外观仍需研究更新间隔和 incremental learning。
- Data availability：Data will be made available on request。
