# Multiobjective Simulated Annealing-Based Stopwords Substitution for Rubbish Text Attack

## 一句话理解

论文将 rubbish text attack 建成约束多目标优化问题，在保持模型原预测和高置信度的约束下最大化文本修改/语义混乱，并提出 MOSA-S2：用 stopwords 或语义反向词替换实义词，再用非支配排序和 Metropolis 温度接受机制的多目标模拟退火搜索替换优先级。

## 问题与动机

- 研究问题和场景：NLP 模型不仅对微小 adversarial perturbations 过度敏感，也可能对大幅语义破坏过度不敏感。Text rubbish examples 指对人类近乎无意义、但模型仍保持原预测甚至更高置信度的文本。
- 为什么重要：
  - 可评估模型鲁棒性和解释方法在“语义被破坏但预测不变”情况下的失败；
  - 可作为训练样本提升模型鲁棒性和泛化；
  - 可作为 post-hoc explanation，暴露模型是否依赖 spurious cues 而非语义理解。
- 现有算法为什么不足：
  - Input Reduction 通过删除不重要词保持预测，但常导致 model confidence (MC) 下降，且剩余词可能仍包含明显类别证据。
  - AGPS 用 preposition substitution 和 annealing genetic algorithm，但把 modification rate 与 MC 加权成单目标，权重主观且难覆盖 Pareto tradeoff；遗传退火还需要较多查询。
  - 简单删除或固定 preposition 替换限制了 rubbish examples 的多样性和语义混乱程度。
- 本文希望解决什么：同时提高修改率、模型置信度、文本混乱度和查询效率，并证明模型对语义破坏的 undersensitivity 在多种 DNN 和 LLM 上存在。

## 核心理念与算法流程

- 核心理念：把 rubbish text attack 转成 multiobjective constrained optimization：约束是模型预测标签保持不变；目标是最大化输入与输出的差异，同时保持原标签高置信度。由于修改率和置信度冲突，不用固定权重，而是用 Pareto dominance 对候选修改排序，并用模拟退火概率接受非支配等级较差但可能跳出局部最优的解。
- 主要流程：
  1. 对输入文本做 POS tagging，只允许替换 nouns、adjectives、verbs、adverbs 等实义词。
  2. 从 NLTK English stopwords corpus 构造无意义替换候选；对每个可替换词，选择能最大化原标签预测概率的 stopword 作为该词的最佳替换。
  3. 用 gradient-based word importance ranking 估计每个词对模型预测的贡献，优先考虑不重要词以减少预测翻转。
  4. 在每个温度下，根据重要性反比和 sampling radius 选出候选词集合。
  5. 用 importance-based composite perturbation 生成候选：先单词替换，若预测仍不变，再尝试二次替换，形成候选解集。
  6. 对候选解集按 NSGA-II fast nondominated sorting 分层，得到每个候选的 nondomination rank。
  7. 若新解 Pareto 支配当前解，则直接接受；否则按与 rank 和温度相关的 Metropolis probability 接受，允许跳出局部最优。
  8. 按 `alpha=0.9` 降温，最低温度由输入长度自适应设置；最终输出满足修改限制的 rubbish text。
  9. Grammatically constrained variant 中，nouns/verbs 选择语义相似度最低且 POS 一致的候选，adjectives/adverbs 优先用 WordNet antonyms，并做形态修正，使文本更可读但语义偏离更大。
- 关键组成部分：stopwords substitution、POS 过滤、gradient-based importance ranking、importance-based single/double composite perturbation、nondominated sorting、Pareto-rank Metropolis acceptance、adaptive temperature schedule、grammatical constraints。
- 可能被修改的位置：候选词库、重要性评估、扰动邻域、非支配排序目标、接受概率、温度调度、语法约束、查询预算控制。
- 必须保留的核心：用 Pareto dominance 处理“更大修改率 vs 更高模型置信度”的冲突，并允许温度控制下接受非改进解，以避免固定权重/贪心顺序陷入局部最优。

## 实验证据

- 测试问题和对比算法：
  - Datasets：MR、IMDB、AG News、SNLI、MRPC、QQP；每个数据集随机选 500 instances 做主实验，SNLI 只修改 hypothesis。
  - Victim models：CNN、LSTM、BERT、RoBERTa、ALBERT、DistilBERT、XLNet。
  - Baselines：Input Reduction (IR)、AGPS。
  - Metrics：model confidence (MC)、modification rate (MR)、perplexity (PPL)、semantic similarity (SIM)；理想攻击为高 MC、高 MR、高 PPL、低 SIM。
  - 框架：TextAttack；代码链接由论文给出为 `https://github.com/soar-create/MOSA-S2`。
- 主要实验结论：
  - Stopwords substitution：MOSA-S2 在所有 victim models 和 datasets 上 MC 均优于两个 baselines，平均比 IR 高 `11.39%`、比 AGPS 高 `3%`；生成样本平均 MC 比原输入还高 `4.53%`。
  - Multiobjective simulated annealing：MOSA-S2 在 MR 上比 IR 高 `6.54%`、比 AGPS 高 `4.19%`，同时达到最高 MC 和 MR，作者据此认为其更能平衡冲突目标。
  - Rubbish quality：MOSA-S2 的 PPL 比 IR 高 `29.84%`、比 AGPS 高 `13.05%`，说明文本更混乱/低流畅；SIM 也保持优势。
  - Efficiency：在同样把 AGPS 候选扩展为 stopwords 后，MOSA-S2 消耗更少 queries 并生成更高质量样本。
  - Human evaluation：IMDB 和 SNLI 各 50 examples，3 名 annotators 按 plausibility/grammaticality 评分；MOSA-S2 得到最低 plausibility 和 grammaticality，符合“对人类无意义”的目标。
- 消融或机制证据：
  - Without nondominated sorting：用 AGPS 推荐权重做单目标 SA，MC 下降 `7.06%`、MR 下降 `4.22%`，说明非支配排序对双目标平衡重要。
  - Without composite disturbance：只用 single replacement，候选多样性下降，MC/MR 退化。
  - Without gradient-based ranking：随机词序更易过早改到关键词并导致预测翻转。
  - Without temperature-based probabilistic acceptance：只接受严格支配当前解，MC 下降 `3.75%`、MR 下降 `3.25%`，说明退火式接受帮助跳出局部最优。
  - Model retraining：向 MR 训练集中加入 500/1000/2000 个 rubbish samples 并用 negative weights 重训 BERT，降低 reattack 中 MR/MC、保留更多语义，并在测试准确率上带来更强 robustness improvement。
  - Transferability：BERT 上生成的 rubbish samples 对 CNN、RoBERTa、ALBERT、DistilBERT 具有较强 transferability；MOSA-S2 优于 baselines。
  - Candidate lexicon：SW-10、SW-NLTK、SW-spaCy 等均保持高 MR；MRPC 上 MC 从 `95.84%` 到 `98.06%`，MR 约 `96%` 稳定。SW-10 仅 `960` queries，SW-spaCy 为 `23875` queries，查询增加主要来自候选空间扩大。
  - Grammatically constrained variant：AG News 上 query count 从 SW-NLTK 的 `13893` 降到 `278`，MC 仍有 `97.36%`；可读性和语法连贯性提高，同时引入语义反向线索误导人类。
  - LLM experiments：Llama-2-Chat-7B、Vicuna-7B、GPT-3.5、GPT-4o 均可观察到 undersensitivity；Llama-2 在 AG News 上 MC 从 `95.44%` 增到 `98.30%`；GPT-4o 更稳健，MR `67.89%` 且 MC 从 `86.59%` 降到 `79.65%`。
- 参数实验：
  - `K=15`：internal simulation steps 小于 15 时 MR 上升，之后趋于平稳。
  - `T0=1000, alpha=0.90`：在 AG News/BERT 网格搜索中取得探索与收敛折中。
  - `delta=2`：采样半径过大引入噪声并降低 MC。
  - `beta=100`：用于缩放 nondominated rank differences 和 temperature，使接受概率稳定。
- 证据边界：
  - 表格多为图片占位，逐模型/逐数据集的具体数值需回 PDF。
  - 这是攻击/鲁棒性评估方法，真实部署中应作为安全审计与防御训练工具，而非无约束滥用。
  - LLM 实验样本量较小：开源模型每个相关数据集 200 samples，GPT-3.5/GPT-4o 仅 AG News 100 samples。
  - Human evaluation 只覆盖 IMDB/SNLI 和 3 名 annotators，主观评分可能受样本选择影响。

## 局限与未来工作

- 作者明确说明的局限：
  - Grammatically constrained variant 不保证 perfect grammaticality，只通过 POS 和 morphology constraints 改善可读性。
  - LLM 部分显示闭源模型更稳健但仍不完美，相关评估尚可扩大。
- 作者未来工作：
  - 将方法扩展到测试 pretrained language models 和 interpretation methods 的鲁棒性；
  - 缓解 undersensitivity 以保证鲁棒决策；
  - 探索 excessive sensitivity 与 undersensitivity 之间的 tradeoff。
- 我们认为仍需确认的问题：
  - MOSA-S2 在多语言、长文档、多标签和生成式任务中的目标定义如何调整。
  - MC/MR/PPL/SIM 是否足以区分“无意义”与“语义反转但可读”的两种攻击目标。
  - 语法约束版更接近 stealthy attack，防御训练时应如何避免引入有害分布偏差。
  - LLM prompt 分类的置信度如何校准，不同 API/采样设置会不会改变 MC 结论。
  - 防御训练中 negative weights 的设置与 clean accuracy/robustness tradeoff 仍需系统研究。

- 值得建立或补充的设计知识：

- 暂留在论文卡中的方法、原理或架构启发：
  - Stopword frequency analysis 可作为候选库压缩策略：先用高频有效替换词形成 SW-10 小词库，在低查询预算下运行。
  - Grammatically constrained variant 表明“语义偏离”和“语法可读”可以分开建目标，适合更真实的鲁棒性审计。
  - Rubbish samples 可以作为 undersensitivity 的专门评估集，与传统 adversarial examples 共同构成 oversensitivity/undersensitivity 双端压力测试。
- 局部创新线索：
  - 将 nondominated rank acceptance 改成 crowding-aware acceptance，避免只按 rank 接受导致 Pareto front 覆盖不足。
  - 把 MC/MR/PPL/SIM 四指标直接作为多目标，而不是只优化 MC/MR、用 PPL/SIM 评价。
  - 用 bandit 或 Bayesian optimization 调节 `K,T0,alpha,delta,beta`，减少人工参数调优。
  - 将 candidate selection 从最大 MC 改为同时考虑 MC、PPL、SIM 和 human plausibility proxy。
- 结构创新线索：
  - 构建 NLP robustness audit：clean accuracy -> adversarial sensitivity -> rubbish undersensitivity -> transferability -> retraining mitigation。
  - 将 MOSA-S2 作为通用 discrete candidate priority optimizer，服务于可解释反事实、输入消融、鲁棒训练样本生成和模型诊断。
