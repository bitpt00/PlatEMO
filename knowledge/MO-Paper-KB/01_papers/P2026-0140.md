# An evolutionary multi-objective optimization framework for polyp tracking in endoscopy videos

## 一句话理解

论文提出 EndoTrack，用于内镜视频中的在线息肉多目标跟踪。它先用 12 维非线性 EKF 预测息肉位置、姿态和形变，再把每帧检测与轨迹的数据关联建模为三目标组合优化：最大化空间重叠、外观一致性和检测置信度。NSGA-II 产生非支配关联矩阵后，系统先用 knee point 筛选数学折中，再用层级视觉优先级选择更符合临床连续性的单个关联方案。

## 问题与动机

- 研究问题和场景：
  - 结肠镜检查中，单帧息肉检测不能保证跨帧身份连续、漏检恢复和稳定计数；
  - 内镜有快速平移、旋转、镜头退出、组织非刚性形变、遮挡、反光和气泡等伪影；
  - 在线 tracking-by-detection 框架需要在每帧快速决定已有轨迹、检测、新轨迹和假阳性之间的关联。
- 现有算法为什么不足：
  - 普通 Kalman/SORT 类线性运动模型难表达内镜视角下的加速度、旋转和形变；
  - Hungarian/线性分配通常把 IoU、ReID 和置信度压成固定权重单目标，一旦空间线索和外观线索冲突就容易误关联；
  - 只按 IoU 或级联优先级会在快速镜头旋转、低帧率、大位移和临时遮挡下丢失身份；
  - 延迟确认新轨迹可减少假阳性，但会牺牲医疗筛查中更重要的高召回。
- 本文希望解决什么：
  - 用非线性 EKF 保持更符合内镜几何和息肉形变的轨迹状态；
  - 用 Pareto 数据关联保留多种互补线索的非支配假设，而不是提前固定权重；
  - 用 knee point + hierarchical visual prioritization 在在线系统中从 Pareto front 中稳定选出一个可执行关联矩阵；
  - 在临床长视频和公开数据集上同时提高 MOTA、IDF1 和 HOTA。

## 核心理念与算法流程

- 核心理念：
  - 将在线多目标跟踪的关键瓶颈从“单目标匹配分数设计”改成“多目标关联矩阵搜索 + 任务优先级选解”；
  - 先保留 IoU、外观、置信度之间的 Pareto trade-off，再在非支配候选中选择符合内镜连续性的方案。
- 主要流程：
  1. 每帧由 YOLO-OB 检测息肉框和置信度，并由 AdaSP ReID 提取 2048 维外观特征；
  2. 对已有轨迹执行 12 维非线性 EKF 预测，状态包含中心、长宽比例、高度、方向、速度、加速度、形变率和角速度等；
  3. 构造大小为 `(m+2) x n x 3` 的 utility tensor，其中 `m` 是已有轨迹数，`n` 是当前检测数，额外两行分别表示新轨迹初始化和假阳性吸收；
  4. 决策矩阵 `X in {0,1}^{(m+2) x n}` 表示检测由哪个轨迹/虚拟行解释；每个检测必须被解释一次，每条真实轨迹至多匹配一个检测，虚拟行允许多次使用；
  5. NSGA-II 在 10 代内搜索非支配关联矩阵，目标为最大化 IoU、外观 cosine similarity 和检测 confidence；
  6. 先用 knee point metric 选择最大边际收益候选子集，再按 IoU、外观、置信度的层级视觉优先级做最终 tie-break；
  7. 匹配轨迹用 EKF 更新，新检测立即初始化候选轨迹，短于 5 帧的轨迹后处理删除为伪影。
- 关键组成部分：
  - 12D nonlinear EKF motion predictor；
  - 多目标 data association decision matrix；
  - NSGA-II bounded per-frame search；
  - knee point + HVP 双阶段 Pareto 选解；
  - occlusion momentum decay、boundary-aware morphology correction、high-recall initiation with temporal pruning。
- 可能被修改的位置：
  - 把 NSGA-II 替换为 MOEA/D、局部搜索、hybrid exact-heuristic 或 surrogate-assisted assignment；
  - 把三目标扩展为不确定性、遮挡风险、时间一致性、实例分割质量或临床危险等级；
  - 将 HVP 从固定 IoU-first 改成基于场景状态、检测不确定性或医生偏好的动态优先级；
  - 对高目标密度视频加入 candidate pruning 或 coreset appearance matching 降低每帧延迟。
- 必须保留的核心：
  - 数据关联矩阵的可行性约束必须表达一检一归属、真实轨迹至多一检、虚拟行可多归属；
  - 多个互补关联线索应先以 Pareto 候选形式保留，不能过早压成固定权重；
  - 在线系统最终仍需可复现的单解选择层，否则 Pareto front 不能直接驱动 tracker update。

## 实验证据

- 测试问题和对比算法：
  - 数据集：Union 自采高清临床数据、SUN-SEG、CVC-ClinicDB；
  - Union 包含 24 个完整临床过程，过滤后 58,548 个阳性帧，测试用 2 个序列；
  - SUN-SEG 包含 500 个序列、49,136 帧，覆盖多种息肉病理和形态；
  - CVC-ClinicDB 包含 612 帧低分辨率数据，用于低帧率、大位移和多目标关联压力测试；
  - 对比算法包括 DeepSORT、ByteTrack、OC-SORT、BoT-SORT、StrongSORT、TrackTrack；
  - 指标包括 MOTA、IDF1、HOTA、MOTP、IDSw、Precision、Recall、MT、FPS。
- 实现设置：
  - 前端检测器为 YOLO-OB；
  - AdaSP ReID 用训练划分中的 32,067 个样本训练；
  - NSGA-II 使用 inspyred v1.0.2，随机种子 241001；
  - `Npop=10 x n` 并裁剪到 `[30,60]`，每帧 10 代；
  - 推理硬件为 Intel i5-12400 CPU 和 NVIDIA RTX 2060 GPU；
  - Union 的最大轨迹年龄设为 500 帧以支持长时重识别，SUN-SEG 和 CVC-ClinicDB 设为 5 帧以防 ghost trajectory。
- 主要实验结论：
  - Union 使用 YOLO-OB 检测时，EndoTrack 达到 75.9% MOTA、43.6% HOTA、45.9% IDF1、79 次 IDSw、20.2 FPS；相对 TrackTrack，MOTA +2.5%，IDF1 +16.8%；
  - Union 使用 GT labels 时，EndoTrack 达到 96.8% MOTA、71.7% HOTA、68.1% IDF1，显示关联层本身的优势更明显；
  - CVC-ClinicDB 上 EndoTrack 的 MOTA 为 73.4%，高于 BoT-SORT 61.4% 和 TrackTrack 66.8%；IDF1 83.3% 略低于 BoT-SORT 86.0%，作者解释为优先保证高召回和即时建轨；
  - SUN-SEG 上 EndoTrack 达到 98.5% MOTA、83.4% HOTA、97.8% IDF1、24 次 IDSw，整体优于 TrackTrack 和通用 MOT；
  - Union 30 次不同 NSGA-II 随机种子、SUN-SEG 500 个序列的 Wilcoxon signed-rank test 均显示关键指标相对 TrackTrack 的改进显著，`p < 0.001`。
- 消融或机制证据：
  - 目标消融：只用 IoU 的 MOTA/IDF1 为 10.8/8.5；IoU+confidence 为 45.8/10.8；IoU+ReID 为 31.3/4.2；三目标完整模型达到 75.9/45.9，并把 IDSw 降到 79；
  - Fig. 4 显示在内镜突然旋转、IoU 近 0 时，外观和检测置信度仍可帮助正确延续身份；
  - 选解消融：随机选 Pareto 解 MOTA 29.4；只用 KP 为 66.0；只用 HVP 为 61.3；KP+HVP 为 75.9，说明数学折中筛选和临床优先级互补；
  - 运动预测消融：12D EKF 相比标准线性 KF 将 MOTA 从 70.1 提高到 75.9，HOTA 从 43.3 到 43.6，IDSw 从 88 降到 79，但 IDF1 从 46.3 略降到 45.9；
  - 运行时分析：YOLO-OB 和 AdaSP 分别约 22ms、9ms，运动预测和 MOEA 数据关联合计约 18ms，整体 20.2 FPS。
- 证据边界：
  - MOEA 的实时性依赖息肉同帧数量通常很少；若目标密度高或要求超过 30 FPS，迭代搜索和 Pareto sorting 会成为瓶颈；
  - CVC-ClinicDB 上 IDF1 不是最优，说明大位移/低帧率时多目标关联仍可能牺牲身份一致性；
  - TrackTrack 的离线阶段使 FPS 不完全可比；
  - 检测器 YOLO-OB 的高召回是整体 tracking 表现的重要前提。

## 局限与未来工作

- 作者明确说明的局限：
  - NSGA-II 的迭代适应度评价和非支配排序引入不可忽略的计算开销；
  - 人群规模和迭代代数等超参数可能需要跨内镜模态重新调节；
  - 多目标关联依赖所选目标的可靠性和互补性；
  - 极低帧率或大位移下，运动连续性变弱，空间和外观线索可能同时模糊，导致 IDF1 不如某些特化启发式 tracker。
- 作者未来工作：
  - 引入 online coreset-based appearance modeling，减少冗余特征缓冲并提升长时遮挡后的 point-to-set matching；
  - 用 fast surrogate models 或 hybrid optimization + deterministic pruning 降低关联延迟；
  - 加入 uncertainty-aware objective weighting，在极端成像条件下自适应调整优先级。
- 我们认为仍需确认的问题：
  - HVP 固定优先 IoU 在大位移或低帧率下可能不总是合理，是否应由场景状态切换到 appearance-first 或 confidence-first；
  - 虚拟行新轨迹/假阳性的 objective 设计细节需要复现代码进一步确认；
  - NSGA-II 随机性虽经 30 次运行验证，但每帧在线抖动对医生视觉体验的影响仍需用户研究；
  - 复杂多息肉场景下的 Pareto front 规模、选解稳定性和延迟上界还需更密集数据验证。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：[Pareto 数据关联的在线跟踪选解层](../02_design_knowledge/K-pareto-data-association-online-tracking-selection.md)。它抽象出“关联矩阵多目标搜索 + 虚拟假设行 + knee/HVP 单解选择”的在线决策模式，可迁移到多目标视觉跟踪、传感器融合、机器人目标管理和医疗视频分析。
- 暂留在论文卡中的方法、原理或架构启发：
  - 12D nonlinear EKF 是内镜场景的领域运动模型，具体状态设计较依赖息肉框和镜头几何，暂不单独建通用设计知识；
  - occlusion momentum decay 和 boundary-aware morphology correction 是有价值的 tracking 工程机制，但属于本文框架的局部稳健化组件；
  - high-recall initiation with temporal pruning 可迁移到医疗筛查或安全预警，但需要更多跨论文证据后再独立提升。
- 局部创新线索：
  - 在 NSGA-II 初始化中加入上一帧优秀关联矩阵、Hungarian 解或高置信 greedy 解，减少每帧搜索代数；
  - 将 HVP 改成 uncertainty-gated priority：运动预测不确定时降低 IoU 优先级，外观漂移时提高 confidence 或历史一致性；
  - 对虚拟新轨迹/假阳性行加入显式假设成本，形成四目标或约束化关联；
  - 用 archive smoothing 限制相邻帧所选 Pareto 解突变。
- 结构创新线索：
  - 构建“在线感知 MOO 决策层”：perception backbone -> multi-objective hypothesis tensor -> bounded MOEA/heuristic Pareto search -> task-prior selector -> state update；
  - 将多目标数据关联扩展到多传感器系统，把不同传感器可靠性、空间一致性、时间连续性和任务风险作为 Pareto objectives；
  - 让医生或下游系统通过 reference point 或 lexicographic rule 动态改变关联优先级，实现风险敏感跟踪。
