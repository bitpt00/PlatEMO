# Hybrid evolutionary framework with multiple fragmentation strategies and reinforcement learning for multi-objective molecule generation

## 一句话理解

论文提出 RL-GFM：在 NSGA-II 分子进化框架中，不依赖预定义 fragment library，而是用网格父代配对和 scaffold 保护的 fragment-masked crossover 扩展片段组合空间，再用两个 actor-critic 策略分别学习交叉父代选择和突变规则选择，以同时优化分子性质、合成可达性、novelty 和 docking 等多目标。

## 问题与动机

- 研究问题和场景：
  - 面向 de novo molecular generation 和 fragment-based drug discovery (FBDD)，希望在大化学空间中生成同时满足多种性质的候选小分子。
  - 典型目标包括 PMO benchmark score、synthetic accessibility (SA)、novelty、QED 和 protein docking score。
- 现有方法为什么不足：
  - 传统 FBDD 常依赖预定义 fragment libraries，探索空间被库限制，并且维护 fragment vocabulary 有成本。
  - 许多深度生成模型把 fragment assembly 变成黑箱，解释性弱，也难清晰处理多性质权衡。
  - 部分遗传算法或片段重组方法用单目标或加权和优化，容易牺牲真实的多目标 trade-off。
  - 随机 walk 式 crossover/mutation 在复杂多属性空间中性能不稳定。
- 本文希望解决什么：
  - 用显式 SMILES/键切割/重组操作保留可解释的生成过程；
  - 不预先维护固定 fragment library，而是在进化中动态切割和重组分子；
  - 让 RL 学会选择更有潜力的交叉父代和突变规则；
  - 用 MOEA 框架保持多目标搜索和 Pareto selection。

## 核心框架 RL-GFM

- 总体流程：
  1. 从 ZINC250K 随机采样 100 个初始分子，并按文献规则过滤 GSK alerts、macrocycles、过多卤素、过多 rotatable bonds、过多 HBD/HBA 等。
  2. 根据任务定义多目标 fitness。
  3. 用三类 variation 生成候选：grid-based fragment-masked crossover、RL-guided crossover、RL-guided mutation。
  4. 合并父代和子代后，用 NSGA-II fast non-dominated sorting 与 crowding distance 选择下一代。
- Grid-based parent pairing：
  - 在 objective space 中按每个目标分成 5 个区间，形成 `5^M` 个 grid cells。
  - 每个非空 grid 中选择一个 grid ideal point。
  - 局部层面：cell 内解与该 cell 的 ideal point 配对，保持 intra-grid diversity。
  - 全局层面：所有 grid ideal points 与 global ideal point 配对，促进 inter-grid convergence。
- Fragment-masked crossover：
  - 将分子划分为 protected scaffold 和可修改 side chains。
  - scaffold 内部键以及 scaffold-side-chain 连接键被 mask 为 0，不切割。
  - side-chain 内部键被 mask 为 1，可随机断裂并重组。
  - 这样在保护核心药效团/稳定 scaffold 的同时，在外围 substituents 上引入组合创新。
- RL-based crossover：
  - Crossover actor 是带 cross-attention 的 transformer decoder。
  - 当前分子和候选父代用 Morgan fingerprint 经过共享两层 MLP 编码。
  - actor 输出当前分子与候选父代的配对概率；critic 估计当前分子状态价值。
- RL-based mutation：
  - Mutation actor 是两层 ReLU MLP，输出 89 个 SMART reaction mutation rules 的选择概率。
  - mutation critic 是线性 value head。
- Reward / loss：
  - 两个策略共用 actor-critic 框架。
  - 若 offspring 是 Pareto-optimal，reward 为 offspring 多目标向量的 geometric mean `GMean(f_off)`。
  - 若 offspring 非 Pareto，reward 为 `-epsilon`。
  - 若重复使用同一 parent pair，则 reward 为 `-GMean(f_off)`。
  - 作者选择 GMean 是为了避免单一目标主导 RL 更新，让 RL 学到多目标均衡的父代/突变选择。
- Multi-objective fitness：
  - PMO benchmark：用 adaptive weighting，把 PMO score 作为主目标，并用 sigmoid decay 系数调节 score 与 normalized SA 的复合目标，避免过早牺牲主任务分数。
  - Docking task：完全属性分离，三目标为 normalized docking score、QED 和 normalized SA。

## 实验证据

- PMO benchmark：
  - 使用 23 个 PMO tasks，oracle query 上限为 3000。
  - 指标为 top-10 molecules 平均 property score 随 oracle calls 的 AUC。
  - Baselines 包括 REINVENT、Graph-GA、SELFIES-REINVENT、GPBO、STONED、LSTM-HC、f-RAG、Genetic-GFN、Mol-GA 等。
  - RL-GFM 在 23 个任务总分为 18.007，相比第二名 f-RAG 提升 6.4%，相比最弱 baseline LSTM-HC 提升 47.3%。
  - 相似性任务上表现突出，例如 albuterol_similarity 为 0.995，mestranol_similarity 为 0.939。
  - 作者也指出 ranolazine_mpo 上 f-RAG 更好，因为检索/拼接已知相关结构可更直接逼近目标；RL-GFM 更偏广泛探索和 novelty。
- Diversity / novelty / SA：
  - Table 2 中 RL-GFM 的 top-100 平均 diversity 为 0.573，novelty 为 0.912，SA 为 2.332，优于 Genetic GFN、Mol-GA 和 REINVENT 的综合平衡。
  - 摘要也强调 structural novelty rate 超过 90%。
- Docking tasks：
  - 目标蛋白为 PARP1、FA7、5HT1B、BRAF、JAK2；用 QuickVina 2 计算 docking score，同时保留 QED 与 SA。
  - top 5% novel candidates 需满足 Tanimoto similarity < 0.40、docking score 低于 known actives median、QED > 0.50、SA < 5.0。
  - Table 3 中 RL-GFM 在 5 个靶点上 docking score 均最佳：PARP1 `-12.960±0.01`、FA7 `-10.310±0.03`、5HT1B `-13.343±0.2`、BRAF `-12.671±0.05`、JAK2 `-12.090±0.07`。
  - Table 4 中 RL-GFM 在 4/5 个靶点 novel hit ratio 最高，5HT1B 达 `70.070±5.051`，FA7 达 `35.570±1.547`。
- 消融与机制：
  - Fig. 4 中 NSGA-II w Grid 优于 NSGA-II baseline，说明 grid fragment-masked crossover 提升化学空间探索效率。
  - Full RL-GFM 进一步优于 NSGA-II w Grid，说明 RL-guided operators 带来额外定向搜索收益。
  - Operator contribution analysis 显示早期 grid operator 占主导，用于扩大多样性；中后期 mutation/crossover 更主导，用于精修候选。
- 复杂度与运行：
  - 主导复杂度仍为 NSGA-II 的 `O(MN^2)`；grid pairing 为 `O(NM)`；RL variation 被作者认为是个体级常数开销。
  - 每代总复杂度为 `O(MN^2)`，总计 `O(GMN^2)`。
  - RL-crossover 和 RL-mutation 每个 PMO task 在单张 RTX 3090 上训练小于 1 小时。
  - 每个 PMO task 分子生成平均 4.26 分钟，最短 1.38 分钟，最长 10.09 分钟。
  - 作者强调 f-RAG 需要 10,000 oracle calls 获得最佳 top-10 PMO 和 top-100 SA，而 RL-GFM 用 3000 calls 达到可比优化表现。
- 超参数：
  - Grid partition 默认 `5^M`，作者认为 10-way 或更高会使 grid 稀疏、损害父代配对多样性并增加开销。
  - 衰减系数 `k=0.001` 在 PMO score 0.783 与 SA 2.332 之间取得平衡；`k=0.0005` 探索不足，`k=0.005` SA 变差。

## 局限与未来工作

- 作者明确说明的局限和未来方向：
  - 初始化数据库如 ZINC250K 会影响 initial convergence trajectory；
  - 未来将研究不同 initialization distributions 下的敏感性；
  - 需要进一步协调 RL-based guidance 和 evolutionary stochastic exploration 的平衡。
- 我们认为仍需确认的问题：
  - Docking score 是计算代理，不等同于真实实验 binding affinity；没有湿实验验证。
  - RL reward 依赖当前 Pareto status，任务目标缩放和 GMean 正值化会影响策略学习稳定性。
  - Mutation 仍依赖 89 个 SMART reaction rules，因此并非完全无先验模板。
  - Scaffold mask 的保护策略可能限制 scaffold hopping；对需要核心骨架创新的任务可能不足。
  - 与 f-RAG 等检索增强模型相比，RL-GFM 在某些依赖已知 motif 的任务上可能收敛不够直接。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：网格片段遮罩的 RL 引导分子演化。它可用于多目标分子、材料或符号结构生成：用 objective grid 决定配对，用 mask 保护核心结构、开放外围重组，再用 Pareto-aware RL 选择父代和变异规则。
- 暂留在论文卡中的方法、原理或架构启发：
  - 多目标分子生成中，RL 不必学习完整分子分布，可以作为轻量 operator controller 嵌入 MOEA。
  - GMean reward 是一种把 Pareto status 转化为 RL 信号的简单接口，但需要处理目标缩放。
  - 初期多样性算子、中后期精修算子的使用频率变化，可用于自适应算子调度。
- 局部创新线索：
  - 将 scaffold mask 从硬规则改为可学习 mask，让模型根据 target pocket 或 synthesis route 决定可切割区域。
  - 用 uncertainty 或 docking pose consistency 修正 docking reward，降低单次 docking proxy 噪声。
  - 为不同 Pareto 区域训练不同 mutation-rule policy，避免一个全局 policy 平均化。
  - 将 parent-pair grid 从固定 `5^M` 改为基于 population density 的 adaptive grid。
