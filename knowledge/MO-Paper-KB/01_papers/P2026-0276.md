# Multi-Objective Genetic Programming Assisted Stochastic Deep Reinforcement Learning for Dynamic Knowledge Integration in Transportation Networks

## 一句话理解

本文把多目标遗传编程用于构造高质量相似度特征，再用随机化深度强化学习选择和组合这些特征，在没有黄金对齐标签的交通知识图谱动态融合场景中完成实体匹配。

## 问题与动机

- 研究问题和场景：Transportation Networks (TNs) 的动态知识融合需要持续对齐来自传感器、GPS、地图、天气、社交媒体等异构来源的知识图谱实体。
- 现有算法为什么不足：
  - 单个或固定组合的 Similarity Features (SFs) 难以适应不同来源、不同类型实体的词汇、结构和上下文差异；
  - 监督式或分类器式匹配依赖预标注映射，真实 DKI 场景中黄金对齐通常缺失；
  - 常规 DRL 做 SF 选择时容易过拟合特定特征，探索动作空间不足，探索和利用平衡不稳定；
  - 基础 SFs 表达能力有限，无法充分捕捉复杂上下文语义。
- 本文希望解决什么：建立一个能自动构造、选择和组合 SFs 的 DKI 框架，使实体匹配在动态、异构、缺少黄金标签的交通知识图谱中仍能保持较高准确性和适应性。

## 核心理念与算法流程

- 核心理念：先用 MOGP 在 approximate precision 和 approximate recall 两个目标上演化非支配 SF 表达式，形成高质量、多样化的特征库；再把 SF 选择看作 SDRL 动作，用概率 Q 向量随机采样特征子集，并用无黄金对齐的 approximate f-measure 作为奖励。
- 主要流程：
  1. 从两个知识图谱抽取 class、property、instance，并计算基础 SF value matrices。
  2. 以基础 SFs 作为 GP terminals，以特征矩阵组合函数作为 internal nodes，初始化 GP tree population。
  3. 对每棵 GP 树解码得到新的 SF value matrix，再由 alignment extraction 得到实体映射。
  4. 用 approximate recall 和 approximate precision 评价每个 SF，进行非支配排序、子树 crossover/mutation 和环境选择，输出 Pareto front SFs。
  5. SDRL 初始化 Q vector 为 0.5；每一维表示某个候选 SF 被选择的概率。
  6. 每轮用随机数与 Q vector 比较生成二进制 action，选择一组 SFs。
  7. 用 OWA aggregation 聚合被选 SFs，得到实体相似度并抽取对齐。
  8. 用 approximate f-measure 计算奖励，更新 primary/target networks 和 elite action；当所有 Q 值超过上下阈值后停止。
- 关键组成部分：
  - MOGP-based SF construction：在完整 SF 组合空间中搜索非支配高阶特征。
  - Stochastic Q vector：把动作从确定性选择改为概率选择，增强探索。
  - Approximate alignment quality metrics：用匹配覆盖率和平均相似度近似 recall、precision、f-measure，避免依赖黄金对齐。
  - OWA aggregation：按排序权重聚合多个选中 SFs，使高贡献特征权重更大。
  - Schema-first matching：先做 class/property matching，再分区做 instance matching，降低实例相似度矩阵规模。
- 可能被修改的位置：
  - 可替换 GP terminal set，例如加入图嵌入相似度、时空邻域相似度、语义编码器相似度；
  - 可把 stochastic Q vector 用于其他二进制组件选择，例如代理模型选择、局部搜索算子选择或特征子集选择；
  - approximate reward 可加入 coverage、置信度分布、冲突率或一对一约束惩罚；
  - OWA 聚合可替换为 attention、rank-weighted ensemble 或稀疏门控。
- 必须保留的核心：MOGP 负责产生可被选择的高阶 SF 库，SDRL 负责在线选择 SF 子集；若只保留普通 DRL 选择原始 SFs，就失去本文最主要的特征构造贡献。

## 实验证据

- 测试问题和对比算法：
  - OAEI KG 数据集包含 Star Wars、Marvel、Star Trek 等多个 Wiki 知识图谱组合，规模从数千到二十余万 instances。
  - 交通知识图谱包含五类真实 TN pair：OSM-Google Maps、Geonames-Waze Traffic、European Road Network-Social Media Traffic、Uber Movement-Air Quality、Public Bicycle-Sharing-City Infrastructure。
  - 对比方法包括 OAEI KG matching 参赛方法、GP-based 方法和 DRL-based 方法；GP 结果取 30 次独立运行均值，并用 Wilcoxon rank-sum test 做显著性检验。
  - 参数设置：SDRL 学习率 `alpha=0.05`、折扣因子 `gamma=0.95`；MOGP crossover `0.7`、mutation `0.4`、max generations `300`、population size `200`、terminal selection probability `0.4`。
- 主要实验结论：
  - Table II 显示 MOGP-SDRL 在所有测试案例的 f-measure 上整体优于对比方法。
  - entertainment KG 案例中，mcu-marvel、malpha-mbeta、malpha-stex 的 f-measure 分别达到约 `0.84`、`0.94`、`0.98`。
  - 交通案例中，OSM-GM、Geo-WT、UM-AQ 的 f-measure 分别达到约 `0.95`、`0.89`、`0.91`，显示对动态交通数据融合的适应性。
  - 作者指出 PBS-CI 等高度受限场景中性能相对低一些，DRL-based 方法可达到相近表现，说明概率探索也可能偶尔选到次优特征组合。
- 消融或机制证据：
  - Approximate metrics 对比：MOGP-SDRL 与替换 approximate recall/precision/f-measure 的多个变体在 30 次运行中多数相当或更好，approxF 在所有案例中与 classic f-measure 表现一致。
  - MOGP SF construction 对比：MOGP-SDRL 在所有案例中优于只用原始 SFs 的 `MOGP-SDRL_ori` 和随机组合 SFs 的 `MOGP-SDRL_rand`；例如 malpha-stex 为 `0.98`，而两个变体约为 `0.84` 和 `0.65`；OSM-GM 为 `0.95`，而两个变体约为 `0.88` 和 `0.51`。
  - 参数敏感性显示 max generation `300`、population `200` 和 terminal probability `0.4` 在性能和复杂度之间较均衡。
- 证据边界：
  - 主要表格在 Markdown 中为图片占位，具体完整数值需回看 PDF 表格；
  - 方法在 PBS-CI 等高度领域特定、受限场景中可能需要额外 domain tuning；
  - 未来更大规模 TN KG 的可扩展性仍需验证。

## 局限与未来工作

- 作者明确说明的局限：
  - 在 entity relationships 高度领域特定、上下文因素影响较弱的案例中，概率探索可能导致次优 SF 选择，PBS-CI 是一个边界案例；
  - 可扩展到更大、更复杂 TN 数据集的能力仍需进一步研究。
- 作者未来工作：
  - 增强框架在更大规模 TNs 中的 scalability；
  - 融合 GNN 或 Transformer 等深度模型，捕捉更深层实体语义关系。
- 我们认为仍需确认的问题：
  - approximate metrics 在噪声实体、错误类型边或极端一对多关系下是否仍稳定；
  - MOGP 构造 SFs 的计算成本是否能支撑真正实时 DKI；
  - GP 函数集和 terminal set 对跨领域迁移的影响；
  - Q vector 阈值停止规则是否会过早固定特征组合。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“多目标 GP 构造特征库的随机 DRL 选择”，因为它把 feature construction 与 feature selection 分层耦合，可直接迁移到特征子集、算子库、代理库或规则库选择问题。
- 暂留在论文卡中的方法、原理或架构启发：
  - approximate reward 的思想可用于无标签结构匹配、聚类一致性优化或自动指标代理；
  - schema-level matching 先降维再实例匹配，是大规模图匹配的工程性关键；
  - Q vector 以概率而非离散动作值表示选择倾向，可减少早期策略僵化。
- 局部创新线索：
  - 在 MOEA 中用 MOGP/GP 先生成“组合算子”或“组合距离度量”，再由 RL 选择使用；
  - 用 approximate recall/precision 替代需要真实标签的 wrapper 评价，形成弱监督候选筛选；
  - 把 OWA rank aggregation 改造成 attention-gated aggregation。
- 结构创新线索：
  - 构建“结构生成器 MOGP -> 概率选择器 SDRL -> 无标签近似奖励 -> 在线重构特征库”的闭环；
  - 在动态优化中把环境变化后可选策略库先演化扩充，再由 RL 按新环境反馈选择策略组合。
