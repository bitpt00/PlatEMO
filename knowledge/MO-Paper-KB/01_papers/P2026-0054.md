# A reference vector-guided many-objective evolutionary algorithm based on an adaptive adjustment strategy

## 一句话理解

论文提出 RVEAADS，用于 many-objective evolutionary optimization。它保留一部分高 rank 非支配精英，并对剩余候选执行 RVEA 式参考向量/APD 环境选择；当每个参考子空间只选一个解导致新种群数量不足，或一些接近角平分线/近 PF 的候选被丢弃时，算法额外构造两个候选集：多样性维护集 `DP` 和收敛促进集 `PP`。自适应调整先加入同时满足多样性和收敛的交集，再按演化阶段早期偏 `DP`、后期偏 `PP` 补足缺失个体，从而在高维目标下缓解单一参考向量选择的早熟和覆盖不足。

## 问题与动机

- 研究问题：
  - MaOP 中目标数超过 4 后，Pareto dominance 难以区分个体收敛质量；
  - 参考向量/分解式算法能划分目标空间，但固定均匀参考向量不一定与真实 PF 匹配；
  - 每个子空间只保留 APD 最优个体时，空子空间或早期候选不足会让最终精英数量低于预设种群规模；
  - 一些被丢弃个体虽然没有成为本子空间 APD 最优，但可能靠近角平分线、收敛性接近精英，仍有补充价值。
- 现有方法为什么不足：
  - dominance-based MOEA 在 many-objective 中选择压力弱；
  - indicator-based MOEA 指标成本可能较高；
  - decomposition/RVEA 依赖参考向量分布，面对 irregular、disconnected 或 nonuniform PF 时容易方向浪费；
  - 单一精英选择标准会导致早熟，且缺少对“选不满”的显式补位机制。
- 本文希望解决什么：
  - 用 elite retention 保留当前非支配排序质量较高的个体；
  - 用 diversity maintenance 找回被参考向量初筛丢弃但覆盖价值较高的候选；
  - 用 convergence promotion 找回比同子空间精英更靠近理想点的候选；
  - 用 adaptive adjustment 根据缺失个体数量和迭代阶段补齐新种群。

## 核心模型与算法流程

- 基础参考向量选择：
  - 用 uniform mixed design 生成参考点并归一化为单位参考向量；
  - 根据 ideal point 平移目标值；
  - 将每个候选关联到夹角最小的参考向量；
  - 计算 APD，在每个非空子空间中选择 APD 最小的候选进入 `S_{t+1}`。
- Algorithm 1 主框架：
  - 初始化种群 `P_t` 和参考向量 `V`；
  - 对 `P_t` 执行非支配排序得到 `P_n`；
  - 按预设比例 `r` 保留精英 `P_r`；
  - `P_r` 用 SBX 和 PM 生成 `P'_r`，保证高质量精英信息继续繁殖；
  - 剩余 `P_n - P_r` 用 GA operator 生成 `P_g`；
  - 合并 `P_c = (P_n - P_r) union P_g`，交给 Algorithm 2 环境选择；
  - 最终 `P_{t+1} = G_t union P'_r`。
- Algorithm 2 环境选择：
  - 先执行标准 reference vector-guided selection，得到初始精英集 `S_{t+1}`；
  - 未被选中的候选形成剩余集 `R`；
  - 用 Algorithm 3 从 `R` 中构造多样性候选集 `DP`；
  - 用 Algorithm 4 从 `R` 中构造收敛候选集 `PP`；
  - 用 Algorithm 5 根据 `DP` 和 `PP` 补齐缺失个体，得到 `G_t`。
- Algorithm 3 diversity maintenance：
  - 标准参考向量划分可能丢掉靠近相邻向量角平分线的候选；
  - 用已选精英生成新的参考向量 `V_new`，重新划分目标空间；
  - 在新子空间中选择未进入 `S_{t+1}`、但与新参考向量欧氏距离较优的个体，形成 `DP`；
  - 作用是让后续补位更偏向覆盖新潜力区域。
- Algorithm 4 convergence promotion：
  - 对每个剩余解 `R_i`，确定它所在子空间的已选精英 `P_e`；
  - 若 `R_i` 的平移目标向量 L1 范数不大于 `P_e`，则认为它具有显著收敛性并加入 `PP`；
  - 该策略复用参考向量选择中已有的子空间关联和目标变换，成本较低。
- Algorithm 5 adaptive adjustment：
  - 先取 `EP = DP intersect PP`，优先加入同时满足多样性和收敛的个体；
  - 若种群仍未达到上界 `N'`，按演化进度补位；
  - 早期优先从 `DP` 中加入个体，扩大探索区域；
  - 后期优先从 `PP` 中加入个体，加速靠近 PF；
  - 直到当前环境选择输出达到所需规模。
- 复杂度：
  - 非支配排序约 `O(N^2 M)`；
  - reference vector-guided selection 的目标变换、空间划分和 APD 计算最坏约 `O(MN^2)`；
  - diversity maintenance 和 convergence promotion 最坏约 `O(N^2)`；
  - adaptive adjustment 最坏约 `O(MN^2)`；
  - 总体复杂度为 `O(MN^2)`。

## 实验证据

- 基础设置：
  - 对比算法：RVEAa、MMOPSO、MOEA/D-DE、SPEA2、RVEAiGNG、hpaEA、HEA、NSGA-III、Pre-DEMO、MSEMOEA；
  - 测试集：DTLZ、WFG、MaF 共 25 个 benchmark problems；
  - 目标数：3、5、8、10、15、20；
  - 种群规模统一为 105；
  - 最大函数评价次数为 525000；
  - 30 次独立运行；
  - 指标为 HV 和 IGD；
  - Wilcoxon rank-sum test 显著性水平为 0.05；
  - 平台为 PlatEMO，MATLAB R2023b。
- DTLZ 结果：
  - HV 上 RVEAADS 在 42 个 DTLZ 实例中 16 个最佳、3 个第二；
  - IGD 上 17 个最佳、7 个第二；
  - 作者认为 DTLZ1-4 上表现较好；
  - DTLZ5 退化 PF 和 DTLZ7 断裂 PF 上表现不稳定，因为参考向量更新可能使新向量分布与真实 PF 不匹配。
- WFG 结果：
  - HV 上 RVEAADS 在 54 个 WFG 实例中 28 个最佳、6 个第二；
  - IGD 上 13 个最佳、10 个第二；
  - WFG2 上表现较弱，作者归因于 discontinuous PF 和强变量依赖；
  - WFG 非均匀前沿会让大量参考点落入无效区域，因此固定均匀参考向量仍是弱点；
  - 目标数超过 10 时，参考向量关系和 convergence metric 计算复杂性影响性能。
- MaF 结果：
  - HV 上 54 个 MaF 实例中 25 个最佳、11 个第二；
  - IGD 上 30 个最佳、13 个第二；
  - 作者认为 MaF 的 multimodal、discontinuous 和 complex PF 特征下 RVEAADS 整体更稳定；
  - MaF4 仍较难收敛。
- 收敛曲线与运行时间：
  - WFG1 的 3、5、8、10、15、20 目标实验中，RVEAADS 的 HV/IGD 趋势整体较稳；
  - runtime 随评价数近似线性增加；
  - RVEAADS 在约 100 次评价附近有明显增长，作者认为与生成新参考向量分区有关；
  - 相比需要训练 GNG 网络的 RVEAiGNG，计算增长较慢。
- 消融实验：
  - Variant1：只加入 elite retention；
  - Variant2：只在 reference vector selection 后加入 diversity maintenance；
  - Variant3：只加入 convergence promotion；
  - Variant4：后期自适应结合 diversity preservation 和 convergence promotion；
  - RVEAADS 在 5-objective 和 15-objective 的 DTLZ/WFG/MaF 结果中整体优于四个变体；
  - 作者认为完整组合在高维目标下对多样性和收敛平衡贡献更明显。
- 参数敏感性：
  - `r` 测试 `1/2`、`1/3`、`1/4`；
  - `r=1/3` 在三类测试集上整体最好；
  - `r` 太小削弱 elite retention，太大则削弱种群收敛/搜索补位空间。
- 路径规划应用：
  - 障碍路径规划中比较 NSGA-III、ABC+PSO、GA、RVEAADS；
  - Table 11 中 RVEAADS path length 为 34.4，优于 NSGA-III 38、ABC+PSO 36.2、GA 41；
  - Table 11 中 RVEAADS success rate 为 95%，正文一处写 93%，存在不一致；

## 局限与未来工作

- 作者明确局限/未来方向：
  - RVEAADS 在 regular PF 上可以使用固定参考向量；
  - 但 fixed reference vectors 面对 irregular PF 仍有较大挑战；
  - 未来希望在 reference vector-guided 过程中动态调整向量分布，根据 PF 特征适当改变搜索方向，再与 adaptive adjustment strategy 结合。
- 我们认为仍需谨慎的问题：
  - `DP` 与 `PP` 候选的质量可能高度重叠，交集优先不一定总是最优；
  - 早期/后期用固定 0.5 阈值切换较粗，可能不适配停滞或多阶段 PF；
  - convergence promotion 用 L1 范数比较，在尺度归一化不稳或目标冲突强时可能偏向局部极端；
  - diversity maintenance 用已选精英生成新参考向量，若早期精英偏置会放大错误方向；
  - 需要与更多 reference-vector adaptation 方法进行独立对比。

## 可迁移设计要点

- 参考向量环境选择不应只返回“每个非空子空间的一个 APD 最优解”；未选剩余解中可能仍有覆盖或收敛价值。
- 对初筛后的剩余解，可以并行构造两个角色候选集：一个偏多样性补洞，一个偏收敛加速。
- 同时满足多样性与收敛的交集候选应优先考虑，但仍需要防止过度集中。
- 早期偏探索、后期偏收敛的补位逻辑很容易嵌入现有 MaOEA；更稳的版本可改成基于停滞、空子区比例或 HV/IGD 改变量自适应切换。
- `r` 这类精英保留比例决定了“稳定继承”和“补位探索”的预算分配，需要与目标数、PF 形状和候选池规模联动。
