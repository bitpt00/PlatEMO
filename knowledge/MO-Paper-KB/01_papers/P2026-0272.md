# Efficiently Combining Iterated Local Search and Decomposition: A Comprehensive Study on Multi-Objective Binary Landscapes

## 一句话理解

论文系统研究二进制多目标组合优化中 ILS 与 decomposition 的结合方式，核心贡献是 EILS/D：在某个子问题的局部搜索过程中，每个被探索邻居不只服务当前权重，而是立即尝试替换所有被该邻居改善的子问题；只有当所有子问题都持有各自局部最优解后，才对整个种群统一扰动，从而把分解协作和 ILS 的“局部最优后软重启”原则细粒度融合。

## 问题与动机

- 研究问题和场景：
  - Binary multi-objective combinatorial optimization；
  - 目标是找到高质量 Pareto front approximation；
  - 测试对象包括 `rho`-MNK landscapes 和 MUBQP；
  - 解空间是二进制串，邻域主要为 Hamming distance 1 的 1-flip。
- 现有算法为什么不足：
  - PLS 及其变体没有明确 local-optima escape，anytime behavior 往往较弱；
  - 2PPLS、PPLS/D、DCDG-MOMA 等把 decomposition 与 local search 结合，但通常缺少扰动/软重启；
  - standalone ILS/D 只在一个子问题内部做 LS，LS 内部发现的邻居不会被其它子问题及时利用；
  - standalone 版本在邻居替换其它子问题后，不能保证被替换子问题也局部最优，扰动可能作用在尚未爬到局部最优的解上。
- 本文希望解决什么：
  - 让 LS 的每一步 neighborhood exploration 对所有 decomposition subproblems 可见；
  - 保持 ILS 设计原则：先形成局部最优，再扰动跳出；
  - 比较 standalone、collaborative、embedded 三种 ILS/D 设计和七类已有 LS-based MOO 算法；
  - 分析 scalarizing function、perturbation strength、population size 等关键组件。

## 核心理念与算法流程

- 基础分解：
  - 用 `mu` 个 weight vectors 产生 `mu` 个 scalarized subproblems；
  - scalarization 包括 weighted sum (WS) 和 Chebyshev (CHB)；
  - 每个子问题维护一个解 `x_i`。
- Standalone ILS/D：
  - 对每个子问题先执行单目标 LS；
  - 每轮选择子问题 `i`，再从邻域 `B(i)` 中选 `j`；
  - 扰动 `x_j` 后，以 `S(.|w_i)` 做 LS 得到 `x*`；
  - `x*` 可以替换邻域子问题中被其 scalar value 改善的解；
  - `B(i)={i}` 时为 IILS/D，运行独立 ILS；
  - `B(i)` 为邻近子问题集合时为 CILS/D，扰动起点和替换阶段都有协作。
- EILS/D 的细粒度嵌入：
  - 为每个子问题维护 `LO[i]`，表示当前解是否为该权重下的局部最优；
  - 对一个未局部最优的子问题 `i` 执行 LS；
  - 在扫描 `N(x_i)` 时，每个邻居 `x'` 会对所有子问题 `j` 检查 `S(x'|w_j)` 是否改善 `S(x_j|w_j)`；
  - 若改善，则立即更新 `x_j <- x'`，并标记 `LO[j] <- False`；
  - 如果多个子问题持有同一个局部最优解，且该解对它们都已被检查，可标记这些重复子问题为局部最优；
  - 当全部 `LO[i]=True`，即整个分解种群达到“Pareto local optimum set”式状态，再对所有 `x_i` 同时执行 perturbation 并重置 `LO`。
- 设计直觉：
  - LS 内部邻居可能对其它权重更有价值，不能等到 LS 结束后才传递；
  - 全体局部最优后统一扰动，相当于先找一组 decomposition local optima，再对该集合做 ILS soft restart；
  - 这比 standalone 方式更紧密协作，也避免 perturbation 作用在尚未本地优化的解上。
- 参数与实现选择：
  - 所有算法除 SEMO 外采用 1-flip neighborhood；
  - 单目标 LS 使用随机顺序 first-improving pivot rule；
  - perturbation 为随机翻转 `r` 个 bits，`r in {1,4,8,16,32,64}`；
  - decomposition algorithms 使用 `mu in {50,100,250,500}`；
  - WS 和 CHB 均测试；CHB reference point 对大多数算法动态更新；
  - 所有算法维护 unbounded external archive 保存非支配解并计算 HV。
- 可能被修改的位置：
  - LS pivot rule：first-improving、best-improving、candidate-list、partial neighborhood；
  - perturbation：固定 bit flips、自适应强度、结构化扰动、archive-guided restart；
  - scalarization：WS、CHB、PBI、achievement scalarizing、preference-weighted scalarization；
  - replacement 范围：所有子问题、邻近子问题、ROI 子问题或动态筛选子问题。
- 必须保留的核心：
  - LS 内部探索的邻居要能即时服务多个子问题；
  - 每个子问题都需要本地最优状态标记；
  - 扰动应在“全体子问题局部最优”之后触发；
  - 外部 archive 需要记录搜索过程中的非支配解，避免当前分解种群无法覆盖全部 PF。

## 实验证据

- MNK landscape 设置：
  - 72 个 `rho`-MNK landscapes；
  - `M in {2,3}`，`N in {128,256,512}`，`K in {2,4,6,8}`，`rho in {-0.4,0,0.4}`；
  - `K` 表示 epistatic interaction / non-linearity；
  - 正 `rho` 降低目标冲突，负 `rho` 增加目标冲突；
  - 总计 401 个算法配置，预算 `10^7` evaluations，每个配置 20 次运行；
  - 评价指标为 HV，参考点取所有 archives 中各维最差值。
- 对比算法：
  - 本文提出：IILS/D、CILS/D、EILS/D；
  - 文献方法：IaPLS、2IaPLS、PILS、MOW-P、dRBC、SEMO、IPPLS/D；
  - 传统 MOEA/D、NSGA-II、NSGA-III 未列入，因为前人已显示它们在同类 binary landscapes 上弱于 MOW-P、dRBC、SEMO。
- 高预算总体结果：
  - 三个最有竞争力算法为 EILS/D、CILS/D 和 MOW-P；
  - IILS/D 弱于 CILS/D/EILS/D，说明子问题协作有益；
  - CILS/D 和 EILS/D 随维度 `N` 增大整体优于 MOW-P；
  - EILS/D 在双目标上通常优于 CILS/D，三目标差异更缓和；
  - Table I 的总体 median 显示 EILS/D 和 CILS/D 在许多组合下 rank 接近 0，而 SEMO、PILS、dRBC、IPPLS/D 通常排名较后。
- Anytime behavior：
  - Fig. 1 显示 EILS/D 在 `rho=0,N=512` 的多个 `K` 设置上有极强 anytime profile；
  - EILS/D 在预算增长全过程超过 CILS/D、MOW-P、2IaPLS、dRBC、SEMO、IPPLS/D；
  - MOW-P 往往需要高预算才追上部分算法，作者认为其 non-elitist/non-cooperative 特性更偏 diversification。
- EAF 差异：
  - EILS/D 在 PF 中央区域优于 MOW-P；
  - MOW-P 只在极端区域略优；
  - 随 `K` 或 `N` 增大，EILS/D 的优势更明显；
  - 作者指出 EILS/D 极端前沿覆盖仍可改进。
- 参数分析：
  - scalarizing function 是影响最大的参数；
  - Table II 和 Fig. 3 显示 WS 在所有 decomposition-based algorithms 上显著优于 CHB，尤其在 `N` 和 `M` 增大时；
  - 作者认为 WS 的线性 landscape 可能更平滑，虽然 WS 理论上无法通过单目标搜索直接得到 unsupported solutions；
  - external archive 记录搜索过程中所有非支配解，可能缓解 WS 的 supported-solution 限制；
  - perturbation 强度次重要，过小会困在同一局部最优，过大近似随机重启；
  - `r=8` 在所测 landscapes 上整体稳健，但最优值应随 landscape 结构调整；
  - population size 影响较小，但会改变 anytime 行为：小实例高预算可用更大 `mu`，大实例小 `mu` 反而更有效。
- MUBQP 验证：
  - 使用 72 个 MUBQP configurations；
  - `N in {128,256,512}`，`M in {2,3}`，`rho in {-0.4,0,0.4}`，matrix density `d in {0.2,0.4,0.6,0.8}`；
  - 对比 EILS/D、MOW-P、dRBC、2IaPLS、IPPLS/D；
  - 预算 `10^6` evaluations，每个配置 20 次运行；
  - Table III 显示 EILS/D 在几乎所有实例上显著优于其它算法；
  - 双目标实例中 EILS/D 只在 5 个实例被 2IaPLS 超过；
  - 三目标实例中 EILS/D 仅在 3 个实例被超过；
  - 进一步支持 embedded LS design 的鲁棒性。
- 证据边界：
  - 主要是二进制 landscapes 和 MUBQP，尚未验证排列、路径、调度或真实工程 MOCOP；
  - 表格 OCR 较乱，具体逐实例数值需回查 PDF；
  - 性能评价依赖 external archive，当前 population 的 PF 覆盖与 archive 覆盖需区分；
  - WS 优于 CHB 的机理仍是假设，作者也建议用 fitness landscape analysis 深入研究。

## 局限与未来工作

- 作者明确的未来方向：
  - 引入自适应 perturbation strategies，使扰动强度匹配问题特征；
  - 用 fitness landscape analysis 工具理论分析为什么 WS 在测试 landscapes 上优于 CHB；
  - 将 cooperative LS insight 泛化到更多 MCOP；
  - 扩展到 permutation domains 或 real-world instances。
- 我们认为仍需确认的问题：
  - EILS/D 的全子问题即时检查在 `mu` 大、目标多或邻域大时成本可能很高；
  - 对非二进制、强约束或可行性稀疏问题，LS 邻居是否能安全共享给所有子问题；
  - WS 依赖 archive 弥补 unsupported solutions，若 archive 受限或在线输出只看 population，效果可能下降；
  - 同时 perturb 全部局部最优可能破坏已有极端解，是否应分批或区域自适应 perturb；
  - EILS/D 中央前沿强、极端区域略弱，可能需要 boundary-weight 保护或极端子问题专项策略。

- 局部创新线索：
  - 把 immediate update 从全子问题改为邻域子问题、相似权重子问题或当前 ROI 子问题，降低成本；
  - 使用 adaptive perturbation：根据最近 archive 新增率、LO 循环长度或 basin revisiting 调整 bit flips；
  - 对极端权重子问题使用更强 boundary preservation，弥补 EILS/D 极端区域弱点；
  - 在 neighbor evaluation 中加入 delta evaluation 和缓存，降低全子问题 scalar 检查成本。
- 结构创新线索：
  - 构建“embedded LS kernel + decomposition population + local-optimality state + archive output”的 MOCOP 内核；
  - 与 ALNS/VNS 结合：每个局部 move 仍可即时尝试更新多个子问题，而不是只返回当前子问题局部最优；
  - 与 GPU/tensorized EMO 结合：把邻居对全子问题 scalar improvement 的检查张量化；
  - 与 preference search 结合：只对偏好 ROI 权重集合进行 immediate update，提高交互式搜索效率。
