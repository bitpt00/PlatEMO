# Surrogate-assisted evolutionary optimization using on-demand helper task for high-dimensional expensive multi-objective problems

## 一句话理解

论文提出 SAEA-DHT：针对高维昂贵多目标优化，在真实评价预算很少时，按当前收敛/多样性需求动态构造低维 helper task，在 helper task 和原任务上并行代理搜索，再把 helper task 的优质解跨维映射回原空间，并用阶段化 infill 准则选择少量真实评价点。

## 问题与动机

- 研究问题和场景：high-dimensional expensive multi-objective optimization problems (EMOPs)，决策变量通常超过 30，真实 fitness evaluations 来自数值仿真或物理实验，预算严格受限。
- 现有算法为什么不足：
  - 多数 SAEAs 主要面向低维或中等维度 EMOP，高维下 surrogate training 样本稀疏、泛化差，GP 等模型训练成本也快速上升。
  - 普通降维或低维辅助任务常把 reduced task 与 original task 分开优化，忽略两者相关信息，helper task 发现的优质结构没有被充分迁移回原任务。
  - 既有 fixed low-dimensional helper task 难同时满足不同阶段需求：早期更需要收敛关键变量，后期或停滞时更需要补充多样性。
  - 高维 EMOP 中 infill selection 很难兼顾 convergence 和 diversity；固定使用单一准则容易在有限真实评价下偏向某一侧。
- 本文希望解决什么：
  - 根据当前优化阶段构造 on-demand low-dimensional helper task；
  - 用 cross-dimensional knowledge transfer 把 helper task 的非支配优质解映射回原高维空间；
  - 用 adaptive infill selection 在 convergence-driven 与 diversity-driven 真实评价准则之间切换；
  - 在 DTLZ/MaF/WFG 和 TREE 真实问题上验证高维 EMOP 的样本效率。

## 核心理念与算法流程

- 核心理念：不要把降维辅助任务看成固定子问题，而是把它变成一个随搜索阶段变化的服务层。当前需要收敛时，helper task 只优化 convergence-critical variables；当前需要多样性时，helper task 改为优化 remaining/diversity-demand variables；helper task 的非支配解再通过分布对齐和 rank alignment 映射回原空间，供原任务筛选真实评价点。
- 主要流程：
  1. LHS 产生 `NI` 个初始样本，真实评价后加入 archive `Arc`。
  2. 从 `Arc` 随机选 `N` 个解初始化原任务种群 `Pt`，初始 `Stage=1` 表示 convergence urgent。
  3. 在每次迭代中执行 on-demand helper task construction：
     - 归一化 `Arc`；
     - 用非支配排序把 evaluated solutions 分为 first-rank well-converged set `C1` 和 bottom-quarter poorly-converged set `C2`；
     - 计算每个变量在 `C1` 与 `C2` 中均值差 `v_dif`；
     - 按 `v_dif` 降序二分为 convergence-related variables `v_c` 与 diversity-related variables `v_d`；
     - `Stage=1` 时用 `v_c` 构造 helper task，`Stage=2` 时用 `v_d` 构造 helper task。
  4. 对 original task 和 helper task 分别训练 RBF objective surrogates，并用 NSGA-II+SDE 做代理辅助内搜索，得到 `Q` 与 `Qh`。
  5. 选出 helper task 中非支配解 `Qh^N`，通过 cross-dimensional knowledge transfer 映射到原任务决策空间，得到 transferred solutions `Th`；用原任务 RBF 预测 `Th` 的目标值，与 `Q` 合并为 fused population `Qf`。
  6. 执行 adaptive infill selection：
     - `Stage=1` 时，用固定 reference vectors、活跃向量聚类和 convergence value `CV` 选择每簇最小 `CV` 的候选；
     - `Stage=2` 时，用 `Arc` 中解的 SDE diversity metric 训练 RBF `fD`，预测 `Qf` 的 diversity values，选 top `k` 候选。
  7. 对 `Inew` 做真实评价，更新 `Arc` 和 `Pt`。
  8. 用当前与上一轮 population 的 HV improvement 和 best convergence value `Con` 评估下一轮 `Stage`：HV 改善且 `Con` 改善为 convergence urgent；HV 改善但 `Con` 未改善为 diversity demand；HV 不改善则回到 convergence urgent。
- 关键组成部分：
  - FE-efficient decision variable extraction；
  - on-demand helper task construction；
  - original/helper 双任务 RBF surrogate-assisted NSGA-II+SDE；
  - cross-dimensional knowledge transfer with distribution alignment and fitness-rank matching；
  - convergence/diversity adaptive infill selection；
  - HV + best convergence value stage assessment。
- 可能被修改的位置：
  - 变量重要性可从均值差替换为 sensitivity、surrogate gradient、rank contribution、interaction-aware grouping 或 sparse feature selection；
  - helper task 可从二分变量扩展为多组变量、候选 task pool 或动态子空间 ensemble；
  - RBF 可替换为 GP、sparse GP、ensemble、dropout NN、multi-output surrogate 或 local surrogate；
  - cross-dimensional transfer 的线性映射可替换为 kernelized DACoM、autoencoder decoder、normalizing flow 或 manifold alignment；
  - stage assessment 可加入长窗口 trend、model uncertainty、stagnation detector 或 bandit credit；
  - infill 可与 EI/LCB/EHVI、constraint risk、HV contribution、reference-vector density 组合。
- 必须保留的核心：
  - helper task 的变量子集要由当前优化阶段决定，而不是固定低维化；
  - helper task 搜到的高质量解必须通过显式跨维机制回到原任务；
  - 真实评价候选选择要跟随同一个阶段信号，在收敛和多样性需求之间切换；
  - stage assessment 应主要基于真实评价 archive，而不是只看代理预测。

## 实验证据

- 测试问题和对比算法：
  - Benchmarks：DTLZ1-DTLZ7、MaF1-MaF7、WFG1-WFG9，三目标，决策维度为 30、50、70、100。
  - Scalability：MaF with `m=3, D=200`；MaF many-objective with `m=7, D=140`。
  - Real-world-like applications：六个 time-varying ratio error estimation (TREE1-TREE6) problems，`D=120`，TREE1-TREE5 为二目标，TREE6 为三目标。
  - Baselines：SPGP-SAEA、EDN-ARMOEA、MCEA/D、MO-L2SMEA、TP-SAEA、LMOCSO。
  - Metrics：benchmark 用 IGD 与 IGD+；TREE 因 true PF unknown，用 HV；31 次独立运行，Wilcoxon rank-sum test 0.05。
  - 参数：`NI=11*D-1`，`MaxFEs=11*D+120`，population `N=100`，infill `k=5`，inner generations `gmax=20`，transfer weight `alpha=0.1`。
- 主要实验结论：
  - DTLZ：SAEA-DHT 在 28 个 DTLZ cases 中取得 12 个最佳 IGD；DTLZ1/DTLZ3/DTLZ7 上并非始终领先。
  - MaF：SAEA-DHT 在 28 个 MaF cases 中取得 17 个最佳 IGD；相对 SPGP-SAEA、EDN-ARMOEA、MCEA/D、MO-L2SMEA、TP-SAEA、LMOCSO 的 +/-/= 统计分别为 `8/17/3`、`4/21/3`、`5/19/4`、`0/22/6`、`9/18/1`、`2/19/7`。
  - WFG：SAEA-DHT 在 36 个 WFG cases 中取得 26 个最佳 IGD；相对六个 baseline 的 +/-/= 统计分别为 `2/28/6`、`3/32/1`、`0/36/0`、`8/22/6`、`4/32/0`、`0/36/0`。
  - IGD+ 结果与 IGD 结论高度一致。
  - 可视化显示 SAEA-DHT 在 100 维 DTLZ2、MaF1、WFG4 上通常有更好的收敛或分布。
  - 200 维 MaF：SAEA-DHT 在 7 个三目标 MaF 问题中 6 个 IGD 最佳，IGD+ 结论一致，支持决策空间 scalability。
  - 7 目标 140 维 MaF：SAEA-DHT 在 many-objective 下仍有竞争力，但不是绝对领先，作者将其作为 objective-space scalability 证据。
  - TREE：SAEA-DHT 在 TREE1、TREE3、TREE4、TREE5 上 HV 最好；TREE2 上 MCEA/D、MO-L2SMEA、TP-SAEA 更好；TREE6 上 MO-L2SMEA 更好。
- 消融或机制证据：
  - 无 on-demand helper task 的 SAEA-DHT-V1 在 100 维 DTLZ/MaF 14 个问题上相对完整 SAEA-DHT 为 `0/6/8`，支持 helper task construction 的贡献。
  - Stage switching 与 trigger condition 的平均相关系数在 DTLZ1-DTLZ7 上为 `0.5263` 到 `0.7062`，作者认为证明阶段切换具有 on-demand 行为。
  - Adaptive infill selection 三个变体：只用 convergence criterion、只用 diversity criterion、随机选 criterion；完整 SAEA-DHT 整体优于三者，其中随机策略在 100 维 MaF 上 `0/5/2`。
  - 用 DAE 替代本文 variable extraction 的 SAEA-DHT-DAE 在 100 维 MaF 上相对完整 SAEA-DHT 为 `0/2/5`，作者据此认为 problem-specific stage-aware extraction 比通用 DAE 更适合有限 FE 场景。
  - 参数敏感性显示 `alpha=0.1` 较稳健，`k=5` 较优，`gmax=20` 在性能与成本间折中，`NI` 对可用后续评价预算影响明显。
- 证据边界：
  - 内部 runtime 上，SAEA-DHT 比 SPGP-SAEA、MCEA/D、MO-L2SMEA、TP-SAEA、LMOCSO 更长，原因是 original/helper task 均需训练 RBF 且需跨维映射。
  - 在 DTLZ7、MaF4、MaF7 等 discontinuous / multi-modal / nonlinear coupling 问题上暴露局限。
  - TREE 是标准化 real-world problem set，不等同于完整工程部署；SparseNN 结果在补充材料中，主文只简要提及。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前 decision variable extraction 更适合 separable variables；强耦合复杂问题中性能可能下降。
  - Cross-dimensional transfer 基于 covariance matching，依赖 nonlinear eigenvalue decomposition，计算负担较重；线性映射假设可能无法捕捉 heterogeneous decision variables 的复杂非线性关系。
  - RBF models 缺少显式过拟合防控，对 noisy objectives 敏感；噪声会削弱 stage assessment 与 infill selection 稳定性。
  - Stage assessment 可能在 deceptive HV improvement 或 flat search region 中长期误判阶段，导致错误策略持续应用和停滞。
- 作者未来工作：
  - 扩展到 constrained、dynamic、noisy、multi-fidelity optimization；
  - 对 mixed、strongly correlated、redundant variables 加入 complex interaction models 和 feature selection preprocessing；
  - 引入 GP、model ensembles 等 uncertainty handling，提高代理可靠性；
  - 用 kernelized DACoM 等非线性迁移方法，并分析 mapping 过程中的 uncertainty propagation；
  - 集成 adaptive reference vector generation；
  - 进一步研究 `alpha` 自适应机制；
  - 扩展到 many-objective expensive problems，加入更强 selection pressure 和 diversity preservation；
  - 发展 convergence / worst-case analysis，以及 helper task 质量评价理论；
  - 与 power systems、aerospace engineering 等领域专家开展正式案例研究。
- 我们认为仍需确认的问题：
  - `v_dif` 单变量均值差能否识别协同变量组；强非线性变量交互可能被二分拆散。
  - Stage assessment 只看相邻两轮 HV/Con，容易受小样本 archive 波动影响；应考虑滑动窗口和置信度。
  - Helper task 的二分比例固定为一半，虽然补充实验支持，但不同任务可能需要动态子空间大小。
  - Cross-dimensional mapping 的质量没有独立诊断指标；transfer 失败可能被 infill selection 部分掩盖。
  - RBF 代理和 NSGA-II+SDE 的选择同时参与性能提升，单独归因到 on-demand helper task 要谨慎。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 更新已有设计知识：[动态辅助任务构造](../02_design_knowledge/K-dynamic-auxiliary-task-construction.md)。本文补充了高维昂贵 MOO 场景下的 stage-aware helper task、跨维映射和阶段化 infill 证据。
- 暂留在论文卡中的方法、原理或架构启发：
  - Cross-dimensional knowledge transfer 目前与 on-demand helper task 框架紧耦合，暂不单独成卡。
  - Adaptive infill selection 的 convergence/diversity 双准则很有用，但单篇中与 SAEA-DHT 其他组件耦合较强，暂留本卡。
  - HV + best `Con` 的 stage assessment 可作为阶段检测模板，但需要更多论文支持。
- 局部创新线索：
  - 把 `v_dif` 替换为 interaction-aware importance，例如 pairwise/group perturbation、Sobol-like indices、surrogate Jacobian 或 sparse group lasso。
  - 对 helper task 维护多个候选比例，例如 25%/50%/75% 变量子集，用真实评价贡献选择。
  - 在 transfer 后加 reliability score：原任务 surrogate uncertainty、边界修复距离、rank consistency 或 archive nearest-neighbor novelty。
  - 把 convergence/diversity infill 变成 bandit policy，由真实评价后的 HV/IGD/HV-contribution 更新 credit。
  - 在 noisy EMOP 中用 ensemble RBF/GP 估计 stage 信号置信区间，低置信时减少阶段切换。
- 结构创新线索：
  - 构建“stage sensor -> helper-task generator -> helper/original surrogate co-search -> cross-dimensional transfer -> stage-matched infill”的通用高维 SAEA 架构。
  - 将 on-demand helper task 与已有目标级代理选模结合：helper task 可用轻量 RBF，原任务目标按 GP/RBF/NN 自适应选模。
  - 把 helper task 从一个低维任务扩展为多个 task experts：收敛变量、边界变量、稀疏变量、约束修复变量分别服务不同阶段。
  - 对 constrained high-dimensional EMOP，让 helper task 不仅按 convergence/diversity 切换，也按 feasibility-repair / CPF-diversity 切换。
