# 基于向量自回归演化的动态多目标优化

## 一句话理解

本文提出 VARE，把动态多目标优化中的新环境初始化看成一组按参考方向分解的多变量时间序列预测问题：先用每个参考方向在历史环境中的关联个体形成轨迹，经 PCA 降维后用 vector autoregression (VAR) 同时预测多个决策变量的联动变化；当历史不足或 VAR 表现不稳时，再用同时感知目标空间和决策空间变化强度的环境感知超变异 (EAH) 补充多样性，并按方向历史成功率自适应选择 VAR 或 EAH。

## 问题与动机

- 研究场景：dynamic multiobjective optimisation problems (DMOPs)，目标函数、约束或变量会随环境变化，算法需要追踪随时间变化的 Pareto set (PS) 和 Pareto front (PF)。
- 现有 prediction-based DMOEAs 的主要不足：
  - 常把决策变量看成彼此独立，用单输出模型分别预测每个变量，难以捕捉变量联动；
  - 常只利用最近一到两个环境，忽略较长历史中的时序模式；
  - 使用相同步长或中心位移预测不同参考方向，难以处理局部变化方向和幅度不一致；
  - MOEA/D-SVR 等逐变量逐方向建模成本高，且没有显式建模变量间依赖；
  - 固定超变异容易在 PS 未改变但目标值改变时产生无谓扰动。
- 本文希望在保持较低运行时间的前提下，同时解决动态响应中的“多历史、变量依赖、方向差异和多样性补偿”问题。

## VARE 总体框架

- 主搜索框架采用带 reference directions 的 SPEA/R diversity-centred sorting。作者补充实验认为该搜索器在动态场景中比 MOEA/D 和 NSGA-III 更利于维持多样性。
- 算法维护：
  - reference directions `lambda_i`；
  - 当前父代 `P`；
  - 历史环境种群 archive `A`；
  - 每个参考方向选择 VAR 预测的概率 `pi_i`。
- 检测到环境变化时：
  1. 将当前 `P` 存入历史 archive；
  2. 对每个参考方向 `lambda_i`，按概率 `pi_i` 选择 VAR 预测，否则使用 EAH；
  3. 将得到的新环境候选 `Q` 与旧 `P` 合并；
  4. 用 diversity-centred sorting 更新新环境初始种群。
- 未检测到环境变化时：
  - 使用 genetic operation 或 EDA 生成子代；
  - 仍用 diversity-centred sorting 完成环境选择。

## VAR 降维时序预测

VAR 预测的输入不是单个变量的历史，而是一个参考方向上的历史决策向量序列：

```text
archive populations across environments
-> associate one solution with each reference direction in each environment
-> build trajectory A_i = {a_i^1, ..., a_i^t}
-> PCA maps n-dimensional decisions to k-dimensional latent vectors
-> learn VAR(l) in latent space
-> one-step prediction for new environment
-> reverse PCA reconstruction to original decision space
```

- 对每个参考方向 `lambda_i`，先从历史 archive 中取该方向关联个体 `A_i={a_i^1,...,a_i^t}`。
- 直接在 `n` 维决策空间拟合 VAR(l) 会产生 `n + n^2 l` 级参数，维数稍高时样本不足且成本大。
- 因此作者先做 PCA 降维，选择能够解释 80% variance 的最小维数 `k`；实验可视化显示在许多问题中 `k` 常为 1 或 2。
- 在低维空间用 Bayesian estimation 学习 VAR(l)，比普通最小二乘更快；预测得到新环境低维向量后，再通过 reverse PCA 重构为原始决策向量。
- 由于 VAR 是多输出时间序列模型，它显式保留决策变量之间的线性依赖和跨环境历史相关，而不是逐变量独立预测。

## 环境感知超变异 EAH

EAH 用于历史不足、VAR 不可靠或需要增加响应多样性的方向。它的核心是同时估计目标空间变化和决策空间变化，再把变化强度转成 polynomial mutation 的分布指数 `eta`：

- 目标空间变化 `Delta F`：
  - 使用一组 change evaluators；
  - 比较同一候选在变化前后多个目标上的相对变化。
- 决策空间变化 `Delta X`：
  - 环境变化后重新评价 change evaluators；
  - 对每个参考方向找新环境关联个体；
  - 对对应决策向量距离做 95% 右尾 T-test，判断 PS 是否显著变化；
  - 若显著，再计算平均相对决策差异。
- 综合 `Delta F` 和 `Delta X` 得到 polynomial mutation 的 `eta`，并限制在 `[2,20]`。
- 直觉：
  - 若目标值改变但 PS 基本不动，决策空间检验会抑制过强变异，使 `eta` 较大、扰动较小；
  - 若 PS/PF 均发生明显变化，则降低 `eta`，增强突变以恢复多样性和追踪能力。

## VAR 与 EAH 的自适应调度

- 对每个参考方向 `lambda_i`，VARE 维护使用 VAR 的概率 `pi_i`。
- `pi_i` 由最近 `L` 个环境中 VAR 产生个体和 EAH 产生个体被保留到初始种群的成功率共同决定。
- 因此不同方向可以有不同响应策略：
  - VAR 在该方向历史上预测成功，则提高 VAR 概率；
  - VAR 失败或环境变化不适合线性预测，则更多调用 EAH。
- 参数敏感性实验显示 lag order `l=5` 整体最好，`L=l` 足够；过大的 `l` 会因样本不足和过拟合导致性能下降。

## 实验设置与结果

- Benchmark：
  - CEC 2018 DMO 的 DF1-DF14，其中 9 个 biobjective、5 个 triobjective；
  - 另加入 F8、FDA4、FDA5，共 17 个 DMOPs。
- 动态参数：
  - `nt ∈ {5,10,20}`；
  - `tau_t ∈ {10,20,30}`；
  - 每个问题设置 `10*nt` 次环境变化。
- 种群和预算：
  - biobjective `N=100`；
  - triobjective `N=105`；
  - 尽量保证每个环境使用相同 `N*tau_t` 函数评价。
- 对比算法：
  - Group A：PPS、SGEA、Tr-RM-MEDA、MOEA/D-SVR；
  - Group B：DIP、KTS、AE。
- 指标与统计：
  - MIGD、MHV；
  - 30 次独立运行；
  - MATLAB 2022a，Linux，Intel Xeon Gold 6138。

主要结果：

- Group A 中，VARE 在大多数问题上取得最好或接近最好的 MIGD/MHV 总体排名。
- 在 DF3/DF4 等存在变量 linkages 的问题上，VARE 优势明显，作者将其归因于 VAR 对决策变量相关性的建模。
- 在 DF7/DF8 等多方向和步长变化问题上，VARE 与 MOEA/D-SVR 均比中心预测类方法更稳；但 VARE 运行时间远低于 MOEA/D-SVR。
- 对 disconnected PF 的 DF9，VARE 与 Tr-RM-MEDA 表现相近。
- triobjective 中，VARE 在多数问题领先，但在 DF10/DF11/DF13 上略逊于 SGEA。
- 运行时间上，SGEA 最快，其次 PPS 和 VARE；VARE 通常在两分钟内完成 100-change 问题，而 Tr-RM-MEDA 与 MOEA/D-SVR 往往需要约百分钟量级。作者总结 VARE 约只需 Tr-RM-MEDA/MOEA/D-SVR 2% 的运行时间。
- Group B 中，VARE 在 biobjective 9 个问题中 7 个取得最佳 MHV，仅 DF6 明显输给 DIP，DF8 与 AE 接近；triobjective 中 5/8 领先，其余 3 个由 AE 小幅领先。
- KTS 在部分动态场景中因为响应消耗过多评价预算而错过环境变化，IGD 曲线出现不连续。

## 消融与参数

- 消融比较 VARE、VAR-only、EAH-only，在 17 个问题上取 `(nt,tau_t)=(10,10)`。
- VAR-only 在多数问题上已经接近完整 VARE，说明 VAR 是主要贡献。
- EAH-only 整体弱很多，但在 DF2、DF12、F8、FDA4 等 VAR 预测困难问题上能改善完整 VARE。
- `l ∈ {1,2,5,8,10,15}` 的敏感性显示：
  - `l=1` 历史不足；
  - `l=5` 整体最好；
  - `l=8` 后提升趋缓；
  - 更大 `l` 可能因样本不足、估计不稳而变差。
- `L=gamma*l` 且 `gamma∈{1,...,5}` 的实验显示 `L` 影响较小，`L=l` 已足够。

## 真实应用：动态水火电调度

- 问题：dynamic hydrothermal power scheduling。
- 目标：
  - 最小化 fuel cost；
  - 最小化 gas emission。
- 约束包括电力平衡、水库与火电机组相关非线性约束。
- 设置两类环境变化间隔：30 分钟和 1 小时。
- 因真实 PF 未知，作者用近似 PF 和 max-min normalization 后的 HV 评估，参考点为 `(1.1,1.1)`。
- 结果：
  - 1 小时间隔下，VARE 与 DIP 最优；
  - 30 分钟间隔下，VARE 与 AE 表现最好；
  - VARE 在两种时间粒度下均保持领先或并列领先。

## 局限与阅读边界

- VARE 强依赖 reference directions，VAR 预测和 EAH 都以参考方向关联个体为基本单位；不直接适配完全非参考向量的动态优化器。
- VAR 是线性时间序列模型，对高度非线性、突变式或混沌式 PS/PF 演化可能不足。
- VAR 需要足够历史环境；早期或环境变化机制突然切换时，预测质量依赖 EAH 补偿。
- PCA 80% variance、`l=5`、`L=l` 等设置来自实验经验，跨问题自动选择仍未解决。

## 可复用知识与创新线索

- 值得建立的设计知识：已新建“向量自回归降维动态响应”，因为它提供了可移植的动态响应模块：参考方向历史解轨迹、PCA 降维、多输出 VAR 预测、变化感知超变异和基于成功率的策略调度。
- 局部创新线索：
  - 用 kernel PCA、autoencoder、random projection 或 active subspace 替代 PCA；
  - 用 sparse VAR、switching VAR、Kalman filter、Gaussian process state-space model 替代线性 VAR；
  - 把 `pi_i` 的成功率调度改成 bandit 或 Bayesian model selection；
  - 将 EAH 的 T-test 改成 nonparametric test、change-point detector 或 uncertainty-aware severity estimator。
- 结构创新线索：
  - 在已有 DMOEA 的 change response 层插入“参考方向轨迹建模 + 环境感知扰动”；
  - 将 VAR/EAH 输出作为动态代理模型的 warm-start 点；
  - 在动态约束 MOO 中把可行边界移动也纳入决策空间变化强度。
