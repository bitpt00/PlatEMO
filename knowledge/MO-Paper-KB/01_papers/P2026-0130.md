# A decomposition-based constrained multi-objective optimization algorithm with dynamic resource reallocation guided by niche classification

## 一句话理解

本文提出 DRNC：在 decomposition-based CMOEA 中不再默认所有 reference-vector 子问题同等重要，而是每代根据每个 niche 的“是否存在、是否可行、是否被支配以及被支配程度”分成 5 类，再让主种群、辅助种群和 mating pool 对不同类型 niche 分配不同资源，并用代际 subpopulation movement 评估同类 niche 的继续投资潜力。

## 问题与动机

- 研究对象：constrained multi-objective optimization problems (CMOPs)。
- decomposition-based CMOEA 的基本做法是用 weight vectors / aggregation functions 把 CMOP 分解为多个 scalar subproblems。
- 关键问题：不同 subproblems 对 CPF 的贡献不均匀，资源需求也随进化阶段变化。
- 现有方法不足：
  - uniform weight allocation 简单但会浪费预算在不贡献 CPF 的 subproblems；
  - 只按 feasibility 优先会把搜索推向局部可行区，且 feasible subregion 不一定贡献最终 CPF；
  - population-level phase switching 只能全局同步调整，无法给每个 subproblem 个性化搜索序列；
  - 依赖 dominance 后验淘汰可能过早丢弃实际包含 CPF 片段的 subproblem。
- 本文目标：把 subproblem/niche 的局部状态转化为动态先验知识，指导 resource reallocation、selection 和 mating。

## 核心算法 DRNC

- 初始化：
  - 两个 population：main population `PG1` 与 auxiliary population `PG2`；
  - external archive `E` 保存所有已发现 feasible solutions；
  - partition optimal solution set `S` 保存每个 niche 的代表性历史最优解；
  - niche category `Type` 由 Algorithm 2 动态更新。
- 主循环：
  - 根据 niche category 与 intergenerational fitness 构造两个 mating pools；
  - 生成 `OG1` 与 `OG2`，合并为 `OG`；
  - 用 `OG` 中 feasible solutions 更新 external archive `E`；
  - 重新更新 `S` 与 `Type`；
  - 用 Algorithm 3 更新 main population；
  - 用 Algorithm 4 更新 auxiliary population；
  - 用 Algorithm 5 计算 niche-level fitness；
  - 最终输出 `PG1`。

```text
weight-vector niches
-> partition optimal solution set S
-> Type-1..Type-5 dynamic niche classification
-> main population: prioritize Type-5 / Type-4, release Type-3, preserve useful Type-2
-> auxiliary population: two-phase UPF-to-infeasible-side CPF support
-> intergenerational niche fitness by Gap and direction alignment
-> mating pool selection by Type + fitness
```

## 动态生态位分类

- 每个个体根据最近 unit weight vector 归入一个 niche。
- 每个 niche `i` 维护一个 partition optimal solution `Si`：
  - 若该 niche 没有 feasible individuals，则选 minimum CV individual；
  - 若存在 feasible individuals，则在 non-dominated feasible individuals 中选 PBI 最小者。
- 分类依据：
  - existence：`Si` 是否为空；
  - feasibility：`Si` 是否可行；
  - dominance：可行 `Si` 是否 non-dominated；
  - dominance degree：对 dominated feasible `Si`，用其相对 dominating non-dominated solution 的角度潜力评估未来成为 non-dominated 的可能。
- 动态阈值 `eta`：
  - 用 logistic function 由 lower bound `lb`、当前代数和最大代数构造；
  - 早期和后期变化慢，中期变化快；
  - 默认 `lb=0.8`。
- 五类 niche：
  - Type-1：unexplored niche，`Si` 为空；
  - Type-2：infeasible niche，`Si` infeasible；
  - Type-3：high-dominance niche，`Si` dominated 且 dominance degree `< eta`；
  - Type-4：low-dominance niche，`Si` dominated 且 dominance degree `>= eta`；
  - Type-5：non-dominated niche，`Si` 是 non-dominated feasible。

## 主种群资源重分配

- main population 以高优先级 niche 为核心：
  - Type-5：non-dominated feasible，被视为最直接贡献 CPF 的 niche，至少保留一个个体，并从局部到全局逐渐扩大搜索；
  - Type-4：dominated 但仍有较高进化潜力，每个 niche 保留一个个体；
  - Type-3：high-dominance，立即释放资源，不保留个体；
  - Type-2：当 Type-5/4 基准集合不足时，可选择低 CV 个体，用于连接 discontinuous feasible subregions 和边界开发；
  - Type-1：不处理。
- 环境选择：
  - 从 `S` 中提取 Type-5 和 Type-4 代表形成 benchmark set `B`；
  - 优先选择 union population 中 Type-5 个体；
  - 删除被 `B` 支配的个体；
  - 使用 fast non-dominated sorting 与 SPEA2-style crowding pruning 保持多样性；
  - 若资源仍不足，引入 Type-2 个体并按 CV 删除冗余。

## 辅助种群与 mating

- auxiliary population 两阶段：
  - Phase 1 忽略约束，每个 niche 选择 PBI 最小个体，快速接近 UPF 并推动主种群跨越不可行区；
  - 当相邻代 `Gap(PG2+1, PG2) <= alpha` 时进入 Phase 2，默认 `alpha=1e-4`；
  - Phase 2 重新引入约束，从 infeasible side 接近 CPF。
- Phase 2 的 niche-specific selection：
  - Type-2：选 minimum CV individual；
  - Type-3/4：选到 Type-5 代表集合欧氏距离最小的个体；
  - Type-5：若远离 CPF 则选 minimum CV，若已有 feasible non-dominated 则随机选一个 non-dominated feasible individual；
  - Type-1：不处理。
- mating pool selection：
  - 先按 `Type` 与 fitness 做 binary tournament 选择 niche；
  - Type number 越高优先级越高，同类中 fitness 越低优先级越高；
  - 对 Type-2/3，第二父代从 `PG union E` 随机选择，以增强探索；
  - 对 Type-4/5，第二父代按到第一父代的 Euclidean distance tournament 选择，以强化局部开发和邻域稳定。

## 代际 fitness

- 传统 fitness 只评价单代个体质量，容易把资源持续集中到当前高表现区域，也会在接近 CPF 后遭遇 diminishing returns。
- DRNC 为每个 niche 赋同一个 niche-level fitness：
  - `PG_{t+1,i}` 空、`PG_{t,i}` 非空：`F_i=+inf`，表示该 niche 可能已枯竭；
  - `PG_{t+1,i}` 非空、`PG_{t,i}` 空：`F_i=-inf`，优先探索 newly discovered niche；
  - 两代均非空：`F_i = sign * Gap(PG_{t+1,i}, PG_{t,i})`；
  - `sign=-1` 表示变化方向符合当前 niche optimization direction，应奖励；
  - `sign=+1` 表示方向不符，应惩罚；
  - 若 Gap 为 0，则用 offspring distance 作为继续投资成本信号；
  - 两代均空则忽略。
- 作用：让资源投向“仍在有效前进”的 niche，而不是只投向当前静态表现最好的个体。

## 实验设置

- Benchmark suites：
  - constrained DTLZ：10 个；
  - DAS-CMOP：9 个；
  - LIR-CMOP：14 个；
  - MW：14 个；
  - LSCM：12 个；
  - 共 59 个 benchmark functions。
- 真实应用：
  - multi-unmanned surface vehicle collaborative path planning (MUCP)，4 个场景；
  - objectives：total travel distance、threat exposure、total turning angle；
  - constraints：boundary limits、inter-USV collision avoidance。
- 对比算法：
  - APSEA、CMOEMT、CMOEA-CD、MTOTC、DPPPS、MOEA/D-LCDP、MOEA/D-CMT。
- 指标：
  - IGD+；
  - HV，reference point 为 `1.1 x nadir point`；
  - Wilcoxon rank-sum test；
  - Friedman test with post-hoc analysis。
- 参数：
  - `N=100` for 2 objectives，`N=105` for 3 objectives；
  - Max evaluations：MW `100000`，constrained DTLZ `150000`，DAS-CMOP/LIR-CMOP `200000`，LSCM `500000`；
  - 每个算法独立运行 30 次；
  - PBI penalty `theta=1`；
  - stage switching threshold `alpha=1e-4`；
  - low-dominance lower bound `lb=0.8`。
- 算子配置：
  - constrained DTLZ 与 MW：双种群均用 GA；
  - LIR-CMOP：双种群均用 DE；
  - DAS-CMOP 与 LSCM：main population 用 GA，auxiliary population 用 DE。

## 主要结果

- LIR-CMOP + MW：
  - IGD+ 上 DRNC 在 28 个问题中取得 21 个 best；
  - HV 上 DRNC 取得 19 个 best；
  - LIR-CMOP3、LIR-CMOP8、MW5、MW13 的可视化显示 DRNC 更能覆盖断裂/离散 CPF 并维持均匀分布。
- DAS-CMOP + constrained DTLZ + LSCM：
  - IGD+ 上 DRNC 在 31 个问题中取得 19 个 best；
  - HV 上 DRNC 取得 17 个 best；
  - DAS-CMOP1、DAS-CMOP9、C1-DTLZ3、LSCM4 的可视化显示 DRNC 能穿越 infeasible barriers、覆盖 archipelago-like feasible fragments，并在复杂约束变量耦合下保持收敛。
- Friedman test：
  - DRNC 在所有 benchmark 上 IGD+ average rank 为 `1.63`，HV average rank 为 `1.98`；
  - 第二名 CMOEA-CD 的 ranks 为 `3.49` 和 `3.42`；
  - 以 DRNC 为 control method 的 post-hoc p-values 均显示显著优势。
- Runtime：
  - DRNC 运行时间只高于 CMOEA-CD 和 APSEA，低于 MOEA/D-CMT、CMOEMT、MTOTC 等多种复杂协同方法；
  - 作者认为原因是 DRNC 只维护两个 populations，且避免额外 inter-population information exchange。
- MUCP：
  - DRNC 在 4 个多 USV 协同路径规划场景中 HV 均为最优；
  - 场景包括双 USV parallel/crossover、更复杂 parallel cooperation、四 USV opposite-direction collision-free planning。

## 消融与参数分析

- 参数 `theta`：
  - 在 LIR-CMOP 上比较 `theta=0,1,2,3,4`；
  - `theta=1` 在所有测试实例上表现最好。
- stage threshold `alpha`：
  - 比较 `1e-2,1e-3,1e-5,1e-6`；
  - 推荐 `alpha=1e-4`，避免过早切换或过度延迟。
- dynamic threshold `eta`：
  - 比较 logistic、linear、exponential membership functions；
  - `lb` 在 `0.5-0.95` 搜索；
  - LIR-CMOP12 上 `lb≈0.8` 最优，logistic 比 linear/exp 更稳。
- genetic operator setting：
  - dual-DE 对 LIR-CMOP 最有效；
  - dual-GA 对 MW 和 constrained DTLZ 最有效；
  - GA-main/DE-auxiliary 对 DAS-CMOP 和 LSCM 最平衡。
- niche classification 消融：
  - `DRNC-V1` 使用 uniform weight allocation、non-adaptive auxiliary selection 和 random second parent；
  - 在 LIR-CMOP 上，DRNC 相对 V1 的 IGD+ 为 `0/13/1`，HV 为 `2/12/0`；
  - LIR-CMOP4 的可行解比例曲线显示 DRNC 更快达到完全可行。
- intergenerational fitness 消融：
  - `DRNC-V2` 随机选择 mating parent `p1`，不使用 fitness guidance；
  - 在 DAS-CMOP 上，DRNC 相对 V2 的 IGD+ 和 HV 均为 `0/7/2`；
  - 说明代际 niche progress 比单代静态表现更能识别未开发潜力。

## 与知识库相关的设计知识

- 新增/关联设计知识：
  - `K-niche-classified-decomposition-resource-reallocation`：生态位分类驱动的分解子问题资源重分配。
- 与已有设计知识的区别：
  - 不同于 `K-dominance-decomposition-coevolution-stage-switching`：该知识维护 dominance/decomposition 两个完整框架并做 population-level stage switching；本文仍在 decomposition/niche 框架内，对每个 niche 做 Type-1 到 Type-5 的个性化资源分配。
  - 不同于 `K-update-state-driven-dual-reference-switching`：该知识切换聚合函数参考模式；本文不切换 reference point，而是按 niche category 改变 selection、auxiliary behavior 和 mating。
  - 不同于 `K-decomposition-dominance-sparse-exploration`：该知识在 MOEA/D 中叠加 SPEA-II 全局选择和稀疏探索；本文核心是 niche 分类先验和代际 progress fitness。
  - 不同于 `K-game-competitive-dual-population-resource-allocation`：该知识按主/辅 population 的整体竞争度分配资源；本文资源最小单元是 weight-vector niche/subproblem。

## 局限与未来工作

- 极小 CPF 问题中，宽广 objective space 可能使 ideal point 远离 feasible region，导致许多 reference vectors 无效。
- 当前 pruning operator 在 high-dimensional objective spaces 中可能因 distance-based selection 带来位置不稳定。
- 算子配置虽然按 test suite 适配，但仍是静态规则；作者计划引入 reinforcement learning 动态选择算子。
- DRNC 目前主要验证在低/中目标数 CMOP，constrained many-objective optimization 仍需扩展。
