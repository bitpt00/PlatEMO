# Observer-Based Multiobjective Control of Switched Networked Control Systems With Multipath Packet Dropouts

## 一句话理解

本文把切换网络控制系统中的控制输入丢包、测量输出丢包和切换规则丢失分别建成独立 Bernoulli 随机过程，并设计 mode-dependent / mode-independent 混合观测器控制器，通过 MLF、ADT 和两步 LMI 同时保证观测误差的加权 H∞ 性能与系统输出的加权 L2-L∞ 性能。

## 问题与动机

- 研究问题和场景：switched networked control systems 在共享网络中会遇到多路径 packet dropouts，且切换规则本身也可能丢失；系统状态不全可测，需要 observer-based control。
- 现有算法为什么不足：已有 SNCS 研究多关注控制输入或测量输出丢包，较少处理 switching rule loss；传统观测器常假设 observer 与 plant 共享同一动态参数，但在丢包和切换规则丢失下 observer 不一定能获得当前 `A_l`；已有 observer-based control 多只最小化系统输出扰动衰减，较少同时考虑估计误差扰动衰减。
- 本文希望解决什么：在多路径丢包和切换规则丢失同时存在时，联合设计 observer dynamics、observer gains 和 controller gains，使 closed-loop SNCS 稳定，并同时满足两个性能指标。

## 核心理念与算法流程

- 核心理念：当切换规则和 plant dynamics 可用时启用 mode-dependent observer/controller；当传输失败时启用 mode-independent observer/controller，并额外设计 observer dynamics `A`，从而不再强制 observer 使用 plant 的动态矩阵。
- 主要流程：
  1. 用三个互相独立的 Bernoulli 随机变量描述 control input dropout、measurable output dropout 和 switching rule loss；
  2. 构造 hybrid observers：成功获得切换规则和 `A_l` 时使用 mode-dependent observer，否则使用待设计的 mode-independent dynamics `A` 与 gain `L`；
  3. 基于 observer state 构造 hybrid controllers：切换规则成功时使用 `K_l`，否则使用 `K`；
  4. 写出闭环 augmented system，以 `psi=[x,e]` 同时描述 system state 和 estimation error；
  5. 用 multiple Lyapunov functionals 和 average dwell time 推导 stability、weighted H∞ 和 weighted L2-L∞ performance 条件；
  6. 通过两步 decoupling 和变量替换，把 observer/controller 设计条件转化为严格 LMI；
  7. 给定或优化 `gamma`，求 observer dynamics、hybrid observer gains 和 hybrid controller gains。
- 关键组成部分：multipath Bernoulli dropout model、hybrid observer/controller、observer dynamics co-design、MLF、ADT、weighted H∞ for estimation error、weighted L2-L∞ for controlled output、two-step LMI synthesis。
- 可能被修改的位置：网络控制系统的 observer design、packet dropout compensation、switching rule loss handling、robust/multiobjective controller synthesis。
- 必须保留的核心：切换规则或动态参数不可用时要有 mode-independent fallback observer/controller；多目标性能必须同时覆盖 estimation error 和 controlled output，而不是只优化系统输出。

## 局限与未来工作

- 作者明确说明的局限：所有 sensors 共享相同测量丢包概率、所有 actuators 共享相同控制丢包概率；不处理 partial packet dropout；假设 switched system 与 hybrid controllers/observers 同步切换；未考虑 switching rule 受 disturbance 影响；未处理系统参数不确定性。
- 作者未来工作：扩展到 disturbance-influenced switching rules、partial dropout 或不同 sensor/actuator dropout probabilities、asynchronous SNCS、matched/unmatched uncertainties。
- 我们认为仍需确认的问题：LMI 尺寸随 subsystem 数和状态维数扩展后的可解性；多性能指标是否可进一步形成 Pareto trade-off 而不只是共同最小化 `gamma`；在真实网络延迟、乱序和非 Bernoulli 丢包下是否稳健。

- 局部创新线索：将 Bernoulli dropout 扩展到 Markov dropout、partial packet dropout 或 path-dependent dropout；在 LMI 设计中加入 passivity、dissipativity、energy cost 或 actuator saturation。
- 结构创新线索：把 mode-dependent controller、mode-independent fallback controller、dropout probability model 和 multi-performance LMI optimizer 作为一套可复用的 robust NCS synthesis pipeline。
