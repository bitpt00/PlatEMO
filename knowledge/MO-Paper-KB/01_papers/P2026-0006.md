# Representation embedded learning via autoencoder for large-scale multi-objective optimization

## 一句话理解

本文提出 RELA，用目标空间分布而不是只用决策空间变量分组来引导 LSMOP 搜索：先按 objective-space distribution 把 population 聚成两个子群，用各子群的非支配解训练 autoencoder，提取并融合 latent encodings，再经 decoder 重构出质量更高的 non-dominated solution set。前 25% 评价预算用重构解集引导收敛，后期切换到 diversity optimization，兼顾 convergence 与 diversity。

## 问题与动机

- 研究问题和场景：large-scale multi-objective optimization problems，决策变量通常达到数百、数千甚至更多，传统 MOEA 容易受 curse of dimensionality、搜索空间复杂性和大量局部最优影响。
- 现有方法为什么不足：
  - Decision variable grouping 依赖分组准确性，且高维变量分组会消耗大量计算资源；
  - Decision space reduction 可能丢失全局信息，导致陷入局部最优；
  - 新搜索策略或概率模型多关注 decision space，较少利用 objective space 中 population distribution 的演化信息；
  - 经典 decision variable analysis 常假设变量属性在全局 objective space 一致，但不同 objective regions 的个体可能具有不同特征；
  - 只用当前非支配解集直接引导高维搜索，可能没有充分融合不同子区域的潜在演化信息。
- 本文希望解决什么：从 objective-space 子区域中学习 elite solutions 的 latent representations，进行跨子群信息融合并解码成更优的重构解集，用该解集在决策空间提供更准确的搜索方向。

## 核心理念与算法流程

- RELA 总框架：
  1. 初始化 population `P`。
  2. 若已消耗评价比例小于阈值 `phi`，执行 autoencoder reconstruction pipeline。
  3. 将 `P` 按 objective-space distribution 用 k-means 分成 `P1/P2`。
  4. 对每个子群做 non-dominated sorting 得到 `NS1/NS2`，并将解按变量上下界归一化。
  5. 分别用 `NS1/NS2` 训练 autoencoder 1 和 2，得到 encodings `C1/C2` 及 decoders `De1/De2`。
  6. 用 encoding reconstruction strategy 融合 `C1/C2`，得到 `C1'/C2'`。
  7. 用 `De1/De2` 将重构 encodings 解码回 decision space，形成 reconstructed non-dominated solution set `Xr`。
  8. 用 `Xr` 引导子代生成并环境选择。
  9. 当评价比例超过 `phi` 后，改用 diversity optimization strategy 生成子代。
- Representation embedding learning：
  - Autoencoder 由 encoder 和 decoder 组成，encoder 把决策向量 `x=(x1,...,xn)` 映射到 `k` 维 encoding，decoder 从 encoding 重构 `x`。
  - 每代为两个 objective-space 子群分别训练 autoencoder，训练数据是子群内的非支配解。
  - 归一化公式为 `x_i'=(x_i-lower_i)/(upper_i-lower_i)`。
  - 训练用 mean squared error，并采用 sigmoid activation；权重通过 gradient descent 更新。
- Encoding reconstruction：
  - Encoding crossover：对 `C1/C2` 中对应 encodings 执行 SBX，保留原有 encoding 信息的同时引入多样性。
  - Encoding extraction：把 `C1` 与 `C2` concatenate 成 `2k` 维集合 `C`，训练第三个 autoencoder，再输出 `k` 维 compact encodings `C'`。
  - 将 `C'` 分别并入 `C1'/C2'`，供两个 decoder 解码。
- Solution set reconstruction：
  - 把重构 encodings 输入 `decoder1/decoder2`，输出合并为 `Xr`。
  - 作者认为 `Xr` 比原始 non-dominated solution set 具有更好 convergence 与 diversity，可作为更高质量的搜索引导。
- Reconstruction-based offspring generation：
  - 对当前个体 `x`，在 objective space 中找到与它角度最小的重构解 `x_best^r`。
  - 用 normalized direction `(x-x_best^r)/||x-x_best^r||` 加上 DE-like 差分项 `x_d1-x_d2` 生成 `x_new`。
  - 该方向项提供收敛引导，差分项提供多样性。
- Diversity optimization offspring generation：
  - 对当前 population 做 non-dominated sorting，得到非支配集 `ND` 和 dominated set `D`。
  - 对 dominated solutions，匹配 `ND` 中角度最小解，再用同一子代公式生成新解。
  - 对 non-dominated solutions，匹配 `ND` 中角度最大解，让每个非支配个体向相距最远的方向探索，以增强多样性。
- 复杂度：
  - Autoencoder training、encoding reconstruction、solution reconstruction 与 environmental selection 叠加后，单代整体复杂度约为 `O(mN^2+nKN)`。

## 实验证据

- 实验设置：
  - Benchmark：LSMOP1-9 与 IMF1-10。
  - LSMOP1-9：`n=1000,2000,5000`，目标数为 2 和 3，共 54 个测试设置。
  - IMF1-10：`n=1000,2000,5000`，IMF4/IMF8 为 3 objectives，其余为 2 objectives，共 30 个设置。
  - Real-world case：TREE1-5，TREE1-2 为 3000 variables，TREE3-5 为 6000 variables。
  - 对比算法：NNCSO、LMOEADS、DGEA、FDV、ALMOEA。
  - 每个算法 20 independent runs；Wilcoxon rank sum test 和 Friedman test，显著性 `p<0.05`。
  - 指标：IGD 与 HV；2-objective population size `N=100`，3-objective `N=153`，`MaxFE=100000`。
- LSMOP1-9 综合结果：
  - 在 54 个 LSMOP 设置中，RELA 取得 39 个最佳 IGD；第二好的 LMOEADS 为 13 个最佳 IGD。
  - RELA 在 IGD 上分别优于 NNCSO、LMOEADS、DGEA、FDV、ALMOEA 的问题数为 52、40、54、45、46。
  - 在 HV 上，RELA 取得 40 个最佳结果；第二好的 LMOEADS 为 7 个最佳 HV。
  - RELA 在 HV 上分别优于五个对比算法 47、39、48、41、37 个问题。
  - Friedman ranking 显示 RELA 在 IGD 和 HV 上均为最佳；all IGD rank 为 1.45，all HV rank 为 5.41。
- 收敛过程：
  - Fig. 3 中 RELA 前 25% FE 用 autoencoder 重构非支配解集引导收敛，之后用 diversity optimization 增强多样性。
  - 作者观察到 RELA 在早期和切换 diversity optimization 后 IGD 均明显下降，约 30% FE 时达到并继续维持最优 IGD。
- IMF1-10 结果：
  - RELA 在 30 个 IMF 设置中取得 15 个最佳 IGD。
  - 相对 NNCSO、LMOEADS、DGEA、FDV、ALMOEA，RELA 分别在 30、21、30、24、30 个设置中取得更优 IGD。
  - Friedman 最终 rank 为 1.5，`chi^2=96.46`，`p=2.95e-15`。
  - 按 IMF 特征分组，RELA 在 linear association 和 3-objective 问题上略弱于 LMOEADS，但在其他特征上表现最好。
- Runtime：
  - RELA 只在前 25% FE 训练 autoencoders，平均 runtime 显著低于 NNCSO 和 ALMOEA 两个 ML 方法。
  - 非 ML 方法如 LMOEADS/FDV 通常更快，但随着维度增加，其相对 RELA 的 runtime ratio 增大，作者认为非 ML 方法高维效率下降。
- 可视化与消融：
  - Fig. 6 显示 encoding extraction 和 encoding crossover 重构出的 solution sets 更靠近 ideal point，说明重构解集比原始非支配集更适合引导。
  - RELA1 去掉 autoencoder reconstruction，改用原始非支配解集引导；RELA 相对 RELA1 在 27 个 LSMOP 设置上为 `0/23/4`。
  - RELA2 去掉 diversity optimization；RELA 相对 RELA2 为 `4/14/9`。
  - 作者认为 encoding reconstruction 对性能影响更显著，diversity optimization 对避免局部最优和保持全局搜索能力也重要。
- 参数敏感性：
  - `phi`：`25%` 的 IGD rank 最好，`50%` 的 HV rank 略好，但 runtime 为 25% 的 1.46 倍；作者选择 `phi=25%` 作为性能和运行时间折中。
  - `k`：实验选择 `k=n/10`；更大的 `k` 可能更好但 runtime 明显增加，Bonferroni-corrected p-values 显示差异不显著。
  - `nLayer`：3 层 autoencoder 在 IGD/HV/running time 折中上最合理。
  - Activation function：sigmoid 显著优于 satlin，和 purelin 差异不显著；作者选择 sigmoid。
  - `nSub`：2-6 个子群中，增加子群数未显著改善 IGD，但会明显增加 runtime，因此选择 `nSub=2`。
- TREE 真实问题：
  - TREE 是 voltage transformers 的 Time-Varying Ratio Error Estimation 问题，具有 irregular PS/PF、变量交互、变量-目标相关和约束。
  - TREE1-3 有 2 objectives/3 constraints，TREE4-5 有 2 objectives/4 constraints。
  - RELA 在 TREE1、TREE2、TREE5 取得最佳 HV；TREE3 与 LMOEADS 统计相当，TREE4 略低于 LMOEADS。
  - Table 11 总结中 RELA 相对 LMOEADS 为 `1/3/1`，相对其它算法均为 `0/5/0`。

## 局限与未来工作

- 作者明确提出的未来方向：
  - 进一步研究如何选择 ML model；
  - 如何训练模型；
  - 如何利用 learned knowledge 更有理论基础地引导 population evolution。
- 我们认为仍需确认的问题：
  - 每代在线训练 autoencoders 虽然 epoch 少，但在更高维、更大 population 或昂贵评价外还会增加实现复杂度。
  - `phi=25%` 是全局固定阈值，未根据收敛停滞、diversity loss 或 reconstruction quality 自适应切换。
  - Objective-space k-means 只分两个子群；复杂 PF 或多模态 PS 下可能需要更多区域，但更多子群又增加训练成本。
  - Autoencoder 训练数据只来自各子群非支配解，若早期非支配解质量差或分布偏斜，重构解集可能放大偏差。
  - 重构解是否一定 feasible 或边界内，论文主要通过归一化方向控制解释，缺少更细的约束/repair 说明。
  - TREE 是约束真实问题，但核心 RELA 机制主要按无约束 LSMOP 描述，约束处理细节不足。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：已新建 [目标空间分群的自编码解集重构](../02_design_knowledge/K-objective-clustered-autoencoder-solution-reconstruction.md)，因为它给出可直接移植到 LSMOP 的在线 representation-learning pipeline：objective-space clustering、subpopulation autoencoders、cross-subpopulation encoding reconstruction、decoded solution-set guidance 和后期 diversity optimization。
- 暂留在论文卡中的方法或启发：
  - `phi/k/nLayer/AF/nSub` 的具体默认值先作为 RELA 实例参数记录，不单独建参数卡。
  - TREE 电压互感器误差估计是应用场景，当前不单独建工程问题卡。
- 局部创新线索：
  - 用 reconstruction error、IGD/HV improvement 或 offspring survival rate 自适应决定 `phi`。
  - 将 k-means 替换为 reference-vector、density、manifold 或 clustering stability 驱动的 objective-space 分区。
  - 让每个子群 autoencoder 共享部分权重或使用 mixture-of-autoencoders，降低重复训练成本。
  - 在 reconstructed solution set 上加入 uncertainty/novelty/feasibility 过滤，避免 decoder 生成低可信候选。
- 结构创新线索：
  - 构建“objective-region representation bank”：跨代保存每个 objective region 的 encoder/decoder，用稳定区域 warm-start 训练。
  - 与 variable grouping 结合：autoencoder 只重构高重要变量或低维 latent variables，其余变量用局部搜索补偿。
  - 与 surrogate-assisted LSMOP 结合：代理先评估重构候选的潜在贡献，真实评价只给高价值 decoded solutions。
