# 双智能体对抗策略的多目标竞争协同进化与规则性决策

## 一句话理解

这篇论文把 attacker-defender wargame 抽象为两个相互依赖的多目标优化问题：每个智能体都有自己的策略变量和 Pareto front，但任何策略的效果都必须和对手策略配对后才能评价。作者用 MoCCoEv 交替进化两方 Pareto 策略集，再用轮流响应式 MCDM 选择策略；进一步用 progressive shrinking 固定已承诺或在 Pareto 集中低变化的变量，让连续决策更接近真实场景中的“前面走过的棋不能随便撤回”。

## 研究问题

- 多智能体对抗问题中，一方策略的效果取决于对手策略，不能把 attacker 和 defender 各自独立优化。
- 每个智能体自身又有多个冲突目标，因此单个最优策略通常不存在，需要得到各自的 Pareto strategy set。
- 得到两套 Pareto front 后，还需要交互式决策：一方声明策略，另一方从自己的 Pareto front 中选响应策略，循环直到出现 equilibrium point 或 strategy cycle。
- 真实序贯决策还存在 commitment：早期已经选择的资源、平台或部署不能在下一轮任意切换到完全不同策略。

## Wargame 策略优化问题

- 场景包含 offense/attacker 与 defense/defender 两个智能体。
- attacker 希望对 airbase 造成更多命中，同时控制自身成本，并让 defender 支出更大代价；defender 目标与其相反。
- 两方策略变量包括：
  - research and engineering (RE)：平台能力、传感器、速度、隐身、载荷等；
  - force composition (FC)：不同资产数量和组成；
  - mission plans (MP)：阵型、交战规则、路线等。
- attacker 有 50 个变量，defender 有 24 个变量。
- 原始仿真来自 Command Modern Air and Naval Operations (CMANO)，每个 scenario 在无图形加速下平均约 6 分钟，论文因此用从 simulator 数据训练的 surrogate model 近似评价。
- 原始目标中部分生命损失成本和 expenditure 高相关，作者删除高度相关目标，并用 expenditure difference 简化目标表示。

## MoCCoEv 算法

- 维护两个人口：
  - `Pop1`：attacker/offense strategy population；
  - `Pop2`：defender/defense strategy population。
- 评价 `Pop1` 中一个策略时，不是只配一个固定 defender，而是和 `Pop2` 中所有 defender 策略逐一组合评价。
- 对每个 attacker 策略，取其与所有 defender 策略配对后的目标均值作为该策略的 fitness vector。
- defender population 也对称处理。
- 两个种群交替更新：
  - 对 `Pop1` 连续执行 `tau1` 代选择、变异、与对手全集评估、NSGA-II survival；
  - 再对 `Pop2` 连续执行 `tau2` 代同样过程；
  - 直到终止。
- 作者使用 NSGA-II 作为每个 population 的环境选择机制。

## 决策模型 1：离线 Pareto 集上的轮流响应式 MCDM

1. 离线运行 MoCCoEv，得到 attacker 和 defender 各自的 Pareto strategy set。
2. 假设 defender 先行动：
   - 每个 defender 策略与所有 attacker Pareto 策略配对；
   - 对 defender 目标向量计算平均值和标准差；
   - 从 defender ND 策略中选目标标准差最低者作为最稳健初始策略。
3. attacker 看到 defender 选择后：
   - 用每个 attacker Pareto 策略对抗该 defender；
   - 找出当前配对下的 attacker ND set；
   - 用 highest tradeoff / knee-like 规则选择最合适响应。
4. defender 再对 attacker 的选择做同样响应。
5. 迭代直到出现：
   - equilibrium strategy pair；或
   - equilibrium cycle。

在论文复用的早期离线结果中，MCDM 产生了 `D9 -> O36 -> D43 -> O0 -> D9` 的 equilibrium cycle。

## 决策模型 2：Progressive shrinking

离线 Pareto 集允许一方从任意策略跳到另一策略，但真实序贯决策中并不总可行。Progressive shrinking 用变量固定模拟“已承诺决策”：

1. 先执行 MoCCoEv 和一次 DM，得到两方选择的策略。
2. 由专家指定必须连续保持的变量，固定为当前 DM 策略中的取值。
3. 在缩小后的变量空间中重新优化，获得新的两方 Pareto strategy set。
4. 对每个变量在新 Pareto set 中的取值计算 coefficient of variation (CoV)。
5. 若变量 `CoV < 0.3`，视为在优质策略中已经收敛到稳定取值，将其固定为当前 DM 点的值。
6. 重复缩小变量、重优化和 DM，直到没有变量 CoV 低于阈值。

这个过程同时实现两件事：

- 从决策角度，已经稳定或已承诺的变量不再任意改变；
- 从优化角度，变量维度逐步下降，后续搜索更集中。

## 实验与结果

- 每个 co-evolving population 大小为 50。
- MoCCoEv 运行 200 generations。
- 最终得到 attacker 和 defender 各 10 个 ND strategies。
- 五次 MoCCoEv 重复运行之间用 Wilcoxon rank-sum test 检验，offense 和 defense 策略结果均未发现显著差异，作者认为过程较稳健。
- 与训练数据中的 ND 策略和单智能体独立优化相比：
  - MoCCoEv 的两方 ND fronts 更接近，体现了双方策略相互制约；
  - 独立优化会让一方仿佛可以同时控制对手变量，不符合对抗问题。
- Progressive shrinking 结果：
  - 初始变量数为 attacker 50 个、defender 24 个；
  - 经过 8 轮 shrinking 后，剩余 attacker 8 个变量、defender 4 个变量；
  - 最终 DM 得到 `Defense0 -> Offense11 -> Defense14 -> Offense11` 的 equilibrium point。
- 人类 wargame expert 检查最终策略后，认为算法得到的两方策略具有合理性和智能性。

## 局限与阅读边界

- 这是单一真实 wargame case study，缺少跨多类 multiagent game benchmark 的系统比较。
- 论文假设每方知道对手可能策略集合；真实对抗中这种信息通常不完整。
- 对手影响通过“与对手 population 全配对后取平均目标值”表示，可能低估 worst-case 或风险敏感策略。
- DM 启发式较强：
  - 初始 defender 用最低目标标准差代表鲁棒；
  - 后续响应用 highest tradeoff 点代表偏好；
  - 这些偏好不一定适合所有决策者。
- Progressive shrinking 的 `CoV < 0.3` 阈值和专家固定变量依赖领域知识。
- 高保真 simulator 由 surrogate 近似，最终策略质量依赖训练数据和代理误差；正文没有完整展开代理模型细节。
- 第三类更实际的“每次声明策略后，对手在线重优化缩小空间”的模型只作为未来工作提出，未实现。

## 可复用知识与创新线索

- 可复用机制：
  - 双智能体各维护一个 population，并用对手全集配对后的平均目标作为 fitness；
  - 离线得到两方 Pareto strategy sets，再做轮流响应式 MCDM；
  - 用 equilibrium point/cycle 判断交互式决策过程是否稳定；
  - 用 Pareto set 中变量 CoV 识别稳定变量并逐步固定，模拟 commitment。
- 局部创新线索：
  - 把平均对手 fitness 换成 CVaR、worst-case、均值-方差或分位数鲁棒 fitness；
  - 用偏好学习或交互式 DM 替代固定 highest tradeoff 规则；
  - 将 progressive shrinking 与在线 reoptimization 结合，让每个 agent 在对手声明后重新求解缩小后的 Pareto set；
  - 对多智能体供应链、网络攻防、市场竞争、双边谈判、机器人对抗任务复用该框架。
