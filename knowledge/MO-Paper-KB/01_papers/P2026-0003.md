# A niche-based multiobjective evolutionary algorithm for constrained multiobjective optimization with application to power dispatch problems

## 一句话理解

本文提出 NMOEA：面对可行域狭窄、断裂或结构复杂的 CMOP，不再用固定多种群或单一约束处理规则，而是按解空间距离、目标空间角度和约束违反程度动态形成多个 niches；每个 niche 内根据密度与可行率自适应选择搜索算子和约束处理方式，并周期性进行全局交互和重新划分。

## 问题与动机

- 研究对象：constrained multi-objective optimization problems (CMOPs)。
- 应用背景包括电力调度、工业设计、资源管理和物流调度等。
- CMOP 的主要困难：
  - feasible region 可能狭窄、断裂或几何结构复杂；
  - infeasible barriers 会阻碍种群接近 constrained Pareto front (CPF)；
  - 局部 feasible Pareto fronts 容易造成停滞；
  - 需要同时保持可行域内收敛性和多个可行片段之间的多样性。
- 现有多种群 CMOEA 的不足：
  - population partitioning 往往不够精确，难以按解的空间分布和约束状态动态调整；
  - 子种群之间协调不足，容易形成信息孤岛；
  - 单一算子或单一约束处理规则无法同时适应稀疏、密集、可行和不可行生态位。
- 本文目标：用 niche principle 维护多个空间子群，并在 niche 内自适应搜索、niche 间周期性交互，从而覆盖复杂可行区域。

## 核心算法 NMOEA

- 初始化：
  - 随机生成 population `P`，规模为 `N`；
  - 初始化外部档案 `A`；
  - 设置 generation counter `gen=0`；
  - 通过 niche division 得到 `{N1,...,Nu}`。
- 主循环：
  - 对每个 niche `Ni`：
    - 根据 niche 特征选择遗传算子生成 offspring `Oi`；
    - 根据 niche 特征选择约束处理规则更新 `Ni`；
    - 用 SPEA2-style environmental selection、constrained dominance 和 crowding distance 更新 archive `A`。
  - 每隔 `genthre` 代执行 inter-niche interaction：
    - 合并全部 niches；
    - 生成 `N/2` 个全局 offspring；
    - 用 SPEA2 environmental selection 选择 `N` 个个体；
    - 更新 archive；
    - 重新执行 niche division。
- 最终输出 archive `A`。

```text
population P
-> adaptive-radius niche division
-> per-niche operator selection by density
-> per-niche constraint handling by feasible ratio
-> archive update
-> periodic inter-niche SBX/PM interaction
-> global selection and niche re-division
```

## 动态生态位划分

- 生态位划分包含四个阶段。
- Stage 1：计算自适应 niche radius `R`：
  - `R` 随 decision-space 维度、每个变量的分布范围和随机系数 `sigma` 变化；
  - `sigma` 服从 `[1,5]` 上的均匀分布；
  - 半径过小会导致个体高度相似和早熟，过大则会让子群过于分散、收敛变慢。
- Stage 2：分配 feasible solutions：
  - 若 feasible individuals 数量不少于预设 feasible leader 数 `Nniche`，则在 objective space 中按角度分布选择 `Nniche` 个 feasible leaders；
  - 若 feasible individuals 不足，则所有 feasible individuals 都成为 leaders；
  - 每个 leader 吸收 decision-space 半径 `R` 内的个体形成 niche；
  - 未分配的 feasible individuals 分给最近的已存在 niche。
- Stage 3：处理 infeasible solutions：
  - 对未分配 infeasible individuals，选择 constraint violation 最小的个体作为 leader；
  - 将半径 `R` 内的 infeasible individuals 聚成 niche；
  - 重复直到 infeasible set 为空。
- Stage 4：合并小生态位：
  - size 小于 2 的 niche 合并到 decision-space 最近的 niche。

## 生态位内自适应进化

- 算子选择依据 niche density：
  - density 低于阈值 `denthre` 时，使用 `DE/current-to-best/1`，强调向 niche leader 的局部开发；
  - density 高于阈值 `denthre` 时，使用 SBX crossover 和 polynomial mutation，强调探索和分布扩展；
  - 文中局部表述对 density 语义略有不一致，但显式规则是按 `denthre` 在 DE 与 GA/SBX+PM 之间切换。
- 约束处理依据 feasible ratio：
  - `rf = Nfea / Ndp`，其中 `Ndp` 是 niche 中原个体与 offspring 的总数，`Nfea` 是可行个体数；
  - 若 `rf < rfthre`，使用 constrained dominance relation 和 crowding distance，优先推动种群进入可行域；
  - 若 `rf >= rfthre`，放松约束，只用 non-dominated sorting 和 crowding distance，给高质量但可能暂时不可行的区域保留探索机会。

## 生态位间交互

- 每隔 `genthre` 代执行一次交互。
- 交互过程：
  - 合并全部 niches 得到 `Pniche`；
  - binary tournament 选择 `N/2` 个 parents；
  - 用 SBX crossover 和 polynomial mutation 生成 `N/2` 个 offspring；
  - 对 `Pniche union Off` 用 SPEA2 environmental selection 选择 `N` 个个体；
  - 用 offspring 更新 archive；
  - 对新 population 重新划分 niches。
- 设计意图：
  - 防止 niche 内长期自循环；
  - 促进断裂可行片段之间的信息交换；
  - 缓解 population fragmentation 和 premature convergence；
  - 在保留局部生态位结构的同时周期性校正全局分布。

## 与相关方法的区别

- 与 cooperative coevolution 不同：
  - 本文不是把问题分解成 objective task、constraint task 或 helper task；
  - 而是把 solution space 分解成多个空间生态位。
- 与普通多种群 CMOEA 不同：
  - niche 的形成同时考虑 decision-space 距离、objective-space angular diversity 和 constraint satisfaction；
  - niche 内搜索规则会随 density 和 feasible ratio 改变；
  - niche 间交互后会重新划分，而不是固定子群长期独立演化。
- 与分解式 reference-vector niche 不同：
  - 本文的 niche 核心是解空间邻域和约束状态；
  - 不是围绕固定 weight vector/subproblem 做资源分配。

## 实验设置

- Benchmark suites：
  - CF：10 个问题；
  - MW：14 个问题；
  - decision dimension 均为 15；
  - CF8、CF9、CF10、MW4、MW8、MW14 是三目标，其余为双目标。
- 对比算法：
  - PPS；
  - CMOEA-MS；
  - CAEAD；
  - CCMO；
  - DNNSGAII；
  - CMOES。
- 指标与统计：
  - benchmark 使用 IGD；
  - 每个算法独立运行 30 次；
  - Wilcoxon rank-sum test，显著性水平 0.05；
  - 实现平台为 PlatEMO。
- 参数：
  - population size `N=100`；
  - maximum evaluations `8e5`；
  - `Nniche=21`；
  - `denthre=0.4`；
  - `rfthre=0.4`；
  - `genthre=10`。

## 主要结果

- CF suite：
  - NMOEA 在 CF3 和 CF9 上取得最优 IGD；
  - 在多个问题上保持较稳定结果；
  - DNNSGAII 在 CF8/CF10 出现 NaN，NMOEA 未出现该现象；
  - 统计汇总显示 NMOEA 在 CF 上是竞争性而非压倒性最优。
- MW suite：
  - NMOEA 在 14 个问题中的 9 个取得最优 IGD：
    - MW1、MW2、MW5、MW6、MW8、MW9、MW10、MW12、MW13；
  - 相比 PPS、CAEAD、CCMO、CMOES 均在 11 个问题上更优；
  - 相比 CMOEA-MS 在 7 个问题上更优；
  - 相比 DNNSGAII 在 14 个问题上均更优。
- Runtime：
  - NMOEA 快于 CCMO、CMOES 和 PPS；
  - 慢于 CAEAD、DNNSGAII 和 CMOEA-MS；
  - 作者认为其在解质量与计算成本之间较平衡。

## 参数与消融

- 参数敏感性：
  - `Nniche` 从 17 增至 21 时性能改善，继续增大后下降，默认取 21；
  - `denthre=0.4` 在 MW13 上最优，MW14 对该参数相对不敏感；
  - `rfthre=0.4` 在 MW14 上最优，MW13 在更大值下也有改善，默认取 0.4 作为稳健折中；
  - `genthre=10` 最好，过频或过迟交互都会损害性能。
- 消融变体：
  - `NMOEA-NN`：移除 niche division，使用单 population；
  - `NMOEA-NI`：移除 inter-niche interaction；
  - `NMOEA-De`：只用 DE；
  - `NMOEA-GA`：只用 GA/SBX+PM；
  - `NMOEA-CD`：只用严格 constrained dominance；
  - `NMOEA-NC`：只用 non-dominated sorting 和 crowding，忽略约束处理。
- 消融结论：
  - niche division 对维持复杂可行域覆盖必要；
  - inter-niche interaction 可减少碎片化和早熟；
  - 自适应算子优于固定 DE 或固定 GA；
  - 严格 constrained dominance 会过度收缩搜索；
  - 完全放松约束又缺少可行性引导；
  - inter-niche interaction 是计算成本最高的组件之一。

## 电力调度应用

- 应用问题：economic-environmental dispatch problem (EEDP)。
- 决策变量：6 台发电机的 active power。
- 目标：
  - generation cost；
  - pollutant emissions。
- 约束：
  - generator capacity；
  - power balance；
  - network loss；
  - security / power-flow constraints。
- 由于真实 Pareto front 不可得，应用实验使用 HV。
- 结果：
  - NMOEA 的 HV 为 `1.6754e-2 (1.29e-5)`，为最高；
  - 与 PPS、CCMO、CMOES 统计相当；
  - 优于 CAEAD、CMOEA-MS 和 DNNSGAII；
  - 运行时间仅慢于 DNNSGAII，快于 PPS、CAEAD、CMOEA-MS、CCMO 和 CMOES。

## 与知识库相关的设计知识

- 新增设计知识：
  - `K-solution-space-niche-coevolution-cmop`：解空间生态位协同的约束多目标搜索。
- 与已有设计知识的区别：
  - 不同于 `K-niche-classified-decomposition-resource-reallocation`：该知识按 reference-vector subproblem 的 Type-1 到 Type-5 进行资源重分配；本文按 decision-space radius、feasible angular leaders 和 infeasible low-CV leaders 形成空间生态位。
  - 不同于 `K-dynamic-clustered-competitive-swarm-cmop`：该知识用目标空间聚类限制 CSO winner-loser 学习范围；本文是更一般的 GA/DE 生态位协同框架，并显式切换约束处理规则。
  - 不同于 `K-trend-orthogonal-dualswarm-constrained-search`：该知识维护主/辅双群的趋势与正交互补；本文维护多个空间 niches，并通过周期性全局交互重构生态位。
  - 不同于 `K-coarse-fine-clustering-density-competing-mmop`：该知识服务于多模态 MOP 的粗细聚类和峰值覆盖；本文面向 CMOP 的可行域断裂与约束处理。

## 局限与未来工作

- niche radius 中含随机系数，可能引入稳定性问题。
- `Nniche`、`denthre`、`rfthre`、`genthre` 仍需人工设定。
- inter-niche interaction 带来较明显计算成本。
- 算子切换和约束处理切换依赖阈值规则，尚未自适应学习。
- 作者提出未来方向：
  - 设计更高效的 constrained search operators；
  - 引入 self-adaptive parameter tuning；
  - 扩展到离散/组合优化，例如带时间窗车辆路径问题。
