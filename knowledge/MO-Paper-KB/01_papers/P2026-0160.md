# Clustering and entropy-guided unsupervised learning for multi-objective evolutionary optimization of reentrant hybrid flow shop scheduling

## 一句话理解

论文面向以 makespan 和 total energy consumption 为双目标的 reentrant hybrid flow shop scheduling，提出 CEUL-MOEA：用探索-开发双种群分工搜索，再用 DBSCAN 目标空间聚类、熵权扰动强度和斜率引导邻域搜索分配搜索资源，最后用 energy-driven backward adjustment 压缩机器空闲能耗。

## 问题与动机

- 研究场景：
  - Reentrant hybrid flow shop scheduling problem (RHFSP) 中，作业要多轮经过多个阶段，每个阶段可能有并行机器；
  - 目标同时最小化 `Cmax` 和 `TEC`，其中 `TEC = processing energy + idle energy`；
  - 低碳制造需要把生产效率和机器空闲能耗一起优化。
- 现有工作为什么不足：
  - 多数 RHFSP 研究仍偏 makespan、total tardiness 或质量指标，较少把 machine-level energy saving 放入多目标框架；
  - 普通 MOEA 容易在 RHFSP 的组合搜索空间中早熟，难同时维持收敛、边界覆盖和均匀分布；
  - GD/IGD 依赖参考前沿，HV 计算昂贵，难直接作为每代内部局部搜索指示器；
  - 随机或固定邻域搜索不知道哪些 Pareto 区域过密、哪些目标方向需要加强；
  - 盲目 backward adjustment 可能反而增加能耗。
- 本文希望解决什么：
  - 建立 RHFSP 的 makespan-TEC MILP 模型；
  - 构建一个不依赖标签数据的 unsupervised search-control 模块；
  - 用轻量内部指标驱动 exploitation population 的局部搜索；
  - 用聚类与熵信息为 elite neighborhood search 分配扰动预算；
  - 用有理论筛选的 ED-BA 降低 idle energy。

## 核心模型与算法流程

- 问题建模：
  - 作业数 `n`，阶段数 `S`，重入轮数 `L`，阶段 `s` 有 `m_s` 台并行机器；
  - 目标为 `min (Cmax, TEC)`；
  - `TPE` 由总加工时间乘 processing energy rate `PE` 得到；
  - `TIE` 由每台机器 activation interval 减去加工时间后乘 idle energy rate `IE` 得到；
  - 模型显式引入 machine start-up time、shut-down time 和 activation 变量，以统一计算加工能耗与空闲能耗。
- CEUL-MOEA 总流程：
  1. 用 hybrid heuristic initialization 生成 exploitation population `P1` 和 exploration population `P2`。
  2. `P1` 使用 multi-lap encoding (MLE)，编码较紧凑，适合快速开发。
  3. `P2` 使用 dual-string encoding (DSE)，同时编码 operation sequence 和 machine string，搜索空间更大。
  4. `P1` 通过 IEI-LS 做内部指标驱动局部搜索。
  5. `P2` 通过 PDCC 接收 `P1` 的迁移个体，并把 WES 最好与最差的个体配对交叉。
  6. 合并双种群后，精英集用 CE-NS 做聚类-熵权邻域搜索。
  7. 对 elite population 应用 ED-BA，降低不增加 makespan 的 idle energy。
  8. 最后用 non-dominated sorting 输出 Pareto set。
- Hybrid heuristic initialization (HHI)：
  - `P1` 的 seed sequence 按作业总加工时间降序生成；
  - 用三种 insertion objective guide 配合 MFD/TFD 两种机器分配规则生成 12 类互补解；
  - `P2` 随机生成 OS 和 MS，以避免启发式初始化带来的结构偏置。
- IEI-LS 内部指标局部搜索：
  - 定义四个轻量指标：
    - `IP`：到 ideal point 的距离，用于 convergence；
    - `NAE`：与 nadir/boundary 相关的边界覆盖度；
    - `NNDD`：相邻解距离的标准差，用于 distribution uniformity；
    - `IPGS`：结合 ideal point guidance 和 spread 的种群级指标。
  - 设计六个局部搜索 `LS1-LS6`：
    - `LS1/LS2` 用 `IP` 引导 convergence，分别配合 MFD/TFD；
    - `LS3/LS4` 用 `NAE` 引导 boundary coverage；
    - `LS5/LS6` 用 `NNDD` 引导 distribution uniformity。
  - 若当前 `IPGS` 下降且 `iter % 5 == 0`，使用 `LS1-LS4`；否则使用 `LS5-LS6`。
- CE-NS 聚类与熵引导邻域搜索：
  - 先用 IDUS 从 mixed population 选出 `gamma` 个 elite solutions；
  - 在归一化 objective space 中对 elite solutions 执行 DBSCAN，`MinPts=1`，允许单解形成独立簇；
  - 对每个 cluster 将目标空间离散为 `nbins x nbins` 网格，计算 cluster entropy；
  - 归一化 entropy 并映射为扰动权重 `w_i`，决定从该簇抽取多少个体进行邻域搜索；
  - 计算 cluster slope `s_i = mean normalized makespan / mean normalized TEC`；
  - 依据 slope 选择邻域组合：
    - `s_i > 2`：优先降低 makespan，使用 `NS1/NS3/NS5`；
    - `1 <= s_i <= 2`：偏平衡但略重 makespan，使用 `NS1/NS5/NS6`；
    - `0.5 <= s_i < 1`：偏平衡但略重 TEC，使用 `NS2/NS5/NS6`；
    - `s_i < 0.5`：优先降低 TEC，使用 `NS2/NS4/NS5`。
  - `NS1/NS2` 重新分配 critical machines 上的操作，分别按 makespan/TEC 评价；
  - `NS3/NS4` 重插 critical operations，分别按 makespan/TEC 评价；
  - `NS5` 接受 dominance-improving insertion，`NS6` 做 operation swap 并接受改进解。
- ED-BA energy-driven backward adjustment：
  - 核心目标是延后部分操作，压缩机器 active interval 内的非生产 idle time，同时不违反 precedence、machine order 或 makespan。
  - 定义 `EAJ`、`ETJ`、`BEA` 和 `BIJ`，分别表示 energy anchor job、energy terminal job、backward energy adjustment 和不可后移作业集合。
  - Theorem 1：若 `EAJ in BIJ`，对 `ETJ` 做 BEA 不能降低 TEC。
  - Theorem 2：若 `EAJ notin BIJ`，对 `ETJ` 做 BEA 是否降能耗仍不确定。
  - Single-lap SED-BA 用 simultaneous judgment and adjustment，必要时评价 TEC 并回滚 ETJ 调整；
  - Multi-lap MED-BA 先基于 EAJ/ETJ/BIJ 规则筛选 eligible operations，再统一执行 BEA，降低多重入依赖下的重复评价成本。
- 必须保留的核心：
  - 双编码/双种群分工只是 CEUL-MOEA 的上层框架；
  - 本文最可复用的关键是“objective-space structure discovery -> search budget/strategy allocation”和“theorem-screened backward energy adjustment”两个模块；
  - 若迁移到其他调度问题，至少要能定义 objective-space cluster、目标偏置 slope、关键机器/关键操作邻域和可行的后向能耗调整。

## 实验证据

- 实验设置：
  - 平台：Windows 10 64-bit，Intel Core i7-13790F 3.60 GHz，32 GB RAM，Python / PyCharm 2021；
  - 每个算法每个实例独立运行 5 次；
  - 终止时间 `TimeLimit = 50 x L x n x S ms`；
  - 实例：基于文献生成 125 个 small-scale 和 150 个 large-scale RHFSP instances；
  - 小规模 `n in [10,20]`、`S in [5,10]`、`L in [1,2]`、`m_s in [1,2]`；
  - 大规模 `n in [10,50]`、`S in [5,25]`、`L in [1,6]`、`m_s in [1,6]`；
  - 能耗参数：`PE=4`、`IE=1`；
  - 指标：GD、IGD、HV，以及 AGD/AIGD/AHV 汇总。
- 参数校准：
  - Taguchi `L9(3^4)` 设计考察 `beta`、`gamma`、`epsilon` 和 `nbins`；
  - `gamma` 对 AGD/AIGD/AHV 的影响最大，`nbins` 次之；
  - 最终参数为 `beta=48`、`gamma=30`、`epsilon=0.1`、`nbins=50`。
- MILP 验证：
  - Gurobi 9.5.0 用 `setObjectiveN` 验证小规模模型；
  - 在 L1-J2-S4、L2-J2-S2 等极小实例上可快速得到最优；
  - 规模增大后 Gurobi 到达 3600s 时间上限，常只给一个非支配解；
  - CEUL-MOEA 在 L2-J10-S10 和 L2-J11-S10 上用约 10s 给出多个非支配解，IGD/HV 分布明显更好。
- 五组件消融：
  - 去掉 IEI-LS、CE-NS、ED-BA、exploration population 或 exploitation population 均会退化；
  - 完整 CEUL-MOEA 相对这些变体在 `AGD` 上改善约 `3%-96%`，在 `AIGD` 上改善约 `24%-95%`，在 `AHV` 上改善约 `4%-86%`；
  - 作者指出 CE-NS 是最关键组件，ED-BA 对 AGD 和能耗区间压缩也有明显作用；
  - 去掉 exploration population 时 diversity 明显下降；去掉 exploitation population 时 AGD/AIGD 明显变差、AHV 下降。
- 无监督模块单独消融：
  - 变体 `CEUL-MOEA\UL` 用 random neighborhood selection 替换 Sec. 4.5 的 unsupervised learning；
  - 完整算法在全部实例上约提升 `AGD 30%`、`AIGD 12%`、`AHV 4%`；
  - 作者认为 clustering + entropy 能避免低效和冗余搜索。
- 与六个算法对比：
  - 对比算法：L-NSGA、MLPGA、IMOEA/D、IMOEA/D-LS、QVNS-NSGA-II、VNS-NSGA-II；
  - 275 个实例上，CEUL-MOEA 在 `AGD` 上约优于对比算法 `38%-99%`，在 `AIGD` 上约优于 `72%-95%`，在 `AHV` 上约优于 `26%-91%`；
  - 小规模均值：CEUL-MOEA `AGD=0.002`、`AIGD=0.071`、`AHV=0.929`；
  - 大规模均值：CEUL-MOEA `AGD=0.005`、`AIGD=0.045`、`AHV=0.829`；
  - 小规模 125 实例中，CEUL-MOEA 取得最佳 `AGD/AIGD/AHV` 的比例分别为 `95.2%/91.2%/100%`；
  - 大规模 150 实例中，对应比例为 `46.1%/86.7%/96.2%`。
- 统计检验：
  - Friedman test 中，CEUL-MOEA 在小规模 `GD/IGD/HV` 的 rank 分别为 `1.05/1.14/7.00`，p-value 约为 0；
  - 大规模中 `GD` rank `1.84` 略差于 QVNS-NSGA-II 的 `1.79`，但 mean/min/max/std 仍很好；`IGD/HV` rank 为 `1.23/6.95`；
  - Wilcoxon signed-rank test 中，CEUL-MOEA 与六个对比算法在 GD/IGD/HV 上 p-value 均小于 0.01。
- OLED ARRAY 案例：
  - 使用某半导体公司 OLED display ARRAY workshop 的匿名实际生产周期数据；
  - CEUL-MOEA 在案例中得到 `GD=0.000`、`IGD=0.049`、`HV=0.855`；
  - 虽然不是所有方法中 makespan 最低，但能耗更低，trade-off 更好。

## 局限与未来工作

- 作者明确指出的局限：
  - 当前模型限于 RHFSP with TEC objectives，尚未扩展到 multi-factory 或 multi-site scheduling；
  - 未考虑 carbon emissions、environmental impacts 等更全面 sustainability objectives；
  - 无监督模块虽然无需训练，但对 `epsilon`、`MinPts`、`nbins` 等参数敏感；
  - ED-BA 假设 idle energy 与 idle time 正相关，复杂能耗系统中可能失效。
- 作者未来工作：
  - 将 CEUL-MOEA 扩展到 multi-factory 和 multi-site scheduling；
  - 纳入 carbon emissions 等 sustainability objectives；
  - 研究 adaptive parameter control 提升鲁棒性；
  - 引入 graph-based representations 和 end-to-end DRL；
  - 将 ED-BA 推广到 start-up/shutdown effects、thermal dynamics、sequence-dependent setup energy 和 variable-speed processing。
- 我们认为仍需确认的问题：
  - CEUL-MOEA 组件很多，虽然有消融，但仍难完全区分双编码、双种群、IEI-LS、CE-NS 和 ED-BA 的交互贡献；
  - Markdown 中 entropy weight、IP/NAE/NNDD/IPGS 公式为图片占位，复现前需回 PDF；
  - `MinPts=1` 会让单解也成簇，可能把孤立异常解视为需要资源的区域；
  - CE-NS 的 slope thresholds `0.5/1/2` 是经验规则，目标尺度和归一化会影响判断；
  - 生成实例数量大，但真实案例只有一个匿名产线案例，部署泛化仍需更多行业数据；
  - ED-BA 的适用性依赖能耗模型，若存在启停成本或热惯性，简单后向移动可能不再省能。

  - IEI-LS 的四个内部指标可作为轻量 online diagnostics，但本文只在 RHFSP 中验证，暂不单独成卡；
  - MLE/DSE 双编码和 HHI 初始化依赖 RHFSP 编码细节，暂留在论文卡；
  - PDCC elite-inferior coupling 可以迁移到其他双种群算法，但证据仍与完整 CEUL-MOEA 绑定。
- 局部创新线索：
  - 用 HDBSCAN、kNN density、reference-vector occupancy 或 learned objective embedding 替换 DBSCAN；

  - 在 CE-NS 中给 noise / singleton clusters 设置最小和最大预算，防止异常解过度消耗邻域搜索；
  - 将 ED-BA 与 TOU electricity price、carbon intensity 或 start-up/shutdown cost 结合，判断“后移”是否真的节能。
- 结构创新线索：
  - 构建“objective-space unsupervised diagnosis -> neighborhood portfolio scheduling -> energy-aware schedule post-processing”的调度型 MOEA 模板；
  - 将 exploitation population 的 IEI-LS 与 elite CE-NS 统一为两层 search controller：前者控制个体局部插入，后者控制 Pareto 区域资源分配；
  - 将 CE-NS 用于 expensive MOO：只对 entropy/slope 判定最有价值的 elite clusters 进行真实局部搜索，其余区域用 surrogate 或 archive 保留。
