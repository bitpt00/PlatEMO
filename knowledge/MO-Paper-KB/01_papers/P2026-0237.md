# Two-Stage Clustering and Independent Competing-Based Evolutionary Algorithm for Multimodal Multiobjective Optimization

## 一句话理解

本文提出 TSCICEA：把 MMOP 中的模态识别看成随演化状态变化的聚类问题，早期用 K-means 快速粗分模态位置，后期用 DBSCAN 修正错分并细分模态，再让每个子种群按自身密度选择局部或全局竞争策略来独立寻找对应模态。

## 问题与动机

- 研究问题和场景：Multimodal multiobjective optimization problems (MMOPs)，多个决策空间 Pareto set components 映射到同一个或相近 Pareto front，需要同时找到多个等价 PS 区域。
- 现有算法为什么不足：
  - 很多 MMOEA 只把多个模态作为整体定位，忽略不同模态所在 fitness landscape 的难度差异；
  - 固定聚类方法贯穿整个演化过程，不能适应早期分散、后期聚集的种群分布变化；
  - 聚类后如果所有子种群使用同一选择/竞争方式，密度高和密度低的模态会受到不合适的选择压力；
  - 子种群之间缺少独立、并行的模态识别机制，会降低识别准确性和运行及时性。
- 本文希望解决什么：更准确地区分多个模态，并让每个子种群按自己的密度状态独立选择最适合的竞争方式，从而同时提升决策空间覆盖、目标空间质量和运行效率。

## 核心理念与算法流程

- 核心理念：种群演化天然经历“分散探索 -> 聚集成多个模态簇”的过程；因此聚类策略应随演化阶段切换。早期先用 K-means 快速获得粗粒度模态结构，后期再用 DBSCAN 捕捉复杂形状和修正粗聚类错分。聚类完成后，每个子种群不再被全局统一处理，而是根据自身规模/密度独立采用局部或全局竞争。
- 主要流程：
  1. 随机初始化规模为 `N` 的种群。
  2. 每代进行 nondominated sorting，分别计算目标空间 SDE、决策空间 crowding distance，并合成综合 crowding distance。
  3. 通过 tournament 构造 mating pool，使用 SBX 与 polynomial mutation 生成 offspring。
  4. 合并父代和子代为 `JointP`。
  5. 若 `NFE/MaxNFE < p`，用 K-means 对 `JointP` 粗聚类，聚类数 `K` 由 Calinski-Harabasz index 自动确定。
  6. 若 `NFE/MaxNFE >= p`，用 DBSCAN 对 `JointP` 细聚类，半径 `epsilon` 由动态因子 `beta=alpha*(1-NFE/MaxNFE)` 调整，`Minpts=5`。
  7. 对每个子种群执行 Independent Competing：后期且子种群规模足够大时使用 Competing1，否则使用 Competing2。
  8. 各子种群选出的 survivors 合并为下一代 `Pop`。
- 关键组成部分：
  - Two-stage clustering：K-means 粗分 + DBSCAN 细分，适配种群从分散到聚集的演化状态。
  - Dynamic DBSCAN radius：随 `NFE/MaxNFE` 缩小或调整邻域半径，配合后期模态精细识别。
  - Independent Competing Strategy (ICS)：每个子种群按密度/规模选择局部 fitness 或全局 dominance-neighborhood fitness。
  - Survivor quota `PN_i`：按子种群规模分配保留名额，子种群过多时每个优先子群至少保留 1 个。
- 可能被修改的位置：
  - K-means/DBSCAN 可替换为谱聚类、HDBSCAN、nearest-better clustering、GMM 或 learned embedding clustering；
  - 阶段切换参数 `p` 可由 NFE 比例改为聚类稳定性、NMI、density entropy 或模态数量变化；
  - ICS 的局部/全局竞争切换可基于子种群质量、HV/IEDR 贡献、局部收敛速度或不确定性；
  - 子种群并行执行可扩展到不同算子、不同参数或不同局部搜索器。
- 必须保留的核心：先用低成本粗聚类确定大致模态结构，再用密度聚类在后期修正错分；聚类后的子种群必须独立识别自己的模态，并根据局部密度调整竞争压力。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：46 个 MMOP，来自 MMMOP suite，并扩展 CEC2019 中 MMF14、MMF14_a、MMF15、MMF15_a，覆盖 2-15 objectives 和 4-15 variables，多数为 concave。
  - 对比算法：MMEAPSL、MMEASND、CoMMEA、CMMO、HREA/HERA、MMEAWI、MMOEADC、FPITSEA、MMMEA。
  - 设置：population size 200，MaxNFE 10000，SBX/PM，30 次独立运行，PlatEMO，MATLAB；CPU 为 Intel Core i5-13500H 2.60 GHz，16 GB RAM。
  - 指标：`I_EDRX` 衡量高维决策空间 convergence/diversity，`I_MST` 衡量目标空间综合质量，HV 衡量目标空间 convergence/diversity。
- 主要实验结论：
  - `I_EDRX`：TSCICEA 在 40/46 个问题上取得 best，作者认为固定聚类方法未能适应动态种群分布。
  - `I_MST`：TSCICEA 在 27/46 个问题上 best，另有 7 个问题与其他算法相近，整体排名第一。
  - HV：TSCICEA 在 41/46 个问题上取得 best，作者归因于 ICS 促进子种群有效搜索。
  - Friedman test：TSCICEA 在 `I_EDRX`、`I_MST`、HV 及 `I_EDRX+HV` 综合排名上均为第一。
  - Running time：46 个问题平均 CPU time 最低，FPITSEA 第二；作者认为 two-stage clustering 和 ICS 避免盲目搜索。
- 消融或机制证据：
  - 参数 `p`：在不同 `p` 值下比较平均 rank，`p=0.9` 同时使 `I_EDRX` 和 HV 较好，作者推荐该值。
  - Clustering ablation：仅 K-means 在 `I_EDRX` 上较好但 HV 较弱；仅 DBSCAN 在 HV 较好但 `I_EDRX` 较弱；组合 two-stage clustering 在两类空间之间取得更好折中。
  - ICS ablation：只用 Competing1 在目标空间好但决策空间差；只用 Competing2 在决策空间相对好但目标空间差；ICS 在两类空间之间平衡最好。
  - P21/P31 convergence 与 box plots：TSCICEA 在多目标多变量问题上收敛速度、精度和 30 次运行稳定性均优于对比算法。
- 证据边界：
  - 结果表和消融图在当前 Markdown 中多为图片占位，精确平均值和标准差需回看 PDF/补充材料；
  - benchmark 决策变量维度为 4-15，尚不能说明超高维 MMOP 扩展性；
  - 主要是连续 benchmark，约束、动态、混合变量和真实工程 MMOP 需进一步验证。

## 局限与未来工作

- 作者明确说明的局限：
  - TSCICEA 中参数仍需进一步调优，以最大化算法表现。
- 作者未来工作：
  - 进行进一步参数 tuning experiments；
  - 将 TSCICEA 用于更多真实应用，如 wind farm layout optimization 和 engineering design problem。
- 我们认为仍需确认的问题：
  - 用 `NFE/MaxNFE` 和固定 `p=0.9` 做阶段切换是否足够稳，是否应加入聚类稳定性反馈；
  - DBSCAN 半径公式对变量尺度、维度和多模态间距是否敏感；
  - 子种群数量很多时 `PN_i` 名额分配是否会误删小但重要的模态；
  - ICS 中 `Minpts=5` 和 `delta=9*beta` 是否能跨问题泛化。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“粗细聚类与密度独立竞争的多模态识别”，因为它为 MMOP 提供了阶段化模态划分和子种群密度自适应选择两个可移植模块。
- 暂留在论文卡中的方法、原理或架构启发：
  - 聚类算法应匹配当前种群形态：分散时重速度和粗定位，聚集时重形状和错分修正；
  - 子种群竞争强度不应全局一致，密集模态需要局部精细竞争，稀疏模态需要更宽松的全局比较；
  - 运行效率可以来自减少错误模态划分和盲目搜索，而不只是降低算子复杂度。
- 局部创新线索：
  - 在已有 MMOEA 的环境选择前加入 `K-means -> DBSCAN` 粗细聚类；
  - 将 ICS 用作任何多子种群算法的 survivor selection；
  - 用 adaptive `p`、HDBSCAN 或聚类稳定性替代固定阶段阈值。
- 结构创新线索：
  - 构建“演化状态识别 -> 粗/细聚类切换 -> 子种群密度诊断 -> 独立竞争选择 -> 并行模态开发”的 MMOP 管理框架；
  - 与已有级联聚类、图学习子代生成或子种群均衡进化组合，形成更完整的多模态搜索控制器。
