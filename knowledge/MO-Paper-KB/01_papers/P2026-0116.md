# A dual-task-assisted self-organizing map evolutionary algorithm for constraining multimodal multi-objective optimization

## 一句话理解

本文提出 DSCMMOEA，把 constrained multimodal MOO 拆成一个受约束 SOM 主任务和一个无约束辅助任务：主任务学习 CPF/CPS 拓扑并保留可行多模态解，辅助任务挖掘高质量不可行解跨越 infeasible regions，再用目标/决策双空间密度和自适应剪枝选择下一代。

## 问题与动机

- 研究问题和场景：constrained multimodal multi-objective optimization problems (CMMOPs)，即算法既要满足约束并逼近 constrained Pareto front (CPF)，又要在决策空间覆盖多个等价 constrained Pareto solution sets (CPSs)。来源：Sec. 1。
- 现有算法为什么不足：
  - CMOEA 主要关注目标空间和约束处理，通常忽略 decision-space multimodality，可能只找到一个可行 PS。来源：Sec. 1、Sec. 2.1。
  - MMOEA 能维持多个 PS，但缺少约束处理能力，面对碎片化或窄可行域时容易保留不可行或低质量解。来源：Sec. 2.2。
  - 既有 CMMOEA 如 CMMO-MTA 用多任务框架处理 CMMOP，但计算成本高、参数调节复杂。来源：Sec. 1、Sec. 2.3。
  - 复杂约束会把 feasible regions 切成离散、狭窄或不连续区域；单纯可行优先容易陷入局部可行域，单纯无约束辅助又可能被 UPF 误导。来源：Sec. 2.4。
- 本文希望解决什么：在约束处理、决策空间多样性、目标空间收敛和全局搜索之间建立一个弱耦合但持续交换信息的双任务机制，并用 SOM 自适应学习未知 CPF/CPS 拓扑。

## 核心理念与算法流程

- 核心理念：受约束主任务负责最终可行解和拓扑学习，无约束辅助任务负责穿越不可行区域；二者通过 offspring sharing 共享高质量候选，再由同时考虑 convergence、feasibility、decision-space density 和 objective-space density 的选择机制筛选。
- 主要流程：
  1. 初始化主任务 `P1`、辅助任务 `P2` 和 SOM 网络。来源：Algorithm 1，PDF 5-6。
  2. 对 `P1` 使用受约束 fitness，对 `P2` 使用忽略约束的 fitness；fitness 同时合成收敛指标和双空间密度。来源：Algorithm 2、Sec. 3.2，PDF 7-8。
  3. 用 `P1` 的 fitness 更新 SOM，训练得到近似 CPF/CPS 拓扑的 map；按 best-matching neuron 与邻域选择交配对象，生成主任务 offspring `O1`。来源：Algorithm 3、Sec. 3.3，PDF 8-12。
  4. 辅助任务用常规 GA/DE 生成 offspring `O2`，忽略约束以挖掘潜在高质量不可行区域。来源：Algorithm 1，PDF 6。
  5. 两任务动态共享 offspring：辅助任务中高质量个体补充主任务决策空间探索，主任务中收敛较好的可行解引导辅助任务。来源：Sec. 3.1，PDF 6。
  6. 动态环境选择先保留非支配解；若数量超出阈值，则比较决策空间和目标空间 crowding distance，逐个删除对应空间中最拥挤且表现更差的个体。来源：Algorithm 4、Sec. 3.4-3.5，PDF 12-14。
- 关键组成部分：
  - 主任务 `P1`：原约束问题，考虑 objective dominance 与 constraint dominance；
  - 辅助任务 `P2`：无约束问题，保留 objective-promising infeasible solutions；
  - SOM training：用动态 learning rate 和 neighborhood radius 学习 population topology；
  - 双空间 fitness：以 `k=sqrt(N)` 最近邻密度衡量 decision/objective diversity，并随迭代逐步提高 decision-space 权重；
  - adaptive pruning：不是简单相加两个 crowding distance，而是交替比较两个空间最拥挤个体并删除更差者。
- 可能被修改的位置：
  - SOM 可替换为 growing SOM、neural gas、拓扑保持流形学习或局部图学习；
  - offspring sharing 可加入迁移成功率、reference-region gate、constraint-boundary gate 或 source-label credit；
  - 双空间密度权重可由固定代数函数改成 diversity stagnation、feasible ratio 或 HV/IGDX 反馈；
  - adaptive pruning 可细化到每个 reference vector、decision cluster 或 constraint boundary。
- 必须保留的核心：主任务不能丢掉约束和 SOM 拓扑学习，辅助任务不能完全替代主任务；CMMOP 的关键收益来自“受约束拓扑学习 + 无约束跨域探索 + 双空间保留”的组合。

## 实验证据

- 测试问题和对比算法：
  - CMMOP：CMMF1-17 和 CMMOP1-14，共 31 个问题；指标为 IGD、IGDX、CPSP，Wilcoxon `p=0.05`。对比 C-TAEA、CMOEA-MS、POCEA、PPS、C-CoMMEA、C-CMMO、C-MO_Ring_PSO_SCD、C-TriMOEATAR、CMMODE、CMMO-MTA。来源：Sec. 4.1。
  - CMOP：MW、CF、C_DTLZ 共 34 个问题，指标为 IGD、HV、average Hausdorff distance `Λp`，`N=100`、`MaxFEs=70000`、31 次运行。来源：Sec. 5.1。
  - 真实问题：CMMOP site selection 和 RWMOP1-10。来源：Sec. 4.5、Sec. 5.3。
- 主要实验结论：
  - CHT 对比中，`DSCMMOEA+DS` 在 Table 1 的 31 个 CMMOP 上 IGD 相对 CDP/ToR/ST 均为 `0/30/1`，说明 dynamic selection 比传统 CDP、ToR、ST 更适合该框架。来源：Sec. 4.2、Table 1，PDF 16。
  - Table 2 与 Table 3 中，`DSCMMOEA+DS` 分别取得 24 个最优 IGDX 和 30 个最优 CPSP，明显优于其他 CHT 变体。来源：Sec. 4.2，PDF 18。
  - 双任务消融中，完整 DSCMMOEA 在五个测试问题上 IGDX 全部优于 `T1/T2/T3`，说明单一 SOM 主任务、单一辅助任务或去约束主任务都不够。来源：Fig. 7、Sec. 4.2，PDF 18-19。
  - 权重与剪枝消融显示完整双空间动态权重和 adaptive pruning 均优于固定或单空间变体。来源：Fig. 8-9、Sec. 4.2，PDF 12、18-19。
  - CMMOP 综合分析中，DSCMMOEA 在 IGD、IGDX 和 CPSP 上相对十个对比算法总体最有优势，并在 Fig. 12-13 中取得最好的 objective/decision 综合 rank。来源：Sec. 4.3.3，PDF 25。
  - Runtime：DSCMMOEA 因环境选择中的 pruning 复杂度更高而运行时间处于中低水平，整体仍可接受；明显短于最慢的 C-TAEA/CMMO-MTA/C-MO_Ring_PSO_SCD。来源：Sec. 4.3.3、Fig. 14，PDF 25。
  - 参数：SOM 初始邻域半径 `sigma=4` 总体最好，过小或过大都不稳定。来源：Sec. 4.4，PDF 25。
  - Site selection：DSCMMOEA 在 IGD、IGDX、CPSP 三个指标上显著优于所有对比算法；可同时覆盖多个可行最优区域并保持更好收敛。来源：Sec. 4.5、Table 8、Fig. 16，PDF 28。
  - CMOP：在 MW 上略弱于 C-TAEA 但优于其他八个算法；CF 上与 CMMODE 接近并优于或相当于多数对比；C_DTLZ 上与 C-TriMOEATAR 各取得 4/10 个 best IGD，Fig. 19 显示 DSCMMOEA 的 IGD rank 最好、HV rank 仅次于 C-TAEA。来源：Sec. 5.2，PDF 29-30。
  - RWMOP：DSCMMOEA 在 RWMOP1-10 上有两个最优 IGD；总体性能仅略低于 C-CMMO，优于其他对比算法，HV 在 RWMOP1、RWMOP3、RWMOP5 最优。来源：Sec. 5.3、Table 10，PDF 30。
- 消融或机制证据：
  - CHT 消融支持 dynamic selection；
  - `T1/T2/T3` 支持双任务结构；
  - 权重变体支持 dynamic decision/objective diversity weighting；
  - pruning 变体支持双空间 adaptive pruning；
  - `sigma` 参数分析支持 SOM neighborhood 半径需适中。
- 证据边界：
  - 算法优势来自多个模块组合，单独 SOM、单独无约束辅助或单独 pruning 的贡献不能外推为充分条件；
  - 高维扩展仅在未来工作中提出，当前证据主要是 2D/3D 连续 CMMOP/CMOP；
  - site selection 是相对简单的二维地理选址，尚不能代表复杂工程 CMMOP；
  - SOM 和 pruning 的计算成本在大规模、多约束或 many-objective 问题上可能放大。

## 局限与未来工作

- 作者明确说明的局限：结论中没有给出失败案例，但 runtime 分析指出 pruning 使 DSCMMOEA 的环境选择复杂度较高；CMOP/RWMOP 上对 C-TAEA 或 C-CMMO 并非全面胜出。来源：Sec. 3.6、Sec. 4.3.3、Sec. 5.2-5.3。
- 作者未来工作：
  - 进一步改进 DSCMMOEA；
  - 应用于更复杂真实工程问题；
  - 扩展到 high-dimensional problems。来源：Sec. 6。
- 我们认为仍需确认的问题：
  - 当 UPF 与 CPF 完全分离时，无约束辅助任务是否会持续产生负迁移；
  - SOM 初始半径、神经元规模和训练频率是否需要随 feasible ratio 或 CPS 数量自适应；
  - 双空间 density 在高维下是否受距离集中影响；
  - adaptive pruning 在 many-objective 下是否会过度保留目标空间边界而牺牲决策空间覆盖；
  - offspring sharing 应按 reference region 或 decision cluster 局部控制，而不是全局共享。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“ SOM 拓扑双任务的约束多模态协同”：抽象出受约束 SOM 主任务、无约束辅助任务、动态 offspring sharing、双空间 density fitness 和 adaptive pruning 的 CMMOP 架构。
- 暂留在论文卡中的方法、原理或架构启发：
  - CMMOP 可先按“最终可行任务”和“跨不可行域任务”拆分，再在环境选择中统一回收；
  - SOM 的 winner-neighbor 交配可作为未知 PS topology 下的轻量替代图学习；
  - 不把两个空间 crowding 直接相加，而是逐步比较最拥挤候选，可避免一个空间的极端密度掩盖另一个空间的问题。
- 局部创新线索：
  - 把 dynamic offspring sharing 改成 per-cluster survival gate，统计来源任务个体在每个 CPS 片段的保留率；
  - 用 feasible-boundary classifier 判断辅助任务 offspring 是否靠近可修复区域；
  - 用 growing SOM 自动增删神经元，减少 `sigma` 和网格规模敏感性；
  - 将 pruning 的删点目标从 crowding distance 换成 IGDX/CPSP proxy 或 topology persistence。
- 结构创新线索：
  - “constrained topology learner + unconstrained infeasible explorer + dual-space survival filter”可迁移到 constrained MMOP、约束多解推荐、路径规划选址、工艺参数多解设计；
  - 可与迁移成功率门控机制结合，让无约束辅助任务不再固定共享，而是按局部保留贡献自动开关。
