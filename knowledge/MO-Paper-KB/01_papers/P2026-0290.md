# Hybrid Action-Based Reinforcement Learning for Multiobjective Compatible Autonomous Driving

## 一句话理解

论文提出 HPA-MoEC：用按目标拆分的 ensemble critics 评估自动驾驶策略，用“离散语义动作 + 连续路径/加速度参数”的 hybrid parameterized action 输出驾驶动作，并用 ensemble epistemic uncertainty 定向探索，从而同时改善效率、动作一致性和安全性。

## 问题与动机

- 研究问题和场景：多车道高速公路自动驾驶决策与控制，需要在 safety、efficiency、action consistency 等多个驾驶目标之间保持兼容。
- 现有 RL 自动驾驶为什么不足：
  - 单一 reward/critic 把多个目标提前混成一个标量，容易让策略过度追求速度或过度保守，难以准确学习目标冲突。
  - 单一离散动作输出语义决策，动作一致性较好但控制灵活性不足。
  - 单一连续动作直接输出 steering/acceleration，灵活但容易产生横纵向控制波动。
  - 普通随机探索如 epsilon-greedy、SAC entropy 或 Gaussian noise 缺少方向，容易重复采样低价值经验。
- 本文希望解决什么：
  - 用 MORL policy evaluation 让安全目标独立进入 critic；
  - 用 hybrid parameterized action 同时输出抽象 guidance 和具体 control；
  - 用 ensemble critic 不确定性指导离散和连续动作探索，加快收敛。

## 核心理念与算法流程

- 核心理念：把“多目标评价、动作空间结构、探索方向”作为一个联合设计，而不是只改 reward。安全等目标由独立 ensemble critic 评价；离散动作负责 lane-level 语义，连续参数负责细粒度路径和加速度；ensemble 分歧提供 epistemic uncertainty，指导 agent 去探索未知但可能有价值的动作区域。
- HPA-MoEC 训练流程：
  1. 把 MDP 改写为 `S, H, [R_1,...,R_N], T, gamma`，其中 `H={(o,a_o)}` 是 hybrid parameterized action。
  2. Actor `mu(s)` 输出连续参数 `a_o`；离散动作 `o` 从 action option set 中选择。
  3. 对每个目标/属性建立一个 ensemble critic；第 `i` 个属性有 `M` 个 critics，整体共有 `N*M` 个 value networks。
  4. Critic 更新同时考虑自身 TD error、同属性 ensemble 平均 TD error、所有目标加权整体 TD error，以及防止 ensemble 内 critic 随机偏离的 guiding/convergence loss。
  5. Actor 更新目标是最大化按目标权重加权的 overall value function。
  6. 用同一属性内多个 critics 的预测方差估计 epistemic uncertainty，再按目标权重合成总不确定性。
  7. 连续参数探索：沿 uncertainty gradient 在 actor 原输出附近构造有限候选集，低成本近似最大不确定连续动作。
  8. 离散动作探索：按各离散动作的不确定性进行概率选择；当不确定性都低时转向更贪心的 reward-oriented 选择。
  9. 执行动作、收集多目标 reward vector、写入 replay buffer，随机采样更新 critics、actor 和 target networks。
- 自动驾驶实现：
  - 离散语义动作 `b`：left lane change、right lane change、lane keeping。
  - 连续参数 `(l, acc)`：`l` 用于生成 guiding path 终点，`acc` 是纵向加速度命令，范围为 `[-3,3] m/s^2`。
  - 横向 steering angle 由 guiding path 和 Stanley algorithm 生成；纵向加速度直接来自 actor 输出。
  - Reward 拆成 `R_safe` 和 `R_gen`：安全 reward 关注碰撞/出路和 TTC；general reward 覆盖效率、舒适/动作一致性和对周车干扰。

## 实验证据

- 场景和设置：
  - 在 `highway-env` 中构建三车道结构化道路，EV 与 SV 初始位置和速度随机。
  - SV 用 IDM 和 MOBIL 控制，可换道接近目标速度并扰动 EV。
  - V/C 设置为 `0.5`，表示中等拥堵。
  - episode 在碰撞/出路时终止，最长 200 s。
  - 训练每个算法使用 6 个不同 seeds；测试在仿真 rule-based SVs 和 HighD dataset 中各 200 episodes。
- Baselines：
  - DQN：只输出离散语义决策，PID 控制，epsilon-greedy 探索。
  - SAC-C：只输出连续 steering angle 和 acceleration，用 entropy/Gaussian noise 探索。
  - SAC-H：SAC 的 hybrid action 变体。
  - PPO-H：on-policy actor-critic，action space 类似 SAC-H。
  - Ablations：HPA-MoEC、去掉不确定探索的 HPA-Mo、去掉多目标评价的 HPA、去掉 hybrid action 的 DA-Mo。
- Metrics：
  - AR average reward；
  - CR collision rate；
  - AS average speed；
  - NL number of lane changes；
  - VS/VA steering angle 和 acceleration 方差，用于动作一致性。
- 训练结果：
  - HPA-MoEC reward 最高且 seed 间波动小；达到 replay 最小样本后策略提升速度明显快于基线。
  - HPA-MoEC 训练中维持低 CR；安全 objective 从 general performance 中解耦后，agent 更重视安全。
  - SAC-C 因直接控制 steering 容易出路并提前终止；DQN reward 最低，说明只靠离散动作不足以处理复杂驾驶任务。
- Rule-based SV 测试：
  - HPA-MoEC 获得最高 AR 和 AS，且 VS/VA 最小，说明效率和动作一致性同时最好。
  - 相比 SAC-H，HPA-MoEC 的 AS 提高 13%，NL 提高 28%。
  - 相比 PPO-H 和 SAC-H，HPA-MoEC 的 VS 分别低 26% 和 42%，VA 分别低 41% 和 54%。
  - 安全上 HPA-MoEC 的 CR 仅次于过度保守的 SAC-C；相比 SAC-H/PPO-H，CR 分别降低 67% 和 69%。
  - DQN 的 CR 为 `0.38%`，频繁 lane changes 使风险更高。
- HighD 测试：
  - 真实轨迹数据更稀疏，所有方法更容易，但 HPA-MoEC 仍最高 AR，并保持最高 AS 和较低 VS/VA。
  - HPA-MoEC 在 HighD 中 CR 降到 `0.01%`，显示训练于仿真后对人类驾驶 SV 仍有适应性。
- Ablation：
  - HPA-MoEC 约 1400 episodes 收敛，HPA-Mo 约 1700 episodes，uncertainty exploration 使训练效率提升约 18%。
  - 去掉多目标 policy evaluation 后，HPA 的 AR 降低，CR 相比 HPA-Mo 近三倍增加。
  - 去掉 hybrid action 后，DA-Mo 最差；相比 HPA，VS 增加约 25%，AS 下降 15%，CR 增加 100%。
  - w/o EU-E baseline 显示 HPA-MoEC 早期更充分探索高不确定区域，随后不确定性更快下降；lane change 的 uncertainty 高于 lane keeping。
- 证据边界：
  - 表格数值在 Markdown 中为图片占位，以上相对改进来自正文描述。
  - 训练和测试仅限多车道高速场景；未覆盖匝道、交叉口、城市混行和感知不确定性。
  - Reward、目标权重、action 结构依赖驾驶任务手工设计。
  - 安全仍以仿真/HighD 测试 CR 和 TTC 奖励为主，未给出形式化 safety guarantee。

## 局限与未来工作

- 作者明确说明的局限：
  - 训练和测试限制在 multilane highways。
  - 其他道路类型如 ramps 和 intersections 需要更高维感知状态。
- 作者未来工作：
  - 使用 BEV images 等高维感知信息作为 state space，将 HPA-MoEC 扩展到更复杂交通场景。
- 我们认为仍需确认的问题：
  - 多目标权重 `omega` 是否固定，能否随场景风险、法规或用户偏好动态变化。
  - Ensemble uncertainty 在分布外真实道路、感知误差和稀有危险场景中是否可靠校准。
  - Hybrid action 的 guiding path 和 Stanley 控制器若更换为 MPC/纯学习控制，结论是否仍成立。
  - 安全 critic 是否需要 hard safety shield、control barrier 或 reachability filter 才能上车。
  - 只随机 replay 是否浪费了不确定探索收集到的高价值经验，是否应与 prioritized replay/offline RL 结合。

- 局部创新线索：
  - 将固定 `omega` 改成 risk-conditioned 或 preference-conditioned weights，使安全 critic 在高风险场景自动增权。
  - 用 conservative/offline RL 预训练 ensemble critics，再在线用 uncertainty exploration 小步微调。
  - 在 uncertainty exploration 外层加 safety shield，只允许探索通过 TTC/CBF/可达性过滤的动作。
  - 把 ensemble 方差拆成目标级不确定性，分别监控 safety uncertainty、efficiency uncertainty 和 comfort uncertainty。
- 结构创新线索：
  - 构建通用混合动作 MORL 控制层：

```text
state perception
-> semantic option + continuous parameter actor
-> objective-specific ensemble critics
-> uncertainty-guided hybrid exploration
-> safety-filtered execution
-> multiobjective behavior metrics
```

  - 从自动驾驶迁移到机器人、无人机、过程控制或调度：离散 option 表示模式/任务/路线，连续 parameter 表示速度、力度、时间或资源量。
