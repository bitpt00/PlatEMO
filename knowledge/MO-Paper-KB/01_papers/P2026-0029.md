# A dual-population evolutionary algorithm with variable constraint guidance for constrained multi-objective optimization problems

## 一句话理解

本文提出 VCGDPEA：维护主种群 `Pop1` 和辅助种群 `Pop2`，`Pop2` 先无约束搜索 UPF 为 `Pop1` 提供跨越大不可行区的方向；当检测到 `Pop2` 对 `Pop1` 的指导贡献停滞或失效后，算法切换到第二阶段，让 `Pop2` 的约束边界快速收缩并靠近 CPF，继续以低约束强度的不可行/边界信息帮助 `Pop1` 收敛到 CPF。

## 问题与动机

- 研究问题和场景：
  - 面向 constrained multi-objective optimization problems (CMOPs)；
  - CMOP 同时存在目标冲突和约束冲突，可行域可能被大面积不可行域包围、分裂或退化；
  - 过早强调可行性会困在局部可行区域，过早强调目标又会长期停留在不可行区域；
  - UPF 与 CPF 的关系存在四类：重合、包含全部 CPF、包含部分 CPF、完全不包含 CPF。
- 现有方法为什么不足：
  - 多阶段算法常花费大量资源搜索 UPF，但后续没有充分利用已获得信息；
  - 固定使用 UPF 或固定约束边界收缩速度，会在不同 UPF-CPF 关系下错配；
  - 传统双种群方法中辅助种群若长期追 UPF，可能在 Type IV 问题上浪费预算；
  - 只用 CDP 会在 feasible-first 压力下损失多样性；
  - many-objective CMOP 中 CDP 和 Pareto dominance 的区分力会下降。
- 本文希望解决什么：
  - 更合理地利用 promising infeasible solutions；
  - 在线判断 `Pop2` 的 UPF 信息是否仍能指导 `Pop1`；
  - 在辅助信息失效后尽早切换到 CPF 附近开发；
  - 让约束边界在第二阶段比既有 MTCMO 式方法更快收缩；
  - 通过不同阶段、不同种群的算子配置平衡探索和开发。

## 核心理念与算法流程

- 基本角色：
  - `Pop1` 是主种群，始终用 CDP environmental selection，主要搜索 CPF；
  - `Pop2` 是辅助种群，负责从 infeasible/UPF 方向为 `Pop1` 提供搜索指导；
  - 两个种群的 offspring 会交叉进入彼此的环境选择池。
- Stage 1：
  - `Pop2` 不考虑约束，搜索 UPF；
  - `Pop1` 在可行性压力下只生成 `NP/2` offspring，避免早期在约束下浪费过多资源；
  - `Pop2` 用 GA、DE/rand/1 和 DE/current-to-pbest/1 混合生成 offspring；
  - 其中 DE/rand/1 结合 angle-based niching parent selection 强化探索。
- Stage 2：
  - 当 adaptive stage switching 触发后，`Pop2` 不再无约束深挖 UPF；
  - `Pop2` 使用 constraint boundary contraction strategy；
  - `Pop1` 用 DE/current-to-pbest/1 强化 CPF 附近开发；
  - `Pop2` 用 DE/rand/1 保持方向多样性；
  - 两个种群在 Stage 2 使用相同规模，加速靠近 CPF。
- Adaptive constraint boundary contraction：
  - `VAR` 在 Stage 1 不收缩，保持为两种群平均 constraint violation；
  - 进入 Stage 2 后，`VAR` 从 `CV0` 快速下降；
  - `CV <= VAR` 的个体进入 `MP1`，其余进入 `MP2`；
  - 若 `MP1` 为空，则从 `MP2` 中按 CDP 选择；
  - 若 `MP1` 不足 `NP`，先保留 `MP1`，再从 `MP2` 中补足；
  - 若 `MP1` 超过 `NP`，在 `MP1` 内用非支配排序，并将 constraint violation 作为额外目标辅助选择。
- Adaptive stage switching：
  - 监测 `Pop2` 目标总值变化、`Pop2` 中非支配解比例、两个种群可行比例，以及 `Pop1`/`Pop2` 首层解合并后的相对排名；
  - Case 1：`Pop2` 收敛停止次数超过 2，说明继续搜索 UPF 收益小；
  - Case 2：连续指导失败次数足够长，且 `Pop2` 非支配解比例超过 `alpha1`，说明 UPF 已基本获得但对 `Pop1` 无更多帮助；
  - Case 3：多段指导失败中的最长连续失败次数超过阈值，作为 Case 2 的兜底；
  - 触发后从 Stage 1 切换到 Stage 2。
- 可能被修改的位置：
  - 指导失败指标可替换为 archive contribution、HV contribution、rank improvement 或 CPF distance proxy；
  - `VAR` 收缩曲线可按可行比例、边界解密度或 constraint hardness 自适应；
  - `Pop2` 可从单一 UPF 辅助种群扩展为 UPF/SPF/constraint-subset 多辅助种群；
  - CDP 可替换为 fuzzy CHT、epsilon CHT、CV-as-objective 或 reference-vector feasible-first；
  - Stage 1 中 `Pop1` 规模缩减可改成预算分配策略。
- 必须保留的核心：
  - 辅助种群先无约束探索 UPF；
  - 阶段切换由辅助种群对主种群的指导有效性触发，而不是固定迭代数；
  - 第二阶段辅助种群使用约束边界收缩靠近 CPF；
  - 主种群始终承担 CPF 输出责任。

## 实验证据

- 实验设置：
  - 对比算法包括 CMOEAD、NSGA-III、C3M、MSCEA、CAEAD、BiCo、URCMO、IMTCMO、MCCMO、APSEA；
  - 基准包括 LIRCMOP、MW、CF、DASCMOP，共 47 个 test problems；
  - 指标为 IGD 和 HV；
  - 每个算法在每个问题上独立运行 30 次；
  - `NP=100`；
  - LIRCMOP 最大评价次数为 200,000，其它 benchmark 和真实问题为 100,000；
  - VCGDPEA 参数包括 `CRset=[0.1,0.2,1.0]`、`Fset=[0.6,0.8,1.0]`、`alpha1=0.8`、`lambda1=0.05`、`lambda2=0.3`。
- 47 个 benchmark：
  - 在 LIRCMOP、MW、CF、DASCMOP 的 47 个问题上，VCGDPEA 整体表现优于或竞争于 10 个 CMOEA；
  - 作者解释 DASCMOP 多为 Type IV，UPF 与 CPF 不重合，VCGDPEA 能检测 `Pop2` 指导失败并更快切换；
  - 多问题 Wilcoxon signed-rank test 中，所有 `p` 值低于 0.05，且 `R+` 大于 `R-`；
  - Friedman test 中，VCGDPEA 在 11 个算法中取得最小平均排名。
- 过程可视化：
  - LIRCMOP1 是 Type IV 且有大不可行区；
  - CAEAD 在早期快速靠近 UPF 后仍可能重新探索 UPF，浪费预算；
  - IMTCMO 的辅助种群位于 UPF 与 CPF 之间，但边界收缩较慢；
  - VCGDPEA 能根据指导情况切换阶段，并在 CPF 附近保持更好的收敛和分布；
  - LIRCMOP12 的可视化也支持类似结论。
- 高维实验：
  - LIRCMOP 和 DASCMOP 扩展到 50 维和 100 维；
  - 作者总结 VCGDPEA 在 IGD 和 HV 上保持强竞争力，并在高维 CMOP 上表现突出；
  - 但结论部分也承认缺少专门的大规模 CMOP 策略，large-scale CMOP 上会出现性能下降风险。
- Many-objective 实验：
  - 在五目标 ZXH_CF 上，VCGDPEA 由于使用 CDP，非支配解不可比较增多，收敛性能下降；
  - 相比 NSGA-III、C3M、CAEAD 更好；
  - 与 BiCo、URCMO、IMTCMO 竞争；
  - 但弱于 CMOEAD、MSCEA、MCCMO、APSEA。
- 真实 CMOP：
  - 包括 multi-product batch plant、process flow sheeting、two-reactor problem、power distribution system planning；
  - VCGDPEA 在四个真实问题的 HV 上均取得最大或相近结果；
  - 作者认为其对真实 CMOP 有竞争力，但工业应用仍需更多模块适配复杂约束、高维变量和动态环境。
- 消融实验：
  - 变体包括单种群无阶段/无边界收缩、单种群+阶段切换、单种群+阶段切换+边界收缩、双种群+阶段切换但无自适应边界收缩；
  - VCGDPEA 的 Friedman ranking 最小：IGD 为 1.8085，HV 为 1.9043；
  - `VCGDPEA-VAR` 与 VCGDPEA 比较结果为 `2/23/22`，支持本文边界收缩策略；
  - VCGDPEA 相比 GA-only 和 DE-only 变体分别为 `6/28/13`、`3/26/18`，支持混合 evolutionary strategy；
  - Stage 1 中 `Pop1=NP/2` 的设置优于多个替代主群规模变体。
- 参数敏感性：
  - 对 `NP`、`Pm`、`alpha`、`lambda1`、`lambda2` 做敏感性分析；
  - 在 CF1、DASCMOP1、LIRCMOP1、MW1 上比较 IGD/HV 中位表现；
  - 作者认为 VCGDPEA 对参数设置不敏感。

## 局限与未来工作

- 作者明确说明的局限：
  - 缺少专门针对 large-scale CMOPs 的策略，因此在大规模 CMOP 上会有性能下降；
  - many-objective CMOP 中，由于使用 CDP，非支配解之间不可比较增多，导致收敛性能下降；
  - 真实工业应用还需针对复杂约束、高维变量和动态环境进一步适配。
- 作者未来工作：
  - 设计并选择性引入更多功能模块，以更高效解决 real-world CMOPs；
  - 对 hybrid constraints 引入 hierarchical processing 和 dynamic boundary update；
  - 对 expensive multi-objective optimization 引入 surrogate model 和 parallel computation。
- 我们认为仍需确认的问题：
  - `Pop2` 对 `Pop1` 的指导失败指标是否能稳定区分 Type IV 和暂时停滞；
  - `VAR` 快速收缩是否会在需要长期 UPF 细节的 Type I-III 问题上过早拉回；
  - `Pop1` Stage 1 缩小规模的收益是否依赖 `NP=100`；
  - CDP 替换成 many-objective 友好选择后，原阶段切换条件是否还成立；
  - 公式多处图片省略，边界收缩和指导失败判定的细节需代码复核。

- 局部创新线索：
  - 用 archive contribution 或 HV gain 直接度量 `Pop2` guidance success；
  - 在 Stage 2 让 `VAR` 按 feasible ratio 或 boundary-solution density 自适应降速；
  - 为不同 reference vectors 分别判断 UPF guidance 是否失效，避免全局一次切换；
  - 把 CDP 换成 angle-based feasible-first 或 indicator-based CHT，改善 many-objective 退化；
  - 在 Type I-III 中保留少量无约束 UPF 子群，防止边界收缩后丢失远端 CPF 片段。
- 结构创新线索：
  - 构建通用“辅助信息贡献审计器”：任何 CMOEA 辅助任务、辅助种群或无约束任务都必须证明仍在改进主种群，否则降权、收缩或终止；
  - 将 UPF exploration 视为临时 search service，按指导失效自动转为 boundary exploitation；
  - 与多辅助约束任务结合：每个辅助任务独立记录 guidance failure，形成多任务级 stage switching。
