# A Novel Multi-Objective Memetic Algorithm for Multi-Task Fuzzy Flexible Job Shop Scheduling

## 一句话理解

这篇论文把多个 fuzzy flexible job shop scheduling tasks 放进同一个多目标多任务 memetic framework，用 routing/sequencing 双向量统一编码解决任务异构表示问题，再用 Q-learning 自适应双邻域大小和改进外部邻域更新提高正迁移率。

## 问题与动机

- 研究问题和场景：multi-task multi-objective fuzzy flexible job shop scheduling (FFJSS)，每个任务可能有不同 job 数、machine 数、operation 结构和机器可用性，同时目标为 fuzzy makespan 与 fuzzy energy consumption。
- 现有算法为什么不足：传统 FFJSS 多按单任务独立求解，无法复用相似生产线之间的调度知识；MFEA 类方法需要统一表示，但 FFJSS 同时包含 routing 和 sequencing，且不同任务结构不一致；分解式多任务迁移已有内外邻域思想，但忽略 neighborhood size 和负迁移个体对迁移质量的影响。
- 本文希望解决什么：设计适合多任务 FFJSS 的统一编码，并用双邻域迁移、Q-learning 邻域大小控制和全局视角外部邻域更新，提升跨任务正迁移。

## 核心理念与算法流程

- 核心理念：每个个体同时维护 task-specific representation 与 unified representation。统一表示只在知识迁移时使用，包括 routing real-valued vector 和 sequencing permutation vector；在 decomposition framework 中，每个个体有 internal neighborhood 和 external neighborhood，分别承载同任务局部开发与跨任务迁移。
- 主要流程：
  1. 为每个任务初始化一个 population，使用五种启发式初始化 routing/sequencing。
  2. 对所有任务构造统一表示：routing 维度取最大 operation 数，sequencing 维度覆盖各任务最大 job-operation 结构。
  3. 为每个个体构造双邻域：internal neighborhood 为同任务中 weight vector 最近的 `T` 个体；external neighborhood 为其他任务中被迁移后表现好的个体。
  4. 每代根据当前 Pareto front 的 convergence improvement `Delta C` 和 diversity improvement `Delta D` 离散成 4 个状态。
  5. Q-learning 从 action set `{5,10,15,20}` 选择 dual-neighborhood size `T`，reward 主要鼓励 diversity improvement。
  6. 若随机数小于 transfer probability `delta`，从 internal/external 两类邻域选父代执行跨任务 POX/UX 与 mutation；否则只在 internal neighborhood 内繁殖。
  7. 对 offspring 执行 local search，并用 Tchebycheff aggregation 从全局 subproblem 视角更新 internal/external neighborhoods。
- 关键组成部分：
  - Unified FFJSS representation：routing 和 sequencing 两条染色体分别统一到跨任务最大结构。
  - Dual-neighborhood transfer：internal neighborhood 提供同任务局部收敛，external neighborhood 提供跨任务多样性和迁移。
  - Q-learning neighborhood size selection：用收敛/多样性状态反馈选择邻域大小。
  - Improved neighborhood update：迁移个体不只尝试更新当前 subproblem，还检查是否能更新其他 subproblem，提高正迁移率。
- 可能被修改的位置：多任务调度的统一编码、MFEA/MOEA/D-MTO 的 parent selection、外部邻域维护、transfer probability / neighborhood size 控制。
- 必须保留的核心：双邻域的 external neighborhood 必须由迁移个体表现动态更新；若只随机跨任务交配或固定同子问题迁移，就无法体现本文对正迁移率的主要改进。

## 实验证据

- 测试问题和对比算法：
  - 构造八类 multi-task FFJSS scenarios，覆盖 same difference、small difference、big difference，基于 job/machine 数变化。
  - 每次实验两个任务，population size 每任务 100，总 200；运行 30 次，最大 200 generations；mutation probability 0.8；Q-learning `gamma=0.8`、learning rate 0.1、greedy factor 0.95；transfer probability 默认 0.1。
  - 对比 NSGA-II、MOEA/D、MOEA-DCH、LRVMA、MOMFEA、MTEA/D-DN，以及 Variant1/Variant2 消融。
  - 指标：IGD 和 HV；Wilcoxon rank-sum 5% 与 Friedman ranking。
- 主要实验结论：
  - 综合 IGD/HV 排名为 `MOMA > MOMFEA > MOEA-DCH > LRVMA > MTEA/D-DN > NSGA-II > MOEA/D`。
  - 近似 Pareto front 可视化显示 MOMA 在大多数代表实例上收敛和多样性较好，但 J20M7、J20M8、J30M6、J30M7 等实例存在例外。
  - 复杂任务尤其是 simple + complex 组合（如 J80M9、J80M10）更能从知识迁移中受益。
- 消融或机制证据：
  - Variant1 加入自适应 dual-neighborhood size；Variant2 加入 improved neighborhood update；Friedman 排名为 `MOMA > Variant2 > Variant1 > MTEA/D-DN`，说明两项机制均有贡献。
  - Transfer effectiveness 中 `NW` 和 positive transfer ratio `R=NP/NT` 排名为 `MOMFEA < MTEA/D-DN < Variant1 < Variant2 < MOMA`，支持 MOMA 提高正迁移效率。
  - 传输概率敏感性显示较高 transfer probability 会降低性能；多数场景推荐 0.1-0.3。
- 证据边界：
  - 主文表格多为图片占位，完整数据在 supplementary。
  - 默认 transfer probability 仍固定为 0.1，作者也承认需要自适应机制。
  - 转移知识的解释性不足，难说明哪些 routing/sequencing 模块真正跨任务有用。

## 局限与未来工作

- 作者明确说明的局限：
  - 使用固定 transfer probability。
  - transferred knowledge 缺乏解释性。
- 作者未来工作：开发 adaptive transfer probability mechanisms；探索 transferred knowledge 的 interpretability；将 MOMA 应用到其他 combinatorial optimization problems。
- 我们认为仍需确认的问题：
  - Q-learning reward 偏向 diversity improvement，是否会在某些阶段牺牲收敛。
  - 两任务设置扩展到多于两个 FFJSS 任务时，external neighborhood 维护和 transfer probability 是否仍稳定。
  - 不同任务 job/machine 差异很大时，统一 sequencing/routing 表示是否会引入大量无效基因。
  - local search 与 transfer strategy 的独立贡献仍需更细消融。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 补充“多邻域多知识的分解式多任务迁移”：本文提供组合调度场景中的 dual-neighborhood transfer、Q-learning neighborhood size 和 positive transfer tracking 证据。
- 暂留在论文卡中的方法、原理或架构启发：
  - Routing/sequencing 双向量统一编码很适合 FFJSS，但领域性较强，暂留在论文卡。
  - `R=NP/NT` positive transfer ratio 可作为多任务迁移诊断指标，后续若多篇采用可单独抽象。
- 局部创新线索：
  - 用 UCB/Thompson sampling 替代 Q-table 选择 neighborhood size 和 transfer probability。
  - 将 external neighborhood 按任务相似性、job/machine 差异或历史 positive transfer ratio 分层。
  - 对 routing 与 sequencing 分别设置 transfer probability，避免两个编码部分迁移收益不一致。
- 结构创新线索：
  - 构建多任务调度知识路由器：统一编码 -> internal/external neighborhoods -> 自适应邻域/迁移概率 -> positive-transfer 更新 -> local search 精修。
  - 与调度领域启发式库结合，让跨任务迁移不仅传个体，也传 dispatching rule、machine assignment pattern 或局部搜索模板。
