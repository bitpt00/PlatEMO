# A fuzzy multi-objective neuro-evolutionary framework with bargaining-based selection for interpretable body fat prediction

## 一句话理解

论文提出 MOFAGLSUD-FS-MLP：用四个模糊推理系统在线调节二进制特征选择的全局学习、多样性速度扰动、局部差分搜索和算子选择，把 body-fat prediction 建成 `RMSE + feature count + residual dispersion` 三目标问题，再用 Nash Bargaining Solution 从 Pareto 模型集中选出准确、简洁、稳健都不过度牺牲的临床折中模型。

## 问题与动机

- 研究问题和场景：根据人体测量、临床化验和人口学变量预测 body fat percentage (PBF)。传统 BMI、waist-to-hip ratio、BIA 等代理指标简单但线性、群体依赖强，难以捕捉非线性高维生物医学关系。
- 为什么重要：
  - PBF 与心血管和代谢风险相关，模型需要准确，也需要变量少、解释性强、稳定。
  - 医疗模型不适合只追求最低误差；过多特征会降低可用性，残差分布太分散会降低个体层面的可靠性。
  - 多个 feature subset 可能在目标空间表现相近，形成 multimodal feature-selection landscape，普通单目标搜索易早熟或只给单个主观加权解。
- 现有算法为什么不足：
  - IFW-RE-SVM、FA-GL-BICA、FABGA 等 fuzzy/evolutionary body-fat predictors 主要是单目标或固定加权，缺少显式 Pareto trade-off。
  - NSGA-II、MOPSO、MOICA、FAME 能做多目标特征选择，但没有面向 body-fat prediction 的 fuzzy meta-control 和临床可解释决策层。
  - 传统 dominance ranking 只给解集，不直接回答临床部署时选哪一个模型。
- 本文希望解决什么：同时优化预测精度、特征简洁性和稳健性，并让搜索控制与最终选解都具备可解释的 fuzzy/game-theoretic 逻辑。

## 核心理念与算法流程

- 核心理念：把“选择哪些特征训练 MLP”视为二进制组合优化。单目标版本 FAGLSUD 用 fuzzy adaptive global-local search 找一个加权最优特征子集；多目标版本 MOFAGLSUD 维护 Pareto front，并用 MOBG/NBS 选择公平折中。
- 目标定义：
  - `nf`：选中特征个数，表示 parsimony；
  - `RMSE`：预测误差，表示 accuracy；
  - `STDerr`：同一测试集内 residual dispersion，表示 within-run robustness；
  - `STDruns` 只表示 30 次运行之间的指标波动，作者专门区分它与 `STDerr`。
- 主要流程：
  1. 将 Johnson 数据集的 13 个变量、NHANES 数据集的 41 个变量编码为 binary feature subset。
  2. 每个候选子集训练/测试一个 MLP regressor，用 `nf, RMSE, STDerr` 等统计量评价。
  3. FIS1/FAGLVA 根据 normalized performance indicators 和迭代阶段调节 cognitive/social learning coefficients，引导 colony/imperialist 向个人最好、局部 imperialist 和 global best 学习。
  4. FIS2/FAUDVD 调节 diversity-based velocity diversification，让候选从其他 colony/imperialist 的经验中学习，减轻早熟。
  5. FIS3/FAEDELS 调节 enhanced differential evolution local search 的 mutation/crossover scaling factors，在局部精修与探索之间切换。
  6. FIS4/FAOS 根据 stagnation、当前算子概率和迭代阶段更新 FAGLVA、FAUDVD、FAEDELS 的激活概率。
  7. 用 symmetric V-shaped transfer function 将连续速度/步长映射为 bit-flip probability，抑制小幅震荡 bit flips，同时允许较大步长触发明确翻转。
  8. 多目标版本先做非支配排序，再用 archive 保存一线 PF，并用 SSDR 在 objective space 和 decision space 同时惩罚过密区域。
  9. 生成 Pareto set 后，MOBG/NBS 将 accuracy、simplicity、robustness 视作三个合作 agent，最大化 normalized utility gains 的乘积，选出最终模型。
- 必须保留的核心：
  - 搜索端：fuzzy meta-control 不是后验解释，而是在线控制搜索参数和算子概率。
  - 目标端：不要把 `nf, RMSE, STDerr` 过早压成单目标；多目标版本需要保留 PF。
  - 决策端：最终单模型应由可解释选解规则从 PF 中选出，而不是人工挑最顺眼的点。

## 实验证据

- 测试问题和对比算法：
  - Datasets：Johnson anthropometric dataset，`n=252`、13 个变量；NHANES 1999-2000 clinical dataset，`n=862`、41 个变量；二者均为历史 male-only U.S. cohorts。
  - 数据划分：70/30 train-test，训练部分使用 5-fold CV 调参；30 independent runs；Wilcoxon signed-rank tests + Holm correction。
  - 单目标 baselines：FA-GL-BICA-FS-MLP、ICA-FS-MLP、FABGA-FS-MLP、PSO-FS-MLP、DE-FS-MLP、MR-MARS、RF-IRE-SVM、DT-SVM、FA-XGBoost、WOA-IFW-RE-SVM 等。
  - 多目标 baselines：NSGA-II-FS-MLP、MOPSO-FS-MLP、MOICA-FS-MLP、FAME-FS-MLP。
  - Metrics：MAE、RMSE、MAPE、TIC、`STDerr`、`STDerr,mean`、`STDruns`、`nf`、convergence time、Pareto dominance relation。
- 搜索组件消融：
  - Dataset I：FAGLSUD + proposed symmetric V-TF 得到 `nf=5`、RMSE `3.9511`、`STDerr=1.6130`、time `4.9066s`；classical V-TF 的 RMSE 为 `3.9850`，S-shaped sigmoid 为 `4.0350`。
  - Dataset II：proposed symmetric V-TF 得到 `nf=15`、RMSE `5.0799`、`STDerr=2.0754`；classical V-TF 为 `5.1120`，S-shaped 为 `5.1650`。
  - 去掉 fuzzy inference、FAGLVA 或只保留 diversity component 的内部变体均在收敛时间、精度或 residual dispersion 上退化，作者据此认为 fuzzy adaptive operators 有贡献。
- 单目标预测对比：
  - Abstract 总结 single- and multi-objective variants 相对 full feature set 最多减少 `65%` 特征，并相对 state-of-the-art fuzzy/evolutionary baselines 降低 RMSE `3-8%`。
  - Dataset I 中 FAGLSUD-FS-MLP 的 RMSE `3.9511`、`nf=5`、`STDerr,mean=1.6130`，优于 FA-GL-BICA、ICA、FABGA、PSO、DE 和多个 ML baselines。
  - Dataset II 中 FAGLSUD-FS-MLP 的 RMSE `5.0799`、`nf=15`、`STDerr,mean=2.0754`，在核心指标上优于重实现 baselines。
  - Table 8 显示在 RMSE、MAE、TIC、`STDerr,mean` 等关键指标上的 Wilcoxon-Holm 比较多为显著；`nf` 和 MAPE 在部分比较中不显著。
- 多目标 PF 对比：
  - Dataset I 中 MOFAGLSUD 给出 F1-F4：`(RMSE,nf,STDerr)` 分别为 `(4.5129,2,1.8466)`、`(4.2868,3,1.7556)`、`(3.9512,5,1.6140)`、`(3.8901,9,1.5920)`，并在多组 dominance relation 中优于 MOICA/MOPSO/NSGA-II/FAME 的对应解。
  - Dataset II 中 MOFAGLSUD 给出 F1-F3：`(5.2041,14,2.1253)`、`(5.0796,15,2.0767)`、`(4.9531,26,2.0033)`。
  - Table 11 使用同一 MOBG/NBS 决策规则抽取每次运行的可比解，再比较 RMSE、`nf`、`STDerr`；相对 MOICA、MOPSO、NSGA-II、FAME 多数比较显著。
- MOBG/NBS 选解：
  - Dataset I 的 NBS 选择 F3：RMSE `3.9512`、`nf=5`、`STDerr=1.6140`，避开最低 RMSE 但 9 特征的 F4 和更少特征但误差更高的 F1/F2。
  - Dataset II 的 NBS 选择 F2：RMSE `5.0796`、`nf=15`、`STDerr=2.0767`，相对 F1/F3 更均衡。
- 临床可解释性：
  - Dataset I 中 abdomen、hip、knee、ankle、wrist 等被全局解或 Pareto 解反复选中。
  - Dataset II 中 GGT、waist、weight、potassium、phosphorus 等在 Pareto 解中稳定出现，作者认为与代谢风险和中心性肥胖有生理一致性。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前验证基于静态 cross-sectional datasets；更强证据需要 longitudinal 或 real-time validation。
  - 两个数据集都是历史 male-only U.S. cohorts，不能声称模型已对当前多样化人群临床校准。
  - 未测试 imaging、genomics、wearable sensor streams 等高维模态，也未验证 distributed/cloud scalability。
  - 未来需要动态/纵向 PBF 预测、医学协作验证 recurrent features、个性化 fuzzy linguistic explanation、multi-agent/federated clinical decision settings 和 interactive visual analytics。
- 我们认为仍需确认的问题：
  - NPop=10、itmax=100 对两个小中等数据集有效，但在更高维特征和大型神经模型上可能不足。
  - MLP 每个候选都要训练/验证，真实大数据场景中 fitness cost 可能成为瓶颈；需要 surrogate、weight inheritance 或并行评估。
  - 四套 fuzzy rule bases 虽固定跨数据集使用，但仍来自专家规则设计；跨领域迁移时是否要重设 rule base 尚未证明。
  - MOBG/NBS 没有系统对比 TOPSIS、VIKOR、knee point、interactive preference 等最终选解方法。
  - `STDerr` 衡量的是测试观测残差分散，不等同于 calibration、uncertainty coverage 或 subgroup fairness。
  - Code 不是公开下载，而是向第一作者合理请求，复现成本较高。

- 值得建立或补充的设计知识：

- 暂留在论文卡中的方法、原理或架构启发：
  - Fuzzy meta-control 可作为演化搜索的可解释参数控制层：不同 FIS 分别负责学习系数、多样性、局部搜索和算子概率。
  - Symmetric V-shaped transfer function 是二进制搜索中控制 bit-flip 稳定性的可复用细节，但目前证据主要来自本文两个数据集。
  - SSDR 结合 objective-space 与 decision-space spread，适合 feature subset MMOP 中避免“目标值相近但子集冗余”的局部拥挤。
  - 在医学模型选择中，把 residual dispersion 作为独立目标，比只报告 RMSE 更能暴露个体误差分布风险。
- 局部创新线索：
  - 将 fuzzy rule bases 改成从历史运行中学习或用 offline RL/meta-learning 自动校准。
  - 对 NBS score 加入置信区间或 bootstrap lower-bound utility，避免选择统计不稳定的解。
  - 将 MLP fitness 替换为 warm-start/weight-sharing evaluator，提高大特征集上的搜索效率。
  - 对 feature recurrence 做 subgroup analysis，检查不同人群上的稳定特征是否一致。
  - 把 `STDerr` 扩展为 calibration error、prediction interval width、subgroup worst-case error 或 fairness gap。
- 结构创新线索：
  - 构建“MOEA/NAS 生成模型族 -> NBS 选部署模型 -> 医生/工程师交互调整偏好 -> 再局部重搜”的闭环。
  - 在每个 Pareto cluster 内选择一个 NBS，形成多个临床档位，而不是只输出一个全局折中。
