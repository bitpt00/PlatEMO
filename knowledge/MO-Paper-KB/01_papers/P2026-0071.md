# Multiple task nonparallel embedded matrix machine and its application in multi-objective fault diagnosis

## 一句话理解

这篇论文提出 MTNPEMM，一个面向矩阵形式振动信号的多任务非平行嵌入矩阵分类器。它不是多目标优化算法；题名中的 multi-objective 更接近“多个诊断对象/部件”。方法把 support matrix machine 扩展到多任务学习：为正负类构造两组非平行超平面，分离任务共享权重和任务个性权重，并通过 kernel enhancement embedded term 在矩阵样本切片之间互相映射，以同时利用矩阵行列相关和跨任务共性。最后用 One-vs-One 处理多类故障诊断。

## 问题与动机

- 研究问题：
  - 机械设备故障诊断中，轴承、齿轮、不同轴或不同工况往往需要同时诊断；
  - 原始振动信号转换成矩阵后能保留更多状态信息，但传统 SMM 类方法多为单任务学习；
  - 单任务模型不能共享多个部件/任务之间的共性信息，迁移到新任务时常需重新调参。
- 现有方法为什么不足：
  - SVM/TSVM 需要先抽取有限特征，容易遗漏原始信号结构；
  - SMM 能处理矩阵样本，但只能单任务建模；
  - DMTSVM 可做多任务，但处理矩阵样本时需要向量化，导致矩阵结构损失和维度灾难；
  - 一维深度多任务网络适合序列特征，但不能直接利用矩阵样本的行列内部关系。
- 本文希望解决什么：
  - 在 SMM 框架中同时建模多任务共性和任务个性；
  - 保留矩阵样本结构，不把矩阵简单拉直；
  - 用非平行超平面降低求解规模并提升分类稳定性；
  - 在多个机械故障诊断任务上减少单任务模型的跨任务性能下滑。

## 核心模型与算法流程

- 输入数据：
  - 每个任务有矩阵样本 `x_i in R^{m x n}` 和类别标签；
  - 原始振动信号先经 SGST 或 STFT 转换为矩阵样本，作者最终采用 SGST；
  - 多类问题通过 One-vs-One 拆成多个二分类子问题。
- MTNPEMM 的模型结构：
  - 对每个任务构造正类和负类两组非平行超平面；
  - 权重和阈值拆成共享部分与任务个性部分，例如 common weight/threshold 与 task-specific deviation；
  - 正类样本被约束尽量靠近正类超平面，负类样本与其保持间隔；负类超平面同理；
  - insensitivity loss `epsilon` 控制正类样本在超平面附近的容忍带；
  - hinge loss 约束异类样本保持至少单位间隔。
- kernel enhancement embedded term：
  - 对不同数据集中的矩阵样本进行切片级相互映射；
  - 目的是挖掘矩阵行列相关性，并把多任务共同信息嵌入核增强项；
  - scale parameter 用于特征缩放，power `d` 用于处理更复杂的矩阵数据；
  - nonlinear offset 用于捕捉非线性关系，并提高数值稳定性。
- 求解和预测：
  - 推导后转化为两个二次规划问题；
  - 使用 MATLAB quadratic programming 求解；
  - MTNPEMM 本身是二分类器，多类故障诊断用 One-vs-One 训练多个二分类学习器；
  - 预测阶段对所有二分类器输出投票，确定最终故障类别。
- 复杂度：
  - 作者称主要成本来自两个二次规划问题；
  - MTNPEMM 复杂度写作 `O(r(3l/2)^3)`，其中 `l` 为样本数，`r` 为迭代数；
  - 多任务机制不改变主复杂度阶；
  - 与 SMM、MSMM、NPBSMM、SSMM、NPLSSMM 的复杂度进行文本比较，但公式抽取有排版噪声。

## 实验证据

- Case 1：AHUT rolling mill vibration characteristics test bench。
  - 三个相关任务：gearbox bearings、gearbox gears、rolling mill bearings；
  - 速度/故障类型在 Table 1-3 中列出；
  - 数据集共 200 个样本，训练集和测试集各 100 个；
  - 对比方法：SSMM、SMM、MSMM、NPBSMM、NPLSSMM；
  - 评价指标：Accuracy、F1score、Kappa、Precision、Recall。
- Case 1 参数与预处理：
  - kernel enhancement embedded term 的 scale parameter 设为 1，power `d=2`；
  - insensitivity loss 在 `epsilon=0.01` 附近分类效果最好；
  - MTNPEMM 的 penalty coefficient、offset 和 deviation parameter 均设为 1；
  - SGST 相比 STFT 略优，Table 4 中 SGST 平均 Accuracy 为 0.9950，STFT 为 0.9650。
- Case 1 主结果：
  - Table 5 中 MTNPEMM 在三个任务上 Accuracy 分别为 0.9883、0.9983、0.9983；
  - 其他方法在 Task 2 和 Task 3 上明显下降，例如 SMM 在 Task 3 Accuracy 为 0.8017，MSMM 为 0.8374；
  - 作者归因于单任务模型不能利用不同诊断对象之间的共同信息。
- Case 1 稳定性：
  - 每类样本打乱后重新划分训练/测试，重复 5 次；
  - 作者称 MTNPEMM accuracy 超过 99%，且标准差最小；
  - 对比方法即使重新调参，MTNPEMM 仍保持最高分类准确率。
- Case 2：AHUT comprehensive fault simulation experimental platform。
  - 两个任务：bearing fault dataset 和 parallel axis gearbox gear fault dataset；
  - 每个 bearing state 有 180 个 fault samples，90 个训练、90 个测试；
  - 新增 Specificity、AUC、G-mean 指标。
- Case 2 主结果：
  - Task 1 上 MTNPEMM 各指标均为 1；
  - Task 2 上 MTNPEMM Accuracy 为 0.9958，Kappa 为 0.9952，G-mean/AUC 为 0.9976；
  - Table 9 中 MSMM 和 NPBSMM 的 F1score/Precision 出现 `NaN`，说明部分类别预测或指标计算存在异常。
- 时间与统计检验：
  - Table 12 中 MTNPEMM 总时间为 36.1726 s；
  - 它慢于 NPBSMM 5.2371 s、NPLSSMM 14.5697 s、MSMM 18.5614 s，但快于 SSMM 196.4971 s 和 SMM 138.5854 s；
  - Friedman test 中 MTNPEMM 平均 rank 为 1，其他方法 rank 为 3.225-5.679；
  - 计算得到 `FF=37.0826`，拒绝无显著差异原假设；
  - Nemenyi test 的 CD 为 1.5317，作者称 MTNPEMM 与其他方法存在显著差异。
- 可扩展性：
  - 用 Case 1 构造更多二分类多任务，任务数为 4、5、6 时平均 accuracy 分别为 0.9962、0.9960、0.9975；
  - SGST 矩阵维度为 25x25、32x32、36x36 时平均 accuracy 分别为 0.9872、0.9883、0.9950；
  - 作者认为模型适合高精度、少样本、离线训练的工业故障诊断。

- 参数选择采用逐个参数调节，未说明是否有严格嵌套验证；分类性能可能受调参协议影响。
- Table 9 中部分方法 F1score/Precision 为 `NaN`，提示类预测分布或指标计算需要额外核查。
- MTNPEMM 准确率很高，但 Case 1 样本量较小，Case 2 平台也相对集中；跨设备、跨工况和更强噪声条件下仍需验证。

## 局限与未来工作

- 作者明确局限/部署判断：
  - MTNPEMM 需要已有样本训练，更适合离线训练和离线故障分析；
  - 两个二次规划问题可以分开求解，有一定并行化潜力；
  - 适合高准确率、数据稀缺的工业应用，如定期健康评估和离线故障诊断。
- 我们认为仍需谨慎的问题：
  - 多任务相关性由共享模型隐式利用，没有显式任务相似性诊断；
  - 对无关任务或负迁移任务的鲁棒性未测试；
  - 对类别不平衡、开放集故障、新故障类别和跨域工况漂移的适应性仍不清楚；
  - 与深度多任务模型的对比较有限，且未纳入现代轻量 Transformer/CNN 或 domain adaptation 基线；
  - 高维矩阵、大任务数和大样本下二次规划求解成本可能成为瓶颈。
