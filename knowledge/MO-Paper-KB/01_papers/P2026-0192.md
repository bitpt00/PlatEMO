# Multiobjective Hierarchical Reinforcement Learning for Plant-Wide Optimization of Bayer Process

## 一句话理解

论文面向 Bayer 法氧化铝全流程优化，提出 MOHRL：上层多目标策略在月尺度优化产量和蒸汽消耗，并输出每日生产指标目标；下层通用策略在小时尺度决定各单元操作指标以跟踪目标；上层用分解式 MOHPG/D、population buffer 和 task-selection 在一次训练中得到对应不同市场需求的 Pareto policy set，并把原矿性质作为 context 输入以适应工况变化。

## 问题与动机

- 研究问题和场景：Bayer process 是大规模氧化铝生产流程，包含 milling、digestion、clarification、precipitation、calcination、evaporation 等单元；全流程优化需要最大化月产量、最小化 digestion/evaporation 蒸汽消耗，并协调多个时间尺度和单元过程。
- 现有方法为什么不足：
  - 单尺度优化只优化某一生产层级或单元过程，容易忽略其他尺度和单元之间的耦合，导致全局次优。
  - RTO/MPC 等模型方法依赖稳态和准确机理模型；Bayer 过程物理化学反应复杂，生产条件难以长期稳定，模型 mismatch 会降低效果。
  - MOEA 可做静态多目标优化，但对于动态工况和 sequential decision-making，每次工况变化后重新迭代成本高。
  - 既有 RL 工业优化多集中在单目标或单时间尺度；直接加权多目标只能训练预设偏好的单一 policy。
  - 传统 HRL 多面向游戏/机器人，不能直接处理 Bayer 过程的月-日-小时生产指标层级和多目标市场偏好。
- 本文希望解决什么：
  - 用 hierarchical MDP 把月尺度 production plan、日指标目标和小时 operational indices 连接起来；
  - 用下层 goal/context-conditioned universal policy 学习不同日目标和原矿性质下的操作指标跟踪；
  - 用上层 decomposition-based MORL 训练一组 Pareto policies，对应不同市场需求；
  - 在应用阶段根据实时状态和 raw ore context 在线决策，无需每次工况变化后重新优化。

## 核心理念与算法流程

- 核心理念：把 plant-wide optimization 拆成“上层目标规划 + 下层目标跟踪”的双时间尺度 HRL。上层 policy 关注月度产量/蒸汽消耗的多目标 tradeoff；下层 policy 作为通用执行器，接收上层 goal 和 raw ore context，按小时输出单元操作指标 setpoints，使实际日指标跟踪目标。
- Hierarchical MDP：
  - 上层 state `s=[p1,p2,p3]` 为日产量、digestion 蒸汽、evaporation 蒸汽；action/goal `g=[p1*,p2*,p3*]` 为下一天目标；context `c=[l1,l2]` 为原矿 alumina content 和 A/S ratio。
  - 上层 reward vector 包含月度 yield 最大化和两类 steam consumption 最小化，同时用 penalty 鼓励输出下层可达到的目标。
  - 下层 action `a=[o1*,...,o7*]` 为 digestion/precipitation/evaporation 的 C/A ratio 与 caustic concentration 目标；reward 是日指标与上层目标之间的跟踪误差，并对超限 action 加 penalty。
  - 应用阶段，上层每个下层 episode 开始输出一次日目标，下层在 `TL` 小时内连续输出操作指标；经历 `TH` 天构成一个上层 episode。
- MOHRL 训练流程：
  1. 用 TRPO 预训练下层 policy `mu_phi(a|s,g,c)`。每个 episode 随机采样 goal-context pair，并在 episode 内固定，形成局部 stationary MDP segment。
  2. 上层维护 task `(pi, omega)`，其中 `pi` 是 policy，`omega` 是 objective preference weight vector。
  3. Warm-up stage 随机初始化 `n` 个上层 policies 和均匀 weight vectors，运行 MOHPG/D 得到初始 offspring。
  4. Evolutionary stage 中，先把 offspring 插入 population buffer 和 external Pareto archive，再由 task-selection 选出下一批任务。
  5. Population buffer 将 objective space 按 reference vectors 分 bin，每个 bin 保留距离 reference point 表现较好的少量 tasks，保证 convergence 和 diversity。
  6. Task-selection 每代随机生成 `nnew` 个新 weight vectors，并从 population 中挑选 weighted scalar value 最大的 policy 与新权重配对；其余任务随机从 population 选取。
  7. MOHPG/D 对每个 task 用 weighted policy gradient 更新上层 policy；每个 objective 的 advantage function 分别估计，使同一 policy 可用不同 weight vector 继续训练。
  8. 终止后输出 external Pareto archive EP 中的 non-dominated policies，供决策者按市场需求做 posterior decision making。
- 可能被修改的位置：
  - 下层 TRPO 可替换为 PPO、SAC、TD3、model-based RL 或 safe RL；
  - 上层分解权重可替换为 preference-conditioned policy、hypernetwork、Pareto set learning 或 constrained MORL；
  - population buffer 的 bin 策略可替换为 HV contribution、novelty、uncertainty 或 trust-region coverage；
  - raw ore context 可扩展为市场价格、设备健康、库存、扰动预测、质量约束等。
- 必须保留的核心：
  - 多时间尺度层级：上层输出可执行目标，下层负责短尺度跟踪；
  - 下层 policy 必须以 goal 和 context 为输入，否则无法成为上层不同目标的通用执行器；
  - 上层必须保留 Pareto policy set，而不是只训练单一加权 policy；
  - context 作为 policy input 用于工况自适应，避免每次工况变化重训。

## 实验证据

- 仿真环境建模：
  - 使用山西省 Huaxing Alumina Refinery 的 18 个月 546 组实际生产数据构造 Bayer process simulation environment。
  - 用 430 组训练、116 组测试，训练三个 `12-64-1` 单隐藏层 ReLU feedforward neural networks 近似日产量、digestion steam、evaporation steam 的动态关系。
  - 三个模型测试 RMSE 分别为 128.21、6.04、2.93，作者据此认为模型可近似 Bayer process dynamics。
- 上层月度多目标优化：
  - 对比五个 MORL baselines：Radial Algorithm (RA)、RANDOM、MOEA/D-based MORL、PG-MORL、Meta-MORL；每个 baseline 都扩展为同一 hierarchical structure。
  - 下层 policy 先预训练 `1e4` iterations；每个算法 5 个随机种子；policy networks 为两层 64 hidden nodes、tanh；每次 policy gradient 采样 200 episode trajectories。
  - 指标：external Pareto archive 中 non-dominated policies 数量 (ND) 和 HV；HV 每 200 iterations 用 100 episodes 评估并归一化。
  - 结果：MOHRL 的 HV learning curve 最终优于五个 baselines，最终 PF 在 convergence 与 diversity 上更好；同时获得相对较多 non-dominated policies，给决策者更多 tradeoff choices。
  - 机制解释：RA/MOEA-D 固定 weight vectors 早期上升快但后期 diversity 不足；RANDOM PF 较密但很多 policies 优化不充分；PG-MORL 难准确预测 time-varying coupled relationships 下的 policy improvement；Meta-MORL 的单个 meta-policy 难保证 PF diversity。
  - 五种 raw ore properties 下的 PF 显示，不同 market demands 对应的 policies 能根据 raw ore operating conditions 做决策。
- 下层在线决策：
  - 从 Pareto policy set 选取 weight vector `[0.25,0.25,0.50]^T` 的上层 policy，模拟一个月生产过程。
  - 上层 policy 输出 daily production target values，下层 policy 每两小时决定 operational indices，使实际日指标跟踪目标；三项日指标跟踪 RMSE 为 167.10、184.32、172.08。
  - Context 消融：在不同 alumina content 和 A/S ratio 组合下，带 context policy 的平均 RMSE 为 226.32、270、124.08；无 context policy 为 379.2、430.96、192.24。作者认为 context input 能显著提升 raw ore 变化下的目标跟踪。
- 证据边界：
  - 仿真环境由神经网络近似真实过程，不是在线真实工厂闭环试验。
  - 只考虑 raw ore properties 作为周期可测 context，尚未处理突发 disturbances 和 uncertainties。
  - 上层目标为三维，作者未来仍需研究高维 production indices 的 MORL。

## 局限与未来工作

- 作者明确说明的局限：
  - MOHRL 还不能同时解决 plant-wide optimization 中所有挑战。
  - 当前只考虑 periodically measurable environmental context，对 unexpected variations、uncertainties 和 disturbances 的补偿不足。
  - 是否协调优化 lower-layer unit processes 还能进一步提升 overall performance 尚未研究。
- 作者未来工作：
  - 发展更先进 MORL 以优化 higher-dimensional objectives，引入更多 production indices。
  - 在框架中加入补偿 unexpected variations、uncertainties 和 disturbances 的机制。
  - 研究 lower-layer unit processes 的协同优化是否进一步提升全流程性能。
- 我们认为仍需确认的问题：
  - 仿真模型误差会如何影响 policy learning 和实际部署安全性。
  - Posterior decision making 被排除在本文范围外，但实际生产需要将 PF policies 映射到市场需求和风险偏好。
  - TRPO/on-policy 采样成本在真实工业系统中是否可承受。
  - 下层 policy 假设自动化系统可跟踪 setpoints，未讨论底层控制器故障或约束冲突。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：多时间尺度目标分解的多目标分层 RL。该知识可迁移到矿物加工、化工、能源、供应链和大型制造系统的 plant-wide optimization。
- 暂留在论文卡中的方法、原理或架构启发：
  - Bayer-specific 变量、反应机理和指标范围属于应用上下文，不单独建场景卡。
  - 使用 `12-64-1` NN 近似工艺动态是仿真实现细节，不升级为通用代理知识。
- 局部创新线索：
  - 用 preference-conditioned upper policy 或 hypernetwork 替代多个独立 upper policies，减少 policy population 存储。
  - 将 lower-layer context 扩展到设备状态、库存、价格和扰动预测。
  - 用 offline RL/safe RL 限制工业数据外推，避免 policy 在未见工况下输出危险 setpoints。
  - 在 population buffer 中加入 HV contribution 或 uncertainty，替代简单 reference-vector bin。
- 结构创新线索：
  - 构建“长周期 Pareto policy planner + 短周期 goal-conditioned controller + context monitor”的工业多目标决策架构。
  - 将 MOHRL 与 MPC/RTO 混合：RL 生成可行目标与策略，MPC 保证底层短时约束和安全。
