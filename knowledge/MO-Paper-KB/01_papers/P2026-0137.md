# Q-learning-based multi-objective hyper-heuristic algorithm for multi-campus university course scheduling

## 一句话理解

本文把多校区大学排课建成三目标组合优化问题，并提出 MO-QL-HH：用 Q-learning 高层策略按当前解的目标状态选择 10 个低层启发式算子，在随机探索算子和面向通勤、教室、课时偏好的贪婪算子之间自适应切换。

## 问题与动机

- 研究问题和场景：multi-campus university course scheduling problem (MCUCSP)，同一大学多个校区共享教师资源，需要安排课程、教室、时间、周次和校区。
- 多目标模型关注三个目标：
  - `TT`：跨校区教师通勤时间；
  - `CU`：课程安排中使用的教室数量；
  - `CCI`：综合课时指标，包含夜间课时、教师偏好、课程适宜时段和同日过多课时等因素。
- 现有研究为什么不足：
  - 多数 UCSP 研究聚焦单校区，忽略跨校区教师通勤疲劳和同日跨校区教学约束；
  - 多数模型把软约束加权成单目标，权重主观且会压缩目标空间，难表达教师福利、资源效率和教学质量之间的 trade-off；
  - exact methods 难扩展到大规模排课；
  - 固定元启发式或固定局部搜索不能随搜索状态动态选择合适的排课修改算子。
- 本文希望解决什么：构建显式考虑多校区通勤的多目标排课模型，并用 Q-learning hyper-heuristic 自动调度领域启发式算子，提升 Pareto 解集的收敛、多样性和约束可行性。

## 核心理念与算法流程

- 核心理念：把“如何修改一张可行课表”交给领域低层启发式，把“当前该用哪种修改方式”交给 Q-learning。随机算子提供全局扰动，贪婪算子定向改善夜间课、同日重复课、教师偏好、课程时段、跨校区通勤和教室利用。
- 编码与解码：
  - 单个排课个体由课程任务、校区、教室、timeslot、执行周次和安排顺序构成；
  - 解码时逐层验证校区、教室类型、容量、教师/班级/教室时段冲突、周次和跨校区约束；
  - 低层启发式执行后通过 repair 保证硬约束可行。
- 贪婪初始化：
  1. 对课程任务计算 difficulty score，主要由班级数量和课时数决定；
  2. 高难任务优先安排，降低后续回溯风险；
  3. 在满足教室类型和容量的前提下优先复用已使用教室，降低教室碎片化；
  4. 随机遍历 timeslot 并检查教师、班级、教室和跨校区冲突。
- Q-learning 高层策略：
  - State：将当前解三个目标值按 reference point 归一化并离散到 0-3，形成目标状态向量；
  - Action：10 个 LLH 算子；
  - Policy：`epsilon`-greedy，在探索和当前最大 Q 值动作之间选择；
  - Exploration decay：根据最近 10 代 HV 停滞情况调整 `epsilon`，并限制在上下界内；
  - Reward：根据动作前后每个目标相对 reference point 的改善计算总奖励；
  - Update：用 temporal-difference 公式更新 Q-table。
- 低层启发式算子：
  - 随机探索算子 `LLH1-LLH4`：course swap、course move、campus swap、timeslot swap；
  - 贪婪开发算子 `LLH5-LLH10`：evening adjustment、same-class over-scheduling dispersion、teacher preference optimization、course-period adaptation、cross-campus commute reduction、classroom utilization minimization。
- MO-QL-HH 主流程：
  1. 用贪婪初始化生成 population，并更新 Pareto front；
  2. 初始化 Q-table；
  3. 每代对每个个体提取状态，选择 LLH action；
  4. 执行动作、解码并 repair；
  5. 根据目标改善计算 reward 并更新 Q-table；
  6. 更新 Pareto front；若未改善，则按探索概率保留新解或从 PF 重采样精英；
  7. 根据 HV 停滞调整探索率，直到最大迭代数。

## 实验证据

- 实验设置：
  - 20 个多校区实例，基于广西民族大学人工智能学院课程开设计划构造；
  - 校区数为 2-6，课程任务数为 100、200、350、500，学期 16 周；
  - 对比算法：NSGA-II、MOEA/D、NSGA-III、SPEA2、MOEA/D-AAWNs、HGTSA；
  - 所有对比算法使用相同编码解码、初始化和 heuristic operators；
  - 每个算法每实例独立运行 10 次，100 iterations；
  - 指标：HV、IGD、C-metric、CPU runtime。
- 参数实验：
  - 对 population size `PS`、learning rate `alpha`、discount factor `gamma` 做 full factorial design；
  - 每个任务规模执行 `4^3=64` 个参数组合，每组运行 10 次，以 HV 为 response；
  - ANOVA 显示 `PS` 在所有规模上极显著，`alpha` 和 `gamma` 在多数情况下也显著；500 任务规模下参数交互显著，说明需要考虑参数协同。
- 与对比算法结果：
  - HV：MO-QL-HH 在 20 个实例中除 Instance 17 外均取得最佳均值；
  - IGD：MO-QL-HH 在除 Instance 16、17、20 外的实例上取得最佳均值；
  - C-metric：MO-QL-HH 相对 HGTSA 在 95% 实例占优，相对 NSGA-II、MOEA/D、NSGA-III、SPEA2、MOEA/D-AAWNs 在所有实例占优；
  - CPU：NSGA-II 平均最快，MO-QL-HH 平均时间排名第五，说明质量提升伴随额外计算开销。
- 消融实验：
  - A1 为完整 MO-QL-HH，A2 去掉 greedy operators，A3 去掉 random operators；
  - A1 在 HV 和 IGD 的所有实例平均结果中最优；
  - C-metric 中 A1 相对 A2 在 85% 实例占优，相对 A3 在 100% 实例占优；
  - A1 平均 CPU runtime 低于 A2 和 A3；
  - 收敛曲线显示完整随机+贪婪算子组合在多个规模上更快、更稳定。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前模型是静态、确定性排课环境，不处理教师临时缺勤、教室不可用等动态扰动；
  - 随校区数和课程任务数继续增大，MO-QL-HH 的求解效率和资源消耗会面临更大挑战。
- 作者未来工作：
  - 用 rolling-horizon optimization 等实时重排策略处理动态扰动；
  - 加入学生通勤时间、课程先修关系等更多实际约束；
  - 与 deep reinforcement learning 结合，用函数近似替代大状态空间 Q-table；
  - 在更大规模实例和考试排程、护士排班等其他 timetabling 域验证。
- 我们认为仍需确认的问题：
  - 真实多校区排课中学生跨校区流动、教师偏好公平性和行政班冲突是否需要独立目标；
  - Q-table 状态只离散目标值，是否足以表达约束紧张度、校区结构和当前 Pareto 区域；
  - 所有对比算法使用相同 LLH 时，收益主要来自 Q-learning 调度还是 Pareto 更新/重采样策略；
  - 数据可用性声明与实例仓库链接应进一步核对。

  - 低层算子最好按“随机扰动 + 目标定向贪婪修复”成组设计；
