# Dynamic Constrained Multiobjective Evolutionary Algorithm With Multipopulation Prediction and Dynamic Fusion Ranking

## 一句话理解

本文提出 MP-DFR：把动态约束 MOO 中的 PS 预测转化为 CPD 点集配准后的个体轨迹预测，并分别为主/辅种群生成任务专属初始种群，再用动态融合双排序提升辅助种群在历史经验和当前约束搜索之间的切换效率。

## 问题与动机

- 研究问题和场景：Dynamic constrained multiobjective optimization problems (DCMOPs)，目标和/或约束随时间变化，算法需要在每个环境快速跟踪 dynamic constrained Pareto set/front。
- 现有算法为什么不足：
  - 多数 DMOP 方法忽略约束变化，不能直接处理 DCMOP；
  - DCMOP 中可行域会随时间移动或变形，简单中心预测难以捕捉复杂 PS manifold；
  - 个体级预测需要正确匹配相邻环境中的同一“轨迹”，匹配错误会导致预测方向错误；
  - 双种群/多种群 DCMOEA 往往给不同任务使用相似或随机初始种群，没有充分利用每个任务自己的历史信息；
  - EDT-1 这类历史相似环境辅助任务依赖 SCPF 与当前 CPF 的相似性，后期可能偏离当前主任务。
- 本文希望解决什么：提高 DCMOP 中新环境初始种群预测精度，并让主种群的可行性搜索和辅种群的快速收敛搜索更稳定协同。

## 核心理念与算法流程

- 核心理念：用 CPD 在相邻环境的解集之间建立对应关系，把“动态 PS/PF 预测”变成“点集配准 + 个体运动方向外推”；同时为主任务和辅助任务维护不同历史档案，使两类种群在环境变化后从不同分布起步。
- 主要流程：
  1. 初始化两个规模为 `N/2` 的种群，环境稳定时分别生成 offspring。
  2. 变化检测器每代重评估 10% detector individuals，若目标或约束值变化，则触发动态响应。
  3. 当历史环境少于 2 个时随机生成两类初始种群；否则用 RMTT 分别预测主种群、辅种群和下一环境 CPF。
  4. 主种群 `Pop1` 以寻找当前 CPF 为任务，用 CDP-based environmental selection。
  5. 辅种群 `Pop2` 以快速穿越 infeasible regions 和逼近潜在 CPF 为任务，用 DFTR-based environmental selection。
  6. 每代在 `TP1 union TP2` 中记录 `CPOP_t` 和 `UPOP_t`，分别作为后续主/辅种群预测档案。
  7. 用 RMTT 预测各历史环境 CPF，再通过 PSEI 找到最相似历史 CPF，供辅助种群 EDT-1 排序使用。
- 关键组成部分：
  - RMTT：CPD 对齐相邻时间点的解集，构造个体方向矩阵，再用 first-order dynamic prediction 预测下一时间点。
  - Task-specific archives：`CPOP` 存储 constrained nondominated solutions，服务主种群；`UPOP` 存储 unconstrained nondominated solutions，服务辅种群。
  - Predicted CPF + PSEI：用预测 CPF 而非原始历史 CPF 识别最相似环境，降低动态错配。
  - DFTR：对辅种群同时用 improved epsilon-relaxation 和 EDT-1 排序，将一致保留/删除的个体直接处理，对冲突个体按随代数变化的权重分配名额。
- 可能被修改的位置：
  - CPD 可替换为 optimal transport、graph matching、manifold registration 或 learned correspondence；
  - first-order dynamic prediction 可替换为二阶趋势、Kalman filter、局部 surrogate 或时序模型；
  - `CPOP/UPOP` 可扩展为多个任务档案，如边界不可行、低 CV、高 diversity 或特定约束档案；
  - DFTR 的时间权重可改为基于预测误差、可行率、HV/IGD 改善或历史贡献的自适应权重。
- 必须保留的核心：环境变化后不能只做全局中心平移；需要先建立跨环境个体对应关系，再按任务分别预测不同初始分布；辅助种群选择也必须同时考虑历史相似环境经验和当前约束趋近。

## 实验证据

- 测试问题和对比算法：
  - Benchmarks：DCF1-DCF10 与 DCP1-DCP9，共 19 个动态约束双目标问题，覆盖目标变、约束变、目标约束同时变三类动态。
  - 动态设置：`nt` 为 5 或 10，`tau_t` 为 30 或 50，共 76 个场景；`N=100`，`D=100`，20 次独立运行。
  - 对比算法：DCNSGA-IIA、DCNSGA-IIB、DC-MOEA、dCMOEA、mEDCMOA、TDCEA、HATC、SKTEA。
  - 指标：MIGD、MHV、MFSR，配合 Wilcoxon rank-sum、multiple-problem Wilcoxon signed-rank 和 Friedman rank。
- 主要实验结论：
  - MIGD：MP-DFR 在 76 个场景中取得 31 个 best；相对八个对比算法显著优于的场景数分别为 63、55、67、61、70、68、38、57。
  - MHV/MFSR：总体优于或至少可比，作者认为双任务种群提升 diversity，CDP 与 improved epsilon-relaxation 提升 feasible region 捕捉能力。
  - 多问题统计：MIGD 与 MHV 的 multiple-problem Wilcoxon `p` 值均低于 0.05，且 Friedman ranking 中 MP-DFR 在 MIGD/MHV 上平均排名最好。
  - CPU-time：由于 CPD 个体对应有额外开销，MP-DFR 比部分算法慢几秒，但在 `tau_t=5, nt=30` 下仍能在半分钟内完成并取得较好性能。
  - Raw ore allocation：在矿石分配真实案例中，MP-DFR 在不同变化严重度和 MFSR/MHV 指标上取得最好或第二好结果。
- 消融或机制证据：
  - RMTT 精度：相对 MP-LPM，MP-DFR 在 39/76 个 MIGD 场景显著更好、10 个更差；相对 MP-CGLP，28/76 个更好、19 个更差。
  - RMTT 边界：DCF1 和 DCF8 上中心点轨迹比单个体轨迹更能捕捉 CPS，因此 MP-DFR 的优势减弱。
  - 任务专属双种群预测：MP-DFR 相对双种群都随机初始化的 MP-Rand12 在 47/76 个场景更好、16 个更差；只预测一个种群介于二者之间。
  - DFTR：相对只用 EDT-1 或只用 improved epsilon-relaxation，MP-DFR 分别在 36 和 34 个场景显著更好，均只有 19 个场景更差。
- 证据边界：
  - 主要 benchmark 为动态约束 bi-objective，many-objective 和混合变量证据不足；
  - 结果表大量为图片占位，当前卡片记录正文统计结论而非逐项数值；
  - RMTT 依赖相邻环境存在可配准的解集对应关系，若中心轨迹更稳定或环境剧烈随机变化，个体级配准可能不占优。

## 局限与未来工作

- 作者明确说明的局限：
  - CPD 带来额外计算成本；
  - RMTT 强调单个体轨迹，在 DCF1、DCF8 等中心轨迹更能刻画 CPS 的问题上不一定最好。
- 作者未来工作：正文结论未给出非常具体的未来模块方向，主要总结 MP-DFR 在 benchmark 和真实案例中的优势。
- 我们认为仍需确认的问题：
  - CPD 在高维决策空间、many-objective、强噪声或多模态 POS 中的对应关系是否稳定；
  - `w=floor(tau/tau_t)` 形式的 DFTR 时间权重是否应归一化或改为反馈驱动；
  - `CPOP/UPOP` 两档案能否扩展到约束边界、低 CV 不可行解或多个历史模态；
  - 若相邻环境个体数、可行率或 CPF 拓扑差异很大，点集配准是否需要 outlier/partial matching 机制。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“配准轨迹跟踪的任务专属动态约束预测”，因为它把 CPD 个体配准、主/辅任务档案预测、预测 CPF 相似环境识别和 DFTR 组合成可直接移植的 DCMOEA 变化响应与辅助选择框架。
- 暂留在论文卡中的方法、原理或架构启发：
  - DCMOP 中“预测谁”比“用什么预测器”同样重要；主任务应预测 CPS 附近，辅任务应预测 UPS/UPF 附近。
  - 历史相似环境不应直接拿当前历史 CPF 比较，而可先预测到当前时间再比较。
  - 辅助任务早期可更相信历史经验，后期应逐渐回到当前约束和可行性判断。
- 局部创新线索：
  - 将任意 DMOEA 的中心预测替换为 CPD/OT 个体对应预测；
  - 在已有双种群 CMOEA 中加入 `CPOP/UPOP` 双档案动态初始化；
  - 把 DFTR 的双排序融合用于其他辅助种群选择，如 EDT + CV、UPF distance + feasibility 或 reference-vector history + CDP。
- 结构创新线索：
  - 构建“变化检测 -> 任务档案选择 -> 个体配准预测 -> 预测 CPF 找历史任务 -> 双排序辅助选择”的 DCMOEA 响应层；
  - 与策略池结合：配准预测处理形状连续变化，中心预测处理整体平移，随机/边界档案处理强不确定变化。
