# P2026-0093 - A large-scale multi-objective optimization algorithm integrating multi-directional fuzzy sampling and multi-source learning competitive swarm optimizer

## 一句话概括

本文提出 LSMDCSO，用 APD 选择代表解作为锚点，在大规模决策空间中构造梯度、边界和正交多方向模糊采样候选，再用多源学习 CSO 做细粒度 refinement，以缓解方向采样稀疏、后期精度不足和高维多样性退化问题。

## 研究问题

大规模多目标优化中，决策变量维度远大于目标数，目标空间中的少量方向很难在高维决策空间中充分穿过真实 PS。已有方向采样方法虽然高效，但常依赖少量代表解或单一线性方向，容易出现搜索方向稀疏、PF 覆盖不足和后期收敛精度不够。

作者认为仅靠变量分组会消耗大量评价，降维/变换方法可能损失原问题信息，而单纯新型搜索算子在超大规模和有限计算资源下效率下降。因此本文设计了 LSMDCSO，把方向采样的粗粒度全局搜索与 CSO 的细粒度局部开发组合起来。

## 方法核心

### LSMDCSO 总体框架

每代流程如下：

1. 初始化或维护当前种群 `P`。
2. 用 APD 从当前种群中选择代表解集合 `RS`。
3. 当 `FEs / MaxFEs < 0.8` 时执行 MDFS，生成采样候选 `SamplePop`，并用 SPEA2 truncation 环境选择更新种群。
4. 每一代都执行 MLCSO，用代表解和竞争学习进一步生成 offspring。
5. 将 offspring 与当前种群合并，再用 SPEA2 truncation 做环境选择。

该设计把 MDFS 作为前中期的方向采样层，把 MLCSO 作为全程 refinement 层。

### APD 代表解选择

LSMDCSO 先生成 `Nr` 个目标空间参考向量，把个体按与参考向量的最小夹角分配到子区域。每个子区域内选择 APD 最小的个体作为代表解；空子区域则从剩余个体中选择角度最小个体补充。APD 的作用是动态平衡收敛和多样性：早期更强调靠近 PF，后期更强调方向覆盖。

### MDFS 多方向模糊采样

MDFS 将采样方向分为两类，并以 0.5 概率选择执行：

| 采样类型 | 方向构造 | 作用 |
|---|---|---|
| 收敛采样 | 近似梯度方向 `GV` + 决策边界方向 `BV` | 用梯度近似提升局部收敛，用边界方向维持全局探索 |
| 多样性采样 | 代表解两两配对方向 `DV` + 正交方向 `DV^O` | 在代表解之间和侧向正交方向扩展搜索，缓解方向稀疏 |

梯度估计使用 simultaneous perturbation gradient estimator, SPGE。相比普通有限差分，SPGE 对高维函数只需两次函数评价即可估计方向，降低维度带来的评价开销。

收敛采样中，用比例因子 `phi` 在边界方向和梯度方向之间分配采样数量，使总采样数保持为 `Nr * Ns * 2`，不额外扩大评价预算。多样性采样中，代表解随机分成两组并配对，构造主方向和与之正交的补充方向，再进行双向采样。

采样后的解经过 FVO fuzzy variable operator。FVO 随进化推进逐步降低 fuzziness，使搜索从早期粗粒度探索过渡到后期细粒度开发。

### MLCSO 多源学习竞争群优化

MLCSO 针对传统 LMOCSO 的两个问题做改造：随机配对缺少全局质量视角，单一 loser 向 winner 学习会限制信息来源。

MLCSO 的做法是：

- 每代先用 SDE 计算个体质量。
- 以 0.5 概率采用全局排序配对：SDE 排名前 50% 为 winner set，后 50% 为 loser set，再随机配对。
- 以 0.5 概率保留传统随机配对，用于维持探索。
- loser 按 CSO 公式向其配对 winner 学习，产生一半候选。
- 从每个配对中随机选一个学习者组成 `LE`，再随机选择一个 APD 代表解作为 `Best` 引导，产生另一半候选。
- `P ∪ P1 ∪ P2` 经环境选择得到输出。

这样同时利用局部 winner、全局质量分层和代表解多源引导，补偿方向采样候选在后期精度上的不足。

## 复杂度

论文给出每代复杂度：

`O(N * Nr * M + Nr * Ns * M * D + N * D + N^2 * M)`

其中 APD 代表解选择为 `O(NNrM)`，MDFS 主要为 `O(NrNsMD + ND)`，MLCSO 为 `O(ND + N^2M)`，环境选择为 `O(N^2M)`。

## 实验设置

| 项目 | 设置 |
|---|---|
| 基准 | LSMOP1-9, ZCAT1-20, TREE1-5 |
| 目标数 | LSMOP/ZCAT: 2 和 3；TREE: 2 |
| 决策维度 | LSMOP/ZCAT 最高 10000；TREE1-2 为 3000，TREE3-5 为 6000 |
| 对比算法 | DGEA, FDV, FLEA, IMTCMO_BS, LERD, LMOCSO, LSMOF, LMOEA-DS |
| 指标 | IGD, HV；TREE 无真实 PF，使用 HV |
| 平台 | PlatEMO |
| 重复次数 | 每个问题 20 次独立运行 |
| 统计检验 | Wilcoxon rank-sum test, 0.05 significance level |
| 主要参数 | `N=100`, `MaxFEs=80000`, `phi=0.7`, `Nr=M+10`, `Ns=30` |

## 主要结果

在 3 目标 LSMOP1-9 上，LSMDCSO 在大多数函数和维度上取得最优 IGD；主要例外是多峰问题 LSMOP3 和 LSMOP7，其中 LSMOF 或 IMTCMO_BS 在个别场景更好。2 目标 LSMOP 上，LSMDCSO 在 LSMOP1、2、3、4、9 上显著优于对比算法。HV 结果也显示 LSMDCSO 在多数 LSMOP 上保持优势。

在 ZCAT 上，LSMDCSO 表现最强。3 目标 ZCAT 的表 5 中，所有 8 个对比算法相对 LSMDCSO 的 `+/-/=` 均为 `0/80/0`；2 目标 ZCAT 的表 6 中也均为 `0/40/0`。正文认为 LSMDCSO 在所有测试 ZCAT 问题上获得最优 IGD/HV 和较小标准差。

在真实 TREE 问题上，LSMDCSO 在 TREE1、TREE2 上取得最高 HV；在 TREE3-TREE5 上与 LSMOF、LMOEA-DS 或 IMTCMO_BS 接近或可比。FDV 和 LMOCSO 在 TREE3-TREE5 上部分无法得到可行解，突出 LSMDCSO 的鲁棒性。

运行时间方面，LSMDCSO 在 1000 维时比轻量算法更耗时，但在 10000 维时相对 DGEA 和 IMTCMO_BS 表现出更好扩展性；虽然仍慢于 LSMOF、LMOEA-DS、FLEA 等采样方法，但在同一数量级内。

## 消融与参数分析

消融包括移除 APD 代表解、收敛采样、多样性采样、梯度/正交方向、FVO、MLCSO 和替换为 LMOCSO。结果显示：

- 移除收敛采样的 LSMDCSOnCV 退化最严重，在 18 个 LSMOP 测试实例上全部最差。
- LSMDCSO 相比随机方向版本 LSMDCSOods 在 15 个问题上显著更好，说明梯度和正交方向有效。
- 移除 FVO 后在 14 个问题上退化，说明模糊粒度调节有贡献。
- 移除 APD 代表解后在 16 个实例上退化，说明代表解质量影响采样方向。
- LSMDCSO 在超过半数测试问题上显著优于移除或替换 MLCSO 的版本，说明多源竞争细化有贡献。

MDFS 还被嵌入 IMTCMO_BS 和 LMOEA-DS 两个算法。增强后算法在至少半数 LSMOP 问题上显著优于原算法，说明 MDFS 不是只依赖 LSMDCSO 主体。

参数 `phi` 从 0 到 1 扫描，`phi=0` 仅用梯度方向表现最差，`phi=1` 仅用边界方向也不是最优；`phi` 在 `[0.6,0.8]` 稳定，`0.7` 平均排名最好。`Nr` 太大增加方向构造成本且未必提升多样性，最终取 `Nr=M+10`；`Ns` 从 10 增至 30 有收益，超过 30 后改进趋于饱和且可能浪费评价，最终取 `Ns=30`。

## 局限性

1. 极端崎岖或欺骗性景观中，近似梯度方向可能不可靠。
2. 不规则或断裂 PF 会影响代表解选择稳定性。
3. 超大维度下仍可能受到内存和评价预算瓶颈约束。
4. 论文尚未验证 constrained、dynamic、many-objective 场景。

## 证据边界

实验覆盖连续无约束 LSMOP/ZCAT/TREE，目标数主要为 2-3，最大决策维度为 10000。对离散、混合变量、强约束、动态和 many-objective 问题，需要重新设计方向修复、采样预算和代表解选择机制。
