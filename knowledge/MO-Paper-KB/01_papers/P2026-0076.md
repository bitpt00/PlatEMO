# ISDE+MBO：用 Markov Blanket 依赖结构指导反事实后代生成

## 一句话理解

论文不把因果性继续增加为优化目标，而是先用 Markov Blanket 发现与预测目标相关的特征组，再让进化算法只在随机选中的相关特征组内变异，以三目标优化生成有效、接近原样本且位于数据分布附近的反事实解释。

## 研究问题与场景

- 场景：为黑盒分类模型生成反事实解释（Counterfactual Explanation, CE），回答“需要改变哪些特征、改变多少，才能使模型输出变为目标类别”。
- 决策变量：从原始测试实例出发构造的候选反事实样本。
- 核心要求：
  - 预测结果翻转到目标类别；
  - 与原实例尽可能接近；
  - 不成为数据分布外的异常点；
  - 改动特征少、逻辑关联合理，并能给用户多个替代方案。
- 应用示例：信用审批行动建议、医疗决策解释和 COMPAS 风险模型偏差审计。
- 核心困难：数学上能翻转预测的特征组合不一定符合现实依赖关系，也不一定真正可行动。

## 动机链

1. 最近邻式 CE 通常隐含假设特征相互独立，因此可能给出统计上或现实中不连贯的修改建议。
2. SCM 式因果反事实能够表达干预及下游影响，但依赖预先给定且准确的因果模型，在复杂高维场景中难以获得。
3. 多目标 CE 可同时优化有效性、距离、稀疏性、合理性等要求，但为每个 desideratum 设置目标会增加目标冗余，仍不能保证搜索落在依赖关系合理的区域。
4. Markov Blanket 能识别与目标变量条件相关的局部特征集合。
5. 因此，作者不把“因果性”作为额外目标，而是把发现的局部结构直接嵌入后代生成和变异算子，用搜索过程本身限制候选解结构。

## 三目标问题定义

### 目标 1：翻转结果

```text
o_outcome(f(x'), Yc) = 1 - P(Yc)
```

- `x'` 是候选 CE，`Yc` 是目标类别。
- 最小化该目标会提高模型将 `x'` 判为目标类别的概率。

### 目标 2：最小修改距离

```text
d_cat  = changed categorical features / number of categorical features
d_cont = mean_k |x_k - x'_k| / feature_range_k
o_dst  = d_cat + d_cont
```

- 分类特征距离统计变更比例。
- 连续特征使用按范围归一化的 Manhattan 距离。

### 目标 3：可行性 / 分布合理性

- 作者称使用 Gaussian Process（GP）建立数据分布模型，并用候选 CE 的 log-likelihood 表示 plausibility。
- Eq. (8)-(9) 将其写成高斯预测分布下的对数似然。

### 优化方向矛盾

- 正文明确说应最大化 log-likelihood，使 CE 更可能来自数据分布。
- Eq. (10) 却把 `o_plau` 与另外两个目标一起最小化，也没有写负号。
- 若严格按公式执行，最小化 log-likelihood 会偏向更不合理的低似然样本。
- 我们的判断：实现很可能使用了负对数似然或相反方向，但论文公式未说明，属于核心复现歧义。

## 核心理念与算法流程

### 整体框架

- 基础优化器：指标型多目标算法 `ISDE+`。
- 新增结构：
  - 改进的 Simultaneous Markov Blanket（STMB）发现与目标相关的 PC 和 Spouse 特征；
  - 将 PC 与对应 Spouse 组织成依赖特征组；
  - EPMB 变异为每个个体随机选择一个特征组，只在组内执行 Fast Evolutionary Programming 式变异。
- 选择机制仍使用 `ISDE+` 指标和环境选择。

### 算法流程

1. 用训练数据训练分类模型和 GP 模型。
2. 以类别标签为目标节点，运行修改后的 STMB：
   - 用条件独立性检验识别 Parent/Child（PC）集合；
   - 发现与 PC 关联的 Spouse；
   - 清理假阳性；
   - 保存 PC 与 Spouse 的映射字典 `A`。
3. 随机初始化候选 CE 种群并计算三个目标。
4. 每代对每个个体随机抽取 `A` 中一个依赖特征组。
5. 仅对该组中的维度执行自适应 Cauchy 变异，其他特征保持不变。
6. 评价新后代，以 `ISDE+` 指标执行环境选择。
7. 输出最终反事实解集，为一个用户同时提供多个替代行动路径。

## 关键组成部分

### 修改后的 STMB 与依赖特征组

- Markov Blanket 由目标节点的 Parents、Children 和 Spouses 构成。
- 作者不区分 PC 节点究竟是 Parent 还是 Child，而是保留 PC 与 Spouse 的关联。
- 文中示意结构为 `P -> T -> C <- S`，并随机组合这些局部链形成每个后代可修改的特征模板。
- 该模板把搜索从“任意维度组合”缩小为“一个局部依赖组中的维度组合”。

### EPMB 因果变异

对每个个体：

```text
k <- random dependency-group key
S <- A[k]
for j in S:
    x'_ij = x_ij + eta_ij * delta_j, delta_j ~ Cauchy(0,1)
    eta'_ij = eta_ij * exp(tau1 * G_i + tau * g_ij)
```

- Cauchy 扰动提供较长尾的探索步长。
- 自适应策略参数控制各维变异尺度。
- 仅改变选定组中的维度，使后代天然稀疏并减少不相关修改。

## 实验设置

- 数据集：German Credit、Heart、Adult、Indian Diabetes、Ionosphere、Student Performance 和 COMPAS。
- 数据规模：270 至 48,842 个实例，8 至 33 个输入特征，同时覆盖连续和分类特征。
- 预处理：
  - 连续特征使用 z-score；
  - 分类特征使用 label encoding；
  - 训练/测试按 80:20 划分。
- 模型：ANN、SVM、Decision Tree、Random Forest 和 XGBoost。
- GP：Adult 和 COMPAS 的训练集超过 1000 时，随机抽取 1000 个训练实例拟合 GP。
- MOEA 对比：HypE、IBEA、NSGA-II、NSGA-III、RVEA、`ISDE+` 和 `ISDE+MBO`。
- 公平设置：PlatEMO、种群 100、最大函数评价 10,000、30 次独立运行。
- 指标：HV 均值和标准差、Wilcoxon signed-rank test、Friedman ranking。
- 硬件：3.50 GHz Intel Core i9、64 GB RAM。

## 实验证据

### Markov Blanket 发现结果

- Credit、Heart、Student 和 Ionosphere 的 MB 包含全部输入特征。
- COMPAS、Diabetes 和 Adult 分别排除 2、1、2 个非 MB 特征。
- 因此，论文中的稀疏性不主要来自“从整个 MB 中排除大量特征”，而更多来自每个后代只选用一个局部特征组。
- 作者通过 Credit、Adult 和 COMPAS 的关系图及领域直觉解释依赖结构，但没有真实因果图作为定量正确性基准。

### MOEA 综合性能

- 在 7 个数据集 × 5 个分类器形成的 35 个问题中，`ISDE+MBO` 获得 26 个最佳平均 HV。
- 分数据集最佳问题数：
  - Credit、Heart、Diabetes：各 5/5；
  - COMPAS：3/5；
  - Adult：1/5；
  - Student：4/5；
  - Ionosphere：3/5。
- Friedman 综合排名中，`ISDE+MBO` 在 6/7 个数据集排名第一，Adult 数据集由原始 `ISDE+` 排名第一；总平均排名第一。
- 论文实验直接支持：依赖结构限制的变异在多数问题中显著改善 HV，但并非在所有模型和数据集上都更优。

### 消融实验

对比变体：

- 原始 `ISDE+ (GA)`；
- 仅让 GA 在 MB 特征组内操作的 `ISDE+ (GA+MBO)`；
- 使用 Fast Evolutionary Programming 但不使用 MB 的 `ISDE+ FEP`；
- 完整 `ISDE+MBO`。

主要证据：

- 完整 `ISDE+MBO` 的 Friedman 排名最高。
- 相比完整方法，原始 `ISDE+` 在 35 个问题中更差 22 次、更好 9 次、相似 4 次。
- `GA+MBO` 更差 21 次、更好 13 次、相似 1 次，说明仅限制特征组已有收益，但不是所有问题都改善。
- Table 13 中 `FEP` 的 Better/Worse/Similar 为 `8/15/12`；正文却写为更好 8、相似 13、更差 14，二者不一致。
- 我们的判断：消融支持“依赖特征组 + FEP 式变异”的组合价值，但各组件贡献并非压倒性稳定。

### 与 CE 方法的对比

- 对 CARE 和 CFM-FW，在 Diabetes、Credit、Heart 的 30 个实例上比较 validity、sparsity、diversity 和 runtime。
- 提出方法在 15 个“数据集×分类器”组合中均获得最高 validity，运行时间约 1.95-3.05 秒。
- 提出方法的 diversity 多数较高，但并非每项都最好。
- 提出方法的 sparsity 通常差于 CFM-FW，不能据 Table 14 声称同时全面优于其稀疏性。
- CARE 和 CFM-FW 的复现代码由 LLM Claude Code 实现；运行时间和失败率可能明显受复现质量影响，因此数个数量级的速度优势需要独立复核。

### 应用示例

- Credit 示例展示了调整贷款用途、金额、还款期限、抵押物和付款计划等多个可选建议。
- COMPAS 示例中，CE 通过改变性别或种族降低风险分数，从而暴露模型对敏感属性的依赖。
- 这些案例支持框架能够生成多样的候选路径和辅助偏差诊断，但不能证明所有建议都具有真实因果效果或现实可执行性。

## 关键正确性与复现风险

### Markov Blanket 不等于已验证的因果干预结构

- 作者明确表示算法不区分 PC 节点是 Parent 还是 Child，却使用有方向的“causal chain”解释结果。
- 仅凭观测数据和条件独立性，通常无法识别 Markov 等价类中的全部边方向。
- Spouse 与目标共享一个 Child，并不意味着改变 Spouse 会导致目标变化。
- 因此，更稳妥的解释是“局部条件依赖结构指导变异”，而不是已验证的因果行动路径。

### Algorithm 2 的独立性判断疑似写反

- Algorithm 2 第 9-10 行写为：若 `X` 与 `T` 在给定 `Z` 后不独立，则从候选 PC 集删除 `X`。
- 按 Markov Blanket 发现逻辑，通常应在发现条件独立时删除候选，而不是在发现依赖时删除。
- 若论文符号和伪代码按字面执行，PC 发现逻辑会反向。

### Algorithm 2 与 Algorithm 3 的映射接口不一致

- Algorithm 2 将 `A[X]` 更新为包含 `Y`，其中循环中的 `X` 是 Spouse、`Y` 是 PC。
- Algorithm 3 却称随机字典键 `k` 对应 PC，并令 `S=A[k]` 获得 PC 与 Spouse 子集。
- 按伪代码字面，键的角色相反，而且 `S=A[k]` 未显式包含键本身，不能保证完整依赖组均被变异。

### GP plausibility 定义不清

- 论文称使用 GP 回归建立输入数据分布，但没有说明 GP 的回归目标是什么。
- Eq. (9) 又退化为逐特征均值和方差的高斯似然形式，与具有 RBF 核的 GP predictive distribution 表述不完全一致。
- 除目标方向符号矛盾外，GP 如何估计混合型输入密度也缺少可复现细节。

### 分类变量和行动约束

- Algorithm 3 对选中维度统一施加连续 Cauchy 扰动。
- 论文未说明分类特征变异后的取整、合法类别映射、边界修复或无效值处理。
- 框架没有显式区分可改变、不可改变和只能单向改变的特征；COMPAS 示例甚至主动改变种族和性别用于偏差诊断。
- 因此，“可行动”更多来自局部依赖组和案例解释，不等同于满足严格现实行动约束。

### 实验协议仍需确认

- 主 MOEA 对比报告 30 次独立运行，但没有清楚说明每个数据集与分类器问题使用多少个不同测试个体；若只围绕单个随机实例重复优化，不能代表跨用户稳定性。
- HV 的实际 reference point 和目标归一化细节未明确给出。
- 与其他 MOEA 的比较同时改变了基础优化器和变异结构；消融缓解了归因问题，但不能完全证明该结构对任意 MOEA 都有效。

## 作为基础算法时的分析

- 必须保留的核心：
  - 三目标或其他能评价候选 CE 质量的目标体系；
  - 从数据或领域知识获得的变量依赖组；
  - 每个后代只在一个或少数依赖组内改变；
  - 完整解评价和多目标环境选择。
- 可以修改的位置：
  - 将 STMB 替换为可靠的图结构、领域规则、功能模块或交互分组；
  - 使用带置信度的软结构，而不是硬性禁止组外变异；
  - 根据历史贡献自适应选择特征组；
  - 为连续、整数、类别和不可变特征配置类型安全的变异与修复；
  - 将 `ISDE+` 替换为 NSGA-II、分解式算法或其他环境选择；
  - 将 GP plausibility 替换为密度模型、生成模型、约束或异常检测器。

## 局限与未来工作

### 作者明确说明的局限

- 用数值编码表示分类变量并交给 RBF GP，隐含类别编码距离具有意义的假设。
- Markov Blanket 发现依赖 Markov 和 Faithfulness 条件；有限样本、噪声和因果作用抵消可能导致 MB 不够稀疏或遗漏变量。

### 作者未来工作

- 为分类变量使用 categorical、Hamming、string kernel 或混合 GP。
- 使用干预数据或功能因果模型处理严重违反 Faithfulness 的场景。

### 我们认为仍需解决

- 明确修复 Algorithm 2 的独立性判断和 Algorithms 2-3 的字典接口。
- 将依赖结构与真正可干预的因果方向、不可变特征和行动成本分开建模。
- 修正 plausibility 目标方向，并完整说明 GP 密度估计过程。
- 在已知真实因果图或合成 SCM 上验证结构恢复与干预正确性。
- 报告跨多个测试个体的稳定统计，而不只报告优化器随机运行。
- 在其他基础 MOEA 中移植该变异算子，验证跨算法复用价值。

## 可复用知识与创新线索

### 已升级为设计知识

- 依赖结构指导的变异算子：把难以写成目标函数的结构知识转化为“哪些变量可共同改变”的后代模板，并只在模板覆盖维度中执行变异。

### 暂留在论文卡中的方法、原理或架构启发

- 将多样反事实解集同时用于行动建议与模型偏差审计。
- 把多个相互重叠的 desiderata 从目标空间移到生成过程或修复过程，控制目标数量。
- 用局部结构模板为不同个体分配不同的搜索子空间。

### 局部创新线索

- 为每条依赖链估计可信度和历史 HV 贡献，自适应选择链与组外探索概率。
- 将硬限制变为软限制：大部分后代在依赖组内变异，少量后代允许跨组发现遗漏关系。
- 为每类变量配置类型安全、方向安全和行动成本感知的变异。

### 结构创新线索

- 构建“结构发现器 + 算子调度器 + 多目标选择器”的三层框架：结构发现器产生候选变量组，调度器按收益分配变异预算，选择器保留综合质量高的解。
- 同时维护多个结构假设或因果图，使搜索在结构不确定性下产生稳健解，而不是依赖单一 MB。
