# Modeling risk attitudes in picture fuzzy multi-objective linear programming with chance constraints

## 一句话理解

本文为 picture fuzzy 多目标线性规划建立一套风险态度可调的机会约束求解框架：先把 GTPFN 系数按乐观/中性/悲观风险偏好退化为 GTFN，再用 possibility、credibility 或 necessity measure 转成确定性等价模型并求解。

## 问题与动机

- 研究问题和场景：现实决策中的收益、成本、资源和约束系数可能同时包含不确定性、犹豫、拒绝和专家可信度，普通 fuzzy 或 intuitionistic fuzzy MOLP 难以完整表达。
- 现有算法为什么不足：
  - 传统 fuzzy set 只用 membership 描述不确定性，无法显式表达 non-membership、neutrality 和 refusal。
  - 直接用 extension principle 和 alpha-cut 做广义模糊算术可能计算复杂、区间膨胀并导致过度保守。
  - 已有 chance-constrained MOLP 多局限于 fuzzy 或 intuitionistic fuzzy 数据，缺少同时覆盖 GTFN、GTIFN 和 GTPFN 的统一框架。
  - 既有 picture fuzzy 方法多用于排序或聚合，缺少完整的 chance-constrained MOLP 确定性化方案。
- 本文希望解决什么：给出 GTPFN 的一致定义、保形算术、风险态度驱动的降阶方法，以及乐观/中性/悲观三类机会约束模型，让决策者能显式调节风险偏好并交给常规优化器求解。

## 核心理念与算法流程

- 核心理念：picture fuzzy 系数信息量很高，但直接优化成本大；可先根据决策者风险态度和“收益/成本”类型，把每个 GTPFN 压缩为代表性 GTFN，再用对应 chance measure 得到确定性约束。
- 主要流程：
  1. 将不确定系数表示为 GTPFN，包含 positive、neutral、negative membership 和 refusal 信息。
  2. 判断每个系数是 benefit-type 还是 cost-type，例如目标收益是 benefit，技术消耗系数是 cost，资源右端项可视为 benefit。
  3. 根据语言风险标签选择 `u, omega`，从 Extremely Optimistic 到 Extremely Pessimistic 共 9 档。
  4. 用 Definition 7 将 GTPFN 退化为 GTFN：`h=(u h_mu + 1 - h_nu)/(u+1)`，并用 `omega` 混合上下端点。
  5. 根据风险态度选择 chance measure：乐观用 possibility，悲观用 necessity，中性用 credibility。
  6. 使用 Table 4 中的确定性等价式，将 fuzzy chance constraints 转换为普通非线性或线性约束。
  7. 对 MOLP 的多个目标使用权重、目标水平或价值函数等方式整合，再用 `fmincon` 等常规求解器求解。
  8. 通过敏感性分析观察风险参数变化对决策变量、目标值、confidence level 和高度的影响。
- 关键组成部分：
  - Refined GTPFN definition：确保 positive、neutral 和 negative membership 之和不超过 1。
  - Risk-driven degeneration：用 `u` 和 `omega` 将 GTPFN/GTIFN 降为 GTFN。
  - Shape-preserving arithmetic：保留梯形形式和线性结构，避免高度最小算子导致的信息损失。
  - Extended possibility/necessity/credibility measures：支持 subnormal generalized fuzzy variables。
  - Risk-attitude-based deterministic counterparts：乐观、悲观、中性三类 chance constraints 的确定性等价。
- 可能被修改的位置：风险标签到 `u/omega` 的映射、benefit/cost 分类、confidence level、目标整合方式、GTPFN elicitation 方式和确定性求解器。
- 必须保留的核心：若作为基础方法，应保留“风险态度退化 + 对应 chance measure + 确定性等价”的三段结构；只做 defuzzification 或只用普通 fuzzy ranking 不等同于本文框架。

## 实验证据

- 测试问题和对比算法：论文给出 3 个文献 benchmark 应用：不同高度的 intuitionistic fuzzy 单目标 LP、同高度的 intuitionistic fuzzy 多目标 LP、以及不同高度的 picture fuzzy 单目标 LP。求解使用 MATLAB `fmincon`，多目标例子采用等权整合以便解释。
- Example 1：
  - 先将 IF coefficients 按 somewhat optimistic、somewhat pessimistic 和 neutral 三种态度退化为 GTFN。
  - 结果显示最大化目标的 defuzzified value 随悲观程度上升而下降：somewhat optimistic 为 `12.7530`，neutral 为 `10.3252`，somewhat pessimistic 为 `9.3336`。
  - 作者指出部分 reduction 后的 membership chance value 可能略低于设定阈值，可通过提高 formulation threshold 修正。
- Example 2：
  - 处理同高度 GTIFN 多目标 LP；由于所有系数高度均为 `0.8`，确定性模型不含额外非线性高度约束。
  - 在乐观、悲观、中性三种态度下生成不同退化参数和最优解，说明相同 MOLP 可按风险态度形成不同资源配置。
- Example 3：
  - 用 picture fuzzy LP 做风险参数敏感性分析，求解 9 个风险场景。
  - 乐观场景的解大致聚集在 `[58.5, 222.5, 209.5]^T`，悲观场景聚集在 `[70, 0, 350]^T`；中性解为 `[70, 0, 360]^T`，略偏悲观。
  - 随 `u` 从 `0` 增至 `infinity`，最大化目标值 `g` 从 `86291.89` 降至 `64709.38`，整体高度 `h` 从 `0.79` 降至 `0.40`，体现从高回报/高暴露转向更保守方案。
- 证据边界：
  - 主要是建模和数值示例，不是大规模算法 benchmark。
  - 求解器依赖 `fmincon`，非凸或大规模问题上的全局最优性未系统证明。
  - 风险参数和 confidence level 的选择具有主观性，实验更多展示一致性而非经验最优性。

## 局限与未来工作

- 作者明确说明的局限：
  - confidence level 和 risk preference parameters 的选择带有主观性，会导致结果变动。
  - 当前方法要求系数非负，这是实际应用中的一个明显限制。
  - 完整 GTPFN 可能涉及 15 个参数，专家 elicitation 认知负担较高。
  - 低负担 elicitation 路径仍需要领域语言词典校准，并可能引入近似误差。
- 作者未来工作：
  - 研究 adaptive parameter tuning，减少 confidence level 和风险参数选择的主观性。
  - 融合 type-2 fuzzy、hesitant fuzzy 等 hybrid fuzzy environments。
  - 放宽 crisp decision variables 假设，引入 fuzzy 或 interval-valued variables。
  - 扩展到 nonlinear 或 mixed-integer MOLP。
  - 应用于风险敏感 portfolio optimization、供应链和库存控制。
- 我们认为仍需确认的问题：
  - `u/omega` 与真实决策者风险偏好的标定是否稳定。
  - 先退化再做 chance measure 是否会丢失 neutrality/refusal 对约束可行性的局部影响。
  - 对负系数、混合符号系数或强相关模糊系数如何扩展。
  - 多目标整合采用等权或目标水平时，是否掩盖了原始 Pareto trade-off。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 风险态度驱动的模糊机会约束确定性化：适合把 generalized/intuitionistic/picture fuzzy MOLP 交给常规优化器求解，同时保留乐观、中性、悲观风险语义。
- 暂留在论文卡中的方法、原理或架构启发：
  - Refined GTPFN 的完整数学定义和保形算术细节较偏数学基础，暂留在论文卡和原文中。
  - Example 1 中 reduction 后 chance value 可能低于目标阈值的校准问题，作为复现注意事项保留。
  - `fmincon` 求解和等权目标聚合属于具体实现选择。
- 局部创新线索：
  - 将 `u/omega` 从固定语言表改为数据驱动或交互式风险偏好学习。
  - 为 GTPFN reduction 增加保守性校准，自动提高 chance threshold 以抵消退化误差。
  - 在 MOEA/D 或偏好式 MOEA 中把不同风险态度作为多个子问题并行扫描。
- 结构创新线索：
  - 构建“不确定系数 elicitation -> 风险态度退化 -> chance measure 确定性化 -> 多偏好求解 -> 风险敏感报告”的建模预处理层。
  - 将 picture fuzzy 参数与 robust optimization、scenario optimization 或 distributionally robust optimization 结合，比较风险语义的一致性。
