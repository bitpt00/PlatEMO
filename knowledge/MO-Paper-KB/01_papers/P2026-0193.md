# An Improved Reference Point-Based Evolutionary Algorithm for Dynamic Multi-Objective Optimization With Preferences

## 一句话理解

论文提出 DPA-NSGA-II，用动态自适应 `r`-dominance 在每个环境周期内调节参考点偏好强度，让搜索先保持 Pareto 探索、再快速收敛到 DM 当前 ROI、最后维持 ROI 内多样性；同时用 PPM 根据历史 reference points 做 least-squares 线性预测，提前给种群一个 hypothetical reference point，从而在环境和偏好同时变化时跟踪动态 ROI。

## 问题与动机

- 研究问题和场景：dynamic multi-objective optimization problems (DMOPs) 中 PS/PF 会随环境变化；实际决策者往往只关心由 reference point 定义的 region of interest (ROI)，而不是完整 PF。
- 现有方法为什么不足：
  - 许多 DMOEAs 主要跟踪完整 PS/PF，忽视 DM 的动态偏好，导致预算浪费在无关 PF 区域。
  - Prediction-based DMOEA 会用历史 PS/PF 预测新环境种群，但没有把 reference point 或 ROI 作为先验知识纳入预测。
  - 静态 reference point-based 方法如 `r`-dominance 假设 reference point 不变，不能处理偏好随环境变化的 ROI 漂移。
  - 如果 DM 在新环境才给出 reference point，种群可能滞后，当前环境结束前尚未到达期望 ROI。
- 本文希望解决什么：
  - 将 reference point preference 纳入动态优化循环；
  - 在环境变化时同时响应 PS/PF 变化和 ROI 变化；
  - 自适应调整 ROI 搜索压力，避免过早收敛或 ROI 覆盖不足；
  - 用历史偏好预测 hypothetical reference point，缓解偏好变化响应滞后。

## 核心理念与算法流程

- 核心理念：在动态环境中，偏好信息本身也是时间序列。算法不应只预测新环境的 Pareto set，还应预测 DM reference point 轨迹，并根据当前阶段动态控制偏好选择压力。
- DPA-NSGA-II 总流程：
  1. 初始化 population、DM reference points、DAR 参数、PPM 参数和终止条件。
  2. 每代用 detectors 检查环境是否变化。
  3. 如果环境变化，判断 DM 是否更新 reference point；若偏好变化，则用 PPM 将新 reference point、历史 reference points 和当前时间融合，得到用于引导搜索的预测 reference point。
  4. 触发 prediction-based change response technique，本文采用 PPS 生成新环境初始种群。
  5. 如果环境未变化或变化响应完成，使用 DAR-dominance 替代普通 `r`-dominance 进行 population ranking，再按 NSGA-II 环境选择更新种群。
  6. 重复直到达到最大代数。
- DAR-dominance：
  - `r`-dominance 中阈值 `delta` 控制偏好强度。`delta=1` 等价于 Pareto dominance；`delta=0` 近似按 reference point 距离给 Pareto-equivalent solutions 全排序。
  - 每个环境周期开始后，`delta_init=1`，先强调 Pareto exploration，避免新环境初期围绕错误 ROI 早熟。
  - 中期逐渐降低 `delta`，增强 reference point preference，使 population 快速收敛到 ROI。
  - 到稳定阶段后，将 `delta` 提高到 `delta_limit`，在 ROI 内恢复一定多样性。
  - 稳定时间 `T_stable` 由历史环境变化间隔估计，`lambda` 控制进入稳定阶段的早晚。
- PPM：
  - 对每个目标维度的 reference point coordinate 建立时间的一阶线性模型。
  - 用最近若干组历史 `(Tj, Zj)` 通过 least squares 拟合直线。
  - 根据 average preference-change interval 和到达理想 ROI 所需时间估计 hypothetical time。
  - 用参数 `eta` 在 DM 新给定 reference point 和预测 hypothetical reference point 之间调节偏移强度；`eta` 越大，预测点越偏离当前 DM 点，提前量越强。
  - 正文参数设置中使用最近 3 个环境的偏好历史；历史不足 3 个时禁用 prediction。
- 可能被修改的位置：
  - `r`-dominance 可替换为 reference-vector ROI selection、achievement scalarizing function、preference cone dominance 或 R2/ASF ranking；
  - PPM 的线性 least squares 可替换为 AR/VAR、Kalman filter、Gaussian process、spline 或 online preference learning；
  - PPS 可替换为任意 DMOP change response，如 center prediction、transfer learning、second-order prediction 或 data-stream surrogate；
  - `lambda/eta/delta_limit` 可由 change severity、preference volatility 或 ROI tracking error 自适应。
- 必须保留的核心：
  - 同时处理 environmental change 和 preference/reference-point change；
  - ROI 搜索压力随环境周期阶段变化，而不是固定偏好强度；
  - reference point 预测必须使用历史 preference sequence，而不仅是历史 Pareto solutions；
  - 评价应面向 ROI 的 convergence/diversity，而不只看完整 PF 的 IGD/HV。

## 实验证据

- 实验设置：
  - 16 个 benchmark problems：5 个 FDA、3 个 dMOP、8 个 JY。
  - 环境变化 severity `nt=10`，change frequency `tau_t` 取 5、10、20、30；每次运行有 30 次环境变化，首次变化前允许 100 代静态演化。
  - 偏好变化模式包括 no change preference (NCP)、linear change preference (LCP)、cyclic change preference (CCP)。
  - 对比八个 DMOEAs：PPS-NSGA-II、AE-NSGA-II、IT-NSGA-II、KL-NSGA-II、KTS-NSGA-II、HRS-NSGA-II、DIP-NSGA-II、KTMM-NSGA-II。
  - 所有算法 population size 为 100；10% population 作为 detectors；SBX `pc=0.9, eta_c=20`，PM `eta_m=20, pm=1/n`；每个实例独立运行 20 次。
  - DAR 参数：`delta_init=1.0`、`delta_stable=0.5`、`delta_limit=0.6`；参数分析后采用 `lambda=0.8`、`eta=0.5`；PPM 用最近 3 个环境的 reference points。
  - 指标：作者认为普通 IGD/HV 不适合只逼近 ROI 的偏好 DMOP，因此采用 MGD 和 MSP；Friedman、Nemenyi 检验用于显著性与排名。
- 与对比算法比较：
  - 在 `tau_t=5` 的快速环境变化下，DPA-NSGA-II 在所有 preference change modes 下整体表现更好；作者认为原因是它直接搜索 ROI，不必在短时间内覆盖完整 PF。
  - 在 `tau_t=10` 的较慢变化下，DPA-NSGA-II 在多数 DMOP 和三种偏好变化模式下取得最佳表现，尤其在 ROI 分布上优势明显。
  - 作者观察到，在短时间间隔下 knowledge transfer-based algorithms 难以获得可靠历史知识，可能发生 negative transfer；reference-point guidance 对 ROI 搜索更直接。
- 消融：
  - 四个变体：baseline DPA、DAR-DPA、PPM-DPA、DAR-PPM-DPA。
  - 在 `(tau_t, nt)=(30,10)` 上，完整 DAR-PPM-DPA 的 Friedman/Nemenyi 排名最佳，并显著优于 baseline 和单策略变体，说明 DAR 与 PPM 有协同效果。
- 参数敏感性：
  - `lambda` 取 `{0.2,0.4,0.6,0.8,0.9,1.0}`，`eta` 取 `{0.1,0.3,0.5,0.7,0.9,1}`，在 JY problems 且 `(tau_t, nt)=(20,10)` 上测试。
  - `lambda=0.8` 在多数 JY 上最好；过小可能太早进入稳定阶段，陷入局部 ROI。
  - `eta=0.5` 多数问题最优；过小会导致 ROI 响应滞后，过大会把 population 引向偏离真实 ROI 的方向。
- 计算效率：
  - 复杂度与多数 DMOEAs 差异不大，主要仍受 nondominated sorting 环境选择影响。
  - 在 dMOP1-dMOP3、`(tau_t, nt)=(10,10)` 上平均 runtime 与先进算法相当或更好。
- 真实应用：
  - D-PID dynamic control problem，30 个 time-varying states，每个 state 演化 30 generations，DM/engineers 为每个状态给 reference points。
  - 因真实 PF 未知，作者用 NSGA-II 在每个环境独立运行 100 generations 得 approximate PF 计算 MGD；20 次独立运行。
  - DPA-NSGA-II 在 D-PID 的 MGD/MSP 上优于对比算法，说明 DM guidance 对真实动态控制有帮助。
- 证据边界：
  - 许多统计细节在 supplementary，Markdown 正文只保留显著性概述和部分图表占位。
  - reference point change 模式是人工设计的 NCP/LCP/CCP，真实 DM 偏好可能更噪声化或突变。
  - PPM 依赖短期线性变化假设，复杂偏好轨迹可能不适用。

## 局限与未来工作

- 作者明确说明的局限和 threats：
  - External validity：DPA 对不同类型、不同特征 DMOP 的泛化仍不确定，需要在 irregular nonlinear 或 noisy dynamic environments 中进一步验证。
  - Internal threats：性能依赖 PPM 预测准确度和 DAR-dominance 有效性，prediction error 或 preference dynamics 变化可能影响效果。
  - Construct threats：DAR 和 PPM 的理论基础依赖对 preference changes 与 ROI dynamics 的特定假设，需要检验其他 construct 是否更好。
  - Limitations：当前验证受限于测试 benchmarks 和一个真实问题；highly irregular 或 abrupt preference shifts、large-scale scalability 和 computational complexity 仍需深入研究。
- 作者未来工作：
  - 开发更高效 decision-making techniques；
  - 处理 noisy environments 下的 preference-based DMOP；
  - 增强对极端偏好变化和大规模优化的适用性。
- 我们认为仍需确认的问题：
  - 当 DM preference 是策略性、交互式或多用户冲突偏好时，单 reference point 是否足够。
  - MGD/MSP 对 ROI quality 的度量是否能反映真实决策满意度。
  - PPM 历史窗口固定为 3 是否稳健，是否应随 preference volatility 自适应。
  - DAR 的 `delta` 调度是否可由 ROI tracking error 在线闭环控制。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：动态参考点 ROI 偏好跟踪。它不同于普通 DMOP PS/PF 预测或静态 reference point search，重点是同时追踪环境变化和 DM preference/ROI 变化。
- 暂留在论文卡中的方法、原理或架构启发：
  - PPS 只是本文采用的 change response prototype，已有更通用动态预测卡，不单独新建。
  - D-PID 是应用验证场景，不单独建应用卡。
- 局部创新线索：
  - 将 PPM 从线性 least squares 改为 Kalman filter 或 Gaussian process，并输出 reference point uncertainty。
  - 用 ROI tracking error 自适应调节 `eta` 和 `lambda`。
  - 在多 reference point 或 preference distribution 下，把 DAR 扩展为多 ROI parallel tracking。
  - 用 DM feedback 对 predicted reference point 做在线修正。
- 结构创新线索：
  - 构建“environment detector -> PF/PS predictor -> preference trajectory predictor -> adaptive ROI dominance -> ROI metrics”的偏好动态优化框架。
  - 将该机制嵌入工业控制、项目调度、动态路径规划等需要阶段性目标偏好切换的决策系统。
