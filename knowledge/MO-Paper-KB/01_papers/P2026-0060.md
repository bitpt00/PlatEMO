# P2026-0060 - Multi-objective mix optimization of geopolymer recycled aggregate concrete using prior knowledge embedded neural network and evolutionary algorithm

## 一句话概括

本文把经验控制方程嵌入神经网络训练成 KENN 强度预测代理，再把该代理接入 NSGA-II，同时优化 GPRC 的 28 天抗压强度、CO2 排放、能耗和成本，形成“先验约束预测模型 + 多目标配比优化 + 实验验证”的绿色混凝土配比设计流程。

## 研究问题

地聚物再生骨料混凝土 GPRC 能降低普通硅酸盐水泥混凝土的碳排放和资源消耗，但再生细骨料、再生粗骨料和再生混凝土粉的异质性、缺陷和杂质会显著影响强度。传统经验公式或普通回归模型往往依赖有限数据和窄材料范围，难以稳定外推到新配比。

论文要解决的是一个工程配比问题：在数据有限的情况下建立可信的 28 天抗压强度预测模型，并把该模型作为目标函数嵌入多目标优化，使候选配比既满足目标强度，又降低 CO2 排放、能耗和材料成本。

## 数据与变量

作者从 2000-2024 年文献收集 292 组 GPRC 28 天抗压强度数据。数据仅保留以 FA、GGBS 和 RCP 为前驱体、以 NaOH 与 Na2SiO3 为碱激发剂、标准养护条件下的混凝土样本，排除砂浆和浆体。不同试件形状的强度统一换算到 100 mm 立方体强度，训练/测试按 70%/30% 划分。

| 变量 | 含义 |
|---|---|
| `x1` | 碱激发剂溶液与前驱体材料比 |
| `x2` | 细骨料与前驱体材料比 |
| `x3` | RFA 替代率 |
| `x4` | RCA 替代率 |
| `x5` | 砂率 |
| `x6` | NaOH 模数 |
| `x7` | Na2SiO3 与 NaOH 质量比 |
| `x8` | Na2SiO3 模数 |
| `x9` | RCP 替代率 |
| `x10` | FA 含量 |
| `x11` | GGBS 含量 |

相关性分析显示输入变量之间的绝对相关系数均低于 0.7，作者据此认为多重共线性较低。

## 方法核心

### 先验知识嵌入神经网络 KENN

KENN 的基础网络输入为 11 个配比变量，输出 28 天抗压强度。网络包含 8 个隐藏层，神经元数为 `32, 64, 256, 512, 256, 64, 32, 32`，激活函数为 Tanh。

模型的关键不是只拟合数据，而是把一个含单变量非线性项和变量交互项的控制函数并入训练。该函数用 `alpha_i-i`、`beta_i-i` 描述单变量影响，用 `alpha_i-j`、`beta_i-j` 描述两两交互影响，并通过偏置项 `b` 捕捉基线。总损失由三部分组成：

```text
L_total = phi1 * L_data + phi2 * L_func + phi3 * L_func-data
```

其中 `L_data` 约束神经网络预测与试验数据一致，`L_func` 约束控制函数输出与神经网络预测一致，`L_func-data` 约束控制函数输出与试验数据一致；三项均采用 Smooth L1 损失。论文设置 `phi1=1`、`phi2=0.1`、`phi3=1`，并使用 Adam 优化。

训练采用多阶段自适应学习率：初始学习率 0.01；验证损失 50 个 epoch 不变时学习率乘 0.5；下限 0.001。模型在第 8750 次迭代收敛。

### NSGA-II 多目标配比优化

训练后的 KENN 强度预测模型作为 NSGA-II 的强度目标函数。优化目标包括：

| 目标 | 方向 | 说明 |
|---|---|---|
| 28 天抗压强度 | 最大化或满足目标等级安全裕度 | 使用 KENN 预测，并按设计强度和经验标准差设置约束 |
| CO2 排放 | 最小化 | 按各组分单位质量排放和单位体积用量计算 |
| 能耗 | 最小化 | 按各组分单位质量能耗和单位体积用量计算 |
| 成本 | 最小化 | 按各组分单位质量成本和单位体积用量计算 |

约束用于保证配比物理可行和满足材料供应条件。示例约束包括：`x8` 固定为 3.29，`x9` 固定为 20%，GGBS:FA 为 7:3，RFA 和 RCA 均为 100% 替代；同时给 `x1`、`x2`、`x5`、`x6`、`x7`、`x8` 设置上下界。作者强调这些约束可以按项目要求调整。

NSGA-II 设置为父代种群 100、子代种群 200、运行 100 代、交叉概率 0.95、变异概率 0.05。Pareto 前沿生成后，用 Ideal Point 方法计算各方案到理想点的欧氏距离，选择折中配比。

## 主要结果

KENN 在测试集上的 `R2=0.9126`，优于 GDM 的 `R2=0.8121` 和 LSM 的 `R2=0.8461`。相对于 GDM 和 LSM，KENN 测试集 R2 分别提升 12.4% 和 7.86%。测试集误差指标为 `MAE=3.1989 MPa`、`RMSE=4.1538 MPa`，也低于 GDM 和 LSM。训练集最大绝对误差为 6.1 MPa，测试集最大绝对误差为 12.3 MPa。

特征重要性显示前五个关键因素为 RCP 替代率、砂率、GGBS 含量、细骨料与前驱体材料比、RFA 替代率。SHAP 分析进一步显示：RCP、RFA、RCA 以及过高细骨料/前驱体比通常削弱强度；GGBS 和适当砂率对强度有正向作用。

NSGA-II 为 C30、C50、C70 三个强度等级各生成三组代表性配比。实验用 100 mm x 100 mm x 100 mm 立方体试件验证，每组 3 个试件，按 GB/T 50081-2019 取平均值。Table 5 中所有强度预测误差绝对值均小于 5.0%。坍落度从 C30 的约 144 mm 降到 C70 的约 93 mm，但均处于普通混凝土可接受范围 50-180 mm。

C50 方案的 CO2 排放为 224.43 kg eq CO2/m3，成本为 95.74 $/m3，能耗为 3417.94 MJ/m3。作者将其与 Al-Tam et al. (2025) 的 C50 GPC 对比，后者 CO2 排放 580 kg eq CO2/m3、成本 482 $/m3、能耗 3590 MJ/m3；本文方案在碳排放和成本上明显更低，能耗略低。

## 实验证据

- 测试问题和对比算法：292 组文献 GPRC 强度数据；强度模型与 LSM、GDM 比较；配比优化使用 KENN 嵌入 NSGA-II，并通过 C30、C50、C70 实验验证。
- 主要实验结论：KENN 在测试集上达到 `R2=0.9126`，预测误差低于 LSM/GDM；优化配比的实测强度与预测强度最大误差小于 5.0%。
- 消融或机制证据：论文没有完整 KENN 去先验损失消融，但通过 LSM/GDM 参数估计对比、控制函数参数解释和 SHAP 分析支持先验约束与变量交互的有效性。
- 证据边界：实验验证只覆盖作者设定的材料系统和三个目标强度等级；NSGA-II 对比重点不是算法性能 benchmark，而是工程配比可行性验证。

## 局限与未来工作

- 作者明确说明的局限：当前模型仅覆盖钠基碱激发体系，以及再生骨料、FA、GGBS、RCP 等特定组分；没有考虑钾基激发剂、赤泥、偏高岭土等其他材料。
- 作者未来工作：扩展激发剂和前驱体材料范围，并把更全面的多尺度物理与化学特征纳入建模框架。
- 我们认为仍需确认的问题：KENN 中控制函数形式和权重 `phi` 对其他材料系统是否稳健；代理误差如何在多目标 Pareto 前沿中传播；与随机森林、GPR、纯 NN、PINN 或多保真模型的公平消融仍不足。

## 复用要点

如果迁移到其他材料或工程配方问题，最小接口包括：

1. 一个能标准化不同实验来源的配方-性能数据集。
2. 一组有物理意义的比例变量或结构变量。
3. 一个可微或可评估的领域控制函数，至少能表达单变量影响与关键交互。
4. 一个同时约束数据拟合、代理-先验一致性和先验-数据一致性的训练损失。
5. 一个多目标优化器，用代理预测性能，用组分用量计算成本、排放、能耗等工程目标。
6. 一个折中选解和实验验证环节，避免只在代理模型上报告 Pareto 前沿。

## 证据边界

该论文的主要价值在工程方法链路，而不是提出新的 NSGA-II 算子。配比优化的 Pareto 前沿依赖 KENN 代理和组分指标表；若材料分布、激发剂体系、试件尺寸换算或碳/能耗数据库变化，最优方案和可靠性需要重新验证。
