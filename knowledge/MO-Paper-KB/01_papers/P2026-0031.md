# P2026-0031 - A dual-population based uniform search framework for solving large-scale multi-objective optimization problems

## 一句话概括

本文提出 DPUSEA，用收敛种群 `Pc` 与多样性种群 `Pd` 弱协同：在决策空间用聚类限制交配保护高维优质基因块，在目标空间用 ESI 找出稀疏或收敛差的子区域并做增强采样，从而在大规模多目标优化中同时改善收敛和均匀覆盖。

## 研究问题

大规模多目标优化问题通常有上千到数千个决策变量。论文认为这类问题同时有两类困难：一是高维决策空间中，全局随机交配容易破坏局部高质量结构；二是目标空间中，不同子区域的收敛和稠密程度不同，固定均匀资源分配会导致局部区域采样不足、停滞或分布不均。

已有方法大致包括变量分组/协同协作、决策空间降维或问题转换、新型搜索机制、学习或代理辅助方法。作者指出这些方法往往只偏向某一侧：变量分组可能昂贵或不准确，降维和问题转换依赖参考点或变换质量，学习方法依赖有偏且不足的训练数据，新算子又常有较强参数依赖。因此本文希望在一个框架内同时处理决策空间局部搜索和目标空间均匀覆盖。

## 方法核心

### DPUSEA 双种群框架

DPUSEA 维护两个互补种群：

| 种群 | 选择偏好 | 作用 |
|---|---|---|
| `Pc` | APD environmental selection | 偏收敛，最终输出该种群 |
| `Pd` | 基于参考向量子区域的局部非支配排序 | 偏多样性，提供目标空间覆盖与增强采样基础 |

两个种群并不是强耦合迁移，而是在环境选择阶段共享全部新生成个体：`Pc` 和 `Pd` 都可以从 `Oc`、`Od` 与增强采样个体 `Os` 中选择，但各自保留不同选择准则。这样把交互设计成弱协同：共享候选来源，但不强迫两个种群采用同一选择压力。

### 决策空间限制交配 DSRM

DSRM 对当前种群的决策向量做 K-means 聚类，聚类数等于子区域数 `RS`。对每个个体，以概率 `pr` 从同一决策空间聚类中选父代，以概率 `1-pr` 从全种群选父代。其意图是：

- 把决策空间邻近个体视为同一局部生态位，优先进行局部交配。
- 在高维空间中缩小后代搜索范围，减少全局随机交叉对优质基因块的破坏。
- 保留小概率跨簇交配，避免过早局部化并维持全局信息交换。

算法复杂度中，DSRM 的 K-means 项为 `O(KND)`；当 `K=RS` 固定时，可视作 `O(ND)`。

### 目标空间状态评估与增强采样

作者把自适应子空间增强采样拆成两个部分：

1. Evolutionary State Indicator, ESI：用参考向量划分目标空间子区域，每个子区域综合考虑角度/密度与沿参考方向的收敛投影距离。ESI 越小，表示该子区域越稀疏或收敛越差。
2. Subspace Enhanced Sampling, SES：按 ESI 升序选择状态最差的约一半子区域。每个被选子区域从 `Pd` 中取与参考向量夹角最小的若干解，构造变量上下界子空间；再围绕目标解沿采样方向生成候选。以概率 `pr` 使用局部子空间，以概率 `1-pr` 回到全局边界采样。

这种机制让目标空间中薄弱区域得到额外候选，而候选的变量范围又来自当前区域附近的决策结构。

### 环境选择

`Pd` 的环境选择先用参考向量划分目标空间，再在每个子区域内选择夹角较小的候选并执行局部非支配排序，目标是保证各个目标方向均有代表性解。

`Pc` 使用 APD 指标选择，类似 RVEA 中把角度和距离结合的选择压力，目标是优先提高收敛质量。

整体每代主要复杂度为 `O(MN^2 + ND)`，其中 APD 选择是 `O(MN^2)`，决策空间聚类是 `O(ND)` 量级。

## 实验设计

| 项目 | 设置 |
|---|---|
| 测试集 | LSMOP 与 GLSMOP |
| 规模 | 1000、3000、5000 决策变量 |
| 目标数 | LSMOP: 2/3；GLSMOP: 3/5 |
| 总实例 | 108 个 |
| 对比算法 | DGEA, FLEA, IM-MOEA/D, LSMOEA-DS, LSMOF, LMOCSO |
| 平台 | PlatEMO 4.2, MATLAB R2020b, Windows 11 |
| 指标 | IGD；消融中还使用 SP |
| 重复次数 | 20 independent runs |
| 统计检验 | Wilcoxon rank-sum test, 5% significance level |
| 主要参数 | `N=100`, `MaxFE=200000`, `RS=20`, `pr=0.9`, APD `alpha=2` |

## 主要结果

整体上，DPUSEA 在 108 个测试实例中有 80 个取得最好 IGD。

在 LSMOP 上，DPUSEA 在 54 个实例中有 42 个最好；LMOEA-DS 有 4 个最好，DGEA、FLEA、LSMOF 各 2 个，LMOCSO 1 个，IM-MOEA/D 0 个。作者特别指出 DPUSEA 在 LSMOP1-5 与 LSMOP9 上表现强。LSMOP9 的可视化显示，在 2 目标、3000 维、非凸且不连续 PF 上，DPUSEA 能找到所有真实 PF 区域并保持较均匀分布。

在 GLSMOP 上，DPUSEA 在 54 个实例中有 38 个最好；LMOCSO 有 9 个最好，IM-MOEA/D 有 4 个，DGEA 有 3 个，FLEA、LMOEA-DS、LSMOF 为 0 个。作者认为 DPUSEA 在 GLSMOP1-6 上优势明显，但在 GLSMOP7-9 的非线性、多峰、欺骗性问题上会因过度开发和全局探索不足而受限。

## 消融与参数分析

消融版本包括：

- DPUSEA-DSRM：用 NSGA-II 锦标赛选择替换 DSRM，保留 SES。
- DPUSEA-SES：移除子区域状态评估与增强采样，保留双种群协同。

在 2 目标、1000 维 LSMOP1-9 上，DPUSEA 在 7/9 个问题上取得最好 IGD；两个消融版本各只在 1 个问题上最好。SP 指标上，DPUSEA 与保留 SES 的 DPUSEA-DSRM 明显优于移除 SES 的版本，说明 SES 对 PF 均匀性贡献更直接；DSRM 则更多改善收敛与整体 IGD。

参数敏感性测试覆盖 `RS=15,20,25` 与 `pr=0.5,0.9,1`。论文结论是整体对参数不太敏感，`RS=20` 在资源分配和计算代价之间较平衡，`pr=0.9` 在多个测试上为最优或近似最优。

## 局限性

1. 决策空间 K-means 聚类在极高维问题上可能计算效率低且稳定性不足。
2. `RS`、`pr` 等关键参数仍需人工设置，影响跨问题泛化。
3. 对强多峰、欺骗性或异质性结构问题，局部开发可能过强，全局探索和局部精修仍不足。
4. 论文未来工作包括引入高级降维机制、自适应参数学习机制，以及把稀疏算子嵌入后代生成以适配稀疏 LSMOP。

## 复现要点

若在现有 MOEA 中复用该思想，最小实现接口包括：

1. 一个收敛种群选择器，例如 APD、PBI 或收敛偏好的指标选择。
2. 一个多样性种群选择器，按参考向量划分目标空间并在子区域内做局部非支配排序。
3. 一个决策空间聚类交配模块，输入种群决策向量和 `pr`，输出父代索引。
4. 一个目标空间状态评价模块，输出每个参考向量子区域的 ESI。
5. 一个增强采样模块，对低 ESI 子区域按局部变量边界生成额外候选。

## 证据边界

实验主要集中在连续 LSMOP/GLSMOP 基准上，且使用固定 `N=100` 与 `MaxFE=200000`。该框架对离散编码、强约束问题、动态问题、昂贵仿真问题和真实工程任务的效果仍需额外验证。
