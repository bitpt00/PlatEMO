# Knee Point-Guided Online Cooperative Path Planning for UAVs in Dynamic Multi-Objective Environments

## 一句话理解

本文把动态威胁环境下的双 UAV 在线路径规划建模为路径长度与安全风险的动态多目标优化问题，并用膝点引导的轻微/剧烈变化双响应机制，在实时重规划中生成更高质量的初始种群。

## 问题与动机

- 研究问题和场景：双 UAV 协同任务中，一个服务 UAV 执行飞行任务，一个干扰 UAV 抑制威胁；环境包含静态威胁、突发威胁和移动威胁，在线规划需在路径长度和安全风险之间动态折中。
- 现有算法为什么不足：作者认为多数 UAV 路径规划默认环境静态或依赖先验地图，难以实时适应突发/移动威胁；已有威胁建模多把威胁当作被动避障区域，缺少主动干扰机制；多 UAV 协同多采用固定 leader-follower 角色，缺少随威胁和位置变化切换角色的能力；已有 DMOEA 变化响应若只用单一预测、随机重启或固定迁移策略，难以同时处理轻微变化和剧烈变化。
- 本文希望解决什么：构建集成双 UAV 协同干扰、动态角色切换和膝点引导变化响应的在线动态多目标规划框架，使 UAV 在复杂动态威胁下快速重规划可行且高 HV 的路径。

## 核心理念与算法流程

- 核心理念：当前环境的 POF 膝点代表路径长度与风险之间的高价值折中。轻微环境变化时，围绕历史膝点做局部邻域采样并用膝点运动趋势平移非支配解；剧烈变化时，局部平移不足，需将膝点及其邻近高质量非支配解作为正样本，通过 GFK+CORAL+KNN 从目标域候选中筛选新初始种群。
- 主要流程：
  1. 每个目标点开始前执行动态角色切换：比较两种角色分配下的路径 fitness，若一方支配另一方则选择支配方案，否则等概率选择。
  2. 每个在线规划周期先执行威胁干扰机制，确定干扰 UAV 与威胁的交互，并检测环境变化。
  3. 若检测到变化，按检测个体目标值归一化变化量计算 `delta_t`，并与阈值 `delta_def` 比较。
  4. 若 `delta_t < delta_def`，调用 KGNS 生成新环境初始种群；否则调用 KGIT。
  5. 以生成的初始种群进入 baseline MOEA/D 优化；若未检测到变化，则直接用 baseline 算法继续优化。
  6. UAV 沿膝点/全局 knee point 对应可执行路径飞行一个 `Delta t`；若超出最大时间仍未到达目标，则返回上一目标点并重新规划。
- 关键组成部分：
  - Threat jamming mechanism：用 Gaussian 威胁强度、雷达方程和单次只干扰一个威胁的约束建模服务 UAV 风险。
  - Dynamic role-switching：在 leader-follower 框架下按路径 fitness 动态决定服务/干扰角色。
  - Cooperative and physical constraints：包括冲突避免、角色唯一性、速度、转向/爬升角和高度约束，并以惩罚项合入安全风险。
  - KGNS：膝点邻域采样预测新膝点，再按两个最近膝点的移动趋势加权移动非支配解，缺口由随机多样性解补足或精英截断。
  - KGIT：为解决膝点样本少造成的类别不平衡，选取每个膝点最近的非支配解作人工膝点，构造源/目标正负样本，经 GFK、CORAL 和 KNN 标记目标域未标注候选。
- 可能被修改的位置：变化强度度量、`delta_def` 阈值、膝点识别方法、KGNS 采样半径、人工膝点数量、GFK/CORAL/KNN 的对齐和分类器、baseline MOEA/D、角色切换的支配/随机规则。
- 必须保留的核心：膝点作为局部高价值锚点；按变化强度区分轻微局部调整和剧烈迁移筛选；在线路径规划中把变化响应输出作为静态优化器的新初始种群。

## 实验证据

- 测试问题和对比算法：
  - 性能实验将 KGO-MOEA/D 与静态/动态多目标变化响应算法比较，正文讨论包括 RI-MOEA/D、Tr-MOEA/D、T-MOEA/D 等；详细表格在补充材料 Table S-2。
  - 消融/仿真实验设计四类动态威胁场景：静态单威胁、静态+突发威胁、慢/中/快移动威胁、混合静态与动态威胁。
  - 比较实验还包括 A*、APF、DQN、DNSGA-II、MOPSO 和 MOEA/D。
- 主要实验结论：
  - 性能实验中，作者称 KGO-MOEA/D 在多数测试问题上显著优于竞争算法，原因是新环境初始种群有更好 diversity 和 coverage，降低早期适应成本。
  - 静态单威胁场景中，KGO-MOEA/D 能在环境变化后调整高度绕开威胁；RI-MOEA/D 在威胁被干扰后仍可能穿越威胁区域。
  - 静态+突发威胁场景中，两算法均受突发威胁影响，但 KGO-MOEA/D 受影响较小，且后续更能避开剩余静态威胁。
  - 慢/中/快移动威胁场景中，KGO-MOEA/D 通常给出更平滑稳定路径，并在 HV 上更稳定地高于 RI-MOEA/D；威胁速度越快，对路径影响越小，两者路径越相似。
  - 混合静态/动态威胁场景中，KGO-MOEA/D 在动态威胁出现后更快适应，并在 HV 与可视路径质量上优于 RI-MOEA/D。
  - 角色切换分析显示，在混合静态和动态威胁场景下，动态角色切换可根据位置和威胁情况更合理地分配 UAV 角色；例如 T=113 时角色调整提升了安全性和协同效率。
  - 实时性结果：补充材料 Table S-8 报告平均响应时间约 0.015s 到 0.48s；剧烈变化触发 KGIT 时间更高，轻微变化用 KGNS 更快。
- 消融或机制证据：
  - KGO-DMOEA 的 Algorithm 1 明确将响应策略按 `delta_t < delta_def` 分流，说明本文并非固定使用迁移学习。
  - KGNS 通过局部邻域采样保持新膝点接近旧膝点，并用两个最近膝点加权移动非支配解，适合轻微变化。
  - KGIT 用人工膝点缓解膝点正样本过少的类别不平衡；再用 GFK 做流形迁移、CORAL 做协方差对齐、KNN 标记未标注目标样本，适合剧烈变化。
  - 对比实验中作者指出 DNSGA-II 和 MOPSO 在相同迭代次数下未充分收敛，无法避障；MOEA/D 在动态 UAV 模型中作为 baseline 表现较好，但 KGO-MOEA/D 在突发威胁下风险规避更强。
- 证据边界：
  - 许多关键数值结果和参数表位于补充材料，正文主要给出路径图、HV 曲线和定性解释。
  - 仿真中用固定阈值 `Delta t=0.4` 量化环境变化强度，因为真实场景中 `nt` 和 `tau_t` 难获得；这提示阈值选择仍需在线自适应。
  - 实验是仿真路径规划，未覆盖通信延迟、传感误差、风场、能耗、干扰资源连续分配和真实飞控闭环。

## 局限与未来工作

- 作者明确说明的局限：
  - 真实场景中 `nt` 和 `tau_t` 往往难以获得，本文仿真使用固定阈值 `Delta t=0.4` 量化变化强度。
  - 在线路径规划仍基于简化威胁与 UAV 约束模型，复杂飞行场景和多维威胁模型尚未覆盖。
- 作者未来工作：
  - 构建更真实、更复杂和多维的威胁模型；
  - 开发自适应环境复杂度的检测机制，动态调整响应间隔，尤其提高任务最后阶段的规划效率。
- 我们认为仍需确认的问题：
  - `delta_def` 或固定阈值如何随场景、威胁速度、目标距离和评估预算自适应。
  - KGIT 的 GFK+CORAL+KNN 在更高维路径编码、更多 UAV 或更密集威胁下是否仍满足实时性。
  - 人工膝点数量 `M` 和膝点识别误差对分类器正样本质量的影响。
  - 双 UAV 单威胁干扰约束如何扩展到多 jammer、多服务 UAV 和多威胁同时干扰。
