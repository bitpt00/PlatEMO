# An Adaptive Multi-Objective Task Splitting Algorithm for Agricultural Multi-Robot Task Allocation

## 一句话理解

本文面向果园采摘多机器人任务分配，把“多行程路线规划”和“单棵树任务可拆分”同时纳入 makespan-energy 双目标模型，并提出 AMTSA：先用混合编码和路线结构搜索探索机器人/route 分配，再在后期用 MTSO 针对瓶颈机器人做空间邻近与时间均衡的任务拆分优化。

## 问题与动机

- 研究问题和场景：
  - 果园采摘中，只有满足成熟度、质量或传感器阈值的果树会成为 harvestable tasks；
  - 机器人载荷有限，紧凑果园又限制机器人尺寸，因此单个机器人往往需要多次返回 depot 并执行多个 routes；
  - 单棵树的果实可由不同机器人或不同 route 共同采摘，任务拆分会影响路线形状、负载、服务时间和完工时间；
  - 目标是最小化最大完工时间 `T_max` 和总能耗 `E_total`，能耗随距离和当前负载变化。
- 现有方法为什么不足：
  - 普通 agricultural MRTA 多假设任务点不可拆分，难以利用可拆任务带来的负载平衡空间；
  - MTVRP 关注多 trip，但通常没有处理任务拆分和多目标负载均衡；
  - SDVRP 关注 split delivery，但多为单目标、单 route 或无限车辆假设，不适合多机器人多行程采摘；
  - 固定维度编码难以同时表达动态 route 数量、机器人复用和 `[0,1]` 连续拆分比例；
  - 若过早优化微观拆分比例，会限制宏观路线结构探索；若只优化宏观路线，又会留下负载和时间失衡。
- 本文希望解决什么：
  - 建立符合果园多机器人采摘的多 trip、split delivery、load-dependent energy 模型；
  - 设计能同时维护路线结构和任务拆分信息的可变结构表示；
  - 让搜索从早期路线结构探索逐步转向后期任务拆分精修；
  - 在空间效率、能耗和机器人时间均衡之间生成稳定 Pareto 解集。

## 核心理念与算法流程

- 核心理念：
  - 将解拆成 route assignment/sequence 与 task-splitting information 两部分；
  - 早期优先通过 route structural optimization 改变任务-机器人-路线的宏观结构；
  - 后期对 nondominated solutions 中的瓶颈机器人做 multi-objective task split optimization；
  - 拆分时使用两类互补机制：PTSM 偏空间邻近与能耗效率，BTSM 偏时间均衡与 makespan 改善。
- AMTSA 总流程：
  - 根据果园节点、产量、机器人容量、速度和负载能耗参数建立 AMRTA 模型；
  - 初始化种群，其中一个启发式解偏 makespan balance，其余随机生成；
  - 每轮根据自适应参数 `P` 选择搜索模式：route structural optimization 或 MTSO；
  - route mode 通过路线间任务交换/转移、路线内序列调整和 archive 选择生成新解；
  - MTSO mode 在非支配解上识别瓶颈机器人和偏离任务，执行 PTSM/BTSM 拆分；
  - 更新种群和外部非支配解集，输出 approximate Pareto front 和默认 knee solution。
- 混合编码：
  - 路线编码使用任务序列和分隔符表示机器人与 route：
    - `0` 分隔不同机器人；
    - `1` 分隔同一机器人内的多个 routes；
  - 拆分信息记录 task、robot、route 和 split ratio；
  - route structural changes 后同步更新 splitting information，同一任务在同一新 route 中的多个片段会合并；
  - 这种表示允许 route 数量和拆分关系随搜索动态变化。
- 自适应模式切换：
  - 参数 `P` 随已用时间减少，后期更容易触发 MTSO；
  - `P` 同时受 MTSO 新解进入下一代的比例 `phi` 影响：若 MTSO 有效，后续继续增加拆分精修概率；
  - 机制意图是先扩展路线结构，再把计算资源集中到可改进的非支配结构附近。
- Route structural optimization：
  - ITO 包含同机器人内任务交换、同机器人内任务转移、机器人间任务交换、机器人间任务转移；
  - compound move strategy 连续执行若干随机 inter-route operators 后再评价，允许中间劣解跨越局部最优；
  - route 修改后按容量重新划分路线并同步 split information；
  - ISA 在初始化阶段全量执行，后续只对被 ITO 改动的 route 做路线内序列贪心调整；
  - archive length 同时考虑平均 route 数和种群非支配比例，复杂结构或收敛不足时扩大局部探索。
- MTSO：
  - 选择完工时间最长的 bottleneck robot 作为优化对象；
  - DTPIM 对该机器人每条 route 计算几何 centroid，并结合与 depot/centroid 的相对方向和距离选出偏离任务；
  - PTSM 在其他机器人 routes 中寻找与目标任务空间接近且有容量余量的接收位置，并按容量和时间平衡自适应确定 split ratio；
  - BTSM 在最大 makespan 机器人和最小 makespan 机器人之间重分配任务，可建立独立新 cycle 或插入已有 cycle；
  - 候选拆分方案需经过插入位置评价、ISA 修正和非支配保留。
- 必须保留的核心：
  - 若复用 AMTSA 思想，关键不是具体果园参数，而是“路线/拆分混合编码 + 先宏观路线、后微观拆分的自适应调度 + 面向瓶颈 route 的空间/时间双机制拆分”。

## 实验证据

- 真实果园案例：
  - 果园面积约 5300 平方米，880 棵苹果树，行距/株距约 2m/3m；
  - 构造实例含 660 个 harvestable trees 和 5 个 robots；
  - 对比算法包括 AMOEA、CDABC、MODABC、NSGA-II、RNSGA、RMOEA/D；
  - AMTSA 近似 Pareto front 整体支配或明显优于多数对比算法，CDABC/MODABC 局部接近但解集更聚集，AMOEA 多样性较好但收敛不足；
  - 默认 knee solution 在展示运行中同时取得更低 makespan 和 energy；
  - Gantt 结果显示 AMTSA 让机器人完成时间更接近，但机器人间能耗仍不完全均衡，说明 makespan-energy 冲突真实存在。
- 15 个构造测试实例：
  - 基于果园数据构造不同区域尺寸、树数和机器人数量的 Pro1-Pro15；
  - 每个算法运行 10 次，时间上限设为 `Tmax = n * 0.3s`，输出种群大小为 30；
  - 全部输出解 HV 的 `+/−/=` 统计中，AMTSA 相对 AMOEA 为 `1/9/5`，相对 CDABC 为 `0/12/3`，相对 MODABC 为 `0/13/2`，相对 NSGA-II 和 RMOEA/D 为 `0/15/0`；
  - 默认输出解统计中，AMTSA 相对 AMOEA 为 `1/8/6`，对 NSGA-II 为 `0/15/0`，对 RMOEA/D 为 `0/15/0`；
  - Pro7 上 AMOEA 的部分运行可取得更高 HV，但波动更大；作者将其解释为 high-risk/high-reward，而 AMTSA 更稳定。
- 统计检验：
  - Friedman 平均排名中，AMTSA 在 all outputs 和 default outputs 上均排名第一；
  - post-hoc 检验显示 AMTSA 相对六个对比算法均有显著优势；
  - Cliff's delta 对 NSGA-II/RMOEA-D 接近极大效应，对 AMOEA 效应较中等，说明最强竞争来自 AMOEA 的随机探索能力；
  - Spearman 相关分析显示 AMTSA 与多数 peer 的 HV 排名相关较低或为负，说明其搜索行为与基线存在差异。
- 消融与敏感性：
  - 固定 `P` 变体验证 MTSO 在小中规模实例上有明显收益，但过强 MTSO 会牺牲宏观路线探索；
  - 禁用 DTPIM、PTSM、BTSM 或 `phi` 反馈会降低整体表现，支持偏离任务识别、空间邻近拆分、时间均衡拆分和自适应资源分配的必要性；
  - V2 随机任务选择在个别实例有效，说明最大偏离任务并不总是唯一瓶颈，DTPIM 仍有改进空间。
- 证据边界：
  - 真实案例仍是仿真/数据驱动验证，未在实体机器人集群上闭环测试；
  - 机器人被假设为同质、无故障，能量足够完成任务，未纳入严格电池容量、充电或动态事件；
  - 公式和图中部分细节需回查 PDF，Markdown 提取不能完全保证所有参数表达；
  - 对比算法参数公平性和跨场景泛化仍需进一步验证。

## 局限与未来工作

- 作者明确说明的未来方向：
  - 加入严格续航约束、充电/换电、动态事件、机器人故障和环境变化；
  - 扩展到异构机器人团队；
  - 在物流配送、仓储自动化等领域验证；
  - 探索 learning-based methods 用于农业 MRTA；
  - 开展小规模实体机器人 field tests，并考虑人机协作调度。
- 我们认为仍需确认的问题：
  - DTPIM 的几何偏离指标能否适应强障碍、狭窄行间通道或非欧氏路径距离；
  - split ratio 的连续决策若需要整数果实数约束，实际实现中的取整与可行性修复会不会影响 Pareto 排名；
  - MTSO 逐个非支配解精修的计算成本在数千任务或动态滚动重规划中是否可接受；
  - 任务拆分可能带来机器人同时到达同一树、现场冲突或额外协调成本，本文模型未显式处理；
  - 与 ALNS、large neighborhood search、matheuristic 和 exact split-delivery solver 的公平消融仍可补充。
