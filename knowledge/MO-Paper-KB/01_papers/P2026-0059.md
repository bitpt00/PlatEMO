# A multiobjective construction site layout and safety planning model based on evolutionary algorithms

## 一句话理解

论文把高风险施工场地或海外基地的设施布局、防护材料选择和受损后的恢复顺序放进同一个三目标优化框架：外层 NSGA-II 搜索设施坐标、朝向和材料，内层贪婪算法在每个候选布局上决定修复顺序，从而同时最小化爆炸袭击后果、建设/修复资源成本和运营停摆时间。

## 问题与动机

- 研究场景：
  - 能源生产基地、海外军事基地或大型施工场地可能遭受无人机、火箭弹、汽车炸弹等爆炸袭击；
  - 设施之间的距离、朝向、材料强度和关键设施的恢复顺序会共同影响人员伤亡、经济损失和任务停摆；
  - 决策者既要提前规划场地布局和防护材料，也要知道袭击后如何分配有限维修队。
- 现有工作为什么不足：
  - 传统 construction site layout planning 多关注运输距离、安全间距、成本或施工效率；
  - 防爆/反恐风险常作为后验评估，较少直接进入多目标布局优化；
  - 恢复顺序通常与布局设计分开处理，无法反映布局和材料选择对后续停摆损失的影响；
  - 单目标或加权模型很难展示“更安全但更贵”“成本低但恢复慢”等折中。
- 本文希望解决什么：
  - 建立一个集成场地布局、安全防护和恢复计划的多目标模型；
  - 用爆炸后果仿真把人员损失、经济损失和设施损伤反馈到优化目标；
  - 通过 dual-algorithm framework 将演化搜索与恢复顺序贪婪求解耦合；
  - 为管理者输出 Pareto 方案、设施布局图和恢复顺序，而不是单个方案。

## 核心模型与算法流程

- 决策变量：
  - `x_i, y_i`：设施 `i` 的中心坐标；
  - `theta_i`：设施朝向；
  - `M_i`：设施所选建筑材料；
  - `sigma`：受损设施的恢复顺序，由内层贪婪算法在评价时生成，不直接进入外层染色体。
- 三个目标：
  - `O1`：爆炸后果，综合 personnel loss index `PLI` 和 total economic loss index `TELI`，案例中权重为 `w1=0.7`、`w2=0.3`；
  - `O2`：建设与恢复资源配置成本，包括各设施面积乘材料成本，以及维修队配置成本；
  - `O3`：运营影响，按 mission dependency index `MDI`、设施损伤比例和恢复顺序累计 equivalent site operation disruption days。
- 爆炸后果评价：
  - 固定布局后随机模拟 100 次爆炸位置，并用最大总损失计算爆炸后果；
  - 损伤分为 minimal、minor、moderate、heavy、severe 五档，对应 10%、20%、40%、60%、100% 损伤；
  - 设施损伤比例 `PFD_i` 由各损伤环覆盖面积比例加权得到；
  - 人员损失把死亡、重伤、轻伤按 1.0、0.7、0.085 折算为 equivalent deaths；
  - 经济损失包含资产损失和修复/重建成本，损伤超过 40% 时按重建处理。
- 约束：
  - 场地边界约束，设施必须位于矩形边界内；
  - 设施不重叠约束；
  - 一般最小间距和特殊危险品最小间距；
  - 特定功能设施最大间距，例如领导宿舍与总部之间；
  - 恢复资源约束，维修队数量有限，同一设施由一个队修复，同一时间可并行修复数不超过队伍数。
- dual-algorithm framework：
  - 外层 NSGA-II 染色体为 `[(x_i, y_i, theta_i, M_i)]_{i=1}^F`；
  - 坐标用实数编码，朝向和材料用整数编码；
  - 实数段使用 simulated binary crossover 和 polynomial mutation；
  - 整数段使用 single-point crossover 和 uniform mutation；
  - 每个候选解评价时先计算爆炸损伤和 `O1/O2`，再用嵌入式贪婪算法确定恢复顺序并计算 `O3`；
  - 约束处理使用 constraint-domination principle，将约束违反纳入非支配排序与选择。
- 必须保留的核心：
  - 防护布局和恢复顺序要在同一评价循环中耦合，而不是先布局后独立排程；
  - 外层染色体只编码长期/预防性决策，恢复顺序由评价阶段根据受损状态即时生成；
  - 后果目标不能只看设施破坏面积，要同时覆盖人员、资产和任务依赖；
  - 需要同时输出 Pareto 前沿和可执行布局/修复方案，否则难支持工程决策。

## 实验证据

- 案例设置：
  - 假想海外军事基地，矩形场地长 `120 m`、宽 `100 m`；
  - 包含 14 个设施，给出尺寸、人员、资产、材料选项和 MDI；
  - 威胁为 `250 kg` TNT 当量；
  - 两支维修队，每支配置成本为 `$1M`；
  - 一般设施最小间距为 `3 m`，危险品存储最小间距为 `15 m`，领导宿舍到总部最大距离为 `20 m`。
- 建筑材料：
  - 候选材料包括 wood frame、pre-engineered metal、unreinforced masonry、steel frame with lightly reinforced concrete masonry infill walls、reinforced concrete、reinforced concrete with lightly RCMU infill walls；
  - 单位面积成本约从 `$3341/m2` 到 `$4738/m2`；
  - 更强材料提高建设成本，但可降低损伤和后续停摆。
- NSGA-II 参数实验：
  - Python 实现，硬件为 Intel Core i7 2.60 GHz、16 GB RAM；
  - 作者比较 population、generation、mutation、crossover 等组合；
  - 选定 population `200`、generations `500`、mutation `0.1`、crossover `0.9`；
  - 该配置得到 97 个 Pareto 点，运行时间约 `18.4 h`；
  - 其它配置得到 27-94 个 Pareto 点，运行时间约 `2.3-28.8 h`。
- Pareto 结果：
  - 共得到 97 个 Pareto 方案，包括 3 个极端解和 94 个中间解；
  - `O1` 范围约为 `6.7%-55.1%`；
  - `O2` 范围约为 `$7.74M-$9.49M`；
  - `O3` 范围约为 `0.4-9.1 days`；
  - 作者观察到 `O1` 与 `O2` 负相关，`O1` 与 `O3` 正相关，`O2` 与 `O3` 负相关。
- 代表解：
  - S1 最小爆炸后果：`O1=6.7%`，`O2=$9.49M`，`O3=2.1 days`，`NI=2`，`TELI=$1.44M`；
  - S2 最低成本：`O1=55.1%`，`O2=$7.74M`，`O3=9.1 days`，`NI=60`，`TELI=$4.60M`；
  - S3 最小运营影响：`O1=7.5%`，`O2=$9.48M`，`O3=0.4 days`，`NI=4`，`TELI=$0.72M`；
  - S4 为成本不超过 `$7.95M` 的折中方案：`O1=20.0%`，`O2=$7.95M`，`O3=3.1 days`，`NI=12`，`TELI=$2.06M`。

## 局限与未来工作

- 作者明确指出的局限：
  - 场地设施数超过 50 时，布局组合搜索、Monte Carlo 爆炸仿真和二次型约束检查会显著增加计算负担；
  - 当前模型主要是二维平面，未充分刻画三维地形、多层结构和复杂爆炸传播；
  - 只考虑单次爆炸事件，未建模连续攻击、次生灾害或多模态威胁；
  - 仿真和目标值依赖威胁参数、材料参数和 MDI 估计质量。
- 作者未来方向：
  - 使用 hierarchical optimization 或 decomposition-coordination 提高大规模可扩展性；
  - 用 surrogate model 近似爆炸仿真输出，降低评价成本；
  - 扩展到三维场景、复杂地形、连续/多模态袭击和更真实的恢复过程。
- 我们认为仍需确认的问题：
  - 嵌入式贪婪恢复顺序是否在所有损伤状态下接近最优，论文未给出与精确排程或其它启发式的对比；
  - 100 次随机爆炸位置取最大损失是否足以代表尾部风险，采样方差未充分报告；
  - NSGA-II 与其它 MOEA/分解算法缺少系统比较，难判断性能来自模型、编码还是算法；
  - MDI、人员损失权重和经济损失权重包含管理偏好，实际部署需要审计和敏感性分析。

- 与已有设计知识的边界：

  - 不同于 [层级路径重构的约束感知 MRTA](../02_design_knowledge/K-hierarchical-route-reconstruction-constrained-mrta.md)，本文没有 route/robot 层级路线修复，而是设施损伤后的维修队恢复顺序；
  - 不同于 [结构启发初始化与多目标路径重联](../02_design_knowledge/K-structure-aware-initialization-multiobjective-path-relinking.md)，本文的核心不是路径重联或离散排列邻域，而是危险仿真嵌入评价和恢复计划耦合。
- 暂留在论文卡中的方法、原理或架构启发：
  - 五级爆炸损伤环和 equivalent deaths 的具体参数依赖安全工程场景，暂不单独成卡；
  - MDI 运营停摆公式较依赖军事/基地任务评价，暂作为该架构的可替换评价模块；
  - NSGA-II 的 SBX/多项式变异/单点交叉本身不是新知识。
- 局部创新线索：
  - 用 surrogate-assisted MOEA 替代逐候选 Monte Carlo 爆炸仿真；
  - 将最大损失目标扩展为 CVaR 或分位数风险，降低随机采样偶然性；
  - 用 MILP/动态规划/学习启发式替换简单贪婪恢复顺序；
  - 对材料选择加入预算分层或关键设施优先级，形成更可控的防护升级策略。
- 结构创新线索：
  - 构建“预防性布局-防护材料-灾后恢复”三层韧性 MOEA；
  - 将危险仿真作为评价器，把布局决策转成损伤分布、人员风险和停摆曲线；
  - 将恢复子问题作为内层解码器或后处理模块，让长期布局解始终附带可执行恢复计划；
  - 与动态/鲁棒优化结合，处理连续袭击、多灾害、多阶段修复和不确定威胁。
