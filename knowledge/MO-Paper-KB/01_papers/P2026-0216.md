# MOEA/D 综述：分解式多目标进化算法的过去与未来

## 一句话理解

这篇综述以 MOEA/D 为中心，先用教程解释“分解 + 协作”的基本机制，再按四个核心部件系统梳理 MOEA/D 的发展：权重向量设置、子问题标量化、选择机制和繁殖算子；随后扩展到约束、大规模、动态/不确定、昂贵优化、偏好融入、真实应用和未来方向。

## 论文性质与范围

- 本文是 survey，不提出新的优化算法，也没有新的 benchmark 实验。
- 主要价值是给出 MOEA/D 的结构化设计地图：
  - 从数学规划和 MCDM 中的分解思想，到 MOEA/D 如何把分解变成 population-based collaborative search。
  - 把 MOEA/D 的算法创新拆成可定位的组件：weight vector、subproblem formulation、selection、reproduction。
  - 将 MOEA/D 的扩展主题与整个 EMO 社区的未来方向连接起来。

  - `IEEE Transactions on Evolutionary Computation, Vol. 30, No. 3, June 2026`

## 基础框架

- MOEA/D 的两个基础功能组件：
  - **Decomposition**：用权重向量和 scalarizing function 把 MOP 分解为多个单目标子问题。
  - **Collaboration**：所有子问题并行协作，每个子问题维护 best-so-far solution；邻近子问题共享父代、子代或更新信息。
- 三类经典子问题：
  - **Weighted Sum (WS)**：简单凸组合，适合凸 PF，但对非凸 PF 有限制。
  - **Weighted Tchebycheff (TCH)**：不受 PF 凸性限制，但可能难区分 weakly dominated solutions。
  - **Penalty-Based Boundary Intersection (PBI)**：用沿参考方向距离 `d1` 和垂直距离 `d2` 权衡收敛与多样性，penalty 参数控制改进区域大小。
- 基本假设：
  - 邻近子问题更可能有相似目标函数、搜索景观或最优解结构。
  - 均匀权重向量只有在 PF 是 simplex 或接近 simplex 时才容易产生均匀解；断裂、强凸、尺度不均或复杂 PF 会让部分权重方向无解或偏置。

## 四个核心设计部件

### 1. Weight Vector Setting

- 固定方法：
  - 随机权重、uniform design、多层权重、Riesz `s`-energy 等。
  - 优点是实现简单、额外开销低，因此真实应用中仍很常见。
  - 局限是难适配 disconnected、badly scaled、strongly convex 或高维 PF。
- Model-based adaptation：
  - 通过估计 PF 形状后重新采样权重。
  - 代表路线包括 polynomial/curve model、Gaussian process、SOM、growing neural gas、LVQ 等。
  - 风险是模型会被早熟种群或欺骗区域误导。
- Delete-and-add methods：
  - 删除拥挤或无效权重，在稀疏或有前景区域添加新权重。
  - 包括 MOEA/D-AWA、RVEA*、邻域 simplex 新权重、基于 archive 的局部权重重置。
  - 作者指出高维 PF 中用有限权重表示整体 PF 仍受 curse of dimensionality 影响，更有前景的方向是把权重自适应到决策者偏好的 ROI。

### 2. Subproblem Formulations

- TCH variants：
  - AASF、weighted metrics family、generalized `Lp`、smooth TCH 等。
  - 核心是改变 contour line 和 improvement region，使子问题方向更贴合 PF。
- PBI variants：
  - 自适应 penalty `theta`、subproblem-specific penalty、IPBI、LTD 等。
  - `theta` 越大，improvement region 越小，多样性压力越强。
- Constrained decomposition：
  - 不在整个目标空间比较，而是在每个子问题的局部 niche 或 hypercone 内比较。
  - 包括 localized WS、MOEA/D-M2M 等，用来处理非凸、偏置或 disconnected PF。
- 作者归纳：
  - 所有 WS/TCH/PBI 改造的共同目标是让 scalarizing contour lines 与 PF 更匹配。
  - 但参数或模型调整仍可能被早熟种群误导；权重向量和子问题 formulation 的联合自适应仍研究不足。

### 3. Selection Mechanisms

- Mating selection：
  - 原始 MOEA/D 主要从邻域中选父代，开发性强但容易陷入局部。
  - 改进包括小概率全局选父代、按拥挤度跳出邻域、自适应 mating restriction、不同邻域大小 ensemble、基于解的聚类/距离邻域。
- Environmental selection：
  - 原始 MOEA/D 是 steady-state update，新子代可替换邻域多个父代，贪婪且可能损害多样性。
  - MOEA/DD 提出即使 dominated 或 infeasible，只要处于 isolated region，也应保留一定生存机会。
  - Stable matching selection 把环境选择建模为 subproblem-solution matching：子问题偏好收敛，解偏好多样性。
  - 作者指出 selection 的本质与 subproblem formulation 和 fitness assignment 深度交织，diversity 可以写进 formulation，也可以由 selection 机制显式维护。

### 4. Reproduction Operators

- Swarm intelligence：
  - PSO、ACO、ABC、cuckoo search、grey wolf、whale optimization 等都可接入 MOEA/D。
  - PSO 是 MOEA/D 中最常见的 SI reproduction operator。
- Model-based methods：
  - EDA、probabilistic graphical models、PBIL、cross-entropy、CMA-ES 等。
  - 核心是用当前环境中的候选解学习决策空间分布，替代固定交叉/变异。
- AOS and hyper-heuristics：
  - MOEA/D-FRRMAB 是 AOS for MO 的早期代表。
  - AOS/HH 需要在线解决另一个算子配置问题，本身也很难。
- Local search：
  - Nelder-Mead、KKTPM、Pareto local search、neighborhood search、SA、GRASP 等。
  - 对组合问题和工程问题尤其重要。
- 作者观点：
  - no-free-lunch 意味着没有通用赢家算子；算子往往要按问题特征定制。
  - LLM empowered automatic heuristics design 被作者列为可能绕开复杂 AOS/HH 配置的新方向，但知识边界和可靠性仍不清楚。

## 高级主题

- Constraint handling：
  - 分为 feasibility-driven methods、weight vector adaptation、convergence-diversity-feasibility 三方权衡。
  - 作者强调传统先可行后收敛/多样性会陷入窄可行域或局部可行区域；C-TAEA 代表双档案思路。
- Large-scale MOPs：
  - 主要路线是 cooperative coevolution 和 decision variable analysis。
  - 稀疏优化可转成 MOP，但需要同时评价 convergence、diversity 和 sparsity。
  - MMOP 需要同时维护 objective space 和 decision space 多样性。
  - Variable-length MOP 需要处理决策变量长度不固定和 PF 局部难度不均。
- Dynamic and uncertain environments：
  - 常见是变化后用预测模型生成 seed population。
  - MOEA/D 还能通过 weight vector distribution 适配变化。
  - transfer optimization 和 ensemble dynamic response strategy 是重要路线。
- Surrogate-assisted expensive optimization：
  - ParEGO 比 MOEA/D 更早把 surrogate + decomposition 用于昂贵 MOP。
  - MOEA/D-EGO、K-RVEA、RBF/ELM/SVM/classifier surrogate、多任务 GP、transfer learning 等构成主线。
  - 难点是多子问题代理建模成本、infill criterion 和高维距离核退化。
- Preference incorporation：
  - 目标从 approximating entire PF 转向 ROI。
  - MOEA/D 通过调整 weight vector distribution 接入 DM preference。
  - 分为 priori preference elicitation 和 interactive preference elicitation。

## 应用谱系

- Machine learning：
  - feature selection、neural architecture search、adversarial example generation、association rule mining。
- Routing：
  - TSP、VRP、pickup and delivery、location routing。
  - MOEA/D 在组合路由中常依赖专门 reproduction operators 和 local search。
- Engineering optimization：
  - antenna optimization、power systems、process control、search-based software engineering。
- Complex networks：
  - network clustering/community detection、critical node detection。

## 未来方向

- **Learning-enabled optimization**：
  - 方向包括 PS manifold modeling、Pareto set learning、deep reinforcement learning for MOCO、LLM empowered automatic heuristics design。
  - 作者认为 PSL 可把整个 PS 近似成一个模型，并通过采样简化 EMO。
- **Multiagent system versus MOEA/D**：
  - 理论上每个分解子问题可看作 agent，在邻域内协作搜索。
  - 这个视角在 matching-based selection 中已有触及，但 MAS 和 game theory 的潜力尚未充分利用。
- **Parallel computing**：
  - MOEA/D 的分散子问题天然适合并行，但需要把分解组件与现代异构平台的并行结构紧耦合，而不是事后并行化。
  - 未来关键是设计 subproblem 到 hardware parallelism 的映射函数，以及面向子问题特征的 adaptive distributed algorithm。
- **Theoretical studies**：
  - 理论研究仍落后于方法发展。
  - 现有理论主要关注标量化公式和参数关系、runtime analysis；但很多分析仍限于过度简化的合成问题。

## 可复用知识与创新线索

- 本文没有提出实现明确的新算子或新框架，因此不新建设计知识卡。
- 对现有知识库的价值：
  - 可作为 MOEA/D 相关卡片的总导航，尤其是分解式环境选择、参考向量调整、代理辅助、动态响应和偏好式优化。
  - 能帮助判断一个新算法贡献落在哪个组件：weight vector、subproblem formulation、selection、reproduction，或高级主题。
- 局部创新线索：
  - 对已有 MOEA/D 改造，先明确“改权重、改标量函数、改 selection、改 reproduction”中的最小插入点，避免多处同时改导致贡献不清。
  - 在不规则/断裂 PF 中，把权重向量 adaptation 与 subproblem formulation adaptation 联合设计，而不是只调整一侧。
  - 在 constrained MOEA/D 中显式建模 convergence-diversity-feasibility 三方权衡，而不是只做 feasibility-first。
  - 对昂贵 MOP，利用邻近子问题相似性训练 multitask surrogate，而不是每个子问题独立建模。
- 结构创新线索：
  - 构建“MOEA/D 四组件设计矩阵”：每个组件列出固定、模型驱动、自适应、偏好驱动和问题专用版本。
  - 用 MAS/game theory 重新解释子问题协作，把 mating、replacement 和资源分配做成 agent-level protocol。
  - 把 LLM 作为 heuristic design assistant，但要求人类给出 problem context、可执行约束和严格消融验证。
