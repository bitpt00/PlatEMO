# Automatic Fuzzy Architecture Design for Defect Detection via Classifier-Assisted Multiobjective Optimization Approach

## 一句话理解

本文面向含噪声和模糊不确定性的工业缺陷识别，把 FNN 架构搜索建成约束多目标 NAS，并用 NTK 可训练性约束和在线分类器辅助环境选择，在准确率、参数量和搜索成本之间取得折中。

## 问题与动机

- 研究问题和场景：智能制造中的缺陷识别存在灰度模糊、标签噪声和采集场景差异；FNN 能处理不确定性，但人工设计 FNN 架构繁琐且容易出错。
- 现有算法为什么不足：
  - 现有 NAS 多集中于 CNN，面对不确定缺陷数据时往往需要更大模型，泛化和数据需求受限；
  - 常规 NAS 只把架构设计当作准确率优化或准确率-复杂度折中，忽略候选架构自身的可训练性；
  - FNN 模块让计算图更复杂，低可训练架构即使形式合法也会浪费训练评价预算；
  - 回归式性能预测器需要大量已训练架构，少样本下容易把差架构预测为高性能并误导选择。
- 本文希望解决什么：自动搜索适合缺陷识别的 FNN 架构，在较低计算开销下同时获得较少参数和较高准确率，并让搜索过程显式避开低可训练候选。

## 核心理念与算法流程

- 核心理念：用一个快速可训练性指标先把明显不值得训练的 FNN 架构挡在外面，再用在线分类器从当前种群学习“好/差”相对关系，辅助多目标环境选择，避免完全依赖昂贵训练或不稳定回归预测。
- 主要流程：
  1. 从包含 CM、FM、PM、FCM 的搜索空间采样初始种群，并用宏观模块序列 + 微观超参数的两级编码表示架构。
  2. 计算初始可训练性约束 `eta_0`，并真实评价初始个体的参数量和缺陷识别准确率。
  3. 每代用当前种群构造分类器数据集：按 `I_SDE+` 指标排序，前 `tau` 个标为 good，其余标为 poor，并按 7:3 划分训练/评估集。
  4. 训练 ESVM 分类器，用 AUC 判断分类器可靠性，同时按指数公式更新当前可训练性阈值 `eta_t`。
  5. 用两级编码的交叉/变异生成候选子代；若分类器不可靠，只用 `eta <= eta_t` 放行；若可靠，则同时要求 `eta <= eta_t` 且分类器预测为 good。
  6. 收集到 `N` 个合格候选后形成子代种群，真实评价目标函数，迭代到终止条件后用 distance-based 方法选出最终 FNN 架构。
- 关键组成部分：
  - 约束多目标问题：目标为 architecture size (`#Params`) 和 defect recognition accuracy，约束为架构可训练性 `eta`。
  - NTK condition number：用 neural tangent kernel 的条件数刻画架构可训练性，`eta` 越小越容易训练；作者称单个架构计算该指标低于 1 秒。
  - 搜索空间：CM 负责高效特征提取，FM 处理不确定性，PM 降低空间尺寸和参数量，FCM 在尾部完成分类。
  - 改造 FM：融合 fuzzy logic representation、neural representation 和 fusion part，使 FM 可嵌入 CNN 的任意阶段。
  - 两级表示：macro level 保存模块序列，micro level 保存对应模块超参数；FM 的 micro 长度等于 fuzzy neuron 层数。
  - 在线 ESVM：用 bagging SVM 和 cost-sensitive loss 缓解 good/poor 标签不平衡，并用 AUC 触发可靠性门控。
- 可能被修改的位置：
  - 可将 NTK condition number 替换或扩展为梯度流、Jacobian、loss landscape 或 early-training proxy；
  - 可将 ESVM 替换为 pairwise classifier、ranking model、graph neural predictor 或 uncertainty-aware classifier；
  - 可将环境选择门控从硬阈值改成概率预算分配、分层真实评价或多保真训练；
  - 可把两级编码迁移到图拓扑 NAS、程序结构搜索或多模块工程系统配置。
- 必须保留的核心：低成本可训练性约束和在线好/坏分类器共同参与候选准入；当分类器不可靠时，算法必须退回到可训练性约束，避免分类器误导搜索。

## 实验证据

- 测试问题和对比算法：正文说明实验设计细节在补充材料 Section III，包括 datasets、implementation details 和 peer competitors。摘要列出四个缺陷识别数据集：ELPV、CODEBRIM、MIXEDWM38 和 WM-811K；对比包括 NAS-based 方法如 PV-Darts、CENAS、DR-FNAS、WSNAS、MateQNN，以及手工 FNN 如 HFCNN6、HFCNN10。
- 主要实验结论：
  - 摘要报告 CMFNAS 在 ELPV、CODEBRIM、MIXEDWM38、WM-811K 上分别达到 `94.77%`、`81.82%`、`98.99%`、`98.22%` accuracy。
  - ELPV 正文 Table II 比较 `#Params`、search cost、FLOPs、inference time、accuracy、precision、recall、F1、design method 和 fuzzy ability。由于 Markdown 中表格为图片占位，卡片只记录正文明确写出的数值和结论。
  - 在 ELPV 上，CMFNAS-C (Best) 相比 Light CNN 在 test accuracy、precision、recall、F1 上分别高 `1.15%`、`0.84%`、`0.45%`、`0.0071`。
  - CMFNAS-C (Best) dominates HFCNN6 和 HFCNN10；CMFNAS-B (Best) dominates PV-Darts；作者称 search cost 优于 PV-Darts，并相对 DR-FNAS 进一步提升搜索效率和准确率。
- 消融或机制证据：
  - 作者进行 constrained multiobjective framework、module-based search space、classifier、population setting 四类消融；正文结论称 constraint 能减少计算开销并提升模型准确率，classifier management 中 base model 和 division threshold 对性能关键。
  - 详细消融数值在补充材料 Section V，当前 Markdown 未包含具体表格。

  - 正文主要展开 ELPV 表格，其余三个数据集细节放在补充材料；

## 局限与未来工作

- 作者明确说明的局限：
  - 当前模块是线性组合，限制了特征利用；
  - 当前较简单的 FM 难以处理数据集中更复杂的不确定性；
  - 当前 constraint handling 仍不够高效，限制搜索效率。
- 作者未来工作：
  - 引入更灵活的模块拓扑，如 graphical topology，以提升最终架构的特征表示；
  - 集成更高级 fuzzy theory，如 linguistic intuitionistic fuzzy number 和 gradient-based fuzzy rule system，用更少参数增强 fuzzy information 处理能力；
  - 研究更有效的 trainability constraint handling，例如 boundary 和 repair methods。
- 我们认为仍需确认的问题：
  - NTK condition number 对不同数据规模、不同 FM 深度和不同训练超参数是否稳定；
  - AUC 阈值 `beta`、good 标签比例 `tau`、约束下界 `gamma` 与收紧速度 `cd` 是否需要自动调参；
  - 硬门控是否会过早丢弃潜在高性能但 early trainability proxy 不佳的架构；
  - 分类器训练和真实训练评价之间的预算收益，在更大搜索空间中是否仍明显。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“可训练性约束的在线分类器辅助 NAS”，因为它给出了清晰的候选准入接口：快速 trainability constraint 兜底，可靠时再叠加在线分类器判断，能迁移到多种昂贵架构/结构搜索。
- 暂留在论文卡中的方法、原理或架构启发：
  - FM 可以作为处理不确定性的可搜索模块，而不是固定在网络头部或尾部；
  - 两级编码能以较短染色体表达异构模块和变长超参数；
  - `I_SDE+` 可作为多目标种群中好/坏标签的动态构造器，而不是只用 Pareto dominance。
- 局部创新线索：
  - 用 rank/classifier 只筛选是否进入 expensive training，再用多保真训练决定最终环境选择；
  - 将 cost-sensitive ESVM 换成带不确定性的分类器，让低置信候选进入抽查队列；
  - 将 NTK trainability 与参数量、FLOPs、梯度稳定性组成多约束门控。
- 结构创新线索：
  - 构建“可训练性约束层 + 在线关系学习层 + 多目标环境选择层”的通用架构搜索框架；
  - 将该框架用于非神经网络结构优化，例如仿真流程、控制器结构或组合算法配置，其中每个候选都有低成本可执行性/稳定性 proxy。
