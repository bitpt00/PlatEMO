# Pareto fronts guided co-evolutionary algorithm for constrained multi-objective optimization

## 一句话理解

本文提出 PFCEA，用两个职责不同的种群处理不同类型的 CMOP：`PFPop` 先忽略约束追 UPF，再通过 single constraint priority 选择最有用的 single-constrained PF 来靠近 CPF；`BPop` 用 improved fuzzy constraint handling technique 同时权衡 objective value 与 total constraint violation，作为 UPF/SPF 失效时的稳健补位。两个种群谁作为 main population 由 external archive 的 reward accumulation 动态决定。

## 问题与动机

- 研究问题和场景：constrained multi-objective optimization problems，其中 CPF 可能狭窄、断裂、被不可行区域阻隔，且 UPF、single-constrained PFs 和 CPF 的几何关系因问题而异。
- 现有方法为什么不足：
  - CDP 强可行性偏好容易使种群落入局部可行区域并损失多样性；
  - epsilon、angle-based CDP、fitness weighting 等方法能缓和约束压力，但很难自动适应 UPF/SPF 与 CPF 的不同关系；
  - 利用 UPF 或 SPF 的方法只在辅助前沿与 CPF 相关时有效，若 UPF/SPF 与 CPF 无关会浪费预算或误导搜索；
  - 只平衡 total CV 与 objective values 的方法在有用 SPF 存在时又没有充分利用辅助前沿信息；
  - 固定双种群或固定主辅分工无法知道当前 CMOP 属于哪类几何关系。
- 本文希望解决什么：在线同时保留“利用 UPF/SPF 的快速引导”和“目标-CV 平衡的稳健搜索”两条路线，再用奖励累计决定哪条路线在当前问题和阶段更该主导。

## 核心理念与算法流程

- 论文把 UPF、SPFs 与 CPF 的关系概括为四类：
  - Case 1：UPF 与 CPF 不相关，但某个 SPF 与 CPF 相关；
  - Case 2：UPF 和部分 SPFs 与 CPF 相关；
  - Case 3：SPFs 更接近 UPF 而不接近 CPF；
  - Case 4：UPF、SPFs 与 CPF 都不相关。
- `PFPop` 面向 Case 1/2：
  - 早期忽略所有约束，先靠 objective search 接近 UPF；
  - 用 PPS 的 ideal/nadir change rate 判断是否粗略到达 UPF，阈值 `epsilon=1e-2`，窗口 `l=20`，`Delta=1e-6`；
  - 到达 UPF 后不立即停止，而是至少演化到 `beta*T`，避免 UPF 分布太不均导致 constraint priority 判断偏差；
  - 用 SCP 选择最有用约束 `Ch`，之后只考虑该单个约束，对应利用最有用 SPF 引导 CPF 搜索。
- `SCP` single constraint priority：
  - 对每个约束统计总违反度 `TC_i=sum_j CV_i(x_j)`；
  - 同时统计违反该约束的个体数量 `NC_i` 与最大值 `NCmax`；
  - 若 `NCmax>=0.8N`，优先选 `TC_i` 最大且 `NC_i>=0.8N` 的约束；
  - 若 `0.2N<=NCmax<0.8N`，选 `NC_i` 最大的约束；
  - 若 `NCmax<0.2N`，令 `Ch=0`，不选单约束 SPF；
  - 最大值打平时选最小 index 的约束。
- `BPop` 面向 Case 3/4：
  - 使用 Tchebycheff aggregation `g(x|lambda,z*)` 把 objective values 聚合成标量；
  - 对 total CV 在当前 population 内归一化；
  - 对两个解 `x,y` 同时计算 objective difference 与 CV difference；
  - 用 IFCHT 中的 fuzzy advantage `NF_xy` 比较两解，`sigma_g=0.3`、`sigma_cv=10*rf`、`theta=1e-4`；
  - 早期减弱 CV 影响，保留 promising infeasible solutions；后期放大 CV 差异，增强可行性收敛。
- Reward accumulation：
  - 前 `gamma*T` 代 `PFPop` 和 `BPop` 被等概率选作 main population，`gamma=0.5`；
  - 后期根据 archive contribution 调整选择概率，`pmin=0.1` 保证低贡献种群仍有最小机会；
  - reward `R_i` 由第 `i` 个种群 offspring 替换 archive solution 的数量 `AQ_i/N` 累加；
  - 这样在 SPF 有用的问题上提高 `PFPop` 概率，在 SPF/UPF 无关的问题上提高 `BPop` 概率。
- Algorithm 1 主流程：
  1. 初始化 `PFPop`、`BPop`、external archive `A`、weight vectors 和 neighborhoods。
  2. 每代计算 `BPop` 的 feasibility rate `rf`。
  3. 根据 `gamma*T` 或 reward 计算 `p1/p2`。
  4. 用 UPF convergence criterion 和 `beta/eta` 条件触发 SCP，得到 `Ch`。
  5. 按 `p1/p2` 选 main population 和 auxiliary population。
  6. 父代来源由 neighborhood probability `delta=0.9` 和跨群 parent probability `rmp=0.8` 控制。
  7. 同一 offspring 分别更新 `PFPop` 和 `BPop`：前者考虑 `Ch`，后者使用 IFCHT。
  8. 用 SPEA2 选择 `Pm union Q` 中的 `N` 个解，再更新 archive `A`。
  9. 当 archive 已满且 `t>=eta*T` 后，按 archive replacement 更新 rewards。

## 实验证据

- 实验设置：
  - Benchmark：DASCMOP、C-DTLZ、DC-DTLZ、LIRCMOP，共 33 个 CMOP。
  - Real-world CMOPs：disc brake design、front rail design、gear train design、two bar plane truss、reactor network design、process synthesis problem。
  - 比较算法：PPS、C3M、MOEA/D-FCHT、MOEA/D-DAE、MSCMO、URCMO、MTCMO、CMOEMT、CMEGL、CSEMT、MOEA/D-CMT。
  - `N=91`，`MaxFEs=150000`；30 independent runs；Wilcoxon rank sum test，显著性 0.05。
  - 指标：IGDp 和 HV；作者选择 IGDp 而非 IGD，因为 IGD 不是 Pareto compliant。
- 四组 benchmark 总体结果：
  - Table 3 的 total row 中，PFCEA 在 IGDp 上相对 PPS 为 `0/33/0`、C3M 为 `3/28/2`、MOEA/D-FCHT 为 `1/28/4`、MOEA/D-CMT 为 `6/20/7`。
  - HV total row 中，PFCEA 相对 PPS 为 `0/33/0`、C3M 为 `2/28/3`、MOEA/D-FCHT 为 `1/30/2`、MOEA/D-CMT 为 `3/25/5`。
  - Friedman mean ranking 显示 PFCEA 在 IGDp 和 HV 上均为四组 benchmark 的最佳算法。
- 分问题现象：
  - DASCMOP1-2 中 PFCEA 和 C3M 表现最好，原因是它们能利用 SPFs 信息。
  - DASCMOP3/6/9 需要同时平衡 feasibility、convergence、diversity，PFCEA 相对对比算法更有优势。
  - LIRCMOP1 的 UPF、CPF、SPFs 不相关，PFCEA 略差于 MOEA/D-FCHT，作者归因于 `PFPop` 消耗部分预算。
  - LIRCMOP7 中最有用 SPF 与 CPF 高度相似，PFCEA 能有效利用该 SPF。
  - LIRCMOP11/12 的 CPF 位于 narrow and discrete feasible regions，PFCEA 能找到所有 CPFs。
- 消融实验：
  - PFCEA 在六个变体的 Friedman ranking 中最好。
  - 相对 `PFCEA (with only IFCHT)`，PFCEA 的 IGDp/HV summary 为 `7/14/12` 和 `5/16/12`。
  - 相对 `PFCEA (with only SCP)`，PFCEA 为 `1/10/22` 和 `1/11/21`。
  - 作者总结 SCP 对 PFCEA 性能贡献大于 IFCHT；IFCHT 也优于原 FCHT，MOEA/D-IFCHT 不差于 MOEA/D-FCHT。
- 参数分析：
  - `gamma` 控制等概率探索阶段；`gamma` 太小探索不足，太大则推迟 adaptive main population selection；`gamma=0.5` 在六个候选值中 Friedman rank 最好。
  - `eta=0.4` 保证 reward accumulation 进入 exploitation 前有足够时间，`beta=0.2` 是 `eta` 的一半，用于 PFPop UPF 多样性补充。
  - SCP 系数 `(0.2,0.8)` 在五组组合中 mean rank 最好；但 Table 5 显示不同系数组合多数问题表现相似，说明 SCP 对系数不特别敏感。
- 优化过程分析：
  - LIRCMOP1 属于 Case 4，PFPop 找到的 SPF 不能帮助 CPF，reward 逐渐提高 BPop 的选择概率，BPop 后期随 IFCHT 约束压力增强而收敛到狭窄 CPF。
  - DASCMOP5 属于 Case 1，存在与 CPF 相关的 SPF，PFPop 的选择概率随 reward accumulation 上升。
- 真实问题：
  - 六个真实 CMOP 的 true CPF 未知，因此只用 HV。
  - PFCEA 不差于除 MOEA/D-FCHT 以外的所有对比算法；相对 MOEA/D-FCHT，PFCEA 在五个问题上更好，一个问题上更差。
- Data availability：作者声明 Data will be made available on request。

## 局限与未来工作

- 作者明确说明的局限：
  - PFCEA 仍含多个 control parameters，不同 CMOP 可能需要不同参数值；
  - 基于 reward accumulation 的 selection probability 在不同 evolutionary stages 可能并不总适合选择 main population。
- 作者未来工作：
  - 设计 adaptive methods 以避免人工调参；
  - 研究其它双种群 co-evolution strategies；
  - 按建议在 CMOEA 比较中把每次 trial 单独纳入 ranking process。
- 我们认为仍需确认的问题：
  - `SCP` 只选一个单约束 SPF，面对多个互补约束组合或非线性约束交互时可能不足。
  - `TC_i/NC_i` 基于当前 PFPop 分布；若 PFPop 在 UPF 上覆盖不均，priority 仍可能偏向局部约束。
  - `SPEA2` archive update 带来 `O(N^3)` 复杂度，在大 population 或 many-objective 场景下成本可能显著。
  - Reward 以 archive replacement 计贡献，可能偏向短期可替换收益，而不是长期可行域覆盖。
  - 真实问题只用 HV，且 true CPF 未知，无法区分可行性、收敛和多样性分别来自哪个模块。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：已新建 [UPF/SPF 奖励双种群约束搜索](../02_design_knowledge/K-upf-spf-rewarded-dual-population-cmop.md)，因为它提供了可直接移植的 CMOP 框架：一个种群利用 UPF/最有用 SPF，一个种群用 IFCHT 平衡目标和 CV，再用 archive reward 决定谁主导。
- 暂留在论文卡中的方法或启发：
  - `SCP` 的 `0.2/0.8` 分段阈值可作为局部 constraint priority heuristic，但单独建方法卡价值暂不超过新架构卡。
  - `IFCHT` 可独立替换 FCHT，但当前证据仍主要在 PFCEA 和 MOEA/D-FCHT 中验证，先作为架构卡模块记录。
- 局部创新线索：
  - 把 `SCP` 从单约束选择扩展为 top-k constraint subset，允许多个 SPFs 或 constraint combinations 共同引导。
  - 用 constraint-objective correlation、constraint activity、CPF proximity predictor 替代仅基于 `TC_i/NC_i` 的 priority。
  - 将 reward 从 archive replacement 扩展为 HV contribution、feasible coverage、SPF-to-CPF transfer success 或 long-horizon credit。
  - 给 `gamma/beta/eta` 加入可行率、UPF stability、archive improvement 的自适应触发。
- 结构创新线索：
  - 构建“多前沿专家池”：UPF expert、single-constraint SPF experts、balanced CV-objective expert、多约束 subset expert，由 bandit/RL 分配主导权。
  - 与参考向量方向级机制结合：不同 reference direction 可选择不同的 useful SPF 或不同的 BPop/PFPop 权重。
  - 与 surrogate-assisted CMOP 结合：代理预测每个 constraint SPF 与 CPF 的相似度，减少无效 SPF 搜索。
