# Utilizing simplified structural information for multiobjective community detection

## 一句话理解

论文提出一种基于 NSGA-II 的多目标社区检测算法：仍使用能降低搜索空间复杂度的 locus-based representation，但不再把 locus 向量只当普通邻接编码，而是把它诱导出的森林结构显式用于初始化、交叉和局部搜索。核心做法是用相似矩阵生成 label-based 初始社区，再通过 BFS 生成 rooted spanning forest 转回 locus 编码；演化中提高 pendant vertices/leaf nodes 的交叉概率；周期性把 Pareto 解解码成标签，用模块度增益做 pseudo local search，并同步修补 locus 基因。

## 问题与动机

- 研究问题：
  - 社区检测需要自动发现社区数量，并在内部连接密度、外部割边、模块度和真实标签一致性之间折中；
  - 单目标 modularity 方法容易受 resolution limit 影响，MOEA 能提供一组候选社区划分；
  - 大规模网络中搜索空间随节点数爆炸，locus-based representation 可降低复杂度并自然保证社区连通性；
  - 但既有 locus-based MOEA 常把所有节点等同处理，忽略 locus 编码本身诱导的森林结构。
- 现有方法为什么不足：
  - MOGA-Net、MOEA/D-Net、MOCD 等 locus-based 方法主要依赖普通遗传算子，缺少高效局部搜索；
  - MODPSO、MODTLBO/D 等 label-based 方法局部搜索方便，但没有利用 locus 编码的连通性和搜索空间压缩；
  - RMOEA 通过网络缩减提升规模适应性，NCMOEA 通过节点分类和相似矩阵初始化提升搜索质量，但仍没有直接利用 locus 向量的叶节点/森林结构；
  - 随机 mutation 在 locus 编码中可能引发宏观社区划分的大幅变化，反而破坏稳定演化。
- 本文希望解决什么：
  - 把 label-based 初始化的可解释性与 locus-based 搜索空间压缩结合；
  - 让 spanning forest、pendant vertices 和邻居标签成为遗传算子与局部搜索的结构接口；
  - 在大规模静态无向网络上提升模块度、NMI 和稳定性。

## 核心模型与算法流程

- 表示与目标：
  - 个体采用 locus-based representation：第 `i` 个基因取值 `j` 表示节点 `i` 与节点 `j` 属于同一社区，解码时由连通分量得到社区划分；
  - 多目标评价采用 KKM 和 RC，分别衡量社区内部连接密度与跨社区割边强度；
  - 最终性能用 modularity `Q` 和 NMI 评价，二者越大越好。
- 初始化：
  - 对每个个体随机选择 `k < sqrt(n)` 个中心节点；
  - 使用 diffusion kernel similarity matrix `S=exp(-(D-A))`，把非中心节点分配给相似度最高的中心节点，形成 label-based partition；
  - 对每个中心节点对应的社区诱导子图生成 rooted spanning tree，BFS 遍历时每个非根节点把父节点作为 locus value；
  - 中心节点或与中心断开的节点改指向随机邻居，保证 locus 编码可用。
- 叶节点交叉：
  - 基础部分为 uniform crossover，mask 概率为 `pc1`；
  - 额外为 pendant vertices/leaf nodes 生成 mask，概率为 `pc2`；
  - pendant vertex 定义为 locus 森林中的叶节点，作者把它视为社区边界候选，因此给予更高交叉机会；
  - pendant vertices 可在线性时间检测，适合嵌入普通 MOEA 循环。
- 为什么不使用 mutation：
  - locus 编码非常敏感，小的局部扰动可能改变连通分量，导致社区划分发生大幅宏观变化；
  - Fb-tvshow 上的预实验显示随机邻居 mutation `pm=0.1` 未提升模块度，且收敛曲线更不稳定。
- Pseudo local search：
  - 将 locus 个体解码为 label-based representation `temp`；
  - 按随机顺序遍历节点，候选标签为其邻居节点的社区标签；
  - 选择使模块度增益 `Delta Q` 最大的标签；
  - 同步把 locus 基因设为目标社区中某个随机邻居，尽量保持标签改动与 locus 表示一致；
  - 若是最后一次局部搜索，则直接返回 label-based 表示，因为最终目标是社区划分而不是 locus 向量本身。
- 总体流程：
  - 初始化 `Pop`；
  - 每代 tournament selection、pendant-aware crossover、用 KKM/RC 评价 offspring；
  - 用 NSGA-II 环境选择更新种群；
  - 每隔 `iv` 代对 Pareto optimal solutions 执行 pseudo-LS；
  - 最后一轮 pseudo-LS 返回标签划分作为最终输出。
- 复杂度：
  - 初始化中的 diffusion kernel similarity matrix 为 `O(n^3)`，节点标注约 `O(n^2)`，重构约 `O(m+n)`；
  - 每个解的 KKM/RC 评价约 `O(m+n)`，交叉 `O(n)`，环境选择约 `O(popsize log^2 popsize)`；
  - pseudo-LS 每个解约 `O(n^2)`；
  - 总体复杂度写为 `O(n^3 + popsize*(n^2 + maxgen*(log^2 popsize + m + n + n^2/iv)))`。

## 实验证据

- 实验设置：
  - Matlab 2023a，CPU i9-14900HX，内存 16GB，Windows 11；
  - population size 和最大代数均为 100；
  - 每个算法在所有网络上独立运行 15 次；
  - pseudo-LS 间隔 `iv=10`；
  - 正文 5.3 写 `pc1=0.4, pc2=0.6`，但 5.6 参数分析段写默认值为 `pc1=0.6, pc2=0.4`，需复现时核对；
  - baseline 包括 CoCoMi、DCRO、MOGA-NET、MODPSO、MODTLBO/D、RMOEA、NCMOEA，比较结果来自文献 [19]。
- 数据集：
  - 11 个真实网络：Karate、Dolphin、Polbook、Football、Email、Netscience、Fb-tvshow、Ca-GrQc、Ca-HepTh、PGP、Ca-HepPh；
  - 其中 Karate、Dolphin、Polbook、Football 有 ground truth；
  - LFR 合成网络两组：一组 `n=500..2500` 且 `mu=0.6`，另一组 `n=1000` 且 `mu=0.1..0.7`。
- 真实网络 modularity：
  - proposed MOEA 在 11 个真实网络上整体达到 best 或 second best；
  - Email、Fb-tvshow、Ca-GrQc、Ca-HepPh 等网络上 `Qmax/Qavg` 均优于对比方法；
  - Netscience 上略低于 RMOEA，PGP 上略低于 NCMOEA；
  - CoCoMi 在 Ca-GrQc、Ca-HepTh、Ca-HepPh 和 PGP 上 10 小时内未得到结果。
- 真实网络 NMI：
  - 在有真实标签的 4 个网络上，proposed MOEA 都取得最大 NMI；
  - 平均 NMI 在 Karate 和 Polbook 上最好；
  - Dolphin 和 Football 上平均 NMI 分别低于 RMOEA/NCMOEA 或 MODTLBO/D/RMOEA，但仍保持强竞争。
- Mutation 影响：
  - 在 Fb-tvshow 上加入 MOGA-Net 式随机邻居 mutation `pm=0.1` 后，模块度没有提升，收敛更不稳定；
  - 作者据此认为 locus-based representation 的微扰敏感性改变了 mutation 在传统 GA 中维护多样性的作用。
- 初始化消融：
  - Variant A 使用随机 locus-based 初始化；
  - Variant B 使用随机 label-based 初始化后再重构；
  - Variant C 先生成连续向量，再按最大值邻居转成 locus representation；
  - 原始初始化在大规模网络上显著优于三个变体，小规模网络上差异较小；
  - Variant A 和 B 的差异在 Wilcoxon signed-rank test 下不显著，说明相似矩阵节点分配比随机标签更重要。
- LFR 与参数分析：
  - `mu=0.1..0.6` 时 NMI 保持较好，`mu=0.7` 时明显退化；
  - `mu=0.6` 且 `n=500..2500` 时仍有满意表现；
  - `pc2=0` 退化为普通 uniform crossover，`pc1=0` 则只在 pendant points 上交叉，二者表现都差；
  - 增大 `pc1/pc2` 会先提升最大 modularity，再因扰动过强而退化。

## 局限与未来工作

- 作者明确局限：
  - pseudo-LS 提升效率，但不能保证解质量一致性，偶尔会导致性能退化；
  - 实验主要限于静态网络；
  - 参数默认值在正文中有不一致表述，复现需额外确认。
- 作者未来方向：
  - 开发带理论保证或 safeguard 的局部搜索，避免 LS 使个体退化；
  - 尝试不同 objective pairs；
  - 扩展到 dynamic networks、attributed networks 和 overlapping community detection；
  - 在 attributed networks 中把节点属性相似性加入目标函数和相似矩阵初始化。
- 我们认为仍需谨慎的问题：
  - diffusion kernel `O(n^3)` 对超大图可能成为初始化瓶颈，需要低秩近似或局部相似替代；
  - 最后一轮返回 label-based representation，说明最终解和演化中 locus 个体的语义并不总是一致；
  - pseudo-LS 不评价中间个体，依赖容忍较差个体带来的跳出能力，可能在噪声图上放大不稳定性；
  - baseline 结果来自 [19]，runtime 也声明仅供参考，因此时间比较不可作为严格速度结论；
  - pendant vertices 被视作社区边界是有用启发，但在树形/低度网络中叶节点未必等价于真实边界。

- 暂留在论文卡中的方法、原理或架构启发：
  - KKM/RC 目标组合是社区检测常用目标，本文主要贡献不在目标设计，暂不单独建卡；

- 局部创新线索：
  - 将 pendant vertex 改为 boundary uncertainty、edge cut contribution 或 neighbor-label entropy 共同识别边界节点；
  - 用低秩扩散核、personalized PageRank 或 GNN embedding 替换 `O(n^3)` similarity matrix；
  - 给 pseudo-LS 加 Pareto safeguard：只有 KKM/RC 或 modularity proxy 不显著变差时才接受；
  - 让 `pc1/pc2` 由叶节点成功交叉率、边界 NMI proxy 或模块度增益自适应控制。
- 结构创新线索：
  - 构建通用“标签空间规划 + 结构编码重构 + 边界高概率变异”的离散 MOO 模板：
    `label/cluster assignment -> spanning forest reconstruction -> boundary-focused crossover -> label-space local search -> encoding repair`；
  - 在图聚类、路网区域划分、任务簇分配中，把实体分组先转为树/森林/连通骨架，再让遗传算子作用于边界叶节点；
  - 将 pseudo-LS 的标签移动与多目标选择联动，让局部搜索输出多个非支配邻居而非单一贪婪标签。
