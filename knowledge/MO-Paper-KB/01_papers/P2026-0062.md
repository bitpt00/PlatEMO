# A fuzzy cross domain matrix machine for fault diagnosis under multi-objective domain

## 一句话理解

论文并非典型 Pareto 多目标优化，而是面向多对象/多任务机械故障诊断提出 FCDMM：在矩阵样本分类器中同时保留信号矩阵结构、利用跨任务共享信息，并用模糊隶属度和边界因子降低异常样本对非平行超平面的影响。

## 问题与动机

- 研究问题和场景：机械设备故障诊断中，需要同时诊断不同部件、不同位置或不同故障对象，例如轴承与齿轮、齿轮箱轴承与轧辊轴承；传感信号经特征变换后常呈矩阵形式，且工业现场可能存在异常样本、噪声和标注稀缺。
- 现有算法为什么不足：
  - 作者认为许多主流诊断模型是单任务学习，只利用当前任务信息；多工况或多部件场景中，类似故障在不同工况下表现不同，单模型可能泛化差。
  - 多任务 SVM 类方法能利用任务相关性，但通常输入为向量；若把矩阵特征强行展平，会破坏矩阵内部行列结构并带来维度灾难。
  - SMM、SSMM、ODMM、NPBSMM 等矩阵机器能保留矩阵结构，但主要关注当前任务，不能充分利用跨任务信息。
  - MTCEMM 和 MTTPKMC 已经研究多任务矩阵机器，但作者认为它们未在建模中充分考虑异常样本对超平面的影响，也未显式处理特征空间数据分布。
- 本文希望解决什么：
  - 直接处理矩阵形式的故障特征，避免向量化损失结构；
  - 在多任务学习框架中利用跨域/跨任务共性信息；
  - 通过 fuzzy cross-domain term 和 fuzzy membership 弱化异常样本对超平面的拉扯；
  - 通过 boundary factors 控制 margin errors，提高异常样本环境下的鲁棒性。

## 核心理念与算法流程

- 核心理念：把多任务故障诊断看成一组相关矩阵分类任务。每个任务既有共享超平面信息，也有任务特有偏差；同时用样本到类别中心的距离生成 fuzzy membership，对异常或不确定样本降低影响，使决策超平面更稳健。
- 输入与表示：
  1. 每个任务的训练样本为矩阵 `x_i in R^{m x n}`，标签为故障类别。
  2. 论文使用 symplectic geometric similarity transformation (SGST) 将 1024 点振动信号转为 `32 x 32` symplectic geometric coefficient matrix。
  3. 矩阵 kernel 定义为 `K(p,q)=(p^T q + k)^d`，用来保留矩阵样本内部结构。
- FCDMM 模型：
  1. 对正类和负类分别构造两个非平行超平面，类似 twin/SVM 思路。
  2. 所有任务共享公共信息 `w+ / w-`，每个任务再有任务特有偏移 `w_t+ / w_t-`。
  3. 在正/负超平面目标中加入 fuzzy cross-domain terms (FCT)，其核心是用 `S = 1 - 0.5(|x_i-c_i|/(r_i-epsilon))` 形成样本 fuzzy membership 对角矩阵；`c_i` 为类别中心，`r_i` 为样本点到中心的最大距离。
  4. 目标函数还包含 regularization，避免矩阵计算过度奇异。
  5. Boundary factors `sigma_1, sigma_2` 与 scale parameters `v_1, v_2` 用于控制错误边界；slack/relaxation 项允许部分样本位于间隔内或被误分，以降低异常样本影响。
  6. 正负两个超平面对应的优化问题互不影响，分别转化为两个二次规划/对偶问题求解。
  7. 未知样本按到两个超平面的距离进行分类：选择距离更近的类别。
- 参数选择：
  - `k2` 和 `k4` 直接影响训练结果，是最关键参数。
  - `v1, v2 in (0,1]` 主要缩放边界，对准确率影响较小；论文设 `v1=v2=0.4`。
  - 矩阵 kernel 中 `d` 通常取 2，`k` 为小自然数。
  - 因正负超平面独立，论文设 `k1=k3`、`k2=k4`，把调参压缩为 `k1,k2` 两个参数；实验中最佳为 `k1=0.1, k2=0.001`。
- 故障诊断流程：
  1. 加速度传感器采集多个故障部件和故障状态下的振动信号；
  2. 用 SGST 预处理成多任务矩阵数据集；
  3. 将多个任务训练集输入 FCDMM；
  4. 用测试集输出诊断结果并计算 Accuracy、Kappa、Recall、F1score、Precision。
- 可能被修改的位置：
  - SGST 特征可替换为时频图、谱图、Gramian angular field、recurrence plot 或深度特征矩阵；
  - fuzzy membership 可替换为密度、局部离群因子、置信度、类间边界距离或不确定性估计；
  - 参数选择可由 Bayesian optimization、交叉验证、低保真搜索或多目标准确率-时间权衡自动化；
  - FCDMM 可作为下游分类器嵌入特征选择、传感器选择或诊断策略优化。
- 必须保留的核心：
  - 直接保留矩阵样本结构，而不是简单展平；
  - 多任务共享信息与任务特有偏差同时建模；
  - fuzzy membership 用于降低异常/不确定样本对超平面的影响；
  - 边界因子允许适度 margin error，以换取异常样本鲁棒性。

## 实验证据

- 测试问题和对比算法：
  - 对比方法：DMTSVM、MTNPSVM、MTCEMM、MTTPKMC。
  - 指标：Accuracy、Kappa、Recall、F1score、Precision；另用 Friedman test 与 Nemenyi test 分析统计显著性。
  - 实验环境：MATLAB R2022a、Windows 11、12th Gen Intel i5-12450H、16 GB RAM、NVIDIA RTX 3060 GPU。
  - 数据预处理：每个工况 1024 个采样点为一个样本，经 SGST 得到 `32 x 32` 矩阵。
- Experiment 1：山东科技大学轴承与齿轮故障数据。
  - Task 1：6205 bearing，3000 rpm / 40 N，7 类：normal、inner race fault 0.2/0.4、outer race fault 0.2/0.4、ball fault 0.2/0.4。
  - Task 2：planetary gearbox，2000 rpm / 0.5 A，7 类：normal、sun gear pitting/fracture/wear、planetary gear pitting/fracture/wear。
  - 每类 200 样本，100 训练、100 测试。
  - FCDMM 在 Task 1 accuracy 为 98.86% ± 0.72%，Task 2 accuracy 为 99.57% ± 0.44%，均优于四个对比方法。
  - Task 1 中最佳 baseline MTTPKMC 为 97.29%，Task 2 中最佳 baseline MTTPKMC 为 96.71%，FCDMM 分别提升约 1.57 和 2.86 个百分点。
  - Confusion matrix 显示 FCDMM 在 Task 1 和 Task 2 分别仅有 3 和 2 个误分类类别，作者认为 FCT 使不确定样本更清晰。
  - 随机打乱并重新抽样 5 次后，FCDMM 在两任务各指标上仍最高。
  - 异常样本实验：每个 fault category 增加 10 个含随机振动信号的 abnormal samples，训练和测试各含 5 个异常样本；FCDMM 在异常样本环境下仍表现最好，作者归因于 fuzzy hyperplanes 和 fuzzy membership 对异常样本的加权。
- Experiment 2：安徽工业大学 rolling mill vibration characteristic platform。
  - Task 1：gearbox bearings，900 rpm / 2 kN，7 类：normal、outer ring crack、inner and outer ring crack、inner and outer ring ball crack、inner ring and ball crack、ball crack、cage fracture。
  - Task 2：roller bearings，60 Hz / 1200 rpm / 4 kN，7 类：normal、outer ring fault、inner ring and ball fault、inner race crack、steel ball fault、cage fracture、ball and outer race composite fault。
  - 每 fault state 200 样本，半数训练、半数测试。
  - 五次验证结果：Task 1 FCDMM accuracy 98.40% ± 0.32%，Task 2 FCDMM accuracy 99.28% ± 0.39%，均为最高且标准差最小。
  - Friedman test 给出 `chi_F^2=49.35`，自由度 `(4,95)` 临界值为 2.005；Nemenyi test 的 `CD=1.23`，作者据此认为 FCDMM 与其他方法差异显著。
  - 平均 rank：FCDMM 1.1，MTTPKMC 2.825，MTCEMM 2.925，MTNPSVM 3.75，DMTSVM 4.4。
  - 时间成本：FCDMM train/test/total 为 0.7789 s / 43.5528 s / 44.3317 s；比 DMTSVM、MTNPSVM 慢很多，也慢于 MTTPKMC，总时间低于 MTCEMM 51.0549 s。
- 消融或机制证据：
  - 论文没有严格组件消融，但提供异常样本加入实验，间接支持 fuzzy membership 和 boundary factors 对异常/不确定样本的鲁棒性贡献。
  - 参数图显示 `k1=0.1, k2=0.001` 在两个 Experiment 1 数据集上平均分类效果最好，说明模型对关键 compromise parameters 敏感。
- 证据边界：
  - 该文的“multi-objective domain”指多对象/多任务故障数据，不是多目标优化意义下的 Pareto objectives。
  - 没有与深度学习诊断模型、在线学习模型或真实长期流数据概念漂移场景对比。
  - 实验数据均为构造好的故障类别矩阵样本，数据不可直接从论文获得，Data availability 为 available on request。
  - 异常样本由添加 random vibration signals 模拟，是否代表真实工业异常/传感器漂移仍需验证。

## 局限与未来工作

- 作者明确说明的局限：
  - FCDMM 性能提升伴随更高计算需求；训练要解两个二次规划，参数优化也耗时。
  - FCDMM 采用 one-vs-one strategy，所需时间会随样本类别数增加。
  - 当前 FCDMM 是 batch learning model，不适合在线学习；工业设备工况和退化模式随时间变化，需要定期用新数据重训练。
  - 若只诊断单一部件或多个任务彼此不相关，单任务分类器更合适。
- 作者未来工作：
  - 开发 adaptive parameter selection algorithm，例如 Bayesian optimization framework，自动调节参数并降低调参开销。
  - 将 FCDMM 扩展到 online learning，应对 operating conditions 和 degradation patterns 的 concept drift。
  - 将 FCDMM 扩展到 limited-sample fault diagnosis。
- 我们认为仍需确认的问题：
  - Fuzzy membership 用类别中心和最大距离构造，遇到多峰类别、非凸分布或严重类别不平衡时可能不稳定。
  - 模型核心仍是二次规划和 one-vs-one 分类，大类别数、多任务数或高分辨率矩阵输入下扩展性需要系统评估。
  - 异常样本模拟较简单，真实工业异常可能包括传感器失准、工况漂移、未见故障、新设备差异和标签噪声。
  - 如果作为多目标优化中的 surrogate/classifier，需要进一步考察它对少样本、高噪声、跨工况迁移的校准置信度。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 本篇暂不建立设计知识卡。原因是它是多任务矩阵分类/诊断模型，和当前知识库已有多目标优化机制卡片没有直接同类关系；虽然 FCDMM 有可借鉴的 fuzzy abnormal-sample weighting，但单篇证据主要服务于 fault classification，暂留论文卡即可。
- 暂留在论文卡中的方法、原理或架构启发：
  - 对矩阵特征不要轻易向量化：在振动诊断、图像式时频特征、材料显微图、过程监控矩阵中，保留结构可能优于展平。
  - 用样本到类别中心的 fuzzy membership 作为鲁棒权重，可以迁移到 surrogate 训练、可行/不可行分类、异常候选过滤等场景。
  - 多任务共享超平面 + 任务偏移的结构，可用于跨设备、跨工况、跨材料系统的小样本建模。
- 局部创新线索：
  - 在多目标特征选择中，将 FCDMM 作为分类性能评价器，目标为 accuracy、selected features、推理时间或鲁棒性。
  - 用 Bayesian optimization 自动调 `k1,k2,k,d,v`，形成准确率-时间的多目标调参。
  - 将 fuzzy membership 换成 uncertainty-aware weights，例如 ensemble disagreement、local density 或 conformal score。
  - 用 online/continual FCDMM 处理概念漂移，把任务偏移项随时间更新。
- 结构创新线索：
  - 构建“多工况矩阵特征 -> 共享/任务特有分类器 -> fuzzy 异常样本降权 -> 维护建议”的工业诊断模块，可与多目标维护调度或传感器布置优化连接。
  - 在多目标诊断策略中，把 FCDMM 输出的 fault confidence、uncertainty 和 task similarity 作为上层优化的状态或约束。
