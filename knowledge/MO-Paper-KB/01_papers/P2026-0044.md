# Probabilistic electric load forecasting via adaptive online learning and multi-objective optimization: A NA-TP forecasting approach

## 一句话理解

论文提出 NA-TP Forecasting：先用 Granger causality 从天气、日历、发电侧等候选变量中筛出对负荷有因果预测价值的特征，再用 Transformer 做概率预测；在线部署时，AOPF 根据 streaming loss 的 z-score 和 dynamic local regret 只在检测到持续漂移时更新 decoder；最后用 QR-AEP、Q-Risk 和 PIW 三目标优化构造 Pareto 前沿，让调度人员在量化精度、概率校准和区间宽度之间选操作点。

## 问题与动机

- 研究问题和场景：
  - 实时电力负荷预测受到天气、节假日、可再生能源接入和用户行为变化影响；
  - 静态离线模型难以及时适应 distribution shift；
  - 负荷预测不仅要点预测准确，还要给出可靠且不太宽的预测区间；
  - 过度低估负荷在电网运行中可能比过度高估更危险，因此误差代价不对称。
- 现有方法为什么不足：
  - ARMA/ARIMA/Holt-Winters 假设平滑和线性，难处理复杂非线性长序列；
  - RNN/LSTM/GRU 能处理序列，但特征抽取和长程依赖能力仍有限；
  - 许多 Transformer 概率预测模型离线训练、静态部署，或按固定窗口微调；
  - 在线方法常用启发式 drift detector，缺少 regret/local regret 信号；
  - 概率预测常只优化 NLL、pinball loss 或 CRPS，coverage deviation 与 interval sharpness 往往后处理。
- 本文希望解决什么：
  - 在一个框架中结合 causal feature screening、Transformer 概率预测、regret-aware online update 和三目标 Pareto 优化；
  - 同时降低非对称分位误差、改善概率校准并压窄预测区间；
  - 通过稀疏在线更新保持毫秒级部署延迟和较低 adaptation cost。

## 核心理念与算法流程

- 四阶段框架：
  - 数据预处理：聚合历史负荷、天气和时间特征，使用 polar/cyclic encoding，并用 ADF test 检查平稳性；
  - 因果筛选：用 Granger causality 和数据集特定 VAR lag 选择外生变量；
  - 在线概率预测：用 Conv1D + positional encoding + Transformer encoder + probabilistic decoder 做 MLE 或 quantile 输出；
  - 多目标优化：用 Optuna MOTPE 近似 QR-AEP、Q-Risk 和 PIW 的 Pareto 前沿。
- AOPF 动态更新触发：
  - 对每个时间步计算 streaming loss；
  - 在滑动窗口中维护 loss 的均值和标准差；
  - 计算 z-score 异常度；
  - 用 sigmoid 映射得到动态阈值系数 `c_t`，并限制在 `c_min` 与 `c_max` 之间；
  - 只有当 `loss_t > loss_mu + c_t * loss_sigma` 时才进行在线更新；
  - 更新时用 dynamic local regret 的指数加权梯度和 Adam 更新 decoder 参数。
- 三目标概率预测：
  - QR-AEP：带 under-/over-prediction 不对称惩罚的 quantile regression loss；
  - Q-Risk：预测 quantile 的 empirical coverage 与目标 quantile 的偏差；
  - PIW：上、下分位数之间的平均 prediction interval width；
  - MOTPE 维护非支配 trial 集，采样更可能产生 Pareto-efficient 配置的超参数。
- 代价不对称校准：
  - 生成 -10% 到 +10% 的 controlled error scenarios；
  - 计算 mean percentage error 与 percentage cost error；
  - 对 under-/over-prediction 分别拟合 cost sensitivity；
  - 将回归斜率归一化为 QR-AEP 的不对称惩罚系数；
  - 文中使用 `alpha_u=0.4`、`alpha_o=0.2` 表达 under-prediction 更高的运行风险。

## 实验证据

- 论文实验直接支持：
  - AOPF 结果按正文总结显示在线稀疏更新可改善多项预测指标并降低适应成本；
  - MOTPE 的 Pareto 代表解直接展示 QR-AEP、Q-Risk 与 PIW 之间的 operational trade-off，但表 10-13 的细粒度数值仍受 Markdown 图片占位限制。
- 数据与场景：
  - 使用多个 real-world benchmark electricity load datasets；
  - 明确展开 Vietnam 与 Valencia_Spain 的 Granger scenario；
  - 四类场景包括 Base、High、Low、Mixed；
  - 表 8 给出 Vietnam 与 Spain 场景中的输入变量组合。
- 因果筛选：
  - Vietnam 中 solarenergy、uvindex、WEnd、HVa、psin_h、pcos_h 等变量被检测为与负荷有显著 Granger causality；
  - Spain 中多数 generation-related、weather 和 hourly/weekly cyclic variables 与负荷显著相关；
  - 作者按数据集选择 VAR lag：Vietnam 为 1，Valencia_Spain 为 4。
- 在线预测结果：
  - Table 10/11 比较 offline Transformer 与 MLE_AOPF、QR_AOPF；
  - 正文总结 AOPF 通常降低 RMSE/MAPE、CRPS 和 Winkler95，同时仅需 sparse online updates；
  - Table 12 与 SARIMA Online、LSTM Online 比较，作者认为 Transformer backbone + AOPF 在 drift 场景下更稳定；
  - Table 13 与 Informer-Q、Autoformer-Q、TFT、DeepAR 比较，NA-TP variants 多数场景 best 或 second-best；
  - 作者强调 millisecond-level latency、low update frequency 和 low total adaptation cost。
- 多目标优化结果：
  - Table 14 给出 Vietnam 与 Valencia_Spain 各场景的代表性 Pareto solutions；
  - 每个场景用 A/B/C 表示 reliability-oriented、balanced 和 sharper regimes；
  - 例如 Vietnam GrangerL1 中 Q-Risk 从 A 的 0.0717 到 C 的 0.0441 下降，PIW 从 128.6 到 109.7 变窄，但 Pinball 从 350.34 到 370.55 变差；
  - 作者总结 lower Q-Risk 通常伴随 wider uncertainty bands，而 narrower PIW 可能牺牲 calibration；
  - Pareto set 作为 operational decision layer，允许不同 grid contexts 按风险偏好选配置。
- 证据边界：
  - 表 10-13 在 Markdown 中是图片占位，无法从文本逐项核对所有数值；
  - MOTPE 每个 scenario 仅 30 trials，Pareto 前沿可能只是粗略近似；
  - Granger causality 是线性、滞后相关意义上的因果筛选，不等于干预因果；
  - 成本不对称的 `alpha_u/alpha_o` 采用简化代理，真实电力市场结算和应急采购成本可能更复杂。

## 局限与未来工作

- 作者明确说明的未来方向：
  - 深度集成 advanced attention mechanisms 或 domain-adaptive transformers；
  - 扩展到更大规模、多源数据，包括 weather、user behavior 和 electricity market signals；
  - 与 streaming architectures、digital twins 和 cyber-physical power system platforms 集成，形成实时决策支持。
- 我们的判断/仍需确认的问题：
  - AOPF 只更新 decoder 参数时，长期 seasonal regime 变化是否需要 encoder 或 feature extractor 微调；
  - z-score threshold 在 heavy-tailed spike 场景下是否需要 robust scale，如 MAD 或 quantile scale；
  - QR-AEP、Q-Risk、PIW 的多目标优化是否在线重跑，还是离线给出少量配置后部署；
  - 预测区间 coverage 是否需要 conformal calibration 作为外层安全保证；
  - Granger 特征筛选在非线性关系、共线变量和隐变量存在时可能漏掉有价值外生变量。

- 值得建立或补充的设计知识：
  - 新建设计知识：[Regret 触发的 Pareto 概率预测](../02_design_knowledge/K-regret-triggered-pareto-probabilistic-forecasting.md)。它把“在线概率预测 + 漂移触发更新 + 三目标 Pareto 操作层”抽象为可迁移的时序预测-决策接口。
- 与已有设计知识的边界：
  - 不同于 [鲁棒解空间观测的时间联动分布预测](../02_design_knowledge/K-solution-space-observed-time-linkage-distribution-rmo.md)，本文预测的是负荷概率分布和预测区间，不是从优化 archive 预测扰动分布再做鲁棒 MOO；
  - 不同于 [预测嵌入的中断感知供应链多目标规划](../02_design_knowledge/K-prediction-embedded-disruption-aware-supply-chain-moo.md)，本文没有把预测参数写入 MILP 约束，而是直接把概率预测模型的训练/配置做成 Pareto 操作层；
  - 不同于 [预测代理驱动的实时多目标控制优化](../02_design_knowledge/K-predictive-surrogate-driven-real-time-moo-control.md)，本文的核心不是代理优化控制参数，而是在线概率 forecasting 的校准、sharpness 与更新触发。
- 局部创新线索：
  - 用 robust z-score、conformal residual 或 Page-Hinkley detector 替代普通标准差阈值；
  - 在 Pareto 目标中加入 update cost、latency、coverage under extremes 或 CVaR；
  - 把 Granger 筛选替换为 nonlinear causal discovery、PCMCI 或 attention-based causal stability score；
  - 用 preference-conditioned forecasting head 输出不同 risk/sharpness 偏好的区间；
  - 在线阶段按当前 drift type 从 Pareto set 中切换 operating point。
- 结构创新线索：
  - 通用框架：causal feature gate -> probabilistic sequence model -> regret/z-score update trigger -> tri-objective calibration/sharpness optimizer -> operator-facing Pareto selector；
  - 可迁移到风光功率预测、交通流预测、需求预测、库存补货预测和云资源 workload 预测。
