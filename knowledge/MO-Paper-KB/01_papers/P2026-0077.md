# Bi-objective optimization for electric vehicle scheduling under vehicle-to-grid integration

## 一句话理解

本文把 EV 充放电调度拆成“出行需求预测 + 动态耗能估计 + V2G 双目标优化”三段：先用 GM(1,1)、旅行链、Markov chain 和 Monte Carlo 生成 EV 时空负荷，再用温度、空调、道路类型和拥堵修正电池耗能，最后用 IMOBFO 搜索充放电策略，同时最小化用户总成本和电网负荷波动。

## 问题与动机

- 背景：
  - EV 渗透率上升会把随机充电需求叠加到居民用电高峰；
  - 单纯 TOU 电价可引导低价时段充电，但大规模集中响应可能在低谷时段制造新峰值；
  - V2G 允许 EV 在高负荷时段向电网放电，在低谷时段补能，可同时服务用户收益和电网削峰填谷。
- 用户侧困难：
  - 用户有里程焦虑，不愿牺牲下一段出行所需 SOC；
  - 出行时间、停车时长和目的地区域具有强时空差异；
  - 电池耗能受温度、空调、道路类型和拥堵影响，固定能耗模型会误判可调度电量。
- 电网侧困难：
  - 无序充电会出现 peak-on-peak；
  - 仅按低价充电会在 valley hours 集中形成新负荷峰；
  - 调度目标需要同时考虑用户成本和 load curve fluctuation。
- 本文目标：
  - 构造更贴近实际出行和能耗的 EV 负荷预测模型；
  - 建立 V2G 充放电双目标调度；
  - 用 IMOBFO 输出 Pareto 充放电方案，并和七个算法比较。

## 时空负荷预测

- EV ownership forecast：
  - 上海 2013-2022 年 EV 保有量数据较短，作者使用 GM(1,1) 灰色预测；
  - 用 PSO 估计 GM(1,1) 参数，相比最小二乘更贴合历史趋势；
  - 文中 PSO 得到 `a=-0.3336`、`b=4.6425`，最小二乘为 `a=-0.3720`、`b=3.8968`。
- Travel chains：
  - 区域分为 residential areas、work areas 和 business areas；
  - 四类旅行链：居住-工作、居住-商业、居住-工作-商业、居住-商业-工作；
  - 工作日出行率设为 77%，工作相关出行占 79.25%，四类链比例为 65%、15%、10%、10%；
  - 周末出行率设为 70.4%，四类链比例为 15%、75%、5%、5%。
- Travel start time：
  - 工作日出行起始时间有两个峰：08:00-09:00 和 16:00-18:00；
  - 周末出行起始时间有两个峰：11:00-13:00 和 16:00-18:00；
  - 作者分别拟合工作日和周末起始时间分布。
- Spatial transition：
  - 居住区节点按人口占比采样；
  - 工作区节点按区域规模 roulette sampling；
  - 商业区选择同时考虑从前一节点到商业区的 travel time penalty 和商业区规模吸引力。
- Path decision：
  - 交通网络包含 secondary roads、main roads 和 expressways；
  - 拥堵分为 unimpeded、lightly congested、moderately congested、severely congested；
  - 路段权重由距离、拥堵系数、道路类型系数和平均速度得到；
  - 用 Floyd algorithm 求节点间最短时间路径；
  - Markov chain 和 Monte Carlo 用于生成 EV 用户在时间和空间上的状态转移与负荷需求。

## 动态电池能耗模型

- 温度影响：
  - LiFePO4 电池相对容量 `CR%` 随温度非线性变化；
  - 高温环境下容量略升，40 C 相比 25 C 高 3.2%，超过 45 C 后开始下降；
  - 低温影响更显著，-20 C 时相对 25 C 低 56.4%；
  - 作者用多项式拟合温度与相对容量关系。
- 空调影响：
  - 夏季制冷和冬季制热的启停概率由温度决定；
  - 作者用分段曲线和正态分布函数拟合空调开启概率；
  - 空调功率作为额外耗能进入总耗能。
- 道路和拥堵影响：
  - 能耗按 expressway、main road、secondary road 的速度关系计算；
  - 工作日/周末与具体时间段决定拥堵等级；
  - 拥堵越严重，行驶时长修正系数越高，能耗和充电需求越大。
- 总耗能：
  - `E_all,T` 同时包含基础单位里程能耗、空调能耗、路段行驶时间、路段距离、拥堵修正和温度下容量变化；
  - 该模型决定下一段出行所需 SOC，从而约束 V2G 可放电量。

## V2G 双目标调度模型

- 调度窗口：
  - EV 不处于驾驶状态时形成可调度 time window；
  - 每个停车节点有接入时间、停车时长和离开时间；
  - 离开前必须满足下一段出行需要的 SOC expectation。
- 控制变量：
  - `vartheta_n,t=1` 表示 EV `n` 在时刻 `t` 充电；
  - `phi_n,t=1` 表示 EV `n` 在时刻 `t` 放电；
  - 二者不能同时为 1；
  - SOC 随充电、放电和行驶耗能更新。
- 约束：
  - 充放电功率在最小/最大功率范围内；
  - SOC 保持在 `SOC_min` 与 `SOC_max` 之间；
  - 离网 SOC 需满足下一段出行需求，若停车时间不足，则尽量连续充电到可达最大值；
  - 只有当放电收益大于电池退化、补能时间和相关成本时，用户才参与放电。
- 三种策略：
  - disordered charging：接入后立即充满，不考虑 V2G；
  - ordered charging：在 TOU tariff 下尽量选择低价时段充电；
  - ordered charging and discharging：在 V2G 下同时考虑充电成本、放电收益、电池退化成本和补能时间成本。
- 两个目标：
  - 用户侧：最小化 total cost，包含 charging cost、discharging gain、battery degradation cost 和 replenishment time cost；
  - 电网侧：最小化 load variance，平滑各时段负荷曲线。

## IMOBFO 求解器

- 基础 BFO：
  - 模拟 bitterling fish 搜索和争夺 oyster 的行为；
  - `J(t)` 随迭代下降，使搜索从全局探索逐步转向局部开发；
  - 若目标已被其他个体占据，则执行逃逸或随机搜索；
  - 弱个体按适应度相关概率被移除。
- 多目标处理：
  - 不使用 weighted-sum；
  - 先按 Pareto dominance 分层；
  - 用 dominance intensity 表示不同层级的优先级；
  - 同层个体用 crowding distance 保持分布；
  - 非支配排序和拥挤距离用于获得 Pareto-optimal solutions。
- Tent chaos：
  - 在初始化中引入 Tent chaotic map；
  - 增强初始个体随机性和覆盖范围，缓解早熟收敛。
- 约束处理：
  - 超出充放电功率或 SOC 边界时进行 clipping；
  - 若 SOC 调整后仍不可行，则根据低/高电价优先规则和 proximity rule 调整决策变量；
  - 目标是逐步消除冲突，保证候选解满足调度约束。
- 复杂度：
  - 作者给出时间复杂度 `O(MaxGen * Npop * Npev * Dim)`；
  - 决策变量有 `Npev x T` 的二维结构。

## 实验设置

- 案例：
  - 上海某区域交通网络；
  - 论文区分区域属性和道路等级，并在规划区道路网络上生成出行路径。
- 参数：
  - charging power：7 kW；
  - charging efficiency：85%；
  - battery capacity：50 kWh；
  - battery energy consumption：15 kWh/100 km；
  - discharging efficiency：90%；
  - discharging loss cost：0.05；
  - TOU tariff：valley 0.3085 yuan/kWh，normal 0.6170 yuan/kWh，peak 0.9872 yuan/kWh。
- 情景：
  - 电池能耗分为 normal temperature、high-temperature、low-temperature；
  - 时空负荷分为 weekdays 和 weekends；
  - 两者组合成 6 类典型场景。
- 算法：
  - 对比 PSO、IDE、LCBO、NRBO、IVY、NSGA-II、MOEA/D；
  - 单目标算法被扩展为非支配排序 + crowding distance 的多目标版本；
  - 每个算法 iterations 50，population size 30；
  - IMOBFO 参数 `J(1)=1`、`U(1)=1`、`a=0.5`；
  - MATLAB 2021b，Apple M1 Pro CPU，16 GB RAM，macOS Monterey；
  - 算法比较中每个算法独立运行 20 次。

## 主要结果

- Ordered charging 的作用：
  - normal-temperature weekend 的 on-demand charging 中，ordered charging 相比 disordered charging 同时降低负荷标准差和总成本；
  - Table 6 中 standard deviation 从 11.1664 降到 11.1013，sum of costs 从 502.1921 降到 492.5619；
  - full-charging mode 中 ordered charging 的成本从 8602.3906 降到 6936.7166，但 standard deviation 从 672.4728 增到 816.3847；
  - 说明 TOU 会省钱，但满充场景可能在低价时段制造新峰值。
- 温度影响：
  - 充电负荷排序为 low-temperature > high-temperature > normal temperature；
  - 低温使电池容量下降并增加采暖耗能；
  - 高温和低温下的新增负荷集中在 23:00-06:00 和 12:00-18:00，可能加剧 peak-on-peak。
- V2G 双目标策略：
  - normal-temperature 示例中，V2G bi-objective strategy 相比原始 base load 将方差降低 77.1%；
  - 相比 disordered charging 降低 61.6%；
  - 相比 ordered charging 降低 52.4%；
  - high-temperature 场景下，相比分别为 69.0%、51.0%、37.5%；
  - low-temperature 场景下，相比分别为 71.6%、49.5%、38.3%；
  - 论文认为 V2G 充放电策略能在季节变化下稳定降低峰谷差。
- IMOBFO 对比：
  - GD mean：IMOBFO 为 0.0178，低于 PSO 0.1265、IDE 0.3198、LCBO 0.0929、NRBO 0.2463、IVY 0.3304、NSGA-II 0.3643、MOEA/D 0.0839；
  - IGD mean：IMOBFO 为 0.0429，低于其他七个算法；
  - HV mean：IMOBFO 为 0.8254，高于 LCBO 0.6593、MOEA/D 0.5507、PSO 0.3876 等；
  - GD/IGD/HV 的方差也较低，说明稳定性较好；
  - Pairwise statistical tests 显示 IMOBFO 相对每个对比算法的差异显著，除 GD 对 MOEA/D 为 `p<0.003` 外，其余多数为 `p<0.001`。

## 局限与未来工作

- 作者明确局限：
  - 预测模型仍需继续细化；
  - 用户与电网双方利益还可进一步综合；
  - 当前验证受区域约束和仿真偏差影响；
  - 未来需要扩展到更多城市情境并在真实应用中迭代验证。
- Data availability：
  - 数据可用性需联系 corresponding author。
- 我们认为仍需确认：
  - Markov chain 与 NHTS/传统车数据替代 EV 出行的假设，在高渗透 EV 场景中是否仍可靠；
  - V2G 用户参与意愿、合同补偿和电池寿命认知是否会显著改变可调度放电量；
  - 充电桩容量、排队、配电网潮流和电压约束未显式展开，实际部署需补充；
  - IMOBFO 优势来自 Tent 初始化、BFO 更新还是约束修复，缺少严格组件消融。

## 可复用创新线索

- 把用户参与概率纳入 V2G 控制变量：不同用户按里程焦虑、收益敏感度和电池健康偏好设定放电概率。
- 将 load variance 目标替换为配电网潮流指标，例如 transformer loading、voltage deviation 或 feeder congestion。
- 用预测场景生成 Pareto 调度：weekday/weekend、温度和电价情景共同形成鲁棒 V2G 优化。
- 将 IMOBFO 的 dominance intensity + crowding 替换为 reference-vector、indicator 或 preference-based selection，适配更多目标。
- 用 rolling MPC 处理实时交通、气温和用户临时出行变更。
- 引入电池退化的非线性循环模型，避免简单线性放电损耗低估深度放电风险。
