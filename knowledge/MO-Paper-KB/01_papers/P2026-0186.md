# 数据流驱动动态多目标优化中的代理迁移

## 一句话理解

ST-MOEA 面向一种更受限的动态多目标场景：算法不能主动调用真实目标函数，只能使用当前时间步持续到来的带目标值数据流。它把 Kriging 和 RBFN 同时训练成目标函数代理，并把上一时间步的代理超参数迁移到当前时间步，再用 Kriging 不确定性筛选两个代理搜索出来的可靠解。

## 研究问题

- 常规 DMOP 假设算法可以在每个时间步主动评价新候选解。
- 本文定义的 DDMOP 更受限：
  - 数据以 time-ordered data stream 到达；
  - 每条数据包含决策解和对应目标值；
  - 目标函数随时间连续变化；
  - 算法不能主动调用目标函数，只能在下一次变化前利用当前数据流完成优化。
- 直接套用动态 MOEA 会失败，因为它们需要大量实时函数评价。
- 直接套用 offline data-driven MOEA 也不足，因为它们通常只处理当前时间步数据，没有利用相邻时间步之间目标函数平滑变化所带来的历史代理信息。

## 方法框架

### ST-MOEA 总流程

- 输入当前时间步数据流 `S[t]`，以及上一时间步的 Kriging 模型 `K[t-1]` 和 RBFN 模型 `R[t-1]`。
- 分别训练当前时间步的 Kriging 代理 `K[t]` 和 RBFN 代理 `R[t]`。
- 训练时迁移上一时间步的代理超参数。
- 选择任意 MOEA 作为基础优化器。
- 用 Kriging 和 RBFN 两个代理分别驱动独立搜索，得到两个候选种群 `Pk` 和 `Pr`。
- 用 Kriging 监督的 reliable solution selection 从两个种群中选出最终解集。

### Kriging 超参数迁移

- Kriging 训练需要优化超参数向量 `Theta`。
- 作者假设相邻时间步目标函数变化通常较小，因此上一时间步的最优 `Theta[t-1]` 可作为当前 `Theta[t]` 优化的初始搜索点。
- 第一时间步的初始点设为 `[5, 5, ..., 5]`。
- 若超参数搜索结果连续 5 个时间步不变，则执行 reset，改用 `[1, 1, ..., 1]` 作为初始搜索点，降低长期陷入局部最优的风险。

### RBFN 超参数迁移

- RBFN 需要预设高斯核超参数 `alpha`。
- 作者认为 `alpha` 应与当前目标值分布均匀性匹配，但有限数据流可能误判分布。
- 因此 RBFN 的 `alpha` 同时参考：
  - 当前数据流在每个目标上的分布均匀性；
  - 上一时间步采用的 `alpha`。
- 当前分布均匀性判断：
  - 将目标值归一化到 `[0, 1]`；
  - 按数据流大小 `Ns` 等分为 `Ns` 个区间；
  - 统计每个区间的数据数量，与理想均匀情形每格 1 个样本比较；
  - 若平均差异大于 1，判为 uneven，否则判为 uniform。
- 三类 `alpha` 取值：
  - uniform distribution：取较大 `alpha = 2 * mean(R)`；
  - uneven distribution：取较小 `alpha = mean(R) / 2`；
  - large difference：若当前判断和上一时间步隐含判断冲突，取过渡值 `alpha = mean(R)`，缓冲数据流偏差带来的误判。

### 可靠解筛选

- Kriging 和 RBFN 各自驱动同一个基础 MOEA 搜索，形成 `Pk` 和 `Pr`。
- Kriging 重新评价两个种群，并给出预测值和 RMSE。
- 对最小化问题，用 Pauta criterion 构造：
  - LCB = predicted value - 3 * RMSE；
  - UCB = predicted value + 3 * RMSE。
- 互相监督筛选：
  - 用 `Pr` 的 LCB 解去淘汰 `Pk` 中 UCB 被支配的解；
  - 用 `Pk` 的 LCB 解去淘汰 `Pr` 中 UCB 被支配的解；
  - 两边剩余的非支配解作为 reliable solutions。
- 如果 reliable solutions 少于目标解集容量 `Np`，则用 RBFN 重新评价剩余候选，并通过环境选择补足最终解集。

## 实验设置

- 测试问题：F1-F9，以及 SDP1、SDP3、SDP4、SDP5、SDP10。
- 决策维度：`D = 10` 和 `D = 30`。
- 环境变化严重度：`nt = 5, 10, 20`；论文说明较大的 `nt` 表示相邻时间步变化较小。
- 时间步数：`T = 100`。
- 数据流大小：`11 * D - 1`，由 LHS 随机生成。
- 种群大小和最终解集容量均为 100。
- Kriging 与 RBFN 驱动的搜索各执行 50 次迭代。
- 性能指标：MIGD，越小越好；每个时间步用 10000 个 PF 采样点计算。
- ST-MOEA 分别嵌入 NSGA-II、IBEA 和 MOEA/D，形成 ST-NSGA-II、ST-IBEA 和 ST-MOEA/D。
- 对比算法：MS-RV 和 IBEA-MS。由于没有专门 DDMOP 算法，作者把 DDMOP 拆成每个时间步的 offline data-driven MOP 进行比较。

## 主要结果

- 消融实验：
  - ST-NSGA-II 在正文展示的 10 维和 30 维消融表中，在不同问题、变化严重度和维度上获得最好表现。
  - KT-NSGA-II 和 RT-NSGA-II 通常优于不迁移的 K-NSGA-II 和 R-NSGA-II，说明 Kriging/RBFN 的超参数迁移总体有效。
  - RT-NSGA-II 在 F2 问题上不优于 R-NSGA-II，作者在补充材料中讨论该失败情形。
  - 在单代理迁移基础上加入 reliable solution selection 后，ST-NSGA-II 相比 KT/RT 进一步明显提升。
- 对比实验：
  - 10 维问题上，ST-NSGA-II、ST-IBEA、ST-MOEA/D 在所有问题和变化严重度上都优于 MS-RV。
  - 10 维问题上，三种 ST-MOEA 对 IBEA-MS 有总体优势，但在 F8 和 SDP3 上显著更差。
  - 30 维问题上，ST-MOEA 系列相较 MS-RV 和 IBEA-MS 在所有测试问题上表现更好，包括 F8 和 SDP3。
  - 作者认为优势在 30 维更明显，是因为维度升高后代理超参数优化空间扩大，固定超参数更容易导致严重预测误差，而超参数迁移和双代理筛选更有价值。

## 局限与阅读边界

- 论文强调当前没有专门 DDMOP 对比算法，因此对比基线是把问题逐时间步交给 offline data-driven MOEA；这会影响横向结论的强度。
- 方法依赖相邻时间步目标函数变化较平滑的假设；随机剧烈变化会削弱代理迁移有效性。
- RBFN transfer 在数据稀缺时可能误判数据流分布，导致预测不准。
- 两个代理并行搜索和 Kriging 训练带来额外计算负担，虽然作者称复杂度与已有 offline surrogate-assisted MOEA 差异不大。
- 实验以合成 DDMOP benchmark 为主，现实数据流应用还需要验证。
- 正文表格在 Markdown 中以图片占位，精确数值需要查阅 PDF 表格或补充材料。

## 可复用知识与创新线索

- 可复用机制：
  - 把历史代理超参数作为可迁移知识，而不是直接迁移历史种群或历史模型预测值；
  - 用两个互补代理各自搜索，再用带不确定性的代理做交叉监督筛选；
  - 在数据流样本少、目标函数不能主动评价时，优先增强代理训练质量和候选可靠性。
- 局部创新线索：
  - 将 Kriging/RBFN 替换为 SVR、神经代理、随机森林或 ensemble surrogate，并迁移对应超参数；
  - 用多时间步加权历史，而不是只用上一时间步，处理随机变化或延迟漂移；
  - 将 reliable solution selection 中的固定 `3 * RMSE` 改成风险偏好或置信度自适应；
  - 对真实数据流引入 K-fold 或在线校准，估计 RBFN hidden nodes 与 `alpha`。
