# Multi-Objective Heterogeneous Fleet Vehicle Routing Problem: Formulation and Algorithm

## 一句话理解

论文把 heterogeneous fleet vehicle routing problem 扩展为同时最小化总成本和最大单路线成本的 MO-HFVRP，用最大路线成本表示司机公平性；针对可行解稀疏和目标空间分布不均，提出 AMOILS/D：少量加权和子问题各自运行 ILS，再用在线资源分配、PBI 距离反馈扰动度和档案协作接受机制共同逼近 Pareto front。

## 问题与动机

- 研究问题和场景：HFVRP 中车辆类型容量和成本不同，且可有有限车队数量约束。真实物流不仅关注总成本，也关注司机之间的工作/收入公平。
- 优化目标：
  - 最小化 total cost；
  - 最小化 maximum route cost，作为公平性指标，避免某条司机路线成本过高。
- 五个变体：
  - `HVRPFD`：limited fleet，fixed and dependent costs；
  - `HVRPD`：limited fleet，only dependent costs；
  - `FSMFD`：unlimited fleet，fixed and dependent costs；
  - `FSMF`：unlimited fleet，only fixed costs；
  - `FSMD`：unlimited fleet，only dependent costs。
- 现有方法为什么不足：
  - 多数 HFVRP 只做单目标 total cost minimization；
  - 用 weighted sum 处理公平和成本需要事先知道决策者偏好；
  - 现有多目标元启发式常假设 unlimited fleet，不适配 limited fleet 变体；
  - 普通 MOEA 在复杂 VRP 可行域中容易生成不可行解或重复探索无效区域。
- 本文希望解决什么：
  - 系统建立 MO-HFVRP 五类变体；
  - 分析其困难来自 decision space sparse feasible solutions 和 objective space uneven distribution；
  - 把强单目标 HFVRP 局部搜索方法 ILS 扩展为 decomposition-based multi-objective algorithm；
  - 用历史目标空间信息动态控制子问题资源、扰动幅度和跨子问题协作接受。

## 核心理念与算法流程

- 核心理念：MO-HFVRP 的可行解很稀疏，适合用 ILS 在可行局部最优之间跳转；但目标空间分布不均，所有子问题均匀搜索会浪费预算。因此应只设置少量子问题，并让历史改进、目标空间距离和 Pareto archive 共同指导局部搜索。
- 问题分析：
  - 可行性稀疏：一个 8-customer、2-type vehicle 示例中，limited fleet variants 的 feasible proportion 仅约 0.04%；unlimited fleet variants 也只有约 21.33%。
  - 稀疏原因包括 capacity constraints 对连续零子序列长度的限制，以及 vehicle quantity constraints 对非零车型标记次数的限制。
  - 目标空间不均匀：随机可行目标向量大多聚集在 upper-right 区域，接近 PF 的 lower-left 区域更稀疏，部分实例还出现明显分裂。
- AMOILS/D 总流程：
  1. 用 Weighted Sum 将 MO-HFVRP 分解成少量单目标 subproblems，正文默认 `L=10`。
  2. 每个 subproblem 关联一个 ILS process 和 reference solution。
  3. 用 constructive heuristic 生成一个共享 feasible initial solution；不强制初始为 local optimum，以降低多目标场景中过早收敛风险。
  4. 每隔 `I=20` 次迭代计算各 subproblem relative improvement 和 utility，通过 3-tournament 选择 `S=3` 个更有潜力的 subproblems。
  5. 被选中的 ILS process 对 reference solution 执行 perturbation 和 local search，得到新 local optimum。
  6. 用新解与 reference solution 的 PBI-based objective-space distance 和 EMA 更新 perturbation degree `omega`。
  7. 用 local threshold 和 global archive acceptance 判断是否接受新解为 reference solution。
  8. 每隔一段时间更新 Pareto archive，并让各 subproblem 从 archive 中匹配最适合自己的 solution。
- Resource allocation strategy：
  - 用 subproblem 最近 `I` 次迭代的 relative improvement 计算 utility；
  - utility 高的 subproblem 更可能被 3-tournament 选中；
  - 逻辑是若某个 subproblem 最近仍有改善，它可能还处于有潜力区域，应继续分配预算。
- Adaptive perturbation degree control：
  - perturbation degree 指被改变 customer nodes 的数量。
  - 若扰动太大，会接近 random restart；若太小，local search 可能回到同一个 local optimum。
  - 论文用 PBI-based distance 衡量新 local optimum 与 reference solution 在当前 subproblem 方向上的质量距离，同时考虑 convergence 和 diversity。
  - 当距离太大时减小 `omega`，避免破坏 building blocks 或对高质量区域做粗糙跳跃；
  - 当距离太小时增大 `omega`，帮助跳出局部 basin 或加速探索；
  - 使用 EMA 在稳定性和响应性之间折中，默认 `omega0=9`、`d_beta=70`。
- Acceptance mechanism：
  - Local part：用阈值接受略差解，为每个 ILS process 保留探索性，降低 rugged landscape 下陷入局部最优的风险。
  - Global part：用 Pareto archive 作全局目标空间信息。
  - 新解若支配或不被 archive 中解支配，可被当前 process 接受；此时 archive 只作 indicator，不立即更新，避免过贪婪。
  - Archive 周期更新后，每个 subproblem 从 archive 中匹配对其 weighted-sum scalar value 最好的 solution，从而让不同 ILS processes 共享优秀结构。
- 关键设计取舍：
  - 采用少量 subproblems，而不是大量权重；因为可行解稀疏时相邻 subproblems 轨迹高度相似，过多子问题造成冗余探索。
  - 采用 WS 而非 TCH；正文解释 TCH 在最大路线成本目标上会出现许多 solution function values 相同，收敛较慢。
  - 用 archive 弥补 WS 只能直接引向 supported efficient solutions 的不足，保存搜索中发现的 unsupported non-dominated solutions。

## 实验证据

- 实验设置：
  - 实例：Taillard 13-20 共 8 个实例，最多 100 customers；Li H1-H5 共 5 个实例，200-360 customers；N1-N5 约 150 customers，用于部分不含 fixed cost 的变体。
  - 变体：覆盖 HVRPFD、HVRPD、FSMFD、FSMF、FSMD 五种 MO-HFVRP。
  - 对比算法：WS10A、TCH10A、WSPLS10A、WS100、NSGA-II、MOEA/D。
  - 所有 ILS-based 算法使用与 AILS 相同的 perturbation 和 local search operators；实现语言 Java。
  - 指标：HV 越大越好，IGD+ 越小越好；每个 instance 运行 30 次；Wilcoxon rank-sum test 显著性 0.05。
- 主要结果：
  - 正文称 AMOILS/D 在大多数实例上显著优于其他算法，HV 和 IGD+ 平均排名最好。
  - ILS-based algorithms 的平均排名整体优于 NSGA-II 和 MOEA/D，支持 ILS 适合处理 MO-HFVRP 稀疏可行解空间。
  - Fig. 4 中 AMOILS/D 的最终解集在多组实例上更均匀、更宽、更靠近 PF，其他算法会漏掉 PF 局部区域。
  - Fig. 5 的 acceptance histories 显示 AMOILS/D 早期在 upper-right 低质量区域消耗更少计算资源，更快把预算转向 PF 附近。
- 组件和策略证据：
  - WS10A 优于 TCH10A，支持本文选择 WS scalarization；作者认为 TCH 对 maximum route cost 中大量相同目标值处理较差。
  - WS10A 明显优于 WS100，说明少量 subproblems 比大量相近 subproblems 更适合 MO-HFVRP，能减少冗余探索。
  - WSPLS10A 表现较差，作者认为 MO-HFVRP 局部最优多，早期频繁做 PLS 导致不合理资源分配。
  - 正文说明补充材料中的 ablation studies 支持 resource allocation、adaptive perturbation degree control 和 acceptance mechanism 的有效性。
- 证据边界：
  - 详细数值和 ablation 主要在 Supplementary Material，Markdown 主文只保留表格图片占位和总体叙述。
  - 目标只有 total cost 和 maximum route cost；公平性被简化为最大路线成本。
  - 所用 perturbation/local search operators 来自单目标 AILS，尚未为多目标场景重设。

## 局限与未来工作

- 作者明确说明的局限：
  - Fairness 是多维概念，可能还包括 driving time、stop frequency、traffic conditions、driver abilities 等；本文只用 maximum route cost 表示。
  - MO-HFVRP 真实实例仍稀缺，需要更完整 benchmark test suite。
  - 当前 reproduction operators 来自 single-objective scenarios，未专门为多目标场景设计。
- 作者未来工作：
  - 建立更全面的 fairness formulation 和更多真实/合成 benchmark；
  - 将问题扩展到更多现实冲突目标；
  - 设计适合多目标 HFVRP 的 reproduction operators；
  - 结合 fitness landscape analysis 理解不同 operators 的表现。
- 我们认为仍需确认的问题：
  - WS scalarization 仍天然偏 supported solutions，archive 对 unsupported solutions 的补偿程度如何量化；
  - `L=10,S=3,I=20` 在不同规模和更多目标上是否稳定；
  - PBI-based distance 的参数 `d_beta=70` 如何随目标尺度自动设定；
  - Delayed archive update 的周期与 convergence/diversity trade-off 如何自适应；
  - 若引入更多公平指标，maximum route cost 的局部搜索结构是否仍适用。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：分解 ILS 的反馈扰动与档案协作。它不同于“成功率反馈的算子与参数自适应选择”或“大规模变量组资源分配”，本知识的控制对象是 MOCOP 中的 ILS subproblems、扰动强度和 reference solution 接受。
- 暂留在论文卡中的方法、原理或架构启发：
  - MO-HFVRP 的五类模型和 fairness objective 留在本文卡中，暂不单独建建模卡。
  - WS vs TCH 在 maximum route cost 下的差异是本文实例观察，暂不单独建 scalarization 卡。
- 局部创新线索：
  - 将 utility-based resource allocation 换成 bandit/UCB 或 Bayesian improvement 选择子问题。
  - 把 PBI distance 替换成 normalized Tchebycheff distance、HV contribution distance 或 learned landscape distance。
  - 让 archive matching 不只看 scalar value，也看决策结构相似性，避免跨 subproblem 迁移破坏局部结构。
  - 为 total cost 和 fairness 分别设计 multiobjective-aware perturbation/local search operators。
- 结构创新线索：
  - 构建“少量分解子问题 + 强单目标局部搜索 + objective-space feedback + global archive matching”的 MOCOP 通用框架。
  - 在调度、装箱、路径、分配类 MOCOP 中，将已有单目标 ILS/ALNS/VNS 作为子问题求解器，再接入本文三类反馈控制。
