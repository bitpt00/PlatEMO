# Experience Evolution-Guided Multi-Objective Reinforcement Learning

## 一句话理解

本文提出 E2MORL，把 evolutionary reinforcement learning 中的进化对象从高维策略参数改成“episode experiences 的偏好权重”。算法维护一个经验个体种群，用交叉和变异生成新的偏好权重；若某条经验在新权重下的 scalar utility 高于当前 agent 在相同偏好区域的最好表现，则把这批重标经验注入 replay buffer，并用 dominance 与 crowding distance 从 RL agent 回流候选个体，从而在 preference-conditioned MORL 中提升样本质量和 Pareto front 覆盖。

## 问题与动机

- 研究问题：
  - preference-conditioned multi-objective reinforcement learning；
  - policy 输入 preference weights，需要覆盖多个偏好下的 Pareto-optimal behavior；
  - 结合 EA 与 RL 的 evolutionary reinforcement learning 在 MORL 中如何避免昂贵的策略种群评价。
- 现有 ERL 的瓶颈：
  - 传统 ERL 主要进化 policy parameters；
  - preference-conditioned policy 在不同权重下行为不同，评价一个 policy 需要大量 episodes；
  - 只采少量偏好评价会误判高质量个体；
  - policy parameter space 高维，EA 搜索效率低。
- 现有 MORL replay 的不足：
  - PD-MORL 的 HER 将 transition 的 preference weight 随机替换；
  - 这种随机重标忽略经验质量；
  - 原经验在新权重下可能明显差于当前 agent，反而干扰学习。

## 方法核心

- 总体框架：
  - RL optimization：agent 按随机归一化偏好 `w` 与环境交互，得到 episode buffer `R'` 和 cumulative vector reward `f_R'`；
  - RL injection：把 `R'` 作为候选经验个体注入 population，只有 dominance 改善或 crowding diversity 改善时才替换个体；
  - EA optimization：对 population 中经验个体的 preference weights 做交叉和变异；
  - EA injection：只把 utility 优于当前 agent 的重标经验加入 replay buffer。
- 经验个体定义：
  - population 中每个个体 `B_i` 是一个 episode 的经验 buffer；
  - 同一 episode 中 transition 共用同一个 preference vector；
  - 个体 fitness 是 episode cumulative vector reward。
- agent utility 记录：
  - preference space 被均匀分为若干子区域；
  - 数组 `U` 记录每个偏好子区域中 agent 已达到的最大 scalar utility；
  - 评价新重标经验时，不需要重新跑环境，只需用 `w^T f_i` 与 `U_w` 比较。
- experience-level evolution：
  - 从两个父代经验个体取 preference vectors，单点交叉生成两个子权重；
  - 从一个父代权重加入非负 Gaussian mutation 生成第三个子权重；
  - 子权重归一化后评估；
  - 若 `w_c^T f_p > U_{w_c}`，复制父代经验并替换权重后加入临时 buffer；
  - 若 offspring 相对 agent 的 utility margin 高于 parent，则用 offspring 权重更新父代个体。
- RL 与 EA 交互：
  - RL agent 产生的新 episode 可替换被其 dominance 的 population 个体；
  - 若互不支配，则用 crowding distance 判断是否能改善种群多样性；
  - population 注入 replay buffer 的经验也必须通过 agent utility 过滤，避免低质量 off-policy 经验。
- 工程限制：
  - 每条原始 transition 最多生成 5 条新 transition；
  - 初始 10% training steps 禁用 EA injection，用于积累不同偏好下的 agent utility；
  - E2MORL 可嵌入 TD7、TD3、DDQN 等单目标 RL 基础算法形成多目标版本。

## 相关方法定位

| 方法 | 作者定位 | 与本文关系 |
|---|---|---|
| ERL / PDERL / TERL / VEB-RL | 进化 policy parameters 或基于 value/parameter 的种群 | 本文改为进化经验偏好权重，避免高维参数搜索和昂贵 policy evaluation |
| MO-ERL / MOPDERL | 将 ERL 扩展到 MORL，但仍处理 policy population | 本文面向 preference-conditioned single policy 的经验级演化 |
| PGMORL | multi-policy MORL，用 policy population 和 archive 近似 PF | 本文学习 preference-conditioned policy，不维护大量独立 policies |
| PD-MORL | 用 cosine term 和 HER 改善偏好条件策略 | 本文保留偏好重标思路，但用 utility 评价和进化搜索替代随机重标 |
| Q-Pensieve | 用 Q replay buffer 提升样本效率 | 本文用 experience population 提供高质量训练样本 |
| Hyper-MORL | hypernetwork 由偏好生成 policy | 本文不生成 policy 参数，而生成更有训练价值的重标经验 |

## 实验设置与结果

- 测试任务：
  - MuJoCo 连续控制：HalfCheetah、Walker、Hopper、Ant-2、Humanoid、Ant-3；
  - 离散 MORL：Deep Sea Treasure 和 Fruit Tree Navigation；
  - continuous tasks 主要包含 forward reward 和 control cost，Ant-3 额外包含 healthy reward；
  - DST 有 2 个目标，FTN 有 6 个目标。
- 对比方法：
  - continuous：PGMORL、PD-MORL、Q-Pensieve、Hyper-MORL；
  - discrete：Envelope MORL、PD-MORL；
  - E2MORL 分别以 TD7、TD3 和 DDQN 作为基础 RL 算法。
- 指标：
  - HV 越大越好；
  - SP 越小越好，但作者提醒 SP 只有在 HV 接近时才更有解释意义；
  - 每个实验报告 5 次独立运行均值和标准差。
- 关键结果：
  - continuous MuJoCo 上，E2MORL 在大多数环境取得最高 HV，并在多项 SP 上保持竞争力；
  - discrete DST 上 E2MORL 和 PD-MORL 都能得到 true PF；
  - 六目标 FTN 中，E2MORL-DDQN 的 HV 和 SP 优于 Envelope MORL 与 PD-MORL；
  - TD7、TD3、DDQN 三种实现均支持框架可迁移性。
- 消融：
  - 去掉 experience-level evolution 会降低 Ant-2、Walker、Humanoid 上的 HV；
  - 用 PD-MORL 式 HER 替代进化生成经验，有时比不加额外经验还差；
  - 将单点交叉/Gaussian mutation 换成 arithmetic crossover/uniform mutation 后性能接近，说明收益主要来自框架而非某个特定算子。
- 参数分析：
  - population size 越大通常 PF 更密，但 `n=20` 后继续增大收益有限且增加内存；
  - agent utility 分区数 `k` 的敏感性较低，二目标任务中 `k=100` 足以取得竞争表现；
  - Gaussian mutation strength `sigma` 在 `0.05` 到 `0.5` 范围内表现接近。
- 运行成本：
  - E2MORL-TD7 时间开销较高，主要来自 TD7 representation networks；
  - E2MORL-TD3 比 PD-MORL 更快；
  - 去掉 evolutionary operations 的变体只比完整算法略快，说明经验级进化带来的额外时间负担较小；
  - memory 上 E2MORL 因 population 额外占用高于 PD-MORL，但低于 PGMORL 的 policy population/archive 开销。
- 机制分析：
  - population 能在不同环境中提供可观比例的 superior experiences；
  - HER 生成的经验数量更多，但质量较低；
  - 与 HER 相比，E2MORL 生成经验相对当前 policy 的 action discrepancy 显著更低，说明 off-policy 程度更受控。

## 局限与未来工作

- 作者明确指出：
  - 高回报经验在 MORL 中为何有效仍缺少系统理论分析；
  - 与标准 RL 相比，E2MORL 会从 population 获得额外经验，如何更充分利用这些经验仍值得研究。
- 从证据边界看还需确认：
  - 是否能扩展到更高维偏好空间和更多目标；
  - preference space 分区记录 `U` 在稀疏偏好访问下是否稳定；
  - 真实机器人或昂贵仿真中，utility 过滤是否足以控制 distribution shift；
  - 当 reward 尺度差异大或非线性偏好存在时，`w^T f` 评价是否仍合理；
  - population 中 episode-level 个体是否会过度复用早期状态分布。

  - 对不同 reward 目标做归一化或动态尺度校准后再评价 `w^T f`；
  - 将 population 个体从完整 episode 扩展为 sub-trajectory 或 skill segment。
- 结构创新线索：
  - 构建“经验种群 -> 偏好权重搜索 -> utility 过滤 -> replay buffer”的通用 MORL 样本增强层；

  - 与 Tchebycheff/ESR MORL 结合，用非线性 utility 过滤高价值 trajectory；
  - 与离线 MORL 结合，在固定数据集内搜索每条 trajectory 最有利的 preference label，同时约束 action discrepancy。
