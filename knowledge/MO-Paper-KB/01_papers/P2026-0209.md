# Integrated Energy-Efficient Scheduling of Distributed Flow Shop and Distribution Using a Q-Learning-Based Multi-Objective Cooperation Evolutionary Algorithm

## 一句话理解

论文把 distributed flow shop production 与多仓配送联合成一个三目标绿色调度问题，并提出 Q-MCEAK：用三个人口分别搜索工厂分配、工件序列和机器速度，同索引拼成完整生产方案，再由 Q-learning 按当前非支配集覆盖/分布变化，在“交叉+变异”“交叉+知识局部搜索”“变异+知识局部搜索”三类策略之间自适应切换。

## 问题与动机

- 研究对象：integrated energy-efficient scheduling of distributed flow shop and distribution。
- 集成决策：
  - 工件分配到哪个 factory；
  - 每个 factory 内的 job processing sequence；
  - 每个 job 在每台 machine 上的 processing speed；
  - 车辆服务哪些 customers；
  - vehicle visiting sequence。
- 三个优化目标：
  - maximum completion time (MCT)；
  - total energy consumption (TEC)，含机器加工/待机能耗和车辆配送能耗；
  - maximum workload of factories (MWF)。
- 难点：
  - distributed flow shop scheduling 与 multi-depot vehicle routing 都是 NP-hard；
  - 生产阶段的速度选择会同时影响完成时间、机器能耗和工厂 workload；
  - 配送阶段又引入车辆容量、载重、距离和客户访问顺序；
  - 直接用单一编码或单一种群搜索，容易让不同子决策互相拖累。
- 作者定位：
  - 现有 distributed production and distribution 调度较少同时考虑能耗、工厂 workload 和生产-配送一体化；
  - 已有 RL+EA 多选择 heuristic rules、parameters、neighborhoods，本文改为选择由 crossover、mutation 和 knowledge-based local search 组成的搜索策略。

## 模型要点

- 生产阶段：
  - 多个 factories，每个 factory 是相同机器路线的 flow shop；
  - 每个 job 只能分配给一个 factory；
  - 每台 machine 同一时刻最多加工一个 job，每个 job 同一时刻最多在一台 machine 上加工；
  - job 不允许 preemption；
  - 每个 job 在每台 machine 上选择一个 speed，实际 processing time 随 speed 改变；
  - machine energy 包含 busy energy 与 standby energy。
- 配送阶段：
  - 每个 factory 的已完成产品由 vehicles 配送；
  - vehicle 有最大载重，配送能耗受 load、speed 和 distance 影响；
  - 每个 customer 访问一次，vehicle 从对应 factory 出发并返回。
- 解码：
  - 编码只显式表达生产阶段三个决策子串；
  - 配送阶段用 heuristic decoding 得到：同一 factory 的 jobs 完成后装车，超过容量则启用新车；每辆车的 customer 顺序用 nearest insertion method 构造。

## 核心方法：Q-MCEAK

- Solution encoding：
  - `pi'`：长度 `n` 的 factory assignment，`pi'_j` 表示 job `j` 分配到的 factory；
  - `pi''`：长度 `n` 的 job permutation，各 factory 按相对顺序加工被分配 jobs；
  - `pi'''`：每个 job 在各 machine 上的 speed selection。
- 三种群协作：
  - `P_f` 搜索 factory assignment；
  - `P_j` 搜索 job processing sequence；
  - `P_m` 搜索 machine speed selection；
  - 三个人口中相同 index 的三个个体组合成一个完整 solution；
  - 三个人口并行演化，fitness 由 nondominated sorting 与 crowding distance 给出。
- 初始化：
  - `P_m` 使用 random、largest speed、smallest speed；
  - `P_j` 使用 random 与 NEH；
  - `P_f` 使用 random 与 average workload assignment，后者参考同索引的 `P_j` 和 `P_m`。
- Genetic operations：
  - selection：binary selection；
  - `P_f`：uniform crossover，随机改变一个 job 的 factory assignment；
  - `P_j`：partially matched crossover，随机交换两个 jobs；
  - `P_m`：uniform crossover，随机改变某个 job 在一台 machine 上的 speed。
- Knowledge-based local search (KLS)：
  - 定义 critical factory、critical path、critical jobs；
  - Property 1：提高 critical path 上某关键 job 的机器速度可降低 MCT；
  - Property 2：降低某 factory 最后一台 machine 上 job 的速度可降低 machine energy；
  - Property 3：在不影响后继开始时间时，降低 non-critical path job 的速度可降低 energy；
  - Property 4：提高 maximum workload factory 上某 job 的速度可降低 MWF；
  - 据此构造 NS1-NS4，KLS 随机选择 neighborhood 并迭代 `rho` 次。
- Q-learning search strategy selection：
  - 状态：用当前 nondominated set `T_t` 相对上一代 `T_{t-1}` 的 C-metric 和 distribution difference `Delta D` 定义四种状态；
  - 动作：
    - `a1`：selection + crossover + mutation；
    - `a2`：selection + crossover，然后对 rank 选出的 top `sigma * N'` nondominated individuals 做 KLS；
    - `a3`：selection + mutation，然后对 top `sigma * N'` nondominated individuals 做 KLS；
  - action selection：`epsilon`-greedy；
  - reward：转移到最优状态 1 给 `+1`，转移到最差状态 4 给 `-1`，其他为 `0`；
  - Q-table 随进化同步更新，论文参数中 `beta=0.5`、`gamma=0.7`。

## 实验证据

- 实验设置：
  - Test instances 由 flow shop benchmark [39] 与 VRP benchmark [40] 扩展组合；
  - 生产阶段选 Ta001、Ta011、Ta031、Ta041、Ta061、Ta065、Ta070、Ta071、Ta075、Ta080 等，jobs 为 20/40/60/80/100，machines 为 5/10，factories 为 2/3/4；
  - 配送阶段选 p01、p03、p07、p10、p15；
  - 组合得到 30 个 `ISPDab` instances；
  - 指标：Coverage (C)、IGD、HV；C/HV 越大越好，IGD 越小越好；
  - peer comparison 中各算法每实例独立运行 20 次，预算为 `300 * n` fitness evaluations。
- 参数调优：
  - Taguchi method 调 `N, mu, rho, sigma`；
  - 以 ISPD15 的 20 次运行平均 IGD 为 response variable；
  - 推荐参数：`N=40, mu=0.05, rho=9, sigma=0.25`；
  - 作者报告 `N` 影响最大，其次为 `rho, sigma, mu`。
- Q-learning 消融：
  - R-MCEAK 用 random action selection 替代 Q-learning；
  - Q-MCEAK 在 IGD/HV 上优于 R-MCEAK；
  - Friedman 与 Nemenyi post-hoc 显示 Q-MCEAK 显著更好；
  - action 选择比例显示：早期更多使用 crossover+mutation 做 global search，后期更多选择 mutation+KLS 做 local search，crossover+KLS 比例相对稳定。
- KLS 消融：
  - Q-MCEAK-w/o-KLS 用 mutation methods 生成 neighborhood individuals；
  - Q-MCEAK 在多数 instances 更好；
  - 统计结果显示 IGD 差异统计等价，但 HV 上 Q-MCEAK 显著更好。
- CPLEX 对比：
  - 用 epsilon-constraint 构造三个 SOP，每个 SOP 优化一个目标，另两个目标作为约束；
  - CPLEX 最大运行时间 3 hours；
  - Q-MCEAK 每实例运行 20 次并汇总 nondominated solutions；
  - 5/10 jobs 小实例中二者解多为互不支配，且有一个实例 Q-MCEAK 支配 CPLEX；
  - 15 jobs 上 Q-MCEAK 优于 CPLEX；Q-MCEAK 用约 4.86、12.50、22.49 秒求解三个 SOP，而 CPLEX 多数达到 3 hours 上限。
- Peer comparison：
  - 与 NSGA-II、MOEA/D、CMOA 比较；
  - C metric 上 Q-MCEAK 在所有 instances 优于 rivals，t-test 显著；
  - IGD/HV 上 Q-MCEAK 在大多数 instances 更好，boxplots 更集中稳定；
  - t-test、Friedman、Nemenyi、Wilcoxon signed-rank 结果支持 Q-MCEAK 相对三类基线具有显著优势。
- 真实案例：
  - Crankshaft product model X5，forging-based manufacturing 后接 machining；
  - 9 个 operations，包括 milling、turning、quenching、grinding 等；
  - 两个 flow shops，light-duty vans 从 factories 向 customers 配送；
  - Q-MCEAK 的 IGD 均值/方差更小，HV 均值更大且方差更小；
  - Friedman ranks 为 Q-MCEAK、NSGA-II、MOEA/D、CMOA = 1、2、3、4，`p=0.0000`，Dunnett post-hoc 显示 rivals 显著更差。

## 局限与未来工作

- 作者未来工作：
  - 在模型中考虑不确定事件，如 indeterministic processing time 和 machine breakdown；
  - 进一步结合 machine learning 设计更有效的 search methods。
- 我们认为仍需确认的问题：
  - 配送阶段由 heuristic decoding 得到，未把配送 route decision 作为独立协作人口，可能限制复杂配送约束下的搜索空间；
  - Q-learning 状态只看非支配集相对变化，难区分三个子决策人口各自是否停滞；
  - reward 为 `+1/0/-1`，可能不足以反映 HV/IGD 或具体目标端点收益；
  - 同索引协作依赖三个人口 index 的隐式配对，若某一子决策进化速度明显不同，可能需要重配对或协作图学习；
  - CPLEX 对比只在小规模 epsilon-constraint SOP 上进行，不能作为大规模最优性证明。

- 与已有设计知识的关系：
  - 不同于[贡献自适应的多种群多目标协同](../02_design_knowledge/K-contribution-adaptive-mpmo-coevolution.md)：旧卡按目标或子种群贡献分配进化机会；本篇按决策语义拆成三个人口，并用同索引拼接完整 schedule。
  - 可与[时段分解随机拼接的约束调度搜索](../02_design_knowledge/K-temporal-block-decomposition-random-concatenation-cmoea.md)互补：时间块分解解决 horizon 维度，分段种群协作解决同一时段内 assignment/sequence/speed 的语义异构。
  - 可与[非支配排名驱动的辅助速度决策修正](../02_design_knowledge/K-rank-based-auxiliary-speed-decision-refinement.md)互补：本篇把 speed 作为独立人口共同演化，后者把 speed/能耗档位作为主结构后的辅助修正层。
- 局部创新线索：
  - 把同索引配对改为 archive-guided rematching，用某段个体与多个候选子段组合后再选择；
  - Q-learning action 不只选择策略组合，也选择哪个子决策人口优先接受 KLS；
  - 状态拆分为 global archive state 与 `P_f/P_j/P_m` 的 stagnation/diversity state；
  - KLS reward 计入每类 neighborhood 对 MCT/TEC/MWF 的边际改善，形成更细粒度的 action space。
- 结构创新线索：

```text
semantic multipart encoding
-> one population per decision substring
-> problem-specific operators per population
-> index-aligned or learned matching to form complete solutions
-> archive-state RL selects strategy mix
-> knowledge local search targets critical bottlenecks
```
