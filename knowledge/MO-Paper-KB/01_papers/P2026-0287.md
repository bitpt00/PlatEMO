# Integrating Actor-Critic Reinforcement Learning With Evolutionary Algorithm for Multimodal Multiobjective Optimization

## 一句话理解

论文提出 AC-MMEA，把 actor-critic 强化学习嵌入多模态多目标进化算法的环境选择：用当前种群的收敛度和决策空间多样性作为状态，让 actor 输出连续的 niche size 调整动作，再用状态改善作为 reward 在线更新 actor 和 critic，使局部收敛质量的比较范围随搜索状态自适应变化。

## 问题与动机

- 研究问题和场景：Multimodal multiobjective optimization problems (MMOPs) 中，多个相距很远的 Pareto optimal solutions 可能映射到同一个 PF 点；算法不仅要逼近 PF，还要在决策空间找到多个完整且均匀的 PSs。
- 现有方法为什么不足：
  - 只用全局 Pareto dominance 或 global convergence quality 更新种群，会优先保留目标值更好的解，删除一些目标较差但靠近潜在 PS 的 dominated solutions，导致 PS 丢失。
  - Niching 能把比较限制在局部区域，但 niche size 太大会退化成全局选择，太小会减慢收敛。
  - 许多 niche 技术依赖经验参数或演化阶段，缺少根据当前 population distribution 自适应调整的学习能力。
  - 已有 RL 辅助 MMOEA 多用于选择搜索策略或算子，较少直接学习核心环境选择中的连续 niche 参数。
- 本文希望解决什么：
  - 将 niche size 作为连续动作，由 actor-critic 在线学习；
  - 用收敛/多样性状态和状态改善 reward 让 niche size 与当前搜索环境绑定；
  - 结合双种群协同，分别维护多样性探索和收敛性档案；
  - 在不需要 labeled data 和 offline training 的前提下提升 MMOP 环境选择适应性。

## 核心理念与算法流程

- 核心理念：MMOP 环境选择的关键不是固定保留多样性或固定强化收敛，而是根据 population 当前“离最优 PS 多远”和“决策空间覆盖是否足够”动态调节局部竞争半径。Actor-critic 适合输出连续 niche size，并可在进化过程中在线更新。
- 总体框架 AC-MMEA：
  1. 初始化两个大小为 `N` 的种群 `P1` 和 `P2`，以及 actor network `A` 和 critic network `C`。
  2. `P1` 偏向维护决策空间多样性和潜在 PS 覆盖；`P2` 偏向保存全局收敛性好的解。
  3. 每代分别计算 `P1`、`P2` 的 decision-space crowding distance，并用 tournament selection 生成 mating pools。
  4. 两个种群分别用 SBX/PM 生成 offspring `O1` 和 `O2`，再合并为 `O`。
  5. 用 `P2 ∪ O` 执行 archive update，按 global convergence quality 优先保存 nondominated 或更收敛的解。
  6. 用 `P1 ∪ O` 执行 RL-based environmental selection，actor 输出 niche 调整，按 local convergence quality 与 crowding distance 截断到 `N`。
  7. 重新计算 `P1` 的收敛和多样性状态，用 reward 更新 actor/critic。
- `P2` archive update：
  - 计算每个解的 global convergence quality `G`；
  - 优先保留 `G=0` 的 nondominated solutions；
  - 若 nondominated solutions 超过 `N`，用 decision-space crowding distance 删除拥挤解；
  - 若少于 `N`，按 `G` 排序补足。
- `P1` RL-based environmental selection：
  - 收敛状态 `Con`：根据 global convergence quality 找到最好收敛集合 `NS` 与最差收敛集合 `WS`，用平均反向距离刻画二者差距；`Con` 越小表示收敛越好。
  - 多样性状态 `Div`：用所有个体 decision-space crowding distance 的均值表示；`Div` 越大表示决策空间覆盖越好。
  - 状态 `S_t=[Con, Div]` 输入 actor。
  - Actor 输出连续动作 `a_t`，将其乘以初始化 niche radius 得到学习后的 niche size `R`。
  - 用 `R` 计算 local convergence quality，再结合 crowding distance 排序截断 `P1`。
  - Reward 基于状态变化：鼓励 `Div` 增大和 `Con` 减小，并对两个分量归一化。
  - Critic 根据 TD error 更新 value estimation，actor 根据 critic 反馈更新策略参数。
- 网络结构：
  - Actor 使用三层全连接网络，输入维度为 2，输出为一个动作概率/连续 action。
  - Critic 使用两层全连接网络，输入同为状态向量，输出 value estimation。
  - 训练是 online learning，和进化过程同步进行，不需要离线标注数据。
- 时间复杂度：
  - mating selection、diversity measure 和 environmental selection 都主要含有 decision-space distance/crowding 计算；
  - actor/critic 网络规模固定时，动作生成和价值估计开销为常数级附加；
  - 总体时间复杂度为 `O(dN^2)`，其中 `d` 为决策维度，`N` 为种群规模。

## 实验证据

- 实验设置：
  - Benchmark：MMF 16 个问题、IDMP 12 个问题、MMMOP 20 个可扩展问题，共 48 个 MMOPs。
  - 指标：PSP 越大越好；IGDX 和 IGDF 越小越好，分别衡量决策空间和目标空间的收敛/多样性。
  - 对比算法：MO Ring PSO SCD、SS-MOPSO、MOEA/D-SS、MMEAWI、HREA、MMEA-SND、MMEAPSL、SVMEA、DEA-IGNN、MMEA-VGAE，共 10 个代表性算法。
  - 统计检验：Wilcoxon rank-sum test，显著性水平 0.05；同时报告 Friedman average rankings 和 best/all 次数。
  - 参数：population size `100d`，maximum function evaluations `5000d`，20 次独立运行；AC-MMEA 用 Python 3.9/PyTorch，部分对比算法用 MATLAB。
- 数值结果：
  - MMF：正文称 AC-MMEA 获得最佳指标排名和最多 best results，并对多种 PS 形状/数量表现出适应性。
  - IDMP：IDMP 的 PS 搜索难度不均衡，固定 niche 容易丢失困难 PS；正文称 AC-MMEA 在 PSP 和 IGDF 上表现最好，IGDX 稍弱于 MMEA-SND。
  - MMMOP：高维决策空间下学习 population distribution 的生成模型易受稀疏分布影响；正文称 AC-MMEA 在三个指标上总体最好，且其状态输入维度不随决策维度直接增加。
  - Overall：作者认为 AC-MMEA 通过实时估计 population state 并调整 niche，在多类 MMOP 上优于十个对比算法。
- 可视化结果：
  - Omni、IDMPM4T4、MMMOP6C 的补充图显示，AC-MMEA 获得的解更接近 true PSs，并覆盖更广的决策空间区域。
- 参数分析：
  - Actor learning rate `alpha=0.0001` 时 reward 曲线更稳定上升。
  - Critic learning rate `beta=0.001` 时收敛速度和最终 reward 更好。
  - Discount factor `gamma=0.9` 时最终 reward mean 最大，稳定性次优，作者据此采用 `gamma=0.9`。
- 消融与机制验证：
  - `AC-MMEA-P1` 只用多样性种群，收敛不足，整体最弱。
  - `AC-MMEA-P2` 只用收敛种群，目标空间表现可接近完整算法，但 PSP/IGDX 不如 AC-MMEA，说明会丢失部分 PS。
  - 固定 action `a=1` 的 R-MMEA 显著弱于 AC-MMEA；正文称 48 个 MMOPs 上平均 rPSP 改善约 67.86%。
  - 将 AC-MMEA 的 niche 技术替换为 HREA、MMEA-SND、MMEA-VGAE 中的 niche，所得 H-MMEA、S-MMEA、V-MMEA 均不如 AC-MMEA，说明 actor-critic 生成的 niche 具有更强适应性。
- 运行时间：
  - 传统 MMOEAs 整体更快，HREA 时间优势明显。
  - AC-MMEA 因两个全连接网络、state/reward 计算和在线学习有额外开销；比传统算法约慢 2 到 3 倍，但相比部分 learning-based MMOEAs 仍有优势。
- 真实应用：
  - Map-based best location problem，四目标，`N=200`，`MaxFE=5000`。
  - 正文称 AC-MMEA 的 solutions 均匀性优于 MMEAPSL、MMEA-VGAE 和其他对比算法，说明其在实际问题上可行。
- 证据边界：
  - 多数详细数值在补充材料，Markdown 中无法保留精确表格。
  - 训练和运行环境混用 MATLAB 与 Python/PyTorch，运行时间比较可能受实现影响。
  - RL 理论讨论基于 policy gradient 收敛基础，并非对具体 AC-MMEA 在有限预算 MMOP 上的严格收敛证明。

## 局限与未来工作

- 作者明确说明的局限：
  - 与传统算法相比，AC-MMEA 的运行时间仍需改善。
  - State/reward 计算和 actor-critic 网络引入额外复杂度。
- 作者未来工作：
  - 开发更轻量的 RL 模型和更高效的训练方法；
  - 将 actor-critic RL 扩展到 dynamic multiobjective、constrained multiobjective 和 many-objective problems；
  - 研究 learning-based MMOEAs 在更广泛实际问题中的应用。
- 我们认为仍需确认的问题：
  - 只用 `Con/Div` 两维状态是否足以表达多个局部 PS 的结构差异；
  - 单一全局 niche action 能否同时适配不同难度、不同密度的 PS 区域；
  - Reward 是否会偏向短期状态改善，而忽略长期 PS 完整性；
  - 与 bandit、成功率反馈或离散参数表相比，actor-critic 的额外成本何时值得；
  - 多约束、离散、混合变量 MMOP 中 niche size 的含义和距离度量如何定义。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：Actor-Critic 自适应生态位环境选择。它不同于“状态驱动的 DRL 演化算子选择”，后者动作是 GA/DE/CHT 等离散算子；本知识动作是连续 niche size，直接改造 local convergence quality 和 environmental selection。
- 暂留在论文卡中的方法、原理或架构启发：
  - `P1/P2` 双种群结构与 archive update 可作为本文框架细节保留，暂不单独建双种群 MMOP 卡。
  - Map-based best location problem 是应用验证，暂不单独建 benchmark 或应用卡。
- 局部创新线索：
  - 将单一 niche action 扩展为按子区域、簇或参考向量输出多个 local niche sizes。
  - 把 `Con/Div` 状态扩展为 PS 覆盖缺口、模态数量估计、档案新颖度或局部密度分布。
  - 用 lightweight bandit 或 Gaussian process controller 替换 actor-critic，比较低预算下的收益/成本。
  - 在 reward 中加入长期 archive coverage 或 PS loss penalty，避免短期 crowding 改善误导策略。
- 结构创新线索：
  - 构建“种群状态感知 -> 连续选择参数控制 -> 局部收敛环境选择”的通用策略层，可用于 niche size、邻域大小、参考向量角度阈值或 crowding 截断半径。
  - 与状态驱动算子选择结合：一个策略头控制 offspring operator，另一个策略头控制 environmental selection radius。
  - 与多子种群 MMOP 框架结合：每个子种群维护自己的 actor-critic 或共享 actor 加子群状态输入。
