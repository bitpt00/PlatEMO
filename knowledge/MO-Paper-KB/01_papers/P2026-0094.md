# A two-stage evolutionary algorithm for uncertain constrained multi-objective problems with interval-valued objective

## 一句话理解

本文提出 TS-ICMOEA，用两阶段环境选择处理 interval constrained multi-objective optimization problems：前期在区间目标空间中用 interval non-dominated sorting 加 `CI/CV` 二级排序增强全局搜索和收敛压力，后期按可行率切换到“保留可行解 + 低 CV 不可行解填充”或“可行解内 CIDP + interval crowding”选择，从而在区间值目标优化和约束满足之间取得折中。

## 问题与动机

- 研究问题：objective functions 受 interval uncertain parameters 影响，同时存在 inequality/equality constraints 的 ICMOP。
- ICMOP 的难点：
  - 可行域可能狭窄、离散或被大范围 infeasible region 包围；
  - interval-valued objectives 之间存在重叠和位置关系复杂，普通 Pareto dominance 不能直接使用；
  - 间接把区间目标转成确定性目标可能丢失上下界信息，导致可行解不稳定或收敛慢；
  - 只强调约束会牺牲区间目标优化，只强调区间目标又可能长期得不到可行解。
- 本文希望解决什么：
  - 前期如何在 interval objective space 中保持足够选择压力；
  - 后期如何根据当前 feasible rate 自适应平衡可行性恢复和可行域内目标优化；
  - 如何在 high-dimensional objective ICMOP 中避免 non-dominated 个体过多导致的选择退化。

## ICMOP 与区间比较基础

- 问题形式：
  - 决策向量 `x`；
  - 不确定参数 `c` 以区间形式给出；
  - 每个目标 `f_z(x,c)` 是 interval-valued objective；
  - 约束包括 inequality `g_j(x)<=0` 和 equality `h_j(x)=0`。
- 可行性：
  - 用 constraint violation `CV(x)` 汇总全部约束违反；
  - `CV(x)=0` 为 feasible solution，否则为 infeasible solution；
  - equality constraint 使用容差，文中默认 `epsilon=0.0001`。
- 区间目标比较：
  - 使用 interval probability 判断两个区间数大小；
  - 在各目标上基于 interval probability 定义 interval dominance；
  - 用 interval crowding distance 替代普通 crowding distance 维护区间目标空间分布。

## 核心算法流程

- 初始化 population `P_t`，每代执行 mating selection、SBX crossover 和 polynomial mutation 生成 offspring。
- 合并父代和子代为 `Q_t` 后执行两阶段环境选择。
- 阶段由控制因子 `mu` 决定：
  - `t <= mu*Tmax`：第一阶段 global search；
  - `t > mu*Tmax`：第二阶段 feasible region approximation and exploration。
- 默认 `mu=0.5`，即前半预算增强区间目标全局搜索，后半预算强化可行性和可行域内优化。

## 第一阶段：区间目标全局搜索与二级排序

- 第一层排序：
  - 对合并种群 `Q_t` 使用 interval non-dominated sorting；
  - 完整接收前若干 front；
  - 对临界 front `L` 继续二级排序。
- 二级排序：
  - 为 `L` 中个体计算 convergence indicator `CI(x)` 和 `CV(x)`；
  - `CI(x)` 是个体区间目标到当前 population 全局理想区间点的总 interval distance；
  - 对 `min(CI(x), CV(x))` 形成的 bi-objective model 做 Pareto non-dominated sorting；
  - 若仍需截断，用 interval crowding distance 保留分布更好的个体。
- 设计意图：
  - interval non-dominated sorting 保留区间目标信息；
  - `CI` 增强向全局理想方向的收敛压力；
  - `CV` 避免第一阶段完全忽视约束；
  - 二级排序缓解多目标/区间目标下大量个体同层的问题。

## 第二阶段：可行率驱动的双子过程选择

- 先按 `CV(x)=0` 把 `Q_t` 分成 feasible subpopulation `SF` 和 infeasible subpopulation `SI`。
- 计算 feasible rate `phi=|SF|/|Q_t|`。
- 当 `phi < 0.5`：
  - 说明可行解不足；
  - 所有 feasible individuals 直接进入下一代；
  - 剩余名额由 `SI` 中 `CV` 较低的 infeasible individuals 填充；
  - 目标是快速靠近 feasible boundary 并提高可行解比例。
- 当 `phi >= 0.5`：
  - 说明候选解中已有足够可行解；
  - 只在 feasible set 中用 constrained interval dominance principle (CIDP) 排序；
  - 再用 interval crowding distance 维护可行域内分布；
  - 目标是沿 feasible PF 继续改善区间目标收敛和多样性。

## 复杂度

- 第一阶段：
  - interval non-dominated sorting 约 `O(MN^2)`；
  - `CI/CV` 二级排序也按 `O(MN^2)` 计；
  - interval crowding sorting 为 `O(N log N)`。
- 第二阶段：
  - 低可行率子过程按 CV 排序；
  - 高可行率子过程执行 constrained interval non-dominated sorting 和 interval crowding；
  - 最坏复杂度仍为 `O(MN^2)`。
- 作者总结 TS-ICMOEA 的总体环境选择复杂度为 `O(MN^2)`。

## 实验设置

- 平台：PlatEMO。
- Benchmark：
  - 将 LIRCMOP1-LIRCMOP4 转成 interval-valued objective 版本，称为 InLIRCMOP；
  - 将 DC-DTLZ 转成 interval-valued objective 版本，称为 InDC-DTLZ；
  - InDC-DTLZ 覆盖 2、3、4、6、8、10、15 objectives。
- 对比算法：
  - DI-`mu`MOGA；
  - IMOEA-DS；
  - INSGA-II；
  - IP-ICA-MOEA，其中 IP-ICA-MOEA 只用于 bi-objective cases；
  - IMOEA-DS 使用三组 midpoint/width 权重：`0.3/0.7`、`0.5/0.5`、`0.7/0.3`。
- 公共参数：
  - population size `N=100`；
  - maximum iterations `Tmax=1000`；
  - crossover probability `1`；
  - mutation probability `1/D`；
  - penalty coefficient `10000`；
  - 30 independent runs。
- 指标：
  - Interval Inverted Generational Distance (IIGD)，越小越好；
  - feasible rate；
  - Wilcoxon rank test。

## 主要实验发现

- 阶段控制因子：
  - 比较 `mu=0.3`、`0.7`、`0.5`；
  - `mu=0.5` 在 InLIRCMOP 和 InDC-DTLZ 上综合最好；
  - `mu` 增大可加强第一阶段全局搜索，但过长会压缩后期可行域搜索。
- 2/3 目标结果：
  - TS-ICMOEA 在所有 InLIRCMOP 上取得最佳 IIGD，并保持完整可行性；
  - 在多数 InDC-DTLZ 低维目标问题上也有明显优势；
  - Wilcoxon 结果中，对比算法显著优于 TS-ICMOEA 的数量通常为 0-1，显著劣于 TS-ICMOEA 的数量为 8-14。
- Feasible rate：
  - TS-ICMOEA 在 2/3 目标 InDC-DTLZ 上除 `InDC2-DTLZ3` 的 2-objective case 外均达到 1.0；
  - `InDC2-DTLZ3` 2-objective case 的 feasible rate 为 0.93333。
- Many-objective 结果：
  - 在 4-15 objectives 的 InDC-DTLZ 可评价实例上，TS-ICMOEA 的 IIGD 基本为各算法最佳；
  - Table 6 的统计行显示没有对比算法在任何可统计问题上显著优于 TS-ICMOEA；
  - feasible rate 在多数高目标实例上达到 1.0，但 `InDC2-DTLZ3` 随目标数增加下降到 0.7-1.0。

## 失败或边界案例

- 在部分 `InDC-DTLZ3` 低维问题上，TS-ICMOEA 的 IIGD 不如 DI-`mu`MOGA、INSGA-II 或某些 IMOEA-DS 权重版本。
- 作者解释可能原因是第一阶段环境选择压力过强，使 population 早期全局搜索时越过 feasible domain，后期难以回到 convex feasible PF。
- `InDC3-DTLZ1` 在 8、10、15 objectives 下无法计算 IIGD，原因是 PlatEMO 框架中 true constrained PF 难以生成，所有算法相关结果为 NaN。
- 论文主要使用 benchmark，没有真实工程 ICMOP 案例；Data availability 为数据可按请求提供。

## 与知识库相关的设计知识

- 新增/关联设计知识：
  - `K-interval-feasibility-staged-environmental-selection`：区间目标-可行率两阶段环境选择。
- 与已有设计知识的区别：
  - 不同于 `K-kde-interval-pareto-adaptive-mopso`：该知识关注如何从数据构造目标区间并在 MOPSO 中用 IPOR、interval crowding 更新 pBest/gBest/archive；本文关注已有 interval-valued objectives 且带约束时如何做两阶段环境选择。
  - 不同于 `K-bijective-interval-fractional-determinization`：该知识把区间分式目标映射到实值多目标问题；本文保留区间目标并直接做 interval dominance / crowding。
  - 不同于 `K-constraint-violation-state-surrogate-mode-switching`：该知识是昂贵约束代理搜索中的模式调度；本文没有 surrogate，而是在常规 ICMOEA 环境选择中用 feasible rate 切换。
  - 不同于 `K-quantile-staged-constraint-allocation-boundary-transfer`：该知识动态分配具体约束子集并迁移边界不可行解；本文不分配约束，而是按整体 feasible rate 决定保留低 CV 不可行解还是可行集内区间排序。

## 局限与未来工作

- `mu=0.5` 虽然实验上综合较好，但仍是固定阶段比例；不同 ICMOP 可能需要自适应阶段切换。
- 第一阶段强选择压力可能让 population 越过复杂可行域，特别是在某些 convex feasible PF 或断裂可行域问题上。
- 论文处理的是 interval-valued objectives，未来还需要扩展到具有 complex interval constraints 的 ICMOP。
- 区间目标大量重叠或 many-objective 场景下，interval dominance 仍可能产生选择压力不足，需要额外 indicator、reference vector 或 preference 机制。
