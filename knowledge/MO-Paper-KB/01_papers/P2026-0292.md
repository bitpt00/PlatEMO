# Multiobjective Reinforcement Learning: A Comprehensive Overview

## 一句话理解

这是一篇多目标强化学习综述，按 single-policy 与 multiple-policy 两条主线梳理 MORL：前者把多目标回报转成一个偏好化动作选择准则，后者学习一组近似 Pareto front 的策略；同时总结 weighted-sum、W-learning、AHP、ranking、geometric、convex hull、varying parameter 等代表方法，并指出动态偏好、评价基准、状态表示、VFA、收敛理论和多智能体扩展仍是关键难题。

## 问题与动机

- 研究问题和场景：标准 RL 通常最大化单个长期标量回报，但控制、调度、机器人、网络路由和工业决策常同时存在多个长期目标，且这些目标往往冲突。
- 为什么重要：
  - 若目标完全一致或彼此独立，可以合并或分别优化；MORL 真正关心的是策略必须在冲突目标之间折中的情形。
  - 多目标决策需要保留偏好表达、Pareto 策略覆盖和在线行动选择之间的关系，不能只把 MOO 方法机械套到静态优化上。
  - 对后续算法设计而言，明确“单策略偏好化”与“多策略前沿逼近”的区别，有助于判断算法究竟输出一个可执行策略还是一个 policy set。
- 现有研究为什么需要综述：
  - MORL 当时仍较分散，很多算法只在各自任务上验证，难以比较。
  - 多数方法依赖问题先验、偏好权重或目标排序，且缺少统一 benchmark 和已知 Pareto front。
  - MORL 既继承 RL 的状态表示、值函数近似、收敛困难，又继承 MOO 的偏好、非凸 PF 和解集多样性问题。
- 本文希望解决什么：提供 MORL 的基本架构、研究主题、朴素解法、代表方法、重要研究方向和开放问题的系统化地图。

## 核心内容与分类框架

- MORL 基本建模：
  - 环境对同一状态转移返回 reward vector，而不是单一 scalar reward。
  - 每个目标对应一个 state-action value function，组合成 vectored state-action value。
  - `max_pi MQ_pi(s,a)` 与 `max MQ*(s,a)` 都是多目标优化问题，需要偏好表达或 Pareto 选择。
- 两类主要路线：
  1. Single-policy approaches：学习一个满足用户或任务偏好的最佳策略。关键差异在于如何把多个 `Q_i(s,a)` 转成动作选择准则 `TQ(s,a)`。
  2. Multiple-policy approaches：学习一组策略来近似 policy space 中的 Pareto front。关键差异在于如何逼近或覆盖 Pareto front。
- 研究主题：
  - 多目标之间的偏好，以及偏好是否随时间变化；
  - 偏好的数学或交互式表示方式；
  - Pareto front / Pareto policy set 的近似；
  - 面向具体 sequential decision problem 的高效算法设计。
- 朴素方案：
  - Single-policy：维护每个目标的 Q 值，再用合成目标函数 `TQ(s,a)` 选择动作。
  - Multiple-policy：用不同参数、权重、阈值或目标排序多次运行 single-policy 算法，得到一组候选策略。

## 本文重要方法或综述对象

| 方法/路线 | 核心机制 | 作者评价或边界 | 来源章节或 PDF 页码 |
|---|---|---|---|
| Weighted-sum / GM-Q / GM-Sarsa | 对各目标 Q 值做简单求和或加权和，按合成 Q 值选动作 | 实现简单，但对凹 Pareto front 中的 unsupported actions 无法选择，除非改用问题相关的非线性函数 | Sec. IV-A，PDF 5 |
| W-learning / negotiated W-learning | 每个目标估计若不能选择自己偏好动作会损失多少长期回报，执行最大损失目标的偏好动作 | 可避免单纯最高 Q 目标“无所谓”时压制其他目标，但依赖 reward 结构 | Sec. IV-B，PDF 5-6 |
| AHP approach | 用成对目标重要性、重要性矩阵和 fuzzy inference 把定性偏好转成相对好度 | 能表达定性偏好，但需要大量领域先验和规则设计 | Sec. IV-C，PDF 6 |
| Ranking / threshold / sequential approach | 指定目标顺序和阈值，最大化主目标同时满足其他目标最低要求 | 适合安全阈值、风险约束等场景，但目标顺序和阈值仍依赖先验 | Sec. IV-D，PDF 6-7 |
| Geometric approach | 让长期平均 reward vector 接近预设 target set，基于 approachability 思想 | 适合平均回报和目标集合表达，但 target set 仍需领域知识 | Sec. IV-E，PDF 7 |
| Convex hull approach | 备份对某些线性偏好最优的 Q-value vector vertices，一次学习所有线性偏好下的最优策略 | 可视作 value iteration 的多目标扩展；要求 off-policy 框架，覆盖线性偏好对应的 convex hull | Sec. IV-F，PDF 7 |
| Varying parameter approach | 多次运行单策略算法，扫描权重、阈值或排序参数以形成策略集 | 易实现，但效率和覆盖质量取决于参数采样设计 | Sec. IV-G，PDF 7-8 |
| Dynamic preferences | 偏好权重可能随时间变化；可用 preference elicitation、inverse RL 或有限 policy set 覆盖权重空间 | 固定权重可能收敛到劣解；需要在偏好变化时快速选择或更新策略 | Sec. V-B，PDF 8-9 |
| MORL evaluation benchmarks | 建议使用有已知 PF 的任务和区分 single-policy online / multiple-policy offline 的评价指标 | 早期研究缺少统一测试问题和方法，导致算法难比较 | Sec. V-C，PDF 9 |

## 综述结论与证据边界

- 代表性结论：
  - Weighted-sum 与 W-learning 容易实现，但偏好表达能力有限。
  - AHP、ranking 和 geometric approach 能更精细表达偏好，但需要更多问题先验。
  - Convex hull approach 可以同时学习所有线性偏好下的最优策略；varying parameter approach 则通过多次运行单策略算法形成近似策略集。
  - 近期方向包括改进算法质量、适应动态偏好、构建统一评价系统。
- Benchmark 与评价：
  - 作者强调当时 MORL 缺少统一 benchmark、方法学和已知 PF，导致不同论文之间难做绝对比较。
  - 文中提到 Deep Sea Treasure、MO-Puddle World、MO-Mountain-Car、Resource Gathering 等可作为 MORL 评价基础。
  - Online single-policy 与 offline multiple-policy 需要不同评价指标，不能只用同一套 PF 指标。
- 对后续知识库的价值：
  - 这篇更像 MORL 术语和路线地图，可用于解释为什么后续方法要做 preference-conditioned policy、Tchebycheff scalarization、policy set learning、hierarchical MORL 或 replay-based sample efficiency。

## 局限与未来工作

- 作者明确强调的开放问题：
  - State representation in MORL：多目标同时存在时，状态特征必须兼顾所有目标，难度高于单目标 RL。
  - Value function approximation in MORL：大规模或连续状态空间需要 VFA；动态偏好和多目标表示进一步提高近似难度。
  - Convergence analysis：单策略方法的收敛依赖 sub-MDP 学习算法和偏好表示，多策略方法还依赖 PF 近似方式；动态偏好下需额外考虑时间变化，理论仍不足。
  - MORL in multiagent systems：多智能体系统天然多目标，但还要处理合作、竞争和均衡协调。
  - Applications：真实应用和通用 prototype/platform 仍少，需要研究理论限制在实践中有多严重，以及现实约束如何反过来塑造 MORL 模型。
- 我们认为仍需确认的问题：
  - 本文作为综述的可信使用方式应偏向术语和分类，而不是作为具体算法 novelty 的证据。
  - 许多方法的实证评价来自早期小规模任务，无法直接代表深度 MORL 或连续控制表现。
  - 线性偏好、ESR/SER criterion、convex coverage set 等现代 MORL 术语在本文中未充分展开，需要结合后续文献使用。
  - 原 markdown 中大量公式和图表是图片占位，精确公式应回 PDF 或原始论文核对。
