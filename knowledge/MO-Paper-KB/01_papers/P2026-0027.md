# Hybrid data-driven cement-stabilized soil design: An integration of machine learning, multi-objective optimization, and life cycle assessment

## 一句话理解

本文提出一个水泥稳定软土配比设计闭环：用 624 组文献数据训练 UCS 预测模型，采用 GWO 优化 XGB 超参数，再用 NSGA-II 生成 28 天 UCS-成本 Pareto 配比，最后用 entropy-TOPSIS 选最终 mix 并用 cradle-to-gate LCA 评估环境收益。

## 问题与动机

- 研究问题和场景：海洋软土/疏浚沉积物体量巨大，软土高压缩性、低抗剪强度、高含水和高塑性使其不能直接用于道路、堤坝、地基等工程；Portland cement 稳定能提高强度和承载力，但水泥用量带来高成本和 CO2 排放。
- 具体多目标问题：为 Bangkok clay 等高含水软土选择 water、binder、soil 配比，使 28 天 unconfined compressive strength (UCS) 尽可能高，同时材料成本尽可能低；环境影响通过后处理 LCA 评估。
- 现有算法为什么不足：
  - 传统配比实验耗时、费料、难以捕捉配比变量与软土性质之间的非线性交互；
  - 既有 ML 研究多停留在 UCS 预测，没有进入优化和可实施决策；
  - 已有 metaheuristic/NSGA-II 配比研究常能给 Pareto front，但缺少最终单一 mix 的客观选择；
  - ML-MOO 框架常忽略 LCA，难以说明工程配比的环境收益。
- 本文希望解决什么：
  - 构建 ML-metaheuristic-MOO-MCDM-LCA 一体化流程；
  - 比较多种 ML 模型并用 GWO/GA 调参提升 XGB；
  - 用 entropy-TOPSIS 在 Pareto 集中选可实施配比；
  - 用 LCA 将 strength-cost 优化结果转化为碳排放和环境指标证据。

## 核心理念与算法流程

- 核心理念：把“配比-强度”学习成低成本代理后，先在代理上做 Pareto 搜索，再通过客观权重的 TOPSIS 选解，最后用 LCA 审计该解是否真的降低环境影响。
- 主要流程：
  1. 文献计量：用 WoS 和 VOSviewer 分析 cement-soil stabilization 中 ML、UCS、cement、clay 等关键词关系，发现 optimization 和 environmental impact assessment 仍不充分。
  2. 数据集：整理 624 组 cement-stabilized soft soil 样本；输入为 curing time (CT)、water content (WC)、binder content (BC)、liquid limit (LL)、plastic limit (PL)、specific gravity (SG)、fines content (FC)，输出为 UCS。
  3. 预处理：检查无缺失值，用 min-max normalization 缩放变量；随机 80/20 train-test split，并做 10-fold CV。
  4. 模型比较：比较 MLR、DT、RVM、RF、LGBM、XGB；用 RMSE、R2、R、RSR 和 Taylor diagram 评价。
  5. 元启发式调参：对最佳 XGB 用 GWO 和 GA 优化超参数，得到 XGB-GWO 与 XGB-GA。
  6. 解释性分析：用 variable importance 和 SHAP 解释 UCS 代理。
  7. 多目标优化：以 XGB-GWO 预测的 28 天 UCS 和 polynomial cost function 为双目标，用 NSGA-II 搜索 Pareto 配比。
  8. MCDM 选解：用 entropy-weighted TOPSIS 根据 UCS-cost 数据自身变异给权重并排序，选最终配比。
  9. LCA：用 OpenLCA、ecoinvent v3.7 和 ReCiPe 2016 midpoint (H) 做 cradle-to-gate LCA，比较优化 mix 与实验 mix 的 GWP 等环境指标。
- 关键组成部分：
  - 代理目标：`min F(x) = [-f1(28,x,c), f2(x)]`，其中 `f1` 是 XGB-GWO 预测 UCS，`f2` 是材料成本；
  - 决策变量：`x=(Qw/Qs*100, Qb/Qs*100)`，即水/土质量比和 binder/soil 质量比；
  - 固定土类条件：Bangkok clay `c=(LL,PL,SG,FC)=(89,30,2.71,97)`；
  - 成本函数：`f2(x)=CwQw+CbQb+CsQs`，water 0.001 USD/kg，binder 0.082 USD/kg，soil 0.014 USD/kg；
  - 约束：Water 619-812 kg/m3、Binder 150-250 kg/m3、Soil 636-931 kg/m3、Water/Binder 3.01-5.34、Binder/Soil 0.16-0.39；
  - NSGA-II 参数：population 100、200 generations、crossover probability/distribution index `(0.9,15)`，mutation probability/distribution index `(0.1,15)`；
  - GWO/GA 调参参数：population 50、100 iterations、seed 123。
- 可能被修改的位置：
  - 用 source-aware split、leave-one-source-out 或 domain adaptation 替换随机 80/20；
  - 把 LCA 指标从后处理变成第三目标或约束；
  - 加入代理不确定性，避免 NSGA-II 选择代理外推高收益配比；
  - 将 entropy-TOPSIS 换成交互式偏好、Nash bargaining 或法规阈值约束；
  - 扩展到 shear strength、deformation modulus、permeability 和 durability。
- 必须保留的核心：XGB-GWO 只是强度预测代理，NSGA-II 的 Pareto front 是代理前沿；最终工程使用仍需要实验验证和地区化 LCA 数据。

## 实验证据

- 测试问题和对比算法：
  - 预测任务：624 组水泥稳定软土样本的 UCS 预测，随机 80/20 train-test，10-fold CV。
  - ML 对比：MLR、RVM、RF、DT、LGBM、XGB。
  - 超参数优化：GWO 与 GA 优化 XGB。
  - 多目标优化：NSGA-II 优化 28 天 UCS 和 material cost，entropy-TOPSIS 选解。
  - 环境评估：CTG LCA 比较 Mix 1/2/3/4。
- 主要实验结论：
  - Table 1 中变量范围：CT 3-90 days、WC 5-220%、BC 3-60%、LL 33-170%、PL 15-64%、SG 2.14-2.95、FC 60-100%、UCS 15-3628.68 kPa。注意 Table 1 中 LL count 写成 642，而正文称数据库 624 样本，疑似排版或数据统计不一致。
  - Taylor diagram 与 Table 3 均显示 XGB 最好；测试集 XGB RMSE 120.50、`R2=0.94`、`R=0.97`、RSR 0.24；MLR 最差，测试 `R2=0.51`。
  - XGB-GWO 测试 RMSE 82.168、`R2=0.973`、`R=0.987`、RSR 0.162，略优于 XGB-GA 的 RMSE 83.485、`R2=0.973`、`R=0.986`、RSR 0.165。
  - XGB-GWO runtime 52 min，XGB-GA runtime 101 min；作者称混合模型相对 base XGB 平均降低 RMSE 约 31%。
  - 10-fold CV 中 XGB-GWO 的 RMSE 为 `189.34 ± 52.88`，`R2=0.90 ± 0.05`；Friedman/Wilcoxon 显示 XGB-GWO 相比多数 baseline 显著改进，但相对 base XGB 不显著。
  - SHAP 和 feature importance 共同给出重要性：binder content > water content > plastic limit > curing time > liquid limit > specific gravity > fines content。高 water content、plastic limit、fines content 通常降低 UCS；高 binder content、curing time、specific gravity 提高 UCS。
  - NSGA-II+entropy-TOPSIS 选出的 Mix 1：binder 209.78 kg/m3、water 668.53 kg/m3、soil 636 kg/m3、28-day UCS 2243.21 kPa、cost 26.77 USD/m3、TOPSIS `Si=0.847`。
  - NSGA-II Pareto 解范围：UCS 1008.63-2262.80 kPa，cost 21.82-27.28 USD/m3；实验数据范围：UCS 669-2250 kPa，cost 22.70-31.93 USD/m3，说明代理 Pareto 解在 strength-cost 上整体优于实验点。
  - 权重敏感性：UCS 权重从 0.30 到 0.70 时，所选 UCS 约在 1965-2263 kPa 间变化，成本在 24.31-27.28 USD/m3 间变化；作者认为中等权重扰动下选解稳定。
  - LCA：Mix 1 的 GWP 为 159.8 kg CO2 eq，Mix 3 highest-cost experiment 为 190.4 kg CO2 eq，减排 16.07%；Mix 1 还把 UCS 从 Mix 3 的 1348 kPa 提高到 2243.21 kPa，并把成本从 31.93 降到 26.77 USD/m3。
  - 大规模估算：若欧洲和美国约 600 million m3 marine soft soils 用 Mix 1 替代 Mix 3，作者估计节省约 3.1 billion USD，并减少 18.37 million metric tons CO2 eq。
- 消融或机制证据：
  - 模型比较和 GWO/GA 调参比较支持 XGB-GWO 选择。
  - Friedman/Wilcoxon 说明 XGB-GWO 相比多数 baseline 有统计显著性，但不是显著优于 base XGB。
  - TOPSIS 权重敏感性支持 MCDM 选解的稳定性，但不等于真实工程偏好下的唯一最优。
  - LCA 是后处理证据，说明选出的 strength-cost 解环境指标也更低，但环境指标没有直接参与 NSGA-II 搜索。
- 证据边界：
  - 随机 80/20 切分可能高估跨文献来源、跨土类、跨地区部署性能；缺少 source-based/leave-one-study-out 验证。
  - 训练 `R2≈0.999` 虽然作者认为正常，但仍需警惕树集成在同分布数据上的过拟合。
  - NSGA-II 的 Pareto 解依赖代理预测，未报告对 Mix 1 和其他 Pareto 解进行新的制样实验验证。
  - LCA 使用 ecoinvent 默认和平均全球供应链，地区能源结构、运输距离、施工设备会改变 GWP。
  - MOO 当前只优化 UCS 和 cost；LCA 没有成为第三目标，因此可能漏掉 strength-cost 很好但某些环境指标较差的解。

## 局限与未来工作

- 作者明确说明的局限：
  - LCA 的区域供应链差异未覆盖，采用平均全球供应链假设；
  - 当前框架主要预测 UCS，其他机械性能未纳入；
  - DL 模型如 LSTM/CNN 尚未与树模型在该框架中比较。
- 作者未来工作：
  - 探索 LSTM 等能捕捉时间/序列依赖的深度学习结构；
  - 比较 XGB 等树模型与 LSTM/CNN 在泛化和数据效率上的 tradeoff；
  - 扩展到 shear strength、deformation modulus；
  - 应用于更多 soil-binder 组合以验证通用性和鲁棒性。
- 我们认为仍需确认的问题：
  - 需要 leave-one-source-out 或按 soil type/binder type 切分，验证 XGB-GWO 是否真的能跨来源泛化。
  - Mix 1 的真实性能需要新实验验证，尤其是高含水 Bangkok clay 条件下的现场施工可行性。
  - LCA 应该作为后处理还是纳入 MOO 目标，取决于项目是否把碳排放作为硬约束或同等目标。
  - Entropy 权重来自当前 Pareto 数据变异，不一定代表业主、规范或碳政策偏好。

- 暂留在论文卡中的方法、原理或架构启发：
  - “Pareto front + entropy-TOPSIS + 权重敏感性”是比单纯输出 Pareto front 更接近工程落地的选解流程；
  - LCA 后评估可以发现 cost/strength 优化是否同时带来环境收益；
  - GWO/GA 调参本身也应与 base XGB 显著性比较，避免把微小调参收益过度解释。
- 局部创新线索：
  - 在 NSGA-II 中加入 GWP 或多项 LCIA 指标作为第三/多目标，而不是只做后处理；
  - 对 Pareto 解按代理不确定性、source distance 和 LCA 置信区间进行二次筛选；
  - 用 MCDM 权重作为交互式偏好输入，动态选择不同工程场景下的 mix。
- 结构创新线索：
  - 构建“source-aware ML surrogate -> NSGA-II Pareto -> interactive MCDM -> regional LCA -> verification experiment”的可持续地基处理设计平台；
  - 将 soil properties 作为场景条件，训练条件化配比优化器，为不同土类快速给出可行 mix；
  - 引入主动学习，让 LCA/代理不确定性最高的 Pareto knee point 优先进入实验验证。
