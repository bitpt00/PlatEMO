# 基于网格与关系学习的昂贵多目标进化算法

## 一句话理解

论文提出 GRE-MOEA：不用代理模型精确预测目标值，而是用网格筛出的高质量解构造成对关系样本，训练关系代理判断候选是否优于参考点，再在有限真实评价预算下筛选少量 promising solutions。

## 问题与动机

- 研究问题和场景：
  - 面向 expensive multi-objective optimization problems (EMOPs)，真实函数评价次数很少，论文默认最大真实评价次数为 300。
  - 目标数从 3 到 10，决策维数为 30 或 50，并包含 Car Side Impact 真实工程问题。
- 现有算法为什么不足：
  - 回归代理需要预测多个目标值，高维或样本少时精度不足，训练成本也较高。
  - 分类代理只判断好/坏，但在有限样本下容易产生类别不平衡。
  - 关系学习可以用 `(x,y)` 与 `(y,x)` 构造正负样本缓解不平衡，但所有两两组合会产生大量训练对，增加训练时间并引入许多低价值关系。
- 本文希望解决什么：
  - 用网格环境选择先筛出高质量样本，再只基于这些样本构造成对关系训练集。
  - 用关系代理直接比较候选与参考点，而不是预测绝对目标值。
  - 在代理内循环中生成大量候选，但每轮只真实评价少量高分且远离既有评价点的候选。

## 核心理念与算法流程

- 核心理念：
  - 在昂贵 MOO 中，候选间的相对优劣关系可能比精确目标值更容易学习。
  - 成对关系天然提供方向相反的正负样本，可缓解分类不平衡。
  - 网格排序可以在目标空间中提供轻量收敛/分布信号，用于减少训练对数量并保留高价值关系。
- 主要流程：
  1. 用 LHS 生成初始种群并真实评价，所有真实评价样本进入外部档案 `Arc`。
  2. 生成均匀参考向量，并在每轮迭代中用网格环境选择从当前种群中选出前 `N/2` 个 `Pbest`。
  3. 基于 `Pbest` 构造成对关系训练集，训练 PNN 关系代理。
  4. 根据当前评价进度计算 APD 权重 `eta=(FE/FEmax)^alpha`，从种群和参考向量中选出参考点 `Pref`。
  5. 在代理辅助内循环中生成候选，将每个候选与参考点成对输入代理，并按双向关系预测得到候选分数。
  6. 用与已真实评价样本的距离阈值过滤候选，选出最多 6 个高分候选真实评价。
  7. 将新评价样本加入 `Arc`，并用 GrEA 环境选择从档案中更新下一代种群。
- 关键组成部分：
  - **网格排序训练样本筛选**：只用网格环境选择得到的前 `N/2` 个高质量解构造关系样本。
  - **成对关系代理**：PNN 输入两个决策向量的拼接，输出一个解相对另一个解的优劣关系。
  - **参考点驱动候选打分**：候选分别与多个参考点双向比较，累积关系预测分数。
  - **距离过滤真实评价**：避免重复评价过近候选，把真实评价预算留给新区域。
  - **档案式环境选择**：所有真实评价解进入外部档案，再由 GrEA 选择当前工作种群。
- 可能被修改的位置：
  - 可替换昂贵 MOO 中的 surrogate candidate screening、surrogate training set construction 或真实评价候选预筛选模块。
- 必须保留的核心：
  - 代理学习目标是相对优劣关系，而不是绝对目标值；
  - 训练对必须由质量筛选后的子集构造，避免所有样本两两配对带来的时间成本；
  - 代理筛选出的候选必须用真实评价闭环更新档案。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：DTLZ1-7 与 WFG1-4，共 11 个函数；决策维数 `D=30,50`，目标数 `M=3,5,8,10`，共 88 个实例。
  - 对比算法：CSEA、K-RVEA、EDN-ARMOEA、REMO、PC-SAEA；真实问题 CSI 额外对比 NSGA-II 与 MOEA/D。
  - 设置：`FEmax=300`，种群规模 `N=50`，初始 LHS 样本 100，`div=30`，`k=6`，`alpha=2`，代理内循环 `Gmax=3000`；PlatEMO 实现，30 次独立运行，Wilcoxon rank-sum test 显著性水平 0.05。
- 主要实验结论：
  - **论文实验直接支持**：GRE-MOEA 在 88 个 benchmark 实例中获得 62 个最佳结果；K-RVEA 获得 19 个最佳，REMO 获得 7 个最佳，CSEA、EDN-ARMOEA 和 PC-SAEA 均未获得最佳。
  - **论文实验直接支持**：GRE-MOEA 在 DTLZ1-5 和 WFG1 上优势明显；在 DTLZ6/WFG1/WFG2 上与 REMO 或 K-RVEA 接近；在 DTLZ7 和 WFG4 上弱于 K-RVEA，但通常优于 REMO 与 PC-SAEA。
  - **论文实验直接支持**：CSI 真实问题中，GRE-MOEA 的 HV 为 `4.9066e-2 (1.21e-2)`，高于 NSGA-II、MOEA/D、CSEA、K-RVEA、EDN-ARMOEA、REMO 与 PC-SAEA；表 8 中所有对比算法相对 GRE-MOEA 均显著更差。
  - **论文实验直接支持**：运行时间上，GRE-MOEA 快于 K-RVEA、EDN-ARMOEA 和 REMO，但慢于 CSEA 与 PC-SAEA，说明关系代理和网格筛选带来中等额外开销。
- 消融或机制证据：
  - **论文实验直接支持**：训练数据规模消融比较 `N/4`、`N/2`、`3N/4` 和全部样本构造关系对，性能差异不大，但较小训练集明显降低训练时间，论文选择 `N/2` 作为折中。
  - **论文实验直接支持**：用 GR、SDE 和 PC-SAEA fitness 比较候选质量评估，GRE-MOEA 的 GR 方案在超过半数实例中更优或相当。
  - **论文实验直接支持**：参考点选择消融显示，GRE-MOEA 的参考点策略相对 REMO 径向投影和 NSGA-II crowding-distance 非支配参考点，在多数实例更好或相当。
  - **论文实验直接支持**：代理模型消融中，PNN 平均排名 1.90；DT 接近，RF 和 SVM 略差，因此作者选用 PNN。
  - **论文实验直接支持**：`div` 在 DTLZ1-DTLZ5 上不太敏感，论文采用 `div=30`；`k=6` 在 DTLZ5 等场景上优于或接近 `k=3,8,10`。
- 证据边界：
  - 主体 benchmark 为无约束 EMOP；CSI 将约束视为目标并在可行解集上计算 HV，不能等同于完整 constrained MOO 约束处理机制。
  - DTLZ7 与 WFG4 上 K-RVEA 更强，说明关系代理和网格评分对断裂或复杂 PF 并非总是占优。
  - 训练集规模消融显示 `N/2` 主要节省时间，性能优势不是绝对的。
  - PNN 是本文默认选择，但 DT 可达到接近表现，关系代理框架不必绑定到 PNN。

## 局限与未来工作

- 作者明确说明的局限：
  - 网格划分参数 `div` 和参考点数量 `k` 仍需随问题复杂度调整。
  - 高维问题中关系代理训练成本仍可能较高，需要更轻量代理降低时间开销。
  - 非均匀目标空间分布可能削弱固定参考点选择策略。
- 作者未来工作：
  - 将 GRE-MOEA 扩展到 constrained environments。
  - 研究 distributed data EMOPs。
  - 尝试把关系学习与 regression/classification surrogate 结合。
- 我们认为仍需确认的问题：
  - 关系标签如何定义和处理噪声、近似相等或互不支配候选。
  - 网格排序在 many-objective 稀疏支配或强退化 PF 下是否仍能稳定选出高质量 `Pbest`。
  - 距离过滤阈值 `gamma*Delta_g` 是否会在离散/混合变量问题中过早排除有效邻域搜索。
  - 若真实评价预算高于 300，关系代理相对回归代理的优势是否持续。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“网格排序成对关系代理筛选”：它提供了可直接移植的训练样本构造、关系代理评分和真实评价候选筛选接口。
- 暂留在论文卡中的方法、原理或架构启发：
  - PNN、DT、RF、SVM 的具体替换实验只作为代理选择证据保留，不单独建卡。
  - APD 参考点聚类选择是 GRE-MOEA 的重要组件，但目前更适合作为该关系代理流程的一部分记录。
- 局部创新线索：
  - 将固定 `N/2` 训练集改为按代理不确定性或网格拥挤度自适应选择。
  - 对候选与参考点的关系打分加入置信度、历史真实评价贡献或局部密度惩罚。
  - 用 pairwise ranking loss、GNN 或 transformer 替代 PNN，保留成对关系学习接口。
  - 将关系标签扩展为三值：明显更好、明显更差、难以区分，以减少噪声标签。
- 结构创新线索：
  - 构造“质量筛选器 + 成对关系代理 + 参考点任务集 + 真实评价门控”的通用 expensive MOO 代理层。
  - 与自适应代理内环加速器结合：关系代理负责候选排序，贡献监控负责决定代理内循环是否继续。
  - 与约束状态切换结合：无约束阶段用关系代理筛目标进展，约束阶段对可行性关系或 CV 关系建模。
