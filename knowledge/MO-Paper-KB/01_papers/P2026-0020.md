# A Q-learning based multi-objective memetic algorithm for dual-resource-constrained energy-saving distributed flexible job shop scheduling with applications in aerospace manufacturing

## 一句话理解

本文把 energy-saving distributed flexible job shop scheduling 扩展为同时考虑机器重启与工人分配的双资源问题：每道工序不仅要选工厂、机器和顺序，还要选工人；目标为最小化 makespan、系统碳排放和最大工人负载。作者提出 QMOMA，用增强 reference-point NSGA-III 做全局搜索，在解码时用能量反馈的自适应机器重启阈值平衡 idle energy 与设备寿命，并用 Q-learning 根据收敛/多样性状态在线选择六类调度邻域做局部搜索。

## 问题与动机

- 研究问题和场景：dual-resource-constrained energy-saving distributed flexible job shop scheduling with machine restart-aware and worker assignment，简称 `DRC-EDFJSP-WMR`，应用背景为航天复合材料加工车间。
- 现有方法为什么不足：
  - 许多 EDFJSP 只考虑机器资源，未系统引入 worker assignment；
  - 机器 on/off 或 restart 能节能，但固定阈值或 limited restart 策略难同时适应不同 idle gaps 与设备寿命约束；
  - 普通 memetic algorithm 的局部搜索常固定、顺序或随机调用，不能根据当前 Pareto 集状态选择合适邻域；
  - 人因调度若只看 workload 或 fatigue，可能忽略机器重启需要工人配合这一现实耦合。
- 本文希望解决什么：建立可由 CPLEX 小规模验证的 DRC-EDFJSP-WMR 模型，并设计可在 50 个 benchmark 和 8 个真实/扩展航天复材车间实例上稳定搜索三目标 Pareto 解的 memetic MOEA。

## 核心理念与算法流程

- 模型结构：
  - 子问题包括 factory allocation、machine selection、worker assignment 和 operation sequencing。
  - 约束要求每道工序同时分配可行 machine-worker pair，同一 job 的所有工序在同一 factory 内完成，每次机器重启也必须由一个 worker 执行。
  - 三个目标为 `f1=Cmax`、`f2` 总碳排放、`f3` 最大工人 workload。
  - 碳排放由加工能耗、idle standby 能耗、startup 能耗和 shutdown 能耗乘以电力排放系数得到。
- 染色体编码：四层向量 `OS/FS/WS/MS`，分别表示 operation sequence、factory selection、worker selection 和 machine selection。
- 机器重启解码：
  - 对相邻工序之间的 idle interval，比较 standby energy `E_i=IP_f*I_i` 与 worker-aware restart energy `ES_i=SP_f*ST+RP_f*RT`。
  - 若重启能耗低于持续 standby，则重启可能更节能；但频繁 start-stop 会增加磨损，因此解码时还使用动态阈值控制重启频率。
- Energy feedback adaptive restart：
  - 第 `i` 次重启阈值为 `T_i = B*(1+k_i*log(1+r_i))`，其中 `r_i` 是累计重启次数。
  - base threshold 用 energy feedback ratio 更新：`B <- B*(1-alpha*R)`，`R=E_idle/(E_idle+E_re+epsilon)`。
  - `k_i` 在 `[0.5,1]` 内用 sigmoid 随 idle interval index 调整，实验给出的 `k_best=0.8`。
  - 累计重启越多，`log(1+r_i)` 抬高阈值，从而抑制后续无效频繁重启。
- QMOMA 全局搜索：
  1. 初始化 reference points、四层染色体种群和 ideal point。
  2. 用 tournament selection 选父代。
  3. `OS` 用 POX crossover，`WS/MS` 用 UX crossover；`OS` mutation 包含 insertion、swap、inversion，`WS/MS` mutation 随机重选可行工人/机器。
  4. 合并父代和子代，做 non-dominated sorting。
  5. 最后一层超容量时，用增强 reference-point selection：reference direction normalization、Euclidean/cosine multi-distance fusion、solution distribution radius (SDR) 和 occupancy-aware offspring selection。
  6. 对 elite archive 调用 Q-learning adaptive variable neighborhood search。
- Q-learning 局部搜索：
  - 状态用 `Delta AMD` 与 `Delta ND` 的正负组合形成 4 个离散状态；`AMD` 近似收敛，`ND` 近似相邻解分布均匀性。
  - 动作是六个调度邻域 `NS1-NS6`：
    - `NS1/NS2` 侧重 worker workload balance；
    - `NS3` critical block adjacent swap；
    - `NS4` critical block 两端插入内部操作；
    - `NS5` 移动 critical block 首尾操作；
    - `NS6` 在首尾移动基础上合并相邻 critical blocks。
  - reward 为 `+1/-1`：若新 best objective vector 支配上一 best，则正奖励，否则负奖励。
  - policy 使用 epsilon-greedy，`P_suc>0.6` 时 `epsilon=max(epsilon*0.9,0.1)`，否则 `epsilon=min(epsilon*1.1,0.5)`。

## 实验证据

- 实验设置：MATLAB 2022，Intel Core i5-11320H 3.20 GHz；所有算法独立运行 20 次；population size 100；比较指标为 HV 和 IGD。
- 参数：Taguchi DOE 在 EM01-EM50 上给出最优组合 `ps=100`、`pc=1`、`pm=0.4`、`gamma=0.8`；`k_i` 范围 `[0.5,1]`；碳排系数 `alpha_e=0.674 kgCO2/kWh`。
- 小规模模型验证：用 IBM CPLEX 12.6.3 和 QMOMA 求解 Te01-Te08；CPLEX 在小规模单目标优化上更优，作者用此验证 MILP 模型正确性，QMOMA 面向大规模复杂实例。
- 组件消融：
  - `QMOMA01` 为无 restart-aware 的 NSGA-III baseline；
  - `QMOMA02` 加入 energy feedback restart；
  - `QMOMA03` 加入 enhanced reference-point selection；
  - `QMOMA04` 加入 local search；
  - `QMOMA05` 为完整 QMOMA。
  - 相比 `QMOMA04`，完整 `QMOMA05` 在 50 个 benchmark 上平均 HV 提升 32%，IGD 降低 11.4%，支持 Q-learning adaptive selection 的贡献。
- Q-learning 目标贡献：`QMOMA05` 相对 `QMOMA04` 平均 `f1` 改善 2.1%，`f2` 降低 0.2%，`f3` 改善 8.7%；作者指出 `NS1/NS2` 对工人负载改善更明显，`NS3-NS6` 更偏 makespan 与碳排。
- 算子选择行为：EM01 中 `NS6` 选择频率最高，其次为 `NS4/NS3`，`NS1/NS2/NS5` 较低但仍持续被调用，说明策略不是简单固定某个邻域。
- 复杂度：总体近似 `O(ps^2)`，与 NSGA-III、NSGAIISDR、IMA 同阶；平均 runtime 在比较算法中排名第二，主要开销来自 Q-learning adaptive VNS。
- 综合比较：与 MOEA/d-M2M、NSGAIISDR、NSGA-III、PREA 和 IMA 相比，QMOMA 在 50 个 benchmark 中 48 个实例表现最佳；相对最佳竞争者平均 HV 提升 26.4%，IGD 提升 67.3%；Friedman 检验 `p<0.05`，HV/IGD mean rank 分别为 1.00/1.12。
- 真实航天复材车间：WGe01-WGe08 包括 12 到 200 jobs、5 到 15 machines、10/20 workers 的场景；QMOMA 在真实/扩展复材车间数据中 HV 平均提升 22.8%，HV/IGD Friedman mean rank 均为 1.00。
- Data availability：作者声明数据开放在 GitHub 仓库 `https://github.com/BATTLE-Tao/Dataset.git`，文件为 FJS 格式并附 README 元数据说明。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前 worker assignment 采用随机选择机制，没有建模 worker efficiency 的 learning ability、experience、fatigue、psychological state 和 working environment。
  - Q-learning state representation 可能不足以捕捉复杂调度和 MOO 过程中的细微动态变化，未来可引入 deep reinforcement learning。
  - time windows、dynamic task arrivals 等其他分布式调度问题还需要额外算法改造。
  - 结论中还指出当前模型假设 worker efficiency uniform，并忽略 temporal uncertainties；未来会结合 fuzzy theory、stochastic programming、worker skill disparities，并扩展到 distributed flow shop scheduling。
- 我们认为仍需确认的问题：
  - `B <- B*(1-alpha*R)` 的阈值更新主要随 idle energy 占比下降，公式层面对“restart energy 过高时提高 base threshold”的表达不如文字强，需要实现时谨慎解释。
  - 重启策略与 enhanced reference-point selection、local search、Q-learning 同时出现，消融证明 restart 有贡献，但还缺少对动态阈值各子项的细粒度消融。
  - Q-learning 使用四状态和 `+1/-1` reward，状态较粗；对更大动作池、更动态车间或强噪声实例的泛化未验证。
  - benchmark 由经典 FJSP/DFJSP 实例扩展得到，真实数据集中具体工人技能、重启操作时间和设备磨损校准方式仍需现场确认。

- 暂留在论文卡中的方法、原理或架构启发：

  - 将 Q-learning 的动作扩展为“重启策略、worker reassignment、machine reassignment、critical block move”的联合动作，而不只选择局部搜索邻域。

  - 把 worker fatigue 或 skill learning 纳入 `NS1/NS2` 的 worker reassignment 规则，使局部搜索不只平衡 workload，还避免疲劳累积。
- 结构创新线索：
  - 构建“restart-aware decoder + human-aware resource assignment + RL neighborhood controller”的通用绿色人机协同调度框架。
  - 在数字孪生车间中在线记录 idle gap、restart failure、维修成本和 worker availability，用真实反馈更新 restart threshold 和局部搜索 reward。
