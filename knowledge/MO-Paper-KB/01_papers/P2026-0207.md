# Unleashing the Potential of Large Language Models for Dynamic Multiobjective Optimization

## 一句话理解

论文把 DMOP 的新环境解预测改写成时间序列预测问题，用 LLM 在环境变化后根据前 `w` 个环境的非支配解或其均值/方差分布统计生成下一环境初始种群；四类 prompt 分别对应个体级直接生成、加入问题公式、分布密度预测和 CoT 分布趋势推理，避免为每个 DMOP 训练专用预测模型。

## 问题与动机

- 研究对象：dynamic multiobjective optimization problems (DMOPs)，目标函数随时间/环境步变化，需要持续跟踪 dynamic Pareto optimal set/front。
- 现有 DMOEA 三类路线：
  - diversity-based：环境变化后注入随机或变异个体；
  - memory-based：复用历史环境中的优质解；
  - prediction-based：根据历史信息预测未来解状态。
- 作者认为 prediction-based DMOEA 虽然主流，但有两个关键问题：
  - data efficiency 低：回归、神经网络、surrogate 等模型需要足够历史数据；昂贵 DMOP 中历史数据稀缺；
  - model usability 低：模型结构、特征、重训练和超参数需要针对动态特性设计；大规模 DMOP 中更难泛化。
- LLM 带来的预期优势：
  - few-shot/zero-shot 预测潜力；
  - 通过 prompt 直接适配任务，少训练或不训练；
  - 对非线性趋势、规则变化和时间序列模式有一定推理能力。

## 核心方法：LLM-DMOEA

- 角色：
  - LLM 不是替代完整 MOEA，而是 dynamic response handler；
  - 环境变化时，LLM 根据历史非支配解预测下一环境初始种群；
  - 之后仍由 population-based MOEA 在新环境中继续搜索。
- 输入历史：
  - 记录前 `w` 个环境的 nondominated solutions `P_{t-w+1},...,P_t`；
  - 目标是在环境 `t+1` 生成 predicted initial population `P_pred`。
- 框架模块：
  - Data Processor：把历史解或其统计量转成 LLM 可处理的文本；
  - Prompter：用特定 prompt 调用 LLM，生成个体或预测分布统计。
- Algorithm 1：Prompt 1/2 个体级预测：
  - 对每个环境的非支配解做 scaling 与 quantization；
  - 若 `t < w`，随机初始化；
  - 否则将前 `w` 个环境的量化非支配解放入 prompt；
  - LLM 输出可解释为 individuals 的响应；
  - 反量化、反缩放后作为下一环境 `Popinit`。
- Algorithm 2：Prompt 3/4 分布级预测：
  - 对每个历史环境的非支配解用 Gaussian distribution 近似；
  - 记录 mean vector `mu_t` 与 diagonal variance vector `sigma_t^2`；
  - LLM 分别预测下一环境的 `mu_pred` 和 `sigma_pred^2`；
  - 从预测高斯分布中采样生成初始种群；
  - 该路线压缩 token 长度，更适合高维 DMOP。
- Scaling 与 quantization：
  - 先减去最小值，把数据投到非负范围，减少符号 token；
  - 再把浮点数按精度缩放为整数，减少长小数 token；
  - LLM 响应后再转换回原始尺度。
- 四类 prompts：
  - Prompt 1：solution generation，直接给历史非支配个体，让 LLM 生成新个体；
  - Prompt 2：problem-informed，在 Prompt 1 基础上加入数学公式/问题描述；
  - Prompt 3：probability density estimation，给历史 POS 的均值/方差，让 LLM 预测下一 POS 分布；
  - Prompt 4：CoT，在 Prompt 3 基础上引导 LLM 分步推理均值和方差的时间变化。
- 复杂度：
  - 数据处理为 `O(N)`；
  - Transformer LLM 推理主要为 `O(L^2)`，`L` 为 token 序列长度；
  - LLM 推理是主要成本。

## 实验证据

- 实验设置：
  - Benchmarks：DF problems；
  - 指标：Mean Inverted Generational Distance (MIGD)、Mean Hypervolume (MHV)；
  - 对比动态策略：DIP-DMOEA、Tr-DMOEA、KT-DMOEA、IBP-DMOEA、KTM-DMOEA；
  - 静态 solver：RM-MEDA 和 MOEA/D；
  - 随机初始化消融：RI-RM-MEDA、RI-MOEA/D；
  - Expensive DMOP：population size `10`，decision dimension `10`；
  - Large-scale DMOP：decision dimension `100`，population size `50`；
  - 动态参数：`(nt=5, tau_t=10)`, `(nt=10, tau_t=10)`, `(nt=10, tau_t=30)`；
  - `tau = 30 * tau_t`，表示 30 次环境变化；
  - 默认 window size `w=5`；
  - 默认 LLM：Gemini 1.5 Flash，temperature `1`；
  - 每组实验独立运行 10 次。
- Expensive DMOP + RM-MEDA：
  - 主文 Table I 用 Prompt 1；
  - LLM-RM-MEDA 在 DF3、DF4、DF7、DF8、DF11、DF14 的所有动态参数设置下优于对比算法；
  - 作者指出这些问题通常是 nonlinear，说明 LLM 在有限数据下处理复杂动态模式有优势；
  - IGD 曲线显示 LLM-RM-MEDA 多数时间位于较低位置，能快速跟踪 dynamic POFs；
  - MHV 统计中 LLM-RM-MEDA 获得 20 个最佳 case，对比 DIP/Tr/RI/KT/KTM/IB 分别为 1、10、0、3、1、7。
- 失败/弱点分析：
  - DF1 和 DF10 的 POF 在环境中持续从 concave 到 convex 变化，旧 POS 模式会失效，LLM 外推旧规则导致性能不如 IBP-RM-MEDA 或 Tr-RM-MEDA；
  - DF9、DF12、DF13 的 POF discontinuous 或有 gaps，LLM 预测的 smooth decision-space distribution 与真实不连续 objective landscape 不匹配。
- Large-scale DMOP：
  - LLM-RM-MEDA 在大规模设置下仍有竞争力，取得 15 个最低 MIGD 和 16 个最高 MHV；
  - 作者同时指出长 token 序列会降低 LLM 表现，建议 dimensionality reduction 或 population feature extraction 缩短输入。
- Generalizability to MOEA/D：
  - LLM-MOEA/D 在 expensive DMOP 中取得 16 个最佳 MIGD，其他 DIP/Tr/RI/KT/KTM/IBP-MOEA/D 分别为 8、7、0、0、11、0；
  - 在 large-scale DMOP 的补充表中，LLM-MOEA/D 取得 15 个最低 MIGD 和 13 个最高 MHV；
  - 说明框架不绑定 RM-MEDA。
- Prompt 对比：
  - Prompt 1 与 Prompt 4 整体优于 Prompt 2 与 Prompt 3；
  - Prompt 2 加公式后除 DF1 外通常不如 Prompt 1，作者推测 LLM 难理解复杂数学公式；问题公式简单时 Prompt 2 可能有用；
  - Prompt 4 优于 Prompt 3，说明 CoT 有助于分布趋势预测，但会增加响应时间；
  - 高维问题中 Prompt 3/4 明显优于 Prompt 1/2，因为 mean/variance 分布统计显著减少 token 长度；Prompt 4 在高维中最佳 case 达 28 个。
- Window size：
  - Prompt 1/2/3 在 `w=5` 时较好；
  - Prompt 4 在 `w=3` 时最好，可能因为 CoT 能从较少历史中抓重点；
  - 历史太少难以捕捉趋势，历史太多会让 LLM 难以聚焦关键信息。
- Different LLMs：
  - 使用 DeepSeek-V3 替代 Gemini 1.5 Flash 后，LLM-RM-MEDA 仍获得 19 个最优 MIGD 和 17 个最优 MHV；
  - 但有轻微性能下降，说明方法受所选 LLM 影响。
- 真实应用：dynamic fairness debugging in social networks：
  - 将 fairness debugging 扩展为 dynamic large-scale bi-objective optimization；
  - 目标是修改动态图数据，在 fairness 与 accuracy 间折中；
  - 数据集：NBA；
  - 每个 time step 图中变化 80 条 edges；
  - 集成到 GCN 和 FairGCN，得到 LLM-GCN 与 LLM-FairGCN；
  - GCN 中 LLM-GCN 将 ACC 从 72.59% 提升到 73.20%，同时 `Delta_SP` 从 4.27% 降到 2.44%；
  - FairGCN 中 LLM-FairGCN 将 ACC 从 70.19% 提升到 70.86%，`Delta_SP` 从 3.57% 降到 2.28%；
  - 作者称四个 fairness/accuracy 指标均有改进。

## 局限与未来工作

- 作者明确局限：
  - 成本来自 LLM inference time 和 network latency；
  - 10 维时 Prompt 1/2/3/4 约需 2.43/2.68/1.45/1.65 秒；
  - 100 维时约需 13.83/16.64/5.95/6.47 秒；
  - prompt 由人工经验设计，未来可用 prompt optimization 自动改进。
- 作者结论中的边界：
  - 论文认为这是 preliminary case study，仍有大量后续空间。
- 我们认为仍需确认的问题：
  - 商业/闭源 LLM 的版本、温度、网络延迟和调用成本会影响可复现性与实时性；
  - Gaussian diagonal distribution 对多峰、不连续或强相关 POS 的表达不足；
  - LLM 生成个体需要边界、约束、去重和失败解析策略，主文主要关注连续 DF benchmarks；
  - Prompt 2 的公式输入可能因数学表达复杂而退化，问题信息怎样结构化仍不明确；
  - 对真实公平调试案例，还需检查补充材料中的动态图生成、评价预算和统计显著性。

- 值得建立或补充的设计知识：
  - 新建设计知识：[LLM 提示的动态种群时间序列预测](../02_design_knowledge/K-llm-prompted-dynamic-population-time-series-prediction.md)。适合 DMOP 环境变化后需要少样本预测新初始种群、又不想为每个问题训练专用模型的场景。
- 与已有设计知识的关系：
  - 不同于[向量自回归降维动态响应](../02_design_knowledge/K-vector-autoregressive-pca-dynamic-response.md)：旧卡用 PCA+VAR 显式训练时间序列模型；本篇用 LLM prompt 做训练外推理，并可走个体级或分布级输入；
  - 不同于[二阶导数双域自适应动态预测](../02_design_knowledge/K-second-order-dual-domain-dynamic-prediction.md)：旧卡显式建模 PS/PF 的曲率/加速度；本篇把趋势推理交给 CoT prompt；
  - 不同于[可执行测试修复的 LLM 算法代码进化](../02_design_knowledge/K-llm-tested-reproduction-program-evolution.md)：旧卡让 LLM 生成算法代码，本篇让 LLM 预测下一环境的 population 或 distribution。
- 局部创新线索：
  - 对高维 DMOP，先用 PCA/autoencoder/reference-direction clustering 压缩 POS，再让 LLM 预测低维分布；
  - 对不连续 PF，使用 mixture of Gaussians 或 cluster-wise prompt，避免单高斯过平滑；
  - 加入输出 validator：边界修复、约束投影、去重、diversity check 和 small-budget probe；
  - 用策略选择器在 Prompt 1/3/4 间切换：低维用个体级，高维用分布级，复杂趋势用 CoT；
  - 把失败环境的 prediction error 反馈进下一次 prompt，形成轻量在线校正。
- 结构创新线索：

```text
environment change detected
-> collect recent nondominated populations
-> compress to individuals or distribution statistics
-> scale / quantize into text
-> prompt LLM for next POS / distribution
-> parse and validate predicted population
-> use MOEA solver to refine in new environment
-> record prediction error for future prompts
```

创新线索只需简短记录，不创建创意卡。单篇论文抽象出的原理和架构思路默认留在本节，不立即建立规则之外的新卡片类型。
