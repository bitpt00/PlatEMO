# Benchmarking continuous dynamic multi-objective optimization: Survey and generalized test suite

## 一句话理解

论文不是提出新的动态多目标优化算法，而是提出 Generalized Test Suite：把动态 Pareto set 从常见的超平面运动推广到超曲面运动，并可叠加变量贡献不均衡、动态变量相互作用、基于 pi 位数的可复现不规则时间扰动和历史解质量驱动的 time-linkage，用于更真实地区分 DMOA 的跟踪能力。

## 问题与动机

- 研究问题和场景：
  - 动态多目标优化问题中，PS/PF 会随时间变化，算法需要在有限响应时间内跟踪新的 Pareto set/front。
  - 许多现实场景具有非平滑环境变化、变量贡献不均衡、变量相互作用和历史决策影响未来状态的 time-linkage。
  - 因此 benchmark 不只是“给算法算分”，还会决定算法研究被鼓励解决哪些动态特性。
- 现有 benchmark 为什么不足：
  - FDA、DF、JY、SDP 等常用测试套件结构简单、数学可控，但大量问题让 PS 在超平面上变化，可能偏向能利用这种低维规则结构的算法。
  - 另一类让每个 PS 维度都有独立几何的 benchmark 又会把静态求解难度抬高，使结果难以判断来自动态处理能力还是静态 landscape 本身。
  - RDF/RDP 等不规则变化常依赖固定随机数发生器和种子，跨平台复现实验时可能不稳定。
  - 机器学习预测型 DMOA 逐渐增多，作者特别提醒：预测和模型训练时间必须进入评价，否则可能出现预测开销远大于基础优化时间的比较偏差。
- 本文希望解决什么：
  - 构造一套兼顾可解析性、可复现性和现实复杂性的连续 DMOO benchmark；
  - 让问题难度来源可以分层控制：PS 几何、变量重要性、变量交互、时间不规则性和 time-linkage；
  - 用更有区分力的测试环境暴露现有 DMOA 在复杂动态下的真实弱点。

## 核心理念与方法结构

- 核心理念：
  - 将 DMOP 的距离项 `g(x,t)` 设计成模块化载体：通过 `h1/h2` 控制 PS 运动形状，通过矩阵 `R_II,1(t)` 和 `R_II,2(t)` 控制变量贡献与交互，通过时间更新函数控制规则/不规则变化，通过 `phi(t)` 注入历史解误差。
- Generalized PS dynamics：
  - 将决策变量分为 `x_I`、`x_II,1`、`x_II,2`。
  - 传统 `P=1` 时所有距离变量共享同一几何，PS 常在超平面上变化；`P=D-M` 时每个维度单独变化，静态难度过高。
  - 本文采用中间形式 `1 < P < D-M`，主文以 `P=2` 构造 GTS，使 `x_II,1` 和 `x_II,2` 分别贴合 `h1(x_I,t)` 和 `h2(x_I,t)`，从而让 PS 在更一般的超曲面上移动，同时保持静态问题不过度困难。
- Controlled imbalance：
  - 通过调整 `R_II,1(t)` 与 `R_II,2(t)` 的对角元素，让不同变量对 `g(x,t)` 的贡献不同。
  - 这模拟现实系统中某些状态变量或控制变量比其他变量更关键的情形。
- Dynamic variable interaction：
  - 用随时间变化的对称正半定矩阵/旋转矩阵引入部分可分或完全非可分变量交互。
  - Theorem 3.1 给出矩阵构造方式，使 benchmark 难度可由谱性质和非对角关联控制。
- Temporally irregular dynamics：
  - 每个迭代时刻提取 pi 小数点后的指定数字作为伪随机扰动源，并缩放加入时间变化幅度。
  - 当扰动数字为 0 时退化为常规等步长动态；使用 pi 的确定性位数避免固定随机种子在不同平台上不可复现的问题。
- Time-linkage：
  - 在 `g(x,t)` 中引入 `phi(t)`，让未来 landscape 受上一时刻算法近似解质量影响。
  - 作者给出的主方案用真实 PF 膝点与估计 PF 膝点的目标差距定义 `phi(t)`：上一时刻越未收敛，`phi(t)` 越大，误差越会在后续问题中累积。
  - 为保证公平比较，算法也在同一预定义 baseline 问题上评估，`phi(t)=1` 可作为无历史误差影响的参照。

## GTS 实例与实验设置

- GTS 问题：
  - 共 11 个问题，GTS1-GTS8 为两目标，GTS9-GTS11 为三目标。
  - GTS6-GTS8 是 time-linkage case。
  - 表 3 总结了每个问题的 PS/PF 特征，例如 disconnected PS、PS moving on hypersurface、PF degeneration、knee point、PF disconnection、length/curvature changing 等。
  - 官方实现公开在 `https://github.com/dynoptimization/pydmoo`。
- 三组问题配置：
  - Group 1：`R_II,1` 和 `R_II,2` 为单位矩阵，代表简单可分问题。
  - Group 2：矩阵为对角矩阵，对角元素为自然数序列，注入变量贡献不均衡。
  - Group 3：矩阵为带非对角元素的对称正半定矩阵，注入变量相互作用。
- 对比 benchmark 和算法：
  - 使用 DF test suite 以及 FDA4/FDA5 作为传统基准参照。
  - 对比 6 个 DMOA：PPS、DPIM、AE、IGP、KGB、KTMM。
  - PPS/AE 属于经典预测方法；IGP/DPIM 先预测目标空间 PF 再映射到决策空间；KGB/KTMM 属于知识型方法。
- 运行设置：
  - 改变严重度 `n_t={5,10}`，每个时间段可用代数 `tau_t={5,10}`。
  - 每次运行包含 `T=50` 个时间段，第一次变化前先运行 50 代以降低静态优化影响。
  - 每个算法每个实例独立运行 20 次。
- 指标：
  - MIGD：平均 IGD，越小越好。
  - MHV：平均 HV，越大越好。
  - MMS/MS2：覆盖 true PF 的 spread 指标，越大越好。
  - DMIGD/DMHV/DMMS：跨问题、配置和 20 次运行的动态平均汇总。
  - Runtime：作者强调尤其对预测和机器学习型 DMOA 必须报告。

## 实验证据

- 与传统 benchmark 的差异：
  - DF 与 GTS Group 1 在 DMIGD、DMHV、DMMS 上仍处于同一数量级，说明 GTS 不是单纯把问题变得不可解。
  - 加入变量贡献不均衡和变量交互后，GTS Group 2/3 的 DMIGD 与 DMHV 可出现超过十倍的变化，而大多数算法运行时间并未显著增加。
  - 这说明 GTS 主要改变了解质量压力，而不是简单增加计算负担。
- 算法排名暴露出的偏置：
  - 在 DF 上，IGP 排名最好；作者解释为 DF 中多数 PS 在超平面上变化，IGP 的目标空间到决策空间逆映射更容易适配。
  - 在 GTS Group 1 中，PPS 排名第一，IGP 从 DF 第一降到第四；作者将其归因于超曲面 PS 与时间不规则扰动对 IGP 简单采样预测机制的挑战。
  - 在 GTS Group 2/3 中，KGB 排名接近 PPS，尤其 Group 3 表现突出；作者认为其知识引导 Bayesian 分类更适合处理变量交互。
- 运行时间：
  - 对大多数算法，DF 与 GTS 平均运行时间均低于约 16 秒，且两者差异小于 10%。
  - 不同正半定矩阵配置对运行时间影响很小，但明显影响 MIGD/MHV/MMS。
  - KGB 是例外：DF 约 470 秒，GTS Group 1 约 250 秒，GTS Group 2/3 约 25 秒；作者解释为变量独立性会让其聚类分组更耗时。
- 作者总评：
  - GTS 的分层结构能更系统地评价算法对不规则动态、超曲面 PS、变量贡献不均衡和变量交互的适应性。
  - 现有算法可能在标准 benchmark 上表现很好，但在更接近现实的动态结构中出现明显性能下降。

## 局限与未来工作

- 作者明确说明的未来方向：
  - 扩展到更多动态特征；
  - 探索更复杂真实优化场景；
  - 扩展到高维情况。
- 我们认为仍需确认的问题：
  - pi 位数扰动保证可复现，但仍是人工不规则源，是否覆盖真实动态系统的突变、周期漂移和噪声谱需要进一步验证。
  - time-linkage 用算法上一时刻表现改变未来 landscape，可能使不同算法实际面对不同后续轨迹；虽然作者设置 baseline 参照，但报告和复现实验时必须清楚区分。
  - GTS 主要是连续问题，离散、混合变量、强约束和 expensive black-box 动态问题还需要额外构造。
  - 指标仍主要在目标空间，若动态 PS 跟踪和决策空间稳定性很重要，还应补充决策空间指标和切换成本。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：超曲面不规则时联动的 DMOO 基准构造。它可用于设计动态算法压力测试：先以超曲面 PS 动态替代超平面动态，再逐层加入变量贡献不均衡、非可分交互、可复现不规则时间扰动和 time-linkage。
- 暂留在论文卡中的方法、原理或架构启发：
  - 动态算法论文若使用预测模型，应同时报告训练/预测时间与响应窗口是否匹配。
  - Benchmark 可以按“保持静态难度可控、逐层增加动态结构”的方式设计，而不是只追求更复杂。
  - 不规则动态源应保存为确定性序列或明确的外部数据流，避免固定 RNG 造成跨平台不可复现。
- 局部创新线索：
  - 把 pi 位数扰动替换为真实业务事件流、天气/需求/网络流时间序列，形成半真实动态 benchmark。
  - 为 DMOA 设计 response-time normalized indicators，例如单位响应时间内的 MIGD 改善。
  - 将 time-linkage `phi(t)` 从膝点误差扩展到 IGD、HV、决策切换成本或约束违背传播。
- 结构创新线索：
  - 构建动态 benchmark factory：

```text
base DMOP with known PS/PF
-> choose hypersurface PS dynamics
-> choose R matrix family: identity / diagonal imbalance / PSD interaction
-> choose time schedule: regular / deterministic irregular / real event stream
-> choose time-linkage phi(t)
-> generate grouped test suite + reference PF/PS + runtime-aware report
```
