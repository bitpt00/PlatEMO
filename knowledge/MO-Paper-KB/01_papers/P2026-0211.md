# Knowledge Guidance and Twin SVM Classifier Based Dynamic Multiobjective Optimization Control for Wastewater Treatment Process

## 一句话理解

论文面向污水处理过程的动态节能-水质折中控制，构建“ISVR 在线目标建模 + KGSA/TSVM 动态多目标优化初始种群筛选 + knee point 设定值选择 + 事件触发增量 PID 跟踪”的闭环，其中最可复用的优化机制是：环境变化后先把上一环境种群用子空间对齐映射到当前候选分布，再用 TSVM 分类器筛选高质量候选作为新环境初始种群。

## 问题与动机

- 研究问题和场景：
  - Wastewater treatment process (WWTP) 需要同时降低 energy consumption (EC) 并保证 effluent quality (EQ) 达标；
  - influent flow、污染物浓度和天气条件动态变化，使目标函数和最优控制变量设定值随时间改变；
  - 控制变量为好氧池 dissolved oxygen `SO` 的设定值和厌氧池 nitrate nitrogen `SNO` 的设定值；
  - 实际控制输入分别为氧转移系数 `KLa` 和内回流流量 `Qa`。
- 现有算法为什么不足：
  - 单变量优化控制只调 `SO`，难以兼顾 EC 与 EQ；
  - 静态 MOO 控制方法忽略 WWTP 动态特性，环境变化后优化性能不稳定；
  - 已有 WWTP DMOA 会利用历史演化知识，但忽略不同 operating conditions 之间的分布差异，可能产生负迁移；
  - 随机生成或变异新环境初始种群缺少筛选，收敛质量差；
  - Kalman filter 等线性相关假设难以刻画历史种群与当前候选之间的非线性关系。
- 本文希望解决什么：
  - 用 ISVR 在线更新 EC/EQ 模型，让目标函数随新样本适应；
  - 在环境变化时，通过 KGSA 减小 source population 与 target candidates 的分布差异；
  - 用 TSVM 分类器筛出当前环境下更可能高质量的候选，构造初始种群；
  - 用 knee point 在动态 Pareto set 中选择控制设定值；
  - 用事件触发增量 PID 降低不必要控制动作并跟踪时变设定值。

## 核心理念与算法流程

- 核心理念：
  - 动态优化控制中，环境变化后的初始种群质量直接影响响应速度；
  - 上一环境最终种群包含有价值的历史搜索知识，但其分布与当前环境候选不一致；
  - 先做子空间对齐，把历史种群映射到当前候选空间，再把历史非支配/支配标签作为监督信号训练分类器；
  - 分类器不直接输出最终解，只作为 candidate gate，从当前环境 oversampling 得到的候选集中筛出高质量个体，再交给 NSGA-II 精修。
- ISVR 在线目标建模：
  - 用 support vector regression 描述 EC 和 EQ 关于控制设定值的非线性关系；
  - 当新样本到达时，用增量更新规则调整 SVR 参数；
  - 优化问题为同时最小化 `f_EC(x(t))` 和 `f_EQ(x(t))`；
  - 决策变量为 `x(t)=[x1(t), x2(t)]^T`，分别表示 `SO` 和 `SNO` 设定值；
  - 约束包括设定值上下界以及五类 EQ 指标上下界：`SNH`、`SNtot`、`BOD`、`COD`、`SS`。
- KGTSVMC-DMOA 主流程：
  1. 初始环境中随机生成 `POP0`，用 NSGA-II 得到 `POS0`；
  2. 每代随机选取 10% 个体检测环境是否变化；
  3. 检测到新环境 `t1` 后，把上一环境最终 population 记为 source set `U=POP_{t1-1}`；
  4. 用 oversampling 在当前环境生成 `N1` 个候选解，记为 target set `V`；
  5. 运行 KGSA，把 `U` 映射到 `V` 的目标分布，生成训练集 `T={(u'_j,kappa_j)}`；
  6. 对上一环境中属于 `POS` 的个体打 `+1` 标签，否则打 `-1` 标签；
  7. 用训练集 `T` 训练 TSVM 分类器；
  8. 用分类器标记 `V` 中候选，保留 `+1` 个体直到达到种群规模 `n`；
  9. 以该初始种群运行 NSGA-II，得到当前环境 `POS_{t1}`；
  10. 环境未变时继续用 NSGA-II 优化当前种群。
- KGSA 关键流程：
  - 对 source set `U` 与 target set `V` 分别计算协方差矩阵；
  - 用 PCA 提取前 `h` 个主特征向量，得到子空间 `U1` 和 `V1`；
  - 最小化 Bregman matrix divergence / Frobenius norm，求源到目标的映射矩阵 `M*`；
  - 构造新坐标系 `U1*`，并把每个历史个体 `u_j` 转为目标空间中的 `u'_j`；
  - 对 `u'_j` 附加来自上一环境 `POS` 的好/坏标签，作为 TSVM 训练数据；
  - 作用是让训练集和当前候选具有相近分布，减少负迁移。
- TSVM 候选筛选：
  - TSVM 构造两个非平行超平面，分别接近正类和负类样本；
  - 当前候选 `v_r` 按到两个超平面的归一化距离分类；
  - 被标为 `+1` 的候选进入新环境初始种群；
  - 相比传统 SVM，TSVM 需要求解两个较小优化问题，复杂度约为传统 SVM 的一半。
- 设定值选择与控制：
  - 从当前环境 Pareto-optimal set 中选择 knee point，即最大 marginal rates of return 的折中解；
  - knee point 得到 `SO` 与 `SNO` 的最优设定值；
  - 事件触发增量 PID 根据触发条件决定是否更新 `KLa` 和 `Qa`；
  - 触发次数少会降低控制动作与能耗，但可能扩大 EQ，形成能耗-水质跟踪权衡。
- 可能被修改的位置：
  - source set 可用上一环境末代种群、外部档案或多历史窗口；
  - target set 可由 oversampling、预测模型、随机移民或领域可行采样生成；
  - KGSA 可换为 CORAL、GFK、TCA、流形对齐、最优传输或特征无关匹配；
  - TSVM 可换为 SVM、随机森林、pairwise classifier、ranker 或带不确定性的分类器；
  - `+1/-1` 标签可由非支配、top-rank、indicator contribution、可行性或 knee-region 偏好定义；
  - knee point 选择可换成交互式偏好、TOPSIS、鲁棒偏好或安全优先规则；
  - 控制器可换为 MPC、自适应控制或 fault-tolerant control。
- 必须保留的核心：
  - 新环境候选必须来自当前环境，而不是只复制历史个体；
  - 历史标签进入分类器前需要处理 source/target 分布差异；
  - 分类器只做候选准入，后续仍需 DMOA/MOEA 搜索和环境评价；
  - 若分类器筛选出的 `+1` 个体不足，需要定义补齐策略和可靠性检查。

## 实验证据

- 实验平台和参数：
  - 使用 Benchmark Simulation Model No.1 (BSM1)；
  - influent sampling cycle 为 15 min，`SO/SNO` 优化周期为 2 h，控制器采样周期为 45 s；
  - 对比方法包括 KTM-DMOA+PID、DIP-DMOA+PID、KL-DMOA+PID、RSL-MOPSO+PID、MNSGAII-DMOA+PID；
  - 每种方法独立运行 20 次，Windows 10 + MATLAB 2022a；
  - 主要参数：`epsilon=0.1`，`C=1e-3`，population size `n=200`，candidate size `N1=1000`，NSGA-II generations `100`，`c1=10`，`c2=1`；
  - 事件触发参数：`sigma=0.85`，`phi=psi1=0.5`，`eta=2`，`etaI=etaP=etaD=0.3`。
- ISVR 建模证据：
  - Fig. 4 显示 ISVR 和 SVR 都能拟合 EC/EQ；
  - ISVR 的 EC 误差约在 `[-0.01, 0.02]`，EQ 误差约在 `[-0.2, 0.4]`；
  - SVR 的 EC 误差约在 `[-0.07, 0.05]`，EQ 误差约在 `[-0.6, 0.4]`；
  - 作者据此认为 ISVR 更适应复杂动态工况。
- WWTP 控制结果：
  - Table I 中 KGTSVMC-DMOC 在 dry/rain/storm 三种天气下均取得最低 EC 和最低 EQ；
  - Dry：KGTSVMC-DMOC 为 `EC=3782.94`、`EQ=6409.12`，优于 RSL-MOPSO+PID 的 `3803.21/6417.12` 和 DIP-DMOA+PID 的 `3814.34/6434.61`；
  - Rain：KGTSVMC-DMOC 为 `3799.12/8672.21`，优于 DIP-DMOA+PID 的 `3815.11/8707.12`；
  - Storm：KGTSVMC-DMOC 为 `3822.36/7582.39`，优于 KL-DMOA+PID 的 `3844.11/7594.18` 和 RSL-MOPSO+PID 的 `3846.44/7590.36`；
  - weighted sum 和 TOPSIS 版本在三种天气下均明显差于 knee point 版本，例如 dry 下 WS/TOPSIS 为 `3863.15/6683.26` 和 `3872.54/6783.34`。
- 统计显著性：
  - Table II 的 Wilcoxon signed rank test 显示 KGTSVMC-DMOC 相对五个对比方法在三种天气下均 `pW < 0.05`；
  - 典型 `pW`：dry vs DIP 为 `0.0004`，rain vs MNSGAII 为 `0`，storm vs DIP 为 `0`。
- TSVM/KGSA 消融：
  - Table III 比较 KGTSVMC-DMOC、去掉 KGSA 的 TSVMC-DMOC、以及把 TSVM 换为传统 SVM 的 KGSVMC-DMOC；
  - 去掉 KGSA 后速度略快，但解质量明显退化，例如 storm 下 TSVMC-DMOC 为 `3947.58/8546.21`；
  - KGSVMC-DMOC 的 EC/EQ 与 KGTSVMC-DMOC 接近，但运行时间约为 3 倍；
  - dry 下 KGTSVMC-DMOC 时间 `358.07 s`，KGSVMC-DMOC 为 `1098.47 s`；
  - rain 下 `355.75 s` 对 `1136.72 s`，storm 下 `363.41 s` 对 `1103.25 s`；
  - 该结果支持“KGSA 保证筛选质量，TSVM 降低分类成本”的分工。
- 参数敏感性：
  - Table IV 显示过小 `C` 导致欠拟合，过大 `C` 增加过拟合风险，默认 `C=1e-3` 整体最好；
  - 正则参数 `c1=10,c2=1` 在 dry/storm 中最优或接近最优，作者据此采用该配置；
  - Table V 显示事件触发次数少通常对应更低 EC 和更高 EQ，说明减少控制动作会节能但牺牲水质跟踪。
- 实际 WWTP 验证：
  - 在北京某日处理量 16,000 m3 的实际污水厂部署；
  - 实验期为 2023-08-11 至 2023-08-25，其中 2023-08-20 至 2023-08-21 有降雨事件；
  - effluent standards 包括 `SNH<=4 mg/L`、`SNtot<=18 mg/L`、`BOD<=30 mg/L`、`COD<=100 mg/L`、`SS<=10 mg/L`；
  - Fig. 6 显示实际场景中 `SO` 误差约在 `[-0.2,0.4]`，`SNO` 误差约在 `[-0.6,0.8]`。
- Benchmark DMOP 证据：
  - 在 CEC 2018 DF1-DF14 上比较 KGTSVMC-DMOA、KTM-DMOA、DIP-DMOA、KL-DMOA、MNSGAII-DMOA；
  - 指标为 MIGD 和 MHV；
  - 作者总结 KGTSVMC-DMOA 在 28 个指标案例中有 19 个获得更低 MIGD 或更高 MHV；
  - Table VI 中 KGTSVMC-DMOA 在 DF1、DF3-DF6、DF9、DF11-DF13 的 MIGD 上表现突出，在多数 DF 的 MHV 上也最高；
  - 作者承认其在 DF2、DF7、DF8、DF10、DF14 上表现不佳，原因包括 position-related variable 切换不可预测、POF 凸凹切换、三目标不规则变化；
  - Fig. 7 显示 DF1-DF6 上平均 IGD 曲线较低且波动较小。
- 证据边界：
  - 关键表格为 PDF 图片，已目视核验 PDF 第 7-10 页；
  - KGSA 与 TSVM 同时出现，缺少只保留 KGSA/换其他分类器的更多组合消融；
  - 真实 WWTP 部署结果主要给跟踪曲线，没有完整报告与对照控制器的长期经济/排放统计；
  - BSM1 和 DF benchmark 的目标/约束形式与真实工厂仍有差距。

## 局限与未来工作

- 作者明确说明的局限：
  - KGTSVMC-DMOC 未纳入突发 operational disruptions，例如 sensor failures 或 actuator fault；
  - 在 DF2、DF7、DF8、DF10、DF14 等动态 benchmark 上表现不稳定。
- 作者未来工作：
  - 引入 sensor failures processing model；
  - 研究 adaptive fault-tolerant control，增强异常工况下的控制能力。
- 我们认为仍需确认的问题：
  - 环境变化检测只随机选取 10% 个体，检测灵敏度和误报/漏报没有展开；
  - TSVM 筛出的 `+1` 候选不足时如何补齐初始种群，正文未充分说明；
  - POS-based 标签可能在高维目标或大量互不支配时失去区分力；
  - KGSA 依赖 PCA 子空间，若 source/target 分布非线性错位或多模态，线性对齐可能不足；
  - `h` 子空间维度、oversampling 规模 `N1` 和分类阈值敏感性仍需评估；
  - knee point 对偏好不显式，但不一定符合实际排放风险或电价策略；
  - 实际工厂只覆盖约两周和一次降雨，长期季节变化仍需验证。

- 暂留在论文卡中的方法、原理或架构启发：
  - ISVR 在线 EC/EQ 建模属于 WWTP 控制建模细节，暂不单独建卡；
  - 事件触发增量 PID 是控制层实现，暂留在论文卡；
  - knee point 选设定值已有较通用 MCDM 背景，本文没有足够新机制，暂不建卡；

- 局部创新线索：
  - 将 POS 标签替换为 `I_SDE+`、HV contribution、可行裕度或 knee-region 标签，改善分类器监督信号；
  - 增加分类器可靠性检测，如 AUC、校准误差或留出验证，低可靠时退回随机/预测混合初始化；
  - 用多历史环境训练 domain-invariant classifier，而不只依赖上一环境；
  - 用最优传输或多模态子空间对齐替代线性 PCA 对齐；
  - 将 TSVM 输出距离作为候选权重，而不是硬 `+1/-1` 门控。
- 结构创新线索：
  - 构建 DMOP 变化响应层：candidate generator、domain alignment、quality classifier、MOEA refinement、controller/MCDM selector 分离；
  - 与变化严重度策略池结合：轻微变化时多用对齐分类器，剧烈变化时增加随机移民或探索型预测；
  - 与约束动态优化结合：分类器同时预测高质量和低 CV，避免新环境初始种群不可行；
  - 工业控制中把目标 surrogate 的不确定性输入分类器，让候选筛选同时考虑模型误差。
