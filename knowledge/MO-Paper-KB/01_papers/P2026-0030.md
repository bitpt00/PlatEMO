# Multi-objective genetic algorithm with maximum-entropy classification and domain-specific evolutionary operators for microorganism selection on microbiomes

## 一句话理解

论文提出 MADMISM，用 NSGA-III 解决微生物组中的 OTU 子集选择问题：一边最大化 AUC，一边最大化丢弃 OTU 的比例。核心不是单纯把特征选择套上 MOEA，而是先用 chi-square 预筛和排序获得 OTU 先验，再把这个统计排名贯穿初始化、交叉和变异算子，使搜索优先组合高相关微生物，同时保留随机变异维持探索。

## 问题与动机

- 研究问题和场景：
  - 微生物组数据可用于发现疾病、族群、饮食或环境状态的 microbial markers；
  - 原始数据包含大量 OTUs，样本数相对有限，且微生物组数据具有 compositional 特性，需要 centered log-ratio 等变换；
  - 需要找到少量可管理、可解释、具有诊断或环境指示意义的 OTU，同时保持高分类性能。
- 现有算法为什么不足：
  - BiGAMi 同时考虑 AUC 和 OTU 数量，但用加权和单目标 fitness，不保留真实 Pareto trade-off；
  - GARS、SFS、SelectKBest 等方法不是面向微生物组多目标场景设计，或者只输出固定规模/单指标结果；
  - 普通随机初始化、交叉和变异在高维 OTU 空间中会浪费大量预算在低相关微生物组合上；
  - 只做 filter 选择会忽略 OTU 组合对分类器 AUC 的 wrapper 效果。
- 本文希望解决什么：
  - 用真正的双目标 Pareto 搜索同时优化 AUC 和 OTU 子集大小；
  - 用 chi-square 统计相关性作为轻量领域先验，指导所有主要遗传算子；
  - 用最大熵 SGD classifier 统一评价 AUC，使对比方法在相同分类器条件下比较；
  - 证明选出的 OTU 子集不仅数值表现好，也有生物学解释。

## 核心理念与算法流程

- 核心理念：
  - 先用廉价统计检验给每个候选 OTU 一个先验排名，再让 MOEA wrapper 搜索负责组合、取舍和 Pareto 选择；
  - 领域先验不直接决定最终特征集，而是作为初始化、交叉和变异的采样偏置。
- 问题建模：
  - 输入：`M` 个样本、`N` 个候选 OTU；
  - 解：一个选中 OTU 的变长数组，最多包含 `maxOTUs` 个 OTU；
  - 目标 1：最大化 `DiscardedOTUs = (N - nOTUs) / N`；
  - 目标 2：最大化 AUC；
  - 最终输出：一组非支配 OTU 子集；代表解用归一化双目标到 ideal point 的最小欧氏距离选择。
- MADMISM 主流程：
  1. 对 microbiome 数据做 chi-square preselection，保留 chi-square 分数高于平均值的 OTU，并生成排名；
  2. 用领域初始化产生初始种群：前 `maxOTUs` 个个体分别取前 1、2、...、`maxOTUs` 个最高排名 OTU，其余个体从 top `maxOTUs` 中随机取不同数量的 OTU；
  3. 每代用 binary tournament 选父代；
  4. 领域交叉把两个父代 OTU 合并成 pool，按 chi-square 排名排序，随机选 `k` 介于两个父代 OTU 数之间，子代取排名最高的 `k` 个；
  5. 变异在 addition、removal、replacement 三种操作中选择；领域变异的新增/替换 OTU 从高排名可用 OTU 中采样，随机变异从全部可用 OTU 中采样；
  6. 用 SGD maximum-entropy classifier 评估子代 AUC，并计算 OTU 数量目标；
  7. 合并父代和子代后，执行 NSGA-III 的非支配排序、参考点关联和 niching 选择；
  8. 达到最大代数后返回最终 Pareto front。
- 关键组成部分：
  - centered log-ratio microbiome preprocessing；
  - chi-square preselection/ranking；
  - greedy + diversity two-stage initialization；
  - rank-biased union crossover；
  - rank-biased add/remove/replace mutation + random mutation；
  - NSGA-III reference points from Das-Dennis；
  - maximum-entropy SGD AUC evaluator。
- 可能被修改的位置：
  - 将 chi-square 替换为 mutual information、ANOVA、LASSO stability、SHAP/feature attribution、domain pathway score；
  - 将 fixed 0.25/0.75 的领域/随机变异概率改成按收敛停滞或前沿多样性自适应；
  - 将子集编码从变长 OTU 列表换成二进制 mask、grouped OTU blocks 或 taxonomy-aware hierarchical encoding；
  - 将 ideal-distance representative selector 替换为临床成本约束、Nash bargaining、TOPSIS 或用户偏好点。
- 必须保留的核心：
  - 廉价统计排名只能引导采样，最终仍需 wrapper AUC 和 Pareto 环境选择校正；
  - 领域变异和随机变异要共存，否则 greedy ranking 容易早熟或漏掉组合效应；
  - 微生物组 compositional preprocessing 不能省略，否则 OTU 相关性和分类效果可能有系统偏差。

## 实验证据

- 测试问题和对比算法：
  - 8 个真实 microbiome 数据集：CRC-GG、CRC-RS、LH-GG、LH-RS、BW-GG、BW-RS、CH-RS、YB-GG；
  - OTU 数从 501 到 8483，样本数从 75 到 342；
  - 场景覆盖结直肠癌、细菌性阴道病 Nugent score、族群差异、肝硬化和 Atacama 沙漠土壤环境；
  - 对比方法包括 BiGAMi、GARS、SFS、SelectKBest 和全特征 SGD baseline；
  - 多目标算法比较包括 MOEA/D、SMS-EMOA、NSGA-II、NSGA-III；
  - 所有方法限制为 2500 evaluations，并使用相同 maximum-entropy SGD classifier 和 6-fold cross-validation。
- 参数与实现：
  - BiGAMi 按原论文配置，population 250、10 generations；
  - MADMISM 最终配置为 population 20、125 generations，总计 2500 evaluations；
  - 领域变异概率 0.25，随机变异概率 0.75；作者认为领域变异偏 greedy，需随机变异平衡探索；
  - Das-Dennis 参考点中 `M=2`、`p=19`，得到 20 个 reference points，匹配种群规模；
  - 25 次独立运行，结果用 median ± quartile deviation；
  - 统计检验先用 Kolmogorov-Smirnov 和 Levene 判断，再用 ANOVA 或 Mann-Whitney U，显著性 0.05；
  - Python 3.10.12、pymoo、Scikit-learn，硬件为 Intel i7-8700 3.20GHz、32GB RAM、Windows 10 Pro。
- 主要实验结论：
  - MADMISM 在 8 个数据集上同时取得最优 AUC 和最少 OTU 的代表解；
  - 相对全特征 SGD baseline，OTU 数平均减少 99.38%；
  - 相对 state-of-the-art 平均 OTU 数，MADMISM 平均减少 46.35%；
  - 相对 state-of-the-art 平均 AUC，MADMISM 平均提升 12.05%；
  - 在 80 个与 state-of-the-art 的统计比较中，MADMISM 有 76 个显著改进；
  - BW-RS 上改进最突出，OTU 数相对 state-of-the-art 减少 58.33%，AUC 提升 18.92%；
  - 不同参考数据库 GreenGenes/RefSeq 会带来结果差异，说明 microbiome pipeline 会影响最终 marker。
- 多目标性能证据：
  - MADMISM 在所有 8 个数据集上 hypervolume 均优于 MOEA/D、SMS-EMOA、NSGA-II、NSGA-III；
  - 平均 hypervolume 为 90.06%，最高相对提升可达 160%；
  - 5 个数据集 HV 超过 90%；
  - 表 6 中除 BW-GG 对 NSGA-II (`p=0.107`) 和 NSGA-III (`p=0.066`) 外，其余 HV 比较均达到显著，作者总结显著比例为 93.75%。
- 时间与扩展性：
  - MADMISM 平均时间 56.19 秒，接近 GARS 50.43 秒和 BiGAMi 52.13 秒，明显低于 SFS 141.97 秒；
  - 所有数据集运行时间均低于 1 分钟；
  - 最大 OTU 数据集 CH-RS 有 8483 个 OTU，MADMISM 时间为 54.88 秒；作者据此认为时间对 OTU 数和样本数不敏感。
- 生物分析：
  - 每个数据集至少有一个 OTU 在 25 次代表解中稳定出现，说明随机搜索下仍有稳定 microbial markers；
  - CRC 中识别到 Coprococcus、Bacteroides、Alistipes、Rikenellaceae、Methylobacterium jeotgali、Neglectibacter timonensis、Citrobacter koseri 等与 CRC 或炎症/肿瘤相关的 taxa；
  - LH/BV 数据集中识别到 Lactobacillus、Gardnerella vaginalis、Prevotella 等与阴道健康或 BV 相关 taxa；
  - BW 数据集中出现 Limosilactobacillus、Anaerococcus、Coriobacteriaceae、Corynebacterium 等族群差异相关 taxa；
  - CH 中 Blautia 和 Megasphaera micronuciformis 被讨论为肝硬化 dysbiosis marker；
  - YB 土壤数据中 Paenibacillus 与 Arenimicrobium luteum 与干旱环境和生态功能相关。
- 证据边界：
  - 表 2/3/5 在 Markdown 中为图片占位，论文卡未重录逐数据集 AUC/OTU/HV 数值；
  - 与单解方法比较时，需要从 MADMISM Pareto front 选 representative solution；不同选解规则可能改变应用结论；
  - 本文主要验证 8 个二分类 microbiome 数据集，尚未覆盖多分类、多队列外部验证或临床前瞻性验证；
  - 生物相关性多基于既有文献解释，不能替代湿实验或独立队列因果验证。

## 局限与未来工作

- 作者明确说明的局限/未来方向：
  - 不同 reference databases 和 compositional transformations 会影响最终 microbial markers；
  - 需要系统评估预处理流程对结果的影响，形成临床可复现的标准化协议；
  - 临床 pipeline 中应探索完整 Pareto front，而不只取单个 representative solution，让用户按具体诊断成本和 marker 数量需求选解。
- 我们认为仍需确认的问题：
  - chi-square 是单变量统计，可能漏掉强组合效应或非线性交互 OTU；
  - chi-square above-average 的预筛阈值是否在稀疏/高噪声数据上稳定；
  - `maxOTUs` 由 BiGAMi 中位解决定，可能把搜索空间绑定到一个基线方法；
  - 25 次内部交叉验证不能说明跨医院、跨测序平台和批次效应下的泛化；
  - 领域变异概率固定为 0.25，尚未随前沿停滞、rank 可信度或生物先验不确定性自适应。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：[统计排名引导的子集演化算子](../02_design_knowledge/K-statistical-rank-guided-subset-evolution-operators.md)。它抽象出“廉价 filter ranking 贯穿初始化、交叉、变异，但最终由 wrapper Pareto 评价校正”的子集型 MOO 设计。
- 与已有设计知识的边界：
  - 不同于 [滤波性能预测的特征子集预筛选](../02_design_knowledge/K-filter-performance-predictor-feature-subset-preselection.md)，本文不是在评价前筛掉候选子集，而是用统计排名直接生成和修改候选；
  - 不同于 [交互感知岛模型的多目标生物标志物选择](../02_design_knowledge/K-interaction-aware-island-biomarker-selection.md)，本文没有变量交互分组和 island migration，而是轻量地改造 NSGA-III 算子；
  - 不同于 [总体-少数类双任务特征选择迁移](../02_design_knowledge/K-overall-minority-dualtask-feature-selection-transfer.md)，本文不构造辅助任务或类别不平衡迁移，而是处理 microbiome OTU 子集的统计先验采样。
- 局部创新线索：
  - 将 chi-square ranking 改成多指标 rank ensemble，例如 chi-square、mutual information、CLR-aware correlation、stability selection；
  - 对领域变异概率做 feedback adaptation：当前 HV 停滞时提高随机变异，AUC 下降时提高 rank-guided 变异；
  - 在 crossover 中保留父代共同 OTU 后，再按排名补足 top-k，强化稳定 marker；
  - 引入 taxonomy hierarchy，让同属/同科 OTU 的替换优先在相邻生物层级内发生。
- 结构创新线索：
  - 子集型 MOO 可形成通用架构：cheap variable ranking -> rank-aware operators -> wrapper Pareto evaluation -> preference/ideal-point selection；
  - 临床特征选择中，可把专家 marker、实验成本、检测平台可用性作为额外 ranking prior 注入算子；
  - 对完整 Pareto front 做 downstream decision support，让医生在 AUC 损失、检测成本和 marker 可解释性之间选解。
