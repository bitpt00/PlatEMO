# Multi-objective bilevel programming model for optimizing network interdiction deployment

## 一句话理解

本文提出 MOBNIP 与 iNSSSO：把网络阻断建成 defender-attacker 多目标双层模型，上层防御者选择要阻断的边以降低成本、拉长攻击者路径并降低路径可靠性；下层攻击者用 Bi-Objective A* 在阻断后的网络上寻找长度-可靠性折中路径。算法用上层 NSSSO 搜索布防方案、下层 BOA 返回攻击者路径响应，并用动态可靠性阈值和 min-cut 局部搜索强化网络结构导向。

## 问题与动机

- 研究对象：multi-objective bilevel network interdiction problem (MOBNIP)。
- 场景：道路网络中的地面兵力阻断部署，可推广理解为 defender-attacker network interdiction。
- 现有网络阻断研究常见不足：
  - 许多模型只在上层做多目标，低层攻击者响应被简化为单目标；
  - 真实攻击者通常同时关注路径长度和可靠性；
  - 普通 MOEA 不理解网络的割边、瓶颈和攻击者路径结构；
  - 完整求解下层多目标反应集昂贵，直接嵌套双层 MOEA 计算成本高。
- 本文目标：
  - 同时建模上层防御者三目标和下层攻击者双目标；
  - 用可计算的下层路径响应近似评价每个防御方案；
  - 在上层搜索中嵌入网络阻断结构知识。

## MOBNIP 模型

- 网络：
  - undirected graph `G(N,E)`；
  - 每条边有 nominal distance `de`、nominal reliability `re`、interdiction cost `ce`；
  - 防御者阻断边 `e` 后，距离增加为 `delta_e = de(1 + lambda_e x_e)`；
  - 可靠性降低为 `rho_e`，并用 `-ln(rho_e)` 转换为可加路径可靠性目标。
- 上层 defender 决策：
  - 二进制向量 `x`，`x_e=1` 表示阻断边 `e`；
  - 目标 1：最小化总阻断资源 `C`；
  - 目标 2：最大化攻击者 shortest path length；
  - 目标 3：最小化攻击者 most reliable path reliability，等价于最大化其负对数可靠性；
  - 约束：总兵力不超过 `TC`，攻击者路径可靠性不超过阈值 `TR`。
- 下层 attacker 决策：
  - 二进制路径向量 `y`；
  - 目标 1：最小化阻断后路径距离；
  - 目标 2：最小化累计负对数可靠性，即最大化路径原始可靠性；
  - 约束：从 source `s` 到 target `t` 的流守恒路径约束。
- 下层响应选择：
  - 对每个上层 `x`，BOA 生成攻击者 non-dominated paths；
  - 先在无阻断网络中预计算 ideal point `(Dideal, Rideal)`；
  - 从当前 BOA reaction set 中选择距离 ideal point 最近的路径作为代表响应；
  - 该路径被视为攻击者最有利、对防御者最不利的响应近似。

## 核心算法 iNSSSO + BOA

- 上层编码：
  - 每个 candidate 是长度为 `Ne` 的二进制阻断向量；
  - `1` 表示阻断该边，`0` 表示不阻断。
- Initialization：
  - Cost-Constrained Initialization (CCI) 从全零向量开始；
  - 随机排列边；
  - 只要新增边成本不超过 `TC` 就置为 1；
  - 生成满足成本约束且有多样性的初始种群。
- Evaluation：
  - 对每个上层解调用 BOA 求下层非支配路径；
  - 用 ideal-point 最近路径计算上层三个目标；
  - 若路径可靠性超过阈值，使用 `max(0, R-TR) * 1000` 罚项；
  - 罚项均匀加到三个目标上，避免只惩罚单一目标导致排序偏置。
- Population sorting：
  - 使用 non-dominated sorting；
  - 同一 front 内使用 crowding distance 维护多样性。
- Reproduction：
  - 使用 NSSSO update mechanism；
  - 每个新解的基因可来自当前 non-dominated leader、原父代或随机扰动；
  - `Cg=0.6` 控制向 leader 学习概率，`Cw=0.9` 控制保留原值概率。
- Repair：
  - Cost-Constrained Repair (CCR) 对超出 `TC` 的解随机关闭已阻断边，直到满足成本约束。

```text
upper binary interdiction vector
-> BOA lower-level path response
-> ideal-point representative attacker path
-> penalized tri-objective defender fitness
-> nondominated sorting + crowding
-> NSSSO update or min-cut search
-> cost repair + dynamic reliability threshold
```

## Min-Cut Search

- MCS 是面向网络阻断结构的局部搜索。
- 输入：
  - 当前上层解 `X`；
  - BOA 返回的攻击者 non-dominated path set `Pi`；
  - cost vector、`TC`、source、target 和节点集。
- 过程：
  - 取所有攻击者路径中出现过的边，形成 `E_Pi`；
  - 给这些边随机分配 `[1,10]` 的 flow capacity；
  - 构造流网络 `G_Pi`；
  - 通过 max-flow / min-cut 找到 source 到 target 的 minimum cut；
  - 将 cut edges 置为 interdicted；
  - 若成本超出 `TC`，对非 cut 的已阻断边按 `edgeCount(Pi,e)/ce` 排序，先移除 cost-effectiveness 低的边，直到恢复可行。
- 作用：
  - 直接攻击当前下层 reaction paths 中的网络瓶颈；
  - 把 BOA 发现的路径集合转化为上层局部修复信号；
  - 相比普通随机变异，更能覆盖离散、不规则的 MOBNIP Pareto front。

## Dynamic Reliability Thresholding

- DRT 用于动态调整路径可靠性约束。
- 动机：
  - 若早期就使用严格 `TR`，搜索空间过窄，难发现可行且有潜力的阻断区域；
  - 早期放松可靠性阈值可增强探索；
  - 后期逐渐收紧约束，推动 exploitation 和可行性。
- 机制：
  - 初始 dynamic reliability threshold `dR[0]` 比固定 `TR` 更宽松；
  - 每代按距离 `TR` 的差值逐步收紧；
  - 罚项从 `max(0, R-TR)` 改为 `max(0, R-dR[t])`；
  - 阈值更新后，需要重新评价当前 population，使父代和子代在同一阈值下排序。

## 实验设置

- 实例：
  - 基于台湾关键城市和交通路线构造；
  - 四种网络规模：`Nv=50,75,100,125`；
  - 对应边数：`77,127,178,227`；
  - source 为最南端节点，target 为 Taipei；
  - 九个可靠性阈值 `TR=0.4,0.45,...,0.8`；
  - 共 36 个实例。
- 参数：
  - `TC = 5 x Ne`；
  - `ce` 在 `[20,40]`；
  - `re` 在 `[0.98,1]`；
  - `lambda_e` 在 `[0.3,0.6]`；
  - `mu_e` 在 `[0.1,0.4]`；
  - population size `Nsol=100`；
  - runtime limit `2 x Nv`；
  - MATLAB R2023b，Windows 10，Intel Core i7 3.2 GHz，32 GB RAM。
- 对比算法：
  - MOPSDA；
  - NSGA-II；
  - SPEA2；
  - NSGA-III；
  - MOEA/D；
  - NSSSO。
- 公平性：
  - 所有上层算法都耦合相同 BOA 下层路径优化；
  - 对比算法也加入 CCI 和 CCR，以生成可行初始解并处理成本约束。
- 指标：
  - Coverage `Cov`；
  - IGD；
  - Spread `Spr`；
  - number of non-dominated solutions `Nnds`。

## 消融与参数

- EX-1 测试 DRT 与 MCS：
  - `Ndrt` 两级：关闭或开启；
  - `Nmcs` 四级：`0,0.1,0.4,0.7`；
  - 网络规模 75 和 100；
  - `TR=0.4,0.6,0.8`；
  - 每个 treatment 每个数据集运行 10 次。
- ANOVA 结论：
  - `Ndrt` 和 `Nmcs` 对 `Cov`、`IGD`、`Nnds` 均显著；
  - 交互项对 `IGD` 和 `Nnds` 显著；
  - 开启 DRT 一致改善三个指标；
  - `Nmcs=0.1` 在 `Cov` 和 `IGD` 上最稳健；
  - `Nmcs=0` 明显较弱，说明 MCS 对多样性和 PF coverage 关键；
  - 过高 `Nmcs` 会过度专注 min-cut 局部修复，导致过专门化。
- 后续主实验配置：
  - `Ndrt=1`；
  - `Nmcs=0.1`；
  - `Cg=0.6`；
  - `Cw=0.9`。

## 主要结果

- `Nv=50`：
  - iNSSSO 平均 `Cov=0.45`，最佳；
  - 平均 `IGD=2.60`，最佳；
  - 平均 `Spr=0.45`，与 NSGA-II 并列最佳；
  - 平均 `Nnds=99.93`，接近 100。
- `Nv=75`：
  - iNSSSO 平均 `Cov=0.48`，最佳；
  - 平均 `IGD=3.62`，最佳；
  - 平均 `Spr=0.43`，最佳；
  - 平均 `Nnds=99.99`，最佳。
- `Nv=100`：
  - iNSSSO 平均 `Cov=0.47`，最佳；
  - 平均 `IGD=7.22`，最佳；
  - 平均 `Spr=0.43`，最佳；
  - 平均 `Nnds=99.99`，最佳。
- `Nv=125`：
  - iNSSSO 平均 `Cov=0.57`，最佳；
  - 平均 `IGD=17.42`，最佳；
  - 平均 `Spr=0.47`，最佳；
  - 平均 `Nnds=99.94`，最佳。
- 统计检验：
  - Friedman ranks：
    - `Cov`: iNSSSO `1.0556`；
    - `IGD`: iNSSSO `1.0556`；
    - `Spr`: iNSSSO `1.0972`；
  - 三个 Friedman tests 的 p-values 均 `<0.001`；
  - Holm pairwise tests 显示 iNSSSO 相对其他算法均显著更优。
- 机制解释：
  - MOBNIP 的 PF 离散、不规则、非凸；
  - NSGA-III 和 MOEA/D 的参考点/权重向量假设不匹配；
  - MOPSDA 主要依赖 Monte Carlo sampling 与当前非支配解概率分布，收敛弱；
  - iNSSSO 的 MCS 和 DRT 针对网络结构与可靠性约束，能更稳定覆盖碎片化前沿。

## 实践分析

- 代表实例：`(Nv, TR) = (125, 0.4)`。
- 选取三类上层解：
  - minimum-cost；
  - mid-cost；
  - maximum-cost。
- 每类上层解对应三类下层路径：
  - shortest path；
  - most reliable path；
  - closest-to-ideal path。
- 观察：
  - 随阻断边数量增加，阻断策略越来越集中攻击 shortest、most reliable 和 ideal path 上的关键边；
  - 攻击者被迫绕行更远或更不可靠路径；
  - 15 次运行得到 309 个非支配解，用 edge interdiction frequency heatmap 标识高频阻断边。
- 关键边类型：
  - attacker 起点和终点附近的 access roads；
  - 少量道路维持连通性的 bottleneck areas。

## 与知识库相关的设计知识

- 新增设计知识：
  - `K-attacker-path-response-nested-network-interdiction`：攻击者路径响应嵌套的多目标网络阻断搜索。
- 与已有设计知识的区别：
  - 不同于 `K-rl-lower-level-search-mode-scheduling`：该知识学习下层搜索强度；本文用固定 BOA 求下层路径响应，并把路径集合反馈给网络局部搜索。
  - 不同于 `K-cooperative-reaction-set-selection-bilevel-moo`：该知识关注从下层 reaction set 中按合作偏好选响应；本文用 ideal-point 最近路径近似攻击者代表响应，重点是上层网络阻断搜索。
  - 不同于 `K-cgan-lower-front-prediction-bilevel-search`：该知识用生成模型预测下层 PF 降本；本文用启发式 BOA 精确/近似求 bi-objective path set，再用 min-cut 转成上层修复。
  - 不同于普通 graph influence 或 diffusion control：本文是 Stackelberg-style defender-attacker 网络阻断，核心评价来自下层路径重规划。

## 局限与未来工作

- 下层 reaction set 被压缩为距离 ideal point 最近的一条代表路径，可能低估 follower 的其他风险偏好。
- 模型是 deterministic，未考虑 stochastic disruptions 或 dynamic network changes。
- iNSSSO 针对 MOBNIP 特化较强，跨问题域适应性有限。
- 真实 PF 不可得，实验中的参考 PF 来自多算法多次运行聚合。
- 未来方向：
  - 引入不确定性、随机阻断和动态网络变化；
  - 结合 machine learning 提升 iNSSSO 效率和解质量；
  - 扩展到其他 defender-attacker 或安全资源分配场景。
