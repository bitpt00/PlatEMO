# Collaborative Orthogonal Learning for Constrained Multi-Objective Optimization

## 一句话理解

论文提出 DSOCOL：在复杂约束多目标优化中，不再只在多种群之间共享精英解位置，而是让主群从边界、winner-loser 和可行/不可行状态中学习收敛方向，辅群沿该方向的正交补空间扩展搜索，再用三层生态位容量选择维持 CPF 覆盖，从而同时处理可行性、收敛和分布。

## 问题与动机

- 研究问题和场景：
  - constrained multi-objective optimization problems (CMOPs)；
  - 特别是 narrow、disconnected、irregular feasible boundaries；
  - CPF 可能碎片化，且 infeasible barriers 会阻断普通可行性优先搜索。
- 现有算法为什么不足：
  - CDP 在大不可行屏障或分离可行岛上容易早熟；
  - epsilon relaxation 可保留有价值不可行解，但参数和阶段控制困难；
  - 多种群/多任务 CMOEA 多传递精英解坐标，缺少对演化方向的抽取，辅群可能重复主群已经搜索过的区域；
  - 普通 DE/GA/CSO 等繁殖算子主要靠局部随机扰动，面对广阔复杂 landscape 时穿越不可行区能力不足；
  - 过度偏好可行性或收敛会让种群单向聚集，只覆盖 CPF 的局部片段。
- 本文希望解决什么：
  - 在不把 CMOP 重构成显式多任务问题的情况下，解耦 global exploration 和 diversity exploitation；
  - 让主群提取可复用 convergence trend，辅群使用正交方向探索互补子空间；
  - 用 objective-space niche capacity 防止可行解集中在容易到达的 CPF 片段。

## 核心理念与算法流程

- 核心理念：
  - 把双群协作从“共享解的位置”升级为“共享搜索方向”；
  - 主群 `S1` 用 epsilon relaxation 穿越不可行区域并学习收敛趋势；
  - 辅群 `S2` 用 CDP 保持可行 CPF 附近开发，并沿主群趋势的正交方向补充覆盖；
  - 每个参考向量 niche 内单独学习方向，避免全局方向平均掉局部 CPF 结构。
- DSOCOL 主流程：
  - 初始化两个 particle swarms `S1`、`S2`，设置 `K=N/10` 个 weight vectors；
  - `S1` 按 `epsilon(t)` 评价，`S2` 取 `epsilon=0`，即退化为 CDP；
  - 每代分别对 `S1`、`S2` 执行 offspring generation；
  - 合并 `S1 ∪ O1 ∪ O2` 后，对 `S1` 用 SPEA2-style environmental selection；
  - 合并 `S2 ∪ O1 ∪ O2` 后，对 `S2` 用 niche-guided subset selection (NGSS)；
  - 每隔 `TCOL=75` 代执行 collaborative orthogonal learning (COL)，生成方向学习子代后再分别选择；
  - `epsilon(t)` 随可行比例更新，早期放松约束，后期加强约束。
- Offspring generation：
  - loser group 使用基础 CSO loser update；
  - `S1` 的 winner group 用 Eq. (5) 围绕 winner 中心和 spread factor 扩展；
  - `S2` 的 winner group 用 Eq. (6) 结合 best winner 与两个随机 winner 差分增强。
- COL 中的 trend learning：
  - 在每个 niche 中，从 `S1` 选角度最近的 `floor(N/K)` 个候选；
  - 若同时存在 feasible non-dominated set 与 remaining set，分别抽取 `x_w`、`x_l`；
  - 否则按 CV 排序并按中位数切成前半/后半，再抽取代表；
  - 局部开发向量 `Delta1=x_w-x_l`，全局探索向量 `Delta2=x_w-x_r`，其中 `x_r` 是决策空间上下边界；
  - `v` 由 `tau*Delta1+(1-tau)*Delta2` 归一化得到，`tau=FE/FEmax`；早期偏边界到 winner 的全局探索，后期偏 winner-loser 的局部开发；
  - 主群候选为 `u_main=x_r+eta_k*v`。
- COL 中的 orthogonal learning：
  - 在 `S2` 同一 niche 中选代表 `x_b`：优先 feasible non-dominated，否则选最小 CV；
  - 对主群方向 `v` 取正交方向 `v_perp`；
  - 生成 `u_aux=x_b+eta_j*v_perp`，使辅群探索与主收敛趋势互补的子空间。
- NGSS 三层选择：
  - 第一层：按 CDP 把候选分为 non-dominated feasible set `Phi_nf` 和 remainder `Phi_rem`；
  - 第二层：把 `Phi_nf` 按 weight vector 角度分配到 `K` 个 niches，每个 niche 容量限制为 `L=floor(N/K)`，超额时按 crowding 删除并转入 residual；
  - 第三层：用同 niche 的 residual 或角度最近的 residual 填补稀疏 niche，优先补足未覆盖 CPF 片段。
- 可能被修改的位置：
  - 主群方向向量构造；
  - 正交方向生成方式；
  - `TCOL` 和 `K` 的调度；
  - `epsilon` 约束松弛策略；
  - NGSS 的 niche capacity、crowding、CDP 或 residual 填补规则；
  - winner group 的两个增强更新。
- 必须保留的核心：
  - 主群学习 convergence trend，辅群沿正交补空间探索；
  - 每个 niche 内局部学习方向，而不是全局混合一个方向；
  - 主群偏收敛/跨不可行区，辅群偏均匀 CPF 覆盖；
  - 选择阶段显式限制 crowded feasible niches 并填补 sparse niches。

## 实验证据

- 测试问题和对比算法：
  - 33 个 CMOP benchmark：DAS-CMOPs、C-DTLZ、DC-DTLZ、LIR-CMOPs；
  - 标准维度 `D<100`，以及大规模 `D=500`、`D=1000`；
  - 额外 FCP suite 测 deceptive/fraudulent constraints；
  - 10 个 real-world CMOPs，覆盖机械设计、化工、过程综合和电力电子；
  - 对比 APSEA、C3M、CMOEMT、DRLOS-EMCMO、IM-C-MOEA/D、CMOCSO、DVCEA、LCMEA、POCEA；
  - `N=100`，每个问题 30 次独立运行；标准问题 `FEmax=100000`，`D=500` 为 `200000`，`D=1000` 为 `300000`。
- 标准 CMOP 综合结果：
  - IGD 上 DSOCOL 在 33 个问题中的 19 个获得显著优势，DVCEA 在 6 个实例上最好；
  - HV 上，DSOCOL 相对九个对比算法的显著优胜次数分别为 `25,31,17,22,32,16,18,32,33`；
  - Friedman + Holm correction 中 DSOCOL 的 IGD rank `2.0909`、HV rank `2.3788`，均为最佳，对所有对比算法 `p<0.05`。
- 复杂/大规模/欺骗约束结果：
  - 大规模 `D=500/1000` 的补充表中，DSOCOL 在 IGD/HV 上获得最好平均排名，`p<0.05`；
  - FCP deceptive constraints 中，只有 LCMEA 在所有问题上都找到可行解，但 DSOCOL 在 5 个实例中 4 个最好；
  - 其它多数算法在 FCP1-FCP4 上找不到可行区域，作者归因于它们偏可行性/目标或只传递位置知识。
- 消融或机制证据：
  - DSOCOL1 去掉 NGSS 后，在 LIR-CMOP3 上只能覆盖局部 CPF；Table III 中相对 DSOCOL 的 IGD/HV 为 `5/25/36`、`8/19/39`；
  - DSOCOL2 只用 polynomial mutation 更新 winner，DSOCOL 在约 78% cases 上更好或相当；
  - DSOCOL3 去掉 COL 后收敛曲线明显变慢；
  - DSOCOL4 去掉 trend learning 后最差，说明只有正交探索而没有可靠主方向会浪费评价；
  - DSOCOL5 去掉 orthogonal learning 后，收敛速度可接近或略快，但最终分布不如 DSOCOL 均匀；
  - Table IV 中 DSOCOL 的 IGD/HV rank 为 `2.3864/2.6288`，优于所有五个变体；DSOCOL5 的 HV 差异 `p=0.226421` 不显著，说明正交分支主要贡献在分布和覆盖。
- 真实应用：
  - pressure vessel、four-bar truss、front rail、heat exchanger、reactor network、process design/synthesis/flow sheeting、3/7-level inverter SOPWM；
  - 作者称 DSOCOL 整体质量最好，DVCEA 次之；
  - 多个算法在 heat exchanger 或 SOPWM 等问题上出现 `NaN`，说明找不到可行解。
- 证据边界：
  - 许多精确均值/标准差在 Supplementary，主文只给汇总表；
  - DSOCOL 的复杂度 worst case 为 `O(N^3)`，主要来自 SPEA2 truncation；
  - 参数 `TCOL=75`、`K=N/10` 的敏感性放在补充材料；
  - 实验证据主要是 2/3 目标 CMOP 和部分大规模变量，many-objective 只在未来工作中讨论。

## 局限与未来工作

- 作者明确说明的局限：
  - constrained many-objective optimization (CMaOP, `M>3`) 仍有挑战；
  - traditional Pareto dominance-based selection 在 CMaOP 中会退化。
- 作者未来工作：
  - 在 Cartesian products 上执行 orthogonal searches；
  - 尝试把非支配集合基数的指数增长挑战降到多项式复杂度，从而扩展 DSOCOL 到 CMaOP。
- 我们认为仍需确认的问题：
  - `TCOL` 和 `K` 是否能由 feasible ratio、niche occupancy 或 stagnation 自适应调节；
  - `v_perp` 在高维中是否需要构造一组低秩正交基，而不是单个正交方向；
  - 对 equality constraints、noisy constraints 或 surrogate constraints，`x_b` 的可行代表选择是否稳定；
  - 正交方向是否可能离开窄可行流形，需要 repair/projection；
  - 与已有 UPF/CPF 桥接、deceptive escape 和 adaptive CV granularity 机制组合时是否互补或冗余。

- 与已有设计知识的边界：
  - 不同于 [多方向模糊采样与多源竞争细化](../02_design_knowledge/K-multidirectional-fuzzy-sampling-multisource-cso.md)，本文的正交方向来自主群学到的约束收敛趋势，并由辅群在 CPF 附近执行，而不是代表解配对的无约束高维采样；
  - 不同于 [目标分解的高斯演化方向学习](../02_design_knowledge/K-objective-wise-gaussian-evolutionary-direction-learning.md)，本文不拟合目标级概率方向模型，而是按 niche 在线合成一个主趋势并正交化；
  - 不同于 [UPF 参照的动态逃逸种群](../02_design_knowledge/K-upf-referenced-dynamic-escaping-population.md)，本文不显式追 UPF 或保留 second-best/worst 逃逸个体，而是通过 epsilon 主群与正交辅群共同覆盖 CPF；
  - 不同于 [参考子区约束学习与高斯胜者进化](../02_design_knowledge/K-reference-subregion-constrained-learning-gaussian-winner-cso.md)，本文的关键不是限制 loser 学习对象和高斯 winner 进化，而是跨双群传递收敛方向并生成正交互补子代。
- 暂留在论文卡中的方法、原理或架构启发：
  - NGSS 可单独迁移为 constrained objective-space capacity selection，但目前与 COL 强耦合，暂不拆成单卡；
  - winner group Eq. (5)/(6) 是 CSO 局部增强，可后续与其它 CSO 论文共同形成 winner evolution 卡；
  - FCP deceptive constraints 可作为约束算法压力测试线索。
- 局部创新线索：
  - 用 feasible boundary tangent/normal 或 active constraint gradient 替代简单 `v_perp`；
  - 让每个 niche 维护历史成功方向队列，用 PCA 取主方向和正交子空间；
  - 对辅群正交子代增加 projection 或 repair，避免离开窄可行流形；
  - 把 NGSS 的 capacity `L` 改为由 niche improvement rate 或 CPF fragment discovery rate 自适应。
- 结构创新线索：
  - 构建三通道 CMOP 搜索器：主收敛方向、正交覆盖方向、CV/feasibility repair 方向；
  - 与 adaptive CV granularity 组合：主群使用粗粒度/epsilon CV，辅群使用细粒度/局部 CV；
  - 与 surrogate CMOP 组合：用代理判断正交子代的 feasible probability 和 boundary distance，再决定真实评价。
