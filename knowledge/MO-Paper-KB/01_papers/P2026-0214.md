# Learning to Preselection: A Filter-Based Performance Predictor for Multiobjective Feature Selection in Classification

## 一句话理解

本文把多目标特征选择中的 wrapper 评价预筛选从“训练回归/分类代理”改为“用信息论 filter 指标预测分类性能排序”，并按预测器可信度在分类性能预筛和特征子集多样性预筛之间自适应分配候选评价预算。

## 问题与动机

- 研究问题和场景：分类特征选择需要同时最小化分类错误率和选中特征比例，是典型多目标组合优化问题；wrapper 评价要训练分类器，计算代价高。
- 现有算法为什么不足：
  - 回归或分类代理更适合连续优化，在大规模二进制特征子集空间中训练样本少且维度高，容易失效；
  - 普通 filter 方法只用于初始化或启发式引导，没有充分结合 wrapper 评价反馈；
  - 多目标特征选择中目标偏好不对称，分类性能通常比特征数量更重要；
  - 不同特征子集可能有相同错误率和特征数量，导致目标空间重复和停滞。
- 本文希望解决什么：在不评价全部 trial offspring 的情况下，低成本识别更可能有好分类性能且目标空间更有差异的特征子集，提高搜索效率和最终分类性能。

## 核心理念与算法流程

- 核心理念：filter 指标虽然不能直接替代 wrapper 评价，但如果某个 filter 指标在近期已评价特征子集上的排序与真实分类错误率排序高度一致，就可以作为当前阶段的性能预测器；当一致性低时，减少对它的依赖，转而用特征数量差异维护多样性。
- 主要流程：FPPFS 先预计算特征与类别、特征之间的信息论相关值；初始化种群并作为训练集；每代根据最近 `5N` 个已评价解学习 filter 性能预测器；生成 `5N` 个 trial solutions；按相关系数 `rho` 决定多少候选由预测分类性能排序选出，其余候选由特征数量差异选出；只评价预选的 `N` 个 offspring，再进行非支配排序和拥挤距离环境选择。
- 关键组成部分：
  - 五个 filter 指标：Mean Relevance、mRMR、MIFS-CR、N-MRMCR-MI、CFS，均基于信息论相关与冗余。
  - Spearman rank correlation：比较已评价解的分类错误率 rank 与每个 filter 指标 rank，选择最高相关的 filter 作为预测器；负相关按 0 处理。
  - 相关系数驱动预筛比例：`p(rho)` 由模拟退火式指数函数给出，`rho<0.2` 时几乎不用预测器，`rho>0.8` 时几乎全用预测器。
  - 特征数量差异预筛：当预测器不可信时，优先选与父代不同选中特征数的候选，并在其中偏向更少特征，以缓解目标空间重复。
- 可能被修改的位置：
  - 可替换 filter 指标集合，例如加入 ReliefF、Fisher score、互信息网络或模型无关稳定性指标；
  - 可把 Spearman 换成 Kendall tau、top-k rank agreement 或带权相关；
  - 可把特征数量差异扩展为 Hamming 距离、Jaccard 距离或子集互补度；
  - 可插入 NSGA-II、MOEA/D、SparseEA 或其他二进制 MOEA 的 offspring evaluation 前。
- 必须保留的核心：用近期 wrapper 评价结果校准 filter 指标可信度，并把可信度直接反馈到预筛选中，而不是固定相信某个 filter 或固定依赖随机/多样性。

## 实验证据

- 测试问题和对比算法：18 个真实分类数据集，涵盖医疗、金融、信号、手写数字、图像和基因表达；训练/测试 70%/30%，KNN 五折交叉验证计算训练错误率，测试集报告最终结果。对比 SparseEA、SIOM-NSGA-II、PMMOEA、DAEA、BSOEA、PRDH，补充材料还与 SFS 比较。
- 主要实验结论：HV 上 FPPFS 在 18 个数据集中 9 个最佳，Friedman 排名第一；相对 SIOM-NSGA-II、SparseEA、PMMOEA、DAEA、PRDH、BSOEA 分别在 14、6、11、6、8、7 个数据集显著更好，竞争算法显著优于 FPPFS 的数据集最多 3 个。MCER 上 FPPFS 也排名第一，相对六个对比算法分别在 10、6、9、8、4、7 个数据集显著更好。
- 代理对比证据：相对 KNN 分类代理和 RF 回归代理，FPPFS 在高维数据集上明显更好；作者解释为 RF 训练样本远少于特征维度，KNN 的 Hamming 距离难捕捉复杂特征交互，而 filter 指标预计算后对维度更不敏感。
- 收敛和消融证据：与无预测/无预筛的 BA 相比，FPPFS 的 HV 收敛更快，且在 ORL、Brain1 等高维数据集差距更大；FPPFS 相对只用最佳 filter 的 FPPFS-PP 和只用特征数量差异的 FPPFS-DS，在 HV 与 MCER 之间取得更好平衡。低相关数据集上固定使用 filter 会误导搜索，单纯多样性会牺牲 MCER。
- 证据边界：所有 wrapper 评价使用 KNN，分类器换成 SVM、RF、深度模型时 filter 排序与分类性能的相关性需要重验；只比较了二目标错误率/特征比例，没有覆盖特征成本、公平性、鲁棒性等多目标扩展。

## 局限与未来工作

- 作者明确说明的局限：结论部分未展开系统性局限，但方法依赖 filter rank 与 wrapper 分类错误 rank 的单调相关性；需要存储 `O(D^2)` 特征相关矩阵。
- 作者未来工作：扩展到单目标特征选择；进一步减少分类性能评价次数。
- 我们认为仍需确认的问题：
  - 多类别、不平衡、强噪声数据中 filter rank 是否稳定；
  - 当高维特征相关矩阵无法完整存储时如何近似；
  - 预筛比例函数是否适合不同 population size 和 trial multiplier；
  - filter 指标与特定分类器强耦合时，是否需要分类器感知的校准项。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“滤波性能预测的特征子集预筛选”，因为它是离散特征选择场景下的专用预筛模块，与通用 pairwise relation surrogate 不重复。
- 暂留在论文卡中的方法、原理或架构启发：
  - 便宜启发式指标不必直接当目标，可通过近期真实评价 rank 相关性在线校准；
  - 代理可信度低时不应继续强用代理，而应把预算转给多样性或低成本目标；
  - 目标空间重复可用特征数量差异这种廉价信号先粗处理。
- 局部创新线索：
  - 用多个 filter 指标加权集成，而不是只选最高 Spearman 的单一指标；
  - 用 top-k 一致性或 pairwise preference accuracy 代替全局 rank correlation；
  - 让 `5N` trial multiplier 和训练窗口随预测器可信度变化。
- 结构创新线索：
  - 构建“低成本启发式指标库 + 真实评价 rank 校准 + 可信度门控预筛”的通用离散 MOO 代理层；
  - 与稀疏变量类型挖掘结合，用变量类型稳定性修正 filter 预筛分数。
