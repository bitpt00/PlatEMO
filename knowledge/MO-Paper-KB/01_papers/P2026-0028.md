# Evolutionary multitasking for multi-objective feature selection in fish chemical analysis

## 一句话理解

论文面向鱼类化学成分光谱分析中的多输出回归任务，提出 EMTFS：先用目标变量之间的 Pearson/Spearman 相关性聚类得到相关任务组，再为相关任务选统一预处理管线以保持共同特征空间，最后用共享二进制种群同时做多任务多目标特征选择，在任务间转移有用特征子集信息。

## 问题与动机

- 研究问题和场景：用 FT-NIR、FT-Raman、InGaAs Raman 等光谱快速预测 hoki / mackerel 鱼样本的多种化学成分，替代耗时、破坏性或昂贵的实验室测量。
- 数据和优化结构：
  - 共有 117 个鱼样本；
  - 三个光谱数据集分别有 1971、2852、513 个特征，每个特征对应一个 wavenumber；
  - 21 个化学目标变量形成 21 个回归任务；
  - 每个特征选择解是二进制子集，优化目标为 selected feature ratio `NFS/TFN` 和归一化回归误差 `NRMSE`。
- 现有方法为什么不足：
  - 高维光谱中 wrapper 特征选择搜索空间为 `2^n`，容易昂贵且不稳定；
  - 传统特征选择通常对每个化学目标独立处理，忽略相关化学成分之间可共享的光谱信息；
  - Evolutionary multitasking 可共享知识，但任务相关性未知时盲目迁移会产生 negative transfer；
  - 不同任务若选择不同预处理管线，特征分布和有效特征空间可能不同，会破坏共享二进制编码和跨任务迁移。
- 本文希望解决什么：
  - 自动识别哪些化学目标任务相关；
  - 为相关任务保持统一预处理和共同特征空间；
  - 在同一二进制种群中同时优化多个相关特征选择任务；
  - 用任务特异评价和选择降低负迁移风险。

## 核心理念与算法流程

- 核心理念：多输出特征选择中，不要先假设所有任务都应共享知识。先按目标变量相关性聚类，只在相关任务内共享；同时把预处理管线统一，使每个任务面对相同特征坐标；最后用共享种群承载跨任务候选，但每个任务按自己的回归误差和特征数量选择 `N/K` 个优秀解回流到下一代。
- 主要流程：
  1. 对 21 个化学目标变量两两计算 Pearson 与 Spearman 相关性。
  2. 将相关性归一化并转为距离：`distPearson = 1 - Normalised(Pearson(Task_i, Task_j))`，Spearman 同理；再用到原点 `(0,0)` 的 Euclidean distance 表示任务差异。
  3. 用 Ward hierarchical clustering 对任务聚类，并根据 dendrogram 跳变确定任务组。
  4. 在每个相关任务组内比较候选预处理管线，包括 baseline correction、normalisation、Savitzky-Golay derivatisation 等，用 K-fold CV 回归性能选择较稳的统一预处理。
  5. 对 `K` 个相关任务运行 EMTFS：用一个共享二进制种群表示特征子集，每个任务有自己的评价函数。
  6. 每代中，对每个任务 `k`：
     - 用该任务的 wrapper 回归器评价种群的 selected feature ratio 和 `NRMSE`；
     - 用非支配排序和 crowding distance 等多目标选择方式选 `N/K` 个父代；
     - 对父代做 one-point crossover 和 bit mutation，生成并评价 offspring；
     - 从父代与 offspring 合集中再选 `N/K` 个代表该任务的优秀解。
  7. 合并所有任务选出的解形成下一代共享种群。
  8. 最终每个任务选 `NRMSE` 最低的特征子集作为输出。
- 关键组成部分：
  - Pearson + Spearman 双相关任务聚类；
  - 统一预处理管线和共同特征空间；
  - 共享二进制种群；
  - 任务特异多目标评价；
  - 每任务 `N/K` 配额选择；
  - wrapper 回归器按目标变量选择 Linear 或 KNN。
- 可能被修改的位置：
  - 任务相关性可从 Pearson/Spearman 扩展为 mutual information、partial correlation、causal similarity、prediction residual correlation 或 learned task embedding；
  - 聚类可替换为谱聚类、community detection、Bayesian nonparametric clustering 或在线 task grouping；
  - 统一预处理可从硬选择扩展为多管线 ensemble 或带惩罚的 task-specific preprocessing；
  - 任务选择配额 `N/K` 可改为基于任务难度、迁移收益或不确定性的 adaptive quota；
  - crossover/mutation 可替换为稀疏感知、相关波段块、group feature 或 learned mask operator。
- 必须保留的核心：
  - 只在经证据判断相关的任务之间共享；
  - 跨任务共享必须建立在可对齐的特征空间上；
  - 共享种群中的个体需要按任务特异目标评价，而不能用单一综合目标替代；
  - 每个任务都要保留自己的选择入口，避免被其他任务的优势解完全挤出。

## 实验证据

- 数据集和任务：
  - 117 个鱼样本，三类光谱：FT-NIR 1971 特征、FT-Raman 2852 特征、InGaAs Raman 513 特征。
  - 21 个化学目标：Wax/sterol esters、Water、Total MUFA、Polar lipids、Total Phospholipids of lipid、Monoacylglycerols、Free fatty acids、Total NMI PUFA、Ash、Total Phospholipids of sample、Total DMA、Total Omega3、Total PUFA、Nitrogen、Protein、Total Omega6、Total SFA、Triacylglycerols、Fat、Lipids yield、Sterols。
  - 数据提供六个 groups，实验使用 6-fold CV。
- 任务聚类结果：
  - Group 1 共 12 个任务：Ash、Fat、Lipids yield、Nitrogen、Protein、Total Omega3、Total Omega6、Total PUFA、Total SFA、Total DMA、Triacylglycerols、Total Phospholipids of sample。
  - Group 2 共 9 个任务：Water、Total MUFA、Total NMI PUFA、Wax/sterol esters、Sterols、Polar lipids、Monoacylglycerols、Free fatty acids、Total Phospholipids of lipid。
- 预处理和 evaluator：
  - FT-Raman 上，Group 1 中 7/12 个任务的最佳管线为 `Linear Baseline + SNV`，Group 2 中 3/9 个任务最佳管线也为该组合；作者据此为 21 个 FT-Raman 任务采用统一 `Linear Baseline + SNV`。
  - Wrapper evaluator 通过原始特征上的 Linear 与 KNN 表现确定：12/21 个目标使用 KNN，其余 9 个使用 Linear。
- 参数设置：
  - Population size 设为特征数但最多 200；
  - 最大代数 200；
  - one-point crossover；
  - mutation probability 为 `1/D`；
  - 30 次独立运行；
  - 评价指标为 RMSE 和 R Square，显著性使用 Wilcoxon test `p=0.05`。
- 主要性能结论：
  - EMTFS 在 preprocessed FT-Raman、InGaAs Raman truncated 和 InGaAs Raman 三类结果中，对多数化学目标的 RMSE 和 R2 优于 full-feature regression baselines。
  - 作者总结 EMTFS 在 InGaAs Raman 数据集上取得最佳 RMSE 表现。
  - FT-Raman 示例：Fat 的 RMSE 从 baseline 约 0.48-0.66 降至 0.29；Total Omega3 从约 20-23 降至 9.44；Total PUFA 从约 22-26 降至 10.38；Total SFA 从约 10-12 降至 5.72。
  - InGaAs Raman 示例：Ash RMSE 0.08，显著低于 baseline 0.32-0.34；Fat 0.13，低于 0.51-0.74；Lipids yield 0.12，低于 0.38-0.66；Nitrogen 0.03，低于 0.14-0.17；Water 0.27，低于 1.16-1.36。
  - 并非所有目标都明显受益，例如 Triacylglycerols 的 R2 仍可能为负，Wax/sterol esters 等目标的差距较小。
- 特征共享证据：
  - 作者分析 Water、Total MUFA、Total NMI PUFA 的 selected features 重叠。
  - FT-Raman 上，Water 选中特征约 32% 也被 Total MUFA 选择，约 35% 也被 Total NMI PUFA 选择。
  - InGaAs Raman 上，Water 与 Total MUFA 的重叠约 26%，与 Total NMI PUFA 的重叠约 42%。
  - InGaAs Raman truncated 上，对应重叠约 18% 和 8%。
  - 作者将这些重叠作为相关任务共享特征知识的证据。
- 证据边界：
  - 主比较对象多是未做本文 FS 的 regression models，不是强独立单任务 FS 或其他 EMT-FS baselines。
  - 缺少 no clustering、task-specific preprocessing、no EMT 或 independent FS 等关键消融，因此难单独归因任务聚类、统一预处理和 EMT 各自贡献。
  - 样本量只有 117，6-fold CV 下回归误差方差可能较大。
  - 统一预处理提升了可迁移性，但可能牺牲某些任务的最佳单任务预处理。
  - 部分结果和细节在 supplementary materials，主文证据链不完全自足。

## 局限与未来工作

- 作者明确说明的未来工作：
  - 设计新的 knowledge transfer approach，以支持相关任务拥有不同特征集合或不同预处理管线；
  - 因而可以让任务使用各自最优预处理，而不是为了共享强制统一；
  - 对不同 clustering algorithm 和 cluster number 做 stability analysis。
- 我们认为仍需确认的问题：
  - 文中 Sec. 4.4.2 有“varying feature sets / feature-level transformation”的表述，但算法流程和结论未来工作都显示当前 EMTFS 主要依赖共同特征空间；复现时应以统一特征空间假设为准。
  - 任务相关性只从目标变量统计相关性推断，不一定等价于最优特征子集相似性。
  - `N/K` 固定配额是否适合难度差异很大的任务未知；困难任务可能需要更多评价份额。
  - Linear/KNN evaluator 的选择与最终 EMTFS 性能耦合，未充分分析 evaluator 选择错误的影响。
  - 特征重叠只能说明某些任务共享波段，不足以单独证明 EMT 迁移优于独立 FS。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：[任务相关性聚类与统一特征空间的多任务特征选择](../02_design_knowledge/K-task-clustered-uniform-space-emt-feature-selection.md)。本文给出完整的多任务特征选择架构：任务聚类、特征空间对齐、共享种群、任务特异评价和配额选择。
- 暂留在论文卡中的方法、原理或架构启发：
  - 具体的 FT-Raman / InGaAs Raman 化学分析结果属于应用证据，暂不单独成卡。
  - Linear/KNN evaluator selection 是实验实现细节，可在更多 wrapper evaluator 选择论文出现后再抽象。
  - 特征重叠分析可作为 EMT-FS 的事后诊断指标，暂不单独成卡。
- 局部创新线索：
  - 把 Pearson/Spearman 聚类改成基于历史选择 mask 的 task affinity，并随进化过程在线更新。
  - 对每个 cluster 维护多个 preprocessing candidates，用迁移收益和单任务性能的多目标权衡选择是否统一。
  - 将 `N/K` 配额改为 task-bandit：根据每个任务近期 RMSE 改善、前沿多样性或负迁移警报动态分配 offspring。
  - 在共享种群中加入 mask provenance，记录特征子集来自哪个任务，从而估计 cross-task transfer credit。
  - 用 group-aware mutation 按光谱连续波段翻转 bit，增强可解释性和局部搜索效率。
- 结构创新线索：
  - 构建“任务相关性估计 -> 特征空间对齐 -> 多任务子集共享 -> 任务特异选择 -> 迁移诊断”的通用多输出 FS 框架。
  - 将该框架扩展到传感器选择、基因选择、多标签学习、工业软测量和多工况故障诊断。
  - 在不同特征空间场景中加入 feature-level mapping，例如 shared latent bands、canonical correlation、optimal transport 或 graph matching。
