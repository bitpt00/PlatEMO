# A two-stage multimodal multiobjective evolutionary algorithm using Voronoi diagram and modality detection

## 一句话理解

本文提出 MMEA/VM：在 MMOP 中循环交替两个搜索阶段，先用 Voronoi 决策空间邻居扩大多个 Pareto set 的探索，再用模态检测把已发现的 PS 分开，并在每个模态内用分解式目标空间搜索和环境选择精修 PF。

## 问题与动机

- 研究问题和场景：Multimodal multiobjective optimization problems (MMOPs)，多个决策空间 Pareto optimal sets 可能映射到同一个 Pareto front，需要同时保持 objective-space convergence/diversity 和 decision-space multiple PS coverage。
- 现有算法为什么不足：
  - 传统 MOP 算法主要关注目标空间，容易只得到一个或少数等价 PS；
  - 许多 two-stage MMEA 先全局探索再局部开发，但阶段顺序静态且不可逆，一旦进入第二阶段就难以恢复第一阶段漏掉的 PS 区域；
  - 决策空间 niche 往往依赖人工半径或距离参数，参数错配会造成模态混合或小模态丢失；
  - 单独使用 objective-space decomposition 或单独使用 Voronoi/niching 都难同时兼顾 PF 质量与 PS 覆盖。
- 本文希望解决什么：让算法能在搜索过程中反复切换决策空间探索和目标空间开发，用无额外 niche 半径的 Voronoi 邻域扩大 PS 覆盖，并用 modality detection 将不同 PS 独立精修。

## 核心理念与算法流程

- 核心理念：把 MMOP 搜索拆成可循环的两个角色。第一阶段不把邻域定义在目标空间权向量上，而是用决策空间 Voronoi 邻居生成和更新个体，扩大/维持决策空间多样性；第二阶段先识别当前种群包含的多个模态，再对每个模态进行分解式搜索，强化目标空间收敛与 PF 分布。
- 主框架 MMEA/VM：
  1. 初始化 `P0`，用 EnvironmentalSelection 初始化 archive `Arc`。
  2. Stage 1 调用 VDEM/D：为 `nP` 个个体生成目标空间权向量并建立固定链接；对每个个体找决策空间 Voronoi neighbors，用 DE 生成子代，用 PBI 标量函数判断是否更新邻居。
  3. 将 Stage 1 的 non-dominated offspring 加入 `P0`，切到 Stage 2。
  4. Stage 2 先调用 MDS：按目标空间权向量关联形成 objective subpopulation，再在每个 subpopulation 内用 mean-shift 聚类决策空间分组，估计并合并多个 modalities。
  5. 对每个 modality 调用 SMO/D：限定该模态的搜索区域，使用权向量、目标空间邻域、DE 和 PBI 精修解。
  6. 将优秀 offspring 加入 `P0` 和 `Arc`，再对 archive 做 MDS-aware EnvironmentalSelection。
  7. 切回 Stage 1 并重新初始化 `P0`，持续循环直到 `maxFEs`。
- 阶段切换依据：
  - Stage 1 用 `Cdec = Ndec/nP` 记录一代中 progressive children 的比例，`lambda_dec=0.2`；
  - Stage 2 用 `Cobj = Nobj/|Mi|` 记录各 modality 内 progressive children 的比例，`lambda_obj=0.4`；
  - 参数控制从决策探索转向目标开发，以及从目标开发回到决策探索。
- 关键组成部分：
  - VDEM/D：Voronoi diagram-based diversity enhancement mechanism，用共享 Voronoi edge 的个体作为邻居，减少目标空间邻居误把个体推向错误 PS 的风险。
  - MDS：modality detection strategy，先按目标空间权向量分段，再用 mean-shift 在决策空间检测每段内的多个模态。
  - SMO/D：decomposition-based search mechanism in objective space，对每个已识别模态独立进行目标空间分解搜索。
  - EnvironmentalSelection：先把 archive/offspring 按 MDS 分成多个 modality，再按理想名额、非支配性和拥挤程度保留个体，避免一个模态占满 archive。
- 必须保留的核心：Stage 1 的邻域必须来自决策空间 Voronoi 结构，Stage 2 必须先分辨模态再独立开发；若只保留分解搜索或只保留 Voronoi 邻域，双空间平衡会明显弱化。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：MMF suite 19 个函数，IDMP suite 12 个函数，以及一个 map-based real-world problem。
  - 对比算法：Omnioptimiser、DN-NSGA-II、MO_Ring_PSO_SCD、TriMOEA-TA&R、MMEA-WI、MMOEA/DC、HREA、CoMMEA、LORD、FPITSEA、MMODE-VN、DSC-MOPSO、DSC-MOAGDE、DRSC-MOAGDE 等。
  - 设置：每个问题 31 次独立运行；实验在 PlatEMO v4.0 和 MATLAB 上实现；MMF/IDMP 按表中设置 population size 与 MaxFEs。
  - 指标：decision-space 指标 IGDX、PSP；objective-space 指标 IGD、IGDp、HV；附加稳定性指标 SR、MST、MFE。
- MMF suite 主要结论：
  - MMEA/VM 在 IGDX 上 10/19 个问题 best，在 PSP 上 8/19 个问题 best，决策空间 best 数量最高；
  - 目标空间上 IGD、IGDp、HV 分别在 5/19、6/19、5/19 个问题 best，整体目标空间性能接近 CoMMEA、LORD 和 MMODE-VN；
  - Friedman rank 中 MMEA/VM 在 decision-space metrics 排名第一，both spaces 平均 rank 为 3.55，体现双空间折中。
- IDMP suite 主要结论：
  - IDMP 用不同 attraction basin 难度检验 imbalanced PS，MMEA/VM 在 IGDX、PSP、IGD、IGDp、HV 上均有较多 best；
  - 作者认为其优势来自 Voronoi neighbors 与 reference vectors 的组合，不依赖显式 local convergence 或固定 local region 参数，却能保持困难 PS。
- Ablation 证据：
  - Variant 1 去掉 VDEM/D 后决策空间 PS 不完整，说明 Voronoi 决策空间探索对覆盖多个 PS 关键；
  - Variant 2 去掉 SMO/D 后决策空间可能更分散，但目标空间 IGD 变差，说明第二阶段不应继续只强调决策空间；
  - Variant 3/4 替换或删除 MDS-aware selection 后，容易只按非支配性保留个体，导致每个 PS 的数量和分布不均；
  - 作者总结关键是同时平衡 decision-space diversity 和 objective-space convergence。
- 参数与真实问题：
  - `lambda_dec` 在 0.2 到 0.5 范围表现较好，本文取 0.2；`lambda_obj` 综合双空间指标取 0.4；
  - map-based problem 中目标为最小化到便利店、小学、初中、铁路站四类设施的距离，Pareto optimal region 有三个不连续区域；
  - MMEA/VM 在 map-based problem 的五个指标上均为 best 或与 best 可比，并且比部分算法更完整覆盖三个 Pareto region。
- 证据边界：
  - Markdown 中公式、图和部分表格为图片或占位，精确公式排版和所有统计表需回查 PDF；
  - 未看到公开代码或数据集链接，Data availability 声明为未使用数据；

## 局限与未来工作

- 作者明确说明的局限：
  - 两阶段切换依赖手工设定的 `lambda_dec` 和 `lambda_obj`，限制算法可扩展性；
  - 当前框架对不同类型 MOEA 的可迁移性仍有限；
  - MMEA/VM 计算复杂度略高。
- 作者未来工作：
  - 设计 adaptive switching mechanism，使算法根据搜索状态自动调整阶段；
  - 将核心原则扩展成更通用的优化框架，适配更多 MOEA；
  - 扩展到 constrained MMOP、dynamic MMOP 和其他实际多模态优化场景。
- 我们认为仍需确认的问题：
  - Voronoi 邻域在高维决策空间中的计算和距离集中问题；
  - mean-shift MDS 在变量尺度不均、混合变量或离散编码中的可靠性；
  - 重启 `P0` 是否会在某些问题上浪费已获得的结构信息；
  - stage switching 参数能否被 archive coverage、modality stability 或 dual-space improvement 自动替代。

## 可复用知识与创新线索

- 值得建立的设计知识：建立“Voronoi-模态检测的动态双阶段 MMOP 搜索”，因为它把参数轻量的决策空间邻域、模态识别和分解式目标空间开发组织成一个可迁移架构。
- 暂留在论文卡中的方法、原理或架构启发：
  - 目标空间权向量可用于保证 PF 分布，但邻域更新不一定要沿目标空间定义；
  - 先按 objective segment 划分，再在每段中检测 decision-space modality，可避免同一 PF 段内的多个 PS 混合；
  - progressive children ratio 可作为阶段进退信号，但最好进一步自适应。
- 局部创新线索：
  - 用 Delaunay/Voronoi 或近似 nearest-neighbor graph 替换固定 niche 半径；
  - 将 MDS-aware environmental selection 移植到已有 archive-based MMEA；
  - 用 modality stability、archive novelty 或 IGED-like indicator 触发阶段切换。
- 结构创新线索：
  - 构建“决策空间邻域探索 -> 模态检测 -> 模态内分解开发 -> archive 分模态选择 -> 状态触发重启”的通用 MMOP 控制器；
  - 把 Stage 1 的 Voronoi 邻域换成 learned metric/graph neighborhood，把 Stage 2 的 SMO/D 换成 problem-specific local solver；
  - 在 constrained/dynamic MMOP 中增加可行性模态检测或环境变化后的 modality memory。
