# Efficient preference learning algorithm for interactive evolutionary multi-objective optimization

## 一句话理解

论文提出 ERS (Evolutionary Rejection Sampling)：在交互式多目标优化中，决策者只给出少量 pairwise comparisons，ERS 将“生成与这些比较兼容、且在偏好模型参数空间中分布均匀的一组模型实例”视为一个进化采样问题，用 queue、compatibility degree、nearest-neighbor distance 和专用权重向量算子替代 FRS 的朴素 Monte Carlo 拒绝采样。

## 问题与动机

- 研究问题和场景：
  - Preference-based EMO 希望只搜索 DM 真正关心的 PF 子区域。
  - DM 往往不能直接给出权重、阈值或 scalarizing-function 参数。
  - Pairwise comparisons 比直接设置模型参数更自然，但它们只给出不完整偏好信息。
  - 同一组比较可能对应许多兼容偏好模型，需要一组代表性模型来稳健指导搜索。
- 现有方法为什么不足：
  - 直接参数化方法假设 DM 知道并能精确设置偏好模型参数，这在 MCDA 中不现实。
  - Polyrun 可做显式采样，但主要限于线性模型。
  - FRS 支持非线性模型，但使用朴素 Monte Carlo rejection sampling；当比较约束强、目标数高或兼容空间很小时，采样效率急剧下降。
  - FRS 不能保证一次运行得到均匀分布的兼容模型，容易让 IEMO/D 的 scalarizing directions 分布偏斜。
- 本文希望解决什么：
  - 高效生成足够多 compatible preference models。
  - 让模型集合在兼容参数空间中近似均匀分布。
  - 支持非线性偏好模型，并尽量保持模型无关。
  - 使 preference disaggregation 足够快，适合交互式系统响应。

## 核心理念与算法流程

- 偏好模型与兼容性：
  - 论文以 `L_{w,alpha}`-norm value model 为实验对象。
  - 参数包括权重向量 `w` 和 compensation level `alpha`。
  - DM 给出 pairwise comparisons `s_p ≻ s_not_p`。
  - 若模型对每个比较都给 preferred solution 更高 relevance，则该模型与历史偏好 `H` compatible。
  - 目标是构造 `N` 个 compatible models，并最大化模型间最小距离，使其覆盖兼容空间。
- ERS queue：
  - 维护固定长度 `N` 的 queue `Q`。
  - 每个模型包装为 `SortedModel`，存储 model instance、compatibility degree `cd`、`K` 个最近 compatible neighbors 及其距离、唯一 `id`。
  - `cd>0` 表示 compatible；`cd<=0` 表示 incompatible，且负值幅度表示违反偏好的程度。
  - 排序规则优先级：
    - 两个都 compatible 时，nearest-neighbor distance 更大的模型排前；
    - compatible 模型排在 incompatible 模型前；
    - 两个都 incompatible 时，`cd` 更高的模型排前。
  - 作者设置 `K=3`，认为更大 `K` 收益有限但增加开销。
- ERS evolution：
  - 初始化时计算 queue 中模型的 `cd`、nearest-neighbor structure，并排序。
  - 迭代阶段每次用 tournament selection 选父代，生成一个 offspring model。
  - 若 offspring incompatible：
    - 如果 queue 已全部 compatible，则丢弃；
    - 否则按排序插入并移除最后一个模型。
  - 若 offspring compatible：
    - 计算其与现有 compatible models 的距离；
    - 更新受影响模型的 neighbor arrays；
    - 插入 offspring，并删除 queue 尾部多余模型；
    - 更新 similarity matrix，避免重复计算距离。
- 专用 genetic operators：
  - Crossover：在两个权重向量连线附近采样 `w_O = w_1 + gamma(w_2-w_1)`，`gamma` 为 Gaussian，并以 0.5 概率平移 `+1` 以围绕两个父代采样。
  - 若 offspring 权重分量越界，则最多重采样 10 次，否则复制一个父代。
  - Mutation：从重缩放的 simplex 方向采样扰动，保证权重和为 1；若越界则最多重采样 10 次，否则跳过。
  - 算子针对 simplex weight vector，但 ERS 框架可迁移到其他有距离和算子的模型空间。

## 实验证据

- 论文实验直接支持：
  - 96,000 次 standalone sampler runs 显示 ERS 在成功率、时间和兼容模型均匀性上整体优于 FRS；
  - 嵌入 IEMO/D 后，ERS 平均 rank 为 1.22、FRS 为 1.78，说明更好的偏好模型采样可转化为更稳定的偏好区域搜索，但少数困难问题差异不显著。
- Proof of concept：
  - 与 FRS 相同的 DTLZ2 / 3 objectives / `alpha=inf` 设置。
  - ERS 运行 5000 evolutionary steps，tournament size 2，crossover/mutation rescaling 均为 0.1。
  - ERS 生成的 compatible weight vectors 更均匀。
  - Nearest compatible weight distance：FRS 为 0.0073，ERS 为 0.0157。
  - Sampling success rate：FRS 为 4.80%，ERS 为 78.00%。
- Standalone sampler 实验：
  - 比较 ERS 与 FRS，不嵌入 EMO。
  - 变量：`M=2,3,4,5`；`alpha=1,5,inf`；目标 compatible model 数 `N=50,100,150,200`；pairwise comparison 数 `H=1..10`。
  - 每个配置 100 次 paired runs，总计 96,000 次 sampler runs。
  - 指标：TIME、ITER、success rate、NCM、MIN-CN、STD-CN。
  - 困难例子中，线性 DM、`M=5,N=200,H=5` 时，ERS 约 25 ms 达到目标，而 FRS 约 300 ms。
  - `H=10` 时 FRS 在 500 ms 内无法达到 `N=200`，ERS 仍能扩展。
  - 对 `alpha=1,M=5,H=10`，FRS TIME 约 334.045 ms，ERS 约 7.484 ms。
  - FRS TIME 范围约 0.107-733.056 ms，ERS 约 0.746-9.549 ms。
  - FRS success rate 范围约 0.22%-33.98%，ERS 约 29.71%-89.31%。
  - ERS 在所有 runs 中都生成目标数量 compatible models；FRS 在困难设置中经常失败。
  - 终止时 ERS 的 MIN-CN 平均约为 FRS 的 40 倍，STD-CN 约为 FRS 的 1/10，且 paired t-test 与 Wilcoxon 检验显著。
- 嵌入 IEMO/D：
  - 将 ERS 或 FRS 作为 IEMO/D 的 preference-disaggregation procedure。
  - 测试 DTLZ1-7、WFG1-9、ZDT1-6。
  - `M=2,3,4,5`，人工 DM 使用 `alpha=inf`，最多 10 次交互，每次交互后 100 generations adaptation。
  - 指标包括 GD、BS、AS 和 HV；主文集中报告最终 generation 的 HV。
  - DTLZ2 示例中，两者都会收缩到 DM 偏好区域，但 ERS 的 population spread 更好，所有快照 HV 都更高。
  - 全部问题平均 rank：ERS 为 1.22，FRS 为 1.78。
  - ERS 在绝大多数配置上优于 FRS；少数困难问题如 DTLZ6、WFG6、WFG9 等只表现为接近或差异不显著。
  - 论文强调没有任何配置中 FRS 显著优于 ERS。

## 复杂度与实现成本

- Compatibility degree 计算复杂度为 `O(MH)`。
- 初始化阶段主要包括：
  - 计算 `cd`：`O(NMH)`；
  - compatible models 的距离和 neighbor 更新：最坏涉及 `O(N^2K)`；
  - 排序：`O(N log N)`。
- Evolution 阶段每次生成一个 offspring，并可能更新 similarity matrix 和受影响 neighbor arrays。
- 论文给出 ERS 总复杂度表达式，并指出 `LN^2K` 项在实践中通常呈现 sub-quadratic 行为，因为受影响模型子集较小。
- 实现要求：
  - 能计算模型 compatibility；
  - 能定义模型间距离；
  - 能在模型参数空间中设计可行 crossover/mutation；
  - 需要维护 queue、nearest-neighbor arrays 和 similarity matrix。

## 局限与未来工作

- 作者明确说明的未来方向：
  - 检验 ERS 对 `L_{w,alpha}`-norm 之外模型族的适用性，如 additive value functions 或 relational model 的 scoring functions。
  - 动态自适应 ERS 算子参数，例如在偏好空间已强约束时偏 exploitation，在约束弱时偏 exploration。
  - 与最大化 DM feedback information gain 的交互策略结合，加速偏好学习。
  - 应用于 green supply chain design 和 political redistricting 等真实复杂问题。
- 我们的判断/仍需确认的问题：
  - 实验使用人工 DM，不等价于真实人类偏好反馈。
  - 不一致偏好处理不在本文范围内，而真实 DM 反馈可能前后矛盾。
  - 虽称 model-agnostic，但每类模型仍需定义距离和专用 reproduction operators。
  - 主实验以 `L_{w,alpha}`-norm 为中心，其他 MCDA 模型族的证据还不足。
  - 在困难 PF 上，ERS 更好的模型采样也可能被 IEMO/D 搜索能力限制，不能完全转化为最终 HV 优势。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：兼容偏好模型的进化均匀采样。它将 preference disaggregation 从被动拒绝采样改造成一个兼顾 compatibility 与 diversity 的进化采样层，可插入 IEMO/D、NEMO 或其他交互式 EMO。
- 暂留在论文卡中的方法、原理或架构启发：
  - Pairwise comparison 约束越多，兼容空间越小，纯 Monte Carlo 越浪费；此时需要把 compatible boundary 当作搜索目标。
  - Robust preference exploitation 不应只找一个代表模型，而要保留一组分布均匀的兼容模型。
  - 模型采样质量会影响后续 scalarizing directions，从而影响 population spread。
- 局部创新线索：
  - 用 active learning 选择下一对待比较解，让兼容模型空间最快收缩。
  - 将 ERS 的 queue sorting 扩展为三目标：compatibility、diversity 和 model uncertainty。
  - 对不同偏好模型族自动学习 reproduction operators，例如 normalizing-flow proposal 或 manifold mutation。
  - 在 group decision making 中为多个 DM 分别维护 compatible model queues，再求共识或冲突解释。
