# A learning-driven artificial bee colony algorithm for mobile robot multi-objective path planning

## 一句话理解

本文提出 LBABC：面向二维静态环境中的移动机器人三目标路径规划，在 ABC 的 initialization / employed / onlooker / scout 四个位置分别嵌入竞争式可行路径初始化、路径版差分进化、Q-learning 路径算子选择和自适应重启，用学习反馈替代固定或随机算子选择。

## 问题与动机

- 研究对象：mobile robot multi-objective path planning。
- 路径表示：从 start point 到 target point 的二维点序列，包含可变数量中间点。
- 三个优化目标均按最小化处理：
  - path length：影响执行时间；
  - path safety：用路径段到障碍物的最近距离表示，文中转为最小化指标；
  - path smoothness：由连续路径段的最大角度偏差刻画，关联能耗和运动平稳性。
- 约束：路径不能与障碍物或工作空间边界碰撞。
- 现有方法不足：
  - weighted-sum 路径规划需要预设目标权重，容易偏向某一目标；
  - 传统 metaheuristics 常依赖固定算子和人工参数；
  - 随机扰动和随机重启缺少问题知识；
  - 已有 Pareto-based 方法缺少随搜索状态调整算子和处理停滞个体的机制。

## 核心算法 LBABC

- Initialization phase：
  - 使用 competition-based initialization strategy；
  - 结合 spatial segmentation 和 RRT 生成候选路径；
  - 以等概率竞争方式保留在 path length、safety、smoothness 上表现好的路径；
  - 目标是在初始种群中同时获得全局可行性、局部方向多样性和目标空间平衡。
- Employed bee phase：
  - 用 differential evolution strategy 替代原 ABC 的随机邻域更新；
  - 从 non-dominated solution set 中选择在特定目标上表现好的 elite paths；
  - 通过路径级 differential mutation、path crossing 和 dominance selection 生成并筛选新路径。
- Onlooker bee phase：
  - 对 non-dominated solutions 执行 Q-learning-based evolutionary operator selection；
  - 每个 non-dominated solution 视为一个 agent；
  - 所有 agents 共享 Q-table；
  - 动作是六个路径算子；
  - reward 来自新旧路径之间的 Pareto dominance 关系。
- Scout bee phase：
  - adaptive evolutionary restart strategy 只处理长时间未改善的 dominated solutions；
  - 早期更偏向 RRT 生成新的 collision-free path；
  - 后期逐渐提高 path crossing 的使用频率，复用已有高质量路径片段。

```text
competition initialization by segmentation + RRT
-> DE-style employed bee global exploration
-> non-dominated / dominated split
-> Q-learning operator selection on elite paths
-> adaptive restart for stagnant dominated paths
-> Pareto path set
```

## Q-learning 算子选择

- 状态定义：
  - 对每个 non-dominated solution，分别比较 path length、safety、smoothness 与当前 non-dominated set 中对应目标的平均值；
  - 每个目标被离散为 better / worse 两种状态；
  - 三个目标组合成 8 个状态。
- 动作集合：
  - path crossing；
  - path mutation；
  - path insertion；
  - polymorphic path shortening；
  - path safety；
  - path smoothness。
- 奖励：
  - 新路径支配旧路径：`+1`；
  - 新旧路径互不支配：`0`；
  - 新路径被旧路径支配：`-1`。
- 策略：
  - 使用随时间增加的 greedy / exploitation probability；
  - 早期保留更多随机探索；
  - 后期更倾向选择当前状态下 Q-value 最大的算子。
- 作用：
  - 让不同目标短板的路径选择更合适的局部修复算子；
  - 抑制长期无效算子；
  - 在 elite front 周围提高局部搜索效率。

## 路径专用算子

- Differential mutation：
  - 基于两个高质量路径之间的最小距离信息构造差分方向；
  - 对当前路径的中间点做细粒度更新；
  - 用 collision detection 过滤不可行路径。
- Path crossing：
  - 交换两个路径的有效子段；
  - 生成候选路径后根据 dominance 选择更优者。
- Path mutation：
  - 在当前路径邻域生成新点，探索局部空间。
- Path insertion：
  - 插入新的路径点，提高路径结构灵活性和多样性。
- Polymorphic path shortening：
  - 删除冗余中间点；
  - 同时检查前后多个点的可通过性，尽量缩短路径且保持可行。
- Path safety：
  - 找到离障碍物最近的路径点并向外调整。
- Path smoothness：
  - 找到曲率最大的点并调整，以降低急转弯。

## 自适应重启

- 触发对象：stagnation counter 达到阈值的 dominated solutions。
- 重启方式 1：
  - 从三个目标上表现最好的高质量路径中选两条；
  - 使用 path crossing 生成新路径；
  - 保留有效路径片段，强化 exploitation。
- 重启方式 2：
  - 用 RRT 生成 3 条全局 collision-free paths；
  - 选择其中最好的路径；
  - 注入未探索区域信息，强化 exploration。
- 自适应调度：
  - 早期偏向 RRT，扩大可行空间探索；
  - 后期偏向 path crossing，利用已有 Pareto front 附近的结构信息。

## 实验设置

- 环境：
  - 4 张二维地图，每张为 `500 x 500` pixels；
  - Map 1 为对称障碍环境；
  - Map 2 为复杂迷宫；
  - Map 3 和 Map 4 来自 MovingAI benchmark；
  - 每张地图设置 SD、MD、HA、VA 四个 start-target 方向，共 16 个实例。
- 对比算法：
  - IMO-ABC；
  - MOEA；
  - INSGA-II；
  - FIMOPSO；
  - BBPSO；
  - IDE；
  - ExtIPA。
- 公平设置：
  - 所有算法用 MATLAB 实现；
  - CPU 为 Intel Core i7 3.4 GHz，16 GB RAM；
  - 固定运行时间 50 s；
  - 每个实验独立运行 30 次；
  - 部分对比算法原目标数不同，作者将其目标元组调整为本文的三目标。
- 指标：
  - HV；
  - NNS；
  - RNS；
  - IGD；
  - SC；
  - Spread `Delta`。
- 参数调优：
  - Taguchi `L16(4^3)` 正交实验调节 population size `ps`、learning rate `alpha` 和 discount rate `gamma`；
  - 最优设置为 `ps=50`、`alpha=0.3`、`gamma=0.7`；
  - restart threshold `trialmax=10`。

## 主要结果

- Abstract 总结：
  - 相比第二优算法，LBABC 在 HV 上平均提升 1.37%；
  - 在 IGD 上平均提升 40.74%。
- HV：
  - LBABC 在 16 个实例上全部取得最高 HV；
  - 平均 HV 为 `0.7098`，高于第二名 ExtIPA 的 `0.7003`。
- NNS / RNS：
  - NNS 上 LBABC 在 13/16 个实例中最高；
  - RNS 上 LBABC 在 15/16 个实例中最高；
  - 作者认为即使个别实例 INSGA-II 或 IDE 的某项更高，LBABC 的非支配解质量整体更好。
- IGD：
  - LBABC 在 16 个实例上全部取得最低 IGD；
  - 平均 IGD 为 `0.32`，优于其他七个算法。
- SC：
  - 112 个 pairwise comparisons 中，LBABC 有 110 个最优；
  - 两个退化案例出现在 Map 1 的 VA 方向，作者认为密集威胁和多条等距通道可能使贪婪搜索偏向局部最优。
- Spread：
  - LBABC 在 16 个实例中全部取得最小 `Delta`；
  - 平均 `Delta` 为 `0.68`，说明分布更均匀。
- 效率：
  - LBABC 在 50 s 内迭代次数最少，说明机制成本较高；
  - 但在同等 50 s 和同等 1000 iterations 下均取得最高 HV。

## 消融与组件贡献

- Competition-based initialization：
  - 去掉后变为 `LBABC_NI`；
  - LBABC 在 16 个实例上 HV 全部更优；
  - 平均 RPI 从 `0` 对比 `2.48`；
  - ANOVA p-value 为 `0.0002`。
- Differential evolution strategy：
  - 去掉后变为 `LBABC_NE`；
  - LBABC 在 16 个实例上 HV 全部更优；
  - `LBABC_NE` 平均 RPI 为 `2.00`；
  - ANOVA p-value 为 `1.9467e-12`。
- Q-learning operator selection：
  - 用随机策略替代后变为 `LBABC_NQ`；
  - LBABC 在 16 个实例上 HV 全部更优；
  - `LBABC_NQ` 平均 RPI 为 `2.68`；
  - ANOVA p-value 为 `3.6756e-5`。
- Adaptive restart：
  - 去掉后变为 `LBABC_NA`；
  - LBABC 在 16 个实例上 HV 全部更优；
  - `LBABC_NA` 平均 RPI 为 `16.62`；
  - ANOVA p-value 极小，原文 OCR 为 `1.2747 x 10^-15` 附近。
- Tukey test：
  - adaptive evolutionary restart 和 Q-learning operator selection 是最显著组件；
  - competition-based initialization 次之。

## 与知识库相关的设计知识

- 更新已有设计知识：
  - `K-drl-state-driven-evolutionary-operator-selection`：状态驱动的 DRL 演化算子选择。
- 本文作为该知识的新证据：
  - 状态不是全局种群统计，而是每个 elite path 相对当前 non-dominated set 的三目标短板；
  - 动作是路径规划专用的六个局部算子；
  - reward 直接用 Pareto dominance；
  - Q-table 在 non-dominated solutions 之间共享。
- 与已有证据的区别：
  - 不同于 P2026-0042 的 GA/DE DQN 选择：本文是 tabular Q-learning，动作是路径级局部修复算子；
  - 不同于 P2026-0244 的 CHT+遗传算子联合选择：本文没有选择约束处理技术，而是选择路径结构编辑算子；
  - 不同于 P2026-0020 的 critical-path/block 调度邻域选择：本文的状态由路径三目标相对均值形成，动作直接修复路径长度、安全和光滑性；
  - 不同于 `K-winner-mapping-dendrite-guided-bee-offspring`：本文不学习劣解到优解的映射，而是学习当前状态下哪个路径算子更值得调用。

## 局限与未来工作

- 局限：
  - LBABC 缺少 path re-planning 或 local planning 机制，难以处理动态环境；
  - 多目标路径规划只验证在二维环境；
  - 未涉及高维环境下的个体演化。
- 未来工作：
  - 加入 environment-aware 和 online re-planning 模块；
  - 发展可扩展到高维空间的个体演化策略；
  - 研究多机器人多目标路径规划。
- Data availability：Data will be made available on request。
