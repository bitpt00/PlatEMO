# Large-Scale Multi-Objective Sensor-Weapon-Target Assignment Optimization: Benchmark Suites and Knowledge-Driven Heuristics

## 一句话理解

论文提出 SWTA MOP1-5 作为大规模多目标 sensor-weapon-target assignment benchmark，并给出两个可插拔启发式：用每个目标的可拦截 sensor-weapon 组合矩阵做稀疏初始化，优先丢弃不可拦截目标；再在子代评价前用同一矩阵修复不可行 sensor-weapon 组合，从而把极稀疏可行域中的随机搜索改成“先验可行组合过滤 + 随机多样修复”。

## 问题与动机

- 研究对象：large-scale multi-objective sensor-weapon-target assignment (LSMO-SWTA)。
- 核心难点：
  - 决策变量维度随 target 数增长，本文编码为 `3 * NK`，每个目标一行 `[sensor, weapon, time]`；
  - sensor/weapon/target 组合空间指数膨胀；
  - 严格时空约束让可行域极稀疏且碎片化；
  - 现有 SWTA 多聚焦中小规模或双目标，常简化 launch time、flight delay 和资源占用等时空约束；
  - 常规 CHT 和大规模 MOO 的变量分组/降维可能破坏 SWTA 中强耦合的可行结构。
- 作者希望解决两件事：
  1. 建立更高保真、可扩展、可配置目标数和规模的 SWTA benchmark；
  2. 证明简单领域知识若在初始化和 repair 层使用，可显著提升多类 CMOEA/LSCMOEA/SWTA 算法。

## Benchmark 建模要点

- 场景：
  - Centralized attack：多个目标集中攻击单个 protected asset；
  - Decentralized attack：目标分散攻击多个 protected assets。
- 简化假设：
  - 二维平面；
  - targets 和 weapons 做匀速直线运动；
  - sensors 和 weapon vehicles 在交战期保持静止。
- 决策编码：
  - 每个目标 `k` 用唯一 tuple `[i_k, j_k, t_k]` 表示；
  - `i_k` 为 sensor，`j_k` 为 weapon vehicle，`t_k` 为 interception moment；
  - 任一分量为 `0` 表示放弃拦截该目标；
  - 每个 target 最多被拦截一次。
- 四个可配置目标：
  1. expected remaining interception value，越小越好，相当于尽量拦截高价值目标；
  2. resource cost，包含 sensor tracking cost 和 weapon usage cost；
  3. timeliness，用 makespan 衡量拦截完成时间；
  4. operational risk，通过分散使用 sensors/weapons 降低单点资源失效风险。
- 三类约束：
  - Target-related：每个目标最多一次拦截，且 hit time 不超过 flight period；
  - Sensor-related：sensor channel capacity 和目标持续检测 channel demand；
  - Weapon-related：weapon vehicle capacity 和同一 weapon vehicle 连续发射间隔。
- SWTA MOP1-5：
  - MOP1：linear、loosely constrained、low ruggedness、discrete，作为理性资源分配基线；
  - MOP2：加入 target spatial distribution；
  - MOP3：加入 sensor detection probability 非线性；
  - MOP4：加入 weapon interception probability 非线性；
  - MOP5：完整使用提出的实例生成方法，coupled nonlinear、severely constrained、high ruggedness、discrete。
  - 可扩展参数包括 target 数 `NK`、sensor 数 `NS`、weapon vehicle 数 `NV`、sensor channel capacity `Cmax` 和 weapon capacity `Nmax`。

## 核心方法：知识驱动启发式

- Domain knowledge 的定义：
  - 对每个 target `k` 构造 `NS x NV` 的 knowledge matrix `KM_k`；
  - 若 sensor `i` 与 weapon `j` 可以组合拦截 target `k`，`KM_k(i,j)=1`；
  - 否则 `KM_k(i,j)=0`；
  - 该矩阵用于在评价前过滤明显不可行的资源组合。
- Knowledge-driven sparse initialization (KDSI)：
  1. 对每个 target 枚举 sensor-weapon 组合，构造 `KM_1,...,KM_NK`。
  2. 计算每个初始个体的 sparsity `s_i`，即要丢弃的 target 数。
  3. 找出所有不可拦截 target：若 `sum(KM_k)=0`，target `k` 属于 non-interceptable target set。
  4. 为每个初始解构造 `NK x 3` sparse matrix `SM_i`：
     - 若不可拦截目标数 `Nu >= s_i`，从不可拦截 targets 中随机选 `s_i` 个；
     - 若 `Nu < s_i`，先选全部不可拦截 targets，再从可拦截 targets 中随机补足；
     - 对被选 target 的一行随机置零一个分量，使该 target 被视为 discarded。
  5. 用 `p_i' ⊙ SM_i` 修改原始随机初始解，形成稀疏初始种群。
  6. 论文采用 linear sparsity，使初始种群覆盖不同资源消耗水平。
- Knowledge-driven infeasible repair (KDIR)：
  1. 对每个 offspring solution 的每个 target row 取出当前 `(i_k,j_k)`。
  2. 若 `KM_k(i_k,j_k)=1`，保留。
  3. 若为 0，则从 `KM_k` 中取所有 feasible combinations `Q`。
  4. 若 `Q` 非空，随机选一个可行 `(i*,j*)` 替换当前 sensor-weapon 组合。
  5. 若 `Q` 为空，则随机把 sensor 或 weapon 置 0，相当于放弃该 target。
  6. Repair 在 function evaluation 前执行，不调用目标或约束函数；因此与后续 CHT 解耦，可作为通用 plug-in。

## 实验证据

- 实验设置：
  - Benchmark：SWTA MOP1-5，中央/分散攻击模式，2/3/4 objectives，不同规模，共 162 个 test instances。
  - 对比算法：NSGAII-CDP、C3M、CAEAD、CCMO、MTCMO、MTOTC、POMBDE、DSSEA。
  - 每个算法都有 discrete/original variant 和 knowledge-driven variant；KD 版本嵌入 KDSI + KDIR。
  - PlatEMO 实现；
  - `MaxFE = 50 * NK`；
  - 每个算法 20 independent runs；
  - 指标：HV、Feasibility Rate (FR)、Computational Time (CT)；
  - Wilcoxon rank-sum test，significance level `0.05`。
- 综合比较：
  - Centralized SWTA MOP1-5 上，KD variants 相比 discrete variants 的 `+ / approx / -` 汇总为：
    - KD-NSGAII-CDP `79/6/5`；
    - KD-C3M `87/2/1`；
    - KD-CAEAD `86/3/1`；
    - KD-CCMO `86/1/3`；
    - KD-MTCMO `82/4/4`；
    - KD-MTOTC `89/1/0`；
    - KD-POMBDE `79/8/3`；
    - KD-DSSEA `81/4/5`。
  - Decentralized SWTA MOP2-5 上，对应汇总为：
    - `61/3/8`、`70/1/1`、`67/3/2`、`65/5/2`、`62/1/9`、`71/1/0`、`65/5/2`、`69/2/1`。
  - 综合 162 个实例，KD variants 达到最佳性能的比例分别为 `86.4%`、`96.9%`、`94.4%`、`93.2%`、`88.9%`、`98.8%`、`88.9%`、`92.6%`。
  - 作者指出目标数增加时，knowledge-driven variants 的优势更明显。
- KDSI 消融：
  - 在 SWTA MOP5 的 12 cases 上，八个 KD algorithms 与 random-initialized counterparts 比较，KDSI 带来 `95/96` 次显著改进。
  - Table V 中除 KD-POMBDE 为 `11/1/0`，其余七个算法均为 `12/0/0`。
  - 与 RAN、LHS、OBL 初始化接入 NSGA-II-CDP 比较，KD-NSGAII-CDP 在 12 个 cases 上均 ranking first；RAN/LHS/OBL 相对 KD 均为 `12/0/0` 显著更差。
  - Fig. 6 显示 KD 初始化的 HV 起点明显更高，RAN/LHS/OBL 初始 HV 接近 0，需要更多代才满足约束。
- KDIR 消融：
  - 与去掉 repair 的 WR variants 比较，Table VI 显示八个算法在 12 cases 上均为 `12/0/0`，总计 `96/96` 次显著优势。
  - 与 Submodel-guided Repair (SR)、Neighborhood-based Repair (NR)、Opposition-based Repair (OR) 接入 NSGA-II-CDP 比较，KD-NSGAII-CDP 几乎所有 cases 最高 HV，平均 rank 为 1；SR/NR/OR 平均 rank 分别约 `2.92`、`2.67`、`3.42`。
- 证据边界：
  - 完整 HV/FR/CT 和 162 实例的具体数值多在 supplementary，主文只给汇总表和少量案例曲线。
  - 论文说明 source code for benchmark generation and knowledge-driven methods is available online，但当前卡片未独立验证链接状态。

## 局限与未来工作

- 作者明确局限：
  - 未考虑 multiple sensors for relay detection；
  - 未考虑 multiple weapons for sequential interception；
  - fixed-length discrete encoding 在 very large-scale instances 上可能遇到 scalability bottleneck；
  - 当前 domain knowledge 只到 target level，未来希望利用 target 和 interception scheme level knowledge；
  - 未来可设计 dynamic multi-objective SWTA test problems，因为真实作战环境变化后 assignment 需要调整。
- 我们认为仍需确认的问题：
  - 可拦截矩阵只过滤 sensor-weapon 组合，仍不能保证 time/channel/capacity/firing interval 等全局约束可行；
  - 随机 repair 虽保留多样性，但可能反复修出资源冲突，需要与全局约束修复或局部搜索结合；
  - 当知识矩阵有误或环境变化导致可拦截关系变化时，强先验可能误删可行结构；
  - fixed-length `[i,j,t]` 对超大规模目标会产生大量零行，可能需要 variable-length 或 target subset encoding；
  - 该方法在非 SWTA 的任务-资源组合问题中，需要明确什么是“可行组合矩阵”以及它与全局约束的边界。

- 值得建立或补充的设计知识：

- 与已有设计知识的关系：
  - 不同于[结构启发初始化与多目标路径重联](../02_design_knowledge/K-structure-aware-initialization-multiobjective-path-relinking.md)：旧卡侧重结构化初始解和精英路径中间解；本卡侧重用可行组合矩阵在初始化和 evaluation 前做硬过滤/修复。
  - 不同于[业务偏好约束的多段染色体搜索](../02_design_knowledge/K-business-constrained-multipart-chromosome-search.md)：旧卡将业务目标转为 epsilon 阈值并设计多段染色体；本卡处理的是编码行内部任务-资源组合是否物理可行。
  - 可与[时段分解随机拼接的约束调度搜索](../02_design_knowledge/K-temporal-block-decomposition-random-concatenation-cmoea.md)互补：时间块拼接后，可用可行组合矩阵先修复局部任务-资源 pair，再处理跨块约束。
- 局部创新线索：
  - 将 binary `KM_k` 扩展为概率/置信度矩阵，兼顾不确定感知和鲁棒 assignment。
  - Repair 时不随机选可行 pair，而按资源负载、目标价值、时间余量或历史 survival rate 加权选择。
  - 初始化 sparsity 不用线性规则，而由资源容量、不可拦截比例和目标价值分位数自适应决定。
  - 对全局约束再维护二级 repair：先矩阵修 row feasibility，再修 channel/capacity/time conflicts。
  - 对动态场景用快速更新的 `KM_k(t)`，环境变化后只重修受影响 rows。
- 结构创新线索：

```text
domain feasibility oracle
-> per-task feasible combination matrix
-> sparse / resource-level initialization
-> pre-evaluation row repair
-> ordinary CHT handles remaining global constraints
-> MOEA searches trade-offs with much higher feasible hit rate
```

创新线索只需简短记录，不创建创意卡。单篇论文抽象出的原理和架构思路默认留在本节，不立即建立设计知识卡。
