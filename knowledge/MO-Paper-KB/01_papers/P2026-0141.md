# An adaptive coevolutionary resource assignment algorithm for constrained multi-objective optimization

## 一句话理解

论文提出 ARACMO：先用无约束辅助种群靠近 UPF 并把 offspring 共享给主种群和单约束辅助种群，随后丢弃无约束种群，按各约束当前 CV 难度给对应辅助种群分配不同 offspring 资源，并在辅助种群趋稳后按约束相似性逐步合并，从而让多约束 CMOP 的协作预算集中到更关键、更互补的约束信息上。

## 问题与动机

- 研究问题和场景：
  - constrained multi-objective optimization problems (CMOPs)；
  - feasible region 可能 narrow、irregular、disconnected，且由多个 constraints 的交集形成；
  - 不同 constraint 对 CPF 形成的影响和处理难度不同。
- 现有算法为什么不足：
  - CDP / feasibility-first 方法简单，但在初始种群全不可行或窄可行域时选择压力弱，且易早熟；
  - epsilon、penalty、stochastic ranking 等方法依赖阈值或参数，仍可能在复杂约束景观中偏向局部可行区；
  - PPS、ToP 等多阶段方法常依赖固定代数或简单改善率切换，切换过早/过晚都会浪费预算；
  - CCMO、C-TAEA 等长期维护无约束辅助种群，UPF 远离 CPF 时后期贡献会衰减；
  - MCCMO 等单约束多辅助种群默认各约束同等重要，约束多时计算开销大，且相似约束会重复消耗资源。
- 本文希望解决什么：
  - 先利用无约束 UPF 信息跨越 infeasible barriers；
  - 再从“泛化无约束辅助”切换到“约束特异辅助”；
  - 对更难或更关键的约束分配更强 coevolutionary resource；
  - 把相似约束合并成 sub-constraints，减少冗余并提供更深层约束信息。

## 核心理念与算法流程

- ARACMO 顶层结构：
  - 初始化一个无约束种群 `P1`；
  - 主种群 `P` 求解原始 CMOP；
  - 为每个 constraint 初始化一个辅助种群 `SP_i`，只按对应 constraint 或 sub-constraint 选择；
  - 算法分为 exploration stage 和 exploitation stage。
- Exploration stage：
  - 只有 `P1` 参与 reproduction，用 GA 生成 `N` 个 offspring `Off1`；
  - `P1` 用无约束 MOP 环境选择更新；
  - `P` 接收同一批 `Off1`，按所有 constraints 选择；
  - 每个 `SP_i` 也接收同一批 `Off1`，按自己的单约束选择；
  - 用 `P1` 的 ideal point、nadir point、mean point 在窗口 `l` 上做曲线拟合，取三者 fitting degree 的最小值 `Fit_t` 判断无约束种群是否趋稳；
  - 若 `Fit_t > delta`，或 FEs 超过 `phi * MaxFEs`，进入 exploitation stage；正文给 `phi=20%` 作为保护性上限。
- Exploitation stage：
  - 不再维护 `P1`，因为无约束 UPF 信息可能后期冗余；
  - 主种群 `P` 用 GA 生成 `N` 个 offspring；
  - CWA 根据当前所有辅助种群在各约束上的 CV 难度得到权重 `W=(w1,...,wS)`；
  - 每个 `SP_i` 只选择约 `N * w_i` 个 mating parents，并用 DE 生成 `N * w_i` 个辅助 offspring；
  - 主群 offspring 和所有辅助 offspring 合并为共享集合 `Off`；
  - `P` 和所有 `SP_i` 都用 `Off` 更新，但各自按原始 CMOP 或对应 sub-constraint 做环境选择；
  - CCM 在辅助种群趋稳后选择性合并相似 constraints，并更新 sub-constraint 与辅助种群数量。
- CWA 约束权重：
  - 构造 constraint violation matrix `V`，覆盖 `S` 个辅助种群、每群 `N` 个体和 `C` 个 constraints；
  - 对每个 constraint 的 CV 列做 min-max normalization；
  - difficulty `totalcv_j` 由该约束归一化 CV 总和得到，weight `w_j = totalcv_j / (sum_j totalcv_j + epsilon)`；
  - 合并后对 sub-constraint 计算权重时，用组内 constraints 的最大 CV 表示该 sub-constraint 的违反程度。
- CCM 约束合并：
  - 当所有辅助种群 fitting degree 都超过 `delta`，说明当前 sub-constraint 信息已趋稳；
  - 前期 weak combination：优先选低权重约束，因为低重要性辅助种群贡献较小，合并后可减少冗余；
  - 中期 strong combination：开始合并高权重约束，以挖掘更深层、组合约束信息；
  - 后期 all combination：把所有 constraints 合并为原始 CMOP；
  - constraint similarity 用归一化 CV 列向量的 cosine similarity；只有不同 sub-constraint 且相似度超过 `delta_similar` 的最相似约束才合并。
- 可能被修改的位置：
  - `Fit_t` 的阶段切换指标；
  - CWA 中 difficulty 是否只用 CV 总和；
  - `N * w_i` 的取整和最小资源下限；
  - GA/DE 在主群/辅群中的分工；
  - CCM 的 weak/strong/all 时间边界；
  - similarity 是否使用 CV 向量、可行模式、active set 或目标贡献。
- 必须保留的核心：
  - 先用无约束种群探索 UPF，后期转向 constraint-specific auxiliary populations；
  - 约束辅助种群不是等资源，而是按当前约束难度动态分配 offspring 资源；
  - 相似或冗余 constraints 要能合并，否则多约束辅助种群会膨胀；
  - 主种群和辅助种群通过共享 offspring 互相注入信息，但各自保留不同 constraint selection pressure。

## 实验证据

- 实验设置：
  - 平台：PlatEMO 4.3；
  - 对比算法：CCMO、C-TAEA、PPS-MOEA/D、C3M、MCCMO；
  - test suites：DASCMOP、C-DTLZ/DC-DTLZ、LIRCMOP、MW；
  - population size `N=100`；
  - MaxFEs：DASCMOP 和 LIRCMOP 为 `300000`，DTLZ 和 MW 为 `100000`；
  - 每个算法 30 次独立运行；
  - 指标：IGD 和 HV，Wilcoxon rank-sum test `0.05`；补充材料给 Friedman test；
  - 主群使用 SBX + polynomial mutation，辅助群使用 DE + polynomial mutation；DE 的 `CR=1`、`F=0.5`。
- DASCMOP：
  - DASCMOP 同时考验 feasibility、convergence、diversity；
  - ARACMO 在多数实例上取得最佳 IGD，并且 Table 2 的 HV 结果与 IGD 一致；
  - 作者归因于 CWA 将协作强度分配给关键 constraints，使辅助信息更精确。
- C-DTLZ / DC-DTLZ：
  - ARACMO 在 4 个 C-DTLZ 问题上均取得最佳结果；
  - 在 DC-DTLZ 中除 DC2-DTLZ3、DC3-DTLZ3 外表现最佳；
  - DC2-DTLZ3 和 DC3-DTLZ3 具有 multimodal、disconnected CPF，CCMO 因 SPEA2 truncation 多样性更强而优于 ARACMO；
  - 作者认为 ARACMO 的辅助群 DE 在这两个问题上收敛速度偏慢。
- LIRCMOP：
  - ARACMO 在 14 个 LIRCMOP 中 9 个取得最佳；
  - LIRCMOP1-4 的 feasible region 极窄，PPS 的 epsilon pull stage 更有优势；
  - LIRCMOP7、LIRCMOP8、LIRCMOP14 中 CPF 与 UPF 完全分离，ARACMO 明显更好，作者归因于 CWA 给关键约束更多资源；
  - Table 4 的 HV 也显示 ARACMO 在 14 个中 9 个最佳。
- MW：
  - MW 每个问题 feasible rate 小于 `0.1%`，且不少问题有 disconnected feasible regions / PF；
  - ARACMO 在 14 个 MW 问题中 10 个最佳；
  - MW1 上 CCMO 最好但差异不显著；
  - MW2、MW6、MW10 上 C-TAEA 稍优，作者归因于 MOEA/D-M2M partitioning 有利于 corner narrow feasible regions；
  - 作者强调 CCM 在 MW 中帮助减少冗余并提高分布。
- 可视化和统计：
  - Fig. 5 中 ARACMO 在 DASCMOP9、LIRCMOP14、LIRCMOP12 上的非支配解更密、更连续；
  - Supplementary Wilcoxon 统计：IGD 上 ARACMO 分别显著优于 CCMO、PPS、C-TAEA、C3M、MCCMO 的问题数为 `37, 43, 39, 39, 24`；
  - HV 上对应显著优胜数为 `38, 42, 38, 40, 25`；
  - Friedman test 显示 ARACMO 在四套测试上平均 rank 最低。
- 复杂度与运行时间：
  - ARACMO worst-case complexity 为 `O(C*M*N^2) + O(C^2*N)`；
  - 其中环境选择主项来自 `C` 个辅助群、一个主群和一个无约束群，CWA 与 constraint similarity 带来 `C^2` 项；
  - ARACMO 通常比 PPS、C3M、CCMO 慢，但比 MCCMO 和 C-TAEA 更高效；
  - 相比 MCCMO 的 `O(C^2*M*N^2)`，ARACMO 用 CWA/CCM 避免所有子种群 offspring 的二次合并开销。

## 局限与未来工作

- 作者明确说明的局限：
  - 在极复杂 CMOP，尤其 extremely narrow feasible regions 中，辅助种群也可能难以找到 sub-feasible regions 的交集；
  - 为窄/离散可行域使用 DE 辅助群，但在大 objective space 且可行区域有限的问题上可能收敛较弱；
  - CCM 的阶段安排较僵硬：前 1/3 合并弱约束，中 1/3 合并强约束，后 1/3 合并全部约束；
  - threshold 对 stage switching 有影响，相关参数分析放在 Supplementary。
- 我们认为仍需确认的问题：
  - CWA 用 CV 总和表示 constraint importance，是否会高估“违反大但容易修复”的约束；
  - `N*w_i` 是否需要最小资源保障，避免低权重约束长期无 offspring；
  - 相似 constraints 用 CV column cosine 是否能识别目标空间互补但 CV 模式相似的约束；
  - 合并后用组内 max CV 是否过于保守；
  - 无约束 UPF 远离 CPF 时，exploration stage 的共享 offspring 是否可能对某些辅助群产生负迁移；
  - 论文缺少显式 CWA-only、CCM-only、switch-only 的主文消融，机制归因主要来自讨论和补充统计。

- 与已有设计知识的边界：
  - 不同于 [EID 动态约束优先级与协作子代生成](../02_design_knowledge/K-eid-dynamic-constraint-priority-cooperative-offspring.md)，本文不是按约束优先级逐个处理并维护 constraint archives，而是并行维护多个 constraint auxiliary populations，并按 CV 难度分配 offspring 资源、按相似性合并 sub-constraints；
  - 不同于 [UPF 参照的动态逃逸种群](../02_design_knowledge/K-upf-referenced-dynamic-escaping-population.md)，本文早期用 UPF 种群提供共享 offspring，后期不做 objective-only escape，而是转向 constraint-specific exploitation；
  - 不同于 [支配-分解双框架协同与阶段切换](../02_design_knowledge/K-dominance-decomposition-coevolution-stage-switching.md)，本文不是 dominance/decomposition 两框架互补，而是按 constraints 分解辅助任务；
  - 不同于 [趋势-正交互补的双群约束搜索](../02_design_knowledge/K-trend-orthogonal-dualswarm-constrained-search.md)，本文传递的是不同约束辅助群产生的 offspring，而不是主群收敛方向和正交补方向；
  - 不同于 [贡献自适应的多种群多目标协同](../02_design_knowledge/K-contribution-adaptive-mpmo-coevolution.md)，本文调度对象是 constraint auxiliary populations，而不是按目标划分的 MaOP 子种群。
- 暂留在论文卡中的方法、原理或架构启发：
  - stage switch 的 ideal/nadir/mean curve fitting 可与其它 UPF-to-CPF 切换论文共同整理，当前先留在论文卡；
  - 主群 GA、辅群 DE 的算子分工不是独立创新核心，暂不单独成卡；
  - PDF 中 CWA 指数 `1/(1+C)` 的具体平滑作用需要代码复核后再拆出细节。
- 局部创新线索：
  - CWA 权重加入 feasible rate、平均 CV、CV 下降速度、修复成功率和 offspring survival rate；
  - 给每个 auxiliary population 设置资源下限和冷启动探测，避免低权重约束被永久饿死；
  - 用 bandit/RL 学习 weak/strong/all combination 的触发，而不是固定三等分；
  - constraint similarity 从 CV cosine 扩展为 feasible pattern、active set、目标贡献和 offspring 迁移成功率的混合指标。
- 结构创新线索：
  - 构建三层约束协同控制器：UPF 探索、约束权重资源分配、相似约束合并；
  - 与 EID 式约束优先级组合：先并行估计 CWA，再对高权重约束做局部优先处理；
  - 与 surrogate-assisted CMOP 组合：对高权重约束优先训练/采样 constraint surrogate；
  - 与 dynamic CMOP 组合：环境变化后恢复被拆散的 sub-constraints，再重新计算 CWA/CCM。
