# A novel embedded dual-layer multi-objective evolutionary algorithm for multimodal emergency logistics delivery under demand uncertainty and supply shortage

## 一句话理解

论文面向供给短缺和需求不确定下的多式联运应急物资配送，提出“灾前/初期 worst-case route pre-planning + 灾后 real-demand allocation post-adjustment”的两阶段鲁棒模型，并用外层 RL-CNSGA-II 搜索路线与运输方式、内层 GA 针对真实需求场景做物资再分配。

## 问题与动机

- 研究问题和场景：自然灾害初期，多个 supply points、distribution centers、transfer nodes 和 disaster-affected demand points 构成多式联运网络；运输方式包括 road、rail 和 air，且需求高度不确定、总供给不足。
- 为什么重要：
  - 灾后 72 小时对救援效果关键，运输时间影响生命救援，运输成本影响后续采购和救援持续性。
  - 单一运输方式容易受灾害破坏限制；多式联运能结合道路灵活性、铁路低成本大批量和航空快速响应。
  - 供给短缺下不能假设所有需求都完全满足，必须考虑灾区优先级和未满足需求惩罚。
  - 真实需求会随灾情信息更新而变化，单次静态规划容易过保守或无法适应实际需求。
- 现有算法为什么不足：
  - 作者认为多数 multimodal transportation 研究偏 deterministic，虽有不确定需求研究但仍需加强鲁棒和自适应决策。
  - Emergency material delivery 研究常优先保证 fulfillment rate，但对 supply shortage、demand uncertainty 和 dynamic disaster progression 的系统建模不足。
  - 常规 NSGA-II 在多 supply/demand/mode 和 urgency priority 下计算压力大，且固定迁移/算子策略难兼顾 exploration 和 diversity。
  - 直接在同一层同时优化 route/mode 和 scenario-specific allocation 会使决策维度和耦合度过高。
- 本文希望解决什么：建立一个能同时优化 transportation time 和 cost、考虑需求 polyhedral uncertainty 与供给短缺、并可在灾后根据真实需求调整资源分配的 embedded dual-layer evolutionary solution framework。

## 核心理念与算法流程

- 核心理念：把问题拆成两个阶段和两个算法层。
  - 第一阶段：按 worst-case demand scenario 做鲁棒路线和运输方式预规划，目标为最小总运输时间与运营成本。
  - 第二阶段：灾害信息更新后，根据真实需求和灾区优先级重新分配有限物资，控制运输/换装成本和 unmet demand penalty。
  - 外层算法：RL-CNSGA-II 用两种群协同搜索 first-stage route/mode Pareto solutions，并用 Q-learning 根据两种群 diversity 状态自适应调 migration size。
  - 内层算法：GA 在外层给定 routes/modes 后，针对 second-stage real-demand scenario 优化 material re-allocation，并把最优评价反馈给外层。
- 网络与不确定性：
  - 节点集合 `N = I ∪ K ∪ J ∪ L`，分别表示 supply points、distribution centers、demand points 和 transfer nodes。
  - 运输方式 `M={1,2,3}` 对应 road、rail、air；灾害可能导致 road 到 demand points 的 delay coefficient 增大。
  - 不确定需求写作 `Q~_j ∈ [Q_j - Qhat_j, Q_j + Qhat_j]`，其中 `Qhat_j = epsilon * Q_j`。
  - 用 polyhedral uncertainty set 和 uncertainty budget `Gamma = beta * |J|` 控制整体保守度；`Gamma=0` 为确定性，`Gamma=|J|` 退化为 box uncertainty。
  - 后续灾情信息变化可用 `epsilon' = mu * epsilon` 表示不确定范围扩大或缩小。
- Two-stage robust model：
  - First-stage objectives：最小化总运输时间、最小化总运输成本，基于 worst-case / maximum demand scenario `Z*`。
  - First-stage constraints：supply capacity、distribution center throughput、flow balance、demand upper/lower security guarantee、transfer-node capacity、route carrying capacity、decision variable domains。
  - Second-stage objective：在实际需求场景下最小化 material transportation cost、transfer cost 和 unmet demand penalty。
  - Supply shortage 条件：总供给小于总需求，未满足需求 `S_j` 通过 penalty coefficient `alpha_j` 进入目标。
- Fuzzy TOPSIS urgency ranking：
  1. 对人口密度、经济指标、需求等准则用 triangular fuzzy value `(lb, mpv, ub)` 表达。
  2. 按 benefit/cost 型准则归一化 fuzzy matrix。
  3. 乘以 fuzzy weights 得到加权 fuzzy normalized matrix。
  4. 计算 fuzzy ideal 和 anti-ideal solutions。
  5. 计算每个 demand point 到 ideal/anti-ideal 的距离和 closeness coefficient。
  6. `C_i+` 越大，灾点优先级越高，在供给短缺时优先分配。
- Outer RL-CNSGA-II：
  - Chromosome 包含两段：route node sequence 和 mode sequence。节点序列表示从起点到终点的可达路径；相邻节点之间的 mode 取 `1/2/3`。
  - Initialization：从起点开始随机选择可行 next node，直到 destination，保证可行但不追求初始质量；mode 按边可行模式随机选择。
  - Crossover：single-point crossover；若子代 route 不连通，用 Dijkstra 构造缺失子路径，并同步修复 mode sequence。
  - Mutation：随机删除一个非端点 node，再用 Dijkstra 连接前后节点，mode repair 与 crossover 类似。
  - Dual-population coevolution：维护 population 1 和 population 2，分别执行 crossover/mutation、nondominated sorting、crowding computation 和 population merge。
  - Diversity state：计算两个种群当前 diversity 与 initial diversity 的比值，离散成 9 个状态，描述两个种群 diversity decrease / unchanged / increase 的组合。
  - Q-learning migration control：动作是增大、减小或保持 migration size `m(t)`；用 epsilon-greedy 选动作、reward 更新 Q-table；迁移触发时用 RL 给出的 `m` 控制两个种群交换个体数量。
- Inner GA：
  - 目标是 second-stage emergency material re-allocation。
  - 初始种群一半来自外层 route/mode solution，一半随机生成以保留多样性。
  - 按真实需求场景计算 Formula (24) 的 objective value。
  - 使用 tournament selection、crossover、mutation；每轮重新计算 route 上 demand-adjusted cost。
  - 返回 real-demand scenario 下的 best allocation solution 给外层。
- 可能被修改的位置：
  - 将 Q-table migration control 改成 bandit / actor-critic / contextual policy，并把 reward 与 HV、IGD proxy 或 archive contribution 对齐。
  - 将 inner GA 换成 min-cost flow、MILP、LNS 或 rolling horizon solver，降低下层优化噪声。
  - 将 worst-case first stage 改成 CVaR、distributionally robust optimization 或 scenario-adaptive robust set。
  - 将 fuzzy TOPSIS ranking 改成 CRITIC-TOPSIS、Nash bargaining、fairness-constrained allocation 或 learned urgency model。
- 必须保留的核心：如果作为基础算法，至少应保留“first-stage robust route/mode planning + second-stage demand-realized allocation + lower-layer feedback to upper-layer Pareto search”的双层耦合。

## 实验证据

- 实验设置：
  - 数据：基于 Solomon benchmark 的 R-type instances 派生，作者认为其均匀分布更适合灾害节点空间分布。
  - 实例规模：30、50、70、100、150、200 total nodes；supply points 从 3 到 8，distribution centers 从 2 到 6，demand points 从 3 到 10。
  - 灾点严重度：选择国内代表城市，使用 permanent population、GDP 和 demand 等指标经 fuzzy TOPSIS 排序。
  - 运输参数：road / rail / air 的换装时间、换装成本、单位距离成本和 capacity 来自文献设置；road capacity 1 ton、rail 10 ton、air 0.5 ton，单位距离成本分别为 0.1、0.05、1 million yuan/km。
  - 环境：MATLAB R2018a，AMD Ryzen 9 7945HX 2.50 GHz，16 GB RAM。
- 不同规模结果：
  - 随节点规模扩大，route time 和 route cost 整体上升。
  - Table 5 中 optimal 和 average 的 time/cost variance 都小于约 20%，作者据此认为算法在搜索中能稳定靠近较优解。
  - Instance 8 / 150 nodes 的迭代曲线显示 cost 在前 100 iterations 快速下降并收敛到约 4.4 million yuan；time 从约 320 units 下降并较快收敛到约 230 units。
  - 30-node instance 的可视化显示 cost-dominant solution 更偏 road + rail 来降成本，time-dominant solution 更多使用 airway 和 transfer routes。
- 与 NSGA-II / SPEA-II 对比：
  - Table 6 在 12 个设置上比较 objective values 和 improvement ratios。
  - 作者总结：第一目标上，相对 initial solution、NSGA-II、SPEA-II 的平均 improvement ratio 分别为 `32%`、`14%`、`2.6%`。
  - 第二目标上，相对 initial solution、NSGA-II、SPEA-II 的平均 improvement ratio 分别为 `43%`、`0.25%`、`1.8%`。
  - 需要注意，Table 6 中个别实例相对 NSGA-II 的 improvement ratio 为负，说明优势不是每个设置都稳定成立。
- 参数敏感性：
  - 在 instance 8 / 100 nodes 上改变 `epsilon` 和 `beta`。
  - `beta` 增加时 time consumption 通常小幅上升；当 `epsilon=0.1` 时，time 从 `113.4` 到 `118.2`。
  - `beta > 0.6` 时 cost 明显上升；较低 `epsilon` 如 `0.1` 可让 cost fluctuation 更稳定。
  - 当 `beta=0.9` 且 `epsilon` 增大时，time 约在 `114-130 h`，cost 约从 `1.2` 到 `3.0 million yuan`。
  - Fig. 12 中，当 `beta=0.9`，cost 曲线从约 `1.4 million` 上升到约 `2.4 million`，增幅约 `80%`；作者认为 demand fluctuation 对 cost 的影响明显大于对 time 的影响。
- 证据边界：
  - 没有报告 HV、IGD、GD 等标准多目标质量指标，主要比较目标函数值和 improvement ratio。
  - 没有清晰消融隔离 dual population、Q-learning migration、Dijkstra repair、inner GA 或 fuzzy TOPSIS 的单独贡献。
  - 数据是生成/模拟实例，缺少真实灾害物流部署验证。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前 uncertainty modeling 仍可进一步刻画 disaster evolution。
  - 高维问题存在 computational bottlenecks，需要更深的 DRL-evolutionary integration 和 distributed optimization。
  - 当前应用维度有限，需要扩展到 multi-hazard coupling、multi-period dynamic scheduling 和 real-time monitoring。
- 作者未来工作：
  - 构建包含 disaster evolution mechanisms 的 dynamic uncertainty sets。
  - 探索 deep reinforcement learning 与 evolutionary algorithms 的深度融合，并设计 distributed optimization architectures。
  - 研究复杂场景下的模型泛化，包括 multi-hazard coupling、多周期动态调度和 real-time monitoring data 集成的动态决策支持系统。
- 我们认为仍需确认的问题：
  - Q-learning 的 reward 公式在 Markdown 中为图片，具体是否与 HV/多目标质量一致需要回 PDF 或代码核验。
  - RL migration 每 50 代触发、状态离散和动作系数是经验设定，缺少与固定迁移、随机迁移、bandit 或无迁移的系统消融。
  - 内层 GA 返回单个 scenario-optimal allocation，可能使外层评价受下层随机性和 GA 收敛不足影响。
  - First-stage worst-case planning 可能过保守；second-stage post-adjustment 能缓解但没有与 stochastic/CVaR 模型同框比较。
  - Assumptions 简化较多：无 isolated points、每种运输方式一种车辆、车辆数量充分、capacity 只考虑 weight。
  - 实验中“time units/h”和成本单位有时混用，部分图表数值需回 PDF 确认。
  - 供给短缺下 priority ranking 的公平性和伦理约束仅通过 penalty/TOPSIS 间接体现，缺少最低保障、区域公平或脆弱群体约束分析。

- 暂留在论文卡中的方法、原理或架构启发：
  - Fuzzy TOPSIS urgency ranking 可作为供给短缺下的 priority layer，但不应替代公平性约束。
  - Dijkstra repair 是路径类 MOEA 中保持 route connectivity 的轻量修复接口。
  - First-stage worst-case + second-stage reallocation 适合应急预案，但实际部署需要滚动更新和多场景并行评估。
- 局部创新线索：
  - 将 Q-learning migration reward 改为 archive HV improvement、sparse-cell fill rate 或 inner-GA allocation improvement。
  - 用 adaptive scenario budget：早期少量 demand scenarios 快筛，后期对 Pareto candidates 进行多场景 CVaR 精评。
  - 将 inner GA 换成 min-cost flow / MILP warm start，减少下层随机噪声。
  - 在 chromosome repair 中把 Dijkstra shortest path 改为 time-cost-risk multi-label shortest path，避免单一最短路修复偏置。
  - 对 priority ranking 加入 social vulnerability、accessibility、critical infrastructure dependency 和 fairness lower bound。
- 结构创新线索：
  - 构建“uncertainty-set robust preplan -> route/mode MOEA -> realized-demand allocation follower -> scenario-risk feedback”的应急物流模板。
  - 将不同运输方式和不同灾情阶段拆成多任务：road-dominant、rail-dominant、air-dominant 或 mild/severe disaster tasks，通过迁移学习共享 route fragments。
  - 把外层 dual populations 分工为 time-oriented 和 cost-oriented，再用 RL 控制迁移方向和迁移规模。
