# Interval adaptive multi-objective optimization of the proton exchange membrane fuel cell system considering parameter perturbation

## 一句话理解

本文把 PEM fuel cell 的输出功率和系统效率优化从确定性 Pareto 搜索改成 interval Pareto 搜索：先用非参数 Gaussian KDE 从模型预测与实际测量偏差中估计目标函数置信区间，再用 interval Pareto order relation (IPOR) 更新 pBest/archive，用区间 crowding distance 选择 gBest，并根据 particle uniformity 在线调整 MOPSO 的 `omega/c1/c2`，得到能覆盖参数扰动下性能上下界的 IAMOPSO interval Pareto set。

## 问题与动机

- 研究问题和场景：proton exchange membrane fuel cell (PEMFC) 系统的运行参数优化，目标为最大化 net output power 和 system efficiency，决策变量包括 current density、cathode pressure 和 oxygen stoichiometry。
- 现有算法为什么不足：许多 PEMFC 优化只追单目标输出功率或效率；多目标方法常按确定性模型优化，默认温度、压力、压缩机效率、motor efficiency 等参数准确，实际扰动会让 Pareto 解对应的性能偏离。
- 本文希望解决什么：在参数扰动和测量噪声下，保留每个候选运行参数的目标性能区间，生成 interval non-dominated optimal set，让决策者在不同负载或工况下从性能上下界已知的 Pareto 区域中选解。

## 核心理念与算法流程

- 核心理念：不把不确定性压成单点期望，也不假设已知解析概率分布。先用数据驱动 KDE 估计目标扰动的概率区间，再让优化器直接处理 interval-valued objectives。
- PEMFC 建模：
  - 建立 air compressor 和 fuel cell stack 的稳态非线性模型。
  - 输出目标包括 net output power `P_out` 和 system efficiency `eta_sys`。
  - 决策向量为 `x=[i, p_ca, lambda_O2]^T`，即 current density、cathode pressure、oxygen stoichiometry。
  - 不确定参数向量为 `c=[eta_cm, eta_m, T_atm, p_atm]^T`，包括 compressor/motor efficiency 和环境温度/压力。
- KDE 不确定区间：
  1. 用名义参数计算 `P_out,n` 和 `eta_sys,n`。
  2. 在相同工况下取得测量值，计算目标偏差 `Delta P_out` 和 `Delta eta_sys`。
  3. 用 Gaussian kernel density estimation 拟合偏差分布，带宽用 Silverman rule `b=1.06 sigma N_a^{-1/5}`。
  4. 选择置信水平 `1-alpha_P`、`1-alpha_eta`，通过分布反函数得到 `P_out` 与 `eta_sys` 的上下界。
- Interval MOO formulation：由于 `c` 为区间参数，目标函数 `f_nc(x,c)` 也表示为 `[lower, upper]`；本文得到的是 interval Pareto solutions，而不是单点 Pareto solutions。
- IAMOPSO 流程：
  1. 初始化 uncertainty confidence interval、swarm population、archive 和飞行参数 `omega/c1/c2`。
  2. 对每个粒子计算 interval-valued objectives。
  3. 用 IPOR 更新 pBest：若上一位置按区间 Pareto 关系优于当前位置，则保留上一 pBest，否则用当前位置。
  4. 用 IPOR 得到 interval non-dominated solutions 并写入 archive。
  5. 从 archive 中按 interval crowding distance 最大原则选择 gBest，增强区间 Pareto 集分布。
  6. 计算 particle uniformity information，根据其变化调整 `omega/c1/c2`。
  7. 用 MOPSO 速度/位置公式更新粒子，直到最大迭代。
- 粒子均匀度参数调节：
  - 低 uniformity 表示粒子分布不均匀：增大 `omega` 和 `c1`、减小 `c2`，强化多样性和全局探索。
  - 高 uniformity 表示粒子分布较均匀：减小 `omega` 和 `c1`、增大 `c2`，强化 gBest 牵引和 exploitation。
  - 更新幅度由非线性函数 `Re` 控制，范围在 0 到 1。
- 必须保留的核心：KDE 只负责把真实扰动转为目标置信区间，后续选择不能退回单点中值排序，而要用 IPOR、区间 crowding 和 interval archive 维护不确定目标的 Pareto 结构。

## 实验证据

- 实验设置：比较 NSGA-II、MOPSO、vwMOPSO 和 IAMOPSO；swarm/population size 为 100，archive size 为 100，max iterations 为 100；初始 `omega(0)=c1(0)=c2(0)=0.2`；MATLAB R2023b，Windows 10，Intel Core i5-1135G7，16 GB RAM。
- IAMOPSO 输出形态：每个个体在目标空间对应一个 hypercube，Pareto 前沿由红色上边界和蓝色下边界包围，中间区域代表当前决策变量在参数扰动下可能出现的功率和效率结果。PDF 第 9-10 页核验 Fig. 9-10。
- 仿真比较：在参数扰动下，确定性 MOPSO、vwMOPSO、NSGA-II 的优化结果明显偏离，而 IAMOPSO 保留 interval form 并显示更好的分布。PDF 第 9-10 页核验 Fig. 11。
- Table 3 指标：IAMOPSO 的 mean system efficiency 为 0.2028，mean net power 为 31840 W，HV 为 0.2930；对应 NSGA-II 为 0.1990、28697 W、0.2812，MOPSO 为 0.1885、30904 W、0.2901，vwMOPSO 为 0.2018、28690 W、0.2821。PDF 第 12 页核验。
- 带宽敏感性：KDE bandwidth 在基准值上下 20% 变化时，IAMOPSO 的 HV 变化在 2.5% 以内。PDF 第 10 页核验。
- 计算时间：单次迭代约 0.97 s，完整优化约 97 s；作者认为离线优化可接受，但嵌入式实时实现还需提高计算性能。PDF 第 10、13 页核验。
- HIL 实验：平台包含 ES910 optimizer、ES930 module、dSPACE simulator 和 physical piston compressor；采样率 1000 Hz，传感器精度 1.5% F.S.，使用 Kalman filter 平滑噪声。HIL 中 piston compressor 的 airflow pulsation、pipeline vibration 和 sensor noise 构成实际扰动来源。PDF 第 12 页核验。
- HIL 结论：IAMOPSO 在 hydrogen stoichiometry 变化下的 output power 和 efficiency 优于 MOPSO、vwMOPSO、NSGA-II；作者认为 HIL 验证支持其处理不确定参数的能力。PDF 第 12-13 页核验。
- 附录不确定区间：仿真中 90% 置信区间为 output power `[-1050.3 W, 713.1 W]`、efficiency `[-0.003, 0.0022]`；实验中为 output power `[-941.4 W, 923.7 W]`、efficiency `[-0.002, 0.0021]`。PDF 第 14 页核验。

## 局限与未来工作

- 作者明确说明的局限：HIL 已验证但尚未在真实大规模 fuel cell 上验证；IAMOPSO 属于离线优化，约 100 s 完成当前设置，若部署到 embedded system 需要提升计算性能；未来将进行 industrial PEM fuel cell system 验证，并设计 lightweight agent models 以改善实时性。
- Data availability：作者声明 No data was used for the research described in the article。PDF 第 14 页核验；这一表述与文中 HIL/测量数据描述并不完全直观一致，引用时应只作为作者数据声明记录。
- 我们认为仍需确认的问题：区间排序使用 IPOR 时，不同 interval overlap 情形可能产生大量不可比解；只用中点距离和区间面积构造 crowding 是否足够稳定；HIL 仍是模拟栈模型加物理 compressor，非完整真实 PEMFC 系统；对比算法较少，缺少与专门 interval MOEA 或 robust MOPSO 的系统比较；没有报告多次独立运行统计检验；KDE 置信区间依赖样本量和测量工况，跨设备泛化仍需验证。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：已新建 [KDE 区间 Pareto 自适应粒子群](../02_design_knowledge/K-kde-interval-pareto-adaptive-mopso.md)，因为它给出了从数据驱动不确定区间到 interval archive 和自适应 swarm 参数的完整接口，能迁移到其他不确定工程 MOO。
- 暂留在论文卡中的方法、原理或架构启发：
  - 离线 interval Pareto set 可作为不同工况在线选解表，但需要外部 decision rule 选择 point A/B/C。
  - 作者没有把区间目标转为 mean/worst 或中点/半径多目标，而是保留 interval dominance；这对不确定目标解释更直接，但选择压力可能减弱。
  - HIL 验证流程适合工程优化论文增强可信度：真实扰动部件 + 数字实时模型 + 优化器 C 代码部署。
- 局部创新线索：
  - 用 adaptive confidence level 替代固定 90%，根据风险态度输出乐观/保守 interval Pareto set。
  - 将 interval crowding 中点距离扩展为 Wasserstein distance、overlap-aware HV contribution 或 interval probability of dominance。
  - 对 IPOR 不可比解加入 secondary score，例如区间宽度、CVaR、regret 或用户偏好。
  - 用 surrogate/lightweight model 替代完整 PEMFC 仿真，提高嵌入式或在线滚动优化效率。
- 结构创新线索：
  - 构建“在线扰动采样 -> KDE 区间更新 -> 离线/滚动 interval MOEA -> 工况选解”的工业控制优化框架。
  - 与 robust MOO 结合：同时报告 interval Pareto set、mean/worst robust Pareto set 和区间宽度风险。
  - 与数字孪生结合：实时系统数据不断更新 KDE，定期刷新 interval Pareto archive。
