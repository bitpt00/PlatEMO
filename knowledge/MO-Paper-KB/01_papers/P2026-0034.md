# Multi-objective evolutionary algorithms and integer programming for the optimization of underwater acoustic sensor network design

## 一句话理解

论文把被动水下声学传感器网络设计建成离散多目标覆盖问题：用声传播仿真生成覆盖矩阵，用 MILP 精确求解可处理的覆盖-成本投影，用 set-cover 式贪婪法和 PAES/NSGA-II 求解更难的覆盖-成本-定位三目标问题，并把 exact 极端点和 greedy 前沿注入 MOEA，形成能在真实网络扩展场景中更稳的 matheuristic。

## 问题与动机

- 研究场景：
  - 被动、非通信的水下声学监测网络，用于海洋环境、生态和战略海域 surveillance；
  - 传感器或一组垂直堆叠传感器被称为 anchor；
  - 网络需要在指定海域离散网格上布设异构 anchor，以覆盖声源并支持噪声源定位；
  - 声传播受 bathymetry、海底属性、声速剖面、背景噪声和频段影响，不能只用距离半径近似。
- 现有工作为什么不足：
  - 许多 sonar/sensor deployment 工作使用连续距离函数、简化概率或单目标启发式，未显式嵌入真实声传播仿真；
  - MILP 能给精确结果和边界，但加入非共线定位约束和多目标后约束爆炸；
  - 纯 MOEA 可扩展到三目标，但缺少精确最优边界来判断质量；
  - 真实网络扩展时还要固定已有 anchors，并只优化新增 anchors 的位置。
- 本文希望解决什么：
  - 用离散网格和声传播仿真覆盖矩阵建立 UWASN 统一 MILP 模型；
  - 比较 exact bi-objective MILP、branch-and-cut、set-cover greedy、PAES、NSGA-II 和混合策略；
  - 说明哪些问题可用 exact front，哪些必须切换到 heuristic/metaheuristic；
  - 用 exact/greedy 结果初始化或定界三目标 MOEA，支持实际设计者选最终网络。

## 核心模型与算法流程

- 输入与覆盖矩阵：
  - `I`：zone of interest 中的监测网格点；
  - `D`：候选 anchor 部署网格点；
  - `M`：anchor model 集合，包含可用数量和成本；
  - `C[m]`：声传播仿真得到的覆盖矩阵，若 model `m` 的 anchor 放在 `j` 能检测点 `i`，则 `c_ij^m=1`；
  - `S_i`：能覆盖点 `i` 且三点非共线的 anchor triplet 集合，用于定位能力。
- 决策变量：
  - `x_jm`：是否在部署点 `j` 放置 model `m` 的 anchor；
  - `y_i^k`：点 `i` 是否被至少 `k` 个 anchors 覆盖，本文用 `k=1` 和 `k=3`；
  - `z_i`：点 `i` 是否可由非共线三 anchor subnetwork 定位；
  - `a_s`：非共线 triplet `s` 是否被完整选择。
- 目标：
  - `C1`：最大化至少被一个 anchor 覆盖的点数；
  - `C3`：最大化至少被三个 anchors 覆盖的点数，作为冗余覆盖指标；
  - `A`：最小化 anchor 数量或累计部署成本；
  - `L`：最大化可由三个非共线 anchors 定位的点数。
- 约束：
  - 覆盖定义约束，确保 `y_i^k` 与至少 `k` 个已部署 anchors 的覆盖关系一致；
  - anchor model 可用量约束；
  - triplet 激活和定位定义约束；
  - 可选 full coverage 约束；
  - 非共线约束可通过 branch-and-cut 延迟加入，避免初始模型直接包含大量 triplet 约束。
- exact 与 heuristic 解法：
  - `epsilon-constraint` 和 Chalmet 等 MOMILP 方法用于 bi-objective 投影，例如 `C1-A`；
  - fully non-collinear MILP 用 branch-and-cut：先解不含全部非共线约束的模型，发现共线三点后加入 `sum_m x_im + sum_m x_jm + sum_m x_km <= 2`，迭代到无共线 triplet；
  - Algorithm 2 是 set-cover greedy，每次选覆盖当前最多 uncovered points 的部署点；
  - Algorithm 3 先构造尽可能非共线且 3-coverage 好的局部网络，再补齐剩余覆盖；每次增加 anchor 都形成一个非支配候选，但不保证完整 Pareto set。
- MOEA 与 matheuristic：
  - 染色体为 anchor 集合 `(l_1,...,l_n,t_1,...,t_n)`，`l_k` 是部署点，`t_k` 是 model；
  - mutation 等概率执行改 model、改位置、删 anchor、加 anchor，并保持位置唯一；
  - NSGA-II 使用 set-based crossover，PAES 只用 mutation；
  - Greedy Algorithm 3 的 Pareto set 可作为 NSGA-II population 或 PAES archive 的初始化；
  - 对三目标难题，MILP 求 lexicographic extreme points `pmax1` 和 `pmax3`，用于质量边界和 matheuristic 初始化。

## 实验证据

- 实验设置：
  - MILP 使用 OPL 与 Julia/JuMP 建模，CPLEX 求解；
  - heuristic 用 C 实现；
  - 硬件为 Intel i7-1185G7 3.00 GHz、32 GB 内存；
  - 声传播仿真：300 Hz 以下用 RAM parabolic-equation code，300 Hz 以上用 Bellhop ray-tracing；
  - 背景噪声为 shipping noise；bathymetry、seabed 和 sound-speed profiles 来自 SHOM；
  - Bay of Biscay 区域离散为 `102 x 60` 网格，平均 cell size 约 `13 km x 18 km`；
  - 16 个 semi-synthetic test cases，部署点 `|D|` 约 152-1578，可达点 `|P|` 约 484-1923。
- Exact bi-objective `C1-A`：
  - `epsilon-constraint` 比 Chalmet 总运行时间低 7 倍以上；
  - 表 3 中 `epsilon-constraint` 对 16 个测试例生成完整 exact Pareto fronts，front size 约 54-208；
  - 除 DZ4 外总耗时约 `4988.40 s`，Chalmet 约 `35599.05 s`；
  - 论文摘要称 exact `epsilon-constraint` 可在几分钟内处理 up to 2000 monitoring points 的 coverage-vs-cost industrial-scale instances。
- 非共线和三目标困难：
  - 非共线约束数会爆炸，DZ0 的 152 个部署点可产生最多 `573,800` 个待加 constraints；
  - 即使只允许 5 个 anchors，部分 cases 仍超过 `10 h`；
  - DZ5 中 3-coverage 在 10 小时内无法找到 optimal 3-cover，而 1-coverage exact front 约 2 小时可完成。
- Greedy 与 exact 比较：
  - 在 `C1-A` 无 collinearity checking 问题上，Greedy 平均 quality loss 为 `0.99%`；
  - PAES 平均 loss 为 `15.70%`；
  - 平均运行时间：exact `311.77 s`，Greedy `0.773 s`，PAES `0.790 s`；
  - 说明对单纯覆盖-成本，结构化 set-cover greedy 比泛化 PAES 更合适。
- 三目标 `C1-A-L`：
  - PAES/Greedy+PAES/NSGA-II/Greedy+NSGA-II 相对 Greedy 的 hypervolume 都显著提高；
  - PAES 版本通常提升 `140%-156%`，NSGA-II 版本约 `70%-100%`；
  - Greedy initialization 对 PAES 约有 `2%` 改善，但对 NSGA-II 造成 `2%-10%` 损失；
  - 作者解释 NSGA-II 受 Greedy 不优化 `C3` 的偏置影响，PAES 在同等时间预算下平均比 NSGA-II 好约 `1.5x`。
- Lexicographic exact extremes：
  - 作者用 MILP 计算 `pmax1`：先优化 `C1`，再在不损失 `C1` 下优化 `A`，再优化 `C3`；
  - 计算 `pmax3`：先优化 `C3`，再优化 `A`，再优化 `C1`；
  - Greedy+PAES 在所有测试例上找到 exact 确认的 best `C1` 和 best `C3`；
  - 对 `pmax1`，anchor cost 平均 overcost 为 `9.4%`，`C3` 损失约 `7.2%`；
  - 对 `pmax3`，`C1` 损失很小 `0.6%`，但 anchor cost overcost 可达 `438.2%`；
  - G+PAES 计算整条近似前沿用 `22.29 s`，MILP 只算两个极端点用 `67.02 s`，约 `3.01x` speedup。
- 真实 UWASN 扩展案例：
  - 案例来自 SHOM oceanographic campaign，在法国 Brest 以西约 500 km，水深 0-5000 m；
  - 已有 4 个固定 anchors，要新增 5 个 OBS-like anchors；
  - 问题规模为 `|D| x |P| = 637 x 3479`；
  - `C1-C3` bi-objective 上 exact `epsilon-constraint` 找到 dominating optimal solution `(282,82)`，耗时 `75.689 s`；
  - PAES/NSGA-II 仅耗时约 `1.3 s`，但 quality loss 分别为 `57.17%` 和 `75.17%`；
  - `C1-C3-L` 三目标 exact front 不可行，MILP+Greedy+PAES 成为最好 reference；
  - 与 pure PAES 相比，matheuristic hypervolume 改善约 `53%`；与 NSGA-II 相比改善约 `31%`；
  - matheuristic runtime 约 `9.551 s`，相对 pure metaheuristic 增加约 7 倍，但仍低于 10 秒。

## 局限与未来工作

- 作者明确说明的局限：
  - exact MILP 只适合较简单的二目标或小规模投影；
  - 非共线约束和三目标 exact Pareto front 会导致不可承受的约束和重复求解；
  - Greedy 种子若没有优化某个关键目标，会把 MOEA 带向偏置区域；
  - 真实部署中 anchor 落点可能因洋流漂移，当前模型未处理部署位置鲁棒性；
  - 选最终网络还需要 ship steaming costs、weather conditions 等额外 operational criteria。
- 作者未来方向：
  - 研究实际部署位置偏差下的 network robustness；
  - 纳入 AUV 或 underwater gliders 等 mobile detection capabilities；
  - 对无人覆盖区域设计动态/移动检测补充策略。
- 我们认为仍需确认的问题：
  - Greedy+PAES 的优势是否来自 PAES 本身、greedy seed，还是 exact extreme injection，需要更细消融；
  - 真实案例中 MILP+G+PAES 被设为 reference，但并不等于真实 Pareto optimal；
  - 非共线阈值 15 度被作者称为 arbitrary control parameter，需要物理或定位误差模型校准；
  - 声传播仿真和覆盖矩阵预计算成本未完全纳入优化运行时间比较；
  - 异构多 model、多成本真实规模下 exact/greedy/MOEA 的相对表现仍需更多案例验证。

- 值得建立或补充的设计知识：

- 与已有设计知识的边界：
  - 不同于 [有序分割的精确 Pareto 前缀动态规划](../02_design_knowledge/K-ordered-partition-exact-pareto-dp.md)，本文不是用 DP 枚举完整 EPF，而是用 MILP/epsilon-constraint 求可处理投影和极端点，再指导启发式；
  - 不同于 [业务偏好约束的多段染色体搜索](../02_design_knowledge/K-business-constrained-multipart-chromosome-search.md)，本文的 epsilon-constraint 是 exact MOMILP 求解和质量定界，不是业务阈值 fitness 扫描；
  - 不同于 [结构启发初始化与多目标路径重联](../02_design_knowledge/K-structure-aware-initialization-multiobjective-path-relinking.md)，本文的初始化来自 set-cover greedy 和 exact lexicographic points，而不是 elite path relinking；

- 暂留在论文卡中的方法、原理或架构启发：
  - RAM/Bellhop 声传播仿真和 SNR 细节属于 UWASN 应用建模，暂不单独成卡；
  - 15 度非共线阈值未被物理证明，暂不作为可复用规则；
  - PAES vs NSGA-II 的具体表现依赖实现和评价预算，暂不作为通用算法排序结论。
- 局部创新线索：
  - 在 greedy seed 中显式加入 `C3` 或 `L` 的 marginal contribution，减少对三目标 MOEA 的偏置；
  - 自适应选择 exact extreme points，只在前沿空缺区域调用 MILP；
  - 把 collinearity 约束改为连续定位误差模型，而非固定角度阈值；
  - 对 MOEA archive 中靠近 exact bounds 的区域加密搜索。
- 结构创新线索：
  - 构建“exact projection solver + greedy scaffold + MOEA explorer + bound auditor”的组合 MOO 模板；
  - 小规模或低维目标投影由 exact 求真前沿，大规模全目标由 MOEA 搜索；
  - 将 exact solutions 作为 anchor points 注入 archive，并用它们评估 heuristic Pareto set 的极端覆盖和 overcost；
  - 对真实部署问题，把模型外成本或天气风险作为后处理 MCDM，而不是强行放进第一轮求解。
