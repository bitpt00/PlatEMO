# A Review of Evolutionary Algorithms for Multimodal Multi-Objective Optimization: Mechanisms, Progress, and Prospects

## 一句话理解

这是一篇 MMOP/MMEA 综述：作者把多模态多目标演化算法拆成 crowding distance、indicator、niching、clustering、archive、multi-population、machine learning、two-stage 八类机制，并用 37 个代表算法、评价指标和测试集综述说明，单一机制通常不足以同时保持决策空间多个等价 PS 与目标空间收敛。

## 问题与动机

- 研究问题和场景：multimodal multi-objective optimization problems (MMOPs)。与普通 MOP 只强调目标空间 PF 多样性不同，MMOP 要同时识别并保存决策空间中多个距离较远、但目标值相同或相近的 Pareto sets。
- MMOP 的定义：作者沿用文献定义，若某个 Pareto optimal solution `X` 存在一个决策空间距离足够远的 `Y`，且 `||f_X - f_Y|| <= delta`，则该 MOP 可视为 MMOP；两解距离远的条件为 `||x-y|| >= theta`。
- 为什么重要：
  - 多个等价实现给决策者保留未建模偏好选择空间，如风险、可执行性或二级业务偏好；
  - 在原方案失效或环境变化时，等价 PS 可作为鲁棒备选；
  - 多个 PS 的分布能揭示问题结构；
  - 在动态环境下，可不完全重新优化就切换到其他可行实现。
- 现有算法为什么不足：
  - NSGA-II、SPEA2 等传统 MOEA 主要维护目标空间 diversity/convergence，容易收敛到单个 PS；
  - 既有 MMEA 文献快速增长，但缺少按“机制组成”统一拆解现代 MMEA 的系统综述；
  - 决策空间 diversity 与目标空间 convergence 在 MMOP 中天然冲突，单个 crowding、niche、archive 或 indicator 往往只能处理其中一部分。
- 本文希望解决什么：给出一个 mechanism-centric review，用八个机制模块和四个功能过程帮助理解、比较、组合和设计 MMEA；同时整理指标、测试集和未来方向。

## 核心理念与算法流程

- 核心理念：把 MMEA 视为在 exploration 和 exploitation 之间调度多个机制的组合系统，而不是把每篇算法看成孤立命名方法。机制按功能分为四类：decision space partitioning、diversity maintenance、objective space convergence、knowledge-guided processes；two-stage 是跨阶段组合这些机制的 meta-control。
- 综述框架：
  1. 先定义 MMOP 与其决策空间/目标空间双重要求。
  2. 在 Section III 中按八个机制综述代表算法、作用方式、适用条件和局限。
  3. 在 Section IV 中讨论 MMOP 指标必须同时评价 objective space 和 decision space。
  4. 在 Section V 中整理 Omnitest、TWO-ON-ONE、SYM-PART、Polygon/Multi-polygon、MMF/MMFs、MMMOP、IDMP/IDMP_e、真实 location/path/feature selection 等测试问题。
  5. 在 Section VI/VII 中总结理论框架、双空间平衡、鲁棒性、指标、可扩展性、ML/transfer 以及机制隔离归因等未来方向。
- 关键组成部分：八机制分类、37 个代表 MMEA 的机制属性表、13 个代表研究的指标使用表、MMOP 测试集属性表、未来研究方向。
- 可能被修改的位置：这是综述而非可直接运行算法；可用于修改其他 MMOP 算法的部位包括环境选择、模态划分、子种群/档案管理、阶段切换、机器学习辅助子代生成、评价指标和 benchmark 选择。
- 必须保留的核心：MMOP 算法设计必须同时显式考虑决策空间多个 PS 覆盖和目标空间收敛；机制组合要有适用边界与评价协议，不能只以单一指标判断。

| Indicator mechanism | 用 convergence/diversity 指标量化个体潜力，但依赖 ideal point、reference set 或其他参考信息，黑箱问题中错误参考会误导搜索 | 适合作为阶段目标或环境选择依据，需与其他机制配合 | Sec. III-B，PDF 5-6 |

| Clustering mechanism | 可识别 decision/objective space 中的潜在 PS 区域，也可作为 niche、multi-population、crowding 等机制的工具；PS 重叠、交错或连续时边界难定义 | 解释为什么许多 MMOP 算法把聚类作为子模块而非完整解法 | Sec. III-D，PDF 7-8 |
| Multi-population mechanism | 用不同搜索倾向的子种群分别承担 exploration 和 exploitation，但维护多子种群有额外开销，且信息交换难控制 | 适合大规模或可分解 MMOP，并需要弱交互/协调策略 | Sec. III-E，PDF 8 |
| Archive mechanism | 通过一个或多个外部档案保存历史 non-dominated/elite solutions，更新、容量和替换规则决定性能；复杂 MMOP 往往需要 convergence/diversity 多档案 | 给长期保存多个 PS 和避免遗忘提供基础接口 | Sec. III-F，PDF 9 |

## 实验证据

- 测试问题和对比算法：
  - 本文是 survey，不做统一复现实验；主要证据来自 37 个 state-of-the-art MMEA 的机制属性对比、13 个代表研究中的指标使用对比，以及多类测试集的属性整理。
  - 表 VII 总结 37 个 MMEA 的机制组成；Table VIII 总结 MMOP 指标使用；Table IX 总结 MMOP test suites 属性。
- 主要综述结论：
  - 作者认为有效 MMEA 几乎都组合了多个机制，例如 Tri-MOEA&TAR 同时使用 clustering、archive 和 niching，MMEA-WI 使用 archive 和 indicator。
  - 作者认为“没有单一机制能充分解决 MMOP 的所有方面”，高性能算法通常靠互补机制共同平衡 decision-space diversity 和 objective-space convergence。
  - 作者指出机制之间存在依赖：archive 可为 machine learning 提供训练数据；two-stage 需要 indicator 判断阶段目标和切换；multi-population 的划分常需要 clustering/niching。
  - 作者认为当前评价方法仍有缺口：许多指标只评价单一空间，用 IGD+IGDX 等双指标时可能出现一个方法在一个空间更好、另一个空间更差而难以排序的情况。
  - 当前测试集尚不足以覆盖高维、离散、混合整数和真实复杂 MMOP，许多真实 path planning 等问题因编码离散性和长度不确定，现有 MMEA 不能直接适用。
- 消融或机制证据：
  - 综述本身不提供新算法消融；机制证据来自被综述算法的已有结果和作者对机制属性的归纳。
  - 作者将机制局限归纳为高维失效、参数敏感、信息交换困难、archive 成本增长、ML 训练数据偏差等。
- 证据边界：
  - 这是综述型证据，不能把“组合机制通常更有效”当作所有问题上的严格实验定理。
  - Markdown 中表格为图片省略，37 个算法的完整机制勾选、13 个指标使用细节和测试集属性需回查 PDF 表格。
  - 文中未来方向包含若干建议性框架，如 landscape feature analysis、embedded robustness assessment、reference-free indicators、hierarchical decomposition，属于作者展望而非已验证算法。

## 局限与未来工作

- 作者明确说明的局限或开放问题：
  - 八类核心机制在高维问题、复杂决策空间拓扑、参数敏感性、信息交换、存储成本和训练数据依赖方面仍有明显限制。
  - 同时获得 global Pareto solutions 与 local Pareto solutions 仍困难；local PS 因目标空间表现较差容易被环境选择删除。
  - 缺少能综合评价 objective-space convergence/distribution 与 decision-space multi-solution coverage 的高效、鲁棒、可解释且少依赖 reference set 的指标。
  - 现有 test suites 对高维、离散、混合变量和真实世界复杂性覆盖不足。
- 作者未来工作：
  - Theoretical Foundation and Comprehensive Framework：建立 formal definitions、taxonomy、landscape feature analysis 与算法性能映射。
  - Balanced Performance in Decision and Objective Spaces：设计随问题和搜索状态动态平衡两空间性能的机制，可能包括 archipelago、多策略子种群、LLM/meta-learning 自动配置。
  - Robust MMOPs and Practical Applications：将鲁棒性作为与目标空间收敛、决策空间多样性并列的考虑，发展鲁棒 MMOP 定义、指标和 benchmark。
  - Advanced Performance Metrics：设计双空间、reference-free、抗离群且可解释的综合指标和统计比较框架。
  - Scalability and High-Dimensional Problems：发展维度缩减、可扩展 niching、并行/分布式实现和 many-objective MMOP 机制。
  - Integration With Machine Learning and Transfer Optimization：使用 surrogate、transfer optimization 和 adaptive operators 学习问题结构并降低成本。
  - Mechanism Isolation and Attribution Analysis：建立模块化实验框架，隔离不同机制的独立作用和交互效应。
- 我们认为仍需确认的问题：
  - 八机制框架能否进一步变成自动 algorithm configuration 或机制推荐器。
  - 如何在未知 PS 数量、PS 交错、变量混合和多目标数增加时统一定义“决策空间多样性”。
  - 机制之间的互补和冗余如何量化，尤其 archive + ML、clustering + multi-population、indicator + two-stage 的组合。
  - 参考无关指标是否能避免引入新的隐式偏好权重。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：[MMOP 八机制组合设计框架](../02_design_knowledge/K-mmop-eight-mechanism-composition-framework.md)。它不是单一算法，而是用于 MMOP 算法设计、查重、组合创新和评价协议选择的上层机制地图。
- 暂留在论文卡中的方法、原理或架构启发：
  - “机制隔离归因分析”可作为未来实验设计原则：同一机制在不同算法上下文、不同 PF/PS 形状和不同局部最优分布下分别测量贡献。
  - “embedded robustness assessment”可把 robustness 作为 MMOP 的第三维设计约束，但作者尚未给出可直接实现的完整算法。
  - “landscape feature analysis”可作为 MMOP 算法选择的前置诊断层，但目前仍是展望。
- 局部创新线索：
  - 在现有 MMOP 算法中加入机制标签和 credit assignment，记录每代 offspring 来自哪个机制、是否存活、贡献哪个 PS 区域。
  - 用动态指标决定 two-stage 切换，而不是固定代数；指标可以同时包括 IGDX-like coverage、archive novelty 和 local PF quality。
  - 用 reference-free 的双空间相似性指标替代固定 true PS/PF 依赖，适合真实应用。
  - 针对 local Pareto solutions 设计保护性环境选择，避免 objective-space 较差但决策上有用的 local PS 被过早删除。
- 结构创新线索：
  - 构建 MMOP mechanism controller：problem profiler -> mechanism portfolio -> phase scheduler -> archive/metric feedback -> mechanism attribution。
  - 将 multi-population、archive 和 ML 统一成“每个潜在 PS 一个局部记忆与局部模型”的架构。
  - 为高维 MMOP 加入 variable interaction analysis 与 dimension-independent niching，先减轻距离集中再做 PS 保持。
