# Imitation Learning for Multiobjective Optimization--AlphaMOEA

## 一句话理解

本文提出 AlphaMOEA，把多个 MOEA 得到的非支配解作为“专家示范”进行模仿学习：先用多任务 Transformer 网络把每个非支配解拟合成一个 task-specific 参数层，再用 PPO 在这些高维参数表示上选择 SBX/DE 算子继续演化，从而以端到端神经模型输出更高质量的 Pareto 解集。

## 问题与动机

- 研究问题和场景：传统 MOEA 在 dominance、indicator、decomposition 等框架下各有优势，但面对 many-objective、复杂 PF、非规则/不完整 PF、真实问题的不规则前沿时，单一框架的适应性不足；仅靠原始决策空间中的演化过程捕捉决策空间与目标空间关系可能低效。
- 现有算法为什么不足：已有 SL 方法多把神经网络用于学习收敛方向，目标是加速已有 MOEA；已有 RL 方法多用于算子或策略自适应，仍围绕传统 MOEA 框架。很少有方法把 SL 和 RL 组合成 imitation learning，并用高维网络参数空间重新表示非支配解。
- 本文希望解决什么：构造一个完全由神经网络组成的端到端模型，先模仿多个 MOEA 的非支配解，再通过自学习在高维表示中继续搜索，使模型能融合不同 MOEA 的优势并根据问题特征选择合适的探索/开发行为。

## 核心理念与算法流程

- 核心理念：每个非支配解都可以被看成一个任务；多任务网络的 shared Transformer layer 学习这些解的公共抽象表示，task-specific linear layer 学习每个解的个体表示。SL stage 把决策空间中的非支配解映射到高维参数空间；RL stage 把 task-specific 参数视为“个体”，对参数而非原始解执行 SBX/DE，借助 PPO 学习何时探索、何时开发。
- 主要流程：
  1. 用选定的 MOEAs 求解给定 MOP，收集非支配解作为专家示范；
  2. 构建 AlphaMOEA：shared layer 为 Transformer，task-specific layers 为多个 linear layers，每个 layer 对应一个非支配解；
  3. SL stage 用随机输入和非支配解标签训练模型；
  4. 因多个任务/非支配解之间存在 tradeoff，使用 MGDA/Frank-Wolfe 处理 shared layer 的多任务梯度，而不是简单加权求和；
  5. SL 后，shared layer 代表所有解的公共高维表示，task-specific parameters 代表每个解的个体高维表示；
  6. RL stage 将 task-specific parameters 作为个体，构造参数相似性状态矩阵；
  7. PPO actor 在 SBX 和 DE/best/1/bin 两个动作中选择，用于生成新的 task-specific parameter；
  8. 将新参数对应的解与现有 task-specific 解做 nondominance 比较，支配旧解则更新网络结构，被支配则丢弃；
  9. 用 HV 作为 incremental reward 训练 PPO；
  10. 训练完成后，通过前向传播直接输出近似 Pareto 解集。
- 关键组成部分：MOEA expert nondominated set、hard parameter sharing MTL、Transformer shared layer、linear task-specific layers、MGDA/Frank-Wolfe SL training、parameter-similarity state、SBX/DE action set、knee-point DE/best、HV reward、PPO self-learning。
- 可能被修改的位置：学习型 MOEA/Pareto set learning、算法预训练和迁移、神经参数空间中的算子演化、MOEA expert distillation。
- 必须保留的核心：非支配解不是单个样本标签，而是一组有 tradeoff 的任务；SL 学到的是高维参数表示，RL 继续在 task-specific 参数空间演化；reward 需要能评价新增参数对应解对当前 Pareto set 的增量贡献。

## 实验证据

- 测试问题和对比算法：ZDT、DTLZ、RE test suites；常规 MOEA 包括 NSGA-II、AGEMOEA、MOEA/D、RVEA；新近算法包括 DRLOS-EMCMO、LMPFE、MOEAD-DQN、NRVMOEA；另与 Pareto set learning PSL-20/PSL-40 比较。每个参考 MOEA 独立运行 30 次，指标为归一化 HV，Wilcoxon rank sum test。
- 主要实验结论：AlphaMOEA 在 ZDT/DTLZ 大多数问题上显著优于四个常规 MOEA，例外包括 ZDT4、ZDT6、DTLZ6；在 RE31、RE33、RE34、RE37 上优于四个新近 MOEA，RE42 中 NRVMOEA 最好、AlphaMOEA 次优；与 PSL 相比，除 DTLZ6 外多数问题显著更好且 HV 方差更小。
- SL 证据：AlphaMOEA-1（SL 后，无 RL）优于去掉 shared layer 的 AlphaMOEA-2，说明 shared Transformer layer 有助于学习多个非支配解的共同表示并稳定训练。
- RL 证据：用简单随机 SBX/DE 演化替代 PPO 的 AlphaMOEA-3 也有效，说明高维参数空间演化本身有价值；但 AlphaMOEA 收敛更快，并在 DTLZ2 更偏 SBX 探索、DTLZ6 更偏 DE/best 开发，说明 PPO 能根据问题特征调度算子。
- 长训练证据：RL trajectory length 增至 2000 后，AlphaMOEA 在 DTLZ1/DTLZ7 上 1000 步后仍继续提升，在 DTLZ4 上几乎覆盖整个 PF，显示更长训练可增强多样性。
- 证据边界：训练时间很长，ZDT/DTLZ 每个问题约 3 h SL + 2 h RL；每个新 MOP 通常需要重新训练；many-objective 和 large-scale 结果在 supplement，主文只概述；表格多为图片占位，PDF 已定点核验。

## 局限与未来工作

- 作者明确说明的局限：AlphaMOEA 主要有 transferability 和 training time 两个限制；若遇到全新问题，需要重新训练新的 AlphaMOEA；每个 MOP 需要较长预训练时间。
- 作者未来工作：设计 transfer learning 利用已学抽象表示，构建类似 pretrained model 的方法用于相似 MOP；设计更 lightweight 的网络架构；未来暴露于 expensive、multimodality、constraints、dynamism 和 uncertainty 等更多特征，走向 universal MOEA。
- 我们认为仍需确认的问题：非支配解数量增加时 task-specific layers 规模和 MGDA 成本如何控制；随机输入到固定解标签的拟合是否会限制外推；HV reward 对复杂/高目标问题计算成本和偏置；新问题间迁移是否真的优于重新运行 MOEA；训练成本是否只适合重复求解同族问题。
