# A Schema-Guided Constrained Multi-Objective Optimization Evolutionary Algorithm for Multiple Uncrewed Aerial Vehicle Path Planning

## 一句话理解

论文把多无人机三维路径规划建模为带路径长度、碰撞风险和多类飞行安全约束的 CMOP，指出整解级选择会丢掉“差解中优质单 UAV 路径”，因此提出 SGCMOEA：把每条 UAV 路径作为 schema，周期性用 SGSR 从种群和 schema 仓库中替换最差路径组件，并用 AESP 维护带年龄的优质 schema 仓库。

## 问题与动机

- 研究问题和场景：
  - 多架 UAV 在已知三维城市地形中从各自起点飞到终点；
  - 每架 UAV 的路径需要平滑、避开地形障碍、满足爬升/滑翔、转弯半径和高度约束；
  - 多 UAV 之间还需避免时空碰撞；
  - 优化目标为最短总飞行路径长度与最小碰撞风险。
- 现有算法为什么不足：
  - 启发式算法如 A*、Dijkstra、RRT、人工势场依赖问题规则，通常更偏单目标，难提供多目标 Pareto trade-off；
  - 强化学习方法面对多 UAV 时状态/动作空间随 UAV 数指数增长，训练成本高，跨地形/任务泛化有限；
  - 多种群 metaheuristic 可按 UAV 或 UAV 子组演化，但子种群数量随 UAV 数增加，全球约束评价和协调复杂；
  - 单种群方法把所有 UAV 路径编码成一个完整个体，管理简单，却用完整解做粗粒度选择，容易丢弃差整体中的优质单 UAV 路径。
- 作者如何从不足推导本文动机：
  - 论文的 motivation experiment 在 MUPP-3-1 上用 MOEA/D-CDP 取 generation 35 的两个解；
  - Solution 1 总约束违反更低，按 CDP 会优先保留；
  - Solution 2 虽然总约束违反更高，但 UAV1 和 UAV3 的四个 individual constraints 都为 0，是高质量可行路径；
  - 若整解淘汰 Solution 2，这些优质路径组件会随差解一起丢失；
  - 因而需要同时在 solution level 和 schema level 管理遗传信息。

## 核心理念与算法流程

- 核心理念：
  - 一个完整 MUPP 解由多条 UAV 路径组成；
  - 每条单 UAV 路径是一个可评价、可保存、可转移的 schema；
  - 即使完整解差或不可行，其中某条 UAV path 仍可能是可复用 building block；
  - 周期性识别目标解中最差 schema，用同位置最优 schema 替换，再通过完整解重评验证跨 UAV 交互约束。
- MUPP 编码：
  - 每架 UAV 路径由 `nc` 个三维 B-spline control points 表示；
  - `M` 架 UAV 的控制点串接成一个实值决策向量，维度 `D=3*M*nc`；
  - 第 `k` 架 UAV 的控制点序列就是一个 schema unit；
  - B-spline 提供局部可控性和高阶连续性，生成 `nt+1` 个稠密 path points 供目标和约束评价。
- 目标函数：
  - `f1`：最小化所有 UAV 的总路径长度；
  - `f2`：最小化障碍碰撞风险，先将路径点和地形网格投影到水平面，找安全阈值内的邻近地形点，再按已有风险模型计算。
- 约束：
  - `h1`：飞行路径坡度限制，保证爬升/滑翔能力；
  - `h2`：最小转弯半径，保证机动性；
  - `h3`：最低飞行高度/地形安全间隙；
  - `h4`：最高飞行高度 ceiling；
  - `h5`：多 UAV 时空碰撞避免，当两架 UAV 路径点距离低于 `dc` 且到达时间差低于 `tsafe=dc/v` 时判为冲突。
- SGCMOEA 主流程：
  1. 基于 MOEA/D-CDP 初始化种群、ideal point、schema repository `K`、schema age vector `A` 和 ranking matrix `R`；
  2. 常规演化阶段使用 DE/rand/1 和 polynomial mutation 生成候选解；
  3. 对越界变量使用反射式 boundary repair；
  4. 用 CDP 评价候选，按邻域更新 MOEA/D 种群；
  5. 每 5 代触发 schema-guided mechanism；
  6. 先执行 SGSR，合并当前种群与仓库 `G=P_g union K`，构造 schema ranking matrix；
  7. 对目标解找到最差 schema 位置 `w`，从 `G` 中找到同位置最优 schema，并替换形成重构解 `y`；
  8. 再执行 AESP，用 CDP 验证 `y` 是否优于原解 `x_i`，并维护 schema repository 和 age vector；
  9. 直到最大代数，输出最终种群。
- SGSR 关键细节：
  - 对每个 UAV 位置 `k`，从 `G` 的所有解中抽取同位置 schema，形成 `U_k`；
  - 对 schema 使用 CDP ranking：可行 schema 优于不可行 schema；
  - 可行 schema 用 ASF 值排序，不可行 schema 用总约束违反排序；
  - `h1-h4` 和 `f1-f2` 可按 UAV 分解，能复用已计算贡献；
  - `h5` 是跨 UAV 碰撞约束，只有替换后才重新计算验证；
  - ranking matrix `R` 的每列对应一个 UAV 位置，每行对应 `G` 中一个 schema。
- AESP 关键细节：
  - 若重构解 `y` 按 CDP 优于原解 `x_i`，则用 `y` 替换 population 中的 `x_i`；
  - 若最优 schema 来自 repository `K`，重置其 age，表示仍有价值；
  - 成功重构时，原 `x_i` 中被替换掉的 schema 也作为候选 schema，因为它未必无用，只是在当前组合中较差；
  - 失败重构时，`y` 中引入的 schema 被作为候选 schema，保留其未来可能价值；
  - repository 更新时选择 age 最大的旧解 `k_old`，用候选 schema 替换其第 `w` 个 schema 得到 `k_temp`；
  - 若 `k_temp` 按 CDP 优于 `k_old`，则更新 repository；
  - 被更新解 age 设为 0，其余 repository 解 age 加 1，避免陈旧 schema 长期占位。
- 可能被修改的位置：
  - schema update interval，论文默认为每 5 代；
  - schema ranking 的可行性、ASF、总 CV 顺序；
  - repository 大小、age 替换策略、候选 schema 来源；
  - 完整解验证时的跨 schema 约束计算方式；
  - 基础优化器可从 MOEA/D-CDP 换成 NSGA-II、DE、PSO、CMOEA 或代理辅助算法。
- 必须保留的核心：
  - 完整解必须能拆成语义清晰的 component/schema；
  - 组件级评价只能作为初筛，跨组件约束必须在重构后重新验证；
  - schema 仓库不能只保存成功解，也要保留失败重构中的潜在有用 schema；
  - schema transfer 必须发生在同构位置或有可靠映射的位置，避免把 UAV1 路径直接误插到不可兼容任务位置。

## 实验证据

- 测试问题和对比算法：
  - 六个实例基于 Bordeaux Métropole digital surface model 构建；
  - UMP1/UMP2/UMP3 三类 terrain 难度递增；
  - UMP1 使用 5 UAV，UMP2 使用 6 UAV，UMP3 使用 7 UAV；
  - Scenario A 是分布式起点到附近终点的 convergent missions；
  - Scenario B 是集中起点到分散终点的 divergent missions；
  - 通用参数：`nc=4`，B-spline degree `s=3`，path points `nt=200`，`d_safe=10 m`，`h_safe=2 m`，`dc=1 m`，flight speed `v=25 m/s`，`g_a=9.8 m/s^2`；
  - 对比算法包括 CCMO、DDCo、CMOEA-CD、MOEA/D-CDP、CMOEMT；
  - 指标为 HV 和 SR，HV reference point 为 `(10000,10000)`，SR 表示至少找到一个可行解的运行比例；
  - 每个算法 30 次独立运行，种群规模 `N=100`，搜索空间 `[0,200]`；
  - 对比算法终止于 `3.6e4` FEs，SGCMOEA 主演化用 `3.0e4` FEs，以补偿每 5 代 schema 分析额外 `N` 次评价。
- 主要实验结论：
  - Table III 中 SGCMOEA 在六个实例上 SR 均为 100%；
  - 其他算法在困难实例明显退化，例如 DDCo 在 UMP3A/UMP3B 为 0%，CMOEA-CD 在 UMP3A/UMP3B 为 40%/17%，CMOEMT 在 UMP3B 为 7%；
  - Table IV 中 SGCMOEA 在全部六个实例上 HV 均最高，并且 Wilcoxon rank-sum test 显示相对所有对比算法显著优或至少不劣；
  - HV 代表值：UMP1A 8.35e+07，UMP1B 8.60e+07，UMP2A 8.21e+07，UMP2B 8.33e+07，UMP3A 7.35e+07，UMP3B 7.72e+07；
  - 对比算法中 CMOEA-CD 在 UMP1B 与 SGCMOEA 统计相近，但整体 `+/=/-` 为 `0/5/1`，其余算法均 `0/6/0`；
  - Fig. 5 显示 SGCMOEA 在六个实例上生成的代表路径均能形成平滑且避开地形障碍的多 UAV 轨迹。
- 收敛与机制证据：
  - Fig. 6 的 UMP2A/UMP2B 中，SGCMOEA 最早发现可行解并保持稳定 HV 收敛；
  - 作者指出在 UMP3A/UMP3B 等困难实例中，其他算法经常找不到可行解或出现停滞；
  - SGSR contribution rate 每 5 代统计一次，初期为 100%，中期随种群质量上升下降到 10%-30%，但后期会周期性上升；
  - 作者据此认为优质 schema 在整个进化过程中仍可被发现和转移，而不是只在初期有效。
- 消融实验：
  - Table V 比较 Without AESP、Without SGSR、完整 SGCMOEA；
  - UMP2A 上 Without AESP HV 为 `7.93e+07(1.47e+06)`、SR 97%；Without SGSR HV 为 `8.14e+07(2.42e+05)`、SR 100%；完整 HV 为 `8.21e+07(2.44e+05)`、SR 100%；
  - UMP2B 上 Without AESP HV 为 `8.04e+07(1.49e+06)`、SR 97%；Without SGSR HV 为 `8.27e+07(5.36e+05)`、SR 100%；完整 HV 为 `8.33e+07(4.55e+05)`、SR 100%；
  - 作者解释：AESP 对约束满足/可行率关键，SGSR 对 solution quality/HV 关键，两者共同贡献完整效果。
- 证据边界：
  - Table II-V 是 PDF 图片表格，已目视核验 PDF 第 9-11 页；
  - supplementary 还包含 running time、schema interval sensitivity、schema-level constraint satisfaction 和 constraint complexity analysis，但正文只概述，本文卡未逐项展开；
  - 当前实例最多 7 UAV，作者也承认更大规模 fleet 的可扩展性仍需未来验证；
  - SGCMOEA 运行时间较长，未来需 surrogate-assisted 降低成本。

## 局限与未来工作

- 作者明确说明的局限：
  - SGCMOEA 运行时间相对较长，部分来自 MUPP 本身的高计算成本；
  - 当前实验规模仍有限，需要扩展到更大 UAV fleet 验证可扩展性。
- 作者未来工作：
  - 引入 surrogate-assisted optimization，降低计算成本，同时保留 schema-guided approach 的有效性；
  - 将框架扩展到 larger-scale UAV fleets。
- 我们认为仍需确认的问题：
  - schema update interval 每 5 代是否在不同 UAV 数、地形复杂度和评价预算下稳定；
  - repository 保存的是完整 solution 容器中的 schema，如何避免跨任务/跨 UAV 位置不兼容；
  - `h5` 跨 UAV 约束重评成本在更大 `M` 下会增长，可能抵消组件复用收益；
  - 只把每条 UAV path 当 schema，未处理同一 UAV path 内的子路径/局部控制点 building blocks；
  - 若多个 schema 单独都优质但组合后时空冲突严重，SGSR 可能频繁失败；
  - 与更强局部搜索、路径修复、可行性预测或代理模型结合后的贡献分解仍需验证。

  - 与约束优先级/代理搜索模式结合：先识别造成可行性失败的组件，再从 repository 中定向修复；
  - 应用于多车辆任务分配、生产线排程、多机协同控制和模块化工程设计。
