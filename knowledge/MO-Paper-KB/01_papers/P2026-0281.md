# Variable Neighborhood Search for Bi-Objective Heterogeneous Depots Vehicle Routing Problem With Sequential Visiting

## 一句话理解

本文提出 GHDVRPSV 这一异构多仓顺序访问车辆路径问题，并给出 VNS-AS：用仓库锚定的 sub-route fusion encoding 直接压住仓库-产品-客户前序约束，再根据当前解和父代的支配关系选择 Depot-Exchange 或 Customer-Relocation 扰动，并用子路线内 2-opt、同子路线交换和邻近插入做可行局部搜索。

## 问题与动机

- 研究问题和场景：多个 depot 供应的 product types 不完全相同，客户可能需要多个产品，车辆可从任一 depot 出发并返回出发 depot，配送过程中可以顺序访问多个 depot 补货后再服务客户。论文将其定义为 General Heterogeneous Depots Vehicle Routing Problem with Sequential Visiting (GHDVRPSV)。
- 双目标：
  - 最小化 total travel cost；
  - 最小化所有车辆中最长 route cost，用于 workload balance。
- 关键约束：
  - 每个客户只访问一次，不允许 split delivery；
  - 每辆车每个 depot 最多访问一次；
  - 车辆有可装产品种类数和各产品重量容量限制；
  - 车辆必须从某 depot 出发并回到同一 depot；
  - 客户需求必须由其访问前已经装载的产品满足。
- 现有方法为什么不足：
  - 普通 giant-tour representation 只控制节点顺序，难保证 depot 顺序、产品来源和客户服务时刻之间的前序关系；
  - 随机初始化和普通邻域容易生成 infeasible routes，计算预算被修复或丢弃消耗；
  - 固定 shaking 强度不能区分“当前解明显变差”“当前解明显变好”和“当前解与父代互不支配”三类搜索状态；
  - 多仓多产品场景下，跨 depot 或跨 sub-route 移动客户容易破坏可行性。
- 本文希望解决什么：
  - 让编码层天然减少不合法 depot/customer 排列；
  - 用问题结构生成可行初始解；
  - 根据双目标支配关系自适应决定扰动类型和扰动强度；
  - 在局部搜索中只使用可维护 sub-route 可行性的邻域。

## 核心理念与算法流程

- 核心理念：先把一条 vehicle route 分解为若干由 depot 锚定的 sub-routes，客户只能按其产品来源和补货顺序插入合适的 sub-route；随后 VNS 不在任意节点序列上盲目扰动，而是在 depot 交换、客户迁移和子路线局部调整之间切换。
- 主要流程：
  1. 构造初始种群和每个客户的 nearest neighborhood set (NNS)。
  2. 用 SRFE 表示每辆车的路线：每个 sub-route 以固定 depot 开始，连续服务一组客户，然后返回原 depot 或进入下一个 depot-anchored sub-route。
  3. 初始化分两阶段：先随机把 depots 分配到 vehicle routes，并按容量约束把客户插入对应或后续 sub-route；再对所有 sub-routes 做 2-opt 优化。
  4. 对每个候选执行 adaptive shaking。若当前解被父代支配，说明搜索状态差，使用 Depot-Exchange (DE) 并按相对目标差异放大扰动强度；若当前解支配父代，保留该结构而不扰动；若二者互不支配，使用固定强度 2 的 Customer-Relocation (CR)。
  5. DE 在同一路线中选择来自不同 sub-routes 的两个 depots 交换，并临时移除受影响客户后重新插入。
  6. CR 从一条 route 取出客户并移动到另一条 route 的对应可行 sub-route。
  7. Local search 依次使用 SR-2-Opt、RE-DR 和 ANI：前者在 sub-route 内做 2-opt；RE-DR 只在同 sub-route 内随机交换且要求 route cost 改善；ANI 遍历客户的 NNS，在邻近节点两侧尝试满足全部约束的插入。
  8. 用非支配排序保留 elitist nondominated solutions，直到停止条件输出 nondominated set。
- 关键组成部分：GHDVRPSV model、Sub-Route Fusion Encoding (SRFE)、two-stage initialization、dominance-feedback adaptive shaking、Depot-Exchange、Customer-Relocation、SR-2-Opt、RE-DR、Adjacent Neighborhood Insertion (ANI)。
- 可能被修改的位置：VRP/MRTA/多仓配送的编码层、初始化层、VNS shaking 策略、局部搜索邻域、可行性保持机制。
- 必须保留的核心：sub-route 必须由 depot 锚定并表达补货前序；multi-source customer 必须服从后续 sub-route assignment；adaptive shaking 必须由当前解和父代的支配关系触发，而不是固定随机扰动。

## 实验证据

- 数据与设置：
  - 构造 25 个测试 cases，基于 TSPLIB 并加入 customer multi-demand 和 depot supply matrix。
  - 指标为 HV、IGD 和 C-metric；由于真实 Pareto front 未知，作者用所有算法运行期间获得的非支配 objective vectors 合成 approximate PF。
  - Python 3.4 实现，Intel i7-12650H 2.30GHz，16GB RAM；20 次独立运行。
  - 对比算法为 NSGA-II、CEOA、BVNS，均带 constraint checking；种群规模 50；Wilcoxon rank-sum test 显著性水平 0.05。
- 模型验证：
  - 用 Gurobi 对小规模 cases K1-K6 做 hierarchical mode 验证，其中 `F2` 优先级更高。
  - VNS-AS 在 K1-K3 匹配 Gurobi exact solutions；K4-K6 中 Gurobi 在 7200 s 内无法给出 exact solution，而 VNS-AS 能更快给出多个 nondominated solutions。
- 参数敏感性：
  - NNS 大小 `lambda` 对 ANI 有明显影响。K5 和 K7 的最佳设置分别约为 `0.3n` 和 `0.2n`，其余 cases 多为 `0.1n`。
  - 作者最终设定 `n<100` 时 `lambda=0.25n`，`n>=100` 时 `lambda=0.1n`，以平衡邻近探索和大规模计算成本。
- 综合对比结果：
  - HV：VNS-AS 在 24/25 个 cases 中显著优于 NSGA-II、CEOA 和 BVNS。
  - IGD：除 K21 外，VNS-AS 在所有 cases 上取得更低 IGD。
  - C-metric：25 个 cases 中，少于 10% 的 VNS-AS solutions 被其它算法支配；22/25 个 cases 中，对比算法超过 90% 的 solutions 被至少一个 VNS-AS solution 支配。
  - Pareto plots：K14、K18、K24 显示 VNS-AS 更接近 approximate PF；K14/K24 分布较均匀，K18 分布略弱但收敛性强。
- 真实应用证据：
  - 使用中国某物流公司数据，20 个 customers 和两个 depots，数据来自作者给出的 GitHub benchmark。
  - 与 MDSDVRP 对比：MDSDVRP travel cost 为 620，需要四条 routes，且客户 5、16、18 因两仓供应被重复访问；GHDVRPSV 只需两条 routes，travel cost 为 544，降低 12.3%。
  - 负载均衡上，MDSDVRP route length 差值为 98；GHDVRPSV 差值为 8，仅为 MDSDVRP 差值的 8.2%。
- 证据边界：
  - 对比算法参数未系统调优，作者在结论中明确承认为限制。
  - Benchmark 是从 TSPLIB 改造并加入需求/供应矩阵，真实案例规模较小。
  - 目标数为 2，方法对 many-objective 或更复杂随机需求/时间窗约束尚未验证。
  - SRFE 强依赖 depot-product-customer 的前序结构，迁移到其它 VRP 需重新定义 sub-route assignment 规则。

## 局限与未来工作

- 作者明确说明的局限：NSGA-II、CEOA、BVNS 的参数未调优，比较可能受参数影响。
- 作者未来工作：
  - 对对比算法参数做敏感性分析；
  - 给 GHDVRPSV 增加更多现实约束，使模型更贴近真实配送场景。
- 我们认为仍需确认的问题：
  - 随客户数、产品数、depot 数增加，SRFE 的客户重插和 ANI 检查成本是否会成为瓶颈。
  - DE 强度公式基于目标相对差异，目标尺度和归一化方式可能影响扰动强度。
  - 当前每个 depot 每辆车最多访问一次，若现实允许重复补货或动态库存，编码需要扩展。
  - 对含时间窗、车辆异构、随机需求、服务时间和道路时变成本的扩展尚未验证。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：仓库锚定子路线编码与支配反馈自适应 VNS。该知识面向强前序约束的多仓/多资源路径搜索，接口包含 depot-anchored encoding、可行初始化、支配反馈 shaking 和可行局部邻域，与区域压缩路径解码、业务约束多段染色体和分解 ILS 不重复。
- 暂留在论文卡中的方法、原理或架构启发：
  - “当前解支配父代时不扰动”是一种结构保护机制，可迁移到 VNS/ALNS 的 shake gate。
  - `lambda` 根据规模分段设置，反映邻近插入在小规模偏探索、大规模偏节省检查成本的实际折中。
  - RE-DR 的 gain check 很轻量，可作为所有组合邻域的局部过滤器。
- 局部创新线索：
  - 将 DE/CR 的选择从三分支规则扩展为 bandit 或 reinforcement learning operator selector。
  - 对 SRFE 增加 time-window-aware sub-route assignment，避免补货顺序可行但到达时间不可行。
  - 用 route-load entropy、depot utilization 或 customer product overlap 修正 DE 强度。
  - 将 NNS 从欧氏距离换成时间依赖路网距离、服务兼容性或 depot-product 覆盖相似度。
- 结构创新线索：
  - 构建强前序 VRP 通用框架：resource-anchor encoding、feasible assignment decoder、dominance/state-aware shaking、constraint-preserving local neighborhoods、archive selection。
  - 与分解式 ILS/VNS 结合：每个权重子问题运行 SRFE-VNS，archive 在不同 depot sequence 之间共享可行 sub-routes。
  - 与精确方法混合：固定 depot sequence 后，用 MILP 或 dynamic programming 精修客户分配和补货量。
