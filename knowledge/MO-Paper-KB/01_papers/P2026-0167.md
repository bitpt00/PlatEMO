# Towards Generalizable Meta-Deep Reinforcement Learning Algorithm for Multiobjective Traveling Salesman Problems

## 一句话理解

论文提出 MDRL-PFAN，用一个 preference-fused attention network 在同一模型内同时接收 MOTSP 实例和目标权重偏好，再用 Reptile 式元学习跨不同规模任务训练，使模型能 zero-shot 泛化到更大规模 Bi-TSP/Tri-TSP；推理时还可在小批量 adaptation tasks 上轻量 fine-tune，形成 MDRL-PFAN-FT 以进一步提升 HV 和非支配解数量。

## 问题与动机

- 研究问题和场景：multiobjective traveling salesman problem (MOTSP) 是典型多目标组合优化问题，需要在距离、燃料、时间或高度差等冲突目标之间生成 Pareto route set。
- 现有方法为什么不足：
  - Exact algorithms 难以在大规模 MOTSP 上枚举 Pareto-optimal solutions。
  - MOEA/heuristic 依赖 handcrafted rules 和固定参数，适配不同问题规模和结构时鲁棒性不足。
  - 早期 DRL-MOA 等多模型方法为不同 weight preferences 训练多个 submodels，训练成本和参数冗余高。
  - 现有 single-model DRL 虽能用偏好条件生成解，但面对明显大于训练规模的测试实例时仍会性能退化。
  - 有些 meta-learning 多目标 DRL 需要在每个 preference 上 fine-tune 单独模型，部署复杂度高。
- 本文希望解决什么：
  - 用一个偏好条件 attention 模型覆盖多权重偏好；
  - 用跨规模 meta-training 提升对 unseen problem sizes 的泛化；
  - 在推理时支持 zero-shot 和 few-shot 两种模式；
  - 通过轻量 fine-tuning 在同类大规模实例上摊销 adaptation cost。

## 核心理念与算法流程

- 核心理念：把目标权重偏好直接融合到节点特征编码中，使同一个神经构造器能随偏好生成不同 route；再把不同规模实例看作 meta-learning tasks，用 Reptile 的 inner-loop/outer-loop 学到一个对规模变化敏感度低、能快速适配的初始化。
- PFAN 模型：
  1. 输入 problem instance `x={x1,...,xn}` 和 preference weight vector `w`。
  2. Preference-fused mechanism 将 weight preference 作为 prior information 注入 node features，得到 preference-sensitive fused features。
  3. 将 fused features 投影到高维 embedding，并经过 `L=6` 层 multihead attention encoder；每层含 8 heads、feedforward、skip connection 和 batch normalization。
  4. Decoder 采用 autoregressive attention model 结构，逐步选择下一个 node，直到生成完整 tour sequence。
  5. 同一个 PFAN 在不同 `w` 下生成对应不同 scalarized subproblem 的 route，从而近似 Pareto front。
- MDRL-PFAN meta-training：
  1. 设 task distribution `T` 覆盖不同实例规模，weight distribution `W` 覆盖不同偏好。
  2. 每个 meta-iteration 从 `T` 采样若干 instance tasks。
  3. 对每个 task 从当前 meta-parameters `theta` 复制出 task-specific model。
  4. Inner loop 用 policy gradient/RL 训练 `K` steps；reward 来自 Tchebycheff decomposition 下的 scalarized route quality，不需要 ground-truth optimal labels。
  5. Outer loop 用 first-order Reptile 聚合 task-specific parameters，更新 meta-model；避免二阶 meta-gradient 的计算和显存开销。
  6. 训练结束得到 meta-model `theta*`。
- Inference：
  - Zero-shot：直接用 `theta*` 在 unseen instance sizes 和 weight vectors 上生成解，评估跨规模泛化。
  - Few-shot：先用小批 adaptation tasks 做轻量 fine-tuning，得到 `theta*f`，再用于同类型测试实例。作者称该 fine-tuned 版本为 MDRL-PFAN-FT。
- 可能被修改的位置：
  - Preference-fused transformation 可替换为 FiLM、hypernetwork、cross-attention、prompt token 或 graph positional encoding；
  - Reptile 可替换为 MAML、FOMAML、meta-SGD、learned optimizer 或 multi-task pretraining；
  - Reward decomposition 可替换为 Tchebycheff、PBI、R2、HV surrogate 或 preference-conditioned critic；
  - Fine-tuning task selection 可根据规模、目标数、图结构、uncertainty 或 online feedback 自适应。
- 必须保留的核心：
  - 单模型必须显式接收 preference weight，并在同一模型中覆盖多个 tradeoff；
  - meta-training 必须跨不同 problem scales/tasks，而不是只在单一规模上训练；
  - 推理时要区分 zero-shot generalization 与 few-shot adaptation；
  - 用 RL/policy gradient 训练 constructive policy，避免依赖大规模最优标签。

## 实验证据

- 实验设置：
  - 问题包括 Euclidean Bi-TSP 和 mixed Tri-TSP。Bi-TSP 使用两组二维坐标定义两个 distance objectives；Tri-TSP 额外加入一维 altitude，以高度差作为第三目标。
  - 标准测试实例为 KroAB100、KroAB150、KroAB200；跨规模泛化测试使用随机生成的 Bi-TSP500/750/1000 和 Tri-TSP500/750/1000。
  - 对比三类 evolutionary algorithms：NSGA-II、NSGA-III、MOEA/D；四类 DRL：DRL-MOA、PMOCO、CNH、WECA。
  - 指标包括 HV、非支配解数量 `|NDS|`、HV-Gap 和 runtime。
  - Meta-training 设置：`M=6000`，instance task size `T=[20,21,...,40]`，inner-loop Adam learning rate `1e-4`，weight decay `1e-6`，inner-loop steps `K=50`，batch size `B=64`，encoding layers `L=6`，attention heads `S=8`。
  - Fine-tuning adaptation task 为 1000 instances，batch size `Bf=10`；标准 KroAB、大规模 Bi-TSP、大规模 Tri-TSP 分别推荐 `Kf=10/20/30`。
- Training efficiency：
  - Bi-TSP training time：MDRL-PFAN 约 12.72 h，低于 PMOCO 13.34 h、CNH 13.58 h、WECA 12.95 h，远低于 DRL-MOA 45.62 h。
  - Tri-TSP training time：MDRL-PFAN 约 13.47 h，低于 PMOCO 14.01 h、CNH 14.33 h、WECA 13.71 h；DRL-MOA 因训练成本未纳入 Tri-TSP。
  - 作者认为训练效率来自偏好线性融合的轻量模型结构和 Reptile 一阶元更新。
- Fine-tuning efficiency：
  - 随 fine-tuning steps 增加，MDRL-PFAN-FT 性能提升但逐渐平台化；fine-tuning 时间随 steps 增加。
  - 作者选择 `Kf=10/20/30` 作为性能和时间折中；同类问题 fine-tune 一次后可直接用于多个测试实例。
- KroAB instances：
  - MDRL-PFAN 在 KroAB100/150 上 HV 略低于 CNH 和 WECA，但在更大 KroAB200 和与 evolutionary algorithms 比较中更有竞争力。
  - MDRL-PFAN-FT 在 KroAB100/150/200 上取得最高 HV 和更高 `|NDS|`，PF 覆盖更广且更接近坐标轴。
  - DRL methods runtime 普遍低于 evolutionary algorithms；DRL-MOA 因 multi-model architecture runtime 较高。
- Large-scale Bi-TSP：
  - 在 Bi-TSP500/750/1000 上，MDRL-PFAN 和 MDRL-PFAN-FT 的 HV 均高于 PMOCO、CNH、WECA。
  - MDRL-PFAN-FT 的 HV 分别约为 274684、625346、1121821，`|NDS|` 分别为 185、190、188，均为表中最好。
  - 随规模增大，PMOCO/CNH/WECA 的 HV-Gap 增大，CNH 退化最明显；MDRL-PFAN 保持更稳定的跨规模泛化。
- Large-scale Tri-TSP：
  - 在 Tri-TSP500/750/1000 上，MDRL-PFAN 和 MDRL-PFAN-FT 均获得更高 HV 和 `|NDS|`。
  - MDRL-PFAN-FT 的 HV 分别约为 146938036、503886963、1206941834，`|NDS|` 均为 210。
  - CNH 在 Tri-TSP1000 上 HV-Gap 达 17.24%，显示规模增长时泛化退化明显。
- Ablation and sensitivity：
  - 去掉 MLS 造成最大性能下降，说明跨规模元学习是泛化核心。
  - 去掉 PFM 也明显退化，说明把 weight preferences 融入编码很重要。
  - Inner-loop steps `K` 增大通常降低 HV-Gap，但收益会平台化；decaying outer-loop learning rate 最稳定，作者采用 `K=50` 和 decaying `epsilon`。
- 证据边界：
  - 训练规模集中在 20-40 节点，测试到 1000 节点虽显示泛化，但 ultra-large-scale 仍未验证。
  - 应用只覆盖 Bi-TSP/Tri-TSP 类 route problems，结构完全不同的 MOCOP 还需扩展。

## 局限与未来工作

- 作者明确说明的局限：
  - MDRL-PFAN 对 ultra-large-scale instances 的 scalability 仍需进一步探索。
  - 对 structurally diverse multiobjective problems 的适用性仍未验证。
- 作者未来工作：
  - 集成更高效网络结构，如 sparse attention，降低 inference overhead 并提升资源受限场景部署性。
  - 发展 hierarchical learning strategies，扩展到 ultra-large-scale problems。
  - 扩展 multitask generalization 到 multiobjective bin packing、job scheduling 等复杂 MOP。
- 我们认为仍需确认的问题：
  - 从 TSP 类图结构迁移到容量约束、时间窗、动态图或异构资源组合问题时，PFM 是否仍充分。
  - Fine-tuning adaptation tasks 如何选择才能最接近目标规模/结构。
  - 不同 preference distribution 下训练是否会覆盖所有 Pareto 区域。
  - 与强 hand-crafted local search hybrid 后，神经构造器的优势是否保持。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：跨规模偏好融合的元 DRL 组合优化。它提供了“偏好条件单模型 + 跨规模元训练 + 轻量适配”的通用结构，可迁移到路径、调度、装箱、资源分配等多目标组合优化。
- 暂留在论文卡中的方法、原理或架构启发：
  - Bi-TSP/Tri-TSP 具体 cost construction 是 benchmark 细节，不单独建场景卡。
  - KroAB 和 TSPLIB 组合实例属于实验设置，不单独建数据知识。
- 局部创新线索：
  - 将 preference fusion 从线性变换替换为 hypernetwork 或 cross-attention，增强复杂目标关系表达。
  - 用 active task sampling 在 meta-training 中优先抽取当前泛化最差的规模或图结构。
  - 在 fine-tuning 中加入少量 local search rollout 作为 self-improvement data。
  - 将 `|NDS|`、HV 或 coverage surrogate 融入 meta-objective，而不是只用 scalarized reward。
- 结构创新线索：
  - 构建“multi-scale task sampler -> preference-conditioned neural constructive policy -> Reptile meta-training -> zero/few-shot Pareto solver”的学习型多目标组合优化框架。
  - 将 meta-model 作为 MOEA 的 warm-start generator，再由局部搜索或 Pareto archive 修正，兼顾速度和最终质量。
