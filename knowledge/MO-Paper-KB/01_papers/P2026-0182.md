# Robust Multiobjective Evolutionary Algorithm Based on Surrogate-Assisted Robust Distance Metric

## 一句话理解

本文提出 RMOEA-SA：对每代真实评价过的种群训练目标级 RBF 代理，用代理预测每个候选在决策变量扰动邻域内的采样点目标值，再用这些预测点到名义目标值的目标空间距离之和构造 robust distance metric (RDM)，并把 RDM 作为额外目标参与环境选择，从而用较少真实评价同时追求 Pareto 最优性和扰动鲁棒性。

## 问题与动机

- 研究问题和场景：
  - Robust multiobjective optimization problems (RMOPs) 中，决策变量会受制造误差、材料波动、载荷变化或其他外部扰动影响；
  - 一个名义解在部署时可能落到其 `delta` 邻域中的任意位置，导致目标值波动；
  - 算法需要找到在目标空间中既接近 Pareto front、又对决策扰动不敏感的 robust Pareto solutions。
- 现有方法为什么不足：
  - 传统 RMOEA 常对每个候选生成 `H` 个扰动采样点并真实评价，种群大小为 `N` 时每代鲁棒性评估成本会变为 `N * H`；
  - mean effective function、dominance robustness、preference robustness、confidence metric 等鲁棒评价若依赖大量真实采样，难用于昂贵工程问题；
  - 代理辅助方法能降成本，但如何在有限真实评价下准确估计扰动邻域表现，并在鲁棒性与最优性之间做环境选择，仍不直接。
- 本文希望解决什么：
  - 用真实评价档案训练 RBF，替代扰动采样点的真实评价；
  - 用目标空间扰动距离直接度量解的局部鲁棒性；
  - 不把鲁棒性压成固定惩罚项，而是把 RDM 作为一个新目标，让环境选择在 `(M+1)` 维目标空间中自动折中。

## 核心理念与算法流程

- Robust distance metric (RDM) 的直觉：
  - 若名义解 `x_i` 的扰动采样点在目标空间中围绕 `F(x_i)` 分布很近，说明部署扰动对性能影响小；
  - 若这些采样点目标值分散很远，说明该解对决策变量扰动敏感，鲁棒性差；
  - 因此可以用采样点目标值到名义目标值的欧氏距离和来衡量 robustness。
- RMOEA-SA 主循环：
  - 初始化种群 `P0`，真实评价并放入外部档案 `A0`；
  - 每代用档案 `A_t` 为每个目标训练一个 RBF surrogate；
  - 通过 tournament selection、SBX 和 polynomial mutation 生成 offspring `Q_t`；
  - 只对 offspring 做真实目标评价；
  - 合并 `R = P_t union Q_t`；
  - 对 `R` 中每个个体执行 surrogate-assisted RDM 计算；
  - 将原始 `M` 个目标与归一化 RDM 拼成 `(M+1)` 个目标；
  - 用 nondominated sorting 和 crowding distance 做环境选择，得到下一代 `P_{t+1}`；
  - 将 `Q_t` 加入档案并删除重复解，下一代重新训练 RBF。
- Surrogate-assisted RDM：
  - 对每个个体，在最大扰动范围 `delta_max` 内用 Latin hypercube sampling 生成 `H` 个邻域采样点；
  - 用 RBF 预测这些采样点的各目标值；
  - 计算每个采样点预测目标向量与名义解真实目标向量之间的欧氏距离；
  - 对 `H` 个距离求和得到 `RDM(i)`，再在当前合并种群中归一化；
  - `RDM` 越小表示扰动后目标漂移越小，鲁棒性越强。
- 增量外部档案：
  - 档案保存所有真实评价过的 offspring 和历史解；
  - 算法没有单独的 infill criterion，也不把邻域采样点加入真实评价队列；
  - RBF 每代用累积档案重训，使邻域采样点只消耗代理预测成本；
  - 作者强调每代真实评价从 `H * N` 降为 `N`。
- 必须保留的核心：
  - “真实评价档案训练代理 -> 扰动邻域代理预测 -> 目标空间距离度量鲁棒性 -> RDM 作为额外目标选择”这条链路缺一不可。

## 实验证据

- 测试与参数：
  - 平台：MATLAB R2020b、PlatEMO、Intel Xeon Gold 6248R 3.0GHz；
  - 每个问题独立运行 30 次；
  - 主实验真实评价上限为 2000；
  - TP1-TP5 设 `D=10`，TP6-TP9 设 `D=4`，二目标问题种群大小 `N=100`；
  - 算子为 SBX 和 polynomial mutation，`eta_c=20`、`pc=1.0`、`eta_m=20`。
- 对比算法：
  - TP/ZDT/IMOP/CEC2024 等实验主要比较 RMOEA-REDE、CNSDE/DVC、MOEA-RE、NSGAII-DTI、RMOEA/DVA；
  - CSI 图中还出现 DSSEA；
  - 显著性采用 Wilcoxon rank-sum test，显著性水平 0.05；
  - 指标主要为 IGD 和 HV，CEC2024 和高维实验使用 IGD。
- TP/ZDT/IMOP 结果：
  - 在 TP1、TP3、TP4、TP5 等问题上，RMOEA-SA 获得最小 IGD 和最高 HV；
  - TP6/TP7 的 IGD 不总是最好，但 HV 最好，作者认为解集质量和分布仍有优势；
  - TP9 上作者称只有 RMOEA-SA 能有效逼近 robust Pareto front；
  - ZDT1/ZDT2 上 RMOEA-SA 同时取得最好 IGD/HV，ZDT3 上 HV 仍具竞争力；
  - IMOP1-IMOP4 上 RMOEA-SA 整体在 IGD/HV 上优于竞争算法。
- 两个真实/工程问题：
  - Reinforced concrete beam design problem (RE2-1)：二目标混合变量问题，同时最小化材料成本和结构柔度，并满足弯曲承载力和几何比例约束；RMOEA-SA 在 30 次运行和 2000 次真实评价下取得最低 IGD、最高 HV 和较小标准差；
  - Car side impact (CSI)：同时最小化车重和平均肋骨变形，包含 11 个设计变量和决策变量扰动；箱线图中 RMOEA-SA 的 IGD 中位数和四分位范围最低，作者据此认为其在扰动下更稳定。
- CEC2024 与高维实验：
  - CEC2024 选择 MaOP1-MaOP10，三目标七变量，RMOEA-SA 在十个问题上取得最小 IGD；
  - 高维扩展测试 50-D 和 100-D 的 ZDT/IMOP；
  - 50-D 上 RMOEA-SA 多数问题取得最小 IGD；
  - 100-D 上仍多为最低或接近最低，但作者承认维度升高后 RBF 预测误差累积和邻域近似困难会造成一定性能下降。
- 证据边界：
  - 多数表格在 Markdown 中为图片占位，无法逐项核验数值；
  - 真实应用只报告算法比较指标，没有展开完整工程模型和约束细节；
  - 代理模型使用全局 RBF，高维下可靠性依赖档案质量和扰动邻域覆盖。

## 局限与未来工作

- 作者明确说明的未来方向：
  - 提高有限评价下 surrogate prediction accuracy；
  - 将 uncertainty prediction 与 principled infill sampling/model management 结合；
  - 发展 localized surrogate models；
  - 融合 Bayesian optimization，以适配 large-scale 和 dynamic RMOPs；
  - 扩展到更复杂的不确定环境和多样约束。
- 我们认为仍需确认的问题：
  - RDM 只度量目标空间漂移幅度，可能无法区分均值偏移、尾部风险和约束失效；
  - 把 RDM 作为额外目标会在 many-objective 场景中进一步削弱非支配排序选择压力；
  - 全局 RBF 在高维或分段可行域中可能对邻域扰动预测不稳；
  - 没有 infill/model management 时，档案是否能主动覆盖鲁棒性最关键的扰动边界；
  - 对混合变量、离散扰动和非盒形不确定集的采样与距离度量还需改造。

- 局部创新线索：
  - 将 RDM 扩展为 variance、quantile、CVaR、failure probability 或 regret distance；
  - 在 RDM 中加入代理不确定性，距离大且不确定性大的区域优先真实评价；
  - 用局部 RBF、sparse GP、ensemble surrogate 或 conformal interval 替代单一全局 RBF；
  - 对不同 reference vector 或 Pareto 区域分别归一化/调节 RDM，避免统一鲁棒压力误伤边界解；
  - 把 constraint violation 的扰动距离与目标距离合并成 robust feasibility distance。
- 结构创新线索：
  - 构建通用 robust-surrogate selection layer：任意 MOEA 只需提供名义真实目标，鲁棒层负责邻域代理评估和额外目标扩展；
  - 与 expensive MOEA infill 结合：RDM 用于选择，代理不确定性和邻域覆盖用于决定哪些候选/采样点真实评价；
  - 与 dynamic RMOP 结合：用历史环境档案训练时间感知代理，并让 RDM 随环境变化自适应扰动范围；
  - 与偏好优化结合：决策者可指定最低鲁棒性阈值或 RDM 参考点，而不是完全交给非支配排序。
