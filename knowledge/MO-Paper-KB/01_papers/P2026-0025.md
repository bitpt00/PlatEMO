# MoBLS: A broad learning system with multi-objective optimization

## 一句话理解

本文把传统 BLS 的单目标正则化训练重构为“模型近似能力 + 隐层权重稀疏性”的双目标搜索。MoBLS 先用强凸稀疏算子把 hidden layer weights 稀疏化，再用 generalized Pareto 维护保留 sparse/non-sparse 的折中个体，最后用同时利用 global 和 winner 信息的 GWSO 优化群体，并用 half-threshold 剪掉低贡献 hidden neurons。

## 问题与动机

- 研究对象：Broad Learning System (BLS)。
- 主要问题：
  - BLS 相比深层网络训练快，但性能强依赖 hidden/output weights；
  - mapped feature layer 和 enhanced feature layer 的 hidden weights 通常随机初始化，缺少稀疏约束；
  - BLS、MRBLS、OBLS、GC-BLS 等变体对 neuron 数量敏感；
  - 传统 BLS cost function 把 approximation error 和 weight sparsity 用单个 regularization parameter 合成，隐藏了两个目标之间的 tradeoff。
- 本文希望解决：
  - 从多目标角度重构 BLS 训练；
  - 同时获得较好 approximation degree 和较稀疏 hidden weights；
  - 降低模型对 neuron 数量组合的敏感性；
  - 在比 PSO 更合适的时间成本下搜索稳健 BLS 结构。

## 核心算法流程

- MoBLS 的两个目标：
  - approximation objective：网络输出接近 label；
  - sparsity objective：hidden layer weights 稀疏。
- 每轮 population iteration：
  - 对 mapped feature layer weights `U` 和 enhanced feature layer weights `V` 应用 strongly convex sparse operator；
  - 用 sparse 和 non-sparse hidden weights 分别计算 output layer weights；
  - 评价 approximation degree 和 sparsity；
  - 用 generalized Pareto structure maintenance 在 sparse/non-sparse 个体之间维护种群；
  - 用 GWSO 进一步优化 population。
- 训练结束后：
  - 对 mapped feature nodes 和 enhanced feature nodes 执行 half-threshold pruning；
  - 基于剪枝后的 sparse hidden layer weights 重新计算 output layer weights；
  - 输出 MoBLS weights。

## 强凸稀疏算子

- 作者聚焦 hidden layer weights：
  - `U = [U1,...,UN]`：mapped feature layer weights；
  - `V = [v1,...,vM]`：enhanced feature layer weights。
- 稀疏算子对每个 hidden weight element `nu` 构造 strongly convex sparse optimization function。
- 稀疏系数 `iota(t)` 随 population iteration 线性下降：
  - 早期更强稀疏化，便于压缩冗余权重；
  - 后期稀疏压力减弱，避免过度剪掉有效表示。
- 根据 subgradient optimization 得到 sparse hidden weights `U_sparse` 和 `V_sparse`。
- 直观上，该算子相当于给 hidden weights 做可插拔 shrinkage/proximal sparsification，再把 sparse 结果送入双目标评价。

## Generalized Pareto 维护

- 稀疏操作后同时存在 original population 和 sparsified population，规模变为 `2P`。
- 为控制存储和计算，需要回到 `P` 个体。
- 维护原则：
  - sparse individuals 通常更符合模型压缩目标，因此以 sparse population 为基底；
  - 同时保留部分 non-sparse 个体，避免只追稀疏导致 approximation 下降。
- 两条替换规则：
  - 如果某个 non-sparse individual 在 approximation degree 和 sparsity degree 上都不劣于 sparse population 的最小值，则替换对应 sparse individual；
  - 否则与对应位置的 sparse individual 成对比较，只要在 approximation 或 sparsity 中有一项不劣，就以 `0.5` 概率替换。

## GWSO 群体竞争优化

- GWSO 受 PSO 和 CSO 启发，但不是简单 CSO：
  - 先 pair 当前 population 中的 individuals；
  - 根据 approximation degree 判断 winner 和 loser；
  - winner 也会利用 global best/最高 approximation individual 的信息更新；
  - loser 使用 winner 信息更新；
  - 因而同时融合 global information 和 winner information。
- 相比 PSO：
  - 避免每个粒子都同时追随 individual best 和 global best 的较高成本；
  - 更接近竞争式成对更新。
- 相比 CSO：
  - 传统 CSO 中 winner 直接进入下一代；
  - GWSO 让 winner 也继续吸收 global 信息，减少 winner 停滞。

## Half-Threshold 剪枝

- mapped feature layer 可视为 `NK` 个 neurons：
  - 对第 `i` 个 neuron，统计其输入连接权重中大于 threshold `theta` 的元素数量；
  - 若该数量大于 `floor(D/2)`，认为该 neuron 能充分利用 feature information，保留；
  - 否则删除。
- enhanced feature layer 可视为 `M` 个 neurons：
  - 对第 `j` 个 neuron，统计其连接 mapped feature nodes 的权重中大于 `theta` 的元素数量；
  - 若该数量大于 `floor(NK/2)`，保留；
  - 否则删除。
- 该剪枝规则把 hidden weight sparsity 转化为实际网络结构压缩，从而减少 inference redundancy。

## 实验设置

- 数据集：Connectionist、Ecoli、Fertility、Glass、Hayes、Heart、Ionosphere、Iris、Sonar。
- 对比模型：
  - classic BLS；
  - MRBLS；
  - OBLS；
  - GC-BLS；
  - `MoBLS_PSO`；
  - `MoBLS_CSO`；
  - MoBLS。
- 训练/测试：
  - 随机选择 60% samples 作为 training set，其余作为 test set；
  - 10 次独立实验取平均；
  - MATLAB 2023b，5 cores parallel，Intel i7-14700KF。
- neuron 组合：
  - mapped feature layer：`N in {8,16}`，`K in {8,16}`；
  - enhanced feature layer：`M in {40,80,160}`；
  - 共 12 种 `(N x K) x M` 组合。
- 关键参数：
  - input normalized to `[-1,1]`；
  - label one-hot encoding；
  - initial `U/V` elements sampled from `[-1,1]`；
  - activation functions 为 logsig；
  - regularization `lambda=1e-5`；
  - MoBLS：`T=50`、`P=100`、`b1=0.5`、`b2=1.5`、`theta=0.1`。

## 主要实验发现

- neuron robustness：
  - 在 Sonar、Glass、Fertility 以及 Appendix 的 Connectionist、Iris、Hayes、Ionosphere、Ecoli、Heart 上，BLS/MRBLS/OBLS/GC-BLS 对 neuron 数量组合明显敏感；
  - MoBLS 在不同 neuron 组合下表现更稳健；
  - `MoBLS_PSO` 通常也稳定但整体略弱于 MoBLS；
  - `MoBLS_CSO` 在部分数据集上可竞争，但跨 neuron 组合鲁棒性不足。
- statistical analysis：
  - 作者用 Levene test/boxplot-style 指标比较 lower bound、Q1、median、Q3、upper bound；
  - 在 Sonar、Glass、Fertility 及 Appendix 数据集上，MoBLS 的 worst-case test accuracy 接近或超过其他 BLS 变体的 best result；
  - 作者据此认为 MoBLS 相对 classic BLS 和 SOTA variants 有统计显著优势。
- GWSO 贡献：
  - 与 `MoBLS_PSO`、`MoBLS_CSO` 比较，MoBLS 通常取得更好的 generalization；
  - 作者认为 GWSO 能比 PSO/CSO 更好地适配该多目标 BLS 框架。
- 时间消耗：
  - BLS 训练时间最短，MRBLS/OBLS/GC-BLS 时间更高；
  - population-based MoBLS variants 单次训练开销进一步增加；
  - 但传统 BLS variants 为获得理想性能需要尝试更多 neuron 组合，因此 theoretical optimal training time 不一定更低；
  - population-based models 因结构更稀疏，inference time 显著短于 BLS/MRBLS/OBLS/GC-BLS；
  - MoBLS 在性能和训练时间之间形成相对折中。

## 与知识库相关的设计知识

- 新增/关联设计知识：
  - `K-approximation-sparsity-multiobjective-broad-learning`：近似-稀疏双目标宽度学习训练。
- 与已有设计知识的区别：
  - 不同于 `K-initial-convergence-sampling-reverse-winner-cso`：该知识改造 CSO/PSO 的初始化与 loser update；本文的 GWSO 是 MoBLS 训练框架中的 population optimizer，并且 winner 也吸收 global 信息。
  - 不同于 `K-game-competitive-dual-population-resource-allocation`：该知识用于 CMOEA 主/辅种群资源分配；本文只有一个模型训练 population，不涉及主辅约束搜索。
  - 不同于稀疏大规模 MOO 变量选择类知识：本文稀疏对象是 BLS hidden layer weights 和 neurons，不是优化问题决策变量的稀疏 Pareto 解。
  - 不同于 NAS 类知识：本文不搜索深层神经架构拓扑，而是在 BLS 宽度结构内通过双目标训练和阈值剪枝获得稳健稀疏模型。

## 局限与未来工作

- 主要验证分类数据集，没有覆盖 regression、streaming、incremental BLS 或工业在线学习。
- 强凸稀疏算子、Pareto 维护、GWSO 和 half-threshold pruning 同时出现，消融主要通过 `MoBLS_PSO/MoBLS_CSO` 验证 optimizer，尚未完全隔离每个组件。
- population-based 训练开销高于 classic BLS 单次训练。
- 作者未来计划将该 multi-objective optimization mechanism 扩展到 incremental broad learning system。
