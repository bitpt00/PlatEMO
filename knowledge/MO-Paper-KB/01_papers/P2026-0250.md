# Multi-Objective Kernel Ridge Regression-Assisted Subproblem Co-Optimization for Expensive Multi-Objective Binary Optimization

## 一句话理解

本文提出 MOKRR-SCo，用共享加权 Hamming kernel 的多输出 KRR 同时拟合多个目标，再在 MOEA/D 式子问题上用代理模型迭代生成候选，最后优先真实评价相对已评价 archive 更稀疏的候选，以解决昂贵二进制多目标优化中样本少、目标独立建模低效和贪婪代理搜索易早熟的问题。

## 问题与动机

- 研究问题：expensive multi-objective binary optimization problems (EMBOPs)，例如特征选择、关键节点检测和模式挖掘；解为 `D` 维二进制向量，单次真实评价昂贵。
- 现有方法的不足：
  - 传统 MOEA 通常需要大量真实评价，在昂贵二进制问题上不可行；
  - RF/RBF 等代理常逐目标独立训练，忽略目标间相关性，有限样本下数据利用率低；
  - 普通 Hamming distance 只统计 bit 是否不同，难表达不同变量对目标空间影响的差异；
  - 一次性 pre-screening 太粗，容易漏掉有价值候选；贪婪 local search 又过度依赖代理精度，容易被有限样本下的代理误差带偏；
  - 连续昂贵优化 SAEA 的搜索算子迁移到二进制空间时通常不自然。
- 本文希望解决什么：在严格真实评价预算下，同时提高二进制代理模型的准确性、分解子问题搜索的协同效率，以及真实评价选点的多样性鲁棒性。

## 核心理念与算法流程

- 核心框架：
  1. 初始化真实评价 archive `Arc`，生成 `N_lambda` 个权重向量并估计 ideal point；
  2. 每轮针对每个权重子问题训练统一的 MOKRR 多目标代理；
  3. 用 MSCO 从共享 archive 中选取当前子问题的父代，并在代理上进行 `t_max` 次子问题协同优化；
  4. 用 DDISC 从该子问题的候选种群 `P_k` 中选择未评价且与已评价 archive 最稀疏的候选；
  5. 对该候选做真实评价，加入 archive，更新 ideal point 和所有 scalarizing values；
  6. 评价预算耗尽后输出 archive 中的非支配解。
- MOKRR 多目标代理：
  - 使用 kernel ridge regression 的多输出形式，回归系数矩阵同时对应所有目标；
  - 采用 shared weighted Hamming kernel，所有目标共享同一核矩阵；
  - 变量重要性向量 `theta` 由样本对的 bit 差异与目标空间差异估计，再归一化；
  - 与逐目标 KRR 不同，MOKRR 通过共享 kernel 捕捉 inter-objective correlations，并提高有限样本下的建模效率。
- MSCO 子问题协同优化：
  - 对每个权重向量，从全局 archive 中选择 scalarizing value 最好的 `N` 个解作为父代 `P_k`，而不是只使用子问题本地历史；
  - offspring 由 uniform crossover 和 bit-flip mutation 生成；
  - mutation probability 由共享 mutation rate `p_m=1/D` 和 MOKRR 变量重要性共同决定，使关键变量更容易被扰动；
  - 子代由 MOKRR 预测目标值，并用预测 scalarizing value 与父代比较，若更好则替换；
  - MSCO 内部会用代理预测的 offspring 更新 temporary ideal point，避免固定 ideal point 偏置搜索方向。
- DDISC 多样性驱动 infill：
  - MSCO 产出的 `P_k` 都已被代理优化过，不能只按预测 scalarizing value 贪婪选最好；
  - DDISC 计算每个候选到已评价 archive 的 Hamming 距离稀疏指标；
  - 按稀疏度降序选择尚未真实评价的候选，以降低代理误差导致的局部早熟，并补充未探索二进制区域。
- 默认参数：
  - `N_max=40`，`N_lambda=21`，`t_max=20`，`mu=0.01`；
  - population size 随 FE 从 `N_max` 自适应降到 `N_min`，早期偏探索、后期偏开发。

## 实验证据

- 实验设置：
  - Benchmark：multiobjective knapsack problem (MOKP) 和 multiobjective NK-landscapes (MNK)；
  - 每类 3 个独立实例，目标数 `M in {2,3}`，维度 `D in {30,50,100,150,200}`，共 60 个测试实例；
  - 最大真实评价数 `MaxFEs=500`，每个算法 20 次独立运行；
  - 指标：IGD+ 和 HV；参数敏感性和消融主要用 IGD+；
  - 真实 PF 未知时，用 NSGA-II 在 population size 1000、`10^6` FE 下得到的非支配解作为 IGD+ 参考集。
- 参数敏感性：
  - `N_max=40` 排名最好；过大的 `N_max=80/100` 显著退化；
  - `N_lambda=21` 在子问题覆盖与每个子问题预算之间较平衡；太小多样性不足，太大每个子问题资源不足；
  - `t_max=20` 在代理开发强度和内部计算成本之间较稳；
  - `mu` 在 `1e-5` 到 `0.1` 之间差异不显著，作者推荐 `0.01`。
- 消融实验：
  - 相比 RF-SCo 和 RBF-SCo，MOKRR-SCo 分别在 16/20 和 15/20 个问题上显著更好；但低维 MOKP 上 RF/RBF 有时更好。
  - MOKRR-SCo 全部优于 noVIE 变体，说明变量重要性加权 kernel 有贡献。
  - MOKRR-SCo 全部优于逐目标独立 KRR 变体，支持多目标联合建模。
  - 相比 MOKRR-VNS，MOKRR-SCo 在 13/20 个问题上显著更好，只在 3 个问题上更差，支持 MSCO 相比预定义邻域搜索更适合当前框架。
  - 相比 convergence-driven infill `CDISC`，DDISC 在 9/20 个问题上显著更好、2 个问题上更差；高维三目标 MNK 上多样性收益不能完全抵消收敛损失。
- 对比算法：
  - 对比 NSGA-II、SMS-EMOA、MOEA/D、MCEA/D、LDS-AF、MOEA/D-RFTS、SANS；
  - 在 60 个测试实例上，MOKRR-SCo 有 53 个 best performance；
  - Wilcoxon 统计中，相比上述七个算法，MOKRR-SCo 显著更好的实例数分别为 60、60、57、56、53、51、60；
  - 平均排名为 1.22，Friedman test 的 `p<0.05` 支持整体优势；
  - 收敛曲线显示 MOKRR-SCo 在早期有限评价下收敛更快，并随 FE 增加保持改进。
- 真实问题：
  - Multi-objective feature selection (MOFS) 使用 10 个数据集；
  - HV 统计中，MOKRR-SCo 在 9 个数据集上显著优于所有对比算法，仅与 SANS 在 1 个数据集上统计相当；
  - Friedman ranking 中 MOKRR-SCo 排名第一。

## 局限与未来工作

- 作者明确说明的局限：
  - 在少数低维 MOKP 问题上，MOKRR-SCo 低于 MCEA/D、MOEA/D-RFTS 或 LDS-AF；
  - 这些低维问题中 MOKRR 预测精度仍高于 RF/RBF，但 RF 替换 MOKRR 后整体框架有时优化更好，说明问题可能来自 surrogate、search 和 sampling 的相互作用，而不是单纯预测误差；
  - DDISC 在复杂高维三目标 MNK 上有时会牺牲收敛。
- 作者未来工作：
  - 扩展到 large-scale expensive multi-objective binary optimization；
  - 引入更先进的 model management，提高效率和可扩展性。
- 我们认为仍需确认的问题：
  - MOKRR 的预测准确性、scalarizing 排序准确性和最终 infill 贡献之间并不总一致，后续应直接评估 selection contribution；
  - `N_lambda=21` 在更高目标数或更紧评价预算下是否仍合适；
  - 变量重要性估计依赖已评价样本对，早期样本少时可能不稳；
  - 稀疏 Hamming 距离是否能表示真实目标空间信息量，尤其存在等价编码或强 epistasis 时。

## 可复用知识与创新线索

- 已建立设计知识：[共享汉明核 MOKRR 子问题协同](../02_design_knowledge/K-shared-hamming-mokrr-subproblem-infill.md)。
- 局部创新线索：
  - 将 DDISC 改成“预测收敛 + Hamming 稀疏 + surrogate uncertainty”的混合 infill，而不是纯稀疏；
  - 用 pairwise rank accuracy、scalarizing Kendall tau 或真实贡献历史选择 MOKRR/RF/RBF，而不是固定 MOKRR；
  - 对每个子问题学习局部变量重要性，使 mutation bias 更贴近权重方向；
  - 在早期小样本阶段用 RF/RBF/MOKRR ensemble，样本足够后再硬切换到 MOKRR。
- 结构创新线索：
  - 构建二进制昂贵优化通用管线：多输出结构化 kernel 代理、共享 archive 子问题协同、稀疏/不确定性 infill、真实评价闭环；
  - 与特征选择 filter 预筛结合：filter 先给低成本先验，MOKRR 再学习目标相关的 residual 或 rank；
  - 与多任务/多数据集特征选择结合：共享 kernel 可扩展为跨任务 kernel，把任务间相似性纳入 archive 协同。
