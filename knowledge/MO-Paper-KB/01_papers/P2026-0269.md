# Topology-Guided Knowledge Transfer for Multiobjective Multitask Optimization

## 一句话理解

本文提出 MMTO-TGT：在多目标多任务优化中，用 SOM 在源/目标高质量解联合集合上构造拓扑邻域，为每个目标父代提取局部 Pareto set manifold 知识，再用高斯采样、支配关系条件化二次生成和收敛/多样性联合反馈来自适应控制迁移概率。

## 问题与动机

- 研究问题和场景：多目标多任务优化需要同时求解多个相关 MOP，并通过跨任务知识迁移提升每个任务的 Pareto set/Pareto front 搜索质量。
- 现有算法为什么不足：作者认为多数 MMTO 方法迁移的是个体基因、总体分布模型或演化方向，忽略了 Pareto set 的内在几何结构；已有 manifold-based transfer 常使用单一全局映射，难以描述 PS 局部区域之间差异；任务 PS/PF 可能断裂、离散、退化或局部结构不一致，简单全局相似性和固定迁移率容易产生负迁移。
- 本文希望解决什么：为每个目标父代构造与其局部相关的跨任务拓扑邻域，提取局部流形知识并生成迁移后代；同时用 KT 与 self-evolution 的长期收敛和多样性贡献在线调节迁移概率。

## 核心理念与算法流程

- 核心理念：如果源任务和目标任务中的高质量解在统一解空间中局部接近，它们共同支撑的邻域可能落在目标任务有前景的 PS 局部流形附近。SOM 可保留拓扑关系，避免只依赖全局分布映射。
- 主要流程：
  1. 对每个任务维护一个独立种群，初始化 transfer probability `delta_t=0.15`。
  2. 每代对每个任务按 `rand() < delta_t` 决定走 KT 路径或 self-evolution 路径。
  3. KT 路径随机选一个源任务，从源/目标种群中各取 rank 最优 50% elite，统一维度后在并集上训练 SOM。
  4. 对每个目标 elite 父代，映射到 best-matching neuron，取 latent grid 上 K 个最近神经元及自身神经元的权重向量作为局部 manifold knowledge。
  5. 用这些权重向量估计多元高斯分布并采样第一个迁移后代 `o1`。
  6. 根据 `o1` 与父代 `x` 的 Pareto 支配关系生成第二个后代：若 `o1` 支配 `x`，沿成功方向继续推进；若 `x` 支配 `o1`，做 mirror sampling；若互不支配，从源 elite 中随机取解，定位其 SOM 邻域并做多样化重采样。
  7. 后代评价后与父代合并，采用 improved strength Pareto-based environmental selection。
  8. 初始 10% 代后，累计 KT 和 self-evolution 后代在 convergence improvement 与 exclusive HV diversity 上的贡献，并用平滑 reward 更新 `delta_t`。
- 关键组成部分：
  - Multi-population MMTO 框架：每个任务独立进化，显式跨任务协作。
  - SOM topology learning：在源/目标 elite 并集上学习跨任务结构邻域。
  - Local Gaussian manifold model：用目标父代附近的 SOM weight vectors 估计局部高斯，生成 transferred offspring。
  - Dominance-conditioned refinement：根据第一次迁移效果决定 exploitation、mirror correction 或 diversified source resampling。
  - Transfer adaptation：用 KT/self-evolution 的长期平均收敛和多样性贡献调节迁移概率，缓解负迁移。
- 可能被修改的位置：SOM 可替换为 growing neural gas、graph/Spectral/GMM 等拓扑建模；高斯模型可替换为 mixture/flow；源任务选择可由随机改为相似性图；支配关系三策略可扩展为 operator pool；transfer adaptation 可换为 bandit 或 source-target pair 级 credit。
- 必须保留的核心：局部跨任务结构邻域，而非全局任务映射；迁移后代生成要使用目标父代附近的 source+target 高质量结构；迁移强度必须有负迁移反馈调节。

## 实验证据

- 测试问题和对比算法：
  - Benchmark 包括 B17/CEC2017、B21/CEC2021-CPLX、本文构造的十任务 MTUF，以及退化/约束的 MTDTLZ 分析。
  - 真实应用包括四个 OPF case，每个两个受约束任务；两个 SOPM case，每个三个受约束任务。
  - 对比算法包括 3 个 single-task MOEA：AR-MOEA、MSEA、PPSO；7 个 MMTO 算法：MO-MFEA-II、MTEA-D-DN、KR-MTEA、EMT-GS、MTDE-MKTA、MTEA-DCK、MO-MTEA-PAE。
  - 每个算法 30 次独立运行；每任务种群规模 100；B17/B21/OPF 1000 代，SOPM 2000 代；指标为 IGD+ 和 HV，Wilcoxon rank-sum test 显著性 0.05。
- 主要实验结论：
  - B17 上 MMTO-TGT 的 IGD+ 平均排名 3.00、HV 平均排名 3.64，均为最低；作者认为其在多数问题上显著优于竞争算法，且收敛更快。
  - B21 上 IGD+ 排名 2.80、HV 排名 3.25，仍为最佳；作者指出 B21 更异质且 PS 结构更复杂，SOM 邻域在局部 PS 相似任务上更有优势。
  - MTUF 上 IGD+ 排名 2.00、HV 排名 2.15，整体最优；作者认为其在离散/断裂 PS/PF 等复杂结构上保持鲁棒。
  - 运行时间为中等水平，高于部分轻量 baseline，但低于 PPSO、EMT-GS 等最耗时算法；SOM 只在 KT 调用时训练，因此总体可接受。
  - MTDTLZ 退化/约束 PS 分析中，MMTO-TGT 仍取得 competitive results；作者观察到 degenerate fronts 下第一次高斯采样更少支配父代，说明 SOM 拓扑学习精度会受退化影响，但三种补充策略保持了有效性。
  - 真实 OPF/SOPM 上，MMTO-TGT 在 14 个应用实例中总体平均排名 2.14 最佳，并在多数任务上 HV 最优或显著优于对比算法。
- 消融或机制证据：
  - wo-KT 去掉跨任务迁移后最弱，IGD+ 中 44 个 case 败、3 个平；说明 inter-task KT 是主要贡献。
  - wo-TA 去掉 transfer adaptation 后明显弱于完整方法，说明固定迁移概率会在 beneficial/harmful 阶段失配。
  - wo-PD 去掉 Pareto dominance-based generation 后变差，说明支配关系条件化的第二后代有作用。
  - wo-SN 不构建跨任务结构邻域，只在目标任务自身训练 SOM，也弱于完整方法，说明源任务 manifold knowledge 提供额外收益。
  - MMTO-LPT 用 LPCA 替换 SOM 后多数问题变弱，尤其复杂离散/断裂 PS/PF 上，说明 model-free SOM 拓扑邻域比局部线性子空间更稳。
  - 参数分析建议 `K=8`、初始 `delta=0.15`、`alpha1=0.60`、`alpha2=0.10`。
- 证据边界：
  - 详细逐问题数值、收敛曲线和真实应用表格多在 supplementary，正文主要给统计汇总。
  - 作者明确指出并非所有 MOP 都满足 `(m-1)` 维 PS manifold 假设；退化和等式约束问题会降低 SOM 拓扑学习精度。
  - B17-P8 上 MTEA-D-DN 更好，作者认为多模态问题中 decomposition 框架保持 diversity 有优势。
  - B21-P7 等低 cross-task PS similarity 问题中，性能更依赖 operator suitability，KR-MTEA/MO-MTEA-PAE 等多算子方法可竞争。

## 局限与未来工作

- 作者明确说明的局限：
  - PS regularity 假设不适用于所有 MOP，退化或等式约束问题可能不满足 `(m-1)` 维 manifold。
  - 在 degenerate fronts 上，SOM-based topology learning 精度下降，第一次高斯采样较少直接支配父代。
  - SOM 训练和环境选择带来额外计算成本。
- 作者未来工作：
  - 研究更可扩展、对退化更鲁棒的 topology-preserving 方法替代 SOM，例如 growing neural gas；
  - 选择更高效的拓扑建模方法；
  - 引入更高效的非支配排序以降低环境选择成本。
- 我们认为仍需确认的问题：
  - SOM grid 维度按目标数固定，面对 many-objective 或不规则/多段 PS 是否足够。
  - 随机 source population 选择是否会浪费低相似任务上的 KT 调用，是否应建立 source-target task graph。
  - KT contribution 按整任务累计，是否需要细化到 source-target pair、局部神经元邻域或 generation strategy。
  - 维度不同时 zero-padding/truncation 可能破坏变量语义，复杂异构任务需要更可靠映射。
