# 约束多目标优化的自适应约束违反评估框架

## 一句话理解

本文把 constrained MOEA 中常被当作固定预处理的 constraint violation evaluation (CVE) 拿出来做自适应控制：早期把多个解聚成少数簇并共享较粗粒度的 `CV`，让目标信息主导探索；随着可行解比例升高或搜索进入后期，逐步增加簇数，使 `CV` 变细，恢复对可行性和 CPF 收敛的压力。作者还基于该思想设计了双种群算法 DDCo，并应用于锂离子电池三阶段恒流充电协议优化。

## 问题与动机

- 研究问题和场景：constrained multiobjective optimization problems (CMOPs)，目标冲突且存在 inequality/equality constraints，需要逼近 constrained Pareto front (CPF)。
- 作者认为 CMOEA 由三部分构成：
  - MOEA；
  - constraint-handling technique (CHT)；
  - constraint violation evaluation (CVE) framework。
- 过去大量工作集中在 CHT，而 CVE 决定了约束信息如何被利用，却少被单独设计。
- 两个典型 CVE 极端：
  - NCVE：把所有原始约束违反值求和，提供细粒度连续 `CV`；早期可能过度偏向可行性，使种群陷入局部可行区域或错过其他 feasible regions。
  - BCVE：只用 0/1 表示可行或不可行，提供粗粒度约束信息；后期约束压力不足，可能让种群在无意义的不可行区域浪费搜索。
- 本文希望解决什么：让 CVE 的信息粒度随 evolutionary state 从粗到细变化，在早期跨越 infeasible obstacles，在后期提高 constraint satisfaction 和 CPF exploitation。

## ACVE 框架

ACVE 的核心是“聚类后重赋 `CV`”：

1. 合并父代 `P` 和子代 `Q` 得到 `U`。
2. 先按 NCVE 计算 `U` 中每个解的原始 `CV`。
3. 计算父代中可行解比例 `P_fea`。
4. 根据 `P_fea`、当前代数 `t` 和最大代数 `T` 确定簇数 `n_c`。
5. 在 objective space 中用 K-means 将 `U` 分为 `n_c` 个簇。
6. 对每个簇，取该簇最小原始 `CV`，并把它重赋给簇内所有解。
7. 后续 CHT 只看到重赋后的 `CV`。

簇数调度：

- 当 `t <= 0.7T` 时，`n_c` 由 sigmoid 函数控制，近似为 `2Np/(1+exp(-10(P_fea-0.5)))`，并至少为 1。
- 当 `t > 0.7T` 时，强制 `n_c=2Np`，使每个解基本拥有自己的 `CV`，接近 NCVE 细粒度。

由此产生四种行为：

- 早期且 `P_fea=0`：`n_c=1`，所有解共享同一 `CV`，选择主要由 objective information 和 diversity 驱动。
- 早期且 `0<P_fea<1`：`n_c` 随可行比例增加，部分位于未探索可行区域附近的 infeasible solutions 会被同簇低 `CV` 保护。
- 早期且 `P_fea=1`：`n_c=2Np`，退化为细粒度 NCVE，强调可行解上的收敛与分布。
- 后期 `t>0.7T`：无论是否已找到足够可行解，都强制使用细粒度 `CV`，防止种群越过可行域后继续只追 UPF。

## DDCo 算法

作者将 ACVE 扩展为 coevolutionary CVE (CCVE)，并构建 DDCo：

- 维护两个 population：
  - `P1`：主种群，用 NCVE + CDP，负责稳定获取可行解；
  - `P2`：辅助种群，用 CCVE + CDP，负责从 objective-driven 和 infeasible side 提供互补搜索路径。
- Offspring generation：
  - 从 `P1 ∪ P2` 先随机取一个解进入 mating pool；
  - 之后每次分别从 `P1`、`P2` 随机取一个解，计算其到当前 mating pool 最近邻的 objective-space 距离；
  - 保留密度值更大的解，以强调整个演化过程中的 diversity。
- CCVE 与 ACVE 的区别：
  - `P2 ∪ Q` 是需要重赋 `CV` 的集合；
  - `P_fea` 不只来自 `P2`，还利用 `P1` 的可行比例；
  - 用 `gamma` 判断 `P2` 是否已经 crossed feasible regions。
- 若 `P2` 未穿越可行域 (`gamma=1`)：
  - `P_fea=max(P_fea2-u1*P_fea1,0)`；
  - `u1=1/(1+exp(10*(t-0.5)))`；
  - 作用是削弱 `P2` 的可行比例，让它早期更多利用 objective information，给 `P1` 补充探索信息。
- 若 `P2` 已穿越可行域 (`gamma=2`)：
  - 条件包括 `P1` 全可行、`P2` 全不可行、且 `P2` 中解不被 `P1` 中任一解支配；
  - `P_fea=min(P_fea2+u2*P_fea1,1)`；
  - `u2=1/(1+exp(-10*(t-0.5)))`；
  - 作用是逐步拉回 `P2`，让辅助种群从不可行侧逼近 CPF。
- 两个种群更新均使用 CDP 和 SPEA2 fitness；若 feasible nondominated set 超过容量，则用 SPEA2 truncation。

## 实验设置与结果

- ACVE 泛化实验：
  - 将 ACVE、NCVE、BCVE 分别与六类 CHT 结合：CDP、MOO-based、SR、SP、epsilon constrained、ATM。
  - 统一放在 NSGA-II 框架中。
  - 在 MW 和 Zhou’s CF 上比较，详细结果放在 supplementary 的 Tables S1-S6，主文汇总 Wilcoxon 结果。
  - 总结：ACVE 相比 NCVE/BCVE 更常提升各类 CHT，尤其能缓解 NCVE+CDP 的过度可行性偏好，以及 MOO-based 方法中的约束偏好问题。
- DDCo 综合实验：
  - Benchmark：MW、CTP、Zhou’s CF、Zhang’s CF。
  - 对比算法：C-TAEA、CCMO、PPS、ToP、NSGA-II-CDP、ShiP。
  - 指标：IGD、IGD+、HV。
  - 运行设置：30 次独立运行，`MaxFEs=50000`，`T=500`，`Np=100`，可扩展目标问题取 `m=3`；SBX `pc=1.0, eta_c=20`，PM `pm=1/D, eta_m=20`。
  - 作者总结：DDCo 在四套 benchmark 上多数实例优于六个 competitor；CTP 上优势最明显；Friedman + Bonferroni-Dunn 结果显示 DDCo 在所有情况下取得最小平均排名。
- 机制解释：
  - MW 中 CPF 与 UPF 部分重合或完全不同的实例上，辅助种群保留不可行侧解有助于逼近 CPF。
  - CTP 中许多 CPF 位于远离 UPF 的约束边界；CCVE 能让 DDCo 保留接近 CPF 的 infeasible solutions，而只追 UPF 的辅助种群贡献有限。
  - Zhang’s CF 中复杂 CPS 下，双种群协同和 diversity 有效，CCMO 与 DDCo 部分接近。

## 锂离子电池充电应用

- 问题：优化三阶段 constant current charging protocol。
- 目标：
  - 最小化 charging time `Ct`；
  - 最小化 temperature peak `Tp`；
  - 最小化 solid electrolyte interphase layer thickness `SEI`。
- 约束：
  - terminal voltage `U <= Umax`；
  - `Tp <= Tmax`；
  - `SEI <= Smax`；
  - state of charge 达到上限要求。
- 决策变量包括三阶段电流 `cc1, cc2, cc3` 和阶段充电量/时间相关变量。
- 评价使用 COMSOL 构建的 electrochemical-thermal-aging model；单次高保真约 20 秒，实验使用 reduced-order model。
- 参数：`Umax=4.3V`，`Tmax=318K`，`Smax=4.2nm`，`smax=0.9`，初始温度 298.15K，初始 SOC 0.1，population size 50，`MaxFEs=2000`。
- 结果：DDCo 在可行解 HV 上取得最佳平均值；作者展示 6 个代表 protocol，前三个偏 smooth/lower temperature，后三个偏 fast charging，均保持 voltage 和 SEI 在合理范围内。

## 局限与阅读边界

- 论文主要关注 CVE，不利用 constraint gradients、active constraints 或约束结构知识。
- `n_c` 的 sigmoid、`0.7T` 阈值、K-means objective-space clustering 都是启发式，跨问题自适应性仍需更多验证。
- ACVE 依赖 objective-space 聚类；若 objective clusters 与 feasible regions 不对应，重赋 `CV` 可能误保留错误不可行解。
- 主文表格多为图片占位或仅给 Wilcoxon 汇总，完整函数级结果依赖 supplementary。
- DDCo 使用双种群，计算和实现复杂度高于把 ACVE 直接嵌入单种群 CMOEA。
- 作者未来工作：
  - 利用 constraint gradient 或 active constraint 信息；
  - 将 surrogate-assisted CMOEAs 的优势引入 DDCo，以处理 expensive CMOPs。

## 可复用知识与创新线索

- 值得建立的设计知识：已新建“自适应约束违反粒度评估”，因为它把 `CV` 从固定标量改成可随状态调整的约束信息粒度，能嵌入多种 CHT 和 CMOEA。
- 局部创新线索：
  - 用 reference-vector sector、constraint-space clustering 或 feasible-boundary clustering 替代 K-means objective clustering；
  - 将簇内最小 `CV` 改为分位数、uncertainty-calibrated CV 或 low-CV representative；
  - 让 `n_c` 由可行率、CV 分布熵、feasible region coverage、UPF-CPF 距离共同决定；
  - 在现有 CDP、epsilon、SR、VCDP、双边界指标中替换底层 CVE。
- 结构创新线索：
  - 构建“CVE 粒度控制器 + CHT + 双种群辅助不可行搜索”的约束优化框架；
  - 与代理约束建模结合：代理只预测原始 `CV`，CVE 层再做粒度调节，降低 CHT 对代理误差的敏感性。
