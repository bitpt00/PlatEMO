# Exergy-aware multi-objective scheduling of multi-energy microgrid via physics-guided soft-hard constrained deep reinforcement learning

## 一句话理解

本文把多能源微网调度从只看“能量数量”扩展到“火用质量”，为含电解制氢和光催化制氢的氢-电-热-气系统建立多源氢流火用核算，并用带物理软硬约束的 TD3-SH 在不确定可再生出力和负荷下同时优化运行成本、碳排放和火用效率。

## 问题与动机

- 研究问题和场景：hybrid hydrogen-integrated multi-energy microgrid (MEMG) 的 24 小时调度；系统包含 PV、wind、CHP、hydrogen fuel cell、electrical storage、grid、gas boiler、electric boiler、thermal storage、electrolyzer、photocatalytic reactor、methane reactor、hydrogen storage、dynamic hydrogen-blended units 和 CCS。来源：Sec. 2.1、Fig. 1。
- 现有方法为什么不足：
  - 多能源微网调度多从能量数量和经济/低碳角度建模，忽略不同能源形式的质量差异，导致优化结果不能充分反映 useful work utilization。来源：Sec. 1。
  - 既有火用效率研究常只考虑经济和火用效率，环境指标不足；同时多源制氢场景中，PR/EL/HyS 的氢流混合后难准确追踪火用来源。来源：Sec. 1、Sec. 2.3.5。
  - stochastic programming、robust optimization 和 MPC 依赖不确定性建模或预测精度；普通 DRL 虽能处理不确定环境，但常只用 reward penalty 表示物理约束，无法保证动作输出严格满足设备边界。来源：Sec. 1。
  - DQN 需要离散化连续动作空间，维度爆炸且收敛慢；DDPG/SAC 等连续控制方法若缺少物理约束，可能产生不安全动作。来源：Sec. 1。
- 本文希望解决什么：在多源氢能 MEMG 中同时表示 energy quantity、energy quality、carbon impact 和 operating cost，并让 DRL 输出在设备功率、爬坡、氢掺混比例等安全边界内探索，减少 penalty-heavy reward 的无效训练。

## 核心理念与算法流程

- 核心理念：先用第二定律和火用质量系数把电、热、天然气、可再生发电、PR 氢能统一到 exergy 口径，再把 cost、carbon、exergy efficiency 转为到 ideal point 的距离型 reward；最后用 TD3 的连续动作控制和物理边界后处理联合保证安全探索。
- 火用核算流程：
  1. 构建 MEMG black-box exergy flow model：输入火用包括购电、PV/wind、PR 产生并流向 HFC/MR/CHP/GB 的氢、购入天然气；输出火用包括电负荷、热负荷和售电。来源：Sec. 2.2、Fig. 2。
  2. 电能火用品质系数固定为 `lambda_e=1`；热能用 Carnot 质量系数 `lambda_h=1-T1/T2`；天然气化学火用在工程上等价为燃烧热火用。来源：Sec. 2.3.1-2.3.3。
  3. 对 renewable generation，输入火用定义为发出的电和氢火用，因为未利用的风/光会被浪费。来源：Sec. 2.3.4。
  4. 对 PR 氢能，建立 hydrogen production contribution index 和 hydrogen storage energy decoupling coefficient，区分 PR、EL、HyS 混合后流向 MR、HFC、CHP、GB 的氢功率与火用。来源：Sec. 2.3.5、Fig. 3。
- 多目标建模：
  1. Exergy efficiency objective：最大化 MEMG 火用效率。来源：Sec. 3.1。
  2. Economic objective：运行成本包括 CO2 sequestration/transportation cost、电力交易成本和天然气成本。来源：Eq. (17)-(20)。
  3. Environmental objective：碳排放来自 CHP/GB 气体设备和购电排放，并考虑 CCS 捕集。来源：Eq. (21)-(22)。
  4. Multi-objective reward：不是输出 Pareto front，而是用改进 TOPSIS/optimal solution distance，把归一化指标向量 `I_t={eta_E*, F_total*, E_q*}` 推向 theoretical ideal `I_best={1,0,0}`。来源：Sec. 3.2、Fig. 4。
- MDP 与 TD3-SH 流程：
  1. State：储能容量、电/热负荷、可再生出力、电价、PR 氢功率、环境温度、上一时刻动作和当前时段；用长度 `n=4` 的 temporal segment 代替单时刻状态，以降低源荷时序不确定导致的信息不完整。来源：Sec. 4.1。
  2. Action：EL 用电、CHP 电输出、GB 热输出、CHP 热电比、氢掺混比例、MR/HFC 氢输入、ES 充放电、EB 热输出；动作先映射为 ramp/ratio adjustment variables，再经 Tanh 限制到 `[-1,1]`。来源：Sec. 4.2。
  3. Soft constraints：reward 中保留 SOC 约束和功率不平衡等 penalty，让 agent 学习满足物理模型。来源：Sec. 4.3、Sec. 6。
  4. Hard constraints：对 TD3 actor 输出做物理边界函数 `B1`-`B5` 后处理，强制设备功率上下限、热电比、氢掺混比例、派生功率等满足约束；氢掺混上限通过 `beta_re=0.2` 控制在 20% 以下。来源：Sec. 5。
  5. TD3 structure：one policy network + two Q networks，target update 使用两个 Q 中较小者以缓解 overestimation；连续交互中更新调度策略。来源：Sec. 5。
- 关键组成部分：
  - black-box exergy flow model；
  - multi-source hydrogen exergy tracking；
  - ideal-distance multi-objective reward；
  - temporal segment state representation；
  - action decomposition with ramp/ratio variables；
  - physics-guided soft-hard constraints；
  - TD3 double Q structure。
- 可能被修改的位置：
  - ideal-distance reward 可替换为 Pareto-conditioned policy、constrained MORL、CVaR reward 或 preference vector；
  - hard constraint functions 可扩展到网络潮流、电压、启停、最小开停机、储能寿命和氢安全标准；
  - temporal segment 可替换为 LSTM/Transformer 状态编码；
  - 多源氢流比例可由流量计/状态估计或物理数字孪生在线校正；
  - soft/hard 划分可按风险等级自适应调整，例如安全边界 hard，经济/寿命约束 soft。
- 必须保留的核心：火用质量核算、多源氢流追踪、三指标目标、物理硬约束动作后处理和在线 DRL 策略。如果只用成本/碳排 reward，就失去 energy quality；如果只用 soft penalty，就不能保证安全动作；如果只做离线 GA，则不具备实时不确定性响应能力。

## 实验证据

- 测试设置：
  - 数据来源：电/热负荷和 PV 来自 Arizona State University Tempe campus，wind power 和 PR hydrogen power 来自文献；调度间隔为 1 小时。来源：Sec. 6。
  - 电价：valley `0.3`、flat `0.9`、peak `1.9` yuan/(kWh)；天然气价格 `4.0 yuan/m3`，碳交易基准价格 `140 yuan/t`。来源：Table 1。
  - 设备容量：HyS `2.4/0.6 MW`，ES/TS `1.6/0.4 MW`，CHP electrical upper limit `1.2 MW`，EL `1.5 MW`，MR `1 MW`，HFC `1.2 MW`。来源：Table 2。
  - 训练：PyTorch/AIStation；policy/value network learning rate `0.0001`，target soft update `0.001`，4 hidden layers with 64 neurons，2000 epochs，replay buffer 50,000，batch size 1000。来源：Sec. 6.1。
  - TD3-SH 最优超参数：discount factor `0.95`，policy noise `0.15`，exploration noise `0.25`，采样间隔 1 h；reward 约 500 epochs 稳定，结论称 600 episodes 内收敛。来源：Sec. 6.1、Sec. 7。
- 调度行为与季节鲁棒性：
  - 典型冬季日：daily average exergy efficiency `0.704`，carbon emissions `18.327 t`，operating cost `5300 yuan`；高热负荷导致更多高质量电能转热能，火用损失较大。来源：Sec. 6.2。
  - 典型夏季日：average exergy efficiency `0.927`，carbon emissions `17.261 t`，operating cost `6170 yuan`；热负荷低、用电需求高，CHP 更偏向发电。来源：Sec. 6.2。
  - 30 representative days per season：Spring `cost 0.315±0.021 ten-thousand yuan, carbon 19.728±0.64 t, exergy 0.844±0.018`；Summer `0.582±0.028, 18.191±0.57, 0.925±0.014`；Autumn `0.434±0.024, 20.363±0.71, 0.891±0.016`；Winter `0.684±0.031, 21.617±0.83, 0.783±0.022`。来源：Table 3。
  - PR 制氢大部分流向 HFC 提升经济性和火用效率，冬季约 33% PR 氢流向 GB 产热。来源：Sec. 6.2、Fig. 9、Conclusion。
  - 极端天气场景下，average exergy efficiency `0.808`，daily carbon emissions `11.157 t`，operating cost `8072 yuan`，说明 TD3-SH 在强可再生波动下仍可保持低碳和火用效率。来源：Sec. 6.3。
- 多目标设置对比：
  - 单目标场景存在明显冲突；相对 cost-only Scenario 1，exergy-only Scenario 3 使 exergy efficiency 提升 17.09%，但 operating cost 增加 22.12%，carbon emissions 增加 7.56%。来源：Sec. 6.4.1。
  - 相对 cost+carbon Scenario 4，cost+carbon+exergy Scenario 5 使 exergy efficiency 提升 15.02%，cost 仅增加 3.42%，carbon emissions 增加 4.54%，显示三指标联合更平衡。来源：Sec. 6.4.1、Table 5。
- 算法对比：
  - TD3-SH 在 convergence speed 和 final reward 上优于 TD3、DDPG、PPO、SAC；硬约束让 agent 避免高 penalty action space。来源：Sec. 6.4.2、Fig. 12。
  - 15 test days 上，TD3-SH 平均 daily operating cost `0.659 ten-thousand yuan`，低于 TD3/SAC/DDPG/PPO 的 `0.702/0.712/0.751/0.763`；相对 TD3 降低 6.13%。来源：Table 7。
  - TD3-SH 平均 carbon emissions `19.728 t`，低于 TD3/SAC/DDPG/PPO 的 `20.923/21.026/21.724/22.334`；相对 TD3 降低 5.71%。来源：Table 7。
  - TD3-SH exergy efficiency `0.844`，高于 TD3/SAC/DDPG/PPO 的 `0.806/0.811/0.794/0.764`；相对 TD3 提升 4.71%。来源：Table 7。
  - 与 GA 比较：GA 质量略优或相近 (`cost 0.651, carbon 19.154, exergy 0.856`)，但单日求解 time `2434.2127s`；TD3-SH 为 `0.0081s`，适合在线调度。来源：Table 8。
- 证据边界：
  - 本文没有给出完整 Pareto front，而是用 ideal-distance reward 将三目标合成单个 RL reward。
  - GA 作为离线启发式的解质量略好于 TD3-SH，但速度慢很多；结论更适合实时/在线调度而非离线最优性。
  - SOC 等约束仍作为 soft constraints，极端情况下允许短时偏离并惩罚。
  - case study 的设备配置来自先验规划阶段，结论依赖该 MEMG 结构和数据来源。

## 局限与未来工作

- 作者没有单列 limitations，但正文和实验显示以下边界：
  - 目标处理为 ideal-distance scalar reward，不直接输出 Pareto solution set；
  - 物理硬约束主要覆盖设备出力、热电比、氢掺混比例和派生功率边界，未展开网络潮流、电压、启停和寿命退化；
  - 多源氢流追踪基于比例分配和 decoupling coefficient，实际管网混合、测量误差和动态滞后未深入建模；
  - 设备容量由 prior planning 决定，调度层不处理容量规划不确定性；
  - 训练数据和极端天气场景来自特定数据集/文献，跨地区泛化仍需验证。
- 我们认为仍需确认的问题：
  - hard post-processing 是否会改变 actor gradient 的有效性，长期训练是否存在策略-投影不一致；
  - SOC soft violation 在安全关键场景下是否可接受；
  - ideal point `I_best={1,0,0}` 的归一化权重和 sigmoid 参数如何影响实际偏好；
  - exergy efficiency 与 carbon/cost 之间的 trade-off 是否应展示完整 Pareto front；
  - 多个 MEMG 或配电网约束下 TD3-SH 是否仍能保持毫秒级在线决策。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建“火用感知软硬约束能源调度强化学习”：抽象为多源能流火用核算、ideal-distance reward、temporal segment state、物理硬约束动作投影和 soft penalty 的安全在线调度架构。
- 暂留在论文卡中的方法、原理或架构启发：
  - 将不同能源形式的“可做功能力”作为优化目标，比单纯 energy efficiency 更能解释电转热/氢转气的质量损失；
  - 对安全边界 hard project，对寿命/舒适性/可恢复约束 soft penalize，可减少无效探索；
  - 多源混合流要先做 source attribution，否则火用/碳/成本归因会混淆；
  - temporal segment state 是轻量替代 recurrent policy 的一种工程化做法。
- 局部创新线索：
  - 把 hard projection 改成 differentiable safety layer 或 control barrier function；
  - 用 Pareto-conditioned TD3 直接学习不同 cost-carbon-exergy 偏好的策略；
  - 给 SOC、电池寿命、氢储安全设置 adaptive dual variables，替代手工 penalty；
  - 引入 grid constraints、voltage/reactive power 和 network losses；
  - 用 online system identification 更新 exergy coefficients 和 hydrogen source attribution。
- 结构创新线索：
  - “exergy accounting -> ideal-distance MORL reward -> soft-hard safe action layer -> online dispatch”可迁移到综合能源系统、虚拟电厂、工业园区能源调度和氢能供应链；
  - 可与碳税场景随机优化结合：火用/成本/碳 reward 中加入碳价场景或风险项，让 TD3-SH 处理政策不确定性。
