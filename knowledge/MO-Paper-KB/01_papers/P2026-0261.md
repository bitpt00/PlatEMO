# Strategy Selection in Dynamic Constrained Multi-Objective Optimization via State-Augmented Deep Reinforcement Learning

## 一句话理解

论文提出 DCMOEA-SADQN：把动态约束多目标优化中的环境变化响应看成策略选择问题，先用可行性、多样性和收敛性的劣化状态感知变化影响，再用带 pairwise state augmentation 的 DQN 选择动态处理组件和约束处理组件的组合，从而避免固定响应策略在不匹配环境中浪费预算或产生反效果。

## 问题与动机

- 研究问题和场景：
  - Dynamic constrained multi-objective optimization problems (DCMOPs)；
  - objectives、decision variables 和 constraints 都可能随时间变化；
  - 应用例子包括 electric vehicle routing 中交通和路网变化，以及 process engineering 中市场价格和操作约束变化；
  - 环境变化会让之前的非支配解变差、可行解变不可行、种群多样性下降或远离 Pareto front。
- 现有算法为什么不足：
  - 作者观点：当前 DCMOEA 多采用预先设定的动态响应策略或多机制组合，无论环境变化如何影响 population characteristics，都执行固定响应；
  - 作者观点：不同变化会分别损害 solution feasibility、population diversity 和 convergence，固定策略可能低效甚至反向；
  - 作者观点：已有 RL-based DMOEA 处理动态但不处理约束，DRL-based CMOEA 处理约束但不处理动态，缺少同时覆盖 constraint、dynamic 和 learning-based strategy adaptation 的方法；
  - 作者观点：把可行性、多样性、收敛性作为独立 state feature 不够，因为这些特征的劣化存在相互影响。
- 本文希望解决什么：
  - 根据环境变化导致的 population characteristic deterioration pattern，选择适合的 response strategy combination；
  - 让动态处理组件和约束处理组件以动作组合形式被学习选择；
  - 用 state-augmented mechanism 显式建模 state features 之间的 pairwise interactions，提高变化感知和策略选择精度。

## 核心理念与算法流程

- 核心理念：
  - DCMOP 的变化响应不应只看“变化发生了”或“变化严重度”，而应诊断变化损害了哪类种群特征；
  - feasible/non-dominated archives 在变化前后重新评价，可以提供 feasibility、diversity 和 convergence 的劣化信号；
  - DQN 离线学习“劣化状态 -> 策略组合 -> 后续解质量”的映射，在线只需读取当前状态并选 Q-value 最大动作。
- 主要流程：
  1. 维护 `CA_t` 和 `UA_t`：`CA_t` 为 CDP 下的 feasible nondominated archive，`UA_t` 为 CIS 下的 nondominated archive；
  2. 每代随机抽取 10% individuals 重新评价，若 objective 或 constraint violation 变化则检测到环境变化；
  3. 用 `CA_{t-1}` 和 `UA_{t-1}` 构造五维状态 `s_t`，分别表示 feasibility、diversity 和 convergence 的劣化；
  4. 通过 state-augmented mechanism 计算 pairwise interaction matrix、可学习权重调制和上三角展开，得到增强状态 `s'_t`；
  5. DQN 对 63 个可能动作输出 Q-values，选择最大 Q-value 动作；
  6. 该动作决定哪些 dynamic-handling component 与 constraint-handling component 组合被激活，并据此初始化 1-6 个 subpopulations；
  7. 多子种群按各自 constraint-handling component 共进化，更新 `CA_t`、`UA_t` 和各 subpopulation；
  8. 下一次环境变化时，新的 archives 再作为状态输入。
- 关键组成部分：
  - State：`s_t=(gamma_t, sigma_t, nu_t, kappa_t, rho_t)`；
  - Feasibility states：`gamma_t` 表示约束违反严重度，`sigma_t` 表示 `UA_{t-1}` 的 feasible ratio；
  - Diversity state：`nu_t` 表示 `CA_{t-1}` 在变化前后 average HV 的变化，负值表示 diversity loss；
  - Convergence states：`kappa_t` 表示最相似历史环境 centroid 在当前环境重评后的目标或约束偏移，`rho_t` 表示 Kalman predicted centroid 与 `CA_{t-1}` centroid 的决策空间 mismatch；
  - Actions：三类 dynamic-handling components，分别是 diversity-based、memory-based、prediction-based；两类 CHT，分别是 CIS 和 CDP；两两配对成 6 个基本策略，非空子集构成 `2^6-1=63` 个动作；
  - Reward：离线训练时对每个 state 执行全部 63 个动作，演化到下一环境，按 IGD 从小到大排序并给予 rank-based reward；
  - State augmentation：外积得到 pairwise feature interaction matrix，用可学习矩阵 Hadamard product 调制，取严格上三角并与原 state 拼接。
- 可能被修改的位置：
  - 五个 state feature 可扩展为可行率变化、CV 分布、objective-space entropy、reference-vector coverage、archive growth rate 等；
  - 63 动作可替换为更小的分层动作：先选 constraint handling，再选 dynamic response；
  - rank-based IGD reward 可改为无真实 PF 的 online reward，例如 archive improvement、survival rate、MIGD surrogate 或 feasibility-diversity-convergence composite score；
  - DQN 可换成 contextual bandit、policy gradient、action embedding、GNN over strategies 或 hierarchical RL。
- 必须保留的核心：
  - 响应选择由 population characteristic deterioration pattern 驱动；
  - 动作必须能表达 dynamic-handling 与 constraint-handling 的组合，而不是只选单一预测器；
  - state augmentation 要显式表达特征间交互，否则会退化为普通状态输入 DQN；
  - 在线应用不应依赖 true PF，true PF 只用于离线训练的 reward 计算。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：DCP 和 DCF 两个动态约束 benchmark suites；
  - 总实例数：DCP 36 个、DCF 40 个，共 76 个 test instances；
  - 动态设置：`(psi_t, phi_t)` 取 `(5,10)`、`(5,20)`、`(10,10)`、`(10,20)`；
  - 每个 run 有 `EC=60` environmental changes，前 80 代不发生环境变化以降低静态优化影响；
  - Population size `N=100`，decision variables `c=10`，30 independent runs；
  - Baselines：TDCEA、mEDCMOA、DC-NSGA-II-A、DC-NSGA-II-B、DC-MOEA、HATC；
  - Metrics：IGD/HV，并跨环境求 mean 得到 MIGD/MHV；Wilcoxon rank-sum test，显著性 0.05；
  - 表中 “+/-/=” 表示被比较算法相对 DCMOEA-SADQN 显著更好/显著更差/相近，复述时需注意方向。
- DRL 选择机制证据：
  - 相比随机策略选择 DCMOEA-RA，DCMOEA-SADQN 在 MIGD 上 75/76 个实例显著更好，MHV 上 76/76 个实例显著更好；
  - 相比 TS-MAB，DCMOEA-SADQN 在 MIGD 上 75/76 个实例显著更好，MHV 上多数显著更好；
  - DCP2 案例显示 DCMOEA-RA 的策略序列混乱，TS-MAB 有结构但不理解劣化状态，DCMOEA-SADQN 的策略序列更连贯并取得更低 IGD。
- 与 SOTA DCMOEA 比较：
  - Table III：DCMOEA-SADQN 在 DCP 36 个实例中取得 27 个 best average MIGD，在 DCF 40 个实例中取得 28 个 best average MIGD；
  - Wilcoxon 统计中，DCMOEA-SADQN 相比 TDCEA、mEDCMOA、DC-NSGA-II-A、DC-NSGA-II-B、DC-MOEA、HATC 分别在 61、65、71、73、68、66 个实例上 MIGD 显著更好；
  - 结论中总结：基于 MIGD，DCMOEA-SADQN 相比六个 SOTA 算法在 72.4% test cases 中表现更优；
  - DCP3/DCP9 IGD 曲线显示环境变化后 DCMOEA-SADQN 更快降低 IGD 并稳定在较低值。
- 机制和消融证据：
  - DCP4/DCP5 上原 TDCEA 个别结果更好；作者用 SBX/PM 替换 TDCEA 的 DE 得到 TDCEA-G 后，DCMOEA-SADQN 超过 TDCEA-G，说明劣势主要来自 genetic operator 差异而非动态响应机制；
  - 去掉 feasibility、diversity、convergence state 后分别得到 DCMOEA-noFeas、noDiv、noConv；三者有少数实例局部更好，但总体显著退化；
  - noConv 退化最强，在 MIGD/MHV 上分别有 39/76、40/76 个实例显著差于 DCMOEA-SADQN，说明 convergence-related state 尤其重要；
  - 案例研究中 DCP3 表现为 feasibility loss，算法选择 CIS 加 diversity/memory/prediction；DCP9 为 diversity collapse，选择 CDP+prediction 和 CIS+diversity/memory；DCP1 为 convergence degradation，选择 CIS+memory/prediction。
- 补充实验线索：
  - 主文说明 supplementary 中还包含 action space ablation、state augmentation ablation、training/inference cost、cross-benchmark generalization、without true PF training、training trajectory selection 等；
  - 结论称 state-augmented DRL 具有跨问题 generalization、合理 training/inference cost，并在 true PF unavailable 训练时保持 robustness；
  - 这些补充实验未在当前 Markdown 主文展开，精确数值需查 supplementary。
- 证据边界：
  - 主要测试为 2 目标 DCP/DCF benchmark，decision variables 固定为 10；
  - 动态处理组件的具体实现放在 Supplement S-II，主文未完全展示；
  - 离线 reward 默认用 true PF 计算 IGD，真实应用中的在线训练仍未解决；
  - 未提供真实工程应用实验，未来 transfer 到 real-world DCMOP 仍需验证。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前需要离线训练，且 training reward 依赖 true PF；
  - 加入更多组件后 action space 会组合爆炸；
  - 对 real-world problems 的泛化仍需 transfer learning 支持；
  - 目前没有把 genetic operator 也纳入自适应选择。
- 作者未来工作：
  - 发展不需要 true PF 的 online reinforcement learning；
  - 研究 transfer learning，使算法能泛化到与 benchmark 结构差异很大的真实问题；
  - 加入 genetic operator 的自适应选择；
  - 探索 policy gradient 和 action embedding，以缓解动作空间组合爆炸。
- 我们认为仍需确认的问题：
  - 五维 state 是否足以描述 many-objective、high-dimensional 或 mixed-variable DCMOP；
  - 离线全动作执行训练成本在更大 action space 或真实仿真问题中是否可承受；
  - 如果 true PF 不可得，ranking reward 的替代指标如何保证不偏向短期可行性或局部 diversity；
  - 多子种群动作在高成本目标函数下会不会增加过多每次变化的响应成本；
  - 训练在 DCP/DCF 间交叉测试虽有泛化证据，但到真实工程 DCMOP 仍可能存在 distribution shift。
