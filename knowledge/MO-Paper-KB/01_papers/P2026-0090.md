# Many-objective island-based evolutionary algorithm for biomarker selection and cancer molecular diagnosis in high-dimensional omics data

## 一句话理解

论文提出 MOIEA-CMD：面向癌症基因表达数据的多目标生物标志物选择，把候选基因子集编码为二进制 mask，同时优化分类准确率、子集规模、特征相关性和特征冗余。核心不是单纯增加一个特征选择目标，而是先用 GRRA 把基因划成收敛相关基因和多样性相关基因，再对收敛基因做交互分组；多个 island 子种群分别进行“交互子组内强化收敛”和“多样性基因广域探索”，并周期性迁移非支配精英，最后合并得到 Pareto 基因子集。

## 问题与动机

- 研究问题：
  - 高维 omics 数据通常基因数远大于样本数，存在噪声、冗余、类别异质性和过拟合风险；
  - 癌症分型/分子诊断希望同时获得高分类性能和小而可解释的 biomarker 子集；
  - 多目标特征选择天然需要平衡 accuracy、feature count、relevance 和 redundancy；
  - many-objective 选择压力退化、二进制高维搜索空间巨大，普通 MOEA 难以稳定收敛。
- 现有方法为什么不足：
  - NSGA-II、MOPSO、PESA-II 等在多目标/多目标数扩展时容易选择压力不足；
  - 单一特征选择 filter 或 wrapper 评价难以同时处理特征交互和冗余；
  - 变量分析类方法能分解变量，但未必适配基因表达中的相关/冗余和 interaction；
  - 传统集中式种群在高维二进制空间中容易早熟，且不能利用并行/分布式计算。
- 本文希望解决什么：
  - 用 relevance-redundancy 和 interaction 信息降低高维基因空间的无效扰动；
  - 用 island 子种群提升可扩展性、维持多样性并降低集中式排序压力；
  - 通过受控迁移在局部适应和全局信息共享之间折中；
  - 输出既紧凑又具生物解释性的癌症 subtype biomarker 子集。

## 核心模型与算法流程

- 候选解与目标：
  - 先用 mutual information 预筛得到较小特征池 `D subset F`；
  - 每个候选解为二进制向量 `x in {0,1}^D`，1 表示选中该基因；
  - 初始化用以 0.5 为中心的概率阈值生成不同稀疏度的 mask；
  - 目标包括：最小化 selected gene count、最大化 classification accuracy、最大化 selected genes 与类别标签的 relevance、最小化 selected genes 之间的 redundancy；
  - redundancy 使用 symmetric uncertainty / entropy 类指标度量特征间冗余。
- MOIEA-CMD 总体框架：
  - 初始化全局种群；
  - GRRA 将基因划分为 convergence-related genes `Gc` 和 diversity-related genes `Gd`；
  - interaction analysis 将 `Gc` 中存在交互依赖的基因划为若干 `subGc`；
  - 将种群分配到多个 island，每个 island 内循环执行收敛基因优化、多样性基因优化和必要迁移；
  - 合并各 island 的候选解，进行最终非支配排序，输出 Pareto gene subsets。
- GRRA 基因相关/冗余分解：
  - 对每个基因，从当前种群采样 `nSelc` 个候选解，并进行 `nPert` 次扰动；
  - 通过扰动前后目标变化的 RMSE 衡量该基因对收敛的影响；
  - 计算解相对超平面 `f1+...+fm=1` 和法线 `NL` 的 angular deviation；
  - RMSE 低于阈值 `alpha` 的基因先进入候选 `Gc`；
  - 对 angle 值做 k-means，将较小平均角度簇视为更强收敛相关集合；
  - 最终 `Gc` 取二者交集；若交集为空则回退到 angle 簇，其他基因进入 `Gd`；
  - 对 `Gc` 进行 interaction analysis，把存在交互依赖的基因放入同一 subgroup。
- 收敛相关基因优化：
  - 先按四目标评价当前 island 种群，并用非支配排序给出 Pareto front rank；
  - 计算各解到四维 ideal point 的欧氏距离，增加收敛压力；
  - 对每个 convergence subgroup，仅在该 subgroup 内进行 crossover 和 mutation，保留基因交互结构；
  - 父代和子代合并后，用 rank 优先、ideal distance 次优先的 `SelectByRankAndDistance` 做环境选择。
- 多样性相关基因优化：
  - 随机选择父代，并在整个 `Gd` 上重组，扩大二进制搜索空间探索；
  - 合并父代和子代后做非支配排序；
  - 若前若干 front 超过容量，则用目标空间 angular diversity 补齐剩余位置；
  - 该阶段强调 trade-off 覆盖，而不是只压向 ideal point。
- 迁移机制：
  - 每个 island 独立演化，但每隔 `eEval/2` evaluations 触发迁移；
  - island 先做非支配排序，从 top front 中随机选择 `Ms` 个精英作为 migrants；
  - 接收端移除相同数量居民或融合迁入个体；
  - 迁移频率和迁移规模控制局部适应与全局共享之间的折中；
  - 最终各 island 的非支配解汇总后再次排序。
- 复杂度：
  - GRRA 因 `nSelc` 和 `nPert` 固定，随特征数 `D` 和目标数 `M` 近似线性增长；
  - island 将全局种群 `N` 分成 `Is` 份，降低每个子种群的排序负担；
  - 作者给出 distributed dominance ranking 近似 `O(M N log N)` 行为，并认为优于集中式 `O(MN^2)` 排序。

## 实验证据

- 实验设置：
  - 主实验使用 de Souto 等整理的 35 个癌症基因表达数据集；
  - 样本数 22-248，基因数 85-4553，subtype 数 2-14；
  - 对比算法包括 NSGA-II、NSGA-III、PESA-II、MOPSO、MOEA/DVA、LMEA、MOECSA、NSGA-II/CSDR 和 MSEMOEA；
  - 指标包括 ARI、NMI、Accuracy、Micro-F1、Macro-F1；
  - 使用 10-fold cross-validation 和 `k=1` 的 KNN 分类器；
  - population size `N=300`，最大 1000 function evaluations，独立运行 20 次；
  - 统计检验使用 Wilcoxon signed-rank test，显著性水平 0.05。
- 总体性能：
  - Friedman 平均排名中，MOIEA-CMD 在 ARI、NMI、Accuracy、Micro-F1、Macro-F1 上均为最优，overall rank 为 1.69；
  - Wilcoxon 检验显示，MOIEA-CMD 相比 9 个对比算法有显著提升，只有 MOECSA 的差异不显著，`p≈0.55`；
  - 35 个数据集平均结果：ARI `0.8709`、NMI `0.8723`、Accuracy `0.9454`、Micro-F1 `0.8985`、Macro-F1 `0.8599`；
  - MOIEA-CMD 在 31 个数据集取得最高 accuracy，并在 15 个数据集达到 perfect classification。
- island 数与可扩展性：
  - island 数从 4 增至 8 时，ARI 和 NMI 整体提升，4 到 6 的收益最大，6-8 后趋于平稳；
  - 只有 4 或 5 个 island 时，MOIEA-CMD 已在若干数据集上超过主要 baseline；
  - population size 从 100 到 300 时性能提升，超过 300 后收益下降或略降；
  - selected dimensionality `D=200` 表现最好，`D=500` 时仍保持竞争力；
  - runtime 随 island 数增加而下降，作者报告从 2 到 8 个 island 时多个 population size 下 runtime 都超过减半。
- 消融：
  - 完整 8-island MOIEA-CMD 在 Shipp-2002、Su-2001、TCGA-BRCA 上 accuracy 分别为 `0.9835`、`0.9524`、`0.9622`；
  - 去掉 GRRA 后分别降为 `0.9571`、`0.9248`、`0.9175`，TCGA-BRCA 下降最大；
  - 去掉 variable grouping 后分别为 `0.9612`、`0.9283`、`0.9308`；
  - 去掉 migration 后分别为 `0.9724`、`0.9395`、`0.9481`；
  - single-island EA 分别为 `0.9685`、`0.9331`、`0.9463`；
  - 作者据此认为 GRRA 贡献最大，interaction grouping、migration 和 distributed co-evolution 均有独立收益。
- 评价预算：
  - 在 Shipp-2002、Su-2001、TCGA-BRCA 上，1000、2000、3000 FE 的 accuracy 随预算增加而提高；
  - 小型 microarray 数据集 2000 FE 后收益较小，TCGA-BRCA 这类高维 RNA-seq 更受益于额外搜索。
- 临床/生物解释：
  - 作者列出多个 benchmark 数据集与已知癌症 subtype 或 biomarker 对应关系；
  - 代表性基因包括 ESR1、GATA3、HOXA9、MEIS1、FLT3、LMO2、EGFR、NKX2-1、TAL1、BCL11A、MYC、KRT18 等；
  - 作者认为选中特征与 ER signaling、hematopoietic lineage、EGFR signaling、cell-cycle 等癌症通路一致。
- TCGA 扩展实验：
  - 在 TCGA-COAD 上，MOIEA-CMD 报告 ARI `0.826`、NMI `0.845`、ACC `0.926`、Micro-F1 `0.925`、Macro-F1 `0.895`；
  - 在 TCGA-BRCA 上，MOIEA-CMD 报告 ARI `0.849`、NMI `0.883`、ACC `0.952`、Micro-F1 `0.952`、Macro-F1 `0.933`；
  - 作者列出的 TCGA 代表基因包括 COAD 的 APC、KRAS、SMAD4、MUC1 和 BRCA 的 ESR1、ERBB2、PGR、BRCA1。

## 局限与未来工作

- 作者明确局限/未来方向：
  - 当前 island 数量和 migration schedule 固定，不一定适配所有数据集；
  - 目前 feature selection 未纳入 prior biological knowledge；
  - 未来可探索 adaptive island sizing、adaptive migration、pathway/regulatory network priors、多组学整合和 pan-cancer stratification。
- 我们认为仍需谨慎的问题：
  - 队列标记为 not-reviewed，且 Markdown 中公式和部分表格不完整，关键数学细节若要复现需回 PDF 和代码；
  - 论文使用 1-NN + 10-fold CV 报告分类性能，真实临床可用性还需要独立 cohort、外部验证和严格统计控制；
  - 多目标排序和复杂度描述较概括，`O(MN log N)` 的具体 dominance-ranking 实现需要进一步确认；
  - MI 预筛、GRRA、interaction analysis、island 并行和 migration 同时作用，消融只覆盖主要模块，仍难完全分离每个细节贡献；
  - 生物学解释多为 selected genes 与已知通路的一致性，不能直接证明因果机制。

## 可迁移设计要点

- 高维子集选择可以先把变量按“收敛贡献”和“多样性贡献”分层，再给两类变量不同繁殖与选择压力；
- 对强交互变量，不要在全基因空间随机交叉，可先分 interaction subgroup，再在组内定向重组；
- 二进制特征选择中的多样性不只来自 Hamming 距离，也可以用目标空间 angular diversity 保护 trade-off 覆盖；
- island 模型的价值不仅是并行加速，还能在高维 noisy wrapper evaluation 中降低早熟和方差；
- 迁移个体最好来自局部非支配优质区域，但迁移规模和频率需要可调，否则可能导致同质化或信息滞后。
