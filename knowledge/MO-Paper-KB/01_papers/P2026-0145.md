# Learning-based memetic algorithm for bi-objective distributed heterogeneous permutation flow shop scheduling problem with flexible machine speeds

## 一句话理解

本文面向带柔性机器速度的分布式异构 permutation flow shop，提出 LBMA：前期用原始解码保持 makespan 探索，后期切到右移-调速协同的节能解码降低 TEC；局部搜索则用无显式状态的 LNSS 根据邻域历史改进奖励选择六个问题特定邻域，从而同时提升收敛、分布和能耗表现。

## 问题与动机

- 研究问题：distributed heterogeneous permutation flow shop scheduling problem with flexible machine speeds (DHPFSP-FMS)。
- 优化目标：
  - minimize makespan；
  - minimize total energy consumption (TEC)。
- 三类耦合决策：
  - factory selection (FS)：每个 job 分配到哪个 factory；
  - job sequence (JS)：各 factory 内的 permutation processing order；
  - speed setting (SS)：每个 job 在每台 machine 上的 processing speed level。
- 主要难点：
  - 工厂异构、作业排序和机器速度共同决定完工时间与能耗；
  - 单纯降速可能损害 makespan，单纯 earliest decoding 又产生长 idle gaps；
  - 局部搜索有多个邻域，固定或随机选择难以适应不同实例和阶段；
  - 直接采用 Q-learning/DQN 需要状态定义和较复杂学习表，调度问题中状态建模成本较高。

## 核心算法流程

- 编码为三层结构：
  - `JS`：长度为 `N` 的 job sequence vector；
  - `FS`：长度为 `N` 的 factory assignment vector；
  - `SS`：`K x N` 的 machine speed setting matrix。
- 初始化：
  - heuristic method 1 偏向 makespan；
  - heuristic method 2 使用最低机器速度偏向 TEC；
  - random method 保留多样性；
  - 参数 `xi` 控制启发式与随机个体比例。
- 主循环：
  - tournament selection 生成 dominant population；
  - JS 使用 POX crossover，FS/SS 使用 uniform crossover；
  - 对 JS、FS、SS 分别执行插入、工厂重分配、速度变异；
  - 当 `NFE <= lambda * MaxNFEs` 时用 ODS 解码，后期改用 EEDS 解码；
  - 对当前非支配个体执行带 LNSS 的 local search；
  - 用 `Pareto_front(Omega union P_t)` 更新精英档案；
  - 用 NSGA-II 的 non-dominated sorting 和 crowding distance 更新下一代种群。

## EEDS 节能解码

- ODS 先按 `FS` 把 job 分到各工厂，再按 `JS` 和 `SS` 得到单工厂 PFSP-FMS schedule。
- EEDS 在 ODS schedule 之后调整 processing time 和 speed：
  - 计算不同 situation 下每个 job/machine 的 available idle time；
  - 对最后 job、最后 machine、其他 machine 分别按规则反向更新 `SS`；
  - 通过 right-shift policy 把当前 job 的 processing period 向右移动；
  - 右移后为前序 job 或当前 job 的前一台 machine 创造额外 idle window；
  - 在不增加 makespan 的前提下，利用这些窗口降低前序加工速度，从而减少 processing energy 和 idle energy。
- 算法层面采用阶段切换：
  - 前期使用 ODS，避免 EEDS 大量降速后忽略小 makespan 区域；
  - 后期使用 EEDS，提高能耗目标质量；
  - 作者指出 EEDS 相对 ODS 增加 `O(N x K)` 时间复杂度。

## LNSS 邻域选择

- 六个问题特定邻域：
  - `N1`：在最长完成时间 factory 中选择两个 job，执行插入；
  - `N2`：在最长完成时间 factory 中选择两个 job，执行交换；
  - `N3`：从最长完成时间 factory 选一个 job，分配到最短完成时间 factory；
  - `N4`：随机 factory 中选择 processing time 最长 job，分配到另一 factory；
  - `N5`：随机选择一台 machine，降低该 machine 上所有 jobs 的速度；
  - `N6`：类似 `N5`，但提高该 machine 的速度。
- LNSS 维护 `m x 2` 的 Q-table：
  - 第一列为各邻域 action 的 reward value；
  - 第二列为各 action 被选择次数；
  - 用 `epsilon`-greedy 在当前最优 reward action 和随机 action 之间切换。
- reward 规则：
  - 新解支配旧解：`r=1`；
  - 旧解支配新解：`r=0`；
  - 二者互不支配：`r=0.5`。
- 与 Q-learning/DQN 的差别：
  - 不显式定义状态；
  - 不使用 state-action-reward-state，而直接用 action/reward 历史更新；
  - 表规模从 `states x actions` 降到 `actions x 2`；
  - 可直接移植到其他局部搜索，不需要额外状态建模。

## 实验设置

- Benchmark：22 个 DHPFSP-FMS instances，规模覆盖 `20/50/100/200` jobs、`2/3` factories 和 `5/10/20` machines。
- 独立运行：对比实验均运行 20 次。
- 指标：
  - HV，reference point 为 `(1.01, 1.01)`；
  - GD；
  - Spread。
- 因真实 Pareto front 不可得，作者合并所有算法的非支配解并归一化，用该集合近似 true PF。
- 参数：
  - Taguchi L16 测试 `ps`、`lambda`、`pm`、`xi`；
  - 最优组合为 `ps=80`、`lambda=0.6`、`pm=0.05`、`xi=0.6`；
  - `epsilon` 候选包括 `0.0001`、`0.1`、`0.3`、`0.5`、`1` 和动态值 `M=max(1-NFE/MaxNFEs,0.1)`；
  - Friedman rank test 显示 `epsilon=0.3` 最优。

## 主要实验发现

- LNSS 消融：
  - 对比 `LBMA-LE` 和 `LBMA-DQN`，LBMA 在 HV、GD、Spread 多数实例上取得最佳结果；
  - Table 11 的 Friedman rank 显示 LBMA 在三项指标上 rank 最优，且 p-values 均小于 0.05；
  - 当 `epsilon=0.0001` 时探索不足，部分邻域长期不被调用，reward 估计失真。
- LNSS 迁移性：
  - 将 LNSS 嵌入 SOTA 算法 BRCE 得到 `BRCE-LNSS`；
  - Table 12 显示 BRCE-LNSS 在解质量和收敛上优于 BRCE；
  - 作者强调 LNSS 只依赖历史改进信息，不依赖状态信息，因此可移植性较好。
- EEDS 节能策略：
  - `LBMA-1` 只使用 ODS，不包含节能解码；
  - 传统策略只做 machine speed adjustment；
  - Fig. 14 的 6 个代表实例显示节能策略显著降低 TEC，且 EEDS 优于传统调速策略；
  - Gantt chart 对比显示 right-shift + speed adjustment 能创造传统策略没有利用的调速空间。
- 综合对比：
  - 对比算法包括 MOWSA、DMSSA、BRCE、NSGA-II 和 MOEA/D；
  - Tables 13-15 中 LBMA 在 HV、GD、Spread 上全面领先，Wilcoxon 行显示相对各对比算法多为 `22/0/0` 或接近；
  - Table 16 显示相对其他 SOTA 最优结果，LBMA 平均降低 makespan `1.36%`，平均降低 TEC `6.18%`；
  - Table 17 的 Friedman rank 中 LBMA 在 HV、GD、Spread 上均排名第一。

## 与知识库相关的设计知识

- 新增/关联设计知识：
  - `K-right-shift-speed-scaling-energy-decoding`：右移-调速协同节能解码。
  - `K-success-rate-feedback-operator-parameter-adaptation`：LNSS 作为状态无关、reward 均值式的邻域算子选择变体，补充到成功率/历史反馈算子选择知识。
- 与已有设计知识的区别：
  - 不同于 `K-rank-based-auxiliary-speed-decision-refinement`：该知识在已有主结构后用非支配 rank 修正辅助速度档位；本文 EEDS 在 schedule 解码层通过 right-shift 创造额外 idle window，再利用窗口降速。
  - 不同于 `K-forward-event-decoding-reverse-energy-compression-scheduling`：该知识偏向有限 buffer/reentrant flow shop 的前向可行解码和后向 idle compression；本文处理 flexible machine speeds，核心是加工时间右移与速度档位协同。
  - 不同于 `K-energy-feedback-adaptive-machine-restart-scheduling`：该知识决定 standby/shutdown/restart；本文不做机器启停，而是在加工速度和工序时间位置上节能。
  - 不同于 `K-drl-state-driven-evolutionary-operator-selection`：LNSS 刻意避免显式状态和复杂 RL，只用邻域历史 reward 直接更新选择偏好。

## 局限与未来工作

- EEDS 相比 ODS 需要检查所有机器，时间复杂度增加 `O(N x K)`。
- EEDS 会使多数个体速度下降，若过早使用可能削弱小 makespan 区域探索，因此需要阶段切换。
- LNSS 目前只在 DHPFSP-FMS 上系统验证，跨其他调度问题仍需进一步实证。
- 作者建议未来研究引入动态特征和多样化生产需求，并继续围绕问题特征定制优化策略。
