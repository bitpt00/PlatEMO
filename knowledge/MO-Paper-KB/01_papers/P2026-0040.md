# Evolving explainable neural architectures: Dynamic behavioral-novelty weighting in multi-objective neuroevolution for multimodal spam detection

## 一句话理解

本文用 NEAT 同时进化神经网络拓扑和训练超参数，把准确率、泛化间隙和行为新颖性纳入多目标搜索；核心 NEAT-dyMO 通过随代数衰减的新颖性权重，让搜索从早期结构探索平滑转向后期性能开发，并用 SHAP 解释这种阶段性行为。

## 问题与动机

- 研究问题和场景：多模态垃圾信息检测，包括图像、语音和不平衡短信场景，需要在准确率、泛化能力、模型结构复杂性和可解释性之间取得平衡。
- 现有算法为什么不足：
  - 传统 NEAT 或单目标神经架构搜索通常只优化准确率，容易忽视过拟合和结构多样性。
  - 固定深度模型、Transformer 或 AutoML 方法在小样本或模态差异较大的场景中可能计算成本高、解释性弱。
  - 反馈式动态控制器可以调节探索和开发，但作者认为其额外反馈循环会带来计算开销和不稳定性。
  - 普通 Pareto-NEAT 若全局排序，可能让优势物种压制尚未成熟但有潜力的拓扑。
- 本文希望解决什么：设计一个不依赖复杂反馈控制的多目标 NEAT 变体，在早期主动扩大结构与行为探索，在后期转向准确率和泛化表现，并保留对演化历史与超参数贡献的解释能力。

## 核心理念与算法流程

- 核心理念：行为新颖性在早期有助于发现不同拓扑、训练配置和特征子集；随着代数推进，搜索应逐渐减少为新颖而新颖的奖励，把权重转给准确率和泛化间隙。
- 主要流程：
  1. 用 NEAT 编码网络拓扑和训练超参数，基因组包含层数、每层神经元数、激活函数、特征掩码、dropout、学习率和 batch size 等。
  2. 对每个候选网络计算验证准确率 `A(h)`、泛化间隙 `G(h)=max(0,A_train(h)-A_val(h))` 和行为新颖性 `N(g)`。
  3. 行为描述符由结构、训练超参数和采样特征掩码组成，混合变量距离使用 Gower distance。
  4. NEAT-stMO 使用固定权重组合多目标信号。
  5. NEAT-dyMO 让新颖性权重 `w_N(t)` 从初始值线性衰减到下限，并令性能权重 `w_F(t)=1-w_N(t)`。
  6. 早期高新颖性权重鼓励大范围拓扑/超参数探索；后期更高性能权重推动准确率提升和过拟合控制。
  7. 记录演化历史，用 Random Forest surrogate 和 SHAP 分析超参数对准确率、泛化间隙和新颖性的贡献。
- 关键组成部分：
  - 三目标 fitness 信号：准确率、泛化间隙、行为新颖性。
  - 行为描述符：拓扑规模、训练超参数和采样特征掩码的混合表示。
  - 确定性动态权重：模拟退火式 novelty cooling schedule。
  - 物种内 Pareto-NEAT 基线：在 species 内做非支配排序，避免全局 Pareto 排序压垮小物种。
  - 演化历史 XAI：用 surrogate + SHAP 解释搜索中哪些超参数推动不同目标。
- 可能被修改的位置：新颖性描述符、距离函数、权重衰减曲线、性能项定义、泛化惩罚形式、species-local ranking 和 SHAP 诊断模块。
- 必须保留的核心：若作为基础算法，应保留“行为新颖性作为早期探索目标 + 随代数确定性衰减 + 性能/泛化目标后期接管”的控制逻辑；只把 novelty 加进目标或只做 SHAP 解释，不等同于 NEAT-dyMO 的核心。

## 实验证据

- 测试问题和对比算法：三种模态分别评价，包含图像垃圾检测、语音垃圾检测和不平衡短信垃圾检测；对比 NEAT-dyMO、NEAT-stMO、Pareto-NEAT、NEAT-SO、MLP、SVM、Auto-Keras、Hyperband 和 ViT 等。实验使用 5-fold cross-validation，并报告准确率、F1、AUC、训练时间和 RAM。
- 主要实验结论：
  - 图像模态中，NEAT-dyMO 达到 `0.9965±0.0034` accuracy、`0.9967±0.0032` F1、`0.9996±0.0006` AUC；相对 NEAT-stMO 的准确率差异有显著性，作者报告 Wilcoxon `p=0.031`、Cliff `delta=+0.64`。
  - 语音模态中，NEAT-dyMO 达到 `0.9893±0.0059` accuracy、`0.9887±0.0070` F1、`0.9983±0.0019` AUC；相对 NEAT-stMO accuracy `p=0.031`、`delta=+0.36`，相对 ViT accuracy `delta=+0.72`。
  - 文本模态中，NEAT-dyMO 达到 `0.9926±0.0015` accuracy、`0.9722±0.0060` F1、`0.9970±0.0015` AUC；F1 相对 NEAT-stMO、Pareto-NEAT 和 MLP 分别有中到大的效应量。
  - NEAT-dyMO 相对 ViT 等重模型训练更快、RAM 更低；但 SVM、MLP、Auto-Keras 或 Hyperband 在部分文本指标或运行时间上仍有竞争力。
- 消融或机制证据：
  - 线性动态权重与 sigmoid schedule 都体现从新颖性探索到性能开发的思想，作者在 Sec. 5.3 比较不同调度形式。
  - SHAP 分析显示早期较大网络、较高 dropout 与新颖性相关，后期较低学习率和中等 batch size 更有利于准确率。
  - Species-local Pareto-NEAT 作为基线说明保留 niche 对 NEAT 很重要，但 NEAT-dyMO 在文本 F1 和部分模态综合表现上更突出。
- 证据边界：
  - 图像数据接近性能天花板，部分全局 accuracy/F1 检验不显著，容易出现 ceiling effect。
  - 文本任务使用固定 BERT `[CLS]` 768 维嵌入，未搜索 token-level 结构。
  - 语音数据通过 FAISS 相似筛选构造平衡集，结果可能受嵌入邻近性和 hard negative 覆盖影响。
  - 证据主要来自垃圾检测分类任务，尚未证明该动态 novelty schedule 对一般多目标优化或其他 NAS 任务都有效。

## 局限与未来工作

- 作者明确说明的局限：
  - 图像数据集可能不能代表现代图像垃圾、对抗图像或跨平台视觉垃圾样本。
  - 语音数据由 FAISS 相似筛选形成，可能遗漏更难的负样本，准确率也可能反映声学簇分离而非更广泛场景。
  - 严格语音相似阈值 `>=0.99` 有助于避免泄漏，但也可能过度拆分或过滤相近变体。
  - 文本只使用 BERT `[CLS]` 固定嵌入，可能丢失 token-level 和长文本结构信息。
- 作者未来工作：
  - 使用 BERT 多层 mean/max pooling 或 top-k layer 表示，缓解 `[CLS]` 信息瓶颈。
  - 将单模态演化得到的 genotype 作为跨模态融合拓扑的种子。
  - 结合 Grad-CAM、Attention Rollout 和 saliency maps 等 phenotypic XAI。
- 我们认为仍需确认的问题：
  - 线性 novelty 衰减的参数如何随评价预算、任务噪声和架构空间规模自适应。
  - 将多目标压成动态标量 fitness 是否会丢失有价值的 Pareto trade-off。
  - 行为描述符中的特征掩码采样长度和 Gower 权重是否会显著改变新颖性压力。
  - 在真正昂贵 NAS 或强化学习控制任务中，确定性 schedule 是否仍优于反馈式或 bandit 式调度。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 确定性新颖性衰减的神经进化权重调度：适合在结构搜索、程序搜索、NAS 或多算子搜索中，用低成本 schedule 管理探索/开发权重。
- 暂留在论文卡中的方法、原理或架构启发：
  - 用 RF surrogate + SHAP 分析演化历史，作为算法诊断工具，而不直接改变搜索行为。
  - Species-local Pareto ranking 可作为保护 speciation/niche 的具体实现，后续若多篇论文支持再提升为设计卡。
  - 语音任务中用 Wav2Vec2 embedding + FAISS 近邻筛选构造难负样本和平衡集，更偏数据工程方法。
- 局部创新线索：
  - 把线性 novelty 衰减替换为分段、sigmoid、预算感知或停滞感知 schedule。
  - 将泛化间隙目标替换为交叉验证方差、校准误差、推理成本或鲁棒性指标。
  - 行为描述符可加入真实输出行为、约束违反模式、局部搜索轨迹或参考向量覆盖。
- 结构创新线索：
  - 构建“行为描述符 -> novelty archive -> 确定性权重调度 -> 后期性能接管”的轻量策略层，用于不想引入 RL/反馈控制器的结构进化算法。
  - 将演化历史 XAI 作为外部诊断回路，反向设计下一次运行的 schedule、描述符和搜索空间边界。
