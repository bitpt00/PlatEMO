# A Two-Stage Cooperative Discrete Differential Evolution With Q-Learning for Multiobjective Energy-Efficient Distributed Blocking Flow-Shop Scheduling

## 一句话理解

这篇论文面向同时最小化总拖期 TTD 和总能耗 TEC 的分布式阻塞流水车间调度，提出 QTCDDE：先用面向 TTD/TEC 的 MNEH 初始化和离散差分进化改造作业序列，再用 Q-learning 自适应选择速度调整、单工厂序列调整和跨工厂序列调整局部搜索算子。

## 问题与动机

- 研究问题和场景：论文研究 energy-efficient distributed blocking flow-shop scheduling problem (EEDBFSP)。系统中有 `n` 个作业、`F` 个工厂、每个工厂 `m` 台机器；工厂内部无中间缓冲，作业在上一机器加工完成后，如果下一机器忙，只能在当前机器上 blocking。每道工序还要选择加工速度，速度越高加工时间越短但单位时间能耗越高；速度切换时间被忽略，但一旦某道工序开始，速度保持不变。目标为同时最小化 total tardiness (TTD) 和 total energy consumption (TEC)。
- 问题困难：EEDBFSP 同时包含作业到工厂分配、工厂内排序和每个作业-机器速度选择三个耦合子问题；blocking 与 idle 会同时影响交期和能耗，高速加工可能降低拖期却增加正常加工能耗，低速加工可能降低能耗却造成拖期或阻塞。作者指出 DBFSP 在机器数超过 3 时已为 NP-hard，加入能耗与速度决策后更难。
- 为什么重要：作者从绿色制造出发，认为制造业能耗约占全球能源 1/3，分布式生产是先进生产模式之一；在化工、钢铁、机器人单元等无缓冲或阻塞制造环境中，智能调度既影响交付信誉，也影响能源消耗。
- 现有算法为什么不足：作者观点是，已有 DFSP/DBFSP 工作较多研究 makespan、completion time 或 TEC，但同时考虑 TTD 与 TEC 的 EEDBFSP 研究不足；DE 虽被广泛用于连续和离散优化，但用于 EEDBFSP 的离散 DE 研究不充分；Q-learning 虽已用于组合优化和调度，但用于 TTD+TEC 的 EEDBFSP 局部搜索选择仍较少。
- 本文希望解决什么：建立 EEDBFSP 的 MILP 模型用于问题刻画和小规模验证，并提出能同时处理三个子问题的两阶段协作离散 DE + Q-learning 框架：作业分配到工厂、作业在各工厂内的位置安排、每个作业-机器工序的速度选择。

## 核心理念与算法流程

- 核心理念：把 EEDBFSP 的搜索拆成“序列全局探索”和“问题知识局部修正”两个阶段。第一阶段 DDE 用离散化的 current-to-best 差分思想更新作业序列，第二阶段 Q-learning 根据历史反馈选择局部搜索算子，分别修正速度、单工厂排序和跨工厂分配/排序。两阶段交替产生候选，再由快速非支配排序与拥挤距离选择下一代。
- 主要流程：
  1. 用 MNEH 初始化：随机生成每个作业-机器速度，按实际加工时间排序；一半个体按 TTD 最优插入作业，一半按 TEC 最优插入作业；再通过降速优化 idle time 和能耗。
  2. DDE 阶段：对每个个体，使用 TTD/TEC 归一化与 Tchebycheff 权重选择当前代 best；对 `best-current` 与 `r1-r2` 的序列差异执行概率筛选，再用 insert/swap 生成变异个体；随后执行离散交叉并修复重复作业。
  3. 参数自适应：mutation probability `MU` 由以历史成功 `MUs` 为位置参数的 Cauchy 分布产生，crossover probability `CR` 由以 `CRs` 为均值的正态分布产生，并用历史成功信息更新标准值。
  4. Q-learning 局部搜索阶段：动作集合为 13 个局部搜索算子；使用 Q-table/R-table、`epsilon`-greedy 与 `+1/-1` 有效性奖励，逐个个体选择局部搜索动作。
  5. 环境选择：两阶段生成后，按 FNSAC 计算，优先非支配等级并结合 crowding distance 形成下一代。
- 关键组成部分：
  - 混合解表示 `(N,V)`：`N` 表示分配到各工厂的作业序列，`V` 是 `n x m` 速度矩阵。
  - EEDBFSP MILP：约束 (1)-(3) 保证每个作业只占一个工厂位置、每个位置只有一个作业、每个作业-机器只选一个速度；约束 (6)-(11) 递推 departure time 并体现 blocking；约束 (12)-(17) 计算 TTD、normal energy、blocking energy、idle energy 与 TEC。Markdown 中公式多为图片省略，PDF 第 4 页已定点核验。
  - MNEH 初始化：把 NEH 风格插入启发式分别朝 TTD 和 TEC 两个目标构造半数种群。
  - 离散 DE：将连续 `DE/current-to-best/1/bin` 中的向量差异映射为作业位置差异，并用 insert/swap 处理序列个体。
  - 主路径/非主路径局部搜索：作者把完全影响 TTD 和 TEC 的路径称为 main path，围绕 main/nonmain path 的加减速设计 L1-L5。
  - Q-learning 算子选择：用历史有效性反馈在 13 个局部搜索动作之间调度。
- 可能被修改的位置：若作为基础算法，可替换 Q-learning 状态定义和 reward、把 `+1/-1` 改为 HV/IGD/可行性/能耗贡献，或把 DDE 的 insert/swap 换成更领域化的阻塞关键块移动。
- 必须保留的核心：两层决策耦合必须保留，即作业序列/工厂分配与速度矩阵同时优化；blocking、idle、TTD、TEC 的评价解码也必须保留，否则算法不再针对 EEDBFSP 的关键矛盾。

## 实验证据

- 测试问题和对比算法：使用 Taillard test suite，原始 120 个实例按 `n x m` 分 12 个规模，并扩展工厂数 `{2,3,4,5,6,7}`；速度档位为 `{1.00,1.30,1.55,1.75,2.10}`，能耗参数为 `NP=4*V^2 kW`、`BP=1.50 kW`、`IP=1.00 kW`。所有算法 Java 实现，30 次独立运行，终止时间 `0.5*n` 秒。指标为 ONVG 和 C metric。对比算法包括 CPLEX-12.9、BCMA、PDJaya、HHQL。
- 参数实验：Taguchi/DOE 调参考察 `ps`、`c`、`alpha`、`gamma`，作者报告 `ps` 影响最大、`c` 最小；最终设定 `ps=50, c=0.05, alpha=0.5, gamma=0.7`。这是参数敏感性证据，不等于跨问题最优。
- 主要实验结论：
  - 论文实验直接支持：QTCDDE 在全部实例上相对随机初始化版本 QTCDDEni 的 ONVG 更好，C metric 95% CI 与 Wilcoxon 也支持差异，说明 MNEH 初始化有效。
  - 论文实验直接支持：去掉 DDE 的 QTCDDEnd 在 ONVG、C metric 和 Wilcoxon 上显著弱于 QTCDDE，支持第一阶段 DDE 的必要性。
  - 论文实验直接支持：把 Q-learning 局部搜索选择换成随机选择的 QTCDDEnq 弱于 QTCDDE，支持 Q-learning 自适应局部搜索有效。
  - 论文实验直接支持：小规模上 QTCDDE 在 ONVG、C metric 和平均时间上优于 CPLEX；作者用其验证 MILP 正确性并说明 QTCDDE 能有效求解小规模 EEDBFSP，但这并不表示 QTCDDE 是精确最优求解器。
  - 论文实验直接支持：相对 BCMA、PDJaya、HHQL，QTCDDE 在 ONVG 与 C metric 上整体更优；Pareto front 更靠近原点且分布更广；Wilcoxon 检验在 95% CI 下显示显著差异。
- 消融或机制证据：
  - MNEH vs random initialization：支持 TTD/TEC 双目标构造初始化的价值。
  - QTCDDE vs QTCDDEnd：支持 DDE 全局序列探索阶段。
  - QTCDDE vs QTCDDEnq：支持用 Q-learning 而非随机选择局部搜索算子。
  - 参数实验显示种群规模对性能最敏感，说明该问题需要较充足多样性。
- 证据边界：
  - 实验是确定性 benchmark，尚未证明动态工厂、异构工厂、随机故障和真实生产数据上的效果。
  - Q-learning reward 很简化，只记录动作是否 useful；缺少与 UCB、Thompson sampling、DQN、成功率统计等轻量/复杂控制器的同框比较。
  - 局部搜索算子整体消融证明了 Q-learning 选择有效，但没有逐个分离 L1-L13 的贡献。
  - 表格多数在 Markdown 中为图片省略，关键结论通过 PDF 第 11-14 页文字与图表标题定点核验。

## 局限与未来工作

- 作者明确说明的局限：正文未系统列出局限，但从 future work 看，当前 QTCDDE 主要针对静态、同质分布式阻塞流水车间，尚未覆盖动态因素、异构工厂环境和更复杂制造约束。
- 作者未来工作：作者计划将 QTCDDE 扩展到其他分布式调度问题；加入 dynamic operators 处理 dynamic DFSP；考虑 heterogeneous environments；进一步探索制造业约束并解决更复杂的实际分布式调度问题；研究将其他新型 self-learning techniques 融入具体调度问题。
- 我们认为仍需确认的问题：
  - Q-learning 状态到底如何细化表示搜索状态，论文在卡片可读部分给出的状态定义不够丰富，可能更接近动作收益表而非强状态感知控制。
  - `epsilon=0.9*t/Tmax` 随时间增大时，按文中动作选择式 `rand > 1-epsilon` 会提高随机动作概率，这与“后期选择最高 reward 动作”的文字描述存在潜在不一致，复现时应核查代码或公式。
  - DDE 中序列差异、insert/swap 和重复修复对工厂边界的具体处理需要代码级确认。
  - 小规模 CPLEX 对比使用 ONVG/C/time，不适合直接证明大规模近似解质量接近最优。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 补充“成功率反馈的算子与参数自适应选择”：本文提供 DDE 中 `MU/CR` 历史成功参数更新的离散调度应用证据。
  - 补充“状态驱动的 DRL 演化算子选择”：本文提供更轻量的 tabular Q-learning 局部搜索算子调度证据，动作是领域局部搜索而非 GA/DE。
- 暂留在论文卡中的方法、原理或架构启发：
  - TTD/TEC 双目标 MNEH 初始化：一半个体按交期插入，一半按能耗插入，适合作为调度初始化模板，但目前与 EEDBFSP 结合较强，先留在论文卡。
  - main path / nonmain path 的速度加减速：对能耗调度很有启发；已与“非支配排名驱动的辅助速度决策修正”和“前向事件解码与反向能耗压缩调度”查重，机制不同且目前证据不足，先不建新卡。
  - 两阶段协作 DDE + Q-learning：结构清晰，但更像本文算法框架整体，暂不单独建卡。
- 局部创新线索：
  - 把 Q-learning 的 reward 从 `useful +1 / other -1` 改为 HV 增量、TTD/TEC 双目标贡献、blocking time 减少或可行解覆盖增量。
  - 对 L1-L13 按“速度/单工厂/跨工厂”三类维护分层策略，先选类别再选算子，降低动作空间噪声。
  - 将 main path 识别与 critical block、tardy job、high-energy job 标签结合，形成更可解释的局部搜索动作。
  - 对 `MU/CR` 成功历史按 Pareto 区域或工厂负载状态分表，避免全局参数掩盖区域差异。
- 结构创新线索：
  - 构造“序列全局探索 + 辅助速度局部修正 + 学习调度器”的通用绿色调度框架，可迁移到 no-wait/no-idle、有限缓冲、分布式混合流水车间。
  - 把 MILP 小规模解、启发式解和仿真反馈共同作为 offline pretraining 数据，训练局部搜索算子选择器。
  - 引入动态/异构工厂后，可把环境变化严重度或工厂异构度作为 Q-learning/DQN 状态特征。
