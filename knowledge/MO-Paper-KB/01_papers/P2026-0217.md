# 面向图像分类的多目标脉冲神经架构搜索

## 一句话理解

EMO-SNAS 把 SNN 架构搜索建模为“分类错误率 + 脉冲数”的双目标优化：用变量长度编码让网络深度随演化变化，用 ADD/REMOVE/CHANNEL/EXPAND 等算子同时搜索空间结构和时间信息，最终给出一组精度、延迟和能耗折中的脉冲神经网络架构。

## 研究问题

- SNN 依靠稀疏二值脉冲和事件驱动计算实现低能耗，但手工设计架构需要大量专家经验。
- ANN-to-SNN 转换方法常需要数百个 timestep 才能保持精度，推理延迟和能耗偏高。
- 既有 SNN NAS 方法仍存在明显限制：
  - SNASNet 依赖人工设计 backbone，不能全局搜索网络结构；
  - AutoSNN 依赖 supernetwork 和人工设定脉冲数目标，难以自动平衡精度与能耗；
  - 固定长度 ENAS 编码要求预设网络深度，而最优深度通常未知；
  - 常规变异更多关注空间结构，忽略 SNN 的时间维信息；
  - 既有多目标 ENAS 多以参数量或 FLOPs 为目标，不直接面向 SNN 的 spike number/power。

## 方法框架

### 总体流程

- 以 NSGA-II 为外层多目标进化框架。
- 初始化一组变量长度 SNN 架构个体。
- 对每个个体训练并评价分类错误率和平均脉冲数。
- 通过变量长度交叉和四类变异生成子代。
- 用非支配排序和拥挤距离选择下一代。
- 最终输出一组 Pareto 架构供用户按精度、延迟或能耗偏好选择。

### 变量长度编码

- 一个个体是一串 basic blocks，染色体长度就是网络深度。
- 每个 block 编码输入通道和输出通道，输出通道从 `{64, 128, 256}` 中选取。
- 当输出通道为 256 时，stride 设为 2，用来降低特征图尺寸。
- basic block 包含两个 3x3 convolution、两个 LIF layer、两个 batch normalization 和 skip connection。
- 编码只保存通道和 block 序列，既降低搜索维度，又允许深度随演化增减。
- 分类器前使用 accumulate operation 汇聚多个 timestep 的时序信息。

### 双目标适应度

- 目标 1：分类错误率，越低越好。
- 目标 2：spike number，越低越好。
- spike number 统计被激活的脉冲神经元数量，作为功耗、通信负担和事件驱动推理开销的代理指标。
- 论文主体没有直接给出真实 neuromorphic hardware 能耗测试，主证据仍来自 spike number。

### 子代生成

- 交叉：变量长度 single-point crossover。
  - 在两个父代上分别随机选择切点；
  - 交换前后片段生成两个子代；
  - 如果拼接处通道不一致，就把后半段输入通道修正为前半段输出通道。
- 变异：
  - **ADD**：增加一个 basic block，改变深度，增强结构探索；
  - **REMOVE**：删除一个 basic block，避免过深结构并探索不同深度；
  - **CHANNEL**：修改某个 block 的输出通道，做同深度局部调整；
  - **EXPAND**：临时增加某个 block 的 timestep，通过 AND 逻辑引入邻近时间信息，再恢复为与后续 block 对齐的 timestep。
- 论文把 ADD/REMOVE 视为跳出局部最优的探索机制，把 CHANNEL/EXPAND 视为同深度结构上的局部开发机制；EXPAND 的关键价值是让 SNN 搜索不只改空间结构，也能显式利用时间维信息。

## 实验设置

- 数据集：
  - 静态图像：CIFAR10、CIFAR100、TinyImageNet；
  - 神经形态数据：N-MNIST、DVS128 Gesture。
- 基准方法：
  - 手工或转换式 SNN：ResNet20Deng、VGG9-Garg、VGG16-Kundu、QCFS、Opt.mem、DIER-SNN、IIR-SNN 等；
  - surrogate-gradient SNN：CIFARNet-Wu、ResNet11-Lee、ResNet19-Zheng、CIFARNet-Fang；
  - 自动 SNN 搜索：SNASNet、AutoSNN。
- 进化参数：
  - population size 20，generation 20；
  - crossover probability 0.9，mutation probability 0.2；
  - ADD/REMOVE/CHANNEL/EXPAND 概率分别为 0.7/0.1/0.1/0.1；
  - timestep 默认 2；
  - 搜索阶段训练 150 epochs，搜索后重训 600 epochs。
- 硬件：3 块 NVIDIA GeForce GTX 2080 Ti。

## 主要结果

- CIFAR10：
  - 相比 CIFARNet-Fang，准确率提升 0.45%，spike number 降低 58%；
  - 相比 SNASNet 和 AutoSNN，准确率分别提升 0.56% 和 0.45%，spike number 分别减少 74% 和 33%；
  - 搜索成本约 25.5 GPU days。
- CIFAR100：
  - 相比 AutoSNN，准确率提升 0.43%，spike number 降低 28%；
  - 相比 SNASNet，准确率低 0.66%，但 spike number 降低 63%；
  - 搜索成本约 25.5 GPU days。
- TinyImageNet：
  - 相比 AutoSNN，准确率提升 7.51%，spike number 降低 12%；
  - 相比 SNASNet，准确率提升 2.19%，但 spike number 增加 2%；
  - 搜索成本约 57 GPU days。
- N-MNIST：
  - EMO-SNAS 在准确率和 spike number 上均达到表中最好结果；
  - 搜索成本约 18.5 GPU days。
- DVS128 Gesture：
  - 相比 CIFARNet-Fang、ResNet19-Zheng、AutoSNN，准确率分别提升 1.39%、0.35%、0.35%，并减少 spike number；
  - 搜索成本约 2 GPU days。

## 消融与机制证据

- 演化过程可视化显示，种群逐渐向高精度、低 spike 区域移动；CIFAR10/CIFAR100/TinyImageNet 的最好个体分别在第 8、5、12 代左右出现。
- timestep 分析显示，更多 timestep 可以轻微提升精度，但 spike number 明显增加；作者因此强调低 timestep 对推理效率更重要。
- 初始通道分析显示，高性能 SNN 不一定依赖大初始通道：
  - CIFAR10 上 initial channel 64 的 EMO-SNAS 已优于多个人工网络和 AutoSNN；
  - initial channel 128 时，EMO-SNAS 可在精度接近或更高的同时显著减少 spike number 或参数量。
- EXPAND 消融：
  - 在简单 one-block SNN 上，CIFAR10 准确率提升 2.97%，CIFAR100 提升 1.52%，TinyImageNet 提升 2.18%；
  - EXPAND 会带来 spike number 增加，但论文设定较低变异概率以限制整体能耗影响。

## 局限与阅读边界

- 搜索成本仍高：CIFAR10/100 约 25.5 GPU days，TinyImageNet 约 57 GPU days。
- spike number 是能耗代理指标，正文没有在真实神经形态硬件上测量实际功耗。
- 搜索空间主要基于卷积式 basic block，对 Transformer、recurrent SNN、检测、控制等任务的泛化仍需验证。
- EXPAND 能提升精度，但可能增加 spike number；它不是纯降耗算子，而是时间信息和能耗之间的再权衡。
- 多数对比来自文献报告值，未必全部在同一硬件和训练预算下重跑。
- 补充材料讨论 power consumption 和 convergence，但当前 Markdown 抽取主要覆盖正文，细节不完整。

## 可复用知识与创新线索

- 可复用机制：
  - 用变量长度编码避免人工预设网络深度；
  - 在交叉后做轻量通道修复，保证结构可行；
  - 把 SNN 特有的 spike number 作为能耗代理目标，而不是只用 FLOPs 或参数量；
  - 为 SNN 设计时间维变异算子，使 NAS 能直接探索 temporal representation。
- 局部创新线索：
  - 将 EXPAND 的固定 AND 逻辑替换为可学习或可自适应的 temporal fusion；
  - 把 spike number 换成硬件校准后的 energy/latency proxy；
  - 用多保真评价或代理模型降低 GPU-day 搜索成本；
  - 把变量长度编码扩展到 Transformer/SNN 混合结构或事件视觉任务。
