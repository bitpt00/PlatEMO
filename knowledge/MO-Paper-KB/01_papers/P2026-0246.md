# A Bi-Level Multiobjective System for Renewable Energy Self-Consumption: A Resident-Aware Approach to Leveraging Energy Flexibility

## 一句话理解

论文把能源社区中 aggregator 的动态定价与居民 appliance scheduling 建成双层多目标优化：上层最小化可再生能源自消费偏差，下层在居民不满意度和能源成本之间折中，并提出 BiMO-EMS-II，把 adaptive population transfer、UPMX 排列映射交叉和 Decision Making with Cooperation 组合起来，在接近最优自消费的同时保留居民福利折中。

## 问题与动机

- 研究问题和场景：面向 collective self-consumption energy communities，EMSA 作为非营利 cooperative 管理社区 PV 等 RE 资源，通过动态价格信号鼓励居民把用电转移到 RE 高产时段；居民则根据价格和偏好安排 appliance usage。
- 上下层目标：
  - 上层 aggregator 决策价格序列 `c`，目标是最小化 consumption 与 RE availability 的偏差，即提高 self-consumption。
  - 下层居民决策 appliance usage schedule `x` 与 usage-to-preference mapping `mx`，目标是最小化 preference dissatisfaction `D` 和最大居民 energy cost `C`。
- 现有方法为什么不足：
  - 许多 aggregator-resident bi-level 模型用线性规划或 Stackelberg 框架，但忽略 aggregator 作为 self-consumption catalyst 的作用，或忽略居民目标之间的冲突。
  - 传统 optimistic/pessimistic bilevel decision making 假设过强：optimistic 假设居民完全配合上层，pessimistic 假设最坏选择；两者都难描述真实社区中部分合作和居民偏好差异。
  - 作者此前 BiMO-EMS 只通过 load curtailment/reduction 利用 flexibility，无法进行 load shifting，导致能源灵活性利用不足。
  - 嵌套 EBLMO 计算昂贵；已有 SPT/DST 等 KT 没有充分研究迁移数量和解在下层搜索空间中的分布。
- 本文希望解决什么：
  - 建立支持 load shifting 与 curtailment 的 BMOP；
  - 用 UPMX 维护 appliance usage 与 preference mapping 的可行关系；
  - 用 APT 把相邻上层价格方案的下层 reaction set 有选择地迁移到当前下层初始种群；
  - 用 DMC 在 optimistic、pessimistic、resident-aware、fixed cooperation 和 dynamic cooperation 之间统一决策。

## 核心理念与算法流程

- 核心理念：把能源社区看成上下层协商系统，而不是单方优化。上层通过动态价格塑造需求曲线，下层输出代表居民福利的 Pareto reaction set，再由 DMC 根据居民 profile 和合作程度选出一个 schedule 回馈给上层评价。
- BiMO-EMS-II 主流程：
  1. 上层 GA 初始化价格方案 population `C`，对每个价格方案 `c` 调用 lower-level evaluation。
  2. 下层初始化 appliance schedule population `X`：若已有上层 informant，则用 APT 迁移部分下层解；否则用全 0、全 1 和随机 schedule 初始化。
  3. 对每个 schedule `x`，用 mapping heuristic `MH` 生成可行 preference mapping `mx`，先严格映射完全满足的 preference，再把剩余 usage 映射到最近未分配 preference。
  4. 下层 MOEA/D 用 normalized Tchebycheff、UPMX crossover 和 BitFlip mutation 搜索 `D(mx,P)` 与 `C(c,x,e)` 的 Pareto reaction set。
  5. DMC 从下层 reaction set 中选择一个 `xc`：可按 optimistic/pessimistic/RA/fixed cooperation/dynamic cooperation 规则选解。
  6. 上层用返回的 `(c, xc, mxc)` 计算 self-consumption objective `F`，GA 继续演化价格方案，最终输出最佳 pricing scheme 与 schedule。
- 三个关键组件：
  - APT：对 decomposition-based EBLMO，从最近邻上层解的下层 reaction set 中按 weight vector `lambda` 与 ASF 关系构造 temporary population，再按 transfer selection-distance `d` 选取均匀分布子集注入当前下层初始 population。
  - UPMX：改造 PMX/Uniform PMX 以处理 order-based permutation-like schedule，允许空 mapping slot，并用 repair heuristic 保证 appliance usage-to-preference mapping 满足约束。
  - DMC：把下层 reaction set 中的上层 desirability、下层 profile desirability 和 cooperation index `q` 组合起来；dynamic cooperation 通过“某一方的 gain 是否至少补偿另一方的 loss”的公平原则调节 `q`。
- 可能被修改的位置：
  - 上层 GA 可替换为 CMA-ES、DE、MOEA/D、贝叶斯优化或真实能源市场约束搜索器；
  - 下层 MOEA/D 可替换为 NSGA-II、RVEA、偏好 MOEA 或 exact/heuristic scheduler；
  - APT informant 可从最近邻上层解扩展为多个 informants、archive 或 learned task graph；
  - DMC 的 fixed/dynamic cooperation 可换成 bargaining solution、Nash social welfare、regret minimization 或可学习合作策略。
- 必须保留的核心：
  - 上层评价必须通过下层多目标 reaction set，而不是单一居民响应；
  - 居民偏好/成本目标与 aggregator 自消费目标需要显式区分；
  - 反应集选择要允许从完全上层乐观到居民主导之间的连续或动态合作；
  - 若用 APT，迁移解要与 decomposition subproblem/weight vector 对齐，不能只随机复制下层解。

## 实验证据

- 数据与设置：
  - 12 个 realistic datasets 来自 REFIT 公开数据集，覆盖 Small/Medium/Large 社区和 Autumn/Winter/Spring/Summer；从 2013-2015 年 20 个英国家庭电器 kW 读数抽取偏好，按小时聚合并由 threshold 识别 preference。
  - RE 数据按家庭数与季节统一变化，假设每户 4.5 kW PV system，根据 U.K. 季节平均温度与辐照度构造 06:00-18:00 RE production curve。
  - BiMO-EMS-II 用 jMetal 4.5 实现；上层 GA、下层 MOEA/D；主要对比 BiMO-EMS、OptaPlanner OPD/OPC、PRF，30 次运行。
  - 指标：system-level 目标 `S/D/C`，下层比较用 HV、spread、C-metric，统计用 two-sample T-test，运行时间用 CPU time。
- 系统性能：
  - BiMO-EMS-II 在 3 个 dataset 上达到 self-consumption objective `S` 最优；其余数据集与最优 `S` 的差距为 Small up to 19 kWh、Medium up to 25 kWh、Large up to 47 kWh。
  - 与旧 BiMO-EMS 相比，BiMO-EMS-II 在 self-consumption 上一致更好；作者把差异归因于 load shifting 与更有效下层空间探索。
  - `D` 目标上 BiMO-EMS-II 一致优于其他方法，说明在实现高 self-consumption 时对居民 preference satisfaction 的牺牲较小；`C` 上旧 BiMO-EMS 与新方法竞争，说明两者都能给出 cost-attractive pricing schemes。
  - PRF 显示不利用 energy flexibility 会显著恶化 self-consumption：Small 差 68-100 kWh，Medium 差 87-223 kWh，Large 差 158-352 kWh。
- 能源与成本节省：
  - 与使用同一动态价格但不利用 flexibility 的 PRF 相比，冬季节省最高，energy savings 为 86-93% 或 94-306 kWh。
  - 这些节省伴随 36-51% preference satisfaction 牺牲，但居民成本降低 83-95%，即最重收费居民每天少付约 16-26 cost units。
  - 半数实验中 energy savings 超过 80% 或 75 kWh，satisfaction sacrifice 为 14-59%，cost compensation 为 82-96%。
- DMC 实验：
  - Dynamic-q DMC 随居民 profile `v` 变化表现稳定，Small datasets 上 `S/D/C` 变化上限分别为 15 kWh、1.09 dissatisfaction-units、4.88。
  - Dynamic-q DMC 接近 optimistic 性能，最坏差距为 16 kWh、0.73 dissatisfaction-units、2.11。
  - 当 `v=1` 完全优先 preference satisfaction 时，提高 optimism/cooperation 明显改善 `S` 和 `C` 但损害 `D`；作者认为建立合作尤其重要。
  - 作者结论：若知道 LL preference 且允许上下层合作，dynamic-q DMC 是极端 optimistic/pessimistic 的可行替代。
- APT / KT 实验：
  - APT on MOEA/D 比 SPT 快 1-2 秒，并在 Medium/Large datasets 上各项指标竞争。
  - NT 被 APT 在除 spread 外所有数据集和指标上显著超过，说明 KT 有正面影响。
  - APT 在 HV 和 C-metric 上显著优于 NSGA-II 变体；在 Large datasets 中 APT 的 PF 被 SPT 支配从未超过 1%。
  - Supplementary control experiments 显示不同 `d` 可改善 HV/C-metric，但会增加计算量。
- UPMX 实验：
  - UPMX on MOEA/D 在 HV 上显著优于 MOEA/D 其他 crossover，差异最高约 0.1%；相对 NSGA-II 变体优势更大。
  - UPMX 与 PMX 在 C-metric 上竞争，作者认为 UPMX 更能近似 true PF。
  - NSGA-II 运行很快，但作者归因于 premature convergence；UPMX on NSGA-II 的 HV 也优于 NSGA-II 其他算子，但在大数据集上 C-metric 输给 UNI。
- 证据边界：
  - 真实应用只覆盖 REFIT-derived residential preferences 和构造的 PV production curve。
  - 单位价格 `ct` 被归一化到 `[0,1]`，实际成本节省需按真实价格范围换算。
  - 作者没有给出制造级/政策级约束，如居民拒绝移峰、设备不可中断、隐私、实时响应失败等。

## 局限与未来工作

- 作者明确说明的局限：
  - Optimistic decision making 不现实，因此需要 DMC；但 DMC 仍依赖已知居民 profile 和合作假设。
  - BiMO-EMS-II 在 optimal `S=0` 的场景更难达到精确最优。
  - APT 的最优 `d` 存在质量与计算量权衡。
- 作者未来工作：
  - 论文结论没有展开独立未来工作段，主要以 BiMO-EMS-II 的有效性总结收束。
- 我们认为仍需确认的问题：
  - Dynamic cooperation 的公平原则是否能反映真实居民协商、激励兼容和长期满意度。
  - 价格信号与居民调度之间是否会因隐私、设备类型、自动化程度和行为噪声而失效。
  - APT 的最近邻 informant 在高维价格方案中是否可靠，是否需要多 informant 或 archive-based transfer。
  - UPMX 对含运行时长、不可中断、前后依赖和储能约束的 appliance scheduling 是否仍足够。
  - 归一化价格和构造 PV 曲线对真实部署经济性有多大影响。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：协作式双层多目标反应集决策。DMC 可迁移到所有存在下层多目标 reaction set、上层目标与下层 DM 偏好冲突且允许部分合作的 BLMOP。
- 暂留在论文卡中的方法、原理或架构启发：
  - APT 是很有价值的 decomposition-based EBLMO 迁移模块，但目前只在本应用中验证，暂作为待升级线索。
  - UPMX 与 `mx` 修复适用于 appliance/preferences 的特殊映射结构，通用性弱于 DMC，暂不单独建卡。
  - REFIT-to-preference preprocessing 与 PV curve 构造是应用实现细节，不建场景卡。
- 局部创新线索：
  - 把 APT 的 single nearest informant 改成多个近邻 reaction sets 的权重融合，或用 learned similarity 选择 informant。
  - 用 Nash bargaining、Kalai-Smorodinsky、regret matching 或可学习 policy 替换 DMC dynamic-q 公平准则。
  - 将居民 profile `v` 从静态输入改为在线估计，依据居民实际响应更新偏好。
  - 在 UPMX 后加入 constraint propagation，使多时段 appliance 运行块、最短运行时间和不可中断约束自动修复。
- 结构创新线索：
  - 构建“价格激励上层 + 居民 reaction-set 下层 + 协作决策中介”的通用框架，可用于能源、水资源、交通需求管理、云资源定价等上下层偏好冲突问题。
  - 将 DMC 的 cooperation index 作为 evolution state 继承并变异，让上层搜索不仅优化价格，也学习不同居民群体的合作可行区。
