# Expensive Many-Objective Evolutionary Optimization With a Self-Adaptive Surrogate Model

## 一句话理解

论文提出 EMaOEA-SASM：在昂贵 many-objective optimization 中，不再为所有目标函数固定同一种代理模型，而是用 `R^2` 指标为每个目标函数在 GP 与 RBF 之间自适应选模，并用同时考虑决策空间距离、目标空间距离和局部拥挤度的 dual-space indicator 选择一个候选做真实昂贵评价。

## 问题与动机

- 研究问题和场景：求解 expensive many-objective optimization problems (EMaOPs)，目标数从 3 到 20，真实评价预算有限，普通 MaOEA 需要大量目标函数调用，难以直接用于汽车碰撞、能源控制等高成本工程问题。
- 现有算法为什么不足：
  - MaOEAs 面对 many-objective 问题时已经存在支配压力下降问题；若每次评价又昂贵，评价预算更成为瓶颈。
  - 多数 SAEA 为每个目标函数使用同一类 surrogate model；但不同目标函数可能有不同线性程度、多峰性和光滑性，统一模型可能不能同时拟合所有目标。
  - Ensemble surrogate 能覆盖更多函数特性，但每个目标都训练集成模型会显著增加计算成本。
  - 许多 infill criterion 主要看 objective space 或代理预测值/不确定性，较少同时利用 decision space 与 objective space 的空间信息。
- 本文希望解决什么：
  - 每个 objective function 单独选择当前更匹配的 surrogate type；
  - 用 RVEA 在代理目标上低成本搜索候选；
  - 用 dual-space indicator 从候选中挑选更有探索价值的解进行真实评价；
  - 在有限真实评价预算下兼顾 many-objective 的收敛与分布。

## 核心理念与算法流程

- 核心理念：把“代理建模”和“真实评价采样”都做成按当前档案自适应的模块。代理层不预设单一模型，而是在每个目标上用留出测试的 `R^2` 选择 GP 或 RBF；采样层不只选择预测最优解，而是选择在决策空间和目标空间都相对稀疏、能提供新信息的候选。
- 主要流程：
  1. 用 LHS 在决策空间生成 `11*D - 1` 个初始解，真实评价后存入 archive `Arc`。
  2. 对每个 objective function 执行 adaptive model selection：把 `Arc` 随机分为 70% training data `TRD` 和 30% testing data `TED`。
  3. 对该目标分别训练 GP surrogate 和 RBF surrogate，用 `TED` 上真实值与预测值计算两个 `R^2`，选择 `R^2` 更大的模型类型。
  4. 用选出的模型类型和全体 `Arc` 数据训练每个目标的最终 surrogate。
  5. 把 surrogate models 当作 objective functions，使用 RVEA 做 model-assisted optimization；RVEA 内部用 SBX 与 polynomial mutation 生成候选并按代理目标值选择。
  6. 对 RVEA 输出候选计算 dual-space indicator：先找 candidate 在 `Arc` 中决策空间最近邻，得到决策距离 `DX`；再计算候选与该最近邻在目标空间的距离 `DY`；用 `DY` 作为目标空间半径统计局部拥挤度 `eta`。
  7. 选择 DSI 最大的候选做真实昂贵评价，加入 `Arc`；若未达到真实评价上限，重新选择每目标代理并重复。
  8. 终止后输出 `Arc` 中全部非支配解。
- 关键组成部分：
  - objective-wise adaptive model selection；
  - `R^2` distribution-similarity/accuracy indicator；
  - GP/RBF surrogate pool；
  - RVEA as model-assisted optimizer；
  - dual-space infill sampling indicator；
  - archive-driven closed-loop surrogate retraining。
- 可能被修改的位置：
  - 模型池可扩展为 RF、Kriging、SVR、NN、dropout NN、多保真代理或局部代理；
  - `R^2` 可替换为 cross-validation error、rank correlation、calibration error、uncertainty quality、Pareto-rank preservation 等；
  - DSI 可加入 convergence term、代理不确定性、HV contribution 或约束违反风险；
  - RVEA 可替换为 NSGA-II、MOEA/D、RVEA variants 或 problem-specific generator。
- 必须保留的核心：
  - 每个目标函数单独评估代理模型匹配度，而不是全目标共享同一种代理；
  - 代理选择使用已真实评价样本的 holdout/cross-validation 反馈；
  - infill 时同时考虑 decision space 和 objective space 的空间信息；
  - 每次真实评价后更新档案并重新闭环。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：DTLZ 与 WFG，目标数为 3、6、8、10、12、15、20；真实评价预算、决策维度和目标数按 Table I 设置。
  - 对比算法：AB-SAEA、EDN-ARMOEA、KTA2、PA-EMaOEA、EMMOEA、CSEA。
  - 基础设置：初始数据库大小为 `11*D - 1`，reference vectors 数量随目标数为 45、42、44、20、24、30、40；model-assisted optimization 最大迭代 `tmax=50`；PlatEMO 2.8，20 次独立运行。
  - 指标：DTLZ/WFG 用 IGD+，Wilcoxon rank-sum test；真实应用用 HV。
- 主要实验结论：
  - 自适应选模消融：在 WFG8/WFG9 的 3-20 目标设置上，EMaOEA-SASM 比只用 RBF 的 EMaOEA_RBF 在 12 个函数上更好；与只用 GP 的 EMaOEA_GP 性能相近但运行时间显著更少。作者据此认为按目标自适应选模优于预设单一模型。
  - DTLZ：相比 AB-SAEA、EDN-ARMOEA、KTA2、PA-EMaOEA、EMMOEA、CSEA，EMaOEA-SASM 分别在 36、44、34、31、29、31 个 of 49 instances 上更好。
  - DTLZ 细节：作者认为 DTLZ2 显示可扩展性，DTLZ4 中 5/7 case 分布更好，DTLZ5/6/7 体现对退化和断裂问题的优势；但 DTLZ1/3 上表现不足。
  - WFG：EMaOEA-SASM 分别在 51、59、43、60、34、54 个 of 63 instances 上优于六个对比算法，劣于它们的 instances 分别为 5、0、7、0、14、6。
  - 综合 DTLZ+WFG：112 个问题上，EMaOEA-SASM 相比六个对比算法分别更好于 87、103、77、91、63、95 个，劣于 11、0、10、16、21、13 个。
  - 可视化：3-objective DTLZ2/5/7 和 20-objective DTLZ2/5/7 的图示显示 EMaOEA-SASM 获得的非支配解覆盖更多 PF 区域，尤其在 DTLZ7 上比 EMMOEA 覆盖更广。
- 真实应用：
  - Reactive power optimization (RPO)：14-bus RPO，11 个决策变量、3 个目标；EMaOEA-SASM 获得最高 median HV。
  - Hybrid electric vehicle controller design (HEV)：11 个决策变量、7 个目标；EMaOEA-SASM 的 median HV 不是最好，但 boxplot 显示范围和 IQR 更小，作者认为鲁棒性更好。
- 证据边界和负例：
  - DTLZ1/DTLZ3 表现不足，作者归因于代理模型引导 RVEA 找潜在好解不够准确，以及本文 DSI 更重 exploration 而非 exploitation。
  - WFG3 上不如 EMMOEA、AB-SAEA 和 KTA2，作者解释 WFG3 是 convergence-driven test function，而 DSI 更强调 diversity/exploration。
  - 公式和表格在 Markdown 中多为图片占位，逐项数值需回查 PDF/Supplementary。

## 局限与未来工作

- 作者明确说明的局限：
  - 方法默认真实目标函数可以被 surrogate models 较好近似，model-assisted RVEA 找到的解与真实优化问题的优解一致；这一假设不总成立。
  - 当前 infill criterion 只考虑 decision/objective spaces 中的 crowdedness，无法确保模型辅助得到的候选不偏离真实 Pareto front。
  - DTLZ1、DTLZ3、WFG3 等收敛驱动或代理较难拟合问题上表现不足。
- 作者未来工作：
  - 在 infill criterion 中加入 convergence performance，以进一步提升方法性能。
- 我们认为仍需确认的问题：
  - `R^2` 选择的是目标值拟合度，不一定等价于 Pareto ranking、HV contribution 或 candidate selection accuracy。
  - 每轮为每个目标训练 GP 和 RBF 再重训最终模型，目标数和档案规模增加时开销会快速上升。
  - DSI 主要偏 exploration，在高噪声或强收敛压力问题中可能采太多空间稀疏但质量不足的点。
  - 70/30 随机划分在早期样本很少时方差较大，可能导致模型类型频繁切换。
  - 对约束、离散/混合变量、异构评价时间和多保真数据尚未验证。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：目标级自适应代理与双空间 infill 采样。该知识可直接移植到昂贵 MOO/MaOO 的 surrogate management 层，且与现有代理内环、关系代理、特殊点采样不重复。
- 暂留在论文卡中的方法、原理或架构启发：
  - 用 `R^2` 测 distribution similarity 是简单有效的模型选择启发，但对排序型选择是否足够仍需额外验证。
  - RPO/HEV 应用证明了工程场景可用性，但没有给出工程约束细节，不单独升级场景知识。
- 局部创新线索：
  - 将 `R^2` 替换或组合为 rank correlation、Kendall tau、Pareto rank preservation、uncertainty calibration，专门优化“选点正确性”。
  - 把 DSI 与 LCB/EI/EHVI 混合，避免只探索稀疏区域而忽略收敛。
  - 对每个目标维护模型选择概率或 bandit，而不是每轮硬切换 GP/RBF。
  - 在 DSI 中加入约束违反代理或仿真失败风险，用于 expensive constrained MaOP。
- 结构创新线索：
  - 构建“目标级模型池 + 选点准则池 + 真实评价预算调度器”的 SAEA 架构：模型池解决每目标异质性，准则池平衡收敛/探索，预算器根据历史真实贡献选择下一点。
  - 与代理贡献退出机制结合：如果某类模型被选择但真实评价贡献持续下降，则降权或冻结该模型类型。
