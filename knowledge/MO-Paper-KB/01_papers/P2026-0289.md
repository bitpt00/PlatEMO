# A Multiobjective Evolutionary Algorithm Based on Bipopulation With Uniform Sampling for Neural Architecture Search

## 一句话理解

本文提出 MOEA-BUS：针对多目标 NAS 中随机初始化在 MAdds 复杂度轴上天然偏向中等架构的问题，先大量随机采样并按 MAdds 均匀分桶选取初始架构，再把小/大复杂度极端架构和中等复杂度架构分给两个角色不同的种群协同进化，并用 SVM 成对排序代理与 Once-for-All 权重继承减少真实评价成本，从而获得覆盖不同精度-复杂度折中的移动端网络架构。

## 问题与动机

- 研究问题和场景：
  - Multiobjective NAS 需要同时优化 classification accuracy 和 network complexity；
  - 本文以 MAdds 作为复杂度指标，搜索 MobileNetV3-style search space；
  - 真实架构训练和验证昂贵，即使用 one-shot/weight inheritance 也不可能大量真实评价。
- 现有方法为什么不足：
  - 许多 NAS 方法只优化 accuracy，忽略移动端部署中的 MAdds、参数量或推理成本；
  - GD/RL-based NAS 在多目标场景中处理不可微复杂度目标或 reward 设计较困难；
  - 普通 MO-ENAS 常直接套 NSGA-II，较少针对 NAS 搜索空间特性改造；
  - 作者随机采样 5000 个架构后发现，多数集中在 300-400 M MAdds，高/低复杂度架构稀少；
  - 随机初始化会导致初始种群和代理训练数据覆盖不足，后续搜索也难探索极端复杂度区域；
  - 普通多种群互相迁移 elite 可能让基因池同质化，尤其会让中等复杂度架构挤占极端区域。
- 本文希望解决什么：
  - 初始时覆盖不同 MAdds 区间，避免复杂度轴上的样本偏置；
  - 用两个种群分别负责极端复杂度和中等复杂度区域；
  - 通过不对称 elite exchange 保留极端种群的探索角色；
  - 用 pairwise surrogate 快速筛选大量架构，真实评价只给少量 elite。

## 核心理念与算法流程

- Search space and encoding：
  - 以 MobileNetV3 为基础，初始和最终阶段固定；
  - 中间主体由多个 convolutional blocks 堆叠；
  - 搜索 image resolution、每个 block 的层数、每层 inverted bottleneck 的 expansion ratio 和 depthwise convolution kernel size；
  - 固定长度编码中，缺失层用 padding zero 表示。
- Uniform sampling：
  - 先从搜索空间大量随机采样架构并计算 MAdds；
  - 按 MAdds 从小到大排序，并按复杂度范围划分若干区域；
  - 每个区域选择一定数量架构，使初始候选在复杂度轴上更均匀；
  - 低 MAdds 和高 MAdds 的 extreme regions 合并成 population 1；
  - 中等 MAdds 区域合并成 population 2；
  - 初始架构真实评价后进入 archive `A`。
- Bipopulation evolution：
  - 两个种群并行执行 surrogate-assisted subsearch；
  - 每轮先用 archive `A` 训练 surrogate predictor；
  - 每个种群内部用 surrogate 预测 accuracy/error strength，用 MAdds 作为第二目标，执行 `G` 代交叉、变异、非支配排序和 crowding distance 选择；
  - subsearch 结束后用 diversity selection 选择与整体 archive 差异最大的 elite architecture；
  - elite populations 做真实评价并更新 archive；
  - population 1 的 elite 同时加入 population 1 和 population 2；
  - population 2 的 elite 只加入 population 2，不反向进入 population 1，以防中等复杂度架构占据极端探索种群。
- Surrogate and weight inheritance：
  - Surrogate 使用 SVM pairwise comparison relation；
  - 对 archive 中架构两两拼接编码，标签 0/1 表示前者或后者更好；
  - 预测时对候选架构两两比较并累积分数，强度越高表示分类错误率越高；
  - 真实评价时从 Once-for-All supernet 继承权重，再对候选架构训练更新；supernet 权重冻结。
- 必须保留的核心：
  - “MAdds 均匀初始化 -> 极端/中等复杂度双种群分工 -> 不对称 elite exchange -> pairwise surrogate + weight inheritance”是 MOEA-BUS 的完整可复用结构。

## 实验证据

- 实验设置：
  - 数据集：CIFAR-10、CIFAR-100、ImageNet；
  - CIFAR-100 详细结果在 supplementary material；
  - 评价指标：accuracy、MAdds、参数量、search cost；
  - 环境：PyTorch 2.0、CUDA 11.7、单张 RTX 3090 24GB；
  - 代码链接：`https://github.com/pcjiang1998/MOEA-BUS`。
- 标准数据集结果：
  - CIFAR-10 上，MOEA-BUS 的最高平均分类 accuracy 为 `98.39% ± 0.03`；
  - MOEA-BUS-S 在 ENAS 方法中 MAdds 最低，为 281 M，accuracy 为 98.12%；
  - ImageNet 上，最佳架构 top-1 accuracy 为 80.03%、top-5 accuracy 为 94.42%、MAdds 为 610 M；
  - 另一个架构在 ImageNet 上以 446 M MAdds 达到 78.28% accuracy；
  - MOEA-BUS-L 以 0.3 GPU days search cost 达到 78.71% top-1，作者强调优于 MixPath 等高成本方法。
- 两个关键机制消融：
  - NSGA-II random initialization 的最终架构集中在 200-400 M MAdds；
  - 加 multipopulation 后能发现更多大于 400 M 的架构；
  - 单独加 uniform sampling 后低于 200 M 或高于 400 M 的架构明显增多；
  - 完整 MOEA-BUS 在目标空间中分布更均匀，HV 持续提高，Pareto front 更接近 dominant region。
- Surrogate 消融：
  - 从 ImageNet 过往实验中收集约 7000 个架构历史信息；
  - 采样 1300 个架构，其中 300 个训练 surrogate，1000 个测试；
  - 比较 RF、SVM、MLP、AdaBoost，比较 regression prediction 与 pairwise prediction，比较 random/uniform sampling；
  - SVM + Pairwise + Uniform 的 Kendall tau 为 0.7721；
  - 该设置相比 SVM random/regression 的 0.7052 提升 0.0669；
  - Pairwise+Uniform 下，SVM 至少比 AdaBoost/RF/MLP 高 0.035 Ktau。
- Uniform sampling 消融：
  - Random sampling 初始架构集中在 200-400 M，且大于 450 M 的区域没有架构；
  - stratified sampling 在 MAdds 上可较均匀，但目标空间分布不好；
  - Latin hypercube sampling 受整数编码和编码上下界接近影响，目标空间分布较差；
  - uniform sampling 在 entropy 和 HV 上更优。
- Bipopulation 消融：
  - 若两个种群互相交换 elite，低于 250 M 和高于 450 M 的架构更少，Pareto front 更差；
  - 完整 MOEA-BUS final population 的 architecture entropy 为 6.32、HV 为 0.62；
  - 双向 exchange 的 entropy 为 6.07、HV 为 0.60；
  - 不同 Pop1/Pop2 比例中，作者选择 `(25,75)`，认为在性能和计算成本之间最平衡；`(45,135)` 稍好但成本更高。
- 证据边界：
  - 主要表格为图片占位，部分对比数值需回查 PDF；
  - 只在 MobileNetV3 search space 上验证；
  - CIFAR-100 结果不在主文中；
  - supernet 训练成本在 search cost 对比中排除。

## 局限与未来工作

- 作者明确说明的局限与未来方向：
  - 当前只评估 MobileNetV3 backbone / search space；
  - 未来扩展到 ResNet、EfficientNet、Vision Transformers；
  - 未来适配 semantic segmentation、object detection 等领域；
  - 需要为新任务设计对应 search operators 和 surrogate models；
  - 通过跨任务 benchmark 验证泛化性和鲁棒性。
- 我们认为仍需确认的问题：
  - 均匀采样按 MAdds 分桶，若真实硬件 latency 与 MAdds 不一致，覆盖效果可能下降；
  - Pop1/Pop2 的不对称迁移规则是否适合三目标或多硬件预算场景；
  - pairwise SVM 对 encoding 方式和训练样本数量敏感，跨搜索空间需重校准；
  - 从 OFA 继承权重的排序是否会偏向特定模块；
  - 只按 objective-space 分布和 architecture entropy 衡量多样性，未直接验证部署鲁棒性或 ensemble 互补性。

- 局部创新线索：
  - 将 MAdds 均匀采样替换为 latency、energy、memory 或多硬件真实测量分桶；
  - 动态调整 Pop1/Pop2 比例，让极端复杂度区域在早期多、后期少；
  - 对 Pop1 使用更激进变异，对 Pop2 使用局部 exploit 和 surrogate 精修；
  - 将 pairwise surrogate 换成 graph encoder、contrastive architecture comparator 或 uncertainty-aware ranking model；
  - 给不对称 exchange 加 novelty gate，只有结构足够不同或能补预算空洞的 elite 才迁移。
- 结构创新线索：
  - 构建“预算分桶初始化 + 角色化多种群 + 代理排序 + 少量真实评价”的硬件感知 NAS 通用框架；
  - 与复杂度分组环境选择组合：初始化、进化和 archive 三层都按预算保持覆盖；
  - 与架构距离生态位组合：每个复杂度区间内再按结构距离保留多模态模型；
  - 与多设备 NAS 组合：每个硬件设备或 latency bin 对应一个子种群，低/高资源种群向通用种群迁移模块。
