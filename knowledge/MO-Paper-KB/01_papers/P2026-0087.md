# Multi-objective scheduling for a reentrant hybrid flow shop integrating preventive maintenance, machine aging effects, and low-carbon optimization

## 一句话理解

本文面向 semiconductor wafer / OLED ARRAY 等 reentrant hybrid flow shop (RHFS)，把机器服务寿命、预防性维护和低碳调度耦合起来：机器越老，单位加工能耗/碳排越高，维护时间也会随服务寿命非线性变化；因此在排程解码时要动态判断机器可靠性阈值，并优先把 PM 插入已有 idle gaps，必要时再右移当前任务。模型同时最小化 makespan 和 total carbon emissions，求解器是加入 sparrow initialization 与 diversity-enhanced crossover-mutation 的 CHIO-DECM。

## 问题与动机

- 研究问题和场景：
  - reentrant hybrid flow shop scheduling (RHFS)；
  - 工件需要多轮回到相同阶段重复加工；
  - 各阶段有多台功能同质并行机器；
  - 半导体 wafer fabrication、OLED display ARRAY workshop、光学镀膜等设备昂贵且连续高负载的制造场景。
- 现有方法为什么不足：
  - 许多 RHFS 研究关注 makespan 或转运成本，低碳目标不足；
  - 绿色调度常把加工能耗视为固定，忽略机器老化导致的能耗增长；
  - 维护模型常把 PM 时间设为常数，不能反映老化后维护更困难；
  - 只按固定 PM 计划或达到阈值后直接维护，可能打断生产并扩大 makespan；
  - 忽略老化会使可靠性预测、PM timing 和 carbon estimation 都失真。
- 本文希望解决什么：
  - 建立服务寿命、碳排和 PM 时间之间的非线性映射；
  - 在排程中同步考虑生产、维护和低碳目标；
  - 用动态预维护策略利用机器 idle intervals，减少 PM 对完工期的冲击；
  - 在复杂离散 RHFS 上输出 makespan-carbon Pareto front。

## 核心理念与算法流程

- PM-AD-RHFS 模型：
  - 机器失效率用 Weibull distribution 表示；
  - 可靠性函数 `R(t)` 随服务寿命下降；
  - 给定可靠性阈值 `R0`，可求出对应服务寿命阈值 `t0`；
  - 机器维护后不能完全恢复，使用 age reduction factor 更新实际服务寿命；
  - 维护时间是服务寿命的非线性函数，机器越老维护越困难；
  - 机器能耗也是服务寿命的函数，累计加工时间越长，碳排越高；
  - 两个目标为最小化 makespan 和 total carbon emissions。
- 模型约束：
  - 每个操作只能分配给一台可用机器；
  - 加工不可中断；
  - PM 期间机器不能加工；
  - 同一工件操作必须遵守顺序约束和 reentry 轮次约束；
  - 任一机器可靠性不能低于给定阈值；
  - 机器上加工任务与 PM 不能重叠。
- 动态 PM 插入策略：
  - 解码并安排普通 RHFS 加工任务；
  - 每个操作开工前，检查选定机器在执行该操作后的可靠性；
  - 若 `R(age + processing_time) > R0`，正常加工；
  - 否则先安排 PM，再动态调整后续任务；
  - PM 后更新机器失效率和实际服务寿命，并重新计算后续加工碳排。
- PM 插入优先级：
  - 若当前操作前与上一任务之间有足够 idle gap，则直接插入 PM；
  - 若机器已排任务之间存在足够 idle interval，则从已有间隔中寻找可插入位置；
  - 若没有合适 gap，则将当前操作右移，在上一任务后插入 PM；
  - 核心目标是在不破坏可行性的前提下，让维护尽量吃掉已有 idle time。
- 编码与解码：
  - 用连续实数序列表示初始 job priority；
  - 通过排序把连续编码转成离散工件顺序；
  - 后续阶段按 FIFO 规则排序；
  - 机器选择采用 SPT 原则；
  - 工件完成一轮后重新回到第一阶段，继续按上一轮完成顺序进入下一轮。
- CHIO-DECM：
  - CHIO 将个体分为 susceptible、infected、immune 三种状态，并用 age/death 机制替换停滞个体；
  - sparrow-based initialization 用 SSA discoverer 机制初始化 infected individuals，提高初始质量和方向多样性；
  - DECM 在每轮 CHIO 更新后执行 crossover 与 mutation；
  - crossover 随机选择多个位置，交换父代片段并通过 conflict elimination 保持排列唯一性；
  - mutation 随机选择若干位置，对局部片段做 Fisher-Yates shuffle；
  - 新解只有在支配原解时才替换，维持多目标贪婪改进。

## 实验证据

- Benchmark 设置：
  - 6 类作业规模：20、30、40、50、100、200；
  - 3 个 reentry cycles；
  - 2 个 processing stages，机器配置为 `[3,2]`；
  - processing time 从 `[5,15]` 均匀随机生成；
  - electricity carbon emission factor 为 0.5366；
  - service life fallback factor 为 0.9；
  - machine service life threshold 为 50；
  - 每个算法独立运行 10 次，population size 为 100，最大迭代 500。
- 对比算法与指标：
  - 对比 NSGA-II、SSA、MOPSO、DBO、CHIO 和 AOA；
  - 指标包括 GD、IGD、HV 和 additive Epsilon；
  - Table 9 中 CHIO-DECM 在 20×6、30×6、40×6、50×6、100×6、200×6 的四项指标上均为最优。
- 参数调优：
  - 用 Taguchi `L9(3^3)` 对 population size、crossover probability、mutation probability 做调参；
  - 测试实例为 100×6，指标为 HV，reference point 为 `(1500, 43000)`；
  - 根据 SNR 响应表，最优组合为 population size 150、crossover probability 0.75、mutation probability 0.25。
- 消融实验：
  - 变体包括 CHIO、只加初始化的 CHIO_initial、只加交叉变异的 CHIO_cm、完整 CHIO-DECM；
  - 在 20×6 和 100×6 上，CHIO-DECM 的 GD、IGD、HV、Epsilon 均最好；
  - Wilcoxon rank-sum test 加 Bonferroni 校正显示多数比较显著，Cliff's delta 多为中到大效应；
  - 20×6 上 initialization-only 的 IGD 相比 CHIO 未达到 0.05 显著性，其余大多支持改进有效。
- 收敛行为：
  - CHIO-DECM 在早期 HV 快速增长，约 100 iterations 接近稳定；
  - CHIO 约 200 iterations 后才明显增长，约 300 iterations 稳定；
  - 作者认为 sparrow initialization 提供早期多方向探索，DECM 防止后期停滞。
- 半导体/OLED 案例：
  - 使用来自半导体公司 OLED display ARRAY workshop 的匿名真实生产周期数据；
  - 任务包含多轮 reentrant operations 和多阶段并行机器；
  - 动态 PM 策略与传统直接 PM 策略相比，Pareto front 整体位于左下方；
  - 平均 makespan 从 355.37 降到 347.02，改善 2.35%；
  - 平均 carbon emissions 从 22,653.56 降到 22,633.42，改善 0.89%；
  - 作者说明当前机器初始未使用且阈值较低，改进幅度适中，复杂真实条件下可能更明显。
- Service life threshold 敏感性：
  - 测试阈值 90、100、110、120、130、140、150；
  - 阈值变化影响 makespan-carbon Pareto trade-off；
  - 90-110 更偏 energy/emissions priority；
  - 110-130 更偏 balanced objectives；
  - 130-150 更偏 throughput/deadline priority。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前模型抽象掉加工过程中的随机机器故障；
  - processing time 固定，未考虑 condition-driven 或 operator-driven time variation；
  - 目前只优化 makespan 和 carbon emissions；
  - CHIO-DECM 依赖经验超参数；
  - 实验规模和工业验证范围有限，需要更多行业和更大数据验证。
- 作者未来工作：
  - 显式引入 PM 间隔中的 random failures；
  - 允许 processing times 在区间内变化；
  - 加入 machine utilization、maintenance cost、energy efficiency 等目标；
  - 使用 learning-based controller 在线调节算法参数或 operator policy；
  - 在 automotive、aerospace 等不同生产环境中验证可扩展性。
- 我们认为仍需确认的问题：
  - Markdown 中关键公式多为图片，维护时间函数和能耗函数需要用 PDF/code 复核；
  - PM 插入后“重新计算后续碳排”的增量更新细节需要实现确认；
  - SPT/FIFO 解码是否限制了机器分配和后续阶段排序的 Pareto 上限；
  - 动态 PM 与机器启停、速度调节、TOU 电价、worker maintenance resource 同时存在时的优先级；
  - 现实场景中 service life threshold 是否应按机器、产品、工况或电价动态调整。
