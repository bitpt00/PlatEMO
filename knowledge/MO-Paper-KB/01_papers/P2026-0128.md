# A hyper-curvature balanced indicator and adaptive phase exploration co-driven evolutionary algorithm for many-objective optimization

## 一句话理解

本文提出 MaOEA-HAP：在 many-objective optimization 中不用固定参考向量，而是用当前非支配前沿估计曲率，把候选解投影到曲率面来度量收敛，再用候选与已保留解之间的最小夹角度量多样性；环境选择早期用“曲率投影收敛 + 角度多样性”共同筛选，接近 PF 后切到纯角度多样性阶段，并配合自适应角度支配剪枝和 elite archive 增强选择压力。

## 问题与动机

- MaOP 困难：
  - 目标数增加后，大量个体互不支配，Pareto dominance 区分力下降；
  - 固定参考向量在 irregular、degenerate、disconnected 或高维 PF 上容易出现无效方向、空子区和分布偏差；
  - 单一 indicator 可能偏向某些前沿区域或目标，且 HV 等指标在高维下成本高；
  - 固定演化阶段无法根据 population 是否接近 PF 动态切换搜索重点。
- 作者观察：
  - indicator-based selection 能增强选择压力，但单一指标容易 bias；
  - reference-vector based algorithms 能维护分布，但依赖预设方向；
  - convergence 和 diversity 在不同阶段的优先级不同，应该由当前 population 状态触发切换。
- 本文目标：
  - 设计不依赖真实 PF 和固定参考点的几何指标；
  - 在环境选择中同时考虑曲率投影收敛和角度分布；
  - 用自适应阶段因子减少不必要的收敛/多样性双重计算；
  - 在多类 benchmark 和真实问题上验证通用性。

## MaOEA-HAP 框架

- 总体流程：
  - 初始化 population `P` 和 elite archive；
  - 用 `UpdateElite` 保存强收敛 elite；
  - 每代从 elite archive 和当前 population 中构造 mating pool；
  - 使用 SBX 和 polynomial mutation 生成 offspring；
  - 更新 elite archive；
  - 用 ADP + HCBM + adaptive phase exploration 执行环境选择；
  - 更新 phase factor `k`，直到达到最大评价次数。
- Elite archive：
  - 使用 `I_epsilon+` indicator 维护收敛性好的个体；
  - archive 超过 `N` 时，删除 fitness 最低个体并重新计算剩余个体 fitness；
  - mating selection 中，archive 通过随机 pairwise dominance 比较保留 dominance 或互不支配个体，当前 population 也随机采样部分个体。
- 关键组合：
  - ADP 先增强非支配层内筛选压力；
  - HCBM 在环境选择中平衡收敛和多样性；
  - phase factor `k` 控制“收敛+多样性”阶段和“多样性”阶段。

## Hyper-curvature Balanced Indicator

- 核心想法：
  - 不预设 reference vectors；
  - 从当前 non-dominated front 自适应估计曲率参数；
  - 将每个候选投影到曲率面；
  - 用候选到其投影点的距离度量收敛；
  - 用候选与已保留解之间的最小角度度量稀疏/多样性；
  - 组合二者形成 HCBM fitness。
- 曲率参数：
  - `lp` 由当前 non-dominated front 估计；
  - 作者测试候选值 0.5 到 2.0，选择使归一化距离方差最小的值；
  - 这避免依赖真实 PF。
- 收敛距离：
  - 计算归一化 objective vector 与曲率映射向量之间的 Lp 距离；
  - 空间因子设为 `p=1/m`，其中 `m` 是目标数；
  - 作者认为固定 L1/L2 在高维目标空间泛化不足，因此使用目标数相关的 fractional distance。
- 多样性距离：
  - 对每个候选，计算其与已保留解集合之间的最小夹角；
  - 最小夹角越大，说明该候选位于当前已选集合的稀疏方向；
  - HCBM fitness 同时奖励 `1 / convergence_distance` 和 angular diversity。
- 边界保留：
  - 环境选择先加入 `m` 个 boundary solutions；
  - 剩余容量从 critical set 中按阶段规则逐个补齐。

## Adaptive Angular Dominance Pruning

- 问题：
  - MaOP 中许多个体互不支配，直接保留所有非支配解会降低选择压力；
  - 目标空间中夹角很近的相似解会造成冗余。
- ADP dominance：
  - 若 `x` Pareto 支配 `y`，则 `x` 在 ADP 下支配 `y`；
  - 若 `x` 和 `y` 互不支配，则比较 ADP value；
  - ADP value 更好的个体被视作在角度支配意义上优先；
  - 该值反映候选在角度邻域中的均匀/稀疏程度。
- 作用：
  - 在非支配关系失效时提供二级筛选；
  - 剪掉 dominant resistance solutions 和冗余相似解；
  - 保留 Pareto hierarchy 的基本约束，同时增强分布控制。

## Adaptive Phase Exploration

- 动机：
  - convergence 和 diversity 同时优化会消耗更多计算资源；
  - 若 population 尚未接近 PF，需要兼顾收敛和一定多样性；
  - 若 population 已足够接近 PF，应更多维护 diversity 和 spread。
- Phase factor：
  - 先计算每个 solution 的 HCBM convergence distance；
  - 若所有 solution 到估计 PF 的距离都小于阈值 `D`，设置 `k=1`；
  - 否则 `k=0`。
- 环境选择规则：
  - `k=0`：计算 HCBM convergence distance 和 angular diversity，选择综合 fitness 最大的候选；
  - `k!=0`：只计算候选与已保留解的最小角度，选择最稀疏方向个体；
  - 这样早期推动接近 PF，后期强化前沿分布。
- 复杂度：
  - elite archive update 为 `O(MN^2)`；
  - 环境选择包含 ADP、角度和 HCBM 计算；
  - 最坏复杂度为 `max(O(N^2 log N), O(MN^2))`。

## 实验设置

- 对比算法：
  - RVEADWC、MaOEAIH、TSNSGAII、MaOEAIT、DEAGNG、LMPFE、TiGE2、MaOEAIGD；
  - 实验平台为 PlatEMO。
- Benchmark：
  - WFG1-9、DTLZ1-7、MaF1-15；
  - 目标数 `M=5,8,10,15`；
  - 共 31 个 benchmark problems 乘以多个目标维度，形成 124 个 test instances。
- 参数：
  - population size：5、8、10、15 目标分别为 210、156、276、136；
  - `M=5,8,10` 时最大评价次数为 `300N`；
  - `M=15` 时最大评价次数为 `400N`；
  - 每个算法每个问题独立运行 30 次；
  - SBX crossover probability 为 1，distribution index 为 20；
  - polynomial mutation probability 为 `1/D`，distribution index 为 20。
- 指标：
  - IGD+；
  - HV；
  - Wilcoxon rank-sum test，显著性水平 0.05。

## 主要结果

- WFG：
  - HV 上，MaOEA-HAP 在 36 个 WFG test problems 中 30 个最佳；
  - IGD+ 上，在 36 个 WFG test problems 中 21 个最佳；
  - WFG8-WFG9 表现尤其强；
  - 作者指出 HV 优势比 IGD+ 更明显，可能因为对比中许多 reference-vector 算法在规则 PF 上 coverage 较广。
- DTLZ：
  - HV 上，MaOEA-HAP 在 28 个 DTLZ test problems 中 15 个最佳；
  - IGD+ 上，也在 28 个中 15 个最佳；
  - 对 DTLZ4、DTLZ5、DTLZ6 较强；
  - 对 DTLZ1、DTLZ7，RVEADWC、TSNSGAII 或 DEAGNG 在部分维度更强。
- MaF：
  - HV 上，MaOEA-HAP 在 60 个 MaF test problems 中 19 个最佳；
  - IGD+ 上，在 60 个中 19 个最佳；
  - 对 disconnected MaF11 和 biased MaF12 表现较好；
  - 对 MaF2、MaF7、MaF8、MaF9、MaF13 等，部分对比算法在特定问题上占优。
- 综合 Wilcoxon：
  - Table 1 中 MaOEA-HAP 相对所有八个对比算法均取得正 net win；
  - 总体最小 net win 相对 TSNSGAII 为 +79；
  - 最大 net win 相对 MaOEAIT 为 +228；
  - 作者认为即使不使用参考向量，MaOEA-HAP 也能达到或超过 reference-vector based algorithms 的分布维护能力。
- 真实问题：
  - 包含 multilinear distance minimization、many-objective travel quotient、multipoint distance minimization、quadratic assignment 和 side collision；
  - true PF unknown，因此使用 HV；
  - MaOEA-HAP 在 21 个真实测试设置中 16 个表现最佳。
- 消融：
  - MaOEA-HAP1 用 fast non-dominated sorting 替代 ADP，用于验证 ADP；
  - MaOEA-HAP2 去掉 spatial factor `p`，用于验证 fractional distance；
  - MaOEA-HAP3/4 拆分 adaptive phase exploration 的两阶段；
  - 完整 MaOEA-HAP 相对四个变体分别在 43、88、51、79 个问题上表现更好，说明四个组件协同有效。

## 局限与未来工作

- 作者未来工作：
  - 设计更高效的 reinforcement learning-based algorithms；
  - 扩展到更多真实 many-objective optimization applications。
- Data availability：
  - Data will be made available on request。
- 我们认为仍需确认：
  - 曲率参数 `lp` 由当前非支配前沿估计，早期 front 偏差可能误导 HCBM；
  - 阈值 `D=1` 是否适配不同目标归一化和 PF 几何；
  - 完整算法优势来自 HCBM、ADP、elite archive 和 phase switching 的组合，单个组件收益需要更多隔离实验；
  - 高目标数和大种群下 `O(MN^2)` 选择成本对昂贵/实时应用仍需评估；
  - 在约束、离散、动态或 noisy MaOP 中，角度和曲率估计是否稳定。

## 可复用创新线索

- 用局部 front cluster 估计多个 `lp`，对不同 PF 区域使用不同曲率投影。
- 把 `k` 的二值阶段因子改为连续权重，让 HCBM 从收敛-多样性逐渐转向多样性。
- 将 ADP 的角度邻域与 objective-value multiplicity 或 epsilon-box occupancy 结合，适配离散 MaOP。
- 用 reference-vector occupancy 作为 fallback，在曲率估计不稳定或 disconnected PF 上保护空区。
- 将 HCBM 用作 archive truncation、mating selection 或 surrogate candidate selection，而不只用于 environmental selection。
- 用 RL 学习阶段切换阈值或 HCBM 中收敛/多样性权重，响应不同 benchmark geometry。
