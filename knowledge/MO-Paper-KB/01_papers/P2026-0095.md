# A hybrid measure-based state transition algorithm for robust multiobjective optimization

## 一句话理解

论文针对决策变量扰动下的 robust MOP，认为只看 mean performance 会漏掉尾部风险，只看 worst performance 又过于保守，于是把两者组合成 2m 维 hybrid robust objective，再用 modified Tchebycheff decomposition 和 state transition operators 搜索鲁棒 Pareto front，并提出 `rIGD_mean` / `rIGD_worst` 同时评价收敛、分布和鲁棒性。

## 问题与动机

- 研究场景：普通 MOP 忽略制造误差、环境扰动、参数波动等不确定性时，名义最优解在部署后可能失效；本文处理 decision-variable uncertainty 下的 robust multiobjective optimization problems (RMOPs)。
- 现有 robust measure 为什么不足：
  - Type I / mean performance measure 用扰动邻域内平均目标值评价鲁棒性，可能掩盖少数很差扰动样本；
  - worst performance measure 关注最坏样本，能保护尾部但容易过度保守；
  - 普通 IGD/HV 直接用于 RMOP 会忽略鲁棒性，已有鲁棒指标又常把收敛、分布和鲁棒分开评价。
- 本文希望解决什么：
  - 构造同时考虑 mean 和 worst 的 hybrid robustness measure；
  - 将 hybrid measure 引入 modified Tchebycheff aggregation，避免 2m 维鲁棒目标直接非支配排序造成维度膨胀；
  - 用 elite update strategy 减少基于扰动采样的候选比较成本；
  - 设计 `rIGD_mean` 与 `rIGD_worst` 指标综合评价 robust Pareto front。

## 核心理念与算法流程

- RMOP 定义：
  - 决策变量受扰动，写作 `X_delta`；
  - robust Pareto dominance 和 robust Pareto optimality 在不确定情形下定义；
  - Type I robust solution 由 mean effective objective 得到；
  - worst performance measure 用扰动邻域内最大目标值表示最坏表现。
- Hybrid robust objective：
  - 对每个 candidate，在 `Delta` 邻域内用 Latin hypercube sampling 生成 `H` 个扰动样本；
  - mean performance 为扰动样本目标值均值；
  - worst performance 为扰动样本目标值最大值；
  - 对 m 目标问题，同时保留 mean 和 worst 形成 2m 维 hybrid robust objective；
  - 这样既保留平均最优性，又避免忽略 worst-case tail。
- RMOSTA 总流程：
  1. 随机生成 parent population `P` 和 weight vectors；
  2. 为每个 weight vector 建立邻居集合 `B(i)`；
  3. 用 state transition operators 生成 offspring population；
  4. 对 parent/offspring 候选的扰动邻域采样，计算 mean 与 worst performance；
  5. 用 modified Tchebycheff function 将 hybrid robust objectives 标量化为子问题值；
  6. elite update strategy 从少量随机候选中挑选更好个体替换 parent；
  7. 输出 robust Pareto optimal set。
- State transition reproduction：
  - rotation transformation、expansion transformation、axesion transformation 生成不同搜索形态的 offspring；
  - `alpha`、`gamma`、`delta` 是三个变换的尺度因子；
  - 小于最小值时重置为最大值，并用 lessening coefficients 逐步降低采样半径；
  - 每轮产生 `3 * SE * T` 个 offspring，外加原 parent population 形成候选池。
- Modified Tchebycheff aggregation：
  - hybrid measure 使目标维度变为 `2m`，直接处理困难；
  - 本文采用 modified Tchebycheff aggregation `g_tmd = g_te * (1 + phi)`；
  - `phi` 表示 candidate solution 与 weight-vector subproblem 的匹配度，目的是避免聚合值好但搜索方向不匹配的候选进入错误子问题；
  - 附录 C 证明 traditional 与 modified Tchebycheff 的最优解等价；
  - 附录 D 讨论 hybrid robust measure under modified Tchebycheff 的一致性。
- Elite update strategy：
  - 每个子问题不与全体 `N` 候选比较，而是从 parent 和 offspring 中分别随机抽取 `T` 个候选；
  - 分别计算这些候选的 mean/worst performance 与 `g_tmd`；
  - 只用最好的 parent-candidate 和 offspring-candidate 参与替换；
  - 复杂度由传统 Pareto update 的 `O(MN^2)` 或 decomposition update 的 `O(M N_h N)` 降到 `O(M N_h T)`，其中 `T << N`。
- rIGD metrics：
  - `rIGD_mean` 和 `rIGD_worst` 基于 IGD 结构；
  - 一部分衡量 reference solution 到 approximation set 的欧氏距离，用于收敛与分布；
  - 另一部分接入 mean 或 worst-case performance，用于鲁棒性；
  - 目标是在平均场景和最坏场景下分别评价 robust Pareto front 的综合质量。

## 实验证据

- 实验设置：
  - Benchmark：TP1-TP8，前四个来自 Deb and Gupta，后四个来自 Gaspar-Cunha；
  - TP1/TP2 为 multimodal，TP8 的 globally optimal PF robustness 低于 local front；
  - 对比算法：NSGA-II-DTI、MOEA-RE、RMOEA/DVA、CNSDE/DVC；
  - PlatEMO 参数统一，population size `N=100`，sampling points `H=50`；
  - TP1-TP5 的 uncertainty level 为 `0.05`，TP6-TP8 为 `0.015`；
  - 终止条件为 `10^5` function evaluations，Wilcoxon rank-sum test 显著性水平 `0.05`。
- 主对比：
  - `rIGD_mean` 表中 RMOSTA 在多数问题上竞争力最强；可见数值中 TP1、TP3、TP6、TP7、TP8 最优，TP2/TP4/TP5 有其它算法更优。
  - `rIGD_worst` 表中 RMOSTA 在 TP1、TP2、TP3、TP6、TP7、TP8 最优，TP4/TP5 为 MOEA-RE 更优。
  - 对比符号统计：`rIGD_mean` 上，相对 NSGA-II-DTI 和 MOEA-RE 为 `6/2/0`，相对 RMOEA/DVA 和 CNSDE/DVC 为 `8/0/0`；`rIGD_worst` 上，相对 NSGA-II-DTI 为 `7/1/0`，相对 MOEA-RE 为 `6/2/0`，相对 RMOEA/DVA 和 CNSDE/DVC 为 `8/0/0`。
  - Friedman test 拒绝无差异假设，`chi^2=23.50`，`p<0.001`。
  - 平均排名：RMOSTA `1.50`，NSGA-II-DTI `2.25`，MOEA-RE `2.38`，CNSDE/DVC `4.38`，RMOEA/DVA `4.50`；Nemenyi test 显示 RMOSTA 显著优于 RMOEA/DVA 和 CNSDE/DVC。
- 计算开销：
  - RMOSTA 不是最快，但与最快算法时间差距较小；
  - 作者认为其在 robust solution accuracy 上的收益 justify 额外成本。
- 不确定程度敏感性：
  - 在 TP1 和 TP8 上考察 `delta=0.015/0.035/0.05`；
  - 不确定程度增大时 mean 和 worst fronts 的 convergence 都下降；
  - TP8 中解会从 globally Pareto-optimal front 转向 locally robust Pareto-optimal front，说明鲁棒性提升会牺牲名义收敛；
  - Fig. 11 中 TP1 的两个 rIGD 指标保持 `10^-4` 量级且方差很小；TP8 绝对值随 `delta` 上升，但 mean/worst gap 较稳定。
- 可扩展性：
  - 在 TP2 上设置 `Dim=5/10/30`；
  - NSGA-II-DTI 的 `rIGD` 随维度上升较快；
  - RMOSTA 增长更慢且阴影区更窄，作者认为高维一致性更好。
- Hybrid measure 消融：
  - RMOSTA-mean 只用 mean performance；
  - RMOSTA-worst 只用 worst performance；
  - Fig. 13 显示完整 RMOSTA 的 robust Pareto fronts 优于两个单视角变体，单视角变体会出现 abnormal solutions。
- IPM motor case：
  - 案例为 interior permanent magnet motor design，目标是 negated average torque 和 torque ripple；
  - 决策变量包括 magnet length、width、distance to rotor surface；
  - 制造/装配 tolerance 设为 `kappa=5%`；
  - 与 NSGA-II-DTI 在同样 `10^5` 预算和 `L=50` samples 下比较；
  - 两者 nominal PF 接近，但在 high-torque / high-ripple 区域，NSGA-II-DTI worst-case 退化和方差更大，RMOSTA worst-bound 更窄且分布更均匀。

## 局限与未来工作

- 作者未来工作：
  - 使用 parallel computing 降低鲁棒采样和更新成本；
  - 引入 surrogate models 进一步减少计算时间；
  - 结合最新算法提升效率和 scalability。
- 我们认为仍需确认的问题：
  - 结论段称 real-world clinical fluence map optimization case，但正文第 5 节是 IPM motor design，应以正文案例为准并回 PDF 确认是否为文稿错误。
  - 关键公式在 Markdown 中多为图片占位，modified Tchebycheff 的匹配项 `phi` 和 rIGD 细节需要回 PDF 才能复现。
  - 作者结论称 mean metric 上 six out of eight best，但 Markdown 表格可见最优单元似乎是 5/8；需回 PDF 核对表格和统计口径。
  - Hybrid measure 把目标数扩展到 `2m`，若原始目标数已高，分解标量化的权重设计和 rIGD 指标可能更困难。
  - `H=50` 扰动采样能否捕获低概率尾部风险不确定，尤其在高维扰动空间中。
  - Elite update 只随机比较 `T` 个 parent/offspring 候选，可能降低成本但也可能错过更优候选；缺少 `T` 的敏感性分析。
  - IPM 案例用 second-order response surface model，不是真正高保真电磁仿真闭环。

- 已建立的设计知识：

- 与已有设计知识的边界：
  - 不同于 [稳定度调权的鲁棒代理搜索与双指标候选筛选](../02_design_knowledge/K-stability-weighted-robust-surrogate-candidate-selection.md)，本文不依赖代理模型和真实评价候选筛选，而是在非代理 state transition / decomposition 框架中直接组合 mean 与 worst objectives；
  - 不同于 [代理辅助鲁棒距离的目标扩展选择](../02_design_knowledge/K-surrogate-assisted-robust-distance-objective.md)，本文不是用目标漂移距离作为额外目标，而是直接计算 mean 和 worst performance；
  - 不同于 [代理-仿真混合的不确定性评价加速](../02_design_knowledge/K-surrogate-simulation-hybrid-uncertainty-evaluation.md)，本文没有用代理/仿真概率混合评价，而是用 LHS 扰动采样估计鲁棒目标。
- 暂留在论文卡中的方法、原理或架构启发：
  - State transition 的 rotation / expansion / axesion 算子来自既有 STA 体系，本文主要价值在鲁棒度量与更新层；
  - `rIGD_mean/worst` 可作为鲁棒评价指标候选，但目前只跟 RMOSTA 一起验证，先记录不单独成卡。
- 局部创新线索：
  - 将 worst performance 换成 quantile 或 CVaR，减少单个极端采样点造成过保守；
  - 将 elite update 的随机 `T` 候选改成 uncertainty-aware 或 subproblem-distance aware candidates；
  - 对不同 reference direction 单独设置 mean/worst 权重，形成区域化鲁棒偏好；
  - 用 surrogate 或 multi-fidelity model 估计扰动邻域，使 `H` 可自适应扩大；
  - 将 rIGD 扩展为 robust HV/R2 或 reference-vector robust coverage 指标。
- 结构创新线索：
  - 构建“扰动采样 -> mean/worst 双视角目标 -> 分解标量化 -> 少候选鲁棒更新”的通用 RMOP 选择层；
  - 在 MOEA/D、RVEA 或 NSGA-III 中替换原始目标为 hybrid robust objectives，并用 reference-direction 匹配项降低 2m 维退化；
  - 把 mean/worst 作为两类任务做 evolutionary multitasking，再用 decomposition 层合并输出 robust PF。
