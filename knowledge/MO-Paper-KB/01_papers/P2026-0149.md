# Optimized Fuzzy Feedback Control for Autonomous Vehicle Trajectory Tracking via Adaptive Multi-Objective Differential Evolution

## 一句话理解

本文把自动驾驶轨迹跟踪中的 T-S fuzzy controller membership functions 当作多目标优化变量，用 adaptive MODE 同时最小化 H∞ 扰动输出与轨迹误差；算法按可行解数量和代数衰减概率在 DE 交叉变异、Pareto crowding 精修和可行性筛选三种机制间切换，再对优质个体做 variable-scale chaotic search。控制结构上，上层 non-PDC robust fuzzy H∞ controller 输出前轮转角和 yaw moment，下层 torque allocation 用 roll stability 与 energy-efficiency feedback compensation 分配四轮力矩。

## 问题与动机

- 研究问题和场景：autonomous vehicle trajectory tracking under time-varying speed、external disturbance、road adhesion changes and roll/yaw stability constraints。
- 现有方法为什么不足：
  - 传统线性车辆模型难表达非线性、强耦合和多变量动态；
  - T-S fuzzy control 可把非线性系统表示为局部线性子系统组合，但 PDC 要求 model MFs 与 controller MFs 严格一致，保守且对不确定性敏感；
  - non-PDC 能放宽 MF 一致性，但 MFs 选得不好时控制性能仍差；
  - 既有 DE/MODE 调 fuzzy controller 常有固定算子、阶段适应弱、局部聚集和可行性处理不足；
  - 下层 torque allocation 若只关注 yaw moment 或纵向力，难同时兼顾 roll stability 与 energy efficiency。
- 本文希望解决什么：在非 PDC robust fuzzy H∞ 框架下在线优化 controller MFs，并在 CarSim/Simulink 复杂工况中同时提升轨迹跟踪、扰动抑制、车辆稳定性和能耗表现。

## 核心理念与算法流程

- 控制框架：
  - 建立 3-DOF vehicle dynamics model，包含 lateral motion、roll dynamics 和 yaw motion。
  - T-S fuzzy vehicle model 选择纵向速度 `v_x` 为 premise variable，对 `{10,30,50,70,90} km/h` 建立 5 条 fuzzy rules。
  - Controller 使用 non-PDC state-feedback fuzzy control：系统模型 MFs 与 controller MFs 可以不一致，controller MFs 由轨迹误差相关变量构造。
  - Theorem 1-2 用 Lyapunov function、BMI 到 LMI 转换给出 asymptotic stability 和 H∞ disturbance attenuation 的充分条件，local gains 由 `K_i=Y_i X^{-1}` 得到。
- 多目标 MFs 优化：
  - 决策变量为 membership function vector `W=[omega_1(e(k)),...,omega_5(e(k))]^T`，对应 fuzzy weights/MF 参数。
  - 双目标：
    - `f1(W)=min ||z(k)||^2`，降低 H∞ disturbance output；
    - `f2(W)=min ||X_T(k)-X_0(k)||^2`，降低实际轨迹与参考轨迹误差。
- MODE 主流程：
  1. 初始化 population `omega_N^0`，每个个体包含 MFs 的 mean `mu_i` 与 standard deviation `sigma_i` 等参数。
  2. Algorithm 2 根据可行解数量 `N_f`、概率因子 `P1/P2` 生成 `omega_new`。
  3. 在 `omega_new` 上执行 variable-scale chaotic optimization。
  4. 得到 Pareto optimal MFs set `omega_opt`，并用于 upper-layer fuzzy feedback controller。
- 三种搜索机制：
  - Differential evolution crossover/mutation：标准差分变异 + binomial crossover，增强全局探索。
  - Pareto ranking and crowding distance：非支配排序后按 crowding distance 维护 Pareto front 分布。
  - Feasibility detection：以 `||e_y(W)||<=0.4`、`||e_a(W)||<=0.08` 作为可行性条件，不满足则剔除或调整。
- Adaptive search adjustment：
  - 若 `N_f<=1`，说明可行个体不足，优先使用 DE crossover/mutation 做探索。
  - 若可行性较好，则更多使用 Pareto/crowding 精修和 feasibility screening。
  - `P1=P1_initial*(1-t/T)`，`P2=P2_initial*(1-t/T)`，早期概率高、偏探索，后期逐渐降低并转向精修/筛选。
- Variable-scale chaotic search：
  - 对 top 60% 高适应度个体施加 chaotic perturbation，top 40% 保留不扰动。
  - 围绕当前 best `omega_i*` 更新局部搜索区间：`a_i(k+1)=omega_i* - lambda(b_i(k)-a_i(k))`，`b_i(k+1)=omega_i* + lambda(b_i(k)-a_i(k))`，其中 `lambda in (0,0.5)`。
  - 将 chaotic variable 映射到缩小后的局部区间，并让扰动幅度随迭代逐步减小，实现早期探索、后期细化。
- 下层 torque allocation：
  - 优化目标 `J = k_f F_x^T W_d F_x + (1-k_f)(B_xF_x-Delta M_z)^T(B_xF_x-Delta M_z)`。
  - `J1` 偏纵向轮胎力和 energy efficiency，`J2` 偏 yaw moment tracking 和 lateral stability。
  - Roll factor `R=|F_zl-F_zr|/(F_zl+F_zr)`，并用 `w_i = mg/(4F_zi) + (-1)^{j+1} sgn(F_zl-F_zr) k_R R` 补偿左右载荷差。
  - `k_f` 随 sideslip angle `beta` 与 roll angle `phi` 调整：风险高时降低 `k_f`，更重视 yaw moment tracking；风险低时提高 `k_f`，更重视 driving performance 与 energy efficiency。

## 实验证据

- 实验平台：Matlab/Simulink + CarSim，B-Class Hatchback model；local gains 由 MOSEK 求解 LMI 条件；比较 MODE in [29]、IAMODE、IAMODE with VSCOA。
- Double lane change：
  - road adhesion coefficient `mu=0.5`，lower-level controller 使用 roll compensation。
  - IAMODE+VSCOA 的实际 disturbance attenuation index 为 `gamma=1.3`，比 MODE [29] 低 27.57%。
  - HV 随代数上升并接近 1，优于 MODE [29] 与 IAMODE 的收敛速度和 coverage。
  - lateral error 保持在 `±0.3 m` 内；MODE [29] 和 IAMODE 在 2-3 s 左右更明显波动。
  - yaw rate、roll angle、roll rate 更平滑；MODE 中 roll angle 超过稳定性临界阈值，存在 rollover risk。
  - feedback compensation 在稳定状态下降低 torque allocation amplitude，在极端状态需要时增加 torque output，降低不必要能耗并抑制 yaw moment oscillation。
- Slalom / sine-wave steering：
  - IAMODE+VSCOA 的 disturbance response amplitude 小于 1.5，相对 MODE [29] 降低约 30.42%。
  - HV 最快收敛，约 65 generations 后稳定；对比方法收敛慢且可能陷入 local optima。
  - 高曲率下 MODE [29] 与 IAMODE lateral error 超过 `0.4 m`，IAMODE+VSCOA 将 lateral deviation 限制在约 `0.2 m`。
  - yaw dynamics 和 roll motion 的振荡、超调显著减少；下层反馈补偿可灵活调整 wheel torques，提升稳定性、安全性并降低 actuator burden。

## 局限与未来工作

- 作者明确说明的未来工作：
  - 开发 robust T-S fuzzy observer，实时估计 balance angle 和 roll angle，以获得更精确 feedback control。
  - 引入 nonlinear tire model，避免线性假设导致的 allocation error，并将 tire nonlinear losses 纳入经济性评价。
- 我们认为仍需确认的问题：
  - 实验主要为两种 CarSim 工况，缺少真实车辆道路实验和多随机扰动统计检验。
  - IAMODE、VSCOA、下层 feedback compensation 同时使用，组件消融主要通过 MODE/IAMODE/IAMODE+VSCOA 对比，尚未单独隔离每个搜索策略或 torque compensation 公式的贡献。
  - 可行性阈值 `||e_y||<=0.4`、`||e_a||<=0.08` 与 `P1/P2` 初值、chaotic shrinkage 参数的跨车辆泛化需要验证。
  - MFs 在线优化的计算时延、采样周期和硬实时部署成本未详细报告。
  - Data availability 说未使用数据，但文中使用仿真参数和 co-simulation 结果；引用时应按作者数据声明记录。
