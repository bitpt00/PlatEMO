# Class-Imbalanced Learning via Multi-Task Multi-Objective Feature Selection

## 一句话理解

论文提出 CIL-MTFS，把高维不均衡分类的特征选择拆成两个相关任务：`T1` 用带全特征集误差阈值约束的多目标特征选择兼顾整体分类性能和特征数，`T2` 用动态 cost-sensitive 目标强调少数类性能，再通过少数类错误触发的 cross-task genetic transfer 在两个任务间交换特征子集信息。

## 问题与动机

- 研究问题和场景：class-imbalanced high-dimensional tabular data。少数类样本通常是医疗、金融、生物信息等场景中的关键类别，但标准 accuracy-oriented classifier 容易偏向多数类；同时高维小样本会造成过拟合、特征空间稀疏和 minority representative samples 不足。
- 现有算法为什么不足：
  - Data-level undersampling 可能丢失多数类有用样本；oversampling 可能复制噪声或造成过拟合；hybrid sampling 仍会改变原始数据分布。
  - Algorithm-level 方法如 cost-sensitive learning、ensemble、one-class classification 和 kernel modification 可以缓解偏置，但作者认为它们未必能同时解决高维特征冗余和小样本稀疏问题。
  - Feature selection 能同时降维和保留原始样本语义，但 class-imbalanced feature selection 往往强调 minority class，可能牺牲其他类别或整体性能。
  - 已有 evolutionary multi-task feature selection 多把任务按 selected feature count、forward/backward search 或 diversity/convergence 需求划分，主要用于加速或多样性，而不是在 problem formulation level 表达 overall performance 与 minority performance 的冲突。
- 本文希望解决什么：在不人工平衡样本分布的前提下，通过 multi-task multi-objective feature selection 同时保留 overall classification performance、提升 minority class accuracy，并显著降低特征维度。

## 核心理念与算法流程

- 核心理念：同一个二进制特征子集 `x` 同时接受两套评价。`T1` 保证输出是“有实践意义”的特征子集，即训练 balanced error 不差于 full feature set，同时优化 error 和 feature ratio；`T2` 提供 minority-sensitive pressure，寻找对少数类或当前高错误类别有用的特征。跨任务迁移只在 `T1` 个体的 minority error 明显落后时触发，从 `T2` 注入 minority-informative feature subset。
- 主要流程：
  1. 计算使用全特征集 `x_full` 的 balanced classification error，作为 `T1` 的可行性阈值。
  2. 初始化一组二进制特征子集，初始化选中特征数上界为 `min(D,3N)`，并分别按 `T1` 和 `T2` 评价为 `P1` 与 `P2`。
  3. `T1` 的 mating selection 用 constrained non-dominated ranking；可行解优先于不可行解，可行解内部按 non-dominated rank。
  4. `T2` 的 mating selection 按 cost-sensitive error；若 error 相同，选中特征更少者优先。
  5. Cross-task genetic transfer 识别少数类 `k`，计算 `P1` 的平均 minority error `err_k`；当 `MP1` 中父代的 minority error 高于 `err_k` 时，用 `MP2` 中 minority 表现更好的父代替换其配对父代。
  6. 对调整后的父代执行 single-point crossover 和 bit-flip mutation，并删除重复特征子集。
  7. 新 offspring 同时按 `T1` 和 `T2` 评价；`P1` 用 constrained dominance + NSGA-II sorting/crowding 更新，`P2` 用 cost-sensitive error 更新。
  8. 终止后输出 `P1` 中 feasible non-dominated feature subsets。
- 关键组成部分：problem-formulation-level dual task、full-set-error feasibility constraint、balanced classification error、selected feature ratio、dynamic cost-sensitive objective、minority-error-triggered cross-task transfer、duplicate subset removal。
- 可能被修改的位置：多目标特征选择的任务构造、二进制子集 mating selection、class-imbalanced objective design、跨任务父代替换、环境选择中的 feasibility constraint。
- 必须保留的核心：`T1` 必须有“误差不差于全特征集”的约束来排除低特征但高误差的无意义非支配解；`T2` 必须提供 minority/cost-sensitive pressure；迁移触发必须依赖 class-specific performance discrepancy，而不是固定随机迁移概率。

## 实验证据

- 测试问题和对比算法：
  - 17 个真实不均衡分类数据集，来自 biomedical、finance、radar signal processing、handwritten digit recognition、face recognition 等领域。
  - 特征数从 Parkinson 的 22 到 GLI-85 的 22283；样本数从 Lung 的 32 到 Semeion 的 1593；imbalance ratio 从 1.00 到 9.08。
  - 文中说明对比五个 multi-objective feature selection 方法：NSGA-II、DAEA、MFFS、BSOEA、PRDH，以及两个 single-objective-based 方法 IMFWA、MEL；主文 KNN Tables III-V 报告 NSGA-II、DAEA、MFFS、BSOEA、PRDH、IMFWA 与 CIL-MTFS。
  - Base classifiers：KNN (`K=5`) 和 weighted SVM；训练评价用 five-fold cross-validation；每个数据集约 70% training、30% test；每种方法独立运行 30 次；最大 100 generations；population size `N=D` 且高维时 capped at 200。
  - Metrics：MCER、F1-score、G-mean；Wilcoxon rank-sum test 0.05；Friedman test 排名；HV 结果在补充材料。
- 主要实验结论：
  - 与 full feature set 比较：CIL-MTFS 在至少 12/17 数据集的 MCER、F1-score、G-mean 上优于全特征集，同时显著减少特征数。例子：Yeoh-2002-v1 从 5469 个特征平均选约 51 个，classification error 降低约 4.76%；CNS 从 7129 个选约 1053 个，classification accuracy 改善约 3.85%。
  - KNN F1-score：CIL-MTFS 在 17 个数据集上 7 个最佳；相对 NSGA-II、DAEA、MFFS、BSOEA、PRDH、IMFWA 分别在 8、5、4、7、5、7 个数据集显著更好；Friedman rank 为 2.5882，主文表中第一。
  - KNN G-mean：CIL-MTFS Friedman rank 为 2.8824，主文表中第一；相对各 baseline 的显著优势次数为 6、4、4、6、5、7。
  - KNN MCER：CIL-MTFS Friedman rank 为 2.5294，主文表中第一；相对各 baseline 的显著优势次数为 5、7、5、4、6、5。
  - 作者特别指出在 Yeoh-2002-v1、DLBCL、CNS、GLI-85 等高维小样本数据集上表现更明显。
- 消融或机制证据：
  - Fig. 2：CIL-MTFS 的 test non-dominated feature subsets 通常位于全特征集 error 线以下或附近；其他方法可能产生许多 error 明显高于全特征集的非支配解。作者用 Semeion 说明全特征 error 约 6.73%，其他方法部分解超过 50%，而 CIL-MTFS 约束掉这些无意义解。
  - HV 分析：CIL-MTFS 的 HV Friedman rank 在 KNN/weighted SVM 下分别为第三/第五。作者解释这是因为方法不追求完整 Pareto front，而是约束到“优于或不差于全特征集”的有用区域，因此 HV 可能低于覆盖全前沿的算法。
  - Fig. 3：部分数据集 HV 初期下降再上升；作者解释为早期高 HV 的 infeasible solutions 被逐步清除，随后在 feasible meaningful region 内收敛。
  - Ablation：CIL-MTFS 与 `T1` 单任务 CIL-T1FS、将 `T1` error 换成 cost-sensitive error 的 CIL-T2FS 比较。CIL-MTFS 在 MCER 上分别显著优于 6/17 和 4/17；F1-score 上显著优于 8/17 和 6/17；G-mean 上显著优于 8/17 和 6/17；仅在 Ionosphere 的 MCER 上显著差于 CIL-T2FS。
- 证据边界：
  - 主文多数详细数值为 KNN；weighted SVM 与 HV 部分在 supplement，论文卡只保存主文可核验结论。
  - 所有数据集是离线静态表格数据，未验证数据流、概念漂移或在线 class imbalance。
  - 评价成本主要来自训练分类器，复杂度分析省略该部分，因此真实运行成本取决于 classifier、cross-validation 和特征维度。
  - 部分表格在 Markdown 中错位，关键结论已用 PDF 文本核验。

## 局限与未来工作

- 作者明确说明的局限：
  - CIL-MTFS 约束会倾向保留更多特征，因为低特征但违反 full-set-error constraint 的解被丢弃。作者认为这是用更多特征换更可靠 classification performance。
  - 当前方法主要面向 two-class tasks；对多类别或多个 minority classes，作者建议将样本分组为 majority/minority 后适配，但尚未实验。
  - 作者在 full-set comparison 中承认少数数据集上 feature selection 后 error 上升，未来需要更强调 classification performance 而不只是 feature reduction。
  - HV 表现不一定最好，因为方法主动放弃部分传统 Pareto front 区域。
- 作者未来工作：
  - 扩展到 long-tailed classification tasks。
  - 进一步减少 selected features。
  - 与 sample cleaning 和 sample selection 结合，处理 label noise 与 class imbalance。
- 我们认为仍需确认的问题：
  - 多 minority classes 场景中 `k=argmin |S_i|` 的单一少数类识别是否足够，还是需要多类别 error vector 触发迁移。
  - `ferr(x_full)` 作为约束阈值在全特征集已过拟合或 full set 很差时是否会误导。
  - `w_dat` 与 `w_alg` 用最大权重比较后整组选用，可能在类别数较多时忽略多个中等困难类别。
  - 迁移触发只用 minority-class error，未直接考虑迁移后特征数膨胀或 majority class 退化。
  - K-fold 而非 stratified K-fold 的选择是否在极小少数类数据集上产生高方差，需要重复划分和置信区间验证。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：总体-少数类双任务特征选择迁移。该知识把一个高维不均衡特征选择问题拆成 overall constrained MOP 与 minority-sensitive auxiliary task，并用 class-specific error discrepancy 控制跨任务父代替换。
- 暂留在论文卡中的方法、原理或架构启发：
  - Full feature set error threshold 是一种“实用性可行域”定义，可迁移到模型压缩、传感器选择或特征成本优化中。
  - `w_dat` 与 `w_alg` 的 max-selection 表明 class weights 可同时由数据分布和当前算法弱项决定。
  - HV 下降不一定是坏信号：当算法主动清除无意义高 HV infeasible solutions 时，传统多目标指标需要结合应用可行性解释。
- 局部创新线索：
  - 将 `ferr(x_full)` 阈值改为带 margin 的阈值、统计置信阈值或用户可调 threshold。
  - 用 per-class vector 触发多源迁移，而不是只找单一 smallest class。
  - 在 `T2` 中加入 feature ratio 或 feature cost，减少少数类任务向 `T1` 迁移过大特征子集。
  - 结合 filter-performance predictor，在 cross-task transfer 后先预筛 offspring，再做 wrapper evaluation。
- 结构创新线索：
  - 构建三任务不均衡特征选择：overall constrained task、minority-sensitive task、sparsity/cost-sensitive task，通过不同触发信号互相迁移。
  - 将 sample cleaning 作为第三任务或预处理档案，让噪声样本识别与特征子集搜索协同演化。
  - 对 long-tailed multi-class classification 建立 class-cluster tasks，每个任务服务一组难类别，并通过 shared overall task 汇总。
