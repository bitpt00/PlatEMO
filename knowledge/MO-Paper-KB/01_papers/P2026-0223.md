# 多下层搜索模式的双层多目标进化算法

## 一句话理解

BLEMO-MLS 把双层多目标优化中的 lower-level search 做成三种模式：全量修复下层约束、只修 promising 解、暂时不修下层而推进上层目标。算法用 Q-learning 根据有效下层搜索率和双层可行非支配比例动态选择模式，从而在“满足下层最优性约束”和“节省评价推进上层搜索”之间自适应切换。

## 研究问题

- BLMOP 中，上层优化问题受到内嵌下层优化问题约束。
- 候选解要成为双层可行解，不仅要满足普通约束，还要求其下层决策尽量是给定上层决策下的 LLOP Pareto-optimal solution。
- 传统嵌套式 BLEA 严格维护 leader-follower 结构，通常有效但 lower-level FEs 非常重。
- 一直把下层最优性约束放在最高优先级，会消耗大量预算；但暂时忽略下层约束又可能让上层搜索被 infeasible-to-LLOP 的优秀表观解误导。
- 既有方法尝试固定或周期性调整这两种优先级，但缺少根据搜索状态自适应切换的机制。

## 核心概念

### BLMOP 三类问题

- 作者从 BPS 与 UPS 的关系把 BLMOP 划分为三类：
  - **Type I**：BPS 是 UPS 的子集。优先做上层目标搜索通常有利于接近 BPS。
  - **Type II**：BPS 与 UPS 部分重合。上层搜索和下层约束存在局部冲突。
  - **Type III**：BPS 与 UPS 不重合。若忽略下层约束，UPS 中解可能支配真正的 BPS 解，搜索会被严重误导。
- 实践中很难严格判断类型，作者提出 weakened condition：
  - 随机生成一批解，对每个解执行下层优化；
  - 统计下层优化后上层目标支配原解的比例 `RP`；
  - 若 `RP > 90%`，粗略视为 Type I。
- `R_NBF`：当前种群中 nondominated bilevel feasible solutions 的比例，用来判断搜索是否被下层约束违反误导。

### Effective LLS

- lower-level search 很贵，只有当它得到的双层可行解对已有双层可行解集有帮助时才算“有效”。
- 作者定义 effective LLS：
  - 下层优化后的解与已有非支配双层可行解互不支配；或
  - 下层优化后的解在上层目标上支配已有双层可行解。
- `R_ELS`：执行 lower-level search 的候选中，达到 effective LLS 的比例。
- promising candidate solutions：
  - 当前种群中尚未下层优化的解；
  - 在上层目标上不被已有非支配双层可行解支配；
  - 这类解更可能在下层优化后带来有效收敛或多样性增益。

## 方法框架

### 三种 LLS 模式

- `a1`：对所有 lower-level decisions 尚未优化的解执行 LLS。
  - 下层约束满足优先级最高；
  - FE 代价最大；
  - 适合 Type II/III 或搜索被下层违反严重误导时。
- `a2`：只对 promising candidate solutions 执行 LLS。
  - 兼顾下层约束满足和 FE 节省；
  - 通常能比 `a1` 获得更高 `R_ELS`；
  - 论文后续统计显示多数状态下 `a2` 最常被选择。
- `a3`：不执行 LLS，暂时只推进上层目标搜索。
  - 上层目标优化优先级最高；
  - FE 成本最低；
  - 适合 Type I 的上层探索，但需要后续 `a1` 或 `a2` 修正下层约束。

### Hybrid LLS

- `a1` 和 `a2` 调用 hybrid lower-level search。
- 对每个上层决策，把多目标 LLOP 通过 Tchebycheff 函数和方向向量分解为单目标问题。
- 方向向量由候选在下层目标空间的初始位置确定，使不同候选聚焦下层 PF 的不同局部区域。
- 先用 interior point method 执行局部 LLS，快速进入接近下层 PF 的局部区域。
- 再用 DE 式演化搜索继续探索局部下层非支配解。
- 每个上层解有一个下层局部种群 `P_xi`，历史下层优化记录保存在 `DATA` 中。
- 若同一上层决策曾被优化过，可从 `DATA` 载入历史记录并沿新方向继续探索。
- 对较久没有产生更优 offspring 的下层任务，算法降低继续优化概率，以节省 lower-level FEs。

### Q-learning 自适应调度

- 动作集合：`A = {a1, a2, a3}`。
- 状态集合：
  - `s1`：执行 `a1/a2` 后 `R_ELS` 未变差；
  - `s2`：执行 `a1/a2` 后 `R_ELS` 变差；
  - `s3`：执行 `a3` 后 `R_NBF` 未变差；
  - `s4`：执行 `a3` 后 `R_NBF` 变差。
- 奖励：
  - 转入 `s1` 或 `s3` 给正奖励，直接取新的 `R_ELS` 或 `R_NBF`；
  - 转入 `s2` 或 `s4` 给负奖励，按指标下降幅度惩罚。
- Q-table 用 Q-function 更新，discount rate 设为 0.8。
- learning rate 随已消耗 upper-level FEs 自动下降。
- `epsilon`-greedy 中的 `epsilon` 初期接近 0.5，后期逐渐下降，使算法早期探索三种模式、后期更多利用 Q-table。
- 对 `a3` 的潜在价值采用 hysteretic update：如果 `a3` 导致坏状态，后续 `a1/a2` 的恢复效果也会影响对 `a3` 的评价。

### BLEMO-MLS 总体流程

- 初始化 `DATA` 和种群。
- 通过 weakened condition 粗略检测 BLMOP 类型。
- 若判为 Type I，先执行一段只考虑上层目标的探索，得到接近 UPS 的初始种群，再执行下层优化。
- 每一代：
  - 从 `DATA` 提取候选双层可行解集；
  - 用 DE 生成 offspring；
  - 对合并种群执行当前 LLS mode；
  - 基于上层目标用 MOEA/D-M2M 更新种群；
  - 根据 `R_ELS` 或 `R_NBF` 状态变化更新 Q-table 并选择下一代模式；
  - 从 `DATA` 更新 elite population `EP`，作为最终候选 BPS。

## 实验设置

- benchmark：
  - TP1-TP2 和 DS1-DS5；
  - 每个测试问题只有一个 follower，且上下层各有两个优化目标；
  - DS4、DS5 属于 Type I；
  - TP1、TP2 属于 Type II；
  - DS1-DS3 中 `tau = 1` 时为 Type I，记为 DS1-1、DS2-1、DS3-1；
  - DS1-DS3 中 `tau = -1` 时为 Type III，记为 DS1-2、DS2-2、DS3-2。
- 对比算法：N-BLEMO、H-BLEMO、SMS-EMOA、SABLEA-PM、CGAN-BLEMO。
- 实验重复：15 次独立运行。
- 指标：
  - **LGD**：衡量下层决策接近真实 lower-level PS 的程度，越小越好；
  - **UHV**：上层目标空间 HV，越大越好；
  - **UIGD**：上层目标空间 IGD，越小越好。

## 主要结果

- LGD：
  - BLEMO-MLS 在多数测试问题上优于 N-BLEMO、SMS-EMOA、SABLEA-PM 和 CGAN-BLEMO；
  - H-BLEMO 的 LGD 更强，主要因为它用昂贵下层局部搜索严格保证部分解靠近 lower-level PF；
  - 但 H-BLEMO 在 UHV/UIGD 上离真实 BPF 较远，说明下层质量高不等于上层 Pareto 搜索好。
- UHV/UIGD：
  - BLEMO-MLS 几乎在所有类型测试问题上显著优于 N-BLEMO、H-BLEMO、SMS-EMOA 和 CGAN-BLEMO；
  - Type I 上，BLEMO-MLS 和 SABLEA-PM 因优先上层目标搜索而表现较好；
  - SABLEA-PM 在少数 Type I 问题上 UHV/UIGD 更好，但上层 FEs 超过 BLEMO-MLS 30 倍以上；
  - Type II/III 上，BLEMO-MLS 更有优势，因为它会提高下层约束满足优先级，避免 infeasible-to-LLOP 的表观好解误导上层。
- FEs：
  - BLEMO-MLS 的精确 FE 数因自适应模式和自适应 LLS 终止难以直接闭式计算；
  - 论文给出最坏情况估计；
  - 实验中 BLEMO-MLS 相比 SABLEA-PM 和 CGAN-BLEMO 显著节省 upper-level FEs；
  - lower-level FEs 也少于多数对比算法，原因是 `a1` 才全量执行 hybrid LLS，而 `a2/a3` 不会。
- 真实应用：
  - 在 WP-CoMEC 系统的双层定价模型上，与 BL-PIEA 比较；
  - IoTD 数量 `n = 5` 时性能相当；
  - `n = 10` 和 `n = 20` 时 BLEMO-MLS 更好。
- 模式选择分析：
  - `a2` 在多数状态和多数测试问题中最常被选择；
  - `a2` 比 `a1` 更容易让状态转入 `s1`，说明 promising-only LLS 更高效；
  - 当 promising solutions 太少时，`a1` 在某些状态下更有优势；
  - `a3` 虽可能导致坏状态 `s4`，但在 Type I 中有助于推近 UPS，并可通过后续 `a1/a2` 修正。
- 消融：
  - 只用 `a3` 无法直接求解 BLMOP，因为不能保证下层最优性；
  - 在 DS2-2 和 DS2-3 上，BLEMO-MLS 的 `R_ELS` 显著优于只用 `a1` 或只用 `a2` 的变体。

## 局限与阅读边界

- benchmark 多为一个 follower、上下层各两个目标，更多 follower、更高目标数或离散/混合变量 BLMOP 仍需验证。
- 类型检测依赖初始下层优化和 `RP > 90%` 的经验阈值，复杂问题上可能误判。
- Q-learning 状态只由 `R_ELS` 和 `R_NBF` 的升降决定，状态表达较粗。
- `a3` 的收益依赖后续 `a1/a2` 及时修正；若下层约束冲突极强，过多 `a3` 会误导搜索。
- hybrid LLS 使用 IPM 与 Tchebycheff 分解，要求下层问题能被这类局部方法有效处理。
- 正文表格多为图片占位，具体数值需查阅 PDF 表格或补充材料。

## 可复用知识与创新线索

- 可复用机制：
  - 把昂贵 constraint satisfaction 不再视为每代必须全量执行，而是设为多个优先级模式；
  - 用“有效搜索率”衡量昂贵局部搜索是否值得；
  - 用 Q-learning 学习何时严格修复、何时只修 promising、何时暂时探索上层；
  - 用历史下层优化数据库让同一上层决策可沿新方向继续优化。
- 局部创新线索：
  - 把状态扩展为 Type 置信度、约束违反分布、上层收敛速度、下层多样性等；
  - 用 bandit、contextual bandit 或 lightweight RL 替代 Q-table；
  - 将 `a2` 的 promising 规则从非支配关系改为不确定性、膝点、贡献度或风险指标；
  - 把 hybrid LLS 换成代理辅助 LLS、多保真 LLS 或可微下层求解器。
