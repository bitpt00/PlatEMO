# A Clustering-Based Dynamic Adaptive Search Strategy based on Competitive Swarm Optimizer for Constrained Multi-Objective Optimization

## 一句话理解

本文提出 DBCCSO，把 constrained multi-objective optimization 中的 CSO 搜索拆成主群和辅助群两条线：辅助群先无约束探索 UPF、后期用参考向量维护 CPF 多样性，主群则在进入后期后按目标空间 K-means 动态分簇，让 loser 只向同簇 winner 学习，从而避免远距离学习破坏 CPF 附近的局部开发。

## 问题与动机

- 研究对象：constrained multi-objective optimization problems (CMOPs)。
- 优化目标：在满足 inequality/equality constraints 的前提下逼近 constrained Pareto front (CPF)。
- 现有 CSO/CMOCSO 类方法的优点：
  - winner-loser 相对竞争更新简单，收敛快；
  - 与 feasibility-based 或 constraint-dominance 规则容易结合。
- 主要不足：
  - 早期需要整体快速穿越大不可行区；
  - 当一部分种群已接近 CPF 后，全局随机 winner-loser 学习可能让 loser 向过远 winner 学习，子代偏离 CPF；
  - 若过早分簇，又会削弱跨不可行区的全局收敛能力；
  - CPF 附近还需要保持目标空间分布，不能只追低 CV 或局部可行片段。

## 核心算法 DBCCSO

- 维护两个群体：
  - `MS`：main swarm，负责可行解保留、CPF exploitation 和最终输出；
  - `AS`：auxiliary swarm，按阶段承担无约束探索或多样性增强。
- 主循环：
  - 根据 `AS` 过去 `G` 代各目标累计值的标准差判断是否从 stage 1 切到 stage 2；
  - stage 1：`AS` 用 GA/DE 混合算子忽略约束，快速接近 UPF 并帮助 `MS` 穿越大不可行区；
  - stage 2：`AS` 用 reference-vector subregions 和 composite fitness 做 diversity enhancement；
  - `MS` 每代先用 feasible exploitation archive 更新；
  - stage 1 中 `nc=1`，stage 2 中根据 Eq. (20) 动态计算 cluster number；
  - 用 K-means 在 objective space 将 `MS` 分成 `nc` 个 sub-swarms；
  - 每个 sub-swarm 内部单独执行 CompetitiveUpdate，最后合并 `Off1` 与 `Off2`。

```text
MS, AS initialization
while not terminated:
    detect stage by AS objective-change stability
    if stage 1:
        AS <- exploration archive
        Off2 <- GA/DE from AS
        nc <- 1
    else:
        AS <- diversity-enhancement archive
        Off2 <- CompetitiveUpdate(AS, epsilon(t))
        nc <- dynamic_cluster_number(alpha, beta, delta_F, t)

    MS <- feasible exploitation archive
    clusters <- K-means(objectives(MS), nc)
    Off1 <- union CompetitiveUpdate(cluster_i, epsilon(t))
    Off <- Off1 union Off2
return MS
```

## 辅助群两阶段

- Stage 1：exploration archive。
  - 目标是促进全局探索，使 `MS` 能穿越 infeasible regions；
  - `AS` 忽略约束，保留 Pareto non-dominated solutions；
  - 若 `AS` 数量不足，则随机复制补齐；
  - 若数量超出 `N`，用 ideal/nadir 归一化后采用 SPEA2 environmental selection；
  - 该阶段的高质量 `AS` 解用于引导 `MS` 接近 CPF。
- Stage switch：
  - 对每个目标，计算过去 `G` 代序列的 standard deviation；
  - 若所有目标的波动都小于阈值 `sigma`，认为 `AS` 已接近 UPF 并切入 stage 2；
  - 默认参数为 `G=300`、`sigma=0.3`。
- Stage 2：diversity-enhancement archive。
  - 合并 `AS` 和 offspring，用 constrained Pareto dominance 删除 dominated solutions；
  - 若当前无 feasible solutions，则每个参考向量子区保留 minimum CV solution；
  - 若有 feasible solutions，则在每个子区用 `fitness(x)=d1(x)+d2(x)` 选择代表；
  - `d1` 表示 solution 到 reference vector 的 directional alignment / distance；
  - `d2` 是 normalized CV；
  - 不引入额外权重，由归一化后的方向项和约束违反项共同平衡 diversity 与 feasibility。

## 主群与 CDASS

- Main swarm selection：
  - 合并 `MS` 与 offspring；
  - 用 constrained Pareto dominance 初筛；
  - 按 CV 升序保留更可行的解；
  - 若 feasible solutions 超过 `N`，再用 SPEA2 environmental selection 选代表解。
- Clustering-based Dynamic Adaptive Search Strategy (CDASS)：
  - 在 objective space 用 K-means 将 `MS` 划分为多个 sub-swarms；
  - stage 1 固定 `nc=1`，强调整体 winner-loser 学习和全局收敛；
  - stage 2 中 `nc` 由 `alpha`、`beta`、`delta_F` 和迭代代数共同决定；
  - cluster number 总体随指数衰减项下降，使早期细分局部开发，后期逐渐合并簇填补 sub-swarm 间的分布空隙；
  - 当 `AS` objective change `delta_F` 出现显著变化时，临时降低 `nc`，增强全局信息共享，帮助仍未到达 CPF 的个体跨越不可行区。
- CompetitiveUpdate：
  - 按 epsilon-relaxed fitness 评价粒子；
  - 随机抽取两个粒子比较，较优者为 winner，较差者为 loser；
  - loser 根据 CSO 更新式向 winner 学习；
  - winner 和 loser 后续都经 polynomial mutation；
  - 在 CDASS 中，该过程只在同一 cluster 内执行，限制学习范围。

## 实验设置

- Benchmark：
  - LIR-CMOP1-14；
  - DAS-CMOP1-9；
  - MW1-14；
  - 共 37 个 benchmark CMOPs。
- 真实问题：
  - IEEE CEC 2021 real-world constrained MOP benchmark suite 中 16 个 RWMOPs。
- 对比算法：
  - APSEA、C3M、CMOES、CMOEMT、CMOCSO、DD-CMOEA、MSCEA、MSCMO、PPS。
- 指标与运行：
  - benchmark 使用 IGD+ 和 HV；
  - RWMOP 因 true CPF unknown，使用 HV；
  - 每个算法独立运行 30 次；
  - Friedman test with Bonferroni-Dunn correction，显著性水平 0.05；
  - Wilcoxon rank-sum test 做 pairwise comparison。
- 参数：
  - population size `N=100`；
  - `MaxFES=100000`；
  - `alpha=0.6`；
  - `beta=0.003`；
  - `G=300`；
  - `sigma=0.3`；
  - 实验在 PlatEMO 上进行。

## 主要结果

- LIR-CMOP：
  - IGD+ 上 DBCCSO 在 14 个实例中取得 12 个 best；
  - HV 上 DBCCSO 同样取得 12/14 best；
  - 相对 APSEA、C3M、CMOCSO、CMOEMT、CMOES、DD-CMOEA、MSCEA、MSCMO、PPS 的 IGD+ Wilcoxon 优势分别为 14、13、13、14、13、13、14、13、14 个问题。
- DAS-CMOP：
  - IGD+ 上 DBCCSO 取得 5/9 best；
  - HV 上 DBCCSO 取得 5/9 best；
  - 在 DAS-CMOP3 的可视化中，DBCCSO 同时覆盖完整 CPF 且分布更均匀。
- MW：
  - IGD+ 上 DBCCSO 取得 8/14 best；
  - HV 上 DBCCSO 取得 6/14 best；
  - 在 mild constraints 的 MW 中，directional alignment 对分布维护更关键，CV 压力相对较弱。
- 统计排名：
  - DBCCSO 的 IGD+ 平均 rank 为 `2.1622`，HV 平均 rank 为 `2.3784`；
  - 与所有 9 个对比算法相比，多数 p-values 显著小于 0.05。
- RWMOP：
  - 16 个真实 constrained MOP 上，DBCCSO 在 HV 上取得最多 best values；
  - 结果支持其在复杂、异质真实约束景观中的鲁棒性。

## 消融与参数分析

- Stage switching 参数：
  - 搜索 `G in {50,100,200,300,400,500}`、`sigma in {0.001,0.01,0.1,0.3,0.5,1.0}`；
  - `G=300`、`sigma=0.3` 平均 IGD+ rank 最优；
  - `G` 太小或 `sigma` 太大导致过早切换，`AS` 对穿越大不可行区的引导不足；
  - `G` 太大或 `sigma` 太小则切换过晚，削弱第二阶段精修机制。
- CDASS 参数：
  - 搜索 `alpha in {0.3,0.6,1}`、`beta in {0.003,0.03,0.3,1}`；
  - `alpha=0.6`、`beta=0.003` 平均 IGD+ rank 最优。
- 两阶段消融：
  - `DBCCSO-NO` 只使用第二阶段辅助群策略，相比 DBCCSO 的 IGD+ 为 `2/29/6`、HV 为 `1/29/7`；
  - `DBCCSO-NT` 只使用第一阶段机制，相比 DBCCSO 的 IGD+ 为 `7/21/9`、HV 为 `10/21/6`；
  - 说明第一阶段负责跨不可行区，第二阶段负责 CPF 多样性和局部精修。
- CDASS 消融：
  - `DBCCSO-WCDASS` 固定 `nc=1`，相比 DBCCSO 的 IGD+ 为 `1/11/25`、HV 为 `1/14/22`；
  - 固定簇数 `5/15/20` 的 variants 整体也弱于动态簇数；
  - Friedman test 中 DBCCSO 在所有 variants 中 IGD+ 与 HV rank 均最优，相关 p-values 均小于 0.05。

## 与知识库相关的设计知识

- 新增/关联设计知识：
  - `K-dynamic-clustered-competitive-swarm-cmop`：动态聚类限域的竞争群约束搜索。
- 与已有设计知识的区别：
  - 不同于 `K-trend-orthogonal-dualswarm-constrained-search`：该知识用主群 trend 与辅群 orthogonal complement 构造方向互补；本文不显式构造趋势/正交方向，而是通过动态 cluster number 限制 CSO winner-loser 学习范围。
  - 不同于 `K-game-competitive-dual-population-resource-allocation`：该知识关注主/辅群 offspring 或辅助规模资源分配；本文主创新不是资源博弈，而是阶段化辅助群和主群 CDASS。
  - 不同于 `K-adaptive-subregion-multidirectional-swarm-update`：该知识面向大规模 MOO 的参考子区、多方向 winner 更新；本文面向 CMOP，核心是 stage 1 全局穿越不可行区与 stage 2 CPF 局部分簇开发。
  - 不同于 `K-adaptive-constraint-violation-granularity`：该知识重写 CV 表达粒度；本文聚类作用在 reproduction learning scope，而不是 CV reassignment。

## 局限与未来工作

- DBCCSO 主要为 CMOP 设计，没有显式处理 large-scale decision variables 或 many-objective 退化。
- K-means 对初始化和复杂分布可能敏感，作者计划研究 hierarchical 或 density-based clustering。
- CDASS 在 objective space 聚类，若目标空间相近但决策空间可行结构差异很大，可能限制有效学习。
- 复杂度为 `O(MN^2)` 或 `O(N^2 log N)`，与许多 CMOEAs 相当，但真实高成本评价问题仍需结合 surrogate、variable grouping 或 scalable reference vectors。
