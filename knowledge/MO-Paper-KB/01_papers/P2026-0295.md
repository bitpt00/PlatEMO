# G-M3CS: A gradient-based multi-metric multi-objective client selection algorithm for hierarchical federated learning

## 一句话理解

论文把固定层级联邦学习中的客户端选择建模为多目标优化：在每个边缘服务器下用 NSGA-II 选择固定比例客户端，目标从梯度方向、幅值、多样性进一步改造成梯度价值、互补多样性和历史一致性，并用双层 FedMGDA 在边缘端和云端聚合多梯度，以同时提升全局精度和客户端公平性。

## 问题与动机

- 研究问题和场景：
  - 面向 cloud-edge-client hierarchical federated learning (HFL)，层级关系在医院、金融机构、UAV 网络等场景中往往由组织结构固定，不能随通信或成本动态重分配。
  - 需要在固定 edge-client 映射下选择哪些客户端参与当前轮训练，并缓解 edge-level data heterogeneity。
- 现有方法为什么不足：
  - HierFAVG 等加权平均在 Edge-NIID 下容易让全局模型偏向 dominant edge 或 dominant client。
  - 随机客户端选择忽略计算能力、样本量、噪声和梯度贡献差异，会拖慢收敛。
  - 只看梯度方向或只看梯度范数的选择策略容易过度偏向大数据量和大范数客户端，公平性下降。
  - 既有 MOO client selection 多聚焦带宽、算力等系统指标，而非训练过程中的多梯度互补信息。
- 本文希望解决什么：
  - 在固定 HFL 层级中动态选择高价值客户端；
  - 不把性能和公平性简单压成单个加权指标；
  - 让客户端选择和 FedMGDA 聚合共享梯度方向、幅值、互补性与历史稳定性信息。

## 核心方法

- 系统结构：
  - 客户端执行本地训练并上传多梯度；
  - 边缘服务器先在本地客户端集合中做客户端选择和 edge aggregation；
  - 云服务器再对多个 edge gradients 做 cloud aggregation。
- 双层 FedMGDA：
  - 在 edge-client 层，把每个被选客户端的梯度视为一个优化目标，通过最小范数凸组合求公共下降方向。
  - 在 cloud-edge 层，对各边缘服务器上传的聚合梯度重复同样的 MGDA 聚合。
  - 聚合权重围绕 FedAvg 的数据量基准权重 `lambda0`，并用 `epsilon` 限制偏离，避免公平性和平均性能失衡。
  - 实现中使用 normalized gradients，降低异常大范数或恶意梯度对方向求解的影响。
- NSGA-II 客户端选择：
  - 每个 edge 的客户端用二进制染色体编码，1 表示参与，0 表示不参与。
  - 参与比例为 `C`，因此每个染色体必须满足固定数量约束 `K = C * N_l`。
  - 作者设计了保持数量的随机交换变异算子，使每次变异后仍恰好选择 `K` 个客户端，避免不可行染色体。
  - Algorithm 2 在每个全局轮次开始时运行，最终选择 Pareto front 中第一个个体并解码成客户端子集。
- 原始 G-M3CS 三目标：
  - F1：最大化选中客户端梯度与上一轮全局/边缘方向的 cosine consistency。
  - F2：最大化选中客户端梯度的 L2 norm 总量，鼓励更强更新。
  - F3：最大化选中客户端之间的 pairwise cosine distance，避免梯度同质化。
  - 未参加当前轮、当前梯度为空的客户端，可用历史梯度字典中的梯度代替计算。
- G-M3CS+ 的 VCS 三目标：
  - V1 Gradient Value Index：把方向价值和幅值比例通过 sigmoid 组合，避免“方向对但幅值异常”或“幅值大但方向差”。
  - V2 Gradient Complementary Diversity：计算每个客户端梯度相对选中集合平均梯度的 cosine distance，强调围绕总体趋势的互补，而不是无意义发散。
  - V3 Gradient Historical Consistency：用当前梯度与指数滑动平均历史梯度的一致性衡量稳定性，降低异常、漂移或潜在恶意更新被选中的概率。
- 复杂度：
  - 原始 G-M3CS 的 pairwise diversity 使单个个体目标评价达到 `O(K^2 D)`。
  - G-M3CS+ 避免 pairwise interaction，单个个体目标评价降为 `O(KD)`，客户端数量增加时选择时间近似线性增长。

## 实验证据

- 实验设置：
  - 数据集：MNIST、CIFAR-10、FashionMNIST。
  - 数据分布：IID、Edge-NIID、Non-IID(1)、Non-IID(2)。
  - 主实验配置：50 clients、5 edge servers，每个 edge 10 个 clients；使用轻量 CNN，并在附录用 ResNet-18 做补充。
  - Baselines 包括 HierFAVG、HFedMGDA random selection、FedPNS、FedBN2、FedMDFG、FedMC、MOOS。
- 双层 FedMGDA 有效性：
  - 在 CIFAR-10 两种分布上，HFedMGDA 相比 FedMGDA 平均提升 5.02% 和 3.38%，二者均明显优于 HierFAVG。
  - 作者认为提升幅度受 edge 数较少限制，但已验证 HFL 中双层多梯度下降可收敛并有效。
- 全局性能：
  - 摘要报告平均全局模型精度提升 12.9%，公平性提升 26.6%。
  - CIFAR-10 Edge-NIID 下，G-M3CS+ 达到 46.1% accuracy，高于 HFedMGDA random selection 的 37.4%，提升 23.26%。
  - CIFAR-10 NonIID(1) 和 NonIID(2) 下，G-M3CS+ 分别为 65.6% 和 48.7%，均为表中最佳。
  - FashionMNIST 中部分场景 G-M3CS 而非 G-M3CS+ 最好，说明 VCS 改进并非所有数据集上都单调占优。
- 通信与运行：
  - CIFAR-10 Edge-NIID 下，G-M3CS+ 达到 35% accuracy 的通信轮次比例为 0.21，是图中最低。
  - G-M3CS+ 有较高 normalized runtime 0.98，但客户端选择时间随 `K` 近似线性增长，而 G-M3CS 呈二次增长。
- 公平性：
  - G-M3CS+ 相对 HFedMGDA 平均公平性提升 12.8%，相对 HierFAVG 提升 26.6%。
  - FashionMNIST Edge-NIID 中 JFI 为 0.965，高于 HierFAVG 0.911 和 HFedMGDA 0.923。
  - Edge-level variance 多数场景最低，例如 FashionMNIST NonIID(2) 为 10.64，低于其他方法。
  - t-SNE 可视化显示 G-M3CS 选择的客户端在梯度空间中更分散，减少“抛弃”少数客户端。
- 消融：
  - G-M3CS 中去掉 diversity 后 fairness variance 从 2.14 升到 2.87，说明多样性对公平性关键。
  - G-M3CS+ 完整 V1+V2+V3 为 46.1% accuracy、1.82 variance；去掉 V1 后降到 39.5% accuracy、2.57 variance，V1 最关键。
  - `pm=0.2, pc=0.5` 略优，但 Pop/Gen 和交叉变异概率整体不敏感。
  - Pairwise Cosine Distance 相比 L2 distance 有更高 accuracy 和更低 variance，相比 Gram determinant 成本更低，后者因 `O(K^3)` 运行时间近乎翻倍。
- 附录泛化：
  - ResNet-18 + CIFAR-10 EdgeNIID 下，G-M3CS+ 为 89.2% accuracy，比 HFedMGDA 高 9.7%，比 HierFAVG 高 16.9%。
  - ResNet-18 下 client accuracy variance 为 2.28 和 6.03，均为最低。

## 局限与未来工作

- 作者明确说明的局限和未来方向：
  - 当前框架假设静态层级关系；
  - 未纳入模型个性化；
  - 未主动处理攻击场景；
  - 未来扩展到 asynchronous/dynamic HFL；
  - 在 edge layer 引入 federated fine-tuning 和 personalized aggregation；
  - 在多目标框架中加入 robust anomaly penalization，以防御 Byzantine attacks。
- 我们认为仍需确认的问题：
  - NSGA-II 每轮每个 edge 运行，客户端和模型参数规模更大时仍有明显 wall-clock 开销。
  - Algorithm 2 选择 Pareto front 的第一个个体，仍需要更明确的单解决策规则或偏好接口。
  - 历史一致性可能惩罚真实分布漂移下的少数新趋势，需要区分 data drift 和攻击异常。
  - 论文主要在图像分类和仿真分区上验证，真实跨机构 HFL 的网络延迟、隐私约束和掉线机制还未覆盖。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建设计知识：梯度 VCS 三目标的 HFL 客户端选择。它可用于固定层级联邦学习、分布式训练或多节点协同优化中的参与者选择：用梯度价值衡量贡献，用互补多样性避免同质化，用历史一致性抑制异常更新，再用多目标搜索选择参与子集。
- 暂留在论文卡中的方法、原理或架构启发：
  - 客户端选择目标和聚合目标应共享梯度表示，而不是分别优化通信成本和模型权重。
  - “围绕平均趋势的互补多样性”比原始 pairwise dispersion 更适合需要共同下降方向的系统。
  - 固定数量二进制变异是很多资源受限选择问题可复用的小组件。
- 局部创新线索：
  - 用 hypervolume contribution、knee-point 或 preference score 替代“选择 Pareto front 第一个个体”的单解规则。
  - 将 V3 历史一致性拆成稳定性和新颖性两个目标，以免真实概念漂移被误判。
  - 把客户端掉线概率、能耗和隐私预算作为额外目标，形成训练价值和系统成本联合选择。
  - 用 bandit 或 surrogate 近似 NSGA-II 目标评价，减少每轮选择开销。
