# Secure and energy-efficient unmanned aerial vehicle-enabled visible light communication via a multi-objective optimization approach

## 一句话理解

论文把多 UAV 可见光通信部署建成一个三目标优化问题：联合优化 UAV 悬停位置和发射功率，同时让地面接收面的光功率更均匀、让窃听者接收到的信息率更低、让 UAV 运动能耗更小；求解器是在 MOEA/D 上加入 transmission power 的 circle-map 混沌初始化和按物理含义分块的交叉变异。

## 问题与动机

- 研究场景：多个旋翼 UAV 搭载 LED，为地面接收面提供 downlink visible light communication (VLC) 服务；系统中有多个地面 receivers 和一个 unauthorized eavesdropper，每个接收端和窃听端都配备单个 photodetector。
- 关键矛盾：
  - VLC 有 LoS 优势和较低互网干扰，但光信号在照明区域内有广播性质，窃听者可能截获信息。
  - 只提高发射功率可改善部分接收点信号，却会增加信息泄漏和能耗。
  - UAV 高度和位置改变会影响覆盖范围、光功率均匀性、窃听信道和移动能耗。
  - 单目标只看能耗、覆盖或安全都不能满足无线网络部署需求。
- 本文希望解决什么：
  - 通过多 UAV 位置与功率联合优化改善接收面覆盖公平性；
  - 用物理层安全思想最小化 eavesdropper information rate；
  - 控制 UAV 从初始位置移动到最优悬停点的 motion energy；
  - 在 receiver 分布、UAV 数量、高度扰动、VLC channel uncertainty 和 UAV position dynamics 下保持可用。

## 核心理念与算法流程

- 核心理念：安全通信部署不能只把“覆盖”和“能耗”做权衡，还要把 eavesdropper 接收信息率作为显式目标。UAV 的位置和功率同时影响三类目标，因此解向量要把水平位置、高度和功率放在一起编码，但更新时按物理意义分块处理，避免不同量纲和边界的变量被同一个算子粗暴混合。
- UAVDMOP 决策变量：
  - UAV 部署位置 `(X, Y, Z)`；
  - UAV transmission power `P`；
  - 论文有时写 `P_i,k`，但解向量写作 `X = [X_{1 x U}, Y_{1 x U}, Z_{1 x U}, P_{1 x U}]`，复现时应确认功率是 per-UAV 还是 per-UAV-receiver。
- 三个优化目标：
  1. Coverage fairness objective `f1`：最小化所有地面采样点 received optical power 的方差，使接收面光功率更均匀。
  2. Security objective `f2`：最小化 eavesdropper 接收到的总 information rate，降低潜在信息泄漏。
  3. Energy objective `f3`：最小化 UAV motion energy，即从初始位置移动到优化悬停位置的能耗；模型采用 rotary-wing UAV propulsion power。
- 主要约束：
  - UAV 水平位置在 `[X_min, X_max]` 与 `[Y_min, Y_max]` 内；
  - 高度固定为 `H0`，或限制在 `[H_min, H_max]`；
  - 发射功率在 `[P_min, P_max]`；
  - power regulator factor `omega_{i,k}` 被限制在 0/1 或 0-1 范围，论文中表述略不一致，并说明它是由部署和信道增益派生而非直接优化变量；
  - UAV 之间满足最小安全距离 `d_min`。
- MOEA/D-CICM 流程：
  1. 基于 MOEA/D 框架，用权重向量分解多目标问题，维护理想点和邻域。
  2. 用 circle map 对 UAV transmission power 做 chaos initialization；水平位置仍随机初始化，以保持灵活性。
  3. 每代从 mating neighborhood 选两个父代。
  4. 将解按物理含义拆分为水平位置、垂直高度和功率。
  5. 对水平位置和功率执行 uniform crossover，并根据各自边界裁剪；高度在部分设定中保持固定或受限。
  6. 用 DE-style mutation 改进交叉后的同物理含义变量，mutation strength `beta` 随迭代和随机因子变化。
  7. 合并各分量形成新解，评价三目标，更新理想点和邻域解。
- 关键组成部分：
  - UAV-enabled VLC channel model；
  - eavesdropper information-rate objective；
  - coverage variance objective；
  - rotary-wing UAV motion energy model；
  - circle-map power initialization；
  - component-wise crossover/mutation；
  - MOEA/D decomposition selection。
- 可能被修改的位置：
  - 把单 eavesdropper 扩展为多个窃听者或不确定窃听区域；
  - 用 secrecy rate / secrecy outage / worst-case leakage 替代单一 eavesdropper information rate；
  - 把固定高度改为 3D deployment，并加入障碍物、FOV 遮挡和飞行轨迹约束；
  - 用 surrogate 或分区采样降低大规模接收面上 `O(N x U)` 的评价成本；
  - 用鲁棒优化或 chance constraint 处理 CSI 不确定，而不只做事后仿真。

## 实验证据

- 实验设置：
  - Matlab 2023a；
  - UAV power range `0.1-10 W`；
  - UAV motion speed `V=16 m/s`；
  - 最大迭代次数 200；
  - 基本 VLC 参数包括 transmitter semi-angle `60 deg`、receiver FOV semi-angle `60 deg`、photodiode area `1 cm^2`、AWGN 标准差 `-110 dB` 等。
  - 主比较包括 Random deployment、Uniform deployment、MOCRY、MOPSO、MOFPA、传统 MOEA/D。
  - 文中一处说每个方法运行 10 次，后文 convergence 分析又称每个仿真重复 30 runs；该运行次数存在表述不一致。
- 主实验 Case 1，8 UAV：
  - Table 3 中 MOEA/D-CICM 得到 `f1=0.3176`、`f2=0.3120`、`f3=0.7138`，均低于 Random、Uniform、MOCRY、MOPSO、MOFPA、MOEA/D。
  - 高质量通信区域面积从 initial/random/uniform 的约 `40.97/43.34/44.58 m^2` 提升到 MOEA/D-CICM 的约 `50.19 m^2`。
- 主实验 Case 2，12 UAV：
  - Table 4 中 MOEA/D-CICM 得到 `f1=0.5577`、`f2=0.3504`、`f3=3.5071`。
  - 相对 MOCRY、MOPSO、MOFPA、MOEA/D，MOEA/D-CICM 在三个目标上整体更优；但 Uniform deployment 的 `f3=1.7727` 更低，说明纯少移动或固定均匀部署在能耗单点上可能占优，但安全和覆盖表现差。
- 距离约束与不同规模/分布：
  - Tables 5-8 在 6/8/12/16 UAV、Gaussian/Random/Uniform/Exponential receiver distribution、50/100/150/200 iterations 和 UAV distance constraint 下测试。
  - 多数场景中 MOEA/D-CICM 的 `f2` 和 `f3` 明显较低；`f1` 并非所有场景都最佳，部分表中 MOEA/D 或其他方法有更低 coverage variance。
- 鲁棒性、适应性和可扩展性：
  - Section 6 进一步测试 terrestrial receiver distributions、UAV altitude variations `[7,8] m`、VLC channel uncertainty with additive Gaussian noise、UAV position dynamics with Gaussian perturbations，以及 6-16 UAV 服务 3600-14400 receivers 的规模变化。
  - Tables 13-16 显示在 channel uncertainty `sigma_h^2=10^-7` 下，MOEA/D-CICM 通常保持较低 security leakage 和 energy consumption。
  - Tables 17-20 显示在 UAV position dynamics 下，MOEA/D-CICM 仍在安全和能耗上有明显优势。
  - Tables 25-32 组合考虑 changing height、distance constraints、channel uncertainty 和 UAV dynamics，作者据此认为方法适合动态不确定环境。
- 证据边界：
  - 主论文没有清晰的消融实验分离 chaos initialization 与 crossover mutation 各自贡献。
  - Baseline 算法也采用了本文的分块更新处理以适配不同边界，这有利于公平处理变量边界，但也让“算法改动贡献”更难隔离。
  - 已知 eavesdropper CSI 是理想化假设；作者将其作为 PLS 中常用上界/benchmark 设定并做了合理性说明。
  - 多数实验是仿真，缺少真实 UAV/VLC 硬件或 packet-level 链路验证。
  - 模型主要考虑单一 eavesdropper、LoS 信道和垂直收发方向，复杂遮挡、多径、多个窃听者和实时轨迹安全未充分建模。

## 局限与未来工作

- 作者显式或隐含局限：
  - Known eavesdropper CSI 假设偏理想；
  - 固定或窄范围高度简化了三维搜索空间；
  - UAV acceleration/deceleration 在飞行能耗中被忽略；
  - 动态和不确定场景主要通过加性噪声、位置扰动和高度范围仿真验证。
- 我们认为仍需确认的问题：
  - `P_i,k` 与 `P_{1 x U}` 的功率变量定义需在复现时统一。
  - Table 5-32 中 `f1` 不总是最优，若业务重视覆盖公平性，需要额外偏好或约束筛选。
  - `f3` 主要是运动能耗，通信发射功率对总能耗的处理需要复查公式。
  - 单个 eavesdropper 的位置已知时，部署可绕开该点；多个未知窃听区域下需要鲁棒/最坏情形模型。
  - 大规模接收面评价成本为 `O(N x U)`，真实在线部署可能需要代理、网格压缩或分区采样。

  - 在评价前用 receiver clustering 压缩接收面，再对 Pareto 候选做全网格精评。
  - 对位置和功率分别使用不同的 mutation rate 和 repair strategy，按目标贡献自适应调整。
  - 给每个 Pareto 解输出安全热图和能耗分解，辅助后处理选择。
- 结构创新线索：
  - 构建“光/无线信道数字孪生 -> 安全泄漏评估 -> 覆盖公平评估 -> 能耗评估 -> Pareto 部署搜索”的通用安全通信部署框架。
  - 与策略跟随评估结合：上层选 UAV/LED/RSU 部署和功率，下层 follower 根据实时用户需求调度服务。
  - 与鲁棒优化结合：把 CSI、位置扰动、遮挡和接收器分布作为场景集，输出名义/鲁棒双前沿。
