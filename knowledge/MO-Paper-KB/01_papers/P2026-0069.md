# A zero-shot tree-structured multi-objective evolutionary Neural Architecture Search

## 一句话理解

TreeNAS 将神经架构搜索建模为零训练成本的多目标进化问题，用树结构编码保护输入到输出的 backbone 信息流，用 NTK、初始化 MSE 和 FLOPs 同时评价训练性、泛化性和复杂度，并用 Pareto 非支配排序避免固定权重导致的单一偏好。

## 问题与动机

- 研究问题和场景：在 NAS 中自动发现高性能、低复杂度神经网络架构。传统 multi-shot NAS 需要训练大量候选；one-shot NAS 需要训练 supernet 或预测器；zero-shot NAS 虽然低成本，但常依赖单一 proxy，排序不稳定。
- 现有算法为什么不足：
  - 结构盲的 DAG 编码和普通交叉/变异可能保持拓扑合法却破坏关键梯度/信息流路径，zero-cost proxy 不一定识别这种结构损伤。
  - 单一 zero-cost proxy 只反映表达性、梯度敏感性、容量或复杂度中的一面，跨任务和搜索空间排名不稳定。
  - 固定权重或硬约束会把多目标 NAS 压成预设偏好，降低解的多样性。
- 本文希望解决什么：用树结构编码和 mutation 后 refinement 保留 backbone 路径，用多 proxy 共同评价候选架构，并用 Pareto 进化维护不同准确率-复杂度权衡的非支配架构集合。

## 核心理念与算法流程

- 核心理念：NAS 中架构编码不是中性细节。好的编码应让遗传操作在探索局部结构的同时不破坏关键的信息路径；评价也不应将训练性、泛化性和复杂度压成一个固定标量，而应作为多目标共同优化。
- 主要流程：
  1. 随机初始化 `N` 个架构种群和空 elite archive。
  2. 二元锦标赛选择父代。
  3. 将候选架构编码为 tree encoding。
  4. 执行 one-point slice crossover 和 point mutation。
  5. 对 offspring 执行 refinement，将中间基因型投影到最近的可行 backbone 连通基因型。
  6. 通过一次小批量 forward/backward 计算三个 zero-cost 目标：NTK 条件数、初始化 held-out MSE、FLOPs。
  7. 合并父代和子代，更新非支配 elite archive。
  8. 对合并种群进行非支配排序和拥挤距离环境选择。
  9. 输出最终种群中的 Pareto 架构。
- 关键组成部分：
  - Tree-structured encoding：在 OOE 和 OON 搜索空间中分别用三段编码记录操作、连接/路径和 backbone mask/operations。
  - Backbone path refinement：交叉/变异后只最小修改 backbone 相关基因，恢复 input-output 连通路径。
  - Zero-cost multi-objective evaluation：`f1` 为 NTK 条件数，`f2` 为初始化 NTK kernel regression 的 held-out MSE，`f3` 为 FLOPs。
  - Pareto-dominance evolutionary search：非支配 archive、非支配排序和 crowding distance 共同保持不同 trade-off。
- 可能被修改的位置：backbone 识别规则、refinement 投影距离、zero-cost proxy 集合、非支配选择策略、archive 截断、FLOPs/latency/params 复杂度目标。
- 必须保留的核心：若作为基础算法，应保留“结构保真编码 + refinement”和“多 proxy Pareto 评价”两个核心；只保留 Pareto 搜索而不保留结构修复，会重新暴露 backbone 断裂风险。

## 实验证据

- 测试问题和对比算法：Stage I 用 NAS-Bench-101/201 验证准确率-成本和消融；Stage II 在 ImageNet MobileNetV2 空间、ECG2017、NoduleMNIST3D 和跨数据集迁移上验证部署和泛化。
- NAS-Bench-201：TreeNAS 在 CIFAR-10、CIFAR-100、ImageNet-16-120 上达到 `94.37(0.12)`、`73.22(0.16)`、`46.71(0.15)`，搜索成本 3716 GPU 秒；CIFAR-10 达到 benchmark optimal，CIFAR-100 和 ImageNet-16-120 距最优分别 0.29% 和 0.60%。作者报告 Wilcoxon `p<0.05`。
- NAS-Bench-101：TreeNAS CIFAR-10 `94.11(0.13)`，距最优 0.20%；相比 G-EA 准确率提高 0.12%，搜索时间仅为其 12.33%。
- proxy 消融：NAS-Bench-201 CIFAR-100 上，12-epoch baseline 为 69.89%、150000 GPU 秒；单 NTK/MSE 为 71.09/71.53%；FLOPs-only 为 67.22%；未经归一化三 proxy 标量化 69.78%，min-max 标量化 72.42%；TreeNAS Pareto 多目标为 73.22%、3716 GPU 秒。
- 编码消融：随机搜索 66.31；移除 backbone path 为 71.04，下降 2.18 个百分点；移除 crossover 为 71.53；移除 mutation 为 72.16；完整 TreeNAS 为 73.22。作者认为 tree encoding 是主要收益来源。
- ImageNet 部署：在 450M/600M/1B FLOPs 预算下，TreeNAS top-1 为 `78.5±0.2`、`79.7±0.2`、`81.2±0.1`，每个预算搜索成本 0.45 GPU-days，作者称相对 multi-shot/one-shot NAS 降低 40x 到 1000x 成本。
- 跨模态医学验证：ECG2017 Macro-F1 为 `0.69±0.01`，NoduleMNIST3D ROC-AUC 为 `0.92±0.01`，优于 ZenNAS 和 ZiCo 以及部分多训练/AutoML baseline。
- 跨数据集迁移：在 CIFAR-10 搜索后迁移到 CIFAR-100 和 ImageNet-16-120，TreeNAS 分别为 72.86 和 46.53，接近 benchmark optimum。
- 证据边界：
  - zero-cost proxy 最终仍是 ranking surrogate，准确率证据依赖 NAS benchmark 或最终训练验证。
  - ImageNet 和医疗结果是 top-ranked 架构训练后的表现，不能单独归因于某一个 proxy。
  - 对 Transformer、GNN 或非 CNN 风格 cell 的扩展尚未验证。

## 局限与未来工作

- 作者明确说明的局限：TreeNAS 继承 zero-cost NAS 的 proxy fidelity trade-off；skip/identity-dominated 或高度不平衡架构可能产生平滑梯度和低 MSE，被 proxy 误判为优质。Tree encoding 可缓解但不能完全消除。
- 作者未来工作：
  - 架构族自适应 proxy：动态调整 NTK、MSE 和补充指标，如 Transformer 的 attention entropy。
  - 轻量 multi-fidelity refinement：对高不确定候选短训 1-2 epoch，提高排序精度。
  - 扩展到 CNN-style cells 以外的架构家族。
- 我们认为仍需确认的问题：
  - NTK/MSE/FLOPs 的 Pareto 关系在不同搜索空间是否稳定。
  - refinement 的最小 Hamming 投影可能偏向局部固定 backbone，是否会限制结构创新。
  - 对 latency、memory、energy 等硬件实际目标的替换效果。
  - 对非图像任务和大模型搜索空间的 proxy 可靠性。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 结构保真的架构编码与修复：可用于 NAS、图结构搜索、程序结构进化等需要保持关键连通路径的遗传表示。
- 暂留在论文卡中的方法、原理或架构启发：
  - NTK+MSE+FLOPs 作为零成本多目标架构评价。
  - 用 Pareto 选择替代固定 proxy 权重，避免 proxy scale mismatch。
  - 对高不确定架构做 selective multi-fidelity refinement。
- 局部创新线索：
  - 将 backbone refinement 的距离从 Hamming 换为 proxy-aware repair cost。
  - 对不同架构族学习不同 proxy 权重或增加结构熵、attention entropy、latency proxy。
  - 对 skip-dominated 候选加入惩罚或结构深度下限。
- 结构创新线索：
  - 构建“结构语义约束编码 + 零成本多目标评价 + 少量多保真校准”的 NAS 框架。
  - 将 backbone 保护思想迁移到其他图演化任务，如 GNN 架构、计算图调度、符号表达式进化。
