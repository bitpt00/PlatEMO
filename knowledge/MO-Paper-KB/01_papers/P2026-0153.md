# Knowledge-driven large-scale multi-objective evolutionary learning for interval prediction of key quality indicators in blast furnace ironmaking process

## 一句话理解

本文把高炉铁水硅含量的预测区间建模写成大规模双目标优化：最大化区间覆盖率、最小化区间宽度；再提出 DKL-LSMOEA，从早期进化父子代中收集“搜索方向-是否支配改进”数据，用 XGBoost 学变量重要性压缩决策空间，用 GMM 学成功方向分布生成子代，从而快速训练异方差 ELM 区间预测模型。

## 问题与动机

- 研究问题和场景：
  - 高炉炼铁过程强非线性、长时滞、扰动多，关键质量指标热金属 Si 含量依赖人工采样和离线化验；
  - 工业现场不仅需要点预测，还需要 prediction interval (PI) 量化不确定性；
  - PI 应同时覆盖真实值并保持窄宽度，形成 coverage 与 sharpness 的双目标冲突。
- 现有算法为什么不足：
  - 点预测模型不能表达过程波动和风险；
  - conformal prediction 虽有覆盖保证，但在异方差 BF 数据上可能产生过宽区间；
  - LUBE 类神经网络 PI 方法需要设计损失并做高成本梯度训练；
  - MOEA 可优化覆盖/宽度 trade-off，但 ELM PI 模型输入权重和偏置维度随特征数、隐节点数快速增长，形成大规模 MOP，普通 MOEA 收敛慢、多样性差；
  - 现有大规模 MOEA 多面向 benchmark，少用于 BF 质量指标 PI 建模。
- 本文希望解决什么：
  - 建立显式大规模 MOP，同时优化 PICP 和 PINAW；
  - 在不依赖梯度训练复杂神经网络的情况下，优化两个 ELM 的输入层权重/偏置；
  - 从进化历史中学习变量重要性和成功方向分布，降低搜索维度并加速收敛；
  - 在真实 BF 数据上获得覆盖率、区间宽度和点预测精度之间更好的平衡。

## 核心理念与算法流程

- 核心理念：
  - 进化过程本身可产生监督数据：父代到子代的方向向量是输入，子代是否支配父代是标签；
  - XGBoost classifier 的 split gain 可衡量哪些决策变量更常参与成功方向；
  - 成功方向集合可由 GMM 建模，作为后续知识驱动 reproduction 的方向生成器；
  - “变量重要性”解决 where to search，“方向分布”解决 how to search。
- PI 模型：
  - 使用两个 ELM；
  - ELM1 学 conditional mean；
  - 通过 5-fold cross-calibration 得到 residual logarithmic variance label；
  - ELM2 学 heteroscedastic variance；
  - 最终以标准正态分位数构造置信水平 `1-alpha` 的上下界。
- LSMOP formulation：
  - 决策向量 `X` 由两个 ELM 的输入权重和偏置拼接；
  - 隐节点数 `h1=h2=2n`；
  - 总维度 `d=4n(n+1)`，BF 数据 `n=68` 时约 18768 维；
  - 目标为最小化 `-PICP` 和最小化 `PINAW`。
- DKL-LSMOEA 流程：
  - Stage 1：在原始空间 `Omega1` 用 base MOEA（本文为 GDE3）进化 `T1` 代；
  - 每个父子代对形成 direction vector，若 offspring 支配 parent，则标记为 success；
  - Stage 2：用 `{V,L}` 训练 XGBoost classifier，按变量重要性选择 top `theta*d` 变量构造 reduced space `Omega2`；
  - 从成功方向 `V_s` 训练 GMM，得到 directional distribution knowledge；
  - 清空数据集，保证下一轮重新采集当前阶段知识；
  - Stage 3：在 `Omega2` 中从 GMM 采样方向，mask 掉非关键变量，生成 `X_new = X + F*U`；
  - 用非支配排序和拥挤距离做环境选择。
- 可能被修改的位置：
  - base MOEA 可替换 GDE3；
  - XGBoost 可替换为 RF、LASSO、RFE、SHAP/GBDT importance 或神经特征选择；
  - GMM 可替换为 VAE、normalizing flow、diffusion、CMA covariance 或 direction archive；
  - success label 可加入 dominance strength、HV contribution、constraint improvement 或 delayed survival；
  - reduced space 可从 hard top-k 改为 soft mask 或分组预算。
- 必须保留的核心：
  - 知识必须来自在线 evolutionary process data，而非一次性静态变量分析；
  - success label 与后续变量/方向学习要闭环更新；
  - 子代生成要同时使用变量子空间和方向分布，否则只降维或只采方向都会丢失互补性。

## 实验证据

- 测试问题和对比算法：
  - 真实 BF 数据来自中国大型钢厂，时间跨度 2020-02-01 至 2023-06-07；
  - 清洗后 1219 条样本，68 个变量，目标为铁水 Si 含量；
  - 数据按 6:2:2 分为训练/验证/测试，min-max scaling 仅用训练集参数；
  - PI baselines：QRF、PM-LGB、CCR-XGB、DualAQD、EnCQR、EnbPI；
  - BF PI 搜索效率对比：NSGA-II、IM-MOEA/D、LMOCSO；
  - LSMOP benchmark：LSMOP1-9，二目标，`d=100,200,300`；
  - LSMOP SOTA：LMEA、LMOEA-DS、MOCGDE、LERD；
  - 15 次独立运行，Wilcoxon rank-sum 和 Friedman rank test。
- 主要实验结论：
  - BF PI 任务上，DKL-LSMOEA 的 PICP 为 94.76%，与 CCR-XGB 接近；
  - PINAW 为 0.370，是对比方法中最窄；
  - CWC 为 0.630，为最佳；
  - RMSE 为 0.114，与 EnbPI 等最强点预测 baseline 相当；
  - Fig. 6 显示其 PI envelope 更贴近真实 Si 趋势，并随目标波动调整宽度；
  - HV 曲线显示 DKL-LSMOEA 早期 HV 提升更快，最终 HV 最高，Pareto front 收敛和分布优于 NSGA-II、IM-MOEA/D、LMOCSO。
- Benchmark 证据：
  - 在 LSMOP1、2、4、5、8、9 上，所有 tested dimensions 中均取得最佳 IGD；
  - 相对 LMEA、LMOEA-DS、MOCGDE、LERD 的统计结果分别为 `21/6/0`、`22/2/3`、`25/1/1`、`16/8/3`（优/等/差）；
  - LSMOP3 和 LSMOP6 的部分维度上 LERD 或 LMOEA-DS 更强，说明 DKL-LSMOEA 并非所有 landscape 最优。
- 消融或机制证据：
  - 用 LASSO、RFE、RF 替换 XGBoost structural importance 后，DKL-LSMOEA 在 `d=100,200,300` 的 Friedman average ranking 均最好；
  - 作者解释 XGBoost 能更好捕获非线性关系和变量交互，因此重要性更可靠；
  - 敏感性分析显示 `N=120` 是性能/成本折中，`theta=0.1` 最好，`F=1.1` 最好；
  - `theta` 越大，reduced space 越高维，性能持续下降；
  - `F` 太小不能充分利用 direction knowledge，太大会破坏 elite characteristics。
- 证据边界：
  - 真实工业实验只有一个 BF Si 数据集；
  - PI 模型使用 ELM，其他深度/时序结构是否同样适合此优化编码未验证；
  - LSMOP benchmark 是连续无约束二目标，many-objective、约束、离散或动态场景仍需验证；
  - XGBoost/GMM 的学习成本和样本质量依赖早期 base MOEA 的探索质量；
  - `theta=0.1` 的硬筛选可能遗漏需要协同变化的低重要变量。

## 局限与未来工作

- 作者明确说明的局限：
  - 论文未给出明确局限章节，但实验范围显示真实工业验证集中在单一 BF Si 含量 PI 任务；
  - 参数 `N`、`theta`、`F` 需要设置，且 `theta` 对性能影响明显。
- 作者未来工作：
  - 扩展到 dynamic and multi-process industrial scenarios；
  - 融入更先进的 uncertainty quantification techniques；
  - 探索该大规模优化框架在 evolutionary neural architecture search 等应用中的潜力。
- 我们认为仍需确认的问题：
  - 早期 parent-offspring dominance label 在多目标高维噪声问题中是否足够稳定；
  - 如果 base MOEA 初期方向质量差，XGBoost 和 GMM 会否学习到错误知识；
  - 只用 dominance success 的二分类标签会忽略改善幅度、目标区域和多样性贡献；
  - reduced space 中未选变量完全置零，可能抑制后期微调和变量协同；
  - GMM 在非常高维成功方向上是否需要低秩协方差、PCA 或分组建模。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：
  - 新建 [成功方向标注的双知识大规模 MOEA](../02_design_knowledge/K-success-labeled-dual-knowledge-lsmoea.md)。
- 暂留在论文卡中的方法、原理或架构启发：
  - 双 ELM + residual log variance 的 PI 建模可用于其他工业时序质量指标，但作为应用模型暂不单独建卡；
  - `PICP/PINAW/CWC/RMSE` 的评价组合适合工业 interval prediction 任务；
  - `XGBoost/LASSO/RFE/RF` 的结构知识比较可作为后续变量重要性模块的备选。
- 局部创新线索：
  - 把 success label 从二值支配改成 `HV contribution gain`、`rank improvement`、`epsilon dominance` 或 `CWC improvement`；
  - 对不同 Pareto front 区域训练不同 GMM，避免一个全局方向分布平均化；
  - 将 top-k hard mask 改成 probability mask，让低重要变量保留小概率探索；
  - 用 conformal or Bayesian uncertainty 调节 PI model 的 MOEA 目标，避免仅依赖 validation PICP/PINAW。
- 结构创新线索：
  - 构建通用 evolutionary data mining layer：任何 MOEA 都可输出方向样本和 success labels，再由监督模型反馈到变量筛选与 direction generator；
  - 与动态 LSMOP 结合：环境变化后短期提高 `theta` 或重置 GMM，快速重新学习成功方向；
  - 与 neural architecture search 结合：把 architecture edit direction 标为成功/失败，学习关键超参数和有前途编辑分布；
  - 与代理辅助昂贵优化结合：只在代理置信高的方向上训练 GMM，真实评价用于校正 success label。
