# NSGA-II 在多目标 LeadingOnes 问题上的困难

## 一句话理解

本文不是提出新算法，而是给出一个对 NSGA-II 的 many-objective 负面运行时间结果：在 4 个及以上目标的 LeadingOnesTrailingZeroes (LOTZ) 基准上，即使种群规模与 Pareto front 大小同阶，经典 NSGA-II 也会在指数时间内持续漏掉常数比例的 Pareto front。关键机制是 crowding distance 在高目标离散前沿上只给少数点正距离，绝大多数点被随机打平；当第一非支配层先因已知 Pareto 点的重复个体膨胀到超过种群容量时，随机删点会反复丢失尚未充分覆盖的 Pareto 目标值。

## 问题与动机

- 背景：
  - NSGA-II 在 biobjective OMM 和 LOTZ 上已有正向运行时间结果；
  - 但近期工作证明 NSGA-II 在目标数大于 2 的 OneMinMax (OMM) 上会低效；
  - OMM 的特殊性是所有解都在 Pareto front 上，负面结果可能被认为过于理想化。
- 本文要回答的问题：
  - NSGA-II 的 many-objective 困难是否只出现在 OMM；
  - 当大多数解不是 Pareto-optimal、nondominated sorting 有机会发挥作用时，crowding distance 的问题是否仍会导致失败。
- 作者选择的对象：
  - `m`-objective LeadingOnesTrailingZeroes (m-LOTZ)，其中 `m` 为偶数且 `m>=4`；
  - bitstring 被分成 `m/2` 个独立块，每个块对应一对 LeadingOnes 和 TrailingZeroes 目标。

## m-LOTZ 与 NSGA-II 设置

- m-LOTZ：
  - 每个块长度为 `n' = 2n/m`；
  - 对每个块，奇数目标计数前缀连续 1，偶数目标计数后缀连续 0；
  - Pareto-optimal block 形如若干 1 后接若干 0；
  - Pareto set 与 Pareto front 大小均为 `M=(n'+1)^(m/2) = (2n/m+1)^(m/2)`。
- NSGA-II 设置：
  - population size `N <= aM`，其中 `a>1` 为常数；
  - 初始化为均匀随机 bitstring；
  - 理论主结果先分析 fair parent selection 和 standard bit mutation；
  - 环境选择仍为 nondominated sorting，critical front 内用 crowding distance，若仍相同则随机打破平局。

## 主要理论结论

| 结论 | 内容 | 来源章节或 PDF 页码 |
|---|---|---|
| Theorem 1 | 对偶数 `m>=4`，NSGA-II 用 `N<=aM`、fair selection 和 bitwise mutation 优化 m-LOTZ 时，对任意 `T` 和所有 `t<=T`，以至少 `1 - T exp(-Omega((m/n)M))` 的概率，合并父代和子代 `R_t` 仍漏掉 Pareto front 的常数比例 | Sec. III，PDF 4 |
| 指数下界 | 因为在很长时间内都无法覆盖完整 Pareto front，期望运行时间和高概率运行时间至少为指数级 | Introduction、Sec. III，PDF 2、7 |
| Theorem 2 | Theorem 1 可扩展到 random parent selection 和 binary tournament selection，只要每个 parent 独立选择且从已覆盖的大 Pareto 集合中抽到 parent 的概率有正常数下界 | Sec. III，PDF 7 |
| Proof boundary | 证明不直接覆盖 one-bit mutation 或 crossover；作者仅做实验观察 | Sec. III-IV，PDF 7-9 |

## 失败机制

1. Crowding distance 在 many-objective 离散目标值上退化。
   - Lemma 1 表明，对于成对非支配集合，至多 `4n+2m` 个个体有正 crowding distance。
   - 当 Pareto front 大小 `M` 多项式增长时，绝大多数非支配个体的 crowding distance 为 0，只能随机打平。

2. 旧 Pareto 目标值的重复个体增长快于新 Pareto 目标值的发现。
   - 标准 bit mutation 经常复制父代，已覆盖 Pareto 点会在第一非支配层中积累重复个体。
   - 产生全新 Pareto 目标值的概率上界较小，作者用 Chernoff bounds 控制其增长。

3. 第一非支配层会先膨胀到超过 `N`。
   - LOTZ 与 OMM 不同，大量解被支配；因此 early stage 中第一非支配层未必超过容量。
   - 论文核心技术贡献是证明：在发现完整 Pareto front 之前，第一层仍会因已知 Pareto 点复制而超过 `N`。

4. 一旦第一层超过容量，crowding distance 和随机 tie-breaking 会删除许多目标值。
   - Lemma 2 说明，当第一层 `|F1| > (1+alpha)N` 时，选择下一代会以高概率漏掉常数比例的 Pareto front。
   - 这一过程重复发生，导致 NSGA-II 长时间无法越过常数覆盖比例。

## 实验观察

- 实验对象：
  - 4-LOTZ；
  - `n=40`；
  - Pareto front 大小 `M=441`；
  - 运行 1000 iterations，多数设置做 10 次独立运行，但图中展示代表性单次曲线。
- Classic NSGA-II：
  - `N=2M,4M,8M` 均在 1000 代内漏掉常数比例 Pareto front；
  - 种群越大覆盖比例越高，但没有消除问题；
  - 合并种群 `R_t` 覆盖比选中种群 `P_{t+1}` 略好，说明 offspring 不能持续补回被删目标值。
- 第一非支配层结构：
  - selected population 几乎全由 Pareto-optimal individuals 组成；
  - combined population 中仍会出现 nonoptimal individuals，但 nondominated individuals 大多 Pareto-optimal。
- Parent selection 和 crossover：
  - random selection、binary tournament selection 与 fair selection 的行为相近；
  - uniform crossover 几乎不改善；
  - one-point crossover 覆盖更多，但仍不能完全克服 crowding distance 问题。
- Balanced NSGA-II：
  - 在 crowding distance 后增加“目标值 multiplicity 尽量均匀”的 tie-breaker；
  - 在 4-LOTZ 上能快速覆盖完整 Pareto front；
  - 作者据此强调问题来自 classic crowding distance，而不是 population size 必须达到最大 incomparable set 规模。
- One-bit mutation：
  - 覆盖比例高于 standard bit mutation；
  - `N=8M` 时偶尔覆盖完整 front，但平均仍会漏掉少数目标值，不能稳定收敛；
  - 作者尚无完整解释，留作 future work。

## 局限与阅读边界

- 理论证明针对 `m` 为偶数且 `m>=4` 的 m-LOTZ，且 `m` 和 `a` 为常数。
- 主证明覆盖 standard bit mutation 下的 fair/random/binary tournament parent selection，不覆盖 one-bit mutation 或 crossover。
- 实验部分限于 `n=40` 的 4-LOTZ，主要用于解释理论机制，不是大规模算法竞赛。
- Balanced NSGA-II 不是本文原创算法，而是引用已有方法并作为诊断证据。
- LOTZ 仍是合成 pseudo-Boolean benchmark；工程连续 MOO 中的 crowding distance 失效方式可能不同，但“高目标下 crowding distance 区分力不足”的风险具有广泛启发。

## 可复用知识与创新线索

- 值得建立的设计知识：已新建“目标值均衡的二级环境选择”，因为该论文给出强理论证据说明 classic NSGA-II 的 crowding distance 在 many-objective 离散 PF 上会导致指数级失败，并展示 balanced tie-breaker 能显著缓解。
- 局部创新线索：
  - 在 NSGA-II critical front 内先去重或限制同一 objective value 的 multiplicity；
  - 对 crowding distance 为 0 的个体，用 objective-value rarity、reference-vector occupancy 或 HV contribution 二次排序；
  - 在离散 Pareto front 上维护已覆盖目标值表，优先保留稀有或唯一覆盖值；
  - 用 one-bit/local mutation 与目标值均衡选择组合，测试是否能解释并放大 Fig. 4 的覆盖优势。
- 结构创新线索：
  - 把 many-objective 环境选择拆成 `rank -> geometry/diversity -> coverage multiplicity` 三层；
  - 对离散组合 MOO，显式区分“个体数量多”与“不同 Pareto 目标值覆盖多”；
  - 在动态或多模态 MOO 中加入 objective-value coverage memory，避免重复个体挤掉稀有区域。
