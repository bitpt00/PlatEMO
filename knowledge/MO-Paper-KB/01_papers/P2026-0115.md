# A surrogate-assisted evolutionary algorithm with multi-perspective infill sampling for expensive super-many-objective optimization problems

## 一句话理解

论文提出 MP-SAMaOEA：面向昂贵 super-many-objective optimization，不只按代理搜索得到的当前候选表现选真实评价点，而是把候选作为“未来训练样本”的价值纳入 infill。每个候选先找决策空间中最近的真实评价样本，再计算它与该样本在目标空间的夹角，用决策距离和目标角度做非支配排序，选出既能校正代理又不完全放弃探索的少量真实评价点；代理内搜索还用参考向量和 k-means 修复过度聚集。

## 问题与动机

- 研究问题：
  - 当目标数超过 10 时，many-objective problem 进入 super-many-objective 场景，选择压力和分布维护都会变弱；
  - 真实评价昂贵时，逐目标训练代理模型是常见做法，但目标越多，多个代理的预测误差越容易累积；
  - 每个目标函数特性不同，想为每个代理补充高质量训练样本会消耗大量真实评价预算；
  - 现有 infill 往往关注当前候选的预测收敛、多样性或不确定性，较少直接判断候选能否提升代理训练质量。
- 现有方法为什么不足：
  - 一类 SAMaOEA 为每个目标或整体目标训练 regression surrogate，依赖代理预测精度，误差累积后会误导 MaOEA；
  - 另一类学习支配关系、指标或 performance relation，能减轻逐目标误差，但依赖关系/指标学习质量；
  - 只按当前 predicted performance 选点，可能反复评价代理已经熟悉的局部区域，不能有效改善后续代理。
- 本文希望解决什么：
  - 用很少真实评价更新 GP 训练集；
  - 让 infill 同时考虑 candidate 与已评价样本在决策空间和目标空间的相对关系；
  - 在代理内搜索阶段维持参考方向上的多样性，避免低保真代理把种群推向局部聚集；
  - 在 WFG、DTLZ 和水资源规划问题上验证高目标数、低评价预算下的样本效率。

## 核心模型与算法流程

- MP-SAMaOEA 总框架：
  - 初始化时用 LHS 在决策空间生成 `11*D - 1` 个解，真实评价后存入 `DatabaseTS`；
  - 每轮基于 `DatabaseTS` 为每个目标函数训练或更新一个 GP；
  - 从 `DatabaseTS` 中按参考向量选初始 parent population；
  - 在代理预测目标值上运行 `omega_max` 代 SBX + polynomial mutation；
  - 用 k-means-assisted diversity enhancement 做代理内环境选择；
  - 用 multi-perspective infill criterion 从最终 `Pop` 选择少量 `SP`，真实评价后回灌 `DatabaseTS`；
  - 达到 `FEmax` 后输出 `DatabaseTS` 中的非支配解。
- 初始父代选择：
  - 将真实评价档案中的解关联到参考向量；
  - 每个参考向量先选择离 ideal point 最近的解；
  - 若数量不足，则按同一参考向量继续选择次近解，直到达到 `N`；
  - 若最后一轮超过 `N`，只保留 final pass 中更接近 ideal point 的解，使父代规模精确为 `N`。
- k-means-assisted diversity enhancement：
  - 合并 parent 和 offspring 后，每个解关联到夹角最小的参考向量；
  - 若同一参考向量上的关联解数 `mu < 2|Pop|/3`，直接选择该方向上离 ideal point 最近的解；
  - 若 `mu` 超过 `2|Pop|/3`，认为该方向聚集严重，用 k-means 把子群分为 `ceil(mu/3)` 个簇；
  - 每个簇选离 ideal point 最近的解，形成下一代父代；
  - 参考向量按当代目标最大/最小值自适应更新。
- Multi-perspective infill criterion：
  - 对每个代理搜索候选 `S_i`，在 `DatabaseTS` 中找决策空间最近的训练样本 `DBS_i`；
  - 记录最小欧氏距离 `Dis_i`；
  - 计算 `S_i` 与同一个 `DBS_i` 在目标空间中的角度 `Ang_i`；
  - 按 Algorithm 2，对 `Dis_i` 和 `negative Ang_i` 做非支配排序，并从非支配解中选 `n` 个真实评价；
  - 正文解释第一前沿包含两类样本：一类靠近训练样本且目标角度较小，预测较可靠；另一类在决策或目标关系上处于边缘，可补充探索信息；
  - 被两种视角同时支配的候选不建议真实评价，因为它们在决策空间和目标空间都缺少训练价值。
- 复杂度：
  - GP 训练/更新复杂度为 `O(|Arc|^3)`；
  - 代理内优化包含目标平移 `O(mP)`、参考向量关联 `O(mNP)`、距离计算、k-means 分组 `O(N*SP + k*SSP)` 和参考向量更新；
  - 总复杂度写为 `O(|Arc|^3 + mP + mNP + N*SP + k*SSP + mN/(omega/omega_max))` 量级。

## 实验证据

- 实验设置：
  - benchmark：WFG 和 DTLZ；
  - 目标数 `M=6,10,20`；
  - 6/10 目标时 `D=10, FEmax=300`，20 目标时 `D=20, FEmax=400`；
  - WFG2/WFG3 的决策维度分别为 11、11、21；
  - 真实应用：water resource planning problem，3 个决策变量、5 个目标；
  - baseline：AB-SAEA、EDN-ARMOEA、KTA2、PA-EMaOEA、K-RVEA；
  - 所有算法初始真实样本为 `11*D - 1`；
  - 参考向量数在 6/10/20 目标时为 42、20、40；
  - 指标：IGD+ 越小越好，HV 越大越好；
  - PlatEMO，20 次独立运行，Wilcoxon rank-sum test。
- 消融实验：
  - `MP-SAMaOEA-DEC` 只用决策空间欧氏距离，通过 roulette 选 5 个真实评价点；
  - `MP-SAMaOEA-OBJ` 只用目标空间角度，通过 roulette 选 5 个真实评价点；
  - 在 DTLZ2/3/4/7 的 6/10/20 目标上，完整 MP-SAMaOEA 对 DEC 的 IGD+ 统计为 `8/0/4`，对 OBJ 为 `12/0/0`；
  - 作者据此认为双视角 infill 比单独使用决策距离或目标角度更能提升整体代理质量。
- WFG 结果：
  - Table 2 中 MP-SAMaOEA 在 27 个 WFG 实例中取得 25 个 best；
  - 相比 AB-SAEA、EDN-ARMOEA、KTA2、PA-EMaOEA、K-RVEA，IGD+ better/worse/similar 分别为 `21/1/5`、`25/0/2`、`19/1/7`、`27/0/0`、`24/0/3`；
  - 6 目标 WFG8 可视化显示 MP-SAMaOEA 的最终解分布更好；
  - 20 目标 WFG8 的 IGD+ 和 HV 收敛曲线显示明显优势。
- DTLZ 结果：
  - Table 3 中 MP-SAMaOEA overall 最好，并取得 11 个 best result；
  - 相比五个 baseline 的 better counts 为 17、18、17、13、15，worse counts 为 1、2、3、5、2；
  - DTLZ1 上不如 PA-EMaOEA，但优于其余四个算法；
  - DTLZ3 上与 PA-EMaOEA 相近，优于其余四个；
  - DTLZ2/5/6/7 上整体优于对比算法，作者强调多样性优势。
- 真实应用：
  - 水资源规划问题中，MP-SAMaOEA 的 HV 为 `4.3544e-1 (2.65e-3)`；
  - 对比算法 AB-SAEA、EDN-ARMOEA、KTA2、PA-EMaOEA、K-RVEA 的 HV 分别为 `3.5892e-1`、`3.9826e-1`、`4.2319e-1`、`3.0435e-1`、`4.1233e-1`；
  - Table 4 表明 MP-SAMaOEA 在该真实问题上取得最高 HV。

## 局限与未来工作

- 作者明确局限：
  - MP-SAMaOEA 尚缺少处理 multi-modal 或 irregular PF 的专门策略；
  - 未来需要增强优化过程并发展应对此类前沿结构的策略。
- 我们认为仍需谨慎的问题：
  - Algorithm 2 的 `negative Ang_i` 与正文“smaller angles”表述存在方向歧义，复现实验时应确认排序目标；
  - 决策空间欧氏距离在高维、强变量关联、离散/混合编码或存在等价编码时可能误导最近训练样本判断；
  - 目标空间角度只看候选与最近训练样本的响应方向，未显式使用 GP 不确定性、预测误差校准或 HV/IGD 贡献；
  - GP 训练复杂度 `O(|Arc|^3)`，随着评价预算和目标数增加可能成为瓶颈；
  - 真实应用只有 3 决策变量、5 目标，不能完全代表 super-many-objective 工程场景。

## 可迁移设计要点

- 将 infill 从“候选自身多好”改为“候选加入训练集后能否减少代理盲区”；
- 最近训练样本可以同时作为局部预测可信度锚点和目标响应差异参照；
- 决策距离与目标角度适合用非支配排序组合，而不是固定线性权重；
- 代理内搜索的候选池质量会影响 infill，需在进入真实评价选择前抑制参考向量方向上的过度聚集；
- 在复用时可把欧氏距离替换为变量分组距离、Mahalanobis 距离、Hamming 距离或 learned latent distance，把角度替换为 rank correlation、local Jacobian 差异或不确定性校准误差。
