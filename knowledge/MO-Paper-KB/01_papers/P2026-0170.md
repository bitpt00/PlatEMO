# Ensemble of Transfer Techniques via Adaptive Resource Allocation for Multiobjective Multitask Optimization

## 一句话理解

论文提出 MMTO-ETA：在多目标多任务优化中用 LPCA 为每个任务估计局部 Pareto set manifold，把每个局部簇拆成结构知识 SK 和位置知识 LK，再通过 survival-rate reward 在自进化、SK-based transfer 和 LK-based transfer 三种演化方式之间动态分配资源，以兼顾高相似任务的定点迁移和低相似任务的结构迁移。

## 问题与动机

- 研究问题和场景：
  - Multiobjective multitask optimization (MMTO) 同时求解多个相关 MOP；
  - 每个任务内部需要维护 Pareto trade-off，任务之间还要通过 knowledge transfer (KT) 提升效率；
  - 论文采用 multipopulation framework，每个任务保留独立 population，同时显式进行跨任务迁移。
- 现有算法为什么不足：
  - individual gene transfer 在任务最优区域差异大时容易负迁移；
  - population distribution transfer 比个体复制稳健，但容易被 noisy/scattered solutions 扭曲；
  - evolutionary behavior / search direction transfer 受随机搜索过程影响较强；
  - 已有 manifold-related MMTO 主要利用演化方向，未充分拆解 manifold 中不同类型的知识；
  - 固定迁移概率或固定迁移方式无法适配高相似/低相似任务和不同演化阶段。
- 本文希望解决什么：
  - 从 population 的局部 manifold 中提取更细粒度、更稳定的可迁移知识；
  - 区分 structure knowledge (SK) 和 location knowledge (LK)，让它们分别服务于结构模式迁移和高潜力区域迁移；
  - 通过 online reward-driven resource allocation 动态决定每代更多使用自进化、SK 迁移还是 LK 迁移；
  - 降低负迁移风险，同时保持任务间正迁移收益。

## 核心理念与算法流程

- 核心理念：
  - 连续 MOP 的 Pareto set 通常呈 piecewise `(m-1)` 维 manifold；
  - LPCA 能把当前 population 切成多个局部簇，并在每个簇中估计局部主方向；
  - 每个簇的主方向矩阵 `U` 表示结构知识 SK，簇中心 `mu` 表示位置知识 LK；
  - SK 适合在任务最优区域相距远但局部形状相似时迁移结构模式；
  - LK 适合在任务最优区域相近时直接定位高潜力区域；
  - 两类知识并不总是同时有效，因此需要用 offspring survival rate 动态调度。
- MMTO-ETA 主流程：
  1. 为 `T` 个任务分别初始化 population `P1,...,PT`，每个大小为 `N`；
  2. 对每个任务初始化三类演化方法的 reward record 和 selection probability；
  3. 每代对每个任务执行 Knowledge-Extraction，从当前 population 提取 `SK_t` 和 `LK_t`；
  4. 根据上一代 reward 和控制因子 `alpha` 更新三类方法概率；
  5. 对目标任务中的每个个体随机选择一个 source task；
  6. 按 roulette wheel 在自进化、SK-based transfer、LK-based transfer 中选择一种生成 offspring；
  7. 用 strength Pareto environmental selection 更新该任务 population；
  8. 按三类方法生成 offspring 的 survival rate 更新 reward。
- LPCA knowledge extraction：
  - 将任务 `t` 的当前 population `P_t` 划分成 `K` 个 disjoint clusters；
  - 对每个 cluster 计算中心 `mu_j` 和协方差矩阵；
  - 根据 PS 的 `(m-1)` 维正则性假设，提取前 `m-1` 个 eigenvectors 组成局部主方向矩阵 `U_j`；
  - `SK_t={U_1,...,U_K}`，`LK_t={mu_1,...,mu_K}`；
  - 相比全局 PCA，LPCA 可以捕捉不同局部区域的 piecewise manifold。
- SK-based transfer：
  - 对目标任务当前个体 `x_i`，随机选择 source task 中一个 cluster `C_j` 和其中个体 `y`；
  - 用 source cluster center `mu_j` 和 local principal subspace `U_j` 编码 `y` 相对 source cluster 的局部结构偏移；
  - 把该 latent offset 映射到 target cluster 的 local principal subspace `U_t`，再加上 target center `mu_t` 得到 transferred solution `z`；
  - 作用是迁移局部结构模式，而不是直接复制源任务位置。
- LK-based transfer：
  - 随机选择 source population 中的一个 cluster；
  - 直接使用 source cluster mean `mu_j` 作为 transferred solution `z`；
  - 作用是利用任务最优区域接近时的高潜力位置知识。
- 与 DE offspring 结合：
  - 自进化采用 adaptive differential evolution；
  - SK/LK 生成的 `z` 会随机替换 DE 公式中的 `x_i,x_1,x_2,x_3` 之一；
  - trial vector 再与当前个体 `x_i` crossover 生成 offspring；
  - 这样迁移知识不是单独插入 population，而是平滑进入目标任务的变异过程。
- Adaptive resource allocation：
  - 三类方法初始概率相同；
  - 每代根据历史 selection probability、上一代 reward 和控制因子 `alpha` 更新 raw probability，再归一化；
  - reward 由该方法生成 offspring 在 environmental selection 后的 survival proportion 计算；
  - 高相似 B17 场景中 LK-based transfer 往往概率更高；
  - 低相似 B21 场景中 SK-based transfer 更能保持有效性。
- 可能被修改的位置：
  - cluster 方法：LPCA、K-means、spectral clustering、SOM、GMM 或自适应 manifold clustering；
  - `K` cluster 数，可从固定值改为根据 population geometry 自适应；
  - SK 可替换为 tangent vectors、local covariance、graph Laplacian、autoencoder latent directions；
  - LK 可扩展为 cluster center + radius + elite representative；
  - reward 可从 survival rate 改为 HV contribution、IGD+ improvement、constraint feasibility improvement 或长期 bandit credit；
  - source task 选择可从随机改成 task similarity graph；
  - 宿主 DE 可替换为 SBX/PM、PSO、EDA 或问题专用算子。
- 必须保留的核心：
  - 每个任务需维护可估计局部结构的 population；
  - SK 和 LK 要分开使用，并允许不同任务/阶段有不同权重；
  - 资源分配必须来自在线效果反馈，而不是固定迁移概率；
  - 迁移后 offspring 必须经过目标任务评价和环境选择验证。

## 实验证据

- 测试问题和对比算法：
  - Benchmark suites 包括 CEC17 (B17) 和 CEC21 (B21)；
  - 额外测试包括 MTZDT、MTUF，用于检查复杂 PF/PS 的偏置；
  - Real-world application 为四组 constrained optimal power flow (OPF) problems，每组两个任务；
  - 使用 MToP 平台，每个 benchmark 独立运行 30 次，最大 1000 generations；
  - MTZDT 因函数较简单，最大 generations 为 250；
  - 对比算法包括单任务 IRM-MEDA、AR-MOEA、MSEA，以及多任务 MO-MFEA、MO-MFEA-II、MOMFEA-SADE、EMT-ET、EMT-GS、MTDE-MKTA；
  - OPF 因约束处理，排除部分无约束算法，加入 CCMO 和 CMOCSO；
  - 指标为 IGD+、HV，并使用 Wilcoxon rank-sum test 和 Friedman ranking。
- B17/B21 主结果：
  - Table I 汇总统计检验和 Friedman ranking；
  - B17 IGD+ 中 MMTO-ETA ranking 为 `1.56`，优于 MTDE-MKTA `3.39` 和 EMT-GS `4.28`；
  - B17 HV 中 MMTO-ETA ranking 为 `2.61`，仍为最佳；
  - B21 IGD+ 中 MMTO-ETA ranking 为 `3.10`，优于 EMT-GS `3.75`、MTDE-MKTA `4.10` 和 MO-MFEA-II `4.73`；
  - B21 HV 中 MMTO-ETA ranking 为 `4.08`，仍为最佳；
  - 作者指出 B21 中少数问题更偏好 GA operators，MMTO-ETA 在这些问题上略弱。
- 高/低相似任务机制解释：
  - B17 任务相似性较高，LK-based transfer 更能利用精确位置；
  - B21 任务相似性较低，直接位置迁移更不可靠，SK-based transfer 通过局部结构模式保持更强鲁棒性；
  - Fig. 5 显示高相似 B17-P1-T1 中 LK probability 长期较高，低相似 B21-P2-T1 中 SK probability 更强，极低相似 B21-P9-T1 中 SK 与 self-evolution 接近。
- 运行时间：
  - MMTO-ETA 运行时间相对较高，主要来自每代 manifold modeling；
  - 但仍快于 EMT-GS、MOMFEA-II 和 MSEA 等较耗时算法；
  - 相比 MO-MFEA、EMT-ET、MOMFEA-SADE 等轻量方法，MMTO-ETA 需要用更多时间换取更高解质量。
- 复杂 PS/PF 分析：
  - MTZDT 包含 convex、nonconvex、discrete、multimodal 和 nonuniform PF；
  - MTUF 用 UF1-UF10 组成，更侧重复杂 Pareto set structures；
  - 作者总结 MMTO-ETA 在多数任务上 best 或 highly competitive，说明不是只适配单一 PF 类型；
  - 将 LPCA clustering 替换为 K-means 或 spectral clustering 后，K-means variant 整体最弱；
  - MTZDT 上原始 LPCA 表现最好，MTUF 上 spectral clustering variant 略优，说明复杂局部几何下更灵活 clustering 可能有价值。
- 消融实验：
  - 四个变体：`wo-LK`、`wo-SK`、`wo-RA`、`wo-ALL`；
  - Table II 显示 MMTO-ETA 的 IGD+ ranking 为 `2.05`，HV ranking 为 `2.08`，均优于所有变体；
  - `wo-ALL` 最差，IGD+ / HV ranking 为 `4.32 / 4.03`；
  - `wo-RA` 在 IGD+ 上相对 MMTO-ETA 显著差于 24 个 case，说明固定或无自适应分配容易负迁移；
  - B17 高相似场景中去掉 LK 退化明显，B21 低相似场景中去掉 SK 退化更明显；
  - Fig. 4 的四个代表问题中完整 MMTO-ETA 收敛曲线优于变体。
- 参数敏感性：
  - Table III 显示 `K=5` 的平均 ranking `2.74` 最好；
  - `alpha=0.3` 的平均 ranking `2.67` 最好，说明更重视 recent reward 但保留一定历史记忆；
  - DE scaling range `R=[0.3,1.3]` 的 average ranking `2.37` 最好。
- Real-world OPF：
  - 四组 OPF problems，均包含多目标与约束；
  - 作者在 supplementary Table S-XVII 中报告 MMTO-ETA 在多数 test cases 上优于七个对比算法；
  - 因真实最优未知，OPF 采用 HV 评价；
  - 主文只给总结，没有列出完整数值。
- 证据边界：
  - 主文只给统计汇总，详细 IGD+/HV 表在 supplementary files；
  - 真实 OPF 结果也主要在 supplementary；
  - 当前算法主要面向连续统一维度或可统一维度的 MMTO；
  - MMTO-ETA 的优势来自 SK、LK、RA 和 DE/环境选择组合，单个模块贡献需结合消融理解。

## 局限与未来工作

- 作者明确说明的局限：
  - 当前 regularity modeling 使用固定 cluster number `K=5`；
  - LPCA 不是唯一或总是最优的局部结构识别方法；
  - MMTO-ETA 运行时间较轻量算法更高，主要来自每代 manifold modeling。
- 作者未来工作：
  - 引入更有效、更自适应的局部结构识别方法，如 self-organizing map-based strategies；
  - 在框架中加入更多 transfer techniques；
  - 将 MMTO-ETA 扩展到 dynamic optimization scenarios。
- 我们认为仍需确认的问题：
  - 任务数增大时，随机 source task 选择是否会浪费迁移机会，是否需要 task graph；
  - `K=5` 对不同 population size、目标数和任务数是否稳健；
  - LPCA 对强非线性、多峰、离散或混合变量 PS 的局部线性假设可能不足；
  - SK/LK transfer 在强约束任务中可能产生不可行解，需要 constraint-aware repair；
  - survival rate 是短期反馈，可能误判暂时不存活但长期有探索价值的迁移；
  - 维度不一致或变量语义异构的任务需要更明确的对齐/编码机制。
