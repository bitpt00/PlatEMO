# Local Regularity Model for Multimodal Multiobjective Optimization

## 一句话理解

本文把 MMOPs with local Pareto fronts 中的 global optimal solutions 和 local optimal solutions 统一视为 acceptable decisions，用层级 PCA 建局部正则流形，再按局部支配强度概率重构种群，减少 LOS 因当前候选分布不均而被清理或误删。

## 问题与动机

- 研究问题和场景：多模态多目标优化不仅要逼近全局 Pareto optimal set/front，还要在决策空间保留具有可接受目标质量的局部最优解集，即 ADs，包括 GOSs 和 LOSs。
- 现有算法为什么不足：niching、ring topology、dual clustering、clearing、archive cleanup 等方法高度依赖当前候选解分布；在低收敛或欠收敛解污染下，LOS 判别、密度估计和清理半径容易失真，导致可接受局部前沿被灾难性删除。
- 本文希望解决什么：用少量候选解提前估计 AD manifold，把潜在 AD 区域回灌到种群分布中，降低 LOS 搜索对当前种群覆盖质量的依赖。

## 核心理念与算法流程

- 核心理念：Pareto set 或 local Pareto set 可近似为 `(m-1)` 维分段连续流形；如果按 Pareto rank 与局部 connected subset 分层建 PCA 正则模型，就能在欠收敛样本污染下仍预测潜在 AD 区域。
- 主要流程：
  1. 基础 MMOA 产生/更新种群，并维护外部 archive；
  2. 计算每个个体的 local dominance intensity，作为多模态搜索策略的 fitness 输入；
  3. 对 archive 按 Pareto nondominated sorting rank 分层，每层用 HPCA 和 error-to-extension ratio 提取局部 `(m-1)` 维主成分；
  4. 用 feature correlation 和 neighborhood violation 自组织确定局部模型数量和邻域形状，并用 diversity entropy 扩展端点；
  5. 删除落入已构造邻域规则的冗余或欠收敛样本；
  6. 从 LRM 均匀采样，并根据 local dominance intensity 的归一化概率重构部分种群。
- 关键组成部分：acceptable decision / LOS 定义、HPCA、error-to-extension ratio cost function、双层 LRM 结构、feature-correlation/neighborhood-violation 自组织、probability reproduction strategy。
- 可能被修改的位置：多模态算法的 archive 维护、环境选择后补充候选、reproduction/reinitialization 预算分配、LOS/GOS 识别模块。
- 必须保留的核心：分层提取局部主成分、基于邻域规则过滤欠收敛污染、模型采样后以概率方式重构种群，而不是无条件替换。

## 实验证据

- 测试问题和对比算法：构造 MMOPL test suite，包括 IEEE CEC 2019 MMOPL、IDMP variants 以及本文设计的 MM1L/MM3L/MM4L/MM8L 等；对比 DN-NSGA-II、TriMOEATA&R、MMOGA、CEALES、MMOEA/DC、MO-Ring-PSO、RM-MEDA。
- 主要实验结论：LRMO 在 MMOPsL 上整体优于对比 MMOAs，尤其在决策空间 IGDx 上优势明显；作者称 LRMO 对所有 MMOPsL 获得更好的 IGDx，并在多个算法的 rank-sum test 中显著占优。
- 消融或机制证据：feature correlation 推荐值约 0.85；LRM sampled points 在早期能快速降低 IGDx/IGDf，普通 regularity model 有发散趋势；probability reproduction 的热力图比简单 probability replacement 更集中于 AD manifolds；LRM-BASE 比 BASE 更快接近 AD 分布。
- 证据边界：Markdown 中 Table I-II 和 Figs. 3-10 多为图片占位，精确均值、标准差和所有显著性结果需回看 PDF；LRMO 使用的是与 MO-Ring-PSO 相同的经典搜索策略，不能把所有收益完全归因于 LRM 单组件。

## 局限与未来工作

- 作者明确说明的局限：高维场景存在“维度上升导致收敛压力降低”和“多模态多样性维护”之间的矛盾；高维 MMOP 的 multimodality detection 仍为空缺问题。
- 作者未来工作：研究高维优化与多模态之间的关联，并开发更高效的 evolutionary strategies 处理高维与多样性维护的矛盾。
- 我们认为仍需确认的问题：HPCA 在高维距离集中、混合变量、约束 MMOP 和噪声目标下是否稳定；feature correlation 0.85 和 local dominance intensity 的默认邻域公式是否可自动化；LRM 采样比例过高时是否会压制未知模态探索。
