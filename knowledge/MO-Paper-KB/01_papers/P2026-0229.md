# Enhancing Landscape Approximation With Ensemble-Based Surrogate Model for Expensive Constrained Multiobjective Optimization

## 一句话理解

本文提出 EM-SAEA：先用目标导向阶段靠近 UPF，再用全局/局部 GP ensemble 精准近似约束，并用 reference-vector 场景化 VCDP 在有限真实评价下推动种群从 UPF 转向 CPF。

## 问题与动机

- 研究问题和场景：Expensive constrained multiobjective optimization problems (ECMOPs) 中，真实目标和约束评价昂贵，且可行域可能狭窄、断裂或复杂。
- 现有算法为什么不足：
  - 常规 CMOEA 需要大量 FEs，不适用于昂贵评价；
  - ECMOP 中 surrogate 预测约束值会直接决定 feasibility，一旦约束预测错误，种群可能被引向错误区域；
  - 多数 ECMOP SAEA 对目标和约束都只建全局模型，复杂或断裂可行域下容易忽略局部 landscape；
  - CDP 总是优先约束，容易让种群陷入局部可行区；过度放松约束又依赖难调参数。
- 本文希望解决什么：提升约束 landscape approximation 的准确性，并用不依赖固定手工阈值的约束支配规则，在有限 FEs 下兼顾 objective convergence、feasibility 和 diversity。

## 核心理念与算法流程

- 核心理念：目标函数只需相对排序，约束函数却需要更准的 feasibility 判断，因此只对约束函数使用 global + local ensemble surrogate；同时用 reference vectors 将目标空间划分为角扇区，对不同可行/不可行、同区/异区场景使用不同 dominance 规则。
- 主要流程：
  1. LHS 初始化 `NI` 个真实评价样本，形成 archive `Arc`。
  2. 前半预算执行 objective-oriented optimization stage：忽略约束，用 RVMM 等 conventional SAEA 快速靠近 UPF。
  3. 后半预算进入 constraint-oriented optimization stage。
  4. 对每个 objective 用所有 `Arc` 训练一个 GP surrogate。
  5. 对每个 constraint 训练一个 global GP，并按 objective-space reference vectors 构造多个 local training sets，训练 local GPs。
  6. 新候选预测约束时，先按预测目标值分配到最近参考向量对应的 local model，同时计算 global/local constraint uncertainty，采用平均不确定性更小的一方。
  7. 在 decomposition-based evolutionary search 中，用 VCDP 比较候选与随机选出的邻域个体并替换。
  8. 从 surrogate search 得到的最终种群中选择 `mu` 个点真实重评估；若无可行解则按 active reference vector 聚类选低 CV 解，若有可行解则选分布好的非支配可行解。
- 关键组成部分：
  - Ensemble-based constraint surrogate：每个约束一个 global GP 加多个 reference-vector local GP。
  - 双方法 local training set construction：保证每个 evaluated solution 被使用，同时每个 local model 包含最相关样本。
  - Uncertainty-based global/local model choice：对候选约束预测选择更可信模型。
  - VCDP：根据 feasibility、angular sector 和 feasible ratio `pf` 定义三种比较场景。
  - Two-stage optimization：先不管约束增强 objective convergence，再用约束 surrogate 和 VCDP 转向 CPF。
- 可能被修改的位置：
  - 局部模型划分可改用聚类、可行域连通分量、constraint boundary clusters 或 learned embeddings；
  - global/local 选择可用加权 ensemble、Bayesian model averaging 或 uncertainty calibration；
  - VCDP 的 `pf` 概率可加入 feasibility progress、CV 下降率或 archive coverage；
  - stage split 可由固定 50% 改为基于 UPF-CPF 距离、可行率或 surrogate uncertainty 的自适应切换。
- 必须保留的核心：约束 surrogate 必须同时保留 global 和 local 两种视角，并在预测时按不确定性选择或融合；VCDP 必须按 reference-vector sector 区分同区/异区比较，否则会退化为普通 CDP 或随机约束放松。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：C-DTLZ、DC-DTLZ、CF、MW、LIRCMOP，共 44 个问题；只考虑 inequality constraints。
  - Real-world：RCM suite 中机械设计、reactor network design、process synthesis 等 5 个实例。
  - 对比算法：HeE-MOEA、KTA2、MultiObjectiveEGO、KTS、K-MGSAEA、TEA、SA-CRVEA-AS。
  - 指标：IGD+ 和 HV，30 次独立运行，Wilcoxon rank-sum test；population size 100，initial sampling `11D-1`，最大 FEs 400，real-world initial samples 100。
  - EM-SAEA 参数：local reference vectors `k=5`，model-assisted search generations `wmax=20`，每轮 re-evaluation `mu=5`。
- 主要实验结论：
  - Sensitivity/RQ1：将 ensemble constraint surrogate 嵌入 K-RVEA、CSEA、RVMM 的两阶段框架均显著提升 LIRCMOP 表现，说明关键收益来自 constraint-oriented stage，而非特定 objective-oriented SAEA。
  - C-DTLZ、DC-DTLZ、CF：EM-SAEA 在 8 个问题取得 best，比各 peer 分别显著优于 16、11、16、9、15、13、9 个问题。
  - MW、LIRCMOP：EM-SAEA 在 12 个问题取得 best，比各 peer 分别显著优于 27、21、25、16、22、22、17 个问题。
  - Real-world RCM：EM-SAEA 在 3 个问题取得 best，对 7 个 peer 的显著优于数为 5、5、5、4、4、3、5。
  - 可视化：MW9 和 LIRCMOP10 上 EM-SAEA 的 nondominated solutions 同时有更好 convergence 和 diversity，显示 VCDP 与 ensemble surrogate 对连续/断裂可行域均有效。
- 消融或机制证据：
  - Ensemble surrogate 消融：EM-SAEA 优于仅 local 的 EM-SAEA-L 和仅 global 的 EM-SAEA-G，IGD+ 和 FR 排名更好，说明 global/local 互补。
  - 模型调用分析：LIRCMOP5 可行域较连续，global/local 调用差异不大；LIRCMOP11 可行域断裂，后期 local model 调用显著增加，符合“样本增多后 local 更适合复杂局部 landscape”的假设。
  - Two-stage 消融：只 objective-oriented 会越过可行域趋向 UPF，只 constraint-oriented 初始远离 CPF 时目标驱动不足，完整两阶段排名最好。
  - VCDP 消融：相比 CDP、epsilon-constrained、SR、ACDP，VCDP 在 IGD+ 上更好，MW7/MW9 可视化显示更好 convergence 和 diversity。
- 证据边界：
  - EM-SAEA 在 LIRCMOP1-4 较弱，因为 UPF 与 CPF 距离大且可行域极窄，固定 stage split 转向 CPF 需要更多迭代；
  - 仅对 inequality constraints 做实验，equality constraints 通过 relaxation 转换未专门验证；
  - global + local constraints 增加一定 runtime，尽管消融称差异不大。

## 局限与未来工作

- 作者明确说明的局限：
  - LIRCMOP1-4 上固定两阶段切换和当前 CHT 不足以快速处理 UPF-CPF 距离大、可行域极窄的情况；
  - 当前主要面向低/中维 ECMOP，高维决策空间仍待扩展；
  - 只实验 inequality constraints。
- 作者未来工作：
  - 在模型层面提升 objective/constraint fitting accuracy；
  - 设计更 customized stage division strategy；
  - 扩展到更高维 decision spaces。
- 我们认为仍需确认的问题：
  - local reference vector 数量 `k` 在 many-objective 或复杂断裂可行域中如何自适应；
  - uncertainty 比较是否经过校准，GP 不确定性在局部小样本下是否可靠；
  - 对 equality constraints、noise constraints 和 mixed variables 是否仍有效；
  - VCDP 中跨 sector 的随机目标/约束比较是否会引入较大方差。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“全局-局部约束代理与向量场景约束支配”，因为它给出 ECMOP 中 constraint surrogate management 和 constraint handling 的一体化接口。
- 暂留在论文卡中的方法、原理或架构启发：
  - 目标 surrogate 和约束 surrogate 的精度需求不同，不必给目标也做昂贵 ensemble；
  - 可行域断裂时，局部模型应随样本积累逐渐接管 global model；
  - 同区比较应更重视 CV 以防局部可行性丢失，异区比较应保留目标优良不可行解以跨越 infeasible gaps。
- 局部创新线索：
  - 在其他 ECMOP SAEA 中把 constraint GP 替换为 global-local uncertainty ensemble；
  - 将 VCDP 嵌入 MOEA/D、RVEA、NSGA-III 或代理辅助 CMOEA；
  - 用 feasible ratio 和 archive uncertainty 自适应决定目标/约束比较概率。
- 结构创新线索：
  - 构建“目标快速收敛阶段 -> 约束局部地形学习阶段 -> 场景化约束支配 -> 分布式重评估”的昂贵约束优化框架；
  - 对每个 constraint 维护可行域地图：global model 负责整体趋势，local models 负责 narrow/disconnected regions。
