# Pareto Set Learning Through Genetic Programming for Multiobjective Dynamic Scheduling

## 一句话理解

本文提出 PSLGP，把用户偏好作为 GP 调度规则的输入，学习一个可实时按偏好变化输出不同 tradeoff 解的单一动态调度启发式，而不是维护一组覆盖 Pareto front 的独立启发式。

## 问题与动机

- 研究问题和场景：MO-DFJSS 需要在动态作业到达、机器异构、运输时间、工序约束下实时优化 flowtime、tardiness、weighted flowtime、weighted tardiness 等冲突目标。
- 现有算法为什么不足：
  - NSGP-II、SPGP2、MOGP/D 等多目标 GP 通常学习一组启发式覆盖 Pareto front，实际使用时需要管理和选择多个 heuristics；
  - 动态制造场景中用户优先级会实时变化，多启发式集合难以快速适配新 preference；
  - 现有神经 Pareto set learning 模型结构复杂且可解释性弱，不适合很多动态调度场景；
  - 互动式 GP 依赖决策者训练中持续参与，不适合实际开发和部署。
- 本文希望解决什么：学习一个 preference-conditioned scheduling heuristic，使同一棵 GP 调度规则能根据实时偏好改变行为，并尽可能映射所有有效偏好到 Pareto front。

## 核心理念与算法流程

- 核心理念：把偏好权重作为 GP tree terminal/input，让同一个 routing tree 和 sequencing tree 能在不同 preference 下输出不同调度决策；训练时轮换 main preference，并用 KNN surrogate 估计其他偏好下的表现，再用多准则选择和 preference diversity 促使单个 heuristic 覆盖 Pareto set。
- 主要流程：
  1. 初始化 GP population，每个 individual 由 routing rule tree 和 sequencing rule tree 组成，terminal set 中包含调度特征和 preference weights。
  2. 设置 preference set `Lambda`，并选择当前 generation 的 main preference。
  3. Fitness evaluation：对每个 individual 在 main preference 上做真实仿真评价并得到 objective vector。
  4. 基于 main preference 评价结果做 nondominated rank。
  5. 对其他 preferences，用 KNN surrogate 估计 individual 表现；相似性由 phenotypic characterization (PC) under different preferences 计算。
  6. 用 HV、IGD 或 GD 三种 aggregation strategy 将一个 individual 在多个 preferences 下的估计表现聚合为 fitness。
  7. 额外计算 weighted-sum value 和 preference diversity；preference diversity 用同一 heuristic 在不同 preference 下的 PC 差异衡量。
  8. Multicriteria selection 依次比较 rank、fitness aggregation、weighted sum、preference diversity。
  9. Brood recombination 生成 `5N` 候选，基于 KNN surrogate 和 upcoming main preference 做 preselection，并用 niching 去除相同 PC 的重复个体。
  10. 每代轮换 main preference，使各 preference 都有机会得到真实评价；最终输出单个 best preference-conditioned heuristic。
- 关键组成部分：
  - Preference-conditioned GP representation：偏好权重直接进入 routing/sequencing trees。
  - KNN performance surrogate：用行为 PC 相似性估计非 main preference 下的目标表现，避免逐偏好完整仿真。
  - Fitness aggregation：HV、IGD、GD 三种版本 PSLGP-H/I/G。
  - Weighted sum 和 preference diversity：补偿 Pareto 指标忽略的非前沿表现，并鼓励不同偏好产生不同行为。
  - Main preference rotation：保证不同偏好都被真实评价覆盖。
  - Brood recombination + preselection：扩大候选池，再按 upcoming preference 预筛。
- 可能被修改的位置：
  - KNN surrogate 可替换为 learned behavior-performance model；
  - preference diversity 可改为目标空间覆盖、行为互信息或 preference-solution monotonicity；
  - aggregation strategy 可用 R2、epsilon、preference regret 或 calibrated weighted utility；
  - main preference rotation 可用自适应 sampling，优先训练表现弱或覆盖差的 preference 区域。
- 必须保留的核心：单个 heuristic 必须显式接收 preference 作为输入，并在训练中跨 preference 评价/估计/轮换；如果只是为不同偏好训练多个独立 GP rule，就不属于 PSLGP 的核心贡献。

## 实验证据

- 测试问题和对比算法：
  - 模拟 dynamic flexible job shop：5000 jobs，10 heterogeneous machines，机器速度 10-15，运输时间 7-100，作业 2-10 个 operations，due-date factor 1.5，1000 warm-up jobs。
  - 5 个 utilization levels：0.70、0.75、0.80、0.85、0.90。
  - 两类二目标场景：`Fmax-WTmax` 和 `WFmax-Tmax`，共 10 个 DFJSS scenarios。
  - 对比 baseline：NSGP-II；提出方法为 PSLGP-G、PSLGP-I、PSLGP-H，分别主要用 GD、IGD、HV 作为 aggregation criterion。
  - 用 Das and Dennis 方法生成 200 preferences；每个 PSLGP heuristic 在各 preference 下派生对应调度解，与 NSGP-II 的 nondominated heuristic set 比较 HV、IGD、GD。
- 主要实验结论：
  - HV：PSLGP-I average rank 为 1.8，整体最优；PSLGP-G/PSLGP-H rank 均为 2.8，在低利用率场景常优于 NSGP-II，但高利用率下会退化。
  - IGD：PSLGP-I average rank 为 1.8，整体最好，尤其在 `WFmax-Tmax` 条件下表现突出；PSLGP-H rank 为 2.5，PSLGP-G rank 为 3.0。
  - GD：正文分析指出 PSLGP-I 在三类指标整体最稳，NSGP-II 在高 utilization 下仍然鲁棒，但 GD 最弱。
  - 高负载边界：在 `WFmax-Tmax, 0.90` 等极端高 utilization 场景中，所有 PSLGP variants 在部分指标上弱于 NSGP-II，说明单 heuristic 覆盖整条前沿更难。
- 消融或机制证据：
  - 去掉 brood recombination/preselection 的 PSLGP-Ib 在 HV/IGD/GD 上显著退化，HV 中 9/10 scenarios 败于 PSLGP-I，GD 中 10/10 败于 PSLGP-I。
  - 去掉 multicriteria selection 的 PSLGP-Im 也显著退化，HV 中 10/10 scenarios 败于 PSLGP-I，IGD 中 9/10 败于 PSLGP-I。
  - Preference-to-solution distribution 可视化显示不同 preference groups 通常映射到不同目标空间区域，部分场景存在重叠或分散。
  - Top-five learned heuristics 分布分析显示 PSLGP 能学到覆盖较广的 preference-conditioned heuristics，但也可能有 heuristic 只覆盖小区域。
  - 结构分析表明 learned heuristic 中 preference terminal 确实影响 routing/sequencing rule。
- 证据边界：
  - 方法在 low-utilization 和中等 utilization 下更强，高 utilization 下稳定性不足；
  - 单 heuristic 比多 heuristic set 更易管理，但性能方差更大，box plots 中 PSLGP 分布通常更高；
  - KNN surrogate 只用 40 个 decision points 的 PC 近似行为，可能丢失细粒度调度差异。

## 局限与未来工作

- 作者明确说明的局限：
  - 高系统负载场景下表现受限，特别是高 utilization conditions；
  - preference-conditioned heuristic 不总能保证所有偏好都稳定映射到正确 Pareto region；
  - 部分 learned heuristics 可能只覆盖 Pareto front 的小区域。
- 作者未来工作：
  - 提升 learned heuristics 对多偏好的鲁棒性和完整 Pareto front 覆盖；
  - 探索更先进的 fitness aggregation；
  - 集成 adaptive mechanisms 以提升 high-load scenarios 表现；
  - 研究与其他优化方法结合的 hybrid methods。
- 我们认为仍需确认的问题：
  - preference diversity 是否与目标空间 preference alignment 一致；
  - KNN surrogate 在更高维偏好、多目标和更复杂 shop floor 下是否可靠；
  - 单 heuristic 的可解释性和可维护性是否随树规模上升而下降；
  - 如何在实际部署中让用户 preference 变化与调度系统约束同步。

## 可复用知识与创新线索

- 值得建立或补充的设计知识：建立“偏好条件单启发式的 Pareto 集学习”，因为它把偏好输入、行为多样性、跨偏好代理评价和偏好轮换组成一个通用框架，可迁移到调度、路由、装箱和其他实时决策启发式。
- 暂留在论文卡中的方法、原理或架构启发：
  - 单一可调 heuristic 可降低 Pareto set 部署复杂度，但训练时必须显式增强 preference responsiveness；
  - 行为 PC 可以作为 preference-conditioned heuristic 的轻量代理评价接口；
  - 训练时的 main preference rotation 类似 curriculum，避免某些偏好只靠代理估计。
- 局部创新线索：
  - 在调度 GP 或 routing GP 中加入 preference terminals，形成偏好条件 dispatching rule；
  - 用 preference diversity 约束/奖励替代仅看目标指标；
  - 对表现弱的 preference 区域增加真实仿真评价频率。
- 结构创新线索：
  - 构建“preference-conditioned heuristic -> cross-preference surrogate evaluation -> preference diversity selection -> main preference rotation”的单模型 Pareto set learning 框架；
  - 将 learned single heuristic 与一个 small heuristic ensemble 结合，在 high-load 或低置信偏好区切换到专用 heuristic。
