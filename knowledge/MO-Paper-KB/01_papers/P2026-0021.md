# Comment-based summarization using a multi-objective cuckoo search optimization approach

## 一句话理解

论文提出 CSMOCS，用多目标 cuckoo search 解决 comment-based extractive multi-document summarization。算法把摘要看成句子选择二进制向量，同时最大化文档内容覆盖、用户评论相关性和冗余降低，并用问题定制的 mutation 与 repair 在 100 词长度约束下生成摘要。实验在 RA-MDS 数据集上相对 18 种摘要方法取得更高 ROUGE。

## 问题与动机

- 研究问题和场景：
  - 互联网上新闻、社交媒体、论坛和产品页面同时包含源文档和大量用户评论；
  - comment-based summarization 希望摘要既覆盖原文核心内容，又反映读者评论中的重要关注点；
  - 用户评论往往噪声多、非正式、可能跑题，需要过滤并作为摘要选择信号。
- 现有算法为什么不足：
  - 传统 extractive summarization 常只看原文 salience，忽略评论中的 reader-aware 信息；
  - compressive/abstractive 方法可以生成更灵活摘要，但通常不是直接优化评论相关性、内容覆盖和冗余的多目标 trade-off；
  - 既有 comment-based MOO 方法主要使用 binary differential evolution，缺少 swarm-intelligence 与问题定制 mutation/repair；
  - 固定单一评分难同时平衡内容、评论和冗余，还要满足摘要长度约束。
- 本文希望解决什么：
  - 将 comment-based extractive summarization 明确建模为三目标句子子集选择；
  - 设计文本预处理与评论过滤，使评论 centroid 更接近文档主题；
  - 为多目标 cuckoo search 设计长度约束感知的句子 add/remove/exchange mutation 和 repair；
  - 在 RA-MDS 上用 ROUGE-1/2/L/SU4 验证摘要质量。

## 核心理念与算法流程

- 核心理念：
  - 把摘要句子选择从单一 salience 排序转为多目标组合搜索；
  - 源文档 centroid 表示“内容覆盖”，评论 centroid 表示“读者关注”，句间相似度表示“冗余”，长度约束由定制 mutation/repair 控制。
- 问题建模：
  - 文档集 `D` 含 `n` 个句子，评论集 `C` 含 `nC` 条评论；
  - 句子与评论都用 tf-isf term vector 表示；
  - 文档 centroid `O_D` 由所有文档句子向量平均得到，评论 centroid `O_C` 由过滤后的评论向量平均得到；
  - 解为二进制向量 `X in {0,1}^n`，`x_i=1` 表示选入第 `i` 个句子；
  - 目标 1：最大化选中句子与 `O_D` 的 cosine similarity 总和；
  - 目标 2：最大化选中句子与 `O_C` 的 cosine similarity 总和；
  - 目标 3：降低选中句子之间的 pairwise cosine redundancy；
  - 约束：摘要长度接近给定长度 `L`，RA-MDS 中 `L=100` words，容忍度 `epsilon` 与句长范围有关。
- 预处理流程：
  1. 句子切分；
  2. word tokenization；
  3. 使用 ROUGE package stop word list 删除停用词；
  4. Porter stemming；
  5. comment filtering：选取文档集中最高频的一定比例 terms，只保留包含至少一个这些 terms 的评论。参数测试后选择 5%。
- CSMOCS 主流程：
  1. 初始化外部非支配集合 `NDS` 和随机初始 population；
  2. 每代对每个个体随机选一个 candidate summary 做 mutation；
  3. 随机选一个 host nest，与 mutated summary 做 Pareto dominance 比较；
  4. 若 mutated summary 支配该位置解，则替换该位置，并把旧解放入 population 后半部分；否则把 mutated summary 放入后半部分；
  5. 对双倍 population 执行 Pareto rank 与 crowding distance 排序，保留前 `pops` 个作为下一代；
  6. 用被丢弃的一半和最终 population 更新 `NDS`；
  7. 返回非支配摘要集合。
- 问题定制 mutation：
  - mutation probability 设为 `1/n`，每次只改一个句子；
  - adding：优先添加能同时改善 content coverage 和 comment relevance 的未选句子；若找不到，则按由两类相关性组成的 mutation score 选最高分；
  - removing：优先删除不会降低 content coverage 和 comment relevance 的已选句子；若找不到，则删除 mutation score 最低的句子；
  - exchanging：先移除一个句子，再添加一个新句子。
- repair：
  - 当摘要超过上界 `L + epsilon` 时触发；
  - 对摘要内句子计算 repair score，综合 content coverage 与 comment relevance；
  - 反复删除 repair score 最低的句子，直到长度满足约束。
- 可能被修改的位置：
  - 将 centroid similarity 换成 embedding similarity、topic distribution、LLM judge score 或 query-aware relevance；
  - comment filtering 可改为语义检索、聚类去噪、stance-aware filter 或 toxicity/spam filter；
  - redundancy 可从 cosine pairwise sum 改成 MMR、semantic entailment、coverage submodular penalty；
  - repair 可同时考虑句子顺序、连贯性、实体一致和压缩编辑。
- 必须保留的核心：
  - 文档内容和用户评论应作为两个独立目标，而不是提前加权；
  - 冗余控制必须与覆盖/评论相关性同时优化；
  - 长度约束要在变异和修复中直接处理，否则摘要子集可行性会不稳定。

## 实验证据

- 测试问题和对比算法：
  - 数据集：RA-MDS，共 45 个新闻集合；
  - 每个集合包含 10 篇新闻文档、1 到 10 个评论文档、4 个人工参考摘要；
  - 摘要长度约束为 100 words；
  - 对比 18 种方法，覆盖 extractive、compressive、abstractive 三类；
  - 指标：ROUGE-1、ROUGE-2、ROUGE-L、ROUGE-SU4 的 F1 score。
- 实验设置：
  - population size `pops=64`；
  - maximum generations `gensm=500`；
  - mutation probability `1/n`；
  - comment filtering 候选比例为 100% no filter、20%、10%、5%、2.5%、1.25%，最终选择 5%；
  - 每个实验 31 次独立运行；
  - C/C++ 实现，Ubuntu 22.04.3 LTS，AMD Opteron Abu Dhabi 6376 2.3GHz，96GB RAM。
- CSMOCS 自身结果：
  - 平均 ROUGE-1 为 0.4785；
  - 平均 ROUGE-2 为 0.1955；
  - 平均 ROUGE-L 为 0.4319；
  - 平均 ROUGE-SU4 为 0.2188；
  - 中位数分别为 0.4801、0.1846、0.4283、0.2138；
  - ROUGE-2 和 ROUGE-SU4 有少量 outliers，整体分布近似正态。
- 与 18 种方法比较：
  - CSMOCS 在四个 ROUGE 均值上均为最高；
  - CSMOCS 相对所有方法平均提升：ROUGE-1 25.08%、ROUGE-2 33.21%、ROUGE-L 20.75%、ROUGE-SU4 29.03%；
  - 提升范围：ROUGE-1 为 4.94%-52.40%，ROUGE-2 为 4.54%-81.85%，ROUGE-L 为 10.74%-30.88%，ROUGE-SU4 为 6.74%-60.07%；
  - 相对最接近的 STDS，提升为 ROUGE-1 4.94%、ROUGE-2 4.54%、ROUGE-SU4 6.74%；
  - 相对 MOO-CMDS+NER，ROUGE-1 提升 43.23%、ROUGE-2 提升 17.25%、ROUGE-SU4 提升 27.47%；
  - 相对 MOO-CMDS，ROUGE-1 提升 52.40%、ROUGE-2 提升 24.22%、ROUGE-SU4 提升 35.04%。
- 运行时间：
  - 平均每个 RA-MDS topic 运行 241.53 秒；
  - 作者将其作为未来方法比较的 runtime baseline。
- 证据边界：
  - 对比表使用文献报告值，未说明所有方法是否在完全相同硬件和预处理下重跑；
  - 评价以 ROUGE 为主，未包含人工可读性、事实一致性或评论覆盖的人类评估；
  - 数据集 RA-MDS 不可由作者共享，复现实验需另行获取；
  - 方法是 extractive，不能生成源句子之外的新表达。

## 局限与未来工作

- 作者明确说明的局限/未来方向：
  - 将 CSMOCS 适配到 abstractive summarization；
  - 将 CSMOCS 适配到 compressive summarization；
  - 在不同性质的 evaluation scenarios 中测试；
  - 使用 parallel programming 改善 runtime，利用多核架构。
- 我们认为仍需确认的问题：
  - comment filtering 只基于文档高频 term，可能丢弃语义相关但词面不同的评论；
  - centroid 目标容易偏向主题词覆盖，可能不足以保证摘要连贯性和事实一致性；
  - repair 以删除低相关句子恢复长度，可能破坏上下文顺序或实体指代；
  - Pareto front 最终如何选单个摘要用于用户展示，论文主要报告最优结果但决策接口可继续细化；
  - 对 LLM 时代的 abstractive/reader-aware summarization，ROUGE 提升是否仍对应真实用户满意度需要再验证。

- 值得建立或补充的设计知识：

- 暂留在论文卡中的方法、原理或架构启发：
  - CSMOCS 的 host nest replacement 是一种局部 dominance 更新 + 双倍种群截断机制，可视为 cuckoo search 的 MOEA 化实现；
  - ROUGE 作为评价指标只用于实验，算法内部 objective 不直接优化 ROUGE；
  - comment filtering 的 5% 参数是经验选择，尚不独立建卡。
- 局部创新线索：
  - 用 sentence embedding/LLM embedding 替换 tf-isf，提高语义相关性；
  - 在 mutation score 中加入句子位置、实体覆盖、评论 stance 或 novelty；
  - repair 时同时考虑 sentence ordering 和 discourse coherence；
  - 用 MCDM 或 preference point 从 `NDS` 中选最终摘要。
- 结构创新线索：
  - reader-aware 摘要可形成通用 MOO 管线：source-content objective、reader-comment objective、redundancy objective、length/quality constraints、human-facing selector；
  - 将评论集换成用户查询、客服反馈、审稿意见或日志事件，也可得到“主文档 + 外部关注点”的多目标摘要器。
