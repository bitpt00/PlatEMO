# Large-Scale Sparse Multi-Objective Optimization via Customized Individual Learning

## 一句话理解

论文提出 SMOCIL：把 large-scale sparse MOP 的种群按“解质量”和“稀疏性”划成四类个体，再分别对过稠密的好解、稀疏但差的解、既差又稠密的解执行不同的 mask/dec 学习，使稀疏结构学习不再只依赖变量级评分，而能利用种群中不同个体的角色差异。

## 问题与动机

- 研究问题和场景：
  - Large-scale sparse multi-objective optimization problems (LSSMOPs)；
  - Pareto-optimal solutions 中大多数决策变量为 0；
  - 典型应用包括 feature selection、neural network training、sparse signal reconstruction、portfolio optimization；
  - 维度可到 hundreds 或 thousands，关键难点是同时识别少量 nonzero variables 并优化其取值。
- 现有算法为什么不足：
  - 作者观点：常规 NSGA-II、SPEA2 等 MOEA 不利用稀疏性，会在最终应为 0 的变量上浪费搜索预算；
  - 作者观点：SparseEA、MSKEA、S-ECSO、S-NSGA-II 等显式稀疏算子多关注变量级 sparsity prior；
  - 作者观点：MOEA/PSL、PM-MOEA、MOEADRL、EPMEA、SLMEA 等降维或模式挖掘方法能缩小搜索空间，但仍容易缺少个体级和种群级协作；
  - 作者观点：TELSO 引入 individual-level frequent itemsets，但不结合 variable-specific sparse priors，可能忽略低层变量重要性。
- 本文希望解决什么：
  - 在 sparse MOEA 中同时利用变量级先验和种群级结构；
  - 识别不同个体的搜索状态，而不是对全部个体使用同一稀疏更新规则；
  - 让高质量稀疏个体提供模板，让高质量但稠密个体定向减稀，让稀疏但低质量个体修正 mask 或 dec，让低质量稠密个体保持探索。

## 核心理念与算法流程

- 核心理念：
  - LSSMOP 个体不仅有 objective quality 差异，还有 sparsity state 差异；
  - 质量和稀疏性形成四象限，每个象限对应不同的学习需求；
  - P1 作为高质量高稀疏模板，P2/P3/P4 分别通过不同强度和方向的学习向 P1 区域靠近。
- 主要流程：
  1. 用 SparseEA 式单变量激活分析计算每个变量的 sparse prior score；
  2. 随机初始化 population，每个个体有 binary `mask` 和 real-valued `dec`；
  3. 每代按当前 sparsity threshold 和 solution quality 动态划分 P1/P2/P3/P4；
  4. 若 sparsity indicator `theta` 连续 `n` 代不变，跳过 sparsity-level adaptation，转为仅优化 `dec`；
  5. 对 P2/P3/P4 执行 customized individual learning，P1 保持为学习参考；
  6. 二元锦标赛选择父代，按 score-guided SparseEA-style mask update 和 SBX/PM 生成 offspring；
  7. 合并父代和 offspring 后环境选择保留 `N` 个体。
- 关键组成部分：
  - two-layer encoding：`mask_i in {0,1}^D` 控制稀疏结构，`dec_i in R^D` 负责实值收敛，实际解由两者组合；
  - variable score：用 `D x D` random `dec` 和 identity `mask` 逐变量评价，非支配排序 rank 作为变量 score，重复 5 次聚合；
  - quad-population partition：用 median sparsity 划分稀疏好/差，用 rank 1 或 fitness median 划分质量好/差；
  - customized individual learning：按 subgroup 匹配 mask learning、dec learning 或 sparsity-enhancing mutation；
  - switching parameter `n`：当种群稀疏水平稳定时减少对 mask 的干预，转向实值优化。
- 可能被修改的位置：
  - sparsity/quality threshold 可由 median 改为 quantile、reference-vector 局部阈值或自适应阈值；
  - P1 参考解选择可改为区域化 elite、HV contribution elite 或 uncertainty-filtered elite；
  - P2/P3/P4 学习强度可由固定规则改为基于成功率或多样性反馈的控制器；
  - 变量 score 可替换为双种群共识、掩码相似性、代理梯度或问题特定变量重要性。
- 必须保留的核心：
  - 同时用 sparsity 和 solution quality 刻画个体状态；
  - 不同象限采用不同学习策略，而不是对全部个体统一剪枝或统一学习；
  - P1 仅作为动态 elite reference，不应固定不变或永久冻结；
  - mask 更新仍需保留变量级先验，否则会退化为无约束的个体模仿。

## 实验证据

- 测试问题和对比算法：
  - Benchmark：SparseEA 提出的 SMOP1-SMOP8，PF 类型包括 linear、convex、concave，并覆盖 multimodality、deception、epistasis；sparsity parameter `theta=0.1`；
  - 维度：`D = {100, 500, 1000, 5000}`；
  - Real-world：neural network training、portfolio optimization、sparse signal reconstruction 等真实 LSSMOP；论文表述中同时出现 four classes 与 9 test cases，需按 Table II 谨慎引用；
  - Baselines：PMMOEA、SparseEA、MOEA/PSL、S-ECSO、TELSO、S-NSGA-II、DKCA，代码来自 PlatEMO 4.4；
  - Metrics：benchmark 用 IGD 和 10000 reference points；real-world 因 true PF unknown 用 HV；
  - 统计：30 independent runs，Wilcoxon rank-sum test，显著性 0.05；论文中 “+/-/=” 的方向是相对 SMOCIL 的 worse/better/similar，复述时需谨慎。
- 主要实验结论：
  - Benchmark Table I：SMOCIL 相比 PMMOEA、SparseEA、MOEA/PSL、S-ECSO、TELSO、S-NSGA-II、DKCA 分别在 19、26、28、27、28、16、18 个 32 test instances 上显著更好；
  - SMOP1、SMOP2、SMOP7 可视化中，SMOCIL 的 PF 分布和收敛更接近 true PF；
  - 收敛曲线显示 SMOCIL 初期 IGD 较高，原因是随机初始化；随后持续下降，而 SparseEA/TELSO 初期快但后期停滞；
  - 作者解释：TELSO aggressive mask learning 容易早期把个体推向高度稀疏或近零 mask，导致后期 diversity 和有效 offspring 生成能力下降。
- Real-world 证据：
  - Table II：SMOCIL 相比 PM-MOEA、SparseEA、MOEA/PSL、S-ECSO、TELSO、S-NSGA-II、DKCA 分别在 5、3、5、6、7、6、2 个 9 test cases 上显著更好；
  - NN3：不同 sparsity level 下训练误差更低，显示稀疏神经网络优化中的 accuracy-complexity trade-off 较好；
  - PO1：相比 DKCA 更均匀、连续地覆盖 Pareto front；
  - SR2：SMOCIL 在中等稀疏区 reconstruction loss 较低，但对高稀疏区域 coverage 不足，HV 因 objective span 较窄而弱于 SparseEA/DKCA。
- 消融或机制证据：
  - 去掉 P2/P3/P4 learning 的三个变体总体弱于完整 SMOCIL；
  - dual(sparsity)、dual(quality)、triple partition 均弱于 quad partition，说明单独按稀疏或质量分组不足；
  - triple variant 去掉了 high-quality but dense subgroup，性能仍不如 quad，说明 P2 的定向稀疏修正是关键；
  - `n in {5,10,20}` 中 `n=10` 最稳定，`n=5` 过早切换，`n=20` 过保守；
  - threshold quantile 中 50% median 综合最好，25% 有少数实例更好，75% 明显退化；
  - P3 中 dec-based learning probability 25/50/75 差异小，50% 作为默认平衡 mask correction 和 dec refinement。
- 证据边界：
  - SMOP4-SMOP6 上优势较弱，因为这些问题更强调达到目标稀疏比例，而不是识别具体关键变量位置；
  - 高维 SMOP3/SMOP8 受 deception 和 epistasis 影响，个体学习效果会下降；
  - Real-world Table II 的“four classes”和实际 9 cases 需要引用时说明；
  - runtime 对比只和 DKCA、SparseEA、PMMOEA 在 1000 维 SMOP 上比较，显示计算成本相近，但不是完整 wall-clock profiling。

## 局限与未来工作

- 作者明确说明的局限：
  - 对 solution quality 更依赖 desired sparsity pattern 而非 critical variable identification 的问题，SMOCIL 适应性仍需提高；
  - 在极高维环境中 robustness 和 scalability 仍需增强。
- 作者未来工作：
  - 改进 SMOCIL 对不同稀疏结构机制的适应性；
  - 增强极高维 LSSMOP 上的鲁棒性和可扩展性。
- 我们认为仍需确认的问题：
  - `fitness` 在所有算法框架中的定义和归一化方式需要复现代码确认；
  - P1 作为全局模板是否会压制服务于少数 PF 区域的稀有 mask pattern；
  - median threshold 在 many-objective 场景下可能遇到大量非支配和质量区分弱的问题；
  - 对强组合约束、mixed variables、discrete sparse decisions 是否需要 repair 或可行性保持；
  - P2/P3/P4 每代最多一次学习操作是否足以处理百万维稀疏问题。

  - 把 P1 改成按 reference vector/cluster 维护的局部 elite，避免全局模板抹平 PF 区域差异；

  - 将变量 score 换成双种群变量类型、Jaccard mask archive、surrogate uncertainty 或 problem-specific gradients；
  - 对 P3 的 mask/dec 选择概率用 bandit 或 reinforcement learning 控制；
  - 在高稀疏 coverage 不足时，为 P1/P2 增加极端稀疏 reference preservation。
