# Feedback-driven adaptive variable grouping for decomposition-based large-scale multiobjective optimization

## 一句话理解

论文提出 MOEA/D-FAVG：在 MOEA/D 中把变量分组从“一次性前处理”改成随搜索反馈更新的结构。算法先用低成本有限差分近似把变量分为 convergence-related 和 diversity-related，再用采样的二阶差分交互图把收敛变量分组；进化过程中，每个变量子组都有自己的性能指标 `eta_k`，一旦连续停滞就重新分类、拆分或合并子组。同时，每个子组按自身状态选择 exploitation 或 exploration 算子，避免所有变量组使用同一固定算子。

## 问题与动机

- 研究问题：
  - LSMOP 可能有数百到数千个变量，搜索空间随维度指数膨胀；
  - 决策变量分析能把变量按 convergence/diversity 角色分解，但经典方法成本高；
  - 变量作用和交互会随种群接近 PF 而变化，一次性分组容易后期失效；
  - 不同变量子组需要不同算子，固定统一繁殖会浪费搜索能力。
- 现有方法为什么不足：
  - MOEA/DVA、LMEA 等 perturbation-based DVA 通常需要 `O(D*N)` 级额外评价；
  - 固定变量分组无法适应动态 landscape；
  - 单目标动态 regrouping 多按固定间隔或全局贡献分数触发，不能处理 MOO 中 convergence 与 diversity 的双目标；
  - population-level adaptive operator selection 不区分不同变量子组的优化角色。
- 本文希望解决什么：
  - 把变量分析成本降到 `O(D)` 加采样交互检测；
  - 用 subgroup-level performance feedback 判断是否需要重分组；
  - 将 regrouping 作为低频结构调整，将 operator selection 作为高频逐代决策；
  - 在 200 到 5000 维 LSMOP/DTLZ 上提高 IGD/HV，并保留更多评价预算用于真正优化。

## 核心模型与算法流程

- 初始变量分类：
  - 参考解 `x_r` 不是单个最优解，而是按 scalarized fitness 排名前 `ceil(N/5)` 个解的 centroid；
  - 对每个变量做一次有限差分，估计其对各目标的平均敏感度 `delta_i`；
  - 将 `{delta_i}` 归一化后用 `k-means(k=2)` 聚类为高敏感 `V_con` 和低敏感 `V_div`；
  - `k-means` 重启 `R_km=10` 次，取 within-cluster sum of squares 最小者；
  - 分类成本为 `D` 次额外函数评价。
- 收敛变量交互检测：
  - 对 `V_con` 中变量对 `(i,j)` 用二阶有限差分估计交互强度 `phi_ij`；
  - 若 `phi_ij > epsilon`，认为变量相互作用，并在 interaction graph 中连边；
  - 只随机采样 `rho_s * |V_con|(|V_con|-1)/2` 个变量对，默认 `rho_s=0.3`；
  - 对检测到的边做 transitive closure，connected components 形成 convergence-related subgroups；
  - 作者声称交互检测成本可从 `O(|V_con|^2)` 降至 `O(|V_con| log |V_con|)`。
- Feedback-driven regrouping：
  - 对每个子组 `G_k` 计算复合性能指标：
    `eta_k(t)=alpha*Delta_k(t)+(1-alpha)*Sigma_tilde_k(t)`；
  - `Delta_k` 是过去观察窗口中的平均 Tchebycheff scalarized fitness 相对改善；
  - `Sigma_tilde_k` 是变量子空间中 size-normalized diversity；
  - 若 `eta_k < tau` 持续 `W_r` 个观察窗口，则认为该子组 stagnated；
  - 触发后重新用当前种群重算 `x_r`、`delta_i`、`V_con/V_div` 和采样交互图；
  - 对停滞子组，若 `|G_k| > S_max` 则基于组内交互重新拆分，若 `|G_k| < S_min` 则与交互最高的相邻子组合并；
  - 更新 context vectors 到当前 best solutions，重置 stagnation counters。
- Group-level adaptive operator selection：
  - exploitation pool：高分布指数 SBX/PM、低步长 DE，适合局部精修；
  - exploration pool：低分布指数 SBX/PM、与子组多样性成比例的 Gaussian mutation，适合全局探索；
  - 对收敛相关子组，用 sigmoid 规则选择 exploitation pool：
    `p_k(O_E)=1/(1+exp(-beta*(eta_k(t)-tau)))`；
  - `eta_k > tau` 时子组进展良好，偏 exploitation；
  - `eta_k < tau` 时子组停滞，偏 exploration；
  - diversity-related variables 始终用 exploration-oriented operator，在变量边界内按当前目标空间分布加权采样。
- MOEA/D-FAVG 总流程：
  - 初始化 MOEA/D 种群、权重向量、邻域和参考点；
  - 做初始变量分类和交互分组；
  - 每代遍历变量子组，按 `eta_k` 选择算子池；
  - 只对子组维度应用算子，其他维度用 context vector 固定；
  - 用 Tchebycheff scalarization 和 MOEA/D elitist replacement 更新邻域解；
  - 每 `W` 代调用 feedback regrouping；
  - 达到 FEmax 后返回最终种群。
- 复杂度：
  - 初始变量分类 `O(D)` FEs；
  - 采样交互检测 `O(|V_con| log |V_con|)`；
  - 每次重分组额外 `O(D)`；
  - 典型 `D=1000, N=100, K≈10, R<=12` 时，分类和重分组阶段最多消耗约 13% 预算；
  - 实验统计中 `D=1000, M=2, FEmax=100000` 时，初始分析 1.2%，含全部重分组共 3.8%。

## 实验证据

- 实验设置：
  - benchmark：LSMOP1-9 和 DTLZ1-7；
  - 目标数 `M=2/3`；
  - 变量维度 `D=200, 500, 1000, 2000, 5000`；
  - 真实应用：large-scale cloud computing resource scheduling，同时最小化 total execution cost 和 makespan；
  - baseline 9 个：MOEA/DVA、LMEA、WOF、LSMOF、CCGDE3、DGEA、LERD、TPEA、LSMOEA/D；
  - PlatEMO 4.6，2 目标人口 `N=100`，3 目标人口 `N=105`；
  - `D<=1000` 时 FEmax=100000，`D>1000` 时 FEmax=200000；
  - 每个算法独立运行 30 次，Wilcoxon rank-sum test 显著性水平 0.05。
- 默认参数：
  - `T=20`；
  - `h=1e-6`；
  - interaction threshold `epsilon=1e-3`；
  - sampling ratio `rho_s=0.3`；
  - `alpha=0.5`；
  - observation window `W=20`；
  - patience `W_r=3`；
  - regrouping threshold `tau=0.01`；
  - `S_min=5`，`S_max=100`；
  - sigmoid sharpness `beta=10`；
  - `k`-means restarts `R_km=10`。
- LSMOP 结果：
  - 2 目标 LSMOP1-9、五个维度的 45 个设置中，MOEA/D-FAVG 的 IGD 全部最好或与最佳相当；
  - 相对 TPEA 和 LSMOEA/D，MOEA/D-FAVG 分别在 43/45 和 40/45 个 LSMOP 实例上 IGD 显著更好；
  - 优势随 `D` 增大更明显，作者归因于 feedback regrouping 在高维下保持分组有效性。
- DTLZ 结果：
  - `M=2, D=1000` 的 DTLZ1-7 上，MOEA/D-FAVG 全部取得最低 IGD；
  - DTLZ1 和 DTLZ3 这类 multimodal landscape 上优势更明显。
- HV 与可视化：
  - LSMOP1/5/9 的 HV 子集表中 MOEA/D-FAVG 在 9 个设置中均最佳；
  - Pareto front 图显示 MOEA/D-FAVG 更接近真实 PF 且分布更均匀；
  - 收敛曲线显示在 LSMOP1/5/7/9 上达到最低 median IGD。
- 消融：
  - `FAVG-static` 只有初始梯度分类，无动态组件，表现最弱；
  - `FAVG-noAOS` 去掉组级算子选择后退化；
  - `FAVG-noFB` 去掉 feedback regrouping 后退化，尤其 LSMOP9；
  - Table 7 中完整算法在 LSMOP1/3/5/7/9 的 `D=1000, M=2` 全部最低 IGD；
  - `R_km=10` 的多重 `k`-means 重启把 LSMOP3 的 IGD 标准差从 `4.2e-2` 降到 `1.8e-2`。
- 开销：
  - `D=1000, M=2, FEmax=100000` 时，MOEA/DVA/LMEA/LERD 的变量分析开销分别为 18.7%、14.2%、8.5%；
  - MOEA/D-FAVG 初始分析 1.2%，含所有 regrouping 总计 3.8%；
  - 作者强调这些开销已从同一 FEmax 中扣除，仍留下 96.2% 用于主优化。
- Regrouping 动态：
  - LSMOP1 完全可分，触发约 4 次 regrouping；
  - LSMOP9 非可分且 PF disconnected，触发约 12 次 regrouping；
  - 说明 regrouping 频率随问题交互复杂性增加。
- 参数灵敏度与统计：
  - `rho_s=0.1` 时因漏掉真实交互而明显退化，`rho_s>=0.2` 后较稳定；
  - `W=20`、`tau=0.01`、`alpha=0.5` 在 LSMOP5/9 上近似最优；
  - Friedman test 拒绝同分布假设，`p<0.001`；
  - `D=1000, M=2` 的 LSMOP1-9 上，MOEA/D-FAVG 平均 rank 最好：IGD 1.11，HV 1.22。

## 局限与未来工作

- 作者明确局限：
  - gradient-approximation classification 假设目标函数局部足够平滑；
  - nonsmooth 或 discontinuous landscapes 需要 zeroth-order approximation 或 surrogate-assisted gradient estimation；
  - regrouping 仍依赖预设阈值，未来可用 RL 或 meta-learning 做 parameter-free 控制；
  - 当前子组顺序优化，未来可做 parallel/asynchronous subgroup optimization；
  - 需要更多 NAS、大规模 VRP、结构拓扑优化等工程验证。
- 我们认为仍需谨慎的问题：
  - `D=5000` 下仍用有限差分和采样交互，变量相互作用非常密集时 transitive closure 可能产生大组；
  - `k=2` 把变量只分成 convergence/diversity 两类，可能难表示 objective-specific 或 region-specific roles；
  - `eta_k` 使用平均 Tchebycheff 改善与子空间多样性，可能被少数困难子问题或尺度归一化影响；
  - diversity variables 始终 exploration，后期是否错过 diversity variables 的局部精修仍需验证；
  - 主文没有展开云计算调度实验的完整表格，真实应用证据细节不足。
