# A Review of Surrogate-Assisted Evolutionary Multi-Objective Optimization

## 一句话理解

这是一篇 SAMOEA 综述，覆盖约 300 篇文献。核心贡献不是提出新算法，而是给昂贵多目标优化建立一套设计地图：先按问题属性识别 objective structure、variable type、constraint/dynamic 和 data/knowledge setting，再选择 surrogate management、infill criteria 和 acceleration mechanisms，最后针对 multimodal、heterogeneous objectives、transfer learning、preference、RL、decomposition、inverse modeling 等特殊场景定制框架。

## 综述定位与贡献

- 研究对象：
  - expensive multi-objective optimization problems；
  - surrogate-assisted multi-objective evolutionary algorithms；
  - 核心矛盾是真实 objective function evaluations 昂贵，而 MOEA 需要大量候选评价。
- 综述必要性：
  - 早期综述偏重 surrogate construction；
  - 部分综述偏 data-driven modeling 或 machine learning enhanced metaheuristics；
  - expensive single-objective optimization 综述对 multi-objective 适用性有限；
  - 最近五年 SAMOEA 中出现 many-objective、mixed-variable、transfer learning、RL、LLM、privacy 等新趋势，需要更新总览。
- 主要贡献：
  - 约 300 篇文献；
  - 给出按 problem attributes 和 algorithmic design models 的层级分类；
  - 讨论基础框架、评价指标、代理模型管理、infill criteria、加速机制；
  - 总结特殊场景：multimodal、heterogeneous objectives、transfer learning、preference incorporation、RL、decomposition、inverse modeling；
  - 汇总 benchmark 和真实工程应用；
  - 提出未来方向：robust surrogate、parallel/distributed、LLM-assisted、privacy-preserving、theory。

## SAMOEA 基础框架

- Initialization：
  - 用 random sampling、orthogonal sampling、Latin hypercube sampling 等生成初始候选；
  - 经过真实 evaluation 填充初始数据集；
  - 数据集用于训练初始 surrogate，并 warm-start evolutionary search。
- Surrogate model optimization：
  - 包括模型构建、预测、验证和更新；
  - 可用一个或多个 surrogate 预测 objective、indicator、constraint 或 dominance relation；
  - small data 下常用 cross-validation 检查模型质量；
  - online 场景中 surrogate 随新真实评价样本更新，offline 场景中 surrogate 可能固定。
- Evolutionary search：
  - 从数据集选择非支配且分布较好的 parent population；
  - 用 crossover/mutation 或模型生成器产生 offspring；
  - surrogate 估计 fitness 或 dominance relationships；
  - 通过 infill criteria 或 environmental selection 选择少量 promising individuals 做真实评价。
- Termination：
  - 评价预算耗尽；
  - 达到目标质量；
  - population 收敛；
  - 输出数据集中的非支配解。

## 评价指标体系

- Solution quality：
  - convergence、diversity 和 comprehensive indicators；
  - 包括 Spacing、Spread、HV、IGD、IGD+、SDE、Delta_p、epsilon+。
- Model performance：
  - static accuracy：RMSE、R2；
  - ranking consistency：rank correlation；
  - cumulative utility：IGD/FEs curve、AUC；
  - 该综述强调模型指标不能只看点预测误差，还要看排序和优化效用。
- Computational efficiency：
  - Objective Call；
  - Total Elapsed Wall-Clock Time；
  - Evaluation-Computation Ratio；
  - Real FEs to Target Quality；
  - Unit Time Solution Quality；
  - 关键是区分真实评价节省与 surrogate 训练/管理开销。

## 问题属性分类

- Objective space：
  - coupled vs decoupled objectives；
  - multi-objective vs many-objective；
  - regular vs irregular PF；
  - decoupled objectives 需要处理异步、部分评价和预算调度；
  - EMaOP 面临 dominance resistance、surrogate scalability 和 indicator complexity；
  - irregular PF 会放大 model bias 和 data sparsity。
- Decision variable space：
  - continuous、discrete、mixed variables；
  - high-dimensional variables，综述中以 50 维以上作为 HEMOP 讨论点；
  - small-scale vs large-scale search spaces；
  - mixed/discrete 场景常用 random forest、Bayesian forest、BNN、special kernels、distance metrics、distribution estimation。
- Dynamics and constraints：
  - CEMOP 中 feasible region fragmented，constraint surrogate errors 会直接误导可行性；
  - DEMOP 中 objectives、constraints 或参数随时间变化，要求在稀疏数据下快速重建可靠 surrogate；
  - 动态场景需要 transfer、data augmentation、manifold transfer、history reuse，同时避免 negative transfer。
- Augmented optimization methods：
  - online/offline data-driven optimization；
  - knowledge-incorporated optimization；
  - structured domain knowledge、physical laws、expert heuristics 和 spatial constraints 可缓解 sparse data。

## 算法设计组件

- Surrogate management：
  - regression-based models：GP/Kriging、RBF、NN、ELM、ensemble regression；
  - classification-based models：SVM、NN、fuzzy classifier、KNN，用于 pre-screening、active learning、archive management；
  - relation-based models：学习 dominance、rank、pairwise preference，可把 `n` 个评价样本扩展为 `O(n^2)` pairwise relations；
  - hybrid models：组合 regression、classification 和 relation-based models，兼顾预测精度、scalability 和 Pareto consistency。
- Infill criteria：
  - regression surrogate 常配 EI、PI、UCB/LCB、EHVI、HV-based criteria、adaptive normalization、reference-vector strategies；
  - classification surrogate 常用 class probability、decision boundary、sparse-region sampling；
  - relation surrogate 关注 ranking uncertainty、dominance violation、inconsistent relations；
  - 综述强调 infill 必须随 surrogate type、problem characteristic 和 optimization stage 联动。
- Acceleration mechanisms：
  - decomposition、multi-population、collaborative frameworks；
  - problem partitioning、transformation、additive kernels、tree-structured Parzen estimators；
  - learning PS/PF、Pareto set learning、Pareto active learning、sparse sampling from predicted PF；
  - manifold-based offspring、Bezier/simplex models、invariant variation operators；
  - knowledge transfer 和 low-fidelity information 用于 warm start。

## 特殊场景设计要点

- Multimodal SAMOEAs：
  - surrogate 容易模糊多个 equivalent PS；
  - 需要 local/ensemble surrogate、clustering modeling、relation-based surrogate 和 decision-space diversity。
- Heterogeneous objectives and constraints：
  - 目标尺度、uncertainty、evaluation time 和 physical coupling 不同；
  - 需要 objective-wise modeling、balanced sampling、multi-granularity surrogates、constraint-aware learning。
- Transfer learning based SAMOEAs：
  - 利用历史任务、低保真模型或相关领域数据初始化或增强 surrogate；
  - 关键风险是 source-target mismatch 和 negative transfer。
- Preference incorporation SAMOEAs：
  - 将 DM preference 用于 surrogate modeling、infill、operator 或 ROI focus；
  - 风险是 preference 不确定、动态变化和 PF diversity 丢失。
- RL-based SAMOEAs：
  - RL 可控制 offspring generation parameters、surrogate selection、operator scheduling、infill sampling；
  - state 可包括 surrogate uncertainty、population diversity、convergence indicators。
- Decomposition-based SAMOEAs：
  - 用 scalar subproblems 降低 surrogate modeling complexity；
  - 可并行构建 localized surrogate；
  - 风险是 reference vector 固定、subproblem data sparse、objective dependency 和 uneven difficulty。
- Inverse modeling SAMOEAs：
  - 学习 objective space 到 decision space 的 inverse mapping；
  - 可直接生成 promising candidates；
  - 难点是一对多映射、multi-modal inverse、constraint-aware validity 和 forward surrogate validation。

## 应用综述

- Benchmark：
  - ZDT、DTLZ、WFG、LSMOP、MaF、improved DTLZ、inverted DTLZ 等；
  - 真实测试套件覆盖 vehicle structure、aircraft conceptual design、industrial processes、robot trajectory 等。
- 真实应用域：
  - building design；
  - compressor design；
  - battery design；
  - motor design；
  - robotics；
  - neural architecture search；
  - molecular design；
  - chemical process。

## 未来方向

- More efficient and robust surrogate models：
  - BNN、deep GP、conditional neural process；
  - faster kernels、trust-region modeling、multi-fidelity co-Kriging、heteroscedastic GP、ensemble diversification。
- Parallel and distributed frameworks：
  - 并行 surrogate training、parallel infill、distributed EA；
  - 重点问题是 task scheduling、asynchrony、model consistency、decentralized IoT-like settings、secure lightweight communication。
- LLM-assisted SAMOEAs：
  - LLM 可用于 initial population、crossover/mutation guidance、fitness surrogate/classification、adaptive optimizer、synthetic data、denoising 和 feature extraction；
  - 需要系统 benchmark、可靠性、可复现性和可解释性。
- Privacy-preserving SAMOEAs：
  - federated learning 允许多方训练 local surrogates 而不共享 raw data；
  - differential privacy 可对 evaluations、predictions 或 generated samples 加噪；
  - 关键 trade-off 是隐私保护与优化精度。
- Theoretical analysis：
  - 需要从 Bayesian optimization、regret analysis、PAC bounds、information-theoretic analysis 中吸收工具；
  - 关键问题是 surrogate bias 如何影响 evolutionary operators、selection 和 archive convergence。
