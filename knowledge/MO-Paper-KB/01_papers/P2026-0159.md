# An adaptive two-stage multi-population coevolutionary framework for constrained multi-objective optimization

## 一句话理解

论文提出 ATMC：一个三种群、两阶段的复杂 CMOP 框架。Stage I 中探索种群 `P1` 和引导收敛种群 `P2` 都忽略约束，尽快覆盖 UPF；可行开发档案 `P3` 同时保留高质量可行解。Stage II 在动态收缩的 `epsilon` 约束松弛下，让 `P2` 通过 reference vector-guided hierarchical priority selection 从 UPF 沿各个方向均匀靠近 CPF；如果 `P1` 的无约束搜索贡献有限，则按 UPF/CPF 重叠信号暂停它，把预算转给引导收敛和可行解开发。

## 问题与动机

- 研究问题：
  - CMOP 同时要求 convergence、feasibility 和 diversity；
  - 复杂约束会使 CPF 与 UPF 严重分离，可行域狭窄、断裂或带欺骗性；
  - 许多 CMOEA 过度偏好可行非支配解，提前丢弃仍有方向价值的不可行解；
  - 种群容易聚集到最早发现的 CPF 局部片段，错过其他方向上的可行片段。
- 现有方法为什么不足：
  - CDP、penalty 等单一 search behavior 对可行性压力过强，临时不可行但方向好的解会被淘汰；
  - PPS、C3M、DEST、MOEA/D-DAE 等多阶段方法能先追 UPF 再拉回 CPF，但可能缺少全局方向组织，覆盖不均；
  - CCMO、C-TAEA、CMOEA-CD、BiCo 等多种群方法能分工探索和开发，但资源分配和信息交互设计不当会造成干扰或方向聚集；
  - CMOEMT、MTCMO、CMOEA-CDT 等多阶段多种群方法更灵活，但组件和参数较多，仍可能在约束松弛到严格约束的过渡期失去方向多样性。
- 本文希望解决什么：
  - 用双条件 stage transition 避免过早结束 UPF 探索；
  - 用三种群把全局无约束探索、UPF-to-CPF 引导和可行解开发拆开；
  - 用参考向量逐方向选择，保证每个方向都有代表解，不让易可行方向吞掉预算；
  - 通过 adaptive stopping 暂停贡献小的探索种群，减少后期无约束信息干扰。

## 核心模型与算法流程

- 三个种群：
  - `P1` exploration population：独立做 unconstrained exploration，并作为 Stage I 是否收敛的监测对象；
  - `P2` guided convergence population：Stage I 与 `P1` 一起忽略约束靠近 UPF；Stage II 在动态 `epsilon` 和 HPS 作用下从 UPF 均匀靠近 CPF；
  - `P3` feasibility-exploitation archive：全程考虑约束，积累和开发高质量可行解，并作为最终输出。
- Stage I：
  - `P1` 和 `P2` 无约束评价；
  - `P3` 约束感知评价；
  - 三个种群的 offspring 合并为统一候选池；
  - `P1/P2` 使用 SPEA2 式无约束环境选择，`P3` 使用约束环境选择；
  - `P2` 用 boundary-enhanced DE 生成更密的 UPF 边界和稀疏区域解。
- Stage transition：
  - 滑动窗口长度默认 `G=100`；
  - Stability Condition：每个目标过去 `G+1` 代标准差小于 `tau_std=0.5`；
  - Stagnation Condition：每个目标均值相邻代变化的平均绝对值小于 `tau_mean=0.01`；
  - 只有所有目标同时满足稳定和停滞，`flag` 才从 0 切到 1；
  - 切换后 `epsilon_k` 初始化为 `P2` 中不可行个体的平均 CV；
  - 计算 `P1` 非支配解中的可行比例 `rf`，作为 UPF 与 CPF 重叠程度 proxy；若 `rf < beta=0.5`，则 `continue=false`，暂停 `P1`。
- Dynamic `epsilon` relaxation：
  - Stage II 中 `epsilon_{k+1}=(1-tau)*epsilon_k`；
  - 默认 `tau=0.005`；
  - `epsilon` 逐步收缩，让每个参考方向上的候选从 UPF 平滑靠近可行区。
- Boundary-enhanced DE：
  - `P2` 识别 boundary solutions，并优先把边界个体作为 base vectors；
  - 参数 `delta` 在局部邻域搜索与全局随机搜索之间切换；
  - 默认生成 `NDE=N/3` 个 `P2` offspring；
  - 作用是让 Stage I/II 中 `P2` 比 `P1` 获得更密、更完整的 UPF 或边界覆盖。
- Hierarchical Priority Selection (HPS)：
  - 对候选集合 `S` 先分三层：
    - `SRank1`：`epsilon` 可行层中在 `(M+1)` 维，即 objectives + CV 上非支配的 elite solutions；
    - `SRank2`：`CV <= epsilon_k` 的 `epsilon`-feasible solutions；
    - `SRank3`：`CV > epsilon_k` 的 infeasible solutions；
  - 生成 `N` 个 uniform reference vectors，按最小相邻角距离 `h` 定义每个方向邻域；
  - 对每个参考向量 `w_i`，从尚未被选过的可用解中依次查找 `SRank1 -> SRank2 -> SRank3`，优先选角距离最小者；
  - 若该方向没有可用候选，则从全局非支配集 `S2` 中选角距离最小者作为 fallback；
  - 已选解会从 `S_available` 移除，避免同一个解占用多个方向。
- 最终输出：
  - relaxed infeasible solutions 只用于方向引导；
  - 最终解集只来自 `P3`，避免松弛不可行解污染最终可行性。
- 复杂度：
  - `P2` second-stage offspring generation 需要 pairwise distance 和邻域构造，约 `O(N^2 M)`；
  - HPS 中 `(M+1)` 维非支配排序和角度计算约 `O(MN^2)` 与 `O(N^2M)`；
  - 每代主导复杂度为 `O(N^2M)`，与许多分解或支配型 CMOEA 同阶，但常数开销来自跨种群合并、去重、archive 和逐方向 HPS。

## 实验证据

- 实验设置：
  - benchmark 共 49 个问题：LIRCMOP 14 个、DASCMOP 9 个、ZXH_CF 16 个、CF 10 个；
  - 真实问题 7 个：DBD、GTD、MBP、PSP，以及 SPWM5、SPWM9、SPWM13；
  - baseline 11 个：APSEA、PPS、MOEA/D-DAE、CCMO、C3M、CMOEMT、MTCMO、CMEGL、URCMO、MTOTC、CMOEA-CD；
  - PlatEMO / MATLAB R2022a，独立运行 30 次；
  - DASCMOP、CF、ZXH_CF 最大评价 `1e5`，LIRCMOP 最大评价 `3e5`；
  - 指标为 IGD 和 HV，统计检验为 Wilcoxon rank sum test，显著性水平 `0.05`；
  - 主要默认参数：`tau=0.005`，`G=100`，`rf=0.5`，`NDE=N/3`。
- Benchmark 汇总：
  - 在 LIRCMOP 上，ATMC 在 14 个实例中 12 个达到最好，作者归因于 dynamic `epsilon` 与 HPS 对窄可行区和大不可行区的协同；
  - 在 DASCMOP 上，ATMC 综合优势明显，但单个问题上 URCMO、CMEGL、CMOEA-CD 有局部胜出；
  - 在 ZXH_CF 上，ATMC 在 16 个实例中 8 个排名第一，整体显著优于多数算法；
  - 在 CF 上，ATMC 取得 10 个实例中的 4 个最佳；CF8/CF9 上不占优，原因是探索种群在有限预算内未满足切换条件，三种群持续并行消耗预算。
- 全局统计：
  - Table 2 汇总相对 11 个 baseline 的 `+/-/=`，ATMC 在多数比较中显著更好；
  - 改进 Friedman test 中 ATMC 的平均排名最低：IGD 为 `2.24`，HV 为 `2.17`；
  - 第二名 CMOEA-CD 的 IGD/HV 平均排名分别为 `3.96` 和 `4.01`。
- 可视化与机制解释：
  - LIRCMOP12 中只有 CMOEA-CD 和 ATMC 找到全部 CPF 片段，ATMC 数值上更优；
  - DASCMOP2 的方向偏置修正图显示 Stage II 可从切换时的聚集分布扩展到 CPF 均匀覆盖。
- 消融实验：
  - ATMC-S1 去掉 exploration population stopping，完整 ATMC 在 IGD/HV 上分别为 `2/27/20`、`2/30/17`，说明停止无约束探索整体有益；
  - ATMC-S2 去掉 HPS 三层优先分层，完整 ATMC 在 19 个问题 IGD 更好，优势问题通常差一到多个数量级；
  - ATMC-S3 用普通 DE 替代 BDE，完整 ATMC 在 22 个问题 IGD 更好，说明边界增强与 HPS/P3 有协同；
  - ATMC-S4 去掉 HPS 中 angle-based direction guidance，完整 ATMC 在 38 个问题 IGD 更好，是最强消融证据；
  - ATMC-S5 去掉独立 exploration population，完整 ATMC 在 18 个问题 IGD 更好、27 个相当，说明三种群对鲁棒性有贡献。
- 参数灵敏度：
  - `G` 和 `rf` 在测试范围内不敏感；
  - `NDE` 增大到 `N/2`、`2N/3` 或 `N` 会明显退化，说明过多预算给 `P2` 会挤压其它种群；
  - `tau` 到 `0.012` 内较稳健，但过快收缩会提前排除桥接断裂可行域的不可行解。
- 真实问题：
  - 真实问题只用 HV，因为未知 CPF 无法算 IGD；
  - 参考集由所有算法所有运行得到的 feasible nondominated solutions 合并构造；
  - ATMC 在 7 个真实问题上均取得最高 mean HV；
  - SPWM5/9/13 随 inverter level 增大仍保持稳定，作者以此支持其工程可扩展性。

## 局限与未来工作

- 作者明确局限：
  - 仍依赖手动参数，例如 `tau`、`G`、`rf` 和 `NDE`；
  - 需要引入 adaptive control mechanisms 降低人工调参；
  - 后续计划扩展到 many-objective 和 multi-task optimization。
- 作者讨论中的不足：
  - 静态 reference vectors 在大不可行区或 CPF 缺口方向上可能浪费计算资源；
  - CF8/CF9 等问题中 stage transition 未在有限预算内触发，导致三种群长期并行、效率下降；
  - HPS、跨种群合并、去重和 archive 维护带来较大常数开销。
- 我们认为仍需谨慎的问题：
  - `rf` 只看 `P1` 非支配解可行比例，作为 UPF/CPF overlap proxy 较粗；
  - stability/stagnation 基于目标值统计，不能直接判断 CPF 覆盖是否充分；
  - `epsilon` 初始化为 `P2` 不可行解平均 CV，若 CV 分布长尾，收缩起点可能偏高；
  - HPS fallback 可能重复选择全局非支配解，虽保证方向有代表，但也可能弱化真正空方向探索；
  - 真实问题只用 HV，缺少对 feasibility discovery rate、覆盖均匀性和收敛性的分解分析。

- 与已有设计知识的边界：
  - 不同于 [约束边界远距不可行辅助引导](../02_design_knowledge/K-boundary-distant-infeasible-auxiliary-guidance.md)，本文不是在不可行边界上按“近边界且远离主群”筛选，而是每个参考方向按三层优先级选代表；
  - 不同于 [UPF 参照的动态逃逸种群](../02_design_knowledge/K-upf-referenced-dynamic-escaping-population.md)，本文不保留 second-best/worst 做逃逸速度控制，而是用 HPS 和 dynamic `epsilon` 做 UPF-to-CPF 映射；
  - 不同于 [有限状态机驱动的多阶段 CMOEA 策略调度](../02_design_knowledge/K-fsm-event-driven-multistage-cmoea-scheduling.md)，本文没有四状态 FSM，而是双条件二阶段切换和探索种群暂停；
  - 不同于 [约束难度加权的多辅助种群资源分配与合并](../02_design_knowledge/K-constraint-difficulty-weighted-auxiliary-resource-merging.md)，本文不按约束维度建辅助群，而是按搜索角色建 `P1/P2/P3`；
  - 不同于 [自适应 ε 支配与网格档案的多目标蜂群搜索](../02_design_knowledge/K-adaptive-epsilon-grid-archive-moabc.md)，本文的 `epsilon` 是 CV 松弛边界，并与参考向量 HPS 绑定，不是普通目标空间 ε-dominance 档案。
- 暂留在论文卡中的方法、原理或架构启发：
  - BDE 来自 CMOEMT 文献，本卡不单独抽为新知识；
  - `tau/G/rf/NDE` 的具体默认值先作为 ATMC 复现参数，不单独进入通用参数卡；
  - improved Friedman test 和 HV 参考集构造属于实验评价细节，暂不抽卡。
- 局部创新线索：
  - 用 direction-wise contribution 或 per-reference feasible hit rate 替代全局 `rf`，决定是否暂停 `P1`；
  - 让 `epsilon` 对每个 reference vector 单独收缩，难方向慢收缩，易方向快收缩；
  - 用 adaptive reference vectors 或 learned CPF gap detector 关闭长期无贡献方向，减少静态方向浪费；
  - 在 HPS 中加入 uncertainty 或 surrogate feasibility probability，减少对真实 CV 的长尾敏感。
- 结构创新线索：
  - 构建“UPF map -> direction-wise relaxed bridge -> feasible archive output”的 CMOP 通用框架：
    `unconstrained scout + guided bridge + feasible archive + per-direction priority selector`；
  - 将 HPS 嵌入其它 CMOEA 的辅助种群环境选择中，替代普通 CDP、crowding 或 angle-only selection；
  - 在动态 CMOP 中，把 stage transition 触发后的 `P1` 作为变化监测器，环境变化时重新激活；
  - 在 many-objective CMOP 中用稀疏 reference vector、R2 contribution 或 manifold reference directions 替代均匀静态 reference vectors。
