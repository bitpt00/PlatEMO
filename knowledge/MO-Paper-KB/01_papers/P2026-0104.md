# 区间分式多目标问题的双射实空间变换与库存模型验证

## 一句话理解

论文把带区间系数的单目标/多目标分式优化问题放入广义区间向量空间，通过可调双射映射 `psi` 定义区间序关系，并用倒数辅助变量把区间分式目标转化为可由常规多目标优化器求解的实值多目标规划。

## 问题与动机

- 研究问题和场景：处理目标函数、约束或二者的系数都以闭区间表示的 fractional optimization，尤其是具有多个冲突比值目标的 multiobjective interval fractional optimization problem（MIFOP）。
- 应用场景：需要比较多个比率型指标且参数不精确的决策问题，如利润/成本、收益/风险、运输/损耗、资源效率，以及库存管理中的利润与持有/缺货成本权衡。
- 问题特征：
  - 目标是区间值而不是单一实数，区间之间的比较必须先定义序关系；
  - 分式目标中分子和分母都可能含区间参数；
  - 多目标情况下每个区间分式目标会带来上下界、偏好和可行性的一致性问题；
  - 若直接用传统区间算术或参数积分，可能计算复杂、序关系不稳定，甚至得到 improper interval 或不可行解。
- 现有算法为什么不足（作者观点）：
  - 一些 interval fractional optimization 方法更偏重求解步骤，没有严格建立解存在性；
  - 部分方法不能保持区间边界内的序关系，得到的最优解可能落在可行域外；
  - nonlinear IFOP/MIFOP 仍较开放，既有方法常依赖多重积分或复杂映射；
  - Costa、Li、Sahu 等 generalized interval vector space 工作主要覆盖 IOP/MIOP，没有扩展到 interval fractional problems。
- 本文希望解决什么：用广义区间向量空间和双射实空间映射，为 IFOP/MIFOP 建立可比较、可证明有效解等价、能接入常规多目标求解器的统一变换框架。

## 核心理念与算法流程

### 核心理念

把区间值目标先放入扩展区间空间 `Omega`，用双射 `psi: Omega -> R^2` 把区间变成实数对，并用实空间偏序诱导区间偏序；再对分式目标引入分母倒数辅助变量，把区间分式目标变成区间乘积目标；最后在 `psi` 空间中求解普通 bi-objective 或 multiobjective programming problem。

### 关键流程

1. 扩展区间空间：
   - 普通 proper interval 不能构成向量空间，因为缺少加法逆元；
   - 作者采用 `Omega = I(R) union I(R)`，把 proper 与 improper intervals 都纳入广义区间向量空间；
   - `Omega^n` 作为 n 维广义区间向量空间，后续与 `R^{2n}` 建立对应。
2. 定义双射映射：
   - `psi([a1,a2]) = (lambda a1 + (1-lambda)a2, mu a1 + (1-mu)a2)`，其中 `lambda, mu in [0,1]` 且 `lambda != mu`；
   - 对 `Omega^n`，逐分量定义 `psi=(psi_1,...,psi_n): Omega^n -> R^{2n}`；
   - 区间序 `<=_psi` 由 `psi` 映射后的实空间逐分量偏序诱导。
3. 单目标 IFOP 变换：
   - 若 `F(x)=[f1(x),f2(x)]`、`G(x)=[g1(x),g2(x)]` 且 `0<g1<=g2`，则区间比值写为 `[f1/g2, f2/g1]`；
   - 引入 `v1=1/g1(x)`、`v2=1/g2(x)`；
   - 原 IFOP 变为带辅助变量的 interval optimization problem：`[f1(x)v2, f2(x)v1]`；
   - 再经 `psi` 变成二目标实值 BOP。
4. 多目标 MIFOP 变换：
   - 对第 `i` 个区间分式目标引入 `v_i1=1/g_i1(x)`、`v_i2=1/g_i2(x)`；
   - 每个区间目标经 `psi_i` 变成两个实值目标；
   - n 个区间分式目标最终成为 `2n` 个实值目标的 MOPP，并附加倒数等式约束。
5. 有效解等价：
   - Theorem 1 说明 IFOP 的有效解与对应 BOP 的有效解等价；
   - Theorem 2 说明 MIFOP 的有效解与对应 MOPP 的有效解等价。
6. 偏好映射选择：
   - 不同 `psi` 会改变区间序关系、可行域几何和最终有效解；
   - 作者把 `lambda, mu` 视为决策者偏好，例如可强调风险规避、成本效率或利润最大化。

## 实验证据

### 数值示例与理论变换验证

- Example 1 展示单目标 IFOP 通过 `v1,v2` 和 `psi_1` 转为 BOP 后，得到 `x*=1.0` 的有效解（PDF 6）。
- Example 2 对同一 IFOP 使用 `psi_2`、`psi_5`、`psi_6` 得到不同可行域和不同有效解：
  - `psi_2`：`x1*=0, x2*=3.33333`，目标区间 `[17.665,69.66]`；
  - `psi_5`：`x1*=0, x2*=2.5833`，目标区间 `[13.9165,54.666]`；
  - `psi_6`：`x1*=0, x2*=1.833333`，目标区间 `[10.1665,39.666]`。
- 作者指出早期 Bhurjee and Panda 方法在同一示例中给出 `[2.4442,-0.29418]` 这样的 improper interval，因此在该示例下无效（PDF 8）。
- Example 3 展示 MIFOP 到 MOPP 的四实目标变换，并用 LINGO11 得到有效解；作者认为相比旧方法不需要复杂多重积分，且可处理 proper 与 improper intervals（PDF 9）。

### 库存模型设置

- 应用问题：多产品库存模型，价格相关需求，有限预算和仓储空间，订货成本约束；参数如售价、采购价、持有成本、订货成本和需求可用闭区间表示。
- 单目标分式库存模型：最大化 `Total profit / Holding cost`。
- 多目标分式库存模型：
  - 最大化 `Total profit / Back ordered quantity`；
  - 最小化 `Holding cost / Total ordered quantity`。
- 区间数据示例：两种产品，`h1=[10,14]`、`h2=[14,18]`，`P1=[120,130]`、`P2=[150,170]`，`S1=[190,210]`、`S2=[210,230]`，`OC1=[70,90]`、`OC2=[80,100]`，`W=300`，`B=90000`（Table 3，PDF 14）。

### 库存模型结果

- deterministic 单目标模型：`Q1*=130.7658`、`Q2*=9.6170`、`Z*=12.0535`，最大利润 `10384.455`，持有成本 `861.5308`（PDF 13）。
- deterministic 多目标模型在 `w=0.6` 时：`Q1=130.7661`、`Q2=9.6170`，利润 `9807.4575`，最小持有成本 `861.5326`（PDF 13）。
- interval analytical 解：`Q1*=129.4858`、`Q2*=10.25710`，最大利润区间 `[8179.432,12474.29]`，最小持有成本区间 `[719.2287,1997.3192]`（PDF 14）。
- 作者观点：相较 deterministic EOQ 型模型给出单点利润，区间分式模型能给出更宽但更现实的利润/成本范围，从而反映不确定输入下的乐观与保守结果（PDF 14）。

- 对比方法：GA、PSO、GWO、HHO、MOEA/D-DE，以及 analytical formulation。

### 统计检验

- Friedman test 使用两个评价准则：
  - 最大利润区间上界，越大越好；
  - 最小持有成本区间下界，越小越好。
- Table 5 平均秩（越低越好）：MOEA/D-DE `2.25`，GA `3.50`，Analytical `3.50`，HHO `3.75`，PSO `4.00`，GWO `4.00`（PDF 16）。
- 论文实验直接支持：在这两个准则的排名定义下，MOEA/D-DE 平均秩最低。
- 证据边界：`chi_F^2=8.25` 且 `p>0.05`，作者明确说明 95% 置信水平下差异没有统计显著性（PDF 16）；因此“MOEA/D-DE 更平衡”应理解为排名模式而非显著优胜结论。

## 关键正确性与复现风险

- `psi` 不是中性的数值编码：
  - 作者示例明确显示不同 `psi` 会改变可行域几何和有效解；
  - 因此它更像决策偏好/风险态度参数，而不是不改变问题含义的纯坐标变换。
- 目标数翻倍和等式约束增加：
  - n 个区间分式目标变成 `2n` 个实值目标；
  - 同时增加每个分母上下界对应的倒数等式约束；
  - 对常规 MOEA 来说，这会提高目标维数并引入非线性等式可行性处理压力。
- 分母条件要求强：
  - 方法依赖 `0<g_i1(x)<=g_i2(x)`；
  - 分母区间跨 0 或符号不确定时，当前变换不能直接使用。
- 实验规模有限：
  - 核心应用只有两产品库存示例；
  - 摘要和结论提到 scalability study 和 higher-dimensional problems，但本次在正文/表图中未找到对应详细数据。
- 实验表存在局部不一致：
  - GWO 段落一处写最小持有成本 `[715.64,92.74]`，Table 4 和后文为 `[715.64,992.74]`，应以后者为准；
  - HHO 段落一处写 `[771.06,985.11]`，Table 4 和后文为 `[711.06,985.11]`，应以后者为准；
  - Table 4 的 MOEA/D-DE 利润区间有多余逗号 `[8084.78, , 12355.98]`。
- 元启发式比较不能证明变换优于其他建模方法：
  - 启发式算法都求解同一个已变换模型；
  - 实验主要说明变换后的模型可以被常规算法求解，并得到与 analytical benchmark 重叠的区间结果；
  - 没有与其他 interval fractional transformation 或 robust/fuzzy 多目标建模方法进行系统对比。

## 局限与未来工作

### 作者明确说明的局限或边界

- 需要为 interval space 选择具体 `psi`，不同选择对应不同有效解。
- 实验使用库存模型作为应用验证，泛化到其他大规模复杂问题仍需要进一步工作。
- Friedman 检验没有达到显著性，只能说明观察到的排名模式。

### 作者未来工作

- 可将该 interval transformation technique 与 hybrid fuzzy-neural 和 metaheuristic approaches 结合，以处理更大规模、更复杂的多目标问题（Conclusion，PDF 17）。
- 论文还指出可扩展到 portfolio selection、transportation planning 和 resource allocation 等应用（Conclusion，PDF 17）。

### 我们认为仍需确认的问题

- 如何根据应用语义选择 `lambda, mu`，而不是事后尝试多个 `psi`。
- 如何在分母可能接近 0 或符号不确定时稳定扩展该框架。
- 如何把 `2n` 目标和倒数等式约束交给 MOEA 时保持可行性和收敛性。
- 是否可以用多种 `psi` 形成偏好族，报告一组 Pareto/interval 解，而不是只固定 `psi_2`。
- 需要更大维度、更多产品和真实数据的实验，验证“scalability study”的实际证据。

## 作为基础方法时的分析

- 必须保留的核心：
  - 区间序关系必须由明确的 `psi` 和实空间偏序诱导；
  - 分式目标的分母区间需要严格为正；
  - 倒数辅助变量与原分母函数的等式约束必须保留；
  - 求解结果必须回到原区间目标上报告上下界，不能只报告 `psi` 空间值。
- 可以修改的位置：
  - `psi` 参数选择与偏好解释；
  - 把固定 `psi` 改为多 `psi` 并行求解或自适应选择；
  - 倒数等式约束的处理方式，例如罚函数、修复算子或可行性优先选择；
  - 区间约束的保守/乐观/风险加权拆分；
  - 将变换层接入 NSGA-II、MOEA/D、RVEA 或 constrained MOEA。
- 适用边界：
  - 更适合作为 interval fractional MOP 的建模预处理或目标表示层；
  - 不是可直接替代通用进化算子的搜索机制；
  - 对没有区间系数或非分式目标的普通 MOP，增益有限。

## 可复用知识与创新线索

### 已升级为设计知识

- 双射区间分式目标确定性化变换：把带区间分子/分母的分式目标，通过倒数辅助变量和 `psi` 映射转化为实值多目标问题，使常规多目标优化器可以求解。

### 暂留在论文卡中的方法、原理或架构启发

- 将区间序关系选择解释为决策偏好参数，而不是隐藏的预处理细节。
- 在不确定多目标建模中保留 optimistic/pessimistic 上下界信息，而不是先压缩成单一期望值。
- 用多个 `psi` 形成“偏好扫描”，观察解随风险/偏好映射变化的稳定性。
- 在 MOEA 中把 interval objective 的上下界作为两个目标分量，同时用用户偏好映射控制环境选择。

### 局部创新线索

- 在已有 constrained MOEA 中增加 interval-fractional objective wrapper：输入原始区间分式目标，输出 `2n` 个实值目标和倒数约束。
- 将 `psi` 参数作为算法外部偏好输入，和参考向量/权重向量联合设计。
- 为倒数等式约束设计专门 repair，使产生的后代自动满足 `v*g(x)=1`。
- 对分母接近 0 的区域加入安全缓冲或不可行惩罚，避免数值爆炸。

### 结构创新线索

- 构建“区间建模层 -> 偏好映射层 -> 常规 MOEA 求解层 -> 区间结果回译层”的不确定多目标优化框架。
- 建立多偏好子种群：不同子种群使用不同 `psi`，最终汇总为一组风险偏好可解释的区间 Pareto 解。
- 将区间分式变换与 fuzzy/neural surrogate 结合，用代理模型估计区间上下界，再由 `psi` 空间执行多目标搜索。

  - 可直接作为不确定分式多目标问题的建模预处理层，接入现有 MOEA；
  - 有 Theorem 1-2 的有效解等价论证和库存模型验证；
  - 风险主要在单篇证据、`psi` 偏好敏感、目标数翻倍、等式约束处理和实证规模有限。

## 核验结论

- 作者观点：广义区间向量空间与 `psi` 映射能把 IFOP/MIFOP 统一转化为常规 BOP/MOPP，并比早期参数积分方法更直接、更可解释。
- 论文实验直接支持：在本文库存模型中，变换后的模型可由 analytical 方法及 PSO/GA/GWO/HHO/MOEA/D-DE 求解，所得利润/成本区间总体重叠；MOEA/D-DE 在 Table 5 的平均秩最低。
- 论文实验未充分支持：未显著证明 MOEA/D-DE 优于其他方法；未给出摘要所称高维 scalability study 的详细数据；未系统比较其他 interval fractional 建模方法。
- 我们的判断：最值得复用的是“区间分式目标 -> 倒数辅助变量 -> `psi` 实空间多目标”的接口；复用时必须把 `psi` 当成显式偏好参数，并专门处理新增等式约束。
