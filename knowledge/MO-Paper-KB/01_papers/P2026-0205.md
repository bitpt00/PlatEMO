# EMT-DAKT: Evolutionary Multi-Objective Multi-Task Optimization Algorithm Using Deep Models With Adaptive Knowledge Transfer

## 一句话理解

论文提出 EMT-DAKT：在多目标多任务优化中，用更均匀且收敛的初始种群训练 GAN 型知识迁移模型，再让每个个体自适应学习“是否跨任务迁移”和“用源任务个体还是 GAN 生成知识”，最后用结合 inter-task transferred individual 与 intra-task evolutionary trend 的 DE 式子代生成来提升收敛并降低负迁移。

## 问题与动机

- 研究问题和场景：multi-objective multi-task optimization (MO-MTO)。多个相关 MOP 同时优化，任务间可能共享有用知识，但相似性未知或变化，负迁移风险高。
- 现有算法为什么不足：
  - 多数 MO-MTEA 依赖随机初始化，忽略初始 population distribution 对 GAN 或 KT model 训练质量的影响。
  - 既有 GAN-based 迁移能生成知识，但单一知识类型不适合所有任务组合。
  - 固定迁移强度或固定知识生成策略无法随任务相似性和演化阶段调节，低相似任务中容易负迁移。
  - 传统 SBX/PM 子代生成主要在父代附近搜索，global search ability 不足。
  - MO-MTO 不只要传知识，还要同时维持 convergence 与 diversity；生成知识若使用不当会提升多样性但拖慢收敛。
- 本文希望解决什么：提高 transfer knowledge 的质量，并让迁移强度和知识生成策略自适应，使跨任务迁移在不同相似度/复杂度任务中都更稳健。

## 核心理念与算法流程

- 核心理念：把跨任务迁移拆成三个层次：先用 WIPS 生成更适合训练的初始分布；再为每个 source-target task pair 训练 GAN generator 作为 knowledge transfer model；最后每个个体携带 `alpha` 和 `beta` 两个参数，分别控制 inter-task KT intensity 和 knowledge generation strategy probability，通过 offspring 生成与环境选择继承/扰动这些参数。
- 主要流程：
  1. 对每个任务用 WIPS 构造初始种群：先随机生成 `No` 个候选，再按 NBI weight vectors 和 Chebyshev metric 选出 `N` 个分布均匀且接近 PF 的个体。
  2. 每隔 `k` 代，为 source-target task pair 训练 GAN 型 KTM。初次训练满迭代，后续用上一轮权重增量训练且迭代数降为十分之一。
  3. 训练时 source task population 作为 real data，target task population 经 generator 生成 fake/intermediate individuals。
  4. 对当前任务个体，DAKT 更新两个自适应参数：`alpha` 控制是否采用 inter-task knowledge，`beta` 控制 KGSI 或 KGKTM。
  5. 若 `alpha > 0.5`，执行 inter-task KT；若 `beta > 0.5`，用 GAN KTM 生成知识，否则直接从 source task population 选个体映射到 target task。
  6. 若不跨任务，则 OGBK 用 intra-task evolutionary trend 指导搜索。
  7. OGBK 用 hierarchical selection 从按 SPEA strength 排序的等级中选变异个体，并自适应扰动 DE 参数 `F` 和 `Cr`。
  8. 子代和父代合并后用 strength Pareto approach 环境选择，保留能产生更好后代的迁移参数。
- 关键组成部分：WIPS、GAN knowledge transfer model、periodic/incremental KTM training、individual/collective transfer experience、`alpha/beta` adaptive KT parameters、KGSI/KGKTM 双知识生成策略、inter-task/intra-task OGBK、hierarchical selection、adaptive `F/Cr`。
- 可能被修改的位置：初始种群筛选方式、GAN/生成模型结构、`alpha/beta` 更新规则、KG 策略池、HS 分层数、DE 变异公式、环境选择反馈和任务映射方式。
- 必须保留的核心：迁移不是固定开关，而是个体级参数自适应；知识生成不能只依赖直接个体交换，应允许模型学习源任务 population distribution；低相似任务要能回退到 intra-task trend。

## 实验证据

- 测试问题和设置：
  - Benchmark suites：MTMOO 9 组、CEC19-CPLX 10 组、CEC21-CPLX 10 组，每组包含两个 MOP；共计 58 个 benchmark tasks。
  - Real-world application：基于 IEEE30 和 IEEE57 bus systems 构造 OPF MO-MTO，两任务、四组目标组合，共 8 个 tasks。
  - Baselines：MO-MFEA、MO-MFEA-II、EMT-ET、EMT-PD、EMT-GS、MTDE-MKTA。
  - Population size：每个 task `N=100`；bi-objective instances `1000*N*T` FEs，tri-objective instances `1200*N*T` FEs，OPF `1000*N*T` FEs。
  - EMT-DAKT GAN：generator 三层全连接，discriminator 两层全连接；batch size 10；max iterations 200；generator/discriminator learning rates 分别为 `3e-4` 和 `2e-4`。
  - 平台：MATLAB R2022a，MTO-Platform；指标 IGD+ 和 HV；Wilcoxon rank-sum test 0.05、Friedman test、Bonferroni-Dunn test。
- 综合结果：
  - MTMOO：EMT-DAKT 在 18 tasks 上 IGD+ / HV 平均排名分别为 1.6111 / 1.7222。作者指出其在 NILS 等低相似任务上 convergence 和 diversity 优于对比算法，但在 PIMS-T2 上略弱于 EMT-ET。
  - CEC19-CPLX：IGD+ / HV 平均排名分别为 1.4250 / 1.5000；作者认为 DAKT 的自适应迁移强度和 KG strategy selection 提升了复杂场景下的收敛。
  - CEC21-CPLX：IGD+ / HV 平均排名分别为 2.4000 / 3.0250；在更复杂任务上仍保持较好泛化，但 MO-MFEA-II 在部分 tasks 上表现较强。
  - Bonferroni-Dunn：58 tasks、7 algorithms、0.05 显著性下 critical difference 为 1.0582；作者称 EMT-DAKT 与多数对比算法显著不同。
  - Runtime：GAN 引入额外时间，但 MTMOO 和 CEC19-CPLX 上运行时间与 MO-MFEA-II、EMT-GS 相近；CEC21-CPLX 上低于 MO-MFEA-II。
  - OPF：EMT-DAKT 在 8 个 real-world OPF tasks 中 5 个取得最佳 HV，并在整体性能评价中排名第一。
- 消融和机制证据：
  - 综合消融：四个变体分别替换 WIPS、GAN、adaptive KT 和 OGBK；完整 EMT-DAKT 在三套 benchmark 上 IGD+ / HV 平均排名为 2.3362 / 2.4569，优于各变体。
  - GAN KTM 消融：去掉 KGKTM、只保留 KGSI 的 wo-KGKTM 弱于完整方法；完整 EMT-DAKT 在 CEC19-CPLX 上 IGD+ / HV 平均排名为 1.2750 / 1.2500。
  - `alpha/beta` heatmaps：NIHS-T1 早期多数个体用 inter-task KT，200 generations 后逐渐减少以降低负迁移；CEC19-CPLX7-T1 多数个体倾向 KT model；CEC21-CPLX3-T1 中少数个体采用 inter-task KT 并持续调整 KG 策略。
  - 参数敏感性：`No=5N` 在初始化质量和训练资源间折中；`k=10`、`mu_kt=0.4` 降低开销并探索更好 KT 参数；`Ln=5`；`mu_es=0.2`。
- 证据边界：
  - 表格具体单元在 Markdown 中多为图片省略，只能可靠记录正文给出的平均排名和定性比较。
  - EMT-DAKT 同时引入 WIPS、GAN、adaptive KT、OGBK，综合提升不能完全归因于单一模块。
  - GAN 训练开销在两任务 benchmark 上可接受，但作者明确指出多于两个任务时开销较大。
  - 参数较多，敏感性虽给出推荐值，但跨任务/跨领域默认值稳定性仍需复核。

## 局限与未来工作

- 作者明确说明的局限：
  - GAN training time overhead relatively large，尤其面对超过两个 tasks 的情况。
  - EMT-DAKT 引入 many parameters，使 parameter tuning 更复杂。
- 作者未来工作：
  - 探索更有效的 knowledge generation strategies，从 source task population 中提取高质量 transfer knowledge。
- 我们认为仍需确认的问题：
  - GAN 是否比 VAE、normalizing flow、diffusion、score model 或轻量 density estimator 更稳。
  - `alpha>0.5`、`beta>0.5` 的硬阈值是否最优；是否应改为连续混合比例。
  - `alpha/beta` 只通过成功个体继承，是否足以进行长期 credit assignment。
  - 多任务数增加时，source-target pairwise KTM 的数量和训练成本如何控制。
  - 统一搜索空间映射在异构维度或异构变量语义任务中是否可靠。

- 值得建立或补充的设计知识：

- 暂留在论文卡中的方法、原理或架构启发：
  - WIPS 的“先过采样再按权重向量筛选”适合任何需要用 population 训练生成模型的 MOEA。
  - `alpha/beta` 是很轻量的个体级策略基因，可迁移到迁移概率、修复概率、代理调用概率或 local search 触发概率。
  - KGSI/KGKTM 双策略说明直接迁移和模型生成各有适用场景，适合用 bandit 或 credit assignment 进一步泛化。
- 局部创新线索：
  - 将 `alpha/beta` 从二分阈值改成 Dirichlet/softmax 策略，支持多个 source tasks 和多个 generator。
  - 用 source-target transfer success 构造动态任务图，只训练高价值边上的 KTM。
  - 用 replay buffer 记录 transferred individual 的后续 survival/HV contribution，对 GAN generator 做后验微调。
  - OGBK 中把 intra-task trend 换成 archive trend、reference-vector trend 或 surrogate gradient。
- 结构创新线索：
  - 构建 MO-MTO 的生成式知识路由层：source archive -> generator pool -> transfer gate -> offspring operator -> survival feedback。
  - 与多邻域/子问题迁移结合：每个子问题维护自己的 `alpha/beta`，GAN 只在相似子问题邻域间生成。
  - 在工程多场景优化中，把不同工况视为 tasks，用生成器学习从历史工况到当前工况的可行高质量候选分布。
