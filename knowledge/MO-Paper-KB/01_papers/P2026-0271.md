# Dynamic Escaping Population Driven Evolutionary Algorithm for Multi-objective Optimization Problems with Deceptive Constraints

## 一句话理解

论文提出 DEPEA：在 deceptive constrained MOP 中，`CV` 可能越接近 CPF 反而越大，因此算法不再让所有种群都信任 `CV`，而是维护 AP、EP、MP 三个种群；AP 追 UPF，EP 通过保留每个子区的次优或最差个体主动从 UPF 慢速/快速逃逸，MP 在后期用 CDP 开发 CPF，并通过单向可行解共享和边界稀疏种子增强来兼顾可行域发现、收敛和多样性。

## 问题与动机

- 研究问题和场景：
  - Deceptive constrained multi-objective optimization problems (DCMOPs)；
  - deceptive constraint 指：沿同一 CPF 法线方向，离 CPF 更近的不可行解可能有更大的 `CV`；
  - 这会让依赖 `CV` 的 CDP、epsilon、penalty、CV-as-objective 等 CMOEA 被错误方向诱导；
  - 现实例子包括 Haverly pooling 和 process flow sheeting 等非线性工程约束问题。
- 现有算法为什么不足：
  - 普通 CMOEA 过度依赖 `CV`，在 DCMOP 中可能保留低 `CV` 但远离 CPF 的解；
  - 均匀探索 objective space 的 DCMOP 算法能找可行区域，但对已发现区域 exploitation 不够；
  - 决策空间均匀采样/多步采样能穿透 deceptive region，但会生成大量无用候选，评价资源浪费；
  - DPTPEA 的 boundary sampling 只有在找不到可行解时触发，一旦已有局部可行片段，可能错过其它 CPF 片段。
- 本文希望解决什么：
  - 在不过度相信 `CV` 的前提下，沿 UPF 参考方向系统探索远离 UPF 的区域；
  - 一旦 AP 找到可行解，及时让 EP 停止无效逃逸并开发该可行区域；
  - 后期让 MP 利用已发现的可行信息逼近 CPF，同时增强边界稀疏区域探索。

## 核心理念与算法流程

- 核心理念：
  - 对 DCMOP，UPF 可通过 objective values 稳定识别，不受 deceptive `CV` 影响；
  - 如果 CPF 不在 UPF 附近，仅靠 AP 追 UPF 无法找到 CPF；
  - 可以故意在每个 angle subregion 中保留 objective fitness 较差的解，形成“从 UPF 逃逸”的搜索力；
  - 逃逸速度需要分阶段调节：慢速逃逸细致搜索 UPF 附近和中距离区域，快速逃逸补足更远区域；
  - 若子区已有可行解，应终止该子区逃逸，转为开发可行区域。
- 三种群分工：
  - AP (auxiliary population)：忽略约束，使用 angle-based environmental selection，保留每个子区 best solution，收敛到 UPF；
  - EP (escaping population)：忽略 `CV` 形成 escape behavior，UPF exploitation phase 保留 second-best，CPF exploration phase 保留 worst；
  - MP (main population)：后期复制 EP 初始化，用 CDP 聚焦 CPF，最终作为输出。
- 两阶段框架：
  - UPF exploitation phase：
    1. AP 和 EP 均用 GA 生成 offspring；
    2. AP 自己更新，不接受 EP 个体；
    3. AP 中的 feasible solutions 单向共享给 EP；
    4. AP 用 angle-based selection 追 UPF，EP 用 slow escape mode；
    5. 当 AP 的 average/ideal/nadir point change rate 小于阈值，或消耗评估数超过比例 `r=0.15`，切换阶段。
  - CPF exploration phase：
    1. MP 由 EP 复制初始化；
    2. 当 EP 仍在逃逸时，MP 与 EP 采用 weak cooperation 共享 offspring；
    3. MP 用 CDP 选择，EP 用 rapid escape mode；
    4. 当 EP change rate 小于阈值或评估数超过比例 `l=0.25` 后，EP 停止；
    5. MP 独立进化，使用 BDES 和 neighbor pairing strategy 生成 offspring。
- Slow / rapid escape mode：
  - 把 objective space 按 weight vectors 划分子区；
  - 每个子区用不含 `CV` 的 angle-based fitness 评价候选；
  - slow mode 在无可行解时保留 second-best solution，产生弱逃逸力；
  - rapid mode 在无可行解时保留 worst solution，产生强逃逸力；
  - 若子区为空，从最近的三个候选中按 slow/rapid 规则补齐；
  - 若子区已有可行解，则基于 CDP 保留最佳可行解，停止该子区逃逸。
- One-way fine-grained cooperation：
  - AP 追 UPF，EP 逃离 UPF；EP 个体对 AP 收敛无益，还会增加选择复杂度；
  - AP 普通 offspring 进入 EP 会干扰 second-best 保留，让 EP 逃逸失败；
  - 只有 AP 发现的 feasible solutions 被共享给 EP，帮助 EP 避免继续探索已知不可 promising region；
  - 关闭单向合作会让 NCMOP 上 EP 逃得太远，弱合作则会在 FCP3/FCP4 阻碍 slow escape。
- Boundary diversity enhancement strategy (BDES)：
  - 对 MP 计算每个解到前 `k` 个近邻的距离和，得到 sparsity / NBD；
  - 选择最高 sparsity 的 `NP/k` 个 boundary/sparse seeds；
  - 每个 seed 用 `DE/seed/1` 生成 `k` 个 offspring；
  - 使 MP 在 sparse boundary regions 有更多采样机会，改善 CPF 完整覆盖。
- 可能被修改的位置：
  - 子区划分可从 weight vectors 改为 reference vectors、clustering 或 learned sectors；
  - second-best / worst 保留可扩展为第 `q` 分位解、adaptive rank 或 bandit-controlled escape speed；
  - 单向合作可从 feasible-only 改为 high feasible-probability 或 repaired-feasible candidates；
  - BDES 的 sparsity 可换成 angle density、decision-space distance、CPF-fragment coverage 或 boundary uncertainty。
- 必须保留的核心：
  - 在 deceptive constraints 下，搜索不能把低 `CV` 等同于接近 CPF；
  - 至少有一个种群要用 objective-only 信息构造脱离 UPF 的方向；
  - 逃逸过程要有停止机制，避免 NCMOP 或已找到可行区域时无意义远离；
  - AP/EP 之间的信息流要限制，避免 AP 的最优收敛和 EP 的逃逸目标互相污染。

## 实验证据

- 实验设置：
  - 四个 benchmark suites：DCMOP、FCP、MW、DAS-CMOP；
  - DCMOP 和 FCP 用于 deceptive constraints，其中 FCP 含 objective/decision space constraints 和多个 deceptive regions，更难；
  - MW 和 DAS-CMOP 用于 normal constrained MOPs，检查 DEPEA 在非欺骗约束上的泛化；
  - 六个 real-world CMOPs：two-bar truss design、spring design、bulk carrier design、Haverly pooling、process flow sheeting、SOPM7；
  - 所有问题最大函数评价数 300000；
  - 13 个对比算法：BiCo、C-TAEA、PPS、CCMO、c-DPEA、TPEA、MOEAD-CMT、CMOEMT、CSEMT、MTCMO、ICMA、DPTPEA、EMCMMS；
  - 指标为 IGD+ 和 HV，30 次独立运行，Wilcoxon rank-sum test 显著性 0.05。
- DCMOP / FCP 结果：
  - Table I 中 DEPEA 在 11 个 DCMOP/FCP 问题上，相比 13 个算法的 IGD+ 显著更优数量分别为 11、10、11、11、11、10、9、11、6、10、11、11、9；
  - 被对比算法显著超过的数量分别只有 0、1、0、0、0、0、2、0、3、0、0、0、0；
  - HV 结果趋势相似：DEPEA 对 13 个算法显著更优数量分别为 10、10、11、10、10、9、9、11、6、10、11、11、8；
  - FCP1-FCP4 中很多通用 CMOEA 无法得到可行解，表中为 NaN，而 DEPEA 能获得可行解。
- FCP5 行为解释：
  - FCP5 的 CPF 被 infeasible regions 分成上下两个 segment；
  - 非 DCMOP 专用算法通常只能找到较容易的 lower segment；
  - 只有 DEPEA、EMCMMS、ICMA 找到 upper segment，且 DEPEA 最好；
  - DPTPEA 因 Phase 1 已找到可行解，不触发 boundary sampling，错过 upper segment；
  - EMCMMS 多步变异能找到完整 CPF，但资源消耗高，找到可行域后仍持续到 50% MaxFEs；
  - ICMA 能找可行域但 exploitation 不足，收敛精度弱于 DEPEA。
- NCMOP 结果：
  - 在 DAS-CMOP 和 MW 的 23 个问题上，DEPEA 的 IGD+ 相比 13 个算法显著更优数量分别为 20、19、21、20、20、17、18、21、15、18、15、19、21；
  - 显著更差数量分别为 2、3、0、2、2、2、3、1、5、2、6、2、1；
  - HV 趋势相似，说明 EP 的停止机制使 DEPEA 在普通约束问题上仍保持竞争力。
- 策略验证：
  - `DEPEA noEP` 去掉 EP 后在整个 FCP benchmark suite 上失败；
  - `DEPEA onlyS` 只保留 slow escape，后期选择压力不足，EP 原地振荡并浪费评价；
  - `DEPEA onlyR` 和 `DEPEA third` 逃逸过快，在 FCP3/FCP4 无法得到可行解；
  - 结论：EP 必要，slow mode 必须保留 second-best，rapid mode 是补全逃逸过程的机制。
- UPF-CPF 距离变化验证：
  - 作者移动 FCP1/FCP2 的 CPF 位置生成变体；
  - CPF 与 UPF 距离越远，问题越难；
  - CPF 向前移动的变体上几乎所有算法都能找到可行解；
  - CPF 向后移动到更远位置时，仅 ICMA、EMCMMS、DEPEA 能获得可行解；
  - DPTPEA 在 FCP1_1 中失败，因 CPF 到 objective-space boundary 附近后 boundary sampling 几乎浪费。
- 单向合作验证：
  - `DEPEA weakC` 在 UPF exploitation phase 使用普通 weak cooperation，在 FCP3/FCP4 无法获得可行解，因为 AP 信息阻碍 EP slow escape；
  - `DEPEA along` 关闭单向 transfer，在 DCMOP 上可行，但 NCMOP 性能明显下降，因为 EP 缺少及时停止逃逸的机制。
- BDES 验证：
  - `DEPEA DE` 和 `DEPEA GA` 在个别偏多样性或偏收敛的问题上可能超过 BDES；
  - 整体上完整 DEPEA 最好，说明边界稀疏种子增强对综合性能有贡献。
- 证据边界：
  - 主文只列 DCMOP/FCP 的 IGD+ Table I，HV、NCMOP、真实问题、参数敏感性、rank 和 scalability 多数在 supplementary；
  - DEPEA 对 equality constraints 表现不足，作者明确承认；
  - 真实问题中 deceptive constraints 的分布主要通过 supplementary figure 展示，主文没有逐题数值表；
  - 优势来自 EP、单向合作、BDES、MP/CDP 等组合，单模块贡献需结合消融理解。

## 局限与未来工作

- 作者明确说明的局限：
  - slow escape mode 虽能保持搜索强度，但对 equality constraints 仍不足；
  - 当 CPF 由等式约束定义时，DEPEA 难以准确识别可行区域；
  - 未来需要更全面的人工 DCMOP、更深入的真实 DCMOP，以及更灵活的 EP 策略。
- 作者未来工作：
  - 构造更 comprehensive artificial DCMOPs；
  - 进一步探索 real-world deceptive constraints；
  - 设计更灵活的 escape population strategy，例如 bidirectional 或 adaptively weighted collaboration。
- 我们认为仍需确认的问题：
  - second-best / worst 的离散逃逸速度是否可用连续分位数或在线反馈替代；
  - objective-only fitness 在 many-objective 下是否仍能稳定定义 UPF 逃逸方向；
  - AP  feasible-only transfer 对噪声约束或近可行解是否过于保守；
  - BDES 的 Euclidean decision distance 在高维强冗余变量下是否能表示真实 CPF 边界稀疏性；
  - phase switching 依赖固定 `r=0.15`、`l=0.25` 和 `sigma=4e-5`，可能需要问题自适应。

- 局部创新线索：
  - 将 escape rank 从固定 second-best / worst 改成自适应 rank：根据 feasibility discovery rate、UPF-CPF 距离估计或 population stagnation 调节；
  - AP 向 EP 共享的不只是可行解，也可以是 repair 后可行、预测可行或低不确定性 boundary candidates；
  - BDES 的 seed 选择从 kNN sparsity 扩展为 objective-space boundary、constraint-active boundary 和 decision-space novelty 的组合；
  - equality constraints 场景中，在 EP 逃逸后加入 projection / repair / root-finding 层。
- 结构创新线索：
  - 构建 CV 不可信场景下的三通道约束优化框架：UPF anchor、escaping scouts、feasibility exploiters；
  - 与自适应 CV 粒度结合：MP 后期使用细 CV，EP 始终不直接用 CV，AP 提供可行停止信号；
  - 与 surrogate 结合：用代理估计 UPF-CPF distance 和 feasible probability，决定 escape speed 与共享门槛；
  - 与多任务 CMOEA 结合：不同 escape speeds 作为多个辅助任务并行运行，由主任务按可行贡献分配预算。
